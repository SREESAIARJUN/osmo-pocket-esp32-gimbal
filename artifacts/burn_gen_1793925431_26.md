# STM32H743 Nano FC + 4-in-1 80A ESC: System Design Package

**Revision A. Engineering model with stated assumptions.**

> **Scope note.** This package treats "80A burst" as **per channel, ≤ 2 s**, on a **6S (25.2V peak)** bus. Every component value below is a *design-basis assumption* chosen to be representative of real parts in this class. Before layout freeze, substitute the actual datasheet values into the equations in §2–§3. The model is built so you only need to change the parameter table.

---

## 0. Architecture Decision (Read First)

ArduPilot running on the H743 **cannot directly commutate MOSFETs**. A production "FC + 4-in-1 ESC" stack therefore uses this split:

| Domain | Device | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) | ArduPilot (ChibiOS) | Attitude control, emits bi-dir DShot600 ×4 |
| ESC ×4 | STM32G071GBU6 or AT32F421 (one per motor) | AM32 / BLHeli_32 | Six-step commutation, 48 kHz PWM, eRPM telemetry |
| Gate drive ×4 | FD6288Q-class 3-phase half-bridge driver | n/a | Drives 6 N-FETs per channel |
| Power stage | 24× N-MOSFET, 40V, 3.3×3.3 or 5×6 PQFN | n/a | 6 per channel |

The FC-to-ESC link is the DShot wire, which is the subject of §4. The two halves can share one PCB, or be stacked on 20×20 / 25.5×25.5 mounting.

## 2. Loss Model

### 2.1 Conduction topology (six-step, complementary PWM with synchronous rectification)

In each 60° sector, one leg is PWM'd (HS at duty *D*, LS complementary) and one leg's LS is held fully on. Phase current *I* therefore always flows through **exactly two FETs**.

Over one electrical cycle, each leg spends 120° sourcing, 120° sinking, and 120° floating. That gives the following per-FET average conduction loss:

$$
P_{cond,HS} = \frac{1}{3}\,D\,I^2 R_{ds}(T_j), \qquad
P_{cond,LS} = \frac{1}{3}\,(2-D)\,I^2 R_{ds}(T_j)
$$

$$
R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]
$$

Summed over the 6 FETs of a channel:

$$
P_{cond,ch} = 3\cdot\tfrac{1}{3}\big[D + (2-D)\big] I^2 R_{ds} = 2\,I^2 R_{ds}
$$

This total is independent of *D*. Only the distribution between HS and LS changes. **The LS FET is always the hotter device.**

**Numbers at 80 A, T_j ≈ 110 °C** (R_ds = 1.5 mΩ × 1.51 ≈ 2.27 mΩ, rounded to 2.25 mΩ):

- I²R = 6400 × 2.25e-3 = **14.4 W** (one FET at 100 % conduction)
- P_cond,ch = 2 × 14.4 = **28.8 W per channel**
- Worst FET (LS, D → 0.95): (1.05/3) × 14.4
