# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #51 specification, so this design uses typical brushless gimbal parameters. Every assumption is listed in the table below and exposed as a configuration constant in the code, so you can substitute your real values.

| Parameter | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit magnetic (AS5048/MT6701-class), read at the current-loop rate |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7-class) |
| IMUs | 2 × ICM-42688-P on SPI, both on the camera/payload plate |
| Disturbance | Propeller/frame vibration, roughly 80–400 Hz, drifting with throttle |

## 1. Loop Architecture and Rates

```
              1 kHz              4 kHz                  20 kHz
 q_ref ──► [Attitude/Angle] ─► [Velocity PI] ─► iq* ─► [Current PI + FOC] ─► SVPWM ─► Motor
             ▲    P(+I)           ▲    │  + iq_ff (anti-cogging, θ_m)           │
             │                    │    └───────────────────────────────────────┘
       q̂ (Mahony)           ω_joint (gyro-projected, encoder blended)        θ_e (encoder)
             ▲                    ▲
      [Dual ICM-42688-P @ 8 kHz ODR → consistency/fusion → adaptive notch → static notch → LPF]
```

**Bandwidth separation rule.** Each loop should be at least 4–5× slower than the loop inside it:

- ω_c (current) ≈ 2π·1.5 kHz
- ω_v (velocity) ≈ 2π·150 Hz
- ω_p (angle) ≈ 2π·25 Hz
