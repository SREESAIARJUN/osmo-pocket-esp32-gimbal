# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

> **Scope note:** I don't have the Job #27 requirements, so this design states its assumptions in §0. Every parameter that depends on your hardware is a named constant in `GimbalConfig`. Replace them with your measured values before closing any loop on hardware.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7-class, Cortex-M4F/M7 with FPU at 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH (phase), Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5047P class) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR |
| Current loop | 20 kHz, synchronized to the center-aligned PWM ADC trigger |
| Velocity loop | 4 kHz (every 5th PWM period) |
| Angle loop | 1 kHz |
| Dominant vibration | Propeller fundamental 80–300 Hz, plus its 2nd harmonic |

**Bandwidth separation rule:** each loop's bandwidth is at most 1/5 to 1/10 of the next inner loop's bandwidth.
