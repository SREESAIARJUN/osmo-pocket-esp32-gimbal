# 3-Axis Gimbal: FOC Control and Dual-IMU Sensor Fusion Design

I have no prior context for Job #49, so this design rests on the explicit hardware assumptions in §0. Every equation is parameterized, so you can substitute your actual motor and IMU values.

---

## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G4/H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Current sense | 2- or 3-shunt, sampled center-aligned |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, synchronized via CLKIN |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates and bandwidth separation (factor of 5–10 between loops):**

```
 IMU 8 kHz ODR ─► AAF/notch/LPF ─► dual fusion ─► Mahony AHRS (1 kHz)
                                          │                   │
                                          │ ω_cam             │ q̂
                                          ▼                   ▼
 Attitude loop (1 kHz, ~15 Hz BW) ──► ω_cmd ─► Rate loop (4 kHz, ~80 Hz BW)
                                                   │  J⁻¹(r,p) joint map
                                                   ▼
                       i_q* + anti-cogging FF ─► FOC current loop (20 kHz, ~1.5 kHz BW)
                                                   │
                                                   ▼ SVPWM ─► motor ─► encoder (PLL)
```
