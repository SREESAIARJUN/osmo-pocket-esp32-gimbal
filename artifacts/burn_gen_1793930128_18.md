## 0. Scope, Architecture and Assumptions

No MOSFET, board stack-up, battery voltage or burst duration was specified, so the analysis below is **parametric**. Representative values are flagged ⚠ and must be replaced with datasheet values before sign-off. The closed-form equations remain valid for any part.

**Architectural note.** The H743 does **not** generate the 48 kHz commutation PWM. Each motor channel has its own ESC MCU running AM32 or BLHeli_32. The H743 sends bi-directional DShot600 to those MCUs and receives eRPM telemetry back.

```
 6S LiPo ─┬─ Bulk C ─┬─ ESC1 (AT32F421 + 3-ph driver + 6× NFET) ── M1
          │          ├─ ESC2 … ESC4
          │          └─ Shunt + INA ── CURR → H743 ADC
          └─ 5V/10V BEC ── H743 FC (IMU, baro, OSD, flash)
 H743 TIM1 CH1–4 ── bidir DShot600 ──► ESC1–4 signal pins
```
