# Job #63: STM32H743 Nano FC + 4-in-1 80A ESC Design Package

## 0. Architecture Correction (Read First)

Three findings change the design before any math applies:

1. **The STM32H743 cannot be the commutation MCU for four motors.** It has only two advanced timers (TIM1, TIM8) with complementary outputs and hardware dead-time, which is enough for two 3-phase bridges, not four. The workable architecture, used by every production AIO, is:
   - **H743**: runs ArduPilot and sends bidirectional DShot600 to the ESC.
   - **4× AT32F421 (or STM32G071)**: run AM32, each doing 6-step commutation at 48 kHz.
2. **"80A per channel" on a nano form factor is a transient rating only.** Section 2 shows it holds for roughly 2–3 seconds, not continuously. The honest label is **"80A burst (≤2 s) / ~30A continuous"** at 6S, and the spec sheet should say so.
