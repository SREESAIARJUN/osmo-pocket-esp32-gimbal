# STM32H743 AIO + 4-in-1 ESC (Job #32): Power-Stage, Thermal and Bi-Directional DShot Design Package

## 0. Architecture Clarification and Assumptions

On every production 4-in-1 design I know of, the **STM32H743 does not commutate the motors**. The H743 runs ArduPilot and sends bi-directional DShot600 to four **ESC MCUs** (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071). Those ESC MCUs generate the **48 kHz** six-step PWM. The model is split along that boundary.

All component values below are **representative design parameters**, not datasheet quotes. Substitute your selected MOSFET's actual R_DS(on)(T), Q_g, Q_gd, Q_rr and Z_th curves before sign-off.

## 1. Conduction Loss Model

### 1.1 Six-step commutation with synchronous rectification

In each 60° sector:
- One phase high-side is PWM'd at duty D, with complementary low-side synchronous rectification for (1−D).
- One phase low-side is held on at 100%.

The current path therefore always passes through **exactly two conducting MOSFETs in series**:

$$P_{cond,bridge} = 2\, I_{ph}^2\, R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{DS25}\left[1 + \alpha (T_j - 25)\right]$$

### 1.2 Per-device split over one electrical cycle

| Device | Conduction fraction |
|---|---|
| High-side (HS) | D/3 |
| Low-side (LS) | 1/3 (static on) + (1−D)/3 (sync rectification) |

Per-device conduction power:

$$P_{HS} = \tfrac{D}{3}\, I^2 R_{DS}, \qquad P_{LS} = \tfrac{2-D}{3}\, I^2 R_{DS}$$

At full-throttle burst (D → 1), both reduce to I²R/3.

### 1.3 Numbers at the 80 A burst, with self-heating

$$R_{DS}(125\,^\circ\text{C}) = 1.0 \times 1.55 = 1.55\ \text{m}\Omega$$

$$P_{cond,bridge} = 2 \times 80^2 \times 1.55\times10^{-3} = \mathbf{19.8\ W\ per\ motor\ channel}$$

That is ≈ 3.3 W per MOSFET.
