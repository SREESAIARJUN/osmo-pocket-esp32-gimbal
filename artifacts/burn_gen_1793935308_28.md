# STM32H743 Nano FC + 4-in-1 ESC: Architecture & Design Derivations (Job #40)

## 0. Scope, Assumptions & Design Corrections

Several premises in the brief need correcting before any math is useful:

| Item | Clarification |
|---|---|
| **MCU partitioning** | The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. Each ESC channel needs its own commutation MCU running AM32, e.g. 4× AT32F421K8U7 (the current AM32 reference target). The H743 talks to them over bidirectional DShot600. |
| **"80A burst"** | This is treated as **80 A RMS phase current per channel, for a limited duration**. On a 30.5×30.5 mm board this is a thermally time-limited rating, not a continuous one. Section 3 derives the actual time limit. |
| **48 kHz PWM** | This is the ESC MCU PWM frequency (AM32 supports 24/48/96 kHz). It is unrelated to the DShot rate. |
| **Bus voltage** | 6S LiPo: V_bus = 25.2 V max, 22.2 V nominal. Worst-case math uses 25.2 V. |
| **MOSFETs** | Representative 40 V PQFN 3.3×3.3 class device. You must substitute your chosen part's datasheet values. |
