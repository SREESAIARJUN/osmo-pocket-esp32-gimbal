I don't have the Job #43 spec sheet, so this design uses the hardware assumptions in §0. Every motor-, encoder-, and IMU-specific constant lives in one config struct so you can substitute your real values.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.2 mH, K_t ≈ 0.07 N·m/A |
| Encoder | AS5048A-class, 14-bit absolute magnetic, SPI |
| Driver | 3-phase, 3-shunt low-side current sense, 24 V bus |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, both locked to the same CLKIN |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) loop | 20 kHz (PWM-synchronous) | ≈ 1.5–2 kHz |
| Velocity loop | 4 kHz | ≈ 150–250 Hz |
| Angle (attitude) loop | 1 kHz | ≈ 20–40 Hz |
| IMU fusion | 8 kHz in, 1 kHz decimated out | — |

Keep each outer loop's bandwidth at least 5–10× below the loop inside it. That separation lets you tune each loop as if the inner loop were ideal.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is the encoder-to-rotor alignment offset. Find it by applying a fixed d-axis vector and recording the encoder reading.

**Latency compensation.** The SPI read, ADC conversion, and PWM update together delay the angle by t_d (≈ 1.5·T_pwm). Advance the angle used for the inverse Park transform by that delay:

$$\hat\theta_e = \theta_e + p\,\omega_m t_d$$

### 1.2 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(\text{using } i_a+i_b+i_c=0)$$

With three shunts, drop the phase whose low-side duty is shortest (least reliable sample) and reconstruct it from the other two.

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant and PI design by pole-zero cancellation

The dq-frame plant is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Choose PI gains so the controller zero cancels the electrical pole at R/L. The closed loop then becomes first order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

With the assumed values and ω_c = 2π·1500: K_p = 20.7 V/A, K_i = 52.8 kV/(A·s).

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e \hat L\, i_d + \hat\omega_e\hat\lambda_m$$

where λ_m = K_t / (1.5 p).

**Set-points.** Use i_d* = 0 (surface-mount PM motor, no field weakening needed for a gimbal).

### 1.5 Voltage limiting

The linear-SVPWM voltage limit is

$$|v| \le V_{max} = \frac{V_{dc}}{\sqrt3}$$

Allocate voltage with d-axis priority:

$$v_d^{sat} = \text{clamp}(v_d^*, \pm V_{max}),\qquad v_q^{sat} = \text{clamp}\!\left(v_q^*, \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

### 1.6 Discrete PI with back-calculation anti-windup

The integrator update uses the forward-Euler form (integral term updated after output):

$$u_k = K_p e_k + I_k,\qquad u_k^{s} = \text{sat}(u_k)$$
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u_k^s - u_k)\right],\qquad K_{aw} \approx \frac{K_i}{K_p}$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

Inverse Park, then inverse Clarke:

$$v_\alpha = v_d\cos\hat\theta_e - v_q\sin\hat\theta_e,\qquad v_\beta = v_d\sin\hat\theta_e + v_q\cos\hat\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Inject the min-max zero-sequence offset and convert to duty cycles:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

The disturbance τ_dist includes cable drag, imbalance, and base motion coupling.
