# STM32H743 Nano Flight Controller + 4-in-1 ESC: Power-Stage Thermal Model and Bidirectional DShot600 Architecture

## 0. Architecture Correction and Scope

Before the math, one architectural point shapes everything below.

**The STM32H743 does not commutate the motors.** In any ArduPilot-compatible 4-in-1 stack, the work is split as follows:

| Function | Device | Firmware |
|---|---|---|
| Flight control, DShot600 master, bidirectional telemetry decode | STM32H743 (400 MHz) | ArduPilot |
| 6-step commutation, 48 kHz complementary PWM, back-EMF sensing | 4× ESC MCUs (e.g. AT32F421 / STM32G071 / STM32F051) | AM32 or BLHeli_32 |
| Gate drive | 4× three-phase half-bridge drivers (FD6288Q-class) | — |
| Power stage | 24× N-MOSFETs (6 per motor) | — |

The 48 kHz switching analysis therefore applies to the ESC MCUs. The DShot/DMA analysis applies to the H743.

**"80A burst" is ambiguous, so both cases are modeled:**
- **Case A:** 80 A per motor (320 A total). This is what marketing labels usually imply.
- **Case B:** 80 A total (20 A per motor).

As the math shows, Case A is not physically sustainable on a nano (≈20×20 mm mounting, ~25×25 mm board) form factor beyond about 1–2 seconds.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R_DS = 1.5 × 1.51 ≈ **2.27 mΩ**

### 2.2 Six-step synchronous commutation

In any 60° sector, current flows through exactly two legs. With complementary (synchronous-rectified) PWM, each leg always has exactly one FET conducting, either the high-side (duty D) or the low-side (1−D). The series path resistance is therefore always 2·R_DS, **independent of duty cycle**:

$$P_{cond,motor} = 2\,I^2\,R_{DS}(T_j)$$
