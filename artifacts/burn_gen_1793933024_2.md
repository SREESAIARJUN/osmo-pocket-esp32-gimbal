# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original spec for Job #6, so this design states its assumptions explicitly. Each assumption maps to one constant in the code. Change them in `GimbalConfig` and the gain formulas recompute.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5.6 Ω, L ≈ 2.2 mH, λ ≈ 0.0135 Wb |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT
