### 0.1 Architecture

The STM32H743 runs ArduPilot only. It does not commutate motors. Each motor is driven by its own ESC MCU running AM32 or BLHeli_32-class firmware, because commutating 4 sensorless motors at 48 kHz on the H743 alongside the EKF is not how ArduPilot works.

```
 6S LiPo ─┬─► 4-in-1 ESC board (36×36 mm, 30.5 mm mount) [A]
          │    4 × [ESC MCU → 3-phase gate driver → 6 × N-MOSFET]
          │         ▲ DShot600 bidirectional (1 wire per motor, inverted)
          │         │
          └─► FC board: STM32H743 @ 400 MHz, ArduPilot
                TIM1_CH1..CH4 → M1..M4
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths

In 6-step mode with complementary PWM, exactly two MOSFETs carry the phase current at every instant:

- **PWM on:** HS_x and LS_y conduct.
- **PWM off:** LS_x (synchronous rectifier) and LS_y conduct.

So the conduction loss per motor is independent of duty cycle:

$$P_{cond} = 2\,I_{ph}^2\,R_{DS(on)}(T_j)$$

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

### 1.2 Electro-thermal iteration

Conduction loss raises T_j, which raises R_DS(on), which raises loss again. Start the iteration at T_j = 100 °C:

- R = 0.75 mΩ × (1 + 0.0045 × 75) = **1.003 mΩ**
- P_cond = 2 × 80² × 1.003×10⁻³ = **12.84 W per motor**

The converged value is computed in §3.4.

### 1.3 Copper and shunt losses

| Contributor | Resistance | Loss at 80 A |
|---|---|---|
| Phase path: 2 oz outer + 2 oz inner layers, ~15 mm, ~5 mm wide [A] | ≈ 0.25 mΩ | I²R ≈ 1.6 W |
| Shared bus-current shunt (if fitted) | 0.25 mΩ | Carries I_bus = D · I_ph, so its loss is smaller than a phase-path loss |
