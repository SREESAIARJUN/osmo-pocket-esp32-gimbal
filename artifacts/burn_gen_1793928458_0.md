# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage Model, Thermal Budget, and Bi-Directional DShot600 Allocation

**Scope note:** No prior Job #4 specification was provided, so this document states every assumption explicitly. Device parameters marked **[A]** are representative of 40 V trench MOSFETs in 5×6/3.3×3.3 packages. Substitute your actual datasheet values. ## 0. System Architecture and Assumptions

```
 6S LiPo ──► XT60 ──► Shunt ──► V_BAT bus ──┬── Bulk + MLCC bank
                                            ├── ESC ch1..4: [ESC MCU] → [3φ gate driver] → [6× N-MOSFET] → Motor
                                            └── BEC (12V gate drive, 5V/3V3 FC)
 STM32H743 FC ── 4× bi-dir DShot600 (single wire, open-drain-ish, pulled up) ──► ESC MCUs (AM32/BLHeli_32)
```

**Architectural correction:** The H743 does not generate the 48 kHz PWM. Each ESC channel has its own MCU (e.g., STM32G071 or AT32F421 running AM32), which runs 48 kHz complementary 6-step PWM. The H743 sends DShot600 commands and receives eRPM telemetry.
