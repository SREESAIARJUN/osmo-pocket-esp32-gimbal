# STM32H743 FC + 4-in-1 ESC Nano Stack: Loss Model, Thermal Budget, Bi-Directional DShot DMA Plan, and Reference Netlists

## 0. Scope and Corrections

Three points shape everything below:

1. **The STM32H743 is the flight controller MCU, not the ESC MCU.** 4-in-1 ESCs run one small MCU per motor channel, such as STM32G071, STM32F051 or AT32F421, under AM32 or BLHeli_32 firmware. The H743 drives four DShot lines and receives eRPM telemetry back. This document models both boards: the FC (H743) and the ESC (4× MCU + 12 gate-drive phases + 24 MOSFETs).
2. **I don't have your Job #25 BOM**, so device parameters are explicit, labeled assumptions. Replace them with datasheet values and the equations still hold.
3. **The "80A burst" rating does not survive the math on a nano board** if all four channels run at full current simultaneously. Section 3 quantifies this. Treat it as a single-channel or short-transient rating, and state that in the product spec.

## 1. Conduction Loss Model (Six-Step Trapezoidal, Complementary PWM)

### Temperature-dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha (T_j - 25)] = 1.0\,\text{mΩ}\times(1+0.006\times85) = 1.51\ \text{mΩ}$$

### Current paths in one commutation sector

In each 60° sector, two phases conduct:

- **PWM leg:** the high-side FET conducts for D·T_sw. The low-side FET of the same leg conducts for (1−D)·T_sw through synchronous rectification.
- **Return leg:** its low-side FET is on continuously.

Conduction loss per channel:

$$P_{cond} = I^2R(D) + I^2R(1-D) + I^2R = 2I^2R_{ds}(T_j)$$

This result is independent of duty cycle, because synchronous rectification removes D from the expression.

$$P_{cond} = 2\times 80^2 \times 1.51\,\text{mΩ} = \mathbf{19.3\ W\ per\ channel}$$

### Per-FET loss

Each FET conducts for 120° of the electrical cycle. Electrical frequencies run in the kHz range while die thermal time constants are in the ms range, so averaging is valid:

$$\bar P_{FET,cond} \approx P_{cond}/6 \approx 3.2\ \text{W}$$

The worst-case instantaneous FET loss is I²R = 9.7 W, occurring while that FET is the continuous return-leg device.

### Self-consistency check

R_DS(on) depends on T_j, which depends on loss. Iterate:

$$T_j^{(n+1)} = T_{board} + \bar P_{FET}(T_j^{(n)})\cdot R_{th,jb}$$

Use R_th,jb ≈ 1.5–2.5 K/W for a DFN on a 2 oz pad. The iteration converges in 2–3 steps unless thermal runaway occurs, which happens when ∂P/∂T · R_th ≥ 1.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Its hard-switched FET sees V_bus and I at each edge.

### 2.1 Overlap (V–I crossover) loss

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5\times25.2\times80\times50\text{n}\times48\text{k} = \mathbf{2.42\ W}$$

### 2.2 Dead-time body-diode conduction

There are two dead-time intervals per period:

$$P_{dt} = 2 V_f I t_{dt} f_{sw} = 2\times0.8\times80\times200\text{n}\times48\text{k} = \mathbf{1.23\ W}$$

Halving dead time to 100 ns saves about 0.6 W. Check this against the driver's propagation-delay mismatch before committing.

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\times25.2\times48\text{k} = 0.06\ \text{W}$$

### 2.4 C_oss loss

$$P_{oss} = C_{oss(er)} V_{bus}^2 f_{sw} = 1.5\text{n}\times635\times48\text{k} \approx 0.05\ \text{W}$$

Both FETs in the leg are accounted for in this expression.

### 2.5 Gate drive

$$P_{gate} = 2\, Q_g V_{GD} f_{sw} = 2\times60\text{n}\times10\times48\text{k} = 0.06\ \text{W}$$

Most of this dissipates in R_g and the driver, not the FET.

### 2.6 Channel and system totals

| Loss term | W per channel |
|---|---|
| Conduction | 19.3 |
| Switching overlap | 2.42 |
| Dead time | 1.23 |
| Q_rr + C_oss + gate | 0.17 |
| **Total** | **≈ 23.1 W** |

For four channels at 80 A simultaneously: **≈ 92 W**. Add about 3–6 W for copper loss, using I²R of the phase, bus traces and connector at a few hundred µΩ each.
