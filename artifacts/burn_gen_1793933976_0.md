## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (e.g. GM4108), 12N14P, so **p = 7 pole pairs** |
| Phase resistance / inductance | R ≈ 10 Ω, L ≈ 4 mH (line-to-neutral) |
| Torque constant | K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Driver | 3-phase, inline or low-side shunt current sense, 24 V bus |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7), single-precision float |

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c = 2π·1500 rad/s |
| Velocity (rate) | 4 kHz | 250 µs | ω_v = 2π·120 rad/s |
| Angle (stabilization) | 1 kHz | 1 ms | ω_p = 2π·25 rad/s |
| IMU sampling / filtering | 8 kHz → decimated to 4 kHz | 125 µs | — |
| AHRS | 1 kHz | 1 ms | crossover ≈ 0.1–0.5 Hz |

Each bandwidth sits at roughly 1/8 to 1/10 of the loop below it. This keeps the inner loops effectively transparent, so the cascade can be tuned one loop at a time.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Angle Conversion and Delay Compensation

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

There is a computation and PWM delay of about 1.5·T_s between sampling and the moment the new voltage actually takes effect. Compensate for it:

$$\theta_e^{*} = \theta_e + 1.5\,T_s\,\omega_e,\qquad \omega_e = p\,\omega_m$$

### 1.2 Clarke and Park Transforms

Amplitude-invariant Clarke transform, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform into the rotor frame:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant Model (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI with Pole-Zero Cancellation

After decoupling, each axis reduces to the plant G(s) = 1/(Ls + R). Choose the PI controller

$$C(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The PI zero cancels the electrical pole at R/L. The closed loop then becomes a first-order system ω_c/(s + ω_c).

**Decoupling and back-EMF feedforward:**

$$v_d^{*} = \text{PI}_d(i_d^{*} - i_d) - \omega_e L\, i_q$$

$$v_q^{*} = \text{PI}_q(i_q^{*} - i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$

**Voltage limiting.** Use a circular limit with d-axis priority:

$$|v_{dq}| \le V_{\max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

**Anti-windup.** Use back-calculation with K_aw = K_i / K_p:

$$\dot x_I = K_i\, e + K_{aw}(v_{\text{sat}} - v_{\text{unsat}})$$
