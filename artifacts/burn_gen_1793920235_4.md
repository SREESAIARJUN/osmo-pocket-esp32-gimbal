# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #17 specification, so this design states its assumptions explicitly. Every parameter is a named constant you can replace with the real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz (FPU, CORDIC). Code is portable C++17. |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| Current loop | 20 kHz, synchronous with center-aligned PWM |
| Velocity loop | 4 kHz (decimated by 5) |
| Attitude loop | 1
