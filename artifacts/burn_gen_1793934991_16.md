## 0. Architecture Decisions and Assumptions

Several requirements are underspecified. The assumptions below are stated explicitly so that each number can be re-derived when real part numbers are chosen.

| Item | Assumption | Rationale |
|---|---|---|
| Topology | H743 runs ArduPilot as the flight controller. The 4-in-1 ESC uses **4 dedicated ESC MCUs** (AT32F421 or STM32G071) running AM32 or BLHeli_32-class firmware. | Bidirectional DShot is an FC-to-ESC-MCU protocol. The H743 cannot run ArduPilot and also commutate 4 motors at 48 kHz. |
| Bus voltage | 6S LiPo, V_bus,max = 25.2 V | Common for "80 A burst" class ESCs. |
| MOSFET voltage rating | **60 V** | 40 V parts on 6S leave under 15 V margin against regenerative and inductive spikes. Not recommended. |
| "80 A burst" | **Per-channel phase current**, held for ≤10 s | This is the worst-case interpretation. Battery current is lower by the duty factor. |
| Example MOSFET | R_DS(on),25 = 1.2 mΩ, Q_g = 60 nC, Q_rr = 50 nC, t_r + t_f = 35 ns, R_thJC = 0.8 K/W, PDFN5x6 | These are **placeholder parameters**. Substitute datasheet values. |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, 48 kHz | Standard AM32 behaviour. |
| Form factor | 30.5 × 30.5 mm ESC + 20 × 20 or 30.5 FC stack | See the feasibility warning in §3.5. |

> **Feasibility flag:** 80 A per channel on a "nano" footprint is thermally marginal. The analysis below shows it is viable only as a *short burst* with a heatsink and airflow, not as a continuous rating.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\big[1 + \alpha\,(T_j - 25)\big],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At the design point T_j = 110 °C:

$$R_{DS}(110) = 1.2\,\text{mΩ}\times(1 + 0.005\times85) = 1.2\times1.425 = \mathbf{1.71\ mΩ}$$

Because R_DS(on) depends on T_j, the model is coupled. It is solved iteratively in §3.4.

### 1.2 Six-step complementary PWM current paths

During any 60° commutation sector with phase current I_ph and duty D, three switches conduct:

| Switch | Conducts for | Loss |
|---|---|---|
| High-side (PWM leg) | D | I²·R·D |
| Low-side sync rectifier (same leg) | 1−D (minus dead time) | I²·R·(1−D) |
| Low-side (return leg, fully on) | 1 | I²·R |

Summing these:

$$P_{cond,ch} = I_{ph,rms}^2\,R_{DS}\,[D + (1-D) + 1] = 2\,I_{ph,rms}^2\,R_{DS}(T_j)$$

The result is **independent of duty**, which is a useful property of synchronous rectification.

Ripple correction for a triangular ripple ΔI:

$$I_{ph,rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}}$$
