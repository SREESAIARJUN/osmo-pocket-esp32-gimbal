# STM32H743 AIO + 4-in-1 ESC (Job #37): Reference Design and Loss/Timing Model

## 0. Scope, Architecture and Assumptions

### Architecture
The STM32H743 does **not** commutate the motors. It is the flight controller running ArduPilot, and it sends bidirectional DShot600 commands to four ESC MCUs running AM32 or BLHeli_32. Each ESC MCU is an AT32F421 or STM32G071, and each drives a 3-phase gate driver and six N-MOSFETs. The ESC PWM frequency is 48 kHz. Every equation below follows that partition.
