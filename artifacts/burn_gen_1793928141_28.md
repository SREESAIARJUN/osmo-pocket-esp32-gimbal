**Document:** Job #36, Architecture Baseline Rev A

## 0. Architectural Clarification

The STM32H743 cannot be the commutation controller if you want ArduPilot bidirectional DShot.

- **ArduPilot does not run ESC firmware.** Bidirectional DShot is a protocol between the flight controller and separate ESC MCUs that return eRPM.
- **The correct topology** is therefore:

```
STM32H743 (ArduPilot FC) ──DShot600 bidir (×4)──► 4× ESC MCU (AM32 or BLHeli_32)
                                                     │
                                          4× 3-phase gate driver
                                                     │
                                          24× N-MOSFET (4 × 3 half-bridges)
```

- **Where 48 kHz applies.** It is the ESC-side PWM frequency, set in AM32. The H743 never generates it.
- **What "80A burst" means.** It is defined here as **80 A phase current per motor for a time-limited burst**. Section 3 shows this cannot be sustained on a nano (≤30×30 mm) board. It is a transient rating only.

All device parameters below are representative placeholders. Substitute your selected MOSFET's datasheet values; the equations are general.
