## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

θ_offset is found at startup by applying V_d = V_align at θ_e = 0 and reading the encoder after settling.

### 1.2 Clarke Transform (amplitude-invariant, balanced phases)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 Plant Model (surface PM, L_d = L_q = L)

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$
$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

where ω_e = p·ω_m, and λ_m = K_t / (1.5 p) for the amplitude-invariant convention.

### 1.5 Current PI by Pole-Zero Cancellation

The PI zero is placed on the electrical pole R/L, giving first-order closed-loop dynamics with bandwidth ω_ci:

$$C_i(s) = K_{p,i} + \frac{K_{i,i}}{s},\qquad K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

Choose ω_ci ≈ 2π·1.5 kHz, which is less than or equal to 2π·f_pwm/10. This accounts for the ~1.5 T_i of computation plus PWM delay.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e (L i_d + \lambda_m)$$

**Voltage limiting:** apply a circular limit $\sqrt{v_d^2+v_q^2}\le V_{dc}/\sqrt3$. The d-axis gets priority, and the q-axis receives the remainder:

$$v_q^{\max} = \sqrt{V_{\max}^2 - v_d^2}$$

**Anti-windup:** back-calculation with gain K_aw = 1/K_p (equivalently, integrator clamping when saturated in the same sign).

**Discrete form (forward Euler is adequate since ω_ci·T_i ≈ 0.47):**

$$x_k = x_{k-1} + K_i T\,e_k + K_{aw}\,(u^{sat}_{k-1}-u_{k-1})$$
$$u_k = K_p e_k + x_k$$

### 1.6 Inverse Park and SVPWM (min/max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min)(v_a,v_b,v_c),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically identical to sector-based SVPWM and is branch-light.

### 1.7 Angle Advance for Computational Delay

The PWM update lands roughly 1.5 T_i after sampling, so the inverse Park uses an advanced angle:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_i$$

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical Plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

The current loop, with bandwidth ω_ci ≫ ω_v, is treated as unity gain.

### 2.2 Velocity PI (symmetric-optimum style)

With $G_v(s) = \dfrac{K_t}{J s}$ and $C_v(s) = K_{p,v}\left(1+\dfrac{\omega_{z}}{s}\right)$:

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\,\omega_z,\qquad \omega_z = \frac{\omega_v}{a^2}$$

With a = 2, phase margin is about 37°. With a = 3, phase margin is about 53° (recommended).
