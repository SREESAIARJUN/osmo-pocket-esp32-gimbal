## 0. System Assumptions and Timing Architecture

| Item | Value **[A]** |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs, p = 7), R = 5.0 Ω (phase), L = 1.8 mH, K_t = 0.08 N·m/A |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701 class), per joint |
| IMUs | 2× ICM-42688-P on the camera plate, sharing CLKIN/FSYNC, SPI @ 24 MHz |
| PWM | 20 kHz center-aligned, 3-phase, SVPWM |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates.** Each outer loop runs about 5× slower than the loop it commands, which gives timescale separation.

```
Current (FOC) PI      20 kHz   (ADC triggered at PWM center)
IMU sample (ODR)       8 kHz   → vibration filters run at 8 kHz
Velocity PI            4 kHz   (decimated gyro, 2:1)
Attitude estimator     4 kHz
Angle P/PI             1 kHz
Cogging adaptation     4 kHz   (runs alongside the velocity loop)
```

**Signal flow per axis:**

```
θ_ref ──►[Angle P]──ω_ref──►[Velocity PI]──i_q,fb──►(+)──i_q*──►[FOC current PI]──►SVPWM──►Motor
  │           ▲      ▲ +ω_ff      ▲                  ▲ i_q,cog + i_q,acc
  │           │      │            │                  │
  └─d/dt──────┼──────┘      ω_gyro (filtered,        [Cogging FF(θ_e)]◄── encoder θ_m
              │              joint-mapped)
        θ_cam (attitude estimator, dual IMU)
```

Roles of the two sensors:

- **The encoder** handles commutation and the cogging phase.
- **The IMU** closes the stabilization loops. The camera rate is what we actually want to hold at zero, so the velocity loop uses the gyro rather than a differentiated encoder signal.

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \mod 2\pi$$

Here θ_{m,0} is found at calibration by aligning the d-axis: inject i_d = I_align and read the encoder.

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant)

With i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 dq machine model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque: τ = (3/2) p λ_m i_q = K_t i_q.
