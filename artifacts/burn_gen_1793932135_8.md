# Job #63: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

**Design specification and reference implementation, Rev A**

---

## 0. Assumptions and Architecture

I had no hardware file for Job #63, so the design is parametric. The defaults below are typical for a camera gimbal. Replace them with measured values before tuning.

| Item | Default assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 8 Ω, L ≈ 2.5 mH (phase), K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A class), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, common CLKIN at 32.768 kHz |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class)
