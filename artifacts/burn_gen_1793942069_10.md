# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #39 specification, so this design states explicit baseline assumptions (§0). Every parameter that depends on them is a named constant in the code. Replace them with your measured motor and inertia data before tuning.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω phase-phase, L ≈ 4 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6835 class) per axis |
| MCU | STM32G474 / H7 class with FPU, center-aligned PWM at 20 kHz, ADC triggered at PWM center |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO with timestamps |
| Bus | 4S (16.8 V max) |

**Loop rate hierarchy**

| Loop | Rate | Target bandwidth | Feedback source |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5 kHz | Phase shunts |
| Rate (PI + FF) | 4 kHz | 80–200 Hz | Fused gyro, projected to joints, blended with encoder |
| Attitude (P + FF) | 1 kHz | 10–30 Hz | Fused quaternion |
| IMU fusion | 4 kHz (8 kHz decimated ×2) | — | — |

Keep a factor of **≥5–10** between adjacent loop bandwidths so each inner loop looks like unity gain to the loop around it.
