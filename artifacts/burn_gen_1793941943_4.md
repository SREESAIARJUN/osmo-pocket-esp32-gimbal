# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #32 specification, so §0 lists the assumed hardware parameters. Every gain in this document is computed from those parameters, so you can substitute your real values and the design still holds.

---

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 2.2 mH (phase), K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MT6701 class), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload CoM, SPI at 24 MHz |
| MCU | Cortex-M4F/M7 at ≥ 168 MHz with FPU (e.g., STM32G474/H7) |
| Bus | 3S–4S (12–16.8 V) |

| Loop | Rate | Trigger |
|---|---|---|
| PWM / current (FOC) | 20 kHz | ADC injected end-of-conversion, center-aligned |
| IMU sample + filter | 8 kHz | ICM-42688 INT1 (data ready) |
| Rate (velocity) loop | 4 kHz | Every 2nd IMU sample |
| Attitude (angle) loop | 1 kHz | Every 4th rate step |
| Anti-cogging LMS update | 20 kHz, gated | Only during calibration or low-velocity hold |

**Bandwidth separation.** Each outer loop is placed at least 5× below the loop inside it, so the inner loop looks like a unity gain to the outer one:

ω_c,i ≈ 2π·1500 rad/s → ω_c,ω ≈ 2π·60 → ω_c,θ ≈ 2π·10

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

θ_e = p · (θ_m − θ_offset) mod 2π

θ_offset is found at startup by aligning the rotor: inject a d-axis voltage at θ_e = 0 and record the encoder reading.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

i_α = i_a
i_β = (i_a + 2·i_b) / √3

### 1.3 Park transform

i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 Plant model in the dq frame

v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ_m

Torque: τ = (3/2)·p·λ_m·i_q = K_t·i_q (surface PM, L_d = L_q).

### 1.5 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation: choose the PI zero to cancel the electrical pole R/L.

K_p,i = L·ω_c,i
K_i,i = R·ω_c,i

The closed loop then becomes first-order, i/i* = ω_c,i / (s + ω_c,i).

With L = 2.2 mH, R = 5.6 Ω and ω_c,i = 2π·1500:
- K_p,i = 20.7 V/A
- K_i,i = 52 780 V/(A·s)

Control law:

v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

Use i_d* = 0, since no field weakening is needed at gimbal speeds.

**Voltage limiting.** The available voltage is |v| ≤ V_dc/√3 (the linear SVPWM region).
- Prioritize the d-axis: v_q,max = √(V_max² − v_d²).
- Use back-calculation anti-windup (§2.4).

### 1.6 Inverse Park transform and SVPWM (min-max injection)

v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e

v_a = v_α
v_b = −½·v_α + (√3/2)·v_β
v_c = −½·v_α − (√3/2)·v_β

v_0 = −½·[max(v_a, v_b, v_c) + min(v_a, v_b, v_c)]

d_x = ½ + (v_x + v_0) / V_dc, for x ∈ {a, b, c}

Min-max zero-sequence injection is mathematically equivalent to sector-based SVPWM. It is cheaper to compute and has no sector branches.

### 1.7 Delay compensation

The PWM update has a 1.5·T_s transport delay (one computation period plus half a PWM period). Compensate it in the inverse Park transform:

θ_e,comp = θ_e + 1.5·ω_e·T_s

## 2. Cascaded Stabilization Control

### 2.1 Gimbal kinematics

Assume a yaw → roll → pitch chain, with pitch innermost and attached to the camera. Joint angles q = [q_y, q_r, q_p] come from the encoders.

Joint axes expressed in the camera frame:

u_p = e_y
