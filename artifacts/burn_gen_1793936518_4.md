# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #40): System Architecture & Loss Model

## 0. Scope, Assumptions and One Correction

The H743 does not commutate the motors. In any production 4-in-1 design, each ESC channel has its own small MCU running AM32 or BLHeli_32. The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. The model below uses this architecture:

| Block | Assumed part / value | Notes |
|---|---|---|
| FC MCU | STM32H743VIH6 (or VIT6), 480 MHz | ArduPilot ChibiOS |
| ESC MCU (×4) | AT32F421K8U7, AM32 firmware | Supports bidir DShot and variable PWM frequency |
| Gate driver (×4) | FD6288Q-class 3-phase bootstrap driver | Source/sink ≈ 1.5/1.8 A |
| MOSFET (×24) | 40 V N-ch, 3.3×3.3 mm DFN | R_DS(on),25 = 1.0 mΩ @ 10 V, Q_g = 40 nC, Q_gd = 10 nC, Q_gs2 = 4 nC, V_pl = 3.0 V, Q_rr = 40 nC, R_θJC = 1.5 K/W |
| Bus | 6S LiPo | V_bus = 25.2 V worst case (full charge) |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step | Dead time t_dt = 100 ns |
| Gate drive | V_drv = 10 V, R_g,ext = 2.2 Ω (on), 1.0 Ω (off, diode bypass) | |

The MOSFET values are representative of the class, not taken from a specific datasheet. Substitute your chosen part's datasheet numbers into the equations. The equations are the deliverable; the numbers are a worked instance.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In 6-step commutation with synchronous rectification, two phases are active in each 60° sector:

- The **PWM leg** alternates between its high-side FET (on time D) and its low-side FET (off time 1−D).
- The **return leg** low-side FET conducts for the whole sector.

So the motor current I_ph always flows through exactly **two** FET channels in series.

### 1.2 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\qquad \alpha \approx 0.005\ \mathrm{K^{-1}}$$

### 1.3 Loss equations

$$P_{cond,ESC} = 2\, I_{ph}^2\, R_{DS}(T_j)$$
