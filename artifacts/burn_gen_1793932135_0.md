# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

## 0. Design Assumptions

I don't have the specification for "Job #1", so this design uses the assumptions below. Every value is a named constant in the code, so you can change any of them in one place.

| Item | Value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| Current sensing | 2-shunt or 3-shunt, sampled in the center of the PWM period |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |

Loop rates:

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz | ~150–250 Hz |
| Angle / attitude | 1 kHz | ~20–40 Hz |
| IMU fusion | 8 kHz in, 1 kHz attitude out | – |

Rule of thumb: keep at least a 5–10× bandwidth separation between nested loops.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Coordinate transforms

**Electrical angle.** θ_e = p·(θ_m − θ_offset) mod 2π

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

**Park transform:**

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

**Inverse Park transform:**

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
```

### 1.2 Plant model and current PI tuning

The PMSM dq model is:

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
```

Torque is T = (3/2) p λ_m i_q = K_t i_q, with d-axis current regulated to zero (i_d* = 0).

**Decoupling feedforward.** Adding these terms makes each axis a first-order plant 1/(Ls + R):

```
v_d,ff = −ω_e L i_q
v_q,ff =  ω_e L i_d + ω_e λ_m
```

**Pole-zero cancellation tuning** for a target bandwidth ω_c:

```
K_p = L ω_c        K_i = R ω_c
```

This gives a closed loop of I/I* = ω_c / (s + ω_c). Choose ω_c ≤ 2π·f_pwm/10 to account for the 1.5-sample delay (computation plus PWM update).

**Discrete PI with back-calculation anti-windup** (T_s = 1/f_cur):

```
e[n]   = i*[n] − i[n]
u_u[n] = K_p e[n] + x[n] + v_ff
u[n]   = sat(u_u[n])
x[n+1] = x[n] + K_i T_s e[n] + K_aw (u[n] − u_u[n])     with K_aw ≈ 1/K_p · K_i·T_s… use K_aw = K_i/K_p·T_s
```

**Voltage vector limiting.** Under SVPWM the maximum available voltage is |v| ≤ V_bus/√3. Priority goes to v_d:

```
v_q,max = sqrt(V_max² − v_d²)
```

### 1.3 SVPWM (min-max zero-sequence injection)

```
v_a = v_α
v_b = −½ v_α + (√3/2) v_β
v_c = −½ v_α − (√3/2) v_β
v_0 = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c)) / 2
duty_x = ½ + (v_x + v_0) / V_bus
```
