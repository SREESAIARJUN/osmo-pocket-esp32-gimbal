# Job #60: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I have no specification sheet for Job #60, so the parameters below are **explicit assumptions**. All of them sit in one `Config` block in the code, so you can replace them with your identified values.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R_ph ≈ 5.0 Ω, L ≈ 1.8 mH, Kt ≈ 0.075 N·m/A |
| Bus | V_dc = 12 V |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz, internal anti-aliasing filter enabled |
| Kinematics | Yaw (outer, z) → Roll (x) → Pitch (inner, y) |
| MCU | STM32G4 / H7 class with FPU |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | ADC-synchronized PWM ISR |
| IMU filtering | 8 kHz | Driven by data-ready interrupt |
| Velocity | 4 kHz | 8 kHz IMU stream decimated by 2 after filtering |
| Attitude | 1 kHz | Timer |
