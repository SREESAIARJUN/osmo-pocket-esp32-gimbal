## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Driver | 3-phase bridge with 2 low-side shunts, center-aligned PWM 20 kHz, V_bus = 12 V |
| Encoders | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the payload (camera) plate, IMU-B mounted rotated 180° about z |
| MCU | Cortex-M4F/M7 (single-precision FPU) |
| Kinematics | Base → Yaw (z) → Roll (x) → Pitch (y) → Payload |

**Loop rates** (each loop is about ≥5× slower than its inner loop, so the inner loop looks like unity gain to the outer):

| Loop | Rate | Target closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (ISR) | ω_c ≈ 2π·1500 rad/s |
| IMU sampling / filtering | 8 kHz ODR | — |
| Velocity | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·20 rad/s |

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle, where θ_off is found during calibration:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\be
