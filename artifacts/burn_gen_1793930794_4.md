## 0. Assumptions and Architecture Corrections

**Architecture.** An STM32H743 running ArduPilot cannot also commutate four BLDC motors with ESC-grade timing. The correct "AIO" topology is:

```
             ┌────────────────────────── FC domain ──────────────────────────┐
 6S VBAT ──► │ STM32H743VIT6 @480 MHz  │ ICM-42688-P │ DPS310 │ W25N01G │ OSD │
             └────────┬─────────────────────────────────────────────────────┘
                      │ 4× bidirectional DShot600 (single wire, inverted idle-high)
             ┌────────▼──────── ESC domain (×4 identical channels) ─────────┐
             │ AT32F421K8U7 (AM32) → FD6288Q 3-ph driver → 6× N-MOSFET      │
             └──────────────────────────────────────────────────────────────┘
```

## 1. Conduction Loss Model

### 1.1 Commutation geometry
The model assumes 6-step trapezoidal commutation with complementary (synchronous) PWM, which is AM32's default. At every instant, phase current flows through exactly one high-side path and one low-side path:

- During the PWM on-time, current flows through the HS FET of leg A and the LS FET of leg B.
- During the off-time, current freewheels through the LS FET of leg A (synchronous rectification) and the LS FET of leg B.

Either way, two R_ds(on) are in series. Each FET carries current for 1/3 of the electrical cycle.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.005\ \mathrm{K^{-1}}$$

At T_j = 110 °C: R_ds = 0.75 mΩ × 1.425 = **1.07 mΩ**.

Since conduction loss raises T_j, which raises R_ds, the operating point should be solved iteratively (see §3.4).

### 1.3 Per-FET and per-channel losses

$$I_{FET,rms} = I_{ph}\sqrt{\tfrac{1}{3}} = 80\times0.577 = 46.2\ \mathrm{A}$$

$$P_{cond,FET} = I_{FET,rms}^2\,R_{ds}(T_j) = 46.2^2 \times 1.07\,\mathrm{m\Omega} = \mathbf{2.28\ W}$
