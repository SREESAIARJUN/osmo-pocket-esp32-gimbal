# STM32H743 Flight Controller + 80A 4-in-1 ESC (Job #78): System Architecture and Design Model

## 0. Scope, Assumptions, and Architecture Corrections

The brief mixes two separate processors, so the partitioning comes first.

| Function | Where it lives |
|---|---|
| STM32H743 (ArduPilot) | Flight controller. Generates DShot600 and receives bidirectional eRPM telemetry. |
| 48 kHz PWM and commutation | ESC MCU(s), e.g. 4× AT32F421 running AM32, or BLHeli_32-class. The H743 does not drive the gates. |
| Power stage | 4 × 3 half-bridges = 24 MOSFETs, gate drivers, and shunts. |

**Design assumptions.** Replace these with datasheet values before release.

| Parameter | Value |
|---|---|
| Bus voltage | 6S, V_bus,max = 25.2 V |
| Burst current | 80 A **per motor** (the industry convention for "80A burst") |
| MOSFET | 40 V, DFN3.3×3.3 class |
| R_DS(on) | 1.3 mΩ max at 25 °C, 10 V V_GS |
| Gate charge | Q_g = 50 nC, Q_gd = 10 nC |
| Q_rr | 50 nC |
| C_oss(er) | ≈1.5 nF |
| R_θJC | 1.5 K/W |
| Gate driver | 3-phase bootstrap driver (FD6288Q class), V_drv = 10 V |
| Shunt | 0.25 mΩ, low-side, one per ESC channel |
| Commutation | Trapezoidal (6-step), complementary PWM with synchronous rectification, dead time t_dt = 100 ns |
| Form factor | 30.5×30.5 mm mounting, ~36×36 mm board, 8-layer, 2 oz on all layers |
