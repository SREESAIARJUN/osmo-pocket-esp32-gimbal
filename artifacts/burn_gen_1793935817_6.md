## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz (FPU, CORDIC). Code itself is HAL-agnostic. |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7). R ≈ 5–12 Ω, L ≈ 1–3 mH. |
| Encoder | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A class), on the motor shaft. |
| Current sense | 2-phase low-side shunts, sampled at the PWM center. |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz. |
| Bus voltage | 12–16 V |

**Loop rates:**

| Rate | Tasks | Trigger |
|---|---|---|
| 20 kHz (Tᵢ = 50 µs) | Current loop: Clarke/Park, current PI, SVPWM, encoder read, cogging feedforward | ADC-JEOC ISR |
| 4 kHz (T_v = 250 µs) | Rate loop: gyro-driven, outputs i_q* | Every 5th ISR |
| 8 kHz | IMU pipeline: notch filters, LPF, dual fusion | IMU DRDY ISR, decimated into the rate loop |
| 1 kHz (T_θ = 1 ms) | Attitude estimator (Mahony), angle loop, cogging LMS update | Every 4th rate tick |

**Bandwidth separation rule:** each outer loop should be at most ~1/5 the bandwidth of the loop it drives.

- Current loop: ω_ci ≈ 2π·1500 rad/s
- Rate loop: ω_cv ≈ 2π·150 rad/s
- Angle loop: ω_cθ ≈ 2π·25 rad/s

**Gimbal topology.** The control architecture follows the standard high-performance gimbal pattern:

- The **encoder** provides commutation angle and joint position.
- The **payload IMU gyro** provides the rate-loop feedback. Base disturbances therefore appear directly in the measured rate and are rejected at the full rate-loop bandwidth.
- The **IMU attitude** provides the angle-loop feedback.

## 1. FOC Current Loop

### 1.1 Angles

- Mechanical angle from the encoder: θ_m = 2π·N/2¹⁴ − θ_off
- Electrical angle: θ_e = p·θ_m (mod 2π)
- θ_off is found at startup by aligning the rotor: apply v_d > 0 at θ_e = 0 and read the encoder.
