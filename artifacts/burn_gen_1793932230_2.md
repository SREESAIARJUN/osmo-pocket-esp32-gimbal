# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #12 spec, so I've stated every assumption. Each hardware-dependent constant is in one `Config` struct, so you can change values to match your hardware without touching the math.

## 0. Assumed System Parameters

| Item | Assumption |
|---|---|
| MCU | STM32G474-class (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC optional) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.5 Ω, L ≈ 2.2 mH, K_t ≈ 0.11 N·m/A |
| Driver | 3-phase, 24 V bus, center-aligned PWM 20 kHz, 2–3 low-side shunts |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz |

Each loop runs at least 4× slower in bandwidth than the loop inside it. That separation lets you design each loop treating the inner loop as ideal.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$
θ_{m,0} is found at calibration. Inject current along d with θ_e = 0 and the rotor locks to the d-axis; record θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame
$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$
with ω_e = p·ω_m and the torque relation $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$.

### 1.5 Current PI with decoupling and back-EMF feedforward

The plant per axis is $G_i(s) = 1/(Ls+R)$. Use pole-zero cancellation with closed-loop bandwidth ω_c:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/10. Here f_c ≈ 1.5 kHz, so ω_c ≈ 9400 rad/s.

Discrete control law (sample time T_i = 50 µs), with feedforward terms:
$$v_d^* = K_{p,i}e_d + x_d - \omega_e L i_q$$
$$v_q^* = K_{p,i}e_q + x_q + \omega_e L i_d + \omega_e \lambda_m$$
$$x_{k+1} = x_k + K_{i,i}T_i e_k + K_{aw}(v^{sat} - v^*)$$

### 1.6 Voltage limiting (circular, d-axis priority)

$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad m_{max}\approx 0.95$$
$$v_d^{sat} = \mathrm{clip}(v_d^*,\pm V_{max}),\qquad v_q^{sat} = \mathrm{clip}\!\left(v_q^*,\pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$
