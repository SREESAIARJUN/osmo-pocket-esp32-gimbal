# STM32H743 FC + 4-in-1 ESC (Job #53): Loss Model, Thermal Budget, and Bi-Directional DShot600 Allocation

## 0. Scope and Assumptions

**Architecture.** ArduPilot does not commutate motors. The STM32H743 is the flight controller. It sends bi-directional DShot600 to four ESC MCUs (one per channel), which run 6-step commutation at 48 kHz PWM. The power model below covers the ESC stage. The timer/DMA model covers the H743.

**Form factor.** "Nano" combined with 80 A per channel is very aggressive. I assume a 30.5 × 30.5 mm board with a single FET per switch position. A 20 × 20 mm board cannot meet 80 A burst. The model shows why.

## 1. Conduction Loss Model

In 6-step operation with complementary (synchronous) PWM, the current path in any sector is: PWM high-side (duty D) → motor → low-side (always on). The complementary low-side of the PWM leg carries the freewheeling current for (1−D).

**Per-channel conduction loss:**

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2 I^2 R_{ds}(T_j)$$

**Temperature dependence:**

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

**Evaluation at T_j = 110 °C (iterated, see §4):**

- R_ds = 1.5 mΩ × 1.51 = 2.27 mΩ
- P_cond = 2 × 80² × 2.27×10⁻³ = **29.0 W per channel**
- Add bus and phase copper: R_Cu ≈ 0.3 mΩ gives I²R_Cu ≈ 1.9 W, which goes into the PCB, not the junction.

**Per-FET loss.** Each FET conducts for 1/3 of the electrical cycle at an instantaneous 14.5 W. Its average is about 4.8 W.

**Commutation ripple.** At a 1 kHz electrical frequency, the conduction window is about 333 µs. With Z_θJC(333 µs) ≈ 0.3 K/W, the junction ripple is about 4.4 K. This is acceptable.

## 2. Switching Loss Model at 48 kHz

Only the PWM high-side hard-switches. The synchronous low-side switches at near-zero V_DS (ZVS via the body diode).

### 2.1 Transition times

Gate current during the plateau:

$$I_{g,on} = \frac{V_{dr}-V_{pl}}{R_{g,ext}+R_{g,int}} = \frac{5.5}{11.5} = 0.478\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{11.5} = 0.391\ \text{A}$$

Transition times:

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{13\text{ nC}}{0.478\text{ A}} = 27\text{ ns}$$

$$t_{off} = \frac{13\text{ nC}}{0.391\text{ A}} = 33\text{ ns}$$
