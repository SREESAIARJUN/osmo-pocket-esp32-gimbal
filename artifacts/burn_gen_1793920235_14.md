# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #60)

I don't have the Job #60 specification, so the design below rests on explicit assumptions. Every section is parameterized, so you can substitute your real numbers.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | STM32G4 class (FPU, CORDIC), 3 × half-bridge plus inline/low-side shunts |
| Current-loop rate | f_c = 20 kHz (T_c = 50 µs) |
| Rate-loop rate | f_v = 4 kHz |
| Attitude-loop rate | f_θ = 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz, ±2000 dps / ±16 g |
| Vibration source | Multirotor props at 80–300 Hz plus harmonics |
