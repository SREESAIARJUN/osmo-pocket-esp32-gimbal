# FOC Motor Control and Dual-IMU Sensor Fusion for the 3-Axis Gimbal (Job #44)

## 0. Design Assumptions

I don't have the Job #44 spec sheet, so this design uses typical gimbal values. Every value is a `constexpr` in the code, so you can change any that differ.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Phase values | Phase R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (e.g. AS5048A / MT6701), one per joint |
| PWM / current loop | 20 kHz center-aligned PWM; current loop at 20 kHz in the ADC-complete ISR |
| Velocity and angle loops | Both at 4 kHz, triggered by IMU data-ready divided by 2 |
| Attitude update | 1 kHz |
| IMUs | 2× ICM-42688-P on SPI at 8 kHz ODR, ±2000 dps, ±4 g |
| IMU mounting | Placed symmetrically about the camera rotation center (§5.2 explains why) |
| Joint order | Yaw (base) → Roll → Pitch (camera). The camera IMU is on the pitch link. |
| MCU | Cortex-M4F/M7 with single-precision FPU |
