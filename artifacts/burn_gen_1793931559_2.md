## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle, with offset $\theta_0$ found at calibration:

$$\theta_e = p\,\theta_m - \theta_0$$

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = K_t\, i_q \qquad (\text{surface PM},\ L_d = L_q)$$

### 1.3 Current PI Controller (Pole-Zero Cancellation)

Plant: $G_i(s) = \dfrac{1}{Ls + R}$. With the controller

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,$$

the controller zero $K_i/K_p = R/L$ cancels the plant pole, and the closed loop becomes the first-order system $\dfrac{\omega_c}{s+\omega_c}$.

**Constraint.** Choose $\omega_c \le \omega_{pwm}/10$ so that the 1.5-sample delay (computation plus PWM update) costs less than about 15° of phase margin.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(e_d) - \omega_e L\, i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L\, i_d + \omega_e \lambda_m$$

**Voltage limiting.** The available voltage is the circle inscribed in the SVPWM hexagon:

$$|v_{dq}| \le \frac{V_{dc}}{\sqrt3}$$

Priority goes to $v_d$:

$$v_q^{\max} = \sqrt{\left(\frac{V_{dc}}{\sqrt3}\right)^2 - {v_d^*}^2}$$

**Discretization.** Integrators use backward Euler. Anti-windup uses back-calculation with $K_{aw} = 1/K_p$:

$$x_I[k+1] = x_I[k] + T_s\left(K_i\, e[k] + K_{aw}\,(u_{sat}[k] - u[k])\right)$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \frac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM and uses no branches or trigonometric functions.

### 1.5 Voltage-Mode Fallback

Many gimbal motors have $R$ above about 5 Ω, and some boards have no current sensing. In that case, drop the current loop and command voltage directly:

$$v_q = R\, i_q^* + \omega_e\lambda_m$$

The code below supports both modes (`kVoltageMode`).
