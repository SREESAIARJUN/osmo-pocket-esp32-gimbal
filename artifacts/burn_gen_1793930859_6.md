# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the specification for "Job #7", so this design uses the assumptions below. Every assumption is a named constant in the code, so you can substitute your real hardware parameters.

| Item | Assumption |
|---|---|
| MCU | STM32G4 / similar Cortex-M4F at 170 MHz with single-precision FPU |
| Motors | Gimbal BLDC with 12 slots and 14 poles (7 pole pairs, like the GBM2804). R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor sensing | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701) |
| Phase current sensing | 2-shunt low-side. A voltage-mode fallback is provided for boards without shunts. |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the rotation centroid, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |
| Loop rates | Current loop 20 kHz. IMU filtering 8 kHz. Rate loop 4 kHz. Attitude loop 1 kHz. |
