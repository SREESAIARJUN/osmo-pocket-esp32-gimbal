# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #37)

## 0. Assumptions

Job #37's specification wasn't provided, so the design rests on the parameters below. Every one is a `constexpr` or config field in the code, so you can change them in one place.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7). Typical: R ≈ 5–15 Ω, L ≈ 2–5 mH, Kt ≈ 0.05–0.15 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| Inverter | 3-phase, 24 kHz center-aligned PWM, 2–3 shunt current sensing |
| IMUs | 2 × ICM-42688-P on camera plate, SPI at 24 MHz, ODR 8 kHz, ±2000 dps, ±16 g |
| Joint chain | Yaw (outer) → Roll → Pitch (inner, carries camera) |

Loop rates and bandwidths:

| Loop | Rate | Closed-loop bandwidth target |
|---|---|---|
| Current (FOC) | 24 kHz (ISR) | ω_c ≈ 2π·1500 rad/s |
| Velocity | 8 kHz (IMU data-ready) | ω_v ≈ 2π·120 rad/s |
| Angle / attitude | 1 kHz | ω_a ≈ 2π·20 rad/s |

Each loop is at least 5× slower than the one inside it. That separation is what lets each loop be tuned independently.

## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle is computed from the mechanical angle, pole-pair count and encoder offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke** (amplitude-invariant, using $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
