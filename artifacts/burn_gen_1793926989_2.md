# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original Job #7 specification, so I have made the assumptions below explicit and parameterized. Replace them with your hardware values. Every gain in the code is derived from physical parameters, so you shouldn't need to hand-tune magic numbers.

| Item | Assumed value |
|---|---|
| Gimbal kinematic order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → Camera |
| Motors | Gimbal BLDC (SPM, e.g. 12N14P, 7 pole pairs), absolute magnetic encoder per joint |
| Current sensing | 2 or 3 low-side shunts, centered PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, data-ready interrupt |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle and attitude 1 kHz |
| MCU | Cortex-M4F/M7 with FPU, single precision |

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m, with p pole pairs and calibrated offset θ₀:

$$\theta_e = p(\theta_m - \theta_0) \mod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q \equiv K_t i_q$$

### 1.3 Current PI controller with pole-zero cancellation

The plant is G(s) = 1/(Ls + R). Choose a PI of the form C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_{c},\qquad K_i = R\,\omega_{c}$$

The zero then cancels the electrical pole, and the closed loop becomes first-order:

$$\frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$

Pick ω_c ≤ 2π·f_PWM/20. At 20 kHz this gives ω_c ≈ 2π·1 kHz.
