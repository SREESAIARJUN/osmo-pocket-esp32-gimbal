# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation and Dual ICM-42688-P Fusion

I don't have the Job #43 specification, so this design states its assumptions explicitly. Every parameter is in one config block so you can substitute your actual motor and inertia values.

---

## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, e.g. 12N14P (N_s = 12 slots, p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| IMU A | ICM-42688-P on the **camera plate**. Inertial feedback. |
| IMU B | ICM-42688-P on the **base / handle**. Disturbance feedforward. |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |
| Kinematic order | Base → Yaw → Roll → Pitch → Camera |

**Loop rates (timer-synchronous):**

```
 20 kHz  : current loop (ADC trigger at PWM center) + encoder PLL + cogging FF
  4 kHz  : velocity loop (inertial rate from IMU A, base FF from IMU B)
  4 kHz  : IMU ODR (both chips, FSYNC-aligned), notch filtering
  1 kHz  : attitude estimation + angle loop
  50 Hz  : dynamic-notch frequency tracker update
```

**Signal flow:**

```
q_ref ─►[Angle P + FF]─► ω_cam_ref ─►(J⁻¹, −ω_base)─► q̇_ref ─►[Vel PI]─► i_q,pid ─┐
                ▲                                         ▲                      (+)─► i_q* ─►[Current PI]─►SVPWM
       q̂ (Mahony, IMU A)                       ω̂_joint (IMU A, notched)   i_q,cog(θ)┘     ▲
                                                                                         i_d*=0
```

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at calibration: lock with V_d > 0 at θ_e = 0 and record θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

Torque (SPM motor, L_d = L_q):

$$\tau = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$
