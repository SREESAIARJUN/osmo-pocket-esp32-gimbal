# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

I don't have the Job #49 hardware definition, so this design states its assumptions explicitly in §0. Every equation is parameterized. Replace the constants with your measured values.

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz or more |
| Motor | 12N14P gimbal BLDC (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701), one per joint |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC d/q PI + SVPWM) | 24 kHz | ADC end-of-conversion, center-aligned PWM |
| IMU filtering + velocity PI | 8 kHz | IMU DRDY (sync PWM via ICM CLKIN if possible) |
| Attitude estimator + angle loop | 1 kHz | Every 8th IMU sample |
| Cogging LMS adaptation | 8 kHz, gated | Only when \|ω\| is in the adaptation window |

Bandwidth separation targets: current ≈ 1.5–2 kHz, velocity ≈ 80–150 Hz, angle ≈ 15–30 Hz. Each loop should be at least 4–5× slower than the one inside it.

$$\theta_e = p\,\theta_m - \theta_{\text{off}} + \omega_e T_d,\qquad T_d \approx 1.5\,T_{pwm}$$
