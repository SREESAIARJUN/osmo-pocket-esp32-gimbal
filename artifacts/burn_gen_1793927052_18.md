### Architectural note

The STM32H743 is the **flight controller** MCU. Each ESC channel runs its own MCU (AT32F421 running AM32 is assumed). That MCU generates the 48 kHz complementary 6-step PWM and replies with bidirectional-DShot eRPM telemetry. The H743 never drives the gates directly.

## 1. Conduction Loss Model

### 1.1 Current path topology

The ESC uses 6-step trapezoidal commutation with synchronous rectification (complementary PWM). In every 60° sector, current flows through exactly **two FET conduction paths in series**:

- **Switching leg:** the high-side FET for duty D, then the synchronous low-side FET for (1−D). One device of the pair always conducts, except during dead time.
- **Return leg:** one low-side (or high-side) FET that is statically on.

The instantaneous conduction loss per bridge is therefore:

$$P_{cond,bridge} = 2\,I^2\,R_{ds}(T_j)$$

Each of the 6 FETs participates for 120° of the 360° electrical cycle, so the cycle-averaged loss per FET is:

$$\bar P_{cond,FET} = \frac{2 I^2 R_{ds}}{6} = \frac{I^2 R_{ds}}{3}$$

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j - 25)]$$

The model is solved self-consistently. Iterating from T_j = 110 °C:

$$R_{ds}(110) = 0.90\,(1 + 0.006\cdot 85) = 1.36\ \text{m}\Omega$$

$$P_{cond,bridge} = 2(80)^2(1.36\times10^{-3}) = \mathbf{17.4\ W}$$

### 1.3 Copper and interconnect loss

The current path includes the battery pad, internal planes, solder joints and the phase pad. A conservative path resistance for a compact 6-to-8 layer 2 oz board is R_Cu ≈ 0.30 mΩ per channel. Copper resistance also rises at about 0.0039/K.
