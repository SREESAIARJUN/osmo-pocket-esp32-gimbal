# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #78): Power-Stage and DShot Design Model

## 0. Scope and Assumptions

No component list or stackup was supplied, so this model uses the representative parameters below. Every equation is parameterized; replace the numbers with your datasheet values and the results scale directly.

The H743 is the **flight controller** MCU. The ESC side runs four (or one quad-capable) dedicated ESC MCUs with AM32/BLHeli_32-class firmware. The 48 kHz PWM is generated there, not on the H743. This document models both sides and the DShot link between them.
