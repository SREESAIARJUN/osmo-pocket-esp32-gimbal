| Item | Assumed value |

| Kinematic chain | Yaw (base) → Roll → Pitch (camera) |

The control rates are multirate and phase-locked to the PWM timer:

```
PWM / ADC trigger     20 kHz  ── current loop (FOC), cogging FF, SVPWM
IMU data-ready         8 kHz  ── dual-IMU fusion + vibration filters
Velocity (rate) loop   4 kHz  ── every 5th current ISR
Angle (attitude) loop  1 kHz  ── every 4th rate loop, AHRS update
```

The bandwidth separation is roughly 10× per cascade level: f_c ≈ 2 kHz, f_v ≈ 150–200 Hz, f_θ ≈ 30–40 Hz.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p_p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi, \qquad \omega_e = p_p\,\omega_m$$

θ_off is found at commissioning: apply v_d > 0 with θ_e = 0, wait for the rotor to settle, then record θ_m.

### 1.2 Clarke and Park transforms (amplitude-invariant)

With i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Motor model in the dq frame (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p_p \lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI with pole-zero cancellation and decoupling

The PI zero cancels the electrical pole at R/L, giving a first-order closed loop with bandwidth ω_c:

$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c \quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c = 2π·2000 rad/s, which keeps ω_c·T_s ≈ 0.63 (below about 0.1·2π·f_pwm).

The control law, with cross-coupling and back-EMF feedforward, is:

$$v_d^* = K_{p,c}e_d + K_{i,c}\!\int e_d\,dt \;-\; \omega_e L\, i_q$$

$$v_q^* = K_{p,c}e_q + K_{i,c}\!\int e_q\,dt \;+\; \omega_e L\, i_d + \omega_e\lambda_m$$

Set i_d* = 0 (no field weakening is needed for a gimbal).

**Voltage limiting.** The linear SVPWM region is a circle of radius V_bus/√3:

$$|v| = \sqrt{v_d^2+v_q^2} \le V_{\max} = \frac{V_{bus}}{\sqrt3}$$

Saturate with d-priority:

$$v_d \leftarrow \text{sat}(v_d, \pm V_{\max}), \qquad v_q \leftarrow \text{sat}\!\left(v_q, \pm\sqrt{V_{\max}^2 - v_d^2}\right)$$

**Anti-windup (back-calculation).** The integrator is corrected by the amount the output was clipped:

$$\dot x_I = K_i e + K_{aw}\,(v_{\text{sat}} - v_{\text{unsat}}), \qquad K_{aw} = \frac{1}{K_p}$$

### 1.5 Delay compensation

PWM update and sampling add about 1.5·T_s of delay. Advance the angle used in the inverse Park transform:

$$\theta_{e}^{\text{inv}} = \theta_e + 1.5\,\omega_e T_s$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta - v_q\sin\theta,\qquad v_\beta = v_d\sin\theta + v_q\cos\theta$$
