# Gimbal Job #37: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

## 0. Assumptions and Architecture

I don't have a spec sheet for Job #37, so this design uses typical gimbal parameters. Every value marked **[P]** must be replaced with your measured or datasheet value.

| Item | Value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7) **[P]** |
| Commutation sensor | 14-bit magnetic encoder (MT6701/AS5048-class) on the motor shaft |
| Current sensing | 2-phase low-side shunts, ADC sampled at PWM center |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (rate feedback from the fused gyro) |
| Angle loop | 1 kHz (attitude feedback from the estimator) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, read at 4 kHz |

```
 θ*_cam ──►[Angle P + FF]──ω*──►[Vel PI-D + FF]──iq*──►(+)──►[FOC PI d/q]──►SVPWM──►Motor
              ▲                    ▲                    ▲  ▲                 ▲
     attitude (Mahony)     fused gyro rate        cogging FF  accel FF   encoder θe
              ▲                    ▲
     ┌──── Dual ICM-42688-P → calib → lever-arm → adaptive notch → weighted fusion ───┐
```

Two design points:

- **Feedback source split.** The encoder is used *only* for commutation and the cogging-table phase. The stabilization loops use the IMU, which is what keeps the camera inertially fixed.
- **Per-axis IMU frames.** On a 3-axis gimbal, the camera-frame rate is mapped to each motor axis through the joint Jacobian. Section 5.6 gives the mapping; the code assumes the per-axis rate has already been extracted.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle:
$$\theta_e = p\,\theta_m - \theta_{e,0}$$

Clarke transform (amplitude-invariant; uses $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
