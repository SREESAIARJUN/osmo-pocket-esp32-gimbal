# STM32H743 Nano FC + 4-in-1 ESC: 80 A Burst Thermal, 48 kHz Switching, and Bidirectional DShot600 Design Package

## 0. Architecture and Baseline Assumptions

The STM32H743 is the flight controller MCU. It cannot also commutate four motors. Each ESC channel therefore has its own MCU, for example an AT32F421 or EFM8BB51 running AM32 or Bluejay. The H743 generates bidirectional DShot600 on four timer channels and decodes the eRPM telemetry that returns on the same wire.

All results below are parametric. Replace the parameters with your actual BOM datasheet values and the equations still hold.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | DC link voltage |
| I_burst | 80 A per motor | Phase current during the burst |
| f_sw | 48 kHz | PWM switching frequency |
| R_ds(on),25 | 1.0 mΩ at V_GS = 10 V | 40 V MOSFET in DFN 3.3×3.3 |
| α | 0.0045 /K | R_ds(on) temperature coefficient |
| Q_gs2 + Q_gd | 3 + 8 nC | Switching charge |
| Q_g | 30 nC | Total gate charge |
| Q_rr | 40 nC | Body-diode reverse-recovery charge |
| Q_oss | 40 nC | Output charge |
| V_plateau | 3.5 V | Miller plateau voltage |
| R_g,int / R_g,ext | 1.1 Ω / 3.9 Ω | Internal and external gate resistance |
| V_drv | 10 V | Gate drive voltage |
| t_dead | 50 ns | Dead time |
| V_f | 0.8 V | Body-diode forward voltage |
| Control scheme | 6-step trapezoidal, complementary PWM | Synchronous rectification enabled |

**Reality check.** Four motors at 80 A from 6S is about 8 kW, with 320 A at the battery input. On a 20×20 or 30×30 board this is strictly a transient rating. The thermal model in Section 3 quantifies how long the burst can last.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

R_ds(on)(T_j) = R_ds,25 · [1 + α(T_j − 25)]

At T_j = 125 °C this gives R_ds(on) = 1.0 mΩ × 1.45 = **1.45 mΩ**.

### 1.2 Current path

In 6-step operation with synchronous rectification, two MOSFETs are always in the current path:

- During PWM on-time: high-side of phase A in series with low-side of phase B.
- During PWM off-time: low-side of phase A (synchronous) in series with low-side of phase B.

So the path resistance is always 2 · R_ds(on), independent of duty cycle:

P_cond,FET = 2 · I_rms² · R_ds(on)(T_j)

At 80 A and 125 °C: P_cond,FET = 2 × 6400 × 1.45×10⁻³ = **18.6 W per motor**.

### 1.3 Distribution across the six FETs

- Each FET carries the current for roughly 1/3 of the electrical cycle.
- Average dissipation per FET ≈ 18.6 / 6 = **3.1 W**.
- Peak instantaneous dissipation per FET while conducting = I² · R = **9.3 W**.

### 1.4 Copper and interconnect loss

Assume about 0.6 mΩ total path resistance. This covers the 2 oz inner planes, vias, and motor pads.

P_Cu = I² · R_path = 6400 × 0.6×10⁻³ = **3.8 W per motor**.

### 1.5 Self-consistent junction temperature

R_ds(on) depends on T_j, and T_j depends on dissipation. Solve iteratively:

T_j(n+1) = T_board + R_θ,jb · P_FET( R_ds(T_j(n)) )

This converges in 3–4 iterations. Thermal runaway (no convergence) occurs if α · R_θ · P > 1. That condition is not reached with the values used here.

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate currents during the Miller plateau

- Turn-on: I_g,on = (V_drv − V_pl) / (R_g,int + R_g,ext) = 6.5 / 5 = 1.3 A
- Turn-off: I_g,off = V_pl / R_g = 3.5 / 5 = 0.7 A

### 2.2 Transition times

- t_r = (Q_gs2 + Q_gd) / I_g,on = 11 nC / 1.3 A = 8.5 ns
- t_f = (Q_gs2 + Q_gd) / I_g,off = 11 nC / 0.7 A = 15.7 ns

### 2.3 Loss components

Only the active high-side FET switches hard. The synchronous low-side commutates at near-zero voltage.

| Loss term | Equation | Value per motor |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r + t_f) · f_sw = ½ · 25.2 · 80 · 24.2n · 48k | **1.17 W** |
| Dead-time body-diode conduction | V_f · I · 2t_dead · f_sw = 0.8 · 80 · 100n · 48k | **0.31 W** |
| Reverse recovery | Q_rr · V · f_sw = 40n · 25.2 · 48k | **0.05 W** |
| C_oss | ½ · Q_oss · V · f_sw | **0.02 W** |
| Gate drive (dissipated in the driver, not the FET) | Q_g · V_drv · f_sw · 2 | **0.03 W** |
| **Total switching** | | **≈ 1.58 W** |

### 2.4 Effect of switching frequency

Raising f_sw from 24 kHz to 48 kHz costs only about 0.8 W per motor. Conduction loss dominates by roughly 12:1. The 48 kHz choice is thermally cheap and gives quieter, smoother low-throttle behavior.

### 2.5 Total per motor at 80 A

P_motor = 18.6 + 3.8 + 1.58 ≈ **24 W**

With all four motors at 80 A: **P_total ≈ 96 W**.

## 3. Thermal Model

### 3.1 Lumped RC network

```
P_FET → R_θjc (1.5 K/W) → R_θ,spread+vias (3.0 K/W) → [C_board] → R_θ,conv → T_amb
```

### 3.2 Junction-to-board rise per FET

ΔT_j-b = 3.1 W × 4.5 K/W ≈ **14 K average**.

The peak during a conduction interval is lower than 9.3 W × 4.5 K/W. The die thermal mass, on the order of milliseconds, filters the 120° pulses at commutation frequencies above about 500 Hz.
