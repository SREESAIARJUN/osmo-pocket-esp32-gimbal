# STM32H743 AIO + 4-in-1 ESC (Job #19): Design Model

**Scope and assumptions.** This is a parameterized model. I don't have your BOM, stack-up, or layout, so every number below comes from a stated assumption, and you should replace those with datasheet values before sign-off. Two architectural points apply throughout:

1. **The H743 does not commutate the motors.** In any practical 4-in-1 AIO, the STM32H743 runs ArduPilot and sends bidirectional DShot600 to **four ESC MCUs** (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). The **48 kHz PWM** is set in the ESC firmware, not on the H743.
2. **Baseline operating point:** 6S (V_bus = 25.2 V full charge), 80 A burst phase current per motor, synchronous-rectified six-step commutation, ambient 40 °C.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

Evaluate at the design junction temperature T_j = 110 °C:

$$R_{DS}(110) = 1.2\,\text{mΩ}\times(1+0.0055\times85) = 1.2\times1.4675 \approx \mathbf{1.76\ mΩ}$$

### 2.2 Six-step current paths

In any 60° commutation sector, current flows through one high-side leg and one low-side leg in series. With synchronous rectification, the PWM'd leg alternates between its HS FET (for duty D) and its LS FET (for 1−D). As a result, **two R_DS(on) are always in the current path, independent of duty**:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{DS}(T_j)$$

$$P_{cond,motor} = 2\times80^2\times1.76\times10^{-3} = \mathbf{22.5\ W\ per\ motor}$$

Averaged over one electrical revolution, each FET carries current for 1/3 of the period:

$$\bar P_{cond,FET} = \frac{I_{ph}^2 R_{DS}}{3} = \frac{6400\times1.76\times10^{-3}}{3} \approx \mathbf{3.75\ W}$$

### 2.3 Copper losses (do not ignore)

Phase trace and plane resistance on a nano board can rival R_DS(on). For example, 1 oz copper, 4 mm wide, 15 mm long:

$$R_{Cu} = \rho\frac{L}{wt} = 1.72\times10^{-8}\frac{0.015}{0.004\times35\times10^{-6}} \approx 1.84\ \text{mΩ (at 25 °C)}$$

At 80 A that segment alone dissipates about **11.8 W**. Mitigations:
- Use 2 oz (or heavier) outer layers.
- Parallel the phase and bus planes across layers, stitched with via arrays.
- Solder-tin the exposed phase pads.

Target total copper resistance per current loop below 0.5 mΩ.

## 3. Switching Loss Model at f_sw = 48 kHz

Only the PWM'd leg switches in each sector, so the per-motor switching loss is computed for one hard-switched leg.

### 3.1 V–I overlap (hard switching)

$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(35\times10^{-9})(48\times10^3) = \mathbf{1.69\ W}$$
