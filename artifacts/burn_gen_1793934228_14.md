# STM32H743 Nano FC + 4-in-1 80 A ESC: Systems Architecture Package (Job #4)

**Document class:** Preliminary design (Rev A). Values marked **[A]** are engineering assumptions. Values marked **[V]** must be verified against the selected vendor datasheet before layout freeze. This document derives the models from first principles so you can re-run them with final part data.

## 0. Architecture Decision Summary

| Item | Decision | Rationale |
|---|---|---|
| FC MCU | STM32H743VIT6 (LQFP100) or VIH6 (TFBGA100) | 480 MHz, DMAMUX (any request can go to any stream) |
| ESC topology | **4 independent ESC MCUs** running AM32 (or BLHeli_32) | The H743 does flight control only. It does not commutate motors. |
| ESC MCU | AT32F421K8U7 or STM32G071GBU6, one per motor | Native AM32 targets; bidir
