# STM32H743 Nano FC + 4-in-1 ESC (Job #20): Architecture, Loss Model, DShot/DMA Allocation, Netlist

## 0. Architectural Ground Truth (read first)

Three constraints shape everything below:

1. **The H743 does not commutate the motors.** ArduPilot has no 6-step or FOC motor-control path for a 4-in-1 ESC. The correct partition is:
   - **H743**, running ArduPilot, sends bidirectional DShot600 to the ESC MCUs.
   - **ESC MCUs** handle commutation. Options are 4× AT32F421 running AM32, or EFM8BB21 running Bluejay. Bluejay natively supports 24, 48 and 96 kHz PWM, so 48 kHz is a standard setting.
   - The **gate drivers and MOSFET bridges** sit below the ESC MCUs.
2. **"80A burst" on a nano (20×20 mm mount, roughly 26×26 mm board) is a transient rating.** It is not continuous. The thermal section shows that you get about 1–2 s with all four channels at 80 A. On this footprint, continuous capability is roughly 25–35 A per channel.
3. **Component parameters are assumptions.** Values marked ⚠ must be replaced with your selected parts' datasheet values. Treat the netlist as a reference topology bound to net names. Physical pin numbers must come from the vendor symbols. I am not inventing pinouts.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 100 °C: R = 1.5 mΩ × 1.375 = **2.06 mΩ**.

### 1.2 6-step complementary PWM

During any 60° commutation sector, current I flows through two phases:

| Device | Conducting fraction | Loss |
|---|---|---|
| High-side, PWM phase | D | D·I²R |
| Low-side, PWM phase (sync rect.) | 1−D (minus dead time) | (1−D)·I²R |
| Low-side, static phase | 1 | I²R |

$$P_{cond,bridge}=I^2R\,[D+(1-D)+1]=\boxed{2I^2R_{DS}(T_j)}$$

The result is independent of duty cycle, which is a useful property of synchronous 6-step.

**At 80 A, T_j = 100 °C:**

$$P_{cond}=2(80)^2(2.06\text{ m}\Omega)=\mathbf{26.4\ W\ per\ channel}$$

### 1.3 Per-device distribution

Each FET conducts within a 120°-type pattern, so the average per device over an electrical revolution is:

$$P_{FET,avg}\approx\frac{26.4}{6}=4.4\text{ W}$$

The instantaneous peak in the static low-side is I²R = **13.2 W**, held for 1/6 of the electrical period. At high eRPM this is averaged by the thermal mass. At low eRPM under high load (stall, hard punch-out from hover), it is not, so use the peak value for T_j checks below roughly 50 Hz electrical.

### 1.4 Copper and shunt losses

| Path | R (est.) | P @ 80 A |
|---|---|---|
| Battery pad → bus planes → bridge → phase pad (6-layer, 2 oz outer / 1 oz inner) | ≈0.3 mΩ ⚠ | 1.9 W |
| Per-channel shunt (if fitted) | 0.5 mΩ | 3.2 W |

Recommendation: use a **single shared 0.25 mΩ DC-link shunt**
