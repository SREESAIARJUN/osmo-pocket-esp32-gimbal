## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

**Electrical angle.**
θ_e = p·(θ_m − θ_0) mod 2π, where θ_0 is the encoder offset found at calibration.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
- i_α = i_a
- i_β = (i_a + 2·i_b)/√3

**Park transform:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and decoupled PI current control

**Plant in the dq frame:**
- v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
- v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ_m

**Controller.** Use a PI per axis, add decoupling and back-EMF feedforward, then apply pole-zero cancellation:
- K_p = L·ω_c
- K_i = R·ω_c

With these gains the closed loop becomes a first-order system with bandwidth ω_c. Choose ω_c = 2π·1500 rad/s (f_s/13), which keeps the 1.5-sample PWM/computation delay at under 10° of phase.

**Control law:**
- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

**Voltage limiting.** Limit the vector to the inscribed SVPWM circle, |v| ≤ V_bus/√3. Keep v_d priority, then clip v_q.

**Anti-windup.** Clamp the integrator and back-calculate it from the saturated output.

### 1.3 SVPWM (min/max zero-sequence injection)

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the zero-sequence offset: v_0 = −(max + min)/2.
3. Compute each duty cycle: d_x = ½ + (v_x + v_0)/V_bus.

This is mathematically identical to sector-based SVPWM.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical model per axis

J·ω̇ = K_t·i_q − B·ω − τ_cog(θ) − τ_g(θ) − τ_dist

**Gravity torque** (residual imbalance, mostly on the pitch axis):
τ_g = m·g·l·cos(θ + φ)

The controller adds this as a feedforward term.

### 2.2 Choice of feedback signals

This is the key decision for a gimbal. The goal is to stabilize the camera in inertial space, so:

- **Velocity loop feedback** is the inertial rate of the camera about the joint axis, taken from the fused gyro. It is mapped to joint space with the inverse Jacobian.
- **Angle loop feedback** is the attitude error from the estimator (§4).
- **Encoder angle** is used only for commutation (θ_e), cogging compensation, the joint-space Jacobian, and soft limits.

### 2.3 Joint–camera kinematics (yaw → roll → pitch chain)

With joint angles (ψ_j, φ_j, θ_j), the camera angular velocity ω_c relates to the joint rates q̇ and the base rate ω_b by:

ω_c = R_cb·ω_b + J(q)·q̇

The Jacobian columns are the joint axes expressed in the camera frame:

J(q) = [ R_y(θ_j)ᵀ·R_x(φ_j)ᵀ·ẑ,  R_y(θ_j)ᵀ·x̂,  ŷ ]

**Rate command per motor:**
q̇* = J⁻¹·(ω_c* − R_cb·ω̂_b)

The term ω̂_b is unknown, so in practice you close the loop on the camera-frame error:
