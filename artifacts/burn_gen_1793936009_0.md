**Rate hierarchy.** Each loop is roughly 5× slower than the one inside it, which keeps the loops dynamically decoupled.

```
 20 kHz  ── Current loop (FOC, PI on id/iq) ─────── ADC-triggered ISR
  4 kHz  ── Velocity loop (PI + anti-cogging FF) ── every 5th PWM ISR
  1 kHz  ── Attitude/angle loop (P + rate FF) ───── IMU-data-ready task
  8 kHz  ── IMU sampling, notch + LPF, fusion ───── IMU DRDY / FIFO
```

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms
**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform** with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{offset}}$:
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and Decoupling
$$v_d = R_s i_d + L_s\dot i_d - \omega_e L_s i_q,\qquad v_q = R_s i_q + L_s \dot i_q + \omega_e L_s i_d + \omega_e\lambda_m$$

The decoupling feedforward cancels the cross terms and back-EMF:
$$v_d^{ff} = -\omega_e L_s i_q,\qquad v_q^{ff} = \omega_e L_s i_d + \omega_e \lambda_m$$

With these terms cancelled, each axis reduces to the first-order plant $G_i(s)=\dfrac{1}{L_s s + R_s}$.

### 1.3 Current PI by Pole-Zero Cancellation
Choose $C_i(s) = K_p + K_i/s$ with $K_i/K_p = R_s/L_s$. The open loop becomes $\omega_{ci}/s$, so the closed loop is first-order with bandwidth $\omega_{ci}$:
$$K_{p,i} = L_s\,\omega_{ci},\qquad K_{i,i} = R_s\,\omega_{ci}$$

Use $\omega_{ci} = 2\pi\cdot 1500$ rad/s. This is ≤ $f_{pwm}/10$ to leave margin for the 1.5-sample transport delay.

**Discrete form** (forward Euler, sample time $T_c$), with back-calculation anti-windup gain $K_{aw}$:
$$u_k = K_p e_k + I_k,\quad u_k^{sat} = \text{sat}(u_k),\quad I_{k+1} = I_k + K_i T_c e_k + K_{aw}(u_k^{sat}-u_k)$$

**Voltage limiting** uses circular saturation on the vector $(v_d, v_q)$:
- Limit magnitude: $|v_{dq}| \le V_{dc}/\sqrt3$ (linear SVPWM region).
- $v_d$ gets priority: $v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$.
