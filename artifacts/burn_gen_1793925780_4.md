# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the original specification for Job #2, so the design below rests on these assumptions. Every constant lives in one config block, so adapting it to your hardware means changing parameters only.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH |
| Encoders | AS5048A, 14-bit absolute magnetic, one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, rigidly co-mounted |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |
| Current loop | 20 kHz, synchronous with PWM center |
| Rate loop | 4 kHz |
| Attitude loop and AHRS | 1 kHz |

## 1. Architecture

```
          ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ────┐ ┌──────── 20 kHz ─────────┐
q_ref ──► │ quaternion error → ω_cam,ref │►│ J⁻¹(q) → q̇_ref │►│ rate PI → i_q,ref (+FF)  │──► FOC PI(d,q) → SVPWM
          └──────────────▲────────────────┘ └──────▲─────────┘ └──────▲──────────────────┘
        AHRS (Mahony) ◄──┤  q̂_cam          J⁻¹ ω_gyro│          cogging FF(θ_m), friction FF
  Dual ICM-42688-P → AAF → dynamic notch → consistency/inverse-variance fusion
```

The rate loop is closed on inertial camera rate (gyro), mapped into joint space. This rejects base motion at the full gyro bandwidth. The encoder supplies three things:

- the electrical angle for commutation,
- the joint angles for the kinematic Jacobian,
- the cogging-map phase.
