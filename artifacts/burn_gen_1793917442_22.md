## 0. Architecture Decision

**The STM32H743 does not commutate the motors.** ArduPilot on the H743 sends bidirectional DShot600 to four dedicated ESC MCUs, which run AM32 (or BLHeli_32) and generate the 48 kHz PWM. Running four 6‑step or FOC power stages plus ArduPilot's EKF3 on one core is not a viable architecture, and no supported ArduPilot firmware path exists for it.

```
6S LiPo ─┬─► 4‑in‑1 Power Stage (24× N‑MOSFET, 4× 3‑ph gate driver)
         │        ▲ PWM 48 kHz (6 lines/ch)
         │   4× ESC MCU (AT32F421 / STM32G071, AM32)
         │        ▲ DShot600 bidir (1 wire/ch, open‑drain‑ish, pull‑up)
         └─► FC: STM32H743VIT6 @ 400 MHz (ArduPilot ChibiOS)
```

## 1. Conduction-Loss Model (80 A Burst)

### 1.1 Current path

In 6‑step (120°) commutation, two legs conduct at any instant:

- **Driven leg:** the PWM leg. The high-side FET conducts during the on-time D, and the complementary low-side FET (synchronous rectification) conducts during 1−D.
- **Return leg:** the low-side FET is held on for the full 60° sector.

At every instant, phase current I flows through exactly **two** channel resistances in series (independent of D, with sync rectification). It also passes through the shunt and the copper.

### 1.2 Temperature-dependent R_DS(on)

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.0 × (1 + 0.0045 × 100) = **1.45 mΩ**.

### 1.3 Per-channel conduction loss

$$P_{cond,FET}=2\,I^2 R_{DS}(T_j)=2(80)^2(1.45\times10^{-3})=\mathbf{18.6\ W}$$

$$P_{shunt}=I^2R_{sh}=6400(0.25\times10^{-3})=\mathbf{1.6\ W}$$

$$P_{Cu}=I^2R_{Cu}=6400(0.5\times10^{-3})=\mathbf{3.2\ W}$$

### 1.4 Per-FET distribution

Each of the 6 FETs per channel conducts for 1/3 of the electrical cycle:

$$\bar P_{FET,cond}=\frac{I^2R_{DS}}{3}=3.1\ \text{W (per FET, cycle-averaged)}$$

### 1.5 Electro-thermal stability

Loss rises with temperature, and temperature rises with loss. With R_θ as junction-to-sink:

$$T_j = T_{s} + R_\theta\, I^2 R_{25}[1+\alpha(T_j-25)]$$

$$\Rightarrow\ T_j=\frac{T_s+R_\theta I^2R_{25}(1-25\alpha)}{1-\alpha R_\theta I^2 R_{25}}$$

**Runaway condition:** the denominator reaches zero when $\alpha R_\theta I^2R_{25}\ge1$.

Per FET with the 1/3 duty (I²R₂₅/3 = 2.13 W) and R_θ(j‑s) ≈ 2 K/W: 0.0045 × 2 × 2.13 = 0.019. This is far below 1, so the junction is locally stable. **The limit is board heat capacity, not per-die runaway** (see §3).
