# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model (Job #58)

## 0. Architecture Correction and Assumptions

**Correction:** ArduPilot cannot commutate motors directly. It outputs DShot only and has no BLDC/FOC bridge drivers. A working "H743 4-in-1" board is therefore an AIO with two domains:

- **FC domain:** STM32H743 running ArduPilot, sending DShot600 with bidirectional telemetry.
- **ESC domain:** 4× ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware), each driving a 3-phase gate driver and 6 MOSFETs at 48 kHz.

## 1. Conduction Loss Model

### 1.1 Commutation Topology

Assume 6-step (120°) trapezoidal drive with synchronous complementary PWM on the high side. Each phase spends 1/3 of the electrical cycle in each of three states: driven high, driven low, or floating.

| Phase state | High-side FET | Low-side FET |
|---|---|---|
| Driven high (PWM) | conducts D | conducts (1−D) (synchronous rectification) |
| Driven low | off | conducts 100 % |
| Floating | off | off |

Per-phase-leg average conduction loss:

$$P_{cond,leg} = I^2 R_{DS}(T_j)\cdot\tfrac{1}{3}\big[D + (1-D) + 1\big] = \tfrac{2}{3}\,I^2 R_{DS}(T_j)$$

Per motor channel (3 legs):

$$\boxed{P_{cond,ch} = 2\,I^2 R_{DS}(T_j)}$$

This is independent of D, because two FETs are always in the current path.

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

| T_j | Factor | R_DS |
|---|---|---|
| 25 °C | 1.00 | 0.80 mΩ |
| 100 °C | 1.41 | 1.13 mΩ |
| 125 °C | 1.55 | 1.24 mΩ |

Because R depends on T_j and T_j depends on loss, the solution must be iterated. Start at T_j = 100 °C and converge, as in §3.3.

### 1.3 Numbers at 80 A, T_j = 100 °C

- Per FET while conducting: 80² × 1.13 mΩ = **7.23 W**
- Per channel: 2 × 7.23 = **14.5 W**
- PCB copper path (≈0.25 mΩ per channel, phase pad to bus): 80² × 0.25 mΩ ≈ **1.6 W**
- Shared current shunt (0.25 mΩ, total bus current): see the 4-motor case in §3.

## 2. Switching Loss Model at 48 kHz

Only one leg per channel is switching at any instant. The other conducting leg is static low-side.

### 2.1 Hard-Switching V-I Overlap

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(30\,\text{ns})(48\,\text{kHz}) = \mathbf{1.45\ W}$$

### 2.2 Output Capacitance

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 60\,\text{nC}\times25.2\times48\text{k} = \mathbf{0.073\ W}$$

### 2.3 Reverse Recovery of the Low-Side Body Diode

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = \mathbf{0.048\ W}$$

Q_rr scales with I and di/dt, so treat this value as a lower bound.

### 2.4 Dead-Time Body-Diode Conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = 2\,V_f I\, t_{dt} f_{sw} = 2(0.8)(80)(50\,\text{ns})(48\text{k}) = \mathbf{0.31\ W}$$

### 2.5 Gate Drive

Per FET:

$$P_g = Q_g V_{gs} f_{sw} = 80\,\text{nC}\times10\times48\text{k} = 0.038\ \text{W}$$
