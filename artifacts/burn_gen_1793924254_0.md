# STM32H743 FC + 4-in-1 80A ESC (Job #48): Architecture, Loss Model, DShot DMA Plan and Netlists

## 0. Architectural Corrections

The brief contains three assumptions that would break the design if built as stated.

**1. The STM32H743 should not commutate the motors.** ArduPilot does not run sensorless BLDC commutation, and four 6-step or FOC loops on the flight MCU would wreck scheduling determinism. The baseline is:
- **H743**: runs ArduPilot and sends bi-directional DShot600 to the ESC.
- **4× ESC MCUs**: run AM32 or BLHeli_32-class firmware. AT32F421K8U7 is used for AM32 here; STM32G071 is an alternative.

**2. "80A" must be a timed burst, not a rating.** At nano or 30×30 scale, 80A per channel is a **≤2–5 s burst** rating, as derived below. Continuous capability is roughly 30–40A per channel, depending on airflow.

**3. The 48 kHz figure is assumed to be the ESC PWM frequency.** It is not the DShot rate. DShot600 is a 600 kbit/s serial protocol, analyzed separately in §4.

**Assumed operating point (change these and re-run §2–3):**

## 2. Conduction Loss Model (80A Burst)

### 2.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha (T_j-25)],\quad \alpha\approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.0 × 1.45 = **1.45 mΩ**

### 2.2 Six-step with synchronous PWM

At any instant, two phase legs carry current: one high-side and one low-side. In the PWM'd leg, current alternates between the high and low FET in that leg. Either way, exactly **one FET per active leg** conducts the full phase current. Therefore, independent of duty cycle (dead time ignored here, handled in §3):

$$P_{cond,bridge}=2\,I_{ph}^2\,R_{DS}(T_j)$$

Over one electrical cycle, each leg is active 2/3 of the time. At high eRPM the die thermal time constant (≈ms) averages this, so the per-FET average is:

$$P_{FET,avg}=\frac{P_{cond,bridge}}{6}\cdot(\text{balanced})$$

### 2.3 Numbers at 80A

| Term | Expression | Value |
|---|---|---|
| FET conduction, 1 bridge | 2·80²·1.45 mΩ | **18.56 W** |
| PCB copper + solder path (≈0.5 mΩ loop) | 80²·0.5 mΩ | 3.20 W |
| Shunt share (0.25 mΩ total, at 320A) | 320²·0.25 mΩ / 4 | 6.4 W total → 1.6 W/ch |
| **Conduction subtotal per channel** | | **≈23.4 W** |

Two caveats on these numbers:
- 320A total is never sustained, so in practice the shunt term is burst-only.
- The shunt must be ≥3W-rated and pulse-rated, or must be split across multiple parallel shunts.

## 3. Switching Loss Model (48 kHz)

Only the PWM'd leg switches; the other active leg is static during a 60° sector.

$$P_{sw}=\underbrace{\tfrac12 V I (t_r+t_f) f}_{\text{V–I overlap}}+\underbrace{Q_{rr} V f}_{\text{reverse recovery}}+\underbrace{Q_{oss} V f}_{\text{C}_{oss}}+\underbrace{2 V_{SD} I t_{dt} f}_{\text{dead-time diode}}+\underbrace{Q_g V_{GS} f \cdot 2}_{\text{gate (driver)}}$$

| Term | Calculation | Value |
|---|---|---|
| Overlap | 0.5·25.2·80·40e-9·48e3 | **1.94 W** |
| Q_rr | 50e-9·25.2·48e3 | 0.06 W |
| Q_oss | 40e-9·25.2·48e3 | 0.05 W |
| Dead-time body diode | 2·0.8·80·100e-9·48e3 | 0.61 W |
| Gate drive (2 FETs) | 2·50e-9·10·48e3 | 0.05 W (dissipated in driver/R_g) |
| **Switching subtotal per channel** | | **≈2.7 W** |

**Design observations:**
- At 48 kHz, switching loss is only about 11% of conduction loss. **Conduction dominates**, so spend money on R_DS(on) and copper, not faster edges.
- Faster edges would trade a small loss gain for worse dv/dt EMI into the IMU.
- Dropping to 24 kHz saves about 1.3 W per channel. The cost is more audible noise and current ripple on low-inductance motors.

### Totals at 80A burst

| | Per channel | ×4 channels |
|---|---|---|
| Conduction (FET + Cu + shunt) | 23.4 W | 93.6 W |
| Switching | 2.7 W | 10.8 W |
| **Total** | **26.1 W** | **≈104 W** |

### Input capacitor ripple (often the real failure point)

$$I_{C,rms}\approx I_{ph}\sqrt{D(1-D)} \le 0.5\,I_{ph}=40\ \text{A per channel}$$

With 4 unsynchronized ESC PWMs, the worst-case aggregate is ≈ 40·√4 = **80 A_rms**. This must be shared as follows:
- **MLCCs** (≈2–3 A_rms each at 48 kHz): ≥3 × 10 µF/50V X7R
