# STM32H743 Nano AIO with Integrated 4-in-1 ESC: Systems Architecture and Analytical Model

**Scope:** 6S (25.2 V max), 4 × 80 A burst, 48 kHz PWM, ArduPilot bidirectional DShot600.

> **Engineering note on the "80 A burst" requirement:** On a 20×20 or 25.5×25.5 mm nano footprint, 80 A per motor is only achievable as a **time-limited burst of about 2–3 s** with propwash airflow. The model below derives that limit rather than assuming it. All MOSFET and driver parameters are representative datasheet-class values, listed explicitly so you can substitute your actual BOM parts. The netlists are architectural reference netlists. They must be checked against the chosen parts' datasheets and pinouts before layout.

---

## 1. System Architecture

```
            6S LiPo (18.0–25.2 V)
                   │
        ┌──────────┴────────────┐
        │  Input: TVS + 35V bulk│
        │  + 4×(4.7µF X7R/HB)   │
        └──┬───────┬───────┬────┘
           │       │       │
     ┌─────▼──┐ ┌──▼───┐ ┌─▼────────┐
     │ Buck   │ │ Buck │ │ 4× ESC   │
     │ 10V/1A │ │ 5V/2A│ │ power    │
     │(gate dr)│ │(FC)  │ │ stages   │
     └────────┘ └──┬───┘ └─▲────────┘
                   │LDO 3.3V│
            ┌──────▼──────┐ │ DShot600 bidir ×4
            │ STM32H743   ├─┘ (single-wire, open-drain-ish w/ pull-up)
            │ 480 MHz FC  │
            └─────────────┘
     Each ESC channel: AT32F421 / STM32G071 (AM32) + FD6288-class
     3-phase gate driver + 6× 40V N-MOSFET (3.3×3.3 DFN)
```

**Key partition decision:** The H743 does **not** commutate motors. It generates DShot frames and decodes eRPM telemetry. Each ESC channel has its own small MCU running AM32 or BLHeli_32. This isolates commutation timing from the flight-control loop, and it is how every production AIO is built.
