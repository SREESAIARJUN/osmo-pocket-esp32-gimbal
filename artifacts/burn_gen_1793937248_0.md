# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #2 specification, so this design uses the assumptions below. Every value is a named constant, so you can substitute your own.

| Parameter | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 14 poles (7 pole pairs), 12 slots, R ≈ 5 Ω, L ≈ 2 mH |
| Position sensor | 14-bit magnetic encoder per axis (e.g. AS5048A / MT6701) |
| Current sense | 2 low-side shunts per motor |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Current loop | 20 kHz, synchronous to PWM center |
| Velocity loop | 4 kHz |
| Angle loop and fusion | 1 kHz (IMU filtering runs at 8 kHz) |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

Here $p$ is the number of pole pairs and $\theta_{\text{off}}$ is the encoder-to-rotor offset found at calibration.

### 1.2 Clarke transform (two shunts, $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$
$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p\lambda_m i_q \equiv K_t\, i_q$$

### 1.5 Current PI with pole-zero cancellation

The plant per axis is $G_i(s) = \dfrac{1}{Ls+R}$. Choosing

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

makes the closed loop first-order: $\dfrac{i}{i^*} = \dfrac{\omega_{ci}}{s+\omega_{ci}}$.

Pick $\omega_{ci} \le 2\pi f_{pwm}/20$. At 20 kHz that is about 6.3 krad/s, i.e. 1 kHz of current bandwidth.

### 1.6 Decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L\, i_d + \hat\lambda_m)$$

### 1.7 Voltage limiting

Limit the voltage vector to the linear SVPWM hexagon-inscribed circle, giving d-axis priority:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3},\qquad v_q^{\max} = \sqrt{V_{\max}^2 - v_d^2}$$

### 1.8 SVPWM via min-max zero-sequence injection

Inverse Park gives $v_\alpha, v_\beta$. Then:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.9 Delay compensation

The PWM update has a 1.5·Ts delay. Advance the angle used in inverse Park:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Gimbal structure

The stabilization goal is camera attitude in the world frame. The loops are arranged as follows:

```
 q_ref ─►[Attitude P]─► ω_cam* ─►(J⁻¹)─► ω_j* ─►[Velocity PI + FF]─► τ* ─►(÷Kt, +cog FF)─► i_q* ─►[Current PI]─► motor
              ▲                                  ▲                                                ▲
         q̂ (fused IMU)                     ω̂_j (gyro→joint)                                  i_dq (shunts)
```

### 2.2 Joint-rate mapping

For a yaw(ψ) → roll(φ) → pitch(θ) gimbal (outer → inner), the camera angular velocity in the camera frame is

$$\omega_{cam} = R_{cb}\,\omega_{base} + J(\varphi,\theta)\,\dot q,\qquad J = \begin{bmatrix} -\cos\varphi\sin\theta & \cos\theta & 0\\ \sin\varphi & 0 & 1\\ \cos\varphi\cos\theta & \sin\theta & 0\end{bmatrix}$$
