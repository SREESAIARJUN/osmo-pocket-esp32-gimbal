# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for "Job #7", so this design uses the typical hardware assumptions listed in §0. Every parameter is exposed in a config struct, so you can substitute your real values.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 1.5 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) |
| Inverter | 3-phase, two low-side shunts, SVPWM, V_bus = 12 V |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, symmetric about the plate centroid |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

The control loops are nested, each running slower than the one inside it:

```
20 kHz ─ PWM ISR ─────── Current loop (FOC, PI on d/q)         ω_c ≈ 2π·1500 rad/s
 4 kHz ─ every 5th ISR ─ Velocity loop (PI + cogging FF)        ω_v ≈ 2π·150
 8 kHz ─ IMU DRDY ────── Dual-IMU fusion + notch/LPF + attitude
 1 kHz ─ every 4th vel ─ Angle loop (P/PI + velocity FF)        ω_θ ≈ 2π·30
```

The rule of thumb is to keep each loop's bandwidth at least 5–10× below the loop inside it.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

The electrical angle comes from the mechanical angle and the encoder offset:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (two-shunt, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model in dq coordinates (SPMSM, L_d = L_q = L)

$$v_d = R\,i_d + L\dot i_d - \omega_e L\, i_q$$

$$v_q = R\,i_q + L\dot i_q + \omega_e L\, i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 Current PI with pole–zero cancellation

The control law is a PI on each axis plus decoupling feedforward:

$$v_d^* = K_{pc}\,e_d + K_{ic}\!\int e_d\,dt \;-\;\omega_e L\, i_q$$

$$v_q^* = K_{pc}\,e_q + K_{ic}\!\int e_q\,dt \;+\;\omega_e L\, i_d + \omega_e\lambda_m$$

Choose the gains so the PI zero cancels the electrical pole:

$$K_{pc} = L\,\omega_c,\qquad K_{ic} = R\,\omega_c$$

The decoupled closed loop then becomes first order:

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

To keep phase margin above 60° with one sample of computation delay plus PWM delay (≈ 1.5 T_s), keep ω_c ≤ 2π·f_pwm/12.
