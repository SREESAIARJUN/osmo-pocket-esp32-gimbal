# 3-Axis Gimbal FOC Motor Control & Dual-IMU Sensor Fusion: Design Specification

## 0. Assumptions

I don't have the Job #48 specification, so this design uses common gimbal parameters. Change the constants in `config.hpp` (Section 7.1) to match your hardware.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R_s ≈ 5–15 Ω, inline/low-side current shunts on 2 phases |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), one per axis |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |
| PWM | 20 kHz center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz |
| Kinematic order | Base → Yaw → Roll → Pitch → Camera |

## 1. FOC Inner Current Loop

### 1.1 Electrical angle

```
θ_e = wrap_2π( p · (θ_m − θ_offset) )
ω_e = p · ω_m
```

θ_offset is found at commissioning: inject i_d = I_align with θ_e = 0, let the rotor settle, then latch the encoder reading.

### 1.2 Clarke transform (power-invariant amplitude form, i_a + i_b + i_c = 0)

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

### 1.3 Park transform

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.4 PMSM model in the d-q frame

```
v_d = R i_d + L_d di_d/dt − ω_e L_q i_q
v_q = R i_q + L_q di_q/dt + ω_e (L_d i_d + λ_m)
τ_e = (3/2) p λ_m i_q = K_t i_q          (surface PM, L_d ≈ L_q)
```

### 1.5 Current PI with decoupling and back-EMF feedforward

Design by pole-zero cancellation, with target current bandwidth ω_bc (rad/s):

```
K_p,c = L · ω_bc
K_i,c = R · ω_bc            (continuous, so the zero cancels the pole at R/L)
```

The closed loop then reduces to the first-order system ω_bc/(s + ω_bc). Choose ω_bc ≤ 2π·f_pwm/20, for example 2π·1000 rad/s.

Discrete control law (backward Euler):

```
e_d[k]   = i_d* − i_d
v_d'     = K_p e_d + I_d[k]
v_d      = v_d' − ω_e L i_q
v_q      = v_q' + ω_e L i_d + ω_e λ_m
I_x[k+1] = I_x[k] + K_i T_c e_x + K_aw (v_x,sat − v_x)      (back-calculation anti-windup)
```

### 1.6 Voltage limiting (circle limit, d-axis priority)

```
V_max  = V_bus / √3 · m_max                  (m_max ≈ 0.95)
v_d,s  = clamp(v_d, ±V_max)
v_q,s  = clamp(v_q, ±√(V_max² − v_d,s²))
```
