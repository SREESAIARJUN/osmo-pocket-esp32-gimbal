## 1. Layer A: Bidirectional DShot600 on the STM32H743

### 1.1 Bit-level timing

| Parameter | Equation | Value |
|---|---|---|
| Bit period | T_bit = 1/600 kHz | 1.667 µs |
| "1" high time (75 %) | | 1.250 µs |
| "0" high time (37.5 %) | | 0.625 µs |
| Command frame | 16 bits = 11 throttle + 1 telemetry + 4 CRC | 26.67 µs |

**Timer clock.** At 480 MHz core (rev V silicon), the APB timer clock is f_TIM = 240 MHz. ArduPilot uses about 20 ticks per bit, so:

- f_cnt = 600 kHz × 20 = 12 MHz
- Prescaler: PSC = 240/12 − 1 = **19**
- ARR = 19 (20 ticks per bit)
- CCR values: "0" ≈ 7 ticks, "1" ≈ 14–15 ticks

The prescaler divides exactly, so there is zero bit-rate error.

**Bidirectional mode.** The line is inverted (idle-low becomes idle-high), and the CRC is inverted:

```
CRC = (~(v ^ v>>4 ^ v>>8)) & 0x0F
```

**ESC reply.** About 30 µs after the frame, the ESC responds:

- 21-bit GCR at 5/4 × 600 kHz = 750 kbit/s
- Reply length = 21 / 750 k = 28 µs

**Full cycle budget:**

- T_cycle ≈ 26.7 + 30 + 28 + ~10 (guard) ≈ 95 µs
- Maximum update rate ≈ 10.5 kHz
