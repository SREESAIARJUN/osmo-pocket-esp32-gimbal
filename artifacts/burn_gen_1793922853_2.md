# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have a spec sheet for Job #50, so the design is parameterized. Every hardware-dependent value lives in a config struct. The assumptions behind the defaults are listed first so you can replace them with your actual numbers.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7 class, single-precision FPU, CMSIS `arm_sin_cos_f32` available |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (MT6701
