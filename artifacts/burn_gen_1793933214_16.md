# STM32H743 Nano FC + 4-in-1 ESC (Job #44): Power-Stage and DShot Architecture Model

## 0. Architecture Assumptions

These assumptions shape every number below.

| Item | Assumption | Why it matters |
|---|---|---|
| Form factor | 20×20 mm stack (FC + ESC), M2 mounting | Sets thermal mass and the convection area |
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | Sets switching loss and FET voltage class (40 V) |
| "80 A burst" | Per channel, 4 channels simultaneously | Total battery current about 320 A. This is the worst case. |
| Commutation | AM32/BLHeli_32-style trapezoidal, complementary PWM (synchronous rectification) | Determines the conduction pattern |
| PWM | 48 kHz on the ESC MCU | Not on the H743 (see note below) |
| MOSFET (reference) | 40 V, R_DS(on) ≈ 1.0 mΩ @ 25 °C, Q_g ≈ 60 nC, Q_rr ≈ 60 nC, C_oss ≈ 1.5 nF, 5×6 / 3.3×3.3 DFN | Replace with your BOM values; the equations are parametric |

**Partitioning note.** The H743 should not drive the bridges directly. It has only two advanced timers with complementary outputs and dead-time (TIM1 and TIM8), which covers two motors. ArduPilot also contains no sensorless BLDC commutation code.

The standard architecture, assumed here, is:
- **H743**: runs ArduPilot and sends bidirectional DShot600.
- **Four ESC MCUs** (e.g., AT32F421 running AM32): each generates its own 48 kHz complementary PWM.

## 1. Conduction Loss Model

### 1.1 Current path

In a trapezoidal six-step scheme, two phases conduct at any instant:
- **PWM leg:** current flows through the high-side FET for duty D and through the synchronous low-side FET for (1−D).
- **Return leg:** current flows through the low-side FET for 100% of the sector.

Per motor:

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

Note that this is independent of D, which is a consequence of synchronous rectification.

### 1.2 Temperature coefficient

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha(T_j - 25)],\quad \alpha \approx 0.006\ /\mathrm{K}$$

At T_j = 110 °C: R_ds ≈ 1.0 × 1.51 ≈ **1.5 mΩ**.

### 1.3 Numbers at 80 A

| Term | Expression | Value |
|---|---|---|
| FET conduction | 2 × 80² × 1.5 mΩ | **19.2 W** |
| PCB copper (phase + bus path ≈ 0.5 mΩ) | 80² × 0.5 mΩ | **3.2 W** |
| Per motor conduction | | **22.4 W** |

### 1.4 Per-FET distribution

Each FET is active in two of the six sectors.

- **Instantaneous peak** (return-leg low side): 80² × 1.5 mΩ = **9.6 W**.
- **Averaging:** the electrical period is short (e.g., 357 µs at 2.8 kHz) compared with the die-to-board thermal time constant (ms range). So the time average applies:

$$\bar P_{FET} \approx \frac{19.2}{6} = 3.2\ \mathrm{W}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Per motor:

$$P_{sw} = \underbrace{\tfrac12 V_{in} I (t_r+t_f) f_s}_{\text{V–I overlap}} + \underbrace{Q_{rr} V_{in} f_s}_{\text{reverse recovery}} + \underbrace{C_{oss}V_{in}^2 f_s}_{2\times\frac12 C V^2} + \underbrace{2 V_f I\,t_{dt} f_s}_{\text{dead-time diode}} + \underbrace{2 Q_g V_{gs} f_s}_{\text{gate (driver)}}$$

Inputs: V = 25.2 V, I = 80 A, f_s = 48 kHz, t_r = t_f = 20 ns, t_dt = 100 ns, V_f = 0.8 V, V_gs = 10 V.
