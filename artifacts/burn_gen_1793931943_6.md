# 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design (Job #13)

This document covers the control equations, tuning laws, filter design and a complete C++17 implementation. The code has no heap allocation and is portable to Cortex-M4F/M7 with an FPU.
