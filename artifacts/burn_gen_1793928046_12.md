## 0. Assumptions and Loop Architecture

| Item | Assumed value (replace with yours) |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs $p=7$, slots $N_s=12$), e.g. GBM2804-class |
| Phase resistance / inductance | $R_s = 5.0\,\Omega$, $L_s = 1.8\,\text{mH}$ (line-to-neutral) |
| Torque constant | $K_t = \tfrac{3}{2}\,p\,\lambda_m \approx 0.08\,\text{N·m/A}$ |
| Axis inertia (motor + payload) | $J_{yaw}=2.5\text{e-}3$, $J_{roll}=1.2\text{e-}3$, $J_{pitch}=6\text{e-}4\ \text{kg·m}^2$ |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read every current cycle |
| Inverter | 3-phase, 24 kHz center-aligned PWM, 2 or 3 low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ±2000 dps, ±16 g |
| MCU | STM32G4/H7-class Cortex-M4F/M7 with single-precision FPU |
