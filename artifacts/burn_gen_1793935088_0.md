## 0. Scope, Assumptions, and Key Findings

**Assumptions**

| Parameter | Value | Notes |
|---|---|---|
| Form factor | 20×20 mm (M2 or M3 mount), 6-layer, 2 oz on all layers | "Nano" class |
| Bus | 6S LiPo: 22.2 V nominal, **25.2 V max** | All worst-case math uses 25.2 V |
| Burst rating | **80 A per motor channel**, at most 10 s claimed | Interpretation of the marketing number is checked in §3.6 |
| ESC PWM | 48 kHz, complementary (synchronous rectification) | AM32-class firmware |
| Commutation | 6-step trapezoidal | FOC changes the conduction factor (§2.2) |
| MOSFET (reference) | 40 V N-ch, PDFN 3.3×3.3 | Parameters in §1.2 |
| Gate driver | 3-phase half-bridge driver with bootstrap (FD6288Q-class) | |
| ESC MCUs | 4× AT32F421 or STM
