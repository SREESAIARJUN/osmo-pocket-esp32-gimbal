## 2. Conduction Loss Model

### 2.1 Current path

In 6-step with complementary PWM, motor current always flows through exactly **two channel resistances** in series:
- **PWM-on:** HS of the active leg, then motor, then LS of the return leg.
- **PWM-off:** LS of the active leg (synchronous rectification), then motor, then LS of the return leg.

Neglecting dead time, the instantaneous conduction loss per ESC channel is independent of duty cycle:

$$P_{cond,ch} = I^2 \cdot 2\,R_{DS}(T_j), \qquad R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

### 2.2 Temperature-coupled evaluation (80 A burst)

At T_j = 100 °C: R_DS = 1.2 mΩ × (1 + 0.006 × 75) = **1.74 mΩ**

$$P_{cond,ch} = 80^2 \times 2 \times 1.74\,\text{m}\Omega = \mathbf{22.3\ W}$$

R_DS rises with T_j, which raises P, which raises T_j. The fixed point is:

$$T_j = T_{ref} + R_{th}\, I^2\, 2R_{25}[1+\alpha(T_j-25)] \;\Rightarrow\; T_j = \frac{T_{ref} + 2R_{th}I^2R_{25}(1-25\alpha)}{1 - 2R_{th}I^2R_{25}\alpha}$$

**Runaway criterion:** if 2·R_th·I²·R_25·α ≥ 1, no steady state exists. With per-channel R_th = 10 K/W at 80 A, this term is 0.92. The system is near runaway, which is why 80 A can only be a time-limited burst rating (see §4).
