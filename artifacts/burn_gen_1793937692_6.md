# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

Job #32 came without a spec sheet, so this design uses the assumptions below. Every constant is set in one configuration block in the code, so you can change any of them.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 12N14P gimbal BLDC (GBM2804-class): p = 7 pole pairs, R ≈ 5.6 Ω, L ≈ 2.1 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic encoder (AS5048A / MT6701) over SPI, read at 20 kHz |
| MCU | STM32G474 at 170 MHz with single-precision FPU, inline shunts, 24 V bus |
| IMUs | 2 × ICM-42688-P on separate SPI buses. They share a CLKIN, run at 8 kHz ODR, and sit symmetrically about the camera
