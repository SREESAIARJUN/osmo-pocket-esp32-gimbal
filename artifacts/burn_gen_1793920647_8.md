# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #32)

**Scope.** This design covers the 20 kHz current loop, the cascaded inertial angle/rate controller, adaptive anti-cogging feedforward, and dual ICM-42688-P vibration-rejecting attitude estimation.

**Assumptions.** I don't have the Job #32 spec, so the design rests on the parameters below. Change them in one place (`GimbalConfig`).

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU; CORDIC is optional) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each axis |
| Current sense | 2 low-side or inline shunts per motor |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
