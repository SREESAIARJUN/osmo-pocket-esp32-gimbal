## 1. Field-Oriented Control: Inner Current Loop at 20 kHz

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau = \tfrac32 p\lambda\, i_q = K_t\, i_q$$

### 1.3 Decoupled PI Controller (Pole-Zero Cancellation)

First add the decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q$$

$$v_q^{ff} = \omega_e(L i_d + \lambda)$$

With this feedforward, each axis reduces to the plant 1/(Ls + R).

Choose the PI zero to cancel the electrical pole (K_i/K_p = R/L). The closed loop then becomes first order with bandwidth ω_c:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

$$G_{cl}(s) = \frac{\omega_c}{s + \omega_c}$$

Choose ω_c ≤ 2π·f_pwm/10 to preserve phase margin. With 20 kHz switching and about 1.5 samples of delay, ω_c = 2π·1500 rad/s is a safe choice.

### 1.4 Voltage Limiting and SVPWM

**Circular voltage limit.** The available voltage is V_max = V_bus/√3. When saturated, give the d-axis priority:

$$v_q \le \sqrt{V_{max}^2 - v_d^2}$$

**Space-vector PWM by min-max injection** (equivalent to SVPWM):

$$v_{off} = -\tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_{off}}{V_{bus}}$$

### 1.5 Anti-Windup by Back-Calculation

$$I_{k+1} = I_k + T_s\Big[K_i e_k + K_{aw}\big(u_{sat} - u_{unsat}\big)\Big]$$

Use K_aw = K_i/K_p, which equals 1/T_i.
