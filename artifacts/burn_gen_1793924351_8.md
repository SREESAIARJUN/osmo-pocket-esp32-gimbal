## 1. FOC Current Loop (Inner, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_m,0 is found at commissioning by aligning the rotor with a d-axis current vector.

### 1.2 Clarke transform (amplitude-invariant, balanced currents)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 Plant (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 PI current control with decoupling and back-EMF feedforward

The control law is

$$v_{d}^* = PI_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

With decoupling, each axis reduces to G(s) = 1/(Ls + R). Pole-zero cancellation gives a first-order closed loop with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10\text{–}20}$$

With f_PWM = 20 kHz, choose ω_c = 2π·1500 rad/s. This gives K_p = 37.7 V/A and K_i = 94 250 V/(A·s).

Set i_d* = 0. A gimbal never needs field weakening.

### 1.6 Voltage limiting and SVPWM

- **Voltage limit:** apply a circular limit |v_dq| ≤ V_bus/√3. Clamp v_q to the remaining headroom with d-axis priority.
- **Inverse Park transform:** convert v_dq back to v_αβ.
- **Phase voltages:**

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

- **Min-max zero-sequence injection (equivalent to SVPWM):**

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ* ─►[Angle P/PI]─ω*─►(+ω_ff)─►[Velocity PI]─τ*─►(+τ_cog,ff + J·α_ff)─►/Kt─i_q*─►[Current PI]─►Motor
         ▲ θ_imu (camera attitude)        ▲ ω (gyro, inertial)
```

For a stabilizer, the outer loops close on **inertial** camera attitude and rate from the IMU, not on the encoder. The encoder is used for commutation (θ_e), cogging phase, and joint limits.

### 2.2 Velocity loop plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Because the current loop is about 10× faster, treat it as unity gain. The plant is then ≈ 1/(Js).

Velocity PI in parallel form:

$$\tau^* = K_{p,v}\,e_\omega + K_{i,v}\!\int e_\omega\,dt,\qquad e_\omega=\omega^*-\omega$$

For crossover ω_v and phase margin set by the PI zero at ω_v/a (a = 4 gives about 76°):

$$K_{p,v} = J\,\omega_v,\qquad K_{i,v} = K_{p,v}\,\frac{\omega_v}{a}$$

Choose ω_v ≤ ω_c/5 (for example 2π·150 rad/s). Also keep ω_v below the first structural mode, and use the notches in §4 to suppress that mode.

**Anti-windup (back-calculation).** The integrator update is

$$\dot I = K_{i,v} e_\omega + K_{aw}(\tau_{sat} - \tau_{unsat}),\qquad K_{aw}=\frac{1}{T_t},\; T_t=\sqrt{\frac{K_{p,v}}{K_{i,v}}}\cdot\frac{1}{1}$$

### 2.3 Angle loop

The angle loop is a P controller (plus an optional small I term) on the attitude error.

**Attitude error.** For the full 3-axis case, use the quaternion error q_e = q*^{-1} ⊗ q, mapped to a body-rate error vector:

$$\mathbf e_\theta = 2\,\text{sgn}(q_{e,w})\,\mathbf q_{e,xyz}$$

Then map body-frame rate demands to joint rates through the gimbal Jacobian, ω_joint = J_g^{-1}(φ) ω_body. For a yaw-roll-pitch gimbal near level, J_g ≈ I.
