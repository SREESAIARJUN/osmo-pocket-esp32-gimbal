**Architectural note.** The STM32H743 runs ArduPilot only. It does not commutate motors. Each ESC channel needs its own commutation MCU, for example 4× AT32F421 or STM32G071 running AM32. The H743 talks to them over bidirectional DShot600.

**Critical finding up front.** A 20 × 20 board cannot dissipate the heat from 80 A continuously. The analysis below shows 80 A is only achievable as a 1–2 s adiabatic burst. Sustained current is roughly 25–35 A per channel, depending on airflow. This must go into the product spec.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step with complementary PWM

During each 60° commutation sector, two legs are active:
- **PWM leg:** the high-side conducts for D·T_sw. The low-side synchronous-rectifies for (1−D)·T_sw − 2t_d.
- **Low leg:** the low-side is held on for 100% of the sector.
- **Third leg:** floating, used for BEMF sensing.

So at almost every instant, **two MOSFET channels carry the phase current I**:

```
P_cond,ch = I² · R_DS(on)(T_j) · [D + (1−D − 2·t_d·f_sw)]  +  I² · R_DS(on)(T_j)
          ≈ 2 · I² · R_DS(on)(T_j)            (dead-time fraction handled in §2.4)
```

### 1.2 Temperature dependence

```
R_DS(on)(T_j) = R_25 · [1 + α(T_j − 25)],   α ≈ 0.005 /K  (≈1.5× at 125 °C)
```

### 1.3 At 80 A

| T_j | R_DS(on) | P_cond per channel | P_cond, 4 channels |
|---|---|---|---|
| 25 °C | 0.90 mΩ | 11.5 W | 46 W |
| 100 °C | 1.24 mΩ | 15.8 W | 63 W |
| 125 °C | 1.35 mΩ | 17.3 W | 69 W |

### 1.4 PCB copper loss (not negligible)

Assume a 2 oz (70 µm) phase trace, 4 mm wide, 8 mm long, on two parallel layers:

```
R_Cu = ρ·L/(w·t·n) = 1.72e-8 · 0.008 / (0.004 · 70e-6 · 2) = 0.25 mΩ  (+0.4%/K)
P_Cu  = 80² · 0.25e-3 ≈ 1.6 W per channel
```

The battery input path carries the sum of all four channels' average currents. It requires solder-bar or wire-to-pad construction, not just traces.

## 2. Switching Losses at 48 kHz

### 2.1 Hard-switching V·I overlap (PWM leg high-side)

```
E_sw  = ½ · V_bus · I · (t_r + t_f) = ½ · 25.2 · 80 · 30e-9 = 30.2 µJ
P_sw  = E_sw · f_sw = 30.2e-6 · 48e3 = 1.45 W
```

### 2.2 Reverse recovery (low-side body diode, at high-side turn-on)

```
P_rr = Q_rr · V_bus · f_sw = 50e-9 · 25.2 · 48e3 = 0.06 W
```

### 2.3 Output capacitance

```
P_oss ≈ ½ · Q_oss · V_bus · f_sw = 0.5 · 60e-9 · 25.2 · 48e3 = 0.04 W
```

### 2.4 Dead-time body-diode conduction

```
P_dt = V_SD · I · 2·t_d · f_sw = 0.8 · 80 · 400e-9 · 48e3 = 1.23 W
```

This is a major 48 kHz penalty. Halving dead time to 100 ns saves about 0.6 W per channel. Validate shoot-through margin against the driver's propagation-delay mismatch before doing so.

### 2.5 Gate charge (dissipated mostly in the driver and gate resistors)

```
P_g = Q_g · V_drv · f_sw · 2 (switching devices) = 50e-9 · 12 · 48e3 · 2 = 0.058 W
```
