# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the original specification for Job #45. This design therefore uses a typical high-performance gimbal configuration, listed in §0. Every equation is parametric, so you can substitute your actual motor, encoder and inertia values.

---

## 0. Assumed System Parameters

| Item | Assumption |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048A) per axis, read over SSI/SPI |
| Current sense | 2-shunt low-side, 12-bit ADC, PWM-synchronised |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz |
| Kinematic order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |

Loop rates:

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| IMU sampling | 8 kHz | 125 µs |
| Velocity (rate) loop | 4 kHz | 250 µs |
| Attitude/angle loop | 1 kHz | 1 ms |
