# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for "Job #5", so this design uses the baseline assumptions below. Every assumption is a named constant, so you can substitute your real parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Rotor sensor | 14-bit absolute magnetic encoder (e.g. AS5048A / MT6701) per axis |
| Current sensing | 2 low-side shunts per motor; the third phase is reconstructed |
| Camera IMUs | 2× ICM-42688-P on the camera plate, SP
