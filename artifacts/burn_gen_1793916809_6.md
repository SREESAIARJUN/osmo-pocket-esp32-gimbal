# 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection (Job #14)

I don't have the Job #14 specification, so the design rests on the assumptions below. Every gain is computed from these physical parameters, so you only need to change the `Params` struct to match your hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7 class with FPU and hardware-synchronized ADC |
| Motor | 12N14P gimbal BLDC (p = 7 pole pairs), R = 5.5 Ω, L = 2.2 mH, Kt = 0.06 N·m/A |
| Encoder | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A) |
| IMUs | ICM-42688-P **#0 on the camera plate** and **#1 on the gimbal base/frame**, SPI, 8 kHz ODR |
| Axis order | Yaw (Z) → Roll (X) → Pitch (Y) → camera |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz |
