## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per axis |
| MCU | STM32G4-class Cortex-M4F, 170 MHz, single-precision FPU (CORDIC optional) |
| Power stage | 3-phase driver, center-aligned PWM, low-side or inline shunts |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the payload centroid, each on its own SPI bus |
| IMU sync | Both IMUs clocked from one 32 kHz CLKIN, and/or sampled on a common FSYNC |

**Loop rates:**

| Loop | Rate | Feedback source |
|---|---|---|
| Current (FOC) | 20 kHz | Phase shunts + encoder (commutation) |
| Velocity | 4 kHz | Fused payload gyro, projected onto the joint axis |
| IMU fusion and filtering | 4 kHz | Both IMUs, ODR = 8 kHz, decimated by 2 |
| Angle / attitude | 1 kHz | Mahony attitude estimate |

```
θ_ref ─►[Angle P/PI]─ω_ref─►[Vel PI + D]─iq_fb─►(+)─iq*─►[FOC: PI_d, PI_q, decoupling, SVPWM]─► Motor
              ▲                  ▲                ▲
              │                  │                └── iq_cog(θ_m)  anti-cogging feedforward
              │                  └── ω_axis = ĵᵀ · ω_fused  (dual-IMU gyro → notch → LPF)
              └── attitude estimate (Mahony) → joint-space error via J⁻¹
```

The encoder is used for commutation and cogging phase. The inertial sensors close the stabilization loops, so base motion is rejected directly.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi, \qquad \omega_e = p\,\dot\theta_m$$

θ₀ is the encoder offset, found once by holding v_d = V_align at θ_e = 0.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

### 1.4 PMSM model (surface magnets, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

$$\tau = \tfrac32\, p\, \lambda_m\, i_q \equiv K_t\, i_q$$
