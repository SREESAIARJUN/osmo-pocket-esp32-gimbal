# STM32H743 AIO Flight Controller with 4-in-1 80A ESC: Systems Architecture (Job #9)

## 0. Scope and Assumptions

**Architecture assumption:** The H743 runs ArduPilot and drives four ESC MCUs (e.g., AT32F421 running AM32) over bi-directional DShot600. The ESC MCUs generate the 48 kHz phase PWM. The H743 does not commutate motors directly. No production 4-in-1 design does this, and ArduPilot cannot.

**Component values:** All MOSFET and driver parameters below are representative values for a 40 V, 3.3×3.3 mm or 5×6 mm trench FET class. Treat them as placeholders. Substitute the actual datasheet values and re-run the equations; the model is written so you can do that directly.

**Board size:** "Nano" is interpreted as a 20×20 mm mounting pattern on a roughly 26×26 mm board. This is the single biggest risk in the job. Section 3 shows that 80A burst on this footprint is time-limited, not continuous.

## 1. Conduction Loss Model

### 1.1 Topology
Trapezoidal 6-step with complementary (synchronous) PWM. At any instant, current I flows through exactly two FET conduction paths:

- **PWM leg:** the high-side (HS) FET conducts for D·T, and the low-side (LS) FET conducts for (1−D)·T, excluding dead time.
- **Return leg:** the LS FET is on for the full commutation sector.

### 1.2 Equations

R_ds(on) temperature dependence (linearized):

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0067\ \text{K}^{-1}\ (\Rightarrow k_T = 1.5 @ 100\,°C)$$

Per-FET losses:

$$P_{cond,HS} = I^2 R_{ds} D, \qquad P_{cond,LS(PWM)} = I^2 R_{ds}(1-D), \qquad P_{cond,LS(ret)} = I^2 R_{ds}$$

Per ESC channel, which is duty-independent:

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j)$$

Copper path (pad → FET → phase pad → return), with R_cu ≈ 0.5 mΩ for 2 oz outer and 1 oz inner stack:

$$P_{cu,ch} = I^2 R_{cu}(1+0.00393(T-25))$$

### 1.3 Worked Numbers (T_j = 100 °C, R_ds = 1.8 mΩ)

| Term | Calculation | Result |
|---|---|---|
| Single FET full-on | 80² × 1.8 mΩ | **11.52 W** |
| Channel conduction | 2 × 11.52 | **23.04 W** |
| Copper (~60 °C) | 6400 × 0.5 mΩ × 1.14 | **3.65 W** |
| **Channel total (conduction)** | | **26.7 W** |

Because of the R_ds(on) temperature coefficient, this is a positive-feedback system. Solve it iteratively; see §3.3.

## 2. Switching Loss Model at 48 kHz

Switching loss occurs only in the PWM leg. The return-leg LS FET does not switch within a sector.

### 2.1 Equations

**Hard-switching V·I overlap (HS FET):**
$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw}$$

Where t_r,f ≈ Q_gd / I_g,plateau and I_g ≈ (V_drv − V_plateau)/R_g,total.

**Dead-time body-diode conduction (LS FET, 2 edges per period):**
$$P_{dt} = V_f\, I\, (2 t_d)\, f_{sw}$$

**Reverse recovery (deposited in the HS FET at turn-on):**
$$P_{rr} = Q_{rr} V_{bus} f_{sw}$$

**Output capacitance:**
$$P_{oss} \approx \tfrac{1}{2} Q_{oss} V_{bus} f_{sw}$$

**Gate drive (per switching FET, mostly dissipated in the driver and R_g):**
$$P_{g} = Q_g V_{drv} f_{sw}$$

|---|---|---|---|
