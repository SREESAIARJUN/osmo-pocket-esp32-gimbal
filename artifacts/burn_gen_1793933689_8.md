# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #28 specification, so this design uses the assumptions in §0. Every motor-, mount-, and airframe-specific value is a parameter you can replace.

---

## 0. Assumptions and Loop Architecture

| Item | Value (default) |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 12N14P (pole pairs p = 7), with magnetic encoder (e.g. AS5048A/MT6701, 14-bit) |
| Driver | 3-phase inverter with low-side or inline shunts, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro ±2000 dps, accel ±16 g, ODR 8 kHz |
| Gimbal order | Yaw (Z) → Roll (X) → Pitch (Y) → camera |

**Rate hierarchy.** Each loop runs at roughly 5–10× the bandwidth of the loop outside it.

```
 IMU1 ─┐  8 kHz                                      20 kHz
 IMU2 ─┴► [rotate→AAF→dyn-notch→notch→LPF→fuse] ──► ω_cam ──┐
                                                            │
 θ_ref ─► [Angle P+FF] 1 kHz ─► ω_ref ─► [Velocity PI] 4 kHz ─► τ_ref
                                                            │
                     τ_cog_ff(θ_m) (anti-cogging) ──────────┤
                                                            ▼
                                          i_q* = τ/K_t ─► [Current PI dq + decoupling] ─► SVPWM
```

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$
