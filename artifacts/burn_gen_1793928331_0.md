# STM32H743 FC + 80A 4-in-1 ESC (Job #42): Design Model

## 0. Architectural Clarification and Assumptions

**Partitioning.** In ArduPilot, the STM32H743 is the flight controller. It does not commutate motors. Each ESC channel needs its own commutation MCU, typically an AT32F421 or STM32G071 running AM32 or Bluejay. The 48 kHz PWM described below is generated by those ESC MCUs. The H743 only generates bidirectional DShot600 and decodes eRPM telemetry. The model below follows this partitioning.

**Baseline assumptions.** Change these and re-run the equations; every result scales from them.

| Parameter | Value | Note |
|---|---|---|
| Bus voltage V_bus | 25.2 V | 6S, fully charged (worst-case switching) |
| Burst battery current per channel, I_batt | 80 A | |
| Duty at burst, D | 0.90 | |
| Phase current while conducting, I_ph | I_batt / D ≈ 89 A | |
| MOSFET | 40 V, DFN5x6, one per switch | R_DS(on),max = 1.2 mΩ at 25 °C; Q_g = 50 nC; Q_rr = 40 nC; Q_oss = 30 nC |
| R_DS(on) temperature factor at T_j = 110 °C | k_T = 1.45 | |
| Effective transition times t_r, t_f | 15 ns each | ~1.5 A gate driver, R_g = 3.3 Ω |
| Dead time t_dt | 100 ns per edge | Body diode V_f = 0.8 V |
| Commutation scheme | 6-step trapezoidal, complementary PWM on the high side | |

## 1. Conduction Loss Model (80A Burst)

### 1.1 Six-step current paths

In six-step drive, each phase conducts for 120° high-side and 120° low-side per electrical cycle, and floats for the remaining 120°. At every instant, exactly two legs carry I_ph.

Two quantities set the conduction loss:

$$R_{on}(T_j) = R_{25}\,k_T = 1.2\,\text{m}\Omega \times 1.45 = 1.74\,\text{m}\Omega$$

$$P_{inst} = I_{ph}^2 R_{on} = 89^2 \times 1.74\times10^{-3} = 13.8\ \text{W (one conducting FET)}$$

### 1.2 Per-device duty-weighted losses

**High-side FET.** It conducts only during its 120° high window, and only for the PWM on-time:

$$P_{HS} = P_{inst}\cdot\tfrac{1}{3}D = 13.8 \times 0.30 = 4.13\ \text{W}$$

**Low-side FET.** It conducts during synchronous rectification in its high window, plus the full 120° low window:

$$P_{LS} = P_{inst}\left[\tfrac{1}{3}(1-D) + \tfrac{1}{3}\right] = 13.8 \times 0.367 = 5.05\ \text{W}$$

### 1.3 Totals

| Level | Conduction loss |
|---|---|
| Per leg | 9.18 W |
| Per ESC (3 legs) | 27.5 W |
| Check: 2 × P_inst | 27.6 W ✓ |
| 4-in-1, all channels at burst | **≈110 W** |

**Hottest device:** the low-side FET, at about 5 W.

### 1.4 Copper and shunt losses

**Phase copper.** Assume a 2 oz internal + 2 oz external stack, with about 0.3 mΩ effective per phase path:

$$P_{Cu} = 2 \times 89^2 \times 0.3\,\text{m}\Omega \approx 4.8\ \text{W per ESC}$$

**Shared shunt.** With a single 0.25 mΩ shunt carrying 4 × 80 = 320 A:

$$P = 320^2 \times 0.25\,\text{m}\Omega = 25.6\ \text{W}$$

This is unacceptable. Use per-channel shunts instead, or a Hall sensor (e.g. ACS series / TMCS1100-class) on the battery input.

**Per-channel 0.5 mΩ shunt:**

$$P = 80^2 \times 0.5\,\text{m}\Omega = 3.2\ \text{W per channel}$$

## 2. Switching Losses at f_sw = 48 kHz

Only one leg is PWM-switching at any time in six-step drive.

| Mechanism | Equation | Value (per ESC) |
|---|---|---|
| V-I overlap (HS hard switching) | ½·V·I·(t_r + t_f)·f = 0.5·25.2·89·30 ns·48k | 1.61 W |
| Reverse recovery | Q_rr·V·f = 40 nC·25.2·48k | 0.05 W |
| Output capacitance | ½·Q_oss·V·f | 0.02 W |
| Dead-time body-diode conduction | V_f·I·2t_dt·f = 0.8·89·200 ns·48k | 0.68 W |
| Gate drive (2 FETs switching) | 2·Q_g·V_gs·f = 2·50 nC·10·48k | 0.05 W (dissipated in the driver/R_g) |
| **Total switching** | | **≈2.4 W** |

**Sensitivity:**

$$\frac{\partial P_{sw}}{\partial f} \approx 50\ \mu\text{W/Hz}$$

- Raising f_sw from 48 kHz to 96 kHz adds about 2.4 W per ESC.
- The dead-time term is significant. Each 10 ns reduction saves about 0.07 W.
- AM32 dead-time should be tuned to the measured driver propagation delay.

### Burst loss budget

| Item | Per channel | 4-in-1 |
|---|---|---|
| Conduction (FETs) | 27.5 W | 110 W |
| Switching | 2.4 W | 9.6 W |
| Copper | 4.8 W | 19 W |
| Shunt (per-channel) | 3.2 W | 12.8 W |
| **Total** | **≈38 W** | **≈150 W** |

**Efficiency:** about 98% at 2 kW per channel (80 A × 25.2 V). The efficiency is fine; the problem is the heat *density* in a nano form factor.
