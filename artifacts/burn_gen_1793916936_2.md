### 0.1 Architecture Clarification

On an H743 AIO, the H743 does not switch the MOSFETs. The partitioning is:

| Function | Device | Firmware |
|---|---|---|
| Flight control, DShot600 generation, bidir telemetry decode | STM32H743 | ArduPilot |
| 48 kHz PWM, commutation, eRPM encoding | 4× ESC MCUs (e.g., AT32F421 / STM32G071) | AM32 / BLHeli_32-class |
| Gate drive | 4× 3-phase half-bridge drivers (e.g., FD6288Q-class) | none |
| Power stage | 24× N-MOSFETs (6 per motor) | none |

The "48 kHz switching" therefore lives in the ESC MCUs. The "DShot DMA" lives in the H743.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path in 6-Step Trapezoidal Drive

During any commutation sector, two phases conduct:
- **Phase A (PWM leg):** the high-side conducts for duty D. The low-side (synchronous rectification) conducts for 1−D.
- **Phase B (return leg):** the low-side is on for 100% of the sector.

At any instant, two R_ds(on) are in series with the motor current:

$$P_{cond,motor} = I_{rms}^2 \cdot R_{ds}(T_j)\,[D + (1-D)] + I_{rms}^2 \cdot R_{ds}(T_j) = 2\,I_{rms}^2\,R_{ds}(T_j)$$

This result is independent of D. This holds for synchronous rectification. With diode freewheeling, the (1−D) term becomes V_f·I.

### 1.2 Temperature-Dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 100 °C: R_ds = 1.0 × (1 + 0.006 × 75) = **1.45 mΩ**.

### 1.3 Ripple Correction

Phase-to-phase inductance L ≈ 30 µH (typical 2207–2810 class motor). Use D = 0.5, the worst case:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} = \frac{25.2 \times 0.25}{30\mu \times 48k} = 4.4\text{ A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 1.6 \approx 6402\text{ A}^2$$

The ripple contribution is negligible (0.03%) at 80 A.

### 1.4 Result

$$P_{cond,motor} = 2 \times 6402 \times 1.45\text{ m}\Omega = \mathbf{18.6\text{ W}}$$

Add PCB copper. Phase trace plus pad plus via spreading is about 0.25 mΩ per path, giving 2 × 6400 × 0.25 m = **3.2 W per motor**. This term is not optional. On 2 oz copper, it is ~17% of the FET loss.

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate Current and Transition Times

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{src} + R_{g,ext} + R_{g,int}} = \frac{7}{5.2} = 1.35\text{ A} \Rightarrow t_{on} = \frac{Q_{sw}}{I_{g,on}} = 8.9\text{ ns}$$

$$I_{g,off} = \frac{V_{pl}}{R_{sink} + R_{g,ext} + R_{g,int}} = \frac{3}{4.2} = 0.71\text{ A} \Rightarrow t_{off} = 16.9\text{ ns}$$

### 2.2 Loss Components (per motor, one hard-switched leg per sector)

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_on + t_off)·f = ½ × 25.2 × 80 × 25.8 n × 48 k | **1.25 W** |
| Reverse recovery | Q_rr·V·f = 40 n × 25.2 × 48 k | 0.05 W |
| C_oss (both FETs in leg) | 2 × ½·C_oss·V²·f | 0.04 W |
| Dead-time body-diode conduction | V_f·I·2t_dt·f = 0.8 × 80 × 200 n × 48 k | **0.61 W** |
| Gate drive (dissipated in driver/R_g) | 2·Q_g·V_drv·f | 0.06 W |
| **Total switching** | | **≈ 2.0 W** |

**Key takeaways:**
- Dead time is the second-largest switching term. Dropping t_dt from 100 ns to 50 ns (if driver and shoot-through margin allow) saves about 0.3 W per motor.
- The off-transition dominates. A split R_g
