## 0. Architecture Clarification and Key Findings

### Where switching happens

The STM32H743 does **not** generate the 48 kHz bridge PWM. On every practical 4-in-1 design, the work is split as follows:

| Function | Device | Rate |
|---|---|---|
| Flight control, mixer, DShot600 command, eRPM decode | STM32H743 (FC) | DShot frame rate, ~1–8 kHz loop |
| Commutation, 48 kHz PWM, current sense, telemetry encode | 4× ESC MCU (e.g., AT32F421 running AM32, or BLHeli_32-class) | 48 kHz PWM |
| Gate drive | 4× 3-phase half-bridge driver (FD6288Q-class), 24 MOSFETs | 48 kHz |
