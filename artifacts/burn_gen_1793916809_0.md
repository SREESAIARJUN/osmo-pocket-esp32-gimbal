**Loop hierarchy (per axis):**

```
θ_ref ─►[Angle P + vel FF]─► ω_ref ─►[Velocity PI]─► i_q* ─►(+ i_cog_ff + base-rate FF)─►[Current PI d/q]─► SVPWM

   │                            │                                                              ▼

```

The base-disturbance rate (from IMU B) is injected as feedforward into ω_ref (§2.5).

**Bandwidth separation rule:** each outer loop should be 5–10× slower than the loop inside it.

- Current loop: ω_ci ≈ 2π·1500 rad/s
- Velocity loop: ω_cv ≈ 2π·150 rad/s
- Angle loop: ω_cp ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

**Electrical angle** (θ_off is the encoder-to-rotor alignment offset, found at calibration):

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Delay compensation.** The PWM update takes effect about 1.5 T_s after the current sample. Use the advanced angle for the inverse Park transform:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Plant and PI Design (Pole-Zero Cancellation)

**Plant in dq coordinates:**

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis reduces to

$$G(s) = \frac{1}{Ls+R}$$

**Controller.** Use the PI form

$$C(s) = K_p + \frac{K_i}{s}$$

Choose the gains so the PI zero cancels the electrical pole:

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

The open loop then becomes ω_ci/s, so the closed loop is first-order with bandwidth ω_ci.

**Numeric example.** With ω_ci = 2π·1500:
- K_p = 1.8e-3 × 9425 ≈ 16.96 V/A
- K_i = 5.6 × 9425 ≈ 52,780 V/(A·s)

**Discretization** (forward Euler on the integrator):

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}(u_{sat,k} - u_k)$$

The last term is back-calculation anti-windup with K_aw = K_i/K_p × T_s, which corresponds to a tracking time constant of K_p/K_i.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m),\qquad \lambda_m = \frac{2K_t}{3p}$$

**Voltage limit.** Apply a circular limit, with the d-axis given priority:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$
