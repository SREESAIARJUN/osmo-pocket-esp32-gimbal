# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #4 specification, so the design below uses typical gimbal values. Every value marked **[A]** is an assumption you should replace with your own.

| Item | Value |
|---|---|
| Motors **[A]** | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder **[A]** | 14-bit absolute magnetic (AS5048A / MT6701), read every current cycle |
| MCU **[A]** | STM32G4 / H7 class with FPU, center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, data-ready synchronized |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| IMU sampling and filtering | 8 kHz | — |
| Velocity (inertial-rate stabilization) | 4 kHz | ~80–150 Hz |
| Angle / attitude | 1 kHz | ~15–30 Hz |
