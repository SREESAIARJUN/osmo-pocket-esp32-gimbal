# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #35): Power-Stage, Thermal, and Bi-Directional DShot Design Model

## 0. Design Review Finding and Assumptions

**Finding:** The model in §2–§4 shows that **80 A per channel on a 20×20 mm "nano" board is credible only as a ~1 s single-motor transient**. It is not credible as a sustained or four-channel rating. Section 4.4 gives the board size and MOSFET class needed to make 80 A burst a defensible spec.

### 0.1 Architecture

The STM32H743 cannot run four sensorless BLDC commutation loops plus ArduPilot. The partitioning is:

| Function | Device |
|---|---|
| Flight controller (ArduPilot) | STM32H743VIT6 (LQFP100), 480 MHz |
| ESC MCU ×4 | STM32G071GBU6 or AT32F421 running AM32 (6-step, complementary PWM, 48 kHz) |
| Gate driver ×4 | FD6288Q-class 3-phase bootstrap driver |
| Power MOSFETs ×24 | 40 V N-ch, DFN3.3×3.3 (nano) |
| Phase-current/battery sense | Shunt + INA-class amp (or ESC-side sense) |

All part numbers are representative. Parameters below must be replaced with datasheet values of the selected parts before sign-off.

### 0.3 Operating Point

- **Supply:** 6S, V_bus = 25.2 V (worst case, full charge).
- **Current definition:** "80 A burst" = **motor/phase current per ESC channel**. Battery current is D·I_phase in 6-step.
- **PWM:** f_sw = 48 kHz, dead time t_dt = 100 ns, gate drive V_drv = 10 V.
