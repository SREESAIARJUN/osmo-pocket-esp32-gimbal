# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the Job #24 specification, so this design uses the typical gimbal-class assumptions listed in §0. Every assumed number is a named constant in the code. Replace them with your measured values before tuning.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC). Portable to any Cortex-M4F/M7. |
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (MT6701/AS5047) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the roll/pitch intersection (r₂ ≈ −r₁) |
| Current sensing | 2-shunt, inline or low-side, sampled at PWM center |

**Loop rates (single-rate scheduling from the PWM ISR):**

```
PWM ISR 20 kHz : ADC → Clarke/Park → PI_d, PI_q → inv Park → SVPWM        (current loop)
  ÷5  → 4 kHz  : encoder → velocity est. → velocity PI + cogging FF       (velocity loop)
  ÷20 → 1 kHz  : IMU fusion → attitude → angle P(I) + rate FF             (angle loop)
IMU 8 kHz ODR  : FIFO/DMA burst → notch/LPF chain at 8 kHz, decimate to 1 kHz
```

**Bandwidth separation rule:** ω_c ≥ 5·ω_v and ω_v ≥ 4–5·ω_θ.
- Typical values: ω_c = 2π·1500, ω_v = 2π·150, ω_θ = 2π·30 rad/s.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform**, using electrical angle θ_e = p·(θ_m − θ_offset):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and Decoupling

The dq voltage equations for a surface PMSM (L_d = L_q = L) are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Apply decoupling and back-EMF feedforward. Here λ_m = 2K_t / (3p) for the amplitude-invariant transform:

$$v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e L i_d + \omega_e\lambda_m$$

Each axis then reduces to the first-order plant G(s) = 1 / (Ls + R).

### 1.3 PI Design by Pole-Zero Cancellation

$$C(s) = K_p + \frac{K_i}{s},\quad K_p = L\,\omega_c,\quad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

**Discretization:** forward Euler on the integrator at T_c = 1/20 kHz. Use back-calculation anti-windup with gain K_aw = K_i / K_p:

$$x_{k+1} = x_k + T_c\big[K_i e_k + K_{aw}(u^{sat}_k - u_k)\big],\qquad u_k = K_p e_k + x_k$$

### 1.4 Voltage Limit and Space-Vector PWM

Limit the voltage vector to the linear SVPWM region, giving d-axis priority:

$$|v| \le \frac{V_{bus}}{\sqrt3}, \qquad v_q^{max} = \sqrt{(V_{bus}/\sqrt3)^2 - v_d^2}$$

**SVPWM via min-max zero-sequence injection:**

$$v_{abc} = T^{-1}_{Clarke}\,v_{\alpha\beta},\quad v_0 = -\tfrac12(\max v_{abc}+\min v_{abc}),\quad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$
