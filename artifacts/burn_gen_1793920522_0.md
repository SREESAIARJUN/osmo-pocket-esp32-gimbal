# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original spec for Job #7, so this design rests on the assumptions in Section 0. Every equation is parameterized, so you can substitute your real motor and timing values.

---

## 0. Design Assumptions

| Item | Value (assumed) |
|---|---|
| MCU | STM32G4 @ 170 MHz, FPU, center-aligned PWM |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH |
| Rotor sensor | AS5048A / MT6701, 14-bit absolute magnetic encoder |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, FIFO off, data-ready synchronized |
| Current loop | 20 kHz (inside the PWM ISR) |
| Velocity loop | 4 kHz (divide-by-5) |
| Angle loop | 1 kHz (divide-by-20) |
| Attitude estimator | 1 kHz (IMU data pre-filtered at 8 kHz, decimated) |

**Loop structure per axis:**

```
θ_ref ─►[Angle P + ff]─► ω_ref ─►[Velocity PI + AW]─► τ_ref ─►(+ cogging FF)─► i_q,ref ─►[Current PI, dq decoupled]─► SVPWM
          ▲ θ̂ (IMU attitude)        ▲ ω̂ (filtered fused gyro)                   ▲ θ_m (encoder)       ▲ i_a,i_b
```

On a stabilizer, the outer loops are closed on **inertial** feedback: attitude and gyro rate from the IMUs. The encoder is used only for commutation and the cogging-table index. Closing the loops on inertial feedback is what makes the gimbal reject base motion.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (SPM motor, L_d = L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 PI with decoupling and pole-zero cancellation

Choose the closed-loop current bandwidth $\omega_c$, typically $\omega_c \le 2\pi f_{pwm}/20$, giving ~1 kHz at 20 kHz PWM:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This gives a closed-loop transfer function $i/i^* = \omega_c/(s+\omega_c)$.

The decoupled outputs are:
$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

with $i_d^* = 0$.

### 1.6 Voltage limiting (circular)

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max}$$

Apply priority to $v_d$, then scale $v_q$:
$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.8 Torque
$$\tau = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant
$$J\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity PI (discrete, back-calculation anti-windup)

The tracking error is $e_\omega[k] = \omega^*[k] - \hat\omega[k]$.

$$u[k] = K_{p\omega} e_\omega[k] + I[k] + \tau_{ff}[k]$$
$$u_{sat}[k] = \text{clamp}(u[k], \pm\tau_{max})$$
$$I[k+1] = I[k] + T_\omega\left(K_{i\omega} e_\omega[k] + K_{aw}(u_{sat}[k] - u[k])\right)$$

Gain design, with the velocity crossover $\omega_v \le \omega_c/5$:
$$K_{p\omega} = J\,\omega_v,\qquad K_{i\omega} = K_{p\omega}\,\frac{\omega_v}{4},\qquad K_{aw} = \frac{1}{T_t},\; T_t = \sqrt{T_i T_d}\approx \frac{K_{p\omega}}{K_{i\omega}}$$

The output is a torque command. It is converted to current with $i_q^* = u_{sat}/K_t$.

Optional acceleration feedforward:
$$\tau_{ff} = J\,\dot\omega^* + b\,\omega^*$$

### 2.3 Velocity feedback filter

Take the gyro rate after the vibration filter chain (Section 4). Then apply a 1st-order LPF at $f_{v} \approx 5\,f_{\omega_v}$:

$$\hat\omega[k] = \hat\omega[k-1] + \alpha(\omega_{gyro}[k] - \hat\omega[k-1]),\qquad \alpha = 1 - e^{-2\pi f_v T_\omega}$$

### 2.4 Angle loop (P plus rate feedforward)

Use the shortest-path angle error:
$$e_\theta = \operatorname{wrap}_{[-\pi,\pi)}(\theta^* - \hat\theta)$$
$$\omega^* = \text{clamp}\left(K_{p\theta}\, e_\theta + \dot\theta^*,\ \pm\omega_{max}\right),\qquad K_{p\theta} = \omega_\theta \le \frac{\omega_v}{4}$$

A pure P term suffices because the velocity loop's integrator already rejects constant torque disturbances. This keeps the outer loop free of a double integrator and its overshoot.
