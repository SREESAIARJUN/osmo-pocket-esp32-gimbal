# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I don't have the Job #39 specification, so the design rests on the typical gimbal hardware below. Every value is a named constant you can change in the code. **Replace them with your actual parameters before tuning.**

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sense | 2- or 3-shunt, ADC synchronized to PWM center |
| MCU | STM32G4 / H7-class Cortex-M4F/M7 with FPU |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz |
| Velocity (rate) loop | 4 kHz |
| Angle (attitude) loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR 8 kHz, gyro ±500 dps, accel ±4 g |

**Loop-rate hierarchy.** Each loop's bandwidth should be at most about 1/10 of the loop below it and at most about 1/10 of its own sample rate:

- Current loop bandwidth: 1.5–2 kHz
- Rate loop bandwidth: 80–150 Hz
- Attitude loop bandwidth: 10–25 Hz

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

- θ_m is the mechanical encoder angle.
- θ_off is found at commissioning: apply V_d along the α-axis and record θ_m.
