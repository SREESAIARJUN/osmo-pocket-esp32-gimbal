# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

> **Assumptions.** I don't have the original specification for Job #27, so this design uses these defaults:
> - Brushless gimbal motors (e.g., GBM2804, 12N14P, 7 pole pairs).
> - 14-bit magnetic encoder (AS5048A / MT6701).
> - STM32G4 or similar Cortex-M4F with FPU.
> - Two ICM-42688-P IMUs on the camera plate.
>
> Every parameter is centralized in `config.hpp`. Replace the defaults with your measured values.

## 1. Architecture and Loop Rates

| Loop | Rate | Ts | Input | Output |
|---|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | i_a, i_b, θ_e | PWM duty |
| Encoder PLL / anti-cogging | 20 kHz | 50 µs | θ_m raw | θ̂_m, ω̂_m, i_q,ff |
| IMU acquisition + filtering | 4 kHz | 250 µs | 2× ICM-42688-P FIFO | ω_fused, a_fused |
| Velocity loop | 4 kHz | 250 µs | ω_ref, ω_meas | i_q,ref |
| Attitude fusion + angle loop | 1 kHz | 1 ms | q̂, q_ref | ω_ref per axis |

Bandwidth separation is about 4–5× per stage:
- Current loop: about 2 kHz
- Velocity loop: about 150–250 Hz
- Angle loop: about 30–50 Hz

## 2. FOC Current Loop Equations

### 2.1 Electrical angle

$$\theta_e = \mathrm{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{\text{off}})\big)$$

Here `p` is the number of pole pairs and θ_off is the encoder offset, found during alignment by injecting `v_d` with θ_e = 0.

### 2.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 2.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 2.5 Current PI controller with decoupling

The design uses pole-zero cancellation. The plant is 1/(Ls+R). Choosing

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

makes the closed loop first-order:

$$\frac{i}{i^*} = \frac{\omega_{ci}}{s+\omega_{ci}}$$

Discrete form (forward Euler, Ts = 50 µs), with back-calculation anti-windup gain $K_{aw} = 1/K_p$:

$$e_k = i^*_k - i_k$$

$$u_k = K_p e_k + I_k + v_{ff}$$

$$\bar u_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + T_s\big(K_i e_k + K_{aw}(\bar u_k - u_k)\big)$$

Decoupling feedforward terms:

$$v_{d,ff} = -\omega_e L i_q,\qquad v_{q,ff} = \omega_e L i_d + \omega_e\lambda_m$$

Voltage vector limiting gives the d-axis priority:

$$|v_d| \le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}$$

### 2.6 Inverse Park transform and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Phase voltages:

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection and duty cycles:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and gives 15.5% more linear range than sine PWM.
