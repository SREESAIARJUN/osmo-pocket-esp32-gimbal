# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #39 specification, so this design states its assumptions explicitly. Every gain is derived from plant parameters, so you can substitute your real values. The code is written but has not been compiled or run on hardware.

---

## 0. Assumptions & Timing Architecture

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC) | Any Cortex-M4F/M7 works |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH | High-R gimbal motors |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI | One per joint |
| Current sense | 2- or 3-shunt, synchronous ADC at PWM center | |
| IMUs | 2× ICM-42688-P on camera plate, mirrored about the plate center | Shared CLKIN |
| Kinematics | Yaw (base) → Roll → Pitch (camera) | |
