# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the specifics of Job #46, so this design uses typical gimbal values. Everything is parameterized in the code, so you can substitute your real numbers.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, CORDIC optional |
| Motor | Hollow-shaft gimbal BLDC, 12N14P, so pole pairs \(N_p = 7\) |
| Phase resistance and inductance | \(R_s\) ≈ 5–15 Ω, \(L_s\) ≈ 2–5 mH |
| Rotor encoder | 14-bit magnetic encoder (AS5048A / MT6701), SPI |
| Current sensing | Inline or low-side, 2 or 3 shunts |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Current (FOC) loop | 20 kHz, synchronized to PWM |
| Velocity loop | 4 kHz |
| Angle (attitude) loop | 1 kHz |
| IMU fusion | 8 kHz in, 4 kHz out |

Rate structure: each loop runs 4–5× faster than the one above it, and the closed-loop bandwidths are separated by about 5–10×.

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

\[
\theta_e = N_p(\theta_m - \theta_{\text{off}}) \bmod 2\pi
\]

The PWM update takes effect about 1.5 periods after the current sample. To compensate for that delay, the angle used in the inverse Park transform is advanced:

\[
\hat\theta_e = \theta_e + 1.5\,T_s\,\omega_e
\]

### 1.2 Clarke and Park transforms

Clarke (amplitude-invariant, with \(i_a + i_b + i_c = 0\)):

\[
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
\]

Park:

\[
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
\]

### 1.3 Plant and decoupling

The dq-frame voltage equations are:

\[
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
\]

The PI output is augmented with feedforward terms that cancel the cross-coupling and back-EMF:

\[
v_d = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q,\qquad
v_q = \text{PI}_q(i_q^* - i_q) + \omega_e (L i_d + \lambda_m)
\]

After decoupling, each axis reduces to \(G(s) = 1/(Ls+R)\).

### 1.4 Current PI tuning (pole-zero cancellation)

Placing the PI zero on the plant pole gives:

\[
K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}
\]

The resulting closed loop is first order: \(\frac{i}{i^*}=\frac{\omega_{ci}}{s+\omega_{ci}}\).

- Choose \(\omega_{ci} \le 2\pi f_s/20\).
- At 20 kHz this means \(f_{ci}\) ≈ 1 kHz or less.

### 1.5 Voltage limiting and SVPWM

Voltage limiting:

- Limit the voltage vector to the linear SVPWM region, \(|v_{dq}| \le V_{dc}/\sqrt3\).
- Give \(v_d\) priority: \(v_q^{\max} = \sqrt{V_{\max}^2 - v_d^2}\).

SVPWM uses the min-max (common-mode injection) form, which is equivalent to classic 7-segment SVM:

\[
v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad
v_{cm} = -\tfrac12(\max + \min),\quad
d_x = \tfrac12 + \frac{v_x + v_{cm}}{V_{dc}}
\]

## 2. Cascaded Angle → Velocity Control

On a gimbal, the velocity feedback should be the inertial body rate projected onto the motor axis, taken from the fused gyro. The encoder is used for commutation, and as a fallback for velocity feedback. This is what gives inertial stabilization rather than joint-space control.

### 2.1 Mechanical plant

\[
J\dot\omega = K_t i_q - B\omega - \tau_{\text{cog}}(\theta_m) - \tau_{\text{fric}} - \tau_{\text{dist}},
\qquad K_t = \tfrac32 N_p\lambda_m
\]

The current loop is treated as ideal at velocity-loop bandwidth, so \(G_v(s) \approx \frac{K_t}{Js}\).

### 2.2 Velocity PI

The controller is \(C_v(s) = K_p^v\left(1 + \frac{\omega_z}{s}\right)\), with \(\omega_z = \omega_{cv}/4\). This "symmetric optimum"-style placement gives about 76° of phase margin before delays are included. The gains are:

\[
K_p^v = \frac{J\,\omega_{cv}}{K_t},\qquad K_i^v = K_p^v\,\omega_z
\]

Choose \(\omega_{cv} \approx \omega_{ci}/8\), so \(f_{cv}\) is roughly 60–120 Hz.

The rate measurement is passed through a 2nd-order low-pass filter (section 4) and notch filters. The phase lag of these filters at \(\omega_{cv}\) must be budgeted: each notch should be centered at least 3× above \(\omega_{cv}\).
