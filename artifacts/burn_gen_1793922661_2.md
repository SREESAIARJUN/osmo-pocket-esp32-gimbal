# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Compensation, and Dual-IMU Fusion

I don't have the original Job #9 specification, so this design is built on the assumptions in §0. Every hardware-dependent constant is a named parameter. Change those parameters, not the math.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sense | 2-shunt low-side, sampled at PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G474 / H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the payload center of mass (r₂ = −r₁), shared CLKIN, SPI at 24 MHz |
| Gimbal chain | Base → Yaw (outer) → Roll → Pitch (inner) → Camera |

**Loop rates:**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ~1.5 kHz |
| Velocity (inertial rate) | 4 kHz | 250 µs | ~80 Hz |
| Angle / attitude | 1 kHz | 1 ms | ~15–20 Hz |
| IMU ODR | 8 kHz, decimated to 4 kHz after filtering | | |

Rule of thumb: each outer loop's bandwidth should be no more than 1/4 to 1/5 of the loop inside it. Each loop rate should be at least 10× its own bandwidth.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here θ_{m,0} is the encoder offset. It is found at startup by applying a fixed d-axis voltage and reading the encoder at rest.

### 1.2 Clarke transform (amplitude-invariant, two shunts, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (surface PMSM in the dq frame)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:
$$\tau_e = \tfrac32 p\,\lambda_m i_q = K_t\, i_q$$
