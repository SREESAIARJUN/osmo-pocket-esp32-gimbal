# Job #41: STM32H743 Nano AIO (FC + 4-in-1 ESC) System Model

## 0. Scope, Architecture Correction, and Assumptions

**Architecture.** The STM32H743 does not commutate the motors. In any ArduPilot-compatible design it is the flight controller. Each ESC channel uses its own commutation MCU running AM32 or BLHeli_32-class firmware, for example an STM32G071 or AT32F421. The H743 sends bidirectional DShot600 to those four MCUs. The architecture is therefore:

```
H743 (ArduPilot) ──BDShot600 x4──► 4x ESC MCU ──► 3-ph gate driver ──► 6 MOSFETs/ch ──► motor
```

**Assumptions.** No MOSFET part number was specified, so I parameterized the model and evaluated it with a representative 40 V, 5×6 mm, 6S-capable device. Substitute your actual datasheet values into the equations.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S full charge |
| I_burst | 80 A | Per-motor phase current, burst |
| f_sw | 48 kHz | PWM frequency |
| R_ds(on),25 | 1.2 mΩ | At V_gs = 10 V |
| k_T | ≈1.5 at Tj = 110 °C | R_ds tempco multiplier |
| R_trace | 0.3 mΩ | Copper per conduction path |
| R_shunt | 0.5 mΩ | One per channel, in the DC return |
| t_r, t_f | 15 ns, 12 ns | At R_g = 2.2 Ω |
| Q_rr | 40 nC | Body diode reverse recovery |
| Q_oss | 30 nC | Output charge |
| Q_g | 50 nC | Total gate charge |
| V_F | 0.8 V | Body diode at 80 A |
| t_dt | 100 ns | Dead time per edge |
| Board | 20×20 mm, 6-layer, 2 oz | "Nano" form factor |

## 1. Conduction Loss Model (Six-Step Trapezoidal, Synchronous Rectification)

In each 60° commutation sector, one phase is PWM'd high, one phase is held low, and one floats.

Per phase over one electrical cycle:
- **120° "high" interval:** the high-side FET conducts for fraction D. The complementary low-side FET (synchronous rectification) conducts for (1−D).
- **120° "low" interval:** the low-side FET conducts continuously.
- **120° floating:** no conduction.

The average I²R weighting per phase is:

$$
\tfrac13[D + (1-D)] + \tfrac13(1) = \tfrac23
$$

Summed over the three phases, the conduction loss is **independent of D**:

$$
P_{cond,ch} = 3\cdot\tfrac23\, I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)
$$

The average per FET (6 FETs) is:

$$
P_{cond,FET} = \frac{I^2 R_{ds}(T_j)}{3}
$$

Path parasitics add on top:
- Trace loss: P_trace = 2 I² R_trace
- Shunt loss: P_shunt = I² R_shunt × (fraction of time current flows through the shunt). This is about 1 with synchronous rectification in the DC return.

**Evaluated at 80 A** (R_ds,hot = 1.2 × 1.5 = 1.8 mΩ):

| Term | Calculation | Loss |
|---|---|---|
| MOSFET conduction | 2 × 6400 × 1.8 mΩ | 23.0 W |
| Copper | 2 × 6400 × 0.3 mΩ | 3.8 W |
| Shunt | 6400 × 0.5 mΩ | 3.2 W |
| **Conduction subtotal** | | **30.0 W per channel** |

The per-FET average conduction loss is 3.84 W.

**Thermal runaway coupling.** Because R_ds depends on temperature, the loss is recursive:

$$
R_{ds}(T_j) = R_{25}\,[1 + \alpha(T_j - 25)]
$$

Here α ≈ 0.006 /K. Iterate with T_j = T_board + P_FET·R_θ,jb until it converges. The loop is stable only while P·R_θ·α·R_25 < 1, which holds for this design.

## 2. Switching Loss Model at 48 kHz

Only one half-bridge switches at any instant, so each loss term is counted once per channel.

| Mechanism | Equation | Value at 80 A, 25.2 V |
|---|---|---|
| V-I overlap | ½ V I (t_r + t_f) f_sw | 0.5 × 25.2 × 80 × 27 ns × 48 k = **1.31 W** |
| Reverse recovery | V Q_rr f_sw | 25.2 × 40 nC × 48 k = **0.05 W** |
| Output charge (C_oss) | 2 × ½ Q_oss V f_sw | **0.04 W** |
| Dead-time body diode | V_F I (2 t_dt) f_sw | 0.8 × 80 × 200 ns × 48 k = **0.61 W** |
| Gate drive (driver IC) | 2 Q_g V_gs f_sw | 2 × 50 nC × 10 × 48 k = **0.05 W** |
| **Subtotal** | | **≈ 2.06 W per channel** |

**Design levers:**
- **Dead time:** cutting t_dt from 100 ns to 50 ns saves 0.3 W. Verify shoot-through margin against t_d(off) + t_f at T_j,max before doing so.
- **PWM frequency:** f_sw = 24 kHz halves this table but increases current ripple. Ripple is ΔI ≈ V_bus·D(1−D) / (L_ph·f_sw). Low-inductance racing motors (≈10–20 µH) prefer 48 kHz.
