# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #21)

## 0. Assumptions

I don't have the Job #21 spec sheet, so the design is parameterized on the hardware below. Every value is a `constexpr` or config field, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC (GM4108-class), 12N14P → pole pairs `p = 7`, R ≈ 10 Ω, L ≈ 4 mH (line-to-neutral) |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701) on each joint, SPI |
| MCU | STM32G474 / H7 class with FPU and center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the payload CG, on separate SPI buses |
| Kinematic order (base → camera) | Yaw (ψ, z) → Roll (φ, x) → Pitch (θ, y) |

The loop timing is:

| Loop | Rate | Trigger | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | PWM-center ADC trigger | ~1.5 kHz |
| Encoder PLL + cogging feedforward | 20 kHz | Same ISR | PLL ~300 Hz |
| IMU read + filtering | 8 kHz | IMU INT1 (data ready) | — |
| Inertial rate loop | 4 kHz | Decimated | ~80–120 Hz |
| Attitude loop | 1 kHz | Decimated | ~10–20 Hz |

The bandwidth rule is that each outer loop is at most 1/5–1/10 of the bandwidth of the loop inside it.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,\theta_m - \theta_{e,0}\big)$$

Here θ_e,0 is the encoder offset. It is found by applying v_d = V_align at θ_e = 0, letting the rotor settle, and recording p·θ_m.

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{using } i_a+i_b+i_c=0)$$

### 1.3 Park transform and its inverse

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} v_d\\ v_q\end{bmatrix}$$

### 1.4 Plant in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque is $\tau = \tfrac32 p\lambda_m i_q = K_t i_q$ (SPM motor, so L_d = L_q).
