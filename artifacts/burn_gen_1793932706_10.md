# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## Assumptions about Job #2

I don't have the original Job #2 specification, so this design uses the platform below. Every value is a named constant that you can replace.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, mounted symmetrically about the payload center |
| Gimbal kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
