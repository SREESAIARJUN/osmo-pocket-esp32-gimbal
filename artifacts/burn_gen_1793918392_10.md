# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #40 specification, so this design uses the assumed hardware and numbers below. Every dependent constant lives in one `config` namespace in the code, so you can substitute the real values in one place.

---

## 0. Assumed Platform and Loop Rates

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| Motors | 3 × gimbal BLDC (GBM2804-class): 12N14P, so 7 pole pairs, R ≈ 5.5 Ω, L ≈ 2.0 mH, K_t ≈ 0.065 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| Current sense | 2-shunt or inline, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (rigid body), SPI at 24 MHz, ODR 8 kHz, both on one FSYNC |
| Gimbal order | Yaw (z, outer) → Roll (x, middle) → Pitch (y, inner, camera) |

**Loop hierarchy.** Each inner loop is roughly 5–10× faster in bandwidth than the loop outside it.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ω_c ≈ 2π·1500 rad/s |

| Angle (P + rate feedforward) | 1 kHz (decimated) | ω_p ≈ 2π·20 rad/s |
