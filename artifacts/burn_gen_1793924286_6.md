# STM32H743 Nano FC + 4-in-1 ESC (Job #55): Power-Stage Model, Thermal Analysis, and Bi-Directional DShot600 DMA Plan

## 0. Scope, Assumptions, and Feasibility

I have no prior design data for Job #55, so this analysis rests on the explicit assumptions below. Every number is parametric, so you can substitute real datasheet values.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | 40 V-rated FETs |
| ESC topology | 3-phase, 6-step trapezoidal, synchronous (complementary) PWM | AM32 / BLHeli_32-style |
| ESC MCU | 4 × STM32G071 (or AT32F421) running AM32 | The H743 does **not** drive gates. It is the FC only. |
| f_sw | 48 kHz | Per ESC channel |
| Burst current | 80 A per channel (phase/DC-link equivalent) | |
| MOSFET | 40 V, PQFN 3.3×3.3, R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V, Q_g = 60 nC, Q_gs2 = 4 nC, Q_gd = 8 nC, Q_oss = 50 nC, Q_rr = 40 nC, R_g,int = 1 Ω, R_θJC = 1.2 K/W | Representative of the class. Replace with the chosen part. |
| Gate driver | FD6288Q-class 3-phase bootstrap driver, V_DRV ≈ 10 V | |
| Dead time | 300 ns | |
| Board | "Nano" 20×20 mm (M2 mounting); a 30.5×30.5 mm alternative is evaluated | 6-layer, 2 oz power layers |

**Feasibility flag (read first):** The math below shows that **80 A per channel on a 20×20 mm board is only achievable as a sub-second transient** when all four channels burst simultaneously. It may also be limited by copper and solder current capability before thermal limits apply. I recommend either:

- re-rating to roughly 35–45 A burst for 20×20, or
- moving to 30.5×30.5 mm with an aluminum heat-spreader.
