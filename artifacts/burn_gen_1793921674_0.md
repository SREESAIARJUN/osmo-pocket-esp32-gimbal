# STM32H743 AIO Flight Controller + 4-in-1 80A ESC: Systems Architecture (Job #50)

## 0. Architecture Decision and Assumptions

The STM32H743 is the **flight controller**. Commutation is handled by four dedicated ESC MCUs running AM32 (or BLHeli_32), one per motor. Running 4-motor sensorless commutation at 48 kHz and ArduPilot's full EKF3 stack on a single H743 is not a supported ArduPilot configuration. Bi-directional DShot600 is the FC↔ESC link.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Current Path

The ESC uses 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM. At any instant, motor current flows through exactly **two conducting channels**:
- the PWM leg, where HS or LS conducts depending on PWM state;
- the return leg's static LS.

Because synchronous rectification keeps a channel (not a body diode) in conduction during the off-time except during dead time, the path resistance is always 2·R_ds,on, independent of duty:

$$P_{cond,motor} = I_{ph}^2 \cdot 2R_{ds,on}(T_j)$$

### 1.2 Temperature-Coupled Resistance

$$R_{ds,on}(T_j) = R_{ds,on,25}\,[1 + \alpha (T_j - 25)]$$

Because R depends on T_j and T_j depends on P, the result is a fixed-point problem. It is solved in §4.

At an initial guess of T_j = 125 °C:

$$R_{ds,on} = 1.0 \times (1 + 0.0045 \times 100) = 1.45\ \text{m}\Omega$$

$$P_{cond,motor} = 80^2 \times 2 \times 1.45\times10^{-3} = \mathbf{18.56\ W}$$

### 1.3 Per-FET Distribution

Over one electrical revolution, each FET conducts 1/3 of the time (120° conduction). The worst single FET is the return-leg LS during its interval.

Its average loss over a revolution is:

$$P_{FET,avg} = \tfrac{1}{3} I^2 R = \tfrac13 (6400)(1.45\text{m}) = 3.09\ \text{W}$$

At burst, the electrical frequency is roughly 1–3 kHz. That is far faster than the junction thermal time constant (roughly 1–10 ms for die-attach), so **use the averaged value for T_j**.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches; one HS/LS pair is active per commutation step.

### 2.1 Hard-Switching Overlap (V·I crossover)

$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(40\text{n})(48\text{k}) = \mathbf{1.94\ W}$$

### 2.2 Dead-Time Body-Diode Conduction

$$P_{dt} = V_f I_{ph} \cdot 2t_{dt} \cdot f_{sw} = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = \mathbf{0.61\ W}$$

### 2.3 Reverse Recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\times25.2\times48\text{k} = \mathbf{0.060\ W}$$

### 2.4 C_oss Discharge

$$P_{oss} = \tfrac12 C_{oss}V_{bus}^2 f_{sw}\times 2 = 2\text{n}\times635\times48\text{k} = \mathbf{0.061\ W}$$

### 2.5 Gate Drive (taken from the 12 V rail, not dissipated in the FET)

$$P_{gate} = Q_g V_{GS} f_{sw} \times 2 = 60\text{n}\times10\times48\text{k}\times2 = 0.058\ \text{W}$$

### 2.6 Per-Motor and Board Totals at T_j = 125 °C

| Loss | Per motor | ×4 motors |
|---|---|---|
| Conduction | 18.56 W | 74.2 W |
| Switching overlap | 1.94 W | 7.76 W |
| Dead time | 0.61 W | 2.44 W |
| Q_rr + C_oss | 0.12 W | 0.48 W |
| **Total FET loss** | **21.23 W** | **84.9 W** |
| Shunt (0.25 mΩ, if per-motor) | 1.60 W | 6.4 W |
| Bus caps ESR (see §3.3) | — | ~1.5 W |
| **Board total** | | **≈ 92.8 W** |

**Key insight:** at 80A, conduction dominates (≈87%). Lowering f_sw from 48 kHz to 24 kHz saves only about 1.3 W per motor. Lower R_ds,on, or paralleling FETs (which quarters the loss per FET pair), is the real lever.

### 2.7 Efficiency at Burst

Assume D ≈ 0.95, so the motor terminal voltage is about 23.9 V. Output power is 4 × 23.9 × 80 ≈ 7.66 kW.

$$\eta \approx \frac{7660}{7660+93} = 98.8\%$$
