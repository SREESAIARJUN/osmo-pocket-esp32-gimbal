# STM32H743 Flight Controller with 80A 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot600 Design

## 0. Architecture and Scope

**Architectural correction.** The STM32H743 runs the flight controller (ArduPilot). It does not commutate the motors. Each ESC channel uses its own small MCU running AM32 or BLHeli_32-class firmware, such as an STM32G071 or AT32F421. The H743 sends bidirectional DShot600 to those four MCUs.

**Modulation.** Six-step trapezoidal with complementary (synchronous) PWM:
- At any instant, one high-side and one low-side FET carry the phase current.
- Each FET conducts for 120° of the electrical cycle.
- Only the PWM-switching FET incurs hard-switching loss.

## 1. Conduction Losses at 80A Burst

### 1.1 Temperature-dependent on-resistance

R_ds(Tj) = R₂₅ · [1 + α(Tj − 25)]

| Tj | R_ds(on) |
|---|---|
| 25 °C | 1.50 mΩ |
| 100 °C | 2.18 mΩ |
| 110 °C | 2.27 mΩ |
| 125 °C | 2.40 mΩ |

### 1.2 Per-FET and per-channel loss

At full throttle (D → 1), the per-FET RMS current is:

I_rms,FET = I_pk · √(1/3) = 46.2 A

P_cond,FET = I_rms² · R_ds(Tj) = (I_pk² / 3) · R_ds(Tj)

At any instant two FETs carry the full current, so the per-channel loss is:

P_cond,ch = 2 · I_pk² · R_ds(Tj)

At partial duty D with synchronous rectification, the total is unchanged: the high side carries D·I², and the low side carries (1−D)·I² during freewheel.

### 1.3 Self-consistent junction temperature

Conduction loss raises Tj, which raises R_ds(on), which raises loss. Iterate this loop until it converges:

```
Tj(n+1) = T_board + P_FET(Tj(n)) · Rθ_jb
```

Use Rθ_jb ≈ 1.2 K/W (junction to case) + 3.0 K/W (pad, vias, spreading)
