## 0. Assumptions and Architecture

| Item | Assumed value | Notes |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804), 7 pole pairs | R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Driver | 3-phase, 2 or 3 low-side shunts | Current sensing assumed. A voltage-mode fallback is noted. |
| Rotor sensor | 14-bit magnetic encoder (AS5048A/MT6701) on each axis | Used for commutation and anti-cogging indexing |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI | ODR 8 kHz for gyro and accel |
| MCU | Cortex-M4F/M7 with FPU | Single-precision float throughout |

**Loop rates and bandwidths.** Each loop runs at least 5× slower in bandwidth than the loop inside it.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (PWM-synchronous) | ω_c ≈ 2π·1.5 kHz |
| Velocity (gyro rate PI) | 8 kHz (IMU data-ready) | ω_v ≈ 2π·120 Hz |
| Angle (attitude P + FF) | 1–2 kHz | ω_p ≈ 2π·20 Hz |
| Attitude estimator | 8 kHz predict, 1 kHz accel correction | — |

**Key architectural choice.** In a camera gimbal, the feedback signals come from different sensors:

- The **velocity loop** is closed on the IMU gyro (inertial rate of the camera), not on the differentiated encoder. This rejects base motion directly.
- The **angle loop** is closed on the estimated camera attitude.
- The **encoder** is used for commutation, cogging indexing, joint-angle kinematics, and as a fallback velocity source.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \pmod{2\pi}$$

Here p is the number of pole pairs and θ_{m,0} is the encoder offset found during alignment.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** gives v_α and v_β from v_d and v_q using the transpose of that matrix.

### 1.2 Plant and Decoupled PI

The surface-mount PMSM model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The decoupling and back-EMF feedforward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,\qquad \lambda_m = \frac{2}{3}\frac{K_t}{p}$$

With these terms in place, each axis reduces to the first-order plant 1/(Ls + R).

**PI tuning by pole–zero cancellation.** Set the PI zero at R/L so the closed loop becomes first order with bandwidth ω_c:

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c$$

**Discrete implementation** (forward Euler, sample time T_s = 1/f_PWM) with back-calculation anti-windup:

$$u_k = K_p e_k + I_k + v^{ff},\quad \bar u_k=\mathrm{sat}(u_k),\quad I_{k+1}=I_k + K_i T_s e_k + K_{aw}(\bar u_k-u_k)$$

Use K_aw ≈ 1/K_p·K_i·T_s or simply K_aw = K_i T_s / K_p.

**Voltage saturation.** Limit the voltage vector to the linear SVPWM region using circular limiting with d-axis priority:

$$|v_{dq}|\le \frac{V_{bus}}{\sqrt3}$$

**Torque command.** Set i_d* = 0 (no field weakening on a gimbal) and:

$$i_q^* = \frac{\tau^*}{K_t}$$

### 1.3 SVPWM (Min/Max Injection)

Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Common-mode injection:

$$v_{0} = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

Duty cycle per phase:

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** The PWM update introduces 1.5 T_s of delay. Advance the angle used in inverse Park by:

$$\theta_e + 1.5\,\omega_e T_s$$

**Voltage-mode fallback (no current sense).** Use v_q = R i_q* + ω_e λ_m and v_d = −ω_e L i_q*. This is acceptable for gimbals because ω_e is small.
