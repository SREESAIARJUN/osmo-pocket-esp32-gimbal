# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #6 spec sheet, so this design uses the stated assumptions below. Every parameter is a named constant, so you can retarget it without changing the structure.

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Commutation encoder | 14-bit magnetic (AS5048A / MT6701), on the rotor |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM |
| Current loop | 20 kHz, synchronous with PWM; inline/low-side shunts |
| Velocity loop | 4 kHz, using **gyro** rate (inertial) |
| Angle loop | 1 kHz, using AHRS attitude (inertial) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, sharing an external CLKIN |

## 1. Field-Oriented Control (inner current loop)

### 1.1 Transforms
The electrical angle is θₑ = p·(θₘ − θ_offset), measured at the PWM center.

**Clarke transform** (amplitude invariant, assuming i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
