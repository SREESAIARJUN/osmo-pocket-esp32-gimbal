**Important:** I don't have the Job #17 specification, so this design uses the representative assumptions in §0. Every parameter is a named constant in the code. Replace them with your motor datasheet values and measured R, L, J and K_t before tuning.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.5 Ω, L = 2.0 mH, K_t ≈ 0.06 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A class) |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G474 @ 170 MHz) |
| IMUs | 2 × ICM-42688-P on separate SPI buses, shared CLKIN (32 kHz), ODR 8 kHz |
| Supply | 12 V bus, center-aligned PWM 20 kHz |

**Loop rates and bandwidths.** Each loop runs at least 4–5× above the bandwidth of the loop it encloses.

| Loop | Rate | Target bandwidth | Feedback |
|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | 1.5–2 kHz | Phase currents |
| Velocity (PI + feedforward) | 4 kHz | 150–250 Hz | Fused gyro rate (inertial) |
| Angle (P + feedforward) | 1 kHz | 30–50 Hz | Fused attitude (quaternion) |
| IMU fusion | 4 kHz (decimated from 8 kHz) | n/a | 2 × ICM-42688-P |

For a stabilizing gimbal, the velocity loop is closed on the camera's **inertial rate** (gyro), not on encoder speed. The encoder is used for commutation and for anti-cogging phase.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle (offset found at calibration):

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and decoupling

PMSM voltage equations in the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With feed-forward decoupling,

$$v_d = u_d - \omega_e L i_q,\qquad v_q = u_q + \omega_e L i_d + \omega_e\lambda_m,$$

each axis reduces to the first-order plant

$$G_i(s) = \frac{1}{Ls+R}.$$

### 1.3 PI design by pole–zero cancellation

Use the controller

$$C_i(s) = K_p + \frac{K_i}{s}.$$

Choose

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}.$$

The zero then cancels the electrical pole, and the closed loop becomes

$$T(s)=\frac{\omega_{ci}}{s+\omega_{ci}}.$$

With ω_ci = 2π·1500 rad/s: K_p = 18.85 V/A and K_i = 51 800 V/(A·s).

The current loop has one PWM period of transport delay T_s. The resulting phase loss is ω_ci T_s = 27°, which is acceptable.
