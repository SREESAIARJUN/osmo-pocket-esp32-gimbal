I don't have the Job #26 spec sheet, so this design is built on the explicit assumptions in §0. Every parameter is symbolic, and the code takes a config struct, so you can substitute your real values without changing the structure.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit magnetic encoder (e.g., AS5048A / MA730) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the payload CoM |
| PWM / current loop | 20 kHz, center-aligned, synchronous current sampling |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| IMU ODR | 8 kHz, with on-chip AAF and UI filter, decimated to 4 kHz |

The cascade runs from outside in:

```
 θ_ref ──►[Angle PID]──ω_ref──►[Velocity PI + FF]──i_q,ref──►[Current PI (d,q)]──►SVPWM──►Motor
    ▲ θ̂ (IMU attitude → joint frame)  ▲ ω̂ (fused gyro → joint rate)   ▲ i_d,i_q (Clarke/Park)
                                       └── + i_q,cog(θ_m) anti-cogging feedforward
```

Two points are critical for gimbals:

- **Velocity feedback should be the inertial rate from the gyros**, mapped into the joint axis. Encoder rate alone is not enough. Inertial feedback is what rejects base motion.
- **The encoder supplies the electrical angle** for commutation and the mechanical angle for cogging compensation.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\qquad (i_a+i_b+i_c=0)$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Pole-Zero Cancellation

Choose $C(s) = K_p + K_i/s$ with $K_i/K_p = R/L$. The open loop then becomes $\omega_{cc}/s$. The gains are:

$$K_{p,i} = L\,\omega_{cc},\qquad K_{i,i} = R\,\omega_{cc}$$

with $\omega_{cc} \le 2\pi f_{pwm}/20$. At 20 kHz, this gives $f_{cc} \approx 1$ kHz.

Decoupling and back-EMF feedforward terms:

$$v_d^{ff} = -\hat\omega_e \hat L i_q,\qquad v_q^{ff} = \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

### 1.4 Voltage Limiting and Anti-Windup

The voltage limit is circular, $|v_{dq}| \le V_{bus}/\sqrt3$. Give $d$-axis priority:

$$v_d^\* = \mathrm{sat}(v_d, V_{max}),\qquad v_q^\* = \mathrm{sat}\!\left(v_q, \sqrt{V_{max}^2 - v_d^{\*2}}\right)$$

Anti-windup uses back-calculation with $K_{aw} = 1/K_p$:

$$x_I[k+1] = x_I[k] + T_s\left(K_i e[k] + K_{aw}(u_{sat}-u_{unsat})\right)$$

### 1.5 SVPWM (min-max zero-sequence injection, equivalent to SVPWM)

$$v_{a,b,c}$$ from inverse Clarke, $$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Velocity and Angle Loops (Cascaded)

### 2.1 Mechanical Plant per Axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

The closed current loop is approximated as $G_{cc}(s) \approx \omega_{cc}/(s + \omega_{cc})$, which is effectively unity when $\omega_v \ll \omega_{cc}$.

### 2.2 Velocity PI ("Symmetric Optimum"-Style Placement)

Target crossover is $\omega_v \approx \omega_{cc}/5$ to $/10$. For a ~1 kHz current loop, use $f_v \approx 100$–$150$ Hz, limited in practice by the first structural mode.

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{N},\quad N\in[4,6]$$

Inertia and friction feedforward:

$$i_q^{ff} = \frac{\hat J\,\dot\omega_{ref} + \hat B\,\omega_{ref}}{K_t}$$

The total current command is:

$$i_{q,ref} = \mathrm{sat}\!\left(\underbrace{K_{p,v}e_\omega + x_{I,v}}_{PI} + i_q^{ff} + i_{q,cog}(\theta_m),\ I_{max}\right)$$

Add a 2nd-order low-pass on $i_{q,ref}$ (cutoff $\approx 3\omega_v$) and optional notches at structural resonances. Both use the biquad in §4.4.
