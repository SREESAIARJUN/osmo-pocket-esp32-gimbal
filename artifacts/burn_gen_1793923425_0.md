# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Package (Job #59)

## 0. Scope, Assumptions, and Feasibility Check

### 0.1 Architecture split

An STM32H743 does not drive the ESC MOSFETs directly. The standard architecture is:

| Block | Function | MCU |
|---|---|---|
| Flight controller | ArduPilot, IMU, nav, bidirectional DShot600 master | STM32H743 (400 MHz) |
| 4-in-1 ESC | 4 independent commutation controllers, 48 kHz complementary PWM | 4× AT32F421 or STM32G071 running AM32 (or BLHeli_32 on a legacy MCU) |

The 48 kHz switching analysis below applies to the ESC MCUs. The DMA analysis applies to the H743.

### 0.2 Baseline assumptions

All values are representative; replace them with the datasheet values of the parts you select.

| Parameter | Symbol | Value |
|---|---|---|
| Battery | 6S LiPo | 25.2 V full, **24 V** used under load |
| Burst phase current (per channel) | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| Duty at burst | D | 0.95 |
| MOSFET class | 40 V, PDFN 5×6 | R_DS(on) = 1.0 mΩ @25 °C (10 V V_GS) |
| R_DS(on) temperature factor at T_j ≈ 125 °C | k_T | 1.5 → **1.5 mΩ** |
| Gate charge | Q_g / Q_gs2 / Q_gd | 60 / 7 / 10 nC |
| Output / reverse-recovery charge | Q_oss / Q_rr | 40 / 40 nC |
| Body-diode forward voltage | V_F | 0.8 V |
| Dead time (per edge) | t_d | 200 ns |
| Gate drive voltage | V_drv | 10 V |
| FET count | 4 ch × 3 legs × 2 | 24 FETs |
