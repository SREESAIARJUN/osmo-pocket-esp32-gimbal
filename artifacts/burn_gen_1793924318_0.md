# STM32H743 AIO FC + 4-in-1 ESC: Thermal, Switching, and DShot Architecture (Job #68)

## 0. Scope and Assumptions

**Architecture clarification.** The STM32H743 is the flight controller. It does not commutate the motors. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32, typically an STM32G071 or AT32F421 driving a 3-phase gate driver. The H743 talks to those MCUs over bidirectional DShot600. This is the only architecture ArduPilot supports for this feature set.

## 1. Conduction Loss Model

### 1.1 Topology and conduction paths

The model assumes 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM, which is the AM32 default. During any commutation sector, phase X is PWM'd and phase Y is held low:

- **PWM on-time (D):** current flows through HS_X and LS_Y.
- **PWM off-time (1−D):** current freewheels through LS_X (synchronous) and LS_Y.

Two R_DS(on) are in series at all times, independent of duty cycle, excluding dead time:

$$P_{cond,bridge} = 2\,I_{rms}^2\,R_{DS}(T_j)$$

### 1.2 Ripple correction

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}}\Big|_{D=0.5} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple contributes 0.06%, so it is negligible at 48 kHz.

### 1.3 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right]$$

| T_j (°C) | R_DS (mΩ) | P_cond per motor (W) |
|---|---|---|
| 25 | 1.50 | 19.2 |
| 75 | 1.88 | 24.0 |
| 100 | 2.06 | 26.4 |
| 125 | 2.25 | 28.8 |

### 1.4 Thermal-runaway check

Because P_cond depends on T_j, solve the coupled equation:

$$T_j = T_{ref} + R_\theta\,P(T_j) \;\Rightarrow\; T_j = \frac{T_{ref} + R_\theta\,2I^2R_{25}(1 - 25\alpha)}{1 - R_\theta\,2I^2R_{25}\,\alpha}$$

A stable steady state exists only if R_θ · 2I²R₂₅ · α < 1. At 80 A this gives R_θ < 1/(2·6400·1.5e-3·0.005) = **10.4 K/W** per motor path. That is achievable in principle. In practice the shared board heat sink (Section 4) makes continuous 80 A impossible in a nano form factor.

### 1.5 Other conduction losses (per motor, 80 A)

| Element | Value | Loss |
|---|---|---|
| Current shunt (if per-motor) | 0.25 mΩ | 1.6 W |
| Phase copper, pad to motor wire, 2 oz × 3 layers | ~0.3 mΩ × 2 paths | 3.8 W |
| Battery-side copper, shared | ~0.2 mΩ | depends on I_batt = D·I_ph |
