# STM32H743 Nano FC + 4-in-1 ESC (Job #9): Power-Stage, Thermal, and BDShot Architecture

## 0. Scope, Assumptions, and a Feasibility Warning

**Architecture.** The STM32H743 does not drive the MOSFETs directly. It runs ArduPilot and talks bidirectional DShot600 to four ESC MCUs. Each ESC MCU (AT32F421 or STM32G071, running AM32) runs one motor's commutation loop.
