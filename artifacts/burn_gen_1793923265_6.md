# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #24. This design uses the assumptions below. Every value is a parameter, so changing a row means changing one constant.

## 0. Design Assumptions

| Item | Value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), e.g. GBM2804-class. R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic encoders (AS5048A/MT6701-class), SPI, one per joint |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM at 20 kHz |
| Loop rates | Current 20 kHz; velocity 4 kHz; attitude 1 kHz; IMU ODR 8 kHz, decimated to 4 kHz |
| Kinematic order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |
