## 1. FOC Current Loop (innermost, 20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose of the matrix above.

### 1.2 Plant model (PMSM in the dq frame)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda$$

$$\tau = \tfrac32 p \lambda\, i_q = K_t\, i_q$$

### 1.3 PI controller with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda$$

**Gain selection by pole-zero cancellation.** For a desired current bandwidth $\omega_c$ (e.g., $2\pi\cdot 1.5$ kHz, at most $f_{pwm}/10$):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This makes the closed loop $\approx \dfrac{\omega_c}{s+\omega_c}$.

**Discrete form with back-calculation anti-windup** ($T_c = 50\,\mu s$):

$$u_k = K_p e_k + I_k$$

$$I_{k+1} = I_k + K_i T_c e_k + K_{aw}\big(\text{sat}(u_k) - u_k\big)$$

$$K_{aw} \approx \frac{1}{K_p}\cdot\frac{K_i}{1}\, T_c$$

### 1.4 Voltage limit and SVPWM

The voltage vector is limited circularly to $|v| \le V_{dc}/\sqrt3$, with $v_d$ given priority.

SVPWM uses min-max (zero-sequence) injection:

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant (per joint)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity loop (4 kHz)

The derivative acts on the measurement, and a first-order filter limits derivative noise:

$$i_q^* = K_{p,v}e_\omega + K_{i,v}\!\int e_\omega - K_{d,v}\,\frac{N s}{s+N}\,\omega + \underbrace{\frac{J}{K_t}\dot\omega^*}_{\text{accel FF}} + \underbrace{\hat{i}_{cog}(\theta_m)}_{\text{anti-cogging}}$$

Here $e_\omega = \omega^* - \omega$.

**Pole placement.** Treat the current loop as unity gain (requires $\omega_v \le \omega_c/5$) and target a crossover $\omega_v$ (e.g., $2\pi\cdot150$ Hz):

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The $\omega_v/4$ ratio gives a PI zero about 2 octaves below crossover, which yields roughly 65° phase margin.

**Velocity source.** Gimbals stabilize in inertial space, so the velocity feedback is the **fused gyro rate projected onto the joint axis** (§4.6), not the encoder derivative. The encoder derivative is used only during startup, calibration, and fault fallback.

### 2.3 Angle loop (1 kHz)

The outer loop is a P controller plus rate feedforward. It needs no integrator because the velocity loop already contains one.

$$\omega^* = K_{p,\theta}\, e_\theta + \omega^*_{ff}$$

$$K_{p,\theta} \approx \omega_v/4$$

For the gimbal, the attitude error is computed in SO(3) from quaternions. With desired camera attitude $q_d$ and estimated attitude $\hat q$:

$$q_e = \hat q^{-1}\otimes q_d,\qquad e_\theta = 2\,\text{sgn}(q_{e,w})\,\vec q_{e,v}\quad\text{(body frame, rad)}$$

The body-rate command is then mapped to joint rates through the gimbal Jacobian.

### 2.4 Yaw-Roll-Pitch gimbal Jacobian

With joint angles $(\psi, \phi, \vartheta)$, the camera body angular velocity is:

$$\omega_b = J(\phi,\vartheta)\,\dot q,\qquad J = \begin{bmatrix} -\cos\phi\sin\vartheta & \cos\vartheta & 0\\ \sin\phi & 0 & 1\\ \cos\phi\cos\vartheta & \sin\vartheta & 0\end{bmatrix}$$

Column order is $(\dot\psi,\dot\phi,\dot\vartheta)$; body axes are x = roll, y = pitch, z = yaw. The determinant is $-\cos\phi$, so the Jacobian is singular at $\phi = \pm90°$ (gimbal lock).

Joint-rate commands are computed with damped least-squares:

$$\dot q^* = (J^\top J + \lambda^2 I)^{-1}J^\top \omega_b^*$$

Each component of $\dot q^*$ becomes the $\omega^*$ input of the corresponding joint's velocity loop. The joint feedback is $\omega_{joint} = $ the corresponding row of $J^{-1}\,\omega_{gyro}$, which uses the same DLS solve.
