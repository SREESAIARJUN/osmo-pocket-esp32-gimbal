# Job #33: STM32H743 Nano FC + 4-in-1 ESC Design Package

## Scope, Assumptions, and a Feasibility Warning

**Architecture assumed.** "STM32H743 4-in-1 ESC" is read here as an H743 flight controller (ArduPilot) driving a 4-in-1 ESC stage over bidirectional DShot600. Each motor is commutated by its own small ESC MCU running AM32: 4× AT32F421 class, with 48 kHz PWM.

The H743 is not used as the commutation MCU for these reasons:
- ArduPilot does not commutate BLDC motors.
- Four sensorless 48 kHz commutation loops on the same core as the flight stack would compromise both functions.

**Component parameters.** MOSFET, driver, and capacitor values below are representative of parts used in this class. They must be replaced with datasheet values for the selected BOM before sign-off.

**Feasibility warning.** The math below shows that **4 × 80 A on a 20 × 20 mm "nano" board is only survivable for about 1–2 seconds**, even with ideal layout. Any "80 A burst" rating at this size is a transient rating, not a thermal steady state. This is quantified in §1.4.

## 1. Power-Stage Loss Model (per ESC channel)

### 1.1 Operating Point

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, worst case) | V_bus | 25.2 V |
| Burst phase current | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET R_DS(on) @ 25 °C (40 V, 3.3 × 3.3 mm class) | R₂₅ | 1.6 mΩ |
| R_DS(on) temperature factor @ T_j = 125 °C | k_T | 1.6 |
| Rise / fall time (≈1.5–2 A driver) | t_r, t_f | 15 ns each |
| Dead time | t_d | 50 ns per edge |
| Body-diode V_F @ 80 A | V_F | 0.8 V |
| Reverse-recovery charge | Q_rr | 50 nC |
| Output charge | Q_oss | 40 nC |
| Gate charge @ 10 V | Q_g | 40 nC |

### 1.2 Conduction Loss

The commutation scheme is 6-step trapezoidal with complementary (synchronous) PWM. At any instant, current flows through:
- the PWM leg, either its high-side (HS) or low-side (LS) device, so that leg conducts 100 % of the period, and
- the static low-side FET of the return leg.

So two R_DS(on) are always in series:

$$P_{cond} = 2\,I_{ph}^2\,R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\,[1+\alpha (T_j-25)] \approx k_T R_{25}$$

$$P_{cond} = 2 \times 80^2 \times (1.6 \times 1.6\,\text{m}\Omega) = 2 \times 6400 \times 2.56\,\text{m}\Omega = \mathbf{32.8\ W}$$

The R_DS(on) temperature dependence creates positive feedback, which defines the thermal runaway criterion:

$$\frac{\partial P_{cond}}{\partial T_j}\,R_{th} < 1 \quad\Rightarrow\quad 2I^2R_{25}\alpha\,R_{th} < 1$$

With α ≈ 0.006 K⁻¹ this gives R_th < 8.1 K/W. That is already marginal for small packages on a nano board.

### 1.3 Switching-Related Losses (PWM leg only)

**V–I overlap (hard-switched):**
$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\,\text{ns} \times 48\,\text{kHz} = \mathbf{1.45\ W}$$

**Reverse recovery:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\,\text{nC}\times 25.2 \times 48\,\text{k} = \mathbf{0.06\ W}$$

**Output capacitance:**
$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = \mathbf{0.024\ W}$$

**Dead-time diode conduction:**
$$P_{dt} = V_F I_{ph}(2t_d) f_{sw} = 0.8 \times 80 \times 100\,\text{ns} \times 48\,\text{k} = \mathbf{0.31\ W}$$

**Gate drive** (two FETs switching per cycle; dissipated mostly in the driver and R_g):
$$P_g = 2 Q_g V_{GS} f_{sw} = 2 \times 40\,\text{nC}\times 10 \times 48\,\text{k} = \mathbf{0.038\ W}$$

### 1.4 Totals and Thermal Transient

| Loss term | Per channel | 4 channels |
|---|---|---|
| Conduction | 32.8 W | 131 W |
| Switching (overlap) | 1.45 W | 5.8 W |
| Dead time + Q_rr + Q_oss + gate | 0.43 W | 1.7 W |
| **Total** | **≈ 34.7 W** | **≈ 139 W** |

At 80 A, conduction loss is about 95 % of the total. Raising f_sw has little effect on the loss budget. Lowering R_DS(on) or the current is the only lever that matters.

**Sustained-heat check (steady state).** Use a 20 × 20 mm board, both faces, with forced convection from prop wash, h ≈ 100 W/m²K:

$$R_{\theta,board\text{-}air} = \frac{1}{hA} = \frac{1}{100 \times 8\times10^{-4}} = 12.5\ \text{K/W}$$

$$\Delta T_{ss} = 139 \times 12.5 \approx 1700\ \text{K}$$

This is physically impossible, so the design is **purely transient (adiabatic)**.

**Burst duration (adiabatic model).** Lumped heat capacity of board, FETs, capacitors, and copper:

$$C_{th} \approx m_{FR4}c_{FR4} + m_{Cu}c_{Cu} + \dots \approx 5\ \text{J/K}$$

$$\frac{dT}{dt} = \frac{P_{tot}}{C_{th}} = \frac{139}{5} \approx 28\ \text{K/s}$$

Next, find the junction-to-board offset. Each FET conducts about 1/3 of the electrical cycle, so the average per FET is 34.7/6 ≈ 5.8 W. The instantaneous static-FET conduction is I²R = 16.4 W. With Z_th,j-pcb ≈ 1.2 K/W at short pulses, the peak junction offset is about 20 K.
