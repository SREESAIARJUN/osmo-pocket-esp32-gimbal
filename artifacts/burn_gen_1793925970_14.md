## 1. Conduction Loss Model

### 1.1 Current paths (six-step trapezoidal, complementary PWM)

In each 60° commutation sector, two phases carry current I:

- **PWM leg:** the high-side switch (HS) conducts for duty D. The low-side switch (LS) of the same leg conducts for 1 − D (synchronous rectification).
- **Return leg:** the LS is held fully on, 100% of the sector.

Conduction loss per motor:

$$P_{cond} = I_{rms}^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I_{rms}^2\,R_{ds}(T_j)$$

This result is **independent of duty cycle**, which is a key property of synchronous six-step drive.

Two corrections apply.

**Ripple:**

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus}-E)\,D}{2L_{ph}\,f_{sw}}$$
