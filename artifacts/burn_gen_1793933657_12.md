# STM32H743 FC + 80A 4-in-1 ESC: Design Model (Job #65)

## 0. Assumptions and Scope Corrections

Three points need settling first, because they change the math.

1. **The H743 should not commutate the motors directly.** ArduPilot does not run ESC commutation firmware. The viable architecture is:
   **H743 FC (ArduPilot) → bidirectional DShot600 → 4× ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32) → 3-phase gate drivers → 24 MOSFETs.**
   The netlists below follow this architecture.

2. **"Nano" and "80A burst ×4" conflict physically.**
   - On a 20×20 mm board you cannot fit 24 low-Rds(on) FETs or carry 80A per phase in the copper.
   - The minimum credible form factor is **30.5×30.5 mm, 8-layer, 2 oz outer / 2 oz inner**. All thermal numbers use this board.
   - The model in §3 shows this board's *continuous* rating is ~23A/motor in prop-wash air. 80A is a **burst of a few seconds** only.

3. **No MOSFET part number was specified.** I use a representative 40V class device. Substitute your datasheet values into the equations; every result is parametric.

## 1. Conduction Loss Model (6-step trapezoidal, synchronous rectification)

AM32/BLHeli_32 use 6-step commutation with complementary PWM on the active high-side. In each 60° sector:

- **Leg A (PWM leg):** HS conducts for duty D; complementary LS conducts for (1−D).
- **Leg B (return leg):** LS fully on.
- **Leg C:** floating (BEMF sense).

Each leg spends 1/3 of the electrical cycle as the PWM leg, 1/3 as the return leg, and 1/3 floating. Per-device average loss:
