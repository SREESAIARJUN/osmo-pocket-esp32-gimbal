# STM32H743 AIO Flight Controller with 4-in-1 ESC: Thermal, Switching-Loss and Bidirectional DShot Design

## 0. Scope and Assumptions

I have no prior documentation for "Job #26," so this design rests on the assumptions below. Replace each parameter with values from your selected parts; every equation is written to accept them.

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. Four independent ESC MCUs commutate the motors. Each ESC MCU is an AT32F421 or STM32G071 running AM32 (or BLHeli_32). The H743 sends each ESC bidirectional DShot600 and receives eRPM telemetry back on the same wire.
