# STM32H743 Nano FC + 4-in-1 ESC (Job #14): Power-Stage Model, DShot Timing, Netlists

## 0. Architecture Notes and Assumptions

Two points shape everything that follows.

**1. The H743 does not generate the 48 kHz motor PWM.** In any 4-in-1 stack running ArduPilot, the H743 is the flight controller. It sends DShot600 commands. Each motor channel has its own ESC MCU (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071), which runs the 48 kHz commutation PWM and returns eRPM telemetry over the same wire.
- The switching-loss model (§2) belongs to the ESC MCUs and power stage.
- The DMA model (§4) belongs to the H743.

**2. An "80 A burst" on a nano-class board is a thermal-capacitance rating, not a power rating.** §3 shows that sustainable continuous current on a convection-cooled ~30×30 mm board is roughly 25–30 A per motor. 80 A is achievable only for a few seconds.
