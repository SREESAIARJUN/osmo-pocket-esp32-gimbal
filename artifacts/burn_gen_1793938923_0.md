# STM32H743 Nano FC + 4-in-1 ESC (Job #50): Power-Stage, Thermal, and Bi-Directional DShot Design Package

**Document scope.** This package covers four areas:

1. 80 A burst conduction-loss model
2. 48 kHz switching-loss model
3. Transient thermal model and burst-duration limit
4. Netlists for the ESC power stage, current/voltage sense, and FC-to-ESC interface, plus the ArduPilot bi-directional DShot600 timer/DMA allocation

**Architectural clarification.** The STM32H743 is the flight controller. It generates DShot600 and decodes eRPM telemetry. It does not commutate the motors. Each ESC channel uses a dedicated motor MCU running AM32 or BLHeli_32-class firmware, such as an AT32F421, together with a 3-phase gate driver and 6 N-channel MOSFETs. The 48 kHz PWM is generated by the ESC MCUs.

**Assumptions.** Values marked *(A)* are design assumptions. Replace them with datasheet values from your chosen MOSFET and driver before sign-off.

## 2. Conduction-Loss Model

### 2.1 Current path in 6-step complementary (synchronous) PWM

Take a commutation step where phase A is sourcing and phase B is sinking:

- **PWM on-time (D):** current flows through HS_A, the motor, then LS_B.
- **PWM off-time (1−D):** current freewheels through LS_A (synchronously rectified), the motor, then LS_B.

Two MOSFET channels therefore carry I_ph at every instant, apart from the dead-time intervals:

$$P_{cond,FET} = I_{ph}^2 \cdot R_{ds,hot}\,[D + (1-D)] + I_{ph}^2 R_{ds,hot} = 2\,I_{ph}^2\,R_{ds,hot}$$

### 2.2 Temperature-corrected on-resistance

$$R_{ds,hot} = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.0\,\text{mΩ}\times(1+0.005\times100) = 1.5\,\text{mΩ}$$

### 2.3 Results at 80 A

$$P_{cond,FET} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W\ per\ channel}$$

$$P_{cond,Cu} = I_{ph}^2 \cdot R_{Cu,path} \approx 6400 \times 0.3\,\text{mΩ} = \mathbf{1.92\ W\ per\ channel}$$

The copper term uses the full 0.3 mΩ per active path, which spans the HS/LS stack, the phase pad, and the bus planes.

**Per-FET average:** the conduction duty rotates across 6 FETs over each electrical cycle. Commutation runs at about 1–5 kHz, which is much faster than the junction-to-board time constant (about 10–50 ms). Each FET therefore sees an average of 19.2 W / 6 ≈ **3.2 W**. The instantaneous dissipation while a FET conducts is 80² × 1.5 mΩ = 9.6 W.

### 2.4 DC bus current versus phase current

At duty cycle D, the battery-side current is approximately I_bus ≈ D · I_ph. For example, at 80 A phase and D = 0.85, I_bus ≈ 68 A.

Input capacitor RMS ripple current:

$$I_{C,rms} = I_{ph}\sqrt{D(1-D)} = 80\sqrt{0.85\times0.15} \approx 28.6\ \text{A}$$

This ripple must be shared between the low-ESR electrolytic and a ceramic MLCC bank.

## 3. Switching-Loss Model at 48 kHz

In each commutation step, only one half-bridge is hard-switched (the PWM'd leg). The other conducting FET is static.

### 3.1 V-I overlap

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{ns} \times 48\text{k} = \mathbf{1.45\ W}$$

### 3.2 Reverse recovery

The body diode conducts during dead time, then the HS turns on into it:

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{nC}\times25.2\times48\text{k} = \mathbf{0.048\ W}$$

### 3.3 Output capacitance

$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = 0.5\times50\text{nC}\times25.2\times48\text{k} = \mathbf{0.030\ W}$$

### 3.4 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = V_F I_{ph} (2 t_{dt}) f_{sw} = 0.8\times80\times200\text{ns}\times48\text{k} = \mathbf{0.61\ W}$$

### 3.5 Gate drive

This loss lands in the driver and gate resistors, not the FET die:

$$P_{gate} = Q_g V_{GS} f_{sw} \times N_{switching} = 60\text{nC}\times10\times48\text{k}\times2 = \mathbf{0.058\ W}$$

### 3.6 Switching subtotal

| Term | Power |
|---|---|
| P_VI | 1.45 W |
| P_rr | 0.05 W |
| P_oss | 0.03 W |
| P_dt | 0.61 W |
| **P_sw per channel (FET dissipation)** | **2.14 W** |

**Sensitivity.** The switching terms scale linearly with f_sw. At 24 kHz, switching loss falls to about 1.07 W. At 96 kHz it rises to about 4.3 W. At 80 A, conduction dominates by roughly 9:1, so 48 kHz is an acceptable choice for current ripple and acoustic performance.
