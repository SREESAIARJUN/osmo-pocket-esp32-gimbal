## 1. Motor Model and FOC Equations

### 1.1 PMSM model in the dq frame (rotor-synchronous)

$$v_d = R_s i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q$$

$$v_q = R_s i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac{3}{2}p\left[\lambda_m i_q + (L_d-L_q)i_d i_q\right] \;\approx\; K_t\, i_q \quad (\text{SPM}, L_d=L_q)$$

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

Here $\omega_e = p\,\omega_m$ and $\theta_e = p\,\theta_m + \theta_{off}$.

### 1.2 Clarke transform (amplitude-invariant)

With 3 shunts, using $i_a+i_b+i_c=0$:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park and inverse Park

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

$$\begin{bmatrix}v_\alpha\\ v_\beta\end{bmatrix}=\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}v_d\\ v_q\end{bmatrix}$$

**Delay compensation.** PWM updates take effect one period later and are averaged over that period. Use $\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_s$ for the inverse Park transform.

### 1.4 Current PI with decoupling and back-EMF feedforward

Pole-zero cancellation gives a first-order closed loop $i/i^* = \omega_{cc}/(s+\omega_{cc})$:

$$K_{p,i} = L_s\,\omega_{cc},\qquad K_{i,i} = R_s\,\omega_{cc}\quad(\text{integral gain in V/(A·s)})$$

The control laws are:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L_d i_d + \omega_e\lambda_m$$

Set $i_d^*=0$ (no field weakening is needed at gimbal speeds).

**Voltage limiting.** Limit the vector magnitude to the linear SVPWM region, $|v|\le V_{bus}/\sqrt3$. Give $v_d$ priority:

$$v_{q,max}=\sqrt{V_{max}^2-v_d^2}$$

### 1.5 SVPWM (min/max zero-sequence injection)

This is equivalent to classical 7-segment SVPWM:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Angle and Velocity Control

The plant from $i_q$ to $\omega$, with the inner current loop treated as ideal, is $G_\omega(s)=\dfrac{K_t}{Js+B}$.
