## 0. Architecture Correction and Assumptions

**The STM32H743 cannot be the ESC controller.** It cannot commutate four 3-phase bridges while also running ArduPilot. It lacks enough advanced-control timers (TIM1/TIM8 give only 2 complementary 3-phase sets), and ArduPilot does not run ESC firmware. The only workable architecture is:

```
6S LiPo ─┬─► 4× [AT32F421K8U7 running AM32] ─► 4× FD6288Q ─► 4× 3-phase bridges (24 FETs)
         └─► STM32H743VIT6 (ArduPilot) ──bidirectional DShot600──► the 4 ESC MCUs
```

| Parameter | Assumed value |
|---|---|
| Battery | 6S, 25.2 V max, 22.2 V nominal |
| Burst current | 80 A per motor (phase current while conducting), burst only |
| PWM | 48 kHz, complementary/synchronous (AM32 default style) |
| MOSFET (representative 40 V, PDFN 5×6 class) | R_DS(on),25 = 0.90 mΩ @ 10 V; Q_g = 60 nC; Q_gs2 ≈ 6 nC; Q_gd = 10 nC; V_plateau = 3.5 V; C_oss ≈ 1.5 nF; Q_rr ≈ 60 nC; R_θJC = 1.2 K/W |
| Gate drive | 10 V; R_g,ext = 5 Ω; R_g,int = 1.5 Ω |
| Dead time | 100 ns |
| Board | 30.5 × 30.5 mm, 6-layer, 2 oz copper |

Substitute your actual FET datasheet values into the equations. The structure of the model holds; the numbers move.

> **Feasibility flag.** 80 A burst per motor on a 30×30 board is about 25–40% above what shipping 30×30 4-in-1 ESCs credibly sustain. Section 3 quantifies the duration limit.

## 1. Conduction Loss Model

### 1.1 Current distribution in a 6-step bridge (synchronous PWM)

In each 60° sector, one phase is PWM'd (high-side at duty D, low-side complementary) and another phase's low-side is held fully on. Each phase spends 120° (1/3 of the cycle) sourcing and 120° sinking.

Per-device conduction duty, averaged over an electrical cycle:

$$\delta_{HS} = \tfrac{1}{3}D, \qquad \delta_{LS} = \tfrac{1}{3}(1-D) + \tfrac{1}{3}$$

### 1.2 RMS current including PWM ripple

The ripple is

$$\Delta I = \frac{V_{bus}\,D(1-D)}{2L_{ph}\,f_{sw}}$$

where 2L_ph is the line-to-line inductance. The RMS current then follows:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}$$

At L_ph = 15 µH, V = 25.2 V, D = 0.5, f = 48 kHz: ΔI = 4.4 A. The ripple term is ΔI²/12 = 1.6 A², which is negligible against 6400 A². It is ignored below.

### 1.3 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \qquad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C, R_DS = 1.44 mΩ. Add about 0.15 mΩ of copper and solder path per device, giving **R_eff = 1.59 mΩ**.

### 1.4 Worst case (D → 1, full-throttle burst)

$$P_{cond,HS} = \tfrac13 \cdot 80^2 \cdot 1.59\text{m} = 3.39\ \text{W}$$

$$P_{cond,LS} = \tfrac13(0 + 1) \cdot 80^2 \cdot 1.59\text{m} = 3.39\ \text{W}$$

| Scope | Conduction loss |
|---|---|
| Per phase leg | 6.78 W |
| Per motor (3 legs) | 20.3 W |
| Board (4 motors) | **81.4 W** |

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate current and transition times

**Turn-on:**

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,ext} + R_{g,int}} = \frac{10 - 3.5}{6.5} = 1.0\ \text{A}$$

$$t_{on} \approx \frac{Q_{gs2} + Q_{gd}}{I_{g,on}} = 16\ \text{ns}$$

**Turn-off:**

$$I_{g,off} = \frac{V_{pl}}{R_g} = 0.54\ \text{A} \;\Rightarrow\; t_{off} \approx 30\ \text{ns}$$

> **Check:** the FD6288's own source/sink limit may cap I_g below these values. Verify against the datasheet, and lower R_g,ext if needed.

### 2.2 Energy per PWM cycle (hard-switched high side, V = 25.2 V, I = 80 A)

| Term | Expression | Energy |
|---|---|---|
| Turn-on overlap | ½·V·I·t_on | 16.1 µJ |
| Turn-off overlap | ½·V·I·t_off | 30.2 µJ |
| Reverse recovery (LS body diode → HS) | Q_rr·V | 1.5 µJ |
| C_oss (both devices) | ≈ C_oss·V² |
