## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, 12N14P (pole pairs p = 7) |
| Winding parameters | R_s ≈ 5–15 Ω, L_s ≈ 1–3 mH, high K_t (low-current, high-torque) |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz, ADC-synchronous | ω_c ≈ 2π·1500 rad/s |
| IMU sample (ODR) | 8 kHz | n/a |
| Velocity | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Angle (attitude) | 1 kHz | ω_p ≈ 2π·25 rad/s |
| Cogging LMS adaptation | 4 kHz (gated) | slow, μ-limited |

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than its inner loop:

ω_c / ω_v ≥ 5, ω_v / ω_p ≥ 4

## 1. Field-Oriented Current Loop

### 1.1 Plant model (surface PMSM, L_d ≈ L_q = L)

v_d = R·i_d + L·di_d/dt − ω_e·L·i_q

v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + λ_m)

τ_e = (3/2)·p·λ_m·i_q = K_t·i_q

The electrical angle is θ_e = p·(θ_m − θ_offset), where θ_offset is found by an alignment routine.

### 1.2 Transforms

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

i_α = i_a

i_β = (i_a + 2·i_b) / √3

**Park transform:**

i_d = i_α·cos θ_e + i_β·sin θ_e

i_q = −i_α·sin θ_e + i_β·cos θ_e
