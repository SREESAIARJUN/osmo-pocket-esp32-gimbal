## 0. Architecture Clarification and Assumptions

### 0.1 Partitioning

The STM32H743 does **not** commutate the motors directly. ArduPilot does not run a six-step or FOC ESC firmware, and a single MCU closing four commutation loops alongside the flight stack is not a viable design. The architecture is therefore:

```
STM32H743 (ArduPilot) ──4× bidir DShot600──► 4× ESC MCU (AT32F421 / AM32)
                                                │
                                         3-phase gate driver
                                                │
                                       6× N-MOSFET half-bridges ──► Motor
```

All loss figures below are **per ESC channel** and then aggregated across four channels.
