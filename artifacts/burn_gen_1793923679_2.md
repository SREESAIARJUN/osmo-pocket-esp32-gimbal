# STM32H743 AIO 4-in-1 ESC Nano FC: Power-Stage, Thermal, and Bidirectional DShot Design Model (Job #44)

## 0. Assumptions and Corrections

I don't have the Job #44 requirements, so every parameter below is a stated assumption. Swap in your BOM values and the equations still hold.

**Architecture.** The STM32H743 should not run the motors directly. If it commutated the bridges itself, DShot would be pointless. The standard AIO architecture, and the only one where "bi-directional DShot600" makes sense, is:

```
STM32H743 (ArduPilot) --4x BDShot600--> 4x AT32F421 (AM32) --> 4x 3-phase gate drivers --> 24 MOSFETs
```

The 48 kHz PWM is therefore generated by the AM32 MCUs. The H743 only handles DShot and telemetry.

**"80 A burst" on a nano (20×20 mm) board.** This is physically a sub-2-second rating at best. The model in Section 3 quantifies this. Treat any continuous rating above roughly 20–25 A per channel on this form factor as suspect.

**Baseline parameters:**

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V (6S full) | Worst case for switching loss |

## 1. Conduction Losses at 80 A Burst

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,(1+\alpha)^{(T_j-25)}$$

At T_j = 100 °C: R_ds ≈ 1.0 × 1.0055^75 ≈ **1.51 mΩ**.

This creates positive feedback, since higher loss raises T_j, which raises R_ds. Iterate the thermal model (Section 3) until it converges. For a burst it usually converges. For continuous 80 A it diverges toward thermal runaway of the stage.

### 1.2 Current path under 6-step complementary PWM

In any 60° commutation sector, phase A is PWM'd and phase B is held low:

- **On-time (D):** HS_A → motor → LS_B
- **Off-time (1−D):** LS_A (synchronous rectification) → motor → LS_B

The current always sees two R_ds in series, independent of D:

$$P_{cond,ch} = I_{rms}^2 \cdot 2R_{ds}(T_j), \qquad I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}$$

### 1.3 Ripple term

$$\Delta I = \frac{V_{bus}D(1-D)}{L_{ph-ph}\,f_{sw}}$$

With L = 10 µH (typical 2207 motor, phase-to-phase) and the worst case D = 0.5:

ΔI = 25.2 × 0.25 / (10 µH × 48 kHz) ≈ 13.1 A, so ΔI²/12 ≈ 14.3 A². This is negligible against 6400 A².

### 1.4 Result

$$P_{cond,ch} = 6414 \times 2 \times 1.51\text{ m}\Omega \approx \mathbf{19.4\ W\ per\ channel}$$

For four channels at simultaneous burst this is **≈ 77.5 W**.

**Per-FET distribution.** Each switch carries current for 120° of 360° electrical:

- Averaged over the cycle: ≈ 19.4 / 6 ≈ **3.2 W per FET**.
- Instantaneous while conducting: 80² × 1.51 mΩ
