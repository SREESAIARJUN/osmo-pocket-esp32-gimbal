# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the "Job #22" specification, so I assumed a typical brushless gimbal configuration. Every assumption is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (e.g., GBM2804), 12N14P, so **p = 7 pole pairs** |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each joint |
| MCU | STM32G4/H7-class device with FPU, center-aligned PWM, synchronous ADC sampling |
| Loop rates | Current loop **20 kHz**, velocity loop **4 kHz**, angle loop **1 kHz** |
| IMUs | 2 × ICM-42688-P: **IMU-A on the camera plate** and **IMU-B on the same plate, rotated 180° about z** (orientation diversity), both at ODR 8 kHz |
| Topology | Yaw (outer) → Roll → Pitch (inner) |

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle, the pole-pair count, and the encoder-to-rotor offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

The Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$) is:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform rotates into the rotor frame:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model and Decoupled PI Control

For a surface-mount PMSM, $L_d=L_q=L$. The dq voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The controller is a PI per axis plus feedforward decoupling and back-EMF compensation:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gains by pole-zero cancellation.** With a target current bandwidth $\omega_c$:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Placing the zero at $R/L$ makes the closed loop first-order with bandwidth $\omega_c$. Choose $\omega_c \le 2\pi f_{pwm}/20$; at 20 kHz this gives about 2π·1 kHz.

**Torque.** Electromagnetic torque and the torque constant are:

$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q,\qquad K_t=\tfrac32 p \lambda_m$$
