### Architectural correction

The STM32H743 belongs on the **flight controller**, not the ESC. A production 4-in-1 ESC uses **four small ESC MCUs**, one per motor, running AM32 or BLHeli_32. Typical parts are the AT32F421 or STM32G071.

Running 4× six-step commutation, BEMF zero-cross detection and bidirectional DShot decoding on one H743 is possible in principle. It is not supported by ArduPilot or AM32, and it creates a single point of failure. This package therefore uses the following split:

```
[6S LiPo] ── XT60 ── 4-in-1 ESC (30.5×30.5) ──8-pin JST-SH── H743 FC (20×20 or 30.5)
                     4× AT32F421 + 4× FD6288Q + 24× N-FET
```

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses six-step (120°) trapezoidal commutation with synchronous rectification. In each 60° sector:

- **Phase A** is PWM'd: the high-side (HS) is on for D·T_sw, and the low-side (LS) is on for (1−D)·T_sw.
- **Phase B** LS is held on and acts as the return path.
- **Phase C** floats and is used for BEMF sensing.

Current therefore always flows through exactly **two FET channels in series**.

### 1.2 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R = 0.9 × 1.45 = **1.305 mΩ**.
