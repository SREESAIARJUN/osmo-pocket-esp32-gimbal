## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·θₘ − θ_offset (wrapped to [0, 2π)).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model (surface PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque is τ = (3/2)·p·λ_m·i_q = K_t·i_q.

### 1.3 Current PI (pole-zero cancellation)

The PI controller is C(s) = K_p + K_i/s. Choosing

$$K_{p,i} = L\,\omega_{c},\qquad K_{i,i} = R\,\omega_{c}$$

reduces the closed loop to ω_c/(s + ω_c). Choose ω_c ≤ 2π·f_s/20 (≈ 2π·1 kHz at 20 kHz).

Decoupling and back-EMF feedforward are added to the PI outputs:

$$v_d^* = \text{PI}_d - \omega_e L i_q,\qquad v_q^* = \text{PI}_q + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage saturation.** The usable voltage vector is limited to a circle:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max}\approx0.96$$

Priority goes to v_d. The remaining headroom is given to v_q.

**Voltage-mode fallback (no shunts):**

$$v_q^* = R\,i_q^* + \omega_e\lambda_m,\qquad v_d^* = -\omega_e L\, i_q^*$$

### 1.4 SVPWM (min-max zero-sequence injection)

This method is equivalent to sector-based SVPWM:

1. Compute v_a = v_α, v_b = −½v_α + (√3/2)v_β, v_c = −½v_α − (√3/2)v_β.
2. Compute v_0 = −½(max + min).
3. Compute the duty for each phase: d_x = ½ + (v_x + v_0)/V_bus.
