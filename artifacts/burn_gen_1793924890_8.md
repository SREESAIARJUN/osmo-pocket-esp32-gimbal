# STM32H743 FC + 4-in-1 ESC (Job #58): Design Model

## 0. Architecture Corrections and Assumptions

Several points in the brief need correcting before the math is meaningful.

1. **The H743 does not commutate the motors.** In any 4-in-1 design, each ESC channel or pair has its own MCU (e.g., AT32F421 or STM32G071 running AM32, or EFM8/BLHeli_S). The 48 kHz PWM is set in the ESC firmware. The H743 runs ArduPilot and only generates bidirectional DShot600 and decodes eRPM telemetry.
2. **"80 A burst" must be defined.** Four motors at 80 A each is 320 A, or about 8 kW at 6S. No XT60/XT90 lead, nano-size shunt, or 30×30 mm board copper survives that. I treat 80 A as a **per-channel, non-simultaneous, ≤5 s burst rating**. Section 3 shows what the board can actually sustain.
3. **All component parameters are assumed and must be replaced with datasheet values.** The model is parameterised so you only need to swap numbers.

| Parameter | Symbol | Option A (DFN5x6, low-Rds) | Option B (DFN3.3x3.3) |
|---|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V | 25.2 V |
| R_DS(on) @25 °C | R₂₅ | 0.70 mΩ | 1.20 mΩ |

## 1. Conduction Loss Model

Assume six-step (trapezoidal) commutation with synchronous rectification and complementary PWM on the high side. At any instant, one HS/LS pair is switching at duty D and the opposite-phase low-side is fully on.

**Per-channel conduction loss** (phase current I, ripple neglected; ripple adds a factor of 1 + (ΔI²/12I²)):

$$P_{cond} = I^2 R_{hot}\,[D + (1-D)] + I^2 R_{hot} = 2\,I^2 R_{hot}$$

This is independent of D under sync rectification. The worst case is the full-throttle burst.

**Copper/trace term:** add R_cu ≈ 0.3 mΩ per conduction path for a nano 2 oz multi-layer board. This is often 20–30 % of the total.

| | Option A | Option B |
|---|---|---|
| 2·I²·R_hot @80 A | 2·6400·1.12 m = **14.3 W** | 2·6400·1.92 m = **24.6 W** |
| I²·R_cu (0.3 mΩ) | 1.9 W | 1.9 W |
| P_cond total | **16.2 W** | **26.5 W** |

## 2. Switching Losses at 48 kHz

Only the PWM'd high-side hard-switches.

**(a) V–I overlap:**

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw}$$

- Option A: 0.5·25.2·80·40 ns·48 k = **1.94 W**
- Option B: **1.45 W**

**(b) Reverse recovery** (LS body diode, conducting during dead time):

$$P_{rr} = V_{bus} Q_{rr} f_{sw}$$

- Option A: 25.2·50 n·48 k = **0.060 W**
- Option B: **0.036 W**

**(c) Output capacitance:**

$$P_{oss} \approx \tfrac12 V_{bus} Q_{oss} f_{sw}$$

- Option A: **0.036 W**
- Option B: **0.021 W**

**(d) Dead-time diode conduction** (two dead-time intervals per period):

$$P_{dt} = V_f I \cdot 2t_d f_{sw}$$

- Option A: 0.8·80·200 n·48 k = **0.61 W**
- Option B: **0.65 W**

**(e) Gate drive** (dissipated in the driver and gate resistors, not the FET):

$$P_g = Q_g V_{GS} f_{sw} \times 2 \text{ (HS + LS)}$$

- Option A: **0.058 W**
- Option B: **0.029 W**

### Per-channel totals at 80 A

| | Option A | Option B |
|---|---|---|
| Conduction (incl. Cu) | 16.2 W | 26.5 W |
| Switching (a–d) | 2.65 W | 2.16 W |
| **Per channel** | **≈18.8 W** | **≈28.7 W** |
| **4 channels simultaneous** | **≈75 W** | **≈115 W** |

**General form for derating curves:**

$$P_{ch}(I) = 2R_{hot}I^2 + R_{cu}I^2 + \left[\tfrac12 V(t_r+t_f) + 2V_f t_d\right] f_{sw}\, I + V(Q_{rr}+\tfrac12 Q_{oss})f_{sw}$$

For Option A this evaluates to:

$$P_{ch}(I) = 2.54\times10^{-3}\,I^2 + 0.0319\,I + 0.096 \;\text{[W]}$$

Reducing f_sw to 24 kHz saves only about 1.3 W per channel at 80 A. **Conduction dominates; 48 kHz is not the problem.**

## 3. Thermal Model

### 3.1 Junction rise (fast, ms scale)

The hottest device is the HS FET: half the conduction loss, plus all switching loss.

- Option A: 7.2 + 0.95 (Cu share) + 2.65 ≈ **10.8 W**
- Assume R_th(j–PCB) ≈ 2.5 K/W for an exposed pad with a via array (8–12 vias, 0.3 mm, filled).
- ΔT_j–pcb ≈ **27 K**. For Option B (≈16 W, ~3.5 K/W): **≈56 K**.
