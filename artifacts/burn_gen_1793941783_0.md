# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have access to the Job #45 specification, so this design states its assumptions explicitly (§0). Replace the bracketed parameters with your measured motor and IMU values. Every gain formula is given symbolically so you can re-derive the gains when the hardware changes.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, e.g. 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor angle sensor | 14-bit absolute magnetic encoder (e.g. AS5048/MT6701), sampled each current loop |
| Driver | 3-phase, center-aligned PWM, 2 or 3 low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro/accel ODR 8 kHz, ±2000 dps / ±16 g |
| MCU | Cortex-M4F/M7 with single-precision FPU |

The controller is a cascade of four nested loops. Each loop is roughly 4–10× slower in bandwidth than the one inside it.

| Loop | Rate | Closed-loop bandwidth | Feedback |
|---|---|---|---|
| Current loop (FOC, id/iq PI) | 20 kHz | ~1.5–2 kHz | Shunts + encoder angle |
| Rate loop (PI + feedforward) | 4 kHz | ~150–250 Hz | Fused gyro rate projected on the joint axis |
| Attitude loop (P + rate feedforward) | 1 kHz | ~30–50 Hz | Fused attitude (Mahony filter) |
| Attitude estimator | 1 kHz | — | Dual IMU → notch filters → LPF → Mahony |

Two design notes on this structure:

- **Inertial stabilization.** The rate loop closes on the *gyro*, not the encoder. Base disturbances therefore appear as rate error immediately, which is what makes the gimbal stabilize the camera in inertial space.
- **Role of the encoder.** It is used only for commutation (θ_e), for cogging compensation (θ_m), and for joint-limit and kinematic projection.

## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle is derived from the mechanical (encoder) angle, with θ_off the calibrated electrical zero:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Delay compensation.** PWM and sampling add about 1.5 sample periods of delay. Advance the angle used for the inverse Park transform accordingly:

$$\hat\theta_e = \theta_e + 1.5\,\omega_e T_c$$

### 1.2 Plant and current PI design

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

**Decoupling feedforward.** Adding these terms cancels the cross-coupling and back-EMF:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis reduces to G(s) = 1/(Ls + R).

**PI gains by pole–zero cancellation.** Choose the PI zero to cancel the plant pole, giving a first-order closed loop with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$
