# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power, Thermal, and DShot Timing Model

## 0. Scope and Assumptions

I have no prior project file for "Job #28", so every parameter below is a **stated assumption**. Each one sits in a table so you can substitute your real BOM values and re-run the math. Treat this as the engineering framework and first-pass numbers. It is not a signed-off design.

**Architecture clarification.** The STM32H743 does **not** generate the 48 kHz motor PWM. In every production ArduPilot AIO:

- **H743 (flight controller):** runs ArduPilot. It generates 4× bidirectional DShot600 and captures eRPM telemetry.
- **4× ESC MCUs** (assumed AT32F421 running AM32): run 6-step commutation with 48 kHz synchronous PWM.

The loss model (§1–§3) applies to the ESC power stage. The DMA and timer model (§4) applies to the H743.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous PWM

During any 60° commutation sector, phase A is PWM'd and phase B is held low.

| PWM state | Conducting devices |
|---|---|
| ON (duty D) | HS_A + LS_B |
| OFF (1 − D), synchronous freewheel | LS_A + LS_B |
