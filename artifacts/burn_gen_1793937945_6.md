## 0. Architecture Clarifications and Scope Corrections

These points change the math, so they come first.

1. **The H743 does not commutate the motors.** In any ArduPilot-compatible 4-in-1 design, each motor channel has its own ESC MCU running AM32 or BLHeli_32-class firmware. Typical parts are the AT32F421 or STM32G071. That MCU generates the 48 kHz complementary PWM. The H743 generates only the DShot600 command stream and decodes the bi-directional eRPM reply. The loss model (§1–3) belongs to the ESC side. The DMA model (§4) belongs to the FC side.

2. **"Nano" vs. 80 A.** A 20×20 mm board cannot sink the burst dissipation computed below for any useful duration. This package therefore assumes:
   - a **30.5×30.5 mm, 8-layer, 2 oz** power stack, or
   - a split FC/ESC stack.

   If the 20×20 form factor is a hard requirement, the burst rating must drop to roughly 35–45 A (see §3.5).

3. **"80 A burst" is defined here as 80 A phase current per channel, all four channels simultaneously, for ≤ 5 s,** at 6S (25.2 V max). Single-channel bursts are easier and fall out of the same model.

4. **Component values are placeholder parameters**, typical of 40 V shielded-gate MOSFETs in a 3.3×3.3 DFN. Substitute datasheet values for the selected part. Every equation is kept symbolic so this is a direct swap.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (worst case) | 6S fully charged |
| I_ph | 80 A | Burst phase current per channel |
| f_sw | 48 kHz | ESC PWM frequency |
| D | 0–1 | PWM duty |
| R_ds,25 | 1.0 mΩ | R_ds(on) at 25 °C, V_gs = 10 V |
| α | 0.0045 /K | R_ds(on) tempco |
| t_r, t_f | 20 ns, 20 ns | Effective V-I overlap times at the driver's gate current |
| Q_oss | 30 nC | Output charge |
| Q_rr | 40 nC | Body-diode reverse recovery charge |
| Q_g | 50 nC | Total gate charge |
| V_gs | 10 V | Gate drive voltage |
| V_f | 0.8 V | Body-diode forward voltage at 80 A |
| t_dt | 100 ns | Dead time per edge |
| L_ph | 20 µH | Motor line-to-line inductance (typical 2207–2810 class) |
| R_θjc | 1.5 K/W | Junction-to-case, per FET |

**Commutation model.** AM32 drives the motor with 6-step trapezoidal commutation and synchronous rectification (complementary PWM).
- At any instant, exactly one high-side and one low-side path conduct the phase current.
- Each of the 6 FETs per channel carries current for 1/3 of the electrical period, split between its active and freewheel roles according to D.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C:

$$R_{ds} = 1.0 \times (1 + 0.0045 \times 100) = 1.45\ \text{mΩ}$$

### 2.2 RMS current including PWM ripple

The peak-to-peak ripple is worst at D = 0.5:

$$\Delta I = \frac{V_{bus}\,D(1-D)}{f_{sw}\,L_{ph}} = \frac{25.2 \times 0.25}{48\,000 \times 20\times10^{-6}} = 6.56\ \text{A}_{pp}$$

The RMS current over the conducting interval is:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12} = 6400 + 3.59 = 6403.6\ \text{A}^2$
