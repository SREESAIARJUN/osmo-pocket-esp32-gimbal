## 0. Scope, Architecture and Stated Assumptions

**The STM32H743 does not commutate the motors.** In every production FC/4-in-1 stack, including the one modelled here, the system splits into two tiers:

| Tier | Device | Function |
|---|---|---|
| Flight controller | STM32H743 (480 MHz, LQFP100), ArduPilot | Attitude control, sends 4× bidirectional DShot600, receives eRPM telemetry |
| ESC (×4 channels) | 4× ESC MCU (e.g., AT32F421 / STM32G071, AM32 or BLHeli_32-class firmware) | 6-step commutation, 48 kHz PWM, current sensing, DShot decode and telemetry encode |

### Physical-feasibility flag

A true "nano" board (20×20 mm) cannot carry 4×80 A, even as a burst; the copper and FET area are insufficient. This model assumes a **30.5×30.5 mm 4-in-1** with 8-layer 2 oz copper. Section 3 shows that even this board is thermally limited to seconds-scale bursts.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path in 6-step synchronous commutation

At any instant, two phases conduct.

- **Leg A** (PWM leg): the HS FET conducts for duty D. The LS FET conducts for (1−D) in synchronous rectification.
- **Leg B** (return leg): the LS FET conducts continuously for the 60° sector.

Each leg therefore always has exactly one FET in the current path, so the instantaneous path resistance is:

$$R_{path} = 2\,R_{ds(on)}(T_j) + R_{Cu} + R_{shunt}$$

### 1.2 Hot R_ds(on)

The model is self-consistent: loss raises T_j, which raises R, which raises loss. Evaluating at a design-limit T_j = 110 °C:

$$R_{ds(on)}(110°C) = 1.0\,\text{m}\Omega \times [1 + 0.0045(85)] = 1.38\,\text{m}\Omega$$

### 1.3 Conduction loss per channel

$$P_{cond,FET} = I^2 \cdot 2R_{ds(on),hot} = 80^2 \times 2.76\,\text{m}\Omega = \mathbf{17.7\ W}$$

Each FET conducts 1/3 of the electrical period, so the average per FET is:

$$\bar{P}_{FET} = \frac{17.7}{6} = 2.95\ \text{W}$$
