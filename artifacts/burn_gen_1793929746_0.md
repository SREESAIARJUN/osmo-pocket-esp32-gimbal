# Job #15: 3-Axis Gimbal FOC Control and Dual-IMU Fusion

This document covers current-loop FOC, the cascaded angle/velocity controller, adaptive anti-cogging feedforward, and dual ICM-42688-P vibration rejection, followed by a complete C++ implementation.

---

## 0. Design Assumptions

The job brief did not specify hardware, so the design assumes the following. All parameters are centralized in `GimbalConfig` so they can be changed in one place.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM2804-class), 7 pole pairs (14P), 12 slots, R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic encoder (AS5048A / MT6701), read every PWM cycle |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz, low-side or inline shunts |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, 8 kHz ODR, mounted symmetrically about the camera rotation center |
| Supply | 12–16 V |

### Loop Rates and Bandwidth Separation

Each loop is placed at least 5–10× below the loop inside it.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz | ~1.5 kHz |
| IMU sampling + filtering + fusion | 8 kHz | n/a |
| Velocity PI (gyro feedback) | 4 kHz | ~150–250 Hz |
| Angle P/PI (attitude feedback) | 1 kHz | ~20–40 Hz |
| Attitude estimator (Mahony) | 1 kHz (gyro pre-averaged) | n/a |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

- $p$ is the number of pole pairs.
- $\theta_{\text{off}}$ is found at calibration by applying $v_d>0,\ v_q=0$ and reading the encoder once the rotor locks.

### 1.2 Clarke Transform (Amplitude-Invariant, Using $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant Model (Surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac{3}{2} p \lambda_m i_q = K_t i_q$$

### 1.5 Current PI with Decoupling and Back-EMF Feedforward

The PI gains place the zero on the electrical pole $R/L$, which yields a first-order closed loop at bandwidth $\omega_c$:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad(\text{continuous}),\qquad G_{cl}(s)=\frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c = 2\pi\cdot1500$ rad/s. This must satisfy $\omega_c \le \omega_{\text{pwm}}/10$ to stay robust against the 1.5-sample computation and PWM delay.

The control law per axis $x \in \{d, q\}$ is:

$$v_x^* = K_p e_x + \underbrace{K_i T_s\sum e_x}_{I_x} + v_x^{ff}$$
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Anti-windup (back-calculation).** Let $\mathrm{sat}(\cdot)$ be the voltage-circle limit $|v_{dq}|\le V_{dc}/\sqrt3$. Then:

$$I_x[k+1] = I_x[k] + T_s\big(K_i e_x + K_{aw}(\mathrm{sat}(v_x^*) - v_x^*)\big),\qquad K_{aw} \approx 1/T_s \cdot 0.5$$

**Circular voltage limit.** The $d$-axis has priority:

$$v_d = \mathrm{clamp}(v_d^*, \pm V_{max}),\qquad v_q = \mathrm{clamp}\left(v_q^*, \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

> **Voltage-mode fallback (no shunts).** Many gimbal motors have $R \approx 10\,\Omega$, so they are resistance-dominated. In that case you can use $v_q = R\,i_q^* + \omega_e\lambda_m$ and $v_d = -\omega_e L i_q^*$ directly. The code supports this via `useCurrentSensing = false`.
