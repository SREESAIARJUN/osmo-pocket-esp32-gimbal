## 0. Assumptions and System Architecture

| Item | Assumed value | Notes |

| Phase R / L | $R = 5.6\,\Omega$, $L_d \approx L_q = 2.4\,\text{mH}$ | Measure yours |

| Bus | $V_{dc} = 12\text{–}16.8\,\text{V}$ (4S) | Measured every PWM cycle |
| Rotor encoder | 14-bit absolute (AS5048A / MT6701), SPI | Gives electrical angle |
| IMU A (camera plate) | ICM-42688-P, 8 kHz ODR, ±500 dps / ±4 g | Primary attitude sensor |
| IMU B (base / handle) | ICM-42688-P, 8 kHz ODR | Vibration reference |
| Topology | Yaw (outer) → Roll → Pitch (inner) | Camera on pitch link |

### Loop timing (cascade separation ≥ 4–5×)

```
 PWM / current loop (FOC)  : 20 kHz  (Ts_i = 50 µs)   – ISR synced to PWM center
 IMU sampling + filtering  :  8 kHz  (Ts_g = 125 µs)  – DRDY/FIFO ISR
 Velocity loop             :  4 kHz  (Ts_v = 250 µs)
 Angle / attitude loop     :  1 kHz  (Ts_a = 1 ms)
 Cogging adaptation, notch frequency tracking : background (≤1 kHz)
```

### Signal flow per axis

```
θ_ref ─►(Σ)─► Angle P(+I) ─►(Σ)─► Velocity PI(D) ─►(Σ)─► i_q* ─► FOC PI ─► SVPWM ─► motor
        ▲                   ▲ ω_ff               ▲       ▲ i_cog,ff   ▲
        │                   │                    │       │            │ θ_e (encoder)
   attitude error    filtered camera gyro (IMU A, cleaned using IMU B)
```
