## 0. Baseline Assumptions and a Feasibility Flag

| Parameter | Value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal | Drives switching loss and FET voltage rating |
| FET rating | 40 V, R_DS(on),25 = 1.0 mΩ typ / 1.3 mΩ max @ V_GS = 10 V, PDFN 5×6 | e.g. a TOLL/PDFN-class trench FET |
| Topology | 3 half-bridges per channel, 1 FET per switch position, 24 FETs total | |
| Commutation | 6-step trapezoidal, complementary PWM (synchronous rectification) | AM32 / BLHeli_32 style |
| f_sw | 48 kHz | |
| Dead time | t_dt = 200 ns per transition | |
| "80 A burst" | **Phase current per channel**, not battery current | |
| ESC MCU | Separate per-channel MCU (AT32F421 / STM32G071 class) running AM32 | The H743 does **not** drive gates |
| Gate drive | FD6288Q-class 3-phase driver, V_DRV ≈ 10 V | |

**Feasibility flag.** A true 20×20 mm "nano" board **cannot** carry 80 A burst per channel. It has neither room for 24 PDFN 5×6 FETs nor enough copper cross-section. The model below assumes a **30.5×30.5 mm, 8-layer, 2 oz board**. On 20×20 mm with 3.3×3.3 mm FETs, a realistic rating is roughly 35–45 A burst. §2 shows why.

## 1. Loss Model (Per ESC Channel)

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,[1+\alpha\,(T_j-25)],\qquad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 105 °C: R = 1.0 × 1.40 = **1.40 mΩ** (typical).
