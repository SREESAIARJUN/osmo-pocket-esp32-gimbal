# Job #45: STM32H743 Nano FC + 80 A 4-in-1 ESC Reference Design Package

**Scope:** Mathematical models for conduction loss, 48 kHz switching loss, burst thermal behaviour, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

> **Architecture note:** The STM32H743 is the flight controller MCU. It does not commutate motors. Each motor channel on the 4-in-1 ESC has its own MCU running AM32 or BLHeli_32-class firmware. This design assumes an AT32F421 for that role. AM32 supports 48 kHz PWM and bidirectional DShot (EDT). The H743 generates DShot600 and decodes eRPM telemetry.

## 2. Conduction Loss Model

### 2.1 Current path (six-step trapezoidal, complementary PWM)

At any commutation step, two legs are active:
- one leg is PWM-modulated: its HS switch is ON for duty *D*, and its LS switch is ON for (1−D) as a synchronous rectifier;
- the return leg's LS switch is held ON.

So the phase current always flows through exactly two channels in series, regardless of duty:

$$P_{cond,motor} = I^2 \cdot 2R_{DS(on)}(T_j)$$

### 2.2 Temperature-dependent R_DS(on)

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C: R = 1.0 mΩ × 1.45 ≈ **1.45 mΩ** (use 1.5 mΩ for margin).

### 2.3 Burst numbers

$$P_{cond,motor} = 80^2 \times 2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

Each FET conducts for roughly 1/3 of the electrical cycle, and the loss is shared across 6 FETs. Average per FET:

$$P_{cond,FET} \approx 19.2 / 6 = 3.2\ \text{W}$$

The instantaneous peak on a conducting FET is I²R = **9.6 W** during its conduction interval. This matters for junction ripple at low eRPM, where the commutation period becomes comparable to the die thermal time constant (~1–5 ms).

### 2.4 Parasitic conduction terms

| Element | R | Loss @ 80 A |
|---|---|---|
| Phase copper (pad→FET, 2 oz, ~6 mm, 4 layers parallel) | ~0.25 mΩ | 1.6 W |
| Current shunt (shared bus, 4×80 A = 320 A) | 0.1 mΩ | 10.2 W (burst) |

**Recommendation:** Do not use a single shared 0.1 mΩ shunt at 320 A. Either:
- use per-channel 0.25 mΩ shunts (1.6 W each), or
- use a Hall-effect sensor (e.g., TMCS1100-class is too small; use an ACS772 or estimate current from ESC telemetry).

The thermal model below assumes **per-channel sensing via ESC telemetry**, with no bulk shunt.

**Total conduction per motor at burst: ≈ 20.8 W**

## 3. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The HS switch sees hard turn-on and turn-off, and the LS switch commutates via its body diode during dead time.

### 3.1 Gate-drive transition times

The Miller plateau is V_pl ≈ 4.5 V. Total gate resistance is R_g = 2.2 Ω external + 1.0 Ω internal.

$$I_{g,on} = \frac{V_{DRV} - V_{pl}}{R_{g}} = \frac{10-4.5}{3.2} \approx 1.7\ \text{A} \;\rightarrow\; \text{clamped by driver to } 1.5\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{R_g} = \frac{4.5}{3.2} \approx 1.4\ \text{A}$$

The switching interval is Q_sw = Q_gs2 + Q_gd = 13 nC.

$$t_{on} = 13\,\text{nC}/1.5\,\text{A} \approx 8.7\ \text{ns}, \qquad t_{off} = 13/1.4 \approx 9.3\ \text{ns}$$

Add layout-inductance slowing (L_loop ≈ 1.5 nH) and use **t_r ≈ t_f ≈ 15 ns** for design.

### 3.2 Loss components (per motor, 80 A, 25.2 V)

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·30n·48k | **1.45 W** |
| Dead-time body diode | V_SD·I·2t_dt·f_sw = 0.8·80·200n·48k | **0.61 W** |
| Reverse recovery | V·Q_rr·f_sw = 25.2·40n·48k | 0.05 W |
| Output capacitance | V·Q_oss·f_sw = 25.2·35n·48k | 0.04 W |
| Gate drive (2 FETs switching) | 2·Q_g·V_DRV·f_sw = 2·45n·10·48k | 0.04 W (dissipated in driver/R_g) |
| **Total switching** | | **≈ 2.2 W** |

### 3.3 Sensitivity to f_sw

$$P_{sw} \propto f_{sw}: \quad 24\,\text{kHz} \rightarrow 1.1\,\text{W}, \quad 96\,\text{kHz} \rightarrow 4.4\,\text{W}$$

At 80 A, conduction dominates (~90%), so 48 kHz is a reasonable trade for current ripple and acoustic noise on low-inductance motors.

### 3.4 Voltage overshoot check

$$\Delta V = L_{loop}\frac{di}{dt} = 1.5\,\text{nH} \times \frac{80\,\text{A}}{15\,\text{ns}} = 8.0\ \text{V}$$

Peak V_DS ≈ 25.2 + 8 = 33.2 V against a 40 V rating, which is **83% of rating**. This is acceptable but tight.

- Place a 0402/0603 100 nF + 1 µF X7R decoupling pair at **each** half-bridge, within 2 mm.
- Limit the loop to ≤ 1.5 nH using a vertical loop on L1/L2 with a solid return plane.

## 4. Thermal Model

### 4.1 Total burst dissipation

| | Per motor | ×4 motors |
|---|---|---|
| Conduction (FET + copper) | 20.8 W | 83.2 W |
| Switching | 2.2 W | 8.8 W |
| Drivers, LDOs, ESC MCUs | 0.3 W | 1.2 W |
| **Total** | **23.3 W** | **≈ 93 W** |

Per-FET average: (19.2 + 2.2)/6 ≈ **3.6 W**. The PWM-leg HS switch carries extra switching loss, so the worst-case FET dissipates ~4.3 W.
