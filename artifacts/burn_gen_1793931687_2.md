# STM32H743 AIO Flight Controller + 80A-Burst 4-in-1 ESC: Engineering Design Package (Job #36)

## 0. Architecture Decisions and Assumptions

This section corrects one point in the request and fixes the design inputs.

**The STM32H743 does not run the ESC.** In every production 4-in-1 design, the flight controller MCU sends DShot to dedicated ESC MCUs. Those ESC MCUs generate the 48 kHz complementary PWM, sense BEMF and run commutation. The design therefore splits into two parts:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 480 MHz | ArduPilot (ChibiOS) |
| ESC ×4 | AT32F421K8U7 (QFN32) | AM32, PWM 48 kHz |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap, 6 inputs) | n/a |
| Power stage ×4 | 6× N-MOSFET per motor (24 total) | n/a |

**Design inputs.** All loss numbers below are parametric. Substitute the actual datasheet values of the selected MOSFET.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 16.8 V (4S full) | DC link voltage. A 6S variant requires 60 V FETs. |
| I_pk | 80 A | Per-motor burst phase current |
| I_cont | 45 A | Per-motor continuous design target |
| f_sw | 48 kHz | ESC PWM frequency |
| R_ds(on),25 | 1.2 mΩ (max) | 40 V FET, PDFN 5×6 |
| k_T | 1.6 | R_ds(on) multiplier at T_j = 125 °C |
| t_r, t_f | 10 ns each | Effective V-I overlap times with FD6288 drive |
| Q_g | 50 nC @ 10 V | Total gate charge |
| Q_rr | 40 nC | Body-diode reverse recovery charge |
| C_oss(er) | 1.5 nF | Energy-related output capacitance |
| V_SD | 0.8 V | Body-diode forward drop at 80 A, hot |
| t_dt | 100 ns | Dead time per edge (AM32 configurable) |

| Board | 36×36 mm, 30.5 mm mount, 8-layer, 2 oz all layers | Physical constraint |

**Critical reality check.** "80 A burst" on a nano-class board means 4 × 80 A = 320 A of battery current. That is a short-transient rating only, as Section 3 shows. The derivation below yields the defensible burst duration rather than assuming one.

## 1. Conduction Loss Model

### 1.1 Current path

The ESC uses 6-step (trapezoidal) commutation with synchronous complementary PWM, which is AM32's default.

- During the ON interval, current flows through HS(phase A) → motor → LS(phase B).
- During the OFF interval, LS(A) is driven ON synchronously, so current freewheels through LS(A) → motor → LS(B).

In both intervals, current passes through exactly two channel resistances. Conduction loss is therefore independent of duty cycle D in synchronous mode:

$$
P_{cond} = 2\, I_{ph,rms}^2\, R_{ds(on)}(T_j), \qquad R_{ds(on)}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]
$$

For silicon trench FETs, α ≈ 0.006 /K, which gives k_T ≈ 1.6 at 125 °C.

### 1.2 Ripple correction

The phase-current ripple is set by motor inductance L_ph (assume 15 µH line-to-line):

$$
\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L\, f_{sw}} \;\le\; \frac{V_{bus}}{4 L f_{sw}} = \frac{16.8}{4 \cdot 15\mu \cdot 48k} = 5.8\ \text{A}_{pp}
$$

$$
I_{rms}^2 = I_{dc}^2 + \frac{\Delta I^2}{12} = 6400 + 2.8 \approx 6403\ \text{A}^2 \quad (\text{negligible: } +0.04\,\%)
