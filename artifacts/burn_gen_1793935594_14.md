## 0. Architecture Baseline and Assumptions

The STM32H743 has only two advanced timers with complementary outputs (TIM1, TIM8). That gives at most two 3-phase bridges, so it cannot drive four motors directly. The production-standard partition is therefore used:

| Block | Device | Role |
|---|---|---|
| Flight controller MCU | STM32H743VIH6 (LQFP100/TFBGA100), 480 MHz | ArduPilot, DShot600 master |
| ESC MCUs (×4) | AT32F421K8U7 (or STM32G071) | AM32 firmware, 6-step sensorless, 48 kHz PWM |
| Gate drivers (×4) | FD6288Q (3× half-bridge, 250 V / 1.5 A sink) | Bootstrap high-side drive |
| MOSFETs (×24) | 40 V, PDFN3.3×3.3 class | 6 per motor |
| Supply | 2S–6S (design point: 6S, 25.2 V max) | |

**Design-point MOSFET parameters.** These represent a typical 40 V 3×3 trench FET. Replace them with your selected part's datasheet values.

| Parameter | Symbol | Value |
|---|---|---|

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

### 1.2 Six-step commutation current path

In trapezoidal (120°) commutation with synchronous rectification, the current at every instant flows through exactly two conducting positions:

1. The PWM leg: the high-side FET for duty D, or its complementary low-side FET for (1−D).
2. The static low-side FET of the sinking phase.

The duty cycle therefore cancels out of the total, giving:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

Per-FET RMS current (each phase conducts 240° of 360°, split between HS and LS):

$$I_{FET,rms} \approx I_{ph}\sqrt{\tfrac{1}{3}} = 46.2\ \text{A}$$

### 1.3 Numerical evaluation at 80 A

Assume the converged T_j ≈ 115 °C (verified in §3):

$$R_{ds}(115) = 1.0(1+0.005\cdot 90) = 1.45\ \text{m}\Omega$$

$$P_{cond,motor} = 2\cdot 80^2\cdot 1.45\times10^{-3} = \mathbf{18.6\ W}$$

**Design option: paralleled FETs (2 per position, 48 FETs total).** Effective R halves, so P_cond = 9.3 W per motor. On a 20×20 board this is usually layout-impossible. It becomes viable at 30.5×30.5.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The static low-side FET commutates only six times per electrical revolution, which is negligible.

### 2.1 Gate-drive currents (FD6288Q, R_g,ext = 3.3 Ω, V_drv = 10 V, V_plateau ≈ 4.5 V)

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,ext}+R_{g,int}+R_{drv,src}} = \frac{5.5}{3.3+1.0+3.5} \approx 0.70\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{3.3+1.0+1.5} \approx 0.78\ \text{A}$$

### 2.2 Transition times

$$t_r = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{12\text{ nC}}{0.70} = 17.1\ \text{ns}, \qquad t_f = \frac{12\text{ nC}}{0.78} = 15.4\ \text{ns}$$

### 2.3 Loss components (per motor)

| Mechanism | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·32.5n·48k | **1.57 W** |
| Coss discharge | ½·Q_oss·V·f_sw = ½·40n·25.2·48k | 0.024 W |
| Reverse recovery | Q_rr·V·f_sw = 50n·25.2·48k | 0.060 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200n·48k | **0.614 W** |
