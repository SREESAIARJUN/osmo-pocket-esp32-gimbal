# STM32H743 Nano FC + 4-in-1 ESC: Architecture & Mathematical Model

This model rests on several assumptions that need to be verified against your actual BOM:

1. **The 48 kHz PWM is generated by the ESC MCU, not the H743.** A 4-in-1 ESC runs its own firmware (AM32/BLHeli_32/Bluejay) on a dedicated MCU, assumed here to be an AT32F421 or STM32G071. The H743 only produces bidirectional DShot600 and consumes eRPM telemetry.
2. **"80A burst" is per motor, i.e. 320A aggregate.** On a nano (20×20 or 25.5×25.5 mm) board this is thermally a *seconds-scale* rating, not a continuous one. The math below quantifies this.
3. **MOSFET parameters are representative placeholders** for a 40V, 3.3×3.3 mm DFN part. Replace them with datasheet values before sign-off.

## 3. Conduction Loss Model

### 3.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j - 25)]$$

At T_j = 125 °C:

$$R_{ds} = 1.0\,\text{m}\Omega \times 1.5 = 1.5\,\text{m}\Omega$$

### 3.2 Six-step commutation with synchronous rectification

In six-step commutation, current at any instant flows through one high-side path and one low-side path. With complementary PWM, the switching leg alternates between its high-side FET (duty D) and low-side FET (duty 1−D). Either way, exactly two channel resistances carry I_ph at all times.

The conduction loss per ESC channel is independent of duty to first order:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j) = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W}$$

Each FET conducts for 120° of the electrical cycle, so the average loss per FET is:

$$P_{cond,FET} \approx \frac{19.2}{6} = 3.2\ \text{W}$$

### 3.3 Electro-thermal feedback (runaway check)

Combine the junction temperature equation with the temperature-dependent resistance:

$$T_j = T_a + R_{\theta}\,P(T_j), \qquad P(T_j) = P_0[1+\alpha(T_j-25)]$$

Solving for the closed-loop junction temperature:

$$T_j = \frac{T_a + R_\theta P_0(1-25\alpha)}{1-\alpha R_\theta P_0}$$

The system is stable only if:

$$\alpha\,R_\theta\,P_0 < 1$$

Applying this per FET with P₀ = 2.13 W (the loss at 25 °C):

$$R_\theta < \frac{1}{0.005 \times 2.13} \approx 94\ \text{K/W}$$

Steady state is therefore stable. The real limit is absolute temperature, not runaway.

## 4. Switching Loss Model at 48 kHz

Only the PWM-switching leg incurs these losses. There is one per channel at any instant.

| Mechanism | Equation | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r+t_f)·f_sw = ½·25.2·80·40n·48k | **1.94 W** |
| Reverse recovery | Q_rr·V_bus·f_sw = 50n·25.2·48k | 0.06 W |
| Output capacitance | ½·Q_oss·V_bus·f_sw = ½·40n·25.2·48k | 0.02 W |
| Deadtime body diode | V_SD·I·2t_dead·f_sw = 0.8·80·200n·48k | 0.61 W |
| Gate drive (driver IC) | 2·Q_g·V_drv·f_sw = 2·40n·10·48k | 0.04 W |
| **Σ switching** | | **≈ 2.67 W** |

### 4.1 Per-channel and board totals at burst

$$P_{ch} = 19.2 + 2.67 \approx \mathbf{21.9\ W}$$

$$P_{board} = 4 \times 21.9 \approx \mathbf{87.5\ W}$$

The following sources are not included in the 87.5 W total and add roughly 5–15%:
- Copper trace I²R losses.
- Shunt loss.
- Capacitor ESR loss.

### 4.2 PWM frequency sensitivity

$$\frac{\partial P}{\partial f_{sw}} \approx \frac{2.67\ \text{W}}{48\ \text{kHz}} = 55.6\ \text{mW/kHz per channel}$$

- Dropping to 24 kHz saves about 1.3 W per channel.
- Raising to 96 kHz costs about 2.7 W per channel.

At 80 A, conduction loss dominates (88%), so investing in lower R_ds pays off more than tuning f_sw.

## 5. Thermal Model

### 5.1 Lumped transient (board-level thermal mass)

Assume a 25.5×25.5 mm, 6-layer, 2 oz board with 24 FETs, weighing about 6 g. FR4 has c ≈ 0.9 J/(g·K) and copper has c ≈ 0.385 J/(g·K).

$$C_{th} \approx 4\,\text{J/K}$$

The initial heating rate at burst is:

$$\frac{dT}{dt} = \frac{P}{C_{th}} = \frac{87.5}{4} \approx \mathbf{22\ K/s}$$

### 5.2 Convective steady state

Use prop-wash forced convection, h ≈ 80 W/(m²·K), over both board faces:

$$A = 2(0.0255)^2 = 1.3\times10^{-3}\ \text{m}^2, \qquad R_{\theta,sa} = \frac{1}{hA} \approx 9.6\ \text{K/W}$$

The board time constant is:

$$\tau = R_{\theta,sa}\,C_{th} \approx 38\ \text{s}$$
