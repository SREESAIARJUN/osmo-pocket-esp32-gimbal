## 0. Architectural Correction (Read First)

The requested system cannot work as literally stated, so the design assumes a different partition.

| Assumption in request | Reality | Design decision |
|---|---|---|
| H743 commutates the motors | ArduPilot is flight-control firmware. It does not commutate BLDC motors. | The H743 acts as FC only. Each motor gets a dedicated ESC MCU running AM32 or BLHeli_32-class firmware. |
| 48 kHz switching is set by ArduPilot | PWM frequency is an ESC-firmware parameter. | 48 kHz is configured in AM32 (`PWM_FREQ=48`). |
| 80A continuous on a "nano" stack | Losses are about 40 W per motor at 80A, so this is physically impossible continuously on 30×30 copper. | 80A is a **time-limited burst** (seconds). The derivation is in §3. |

**Baseline assumptions.** Replace the starred (\*) values with your selected datasheet values.

- Battery: 6S LiPo, V_bus,max = 25.2 V, V_bus,nom = 22.2 V.
- Form factor: 30.5×30.5 mm stack (nano), 6-layer, 2 oz all layers.
- Power FETs: 24× 60 V, PQFN 3.3×3.3 (one FET per switch position).
  - R_DS(on)@25°C = 2.0 mΩ\*, Q_g = 20 nC\*, Q_gs2 = 3 nC\*, Q_gd = 5 nC\*, Q_oss = 25 nC\*, Q_rr = 30 nC\*, V_plateau = 4.0 V\*, V_SD = 0.8 V\*, R_θJC = 1.5 K/W\*.
- Gate driver: FD6288Q-class 3-phase bootstrap driver, V_drv = 10 V.
- ESC MCU: AT32F421 / STM32G071 (×4), AM32 firmware, 48 kHz, complementary PWM, dead time 100 ns.
- FC: STM32H743VIT6 (LQFP100), 400 MHz, ArduPilot.

## 2. Conduction Loss Model (80A Burst)

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j)=R_{DS,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha\approx0.0055\ \text{K}^{-1}$$

At T_j = 100 °C: R_DS = 2.0 × 1.41 = **2.83 mΩ**.

### 2.2 Current path in 6-step trapezoidal operation with synchronous rectification

At any instant, the motor current flows through exactly **two** FETs: one high-side and one low-side. During PWM-off, current transfers from the HS FET to the complementary LS FET of the same leg, so the conducting count stays at two.

Including the triangular ripple ΔI (peak-to-peak):

$$I_{rms}^2 = I^2\left(1+\frac{r^2}{12}\right),\qquad r=\frac{\Delta I}{I}$$

The ripple derivation, with line-to-line inductance L_LL = 20 µH (typical 2207-class motor), D ≈ 0.5, and f = 48 kHz:

$$\Delta I=\frac{V_{bus}D(1-D)}{L_{LL}f_{sw}}=\frac{25.2\cdot0.25}{20\mu\cdot48k}=6.6\ \text{A}\;\Rightarrow\;r=0.082\;\Rightarrow\;(1+r^2/12)=1.0006$$

Ripple is therefore negligible at 80 A.

### 2.3 Per motor, per FET, and PCB copper

$$P_{cond,motor}=2\,I_{rms}^2\,R_{DS}(T_j)=2\cdot6404\cdot2.83\text{ m}\Omega=\mathbf{36.2\ W}$$

Each FET conducts on average one-third of the time in the path pair:

$$P_{cond,FET}=\frac{P_{cond,motor}}{6}=\mathbf{6.0\ W}$$

PCB copper adds loss. Assume phase plus bus path R_Cu ≈ 0.25 mΩ per motor, with copper α_Cu = 0.0039:

$$P_{Cu}=I^2R_{Cu}(T)=6400\cdot0.25\text{m}\cdot1.29=\mathbf{2.1\ W}$$
