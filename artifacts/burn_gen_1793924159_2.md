## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), where p is the number of pole pairs.

**Clarke transform** (amplitude-invariant, balanced currents i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and current PI design

The dq voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

**Decoupling feedforward.** Adding the cross-coupling and back-EMF terms back in leaves each axis as a pure RL plant, 1/(Ls + R):

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

**PI gains by pole-zero cancellation.** For a target closed-loop bandwidth ω_c, choose:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

The closed loop is then a first-order lag, ω_c/(s + ω_c). Choose ω_c ≤ 2π·f_s/20; at f_s = 20 kHz this gives about 2π·1 kHz.

**Discrete form** (forward Euler with back-calculation anti-windup):

$$u_k = K_p e_k + I_k,\quad u_k^{sat}=\mathrm{sat}(u_k),\quad I_{k+1}=I_k + T_s\big[K_i e_k + K_{aw}(u_k^{sat}-u_k)\big],\quad K_{aw}=K_i/K_p$$

**Voltage limiting.** The (v_d, v_q) vector is limited to the hexagon's inscribed circle, V_max = V_bus/√3. v_d takes priority.

### 1.3 SVPWM (min-max zero-sequence injection)

This is equivalent to sector-based SVPWM:

$$v_{a,b,c}=\text{invClarke}(v_\alpha,v_\beta),\quad v_0 = -\tfrac12[\max(v_{abc})+\min(v_{abc})],\quad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 1.4 Electromechanical plant

$$J\dot\omega_m = K_t i_q - b\,\omega_m - \tau_{cog}(\theta_m) - \tau_{load},\qquad K_t = \tfrac32 p\lambda_m$$

## 2. Cascaded Position/Velocity Control

The cascade is: Angle (P + velocity feedforward) → Velocity (PI + acceleration feedforward) → i_q.

### 2.1 Velocity loop (4 kHz)

With the current loop approximated as unity gain, the plant seen by the velocity loop is:

$$G_v(s) = \frac{K_t}{Js}$$

**Gains.** For a crossover ω_v, place the PI zero a factor N below crossover (N = 4–5 gives about 50–60° of phase margin):

$$K_p^{v} = \frac{J\omega_v}{K_t},\qquad K_i^{v} = K_p^{v}\frac{\omega_v}{N}$$

Keep ω_v ≤ ω_c/5.

**Velocity estimate.** Use a PLL tracking observer on the encoder angle. It gives lower noise than differencing and introduces no lag at constant speed:

$$\hat\theta_{k+1}=\hat\theta_k + T_s(\hat\omega_k + k_1 \tilde\theta_k),\quad \hat\omega_{k+1}=\hat\omega_k + T_s k_2\tilde\theta_k,\quad \tilde\theta = \mathrm{wrap}(\theta_{enc}-\hat\theta)$$

- Characteristic polynomial: s² + k₁s + k₂.
- Gains: k₁ = 2ζω_o, k₂ = ω_o².
- Use ζ = 1 and ω_o ≈ 3–5 ω_v.
