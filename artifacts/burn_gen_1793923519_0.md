# STM32H743 Nano FC + 4-in-1 ESC (Job #19): System Architecture, Loss Model, DShot/DMA Plan, and Reference Netlist

## 0. Architecture Corrections

Two points shape everything below.

1. **The STM32H743 does not drive the power stage.** In any practical 4-in-1 design, the H743 is the flight controller. It sends bidirectional DShot600 to four ESC MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32). Those MCUs generate the 48 kHz complementary PWM through 3-phase gate drivers. The 48 kHz switching model therefore applies to the ESC MCUs, and the DShot/DMA model applies to the H743.
2. **"80 A burst" on a nano-size board is thermally a 1–3 second event, not a rating.** The model below shows that the realistic continuous capability is about 25 A per channel. You should know this before committing the spec.

All device parameters are **representative assumptions**. Replace them with your chosen MOSFET and driver datasheet values; every equation is written so you can substitute them directly.

## 2. Loss Model per ESC Channel

### 2.1 Conduction Losses (6-step trapezoidal, complementary PWM)

In each commutation state, two legs are active:

- **PWM leg:** the high-side conducts for D·T, and the low-side (synchronous rectifier) conducts for (1−D)·T.
- **Return leg:** the low-side is fully on.

The total conduction loss is therefore:

$$P_{cond} = I^2 R_{hot}\left[D + (1-D) + 1\right] = 2\,I^2 R_{hot}$$

This result is **independent of duty cycle**, which is a useful property for burst analysis. The hot on-resistance is:

$$R_{hot} = k_T R_{25} = 1.6 \times 0.95\,\text{m}\Omega \approx 1.52\,\text{m}\Omega$$

$$P_{cond} = 2 \times 80^2 \times 1.52\text{m} = \mathbf{19.5\ W}$$

Copper path losses add to this:

$$P_{Cu} = I^2 R_{cu} = 6400 \times 0.5\text{m} = \mathbf{3.2\ W}$$

Ripple adds a correction of $I_{rms}^2 = I^2 + \Delta I^2/12$. It is usually below 2% with typical motor inductance (~10–30 µH) at 48 kHz, so it is neglected here.

### 2.2 Switching Losses at 48 kHz

Only the PWM-leg high-side hard-switches. The low-side commutates via the body diode during dead time, so its switching is near-ZVS.

**Hard-switching (V–I overlap):**

$$P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{n} \times 48\text{k} = \mathbf{1.45\ W}$$
