# STM32H743 Flight Controller with Integrated 80 A 4-in-1 ESC (Job #3)

**Design Basis Document: Losses, Thermal Model, Bidirectional DShot600 DMA, and Netlists**

> **Read before use.** No component datasheets were provided, so this document uses a **reference parameter set** (§1.2), chosen as representative of current 30–40 V ESC-class MOSFETs and drivers. Every equation is parametric. Substitute your vendor's numbers before freeze. The math also shows that **four simultaneous 80 A channels on a nano-class board is thermally limited to seconds, not tens of seconds** (§4.4). The program needs to agree on what "80 A burst" means.

---

## 1. System Architecture & Assumptions

### 1.1 Partitioning

The STM32H743 does **not** commutate the motors. Commutation at 48 kHz PWM, zero-cross detection and dead-time control need four dedicated ESC MCUs. The H743 runs ArduPilot and generates bidirectional DShot600 to them.

```
                 ┌──────────────────────────── FC SECTION ────────────────────────────┐
 IMU(SPI1) ─────►│                                                                     │
 Baro(I2C2) ────►│  STM32H743VIT6 (LQFP100) @ 400 MHz  ── ArduPilot ChibiOS          │
 GPS/RC(UARTs) ─►│  TIM1 CH1..CH4 (PE9/PE11/PE13/PE14) ── BDShot600 ──┐                │
 Vbat/Ibat ADC ─►│                                                    │                │
                 └────────────────────────────────────────────────────┼────────────────┘
                                                                      │ 3V3 single-wire, bidirectional
            ┌──────────────┬──────────────┬──────────────┬────────────┘
            ▼              ▼              ▼              ▼
       ESC MCU #1     ESC MCU #2     ESC MCU #3     ESC MCU #4   (AT32F421 / STM32G071 class, AM32 or BLHeli_32)
         │ 6× PWM        ...            ...            ...
       3-ph gate driver ×1 (or 3 half-bridge drivers)
         │
       6× N-MOSFET (3 half bridges) ── Motor n (A,B,C)
```
