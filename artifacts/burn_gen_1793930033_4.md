### Loop rate hierarchy

Each loop runs at least 5–10× faster than the bandwidth of the loop outside it.

```
 ┌──────────────────────── 1 kHz ────────────────────────┐
 │ Attitude loop: quaternion error → camera rate command │
 │ Inverse kinematics: ω_cam → joint rates q̇_cmd         │
 └──────────────────────────┬────────────────────────────┘
 ┌──────────────────────── 4 kHz ────────────────────────┐
 │ Velocity PID (gyro-projected joint rate)              │
 │ + anti-cogging FF + gravity/friction FF → i_q*        │
 └──────────────────────────┬────────────────────────────┘
 ┌──────────────────────── 20 kHz ───────────────────────┐
 │ FOC current PI (d,q), decoupling, SVPWM               │
 └───────────────────────────────────────────────────────┘
 IMU pipeline: 8 kHz (AAF → notch → fuse → LPF), decimated to 4 kHz/1 kHz
```

Target closed-loop bandwidths:

- Current loop: ω_c ≈ 2π·2000 rad/s
- Velocity loop: ≈ 2π·80 Hz
- Attitude loop: ≈ 2π·10–15 Hz

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform** at electrical angle θ_e:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Electrical angle:**

$$
\theta_e = \operatorname{wrap}_{2\pi}\big(p(\theta_m - \theta_{\text{off}})\big)
$$

Here θ_off is found at calibration by aligning to the d-axis: apply V_d with θ_e = 0 and record θ_m.

### 1.2 Plant model in the dq frame

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

The torque equation for a surface PMSM (L_d = L_q) is:

$$
\tau = \tfrac32 p\lambda_m i_q = K_t i_q,\qquad
K_t = \frac{60\sqrt3}{2\pi K_v}\cdot\frac{1}{\sqrt{3}}\cdot\frac{\sqrt3}{2}\ \text{(line-line Kv)}\;\approx\;\frac{8.27}{K_v[\text{rpm/V}]}\;\text{N·m/A}
$$

### 1.3 PI controller with pole-zero cancellation

The current plant is $G_i(s) = \dfrac{1}{Ls+R}$. Choose:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
$$

This gives a closed-loop transfer function $\dfrac{\omega_c}{s+\omega_c}$.
