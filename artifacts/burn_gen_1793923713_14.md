# STM32H743 Nano AIO (4-in-1 ESC + FC): Design Analysis, Job #51

## 0. Scope and Assumptions

I don't have a datasheet set or requirements document for "Job #51," so this analysis uses explicit assumptions (§0.2). Every equation is parametric: substitute your actual MOSFET, board, and airflow data and the conclusions update directly.

### 0.1 A Necessary Architectural Correction

The STM32H743 should **not** commutate the motors directly. ArduPilot is flight-control firmware, not ESC firmware. The correct partition is:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100) | ArduPilot (ChibiOS) |
| ESC ×4 | AT32F421K8U7 or STM32G071GBU6, one per motor | AM32 or Bluejay-class firmware |
| Gate drive ×4 | 3-phase half-bridge driver (FD6288Q-class, 3 high/low pairs) | n/a |
| Power stage ×4 | 6× 40 V N-MOSFET, 3.3×3.3 mm PQFN | n/a |

The H743 talks to each ESC MCU over **bidirectional DShot600**. This is the link analyzed in §4.
