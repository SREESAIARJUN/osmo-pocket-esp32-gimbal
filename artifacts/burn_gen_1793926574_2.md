# STM32H743 Flight Controller + 4-in-1 ESC (Job #39): Reference Engineering Package

## 0. Architecture Corrections and Assumptions

Several points need to be settled before any numbers mean anything.

1. **The H743 does not drive the MOSFET bridges.** In every production 4-in-1 stack, the STM32H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU that performs 48 kHz PWM, commutation and eRPM telemetry. Typical choices are the AT32F421 or STM32G071 running AM32, or the EFM8 running BLHeli_S. This package uses an **AT32F421 + AM32 per channel**.
2. **"80 A burst on a nano board" is the hardest requirement here.** The analysis below shows it is only achievable as a short burst (about 1–2 s), and only with paralleled FETs per bridge position on a 30.5 × 30.5 mm board or larger. A 20 × 20 mm board cannot meet it.
3. **All component parameters are representative assumptions, not a vendor selection.** Substitute datasheet values; every equation is written so you can.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current | I_burst | 80 A per motor channel |
| PWM frequency | f_sw | 48 kHz |
| MOSFET | — | 40 V, PDFN 5×6 class |
| On-resistance at 25 °C | R_ds(on),25 | 1.0 mΩ |

## 1. Conduction Loss Model

### 1.1 Bridge topology

AM32 uses 6-step trapezoidal commutation with synchronous rectification. At any instant two FETs carry the phase current:
- one high-side FET, which is PWM-switching, and
- one low-side FET, which is steady-on.

During PWM off-time, the complementary low-side FET of the switching leg conducts synchronously.

### 1.2 Temperature-corrected on-resistance

$$R_{ds(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)] \approx R_{25}\,k_T$$

At T_j = 125 °C: R = 1.0 mΩ × 1.5 = **1.5 mΩ**.

### 1.3 Per-channel conduction loss

Over one switching cycle, the current always flows through exactly two FET channels:

$$P_{cond,ch} = I^2 \cdot 2R_{ds(on)}(T_j)$$

$$P_{cond,ch} = 80^2 \times 2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

### 1.4 Per-FET conduction loss

Each FET conducts during a 120° commutation window, so it carries a 1/3 time share averaged over an electrical revolution:

$$P_{cond,FET,avg} = \frac{I^2 R}{3} = \frac{6400 \times 1.5\text{ m}\Omega}{3} = 3.2\ \text{W}$$

**Size for the instantaneous value, not the average.** At burst eRPM (about 100–300 Hz electrical), one commutation segment lasts about 1–3 ms. That is comparable to the FET die thermal time constant, so the die sees close to the instantaneous peak:

$$P_{cond,FET,inst} = I^2 R = \mathbf{9.6\ W}$$

### 1.5 Paralleling N FETs per position

$$P_{cond,ch}(N) = \frac{2 I^2 R}{N}, \qquad P_{FET,inst}(N) = \frac{I^2 R}{N^2}$$

With N = 2: 9.6 W per channel and **2.4 W per FET** instantaneous. This is the single most effective lever for an 80 A burst rating.

## 2. Switching Loss Model at 48 kHz

Hard-switching losses fall only on the PWM-switching high-side FET of the active leg.

### 2.1 V-I overlap loss

$$P_{sw} = \tfrac12 V_{bus}\, I\,(t_r + t_f)\, f_{sw}$$

$$= 0.5 \times 25.2 \times 80 \times 20\times10^{-9} \times 48\,000 = \mathbf{0.968\ W}$$

### 2.2 Output-capacitance loss

$$P_{oss} = \tfrac12 C_{oss} V_{bus}^2 f_{sw} = 0.5 \times 10^{-9} \times 635 \times 48\,000 = 0.015\ \text{W}$$

### 2.3 Reverse-recovery loss

This loss occurs in the low-side body diode and is dissipated in the high-side FET.

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\times10^{-9} \times 25.2 \times 48\,000 = 0.060\ \text{W}$$

### 2.4 Dead-time body-diode conduction

There are two dead-time intervals per PWM cycle.

$$P_{dt} = V_f\, I\, (2 t_{dt})\, f_{sw} = 0.8 \times 80 \times 200\times10^{-9} \times 48\,000 = \mathbf{0.614\ W}$$

This term is the hidden cost of running at 48 kHz.
- Halving dead time to 50 ns saves about 0.3 W per channel.
- This requires gate drivers with ≤ 20 ns propagation mismatch.
- AM32's `DEAD_TIME` setting must be validated with a scope on the actual gate waveforms.

### 2.5 Gate-drive loss

This loss is dissipated in the driver, not the FET. It covers two FETs per leg actively switching.

$$P_g = 2\, Q_g V_{gs} f_{sw} = 2 \times 50\text{n} \times 10 \times 48\text{k} = 0.048\ \text{W}$$

With N = 2 paralleled FETs, the gate loss doubles to 0.096 W per channel. The driver's sink/source capability must also double.

### 2.6 Loss budget at 80 A burst (T_j = 125 °C)

| Loss term | N = 1 per channel | N = 2 per channel |
|---|---|---|
| Conduction | 19.20 W | 9.60 W |
| V-I switching overlap | 0.97 W | 0.97 W (current shared; t_r/t_f slightly slower) |
| C_oss | 0.015 W | 0.03 W |
| Q_rr | 0.06 W | 0.12 W |
| Dead-time diode | 0.61 W | 0.61 W |
| Gate drive | 0.05 W | 0.10 W |
| **Total per channel** | **≈ 20.9 W** | **≈ 11.4 W** |
| **Total, 4 channels** | **≈ 83.6 W** | **≈ 45.7 W** |

Conduction dominates at about 92% of losses with N = 1. Therefore raising f_sw from 24 to 48 kHz costs only about 0.8 W per channel. **48 kHz is acceptable; R_ds(on) is the design driver.**
