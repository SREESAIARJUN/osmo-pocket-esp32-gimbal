# STM32H743 Nano AIO Flight Controller with 4-in-1 80A-Burst ESC (Job #21): Power-Stage and DShot Architecture Model

## 0. Architecture Correction and Assumptions

**The STM32H743 does not commutate the motors.** ArduPilot has no motor-commutation or FOC (field-oriented control) code. A buildable design uses this split:

```
STM32H743 (ArduPilot) ──bidir DShot600 ×4──► 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware)
                                              └─► 3-phase gate driver ─► 6× N-MOSFET per motor
```

The 48 kHz PWM is generated by the ESC MCUs. The H743 only handles DShot framing, DMA, and eRPM telemetry decoding.

**Baseline assumptions.** Swap these for your real datasheet values; every equation below is parametric.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | DC link |
| I_ph | 80 A | Burst phase current per channel |
| f_sw | 48 kHz | ESC PWM frequency |
| MOSFET | 60 V, 5×6 / 3.3×3.3 class | R_ds,on,max(25 °C) = 1.8 mΩ |
| Q_g / Q_gs2 / Q_gd | 50 / 4 / 8 nC | Gate charges |
| V_pl | 4.5 V | Miller plateau voltage |
| Q_rr | 60 nC | Reverse-recovery charge at high di/dt |

| R_g | 4.7 Ω external, 1.2 Ω internal | Gate resistance |
| Modulation | 6-step trapezoidal, complementary (synchronous) PWM | AM32 default |

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx 0.006\ \mathrm{K^{-1}}$$

At T_j = 110 °C: R_ds = 1.8 × 1.51 = **2.72 mΩ**.

### 1.2 Six-step current paths

In each 60° sector, three devices share the current:

- The PWM'd high side, phase A, conducts for duty D.
- Its complementary low side, phase A, conducts for (1 − D).
- The low side of phase B conducts continuously.

$$P_{cond,ch} = I_{rms}^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I_{rms}^2\,R_{ds}(T_j)$$

### 1.3 Ripple correction

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{(V_{bus}-E)\,D}{L_{ph} f_{sw}}$$

For a typical 2207 motor (L_ph ≈ 15 µH, D ≈ 0.6, E ≈ 0.85·D·V): ΔI ≈ 6 A. The ripple term adds about 3 A², which is negligible against 6400 A².

$$P_{cond,ch} = 2 \times 6403 \times 2.72\,\mathrm{m\Omega} \approx \mathbf{34.8\ W}$$

### 1.4 Copper and shunt losses

| Path | Calculation | Loss |
|---|---|---|
| Phase pads and planes, ~0.3 mΩ round trip | 80² × 0.3 mΩ | 1.9 W/ch |
| Battery shunt, 0.25 mΩ | (Σ I_bat)² · R_sh. At D = 0.6 with 4 × 80 A, I_bat ≈ 192 A | ≈ 9.2 W |
