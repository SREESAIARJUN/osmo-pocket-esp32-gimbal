# STM32H743 AIO (FC + 4-in-1 ESC) Systems Architecture: Thermal, Switching, and Bidirectional DShot Model

## 0. Architecture Corrections and Assumptions

### 0.1 Architectural clarification

The STM32H743 does **not** generate the 48 kHz bridge PWM. In every production AIO design the partitioning is:

```
STM32H743 (ArduPilot) --4x DShot600 bidir--> 4x ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                               |-> 3-phase gate driver -> 6x N-MOSFET per motor
```

The H743's job is DShot generation, eRPM telemetry capture, and harmonic notch filtering. The 48 kHz PWM runs on the ESC MCUs.

### 0.2 Feasibility flag

80 A burst per motor on a "nano" board (20×20 mm mounting, ~26×26 mm PCB) is **thermally and electrically marginal to infeasible** beyond about 1–2 s. Section 3 quantifies this. I model both a 20×20 and a 30×30 board.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent resistance

```
R_ds(T_j) = R_ds,25 · [1 + α (T_j − 25)]
```

At T_j = 92 °C: R = 1.0 · (1 + 0.006·67) ≈ **1.40 mΩ**

### 1.2 Six-step commutation with synchronous rectification

At any instant, two legs conduct:

- In the PWM-on state, the current path is HS(a) → motor → LS(b).
- In the PWM-off state, the current path is LS(a) → motor → LS(b). The complementary FET conducts; it is not the diode.

Both states therefore present two R_ds in series, and the result is independent of duty D:

```
P_cond,ch = I² · (2·R_ds(T_j) + R_cu)
          = 80² · (2·1.40m + 0.5m)
          = 6400 · 3.30 mΩ
          = 21.1 W per motor
```

For the full board: **P_cond,total = 84.5 W** (71.7 W silicon + 12.8 W copper).

### 1.3 Per-device distribution

Each FET carries current for 1/3 of the electrical period. Its share then splits as D (high side) or 1 − D (low side).

- Time-averaged load: ≈ 17.9 W / 6 ≈ **3 W per FET**.
- Instantaneous peak: 80² × 1.4 mΩ = **9 W** in the conducting FET.

This peak is what the junction-to-case transient impedance (Z_th,jc) sees on the commutation timescale.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches hard (complementary mode).

| Loss term | Formula | Value |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r + t_f) · f_sw = ½·25.2·80·40n·48k | **1.94 W** |
| Reverse recovery | Q_rr · V · f_sw = 50n·25.2·48k | 0.06 W |
| Output capacitance | ½ · Q_oss · V · f_sw · 2 | 0.05 W |
| Dead-time diode conduction | V_f · I · 2·t_dead · f_sw = 0.8·80·200n·48k | **0.61 W** |
| Gate drive (in driver IC) | Q_g · V_gs · f_sw · 2 = 60n·10·48k·2 | 0.06 W |
| **Total per motor** | | **≈ 2.7 W** |

**Board total at 80 A × 4: P_tot ≈ 84.5 + 10.9 ≈ 95 W**
