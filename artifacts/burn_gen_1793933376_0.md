# STM32H743 AIO Flight Controller with 80 A 4-in-1 ESC: Design Reference

## 0. Scope, Architecture Assumptions, and Caveats

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. Each motor channel has a dedicated ESC MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU generates the 48 kHz PWM and talks to the H743 over bidirectional DShot600. Putting 48 kHz six-step commutation for four motors on the H743 alongside ArduPilot is neither supported nor advisable.

**Board.** Assumed 30.5×30.5 mm, 8-layer, 2 oz outer and 2 oz inner power planes. A 20×20 "nano" form factor **cannot** sustain 4×80 A, even briefly, without exceeding junction limits (see §2.6).

**Supply.** 6S, so V_bus = 25.2 V maximum and 22.2 V nominal.

**Values.** All component values below are representative. Before release, verify every parameter (R_DS(on), Q_g, Q_rr, Z_th) against the datasheets of the specific parts you procure.

---

## 1. Power Stage Topology

Each channel has three half-bridges, which is six N-MOSFETs. The control method is trapezoidal six-step with synchronous rectification and complementary PWM on the active leg.

In any commutation sector, the current path is:
- **PWM-on:** HS(A) → motor → LS(B)
- **PWM-off:** LS(A) (sync rect) → motor → LS(B)

So at every instant, **two MOSFETs carry the full phase current.**

**Reference MOSFET** (40 V, PDFN 3.3×3.3 or 5×6 class):

| Parameter | Symbol | Value |
|---|---|---|
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 0.70 mΩ |
| Temperature coefficient | α | 0.007 /K |
| Total gate charge | Q_g | 50 nC |
| Reverse recovery charge | Q_rr | 50 nC |
| Effective output capacitance | C_oss,eff | 1.5 nF |
| Rise / fall time (with driver) | t_r, t_f | 20 ns / 20 ns |
| Body diode V_F | V_F | 0.8 V |
| Junction-to-case | R_θJC | 0.8 K/W |
| Max junction temp | T_J,max | 150 °C (design limit 125 °C) |

## 2. Thermal and Loss Model

### 2.1 Temperature-dependent on-resistance
$$R_{DS}(T_J) = R_{25}\,[1+\alpha(T_J-25)]$$

At T_J = 100 °C: R = 0.70 mΩ × 1.525 = **1.07 mΩ**.

### 2.2 RMS current including ripple
With motor inductance L_m (phase-to-phase), the peak-to-peak ripple is:
$$\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_m f_{sw}}, \qquad I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}$$

Example: L_m = 15 µH, f_sw = 48 kHz, D = 0.9, V_bus − V_bemf ≈ 3 V. This gives ΔI ≈ 3.75 A, so the ripple term (≈1.2 A²) is negligible against 6400 A². **Use I_rms ≈ I = 80 A.**

### 2.3 Conduction loss (per channel)
$$P_{cond} = 2\,I_{rms}^2\,R_{DS}(T_J) = 2(80)^2(1.07\times10^{-3}) = \mathbf{13.7\ W}$$

The split by role:
- **HS (active):** D·I²R = 6.2 W
- **LS of the same leg (sync rect):** (1−D)·I²R = 0.7 W
- **LS of the return leg:** I²R = 6.85 W

**Instantaneous peak per FET ≈ 6.9 W.** The commutation-averaged figure is lower, at about 13.7/3 ≈ 4.6 W per FET pair, because each FET conducts one third of the electrical period.

### 2.4 Switching losses at 48 kHz (hard-switched HS only)

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f = ½·25.2·80·40 ns·48 k | **1.94 W** |
| Dead-time body diode (t_dt = 100 ns, 2 edges) | V_F·I·2t_dt·f = 0.8·80·200 ns·48 k | **0.61 W** |
| Reverse recovery | V·Q_rr·f = 25.2·50 nC·48 k | **0.06 W** |
| C_oss | ½·C_oss·V²·f | **0.02 W** |
| Gate drive (2 FETs, in the driver) | 2·Q_g·V_GS·f = 2·50 nC·10·48 k | **0.05 W** |
| **Subtotal** | | **≈ 2.68 W** |

### 2.5 Interconnect losses
Assume a bus and phase copper path of ≈0.4 mΩ per channel, with half of the copper shared:
$$P_{Cu} \approx 80^2 \times 0.4\,\text{m}\Omega \approx 2.6\ \text{W/channel}$$

Add the bus capacitor ESR loss. A shared bank of 4× low-ESR polymer capacitors totaling 3 mΩ sees ripple current of roughly I·√(D(1−D)) per channel, so:
$$P_{cap} \approx (24\,\text{A})^2 \cdot 3\,\text{m}\Omega \approx 1.7\ \text{W total}$$

### 2.6 Total burst dissipation

| | Per channel | ×4 channels |
|---|---|---|
| Conduction | 13.7 W | 54.8 W |
| Switching | 2.7 W | 10.7 W |
| Copper | 2.6 W | 10.4 W |
| Caps | | 1.7 W |
| **Total** | **19.0 W** | **≈ 77.6 W** |

**Efficiency check:** P_out ≈ 4 × 25.2 × 80 × 0.9 ≈ 7.26 kW, so η ≈ 99.0 %. That is a plausible figure, but the absolute heat is the problem.
