# STM32H743 Nano FC + 80A 4-in-1 ESC: System Architecture & Mathematical Model

**Document scope:** Loss model (conduction + 48 kHz switching), transient thermal model, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

> **Assumptions to resolve before release.** No MOSFET, PCB stackup, or form factor was specified for Job #23. I have used a representative 40 V PDFN3.3×3.3 device class and a 20×20 mm, 8-layer, 2 oz stack. Every number below is parametric. Substitute your datasheet values into the equations in §2–§4 and the results will be valid. Values marked **[ASSUMED]** must be replaced.

## 0. Architectural Clarification

The STM32H743 does **not** run the motor commutation. ArduPilot sends DShot commands from the H743 to four dedicated ESC MCUs, which run AM32 or BLHeli_32 and generate the 48 kHz PWM.

```
 ┌──────────────── FC board (STM32H743VIT6) ───────────────┐
 │ ArduPilot ─► TIM3/TIM5 + DMA ─► DShot600 (bidir, 3.3V)   │
 └───────────────┬──────────────────────────────────────────┘
                 │ 8-pin JST-SH: VBAT, GND, CURR, TLM, M1..M4
 ┌───────────────▼──── 4-in-1 ESC board ────────────────────┐
 │ 4× ESC MCU (e.g. AT32F421 / STM32G071, AM32)              │
 │ 4× 3-phase gate driver ─► 24× N-MOSFET (6 per motor)      │
 │ fsw = 48 kHz, 6-step trapezoidal, synchronous rectific.   │
 └───────────────────────────────────────────────────────────┘
```

## 2. Conduction Loss Model

### 2.1 Current Path
In 6-step commutation with synchronous rectification, two phases are active in any 60° sector. Current always flows through **exactly two channel resistances in series**:
- During t_on: HS(phase A) → winding → LS(phase B)
- During t_off: LS(phase A, sync-rect) → winding → LS(phase B)

### 2.2 Temperature-Dependent Resistance

$$R_{DS}(T_j) = R_{DS,25}\,\big[1+\alpha (T_j-25)\big] \approx R_{DS,25}\cdot k_T,\quad \alpha\approx 0.005\ \text{K}^{-1}$$

$$R_{DS}(125^\circ C) = 1.0 \times 1.5 = 1.5\ \text{m}\Omega$$
