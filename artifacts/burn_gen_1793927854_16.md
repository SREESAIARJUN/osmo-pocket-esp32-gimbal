## 0. Scope, Architecture Assumptions, and Caveats

The STM32H743 cannot practically commutate four BLDC motors and run ArduPilot simultaneously. This design therefore uses the industry-standard partition:

| Block | Device | Role |
|---|---|---|
| Flight Controller | STM32H743VIT6 (LQFP100), 480 MHz | ArduPilot, IMU, DShot600 master |
| ESC MCU ×4 | AT32F421K8U7 or STM32G071GBU6 | AM32 firmware, 48 kHz PWM, BEMF commutation, EDT telemetry |
| Gate driver ×4 | Fortior FD6288Q (3-phase, 250 V, bootstrap) | High/low gate drive |
| MOSFETs ×24 | 40 V N-ch, PDFN 5×6 or 3.3×3.3 | 6S power stage |

> **Important:** All numerical values below use the representative MOSFET parameters in §1. They are **placeholders**. Substitute the values from your chosen part's datasheet. The equations are part-independent, so only the inputs change. Final figures must be validated with thermocouple and IR testing on a prototype.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 100 °C:

$$R_{ds}(100) = 1.2\,\text{m}\Omega \times (1 + 0.0045 \times 75) = 1.605\ \text{m}\Omega$$

### 2.2 Current-path analysis (trapezoidal, complementary/synchronous PWM)

In any 60° commutation sector, two phases conduct. Assume phase A is PWM-driven high and phase B is held low.

- **During D·T_sw:** current flows through Q_AH and Q_BL.
- **During (1−D)·T_sw:** current freewheels through Q_AL (synchronous rectification) and Q_BL.

The total conduction loss per bridge is therefore:

$$P_{cond} = I_{rms}^2 R_{ds}\,[D + (1-D) + 1] = 2\,I_{rms}^2\,R_{ds}$$

This result is **duty-independent**. Synchronous rectification means the current always sees exactly two R_ds(on) in series.

### 2.3 Ripple correction

The peak-to-peak ripple current is:

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

The worst case occurs at D = 0.5:

$$\Delta I = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}_{pp}$$

The RMS current including ripple is:

$$I_{rms}^2 = I^2\left[1 + \frac{1}{12}\left(\frac{\Delta I}{I}\right)^2\right] = 6400 \times (1 + 0.00056) \approx 6403.6\ \text{A}^2$$

Ripple is negligible at 80 A. It matters only at light load.

### 2.4 Result

$$P_{cond} = 2 \times 6403.6 \times 1.605\times10^{-3} = \mathbf{20.55\ W\ per\ channel}$$

The loss distributes across the six FETs as follows:

- Each FET conducts for 1/3 of the electrical cycle.
- Average loss per FET: P_FET,avg = I²R/3 ≈ **3.43 W**.
- Instantaneous loss while conducting: ≈ 10.3 W.

**Example timing:** at 30,000 RPM with 14 poles (7 pole pairs), the electrical frequency is 3.5 kHz and each sector lasts about 48 µs. This is far shorter than the junction thermal time constant, so **average power is the correct input for thermal analysis.**
