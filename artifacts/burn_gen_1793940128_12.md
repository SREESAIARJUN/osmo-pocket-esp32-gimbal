# STM32H743 Nano AIO / 4-in-1 ESC: Loss, Thermal, and Bi-Directional DShot Model

I don't have Job #31's schematic, BOM, or stack-up, so this is built on **explicit, stated assumptions**. Every equation is parameterized, so you can substitute your real MOSFET datasheet values and board geometry. Values marked **[ASSUME]** need verification against your design.

---

## 0. Architecture Correction

The STM32H743 is almost never the commutation MCU in a 4-in-1 ESC. A practical "H743 4-in-1" nano stack is built as follows:

| Function | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743 (400–480 MHz) | ArduPilot |
| ESC commutation (×4) | AT32F421 / STM32G071 / GD32E230 | AM32 (or BLHeli_32) |
| Gate drive (×4) | 3-phase bootstrap driver (e.g., FD6288Q class) | n/a |
| Power stage (×4) | 6 × N-MOSFET per motor, 24 total | n/a |

Two consequences:
- The **48 kHz PWM is an ESC-firmware setting** (in AM32 config). It is not set by ArduPilot.
- **Bi-directional DShot is the H743 ↔ ESC-MCU link.**

If you truly intend the H743 to commutate all four motors directly, that requires 4 × 3-phase complementary PWM with dead-time. The H743 has only TIM1/TIM8 as advanced timers (2 motors' worth of hardware dead-time). That design is not viable for 4 motors without major compromises. Let me know if that is the actual intent.

## 2. Conduction Losses (80 A Burst)

### 2.1 Per-FET RMS Current, 6-Step Synchronous

Each half-bridge conducts actively for 1/3 of the electrical period as the PWM (high) leg and 1/3 as the return (low) leg. The low-side FET also freewheels during the off-time of the PWM'd leg.

$$I_{HS,rms}^2 = I^2 \cdot \frac{D}{3}, \qquad I_{LS,rms}^2 = I^2\left(\frac{1}{3} + \frac{1-D}{3}\right) = I^2\cdot\frac{2-D}{3}$$

### 2.2 Per-FET Conduction Loss

With R_hot = k_T · R_25 = 1.5 mΩ:

$$P_{HS} = 6400 \cdot 0.300 \cdot 0.0015 = 2.88\ \text{W}$$
$$P_{LS} = 6400 \cdot 0.3667 \cdot 0.0015 = 3.52\ \text{W}$$

### 2.3 Per-Motor Conduction Loss

Summing three legs:

$$P_{cond,motor} = 3 I^2 R_{hot}\left(\frac{D}{3}+\frac{2-D}{3}\right) = 2 I^2 R_{hot} = \mathbf{19.2\ W}$$

This is a useful sanity check: at any instant, exactly two FET channels are in series with the phase current, independent of D.

## 3. Switching Losses at 48 kHz

Only one leg switches at any instant in 6-step.

### 3.1 Hard-Switching V·I Overlap

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r+t_f) f_{sw} = 0.5 \cdot 25.2 \cdot 80 \cdot 20\text{ns} \cdot 48\text{k} = \mathbf{0.97\ W}$$

### 3.2 Output-Capacitance Loss

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 30\text{n}\cdot25.2\cdot48\text{k} = 0.036\ \text{W}$$

### 3.3 Dead-Time Body-Diode Conduction

$$P_{dt} = V_F \cdot I \cdot 2t_{dt} \cdot f_{sw} = 0.8\cdot80\cdot200\text{ns}\cdot48\text{k} = \mathbf{0.61\ W}$$

Add Q_rr loss if the datasheet gives it: P_rr ≈ Q_rr · V_bus · f_sw. This is typically 0.05–0.2 W here.

### 3.4 Gate-Drive Loss

Dissipated mostly in the driver and gate resistors.

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\cdot40\text{n}\cdot10\cdot48\text{k} = 0.038\ \text{W}$$
