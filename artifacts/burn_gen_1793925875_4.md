# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #23 specification, so this design uses typical brushless gimbal hardware. Every assumed value is a named `constexpr` or config field. Replace them with your measured values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, hardware FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.0 Ω (phase), L = 2.0 mH, K_t = 0.095 N·m/A |
| Encoder | 14-bit absolute (AS5048A over SPI), read every current-loop cycle |
| Inverter | 3-phase, 12 V bus, 3 low-side shunts, center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro and accel ODR 8 kHz |
| Loop rates | Current 20 kHz · rate (velocity) 4 kHz · attitude/angle 1 kHz · IMU 8 kHz |
