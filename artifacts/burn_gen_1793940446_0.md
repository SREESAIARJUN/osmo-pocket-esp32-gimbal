## 0. Scope, Architecture Clarification, and Assumptions

**Architectural point.** The STM32H743 does not commutate the motors. In any 4-in-1 design, the H743 runs ArduPilot and emits DShot600. Four dedicated ESC MCUs then run AM32 or BLHeli_32 and generate the 48 kHz PWM to the gate drivers. The analysis below follows that split:

| Domain | Silicon | Responsibility |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) | ArduPilot, DShot600 TX, eRPM telemetry RX (input capture) |
| ESC ×4 | AT32F421K8U7 (or STM32G071) running AM32 | 6-step commutation, 48 kHz PWM, BEMF zero-cross detection |
| Gate drive ×4 | FD6288Q (3-phase, bootstrap) | High-side and low-side gate drive |
| Power stage ×4 | 6 N-ch MOSFETs per motor (24 total) | Bridge |

**Baseline assumptions.** No part numbers were specified, so these are representative parameters for a 40 V, ~1 mΩ, 5×6 mm DFN MOSFET. Substitute your datasheet values into the equations.
