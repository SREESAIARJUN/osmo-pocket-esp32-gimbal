## 0. Assumptions and Timing Architecture

| Item | Value | Notes |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz | **[A]** |
| Motor | 12N14P gimbal BLDC (GBM2804-class), p = 7 pole pairs | **[A]** R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit magnetic (AS5048A/MT6701), read in the current-loop ISR | **[A]** |
| PWM | 20 kHz center-aligned, low-side shunt current sensing | |
| Current loop (FOC) | 20 kHz, Ts_i = 50 µs | |
| Velocity loop | 4 kHz | Fed by gyro rate |
| Angle loop | 1 kHz | Fed by fused attitude |
| IMUs | 2× ICM-42688-P on separate SPI buses, 8 kHz ODR, ±2000 dps, ±16 g | |

The loop bandwidths are separated by roughly 5–10× at each level:

```
θ_ref ─►[Angle P/PD 1k]─ω_ref─►[Vel PI 4k]─i_q*─(+)─►[FOC PI 20k]─►SVPWM─►Motor
          ▲                        ▲              ▲ i_ff,cog(θ_m)
          │ θ_fused                │ ω_gyro(filtered)
          └──────[Dual-IMU fusion: consistency → avg → notch → LPF → Mahony]
```

**Gimbal-specific choice.** The velocity loop is closed on **inertial rate from the camera-side gyro**, not on the differentiated encoder. This is what rejects base motion. The encoder is used only for:
- commutation (θ_e),
- the anti-cogging phase (θ_m),
- an optional joint-limit and backlash monitor.

## 1. FOC Current Loop Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is the encoder offset found at alignment (inject d-axis current, wait, read).

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 Plant (surface PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI (pole-zero cancellation)

Target closed-loop bandwidth: ω_ci ≈ 2π·1.5 kHz (well under f_PWM/10).

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

With PI zero K_i/K_p = R/L cancelling the electrical pole, the closed loop becomes:

$$\frac{i}{i^*} = \frac{1}{1 + s/\omega_{ci}}$$

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

At gimbal speeds the back-EMF term is small but cheap, so include it.
