# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

I have no specification for "Job #0", so the design below uses the stated assumptions. Each one is a parameter in the code and can be changed without altering the structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sensing | 2 or 3 low-side shunts. A voltage-mode fallback is provided for boards without shunts. |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz |

## 1. Architecture

```
            ┌──────────── 1 kHz ────────────┐ ┌────── 4 kHz ──────┐ ┌──── 20 kHz ────┐
 q_ref ──►(Attitude err → joint err)─► Angle P ─► Velocity PI ─►(+)─► Current PI d/q ─► SVPWM ─► Motor
            ▲  (Jacobian J⁻¹)             ▲ω_ff    ▲ ω_meas      ▲ i_q,ff(θ) cogging
            │                             │        │ (gyro→joint)│ + accel FF
   Dual ICM-42688-P ─► AAF ─► align ─► fuse ─► dyn. notch ─► LPF ─┘
                                   └► Mahony attitude (q̂, b̂_g)
   Encoder θ_m ─► θ_e = p·θ_m − θ_off ─► Park/inv-Park, cogging LUT index
```

Design choice: the velocity loop runs on the gyro rate (inertial stabilization). The encoder rate serves only for commutation, for cogging adaptation, and as a fallback when the IMU faults.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

Clarke transform (amplitude-invariant):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)
$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

### 2.2 Plant model (SPMSM, $L_d=L_q=L$)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

Torque:

$$
\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q
$$

### 2.3 PI with decoupling and back-EMF feedforward

$$
v_d^* = K_p e_d + K_i\!\int e_d - \omega_e L i_q,\qquad
v_q^* = K_p e_q + K_i\!\int e_q + \omega_e L i_d + \omega_e\lambda_m
$$

Pole–zero cancellation gives a first-order closed loop with bandwidth $\omega_c$:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}\;(\approx 2\pi\cdot 2\,\text{kHz})
$$

Delay compensation: rotate the output voltage vector by $1.5\,\omega_e T_s$. This accounts for one sample of computation plus half a PWM period of ZOH.
