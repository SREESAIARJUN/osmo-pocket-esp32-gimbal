# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional-DShot Design Package (Job #19)

## 0. Scope, Architecture, and Assumptions

### 0.1 Architecture

An STM32H743 is not used as the ESC commutation controller. Production 4-in-1 ESCs use one small MCU per motor running AM32 or BLHeli_32, for example AT32F421, STM32G071, or GD32E230.

The architecture modeled here is therefore an AIO stack:

```
[6S battery] ──► 4-in-1 power stage (4× ESC MCU + 4× 3-phase gate driver + 24 MOSFETs)
                       ▲  bidirectional DShot600 (1 wire per motor)
[STM32H743 FC running ArduPilot] ──► IMU / baro / OSD / UARTs
```
