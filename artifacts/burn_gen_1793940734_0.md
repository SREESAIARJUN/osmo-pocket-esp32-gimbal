# STM32H743 AIO Flight Controller + 4-in-1 ESC: 80 A Burst Electro-Thermal Model, 48 kHz Switching Losses, and ArduPilot Bidirectional DShot600 Allocation

## 0. Scope, Assumptions and One Architectural Correction

I don't have the Job #46 requirements file. The constraints below are explicit assumptions. Every equation is parameterized, so you can substitute datasheet values for the parts actually selected.

**Architectural correction.** The STM32H743 should **not** commutate the motors. ArduPilot does not run BLDC commutation firmware. The H743 is the flight controller and emits bidirectional DShot600. The 4-in-1 ESC section uses dedicated ESC MCUs (4× AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware), with the H743 and ESC on one PCB stack ("AIO"). ## 1. Conduction Loss Model

### 1.1 Current path in 6-step trapezoidal commutation

In any 60° sector, two phases carry current:

- **PWM leg, on-state:** current flows through the high-side switch (HS) of phase X.
- **PWM leg, off-state:** current flows through the low-side switch (LS) of phase X, via synchronous rectification.
- **Return leg:** current flows through the LS of phase Y, which is held ON for the full sector.

At every instant exactly **two FETs** carry the phase current I (dead-time intervals are treated in §2). So:

$$P_{cond,ch} = I_{rms}^2\cdot\big[D\,R_{HS} + (1-D)\,R_{LS} + R_{LS,ret}\big] \approx 2\,I_{rms}^2\,R_{DS(on)}(T_j)$$

$$R_{DS(on)}(T_j) = R_{25}\,\big[1 + \alpha\,(T_j - 25)\big]\ \approx\ k_T R_{25}$$

### 1.2 Ripple correction

The phase current ripple is:

$$\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

The RMS correction is $I_{rms}^2 = I_{dc}^2 + \Delta I^2/12$.

For a typical 5-inch-class motor (L_ph ≈ 15 µH) at D ≈ 0.9 and V_bemf ≈ 21 V, ΔI ≈ 5.2 A. The ripple term adds ≈ 2.3 A², which is negligible against 6400 A². It is dropped from here on.

### 1.3 Numbers at 80 A

$$R_{hot} = 1.5\times0.9\,\text{m}\Omega = 1.35\ \text{m}\Omega$$

$$P_{cond,FET} = 2\cdot80^2\cdot1.35\times10^{-3} = \mathbf{17.3\ W\ per\ channel}$$

### 1.4 Copper loss (often larger than designers expect)

The path runs: battery pad → V+ plane → HS → phase pad → motor → phase pad → LS → GND plane.

- Estimated return-path copper ≈ 0.5 mΩ: 0.5 mΩ at 2 oz across the ~25 mm effective path.
- Resulting copper loss: $P_{Cu} = 80^2 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W/ch}$.

For the shared input path, the battery lead plus XT60/pads at ~1.5 mΩ carry 320 A total, giving **154 W**. This is a system-level red flag: 320 A from a 6S pack is a ~8 kW burst, and almost no nano-class power entry survives it. Confirm whether "80 A" means per motor or total. If it means **80 A total (20 A/motor)**, every per-channel loss below drops by ~16×.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Per channel, one hard-switched commutation per edge.

### 2.1 V–I overlap (hard switching)

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot40\text{ns}\cdot48\text{kHz} = \mathbf{1.94\ W}$$

### 2.2 Reverse recovery (LS body diode → HS turn-on)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{nC}\cdot25.2\cdot48\text{k} = \mathbf{0.06\ W}$$

The recovery also adds current overshoot into the HS turn-on. Include it in t_r if measured.

### 2.3 Output capacitance

$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = \mathbf{0.024\ W}$$

### 2.4 Dead-time body-diode conduction

$$P_{dt} = V_F\, I\, (2 t_{dt}) f_{sw} = 0.8\cdot80\cdot400\text{ns}\cdot48\text{k} = \mathbf{1.23\ W}$$

This term is comparable to the hard-switching loss. Reducing dead time from 200 ns to 100 ns saves ~0.6 W per channel. That is the cheapest efficiency gain available, limited by driver propagation mismatch.

### 2.5 Gate drive (dissipated mostly in driver and R_g)

$$P_{g} = Q_g V_{GS} f_{sw}\cdot N_{switching} = 60\text{nC}\cdot10\cdot48\text{k}\cdot2 = 0.058\ \text{W/ch}$$

### 2.6 Per-channel and board totals at 80 A burst

| Term | W/channel | W ×4 |
|---|---|---|
| FET conduction | 17.3 | 69.1 |
| Copper (local) | 3.2 | 12.8 |
| V–I switching | 1.94 | 7.7 |
| Dead-time diode | 1.23 | 4.9 |
| Q_rr + Q_oss + gate | 0.14 | 0.6 |
| **Total** | **≈23.8** | **≈95 W** |

Electrical efficiency at this point is 1 − 95/(4·80·~23 V) ≈ 98.7%. That is still too much heat for the board.

### 2.7 Frequency sensitivity

Frequency-dependent loss is (1.94 + 1.23 + 0.14) ≈ 3.3 W per channel at 48 kHz. That scales as 0.069 W/kHz per channel.

- Dropping to 24 kHz saves ~6.6 W at the board level.
- The cost is higher current ripple and audible/vibration effects.
