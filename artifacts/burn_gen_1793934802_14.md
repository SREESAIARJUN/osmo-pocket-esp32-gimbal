## 1. Loss Model (per motor channel)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

At T_j = 110 °C (the converged value from §2.4): R_ds = 1.0 × 1.51 = **1.51 mΩ**.

### 1.2 Conduction loss

**Model.** Assume 6-step trapezoidal commutation with synchronous rectification (AM32/BLHeli_32 default, "complementary PWM"). At any instant the current path is:

- **PWM phase:** high-side FET (on-time D) or its complementary low-side FET (off-time 1−D).
- **Return phase:** low-side FET, held on continuously.

Exactly two R_ds are therefore always in series, independent of duty:

$$P_{cond} = 2\,I_{pk}^2\,R_{ds}(T_j)$$

$$P_{cond} = 2 \times 80^2 \times 1.51\times10^{-3} = \mathbf{19.3\ W}$$

**Per-FET breakdown.**

- Peak instantaneous loss in a conducting FET: I²R = 9.7 W.
- Each FET conducts during 120° of every 360° electrical, so the average is 19.3 / 6 ≈ **3.2 W**.
- Electrical frequency is in the kHz range (e.g., 14 pole-pairs at 30k RPM ≈ 7 kHz). The junction thermal time constant is in the ms range, so T_j sees the average, not the 9.7 W pulses.

**Copper loss.** Phase and return path copper adds:

$$P_{cu} = 2 I^2 R_{cu} = 2 \times 6400 \times 0.25\text{ m}\Omega \approx \mathbf{3.2\ W}$$

Copper loss heats the board directly rather than the junctions.

### 1.3 Switching loss at 48 kHz (hard-switched half-bridge, inductive load)

Only one half-bridge is PWM-switching at any time.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·30 ns·48 k | 1.45 W |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 k | 0.05 W |
| Output capacitance | ½·Q_oss·V·f_sw | 0.04 W |
| Dead-time diode | V_SD·I·(2·t_dead)·f_sw = 0.8·80·200 ns·48 k | 0.61 W |
| Gate drive | Q_g·V_gs·f_sw·2 = 50 nC·10·48 k·2 | 0.05 W (mostly in R_g and driver) |
| **P_sw total** | | **2.20 W** |

**Design lever:** Dead-time loss is 28 % of switching loss. Dropping t_dead from 100 ns to 50 ns saves about 0.3 W per motor, but verify shoot-through margin with the actual driver propagation skew.
