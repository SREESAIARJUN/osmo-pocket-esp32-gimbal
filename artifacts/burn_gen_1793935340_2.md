## 0. Architecture Assumptions

This job specification is under-constrained. The assumptions below must be confirmed before layout freeze, and every number downstream is parameterized so it can be recomputed.

| Parameter | Assumed value | Rationale / action |
|---|---|---|
| Form factor | 30.5 × 30.5 mm AIO, 6-layer, 2 oz all layers | "Nano" 20 × 20 is thermally infeasible for 80 A (see §3) |
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal | |
| 80 A rating | **Per channel, burst ≤ 2 s** | Must be defined. "80 A × 4 continuous" is 320 A and is not physically achievable on this footprint. |
| MOSFET | 40 V N-ch, PQFN 3.3 × 3.3, R_DS(on),25 = 1.0 mΩ @ V_GS = 10
