## 0. Architecture Assumptions

Several points in the brief need clarifying before the math, because they change the results.

1. **The H743 does not commutate the motors.** ArduPilot does not run ESC firmware. A real 4-in-1 design pairs the H743 (flight controller) with four dedicated ESC MCUs (e.g., AT32F421 or STM32G071 running AM32 or BLHeli_32). The H743 talks to them over bi-directional DShot600, and the ESC MCUs generate the 48 kHz PWM.
2. **80 A on a "nano" board is a burst rating only, measured in seconds.** Section 3 shows that the board reaches its thermal limit in about 3 s at 80 A on all four channels. Continuous capability is about 25–35 A per channel, depending on airflow.
3. **Baseline parameters:**

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max | Worst case for switching loss |
| Board | 30.5 × 30.5 mm ESC + stacked 20 × 20 FC, or a single 25.5 × 25.5 AIO | A true 20 × 20 AIO cannot carry 80 A |
| PCB | 8-layer, 2 oz on all layers, power on L1/L2/L7/L8 | |
| MOSFET | 40 V N-ch, 3.3 × 3.3 PQFN, R_DS(on),25 = 1.0 mΩ, Q_g = 30 nC, Q_gd ≈ 7 nC, Q_rr ≈ 40 nC, Q_oss ≈ 40 nC | Representative class, not a specific part |
| Gate driver | 3-phase half-bridge driver (FD6288Q class), V_drv = 10 V | |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, f_sw = 48 kHz | |
| Motor | L_line-line ≈ 20 µH (e.g., 2207-class) | |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha\,(T_j - 25)\right],\qquad \alpha \approx 0.0055\ \mathrm{K^{-1}}$$

### 1.2 Current path

In 6-step commutation with synchronous rectification, exactly **two MOSFETs carry the phase current at every instant**:
- either the high side of the PWM leg or its complementary low side, plus
- the low side of the return leg.

So the channel conduction loss is:

$$P_{cond,ch} = 2\, I_{ph,rms}^2\, R_{DS}(T_j)$$

### 1.3 Ripple correction

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

The worst case is D = 0.5:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.56\ \mathrm{A}$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 = 6403.6\ \mathrm{A^2}$$

The ripple term contributes 0.06 % and can be ignored at 80 A.

The junction temperature is solved iteratively in §3.4 and converges at T_j ≈ 117 °C:
