# STM32H743 Nano FC + 4-in-1 ESC (Job #53): Power-Stage, Thermal, and Bi-Directional DShot600 Design Package

## 0. Architecture Correction

An STM32H743 cannot practically commutate four sensorless BLDC bridges at 48 kHz while also running ArduPilot. ArduPilot's bi-directional DShot assumes a separate ESC microcontroller that answers each frame with eRPM telemetry. The partitioning used throughout this document is:

```
┌──────────────── FC section ────────────────┐     ┌──────── ESC section (×4) ────────┐
│ STM32H743VIT6 @ 400 MHz, ArduPilot         │     │ AT32F421K8U7 (or STM32G071)      │
│ TIM3_CH3/CH4, TIM5_CH1/CH2 → DShot600 BIDIR├────►│ AM32 / BLHeli_32-class firmware  │
│ IMU, baro, OSD, UARTs, SD                  │◄────┤ 48 kHz complementary PWM         │
└────────────────────────────────────────────┘     │ 3-ph gate driver + 6× N-MOSFET   │
                                                    └──────────────────────────────────┘
```

**Design target:** 6S (25.2 V max), 80 A burst per channel for ≤ 2 s, 48 kHz PWM, 30.5 × 30.5 mm board.

The analysis in §2 shows that 80 A burst is only marginally achievable on a nano form factor. Treat it as a stress case, not a rating.

## 2. Loss Model: One ESC Channel

### 2.1 Commutation Topology

With 6-step trapezoidal drive and synchronous (complementary) PWM, two phase legs carry the motor current I at any instant:

- **PWM leg:** the HS FET conducts for D·T_s; the LS FET (synchronous rectification) conducts for (1−D)·T_s.
- **Return leg:** the LS FET is held ON for the full 60° sector.

The current therefore always passes through exactly **two channels in series**, regardless of D. This is the key simplification for conduction loss.

### 2.2 Conduction Loss

Temperature-corrected on-resistance:

$$R_{DS(on)}(T_j)=R_{DS(on),25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R = 1.5 mΩ × 1.6 = **2.4 mΩ**.

Per-channel instantaneous conduction loss:

$$P_{cond}=2\,I^2R_{DS(on)}(T_j)+I^2R_{Cu}$$

$$P_{cond}=2(80^2)(0.0024)+80^2(0.0005)=30.7+3.2=\mathbf{33.9\ W}$$

**Per-FET average.** Each of the 6 FETs carries current for about 1/3 of the electrical cycle, so the FET losses split as:

$$P_{FET,avg}\approx \frac{2I^2R}{6}=\mathbf{5.1\ W}$$

At low eRPM (e.g., punch-out from a hover), one FET can sit in a sector long enough to see the full **15.4 W** instantaneously. The FET transient Z_th must therefore be checked as well (§3.3).

**Iterative coupling.** R_DS(on) depends on T_j, which depends on P. Solve the following to a fixed point (2–3 iterations converge):

$$T_j = T_a + P(T_j)\,Z_{th}$$

The 125 °C assumption is self-consistent only if the thermal path in §3 holds.

### 2.3 Switching Loss at f_sw = 48 kHz

Only the PWM leg switches hard: one turn-on and one turn-off per period. The return leg does not switch within the sector.

**(a) V–I overlap (hard switching, inductive clamp):**

$$P_{VI}=\tfrac12 V_{bus} I (t_r+t_f) f_{sw}=\tfrac12(25.2)(80)(30\,\text{ns})(48\,\text{kHz})=\mathbf{1.45\ W}$$

Cross-check with the Miller plateau. With Q_gd = 8 nC and an effective plateau drive current of about 0.6 A, the transition time is t ≈ Q_gd / I_g ≈ 13 ns, which is consistent with the 15 ns assumed.

**(b) Body-diode reverse recovery:**

$$P_{rr}=Q_{rr}V_{bus}f_{sw}=40\text{n}\cdot25.2\cdot48\text{k}=\mathbf{0.048\ W}$$

At 80 A with fast di/dt, Q_rr can be 2–3× the datasheet value, giving roughly 0.15 W.

**(c) Output capacitance:**

$$P_{oss}\approx Q_{oss}V_{bus}f_{sw}\cdot\tfrac12 \;(\text{HS turn-on discharging LS }C_{oss})\approx\mathbf{0.02\ W}$$

**(d) Dead-time body-diode conduction** (two dead-time intervals per period):

$$P_{DT}=V_F\,I\,(2t_{DT})f_{sw}=0.8\cdot80\cdot200\text{n}\cdot48\text{k}=\mathbf{0.61\ W}$$

**(e) Gate drive** (two complementary FETs switched per period; dissipated mostly in the driver and gate resistors):

$$P_g=2\,Q_gV_{GS}f_{sw}=2\cdot50\text{n}\cdot10\cdot48\text{k}=\mathbf{0.048\ W}$$
