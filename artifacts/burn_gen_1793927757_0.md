## 1. System Architecture

```
            ┌───────────────── 1 kHz ─────────────────┐ ┌──────── 4 kHz ────────┐ ┌──── 20 kHz ────┐
 θ_ref ──►(+)─► Angle P(+I) ──► ω_ref ─►(+)─► Velocity PI ─► i_q* ─►(+)──────────►(+)─► Current PI ─► SVPWM ─► Inverter ─► Motor
           ▲                    + ω_ff     ▲                         ▲ i_q,cog      ▲     (d,q) + decoupling
           │                               │                         │              │
      q̂ (AHRS)                       ω̂_axis (gyro)          Cogging FF(θ_m)      i_d,i_q (Park)
           ▲                               ▲                         ▲              ▲
   Mahony AHRS ◄── fused gyro/accel ◄── Dual-IMU fusion ◄── notch + LPF ◄── 2× ICM-42688-P (8 kHz, HW AAF)
                                                                    Encoder θ_m ──► θ_e = p·θ_m − θ_off
```

Design choices:

- **The inner velocity loop uses the gyro (inertial rate), not the encoder.** This gives direct rejection of base motion. The encoder is used for commutation and for joint-limit and kinematic feedback.
- **Feedforward is injected at the current level.** Cogging compensation is a torque disturbance, so it is cancelled at i_q, inside the velocity loop. That way the velocity loop never has to "learn" it.

## 2. FOC Current Loop (20 kHz)

### 2.1 Electrical model (rotor dq frame, surface PMSM)

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e\lambda_m
$$

$$
\tau_e = \tfrac{3}{2}p\,\lambda_m\, i_q = K_t\, i_q \quad (L_d = L_q),\qquad \omega_e = p\,\omega_m
$$

### 2.2 Transforms

Amplitude-invariant Clarke transform:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)
$$

Park transform:

$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

The inverse Park transform is the transpose.

**Delay compensation.** The PWM update lands one period after sampling. To compensate, use the following angle in the inverse Park transform:

$$
\theta_e^{\text{pwm}} = \theta_e + 1.5\,\omega_e T_s
$$
