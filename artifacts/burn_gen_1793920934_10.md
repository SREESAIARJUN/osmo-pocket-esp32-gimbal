# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the Job #9 documents, so this design rests on the explicit assumptions in §0. Every parameter that depends on them is a named constant, so you only need to change one place if your hardware differs.

---

## 0. Assumptions

| Item | Assumed value | Where it matters |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, ≥170 MHz | Loop timing budget |
| Motor | Gimbal BLDC, 12N14P (pole pairs $p = 7$), R ≈ 5–15 Ω, L ≈ 1–3 mH | Current-loop gains, cogging harmonics |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A/MA730 class) on SPI | Commutation, PLL |
| Current sense | 2- or 3-shunt, sampled center-aligned at the PWM midpoint | FOC |
| PWM | 20 kHz center-aligned | Current loop = 20 kHz |
| IMUs | 2 × ICM-42688-P on separate SPI buses, mounted on the **camera plate** at ODR = 8 kHz | Vibration rejection |
| Loop rates | Current 20 kHz → velocity 4 kHz → angle/attitude 1 kHz | C
