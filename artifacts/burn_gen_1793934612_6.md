# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion Design (Job #21)

## 0. Assumptions

I don't have the Job #21 specification, so the design rests on the parameters below. Every one of them is a single constant in the code, so you can change them without touching the logic.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs, N_s = 12 slots), R ≈ 8 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) per axis |
| MCU | STM32G4/H7 class with FPU, 3 timers in center-aligned PWM, inline/low-side shunts |
| Bus | 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz, time-staggered |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

### Loop rates

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle (attitude) | 1 kHz | ~25 Hz |
| IMU acquisition + filtering | 8 kHz | n/a |
| AHRS | 1 kHz | n/a |

Each loop's bandwidth is kept at about 5–10× separation from the loop inside it. This is what allows the loops to be designed independently.
