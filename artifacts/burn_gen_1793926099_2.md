# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for Job #59, so this design rests on the assumptions in §0. Every numeric parameter is collected in one config struct so you can substitute your real hardware values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 (single-precision FPU), e.g. STM32G4/H7 |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Driver | 3-phase half-bridge with low-side or inline shunts, center-aligned PWM at 20 kHz |
| Encoders | 14-bit absolute magnetic encoders (AS5048A / MT6701), one per joint |
| IMU_C | ICM-42688-P on the **camera payload**. It is the attitude reference. |
| IMU_B | ICM-42688-P on the **gimbal base** (handle or drone mount). It provides disturbance feedforward and a consistency check. |
| Joint order | Yaw (outer) → Roll → Pitch (inner, carries the camera) |
