# STM32H743 AIO Nano Flight Controller with 4-in-1 ESC: Design Basis (Job #7)

## 0. Scope, Architecture and Key Assumptions

**Architecture decision.** The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. A 480 MHz H7 running the flight stack cannot also run four sensorless 6-step commutation loops with deterministic timing. Every production AIO board splits these jobs, and this design does too:

```
[STM32H743 FC] --4x DShot600 bidir (1-wire)--> [4x AT32F421K8 ESC MCU, AM32 fw]
                                                    |
                                       [4x FD6288Q 3-phase gate driver]
                                                    |
                                       [4x 3-phase bridge, 24 MOSFETs]
```

All numbers below follow from these stated assumptions. **Replace the MOSFET parameters with the datasheet values of the part you actually select.** The equations hold either way.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per channel | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, PQFN 3.3×3, 1 per position) | R_ds(on),25 | 1.1 mΩ max |
| R_ds(on) temperature coefficient | α | 0.0045 /K |
| Gate charge / Miller charge | Q_g / Q_gd | 50 nC / 10 nC |
| Reverse recovery / output charge | Q_rr / Q_oss | 60 nC / 50 nC |
| Body diode forward voltage | V_f | 0.8 V |
| Dead time | t_d | 200 ns |
| Rise / fall transition (V·I overlap) | t_r, t_f | 25 ns each |
| Junction-to-case | R_th,jc | 1.2 K/W |
| Board | — | 25×25 mm, 8-layer, 2 oz outer / 1 oz inner |

> ⚠️ **Feasibility flag.** "80 A burst" on a nano-format board is only credible as a few-seconds rating per channel. If all four channels burst together, the board draws **320 A** from the battery. No XT60 (≈60 A continuous) or practical nano-board busbar sustains that. Section 3 quantifies this. The honest spec is something like "80 A burst ≤ 2 s, single channel, 45 A continuous with airflow."

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step drive with complementary PWM

In each 60° commutation sector, one high-side (HS) leg is PWM-switched and one low-side (LS) leg is held on. Synchronous rectification (AM32 default) puts the current in the switched leg's LS FET during the PWM off-time.

Over one electrical cycle, each phase leg spends:

- **120° in PWM mode:** HS conducts for D, its LS conducts for (1−D).
- **120° with LS held on:** conducts 100%.
- **120° floating:** BEMF sensing.

### 1.2 Per-FET and per-channel average loss

Temperature-dependent on-resistance:

$$R(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

Per-FET conduction loss:

$$P_{HS}=\tfrac{1}{3}\,D\,I_{rms}^2R(T_j) \qquad P_{LS}=\tfrac{1}{3}\,(1-D)\,I_{rms}^2R(T_j)+\tfrac{1}{3}\,I_{rms}^2R(T_j)$$

Summing over the three legs gives the per-channel loss, which is **independent of duty**:

$$\boxed{P_{cond,ch}=2\,I_{rms}^2\,R(T_j)}$$
