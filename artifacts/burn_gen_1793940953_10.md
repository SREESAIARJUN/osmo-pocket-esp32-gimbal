# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #32): Architecture, Loss Model, DShot DMA Plan, and Netlists

## 0. Architecture Corrections and Scope

Two premises in the request need correcting before the numbers can be trusted.

**1. The STM32H743 does not commutate the motors.** In every production AIO design, the H743 runs ArduPilot and sends DShot600 to four dedicated ESC MCUs, which run AM32 or BLHeli_32. Typical ESC MCUs are the AT32F421 or STM32G071, one per motor. Those MCUs drive a 3-phase gate driver and six MOSFETs each. The 48 kHz PWM and all switching losses therefore live in the ESC domain. The H743 domain owns DShot timing, DMA, and telemetry decode. This document models both domains.

**2. "80A burst" on a nano (20×20 mm) board must be defined.**
- **Interpretation A: 80 A per motor.** The math in §1.6 shows this is only survivable for about 1 s. It is not a credible spec at this size.
- **Interpretation B: 80 A total battery current, about 20 A per motor.** This is thermally realistic.

I compute both cases. The design figures are parameterized so you can substitute your actual MOSFET datasheet values.

## 1. Thermal and Loss Model (ESC Domain)

### 1.1 Conduction-path topology

In any 6-step sector, exactly two half-bridges are active:

- **Static leg:** its low-side FET is ON for the whole sector.
- **PWM leg:**
  - its high-side FET is ON for duty D;
  - its low-side FET is ON (synchronous rectification) for (1 − D).

Assuming low phase ripple (L_motor large relative to 1/f_sw), the phase current I is approximately DC within a PWM period. The conducting device count is therefore always 2, regardless of D:

```
P_cond,ESC = I² · [ D·R_HS + (1−D)·R_LS + R_LS,static ] ≈ 2 · I² · R_ds(T_j)
```

### 1.2 Temperature-dependent R_ds(on)

```
R_ds(T_j) = R_ds25 · [1 + α (T_j − 25)]
```

This creates a feedback loop: the junction temperature depends on R_ds, which depends on junction temperature. Solve it by fixed-point iteration:

```
T_j(k+1) = T_ref + P_total(T_j(k)) · Z_th(t)
```

It converges if the loop gain is below 1:

```
∂P/∂T_j · Z_th = 2 I² R_ds25 α · Z_th < 1
```

At 80 A with Z_th = 2 K/W, the loop gain is 2 · 6400 · 0.0015 · 0.005 · 2 = 0.19. It converges, but the margin is shrinking.

### 1.3 Switching losses at 48 kHz (per ESC, hard-switched PWM leg)

| Loss term | Formula |
|---|---|
| V–I overlap | P_sw = ½ · V_bus · I · (t_r + t_f) · f_sw |
| Reverse recovery | P_rr = Q_rr · V_bus · f_sw |
| Output capacitance | P_oss = Q_oss · V_bus · f_sw (≈ ½ Q_oss · V_bus · f_sw per edge pair) |
| Dead-time diode conduction | P_dt = V_f · I · 2 t_d · f_sw |
| Gate drive (2 switching FETs) | P_g = 2 · Q_g · V_gs · f_sw |
