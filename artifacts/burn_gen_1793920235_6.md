# 3-Axis Gimbal: FOC Motor Control, Cogging Compensation and Dual-IMU Fusion

I don't have the Job #40 specification, so this design states its assumptions explicitly. Every assumption is a single constant in the code. Change them to match your hardware and the equations still hold.

| Item | Assumed value |
|---|---|
| MCU | STM32G4-class Cortex-M4F, single-precision FPU, 170 MHz |
| Motors | 3× gimbal PMSM, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase half-bridge, center-aligned PWM 20 kHz, 2 low-side or inline shunts |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701 class), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, synchronized ODR 8 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| Disturbance | Multirotor props at ~80–250 Hz fundamental plus harmonics; ESC RPM telemetry optional |

## 1. Loop Architecture and Timing

```
                 ┌────────────── 1 kHz ──────────────┐ ┌──────── 4 kHz ────────┐ ┌───── 20 kHz ─────┐
q_ref ──► Attitude error ──► Angle P(+FF) ──► J⁻¹ ──► Velocity PI(+D) ──(+)──► Current PI (d,q) ──► SVPWM ──► Motor
              ▲                                   ▲                    ▲  │           ▲
              │ q̂ (Mahony)                        │ ω_joint            │  └ cogging FF│ i_d,i_q (Clarke/Park)
   Dual ICM-42688-P ─► AAF ─► notch bank ─► fusion ─┘                 └── LMS adapt   │ θ_e encoder
```

| Loop | Rate | Target bandwidth | Rule |
|---|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz | ≤ f_s/10 accounting for 1.5 T_s PWM+compute delay |
| Velocity | 4 kHz (gyro decimated 8→4 kHz) | ω_v ≈ 2π·60–100 Hz | ≤ ω_c/10, and below the first structural mode |
| Angle | 1 kHz | ω_a ≈ ω_v/4 | Symmetric-optimum separation |
| IMU sample | 8 kHz | AAF ≈ 1 kHz | Nyquist 4 kHz, notches act at 8 kHz |

## 2. FOC Current Loop

### 2.1 Transforms (amplitude-invariant)

Clarke transform, with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 2.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 2.3 Current PI with decoupling and back-EMF feedforward

Pole-zero cancellation of the electrical pole R/L gives:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

The voltage commands are:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L i_d+\lambda_m)$$

Set i_d* = 0; field weakening is irrelevant for a gimbal.

### 2.4 Voltage limiting and anti-windup

The voltage vector is limited by a circular limit, with the linear SVPWM range:

$$|v| \le V_{max}=\frac{V_{dc}}{\sqrt3}\,m_{max},\qquad m_{max}\approx 0.95$$

Priority goes to d: v_q is clamped to $\sqrt{V_{max}^2-v_d^2}$.

Integrators use back-calculation anti-windup:

$$x_I[k+1]=x_I[k]+T_s\Big(K_i e[k]+K_{aw}\big(u_{sat}[k]-u[k]\big)\Big),\qquad K_{aw}\approx K_i/K_p$$

### 2.5 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c}=\text{InvClarke}(v_\alpha,v_\beta),\qquad v_0=-\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$
