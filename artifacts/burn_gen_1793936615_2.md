|---|---|---|---|

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform:**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)\quad(i_a+i_b+i_c=0)$$

**Park transform:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix},\qquad \theta_e = p\,\theta_m - \theta_{\text{off}}$$

### 1.2 Plant in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda)$$

**Electromagnetic torque:**
$$\tau_e = \tfrac32 p\left[\lambda i_q + (L_d-L_q) i_d i_q\right] \approx K_t\, i_q,\qquad K_t = \tfrac32 p\lambda$$

### 1.3 Decoupled PI with pole-zero cancellation

Feedforward decoupling turns each axis into $G(s)=\frac{1}{Ls+R}$. The PI controller $C(s)=K_p + \frac{K_i}{s}$ with

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

gives $C(s)G(s) = \omega_c/s$, so the closed loop is first order with bandwidth $\omega_c$.
