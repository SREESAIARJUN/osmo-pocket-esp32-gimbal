# STM32H743 AIO Flight Controller with 4-in-1 ESC: Design Model and Reference Architecture

## 0. Architecture Clarification and Assumptions

An STM32H743 does not commutate the power stage directly in any practical 4-in-1 design. A real-time 6-step or FOC commutation loop running for 4 motors on the FC MCU, alongside the ArduPilot scheduler, is not viable. The standard and recommended partition is:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz) | ArduPilot, sends bi-directional DShot600 to the ESCs |
| ESC ×4 | STM32G071 / AT32F421 (AM32 or BLHeli_32) | Commutation, 48 kHz PWM, eRPM telemetry |
| Gate drive ×4 | 3-phase half-bridge driver (FD6288Q class) | Bootstrap high-side drive |
| Power stage | 6 × N-MOSFET per motor (24 total) | 40 V, ~0.9 mΩ class, PDFN 5×6 |

**Design basis.** All numbers below are derived from these assumed values. Replace them with your selected MOSFET's datasheet values and re-run the equations.

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max, 22.2 V nominal |
| Burst phase current per motor | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 0.90 mΩ |
| R_DS(on) temperature coefficient (125 °C) | k_T | 1.6 |
| Gate-drain charge | Q_gd | 15 nC |
| Total gate charge | Q_g | 80 nC |
| Reverse recovery charge | Q_rr | 50 nC |
| Output capacitance | C_oss | 2.0 nF |
| Body diode forward voltage | V_f | 0.8 V |
| Dead time | t_dt | 100 ns |
| Gate drive current (effective) | I_g | ~1 A |
| Board | — | 30.5 × 30.5 mm, 6-layer, 2 oz outer / 2 oz inner power |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,\big[1 + \alpha\,(T_j - 25)\big], \quad \alpha \approx 0.006\ \text{K}^{-1}$$

$$R_{DS}(125^\circ\text{C}) = 0.90 \times 1.6 = 1.44\ \text{m}\Omega$$

### 1.2 Current path in 6-step commutation with synchronous rectification

During any commutation sector, two phases conduct (e.g., A+ / B−):

- **PWM on-time (D):** current flows through HS_A and LS_B.
- **PWM off-time (1−D):** with complementary (synchronous) PWM, current freewheels through LS_A and LS_B.

At every instant, therefore, the current passes through exactly two channel resistances, independent of duty:

$$P_{cond,motor} = I^2 \cdot 2R_{DS}(T_j) \cdot [D + (1-D)] = 2I^2R_{DS}(T_j)$$

$$P_{cond,motor} = 2 \times 80^2 \times 1.44\times10^{-3} = \mathbf{18.4\ W}$$

### 1.3 Copper and interconnect loss

Assume a phase path (bus → FET → pad → motor wire pad) of approximately 0.35 mΩ, which is achievable with 2 oz copper, a pour, and via stitching:

$$P_{Cu} = I^2 R_{path} = 6400 \times 0.35\times10^{-3} = 2.24\ \text{W per motor}$$

### 1.4 Ripple correction

The RMS current includes the PWM ripple ΔI_pp:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12}$$

Ripple is computed as:

$$\Delta I_{pp} = \frac{V_{bus} D(1-D)}{L_{ph} f_{sw}}$$

For a low-inductance 2207 motor (L_ph ≈ 15 µH, phase-to-phase), D = 0.5, at 25.2 V:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{15\times10^{-6} \times 48000} = 8.75\ \text{A}$$

The correction is +6.4 A², i.e. +0.1 %, which is negligible. This is one benefit of using 48 kHz.

## 2. Switching Loss Model at 48 kHz

There is one hard-switched transition pair per PWM period on the active high-side leg.

### 2.1 V–I overlap loss

The transition time is set by the gate driver charging the Miller plateau:

$$t_r \approx t_f \approx \frac{Q_{gd}}{I_g} = \frac{15\ \text{nC}}{1\ \text{A}} = 15\ \text{ns}$$

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\times10^{-9} \times 48000 = \mathbf{1.45\ W}$$

### 2.2 Reverse recovery loss (low-side body diode)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\times10^{-9} \times 25.2 \times 48000 = 0.060\ \text{W}$$

### 2.3 C_oss loss

$$P_{oss} = \tfrac{1}{2} C_{oss} V_{bus}^2 f_{sw} = 0.5 \times 2\times10^{-9} \times 635 \times 48000 = 0.030\ \text{W}$$

### 2.4 Dead-time body-diode conduction

There are two dead-time intervals per period:

$$P_{dt} = V_f \cdot I \cdot 2t_{dt} \cdot f_{sw} = 0.8 \times 80 \times 200\times10^{-9} \times 48000 = 0.61\ \text{W}$$

### 2.5 Gate drive loss

This loss is dissipated mostly in the driver and gate resistors, not in the FETs. Only the 2 FETs being PWM'd switch at f_sw:

$$P_{gate} = Q_g V_{GS} f_{sw} = 80\times10^{-9} \times 10 \times 48000 = 0.038\ \text{W per switching FET}$$

For 2 switching FETs per motor this is approximately 0.08 W.

### 2.6 Loss budget per motor at 80 A, 25.2 V, T_j = 125 °C

| Loss term | W | % |
|---|---|---|
| Conduction (2 × I²R) | 18.40 | 80.0 |
| PCB copper | 2.24 | 9.7 |
| V–I switching | 1.45 | 6.3 |
| Dead-time diode | 0.61 | 2.7 |
| Q_rr + C_oss | 0.09 | 0.4 |
| Gate drive | 0.08 | 0.3 |
| ESC MCU + LDO + driver quiescent | ~0.15 | 0.6 |
| **Total per motor** | **≈ 23.0 W** | |
| **All 4 motors at 80 A** | **≈ 92 W** | |

**Key insight:** at 80 A, the design is conduction-dominated, at roughly 90 % of total losses. Raising f_sw from 24 to 48 kHz costs only about 1.1 W per motor at burst. R_DS(on) and copper are the levers that matter.

**Efficiency check.** At D ≈ 0.9, the input power per motor is approximately 25.2 × 80 × 0.9 ≈ 1.8 kW, giving η ≈ 98.7 %.
