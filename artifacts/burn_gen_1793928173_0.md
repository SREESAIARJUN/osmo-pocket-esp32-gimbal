## 1. Conduction Loss Model

### 1.1 Current path

In six-step trapezoidal drive with synchronous rectification, exactly two FETs carry the phase current at all times:

- **PWM on-time (D):** HS(phase A) → winding → LS(phase B)
- **PWM off-time (1−D):** LS(phase A) (sync-rect) → winding → LS(phase B)

So the series resistance in the current path is always 2·R_ds(on), independent of duty cycle.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.006\ /\text{K}$$

At T_j = 110 °C: R_ds = 1.0 × 1.51 ≈ **1.5 mΩ**.

### 1.3 RMS current including ripple

$$I_{rms} = \sqrt{I_{dc}^2 + \tfrac{\Delta I_{pp}^2}{12}}, \qquad \Delta I_{pp} = \frac{(V_{bus} - E)\,D}{L_{ph}\,f_{sw}}$$

Worst ripple occurs near D = 0.5. Example: L_ph(line-line) = 20 µH and V_bus − E ≈ 12 V give

ΔI_pp = 12 × 0.5 / (20 µH × 48 kHz) = **6.25 A**.

Then I_rms = √(6400 + 3.3) ≈ 80.02 A. Ripple is negligible at 48 kHz for typical 5" motors. The exception is very low-inductance motors (< 5 µH), which must be re-checked.

### 1.4 Conduction losses per channel at 80 A

$$P_{cond,FET} = 2\, I_{rms}^2\, R_{ds}(T_j) = 2(80)^2(0.0015) = \mathbf{19.2\ W}$$
