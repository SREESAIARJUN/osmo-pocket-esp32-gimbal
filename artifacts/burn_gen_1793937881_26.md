# STM32H743 Nano FC + Integrated 4-in-1 ESC: Power-Stage Model, DShot Timing, and Netlist

## 0. Architecture Decisions and Feasibility Flags

The spec as written has physical conflicts. These must be resolved before layout.

| # | Issue | Consequence | Recommendation |
|---|---|---|---|
| F1 | The STM32H743 cannot run 4× sensorless BLDC commutation alongside ArduPilot's scheduler. | It needs dedicated ESC MCUs. | Use 4× AT32F421 running AM32 on the same PCB. The H743 is FC-only and drives them over internal DShot600 traces. |
| F2 | 24 FETs at PDFN 5×6 need about 720 mm² of placement. A 20×20 nano board offers about 400 mm² total. | The FETs do not fit. | Use PDFN 3.3×3.3 FETs. That raises R_DS(on), which the model below accounts for. |
| F3 | 4 × 80 A means 320 A of battery burst. | That exceeds XT60/XT90 ratings, 12 AWG lead ratings, and most nano-class packs. | Rate 80 A as a **single-channel** burst. The realistic aggregate is ~45–55 A/ch. |
| F4 | Full-board thermal mass is about 2.2 J/K. | 80 A on all four channels survives only about 1.5 s (see §3). | Use 30.5×30.5 mm if 80 A burst is a hard requirement. |

All device parameters below are **design assumptions**. Replace them with the selected part's datasheet values; every equation is parametric.

**Assumed operating point:**
- Bus: 6S, V_bus,max = 25.2 V (worst case for switching loss).
- MOSFET: 40 V N-ch, 3.3×3.3 mm.
  - R_DS(on) = 1.0 mΩ @ 25 °C, with α_T ≈ 1.5 at T_j = 125 °C, giving 1.5 mΩ hot.
  - Q_g = 45 nC, Q_gd = 8 nC, Q_gs2 = 5 nC, Q_rr = 40 nC.
  - C_oss(eff) = 1.5 nF, V_SD = 0.8 V, R_g(int) = 1.2 Ω, R_θJC = 1.5 K/W.
- Gate driver: FD6288Q-class 3-phase, V_drv = 10 V, R_g(ext) = 2.2 Ω.
- PWM: f_sw = 48 kHz with complementary (synchronous) switching, t_dead = 100 ns.
- Commutation: six-step trapezoidal (AM32).

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In six-step drive, two phases conduct at any instant: one high-side FET (PWM'd) and one low-side FET. With synchronous rectification, the current always flows through exactly **two channels' worth of R_DS(on)** plus copper.

The instantaneous conduction loss per ESC channel is:

$$P_{cond,ch} = I^2 \left( 2R_{DS(on)}(T_j) + R_{Cu} + R_{shunt} \right)$$

Temperature dependence:

$$R_{DS(on)}(T_j) = R_{DS(on),25}\left[1 + k_T (T_j - 25)\right],\quad k_T \approx 0.005\ \text{K}^{-1}$$

### 1.2 Per-FET distribution

Each phase spends 1/3 of the electrical cycle as the PWM'd (high) leg, 1/3 as the return (low) leg, and 1/3 floating.

| FET | Conduction share | Loss |
|---|---|---|
| High-side | D/3 | I²R·D/3 |
| Low-side (sync rectifying in PWM leg) | (1−D)/3 | I²R·(1−D)/3 |
| Low-side (return leg) | 1/3 | I²R/3 |
