## 1. Control Architecture

```
 setpoint θ* ─►[Angle P + ω_ff]─ω*─►[Velocity PI]─iq*─►(+)─►[Current PI d/q]─►[SVPWM]─► Motor
                   ▲                     ▲             ▲  iq_ff (anti-cog + friction)
                   │ θ_cam (IMU fused)   │ ω (IMU gyro + encoder blend)
             [Mahony AHRS]◄──[Notch+LPF]◄──[Dual ICM-42688-P fusion]
```

The outer loops close on the **camera-frame inertial attitude** measured by the IMUs. The current loop closes on the **encoder electrical angle**.

## 2. FOC Current Loop Equations

### 2.1 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 2.2 Park transform

The electrical angle is θ_e = p·θ_m − θ_offset.

$$
\begin{bmatrix} i_d \\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}
$$

### 2.3 PMSM model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

Electromagnetic torque:

$$\tau_e = \tfrac{3}{2} p\,\lambda_m i_q = K_t\, i_q$$

The control law sets i_d* = 0 (surface-mount magnets, so maximum torque per ampere is achieved at i_d = 0).

### 2.4 PI control with decoupling and back-EMF feedforward

$$v_d^* = K_{p,i}\, e_d + K_{i,i}\!\int e_d\,dt \;-\; \omega_e L_q i_q$$
$$v_q^* = K_{p,i}\, e_q + K_{i,i}\!\int e_q\,dt \;+\; \omega_e (L_d i_d + \lambda_m)$$

**Gain selection by pole-zero cancellation.** Choose the PI zero K_i/K_p = R/L so it cancels the electrical pole. The closed loop then becomes first order with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci},\qquad \omega_{ci} \le \frac{2\pi f_{PWM}}{10}$$

At 20 kHz PWM this gives ω_ci ≈ 2π·1.5 kHz.

### 2.5 Voltage limiting and anti-windup

1. Limit the voltage vector to the linear SVPWM region:
   $$|v| \le V_{dc}/\sqrt{3}$$
2. Prioritize the d-axis:
   $$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$
3. Apply back-calculation anti-windup, with $K_{aw} \approx 1/K_p$:
   $$\dot{x}_I = K_i e + K_{aw}(v_{sat} - v_{unsat})$$

### 2.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset:

$$v_0 = -\tfrac12\left[\max(v_{abc}) + \min(v_{abc})\right]$$

Duty cycles:

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

**Latency compensation.** The voltage computed now is applied about 1.5 PWM periods later. Advance the angle used in the inverse Park transform accordingly:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_{PWM}$$

## 3. Cascaded Velocity / Angle Control

### 3.1 Mechanical plant

The plant per axis, as seen from the motor, is:

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{fric} - \tau_{dist}$$

### 3.2 Velocity loop (PI with acceleration feedforward)

$$i_q^* = K_{p,\omega}\, e_\omega + K_{i,\omega}\!\int e_\omega\,dt \;+\; \frac{J}{K_t}\dot\omega^* \;+\; i_{q,ff}$$

**Tuning by the symmetric-optimum rule.** Let the inner current loop have equivalent time constant $T_\Sigma \approx 1/\omega_{ci} + T_{s,\omega}$. Then:

$$\omega_{c\omega} = \frac{1}{a\,T_\Sigma}\ (a\approx 2\text{–}4),\qquad K_{p,\omega} = \frac{J\,\omega_{c\omega}}{K_t},\qquad K_{i,\omega} = \frac{K_{p,\omega}\,\omega_{c\omega}}{a^2}$$

### 3.3 Velocity feedback

The velocity feedback is the IMU gyro rate, projected onto the motor axis by the gimbal Jacobian (Section 6):

$$\omega_{fb} = \hat{\mathbf{u}}_{axis}^\top\, R\, \boldsymbol\omega_{gyro}$$

The encoder rate is blended in below about 20 Hz using a complementary filter:

$$\omega = \frac{s}{s+\omega_b}\,\omega_{gyro} + \frac{\omega_b}{s+\omega_b}\,\omega_{enc,inertial}$$

### 3.4 Angle loop (P with velocity feedforward)

$$\omega^* = K_{p,\theta}\,\mathrm{wrap}(\theta^* - \theta) + \dot\theta^*$$

- Set $K_{p,\theta} \approx \omega_{c\omega}/4$, which keeps loop separation at 4× or more.
- No integrator is needed in the angle loop: the velocity loop's integrator already rejects constant torque disturbances, and the cascade remains type-1 for angle error.
