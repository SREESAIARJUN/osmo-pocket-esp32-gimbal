# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #47 specification, so this design states its assumptions explicitly. Every parameter that depends on your hardware is a named constant you can change.

---

## 0. Assumed Hardware and Loop Rates

| Item | Assumption |
|---|---|
| Motors | 3 × gimbal BLDC (GBM2804-class), 12N14P → pole pairs p = 7 |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) on each axis |
| Current sensing | 2 inline shunts per motor |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted at r₁ and r₂ |
| IMU settings | Gyro
