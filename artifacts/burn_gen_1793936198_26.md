## 0. Architecture Clarification

ArduPilot does not perform motor commutation, so the STM32H743 cannot drive the bridges directly. The system architecture is:

| Block | Function |
|---|---|
| STM32H743VIH6 (TFBGA100, 8×8 mm) | ArduPilot: attitude control, sensor fusion, bidirectional DShot600 master |
| 4× ESC MCU (e.g. AT32F421K8U7 or STM32G071GBU6) running AM32 | Six-step commutation, 48 kHz PWM, bidirectional DShot slave |
| 4× 3-phase gate driver + 12× N-MOSFET per side (24 FETs total) | Power stage |
