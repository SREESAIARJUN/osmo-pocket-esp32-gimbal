# STM32H743 Nano AIO with 4-in-1 ESC: System Architecture Package

**Scope:** an 80 A burst electro-thermal model, a 48 kHz switching-loss model, ArduPilot bidirectional DShot600 timer and DMA allocation, a reference netlist, and a verification plan.

**Read this first. The headline engineering finding:**

> On a 20×20 mm (or 25.5×25.5 mm) board, **4 × 80 A simultaneous** dissipates **~110–120 W**. The board has a lumped heat capacity of **~3 J/K**. That is a **~1.5–2 s** thermal budget, not a continuous rating. Treat "80 A" as a **≤1 s per-motor burst**, with firmware-enforced I²t limiting. The math below shows why.

All component values are **design assumptions**. Replace them with datasheet values from the parts actually selected for Job #46 before release. Every equation is parameterized so you can do that directly.

## 1. System Partitioning

```
 ┌───────────────── FC (STM32H743, 400 MHz) ─────────────────┐
 │ TIM3 CH1..CH4 ──► Bidir DShot600 (single wire per motor) ──┼──► ESC MCU ×4 (or 1 quad MCU)
 │ ADC ◄── VBAT divider, ESC current sense (CURR)             │     running AM32 / BLHeli_32
 │ SPI1: IMU   SPI3: OSD/Flash   I2C: Baro/Mag   UARTs        │     PWM 48 kHz, complementary
 └────────────────────────────────────────────────────────────┘     │
                                                                    ▼
                                    3-phase gate driver ──► 6 × N-MOSFET per motor (24 total)
```

The H743 does **not** generate the 48 kHz motor PWM. That is done by the ESC MCU(s). The H743 generates DShot and captures the eRPM telemetry. The two domains are modeled separately below.
