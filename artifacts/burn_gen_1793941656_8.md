| Item | Assumed value |

| MCU | STM32G474, 170 MHz, FPU, CORDIC |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (d/q PI), SVPWM | 20 kHz (T_c = 50 µs) | ω_c ≈ 2π·1.5 kHz |

| Attitude estimation + angle P | 1 kHz (T_θ = 1 ms) | ω_θ ≈ 2π·25 Hz |

Bandwidth separation is ≥ 4× between consecutive loops, which keeps the cascade assumptions valid.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

### 1.2 Plant (PMSM in the dq frame)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque is

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

where K_t = 1.5·p·λ_m.

### 1.3 PI with Pole–Zero Cancellation

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q$$

$$v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

**Voltage limit.** SVPWM's linear range is the inscribed circle |v| ≤ V_dc/√3. Prioritize v_d, then give v_q the remaining headroom:

$$v_q^{max} = \sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}$$

**Anti-windup (back-calculation),** with K_aw ≈ 1/K_p:

$$I_{k+1} = I_k + T\left[K_i e_k + K_{aw}(u^{sat}_k - u_k)\right]$$

**Delay compensation.** PWM update plus sampling adds about 1.5·T_c of delay. Use this lead angle for the inverse Park transform:

$$\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_c$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical Plant per Axis

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

**Feedback signal choice (stabilization).** The velocity loop feeds back the camera-frame gyro rate projected onto the motor axis, ω_cam,j = **a**_jᵀ **ω**_cam. It does not use encoder differentiation. This makes the loop reject base motion directly.

The encoder is used for three things:
- commutation;
- anti-cogging indexing;
- a fallback velocity estimate.

The fallback is a PLL-filtered encoder derivative.
