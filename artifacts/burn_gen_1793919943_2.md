# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #13 spec, so this design rests on the explicit assumptions below. Every parameter is in one config block so you can change it in one place.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs, Nₛ = 12 slots), R = 5.6 Ω, L = 2.1 mH, Kₜ ≈ 0.11 N·m/A |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701), one per axis |
| Current sense | Two inline shunts (phases a, b), sampled at PWM center |
| MCU | STM32G4 / H7 class with FPU (single-precision float throughout) |
| IMUs | 2 × ICM-42688-P. **IMU-P** sits on the payload (camera plate). **IMU-B** sits on the base, after the dampers. |
| Kinematics | Base → Yaw(z) → Roll(x) → Pitch(y) → Payload |

### Loop Rates

| Loop | Rate | Input | Output |
|---|---|---|---|
| Current (FOC) | 20 kHz | iₐ, i_b, θₑ | PWM duties |
| Velocity (inertial rate) | 4 kHz | IMU-P gyro (filtered) | i_q* |
| Angle (attitude) | 1 kHz | Attitude estimate | ω* |
| IMU sampling | 8 kHz ODR | Both IMUs | Filters and fusion |
