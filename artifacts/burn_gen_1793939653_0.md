# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Design Assumptions

I don't have Job #52's specifications, so the design assumes typical gimbal hardware. Every value marked `cfg` is a parameter you should replace with measured values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701 class) |
| MCU | STM32G4/H7 class with FPU, CORDIC optional |
| Current sense | 2-shunt or 3-shunt, inline or low-side |
| IMUs | 2× ICM-42688-P on the camera/payload plate over SPI. IMU_B is ideally rotated 90° or on a different isolation path. |
| Joint order | Yaw (outer, base) → Roll → Pitch (inner, camera) |

**Loop rates**

| Loop | Rate | Period |
|---|---|---|
| PWM / current (FOC) | 20 kHz | Ts_i = 50 µs |
| IMU sample (ODR) | 8 kHz | |
| Fusion + velocity loop | 4 kHz | Ts_v = 250 µs |
| Attitude + angle loop | 1 kHz | Ts_θ = 1 ms |
| Cogging LMS adaptation | 4 kHz | runs with the velocity loop |

## 1. Plant Model

### 1.1 Electrical (dq frame, surface PMSM, L_d = L_q = L)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q, \qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$
