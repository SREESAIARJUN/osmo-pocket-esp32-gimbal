# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

I don't have the Job #46 specification, so the design rests on the stated baseline below. Every motor-, MCU- and mounting-specific number is a parameter you can replace without changing the structure.

---

## 0. Baseline Assumptions

| Item | Value (parameter) |
|---|---|
| Motors | 3× outrunner gimbal BLDC, 12N14P (pole pairs `p = 7`, slots `Ns = 12`), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensing | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2-phase low-side shunts (voltage-mode fallback described in §1.5) |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 40 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, gyro ±2000 dps, accel ±16 g |
| Kinematic order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → camera |

**Loop rates and bandwidth separation**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (every other PWM period) | ~1.5–2 kHz |
| Inertial rate (velocity) | 4 kHz | 80–150 Hz |
| Attitude (angle) | 1 kHz | 15–30 Hz |
| IMU acquisition / filtering | 8 kHz | n/a |

Each outer loop's bandwidth stays at least 5× below the loop inside it.
