## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning: inject d-axis current I_align at θ_e = 0, wait for the rotor to settle, then record θ_m.

**Latency compensation.** The voltage computed now is applied at the next PWM period, so evaluate the angle 1.5 sample periods ahead:

$$\hat\theta_e = \theta_e + 1.5\,T_{s,i}\,\omega_e$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model and PI design

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Each axis therefore behaves as a first-order plant, $G(s)=\frac{1}{Ls+R}$.

**PI tuning by pole-zero cancellation.** Choosing

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

cancels the plant pole and gives a closed loop of $\frac{\omega_c}{s+\omega_c}$. With ω_c = 2π·1500 rad/s:

- K_p = 17.0 V/A
- K_i = 51 800 V/(A·s)

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(e_d) - \omega_e L\, i_q,\qquad
v_q^* = \text{PI}_q(e_q) + \omega_e L\, i_d + \omega_e \lambda_m$$

where $\lambda_m = \frac{2K_t}{3p}$.

**Discrete PI with back-calculation anti-windup** (sample period T_s):

$$\begin{aligned}
u_k &= K_p e_k + x_k\\
\bar u_k &= \text{sat}(u_k)\\
x_{k+1} &= x_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big]
\end{aligned}$$

A good default is $K_{aw} = K_i/K_p$.

**Voltage limiting.** Use circular saturation, $|v_{dq}| \le V_{bus}/\sqrt3$, with d-axis priority. For gimbals, i_d* = 0 always.

**High-R motors.** If R ≫ ω_c L (common in gimbal motors), voltage-mode control is acceptable:

$$v_q = R\,i_q^* + \omega_e\lambda_m$$

The code supports both modes.

### 1.4 SVPWM (min-max zero-sequence injection)

1. Inverse Park transform gives v_α, v_β.
2. Inverse Clarke gives the phase voltages v_a, v_b, v_c.
3. Compute the zero-sequence offset:
$$v_0 = -\tfrac12(\max + \min)$$
4. Compute the duty cycles:
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
