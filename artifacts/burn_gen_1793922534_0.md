# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the "Job #7" specification, so this design is built on the assumptions below. Every assumption maps to a constant in the code, so you can change it if your hardware differs.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 12N14P (pole pairs $p=7$), $R\approx 5\,\Omega$, $L\approx 2\,\text{mH}$ |
| Encoders | 14-bit absolute magnetic encoder per joint (AS5048A/MT6701 class) |
| IMU A | ICM-42688-P on the camera/payload. Measures the controlled quantity. |
| IMU B | ICM-42688-P on the base/handle. Provides a disturbance reference and feedforward. |
| MCU | STM32G4/H7 class with FPU |

Loop rates:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz ISR | 1.5–2 kHz |
| Velocity (inertial rate) | 4 kHz | 150–250 Hz |
| Attitude | 1 kHz | 30–50 Hz |
| IMU ODR | 8 kHz gyro, 1 kHz accel | — |

Each loop's bandwidth is at least 5× lower than the loop inside it. This separation lets each inner loop be treated as approximately unity gain when tuning the loop outside it.

## 1. FOC Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):
$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)
$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:
$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant in the dq frame

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

Torque (surface PMSM):
$$
\tau = K_t i_q,\qquad K_t = \tfrac32 p\lambda_m
$$

### 1.3 PI with pole-zero cancellation and decoupling

Choose the PI zero to cancel the electrical pole:
$$
K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}
$$

The closed loop then becomes $\frac{\omega_{ci}}{s+\omega_{ci}}$.

Add cross-coupling and back-EMF feedforward:
$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad
v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m
$$

Set $i_d^*=0$.
