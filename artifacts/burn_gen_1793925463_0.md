# STM32H743 Nano AIO Flight Controller with 4-in-1 80A ESC (Job #21): Architecture, Loss Model, Thermal Analysis, and DShot DMA Plan

## 0. Feasibility Findings

These findings shape everything below.

1. **The STM32H743 is the flight controller MCU, not the ESC MCU.** A 4-in-1 ESC needs a dedicated commutation MCU for each motor. This design uses an STM32H743 for the flight controller plus four AT32F421 MCUs running AM32 firmware, which supports bi-directional DShot and EDT. The H743 talks to the ESC MCUs only over the DShot lines.
2. **"80A burst" on a 20×20 mm nano board is limited by heat storage, not by the MOSFETs.** With all four motors at 80A, the board dissipates about 85–110W into roughly 2 J/K of thermal mass. That gives about 1–2 seconds of adiabatic burst (Section 3). The rating must therefore come with a time limit, such as "80A for 1 s, one motor." Do not quote it as a sustained figure.
3. **All component values are placeholders.** MOSFET and driver parameters are representative of 40V, 3.3×3.3 mm PQFN parts. Re-run the model with the real datasheet values before layout freeze.

## 1. System Architecture

```
 6S LiPo (25.2V max) ──┬── Bulk caps ── 4× ESC power stages (24× N-FET)
                       │                    ▲ gate drive
                       │       4× FD6288Q-class 3-phase drivers
                       │                    ▲ 6× PWM each @ 48 kHz
                       │       4× AT32F421 (AM32)  ◄── Bi-dir DShot600 ──┐
                       │                                                 │
                       └── 5V/3.3V buck ── STM32H743 (TFBGA100) ── TIM1 CH1–CH4
                                              ├ SPI1: IMU (ICM-42688-P)
                                              ├ I2C: Baro / Mag
                                              ├ SDMMC1 (uses IDMA, no DMA stream)
                                              └ UARTs: RX, GPS, VTX, telemetry
```
