## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms

**Electrical angle:**
θₑ = p·(θₘ − θ_offset) mod 2π

**Clarke (amplitude-invariant):**
- i_α = i_a
- i_β = (i_a + 2·i_b)/√3
- valid when i_a + i_b + i_c = 0

**Park:**
- i_d = i_α cos θₑ + i_β sin θₑ
- i_q = −i_α sin θₑ + i_β cos θₑ

**Inverse Park:**
- v_α = v_d cos θₑ − v_q sin θₑ
- v_β = v_d sin θₑ + v_q cos θₑ

### 1.2 Current PI with Decoupling

The PMSM dq model is:
- v_d = R·i_d + L·di_d/dt − ωₑ·L·i_q
- v_q = R·i_q + L·di_q/dt + ωₑ·L·i_d + ωₑ·λ_m

Using pole-zero cancellation with target current-loop bandwidth ω_c:
- K_p,i = L·ω_c
- K_i,i = R·ω_c

This gives a first-order closed loop: I(s)/I*(s) = ω_c/(s + ω_c).

The control law is:
- v_d = PI_d(i_d* − i_d) − ωₑ·L·i_q
- v_q = PI_q(i_q* − i_q) + ωₑ·(L·i_d + λ_m)

Set i_d* = 0, since gimbal motors are surface-mount
