# STM32H743 AIO (Nano 4-in-1 ESC + FC): Design Model and Allocation

## 0. Scope, Assumptions, and a Feasibility Warning

The STM32H743 does not commutate the motors. In any ArduPilot AIO, the H743 runs ArduPilot and sends bi-directional DShot600 to **four dedicated ESC MCUs**. This design uses 4× AT32F421 running AM32, which supports a 48 kHz PWM setting. The 48 kHz switching analysis therefore applies to the ESC power stage, and the DMA analysis applies to the H743.

**Representative parameters.** Replace these with your exact BOM datasheet values. All equations are parametric.

| Q_rr / Q_oss / Q_g | 50 / 40 / 60 nC | |
| V_SD | 0.8 V | Body diode |
| t_dt | 100 ns | Dead time per edge |
| L_phase | 15 µH | Motor phase-phase |
| Board | 20×20 mm, 6-layer, 2 oz | "Nano" class |

> ⚠️ **Feasibility warning (read before building).** As the math below shows, 80 A on a 20×20 mm board is a **≈2 s transient rating**, not a continuous one. The thermal loop also has **positive feedback** (dP/dT > 1/R_th), which means it runs away rather than settling. Any "80 A" label must be enforced in firmware as a time-limited burst. Use ArduPilot current limiting plus AM32 temperature protection.

## 1. Conduction Loss Model

### 1.1 Commutation topology
AM32 uses 6-step trapezoidal drive with complementary (synchronous) PWM. In each 60° sector:

- **Switching leg:** the high-side (HS) FET conducts for D. Its complementary low-side (LS) FET conducts for (1−D).
- **Return leg:** the LS FET conducts continuously.
