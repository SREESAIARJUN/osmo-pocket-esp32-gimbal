# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original spec for "Job #6," so this design rests on the assumptions below. Every value marked as a parameter can be changed in a config struct.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701 class) per axis |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM |

## 1. Control Architecture

```
 IMU#1 ─┐  ┌──────────────────────┐
        ├─►│ Dual-IMU fusion      │──► q̂ (camera attitude), ω̂ (body rate)
 IMU#2 ─┘  │ notch+LPF+lever-arm  │
           └──────────────────────┘
                     │ θ̂_axis, ω̂_axis
 θ_ref ─►(Σ)─► P_θ ─►(Σ)─► PI_ω ─►(Σ)─────────► iq_ref ─► PI_iq ─► vq ┐
          ▲         ▲ ω_ff  ▲       ▲ iq_cog(θm)          PI_id ─► vd ┤► invPark ► SVPWM
          │         │       │       │ iq_ff(α_ref)                   │
          └─θ̂       └──────ω̂       └─ anti-cogging table        Clarke/Park ◄─ ia,ib
```

The angle and velocity loops close on the IMU estimate, so they act in camera/inertial space. Commutation uses the encoder. For outer and inner joints, the inertial rate is mapped to joint space through the gimbal Jacobian (Section 4.6).

## 2. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 2.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

### 2.2 Clarke transform (amplitude-invariant, balanced, $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 2.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 2.4 PMSM model in the rotor frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \;\xrightarrow{\text{SPM},\,L_d=L_q}\; \tau_e = K_t\, i_q,\quad K_t=\tfrac32 p\lambda_m$$

### 2.5 Current PI with pole-zero cancellation

Each axis has the plant $G_i(s) = \dfrac{1}{Ls+R}$. Choose the PI zero at $R/L$:

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The closed loop then becomes first-order: $\dfrac{i}{i^*} = \dfrac{\omega_c}{s+\omega_c}$.

Pick $\omega_c \le 2\pi f_{\text{PWM}}/10$ to stay clear of the one-sample delay plus ZOH (≈1.5 Ts). At 20 kHz, $\omega_c \approx 2\pi\cdot 1500$ rad/s.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e(L_d i_d + \lambda_m)$$

**Discrete form (backward Euler) with conditional-integration anti-windup.** The integrator is frozen when the output saturates in the same direction as the error:

$$u_k = K_p e_k + I_{k-1} + K_i T_s e_k,\qquad I_k = \begin{cases} I_{k-1}+K_iT_se_k & \text{if not (sat} \wedge \operatorname{sgn}e = \operatorname{sgn}u)\\ I_{k-1} & \text{otherwise}\end{cases}$$

**Voltage vector limit.** Linear SVPWM reaches $|v| \le V_{dc}/\sqrt3$. Give $v_d$ priority, then:

$$v_{q,\max} = \sqrt{V_{\max}^2 - v_d^2}$$

### 2.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\; v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\; v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM and avoids branching.

## 3. Cascaded Velocity and Angle Control

### 3.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{d}$$

The current loop is fast ($\omega_c \gg \omega_v$), so the velocity plant is $G_\omega(s) \approx \dfrac{K_t}{Js}$, with delay $T_\Sigma$ from filtering and sampling.

### 3.2 Velocity PI (symmetric-optimum-style placement)
