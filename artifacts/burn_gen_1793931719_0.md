This document covers the electrothermal model for the ESC power stage, the switching loss model at f_sw = 48 kHz, ArduPilot bidirectional DShot600 timer and DMA allocation, schematic netlists, and a thermal verdict.

**Architectural note.** In a 4-in-1 ESC, the H743 does not switch the FETs. It sends DShot600 to four ESC MCUs (or one quad-capable MCU), and those MCUs generate the 48 kHz complementary PWM. The power math (Sections 1–3) and the H743 timer math (Section 4) are therefore separate domains.

## 1. Conduction Loss Model

### 1.1 Commutation topology

In 6-step trapezoidal drive with synchronous complementary PWM (the AM32 default), at any instant the current path is:

> HS(phase A, PWM duty D) or LS(phase A, sync-rect, 1−D) → motor → LS(phase B, fully on)

Two FETs are therefore always in series with the motor current. This holds independent of D, because the complementary low side replaces the high side during the off-time.

### 1.2 Per-motor conduction loss

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{DS}(T_j)$$

For flat-top trapezoidal current at burst, I_rms ≈ I_pk = 80 A.

Using T_j = 125 °C, so R_DS = 1.0 × 1.5 = 1.5 mΩ:

$$P_{cond,motor} = 2 \times 6400 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

### 1.3 Distribution among the 6 FETs (one electrical cycle)

Each phase is active for 2/3 of the cycle. It sources for 1/3 and sinks for 1/3.

- **High-side FET:** conducts D × 1/3 of the cycle.
  $$P_{HS} = \tfrac{1}{3} D\, I^2 R$$
- **Low-side FET:** conducts (1−D) × 1/3 as sync rectifier, plus 1/3 as the return leg.
  $$P_{LS} = \tfrac{1}{3}(2-D)\, I^2 R$$

At burst, D ≈ 0.95:

- P_HS = 0.317 × 9.6 W = **3.04 W**
- P_LS = 0.35 × 9.6 W = **3.36 W**
- Sum over 6 FETs = 3·(3.04 + 3.36) = 19.2 W ✓

### 1.4 Copper and shunt losses (often ignored, and significant)

| Element | Resistance | Loss at 80 A |
|---|---|---|
| Phase pad + trace, 2 oz, ~6 mm × 3 mm × 2 layers | ≈0.25 mΩ | 1.6 W |
| Current shunt (if per-motor), 0.25 mΩ | 0.25 mΩ | 1.6 W |
| Battery pad → bus plane (shared by 4 motors at 320 A) | ≈0.1 mΩ | 10.2 W total |

The 320 A aggregate bus case is unrealistic for a nano board. See Section 5.

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate current and transition times

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_g} = \frac{10-3}{4.5} = 1.56\ \text{A} \qquad I_{g,off} = \frac{V_{pl}}{R_g} = 0.67\ \text{A}$$

$$t_r = \frac{Q_{gd}+Q_{gs2}}{I_{g,on}} = \frac{9\,\text{nC}}{1.56} = 5.8\ \text{ns} \qquad t_f = \frac{9\,\text{nC}}{0.67} = 13.4\ \text{ns}$$

Add roughly 5 ns each for common-source inductance in a PDFN layout. This gives t_r ≈ 11 ns and t_f ≈ 18 ns.

### 2.2 Loss terms (per motor; only the PWM'd half-bridge hard-switches)

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw | 0.5·25.2·80·29e-9·48e3 = **1.40 W** |
| C_oss discharge | ½·C_oss·V²·f_sw | 0.5·1e-9·635·48e3 = **0.015 W** |
| Reverse recovery | Q_rr·V·f_sw | 30e-9·25.2·48e3 = **0.036 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw | 0.8·80·200e-9·48e3 = **0.61 W** |
| Gate drive (all 6 FETs; dissipated mostly in driver/R_g) | 6·Q_g·V_drv·f_sw | 6·30e-9·10·48e3 = **0.086 W** |
| **Total switching, per motor** | | **≈ 2.15 W** |

Notes on the switching terms:

- **Dead-time loss is the second-largest switching term.** Reducing t_dt to 50 ns (AM32 allows tuning) saves about 0.3 W per motor. Verify against shoot-through with a scope at 80 A.
- **Frequency trade-off.** Halving f_sw to 24 kHz saves ~1 W per motor but raises current ripple. For low-inductance nano motors (L ≈ 15–30 µH), 48 kHz is justified:
