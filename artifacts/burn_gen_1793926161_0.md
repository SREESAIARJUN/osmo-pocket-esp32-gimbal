### Critical architecture note

The H743 should **not** run commutation. ArduPilot does not implement sensorless six-step / BEMF commutation for four motors on the flight MCU.

The correct architecture is therefore:

- **H743 (flight controller):** sends DShot600 commands and receives bidirectional eRPM telemetry.
- **4-in-1 ESC:** four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32), each driving a three-phase gate driver plus six MOSFETs.

The 48 kHz PWM is generated by the ESC MCUs, not by the H743.

## 1. Conduction Loss Model

### 1.1 Current paths (trapezoidal six-step with synchronous complementary PWM)

During each 60° commutation sector, two phases carry current I:

| Switch | Conduction fraction within sector |
|---|---|
| Phase A high-side (PWM) | D |
| Phase A low-side (synchronous freewheel) | 1 − D |
| Phase B low-side (static ON) | 1 |

Total per-motor conduction loss:

$$P_{cond} = I^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{DS}(T_j)$$

This result is **independent of duty cycle**, which makes it a clean worst-case burst metric.

The temperature dependence of R_DS(on) is:

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

### 1.2 Per-FET average

Each FET is active for 1/3 of the electrical cycle. The electrical frequency (kHz range) is much faster than the die thermal time constant (milliseconds), so the average dissipation is valid for thermal purposes:

$$P_{FET,avg} = \frac{2 I^2 R_{DS}}{6} = \frac{I^2 R_{DS}}{3}$$

### 1.3 Self-consistent junction temperature iteration (80 A)

Loss raises T_j, which raises R_DS(on), which raises loss. The iteration converges as follows:

| Iteration | T_j assumed | R_DS (mΩ) | P_cond/motor (W) | P_FET (W) |
|---|---|---|---|---|
| 0 | 25 °C | 1.50 | 19.2 | 3.20 |
| 1 | 90 °C | 2.04 | 26.1 | 4.35 |
| 2 | 110 °C | 2.20 | 28.2 | 4.70 |
| 3 (converged at burst end) | 115 °C | 2.24 | 28.7 | 4.78 |

**Design value: P_cond ≈ 28.5 W per motor at 80 A.**

Note on RMS current: with an L/R motor current ripple Δi, use

$$I_{rms}^2 = I^2 + \frac{\Delta i^2}{12}$$

At 48 kHz with typical motor inductance (around 10 µH), the ripple term adds less than 1%.
