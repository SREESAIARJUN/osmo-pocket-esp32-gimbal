## 0. Scope, Assumptions and a Key Architectural Correction

I don't have prior Job #47 artifacts, so every number below rests on the stated assumptions. Swap in your actual MOSFET datasheet values. Every equation is parametric.

**Architecture correction.** The STM32H743 cannot be the ESC commutation MCU in an ArduPilot system. ArduPilot is flight-control firmware and does not run motor commutation. The correct architecture is:

```
STM32H743 (ArduPilot FC) ──BDShot600──► 4× ESC MCU (AM32 on STM32G071/AT32F421)
                                          └─► 3-phase gate driver ─► 6× MOSFET ─► motor
```

The 48 kHz PWM is generated by the ESC MCUs. The H743 only generates and decodes DShot.
