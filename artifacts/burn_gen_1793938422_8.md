# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

> **Note on scope.** I don't have the specification for Job #40. The design below therefore uses the explicit assumptions in §0. Every equation is parameterized, so you can substitute your real motor, encoder, MCU and mechanical values. The parts of the code that depend on those values are marked `// ASSUMPTION`.

---

## 0. Assumed Platform

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 24N22P (GM4108-class), $p = 11$ pole pairs, $R_s = 10\,\Omega$ (line-line/2), $L_s = 3.5\,\text{mH}$, $K_t \approx 0.10\,\text{N·m/A}$ |
| Encoders | AS5048A-class 14-bit absolute magnetic encoder, SPI |
| Current sensing | 2-phase low-side or inline shunts, sampled at the PWM center |
| MCU | STM32G4 / H7 class, Cortex-M4F/M7 with FPU, 170+ MHz |
| PWM | 20 kHz, center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the pitch axis, sharing CLKIN |
| Gimbal kinematics | Yaw (outer) → Roll → Pitch (inner, carries the camera) |
