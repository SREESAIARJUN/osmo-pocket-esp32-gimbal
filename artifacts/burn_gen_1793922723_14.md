# STM32H743 Nano FC + 4-in-1 ESC (Job #38): Loss Model, Thermal Budget, Bidirectional DShot600 DMA Plan, and Reference Netlist

## 0. Scope, Assumptions, and Architectural Corrections

I have no prior Job #38 specification, so every input parameter is stated explicitly. Replace them with your BOM values and the equations still hold.

Three issues need resolving before any detailed design:

1. **The H743 should not drive the bridges directly.**
   - The H743 has two advanced timers (TIM1 and TIM8) with complementary outputs. That is enough for only 2 three-phase bridges, not 4.
   - ArduPilot does not run motor commutation.
   - The correct architecture is: H743 running ArduPilot → bidirectional DShot600 → 4× ESC MCUs (e.g., AT32F421 running AM32, which supports 48 kHz PWM and bidirectional DShot) → 3-phase gate drivers → 24 MOSFETs.
   - This is how all production "FC + 4-in-1" stacks work.

2. **"Nano" (20×20 mm) cannot carry 80 A burst per motor.**
   - The physics is shown in §3.
   - I model a 30.5×30.5 mm ESC board, which is the minimum credible size.
   - The 20×20 FC can be stacked on top of it.

3. **"80 A burst" means phase current per motor at 6S.**
   - I evaluate the worst case: all four motors at 80 A simultaneously.

## 1. Conduction Loss Model

**Commutation pattern.** The ESC uses 6-step (trapezoidal) commutation with complementary (synchronous-rectified) PWM.

- At every instant, current flows through exactly one upper-path FET and one lower-path FET in series.
- During PWM off-time, the synchronous low-side FET replaces the high-side FET.
- As a result, the series path is always 2·R_ds regardless of duty cycle D.

**Hot on-resistance:**

R_ds,hot = k_T · R_ds,25 = 1.6 × 1.5 mΩ = 2.4 mΩ

**Conduction loss per motor (bridge total):**

P_cond,bridge = I_ph² · 2·R_ds,hot = 80² × 4.8 mΩ = **30.7 W**

**Per-FET distribution.** Each phase leg is active for 2/3 of the electrical cycle. Within its 1/3 "high" window, the leg splits conduction between its HS and LS FETs as D / (1−D).

The worst-case FET is the HS FET at D → 1:

P_cond,FET,max = I_ph² · R_ds,hot · (1/3) = 6400 × 2.4 mΩ / 3 = **5.12 W**
