## 1. FOC Current Loop

### 1.1 Transforms (power-invariant amplitude form, k = 2/3)

**Clarke transform** (balanced three-phase, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32\,p\,\lambda_m\,i_q \equiv K_t\, i_q$$

### 1.3 Current PI by pole-zero cancellation

The plant per axis is G(s) = 1/(Ls+R). Choose:

$$C(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_{bw},\quad K_i = R\,\omega_{bw}$$

The open loop then becomes ω_bw/s, so the closed loop is first-order with bandwidth ω_bw.

- Choose ω_bw ≤ 2π·f_s/20, which is about 2π·1 kHz at 20 kHz.
- Add decoupling feedforward to remove the cross-coupling terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Discrete PI (backward Euler) with back-calculation anti-windup:**

$$u_k = K_p e_k + I_k + u^{ff}_k$$

$$u^{sat}_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}T_s\,(u^{sat}_k - u_k)$$

Use K_aw ≈ K_i/K_p. Saturation is applied to the voltage-vector magnitude:

$$\|v_{dq}\| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max}$$

Use m_max ≈ 0.95. When limiting, prioritize v_d, then give v_q the remaining voltage budget.

### 1.4 SVPWM (min-max zero-sequence injection, equivalent to 7-segment SVPWM)

Phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

Duty cycles:

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.5 Voltage-mode fallback (no current sensing)

If the board has no current sensing, estimate the current-equivalent command directly:

$$v_q = R\,i_q^* + \omega_e\lambda_m,\qquad v_d = -\omega_e L\, i_q^*$$

The velocity loop then absorbs the model error.

## 2. Cascaded Angle → Velocity Control

### 2.1 Structure

The cascade runs from the attitude reference to the motor torque:

$$\theta^* \;\rightarrow\; \text{angle P(I)} \;\rightarrow\; \omega^* \;\rightarrow\; \text{velocity PI} \;\rightarrow\; i_q^* \;\rightarrow\; \text{current PI} \;\rightarrow\; \text{FOC}$$

Feedforward terms enter at two points:

- the reference angular rate ω_ff, added to the velocity command;
- the cogging torque and inertial acceleration, added to i_q*.

### 2.2 Bandwidth separation rule

Each loop must be at least 4–5× slower than the loop inside it:

$$\omega_{c,\theta} \le \tfrac15\omega_{c,\omega} \le \tfrac1{25}\omega_{c,i}$$

**Typical bandwidths for a gimbal:**

| Loop | Bandwidth | Limiting factor |
|---|---|---|
| Current | ~1 kHz | — |
| Velocity | 80–150 Hz | Structural modes of the arm, usually 150–400 Hz |
| Angle | 15–30 Hz | Velocity loop |

### 2.3 Velocity loop

The mechanical plant is:

$$J\dot\omega = K_t i_q - b\,\omega - \tau_{dist}$$

Its transfer function from current to rate is ω/i_q = K_t/(Js+b).

**PI by symmetric optimum.** Place the crossover ω_c with phase margin φ_m:

$$a = \frac{1+\sin\varphi_m}{\cos\varphi_m},\qquad K_{p,\omega} = \frac{J\,\omega_c}{K_t},\qquad K_{i,\omega} = K_{p,\omega}\frac{\omega_c}{a^2}$$

With φ_m = 50°, a ≈ 2.75.

**Velocity measurement.** Two signals are available:

- **Primary (inertial):** the gimbal axis rate, taken as the camera-frame body rate (fused from both IMUs) projected onto that joint's axis. This is the quantity we want stabilized.
- **Secondary (encoder):** the encoder derivative, smoothed by a PLL observer:

$$\hat\theta_{k+1} = \hat\theta_k + T_s\hat\omega_k + T_s k_1 e_k$$

$$\hat\omega_{k+1} = \hat\omega_k + T_s k_2 e_k$$

$$e_k = \text{wrap}(\theta_{enc,k} - \hat\theta_k)$$

Gains: k_1 = 2ζω_n and k_2 = ω_n², with ω_n ≈ 2π·500 Hz and ζ = 1.

**Output filtering.** Pass the velocity PI output through a 2nd-order LPF (or notch) at the arm's first structural mode before it becomes i_q*.
