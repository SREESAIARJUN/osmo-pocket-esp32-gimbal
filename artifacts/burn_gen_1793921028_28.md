## 0. Architecture Clarification

The STM32H743 does not drive the gates. ArduPilot has no field-oriented or 6-step motor control. The board is:

```
┌──────────────────── FC section ──────────────────┐   ┌──────── ESC section (×4) ──────────┐
│ STM32H743VIT6 @ 400 MHz (ArduPilot)              │   │ AT32F421K8U7 (AM32) or EFM8 (Bluejay)│
│  TIM3/TIM5 → DShot600 bidir (1 wire/motor)       ├──►│  TIM1 CH1-3/CH1N-3N @ 48 kHz         │
│  IMU (SPI), baro (I2C), OSD, SD (SDMMC)          │   │  → 3-phase gate driver (e.g. FD6288Q)│
└──────────────────────────────────────────────────┘   │  → 6× N-MOSFET half-bridges          │
                                                       └──────────────────────────────────────┘
```

The 48 kHz PWM is an ESC-firmware parameter (AM32 `PWM_FREQ`). It is not an H743 timer.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent resistance

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.3 × 1.45 = **1.885 mΩ**.

### 2.2 Six-step trapezoidal commutation with synchronous rectification

During each 60° sector, phase X is PWM'd (complementary HS/LS) and phase Y's low side is held on.

- **PWM leg:** current alternates between HS (fraction D) and LS (fraction 1−D):
$$P_{leg,PWM}=I^2R_{ds}\,D+I^2R_{ds}(1-D)=I^2R_{ds}$$
- **Return leg:** $$P_{leg,ret}=I^2R_{ds}$$

Total bridge conduction loss is therefore duty-independent:

$$\boxed{P_{cond}=2\,I_{ph}^2\,R_{ds}(T_j)+I_{ph}^2R_{Cu}}$$

For FOC/sinusoidal drive the equivalent is $P=\tfrac{3}{2}\hat I^2 R_{ds}$ for three legs with peak $\hat I$. That is the same order of magnitude.
