I don't have Job #57's spec sheet, so the design is parameterized. The defaults below are typical for a gimbal. Replace anything marked `// CONFIG`.

## 1. Control Architecture

```
          ┌──────────────── 1 kHz ────────────────┐ ┌────── 4 kHz ──────┐ ┌──────── 20 kHz ────────┐
q_ref ──► Quaternion error ─► Angle P + ω_ff ─► ω*_j ─► Velocity PI ─► i_q* ─(+)─► Current PI (d,q) ─► SVPWM ─► Motor
             ▲                                  ▲                          ▲ i_q,ff (anti-cogging)  ▲ θ_e (encoder)
  Mahony AHRS (fused)               ω_j = J⁻¹(θ)·ω_cam (fused gyro)        └── Fourier FF(θ_m, ω)
             ▲                                  ▲
  2× ICM-42688-P ─► on-chip AAF+notch ─► align/weight/vote ─► dynamic notches ─► LPF
```

Bandwidth separation rule: ω_c,current ≥ 5·ω_c,vel ≥ 5·ω_c,angle.

Typical targets:
- Current loop: 1.5–2 kHz
- Velocity loop: 80–150 Hz
- Angle loop: 15–30 Hz

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

Electrical angle from the mechanical encoder angle:

θ_e = p·(θ_m − θ_off) mod 2π

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 2.2 Plant and Decoupled PI

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
