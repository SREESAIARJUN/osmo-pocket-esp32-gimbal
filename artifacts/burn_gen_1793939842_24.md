# STM32H743 Nano FC + Integrated 4-in-1 ESC (Job #6): Architecture, Loss Model, DShot/DMA Allocation, Netlists

## 0. Architecture and Assumptions

### Architectural clarification

ArduPilot on the H743 does **not** commutate the motors. The correct partitioning is:

```
[STM32H743 FC] --4x bidir DShot600--> [4x ESC MCU (AT32F421 / STM32G071, AM32 fw)]
                                              |-- 3-phase gate driver --> 6x N-MOSFET --> motor
```

The 48 kHz switching frequency is an ESC-firmware parameter (AM32 `PWM frequency`). The H743 only owns DShot timing, DMA, and eRPM decode. Mixing these domains, for example running FOC on the H743, is not supported by ArduPilot and would wreck the scheduler.
