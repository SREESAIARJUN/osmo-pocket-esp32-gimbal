# STM32H743 Nano FC + 4-in-1 ESC: 80A Burst Thermal, 48kHz Switching, and Bidirectional DShot600 DMA Model

## 0. Scope, Assumptions, and a Feasibility Warning

Two clarifications shape the rest of the model.

**1. Architecture.** The STM32H743 does not commutate the motors directly. The standard architecture, assumed here, is:

```
STM32H743 FC (ArduPilot) ──bidir DShot600 ×4──► 4× ESC MCU (AT32F421 / AM32) ──► 3-phase gate driver ──► 6 MOSFETs/motor
```

- The 48kHz PWM is generated by the ESC MCUs.
- DShot and its DMA run on the H743.

**2. 80A burst feasibility.** 80A per motor on a 20×20mm nano board is thermally impossible beyond a few seconds, and Section 3 shows why. I model both cases:

- **Case A:** 80A per motor burst (the literal requirement).
- **Case B:** 80A total burst, i.e. 20A per motor (realistic for nano).

**Baseline parameters (state these explicitly in the design file):**

| Parameter | Value |
|---|---|
| Bus voltage | 6S, V_bus = 25.2V max (22.2V nominal) |
| MOSFET class | 40V N-ch, PDFN 3.3×3.3, R_ds(on) = 0.9 mΩ @ 25°C, Q_g = 60 nC, Q_rr = 50 nC, Q_oss = 50 nC |
| R_ds(on) temperature coefficient | ≈ 1.5× at T_j = 125°C → R_hot ≈ 1.35 mΩ |
| Edge times (FD6288-class driver, R_g ≈ 10Ω) | t_r ≈ t_f ≈ 20 ns |
| Dead time | t_dt = 100 ns per edge |
| Body diode V_f | 0.8V |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, f_sw = 48 kHz |
| PCB | 8-layer, 2 oz copper |

## 1. Conduction Loss Model

In 6-step commutation, two phase legs are active in each sector:

- **PWM leg:** the high-side FET conducts for duty D. With synchronous rectification, its complementary low-side conducts for (1−D).
- **Return leg:** the low-side FET conducts the full period.

Per-motor conduction loss is therefore independent of D (when synchronous):

$$
P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)
$$

Temperature dependence:

$$
R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.005\ /\mathrm{K}
$$

Copper path loss (busbar plus phase pad, R_cu ≈ 0.4 mΩ per motor path):

$$
P_{cu} = I^2 R_{cu}
$$

| | Case A (80A/motor) | Case B (20A/motor) |
|---|---|---|
| P_cond (hot) | 2·6400·1.35m = **17.3 W** | 2·400·1.35m = **1.08 W** |
| P_cu | 6400·0.4m = **2.56 W** | **0.16 W** |

Because losses raise T_j, which raises R_ds, the loss feeds back on itself. Solve P(T_j) and T_j(P) iteratively; in Case A this does not converge without a time limit, which Section 3 quantifies.

## 2. Switching Loss Model at 48 kHz

The hard-switched PWM leg contributes four loss components.

**Overlap (V·I crossover) loss:**

$$
P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw}
$$

**Reverse recovery** (the low-side body diode after dead time):

$$
P_{rr} = Q_{rr} V_{bus} f_{sw}
$$

**Output capacitance:**

$$
P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw}
$$

**Dead-time body-diode conduction** (two edges per period):

$$
P_{dt} = V_f\, I\, (2 t_{dt}) f_{sw}
$$

**Gate drive** (6 FETs, though in 6-step only about 2 actively switch; worst case shown). This loss is dissipated in the driver and gate resistors, not the FETs:

$$
P_{gate} = Q_g V_{gs} f_{sw} \cdot N
$$

| Term | Case A (80A) | Case B (20A) |
|---|---|---|
| P_sw = 0.5·25.2·I·40ns·48k | **1.94 W** | 0.48 W |
| P_rr = 50n·25.2·48k | 0.06 W | 0.06 W |
| P_oss | 0.03 W | 0.03 W |
| P_dt = 0.8·I·200ns·48k | **0.61 W** | 0.15 W |
| P_gate (2 active FETs, 10V) | 0.06 W | 0.06 W |
| **Switching subtotal** | **2.70 W** | **0.78 W** |

**Per-motor total:**

| | Case A | Case B |
|---|---|---|
| Conduction + copper + switching | 17.3 + 2.56 + 2.70 ≈ **22.6 W** | 1.08 + 0.16 + 0.78 ≈ **2.0 W** |
| Four motors | **≈ 90 W** | **≈ 8 W** |
| Efficiency at 25.2V | 4·80·25.2 = 8064 W in → **98.9%** | 2016 W in → **99.6%** |

Efficiency looks excellent, but 90 W concentrated in 4 cm² is the actual problem.

**Bus capacitor ripple current** (per motor, worst case at D = 0.5):

$$
I_{C,rms} = I\sqrt{D(1-D)}
$$

- Case A: 40A rms per motor.
- Case B: 10A rms per motor.

These loads cannot be met with MLCCs on 20×20mm. Size the external low-ESR electrolytic (≥ 1000 µF / 35V) plus 4× 10 µF/50V X7R per phase bridge.

## 3. Thermal Model

### 3.1 Network (per FET, lumped Foster to Cauer approximation)

```
T_j ──R_jc(1.2 K/W)── T_case ──R_cs(1.5 K/W, solder+pad+vias)── T_board ──R_ba── T_air
          │                                  │
        C_j (~0.05 J/K)                    C_board (~3 J/K total)
```

### 3.2 Board-to-air resistance

- Forced convection in prop wash: h ≈ 100 W/m²K.
- Area: A = 2·(0.02)² = 8×10⁻⁴ m².

$$
R_{ba} = \frac{1}{hA} = \frac{1}{0.08} = 12.5\ \mathrm{K/W}
$$
