**Architecture correction.** The H743 does not commutate motors directly. A production design uses:

- **H743**, running ArduPilot, which generates bi-directional DShot600.
- **Four ESC MCUs** (AT32F421 or STM32G071, running AM32) that generate the 48 kHz PWM, do BEMF commutation, and return eRPM telemetry.

This split is assumed throughout.
