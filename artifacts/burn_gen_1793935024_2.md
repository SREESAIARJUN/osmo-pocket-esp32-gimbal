# STM32H743 FC + 80 A 4-in-1 ESC: Engineering Reference Model

**Scope:** Power-stage loss model, thermal model, ArduPilot bidirectional DShot600 timer/DMA plan, and reference netlists.

---

## 0. Assumptions and Architectural Corrections

I don't have access to any internal "Job #31" documentation, so every parameter below is stated explicitly. Substitute your actual BOM values into the equations; the structure of the model holds either way.

Two corrections to the brief:

1. **The STM32H743 does not drive the MOSFETs.** In every production 4-in-1 design, the H743 runs ArduPilot as the flight controller. Each motor channel has its own ESC MCU, typically an AT32F421, STM32G071, or GD32 running AM32 or BLHeli_32. The H743 emits DShot600 to those four MCUs and decodes their bidirectional eRPM replies. The netlists below reflect this.
2. **"Nano" and "80 A burst" conflict thermally.** On a 20×20 mm board, 80 A per channel is not physically sustainable beyond a few seconds, as Section 3 shows quantitatively. Credible 80 A-burst products are 30×30 mm or larger with 6–8 oz total copper. I model a 30.5×30.5 mm ESC stacked with the FC. If the target really is 20×20, derate to roughly 45–55 A burst.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha\,(T_j - 25)]$$

At T_j = 100 °C: R = 1.0 × (1 + 0.005·75) = **1.375 mΩ**.

### 1.2 Per-motor conduction loss

In 6-step drive, two phase legs carry current at any instant. In the PWM leg, the high side conducts for D and the complementary low side for (1−D). In the return leg, the low side is held on. The current path therefore always passes through exactly two channel resistances:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{DS}(T_j) + I_{ph}^2\,R_{Cu}$$

| Term | Calculation | Result |
|---|---|---|
| MOSFET | 2 × 80² × 1.375 mΩ | **17.6 W** |
| PCB copper, R_Cu ≈ 0.25 mΩ path | 80² × 0.25 mΩ | 1.6 W |
| **Subtotal per motor** | | **19.2 W** |

### 1.3 Thermal runaway check

Conduction loss rises with T_j, which raises T_j further. The closed-loop steady state is:

$$T_j = T_a + R_{\theta}\,P(T_j) \;\Rightarrow\; T_j = \frac{T_a + R_\theta\,k\,(1-25\alpha)}{1 - R_\theta\,k\,\alpha},\qquad k = 2I^2R_{25}$$

The system is stable only if **R_θ·k·α < 1**. Here k = 12.8 W, so the condition is R_θ < 15.6 K/W per motor-equivalent. This is satisfied. The real constraint is absolute temperature, not runaway.

### 1.4 Per-FET distribution

Over an electrical cycle, each of the 6 FETs conducts about 1/3 of the time. The average is therefore about 17.6/6 ≈ 2.9 W per FET. However, the electrical period (about 0.3–1 ms at high eRPM) is comparable to the die thermal time constant (about 1 ms). Design to an instantaneous peak of I²R ≈ 8.8 W per conducting FET:

$$\Delta T_{j-c} = 8.8 \times R_{\theta jc}(1.2\ \text{K/W}) \approx 11\ \text{K}$$

## 2. Switching Loss Model at 48 kHz

In 6-step drive, only one leg switches at any time. Per motor:

| Mechanism | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·40 ns·48 k | **1.94 W** |
| Reverse recovery | V·Q_rr·f_sw = 25.2·50 nC·48 k | 0.06 W |
