# Job #33: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion Design

## 0. Assumptions

I don't have the Job #33 spec, so the design uses the typical gimbal hardware below. Every value is a single `constexpr` or config field in the code.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit magnetic (MT6701 / AS5047P), SPI |
| Current sense | 2-phase low-side shunts (voltage-mode fallback given in §2.6) |
| MCU | STM32G4 / H7 class with single-precision FPU |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro and accel at 8 kHz ODR |

**Loop rates:**

| Loop | Rate | Ts |
|---|---|---|
| Current loop (FOC) | 20 kHz | 50 µs |
| Velocity loop | 4 kHz | 250 µs |
| Angle loop and attitude estimator | 1 kHz | 1 ms |
| IMU sampling, filtering and fusion | 8 kHz, fed into the 4 kHz loop | 125 µs |
