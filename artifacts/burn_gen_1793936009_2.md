## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), single core running all 3 axes |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5.6 Ω, L ≈ 2.1 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701 class) |
| Current sense | 2-shunt low-side, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (IMU-A rigid, IMU-B on a different PCB location/orientation), SPI at 24 MHz |
| PWM | 20 kHz center-aligned |

**Loop rates (cascaded; each loop at least 5× slower in bandwidth than its inner loop):**

```
             1 kHz                  4 kHz                   20 kHz
 θ_ref ──►[ ATTITUDE ]──ω_ref──►[ RATE PI + FF ]──i_q_ref──►[ CURRENT PI (d,q) ]──►SVPWM──►Motor
              ▲                      ▲     ▲                          ▲
       fused attitude q̂      fused gyro ω̂  └── cogging FF i_q,cog     i_a,i_b, θ_e (encoder)
              │                      │
     [ Mahony AHRS ] ◄── [ Dual-IMU fusion + notch/LPF chain ] ◄── 2× ICM-42688-P @ 8 kHz
```

**Target bandwidths:** current ≈ 1.5 kHz, rate ≈ 150 Hz, attitude ≈ 25 Hz.

## 1. Field-Oriented Control: Inner Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi,\qquad \theta_m = \frac{2\pi\,N_{enc}}{2^{14}}$$

θ_off is found at startup by applying a fixed voltage on the d-axis (θ_e = 0) and reading the encoder.

**Latency compensation.** The PWM update is applied about 1.5 sample periods after the encoder is sampled:

$$\theta_e^{comp} = \theta_e + p\,\hat\omega_m\,1.5\,T_s$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}\quad(i_a+i_b+i_c=0)$$

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque:

$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q \qquad (i_d^{ref}=0)$$

### 1.4 PI with pole-zero cancellation

The plant is G(s) = 1/(Ls+R). Choose a PI controller C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero then cancels the plant pole, giving a first-order closed loop:

$$\frac{i}{i^{ref}} = \frac{\omega_c}{s+\omega_c},\qquad \omega_c = 2\pi\cdot1500\ \text{rad/s}$$

**Discrete form** (backward Euler, with decoupling and back-EMF feedforward):

$$v_d^* = K_p e_d + I_d - \hat\omega_e \hat L i_q$$
$$v_q^* = K_p e_q + I_q + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$
$$I_x[k+1] = I_x[k] + K_i T_s e_x + K_{aw}T_s\,(v_x^{sat}-v_x^*)$$

The last equation is back-calculation anti-windup, with K_aw = ω_c.

### 1.5 Voltage limiting and SVPWM

**Circular limit, d-axis priority:**

$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2-v_d^2},\qquad V_{max}=V_{bus}/\sqrt3$$

**Min-max zero-sequence injection** (equivalent to SVPWM):

$$v_{0} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big)$$
$$D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Rate and Attitude Control

### 2.1 Why the gyro, not the encoder, closes the rate loop

The gimbal's objective is the camera's inertial rate. The encoder measures joint rate, which equals inertial rate minus base motion.

- The rate loop uses the fused gyro rate projected onto the joint axis.
- The encoder is used only for commutation, cogging feedforward, and fallback.
