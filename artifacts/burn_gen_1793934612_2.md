| Item | Assumed value |

| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| IMU | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz |
| Kinematics | Yaw → Roll → Pitch (camera) |

**Loop rates:**

```
PWM / current loop (FOC)      20 kHz   Ts_i = 50 µs     (ADC-triggered ISR)
Velocity loop (gyro rate)      4 kHz   Ts_v = 250 µs    (every 5th current tick)
Angle/attitude loop            1 kHz   Ts_p = 1 ms
IMU sampling / filtering       8 kHz   (DRDY-triggered DMA)
Cogging LMS adaptation         4 kHz   (inside the velocity tick, optional)
```

**Bandwidth separation rule:** keep at least a 4–5× ratio between nested loops.

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v}\approx 2\pi\cdot 80\text{ Hz},\quad \omega_{c,p}\approx 2\pi\cdot 15\text{ Hz}$$

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

- θ_m is the mechanical encoder angle.
- θ_off is found at calibration by applying a d-axis current with θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (power-invariant amplitude form, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (PMSM, surface-mount so L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with pole-zero cancellation and decoupling

The zero is placed on the electrical pole R/L, which gives a first-order closed loop with bandwidth ω_c,i:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

The command for axis x ∈ {d, q} is the PI output plus a feedforward term:

$$v_x^* = K_{p,i}e_x + \underbrace{K_{i,i}T_s\sum e_x}_{\text{integrator } I_x} + v_{x,ff}$$

The decoupling feedforward terms are:

$$v_{d,ff} = -\omega_e L i_q,\qquad v_{q,ff} = \omega_e L i_d + \omega_e\lambda_m$$

### 1.6 Voltage limit and anti-windup

**Circular limit.** Limit the voltage vector to the inscribed circle of SVPWM:

$$|v_{dq}| \le V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad m_{max}\approx 0.95$$
