# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the original specification for Job #11. The design below uses these baseline assumptions. Every parameter is a named constant, so you can change it in one place.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sense | 2 low-side shunts per axis (phases a, b) |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate. IMU-B is rotated 180° about Z. Separate SPI buses, both clocked from a shared 32 kHz CLKIN. |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries the camera) |

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC) | 20 kHz | Shunts + encoder |
| IMU sample, filtering, fusion | 8 kHz | ICM-42688-P ×2 |
| Rate (velocity) loop | 4 kHz | Fused gyro, projected to joint axes |
| Attitude (angle) loop | 1 kHz | Mahony quaternion |
