## 0. Architecture Decision (read first)

"STM32H743 4-in-1 ESC" usually means an **AIO (all-in-one) board**: an STM32H743 flight controller running ArduPilot, plus a 4-in-1 ESC section on the same PCB. The H743 is not suited to running the motor commutation itself, because ArduPilot does not do FOC or 6-step commutation.

**Recommended partition**

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 / VIT6 @ 400 MHz | ArduPilot |
| ESC MCUs (×4) | STM32G071 or AT32F421 | AM32 (bidirectional DShot capable) |
| Gate drivers (×4) | FD6288Q-class 3-phase half-bridge driver | n/a |
| Power stage | 24× 40 V N-MOSFET, 3.3×3.3 mm DFN | n/a |
| Link (FC → ESC) | 4× bidirectional DShot600 + 1× ESC telemetry UART (optional) | n/a |
