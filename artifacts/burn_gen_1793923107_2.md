## 0. System Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (e.g. GBM2804H-100T): 12N14P, so pole pairs $p=7$, $R_s≈10\,Ω$, $L_s≈2.5\,\text{mH}$, $K_t≈0.08\,\text{N·m/A}$ |
| Encoder | 14-bit magnetic (AS5048A/MT6701) on each joint |
| MCU | STM32G4/H7-class with FPU, centre-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro/accel ODR 8 kHz |

Loop rates:

```
           1 kHz               4 kHz                        20 kHz
θ_ref ─► [Angle P+FF] ─ω_ref─► [Velocity PI] ─i_q*─►(+)─► [Current PI d/q] ─► SVPWM ─► Motor
           ▲ θ̂ (fused attitude)   ▲ ω̂ (dual-gyro, notched)  ▲ i_cog,ff     ▲ i_abc, θ_e (encoder)
```

The design keeps each outer loop at least 5× slower in bandwidth than the loop inside it. With 20 kHz sampling, the current-loop bandwidth is about 1.5 kHz, the velocity loop about 150–250 Hz, and the angle loop about 30–50 Hz.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, using electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model (SPMSM, $L_d=L_q=L_s$)

$$v_d = R_s i_d + L_s\dot i_d - \omega_e L_s i_q$$

$$v_q = R_s i_q + L_s\dot i_q + \omega_e L_s i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 Current PI with Decoupling and Back-EMF Feedforward

**Pole-zero cancellation tuning.** Setting $K_p/K_i = L_s/R_s$ cancels the electrical pole and gives a first-order closed loop with bandwidth $\omega_c$:

$$K_{p,i} = L_s\,\omega_c,\qquad K_{i,i} = R_s\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10\text{–}20}$$

**Control law in discrete form** (sample period $T_s$, error $e_x = i_x^* - i_x$):

$$v_d^* = K_p e_d + I_d - \omega_e L_s i_q$$

$$v_q^* = K_p e_q + I_q + \omega_e L_s i_d + \omega_e\lambda_m$$

**Integrator update with back-calculation anti-windup**, where $\tilde v$ is the voltage after saturation:

$$I_x[k+1] = I_x[k] + K_i T_s e_x + K_{aw}\,(\tilde v_x - v_x^*),\qquad K_{aw}=\frac{K_i}{K_p}$$

**Circular voltage limit.** SVPWM's linear region is limited to $V_{max}=V_{dc}/\sqrt3$. The limit gives d-axis priority:

$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2-v_d^2}$$

### 1.4 Inverse Park and SVPWM (Min-Max Injection)

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Inverse Clarke:**

$$v_a=v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

**Zero-sequence injection** (this is mathematically identical to SVPWM):

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

**Duty cycle** per phase:

$$D_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

**Delay compensation.** PWM update introduces a 1.5-sample delay. Advance the angle used for the inverse Park accordingly:

$$\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical Plant per Axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Because the current loop is about 10× faster, the velocity loop treats it as unity gain:

$$G_v(s)=\frac{K_t}{Js+B}$$

### 2.2 Velocity PI(D) at 4 kHz

The velocity loop uses **gyro feedback**, not a differentiated encoder signal. Gyro rate is noise-free compared with a differentiated encoder and measures inertial (camera) rate directly, which is the quantity the gimbal must stabilise.

**Joint-rate mapping.** For joint $j$ with axis $\hat a_j$ expressed in the camera frame:

$$\omega_j^{meas} \approx \hat a_j^\top\,\omega_{cam}$$

This is exact for the innermost joint. For the outer joints, use the inverse joint Jacobian: $\dot{\mathbf q} = \mathbf J^{-1}(\mathbf q)\,(\omega_{cam} - \mathbf R\,\omega_{base})$.
