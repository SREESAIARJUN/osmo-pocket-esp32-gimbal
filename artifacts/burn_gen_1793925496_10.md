## 0. Architecture Decisions and Assumptions

Three facts change the analysis:

1. **The STM32H743 does not commutate the motors.** No production BLDC firmware (AM32, Bluejay, BLHeli_32) runs on the H7. Like every shipping "FC + 4-in-1" stack, the board uses:
   - **FC domain:** STM32H743 running ArduPilot. It generates bidirectional DShot600 on 4 timer channels.
   - **ESC domain:** 4× dedicated ESC MCUs. The baseline is AT32F421 or STM32G071 running AM32. Each drives one 3-phase bridge through a gate driver.
   - The DShot link is an on-board trace from the H7 timer pin to the ESC MCU's input-capture pin.

2. **80 A per channel on a 20×20 mm board is a transient rating, not a continuous one.** Section 3 shows this numerically. The model below finds the burst duration the hardware can actually sustain.

3. **Part numbers are reference classes.** Where a part is named, it represents a parameter class. Every value must be re-verified against the current datasheet before layout freeze.
