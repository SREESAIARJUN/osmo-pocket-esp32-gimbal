## 0. Architecture and Assumptions

### 0.1 Architectural correction

ArduPilot running on the STM32H743 does not commutate motors. A production design partitions the system as follows:

```
[STM32H743 FC, ArduPilot] --4× bidir DShot600--> [4× ESC MCU, AM32/BLHeli_32] --> [3-ph gate driver] --> [6× MOSFET] --> motor
```

The H743 handles timers and DMA for DShot (§4). Each ESC channel has its own MCU (AT32F421 or STM32G071 class) generating the 48 kHz PWM and six-step commutation. The loss model in §1–3 applies per ESC channel.
