## 0. Architecture Correction (Read First)

The H743 should **not** run the motor commutation itself. ArduPilot has no ESC/FOC firmware path. Driving 12 MOSFETs at 48 kHz with 6-step commutation, BEMF sensing, and dead-time control for 4 motors would consume the advanced timers and ADCs the flight stack needs.

The correct topology is a **two-tier system**:

```
[STM32H743 FC, ArduPilot] --4x bidirectional DShot600--> [4x ESC MCU (AM32 / BLHeli_32)]
                                                               |
                                              [3-ph gate driver] -> [6x MOSFET] -> motor
```

Recommended ESC MCU: AT32F421 or STM32G071, running AM32 (open source, supports bidirectional DShot and EDT telemetry). Everything below assumes this topology.

## 2. Conduction Loss Model

### 2.1 Current Path

In 6-step trapezoidal commutation with synchronous rectification, two phase legs carry current at any instant:

- **PWM-on interval (duty D):** current flows through HS(phase A) → motor → LS(phase B).
- **PWM-off interval (1 − D):** current flows through LS(phase A) (sync-rect) → motor → LS(phase B).

Either way, current passes through exactly **two MOSFET channels** at all times, excluding dead time. Motor inductance keeps current nearly constant within a PWM period, so I_rms ≈ I_b.
