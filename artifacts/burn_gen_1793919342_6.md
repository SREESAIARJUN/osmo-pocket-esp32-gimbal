## 0. Architecture Clarification and Assumptions

**Architecture.** In a production 4-in-1 stack, the STM32H743 does not drive the MOSFETs directly. Each ESC channel, or a shared ESC MCU, runs AM32 or BLHeli_32 on a small Cortex-M0+ part (AT32F421 or STM32G071). That MCU generates the 48 kHz complementary PWM. The H743 runs ArduPilot and talks to the ESCs over bi-directional DShot600. This document models both layers.

**Assumptions.** All MOSFET parameters below are parametric placeholders. Substitute your selected part's datasheet values; every equation is written so you can re-run it.

## 1. Conduction Loss Model

### 1.1 Six-step commutation current paths

Assume 120° trapezoidal commutation with synchronous rectification (complementary PWM). Within any commutation sector, current I flows as follows:

- **PWM leg, high side (HS_A):** conducts for duty D.
- **PWM leg, low side (LS_A, synchronous):** conducts freewheel current for (1 − D).
- **Return leg, low side (LS_B):** held on for 100 % of the sector.

```
P_cond,ch = I²·R_hot·[D + (1−D) + 1] = 2·I²·R_hot          (duty-independent)
```

### 1.2 Temperature dependence

```
R_hot(T_j) = R_ds(on),25 · [1 + α(T_j − 25)],   α ≈ 0.006 /K  →  k_T(125 °C) ≈ 1.6
R_hot = 1.6 mΩ
```

Add the copper path from the phase pad through the via field to the busbar. Typical values are 0.3–0.5 mΩ per path on a 2 oz, 8-layer board. Use 0.4 mΩ:

```
R_path = 2·R_hot + R_Cu = 2(1.6) + 0.4 = 3.6 mΩ
```

### 1.3 Numerical result at 80 A

```
P_FET,cond = 2 · 80² · 1.6e-3 = 20.48 W  per channel
P_Cu       = 80² · 0.4e-3     =  2.56 W  per channel (spread in PCB)
```

### 1.4 RMS correction for current ripple

```
ΔI_pp = V_bus·D(1−D) / (L_phase·f_sw)
```

Take L_phase = 15 µH (typical for a low-kV 5" motor) and the worst case D = 0.5:

```
ΔI_pp = 25.2 · 0.25 / (15e-6 · 48e3) = 8.75 A
I_rms² = I² + ΔI_pp²/12 = 6400 + 6.4  →  +0.1 %
```

The ripple correction is negligible at 48 kHz. This is one of the arguments for 48 kHz over 24 kHz.

### 1.5 Thermal-runaway stability criterion

```
dP/dT_j · R_θ(j→sink) < 1
dP/dT_j = 2·I²·R_25·α = 2·6400·1e-3·0.006 = 0.077 W/K
```

Stability then requires R_θ < 13 K/W. This is satisfied, so the board has no electrothermal runaway at 80 A. The limit is energy (time), not stability.
