# STM32H743 AIO Nano FC + 4-in-1 ESC: Power, Thermal, and DShot Architecture

## 0. Architecture Assumptions

The STM32H743 cannot directly commutate four BLDC motors at 48 kHz while also running ArduPilot. This design therefore uses the standard AIO split:

> ⚠️ **Key finding up front:** 80 A per motor on a nano-format board is a **1–3 second burst rating, not a continuous one**. The math below shows why. Spec sheets and marketing should say so explicitly.

## 1. Conduction Loss Model

### 1.1 Conduction topology

The ESCs use 6-step trapezoidal drive with complementary (synchronous-rectified) PWM. At any instant, exactly two MOSFETs carry the phase current I:

- **PWM on:** HS(phase A) and LS(phase B).
- **PWM off:** LS(phase A) via sync rectification, and LS(phase B).

So, independent of duty cycle D:

$$P_{cond} = I_{rms}^2 \cdot 2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature-dependent resistance

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At the design point T_j = 110 °C:

$$R = 1.5\,\text{mΩ} \times (1 + 0.006 \times 85) = 2.27\,\text{mΩ}$$

### 1.3 Ripple contribution to RMS current

Peak-to-peak ripple occurs at D = 0.5. Assume line-to-line motor inductance L_LL ≈ 15 µH (typical 28xx-class 6S motor):

$$\Delta I = \frac{V_{bus} D(1-D)}{L_{LL} f_{sw}} = \frac{25.2 \times 0.25}{15\,\mu\text{H} \times 48\,\text{kHz}} = 8.75\,\text{A}_{pp}$$

$$I_{rms} = I\sqrt{1+\tfrac{1}{12}\left(\tfrac{\Delta I}{I}\right)^2} = 80 \times 1.0005 \approx 80.04\,\text{A}$$

The ripple contribution is negligible at 48 kHz. That is one argument for 48 kHz over 24 kHz.

### 1.4 Result

$$P_{cond} = 80^2 \times 2 \times 2.27\,\text{mΩ} = \mathbf{29.1\,W\ per\ channel}$$

That is 14.5 W per conducting FET.

| Additional conduction term | Value |
|---|---|
| Per-phase copper (≈0.15 mΩ effective path) | 80² × 0.3 mΩ ≈ 1.9 W/channel |
| Shared current shunt, 0.1 mΩ at 320 A total | 10.2 W total (**use 0.1 mΩ or a Hall sensor; 0.25 mΩ shunts are a hot-spot risk**) |

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing leg commutates each cycle. That leg has one hard-switched HS FET and one LS sync-rectifier FET.

### 2.1 Gate drive transition times (Miller plateau)

Assume 12 V gate drive. The FD6288 output is current-limited, but at these values R_G dominates.

- Turn-on: I_on = (12 − 3.5) / 11 Ω = 0.77 A, so t_r = Q_gd / I_on = **10.4 ns**
- Turn-off: I_off = 3.5 / 11 Ω = 0.32 A, so t_f = Q_gd / I_off = **25 ns**

Turn-off is the slow edge. A diode plus 3.3 Ω turn-off bypass is recommended (see netlist).

### 2.2 Loss terms per channel

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·35 ns·48 k | **1.69 W** |
| Output capacitance | Q_oss·V·f = 40 nC·25.2·48 k | 0.048 W |
| Reverse recovery | Q_rr·V·f = 30 nC·25.2·48 k | 0.036 W |
| Dead-time diode conduction | V_f·I·2t_dt·f = 0.8·80·2·100 ns·48 k | **0.61 W** |
| Gate charge (driver loss) | Q_g·V_drv·f·2 = 40 nC·12·48 k·2 | 0.046 W |
| **Total switching** | | **≈ 2.43 W** |

Dead-time loss is the second-largest term. In AM32, set dead time to the minimum value that is still shoot-through-safe across temperature, typically 60–100 ns. Validate it with a scope on the switch node.
