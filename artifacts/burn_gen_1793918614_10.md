# STM32H743 AIO Nano FC + 4-in-1 ESC: System Architecture Model

**Job #0: Reference Architecture, Rev A**

## 0. Scope, Assumptions, and Feasibility Finding

### 0.1 Architecture

The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors directly. Each of the four motor channels has its own ESC MCU (AM32-class, e.g. AT32F421 or STM32G071), and the H743 talks to each one over bidirectional DShot600. This split is how the industry builds these boards. Running 4× sensorless commutation at 48 kHz on the flight MCU alongside ArduPilot's scheduler would be a real-time liability.

### 0.3 Headline Finding

At 4 × 80 A simultaneous, a nano board dissipates about **94 W**. This is thermally sustainable for only **~2–3.5 seconds** (derivation in §3). "80 A burst" on this form factor must be specified as **≤2 s**, enforced by firmware current and thermal limiting. It cannot be treated as a 10 s rating.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent Rds(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_DS = 1.0 × (1 + 0.0045 × 100) = **1.45 mΩ**.

### 1.2 Current Path in Complementary 6-Step

During each 60° sector, one high-side switch (HS) PWMs and one low-side switch (LS) of another phase stays on.

- **PWM-on (duty D):** current flows through HS_x → motor → LS_y. That is 2 FETs in series.
- **PWM-off (1−D):** current freewheels through LS_x (synchronous rectifier) → motor → LS_y. That is also 2 FETs in series.

The bus therefore always has **2 × R_DS** in the current path, independent of D (dead time excepted):

$$P_{cond,bridge} = I_{ph}^2 \cdot 2R_{DS}(T_j)$$

$$P_{cond,bridge} = 80^2 \times 2 \times 1.45\times10^{-3} = \mathbf{18.56\ W\ per\ motor}$$
