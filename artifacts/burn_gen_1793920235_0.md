# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

## 0. Assumptions

I don't have the Job #12 spec sheet, so this design uses typical gimbal hardware. Every assumption is a constant in `GimbalConfig` and can be changed there.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (GM4108-class): 11 pole pairs, 12N14P, R ≈ 10 Ω, L ≈ 4 mH (phase-to-neutral) |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | STM32G474 / H7-class with FPU, center-aligned PWM at 20 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle 1 kHz · Attitude 1 kHz |
| IMUs | 2 × ICM-42688-P on separate SPI buses, 8 kHz ODR, ±2000 dps, ±16 g |
| Cogging | 12 slots and 14 poles, so LCM(12,14) = 84 cogging cycles per mechanical revolution |

## 1. Control Architecture

```
 Setpoint q_ref ──► [Attitude error → per-axis θ_ref]
                          │
                          ▼  1 kHz
   θ_meas ───────► [Angle P + vel FF] ── ω_ref ──┐
                                                  ▼  4 kHz
   ω_meas (PLL + gyro blend) ──────────► [Velocity PI + accel FF] ── i_q,fb
                                                  │
   θ_m ──► [Anti-cogging Fourier FF + LMS] ── i_q,cog ─(+)
                                                  ▼  20 kHz
   i_abc ─► Clarke ─► Park ─► [d/q PI + decoupling] ─► inv-Park ─► SVPWM
```

Bandwidth separation: each outer loop crossover is at most 1/4 to 1/5 of the inner one.
- ω_c,i ≈ 2π·1500 rad/s (current)
- ω_c,v ≈ 2π·80 rad/s (velocity)
- ω_c,θ ≈ 2π·15 rad/s (angle)

## 2. FOC Current Loop Equations

### 2.1 Transforms (amplitude-invariant)

Clarke transform, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 2.2 PMSM model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

Torque, for a surface PMSM (L_d = L_q):

$$\tau_e = \tfrac{3}{2} p \lambda_m i_q = K_t\, i_q$$

### 2.3 Current PI by pole-zero cancellation

The plant for each axis is G(s) = 1/(Ls + R). Choose the PI controller

$$C(s) = K_p + \frac{K_i}{s}, \qquad K_p = L\,\omega_{c,i},\quad K_i = R\,\omega_{c,i}$$

Then the open loop is ω_c,i / s, and the closed loop is first order with bandwidth ω_c,i.

Feed-forward decoupling terms are added to the PI outputs:

$$v_d^{*} = PI_d - \omega_e L i_q,\qquad v_q^{*} = PI_q + \omega_e L i_d + \omega_e\lambda_m$$

The discrete PI uses Tustin integration with back-calculation anti-windup:

$$I[k+1] = I[k] + K_i T_s\, e[k] + K_{aw}\,(u_{sat}[k] - u[k]),\qquad K_{aw} = \frac{K_i}{K_p}$$

The voltage vector is limited to the linear SVPWM region:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Inside this limit, v_d is given priority. The current loop is clamped to v_q only after v_d has been satisfied.

### 2.4 SVPWM by min/max zero-sequence injection

$$v_{a,b,c} \leftarrow v_{a,b,c} - \tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x}{V_{bus}}$$

## 3. Velocity and Angle Loops

### 3.1 Velocity estimation with a PLL tracking observer

The PLL tracks the encoder angle using a wrapped angle error:

$$e = \mathrm{wrap}_{\pi}(\theta_{enc} - \hat\theta)$$
$$\hat\omega \mathrel{+}= T_s K_{i,pll}\, e$$
$$\hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}\, e)$$

Gains for a critically damped response at bandwidth ω_pll:

$$K_{p,pll} = 2\omega_{pll},\qquad K_{i,pll} = \omega_{pll}^2$$
