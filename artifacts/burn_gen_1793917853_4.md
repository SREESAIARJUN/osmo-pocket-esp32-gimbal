# FOC Motor Control and Dual-IMU Vibration Rejection for a 3-Axis Gimbal

I don't have the original specification for Job #38, so the design below rests on explicit assumptions. Every symbol is parameterized, so you can substitute your real motor and frame data.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g., GBM2804-class), 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoders | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per joint |
| MCU | STM32G4 / STM32H7 class, with an FPU and a 3-shunt or 2-shunt current sense |
| Loop rates | Current/FOC 20 kHz · Velocity 4 kHz · Attitude 1 kHz · IMU sampling 8 kHz |
| IMU A (ICM-42688-P) | On the camera payload. This is the stabilization feedback sensor. |
| IMU B (ICM-42688-P) | On the gimbal base, after the damper. This is the disturbance reference sensor. |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

If you intended two redundant IMUs on the payload instead, Section 6.6 gives the fusion variant.
