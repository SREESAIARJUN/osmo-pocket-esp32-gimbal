## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous commutation

During each 60° sector, two phases conduct:

- **Switching leg:** the high-side FET conducts for D·T. The complementary low-side FET (synchronous rectifier) conducts for (1−D)·T, minus dead time.
- **Return leg:** the low-side FET conducts continuously.

Ignoring dead time, the per-channel conduction loss is:

```
P_cond = I²·R_DS(Tj)·[D + (1−D) + 1] = 2·I²·R_DS(Tj)
```

This result is independent of duty cycle, which is a useful property of synchronous rectification.

### 1.2 Temperature dependence (requires a self-consistent solution)

```
R_DS(Tj) = R_DS,25 · [1 + α·(Tj − 25)]
```

At Tj = 110 °C: R_DS = 1.2 mΩ × 1.383 = **1.66 mΩ**

```
P_cond = 2 · 80² · 1.66e-3 = 21.2 W per channel
```

### 1.3 Copper and interconnect

Assume about 0.3 mΩ per conduction path (pads, vias, phase pad, solder joint), with two paths in series:

```
P_cu = 2 · I² · R_cu = 2 · 6400 · 0.3e-3 = 3.8 W per channel
```

This heat is spread across the board, not concentrated in the junctions.

## 2. Switching Losses at 48 kHz

Only the switching leg hard-switches (one high-side/low-side pair per channel at any instant).

| Loss term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·45 ns·48 kHz | 2.18 W |
| Reverse recovery | Q_rr·V·f_sw = 20 nC·25.2·48 kHz | 0.024 W |
| Coss | ½·Q_oss·V·f_sw | 0.018 W |
| Dead-time diode conduction | 2·V_f·I·t_dt·f_sw = 2·0.8·80·100 ns·48 kHz | 0.61 W |
| Gate drive (mostly in driver and R_g) | 2·Q_g·V_GS·f_sw = 2·30 nC·10 V·48 kHz | 0.029 W |

**Gate driver sizing check.** To achieve t ≈ Q_sw / I_g = 25 ns, the plateau current must be about 0.24 A. Size the gate resistor as R_g ≈ (V_drv − V_plateau)/I_g ≈ (10 − 3.5)/0.24 ≈ 27 Ω total. In practice, use 10–15 Ω external plus the driver's internal resistance.
