# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #46)

## 0. Assumptions

I don't have the Job #46 specification, so this design uses common gimbal hardware. Replace the parameters marked ⚙ with your actual values.

| Item | Assumed value ⚙ |
|---|---|
| Motors | 3× gimbal BLDC (GM4108-class), 12N14P → pole pairs `p = 7`, R ≈ 10 Ω, L ≈ 4 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), one per joint |
| MCU | STM32G474 @170 MHz, FPU, center-aligned PWM at 20 kHz |
| Current sensing | 2 low-side shunts (or inline), ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, sharing one ODR clock |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/Attitude 1 kHz · IMU ODR 8 kHz |

The cascade is: **Attitude/Angle (P + rate feedforward) → Velocity (PI + accel feedforward) → q-current (PI + decoupling) + anti-cogging feedforward**.

Velocity feedback comes from the fused gyro rate projected onto each joint axis, not from differentiated encoder angle. The gyro has far lower noise and latency. The encoder is used for commutation, cogging lookup, and joint-limit kinematics.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle, with offset θ₀ found at calibration:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupled PI

The motor in the dq frame (surface PM, so L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The control law uses PI plus feed-forward decoupling and back-EMF compensation:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Pole-zero cancellation leaves a closed loop of $\frac{\omega_c}{s+\omega_c}$. This gives the gains:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}\;\Rightarrow\; \omega_c \approx 2\pi\cdot 1.5\,\text{kHz}$$

For high-resistance gimbal motors (R/L ≈ 2500 s⁻¹), this places the PI zero at the electrical pole.

### 1.3 Voltage limiting and SVPWM

Limit the voltage vector to the inscribed hexagon circle:

$$|v^*| \le V_{bus}/\sqrt3$$

Scale both v_d and v_q proportionally (or prioritize v_d). Then apply min-max injection SVPWM:

$$v_{x}=\{v_a,v_b,v_c\},\quad v_0 = -\tfrac12(\max v_x + \min v_x),\quad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Discrete PI with back-calculation anti-windup

Use the backward-Euler integrator. With $e_k = r_k - y_k$:

$$u_k^{unsat} = K_p e_k + I_{k},\qquad u_k = \mathrm{sat}(u_k^{unsat}+u_k^{ff})$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s\big(u_k - u_k^{unsat}-u^{ff}_k\big),\qquad K_{aw}\approx \frac{K_i}{K_p}$$

### 2.2 Filtered derivative (optional, used on the angle loop only)

Using the Tustin transform with filter constant τ_f = 1/(N ω_n):

$$D_k = \frac{2\tau_f - T_s}{2\tau_f + T_s}D_{k-1} + \frac{2K_d}{2\tau_f+T_s}(-y_k + y_{k-1})$$

Derivative-on-measurement avoids setpoint kick.
