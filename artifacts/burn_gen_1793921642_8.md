# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bidirectional DShot600 Timer/DMA Allocation

## 0. Scope, Assumptions, and Architecture Corrections

Several assumptions are stated up front so every number below can be re-run against your actual BOM.

**Architecture.** The STM32H743 is the flight controller (FC). It does not commutate motors. A 4-in-1 ESC uses four dedicated ESC MCUs, typically STM32G071 or AT32F421 running AM32 or BLHeli_32-class firmware. Each ESC MCU receives bidirectional DShot600 from one H743 timer channel. I model the board as an AIO stack in which the H743 FC sits over the 4-in-1 ESC.

**Form factor.** An 80 A per-channel burst rating on a "nano" board (20×20 mm) is not physically defensible. I assume a 30.5×30.5 mm mounting pattern (about 36×36 mm board). Section 3 shows why even this size makes 80 A a few-second transient rating, not a continuous one.

**Electrical assumptions:**

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (worst case for switching) |
| PWM | 48 kHz, complementary (synchronous rectification), six-step trapezoidal |
| Dead time | t_dt = 100 ns |
| Gate drive | 10 V, 3-phase half-bridge driver (FD6288Q-class), R_g,ext = 4.7 Ω |

**Reference MOSFET.** I use a representative 40 V, 5×6 mm PDFN N-channel part. For production 6S, prefer 60 V parts if your layout cannot keep ringing below about 32 V.

| Parameter | Value |
|---|---|
| R_DS(on) @ 25 °C, V_GS = 10 V | 1.0 mΩ (max) |
| α (R_DS temperature coefficient) | 0.006 /K |
| Q_g / Q_gs2 / Q_gd | 60 / 6 / 12 nC |
| V_plateau @ 80 A | ≈ 4.5 V |
| R_g,int | 1.0 Ω |
| Q_rr @ 80 A, di/dt ≈ 500 A/µs | 60 nC |
| Q_oss @ 25 V | 40 nC |
| V_SD (body diode) @ 80 A | 0.9 V |
| R_θJC (bottom) | 1.0 K/W |

Substitute datasheet values for your selected part; all equations are parameterized.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in six-step complementary PWM

In each 60° commutation sector, two phases conduct and one floats:

- **PWM leg:** the high-side (HS) conducts for D·T_sw. The low-side (LS) conducts synchronously for (1−D)·T_sw, minus dead time.
- **Sink leg:** the LS is on continuously for the full sector.

Because current always flows through exactly one MOSFET in the PWM leg plus one in the sink leg:

$$
P_{cond,ch} = I_{ph,rms}^2 \, R_{DS}(T_j)\,[D + (1-D)] + I_{ph,rms}^2 \, R_{DS}(T_j) = 2\,I_{ph,rms}^2\,R_{DS}(T_j)
$$

This result is independent of duty cycle. Battery current is I_bat ≈ D·I_ph.
