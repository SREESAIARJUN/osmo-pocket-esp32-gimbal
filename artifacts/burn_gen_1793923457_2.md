# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

**Assumptions.** I don't have the Job #40 specification, so this design uses common gimbal hardware. Every parameter is a `constexpr` or config field, so you can change it to match your hardware.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class, single-precision FPU, 3 axes on 3 timers |
| Current sense | Inline or low-side shunts on 2 phases. A voltage-mode fallback is included. |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro at 8 kHz ODR, ±2000 dps. Mounted on the camera plate, with arbitrary orientation and lever arm. |

**Loop rates**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current / FOC | 20 kHz (T_c = 50 µs) | ~1.5–2 kHz |
| Velocity | 4 kHz (T_v = 250 µs) | ~80–150 Hz |
| Angle | 1 kHz (T_θ = 1 ms) | ~20–35 Hz |
| IMU fusion | 4 kHz (decimated from 8 kHz) | — |

## 1. Plant Model

**Electrical (PMSM in the rotor dq frame):**

$$
\begin{aligned}
v_d &= R i_d + L\frac{di_d}{dt} - \omega_e L i_q \\
v_q &= R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m \\
\omega_e &= p\,\omega_m, \qquad \theta_e = p\,\theta_m - \theta_{e,0}
\end{aligned}
$$
