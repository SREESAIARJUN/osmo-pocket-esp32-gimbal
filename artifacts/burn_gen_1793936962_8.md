# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #50 specification, so this design uses the parameters below. Everything is parameterized. Change the constants in `GimbalConfig` to match your hardware.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.07 N·m/A |
| Position sensing | 14-bit magnetic encoder per axis (AS5048A/MT6701 class), SPI |
| MCU | STM32G4/H7-class, single-precision FPU |
| Kinematic order | Base → Yaw (outer) → Roll (middle) → Pitch (inner) → Payload |
| IMU A ("payload") | ICM-42688-P on the camera plate (stabilization feedback) |
| IMU B ("base") | ICM-42688-P on the frame (vibration reference + feed-forward) |
