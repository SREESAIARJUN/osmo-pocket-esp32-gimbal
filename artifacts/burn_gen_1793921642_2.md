## 2. Loss Model (per motor channel)

### 2.1 Conduction Loss

In 6-step commutation with synchronous rectification, two FETs are always in the current path:
- the PWM leg's high-side FET (duty D), or its complementary low-side FET (1–D);
- the opposite phase's low-side FET (100%).

The instantaneous path resistance is therefore always 2·R_ds(on), regardless of D:

$$P_{cond} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

with the temperature dependence

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 135 °C: R_ds = 1.2 mΩ × 1.495 ≈ **1.79 mΩ**

$$P_{cond} = 2 \times 80^2 \times 1.79\text{ m}\Omega = \mathbf{22.9\ W}$$

Over one electrical cycle, each of the 6 FETs carries current for 1/3 of the time, so the average is **≈3.8 W per FET**.

Note the positive feedback loop: rising T_j raises R_ds, which raises loss. Solve iteratively with the thermal model in Section 4. Convergence requires (∂P/∂T)·Z_th < 1.

### 2.2 Switching Loss at 48 kHz

Only the PWM-active leg hard-switches. The high-side FET sees the V·I overlap; the low-side body diode contributes reverse-recovery charge.

**Transition times (Miller-plateau model):**

Turn-on, with V_pl ≈ 4.0 V:

$$t_{on} \approx \frac{(Q_{gs2}+Q_{gd})\,R_g}{V_{drv}-V_{pl}} = \frac{(5+8)\text{nC}\times 5\Omega}{6\text{ V}} \approx 11\text{ ns} \rightarrow \text{use } 15\text{ ns (layout } L_s)$$

Turn-off:

$$t_{off} \approx \frac{(Q_{gs2}+Q_{gd})\,R_g}{V_{pl}} = \frac{13\text{nC}\times 5\Omega}{4\text{ V}} \approx 16\text{ ns} \rightarrow \text{use } 20\text{ ns}$$

**Energy per PWM period:**

| Component | Equation | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_on + t_off) = ½ × 25.2 × 80 × 35 ns | 35.3 µJ |
| Reverse recovery | Q_rr·V = 30 nC × 25.2 V | 0.76 µJ |
| Output capacitance | E_oss | 0.30 µJ |
| **Total E_sw** | | **36.3 µJ** |

$$P_{sw} = E_{sw}\, f_{sw} = 36.3\,\mu\text{J} \times 48\text{ kHz} = \mathbf{1.74\ W}$$
