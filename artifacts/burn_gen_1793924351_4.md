# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for Job #47, so this design rests on the explicit assumptions in §0. Every motor, sensor and timing parameter is a named constant, so you can substitute your real values without changing the structure.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (GBM2804-class). Pole pairs $p=7$, $R_s\approx 5.6\,\Omega$, $L_s\approx 1.9\,$mH, $K_t\approx 0.09\,$N·m/A |
| Rotor encoder | 14-bit magnetic (AS5048A-class), read over SPI at 20 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7-class) with single-precision FPU |
| Bus voltage | 12–16 V; PWM 20 kHz, center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload center. ODR 8 kHz, ±2000 dps, ±16 g |
| Vibration source | Airframe prop
