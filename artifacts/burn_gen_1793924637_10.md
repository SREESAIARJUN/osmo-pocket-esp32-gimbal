# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design (Job #47)

I don't have the Job #47 specification, so this design uses the assumed parameters below. Every one is a named constant in the code, so you can replace them with your actual values.

| Parameter | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), R = 10 Ω, L = 2.5 mH, Kt = 0.07 N·m/A, pole pairs p = 7 |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701-class), 1 per axis |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, common FSYNC |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, carries camera) |

## 1. Loop Architecture and Rates

```
            1 kHz                  4 kHz                       20 kHz
θ_ref ─►[Angle P + FF]─ω_ref─►[Vel PI + J·α FF]─iq_ref─┬─►[Current PI dq + decoupling]─►SVPWM─► Motor
            ▲                        ▲                  │            ▲
            │ joint angle            │ joint rate       │            │ ia, ib, θe
            │                        │                  └──+ i_cog(θm + ω·Td)  (anti-cogging FF)
  [Mahony attitude] ◄─ [Fusion + adaptive notch + LPF] ◄─ IMU A, IMU B @ 8 kHz (on-chip AAF ≈ 1 kHz)
```

Each loop needs at least 5–10× bandwidth separation from the loop inside it:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle | 1 kHz | ω_θ ≈ 2π·25–35 Hz |
