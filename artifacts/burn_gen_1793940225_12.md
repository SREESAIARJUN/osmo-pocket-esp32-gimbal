# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the specifics of Job #57, so this design rests on the assumptions in Section 0. Every parameter that depends on them is a named constant, so you can re-target the design without changing its structure.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motors | Gimbal BLDC (GM4108-class), 11 pole pairs (`p = 11`), 12 slots (`Ns = 12`), R ≈ 10 Ω, L ≈ 4 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each motor |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| Current sensing | Low-side shunts, sampled at the PWM center |

**Loop rates.** Each outer loop runs at roughly 1/5 to 1/10 of the inner loop's bandwidth.

```
                 1 kHz                    4 kHz                     20 kHz
θ_ref ──►[ Angle PD+FF ]──ω_ref──►[ Velocity PI+FF ]──iq_ref──►[ Current PI (d,q) ]──►SVPWM──►Motor
             ▲                          ▲          ▲                    ▲
             │ θ_cam (Mahony)           │ ω_cam     │ iq_cog(θm)         │ ia, ib, θe (encoder)
             │                          │ (fused gyro)                   │
      [Dual-IMU fusion @ 8 kHz] ────────┘   [Anti-cogging FF] ◄──── θm (encoder)
```

The encoder handles commutation and cogging compensation. The IMU closes the stabilization loops, because the camera's inertial rate is the quantity you want to be zero, not the joint rate.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

Electrical angle: θₑ = p·θₘ − θ_offset

**Clarke:**
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park:**
- i_d = i_α·cos θₑ + i_β·sin θₑ
- i_q = −i_α·sin θₑ + i_β·cos θₑ

**Inverse Park:**
- v_α = v_d·cos θₑ − v_q·sin θₑ
- v_β = v_d·sin θₑ + v_q·cos θₑ

### 1.2 Plant and PI Design (pole-zero cancellation)

The dq-axis plant is:

- v_d = R·i_d + L·(di_d/dt) − ωₑ·L
