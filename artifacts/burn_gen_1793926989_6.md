## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701 class), SPI, read every PWM cycle |
| Current sense | 2-phase inline or low-side shunts, synchronous ADC |
| MCU | STM32G4/H7 class with FPU and CORDIC-optional |
| PWM / current loop | f_pwm = 20 kHz, current loop at 20 kHz (T_i = 50 µs) |
| Velocity loop | 4 kHz (T_v = 250 µs) |
| Angle/attitude loop | 1 kHz (T_θ = 1 ms) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro/accel ODR 8 kHz, FIFO or data-ready |
| Fusion output | 4 kHz rate, 1 kHz attitude |

**Loop-bandwidth separation rule.** Each outer loop should be at least 5–10× slower than the loop inside it:

ω_c,i (≈ 2π·1.5 kHz) ≫ ω_v (≈ 2π·150 Hz) ≫ ω_θ (≈ 2π·20 Hz)

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

i_α = i_a
i_β = (i_a + 2·i_b) / √3

**Park transform**, with electrical angle θ_e = p·(θ_m − θ_offset):

i_d = i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**

v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 SVPWM via min-max zero-sequence injection

This is mathematically equivalent to 7-segment SVPWM.

1. Phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Zero-sequence offset: v_0 = −½·(max(v_a, v_b, v_c) + min(v_a, v_b, v_c))
3. Duty per phase: D_x = ½ + (v_x + v_0) / V_bus, clamped to [0, 1]

The linear range is |v_αβ| ≤ V_bus/√3. Circular limiting is applied to the (v_d, v_q) vector, with d-axis priority.

### 1.3 PMSM model in the dq frame

v_d = R·i_d + L_d·(di_d/dt) − ω_e·L_q·i_q
v_q = R·i_q + L_q·(di_q/dt) + ω_e·(L_d·i_d + λ_m)

Torque (surface-mount PM, so L_d ≈ L_q):

τ_e = (3/2)·p·λ_m·i_q ≡ K_t·i_q

### 1.4 Current PI with pole-zero cancellation and decoupling

The plant is i/v = 1/(L·s + R). Choose the PI controller C(s) = K_p + K_i/s with:

K_p = L·ω_ci
K_i = R·ω_ci

The PI zero (at s = −K_i/K_p = −R/L) cancels the plant pole, giving the closed loop:

i/i* = ω_ci / (s + ω_ci)

**Bandwidth limit from sampling and PWM delay.** The total delay is T_d ≈ 1.5·T_i. To keep roughly 60° of phase margin, choose:

ω_ci ≤ 1 / (3·T_d) ≈ 2π·1.06 kHz at 20 kHz

**Feedforward decoupling** (added to the PI outputs):

v_d,ff = −ω_e·L·i_q
