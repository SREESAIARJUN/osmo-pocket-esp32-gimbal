# STM32H743 Nano FC + 4-in-1 ESC (Job #43): System Design Package

## 0. Scope, Assumptions, and Feasibility

Some of the brief's assumptions drive everything downstream, so they come first.

**Architecture decision.** The STM32H743 cannot run four sensorless FOC/6-step motor loops alongside ArduPilot's scheduler with deterministic commutation timing. The design is therefore partitioned as follows:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 (TFBGA100, 8×8 mm) or VIT6 (LQFP100) | ArduPilot (ChibiOS) |
| ESC MCU ×4 | AT32F421K8U7 (or STM32G071) | AM32 or BLHeli_32-compatible |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap) | n/a |
| Power stage ×4 | 6× N-ch 40 V MOSFET, PDFN5×6 | n/a |

The FC commands each ESC via bidirectional DShot600 and receives eRPM telemetry back on the same wire.

**Feasibility warnings**

1. **80 A per channel is incompatible with a 20×20 mm board.** Twenty-four PDFN5×6 FETs cannot physically fit, and PDFN3.3×3.3 parts cannot sustain 80 A thermally. This package therefore assumes a **30.5×30.5 mm stack**: a 2-board stack (FC on top, ESC below) or a single 8-layer board with FETs on the bottom side.
2. **"80 A burst" is treated as ≤ 3 s on all four channels simultaneously.** Section 2 shows why this limit exists.
3. **Component values below are representative datasheet-class numbers**, not a qualified BOM. Every parameter is kept symbolic first, so you can substitute your selected parts.
