## 0. Architecture Decisions and Stated Assumptions

No MOSFET, gate driver, board size, or burst duration was specified, so I fixed them below. Every equation is parameterized, so you can substitute your actual datasheet values.

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S LiPo, **V_bus,max = 25.2 V** | Worst case for switching loss and overshoot |
| Burst current | **80 A per motor**, all 4 motors simultaneously | Worst case |
| PWM frequency | f_sw = 48 kHz, complementary (synchronous) | ESC firmware setting |
| Dead time | t_dt = 200 ns per edge | |
| MOSFET (representative 40 V, PDFN 5×6) | R_ds(on),25 = 0.70 mΩ @ 10 V; Q_g = 60 nC; Q_gs2 + Q_gd = 17 nC; V_plateau = 3.5 V; R_g,int = 1 Ω; Q_rr ≈ 80 nC @ 80 A; V_SD = 0.8 V; R_θJC = 0.6 K/W | Swap in your part |
| Gate drive | 10 V, FD6288Q-class 3-phase driver (≈1.5 A source / 1.8 A sink), R_g,ext = 4.7 Ω on / 2.2 Ω off | |
| Board | **30.5 × 30.5 mm**, 6-layer, 2 oz copper on all layers | See the critical note below |
| Burst definition | 80 A for t_burst, starting from T_board = 40 °C | t_burst is derived, not assumed |

**Critical architecture note 1: the STM32H743 does not commutate the motors.** No production ArduPilot build runs four sensorless 48 kHz BLDC loops on the flight controller MCU. The standard and only realistic topology is:

```
STM32H743 (ArduPilot) ──bidir DShot600──► 4× AT32F421 (AM32 firmware, 48 kHz PWM)
                                           └─► FD6288Q gate driver ─► 6× N-MOSFET ─► motor
```

The 48 kHz switching model applies to the ESC MCUs. The DShot/DMA model applies to the H743.
