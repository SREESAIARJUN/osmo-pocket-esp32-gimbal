# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have access to the Job #49 specification, so this design is built on the assumptions below. Every value is a constructor parameter or `constexpr`, so you can substitute your measured values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz |
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804), 7 pole pairs, R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 / MA730) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Current loop | 20 kHz, synchronous with center-aligned PWM |
| Velocity loop | 4 kHz (every 5th PWM period) |
| Angle loop | 1 kHz |
| Bus voltage | 12–16 V (V_bus is measured each cycle) |

## 1. FOC Core Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here *p* is the number of pole pairs, and θ_m,0 is the encoder offset obtained by aligning to the d-axis: inject V_d with V_q = 0 and read θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform and its inverse

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix}v_\alpha\\ v_\beta\end{bmatrix}=\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}v_d\\ v_q\end{bmatrix}$$

### 1.4 PMSM model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p\,\lambda_m\, i_q \equiv K_t\, i_q \quad (\text{SPM},\ L_d = L_q)$$

### 1.5 Current PI with decoupling (pole-zero cancellation)

Plant: $G_i(s) = \dfrac{1}{Ls + R}$. Choose the controller $C_i(s) = K_p + \dfrac{K_i}{s}$ with:

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

This gives a closed loop of $\dfrac{\omega_{ci}}{s + \omega_{ci}}$. Use $\omega_{ci} \le 2\pi f_{pwm}/20$; at 20 kHz this is about 2π·1 kHz.

Feedforward decoupling terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

### 1.6 Voltage limiting and SVPWM

Limit the voltage vector with d-axis priority:

$$|v_d| \le V_{max}, \qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2}, \qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$
