# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model

This document covers four topics: 80A conduction losses, 48 kHz switching losses, thermal behavior, and bi-directional DShot600 timer and DMA allocation. Every numerical result depends on the assumptions stated, so the inputs are listed first. Swap in your real MOSFET datasheet values before committing to layout.

---

## 0. Architecture Clarification and Assumptions

**The STM32H743 does not commutate the motors.** ArduPilot is a flight controller stack and does not run 6-step or FOC commutation. The architecture is:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AM32 / BLHeli_32-class,
                                            e.g. AT32F421 / STM32G071)
                                              └─► gate driver ─► 3 half-bridges each
```

**Form factor warning.** "Nano" usually means a 20×20 mm mounting pattern. An 80A-per-channel stage (24 MOSFETs, bulk capacitors, four ESC MCUs, plus the H743) does not physically fit in 20×20 mm with credible thermals. The model below assumes a **30.5×30.5 mm, 8-layer, 2 oz board**. Section 3 shows that even this size supports 80A only as a short burst.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-Dependent On-Resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C:

$$R_{DS} = 1.2\,\text{mΩ} \times (1 + 0.006 \times 85) = 1.81\,\text{mΩ}$$

### 1.2 Current Path in 6-Step Commutation

In every commutation sector, two legs are active:

- **PWM leg:** current alternates between the high-side FET (duty D) and the synchronous low-side FET (1 − D). Either way, exactly one FET is in the path.
- **Static leg:** one FET conducts for the whole sector.

So two R_DS(on) are always in series with the phase current:

$$P_{cond,ch} = 2\, I^2\, R_{DS}(T_j) = 2 \times 6400 \times 1.81\,\text{m} = \mathbf{23.2\ W\ per\ channel}$$

### 1.3 Copper Path Loss

Assume about 0.25 mΩ for the battery-pad → FET → phase-pad path in 2 oz copper, including vias and solder:

$$P_{Cu} = I^2 R_{Cu} \approx 6400 \times 0.25\,\text{m} = 1.6\ \text{W}$$

### 1.4 Average Loss per FET

Each FET carries current for about 1/3 of the electrical cycle. The electrical period at flight RPM is far shorter than the die thermal time constant, so averaging is valid:
