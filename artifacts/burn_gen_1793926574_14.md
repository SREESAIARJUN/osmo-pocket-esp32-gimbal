**Architectural correction up front:** The H743 does **not** drive the bridges. Each ESC channel, or each pair, runs its own MCU (AT32F421 / STM32G071 class with AM32 or BLHeli_32). ## 1. Conduction Loss Model

### 1.1 Current paths in synchronous 6-step

In any sector, two phases carry current I:
- **Phase A (PWM leg):** high side on for D·T_sw. The complementary low side is on for (1−D)·T_sw.
- **Phase B (static leg):** low side on 100 % of the sector.

With synchronous rectification and dead time ignored for now:

$$P_{cond,ch} = I_{rms}^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

This is **independent of D**, which is a useful result: burst loss doesn't fall at partial throttle if current stays at 80 A.

Ripple correction: $I_{rms}^2 = I^2 + \Delta I_{pp}^2/12$. With motor L ≈ 15 µH, ΔI_pp = V·D(1−D)/(L·f) ≈ 25.2·0.25/(15e-6·48e3) ≈ 8.75 A. That adds 6.4 A² to 6400 A², or 0.1 %, so it is negligible.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

| T_j | R_ds | P_cond per channel (80 A) |
|---|---|---|
| 25 °C | 1.20 mΩ | 2·6400·0.0012 = **15.4 W** |
| 100 °C | 1.74 mΩ | **22.3 W** |
| 125 °C | 1.92 mΩ | **24.6 W** |

Per-FET instantaneous dissipation while conducting is I²R = 6400 × 1.92 mΩ = **12.3 W**. Averaged across the six FETs of one channel, that is ≈ 4.1 W per FET.

### 1.3 Thermal runaway check (fixed-point iteration)

$$T_j = T_{pcb} + P_{FET}(T_j)\cdot R_{\theta,j\text{-}pcb}$$

With R_θ,j-pcb ≈ 3.5 K/W (1.5 K/W junction-to-case plus ~2 K/W case-to-copper through vias) and T_pcb = 90 °C:

- Start: T_j = 105 °C → R_ds = 1.78 mΩ → P_FET = 3.8 W → T_j = 103.3 °C. This converges.
- Loop gain: ∂P/∂T · R_θ = (3.8 · 0.006/1.48) · 3.5 ≈ 0.054 ≪ 1. The loop is stable, with no runaway at the device level.

## 2. Switching Loss Model at 48 kHz

Hard switching occurs on the PWM leg only: one high-side turn-on and one turn-off per period.

| Term | Equation | Value (25.2 V, 80 A) |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw | 0.5·25.2·80·30e-9·48e3 = **1.45 W** |
| Reverse recovery | Q_rr·V·f_sw | 40e-9·25.2·48e3 = **0.05 W** |
| Body-diode dead time | V_f·I·2t_dt·f_sw | 0.8·80·200e-9·48e3 = **0.61 W** |
| C_oss | ½·Q_oss·V·f_sw (Q_oss ≈ 40 nC) | **0.02 W** |
| Gate charge (in driver) | 2·Q_g·V_gs·f_sw (Q_g ≈ 50 nC) | **0.05 W** |
| **Total P_sw per channel** | | **≈ 2.2 W** |

Sensitivity: P_sw scales linearly with f_sw. At 24 kHz it is ≈ 1.1 W, and at 96 kHz ≈ 4.4 W. Dead-time loss is the second-largest term, so tune dead time to the minimum safe value for your driver/FET pair.
