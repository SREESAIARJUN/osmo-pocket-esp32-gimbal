# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the "Job #50" spec sheet, so this design states its assumptions explicitly. Every parameter that depends on your hardware is a named constant. Swap in your values and the equations and code still hold.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, 170+ MHz |
| Motors | Gimbal BLDC (e.g. GBM2804-class), 12N14P → **p = 7 pole pairs**, R ≈ 10 Ω, L ≈ 2 mH |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis, on SPI |
| Current sense | 2 low-side shunts per motor (phases A, B) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, 8 kHz ODR |
| Platform | Multirotor, so prop vibration is 80–400 Hz plus harmonics |

**Loop rates (one timer, decimated):**

```
PWM / current loop (FOC)  : 20 kHz   (Ts_i = 50 µs)    ISR, ADC-triggered
IMU sample + filters      :  8 kHz   (Ts_g = 125 µs)   IMU data-ready → DMA
Velocity (rate) loop      :  4 kHz   (Ts_v = 250 µs)
Attitude (angle) loop     :  1 kHz   (Ts_a = 1 ms)
Cogging LMS adaptation    :  4 kHz   (with rate loop, gated)
```

**Cascade structure, per axis:**

```
q_ref ─►[Attitude P + FF]─ω_ref─►[Rate PI-D + FF]─τ_ref─►(+τ_cog_ff)─►[÷Kt]─iq_ref─►[Current PI + FOC]─►Motor
   ▲                           ▲                                                         ▲
   │ q̂ (fused attitude)        │ ω̂ (filtered gyro, axis-projected)                       │ θ_e (encoder)
```

The rate loop closes on the **gyro**, not the encoder. Inertial stabilization is what removes base motion. The encoder supplies θ_e for commutation and θ_m for the cogging feedforward.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$
\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{m,0})\big)
$$

θ_{m,0} is the encoder offset. Find it by applying V_d = V_align at θ_e = 0, waiting for the rotor to settle, and recording θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}
$$

### 1.3 Park transform

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

### 1.4 Motor model in the dq frame

$$
\begin{aligned}
v_d &= R i_d + L_d \dot i_d - \omega_e L_q i_q \\
v_q &= R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m \\
\tau &= \tfrac{3}{2} p \big(\lambda_m i_q + (L_d - L_q) i_d i_q\big) \;\approx\; K_t\, i_q,\quad K_t = \tfrac32 p \lambda_m
\end{aligned}
$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Pole-zero cancellation of the RL plant gives closed-loop bandwidth ω_c (choose ω_c ≈ 2π·1.5 kHz ≤ ω_PWM/10):

$$
K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c
\;\;\Rightarrow\;\; \frac{i_q}{i_q^*} = \frac{\omega_c}{s+\omega_c}
$$

$$
\begin{aligned}
v_d^* &= \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q \\
v_q^* &= \text{PI}_q(i_q^* - i_q) + \omega_e L_d i_d + \omega_e \lambda_m
\end{aligned}
$
