## 0. Assumptions & Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensing | 14-bit magnetic encoder per axis (e.g., AS5048A / MT6701) |
| Current sensing | 2-phase inline or low-side shunts (voltage-mode fallback provided) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| PWM | 25 kHz center-aligned |

**Loop rates (multirate cascade):**

```
 IMU ODR 8 kHz ──► Notch+LPF ──► Fusion (8 kHz gyro, 1 kHz attitude)
                                         │
 Attitude/Angle loop   1 kHz   θ_ref ─►[P + FF]─► ω_ref
 Velocity loop         5 kHz   ω_ref ─►[PI + FF]─► iq_ref (+ iq_cog)
 Current loop (FOC)   25 kHz   iq_ref─►[PI d/q + decoupling]─► SVPWM
```

Each loop's bandwidth is 4–10× below the next-inner loop. With the gains below, this gives roughly 1.5–2 kHz for current, 150–250 Hz for velocity, and 30–50 Hz for angle.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \pmod{2\pi}$$

`θ_offset` is found at calibration: apply $v_d = V_{\text{align}}$, $v_q = 0$ at $\theta_e = 0$, let the rotor settle, and record $\theta_m$.

### 1.2 Clarke and Park transforms

Two phases are measured and $i_c = -i_a - i_b$ (amplitude-invariant form).

**Clarke:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park:**

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM dq model and torque

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q \equiv K_t\, i_q \qquad (i_d^{\text{ref}} = 0,\ L_d \approx L_q)$$

### 1.4 Current PI by pole-zero cancellation

The plant is $G_i(s) = \dfrac{1}{Ls + R}$. Choosing

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

cancels the electrical pole and makes the closed loop first-order:

$$\frac{i}{i_{\text{ref}}} = \frac{\omega_{ci}}{s + \omega_{ci}}$$

Pick $\omega_{ci} \le 2\pi f_{\text{PWM}}/10$. At 25 kHz PWM, $\omega_{ci} \approx 2\pi \cdot 2000$ rad/s. Account for the 1.5-sample computational/PWM delay; it costs about $\omega_{ci}\cdot 1.5T_s$ rad of phase margin (≈ 43° at these numbers, which is acceptable).

### 1.5 Decoupling feedforward

$$v_d^{\text{ff}} = -\omega_e L\, i_q,\qquad v_q^{\text{ff}} = \omega_e (L i_d + \lambda_m)$$

### 1.6 Voltage limiting and anti-windup

Limit the voltage vector to the linear SVPWM region, prioritizing $v_d$:

$$|v| \le V_{\max} = \frac{V_{\text{bus}}}{\sqrt3}\cdot 0.95$$

Use back-calculation anti-windup on each integrator:

$$\dot x_I = K_i e + K_{aw}(u_{\text{sat}} - u),\qquad K_{aw} \approx \frac{K_i}{K_p}$$

### 1.7 SVPWM via min-max injection

Inverse Park, then inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Inject the common-mode offset and convert to duty:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{\text{bus}}}$$

**Voltage-mode fallback (no current sensors):** set $v_q = R\, i_q^{\text{ref}} + \omega_e\lambda_m$ and $v_d = -\omega_e L i_q^{\text{ref}}$. This is a common choice for gimbal motors because R is high and currents are small. The velocity-loop design below still applies.
