# STM32H743 Nano FC + 80A 4-in-1 ESC: Design Model

## 0. Scope and Assumptions

I don't have the Job #65 requirements document, so every number below comes from the assumption table in this section. All equations are parametric, so you can substitute your actual BOM values and recompute.

**Architecture.** In practice, the STM32H743 runs ArduPilot and generates bi-directional DShot600. Each ESC has its own small MCU (for example, STM32G071 or AT32F421 running AM32) that generates the 48 kHz commutation PWM. The H743 does not drive the gates directly. Running 4×3 half-bridges at 48 kHz from the H743 alongside ArduPilot is not a supported ArduPilot configuration. The model below follows the standard split.

## 1. Conduction Loss Model

### 1.1 Commutation topology

In 6-step trapezoidal drive, two legs are active at any instant. One leg is PWM'd and one is held. With synchronous rectification, phase current always flows through exactly one FET in each active leg. The high-side and low-side FETs of the PWM leg split the current in time by D and (1−D).

Because the current path always contains two FETs regardless of duty cycle, the channel conduction loss is independent of D:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

### 1.2 Electrothermal self-consistency

R_DS depends on T_j, and T_j depends on P. The fixed point is:

$$T_j = T_{ref} + P_{FET}(T_j)\,R_{th,j\text{-}ref}$$

Iterating to the burst-end condition (T_j ≈ 110 °C, from Section 3):

$$R_{DS}(110\,°C) = 1.0\,(1+0.0045\cdot 85) = 1.38\ \text{m}\Omega \;\to\; \text{use } 1.4\ \text{m}\Omega$$
