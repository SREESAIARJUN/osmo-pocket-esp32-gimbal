# STM32H743 Nano FC + 4-in-1 80A ESC: System Architecture Package (Job #54)

## 0. Scope, Architecture, and Assumptions

**Partitioning.** On any production 4-in-1 stack, the H743 does not switch the bridges. The H743 runs ArduPilot and emits bidirectional DShot600 frames. Four ESC MCUs run AM32 (or BLHeli_32) firmware and generate the 48 kHz complementary PWM. Each of these MCUs is an AT32F421 or STM32G071. The math is split along that boundary.

```
 6S LiPo ──┬──► 4× [ESC MCU → 3-ph gate driver → 6× N-MOSFET → motor]
           │            ▲ DShot600 bidir (1 wire per motor)
           └──► BEC ──► STM32H743 (ArduPilot) ── SPI IMU / baro / OSD / flash
```

**Design assumptions.** Replace each value with your actual BOM datasheet values. The model is parametric, so every result rescales.
