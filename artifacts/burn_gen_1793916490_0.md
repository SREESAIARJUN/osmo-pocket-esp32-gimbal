# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

I don't have the "Job #5" spec, so this design rests on the assumptions below. Every value lives in one config struct, so you can change any of them without touching the algorithms.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| Motors | 12N14P gimbal BLDC (GBM2804-class): 7 pole pairs, R ≈ 5 Ω, L ≈ 2 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sensing | 2-shunt low-side, sampled at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the pitch axis |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz, IMU ODR 8 kHz |
| Joint order | Yaw → Roll → Pitch (base to camera) |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

**Electrical angle:**
θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs.

**Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):**
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant Model and Current PI

The PMSM dq model is:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

Electromagnetic torque is τ = (3/2)·p·λ_m·i_q = K_t·i_q.

**Decoupled control law:**
- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ̂_m

With the cross-coupling cancelled, each axis reduces to a first-order plant G(s) = 1/(Ls + R).

**Pole-zero cancellation tuning** gives the closed loop 1/(s/ω_c + 1):
- K_p = L·ω_c
- K_i = R·ω_c

Choose ω_c ≤ 2π·f_pwm/10. At 20 kHz this means ω_c ≈ 2π·1500 rad/s.

**Discrete PI with back-calculation anti-windup** (sample time T_s):
- u_k = K_p·e_k + x_k
- ū_k = sat(u_k)
- x_{k+1} = x_k + K_i·T_s·e_k + K_aw·(ū_k − u_k)

Use K_aw ≈ 1/K_p·K_i·T_s·(some factor), or more practically K_aw·T_s ≈ T_s·ω_c.

**Voltage limiting:** apply a circular limit |v_dq| ≤ V_bus/√3, with d-axis priority.

### 1.3 SVPWM (Min-Max Zero-Sequence Injection)

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the zero-sequence offset: v_0 = −(max + min)/2.
3. Compute the duty cycle for each phase: d_x = ½ + (v_x + v_0)/V_bus.

This is mathematically identical to sector-based SVPWM and has a linear range up to |v| = V_bus/√3.

## 2. Cascaded Angle/Velocity Control

### 2.1 Mechanical Plant

The rigid-body model for each joint is:

J·ω̇ = K_t·i_q + τ_cog(θ) + τ_d − B·ω

where τ_d is the disturbance from the base and cable drag, and B is viscous friction.

### 2.2 Loop Structure

```
θ*, ω_ff, α_ff
     │
 [Angle P/PI 1 kHz] ──ω*──► [Velocity PI 4 kHz] ──i_q*──► [Current PI 20 kHz] ──► motor
     ▲                           ▲                      ▲
   θ̂ (IMU attitude)         ω̂ (gyro ⊕ encoder)    i_q* += i_ff,cog + J·α_ff/K_t
```

### 2.3 Velocity Loop

**Control law:**

i_q* = K_pv·e_ω + K_iv·∫e_ω dt + (Ĵ·α_ff + B̂·ω_ff)/K_t + i_cog(θ_m)

**Tuning** for crossover ω_v (with ω_v ≤ ω_c/5):
- K_pv = Ĵ·ω_v / K_t
- K_iv = K_pv·ω
