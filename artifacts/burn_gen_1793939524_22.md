# STM32H743 FC + 4-in-1 ESC (Job #25): 80 A Burst Power Stage and DShot600 Design

This is a reference-level architecture and analysis package. Each parameter is either stated as an assumption or derived. Before releasing any value for layout, check it against the datasheets of your actual MOSFETs and driver.

---

## 0. Architectural Corrections

Three points need to be settled before the math.

1. **The H743 does not run the ESCs.** A practical 4-in-1 uses one ESC MCU per motor, running AM32 or BLHeli_32 commutation (for example AT32F421 or STM32G071). The H743 runs ArduPilot and talks to each ESC MCU over one bi-directional DShot600 line. Commutation on the H743 under ArduPilot is not supported.
2. **"Nano" and "80 A burst" conflict.** Section 3 shows that 4 × 80 A dissipates about 100 W. A 20×20 mm board cannot absorb that for a useful duration.
   - This document assumes a **30.5×30.5 mm board, 8-layer, 2 oz outer and inner power layers**.
   - "80 A burst" is defined as **≤ 5 s per motor, starting from a 60 °C board**.
3. **Battery:** 6S. Analysis uses V_bus = 25.2 V, the worst case for switching loss.

## 2. Conduction Loss Model

### 2.1 Current paths

At any instant in 6-step operation, two phase legs are active.

- **Leg A (PWM leg):**
  - High-side FET conducts for duty fraction D.
  - Low-side FET synchronously rectifies for (1 − D).
- **Leg B (return leg):** one FET is held fully on.

Phase current I_ph flows continuously through exactly two channels. Ignoring dead time:

$$P_{cond,ESC} = I_{ph,rms}^2 \cdot R_{DS}(T_j)\cdot[D + (1-D)] + I_{ph,rms}^2 \cdot R_{DS}(T_j) = 2\,I_{ph,rms}^2\,R_{DS}(T_j)$$

With synchronous rectification, conduction loss is **independent of duty**.

### 2.2 Ripple correction

$$\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}}, \qquad I_{rms}^2 = I_{avg}^2 + \frac{\Delta I^2}{12}$$

Example: L_ph = 15 µH, worst case D = 0.5, V_bemf = 12.6 V.

- ΔI = 12.6 · 0.5 / (15 µH · 48 kHz) = **8.75 A**
- ΔI²/12 = 6.4 A², which is negligible against 6400 A².

### 2.3 Temperature-coupled solution

R_DS rises with T_j, so the model is self-referential. Iterate:

$$T_j = T_{board} + \frac{P_{FET}}{1}\cdot R_{\theta JC}, \qquad R_{DS}=R_{25}[1+0.004(T_j-25)]$$

At T_j ≈ 135 °C:

- R_DS = 1.2 · 1.44 = **1.73 mΩ**
- P_cond,ESC = 2 · 80² · 1.73 mΩ = **22.1 W per ESC**

### 2.4 Per-FET distribution

Each FET carries current for about 1/3 of the electrical cycle.

- Instantaneous loss in a conducting FET: 80² · 1.73 mΩ ≈ **11.1 W**
- Cycle-averaged loss: 22.1 / 6
