# STM32H743 AIO + 4-in-1 ESC (Job #7): Power-Stage Thermal Model, Bi-Directional DShot600 DMA Plan, and Reference Netlist

## 0. Architecture Assumptions

Several points in the brief need settling before any math is meaningful.

1. **The H743 does not commutate the motors.** ArduPilot has no BLDC field-commutation layer. The H743 runs ArduPilot and emits bi-directional DShot600 to four local ESC MCUs. These are typically AT32F421 or STM32G071 running AM32 (or BLHeli_32 on legacy hardware). Each ESC MCU drives one 3-phase bridge at 48 kHz.
2. **"Nano" and "80 A" conflict.** On a 20×20 mm board, 80 A per motor is not physically credible: there is no room for the copper cross-section or the thermal mass. This design assumes a **30.5×30.5 mm mount, roughly 37×37 mm board, 8-layer, 2 oz outer and 2 oz inner power planes**. 80 A is treated as a **burst rating of ≤ 5 s per motor**, not continuous. Section 3 shows why.
3. **Electrical baseline**
   - Supply: 6S LiPo, V_bus = 25.2 V max (22.2 V nominal)
   - PWM: 48 kHz, complementary (synchronous) switching, 6-step trapezoidal commutation
4. **Representative MOSFET** (any 40 V, 3.3×3.3 mm DFN with ~1 mΩ R_ds(on) behaves similarly)

| Parameter | Value |
|---|---|
| R_ds(on) @ 25 °C, V_gs = 10 V | 1.0 mΩ typ / 1.25 mΩ max |
| Q_g (total) | 45 nC |
| Q_gd | 9 nC |
| Q_rr | 40 nC |
| Q_oss | 40 nC |
| V_SD (body diode) | 0.8 V |
| R_th(j-c, bottom) | 1.5 K/W |
| T_j(max) | 175 °C |

## 1. Conduction Losses (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C with the max datasheet value:

$$R_{ds}(125) = 1.25\,(1+0.45) \approx 1.81\ \text{m}\Omega$$

### 1.2 Current path in 6-step with synchronous rectification

During each 60° commutation sector, phase current I flows through exactly two FETs at any instant:

- **PWM on (duty D):** high-side of phase A, then low-side of phase B.
- **PWM off (1−D):** synchronous low-side of phase A (freewheel), then low-side of phase B.

Two FETs always carry the full phase current I. This holds only if the dead time is short; dead-time loss is handled separately in §2.4.

$$P_{cond,ESC} = 2\,I^2\,R_{ds}(T_j)\quad(\text{independent of } D)$$

Per-FET distribution over one electrical revolution:

- Each phase's high-side conducts I for (1/3)·D of the time.
- Each phase's low-side conducts I for (1/3)(1−D) + 1/3 of the time.

$$P_{HS} = \tfrac{1}{3}D\,I^2R_{ds},\qquad P_{LS} = \tfrac{1}{3}(2-D)\,I^2R_{ds}$$

**At burst throttle the low-side FETs run hotter.** At D ≈ 0.9 they carry about 1.2× the high-side's loss. Place the low-side FETs nearest the thermal vias and the GND plane.

### 1.3 Copper and shunt losses (often forgotten)

| Element | Resistance | Loss @ 80 A |
|---|---|---|
| Shunt (shared, 4-in-1 total current) | 0.25 mΩ | Carries ΣI, see §3 |
| Phase trace + via-array per phase path | ~0.4 mΩ (2 oz, 3 mm wide, 8 mm, 2 layers paralleled) | 2 × 80² × 0.4 m ≈ **5.1 W** |
| Motor solder pad / wire joint | ~0.2 mΩ | ≈ 1.3 W |

The trace/pad row covers the two phase paths active at any instant.

### 1.4 Numbers per ESC, I = 80 A

$$P_{cond,FET} = 2\cdot 80^2\cdot 1.81\times10^{-3} = 23.2\ \text{W}$$

$$P_{cond,Cu} \approx 6.4\ \text{W}$$

## 2. Switching Losses at 48 kHz

Conditions: V = 25.2 V, I = 80 A, gate driver ≈ 1.5 A source / 1.8 A sink effective. The FD6288Q-class drivers common on AM32 boards are weaker; this figure assumes a stronger driver.

### 2.1 V–I overlap (hard-switched high-side)

Miller-plateau-dominated transition times:

$$t_r \approx \frac{Q_{gd}}{I_{g,src}} = \frac{9\,\text{nC}}{1.0\,\text{A}} = 9\ \text{ns},\qquad t_f \approx \frac{9\,\text{nC}}{1.4\,\text{A}} \approx 6.5\ \text{ns}$$

Add practical margin for loop inductance and set t_r + t_f ≈ 20 ns:

$$P_{sw} = \tfrac12 V I (t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot20\text{n}\cdot48\text{k} = 0.97\ \text{W}$$

### 2.2 Reverse recovery (low-side body diode → high-side turn-on)

$$P_{rr} = Q_{rr}\,V\,f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ \text{W}$$

The low-side Q_rr loss is dumped into the high-side FET.

### 2.3 Output capacitance

$$P_{oss} \approx \tfrac12 Q_{oss} V f_{sw} = 0.5\cdot40\text{n}\cdot25.2\cdot48\text{k} = 0.024\ \text{W}$$

### 2.4 Dead-time body-diode conduction

With t_dt = 100 ns per edge and two edges per PWM cycle:

$$P_{dt} = V_{SD}\,I\,(2t_{dt})\,f_{sw} = 0.8\cdot80\cdot200\text{n}\cdot48\text{k} = 0.61\ \text{W}$$

This is comparable to the switching loss. Tune AM32 dead time to the minimum that is shoot-through-safe, verified on a scope at V_bus max.

### 2.5 Gate drive (dissipated in the driver/regulator, not the FETs)

$$P_g = 6\,Q_g V_{gs} f_{sw} = 6\cdot45\text{n}\cdot10\cdot48\text{k} = 0.13\ \text{W/ESC}$$

### 2.6 Loss budget per ESC at 80 A burst

| Mechanism | Power |
|---|---|
| FET conduction (hot) | 23.2 W |
| Copper/pads | 6.4 W |
| Switching overlap | 0.97 W |
| Dead-time diode | 0.61 W |
| Q_rr + Q_oss | 0.07 W |
| Gate drive | 0.13 W |
| **Total** | **≈ 31.4 W** |

At this current, conduction dominates (about 94%). Going to 24 kHz saves only about 0.8 W, so 48 kHz is justified for acoustic and current-ripple reasons.
