# STM32H743 FC + 4-in-1 ESC (80 A burst): Power, Thermal, and DShot Timing Model

**Scope:** I don't have the Job #37 design files, BOM, stack-up, or MOSFET selection. This document therefore uses explicit, swappable assumptions (marked **[A]**). The equations are general. The numbers are a worked example you must re-run with your datasheet values. The netlist is a reference topology, not fab-ready output from an ECAD tool.

---

## 0. Architecture Correction

The STM32H743 does not drive the MOSFETs and does not set the 48 kHz switching frequency. In a 4-in-1 stack:

```
STM32H743 (ArduPilot) --DShot600 bidir, 4 lines--> 4× ESC MCU (AT32F421 / STM32G071 / EFM8, running AM32 or BLHeli)
                                                   └─> 3-phase gate driver ─> 6 MOSFETs per motor (24 total)
```

- The 48 kHz PWM is an ESC-firmware parameter.
- The H743 only generates DShot frames and captures eRPM telemetry.
- The model below is split along that boundary.

## 2. Conduction Loss Model

**Six-step trapezoidal with synchronous rectification.** At any instant, exactly one high-side leg and one low-side leg carry the phase current. During PWM off-time, current transfers from the HS FET to the complementary LS FET of the same leg, so the conduction path is always two R_ds(on) in series:

$$P_{cond}(T_j) = 2\,I_{rms}^2\,R_{25}\,[1+\alpha(T_j-25)] \;+\; 2\,I_{rms}^2\,R_{Cu}$$

**Ripple correction.** I_rms² = I_dc² + ΔI_pp²/12. With ΔI_pp = V·D(1−D)/(L·f_sw), low-inductance motors at 48 kHz typically add <2 % and are ignored here.

**Worked numbers (80 A):**

- I² = 6400 A²
- FET, 25 °C: 2·6400·1.0 mΩ = **12.8 W**
- FET, T_j = 110 °C: ×1.425 = **18.2 W**
- Copper: 2·6400·0.3 mΩ = **3.8 W** (rising ~0.39 %/K with temperature)
- **Per FET while conducting:** 6400·1.425 mΩ = **9.1 W**
- **Average per FET:** each FET conducts 120° of each electrical cycle, so ≈ 3.0 W.

**Self-consistent junction temperature (fixed point):**

$$T_j = T_{ref} + R_{\theta}\,P(T_j)
\;\Rightarrow\;
T_j = \frac{T_{ref} + R_\theta\,(P_0 - P_0\alpha\cdot 25)}{1 - R_\theta P_0 \alpha},\quad P_0 = 2I^2R_{25}$$

**Thermal-runaway condition:** R_θ · P₀ · α ≥ 1.

- For one channel's FETs: P₀ = 12.8 W and α = 0.005, so runaway occurs if R_θ(FET-group to ambient) > 15.6 K/W.
- This is not a risk at the junction scale.
- It is a real risk at the board-to-ambient scale on a nano PCB with no airflow.

## 3. Switching Losses at 48 kHz (per channel, 80 A)

Only the PWM-ing leg hard-switches. The model uses a linear V–I overlap.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·30 ns·48k = **1.45 W** |
| Reverse recovery | Q_rr·V·f_sw | **0.05 W** |
| Coss | Q_oss·V·f_sw | **0.06 W** |
| Dead-time diode | V_f·I·2t_dt·f_sw | 0.8·80·100 ns·48k = **0.31 W** |
| Gate drive (to driver/R_g) | 2·Q_g·V_gs·f_sw | **0.06 W** |
| **Total P_sw** | | **≈ 1.93 W** |

**Per-channel total at hot T_j:** 18.2 + 3.8 + 1.9 ≈ **24 W**

**All four motors at 80 A burst:** ≈ **96 W**

**Sensitivities (∂P/∂x):**

- P_sw scales linearly with f_sw. Going from 48 kHz to 24 kHz saves about 1 W per channel.
- P_sw also scales linearly with t_r+t_f, so gate resistor choice matters.
- P_cond scales with I² and dominates by about 10×.
- **Conclusion:** at 80 A, spend copper and R_ds(on) budget, not switching speed.

## 4. Thermal Model

### 4.1 Network

Foster/Cauer per channel:

```
P_FET ─[R_θJC 1.0]─ T_case ─[R_spread ≈ 2–4 K/W/FET]─ T_board(node, C_b) ─[R_θBA]─ T_amb
```

### 4.2 Junction ripple (fast scale)

- A conducting FET dissipates 9.1 W.
- Electrical period at, e.g., 2 kHz eRPM is 0.5 ms. The DFN junction's Z_θ at ~170 µs is ≈ 0.2–0.4 K/W.
- **Result:** ΔT_j ripple ≈ 2–4 K, which is negligible.
- The DC rise from average dissipation, 3 W × (1 + 3) K/W, puts T_j about **12 K above board temperature**.

### 4.3 Board heat-up (slow scale, governs the burst)

For a 30×30 mm board of ~8 g:

- Mixed FR4/Cu gives c ≈ 0.75 J/(g·K), so C_board ≈ 6 J/K, or **~1.5 J/K per channel quadrant**.
- Adiabatic slope (no airflow): dT/dt ≈ 24 W / 1.5 J/K ≈ **16 K/s**.

With R_θBA per quadrant ≈ 8 K/W (prop-wash convection, **[A]**):

$$T_b(t) = T_{amb} + P R_{\theta BA}\,(1-e^{-t/\tau}),\quad \tau = R_{\theta BA}C = 12\text{ s}$$

**Worked case:** T_amb = 40 °C and limit T_j = 125 °C, so the board limit is ≈ 113 °C.

- The steady-state asymptote is 40 + 24·8 = 232 °C. **80 A cannot be sustained.**
- Burst time:

$$t_{max} = -\tau\ln\!\left(1-\frac{113-40}{192}\right) \approx 12\cdot 0.478 \approx \mathbf{5.7\ s}$$
