# STM32H743 FC + 80 A 4-in-1 ESC: Systems Architecture Package

This package covers the power-stage loss model at 48 kHz, the thermal model for the 80 A burst, the ArduPilot bidirectional DShot600 timer and DMA allocation, and the schematic netlists.
