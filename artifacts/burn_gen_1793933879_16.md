# STM32H743 Nano FC + 4-in-1 ESC (Job #32): Architecture, Loss Model, DShot DMA Plan, Netlists and Thermal Analysis

## 0. Scope and Assumptions

The following assumptions are flagged explicitly so they can be challenged.

| Item | Assumption |
|---|---|
| Topology | STM32H743 runs ArduPilot (flight control). Each of the 4 motor channels has its own ESC MCU (AM32-class, e.g. STM32G071/AT32F421) driving a 3-phase bridge. The H743 does **not** commutate motors directly, because ArduPilot's scheduler cannot also host 4× BLDC commutation loops. |
| Bus | 6S LiPo: V_bus,max = 25.2 V, nominal 22.2 V |
| "80 A burst" | Per-channel **phase** current, duration t_b ≤ 10 s (the conventional ESC rating style) |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal |
| MOSFET (reference) | 40 V N-ch, R_DS(on),25 = 1.0 mΩ @ 10 V, Q_g = 50 nC, Q_gd = 8 nC, Q_rr = 40 nC, Q_oss = 60 nC, V_SD = 0.8 V, R_θJC = 1.2 K/W |
| Gate driver | FD6288Q-class 3-phase driver, V_CC = 10 V, bootstrap |
| Form factor | 20×20 mm mount ("nano"), 8-layer, 2 oz copper on all layers |

**Headline finding (Section 4):** an 80 A/channel, 10 s burst on all four channels simultaneously is **not thermally achievable** on a 20×20 nano board. The math below quantifies the real envelope and the design changes required.

## 1. Conduction Loss Model

### 1.1 Conduction path
In 6-step with complementary PWM, phase A is PWM'd high while phase B is held low:
- **On-time:** Q_AH + Q_BL conduct
- **Off-time (sync rect):** Q_AL + Q_BL conduct

Therefore exactly **two FETs carry I_ph at all times** (ignoring dead time):

$$P_{cond} = 2\, I_{ph,rms}^2 \, R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.0055\ \text{K}^{-1}$$

At T_j = 110 °C: R = 1.0 × (1 + 0.0055·85) = **1.47 mΩ**

### 1.3 Burst value (I_ph = 80 A)

$$P_{cond} = 2 \cdot 80^2 \cdot 1.47\times10^{-3} = \mathbf{18.8\ W\ per\ channel}$$

### 1.4 Additional I²R terms

| Element | R | Loss @ 80 A |
|---|---|---|
| Phase-current shunt (if low-side single shunt) | 0.25 mΩ | 1.6 W |
| PCB copper, bus + phase traces (estimate) | ~0.4 mΩ | 2.6 W |

The PCB copper figure is the one most often ignored, and it is not small.

### 1.5 Battery vs. phase current
Average battery current is I_bat ≈ D · I_ph. At throttle duty D = 0.6, a "80 A phase" burst corresponds to ~48 A battery current per channel. Specify which current is meant in any requirement document.

## 2. Switching Loss Model at f_sw = 48 kHz

Per channel, only the PWM'd leg switches hard (one high-side/low-side pair per PWM period).

### 2.1 V–I overlap (hard switching)

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw}$$

The intrinsic Miller-plateau time is t ≈ Q_gd·R_g,tot /(V_drv − V_pl) = 8 nC·5 Ω/(10 − 3 V) ≈ 6 ns. In practice it is dominated by loop inductance, so use **t_r + t_f = 40 ns**:

$$P_{VI} = 0.5 \cdot 25.2 \cdot 80 \cdot 40\text{ ns} \cdot 48\text{ kHz} = \mathbf{1.94\ W}$$
