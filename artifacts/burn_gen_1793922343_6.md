## 0. Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| Motors | 3× gimbal BLDC, 12N14P (e.g. GBM2804-class) | P = 7 pole pairs, slots S = 12 |
| Phase params | R = 5.6 Ω (line-neutral), L = 1.5 mH, Kt ≈ 0.06 N·m/A | Measure these (§7) |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701 class), SPI | Read every current-loop tick |
| Current sense | 2-shunt or 3-shunt low-side, synchronous ADC | Voltage-mode fallback in §1.6 |
| MCU | STM32G4 / H7-class Cortex-M4F/M7 with FPU | All `float` math |

| PWM | 20 kHz center-aligned | |

**Loop rates (timing hierarchy)**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (Ts,c = 50 µs) | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle / attitude | 1 kHz | ω_p ≈ 2π·25 Hz |
| IMU | 8 kHz in, filtered and decimated to 4 kHz | |

**Bandwidth separation rule:** ω_c ≥ 5–10·ω_v ≥ 5·ω_p. Each loop must also stay at or below about 1/10 of its own sample rate.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Angles

The mechanical angle θ_m comes from the encoder. It is converted to the electrical angle using the calibrated electrical zero θ_0:

$$\theta_e = P\,(\theta_m - \theta_0) \bmod 2\pi$$

Electrical speed is ω_e = P·ω_m.

The angle is advanced to compensate for the computational plus PWM delay τ_d ≈ 1.5·Ts,c:

$$\theta_e^{\,\text{comp}} = \theta_e + \omega_e\,\tau_d$$

### 1.2 Clarke transform (amplitude-invariant)

With the balanced-current assumption i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$
