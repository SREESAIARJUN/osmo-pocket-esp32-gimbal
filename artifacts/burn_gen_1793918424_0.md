## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle, with encoder offset θ₀ found at commissioning:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and Decoupled PI Control

The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

with λ = Kt / (1.5 p).

The control law adds feedforward decoupling to a PI on each axis:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L i_d+\lambda)$$

**Pole-zero cancellation tuning.** Choosing gains to cancel the electrical pole L/R makes the closed loop a first-order system with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Pick ω_c ≈ 2π·1.5 kHz, which is at most f_s/10 once the PWM transport delay of 1.5·T_s is accounted for.

**Discrete form (forward Euler, back-calculation anti-windup):**

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u^{sat}_k - u_k)$$

where K_aw = K_i / K_p.
