## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 0.80 × 1.5 = **1.20 mΩ**.

### 1.2 Current path in 6-step with synchronous rectification

During each 60° commutation sector, phase current I flows through exactly **one high-side path and one low-side path**:

- During t_on, the HS FET of phase A and the LS FET of phase B conduct.
- During t_off, the complementary LS FET of phase A and the LS FET of phase B conduct.

Because the complementary FET shares the same R_DS, conduction loss is **duty-independent**:

$$P_{cond,FET} = 2\,I^2 R_{DS}(T_j)$$

$$P_{cond,FET} = 2 (80)^2 (1.20\times10^{-3}) = \mathbf{15.36\ W\ per\ channel}$$

### 1.3 Parasitic copper and shunt

$$P_{Cu} = I^2 R_{trace},\quad R_{trace}\approx 0.5\ \text{m}\Omega\ \text{(pads + pours + vias, hot)} \Rightarrow 3.2\ \text{W}$$

$$P_{shunt} = I^2 R_{sh} = 6400 \times 0.25\times10^{-3} = 1.6\ \text{W}$$

### 1.4 Electro-thermal convergence

R_DS depends on T_j, which depends on P. Iterate:

$$T_j^{(n+1)} = T_{board} + P_{FET}\!\left(R_{DS}(T_j^{(n)})\right) R_{\theta JB}$$

Starting from T_board = 90 °C, the per-FET average dissipation is ≈ 3.5 W. With R_θJB ≈ 2 K/W, T_j ≈ 97 °C, so R_DS ≈ 1.09 mΩ. This converges after 3 iterations. **Using 1.20 mΩ (125 °C) is the conservative design value.**
