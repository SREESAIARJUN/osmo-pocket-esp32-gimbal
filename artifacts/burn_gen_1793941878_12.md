## 0. Architecture Decisions and Assumptions

### 0.1 Partitioning
The STM32H743 is the **flight controller**. It does not commutate motors. Each motor gets a dedicated ESC MCU, which is industry practice and the only way to get sub-µs commutation timing with BEMF zero-crossing. The four ESC MCUs (AT32F421K8U7, running AM32) are dual-sourceable against STM32G071.

```
6S LiPo ──┬─► 4× [ESC MCU → FD6288Q 3-ph driver → 6× N-MOSFET] ─► M1..M4
          ├─► 0.1 mΩ shunt → INA181A3 (gain 100 V/V; use A2 = 50 V/V for 320 A full scale) → H743 ADC
          └─► Buck 5V/3A → LDO 3.3V → STM32H743VIH6 (TFBGA100) / IMU / Baro / OSD
H743 TIM3 CH1..4 ══ Bidirectional DShot600 ══► ESC MCU signal pins (1 wire each)
```

### 0.2 Feasibility Flag (Read First)
**80 A on a 20×20 mm board is a short-burst rating, not continuous.** The thermal model in §3 shows:

- **Continuous capability** is about 20–25 A per motor with prop-wash cooling.
- **80 A on all four motors** is sustainable for roughly 0.5–1 s.
- **80 A on one motor** is sustainable for about 3 s.

The marketing rating must be specified as **"80 A burst (≤1 s, 4 motors) / 25 A continuous"**. Anything else is a field-failure liability.

## 1. Conduction Loss Model

### 1.1 Commutation Topology
The model assumes 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM. In each 60° sector:

- **PWM leg:** the high-side (HS) FET conducts for fraction D of the switching period; the low-side (LS) FET conducts for (1−D).
- **Return leg:** the LS FET conducts 100 %.
- **Floating leg:** off.

Over one electrical cycle, each leg is PWM-high for 1/3 of the time, low (static) for 1/3, and floating for 1/3.

### 1.2 Per-FET RMS Current
With phase current I (treated as flat-top DC within the sector):

$$I_{HS,rms}^2 = \tfrac{1}{3} D\, I^2 \qquad I_{LS,rms}^2 = \tfrac{1}{3}(1-D)\, I^2 + \tfrac{1}{3}\, I^2$$

This assumes the LS FETs are used as the static return leg, which is the AM32 default.

### 1.3 Temperature-Dependent Resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

This dependence is solved iteratively against §3. At T_j = 125 °C: R_DS = 1.4 × 1.6 = **2.24 mΩ**.
