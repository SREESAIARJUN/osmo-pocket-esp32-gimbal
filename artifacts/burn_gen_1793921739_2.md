# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification for Job #46, so this design rests on the assumptions in Section 0. Every parameter is isolated in a config struct so you can substitute your real values. The equations are complete, and the code is self-contained C++17. It uses no heap, no exceptions and no RTTI, and is written for Cortex-M4F/M7/M33 class MCUs.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R_ph ≈ 5–12 Ω, L_ph ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2- or 3-shunt, sampled at PWM center |
| MCU | STM32G4 / H7 class with FPU |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |

### Loop rates and target bandwidths

| Loop | Rate | Closed-loop bandwidth | Feedback source |
|---|---|---|---|
| Current (d/q) | 20 kHz | ~1.5–2 kHz | Phase shunts |
| Velocity (rate) | 4 kHz | ~150–250 Hz | Fused gyro, projected onto the joint axis |
| Angle | 1 kHz | ~20–40 Hz | Fused attitude mapped to the joint angle |
| Anti-cogging feedforward | 20 kHz (evaluated); adaptation at 4 kHz | — | Encoder mechanical angle |

Each loop's bandwidth is 5–10× slower than the loop inside it, so the inner loops can be treated as unity gain when tuning the outer ones.

### Signal flow

```
θ_ref ─►[Angle PI + ω_ff]─► ω_ref ─►[Velocity PI + J·α_ff]─► τ_ref
                                                               │
                                       τ_cog,ff(θ_m) ──(+)─────┤
                                                               ▼
                                             i_q,ref = τ/K_t ─►[Current PI d/q]─► SVPWM
```

The feedback and support paths are:
- **Angle and rate feedback:** Dual IMU → vibration filters → fused gyro → attitude estimate → joint-space projection.
- **Commutation and cogging map:** Encoder.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

**Electrical angle:**

θ_e = p·(θ_m − θ_off) mod 2π

**Clarke transform** (amplitude-invariant):

- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

**Park transform:**

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park transform:**

- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 Plant and PI design (pole-zero cancellation)

The motor in the rotating frame is:

- L di_d/dt = v_d − R i_d + ω_e L i_q
- L di_q/dt = v_q − R i_q − ω_e L i_d − ω_e λ

Here λ is the permanent-magnet flux linkage. The torque constant is K_t = (3/2)·p·λ.

Using C(s) = K_p + K_i/s and choosing K_i/K_p = R/L cancels the electrical pole. The loop then reduces to ω_c/s, which gives:

- **K_p,i = L·ω_c**
- **K_i,i = R·ω_c**
- Suggested crossover: ω_c ≈ 2π·1500 rad/s

**Decoupling feedforward:**

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e L i_d + ω_e λ

**Voltage limit:** |v_dq| ≤ V_bus/√3 (the linear SVPWM limit).

To saturate the vector, d is given priority:

- v_q,max = √(V_max² − v_d²)

### 1.3 Discrete PI with back-calculation anti-windup

Discretize with forward Euler on the integrator, sample time T_s:

- u_k = K_p e_k + I_k
- ū_k = sat(u_k)
- I_{k+1} = I_k + T_s [ K_i e_k + K_aw (ū_k − u_k) ]

Choose the back-calculation gain as K_aw ≈ K_i/K_p, or roughly 1/T_t with T_t = √(T_i T_d) when a D term is present.

### 1.4 SVPWM (min-max zero-sequence injection)

Compute the phase voltages:

- v_a = v_α
- v_b = −½v_α + (√3/2)v_β
- v_c = −½v_α − (√3/2)v_β

Inject the zero-sequence component:

- v_0 = −½[max(v_a,v_b,v_c) + min(v_a,v_b,v_c)]

Convert to duty cycles:

- d_x = ½ + (v_x + v_0)/V_bus, for x ∈ {a, b, c}

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant (per axis)

J θ̈ = K_t i_q − b θ̇ − τ_cog(θ_m) − τ_dist

J is the reflected inertia of the axis, including the camera payload and the outer axes.

### 2.2 Velocity loop

Assume the current loop is fast enough to treat as unity: i_q = i_q,ref. The plant from i_q to ω is then K_t/(J s).

For a PI controller C_v(s) = K_p,v (1 + ω_z/s) with crossover ω_v, set:

- **K_p,v = J·ω_v / K_t**
- **K_i,v = K_p,v·ω_z**
- ω_z = ω_v/4 gives about 76° of phase margin before delays.

**Delay budget.** Gyro filter group delay τ_f plus computation adds a phase
