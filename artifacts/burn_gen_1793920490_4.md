# STM32H743 Nano FC + 4-in-1 ESC (Job #65): System Architecture and Loss Model

## 0. Architecture Corrections Before the Math

Two parts of the brief need correcting first, because they change the design.

**1. The H743 should not commutate the motors.** ArduPilot on the H743 sends DShot to the ESC and receives eRPM telemetry back. It does not run 48 kHz sensorless commutation. Each ESC channel needs its own MCU, such as an AT32F421 or STM32G071 running AM32 or BLHeli_32. The 48 kHz PWM frequency is an ESC firmware parameter, and ArduPilot never sees it. The partitioning used here is:

```
[STM32H743 FC / ArduPilot] --4x BDShot600--> [4x ESC MCU, 48kHz PWM] --> [4x 3-phase bridges, 24 FETs]
```

**2. An "80 A burst" on a nano board is thermally limited to roughly one second.** The math below shows this. Rate the board as **80 A for ≤1 s, about 18 A continuous per channel in prop-wash**, not "80 A".

All component values below are representative assumptions. Replace them with datasheet values for the parts you select.

## 2. Conduction Loss Model

### 2.1 Current path

The model assumes trapezoidal six-step commutation with complementary (synchronous-rectified) PWM.

- At any instant, current flows through exactly **two FETs**: one high-side or freewheeling low-side FET in the PWM phase, plus the low-side FET of the sinking phase.
- With synchronous rectification, the conduction path resistance is independent of duty cycle.

$$P_{cond,ch} = 2\, I_{rms}^2 \,R_{ds}(T_j) + I_{rms}^2 R_{cu}$$

### 2.2 Ripple correction

$$I_{rms} = I_{pk}\sqrt{1+\frac{r^2}{12}},\qquad r=\frac{\Delta I}{I}$$

For a low-inductance quad motor at 48 kHz, assume r ≈ 0.3. This gives I_rms = 80 × 1.0037 ≈ **80.3 A**.

### 2.3 Temperature dependence of R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha(T_j-25)\big],\quad \alpha\approx0.006\ \text{K}^{-1}$$

At 110 °C: R_ds = 1.5 × 1.51 ≈ **2.26 mΩ**.

This creates a positive feedback loop: higher temperature raises R_ds, which raises loss and temperature. Section 4 solves the coupled system.

### 2.4 Numbers per channel

$$P_{cond} = 2(80.3)^2(2.26\text{ mΩ}) + (80.3)^2(0.5\text{ mΩ}) = 29.1 + 3.2 = \mathbf{32.3\ W}$$

Averaged over an electrical revolution, each FET conducts one-third of the time in its phase role. The average per FET is therefore about 29.1 / 6 × 2 ≈ **9.7 W**, worst case before sharing. Use about 5–10 W per FET for junction calculations.

## 3. Switching Loss Model at 48 kHz

Each PWM period has one hard-switched turn-on and one turn-off in the active leg.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r + t_f) · f_sw | ½ · 25.2 · 80 · 40 ns · 48k = **1.94 W** |
| Dead-time diode conduction | V_f · I · 2t_dt · f_sw | 0.8 · 80 · 400 ns · 48k = **1.23 W** |
| Reverse recovery | Q_rr · V · f_sw | 30 nC · 25.2 · 48k = **0.036 W** |
| Coss (hard turn-on) | Q_oss · V · f_sw | 40 nC · 25.2 · 48k = **0.048 W** |
| Gate drive (in driver and R_g) | 2 · Q_g · V_gs · f_sw | 2 · 50 nC · 10 · 48k = **0.048 W** |
| **Total per channel** | | **≈ 3.3 W** |

**Key insight:** dead-time diode loss is about 40 % of switching loss. Cutting dead time from 200 ns to 100 ns saves about 0.6 W per channel. This tuning is worth more than chasing faster edges, which hurt EMI.

**Frequency trade-off:**

$$P_{sw}(f) \approx 68.8\ \mu\text{J} \times f_{sw}$$

- At 24 kHz, switching loss is 1.65 W but current ripple doubles.
- At 96 kHz, it is 6.6 W.
- 48 kHz is a reasonable compromise.

### 4.1 Total loss at burst

$$P_{ch} = 32.3 + 3.3 = 35.6\text{ W},\qquad P_{4ch} \approx \mathbf{142\ W}$$
