# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #53)

## 0. Assumptions

I don't have the Job #53 spec sheet, so the design is built on the assumptions below. Every one of them is a parameter in the code.

| Item | Assumed value |
|---|---|
| Motors | 12N14P gimbal BLDC (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic encoder (AS5048A / MT6701 class), one per axis |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, sharing a CLKIN, read at 8 kHz ODR |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

**Loop rates:**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current loop | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity loop | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle loop | 1 kHz | ω_a ≈ 2π·25 rad/s |
| Attitude/fusion | 8 kHz in, 1 kHz out | — |

Adjacent loops are separated in bandwidth by at least 6×.
