# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #50 spec sheet, so the design is built on the assumptions below. Every value is a named constant in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (GBM2804-class): 12N14P → 7 pole pairs, R ≈ 5–10 Ω, L ≈ 1–3 mH, Kt ≈ 0.05–0.1 Nm/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| Current sense | 2-phase inline shunts, synchronous ADC sampling (voltage-mode fallback provided) |
| MCU | STM32G4 / H7-class with FPU, CORDIC optional |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz · IMU 8 kHz |

**Bandwidth separation (rule of thumb ≥ 4–5× between loops):**

$$
\omega_{c,i}\approx 2\pi\cdot 1.5\text{ kHz},\quad
\omega_{c,v}\approx 2\pi\cdot 80\text{ Hz},\quad
\omega_{c,\theta}\approx 2\pi\cdot 15\text{ Hz}
$$
