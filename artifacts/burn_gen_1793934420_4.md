# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #45, so this design rests on the assumptions in §0. Every hardware-specific constant is in one configuration struct, so you can substitute the real values without changing the control law.

---

## 0. Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 1.2 mH | Typical GBM2804/GBM3506 class |
| Torque constant | K_t ≈ 0.08 N·m/A | Identify per motor |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) on SPI | |
| MCU | STM32G4 / H7 class, single-precision FPU | |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz | Voltage-mode fallback is included |
| Velocity loop | 4 kHz (every 5 PWM cycles) | |
| Angle loop / attitude | 1 kHz | |
| IMUs | 2 × ICM-42688-P on the camera plate, 8 kHz ODR, separate SPI buses, common CLKIN | |
| Vibration source | Unknown (propellers, vehicle, or walking) | An adaptive notch is used for that reason |
