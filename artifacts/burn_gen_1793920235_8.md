# FOC Control and Dual-IMU Fusion for a 3-Axis Gimbal

This covers the cascaded control loops, anti-cogging feedforward, dual ICM-42688-P vibration rejection, and a complete C++17 reference implementation.

---

## 0. Assumptions

I don't have the Job #30 specification, so the design rests on the following assumptions. Every parameter is a named constant, so you can substitute your own values.

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class (FPU, 170+ MHz) |
| Motors | 3 × BLDC gimbal motors, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5047 class) |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

Loop rates:

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC) | 20 kHz, synchronized to the PWM centre | Phase shunts |
| Velocity | 4 kHz | Fused gyro (inertial rate) and encoder |
| Attitude | 1 kHz | Fused quaternion |
| Cogging LMS adaptation | 4 kHz, gated | Velocity-loop effort |

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{using } i_a+i_b+i_c=0)
$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Machine model and decoupled PI

The motor model in the rotor frame is:

$$
v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)
$$

The control law is a PI controller plus cross-coupling and back-EMF feedforward:

$$
v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L_q i_q,\qquad
v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)
$$
