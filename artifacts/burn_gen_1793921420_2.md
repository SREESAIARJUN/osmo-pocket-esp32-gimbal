## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor encoder | 14-bit magnetic (MT6701 or AS5048A) per axis, SPI |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| Current loop (FOC) | 20 kHz (PWM-synchronous, ADC triggered mid-PWM) |
| Velocity loop | 4 kHz (gyro-driven) |
| Angle loop | 1 kHz |
| IMU ODR | 8 kHz gyro and accel, read via FIFO |

**Bandwidth separation rule.** Each outer loop should be at least 4–10× slower than the loop inside it, and each loop's sample rate should be at least 10× its own bandwidth:

```
ω_c,current ≈ 2π·1500 rad/s
ω_c,velocity ≈ 2π·150 rad/s
ω_c,angle ≈ 2π·30 rad/s
```

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

```
θ_e = p·(θ_m − θ_offset)  mod 2π
```

θ_offset is found at calibration by applying a d-axis current vector at θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

```
i_α = i_a
i_β = (i_a + 2·i_b)/√3
```

### 1.3 Park transform

```
i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e
```

### 1.4 Plant in the dq frame (surface PMSM, L_d = L_q = L)

```
v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ_m
T   = (3/2)·p·λ_m·i_q = K_t·i_q
```

### 1.5 PI current controller with decoupling

The PI zero is placed on the electrical pole R/L (pole-zero cancellation). This gives a first-order closed loop with bandwidth ω_cc:

```
K_p,i = L·ω_cc
K_i,i = R·ω_cc
```

Decoupling and back-EMF feedforward terms are added to the PI outputs:

```
v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m
```

Use i_d* = 0. Gimbal motors never need field weakening.

### 1.6 Voltage limiting

Limit to the inscribed circle of the SVPWM hexagon, |v| ≤ V_bus/√3, while preserving vector direction:

```
if √(v_d² + v_q²) > V_max:  scale both by V_max/|v|
```

### 1.7 Inverse Park and SVPWM (min/max zero-sequence injection, equivalent to SVPWM)

```
v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e

v_a = v_α
v_b = −½·v_α + (√3/2)·v_β
v_c = −½·v_α − (√3/2)·v_β

v_0 = −½·(max(v_a,v_b,v_c) + min(v_a,v_b,v_c))
duty_x = ½ + (v_x + v_0)/V_bus
```

### 1.8 Delay compensation

Rotate θ_e forward by 1.5 PWM periods (one for computation, half for ZOH):

```
θ_e,pwm = θ_e + 1.5·ω_e·T_pwm
```

## 2. Cascaded Angle → Velocity Control

### 2.1 What the loops regulate

For a stabilizing gimbal, the controlled quantities are the camera's inertial attitude and angular rate, not the joint angles. Each motor's job is to produce joint rate q̇.

The kinematics for a yaw (ψ) → roll (φ) → pitch (θ) joint chain, expressed in the camera frame, are:

```
ω_cam = R_cb·ω_base + J(q)·q̇

J(q) = [ ê_pitch | R_y(θ)ᵀ·ê_roll | R_y(θ)ᵀ·R_x(φ)ᵀ·ê_yaw ]
