# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

This design covers the full control stack for a 3-axis brushless gimbal:

- The field-oriented control (FOC) current loop.
- Cascaded angle and velocity control.
- Anti-cogging feedforward that adapts online.
- Dual ICM-42688-P sensor fusion with vibration rejection.

The equations come first, followed by a self-contained C++17 implementation with no heap allocation, suitable for an STM32G4/H7-class MCU.

---

## 0. Assumptions

I don't have the Job #37 specification, so the design rests on the assumptions below. Every value is a parameter in the code; replace them with your measured values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor position sensing | 14-bit magnetic encoder per axis (e.g. AS5048A / MA730) |
| Inverter | 3-phase, 20 kHz center-aligned PWM, two low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate (rigid body), SPI, 8 kHz ODR |
| Gimbal joint order | Yaw → Roll → Pitch (outer to inner) |
| DC bus voltage | 12–16 V |

## 1. Timing Architecture

| Loop | Rate | Ts | Feedback signal |
|---|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz | 50 µs | Shunt currents, encoder angle θₑ |
| IMU acquisition and filtering | 8 kHz | 125 µs | Two gyros and two accelerometers |
| Velocity (inertial rate) PI | 4 kHz | 250 µs | Filtered fused gyro, projected onto the joint axis |
| Angle (attitude) P + FF | 1 kHz | 1 ms | Attitude quaternion → joint-space error |
| Anti-cogging LMS update | 4 kHz (gated) | — | Velocity-loop integrator |

Each loop's bandwidth is roughly 5–10× below the loop inside it:

- Current loop: about 1.5–2 kHz
- Velocity loop: about 80–150 Hz
- Angle loop: about 15–30 Hz

> **Key design point:** the velocity loop is closed on **inertial rate from the gyro**, not encoder rate. This is what makes the camera reject base motion. The encoder is used for commutation, for the cogging phase, and as a fallback.
