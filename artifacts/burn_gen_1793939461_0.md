# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification (Job #19)

## 0. Assumptions and Baseline

I have no prior project files for Job #19, so the design is parameterized on the hardware below. Every value lives in a config struct and can be replaced with your actual figures.

| Item | Assumed baseline |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, HRTIM/TIM1 center-aligned PWM) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R_s ≈ 5–12 Ω, L_s ≈ 1–3 mH, low-current (<1.5 A) |

| Kinematics | Yaw (base) → Roll → Pitch (camera) |

### Loop rate hierarchy

| Loop | Rate | Trigger |
|---|---|---|
| Current (d/q PI), SVPWM | 20 kHz | ADC injected end-of-conversion, synced to PWM center |
| Encoder PLL, cogging feedforward | 20 kHz | Same ISR |
| Velocity PI | 4 kHz | Every 5th current ISR |
| IMU read, filtering, fusion | 4 kHz | IMU DATA_RDY (ODR = 8 kHz, decimate by 2) |
| AHRS + angle loop | 1 kHz | Software task |

Bandwidth separation rule: each outer loop's crossover should be at least 5× below the inner loop's.

- ω_c,i ≈ 2π·1500 rad/s
- ω_c,v ≈ 2π·60–120 rad/s
- ω_c,θ ≈ 2π·8–15 rad/s

## 1. FOC Current Loop

### 1.1 Motor model (PMSM, rotor dq frame)

$$
v_d = R_s i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R_s i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e\lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\big[\lambda_m i_q + (L_d-L_q)i_d i_q\big] \;\approx\; K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m
$$

Here ω_e = p·ω_m and θ_e = p·θ_m − θ_offset.

If only a KV rating is available:

$$
\lambda_m = \frac{60}{\sqrt{3}\,\cdot 2\pi\cdot KV\cdot p}
$$

This assumes line-to-line peak volts per rpm. Verify the result with a back-EMF measurement.

### 1.2 Transforms (amplitude-invariant)

Clarke:
$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b),\qquad (i_a+i_b+i_c=0)
$$

Park:
$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park:
$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.3 SVPWM (min/max zero-sequence injection)

This method is mathematically equivalent to sector-based SVPWM and is cheaper to compute.

$$
v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad
D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}
$$

The linear range is limited by |v_dq| ≤ V_dc/√3. Apply this as a circular voltage limit with q-axis priority (see code).
