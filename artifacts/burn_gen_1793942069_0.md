# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

**Assumptions.** I don't have the Job #44 specification, so this design assumes the following. Please correct any that don't match your hardware.

- **Motors:** gimbal-class PMSM/BLDC, 12N14P (12 slots, 14 poles, so 7 pole pairs).
- **Position sensor:** 14-bit absolute magnetic encoder (AS5048A/MT6701 class) on each axis.
- **Current sensing:** low-side or inline current sensing on each motor. A voltage-mode fallback is given in §1.4.
- **MCU:** Cortex-M4F or M7 with a single-precision FPU (STM32G4/H7 class).
- **IMUs:** two ICM-42688-P on SPI, mounted on the camera plate.
- **Gimbal kinematics:** yaw → roll → pitch (outer to inner).

**Loop rates:**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| IMU sampling | 8 kHz (ODR) | 125 µs |
| Velocity | 4 kHz | 250 µs |
| Attitude/angle | 1 kHz | 1 ms |

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms

The electrical angle comes from the mechanical angle, the number of pole pairs p, and a calibrated encoder offset θ_off:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Current-Loop Plant and PI Design

The dq-frame voltage equations of a surface PMSM (L_d = L_q = L) are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With feedforward decoupling, the commanded voltages are:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis is a first-order plant 1/(Ls + R). **Pole-zero cancellation** with a target bandwidth ω_c gives:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/20, which here means ω_c ≈ 2π·1 kHz.

Torque is produced by the q-axis current, with the d-axis current held at zero:

$$\tau = \tfrac{3}{2}p\lambda_m i_q = K_t i_q,\qquad i_d^* = 0$$

### 1.3 Voltage Limiting and SVPWM

- **Voltage limit:** the voltage vector magnitude is limited to $|v| \le V_{bus}/\sqrt3$. The d-axis gets priority; the q-axis receives the remaining headroom, $v_{q,max} = \sqrt{V_{max}^2 - v_d^2}$.
- **SVPWM via min-max zero-sequence injection:** the duty for each phase x is

$$d_x = \tfrac12 + \frac{v_x - \tfrac12(\max v + \min v)}{V_{bus}}$$

### 1.4 Voltage-Mode Fallback (No Current Sensing)

If the board has no current sensing, command the q-axis voltage directly:

$$v_q^* = R\,i_q^* + \omega_e\lambda_m,\qquad v_d^* = -\omega_e L\, i_q^*$$

This is common on high-resistance gimbal motors (R ≈ 5–15 Ω).

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Feedback Signals

For stabilization, the velocity and angle feedback should come from the **IMU**, not the encoder. The encoder is used only for commutation and the joint-axis Jacobian. This rejects base motion directly.

**Joint-axis Jacobian (yaw-roll-pitch).** The body rates of the camera are related to the joint rates by:

$$\boldsymbol\omega_{cam} = J(\theta_r,\theta_p)\,\dot{\boldsymbol q} + R^{cam}_{base}\,\boldsymbol\omega_{base}$$

where

$$J=\begin{bmatrix} -\cos\theta_r\sin\theta_p & \cos\theta_p & 0\\ \sin\theta_r & 0 & 1\\ \cos\theta_r\cos\theta_p & \sin\theta_p & 0\end{bmatrix}$$

The columns correspond to (yaw, roll, pitch) and the rows to the camera axes (x, y, z). The per-axis velocity error used by each motor loop is:

$$\mathbf e_{\dot q} = J^{-1}(\boldsymbol\omega^*_{cam} - \boldsymbol\omega_{cam,meas})$$

$J$ becomes singular at cos θ_r = 0, i.e. **gimbal lock at roll = ±90°**. Clamp the roll command to ±60° or use a damped pseudo-inverse.

### 2.2 Mechanical Plant

$$J_m\,\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.3 Angle Loop (P with Velocity Feedforward)

The angle error is computed on the quaternion error, $q_e = q^{*-1}\otimes q$, using the small-angle approximation $\mathbf e_\theta \approx 2\,\text{sgn}(q_{e,w})\,\mathbf q_{e,xyz}$. The angle loop then produces a rate command:

$$\omega^* = K_{p,\theta}\,e_\theta + \omega^*_{ff},\qquad K_{p,\theta} = \omega_\theta$$
