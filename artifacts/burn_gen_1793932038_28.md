# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power, Thermal, and DShot Architecture

**Scope:** 80 A burst conduction losses, 48 kHz switching losses, ArduPilot bi-directional DShot600 timer/DMA allocation, reference netlists, and thermal budget.

**Status:** Engineering model and reference design. All component values are assumptions to be verified against the selected parts' datasheets and bench measurements before layout freeze.

---

## 0. System Architecture Assumptions

An H743 cannot reasonably run 4× 6-step or FOC commutation at 48 kHz while also running ArduPilot's EKF. The architecture is therefore split:

| Block | Device | Role |
|---|---|---|
| FC MCU | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100) | ArduPilot, DShot600 master, eRPM/notch |
| ESC MCUs (×4) | AT32F421K8U7 / STM32G071 (AM32 or BLHeli_32) | Commutation, 48 kHz PWM, BEMF |
| Gate drivers (×4) | FD6288Q (3-phase half-bridge, bootstrap) | 6 gates per motor |
| MOSFETs (×24) | 40 V, 3.3×3.3 DFN class | 6 per motor |
| Bus | 6S LiPo, V_bus,max = 25.2 V | |
