## 0. Architecture Clarification and Baseline Assumptions

The STM32H743 does not commutate the motors. In any ArduPilot 4-in-1 design, the H743 is the flight controller. It sends bi-directional DShot600 to four ESC MCUs (AT32F421 or STM32G071, running AM32 or BLHeli_32). Each ESC MCU generates the 48 kHz complementary PWM.

| Parameter | Value used | Notes |
|---|---|---|
| V_bus | 25.2 V (6S full), design to 30 V transients | 40 V FETs required |
| I_burst | 80 A per channel, phase current | ~1–3 s bursts |
| f_sw | 48 kHz | ESC-side PWM |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz all layers | 80 A on a 20 × 20 "nano" is not thermally credible (see §3.5) |
| MOSFET (per switch) | 40 V, R_ds,on(25 °C) = 0.90 mΩ max @ V_GS = 10 V, Q_g = 70 nC, Q_gd = 12 nC, Q_rr = 50 nC, Q_oss = 60 nC, R_θJC = 1.2 K/W, V_SD = 0.8 V | 5 × 6 mm DFN class |
| Gate driver | 3-phase bootstrap, ~1.2 A source / 1.5 A sink, R_g,ext = 2.2 Ω | e.g. FD6288Q-class |
| Dead time | 200 ns | |
| Commutation | 6-step, complementary (synchronous-rectified) PWM on the active high-side | |

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation with synchronous rectification, exactly two FETs carry the phase current at every instant:
- **On-time:** HS of phase A and LS of phase B.
- **Off-time:** LS of phase A (freewheeling) and LS of phase B.

So the conduction loss is independent of duty cycle (ignoring dead time):

$$P_{cond} = 2\,I_{ph}^2\,R_{ds,on}(T_j) \;+\; I_{ph}^2 R_{Cu} \;+\; I_{bus}^2 R_{shunt}$$

### 1.2 Temperature dependence

$$R_{ds,on}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)],\qquad \alpha \approx 0.0045\ \text{K}^{-1}$$

| T_j | R_ds,on |
|---|---|
| 25 °C | 0.90 mΩ |
| 100 °C | 1.20 mΩ |
| 125 °C | 1.31 mΩ |

### 1.3 Numbers at 80 A, T_j = 110 °C (R_ds,on = 1.24 mΩ)

| Term | Expression | Loss |
|---|---|---|
| FET conduction | 2 · 6400 · 1.24 mΩ | 15.9 W |
| Phase copper and pads (≈0.25 mΩ per path) | 6400 · 0.25 mΩ | 1.6 W |
| Shunt, 0.5 mΩ, at I_bus ≈ D·I_ph, D ≈ 0.85 | (68)² · 0.5 mΩ | 2.3 W (shared by all channels if single shunt) |

**Conduction subtotal per channel:** ≈ 17.5 W, plus the shared shunt.

### 1.4 Electro-thermal fixed point (runaway criterion)

Conduction loss rises with junction temperature, which in turn rises with loss:

$$T_j = T_{ref} + R_{\theta}\,P(T_j),\qquad P(T_j)=P_0[1+\alpha(T_j-25)]$$

The closed-form solution is:

$$T_j=\frac{T_{ref}+R_\theta P_0(1-25\alpha)}{1-\alpha R_\theta P_0}$$

The system is stable only if:

$$\alpha\,R_\theta\,P_0 < 1$$

Applying this to one FET:
- P₀ ≈ 7.4 W at 25 °C.
- R_θ(j→board) ≈ 4.2 K/W.
- Result: α R_θ P₀ = 0.14.

This is stable locally. The board-level loop is the real limit (§3).
