# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specifications for Job #47, so the design below uses explicit assumptions. Every assumption is a named constant in the code, so you can change it in one place. Values marked **⚠ VERIFY** must be checked against your hardware or datasheet before you fly or power it.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz (FPU, CORDIC). Portable C++17, no heap. |
| Motors | Gimbal BLDC, 12N14P, pole pairs p = 7, R ≈ 5 Ω, L ≈ 1.5 mH ⚠ VERIFY |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| IMUs | 2 × ICM-42688-P on the camera plate (redundant, averaged), ODR 8 kHz, SPI |

**Loop schedule.** Use a bandwidth separation of at least 5–10× between successive loops.

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM | 40 kHz center-aligned | — |
| Current (FOC) loop | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity loop | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Attitude/angle loop | 1 kHz | ω_a ≈ 2π·20 rad/s |
| IMU sampling | 8 kHz, decimated to 4 kHz after filtering | — |

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant; assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform.** The electrical angle is θ_e = p·θ_m − θ_offset.
