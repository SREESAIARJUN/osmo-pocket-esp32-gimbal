# Job #54: FOC Control Loop and Dual-IMU Fusion Design for a 3-Axis Gimbal

## 0. Assumptions and Scope

I don't have the Job #54 specification, so this design uses common gimbal hardware. Every assumption below is a named parameter in the code, so substituting your values does not change the structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, ≥150 MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Commutation sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| IMUs | 2× ICM-42688-P on SPI, mounted on the camera plate, symmetric about the payload rotation center |
| PWM / current loop | 20 kHz center-aligned PWM; current loop at 20 kHz, synchronized to ADC sampling |
| Velocity loop | 4 kHz, using fused gyro data at 8 kHz ODR decimated by 2 |
| Angle loop | 1 kHz |
| Bus | Vdc = 12–16 V |

**Validate these four items on your hardware before closing the loops:**
1. Measure the motor's R and L.
2. Measure the payload inertia J.
3. Confirm the cogging order from your slot/pole count.
4. Check the ICM-42688-P register values against the current TDK datasheet revision.

## 1. Control Architecture

```
            1 kHz                 4 kHz                       20 kHz
θ_ref ─►[Angle P + FF]─ω_ref─►[Velocity PI + FF]─iq_ref─►[dq Current PI]─►SVPWM─►Motor
           ▲  θ_imu              ▲  ω_gyro          ▲ +iq_cog   ▲ id,iq (Park of ia,ib)
           │                     │                  │           │ θ_e from encoder
     [Mahony AHRS]◄──[Dual-IMU fusion + vibration filters]◄── 2× ICM-42688-P @ 8 kHz
                                                    │
                                     [Anti-cogging Fourier FF (θ_m)]
```

The design separates two angle sources:
- **Encoder:** used for commutation (θ_e) and for cogging phase (θ_m).
- **IMU:** used for the stabilization feedback, i.e. camera-frame attitude and rate.

### Bandwidth separation rule

ω_c,i ≥ 5·ω_c,v and ω_c,v ≥ 4–5·ω_c,θ. Typical targets:
- Current loop: f_c,i ≈ 1.5–2 kHz.
- Velocity loop: f_c,v ≈ 150–300 Hz.
- Angle loop: f_c,θ ≈ 30–60 Hz.
