# STM32H743 Nano FC + 4-in-1 80 A ESC: Architecture & Mathematical Model (Job #5)

## 0. Scope and Assumptions

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not drive the MOSFET gates directly. Each of the four ESC channels has its own motor MCU (AT32F421 running AM32) and a 3-phase gate driver. Commutating a sensorless BLDC from the H743 while it also runs EKF3 is not a sane design. The FC-to-ESC link is bidirectional DShot600.

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses 6-step trapezoidal drive with synchronous rectification (AM32 "complementary PWM"). At any instant one high-side and one low-side path carry the phase current I. Within each PWM cycle:

- During D·T_sw, current flows through HS_x and LS_y.
- During (1−D)·T_sw, the current freewheels through LS_x (synchronous) and LS_y.

In both sub-intervals, **exactly two channels carry I**. Conduction loss is therefore essentially duty-independent:

$$P_{cond,ch} = 2\,I^2\,R_{ds(on)}(T_j)$$

Hot resistance:

$$R_{ds(on)}(T_j) = R_{25}\left[1+\alpha (T_j-25)\right] \approx R_{25}\,k_T$$

With R_ds(on) = 1.2 × 1.6 = 1.92 mΩ:

$$P_{cond,ch} = 2 (80)^2 (1.92\times10^{-3}) = \mathbf{24.6\ W}$$

### 1.2 Per-FET distribution

Each FET conducts during 120° of the electrical cycle. The time-averaged loss is about 1/3 of a single-switch loss:

$$P_{FET,avg} \approx \tfrac{1}{3} I^2 R_{ds} = \tfrac{1}{3}(6400)(1.92\text{m}) \approx 4.1\ \text{W}$$

The low-side FETs also absorb the freewheel share, roughly scaled by (1−D). At D ≈ 0.5, the hottest FET sees about 5–6 W average.

### 1.3 Self-consistent temperature solution

Because R_ds(on) rises with temperature, solve iteratively:

$$T_j = T_{pcb} + P_{FET}(T_j)\,R_{\theta JC}$$

$$P_{FET}(T_j) = P_0\left[1+\alpha(T_j-25)\right]$$

where α ≈ 0.006/K.

The closed form converges if α·P₀·R_θ < 1, which is easily satisfied here:

$$T_j = \frac{T_{pcb} + P_0 R_\theta (1-25\alpha)}{1-\alpha P_0 R_\theta}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing phase switches at f_sw. The commutation-rate switching (eRPM-related, a few kHz) is negligible.

| Term | Formula | Value / channel |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½(25.2)(80)(40 ns)(48 k) = **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw | 30 n·25.2·48 k = **0.036 W** |
| C_oss charge | ½·C_oss·V²·f_sw | ½(1.5 n)(635)(48 k) = **0.023 W** |
| Dead-time diode | 2·V_SD·I·t_dt·f_sw | 2(0.8)(80)(50 n)(48 k) = **0.31 W** |
| Gate drive (2 FETs) | 2·Q_g·V_drv·f_sw | 2(50 n)(10)(48 k) = **0.048 W** (dissipated in driver/R_g) |
| **Total** | | **≈ 2.35 W** |

**Sensitivity.** Overlap loss scales linearly with f_sw. At 24 kHz it is about 0.97 W; at 96 kHz about 3.9 W. 48 kHz is a reasonable compromise: low audible noise, low motor current ripple on low-inductance quad motors, and only about 9% of total loss.

**Current ripple check** (motor phase-to-phase L ≈ 20 µH, worst case D = 0.5):

$$\Delta I_{pp} = \frac{V_{bus}D(1-D)}{L f_{sw}} = \frac{25.2(0.25)}{20\mu \cdot 48k} \approx 6.6\ \text{A}$$

This adds a small RMS term, (ΔI)²/12 ≈ 3.6 A², which is negligible against 6400 A
