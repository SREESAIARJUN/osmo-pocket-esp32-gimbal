# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #58 specification, so this design uses typical brushless gimbal parameters. Every value marked **[P]** is a parameter you must replace with measured or identified values for your hardware.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH **[P]** |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (e.g., AS5048A / MT6701) |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G4 / H7), center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR = 8 kHz, sharing a CLKIN source |
| Control intent | The stabilization loops act on **camera attitude/rate measured by the IMUs**. The encoders are used for commutation, cogging compensation and joint-space Jacobians. |

### Loop rate hierarchy

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1.5 kHz |
| Velocity (rate) | 4 kHz | 250 µs | ω_v ≈ 2π·60–120 Hz (limited by structural modes) |
| Angle (attitude) | 1 kHz | 1 ms | ω_θ ≈ ω_v/4 |
| IMU fusion | 8 kHz in, 4 kHz out | — | — |

Bandwidth separation of at least 4–5× between nested loops is required so each inner loop looks like unity gain to the loop outside it.
