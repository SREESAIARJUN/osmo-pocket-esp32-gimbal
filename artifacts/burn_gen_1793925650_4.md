# STM32H743 Nano FC + 4-in-1 ESC: Reference Architecture and Mathematical Model

## 0. Scope and Assumptions

Two points need to be settled before the math.

1. **Partitioning.** The STM32H743 does not commutate the motors directly. In every production 4-in-1 stack running ArduPilot, the H743 is the flight controller. It sends bi-directional DShot600 to four ESC MCUs (or one quad-channel MCU), such as the AT32F421 running AM32 or BLHeli_32. Those MCUs generate the 48 kHz complementary PWM through 3-phase gate drivers like the FD6288Q. This document models that architecture.
2. **No specific BOM was supplied.** All component values below are representative parameters for a 6S, 80 A-burst-class design. Every number is shown with its source formula, so you can substitute datasheet values. The netlists are reference topologies. They must be validated against real parts, simulated, and DRC-checked before fabrication.

**Operating point used throughout:**

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst case for switching) |
| I_burst | 80 A | Per-channel DC-link burst current |
| f_sw | 48 kHz | ESC PWM frequency |
| R_DS(on),25 | 0.70 mΩ | Typical 40 V, 5×6 mm MOSFET |
| k_T | 1.6 | R_DS(on) multiplier at T_j ≈ 125 °C |
| t_r, t_f | 20 ns each | With ~2 A gate drive, R_g ≈ 2.2–4.7 Ω |
| t_dt | 200 ns | Dead time per edge |
| V_SD | 0.8 V | Body-diode forward voltage at 80 A |
| Q_rr | 50 nC | Body-diode reverse-recovery charge |
| C_oss,eq | 1.5 nF | Energy-equivalent output capacitance |
| Q_g | 60 nC | Gate charge at V_GS = 10 V |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

The model assumes trapezoidal (6-step) commutation with complementary synchronous PWM on the active high side.

- At any instant, current flows through exactly **two** conducting channels in series.
- During the on-time D, the path is one high-side FET (HS) plus one low-side FET (LS).
- During the off-time (1−D), the path is the synchronous LS of the PWM leg plus the same LS of the return leg.

Over a full PWM period, two R_DS(on) are always in the path:

$$P_{cond,ch} = I^2 \cdot 2\,R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j)=R_{25}\,[1+\alpha(T_j-25)] \approx k_T R_{25}$$

$$P_{cond,ch} = 80^2 \times 2 \times (0.70\,\text{m}\Omega \times 1.6) = 6400 \times 2.24\,\text{m}\Omega = \mathbf{14.3\ W}$$

### 1.2 Per-FET distribution

Each leg conducts for 2/3 of the electrical cycle. It is the HS for 1/3 of the cycle and the LS for 1/3.

$$P_{HS,avg} = \tfrac{1}{3} I^2 R\,D \qquad P_{LS,avg} = \tfrac{1}{3} I^2 R\,(2-D)$$

At D = 0.5:

- HS FET: 1.19 W
- LS FET: 3.58 W

**The low-side FETs dominate thermally.** Size the copper under the LS FETs first.

Instantaneous peak dissipation is I²R = 7.2 W per FET. This matters at low eRPM. When the commutation period becomes comparable to the die thermal time constant (~1–5 ms), the junction tracks the 7.2 W peak rather than the average.

### 1.3 Copper and shunt conduction

These losses are often larger than designers expect:

$$P_{Cu} = I^2 (R_{trace} + R_{shunt}) = 6400 \times (0.4 + 0.25)\,\text{m}\Omega = \mathbf{4.2\ W/ch}$$

This assumes 2 oz copper and a 0.25 mΩ shunt.

Trace resistance can be estimated as:

$$R_{trace} = \rho_{Cu}\,\frac{L}{w\,t}\,[1+0.0039(T-20)]$$

## 2. Switching Loss Model (48 kHz)

Only the PWM leg hard-switches. The synchronous LS soft-switches after the dead time.

| Mechanism | Formula | Value |
|---|---|---|
| V-I overlap | ½ V I (t_r+t_f) f_sw | ½·25.2·80·40 ns·48 k = **1.94 W** |
| Dead-time body-diode | V_SD · I · 2t_dt · f_sw | 0.8·80·400 ns·48 k = **1.23 W** |
| Reverse recovery | Q_rr · V · f_sw | 50 nC·25.2·48 k = **0.06 W** |
| C_oss | ½ C_oss V² f_sw | **0.02 W** |
| Gate drive (6 FETs) | 6 · Q_g V_GS f_sw | 0.17 W (mostly dissipated in the driver/R_g) |
| **Total switching** | | **≈ 3.4 W/ch** |

**Design levers:**

- Dead-time loss scales linearly with t_dt. Cutting it to 100 ns saves about 0.6 W per channel. Only do this if the driver's propagation-delay mismatch allows it.
- Overlap loss scales with f_sw. Moving from 48 kHz to 24 kHz halves it but raises ripple current.

## 3. Total Loss Budget

| | Per channel | ×4 channels |
|---|---|---|
| MOSFET conduction | 14.3 W | 57.2 W |
| Switching + diode | 3.4 W | 13.6 W |
| Copper + shunt | 4.2 W | 16.8 W |
| **Total** | **21.9 W** | **≈ 88 W** |

Efficiency at burst: P_out ≈ 25.2·80·4 = 8064 W, so η ≈ 98.9%.

**80 A on all four channels is strictly a transient rating.** No nano-format board can dissipate 88 W continuously.

## 4. Thermal Model

### 4.1 Network (Cauer-equivalent)

```
T_j ─[R_jc 0.8 K/W]─ T_case ─[R_cb 15–25 K/W per FET pad, via-array]─ T_PCB
     ─[R_pcb-amb ≈ 4–8 K/W board, airflow dependent]─ T_amb
C_die ~0.05 J/K   C_PCB+heatspreader ≈ 10–15 J/K
```

### 4.2 Junction rise above the board (LS FET, worst case)

$$\Delta T_{j-b} = P_{LS}(R_{jc}+R_{cb}) = 3.58 \times (0.8 + 15) \approx 57\ \text{K}$$

The board-to-FET path (thermal vias plus the copper pour) is the critical resistance. Use at least 20 filled or plugged 0.3 mm vias under each drain tab.

### 4.3 Board bulk temperature during a burst

Treat the board as adiabatic, since the time constant τ = R·C ≈ 5 × 12 ≈ 60 s is much longer than the burst:

$$\Delta T_{board}(t) = P\,R_{th}\left(1-e^{-t/\tau}\right) \approx \frac{P\,t}{C_{th}}$$

| Burst | ΔT_board (88 W, C = 12 J/K) | T_j (T_amb = 40 °C) |
|---|---|---|
| 2 s | 15 K | 40+15+57 = **112 °C** ✔ |
| 5 s | 37 K | **134 °C** ✔ (near limit) |
| 10 s | 73 K | **170 °C** ✖ exceeds 150–175 °C limit |

**Rating conclusion:** specify the board as **80 A burst for ≤ 5 s**. The continuous rating follows from steady state with forced airflow (R_pcb-amb ≈ 4 K/W, T_board ≤ 100 °C):

$$I_{cont} = 80\sqrt{\frac{(100-40)/4}{88}} \approx 33\ \text{A/ch}$$

Note that the loss is not purely I² (switching scales roughly linearly with I), so the true continuous rating is slightly higher. **Market it as 35 A continuous / 80 A 5-second burst.**

Also iterate R_DS(on)(T_j). Loss and temperature are coupled through the temperature coefficient. Solve the fixed point T_j = f(P(T_j)), which typically converges in 3–4 iterations. If it does not converge, you are in thermal runaway.

## 5. Bi-directional DShot600 on the STM32H743 (ArduPilot)

### 5.1 Timing math

- Bit rate: 600 kbit/s, so t_bit = 1.667 µs. A frame is 16 bits, about 26.7 µs plus the reset gap.
- Timer clock on the H743 (SYSCLK 400 MHz, APB×2): f_TIM = 200 MHz.
- ArduPilot encodes each bit as N ticks (default 20 ticks per bit; 0 ≈ 7 ticks, 1 ≈ 14 ticks):

$$PSC+1 = \frac{f_{TIM}}{f_{bit}\cdot N} = \frac{200\text{ M}}{600\text{ k}\times 20} = 16.67$$

Rounding to 17 gives an actual rate of 588 kbit/s, a −2% error. That is well inside the ESC's tolerance.

- **Telemetry return:** about 30 µs after the frame, the ESC replies with a 21-bit GCR-encoded eRPM at 5/4 × 600 k = 750 kbit/s, so t_bit = 1.333 µs. The total return window is about 28 µs.
- The H743 captures edges via input-capture DMA, then decodes GCR → 16-bit word → CRC → eR
