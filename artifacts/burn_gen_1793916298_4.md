## 1. Conduction Loss Model

### 1.1 Current path in 6-step with synchronous rectification
Each 60° commutation sector has one PWM'd phase and one phase held low.

- **PWM ON (duration D):** current flows through the high-side FET (PWM phase) and the low-side FET (return phase).
- **PWM OFF (duration 1−D):** current flows through the low-side FET of the PWM phase (synchronous rectification) and the same return low-side FET.

So **two FETs carry I continuously, independent of D** (dead time ignored):

$$P_{cond,motor} = I^2\left[D\,R_{HS}+(1-D)R_{LS}+R_{LS,ret}\right] \approx 2\,I^2 R_{ds}(T_j)$$

### 1.2 Temperature dependence
$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At an assumed T_j = 100 °C:

$$R_{ds} = 0.70 \times (1 + 0.0065 \times 75) = 1.04\ \text{mΩ}$$

### 1.3 Evaluation at 80 A
$$P_{cond,FET}=2\times 80^2\times 1.04\text{ m}\Omega = \mathbf{13.3\ W/motor}$$

$$P_{cu}=I^2R_{cu}=6400\times0.30\text{ m}\Omega=\mathbf{1.9\ W/motor}$$

### 1.4 Thermal-runaway check
Conduction loss feeds back into T_j. The stability condition is:

$$\frac{\partial P}{\partial T_j}\,R_{\theta} = 2I^2R_{ds,25}\,\alpha\,R_{\theta} < 1$$

With R_θ = 5 K/W: 2 × 6400 × 0.7 m × 0.0065 × 5 ≈ 0.29. This is stable, with gain margin ~3.4×.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd half-bridge switches; the return low-side FET is static. Per motor:

| Component | Equation | Value |
|---|---|---|
| V-I overlap (hard-switched HS) | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·40 ns·48 k | **1.94 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200 ns·48 k | **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 k | **0.06 W** |
| C_oss charge/discharge | C_oss·V²·f_sw (both FETs, approx.) | **0.05 W** |
| Gate drive (dissipated in driver/R_g) | 2·Q_g·V_gs·f_sw = 2·60 nC·10·48 k | **0.06 W** |
| **Total switching-related** | | **≈ 2.7 W/motor** |

### Frequency sensitivity
$$\frac{\partial P_{sw}}{\partial f_{sw}}\approx 54\ \mu\text{W/Hz}$$

Dropping from 48 kHz to 24 kHz saves ≈ 1.3 W/motor (~8 % of total). The cost is higher current ripple and audible noise at low throttle.

Current ripple (motor L_ph–ph assumed 15 µH, worst case D = 0.5):

$$\Delta I \approx \frac{V\,D(1-D)}{L f_{sw}} = \frac{25.2\times0.25}{15\,\mu\text{H}\times48\text{k}} \approx 8.8\ A_{pp}$$

The added RMS conduction loss from this ripple is (ΔI²/12)/I² ≈ 0.1 %, which is negligible.
