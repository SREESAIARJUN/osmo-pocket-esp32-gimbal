# STM32H743 Nano FC + 4-in-1 80A ESC: Reference System Architecture (Job #3)

**Scope:** Power-stage loss model (conduction, switching, diode, reverse-recovery), transient thermal model for 80A bursts, ArduPilot bidirectional DShot600 timer and DMA allocation on the H743, and a hierarchical reference netlist.
