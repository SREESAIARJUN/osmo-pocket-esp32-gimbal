## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{\text{off}})\big)$$

Here θ_off is found at commissioning by applying V_d along α and reading θ_m.

Latency compensation: the encoder sample is about one PWM period old when the new duties take effect, so the angle is extrapolated:

$$\theta_e^{\text{use}} = \theta_e + p\,\hat\omega_m\,(1.5\,T_{pwm})$$

### 1.2 Clarke and Park (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad (i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque: $\tau = \tfrac32 p\lambda_m i_q = K_t\, i_q$.

### 1.4 Current PI with decoupling (pole–zero cancellation)

With decoupling feedforward, each axis becomes $G(s) = \dfrac{1}{Ls+R}$. Choose

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

The PI zero then cancels the electrical pole, giving the closed loop $\dfrac{\omega_{ci}}{s+\omega_{ci}}$. Use $\omega_{ci} \le 2\pi f_{pwm}/20 \approx 2\pi\cdot 1\,\text{kHz}$.

Discrete form (forward Euler, T_s = 1/f_pwm), with back-calculation anti-windup:

$$
\begin{aligned}
e_x[k] &= i_x^*[k] - i_x[k]\\
u_x[k] &= K_p e_x[k] + I_x[k] + v_x^{ff}[k]\\
v_d^{ff} &= -\omega_e L \hat i_q,\qquad v_q^{ff} = \omega_e L \hat i_d + \omega_e\lambda_m\\
(v_d,v_q) &= \operatorname{sat}_{\text{circle}}(u_d,u_q;\ V_{max}=V_{bus}/\sqrt3)\\
I_x[k+1] &= I_x[k] + K_i T_s\, e_x[k] + K_{aw}\,(v_x - u_x),\qquad K_{aw}\approx K_i T_s/K_p
\end{aligned}
$$

Circle saturation gives d-axis priority: $|v_d|\le V_{max}$ and $v_q = \operatorname{sgn}(u_q)\min\!\big(|u_q|,\sqrt{V_{max}^2-v_d^2}\big)$.

> **Note on high-resistance gimbal motors.** Gimbal motors with R ≳ 10 Ω are often run *voltage-mode*: $v_q = R\,i_q^* + \omega_e\lambda_m$, with no current sensing. The code supports this via `kVoltageMode
