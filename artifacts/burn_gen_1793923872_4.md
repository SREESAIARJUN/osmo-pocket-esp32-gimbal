# 3-Axis Gimbal Control Design: FOC, Cascaded PID, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #34 specification, so this design uses the assumptions below. Every parameter that depends on them is a named constant or a config field, so you can substitute your actual values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 or H7 class, single-precision FPU, about 170 MHz or more |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensing | 14-bit absolute magnetic encoder per axis (AS5048A, MT6701 or similar) |
| Current sensing | 2-phase inline shunts (voltage-mode fallback provided) |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI, gyro ODR 8 kHz decimated to 4 kHz |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
