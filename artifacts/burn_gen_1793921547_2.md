## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms
Two phase currents are measured. Assume i_a + i_b + i_c = 0.

**Clarke transform:**
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Electrical angle:**
$$\theta_e = p\,\theta_m - \theta_{e,0}$$

where θ_e,0 is the encoder offset found during calibration.

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 SVPWM (min–max zero-sequence injection)
Phase voltages from the inverse Clarke transform:
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset and duty cycles:
$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The linear range is |v_dq| ≤ V_bus/√3. The voltage vector is circularly limited to that value.

### 1.3 Plant and PI design
Stator dynamics in the rotor (dq) frame:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

**Decoupling feedforward** removes the cross-coupling and back-EMF terms:
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda)$$

After decoupling, each axis is the first-order plant 1/(Ls + R).

**PI with pole–zero cancellation:**
$$C_i(s)=K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The closed loop is then first order:
$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/20 (about 2π·1 kHz at 20 kHz PWM).

**Torque:**
$$\tau = \tfrac32 p\lambda\, i_q = K_t\, i_q \qquad (i_d^*=0)$$

**Anti-windup** uses back-calculation:
$$\dot x_I = K_i e + K_{aw}(u_{sat}-u),\qquad K_{aw}\approx 1/K_p\cdot K_i$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant (per axis)
$$J\dot\omega_m = K_t i_q - \tau_{cog}(\theta_m) - b\,\omega_m - \tau_d$$

τ_d is the disturbance torque: base motion, cable drag, and unbalance.
