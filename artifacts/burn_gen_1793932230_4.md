# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the specification for "Job #7," so this design rests on the assumptions below. Replace them with your actual motor, encoder and mechanical data. All gain formulas are parametric, so only the numbers change.

| Parameter | Assumed value |
|---|---|

## 1. Loop Architecture and Rates

```
 Attitude ref ─►[Angle loop 1 kHz]─ω*─►[Velocity loop 4 kHz]─iq*─►[Current loop 20 kHz]─►SVPWM
     ▲                 ▲                     ▲      ▲ + iq_cog(θm)            ▲
     │           q_cam (Mahony)        ω_joint(gyro) │                       ia,ib, θe
     │                 ▲                     ▲   Anti-cogging FF
     └──── Dual ICM-42688-P → align → fuse → notch bank → LPF ─────┘
```

Each outer loop's bandwidth should be about 4–10× below the loop it commands. With the assumed numbers:

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·120 rad/s
- Angle loop: ω_θ ≈ 2π·20 rad/s

## 2. Field-Oriented Control (Inner Current Loop)

### 2.1 Transforms

The electrical angle is θ_e = p·θ_m − θ_offset, where p = 7 pole pairs.

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
