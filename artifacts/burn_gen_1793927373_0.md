## 0. Architectural Correction

The H743 should **not** commutate the motors directly.

- **The H743 lacks enough channels.** Twelve half-bridges need 12 complementary PWM pairs. The H743 offers only TIM1 (3 pairs), TIM8 (3 pairs), and HRTIM (5 pairs), for a total of 11.
- **ArduPilot is not ESC firmware.** It has no 6-step or FOC ESC firmware.

**Adopted architecture:**

```
                 ┌─────────────── STM32H743 (ArduPilot) ───────────────┐
                 │ TIM1 CH1..CH4  ── Bidirectional DShot600 ──┐         │
                 └────────────────────────────────────────────┼─────────┘
                                                               │
   4× [ AT32F421K8U7 (AM32) → FD6288Q 3-ph gate driver → 6× N-MOSFET ]  → M1..M4
```

There is one ESC MCU per motor. The H743 only generates DShot and decodes eRPM telemetry.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 100 °C: R_DS = 1.0 × (1 + 0.0055 × 75) = **1.41 mΩ**.

### 2.2 Six-step commutation with synchronous (complementary) PWM

In each 60° sector, two phases conduct:

- The PWM leg conducts through the high-side for a fraction D of the time, and through the synchronous low-side for 1 − D.
- The return leg's low-side conducts for 100% of the sector.

$$P_{cond,motor} = I^2 R_{DS}\big[D + (1-D) + 1\big] = 2\,I^2 R_{DS}$$

This result is independent of duty cycle, which is why synchronous rectification matters. Each FET carries current for about 1/3 of the electrical cycle, so:

$$P_{cond,FET} = \tfrac{1}{6}\cdot 2 I^2 R_{DS} = \tfrac{1}{3} I^2 R_{DS}$$

**Numbers at 80 A, T_j = 100 °C:**

- P_cond,motor = 2 × 6400 × 1.41 m = **18.0 W**
- P_cond,FET ≈ **3.0 W**
- P_Cu,motor = I² × R_Cu = 6400 × 0.5 m = **3.2 W**

### 2.3 Electrothermal fixed point

Because R_DS rises with temperature, conduction loss and junction temperature must be solved together:

$$T_j = T_b + R_{th,jb}\,P_{FET}(T_j)$$

$$\Rightarrow\quad T_j = \frac{T_b + R_{th,jb}\,(k - \tfrac{1}{3}I^2R_{25}\alpha\cdot 25 + P_{sw})}{1 - R_{th,jb}\,\tfrac{1}{3}I^2R_{25}\alpha}$$

where k = ⅓ I² R₂₅. Thermal runaway occurs if R_th,jb · ⅓ I² R₂₅ α ≥ 1.

- With R_th,jb = 2 K/W: 2 × 2.13 × 0.0055 = 0.023. This is far below 1, so the design is stable.
