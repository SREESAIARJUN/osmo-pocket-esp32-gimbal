# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification for Job #47, so this design rests on the assumptions in Section 0. Every value that depends on your hardware is a named parameter. Replace those values with measurements from your motors before you close the loops.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value | Notes |
|---|---|---|
| Motor | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs) | R ≈ 5–15 Ω and L ≈ 2–5 mH per phase are typical |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A or MT6701) | Used for commutation and joint velocity |
| MCU | STM32G4 or H7 class with FPU | 32-bit float is sufficient |
| Current loop | 20 kHz, synchronous with the PWM-centred ADC trigger | |
| Velocity loop | 4 kHz (decimation of 5) | |
| Angle/attitude loop | 1 kHz (decimation of 20) | |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR 4 kHz, sharing a CLKIN
