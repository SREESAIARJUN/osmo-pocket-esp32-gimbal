## 0. Baseline Assumptions & Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), one per axis |
| IMU A | ICM-42688-P on the **camera payload** (primary attitude sensor) |
| IMU B | ICM-42688-P on the **base/handle frame** (vibration reference and base-rate feedforward) |
| Kinematic order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |

The design uses five rate groups:

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| IMU sampling (ODR) | 8 kHz | 125 µs |
| Velocity loop + PLL | 4 kHz | 250 µs |
| Attitude loop + fusion | 1 kHz | 1 ms |
| Cogging LMS update | 4 kHz (only while learning) | — |
