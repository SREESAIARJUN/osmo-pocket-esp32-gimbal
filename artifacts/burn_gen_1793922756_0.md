## 0. Architecture Clarification

The STM32H743 does **not** drive the MOSFETs directly. ArduPilot has no support for a single H7 commutating four BLDC motors, which would need 24 complementary PWM outputs and per-motor sensorless BEMF/FOC loops. The correct partitioning is:

 ┌────────────────────────── FC board (STM32H743VIT6, 400 MHz) ──────────────────────────┐
 │ ArduPilot ── RCOutput ── TIM3/TIM4 + DMA ── bidir DShot600 ── M1..M4 signal pins     │
 └───────────────────────────────────────┬────────────────────────────────────────────
