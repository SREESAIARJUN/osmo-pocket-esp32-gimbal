# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #34): Architecture, Loss Model, and Timer Allocation

## 0. Architectural Clarifications

These points change the math, so they come first.

1. **The STM32H743 does not drive the MOSFETs.** In every production 4-in-1 design, the H743 runs ArduPilot and sends DShot600 to four (or one) dedicated ESC MCUs. Typical choices are AT32F421 or STM32G071 running AM32/BLHeli_32 firmware, which drive 3-phase gate drivers (e.g., FD6288Q). The 48 kHz figure is therefore the **ESC-MCU PWM frequency**, not an H743 timer. I model it that way.
2. **"80 A burst" must be qualified.**
   - 80 A per channel × 4 = **320 A** from the battery. That is beyond XT60 or XT90 ratings and beyond any 20×20 or 30×30 "nano" PCB.
   - I compute both:
     - **Case A:** 80 A on one channel.
     - **Case B:** 80 A on all four channels simultaneously.
   - Case B shows the burst is only survivable for seconds.
3. **MOSFET parameters are representative assumptions, not a specific datasheet.** They reflect a 40 V, 3.3×3.3 mm DFN class part. Replace them with your selected part's values before freeze.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ |
| R_DS(on) temp coefficient | α | 0.005 /K |
| Rise / fall time (driver-limited) | t_r, t_f | 15 ns each |
| Output capacitance @ V_bus | C_oss | 1.5 nF |
| Body-diode forward voltage | V_F | 0.8 V |
| Reverse-recovery charge | Q_rr | 40 nC |
| Total gate charge | Q_g | 50 nC |

| PWM frequency | f_sw | 48 kHz |
| Junction-to-board thermal resistance (incl. vias) | R_θJB | 2.0 K/W |

## 1. Conduction Loss Model (6-step trapezoidal, synchronous/complementary PWM)

**Commutation structure**
- At any instant, two phase legs carry current I, and the third floats.
- Each leg is active for 2/3 of the electrical cycle.
- Within an active leg, current flows through the high-side FET for fraction D and the low-side FET (synchronous rectification) for 1 − D.
- So the leg always has one FET conducting.

**Temperature-dependent resistance**

R(T_j) = R₂₅ · [1 + α (T_j − 25)]

At T_j = 125 °C, R = 1.5 mΩ.

**Per-channel conduction loss**

- Two legs conduct at all times:
  P_cond,ch = 2 · I² · R(T_j)
- Per FET, averaged over an electrical cycle (worst case for a high-side FET at D → 1):
  P̄_FET ≈ I² · R(T_j) / 3
- Instantaneous loss while conducting:
  P_FET,on = I² · R(T_j)

**At I = 80 A, T_j = 125 °C**

| Quantity | Value |
|---|---|
| P_cond,ch | 2 × 6400 × 0.0015 = **19.2 W** |
| P̄_FET | 3.2 W |
| P_FET,on | 9.6 W |

**PCB copper loss**
- Assume 0.25 mΩ effective per-channel path (bus planes + phase pours + solder pads, 2 oz outer layers).
- P_Cu,ch = 80² × 0.25 mΩ = **1.6 W**

**DC-link capacitor ripple**
- I_C,rms ≈ I · √(D(1 − D)), which peaks at D = 0.5 at **40 A rms per channel**.
- With an aggregate ESR of 5 mΩ: P_cap = 40² × 0.005 = **8 W**, concentrated in the capacitors.
- This is the most commonly overlooked failure mode on nano boards. Use a polymer bulk capacitor plus a low-ESR MLCC bank at each half-bridge.

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing leg hard-switches. The complementary FET commutates through its body diode during dead time.

| Mechanism | Equation | Value per channel |
|---|---|---|
| V–I overlap (hard switching) | ½ · V · I · (t_r + t_f) · f_sw | ½·25.2·80·30 ns·48 kHz = **1.45 W** |
| C_oss discharge (2 FETs) | 2 · ½ · C_oss · V² · f_sw | **0.046 W** |
| Dead-time body-diode conduction | V_F · I · 2·t_dead · f_sw | 0.8·80·200 ns·48 kHz = **0.61 W** |
| Reverse recovery | Q_rr · V · f_sw | **0.048 W** |
| Gate drive (2 switching FETs) | 2 · Q_g · V_GS · f_sw | **0.048 W** (dissipated mostly in driver) |
| **Total switching** | | **≈ 2.2 W** |

**Sensitivity**
- P_sw scales linearly with f_sw.
- Going from 48 → 24 kHz saves about 1.1 W per channel.
- The trade-off is more motor current ripple and more audible noise.
- Dead-time loss is about 28 % of switching loss. Tighten t_dead to the driver's propagation-skew limit, typically 50–80 ns.
