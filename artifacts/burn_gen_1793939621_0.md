## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle:

  θₑ = p·(θₘ − θ_offset), wrapped to [0, 2π)

Clarke transform (amplitude invariant, with i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2·i_b) / √3

Park transform:

  i_d = i_α·cos θₑ + i_β·sin θₑ
  i_q = −i_α·sin θₑ + i_β·cos θₑ

Inverse Park transform:

  v_α = v_d·cos θₑ − v_q·sin θₑ
  v_β = v_d·sin θₑ + v_q·cos θₑ

### 1.2 SVPWM via min/max zero-sequence injection

This is equivalent to sector-based SVPWM and avoids branching.

1. Phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Zero-sequence offset: v₀ = −½·(max(v_a, v_b, v_c) + min(v_a, v_b, v_c))
3. Duty per phase: dₓ = ½ + (vₓ + v₀) / V_bus, for x ∈ {a, b, c}
4. Linear-region limit: |v_dq| ≤ V_bus / √3. Apply a circular limit, with priority given to v_d.

### 1.3 Current PI controllers with decoupling

Motor model in the dq frame (ωₑ = p·ωₘ):

  v_d = R·i_d + L·(di_d/dt) − ωₑ·L·i_q
  v_q = R·i_q + L·(di_q/dt) + ωₑ·L·i_d + ωₑ·λ

Use pole-zero cancellation with closed-loop current bandwidth ω_c:

  K_p,i = L·ω_c
  K_i,i = R·ω_c   (continuous-time, units V/(A·s))

This gives i(s)/i*(s) = ω_c / (s + ω_c). Choose ω_c ≤ 2π·f_pwm / 20. With 20 kHz PWM, f_c ≈ 1 kHz, so ω_c ≈ 6283 rad/s.

Decoupled voltage commands:

  v_d* = PI_d(i_d* − i_d) − ωₑ·L·i_q
  v_q* = PI_q(i_q* − i_q) + ωₑ·L·i_d + ωₑ·λ,  where λ = Kt / (1.5·p)

The reference i_d* = 0 (surface-mount PMSM, no field weakening is needed at gimbal speeds).

Many gimbal motors have R ≈ 5–15 Ω. If you lack phase current sensing, use voltage-mode FOC instead: v_q = R·i_q* + ωₑ·λ. The rest of this design is unchanged.

### 1.4 Discrete PI with back-calculation anti-windup

Discretize with backward Euler at sample time Tₛ:

- Error: e[k] = r[k] − y[k]
- Unsaturated output: u_raw[k] = K_p·e[k] + I[k−1]
- Saturated output: u[k] = sat(u_raw[k] + u_ff[k])
- Integrator update: I[k] = I[k−1] + K_i·Tₛ·e[k] + K_aw·Tₛ·(u[k] − u_raw[k] − u_ff[k])
- Back-calculation gain: K_aw ≈ K_i / K_p, i.e. 1/T_i

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Plant

Mechanical dynamics:

  J·dω/dt = Kt·i_q − B·ω − τ_cog(θ) − τ_dist

Cascade structure:

  θ* ─►[P (+PI)]─► ω* (+ ω_ff) ─►[PI + ff]─► i_q* ─►[FOC]

Feedback sources:

- **Angle:** IMU attitude (camera orientation in the world frame), mapped to the joint axis.
- **Velocity:** gyro rate projected onto the joint axis. This has lower noise and delay than a differentiated encoder signal.
- **Commutation:** the encoder only.

### 2.2 Bandwidth separation and gains

Treat the current loop as unity gain up to ω_c. Choose ω_v = ω_c / 8 to 10 (≈ 2π·100 Hz) and ω_θ = ω_v / 4 to 5 (≈ 2π·20 Hz).

**Velocity PI.** With plant Kt/(J·s), place the PI zero at ω_v / 4 for about 60° phase margin:

  K_p,v = J·ω_v / Kt
  K_i,v = K_p,v·(ω_v / 4)

For J = 4e-4 and Kt = 0.10, this gives K_p,v = 0.25 A/(rad/s) and K_i,v = 39 A/rad.

**Angle loop.** Use P plus optional small I for static disturbance such as payload imbalance:

  ω* = K_p,θ·e_θ + K_i,θ·∫e_θ dt + ω_ff,  with K_p,θ = ω_θ (rad/s per rad) and K_i,θ ≤ K_p,θ·ω_θ / 10

- ω_ff = dθ*/dt
- i_ff = (J·α* + B·ω*) / Kt + i_cog(θₘ)   (cogging term from §3)
