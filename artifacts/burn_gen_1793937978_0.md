## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(\text{using } i_a+i_b+i_c=0)$$

**Park transform** (θ_e = electrical angle):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Electrical angle:**

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

where p is the pole-pair count.

**Delay compensation.** Compensate for ADC → compute → PWM-update latency, typically about 1.5 T_s:

$$\theta_e^{\text{comp}} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Machine Model

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

**Torque:**

$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d-L_q)i_d i_q\right] \approx K_t i_q,\quad K_t = \tfrac32 p\lambda_m$$

### 1.3 PI with Pole-Zero Cancellation

The plant per axis is $G_i(s) = \dfrac{1}{Ls+R}$. Choosing $C_i(s) = K_p + \dfrac{K_i}{s}$ with $K_i/K_p = R/L$ cancels the electrical pole. The closed loop then becomes first order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Keep $\omega_c \le 2\pi f_{PWM}/10$ for adequate phase margin under the 1.5 T_s delay.

**Discrete form** (forward-Euler integrator with back-calculation anti-windup):

$$u_k = K_p e_k + I_k + u_{ff,k}$$

$$u_k^{sat} = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_k^{sat}-u_k),\quad K_{aw} = \frac{K_i}{K_p} T_s$$

**Decoupling feedforward:**

$$u_{ff,d} = -\omega_e L_q i_q,\qquad u_{ff,q} = \omega_e L_d i_d + \omega_e \lambda_m$$

**Voltage limit (circular).** The d-axis has priority:

$$|v_d| \le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

### 1.4 SVPWM via Min-Max Zero-Sequence Injection

1. Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

2. Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

3. Zero-sequence offset:

$$v_0 = -\tfrac12\left[\max(v_{abc}) + \min(v_{abc})\right]$$

4. Duty cycle per phase:

$$D_x = \frac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM.
