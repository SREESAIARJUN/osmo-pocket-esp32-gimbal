# STM32H743 AIO Flight Controller with 4‑in‑1 80 A ESC: Systems Architecture Model

**Scope:** 80 A burst conduction losses, 48 kHz switching losses, ArduPilot bidirectional DShot600 timer/DMA allocation, reference netlist, and thermal model.

I don't have prior context for "Job #14," so this starts from first principles and states every assumption explicitly. Replace the parameter table with your actual BOM values. The equations are written so you can recompute directly.

---

## 0. Architecture Clarification

ArduPilot does not contain BLDC commutation firmware. An "H743 4‑in‑1 ESC" is therefore an **AIO board**: the STM32H743 runs ArduPilot, and four ESC MCUs run AM32 or BLHeli_32. Each motor is commanded over bidirectional DShot600.

```
 6S LiPo ──► VBAT bus ──► 4× [ESC MCU ─► 3‑ph gate driver ─► 6× N‑FET] ─► motors
              │
              └─► 5V/10V/3V3 regulators ─► STM32H743 (ArduPilot)
                                               │  4× bidir DShot600 (single‑wire, half‑duplex)
                                               └─────────────► ESC MCU 1..4
```

The ESC MCU is typically an AT32F421 or STM32G071 running AM32. Alternatively, one STM32F051 per motor may be used.

**Commutation scheme:** 6‑step trapezoidal with complementary (synchronous) PWM, which is the AM32 default. At any instant, current flows through **exactly two FETs**:

- the PWM'd high side, or its synchronous low‑side partner during the off‑time;
- the static low side of the return phase.

## 2. Conduction Loss Model

### 2.1 Per‑motor conduction loss

During the on‑time D, current flows through HS_a and LS_b. During the off‑time (1−D), it flows through LS_a (synchronous) and LS_b. Therefore:

$$P_{cond} = I^2 R_{ds}(T_j)\left[D + (1-D) + 1\right]\frac{1}{N_{par}} = \frac{2\,I^2 R_{ds}(T_j)}{N_{par}}$$

The loss is independent of D with synchronous rectification, but it is unevenly distributed. The static low side carries current for 1/3 of the electrical cycle at 100 %. Each FET therefore averages:

$$P_{FET,avg} = \frac{P_{cond}}{6}\cdot\frac{6}{3}\cdot\frac{1}{2}\ \text{(over rotation)} \approx \frac{P_{cond}}{3}\ \text{for each FET active at a time}$$

In practice, use **P_cond / 6 averaged** for steady state. Use **P_cond / 2** for peak instantaneous junction heating within a commutation sector (each sector is about 50–200 µs, which is shorter than the FET thermal time constant, so averaging is valid above roughly 1 krpm).

### 2.2 Temperature‑dependent R_ds(on), solved self‑consistently

$$R_{ds}(T_j) = R_{ds,25}\,[1 + k_T(T_j - 25)]$$

$$T_j = T_a + P(T_j)\,R_{θ,JA,eff} \;\Rightarrow\; P = \frac{2I^2R_{25}(1 + k_T(T_a - 25))}{1 - 2I^2R_{25}k_T R_{θ}}$$

The denominator is a thermal‑runaway criterion. The system is unstable if

$$2I^2 R_{25}\,k_T\,R_{θ} \ge 1$$

At 80 A, 2 × 6400 × 0.0025 × 0.0045 = 0.144 W/K. Runaway therefore occurs at **R_θ ≥ 6.9 K/W** (board‑to‑air, per motor). A 20×20 board in prop wash is about 8–15 K/W total. **At 80 A, steady state does not exist on a 20×20 board. 80 A is strictly a transient (burst) rating.**
