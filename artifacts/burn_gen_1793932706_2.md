## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC (e.g. GBM2804/GM3506 class), 12N14P → pole pairs `p = 7` |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the plate centroid, SPI at 24 MHz, ODR = 8 kHz |
| Gimbal kinematics | Yaw (outer) → Roll (middle) → Pitch (inner) |

**Loop rates (all integer-divided from one PWM timer):**

```
PWM / current loop (FOC) : f_c = 20 kHz   (Ts_c = 50 µs)   ADC-injected ISR
Velocity (rate) loop     : f_v = 4 kHz    (Ts_v = 250 µs)  every 5th FOC tick
IMU fusion               : f_i = 8 kHz    (DRDY / FIFO)    filters at 8k, attitude at 2k
Attitude (angle) loop    : f_a = 1 kHz    (Ts_a = 1 ms)
```

Bandwidth separation rule: each outer loop should have ≤ 1/5 of its inner loop's closed-loop bandwidth.
- Current loop: ~2 kHz
- Rate loop: ~150–250 Hz
- Angle loop: ~20–40 Hz

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt{3}}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Design (Pole-Zero Cancellation)

The d-q voltage equations are:

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

After decoupling, each axis reduces to $G(s) = \frac{1}{Ls + R}$. Choose the PI controller $C(s) = K_p + K_i/s$ so that its zero cancels the electrical pole:

$$K_p = L\,\omega_{cc},\qquad K_i = R\,\omega_{cc}\quad\Rightarrow\quad T(s) = \frac{\omega_{cc}}{s+\omega_{cc}}$$

Choose $\omega_{cc} \le 2\pi f_c/10$ (≈ 2π·2 kHz).

Gimbal motors have high R (5–15 Ω) and low L (~1–3 mH). If you have no current sensing, voltage-mode FOC ($v_q = R\,i_q^* + \omega_e\lambda_m$) is a valid fallback. The code supports both modes.

### 1.3 Discrete PI with Back-Calculation Anti-Windup

The discrete control law:

$$u_k = K_p e_k + I_k$$

$$u_k^{\text{sat}} = \text{sat}(u_k)$$

The integrator update includes a back-calculation term:

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_k^{\text{sat}} - u_k),\qquad K_{aw}\approx \frac{K_i T_s}{K_p}$$

Feedforward decoupling terms are added to the PI outputs:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$
