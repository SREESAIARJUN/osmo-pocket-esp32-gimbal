# STM32H743 Nano FC + 4-in-1 ESC (Job #62): Architecture, Loss Model, DShot DMA Plan

## 0. Architecture Assumptions and Corrections

Two scoping points shape everything below.

1. **The H743 should not commutate the motors.** ArduPilot does not run ESC commutation, and bi-directional DShot is a protocol *between* a flight controller and ESC MCUs. The architecture is therefore:
   - **H743 (FC):** runs ArduPilot and emits 4× BDShot600.
   - **4× ESC MCU** (for example AT32F421 or STM32G071 running AM32): one per channel, each driving one 3-phase gate driver and six N-FETs.
2. **"80 A burst" on a nano board is thermally marginal.** The math below shows it holds for about 3 s with all four channels loaded, and that loop-inductance overshoot can exceed a 40 V FET rating at 6S. Treat the numbers as a design gate, not a marketing figure.

## 1. Conduction Loss Model

The model assumes 6-step trapezoidal commutation with synchronous (complementary) PWM. At every instant the current path contains exactly two FETs: either HS(phase A) + LS(phase B), or LS(A) freewheeling + LS(B).

**Per-channel conduction loss:**

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds,hot} = 2(80)^2(1.5\text{ m}\Omega) = \mathbf{19.2\ W}$$

**Temperature coupling.** R_ds depends on junction temperature, so solve the two equations iteratively:

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)],\qquad \alpha\approx0.006\ \text{K}^{-1}$$

$$T_j = T_{pcb} + P_{FET}\,R_{th(j-c)}$$

The solution converges in 2–3 iterations.

**Per-FET average.** Each switch conducts for 120° electrical, so the 19.2 W spreads across the six FETs:

$$P_{cond,FET}\approx \frac{19.2}{6} = 3.2\ \text{W}$$

**Copper loss** must be added. A 10 mm × 3 mm phase pour in 2 oz copper is about 0.25 mΩ:

$$80^2\times0.25\text{ m}\Omega = 1.6\ \text{W per channel}$$

This guide keeps it as margin rather than adding it to the totals below.

## 2. Switching Loss Model at 48 kHz

One leg hard-switches per PWM period.

| Term | Formula | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·30n·48k | 1.452 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200n·48k | 0.614 W |
| Reverse recovery | Q_rr·V·f_sw | 0.060 W |
| Output capacitance | ½·Q_oss·V·f_sw | 0.036 W |
| Gate drive (2 FETs) | 2·Q_g·V_gs·f_sw | 0.058 W (dissipated in driver) |
| **Total per channel** | | **≈2.22 W** |

**Totals at 80 A:**

- Per channel: 19.2 + 2.22 = **21.4 W**
- All four channels: **≈85.7 W**

Battery-side current in that case would be about 4×80×D. A true simultaneous 4×80 A burst only occurs at high duty cycle, near 7–8 kW total, so it is a worst-case envelope.
