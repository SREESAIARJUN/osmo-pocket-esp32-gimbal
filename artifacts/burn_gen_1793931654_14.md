## 0. Architecture Clarification (Important)

On every production AIO "nano" design, the STM32H743 does **not** drive the power stage directly. The topology is:

```
STM32H743 (ArduPilot) ──BDShot600──► 4× ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                        └─► 3-phase gate driver ──► 6× N-MOSFET per motor
                                              (48 kHz PWM generated here)
```

This split determines where each part of the analysis applies:
- **Sections 1–4** (thermal, switching, copper) cover the ESC power stage.
- **Section 5** (DMA/timers) covers the H743.

## 1. Conduction Loss Model

### 1.1 Current Path in 6-Step Synchronous PWM

During each 60° commutation sector, phase X is PWM'd and phase Y is held low:

- **PWM ON:** HS_X → motor → LS_Y (2 FETs in series)
- **PWM OFF:** LS_X (synchronous) → motor → LS_Y (2 FETs in series)

The phase current therefore **always passes through exactly 2 FETs in series**, regardless of duty cycle D.

The per-channel semiconductor conduction loss is:

$$P_{cond,ch} = I_{ph}^2 \cdot 2R_{DS}(T_j)$$

Each of the 6 FETs carries current for 1/3 of the electrical cycle on average. The electrical period at full rpm is 0.1–1 ms, which is much shorter than the die-to-board thermal time constants (≫10 ms). The time-averaged loss per FET is therefore valid:

$$\bar{P}_{cond,FET} = \frac{P_{cond,ch}}{6} = \frac{I_{ph}^2 \, R_{DS}(T_j)}{3}$$
