# STM32H743 Nano FC + 4-in-1 ESC (Job #20): Architecture, Loss Model, DShot/DMA Plan

## 0. Feasibility Findings

These findings drive the rest of the design and should be resolved before layout.

| # | Finding | Impact |
|---|---|---|
| F1 | **80 A on all four motors simultaneously means about 320 A from the battery.** This exceeds an XT60 (about 60 A continuous, roughly 180 A peak), a nano board's power copper, and practical 6S packs. | Spec "80 A burst" **per motor, staggered**, with an aggregate limit of about 150 A. The firmware current limit enforces this. |
| F2 | On a 20×20 or 25×25 mm board, total burst dissipation reaches **about 85 W** with all four motors at 80 A (Section 3). Sustained steady-state capability is **about 6 W**. | Bursts are thermal-mass limited to **about 3 s** with all four motors at 80 A. Sustained current is far lower (Section 4). |
| F3 | The H743 **does not generate the 48 kHz PWM**. The architecture uses 4× AT32F421 ESC MCUs running AM32, each doing 6-step commutation at 48 kHz. The H743 runs ArduPilot and only produces bidirectional DShot600. | Two separate timing domains. The DMA analysis applies only to the H743. |
| F4 | Pin and peripheral assignments below are a **reference design**. They must be checked against the current STM32H743 datasheet (AF tables), the AM32 target definition, and the ArduPilot `hwdef` parser before tape-out. | Treat this as a design review input, not a released netlist. |

## 1. System Architecture

```
 6S LiPo (25.2 V max) ──XT60──┬── 4-in-1 power stage (24 FETs, 4× FD6288Q, 4× AT32F421)
                              │        ▲ bidir DShot600 ×4 (single-wire, open-drain-ish, 3.3 V)
                              │        │
                              └── 12 V/5 V buck ── 3.3 V LDO ── STM32H743VIT6 (ArduPilot)
                                                               ├ IMU (ICM-42688-P, SPI1)
                                                               ├ Baro (DPS310/BMP388, I2C/SPI)
                                                               ├ OSD (AT7456E, SPI2)
                                                               ├ microSD (SDMMC1, 4-bit)
                                                               └ UARTs ×6
```

Each motor channel uses 6× N-MOSFETs (one 3-phase bridge), one FD6288Q 3-phase gate driver, and one AT32F421K8U7 running AM32 with complementary PWM at 48 kHz.

## 2. Device Parameters (Model Inputs)

The reference FET is a 40 V, PDFN 5×6 (or 3.3×3.3 for nano) trench MOSFET.

| Symbol | Value | Meaning |
|---|---|---|
| R_DS(on),25 | 1.0 mΩ | @ V_GS = 10 V |
| α_T | ≈ 0.0045 /K | R_DS temperature coefficient (gives ×1.45 at 125 °C) |
| Q_g / Q_gs / Q_gd | 50 / 12 / 10 nC | Total gate, gate-source, and Miller (gate-drain) charge |
| Q_gs2 | ≈ 5 nC | Gate charge from threshold voltage to plateau |
| V_th / V_pl | 2.0 / 3.0 V | Gate threshold and Miller plateau voltages |
| R_g,int | 1.0 Ω | Internal gate resistance |
| Q_rr | 40 nC | Body-diode reverse-recovery charge |
| Q_oss | 40 nC | Output charge at 25 V |
| V_SD | 0.8 V | Body-diode forward voltage |
| R_th,JC | 1.2 K/W | Junction-to-case thermal resistance |

**Operating point:**
- Bus voltage V_bus = 25.2 V (worst case, full 6S)
- Motor current I = 80 A
- Switching frequency f_sw = 48 kHz
- Dead time t_dt = 100 ns
