# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #7 specification, so this design uses the assumptions below. Every constant lives in one config block, so you can substitute your actual values.

| Parameter | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, high-resistance winding |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701/AS5047-class) |
| Current sensing | 2-phase low-side shunts |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz (gyro and accel), sampled by DRDY interrupt |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz |

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Coordinate transforms

**Electrical angle.** With mechanical angle θ_m and encoder offset θ_off:
$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Delay compensation

The PWM update takes effect about 1.5 T_s after current sampling. The angle used for the inverse Park transform is therefore advanced:
$$\theta_e^{\,out} = \theta_e + 1.5\,\omega_e T_s$$

### 1.3 Space-vector PWM (min-max zero-sequence injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The linear range is |v| ≤ V_bus/√3.

### 1.4 Current PI with decoupling

The plant in the dq frame is:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The control law, with feedforward decoupling, is:
$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

**Gain selection (pole-zero cancellation).** Choose the gains so the closed loop becomes first-order with bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Use ω_c ≈ 2π·1.5 kHz, which is below f_s/10.

**Voltage limiting.** The voltage vector is limited circularly to |v| ≤ V_bus/√3. Anti-windup uses back-calculation with gain K_aw = 1/K_p.

> **Practical note:** Gimbal motors are often high-resistance (5–15 Ω). If you lack shunts, use voltage-mode control instead: v_q = R i_q* + ω_e λ_m. The code supports this through `useCurrentSensing`.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant (per axis)

$$J\ddot\theta = K_t i_q - \tau_{cog}(\theta) - B\dot\theta - \tau_{fric}\,\text{sgn}(\dot\theta) - \tau_{dist}$$

The torque constant is K_t = (3/2) p λ_m.

### 2.2 Bandwidth separation

Each loop should be at least 5–10× slower than the loop inside it:
$$\omega_{cur} \approx 2\pi\cdot1500,\quad \omega_{vel}\approx 2\pi\cdot 150,\quad \omega_{pos}\approx 2\pi\cdot 20\ \text{rad/s}$$

### 2.3 Velocity loop (PI, 4 kHz)

**Feedback signal.** For stabilization, the velocity feedback is the camera gyro rate projected onto the motor axis, ω_fb = **ĝ**·**e**_axis, blended with the encoder derivative. The gyro has far lower latency and noise than a differentiated encoder.

**Gain design.** The plant is P(s) = K_t/(Js). Choose crossover at ω_v and place the PI zero at ω_v/4 (about 60° phase margin):
$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

**Control law.** The output combines PI, a low-pass filtered derivative on measurement, and feedforward:
$$i_q^* = K_{p,v}e_\omega + K_{i,v}\!\int e_\omega\,dt \;-\; K_{d,v}\,\underbrace{\frac{s}{1+s/\omega_f}}_{\text{filtered}}\,\omega_{fb} \;+\; \underbrace{\frac{J\dot\omega^*}{K_t}}_
