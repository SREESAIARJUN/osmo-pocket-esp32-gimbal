# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #48)

I don't have the Job #48 spec sheet, so the design rests on the assumptions in §0. Every gain is derived symbolically, so you can substitute your real motor and frame parameters.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit magnetic absolute (AS5048A / MT6701 class), one per joint |
| MCU | STM32G474 / H7 class, single-precision FPU |
| Motor drivers | 3-phase with low-side shunts, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate (SPI, 8 kHz ODR, DRDY interrupt) |
| Gimbal order | Base → Yaw → Roll → Pitch → Camera |

The control loops are nested, each running slower than the one inside it:

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM carrier (center-aligned) | 40 kHz | — |
| Current (FOC) loop | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| IMU pipeline (AAF → notch → LPF → fusion) | 8 kHz | — |
| Velocity loop | 4 kHz (gyro feedback) | ω_v ≈ 2π·60–120 Hz |
| Angle / attitude loop | 1 kHz | ω_θ ≈ ω_v / 4…6 |
| Anti-cogging learning | background, gated | — |

**Bandwidth separation rule:** each inner loop should be 4–10× faster than the loop around it (ω_c ≥ 5ω_v, ω_v ≥ 4ω_θ). This lets the inner loop be treated as unity gain when tuning the outer loop.

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, assuming balanced currents so i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)
$$

**Park transform** (θ_e is the electrical angle):

$$
\theta_e = p\,(\theta_m - \theta_{\text{off}})
$$
$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant Model (SPM motor, L_d ≈ L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q
$$
$$
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$
