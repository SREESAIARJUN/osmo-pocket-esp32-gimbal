**Correction to the premise:** The STM32H743 does not drive the MOSFETs. In any ArduPilot-compatible AIO, the H743 runs ArduPilot and sends bidirectional DShot600 to four separate ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32). Those MCUs generate the 48 kHz complementary PWM through 3-phase gate drivers.

```
LiPo 6S ─┬─ Bulk/ceramic caps ─┬─ ESC1..4 [MCU → FD6288Q → 6× N-FET] → Motor 1..4
         └─ 5V/9V BECs ─────────┴─ STM32H743 (ArduPilot) ──bdshot600──┘
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,(1+\alpha)^{(T_j-25)},\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: factor = 1.0045¹⁰⁰ ≈ 1.565, so R_DS ≈ **1.88 mΩ**.

### 1.2 Current path in 6-step synchronous commutation

In each 60° sector, one high-side FET is chopped at duty D. Its complementary low-side FET conducts during (1−D). A low-side FET in a second phase conducts continuously. At any instant, current therefore flows through exactly **two** FETs in series:

$$P_{cond,ch} = I^2 \left[ D\,R_{HS} + (1-D)\,R_{LS,comp} + R_{LS,static} \right] = 2\,I^2 R_{DS}(T_j)$$

This holds when all devices are identical.
