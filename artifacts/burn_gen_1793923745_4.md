# FOC Control Loop & Dual-IMU Fusion for a 3-Axis Gimbal

I don't have a spec sheet for "Job #45", so every hardware-specific value below is an **assumption** marked ⚠. These include the motor, encoder, MCU, rates and mounting. Replace them with your measured values. The equations and code are written so that only the `Config` structs need to change.

---

## 0. System Assumptions & Timing Architecture

| Item | Assumed value ⚠ |
|---|---|
| MCU | STM32G474 / H723 (single-precision FPU, CORDIC optional) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Joint encoder | 14-bit magnetic (AS5048A / MT6701), SPI |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR = 8 kHz |
| Kinematic chain | Base → **Yaw** → **Roll** → **Pitch** → camera |
| Bus | 12–16 V |

| Loop | Rate | Feedback | Output |
|---|---|---|---|
| L1 Current (FOC) | 20 kHz (PWM-synchronous ADC) | i_a, i_b, θ_e | duty a, b, c |
| L2 Velocity (rate) | 4 kHz | fused gyro (camera frame) → J^T | i_q* |
| L3 Angle (attitude) | 1 kHz | quaternion estimate | ω_cam* |
| IMU pipeline | 8 kHz in → 4 kHz out | raw gyro/acc
