# 3-Axis Gimbal: FOC, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #11 specification, so this design states its assumptions explicitly in §0. Every gain is derived from physical parameters, so you can substitute your measured values. Register settings for the ICM-42688-P are taken from the DS-000347 datasheet. Verify them against your silicon revision before flashing.

---

## 0. System Assumptions and Loop Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per joint |
| Current sense | 2- or 3-shunt low-side, sampled at the PWM centre |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz |
| Joint order (base→camera) | Yaw (z) → Roll (x) → Pitch (y) |

| Loop | Rate | Target bandwidth | Purpose |
|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | 1.5–2 kHz | Torque generation |
| Inertial rate (camera gyro) | 4 kHz | 80–150 Hz | Disturbance rejection |
| Attitude (quaternion) | 1 kHz | 10–25 Hz | Pointing |
| IMU sampling + filtering | 8 kHz | n/a | Vibration rejection |

The bandwidths are separated by at least 5× per stage, so each inner loop looks like unity gain to the loop outside it.
