# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #60)

**Scope.** I don't have the Job #60 specification, so the design below states its assumptions explicitly. Every parameter is a named constant so you can substitute the real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC) |
| Motors | Gimbal BLDC 5208-class, 12N14P (pole pairs p = 7), R = 10 Ω, L = 3 mH (phase-equivalent) |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) over SPI |
| Current sensing | 3-shunt low-side, sampled at PWM valley |
| IMUs | 2× ICM-42688-P on the camera plate, each on its own SPI bus, sharing FSYNC |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
