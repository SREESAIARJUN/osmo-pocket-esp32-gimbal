# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have access to the specification for Job #53, so this design assumes typical values for a camera gimbal. Each assumption is listed in §0. They all live in one config block, so you can substitute your real numbers without changing any equations.

## 0. Assumptions and Loop Architecture

| Item | Assumed value | Notes |
|---|---|---|
| Motor | BLDC gimbal motor, 12N14P (pole pairs p = 7), R = 5 Ω, L = 2 mH, λ = 0.01 V·s/rad | Measure per axis |
| Encoder | 14-bit absolute magnetic (e.g. AS5048/MT6701) | Mechanical angle θ_m |
| Bus voltage | V_dc = 12–16 V | |
| Current loop | f_i = 20 kHz (PWM-synchronous) | Bandwidth ≈ 2 kHz |
| Velocity loop | f_v = 4 kHz | Bandwidth ≈ 100–150 Hz |
| Angle/attitude loop | f_θ = 1 kHz | Bandwidth ≈ 15–25 Hz |
| IMU | 2 × ICM-42688-P at 8 kHz ODR, decimated to 4 kHz after filtering | On the camera plate |

**Cascade structure**

```
θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Vel PI]─► i_q* ─(+ i_cog)─►[Current PI dq + decoupling]─► SVPWM
             ▲ attitude (dual-IMU fusion)    ▲ rate (fused gyro)         ▲ i_d, i_q (Clarke/Park)
```

**Bandwidth separation rule.** Keep ω_c,i ≥ 10·ω_c,v and ω_c,v ≥ 5·ω_c,θ. This lets each inner loop be treated as unity gain by the loop outside it.

**Why the gyro is used as velocity feedback.** For inertial stabilization, the velocity loop closes on the gyro rate, not the encoder rate. The encoder is used for commutation, for anti-cogging indexing, and as a fallback.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle:
$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, using i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Motor Model in the dq Frame (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

Torque:
$$\tau = \tfrac32 p\lambda\, i_q = K_t i_q$$
