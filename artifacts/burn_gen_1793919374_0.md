# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #49 specification, so this design uses a typical set of assumed parameters. Everything is parameterized, so you can substitute your real hardware values.

| Item | Assumption |
|---|---|
| Motor | Gimbal BLDC (e.g. GBM2804-class), 12N14P → **p = 7 pole pairs**, R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI or SSI |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle 1 kHz · Attitude fusion 1 kHz (IMU ODR 8 kHz) |
| IMUs | 2× ICM-42688-P on SPI, sampled synchronously, one on camera plate and one redundant (or one per frame) |

## 1. FOC Inner Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

θ_off is found at startup by aligning the d-axis. Apply V_d with V_q = 0, then read the encoder.

### 1.2 Clarke and Park transforms

For a power-invariant-free (amplitude-invariant) form, using only two currents (i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and PI design by pole-zero cancellation

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Use a PI controller $C(s)=K_p + K_i/s$ with:

$$K_p = \omega_c L,\qquad K_i = \omega_c R \;\Rightarrow\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz, ω_c ≈ 2π·1000 rad/s.

Add decoupling and back-EMF feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\qquad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$$

**Voltage-mode fallback.** Many gimbal motors (R ≈ 10 Ω) have no current sensing. In that case use $v_q = R\,i_q^* + \omega_e\lambda_m$ open-loop. The cascade above is unchanged.

### 1.4 Discretization (forward Euler on the integrator, sample time T_s)

$$x_k = x_{k-1} + K_i T_s e_k,\qquad u_k = K_p e_k + x_k$$

Vector-magnitude limiting with conditional integration:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

### 1.5 Inverse Park and SVPWM (min-max injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
