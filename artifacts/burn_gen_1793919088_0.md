## 1. Field-Oriented Current Loop (innermost)

### 1.1 Transforms

Measured phase currents are i_a and i_b, with i_c = −i_a − i_b. The electrical angle is θ_e = p·θ_m − θ_off.

**Clarke transform (amplitude-invariant):**
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.2 Plant and PI design (pole–zero cancellation)

Plant model:
- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ

Choose the PI controller C(s) = K_p + K_i/s with:
- K_p = L·ω_c
- K_i = R·ω_c

The closed loop then becomes the first-order system ω_c / (s + ω_c).

Add decoupling and back-EMF feedforward:
- v_d* = PI_d(0 − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ

### 1.3 Voltage limiting and SVPWM

**Circular limit.** The voltage vector magnitude must satisfy |v_dq| ≤ V_bus/√3. When it would exceed this limit, give d-axis priority:
- v_d is clamped to ±V_max
- v_q is limited to ±√(V_max² − v_d²)

**Inverse Park transform:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e
