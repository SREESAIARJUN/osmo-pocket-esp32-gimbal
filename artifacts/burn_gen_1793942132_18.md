# STM32H743 Nano FC + 80A-Burst 4-in-1 ESC: System Architecture Model (Job #16)

I don't have the Job #16 BOM or layout files, so this model uses **stated, representative assumptions**. Every equation is parameterised so you can substitute the actual datasheet values. Before tape-out, check all part numbers, pin alternate functions and thermal resistances against the real datasheets and your stack-up.

## 0. Architecture Clarification

ArduPilot does not commutate motors. The realistic topology is:

```
STM32H743 (ArduPilot FC)                    4-in-1 ESC
TIMx PWM/IC + DMA ── DShot600 bidir ──►  4× ESC MCU (e.g. AT32F421 / STM32G071, AM32 or BLHeli_32)
                   ◄── GCR eRPM telem ──     └─ 48 kHz complementary PWM → gate drivers → 24 MOSFETs
```

- The **48 kHz switching** is produced by the ESC MCUs, not the H743.
- The H743 is responsible for **DShot timing, DMA and telemetry decode**.

## 2. Conduction Loss Model

### 2.1 Current path
For 6-step trapezoidal drive with synchronous rectification:
- During PWM-on, current flows through the high-side FET of the PWM leg and the static low-side FET of the return leg.
- During PWM-off, current flows through the complementary low-side FET of the PWM leg and the same return FET.

So **two R_DS(on) are always in series**, independent of duty cycle (dead time excluded):
