# STM32H743 AIO (FC + 4-in-1 ESC): Power-Stage Thermal, Switching-Loss, and Bi-Directional DShot Design Package

## 0. Scope and Assumptions

**Architecture clarification.** On an AIO board, the STM32H743 is the flight controller. The 48 kHz PWM and commutation run on the ESC-side MCUs, typically 4× AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743 only generates DShot600 and decodes eRPM telemetry. The models below respect that split.

## 1. Conduction Loss Model (6-Step, Complementary PWM)

### 1.1 Current waveform

In 120° six-step commutation, each phase leg is energized for 2/3 of the electrical period. During each energized interval, exactly one FET of that leg carries I_ph at any instant: the PWM FET during D, and the synchronous FET during (1−D).

Ripple at the worst-case duty D = 0.5:

ΔI = V_bus·D(1−D) / (L·f_sw) = 25.2·0.25 / (15e-6·48e3) = **8.75 A p-p**

The RMS current follows:

I_rms² = I_ph² + ΔI²/12 = 6400 + 6.4 → the ripple contribution is 0.1%, so it is negligible.

### 1.2 Temperature-dependent resistance

R_ds(T_j) = R_ds,25 · [1 + k_T·(T_j − 25)]

### 1.3 Loss per FET and per channel

The worst-case FET, averaged over the electrical period, sees:

P_cond,FET = (1/3)·I_rms²·R_ds(T_j)

Two FETs conduct in each channel at all times, so:

P_cond,ch = 2·I_rms²·R_ds(T_j)

At T_j = 110 °C, R_ds = 1.2·(1 + 0.0045·85) = **1.66 mΩ**.

| Quantity | Value |
|---|---|
| I²R (one conducting FET) | 6406·1.66e-3 = 10.6 W |
| P_cond per FET (avg) | **3.55 W** |
| P_cond per channel | **21.3 W** |

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate-drive-limited transition time

I_g = (V_drv − V_plateau) / ΣR_g = 6.5 / 8.7 = 0.75 A

t_sw = (Q_gs2 + Q_gd) / I_g = 12 nC / 0.75 A ≈ **16 ns** each for rise and fall.

### 2.2 Loss components

Hard switching occurs only in the PWM FET of the active leg, which is 1/3 of the period per FET.

| Component | Equation | Value (while active) |
|---|---|---|
| V·I overlap | ½·V·I·(t_r + t_f)·f | ½·25.2·80·32e-9·48e3 = **1.55 W** |
| Reverse recovery (Q_rr) | Q_rr·V·f | 40e-9·25.2·48e3 = **0.048 W** |
| C_oss discharge | ½·C_oss,er·V²·f | **0.018 W** |
| Dead-time diode conduction (sync FET) | 2·V_SD·I·t_dt·f | 2·0.8·80·100e-9·48e3 = **0.61 W** |
| Gate charge (dissipated in driver) | Q_g·V_drv·f | **0.024 W** |
