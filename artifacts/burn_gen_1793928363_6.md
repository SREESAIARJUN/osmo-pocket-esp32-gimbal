# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I have no Job #44 specification, so the design uses typical gimbal hardware. Every value marked **[A]** is an assumption and is a single constant in the code.

| Item | Assumption |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 1.8 mH, Kt ≈ 0.08 N·m/A **[A]** |
| Encoder | 14-bit magnetic (AS5048A / MT6701), read over SPI every current-loop tick **[A]** |

Bandwidth separation is at least 5× per cascade level: current ~1.5 kHz, velocity ~150 Hz, angle ~20 Hz. Treat all of these as targets to verify on the bench.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms
Phase currents come from two shunts, with i_c = −i_a − i_b.

**Clarke (amplitude-invariant)**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park**, with electrical angle θₑ = p·θₘ − θ_offset:
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI design
The d-q voltage equations are:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda_m)$$

After cross-coupling decoupling, each axis reduces to G(s) = 1/(Ls + R). Pole-zero cancellation then gives a first-order closed loop with bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

With ω_c = 2π·1500 rad/s, keep ω_c·T_s ≲ 0.5. Here 9425·50 µs = 0.47, which accounts for the one-sample PWM delay.

**Feedforward/decoupling terms**
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m),\quad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$$

**Discrete PI with back-calculation anti-windup** (backward Euler):
$$u_k = K_p e_k + I_k + u^{ff}_k,\quad u^{sat}_k = \text{sat}(u_k),\quad I_{k+1} = I_k + K_i T_s e_k + K_{aw}(u^{sat}_k - u_k)$$

Use K_aw = 1/K_p for the current loop.
