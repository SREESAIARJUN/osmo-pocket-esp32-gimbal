## 0. Architecture Clarification and Assumptions

The STM32H743 does **not** commutate the motors. A production-grade 4-in-1 needs a local ESC MCU per channel (or one per pair) running AM32 or BLHeli_32. The H743 runs ArduPilot and sends bidirectional DShot600 to those MCUs.

```
[6S LiPo] → [Bus caps] → 4× [ESC MCU → 3φ gate driver → 6× N-MOSFET] → Motors
                               ↑ bidir DShot600 (single wire, open-drain capable)
                        [STM32H743 – ArduPilot]
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)] \quad\Rightarrow\quad R_{DS}(125^\circ C) = 1.6\ \text{m}\Omega$$

### 1.2 Current distribution (6-step trapezoidal, complementary PWM on the high side)

Each phase spends 120° as source, 120° as sink, and 120° floating.

- **High-side (HS) FET:** conducts only during its source sector, at duty D.
$$I_{HS,rms}^2 = I^2\cdot\frac{D}{3}$$
- **Low-side (LS) FET:** synchronous freewheel during the source sector, plus fully on during the sink sector.
$$I_{LS,rms}^2 = I^2\left[\frac{1-D}{3}+\frac{1}{3}\right]$$

### 1.3 Numerical results (I = 80 A, D = 0.9, T_j = 125 °C)

| Device | I²_rms (A²) | P_cond (W) |
|---|---|---|
| HS FET | 6400 × 0.300 = 1920 | **3.07** |
| LS FET | 6400 × 0.433 = 2773 | **4.44** (hottest) |
| Per phase leg | | 7.51 |
| **Per ESC channel (3 legs)** | | **22.5** |

The worst case for the LS FET occurs at D → 0.5 (I²_rms = 3200 A², giving 5.1 W). However, 80 A at 50% duty implies a stalled or heavily loaded motor. Firmware current limiting should prevent that operating point.

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing HS FET hard-switches. The LS FET soft-switches via its body diode during dead time. At any instant exactly one leg is PWM-ing, so per-channel switching loss equals that of one FET switching continuously.

### 2.1 Gate drive currents and transition times

$$I_{g,on} = \frac{V_{dr}-V_{pl}}{R_{g,on}} = 0.70\ \text{A},\qquad I_{g,off} = \frac{V_{pl}}{R_{g,off}} = 0.60\ \text{A}$$

$$t_{on} = \frac{Q_{sw}}{I_{g,on}} = 25.7\ \text{ns},\qquad t_{off} = \frac{Q_{sw}}{I_{g,off}} = 30.0\ \text{ns}$$
