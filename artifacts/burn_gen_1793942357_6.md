# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #47 specification, so this design states its assumptions explicitly (§0). Every equation is parameterized, so you can substitute your real hardware values.

---

## 0. Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474-class (Cortex-M4F, 170 MHz, CORDIC, FMAC) | Any M4F/M7 works |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH | Typical GBM2804/GM3506 class |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per axis | Used for commutation and cogging phase |
| Current sense | 2-shunt inline or low-side, per axis | Voltage-mode fallback given in §2.4 |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz | |
| Rate loop | 4 kHz (gyro-based, camera frame) | |
| Attitude loop | 1 kHz | |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz | Placed symmetrically about the pitch axis (§4.2) |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) | |
