# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the Job #20 specification, so this design uses the assumptions below. Every value is a named constant in the code. Replace them with your measured or datasheet values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs, Nₛ = 12 slots), R = 10 Ω, L = 2 mH, Kₜ ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (e.g., AS5048A) per joint |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, rigidly mounted ~40 mm apart, SPI, ODR = 8 kHz |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

## 0. Loop Architecture and Rates

```
            1 kHz                 4 kHz                     20 kHz
θ*_cam ─►[Attitude P/PI]─ω*─►[Velocity PI-D]─i_q,fb─►(+)─i_q*─►[d/q current PI]─►SVPWM─►Motor
            ▲    (via J⁻¹)        ▲                    ▲                ▲
            │                     │          i_q,ff(θ_m)│                │ i_a,i_b,θ_e
     q̂ (Mahony AHRS)     ω_joint (encoder +            [Cogging Fourier FF + LMS]
            ▲             gyro blend)
  [Dual ICM-42688-P: AAF → LPF → dynamic notches → lever-arm comp → weighted fusion]  8 kHz
```

The loops follow a bandwidth-separation rule: each inner loop is 5–10× faster than the loop around it.

- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v
