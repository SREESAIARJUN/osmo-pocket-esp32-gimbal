# Job #57: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions and Architecture

I have no hardware specifics for Job #57, so I assumed the design point below. Every parameter is a named constant in the code, so swapping in your measured values is mechanical.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, λ_m (flux linkage) = 0.012 Wb |
| Torque constant | K_t = 1.5·p·λ_m = 0.126 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (e.g. AS5048/MT6701) |
| Bus | V_bus = 16.8 V (4S) |
| Inertia | J_pitch ≈ 4e-4, J_roll ≈ 9e-4, J_yaw ≈ 2e-3 kg·m² (axis plus payload) |
| IMU A | ICM-42688-P on the **camera plate**: the controlled-attitude sensor |
| IMU B | ICM-42688-P on the **handle/base frame**: the vibration reference |

**Loop rate hierarchy** (each loop runs at least about 5× above the bandwidth of the loop it wraps):

```
 20 kHz  PWM ISR      : ADC → Clarke/Park → PI(id,iq) → decoupling → InvPark → SVPWM
  4 kHz  IMU ISR      : 2×ICM-42688 read → notch/LPF → NLMS vibration cancel
  4 kHz  Velocity     : PI on inertial axis rate → iq_ref (+ cogging FF)
  1 kHz  Angle/AHRS   : Mahony update → axis angle error → P(+I) → ω_ref
```

Target bandwidths:
- Current loop: f_c,i = 1.5 kHz.
- Velocity loop: f_c,ω = 120 Hz.
- Angle loop: f_c,θ = 20 Hz.

## 1. Field-Oriented Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform, assuming balanced phases so that i_a + i_b + i_c = 0:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$
