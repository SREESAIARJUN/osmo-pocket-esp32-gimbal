# STM32H743 + 4-in-1 80 A ESC Stack: System Model (Job #5)

## 0. Architecture Corrections and Stated Assumptions

These points need resolving before the math, because they change the design.

1. **The H743 does not commutate motors.** In every production 4-in-1 design, the STM32H743 is the flight controller. It sends DShot600 to four ESC MCUs, which run the commutation loop at 48 kHz. Common ESC MCUs are the AT32F421 and STM32G071, running AM32 or BLHeli_32. This model assumes **H743 FC + 4× AT32F421 (AM32) ESC**. Bidirectional DShot exists precisely because the ESC is a separate processor reporting eRPM back.
2. **"Nano" vs. 80 A.** An 80 A per-channel burst rating is not credible on a 20×20 mm board, as the thermal mass analysis below shows. This model assumes a **30.5×30.5 mm, 8-layer, 2 oz stack**. If Job #5 truly requires 20×20 mm, the burst rating must drop to roughly 40–45 A.
3. **Electrical assumptions:**
   - 6S supply (V_bus,max = 25.2 V)
   - 40 V N-MOSFETs, PDFN 5×6 or 3.3×3.3, R_DS(on),max = 1.2 mΩ at 25 °C and V_GS = 10 V
   - Q_g = 60 nC, Q_rr = 60 nC, C_oss = 1.5 nF
   - Effective t_r + t_f = 30 ns
   - Dead time t_d = 200 ns
   - Body diode V_f = 0.8 V
4. **Commutation:** Six-step trapezoidal with synchronous (complementary) PWM, which is AM32's default.

All component values marked *(verify)* are placeholders until checked against the selected part datasheets.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

$$R_{DS}(125\,°C) = 1.2 \times 1.45 = 1.75\ \text{m}\Omega$$

### 1.2 Current path per ESC channel

In six-step drive, two phases conduct at any instant: one high-side path and one low-side path. With synchronous rectification, the PWM phase alternates between its high-side FET (duty D) and its low-side FET (1–D). Either way, exactly **two FETs are always in series with the phase current**:

$$P_{cond,ch} = 2\,I^2 R_{DS}(T_j) = 2(80)^2(1.75\times10^{-3}) = 22.4\ \text{W}$$

Each FET conducts for 1/3 of the electrical period, so the average per FET is:

$$P_{cond,FET} = \frac{22.4}{6} = 3.73\ \text{W}$$

### 1.3 Parasitic resistive losses (per channel)

| Element | Value | Loss at 80 A |
|---|---|---|
| Low-side current shunt | 0.25 mΩ | 1.60 W |
| PCB copper path (bus → FET → phase pad) | ~0.5 mΩ | 3.20 W |
