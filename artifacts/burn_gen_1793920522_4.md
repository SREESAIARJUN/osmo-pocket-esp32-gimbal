## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC unit) |
| Motors | Gimbal BLDC (GBM2804-class), 12N14P, so pole pairs p = 7 |
| Phase parameters | R_s ≈ 5.6 Ω, L_s ≈ 1.2 mH, K_t ≈ 0.045 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sensing | 2-shunt inline sensing, sampled at the PWM center |
| IMUs | 2× ICM-42688-P on the camera stage, both on SPI at 8 kHz ODR, FIFO-timestamped |
| Base disturbance | Multirotor propeller vibration, roughly 80–400 Hz |

The control rates are separated so that each inner loop is much faster than the loop wrapped around it:

```
 20 kHz  : current loop (FOC), SVPWM, encoder read
  4 kHz  : velocity loop (gyro-rate based), cogging feedforward, encoder PLL
  8 kHz  : IMU sampling, vibration filters, dual-IMU fusion  (decimated to 4 kHz)
  1 kHz  : attitude estimator (Mahony), angle loop, joint-space mapping
```

**Bandwidth separation rule:** each loop's bandwidth should be at most one fifth of the loop inside it.

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_p ≈ 2π·20 rad/s

## 1. Field-Oriented Current Loop

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and Current PI Design

The PMSM model in the dq frame is:
$$v_d = R_s i_d + L_s\dot i_d - \omega_e L_s i_q,\qquad v_q = R_s i_q + L_s\dot i_q + \omega_e (L_s i_d + \lambda_m)$$

Adding decoupling feedforward cancels the cross terms:
$$v_d^{ff} = -\omega_e L_s i_q,\qquad v_q^{ff} = \omega_e(L_s i_d + \lambda_m)$$

With the cross terms removed, each axis behaves as a first-order plant:
$$G(s) = \frac{1}{L_s s + R_s}$$

**Pole-zero cancellation design.** Choosing PI gains of
$$K_p = L_s\,\omega_c,\qquad K_i = R_s\,\omega_c$$
places the PI zero exactly on the plant pole, so the closed loop becomes
$$\frac{\omega_c}{s + \omega_c}.$$
