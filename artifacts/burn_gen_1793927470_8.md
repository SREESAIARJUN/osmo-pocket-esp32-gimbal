## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Coordinate Transforms

The electrical angle comes from the mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming balanced currents $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac32\, p\,\big[\lambda_m i_q + (L_d - L_q) i_d i_q\big] \;\xrightarrow{\text{SPM}}\; \tau_e = K_t\, i_q,\quad K_t = \tfrac32\, p\,\lambda_m$$

### 1.3 Current PI with Decoupling

Each axis plant is $G(s) = \dfrac{1}{Ls + R}$. Choose the PI zero to cancel the plant pole, which gives a closed loop $\dfrac{\omega_c}{s + \omega_c}$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Use $\omega_c \le 2\pi f_{\text{PWM}}/20$, for example $2\pi \cdot 1.2$ kHz. Add the feedforward decoupling terms:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e(L_d i_d + \lambda_m)$$

**Voltage limiting.** Limit the voltage vector to the linear SVPWM circle $|v| \le V_{\text{bus}}/\sqrt3$. Give priority to $v_d$; $v_q$ gets the remaining headroom $\sqrt{V_{\max}^2 - v_d^2}$.

**Anti-windup.** Use back-calculation:

$$\dot x_I = K_i e + K_{aw}(u_{\text{sat}} - u_{\text{unsat}}),\qquad K_{aw} \approx K_i / K_p$$

**Note on high-resistance gimbal motors.** With R > 10 Ω and no current sensing, the current loop degenerates to voltage mode: $v_q = R\, i_q^* + \omega_e \lambda_m$. The cascade above it is unchanged.

### 1.4 SVPWM by Min-Max Zero-Sequence Injection

This is mathematically equivalent to sector-based SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{\text{bus}}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{\text{cog}}(\theta_m) - \tau_{\text{dist}},\qquad \dot\theta_m = \omega_m$$

With the current loop closed and fast enough, the velocity plant is $\dfrac{K_t}{Js + B}$.
