# Gimbal Motor Control and IMU Fusion Design (FOC, Cascaded PID, Anti-Cogging, Dual ICM-42688-P)

I don't have the Job #49 specification, so this design states its assumptions explicitly. Every assumption is a named constant in the code, so you can substitute the real values.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.5 Ω, L = 2.2 mH (phase-to-neutral), Kt ≈ 0.09 N·m/A |
| Driver | 3-phase half bridge, low-side shunts, Vbus = 12–16 V |
| MCU | STM32G474 / H7 class with FPU (CMSIS-style HAL abstracted) |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, sampled synchronously |
| Rates | PWM 20 kHz, current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, IMU ODR 8 kHz |

## 1. FOC Current Loop (Innermost, 20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle θ_e = p·(θ_m − θ_offset):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park**, then **inverse Clarke**:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

**SVPWM** via min-max zero-sequence injection (equivalent to 7-segment SVM):

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The linear range is |v_αβ| ≤ V_bus/√3.

### 1.2 Plant and PI Design

The dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Applying decoupling feedforward leaves a first-order plant per axis, G(s) = 1/(Ls+R). Pole-zero cancellation with a target closed-loop bandwidth ω_c gives:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Rightarrow\quad T(s) = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_s/20 to stay clear of the one-sample computational delay plus the ZOH (≈1.5 T_s). At 20 kHz, f_c ≈ 1 kHz, so ω_c ≈ 6283 rad/s.

The decoupling feedforward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\quad \lambda_m = \frac{2K_t}{3p}$$

**Voltage limiting.** Use circular saturation with d-priority:

- v_d is clamped first to ±V_max.
- v_q is then limited to √(V_max² − v_d²), where V_max = 0.95·V_bus/√3.

**Anti-windup.** Use back-calculation with gain K_aw = 1/K_p:

$$x_{I}[k+1] = x_I[k] + K_i T_s\big(e[k]\big) + K_{aw}K_i T_s\big(u_{sat}[k]-u[k]\big)$$

i_d* = 0 (no field weakening is needed for gimbal motors).
