# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #28 specification, so every assumption below is stated explicitly and kept as a parameter in the code. Replace the numbers with your motor, encoder and frame data before tuning.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value | Symbol |
|---|---|---|
| MCU | STM32G4/H7-class, FPU, center-aligned PWM, ADC triggered at PWM center | — |
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R = 5.6 Ω, L = 2.1 mH (phase), Kt ≈ 0.08 N·m/A | p = 7 |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) on each joint | θm |
| Bus voltage | 12–16 V | V_bus |
| Load inertia (per axis, reflected) | 1.5e-4 kg·m² (roll) to 6e-4 (pan) | J |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz gyro / 1 kHz accel | — |

**Loop rates (one hardware timer and a divider chain):**

```
PWM 20 kHz ──► Current loop (FOC)         20 kHz   Ts_i = 50 µs
           └─► Encoder + PLL + Vel loop     5 kHz   Ts_v = 200 µs  (÷4)
           └─► Angle loop + cogging FF      1 kHz   Ts_a = 1 ms    (÷20)
IMU INT1 (8 kHz) ─► Dual-IMU filters        8 kHz; attitude fusion 1 kHz
```

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than its inner loop:

ω_c,i ≈ 2π·1500 rad/s,  ω_c,v ≈ 2π·80–150,  ω_c,θ ≈ 2π·15–30.
