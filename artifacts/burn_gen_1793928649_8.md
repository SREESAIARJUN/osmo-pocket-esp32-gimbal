# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Fusion

I don't have the Job #42 specification, so this design uses the stated **assumptions** below. Every value tied to one of them is collected in `GimbalConfig.hpp` so you can update it in one place.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM4108: 22N24P, so p = 12 pole pairs), with phase-current sensing on 2 phases |
| Encoders | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Kinematics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted roughly symmetrically about the pitch axis, on SPI, ODR 8 kHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Loop rates | Current loop 20 kHz · R
