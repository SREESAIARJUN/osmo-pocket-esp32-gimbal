# Job #33: 3-Axis Gimbal FOC Control and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #33 spec sheet, so the design uses common gimbal hardware. Every value marked **[P]** is a parameter. Replace it with your measured or datasheet value.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω [P], L ≈ 2 mH [P] |
| Encoders | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | STM32G4 class, FPU, 170 MHz |
| IMUs | ICM-42688-P **#1 on the payload (camera)**, **#2 on the base (handle/airframe)**. Both run at ODR 8 kHz, ±2000 dps, ±16 g, over SPI. |
| Kinematics | Yaw (outer) → Roll → Pitch (inner): R = R_z(ψ)·R_x(φ)·R_y(θ) |
| Loop rates | Current 20 kHz
