## 1. Conduction Loss Model (80 A Burst)

### 1.1 Topology

AM32 uses 6-step trapezoidal commutation with synchronous rectification and complementary PWM. In any commutation step:

- **Phase A high-side (HS)** switches at duty D.
- **Phase A low-side (LS)** conducts during (1−D), as the synchronous rectifier.
- **Phase B low-side** is fully on, as the current return path.

### 1.2 Derivation

Rds(on) rises with temperature:

$$R_{ds}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right] \approx R_{25}\cdot k_T$$

Per commutation step:

$$P_{cond} = I^2 R_{ds}(T_j)\,D \;+\; I^2 R_{ds}(T_j)(1-D) \;+\; I^2 R_{ds}(T_j)$$

$$\boxed{P_{cond} = 2\,I^2 R_{ds}(T_j)} \quad \text{(independent of } D\text{)}$$

Phase current is approximately flat-top in trapezoidal drive, so I_rms ≈ I. Ripple adds a correction term:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus}-E)\,D}{2L_{ph}\,f_{sw}}$$

For a typical 2207 motor (L_ph ≈ 15 µH, back-EMF E ≈ 0.5·V_bus, D ≈ 0.6), ΔI_pp ≈ 5.2 A. This adds 2.3 A², which is negligible against 6400 A².

Copper loss follows the same form:

$$P_{Cu} = I^2 R_{cu}$$

## 2. Switching Loss Model (48 kHz)

The Miller plateau dominates the transition:

$$t_r \approx t_f \approx \frac{Q_{gd}}{I_g} = \frac{10\,\text{nC}}{1\,\text{A}} = 10\,\text{ns}$$
