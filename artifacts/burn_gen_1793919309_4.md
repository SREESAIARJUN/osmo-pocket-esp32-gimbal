# STM32H743 AIO + 4-in-1 80A ESC: Systems Architecture Package (Job #0)

Every number below is derived from stated assumptions. Values marked **[VERIFY]** depend on the final MOSFET, gate driver, or stack-up selection and must be replaced with datasheet or measured values before release.

## 0. Architecture Clarification

The STM32H743 does **not** generate the 48 kHz switching PWM. The partitioning is:

| Function | Device | Notes |
|---|---|---|
| Flight control, ArduPilot, bi-dir DShot600 master | STM32H743VIH6 (400/480 MHz) | 4 DShot lines, eRPM telemetry in |
| Commutation and 48 kHz complementary PWM | 4× AT32F421K8U7 (or STM32G071) running AM32 | `PWM_FREQ = 48 kHz` set in AM32 config |
| Gate drive | 4× 3-phase half-bridge driver (FD6288Q-class) | 6 outputs each |
| Power stage | 24× 40 V N-MOSFET, PQFN 3.3×3.3 | 6 per ESC |
| Current sense | 1× shunt (aggregate) + per-ESC sense optional | to H743 ADC |

**Form-factor reality check.** "80 A" on a 25.5×25.5 mm (20×20 mount) nano board can only be a **short-burst, single- or dual-motor** rating. Section 3 quantifies this. Six 5×6 mm FETs per ESC (24 total = 720 mm²) do not physically fit, so the design uses 3.3×3.3 mm FETs with higher R_DS(on).
