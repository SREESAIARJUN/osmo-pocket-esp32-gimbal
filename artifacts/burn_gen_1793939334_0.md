## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, with iₐ + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

v_α = v_d cos θₑ − v_q sin θₑ
v_β = v_d sin θₑ + v_q cos θₑ

### 1.2 Plant and PI Tuning (Pole-Zero Cancellation)

The motor equations in the rotating frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With feedforward decoupling, each axis reduces to G(s) = 1/(Ls + R). Choose the PI controller C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; C(s)G(s)=\frac{\omega_c}{s}$$

The resulting closed loop is first-order: T(s) = ω_c/(s + ω_c).

Bandwidth limit: with the PWM delay of about 1.5·T_s, keep ω_c ≤ 2π·f_s/20. At 20 kHz, ω_c ≈ 2π·1 kHz.

**Decoupling feedforward:**

v_d,ff = −ωₑ L i_q
v_q,ff = ωₑ (L i_d + λ_m)

### 1.3 Voltage Limiting and SVPWM

1. **Circular limit.** Limit the voltage vector to |v_dq| ≤ V_dc/√3. Give d-axis priority:
   - v_q,max = √(V_max² − v_d²).
2. **Min-max (SVPWM-equivalent) zero-sequence injection:**
   - v_x is the inverse-Clarke phase voltage for x ∈ {a, b, c}.
   - v₀ = −½(max v_x + min v_x).
   - Duty cycle: d_x = ½ + (v_x + v₀)/V_dc.

### 1.4 Anti-Windup by Back-Calculation

$$u = K_p e + I,\quad u_{sat}=\text{sat}(u),\quad I_{k+1} = I_k + T_s\left[K_i e + K_{aw}(u_{sat}-u)\right],\quad K_{aw}\approx K_i/K_p$$

## 2. Cascaded Position/Velocity Control

The loop structure is:

```
θ_ref ─►[P(+I) angle, 1 kHz]─ ω_ref (+ ω_ff) ─►[PI velocity, 4 kHz]─ i_q* (+ i_cog + i_ff) ─►[FOC PI, 20 kHz]
            ▲ θ̂ (IMU attitude / encoder)        ▲ ω̂ (gyro + encoder)
```

### 2.1 Velocity Loop

The mechanical plant is J θ̈ = K_t i_q − b θ̇ − τ_dist. With the current loop treated as ideal, this gives:

$$G_v(s) = \frac{K_t}{Js + b}$$

**PI controller with an optional lead/low-pass on the output:**

$$C_v(s) = K_{pv}\left(1 + \frac{1}{T_{iv}s}\right)\frac{1}{\tau_f s + 1}$$

**Symmetric-optimum style tuning**, with target crossover ω_v ≈ ω_c/5 to ω_c/10 (≈ 2π·100–150 Hz):

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad T_{iv} = \frac{4}{\omega_v},\qquad \tau_f = \frac{1}{4\omega_v}$$

### 2.2 Velocity Feedback

The camera-frame gyro is the primary velocity sensor for stabilization. It must first be projected onto the motor axis:

$$\omega_{axis} = \hat{\mathbf a}^\top \mathbf R_{cam\to axis}\,\boldsymbol\omega_{gyro}$$

For the outer axes, a full joint-rate Jacobian inverse is needed (§2.4).

The encoder velocity comes from a PLL-type observer:

$$e = \sin(\theta_{enc}-\hat\theta) \;(\text{or wrapped difference}),\quad \dot{\hat\omega} = K_i e,\quad \dot{\hat\theta}=\hat\omega + K_p e$$
