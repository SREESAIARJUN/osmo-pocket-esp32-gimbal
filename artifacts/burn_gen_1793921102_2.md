# STM32H743 AIO Flight Controller with Integrated 4-in-1 ESC: Engineering Model (Job #59)

## 0. Feasibility Findings

Three issues change the shape of this design.

| # | Issue | Consequence |
|---|---|---|
| F1 | The H743 does not drive the MOSFETs. A 4-in-1 ESC needs a dedicated ESC MCU per motor (AT32F421, STM32G071 or EFM8BB51) running AM32, BLHeli_32 or Bluejay. The H743 only *sends* DShot and *receives* bidirectional eRPM telemetry. | The architecture becomes H743 + 4 ESC MCUs + 4 three-phase bridges. The 48 kHz PWM is generated by the ESC firmware, not ArduPilot. |
| F2 | A sustained or multi-second 80 A burst on all four channels is not thermally viable on a nano (20×20 mm) board. Section 3 shows roughly 85 W of dissipation into about 2.5 J/K of thermal mass. | The 80 A rating must be time-limited (< ~1 s) or the board must grow. |
| F3 | All device parameters below are representative assumptions (a 40 V, ~1 mΩ, 3.3×3.3 mm MOSFET class). | Re-run the equations with the selected part's datasheet values before release. |

## 1. Operating Assumptions

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S, fully charged |
| I_ph | 80 A | Burst phase current, per ESC |
| f_sw | 48 kHz | ESC PWM frequency |
| R_ds(on),25 | 1.0 mΩ | Per MOSFET at 25 °C, V_GS = 10 V |
| α | 0.0055 /K | R_ds(on) temperature coefficient |
| T_j,target | 110 °C | Design junction temperature |
| t_r, t_f | 20 ns each | Current/voltage transition times (gate driver dependent) |
| t_dt | 100 ns | Dead time per edge |
| V_SD | 0.8 V | Body diode forward voltage |
| Q_rr | 50 nC | Body diode reverse-recovery charge |
| Q_oss | 30 nC | Output charge at V_bus |
| Q_g | 40 nC | Total gate charge |
| V_drv | 10 V | Gate drive voltage |
| R_Cu | 0.5 mΩ | PCB copper path per ESC channel (battery pad → phase pad → return) |

**Commutation model.** The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM.

- At any instant, current flows through exactly one high-side and one low-side MOSFET path.
- During PWM off-time, the active leg's low side conducts in place of its high side.
- The series conducting resistance is therefore always **2 × R_ds(on)**, independent of duty cycle.

## 2. Loss Model (per ESC channel)

### 2.1 Conduction Losses

Temperature-corrected on-resistance:

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.0\,\text{m}\Omega \times [1+0.0055\times85] = 1.47\,\text{m}\Omega$$

MOSFET conduction loss:

$$P_{cond,FET} = I_{ph}^2 \cdot 2R_{ds}(T_j) = 6400 \times 2.94\times10^{-3} = \mathbf{18.8\ W}$$

Copper and solder loss:

$$P_{Cu} = I_{ph}^2 R_{Cu}\,[1+0.0039(T_{Cu}-25)] \approx 6400\times0.5\times10^{-3}\times1.3 = \mathbf{4.2\ W}$$

> **Electrothermal feedback.** R_ds rises with T_j, which raises the loss, which raises T_j. The solution converges only while the loop gain is below 1:
> $$\frac{\partial P}{\partial T_j}\cdot R_{th} = I^2\cdot 2R_{ds,25}\,\alpha\cdot R_{th} < 1$$
> Here ∂P/∂T = 0.070 W/K. Runaway therefore occurs if the effective R_th per channel exceeds about **14 K/W**. A nano board in still air will exceed this, so active airflow is mandatory.

### 2.2 Switching Losses at 48 kHz

Only the PWM-switched leg incurs switching losses; commutation events at the eRPM rate are negligible by comparison.

| Loss | Equation | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r+t_f)·f_sw = ½·25.2·80·40 ns·48k | **1.94 W** |
| Dead-time body diode | V_SD·I·2t_dt·f_sw = 0.8·80·200 ns·48k | **0.61 W** |
| Reverse recovery | Q_rr·V_bus·f_sw = 50 nC·25.2·48k | **0.06 W** |
| Coss | Q_oss·V_bus·f_sw | **0.04 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_drv·f_sw | **0.04 W** (dissipated in the driver/MCU, not the FETs) |
| **Total switching** | | **≈ 2.65 W** |

Sensitivity to frequency:

$$\frac{\partial P_{sw}}{\partial f_{sw}} \approx 55\ \mu\text{W/Hz}$$

Dropping to 24 kHz saves about 1.3 W per channel. The cost is more audible noise and greater current ripple.

### 2.3 Totals

| | Per ESC | 4 × ESC |
|---|---|---|
| FET conduction | 18.8 W | 75.2 W |
| PCB copper | 4.2 W | 16.8 W |
| Switching | 2.65 W | 10.6 W |
| **Total** | **25.6 W** | **≈ 103 W** |

Conduction dominates by about 7:1. Switching optimisation therefore has much less leverage than Rds(on), copper weight and phase current.

Per-FET average: 18.8 W / 6 FETs ≈ 3.1 W, plus about 1.3 W on each actively switching high-side device.

## 3. Thermal Calculations

### 3.1 Junction-to-Board (local)

Assume a 3.3×3.3 mm package with R_θJC ≈ 1.5 K/W and a worst-case FET loss of about 4.5 W:

$$\Delta T_{JC} = 4.5\times1.5 = 6.8\ \text{K}$$

The local junction-to-case rise is not the problem. The board-level heat sink is.

### 3.2 Board Thermal Capacitance (20×20 mm, 8-layer, 2 oz)

| Material | Mass | c_p | C |
|---|---|---|---|
| FR4 (0.64 cm³) | 1.2 g | 1.1 J/g·K | 1.3 J/K |

| 24 FETs, MCUs, solder | ~1.0 g | ~0.5 J/g·K | 0.5 J/K |
| **Total C_board** | | | **≈ 2.6 J/K** |
