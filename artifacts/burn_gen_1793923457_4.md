# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #25 specification, so Section 0 lists every hardware assumption. Each one is a `constexpr` or config field in the code. Swap in your actual motor, encoder, MCU and geometry values before tuning.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 2.2 mH, K_t ≈ 0.09 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701 class), one per joint |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| Inverter | 3 inline or low-side shunts, V_bus = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera payload, on SPI at 24 MHz, ODR = 8 kHz |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz, fusion 1 kHz (gyro filtering at 8 kHz) |

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is found at commissioning by applying a d-axis current vector and reading the encoder.

### 1.2 Clarke transform (power-variant, balanced currents i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame (surface-mount, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 PI current controllers with decoupling

Pole-zero cancellation for a target bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

This makes the closed loop approximately first order: i/i* = ω_ci / (s + ω_ci). Choose ω_ci ≤ 2π·f_PWM / 10, i.e. about 2π·1.5 kHz at 20 kHz PWM.
