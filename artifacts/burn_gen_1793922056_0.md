# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #47)

I don't have the Job #47 spec sheet, so this design rests on the assumptions in §0. Every motor, sensor and rate constant is a parameter in `GimbalConfig` and can be changed without touching the algorithms.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), read over SPI at the current-loop rate |
| Current sensing | 2-phase in-line shunts, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR, ±2000 dps, ±16 g |
| MCU | Cortex-M4F/M7 (STM32G4/H7) with single-precision FPU |

The control system is a cascade of loops. Each outer loop runs at a lower rate and lower bandwidth than the loop inside it.

| Loop | Rate | Target bandwidth | Feedback source |
|---|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz | Phase shunts plus encoder electrical angle |
| Velocity | 4 kHz | ~150 Hz | Gyro (camera rate) blended with encoder velocity |
| Angle | 1 kHz | ~20 Hz | Fused IMU attitude (stabilization mode) |
| IMU acquisition and filtering | 8 kHz | — | Both ICM-42688-P sensors |
| Attitude fusion | 1 kHz | — | Mahony complementary filter |

**Bandwidth separation.** Each loop's bandwidth should be at most about 1/5 of the inner loop's bandwidth (ω_inner / ω_outer ≥ 5–10). This lets the outer loop treat the inner loop as an ideal unity-gain block.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Electrical angle from mechanical angle:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

Clarke transform (assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this rotation matrix.

### 1.2 Motor model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque (surface PMSM, L_d = L_q):

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI controller with decoupling

The PI acts on the current error, and the cross-coupling and back-EMF terms are cancelled by feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gain selection.** Choosing the gains so that the PI zero cancels the electrical pole at R/L gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

$$\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

The bandwidth should satisfy ω_c ≤ 2π f_pwm / 10 to stay clear of sampling and PWM delays.

**Voltage limiting.** The voltage vector is limited to the linear SVPWM region:

$$|v_{dq}| \le V_{bus}/\sqrt3$$

The d-axis has priority, and the q-axis receives whatever voltage remains. Integrator windup is handled by back-calculation (§2.3).

### 1.4 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM.

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

The anti-cogging feedforward (§3) removes τ_cog. With the current loop treated as ideal, the plant seen by the velocity loop is K_t / (Js + B).
