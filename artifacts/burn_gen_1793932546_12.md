# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #16 specification, so the hardware assumptions are listed explicitly below (§0). ## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase half-bridge, Vdc = 12–16 V, low-side or inline current sensing |
| Encoder | 14-bit magnetic (AS5048A / MT6701 class), SPI |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, symmetric about the payload rotation center |
| MCU | Cortex-M7 or M4F with single-precision FPU (STM32H7 / G4 class) |

**Loop rates.** Each loop has bandwidth at least 4–5× below the loop inside it.

```
                     (on-chip AAF/notch)
IMU1 ─┐  8 kHz       ┌────────────────────────────────────────────────────┐
      ├─► align ─► inverse-variance fuse ─► dynamic notch ─► LPF ─► ↓2 ─► │ 4 kHz rate loop
IMU2 ─┘                                    (motor-speed tracked)          │
                                                    │                     │
                                       Mahony AHRS (1 kHz) ─► attitude ─► 1 kHz angle loop
                                                                          │
Encoder ─► PLL observer (20 kHz) ─► θe, ω_m ─► FOC current loop (20 kHz) ◄┘ i_q*
                                       └► anti-cogging FF (adds to i_q*)
```

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–2 kHz |
| Rate (velocity) | 4 kHz | 80–150 Hz |
| Angle | 1 kHz | 15–30 Hz |
| AHRS | 1 kHz | — |

## 1. Field-Oriented Control

### 1.1 Rotor angle and velocity: PLL tracking observer

Electrical angle from the measured mechanical angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Quantized encoder data must not be differentiated directly. Use a type-II PLL instead:

$$\varepsilon_k = \operatorname{wrap}_{\pi}(\theta_{m,k} - \hat\theta_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + K_i T_s\,\varepsilon_k, \qquad \hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_p\varepsilon_k)$$

For a critically damped observer with bandwidth ω_o:

$$K_p = 2\omega_o, \qquad K_i = \omega_o^2$$
