## 0. Assumptions and Loop Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, surface-mount, `p` pole pairs, `N_s` slots (e.g. GBM2804: 7 pp, 12 slots) |
| Position sensor | Per-axis absolute magnetic encoder (e.g. AS5048A / MT6701, 14-bit), used for commutation and joint angle |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz (gyro) / 1–4 kHz (accel) |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → camera |
| MCU | Cortex-M4F/M7 with single-precision FPU |

**Loop rates and data flow**

```
             1 kHz                        4 kHz                       20 kHz (PWM ISR)
θ_ref ─►[Angle P + FF]─ω_ref─►[Rate PI (gyro)]─τ_ref─►(+ τ_cog FF)─►[Iq PI / Id PI]─►SVPWM
          ▲  attitude              ▲ joint rate                         ▲ i_abc, θ_e (encoder)
          │                        │
   [Mahony AHRS]◄──[Dual-IMU fusion + notch/LPF]◄── IMU A, IMU B (8 kHz)
```

A stabilising gimbal must close the rate loop on the **inertial** gyro rate, not the encoder rate. Base motion is then rejected at the full rate-loop bandwidth. The encoder is used only for commutation, for anti-cogging phase, and as a fallback or joint-limit reference.

## 1. Current Loop (Field-Oriented Control)

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park and inverse Clarke:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

### 1.2 SVPWM via min–max zero-sequence injection

This is equivalent to conventional 7-segment SVPWM:

$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The linear range is $|v_{dq}| \le V_{bus}/\sqrt3$.
