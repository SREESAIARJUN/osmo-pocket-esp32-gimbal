## 0. Architecture Decisions and Assumptions

Two points need to be settled before the math, because they change the design.

**1. The STM32H743 is the flight controller, not the ESC MCU.**
A 4-in-1 ESC commutates each motor with its own MCU running AM32 or BLHeli_32. The H743 runs ArduPilot and talks to the four ESC MCUs over bidirectional DShot600. Running 4× sensorless FOC/6-step plus ArduPilot on one H743 is possible in principle, but it is not supported by ArduPilot and would forfeit the entire AM32 ecosystem. The architecture used here is:

```
[H743 FC board, 20x20] ──8-pin JST-SH (4x DShot, VBAT, GND, CUR, TLM)──> [4-in-1 ESC board, 20x20]
                                                                          4x AT32F421K8U7 (AM32)
                                                                          4x FD6288Q 3-ph gate driver
                                                                          24x N-MOSFET (6 per motor)
```

**2. "80 A burst" on a 20×20 mm board is a transient rating, not a thermal steady state.**
Section 2 derives the actual sustainable limits. Expect roughly 25–30 A continuous per channel and an 80 A capability measured in fractions of a second to a few seconds. Any datasheet claim beyond that should be treated as marketing.

## 1. Electrical Loss Model (per motor channel)

### 1.1 Conduction Topology (6-step trapezoidal, synchronous/complementary PWM)

In each 60° electrical sector, current flows through two phase legs:

- **PWM leg:** current alternates between the high-side (fraction D) and low-side synchronous rectifier (fraction 1−D).
- **Static leg:** the low-side stays ON for the whole sector.

The temperature dependence of R_ds(on) is modeled as:

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.6 mΩ × 1.5 = **2.4 mΩ**.

### 1.2 Conduction Loss

$$P_{cond} = I^2 R_{ds}\,D + I^2 R_{ds}(1-D) + I^2 R_{ds} = 2\,I^2 R_{ds}(T_j)$$

The result is independent of duty cycle, which is a property of synchronous rectification.

$$P_{cond}(80\text{ A}) = 2 \times 6400 \times 0.0024 = \mathbf{30.7\ W}$$

(At 25 °C junction it is 20.5 W. The 125 °C value is the design case.)

### 1.3 Switching Losses at 48 kHz (hard-switched PWM leg only)

**(a) V-I overlap.** The transition time is set by Miller charge over gate current:

$$t_{sw} \approx \frac{Q_{gd}}{I_g} = \frac{8\text{ nC}}{1.0\text{ A}} \approx 8\text{ ns};\quad t_r + t_f \approx 20\text{ ns (incl. Q}_{gs2}\text{)}$$

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{n} \times 48\text{k} = \mathbf{0.97\ W}$$

**(b) Reverse recovery** (the body diode conducts during dead time, then is hard-commutated):

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 30\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.036\ W}$$

Note that Q_rr increases with di/dt and I_F, so use the datasheet value at the 80 A test condition if one is available.

$$P_{dt} = V_F\, I\, (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 100\text{n} \times 48\text{k} = \mathbf{0.31\ W}$$
