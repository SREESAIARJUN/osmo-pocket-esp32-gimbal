# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, Bidirectional DShot600 Allocation, and Reference Netlist

## 0. Architecture Clarifications

Several points change the design before any math is done.

1. **The H743 does not commutate the motors.** In AIO boards the H743 runs ArduPilot and sends DShot600 to separate ESC MCUs. These are typically 4× AT32F421 or STM32G071 running AM32, or one MCU per motor. The 48 kHz figure is the ESC MCU's PWM frequency, an AM32 setting, not an H743 timer rate.
2. **80 A per channel on a "nano" (20×20 mm) board is a burst rating only.** It is not a continuous rating. Section 3 quantifies this. Expect about 1 to 2 s of 80 A before the board's thermal mass saturates, even with prop-wash cooling.
3. **Parameter values below are representative.** Every value marked [A] is an assumption to replace with your actual MOSFET or driver datasheet values. The formulas stay valid when you do.

### Baseline Assumptions

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst case for switching) |
| I_ph | 80 A | Burst phase current per motor |
| f_sw | 48 kHz | AM32 PWM |
| R_ds(on),25 | 1.2 mΩ [A] | 40 V N-FET, V_gs = 10 V, 5×6 or 3.3×3.3 package |
| α (R_ds temp coefficient) | 0.006 /K [A] | Gives ×1.6 at 125 °C |

## 1. Conduction Loss Model

### 1.1 Current Distribution in Six-Step with Synchronous Rectification

Each phase spends 120° electrical in each of three states: PWM-high, held-low, and floating. With duty D:

- **High-side FET of the PWM leg:** conducts for fraction D of its 1/3 interval.
- **Low-side FET of the same leg:** conducts the freewheel current for fraction (1 − D) of that interval.
- **Low-side FET of the return leg:** conducts continuously for its 1/3 interval.

Averaging over one electrical cycle gives per-device loss:

$$P_{HS} = \tfrac{D}{3} I^2 R_{ds}(T_j), \qquad P_{LS} = \tfrac{(1-D)+1}{3} I^2 R_{ds}(T_j)$$

Summing over the 3 legs:

$$\boxed{P_{cond,motor} = 2\,I^2 R_{ds}(T_j)} \quad \text{(independent of } D\text{)}$$

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

### 1.2 Numbers at T_j = 125 °C

- R_ds = 1.2 mΩ × 1.6 = 1.92 mΩ
- P_cond,FET = 2 × 80² × 1.92 mΩ = **24.6 W per motor**
- P_cond,PCB = 2 × 80² × 0.5 mΩ = **6.4 W per motor**

### 1.3 Thermal-Runaway Stability Criterion

Loss rises with temperature, which raises loss further. The loop is stable only if:

$$\frac{\partial P}{\partial T_j}\,R_{th,j\text{-}a} < 1 \;\Rightarrow\; 2I^2R_{ds,25}\,\alpha\,R_{th} < 1$$

- At 80 A, the left-hand factor is 2 × 6400 × 1.2e-3 × 0.006 = 0.092 W/K.
- So R_th(j-a) must be below about **10.8 K/W** per motor's effective path.
- A nano board in still air (about 50 K/W) **fails this criterion**. This is a second reason 80 A can only be a burst rating.

## 2. Switching Losses at 48 kHz

In six-step, only one leg is PWM-switching at any instant. Per motor:

| Loss term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½ × 25.2 × 80 × 40 ns × 48k | **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw = 50 nC × 25.2 × 48k | **0.06 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8 × 80 × 200 ns × 48k | **0.61 W** |
| C_oss charge | ½·C_oss·V²·f_sw × 2 | **0.05 W** |
| Gate drive (dissipated in driver/R_g) | Q_g·V_gs·f_sw × 2 | **0.05 W** |
| **Total switching** | | **≈ 2.7 W** |
