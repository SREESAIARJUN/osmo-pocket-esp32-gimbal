# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #51)

## 0. Assumptions

I don't have the Job #51 specification, so the design rests on the assumptions below. Every one of them is a single constant in `GimbalConfig.hpp`.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per joint |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic chain | Base → Yaw (Z) → Roll (X) → Pitch (Y) → camera |
| PWM | Center-aligned, 20 kHz. ADC is triggered at the counter peak. |

**Loop rates:**

| Loop | Rate | Ratio to the loop it feeds |
|---|---|---|
| Current (FOC) | 20 kHz | — |
| Velocity | 4 kHz | 5:1 |
| Attitude (angle) | 1 kHz | 4:1 |
| IMU fusion and filtering | 8 kHz, decimated to 4 kHz | — |

The design target is a bandwidth separation of at least 5× between nested loops.
