# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the specification for "Job #7," so this design rests on stated assumptions. **Section 0** lists every parameter you would need to change to match your hardware. Everything below that section is derived from those parameters, so swapping in your motor, sensor and rate values propagates through cleanly.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R = 5.6 Ω, L = 2.0 mH, Kv ≈ 22 rpm/V → λ ≈ 0.0618 V·s/rad (electrical) |
| Inverter | 3-phase, 2- or 3-shunt sensing, V_bus = 12–16 V |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| IMUs | 2 × ICM-42688-P on separate SPI buses, mounted on the camera plate |
| Loop rates | Current 20 kHz · velocity 4 kHz · angle/attitude 1 kHz · IMU OD
