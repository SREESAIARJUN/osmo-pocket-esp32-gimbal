# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #17", so this design uses the typical gimbal parameters below. Every gain is computed from these parameters, so you can substitute your real values.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Motor | — | 14-pole (7 pole pairs), 12-slot gimbal BLDC |
| Phase resistance / inductance | R, L | 5.6 Ω, 2.0 mH (surface PM, so Ld ≈ Lq) |
| Torque constant | K_t = 1.5·p·λ | ≈ 0.08 N·m/A |
| Load inertia per axis | J | 2×10⁻⁴ kg·m² |
| Bus voltage | V_dc | 12 V |
| Encoder | — | 14-bit magnetic (AS5048A / MT6701 class) |
| IMUs | — | 2× ICM-42688-P on the camera plate, mirrored about the roll axis, SPI at 8 kHz ODR |

**Loop rates:**
- Current loop: 20 kHz, synchronous with PWM center.
- Velocity loop: 4 kHz.
- Angle loop: 1 kHz.
- IMU processing: 8 kHz, decimated to 1 kHz for attitude.

## 1. FOC Inner Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform, with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transpose of this matrix.

### 1.2 Plant model in the dq frame

$$v_d = R i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q$$

$$v_q = R i_q + L_q\frac{di_q}{dt} + \omega_e (L_d i_d + \lambda)$$

$$\tau_e = \tfrac32 p\left[\lambda i_q + (L_d-L_q)i_d i_q\right] \approx K_t\, i_q$$

### 1.3 Current PI with decoupling (pole-zero cancellation)

After the cross-coupling and back-EMF terms are cancelled by feedforward, each axis reduces to G(s) = 1/(Ls + R).

Choose the PI as C(s) = K_p + K_i/s with:

$$K_p = \omega_{c}L,\qquad K_i = \omega_{c}R$$

The PI zero then cancels the electrical pole, and the closed loop becomes the first-order system ω_c/(s+ω_c).

Bandwidth selection: with f_pwm = 20 kHz, choose ω_c ≈ 2π·1.5 kHz. This keeps ω_c·T_s < 0.5, which leaves margin for the 1.5-sample computation-plus-PWM delay.

The control law, with decoupling feedforward, is:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e (L_d i_d + \lambda)$$

The d-axis reference is i_d* = 0 (no field weakening needed for a gimbal).

### 1.4 Voltage limiting and anti-windup

The linear SVPWM limit is |v| ≤ V_dc/√3. The d-axis gets priority:

$$v_d^{sat}=\text{clamp}(v_d^*,\pm V_{max}),\qquad v_q^{sat}=\text{clamp}\!\left(v_q^*,\pm\sqrt{V_{max}^2-(v_d^{sat})^2}\right)$$

Anti-windup uses back-calculation with K_aw = 1/K_p:

$$I_{k+1}=I_k + T_s\big[K_i e_k + K_{aw}(v^{sat}-v^*)\big]$$

### 1.5 SVPWM (min-max injection, equivalent to sector SVPWM)

$$v_{a,b,c} = \text{invClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12\big[\max(v_{abc})+\min(v_{abc})\big]$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

**Delay compensation:** use θ_e + 1.5·ω_e·T_s for the inverse Park transform.

## 2. Cascaded Velocity and Angle Loops

### 2.1 Velocity estimation

Raw encoder differencing is too noisy. Use a type-II PLL tracking observer on the encoder angle:

$$e = \text{wrap}(\theta_{enc}-\hat\theta)$$

$$\hat\omega \mathrel{+}= T_s K_{i,pll}\, e$$

$$\hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}\,e)$$

Gains for critical damping at bandwidth ω_pll: K_p = 2ω_pll and K_i = ω_pll². A typical choice is ω_pll ≈ 2π·400 rad/s.

### 2.2 Velocity PI

The plant from current reference to speed is approximately K_t/(Js), because the current loop is fast. Use the symmetric-optimum-style placement, with crossover ω_v at roughly 1/10 of ω_c (e.g. 2π·150 Hz):

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The current command is:

$$i_q^* = \text{PI}_v(\omega^*-\hat\omega) + i_{q,ff}^{accel} + i_{q,cog}(\theta_m)$$

where i_{q,ff}^{accel} = J·α*/K_t.

A first-order low-pass on the derivative is not needed because this is a PI. Do add an optional low-pass on i_q* at about 5ω_v, or a notch at the structural resonance.

### 2.3 Angle loop (P plus feedforward)

For a gimbal, the angle loop is a P controller on the stabilization error, with the body rate fed forward:

$$\omega^* = K_{p,\theta}\,\text{wrap}(\theta^*-\theta) + \omega^*_{ff}$$

Choose K_{p,θ} ≈ ω_v/4 (in 1/s).

The feedforward term ω*_ff is the commanded joint rate that cancels base motion. It is the gyro-measured base rate projected onto this joint axis via the gimbal Jacobian. For the stabilization case, the IMU on the camera supplies θ (camera attitude in the world frame) and the velocity loop uses encoder ω̂. The IMU-gyro rate can be blended into ω̂ (see §4.5).

### 2.4 Stability check

Phase margin of the velocity loop:

$$\text{PM} = 180° - 90° + \arctan(4) - \arctan(\omega_v/\omega_c) - \omega_v T_{d,v}\cdot\tfrac{180}{\pi}$$

With the numbers above, this gives PM ≈ 66°.

## 3. Anti-Cogging Sinusoidal Feedforward

### 3.1 Model

Cogging torque is periodic in mechanical angle. Its fundamental period is 2π/N_c, with N_c = LCM(slots, poles) = LCM(12, 14) = 84. Higher harmonics arise from magnet and encoder errors, and from torque ripple at 6p = 42 per revolution.

The harmonic set is K = {42, 84, 126, 168} (adjust to your FFT of i_q):

$$\tau_{cog}(\theta_m) = \sum_{k\in K} a_k\cos(k\theta_m) + b_k\sin(k\theta_m)$$

The compensation current is:

$$i_{q,cog} = -\frac{\tau_{cog}}{K_t} = \sum_{k} A_k\cos(k\theta_m) + B_k\sin(k\theta_m)$$
