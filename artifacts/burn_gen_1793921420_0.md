# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the spec sheet for Job #46, so this design rests on the assumptions in §0. The equations are written so you can substitute your real parameters without re-deriving anything.

## 0. Assumptions

| Item | Assumed value | Where it matters |
|---|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804), N_s = 12 slots, P = 14 poles (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH | Current loop gains, cogging harmonics |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MA732) on each joint | Commutation, PLL |
| Current sense | 2 or 3 low-side shunts, sampled at the PWM center | Inner loop |
| MCU | Cortex-M4F/M7 or STM32G4 with FPU | float, CMSIS-friendly |
| PWM | 20–25 kHz, center-aligned | Inaudible |
| Loop rates | Current 20 kHz (ISR), velocity 4 kHz, attitude/angle 1–2 kHz | Bandwidth separation |
| IMUs | Two ICM-42688-P on the camera plate, rigidly mounted, ODR = 8 kHz gyro / 4 kHz accel | Fusion |
| Kinematics | Yaw (outer) → Roll (mid) → Pitch (inner, camera) | Jacobian |

## 1. Field-Oriented Control (inner current loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

The offset θ_off is found at startup by applying a d-axis voltage vector at θ_e = 0 and reading the encoder once the rotor has settled.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q \quad (\text{SPM: } L_d = L_q = L)$$

### 1.5 Current PI by pole–zero cancellation

The plant is G(s) = 1/(Ls + R). Choose the PI controller C(s) = K_p + K_i/s with

$$K_p = \omega_{cc} L,\qquad K_i = \omega_{cc} R$$

The closed loop then becomes the first-order system ω_cc/(s + ω_cc).

- Choose ω_cc ≤ 2π·f_pwm/20.
- At 20 kHz this gives about 2π·1 kHz.

Add decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set i_d* = 0 for an SPM motor.

### 1.6 Voltage limiting

Limit the voltage vector to the linear SVPWM hexagon's inscribed circle:

$$\sqrt{v_d^2+v_q^2} \le \frac{V_{bus}}{\sqrt3}$$

Priority goes to v_d. Then:

$$v_q \leftarrow \text{sign}(v_q)\min\left(|v_q|, \sqrt{V_{max}^2 - v_d^2}\right)$$

### 1.7 Inverse Park and SVPWM (min–max zero-sequence injection)

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection and duty cycles:

$$v_0 = -\tfrac12(\max(v_{abc}) + \min(v_{abc})),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}
