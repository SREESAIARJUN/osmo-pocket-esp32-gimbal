# STM32H743 Flight Controller + 4-in-1 ESC (Job #18): Power, Thermal and DShot Timing Model

## 0. Scope and Assumptions

A 4-in-1 ESC runs its own per-channel MCUs (AM32/BLHeli_32 class firmware). The STM32H743 only generates bidirectional DShot600 and decodes eRPM telemetry. The model therefore has two domains:

- **Power stage (ESC):** conduction, switching and thermal behaviour.
- **Command and telemetry path (FC):** timers, DMA and memory.

## 1. Conduction Loss Model

### 1.1 Current distribution in six-step commutation with complementary PWM

In each 60° commutation sector, two phase legs conduct:

- **The PWM leg:** the high-side (HS) switch conducts for a fraction D of each PWM period. The low-side (LS) switch carries the freewheel current for the remaining (1−D) fraction (synchronous rectification).
- **The return leg:** the LS switch conducts 100% of the time.

Each switch participates for 120° (one third) of the electrical cycle. This gives the following RMS currents:

$$
I_{HS,rms}^2 = \frac{I_{ph}^2 \, D}{3}, \qquad
I_{LS,rms}^2 = \frac{I_{ph}^2 (1-D)}{3} + \frac{I_{ph}^2}{3} = \frac{I_{ph}^2(2-D)}{3}
$$

Per leg, HS + LS gives (2/3)·I²R. Across three legs:

$$
\boxed{P_{cond,ch} = 2\,I_{ph}^2\,R_{DS}(T_j)}
$$

This result is independent of D, because exactly two switches are always in the current path.

### 1.2 Temperature dependence (electro-thermal coupling)

$$
R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]
$$

At an estimated T_j ≈ 125 °C, the correction factor is 1.40, so R_DS ≈ 1.05 mΩ.

### 1.3 Numbers at 80 A burst (D = 0.95)

| Quantity | Value |
|---|---|
| P_cond per channel | 2 × 6400 × 1.05 mΩ = **13.44 W** |
| HS switch | 6400 × 1.05e-3 × 0.95/3 = 2.13 W |
| LS switch | 6400 × 1.05e-3 × 1.05/3 = 2.35 W |
| Copper path (≈0.4 mΩ effective per channel) | 6400 × 0.4e-3 = 2.56 W |

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The return leg stays static within a sector, so each loss term below is computed once per channel.

### 2.1 Hard-switching overlap loss (HS switch)

$$
P_{sw} = \tfrac12 V_{bus}\, I_{ph}\,(t_r+t_f)\, f_{sw}
= 0.5 \times 25.2 \times 80 \times 27\text{ ns} \times 48\text{ kHz} = \mathbf{1.31\ W}
$$

The rise/fall times are set by the Miller plateau and gate drive current:

$$
t_{r,f} \approx \frac{Q_{gd}\, R_G}{V_{drv} - V_{plateau}}
