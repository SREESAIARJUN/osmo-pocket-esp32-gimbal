## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

θ<sub>offset</sub> is found at startup by forcing a d-axis current (v<sub>d</sub> = V<sub>align</sub>, θ<sub>e</sub> = 0) and reading the encoder after settling.

### 1.2 Clarke transform (amplitude-invariant, i<sub>a</sub> + i<sub>b</sub> + i<sub>c</sub> = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the rotor frame

$$v_d = R_s i_d + L_d\dot i_d - \omega_e L_q i_q$$

$$v_q = R_s i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

### 1.5 Current PI with decoupling and back-EMF feedforward

The current controller uses pole-zero cancellation of the R/L plant, which gives a closed loop of ≈ ω<sub>c,i</sub>/(s + ω<sub>c,i</sub>):

$$K_{p,i} = L_s\,\omega_{c,i},\qquad K_{i,i} = R_s\,\omega_{c,i}$$

The discrete control law (forward-Euler integrator, T<sub>s</sub> = 50 µs) is:

$$v_d^* = K_{p,i}e_d + x_d - \omega_e L_q i_q$$

$$v_q^* = K_{p,i}e_q + x_q + \omega_e L_d i_d + \omega_e\lambda_m$$

$$x_{d,q}[k+1] = x_{d,q}[k] + K_{i,i}T_s\,e_{d,q}[k] + K_{aw}\,(v^{sat} - v^{*})$$

where e = i* − i. Set i<sub>d</sub>* = 0 (no field weakening is needed at gimbal speeds).

**Voltage limiting (circular, d-priority):**

$$v_{\max} = \frac{V_{dc}}{\sqrt3},\qquad v_q^{sat} = \operatorname{clamp}\!\left(v_q^*,\ \pm\sqrt{v_{\max}^2 - v_d^{*2}}\right)$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM and gives 15.5 % more linear range than sinusoidal PWM.

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta_m) - B\omega - \tau_{dist}$$

Here τ<sub>dist</sub> includes cable drag, imbalance, and base motion coupling.

### 2.2 Velocity loop (4 kHz, gyro feedback)

The controlled variable is the **inertial** rate of the camera about the motor axis:

$$\omega_{meas} = \hat{\mathbf a}^{\top}\,\boldsymbol\omega_{fused}$$

where â is the motor axis expressed in the IMU frame. Inertial feedback is what rejects base motion.
