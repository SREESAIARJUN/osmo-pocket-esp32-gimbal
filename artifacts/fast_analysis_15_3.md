## 1. Message Definitions (DSDL)

### 1.1 Heartbeat: `uavcan.protocol.NodeStatus` (Data Type ID 341)

```
# 341.NodeStatus.uavcan
# Mandatory periodic broadcast from every node (heartbeat).

uint16 MAX_BROADCASTING_PERIOD_MS = 1000
uint16 MIN_BROADCASTING_PERIOD_MS = 2
uint16 OFFLINE_TIMEOUT_MS         = 3000

uint32 uptime_sec                 # Seconds since node start

uint2 HEALTH_OK       = 0
uint2 HEALTH_WARNING  = 1
uint2 HEALTH_ERROR    = 2
uint2 HEALTH_CRITICAL = 3
uint2 health

uint3 MODE_OPERATIONAL     = 0
uint3 MODE_INITIALIZATION  = 1
uint3 MODE_MAINTENANCE     = 2
uint3 MODE_SOFTWARE_UPDATE = 3
uint3 MODE_OFFLINE         = 7
uint3 mode

uint3 sub_mode                    # Reserved, set to 0
uint16 vendor_specific_status_code
```

- **Payload:** 56 bits, which is 7 bytes. It fits in a single CAN 2.0 frame, so no transfer CRC is needed.
- **Publishing rate:** 1 Hz. This is the standard rate. The allowed range is 2–1000 ms.

### 1.2 ESC Telemetry: `uavcan.equipment.esc.Status` (Data Type ID 1034)

```
# 1034.Status.uavcan
# Generic ESC status, published per ESC.

uint32 error_count        # Resets on power cycle
float16 voltage           # Volts
float16 current           # Amperes, negative = regen
float16 temperature       # Kelvin
int18 rpm                 # Negative = reverse
uint7 power_rating_pct    # 0..127, instantaneous demand %
uint5 esc_index           # 0..31
```

- **Payload:** 110 bits, which is 14 bytes.
- **Framing:** this is a multi-frame transfer with 2 frames and a transfer CRC seeded with the data type signature.
- **Publishing rate:** typically 10–50 Hz per ESC. In AP_Periph this is set via `ESC_TELEM_RATE`.

### 1.3 Optional Extended ESC Telemetry: `uavcan.equipment.esc.StatusExtended` (Data Type ID 1036)

```
# 1036.StatusExtended.uavcan
uint7  input_pct            # Demanded throttle %, 0..100
uint7  output_pct           # Actual output %, 0..100
int9   motor_temperature_degC
uint9  motor_angle          # Electrical angle, 0..360
uint19 status_flags         # Vendor/implementation-specific
uint5  esc_index
```

- **Payload:** 56 bits, which is 7 bytes, in a single frame.
- **Publishing rate:** usually published at a lower rate than `Status`.

## 2. Publishing Code (AP_Periph style, libcanard + dronecan_dsdlc)

The headers are auto-generated by `dronecan_dsdlc`. They provide `*_ID`, `*_SIGNATURE`, `*_MAX_SIZE`, and `*_encode()` symbols, so you never need to hard-code signatures.

```cpp
#include <dronecan_msgs.h>   // generated: uavcan_protocol_NodeStatus, uavcan_equipment_esc_Status, ...

// ---------- Heartbeat ----------
static uavcan_protocol_NodeStatus node_status;

void AP_Periph_FW::send_node_status()
{
    node_status.uptime_sec = AP_HAL::millis() / 1000U;
    node_status.health     = UAVCAN_PROTOCOL_NODESTATUS_HEALTH_OK;
    node_status.mode       = UAVCAN_PROTOCOL_NODESTATUS_MODE_OPERATIONAL;
    node_status.sub_mode   = 0;
    node_status.vendor_specific_status_code = hal.util->available_memory() / 1024; // example

    uint8_t buffer[UAVCAN_PROTOCOL_NODESTATUS_MAX_SIZE];
    const uint16_t len = uavcan_protocol_NodeStatus_encode(&node_status, buffer
#if CANARD_ENABLE_TAO_OPTION
                                                           , !canfdout()
#endif
                                                           );
    canard_broadcast(UAVCAN_PROTOCOL_NODESTATUS_SIGNATURE,
                     UAVCAN_PROTOCOL_NODESTATUS_ID,
                     CANARD_TRANSFER_PRIORITY_LOW,
                     buffer, len);
}

// ---------- ESC telemetry ----------
void AP_Periph_FW::esc_telem_send(uint8_t esc_index,
                                  const AP_ESC_Telem_Backend::TelemetryData &td,
                                  float rpm)
{
    uavcan_equipment_esc_Status pkt {};
    pkt.esc_index        = esc_index;                 // 0..31
    pkt.voltage          = td.voltage;                // V
    pkt.current          = td.current;                // A
    pkt.temperature      = C_TO_KELVIN(td.temperature_cdeg * 0.01f);
    pkt.rpm              = constrain_int32(rpm, -131072, 131071); // int18 range
    pkt.power_rating_pct = constrain_int16(td.power_pct, 0, 127);
    pkt.error_count      = td.error_count;

    uint8_t buffer[UAVCAN_EQUIPMENT_ESC_STATUS_MAX_SIZE];
    const uint16_t len = uavcan_equipment_esc_Status_encode(&pkt, buffer
#if CANARD_ENABLE_TAO_OPTION
                                                            , !canfdout()
#endif
                                                            );
    canard_broadcast(UAVCAN_EQUIPMENT_ESC_STATUS_SIGNATURE,
                     UAVCAN_EQUIPMENT_ESC_STATUS_ID,
                     CANARD_TRANSFER_PRIORITY_LOW,
                     buffer, len);
}

// ---------- Scheduling (called from AP_Periph_FW::update / can_update) ----------
void AP_Periph_FW::can_update()
{
    const uint32_t now = AP_HAL::millis();

    static uint32_t last_ns_ms;
    if (now - last_ns_ms >= 1000) {          // 1 Hz heartbeat
        last_ns_ms = now;
        send_node_status();
    }

    static uint32_t last_esc_ms;
    const uint32_t esc_period = 1000U / MAX(g.esc_telem_rate.get(), 1);
    if (now - last_esc_ms >= esc_period) {   // e.g. 50 Hz
        last_esc_ms = now;
        for (uint8_t i = 0; i < ESC_NUMBERS; i++) {
            // populate from AP_ESC_Telem and call esc_telem_send(i, ...)
        }
    }
}
```

## 3. STM32H743-Specific Notes

| Item | Recommendation |
|---|---|
| Peripheral | FDCAN1/FDCAN2 (ChibiOS `hal_fdcan`), configured in `hwdef.dat` (`PD0 CAN1_RX`, `PD1 CAN1_TX`, etc.) |
| Bit rate | 1 Mbit/s classic CAN (`CAN_BAUDRATE 1000000`). Use CAN-FD only if the whole bus supports it. |
| Message RAM | The H7 shares 10 KB of FD
