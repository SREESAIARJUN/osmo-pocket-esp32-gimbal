# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

**Scope and assumptions.** I don't have the original specification for Job #56. The design below therefore uses typical gimbal values, all collected in one parameter struct so you can replace them with your measured numbers.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), hollow shaft |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| Inverter | 3-phase, 20 kHz center-aligned PWM, 2-shunt or inline current sensing (a voltage-mode fallback is provided) |
| IMUs | 2× ICM-42688-P on the camera plate, ±2000 dps, ±16 g, ODR 8 kHz, FIFO, shared CLKIN |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q) | 20 kHz | ≈ 2 kHz |
| Rate (velocity) | 4 kHz | ≈ 120–200 Hz |
| Attitude (angle) | 1 kHz | ≈ 20–40 Hz |
| Attitude estimator | 1 kHz | — |

## 1. System Architecture

```
                 ┌───────────── 1 kHz ─────────────┐ ┌──────── 4 kHz ────────┐ ┌──────── 20 kHz ───────────┐
 θ_ref ──►(Σ)──► Angle P(+I) ──► ω_ref ──►(Σ)──► Rate PI(D) ──► i_q* ──►(Σ)──► Current PI d/q ──► SVPWM ──► Motor
           ▲                      │         ▲                   ▲    │      ▲                                   │
           │                      │         │       i_cog_ff ───┘    │      │  i_d,i_q (Clarke/Park)            │
           │                      │         │       i_ff (accel) ────┘      └──── θ_e = p(θ_m − θ_0) ◄── Encoder ◄┘
           │                      │         │                                           │
     IMU attitude (Mahony)        │   joint-projected inertial rate                      └─► Cogging LUT (θ_m)
           ▲                      │         ▲
           └──── Dual ICM-42688-P → align → per-IMU notch/LPF → consistency check → inverse-variance fusion
```

**Key design choice.** The rate loop is closed on **inertial rate from the fused gyros**, not on encoder speed.

- Gyro feedback rejects base (handle or vehicle) motion directly. Encoder speed only measures motion relative to the base.
- The encoder is still used for commutation, cogging compensation, and a joint-velocity observer that handles damping near end-stops.

## 2. Field-Oriented Control Equations

### 2.1 Electrical angle

$$
\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi,
\qquad
\omega_e = p\,\omega_m
$$

θ₀ is found at calibration by applying v_d = V_align at θ_e = 0 and reading the encoder once the rotor has settled.

### 2.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,
\qquad
i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}
$$
