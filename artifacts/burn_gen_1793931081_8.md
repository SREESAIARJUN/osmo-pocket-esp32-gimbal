# STM32H743 Nano FC + 4-in-1 ESC (Job #49): Architecture, Loss Models, DShot DMA Plan and Netlist

## 0. Feasibility Findings

These results drive every later section.

1. **The STM32H743 does not commutate the motors.** Production-grade designs use one ESC MCU per motor, for example an AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. The 48 kHz PWM is an ESC-firmware setting, not an H743 timer setting.
2. **"80A burst" on a nano board is thermally limited to roughly 2–3 s with all four motors loaded.** It is not a 10 s rating. The math is in §3. With realistic prop-wash cooling, continuous capability is about **17–25 A per motor**. Marketing an 80A burst rating here requires a defined duration and duty cycle.
3. **PCB copper loss is the same order as MOSFET loss at 80 A.** Phase routing must be designed as a power path, not as signal traces.
4. **All device parameters below are stated design assumptions.** Replace them with your selected MOSFET's datasheet values. The equations are general; the numbers are illustrative.

## 1. System Architecture

```
 6S LiPo (18.0–25.2 V)
   │
   ├─[XT60]─[Bulk 470–1000µF ext.]─┬─ VBAT rail (shared bus, 4 ESC bridges)
   │                               ├─ Total-current shunt + amp ─→ H743 ADC
   │                               └─ VBAT divider ─→ H743 ADC
   │
   ├─ ESC section (4 identical channels)
   │    ESCn MCU (AT32F421, AM32, PWM = 48 kHz)
   │       ├─ 3-phase gate driver (FD6288Q-class, bootstrap)
   │       ├─ 6× N-ch MOSFET (3 half-bridges)
   │       └─ BEMF comparator network ← phases A/B/C
   │
   └─ FC section
        STM32H743 @ 400 MHz (ArduPilot)
          ├─ TIM1 CH1..CH4 → DShot600 bidir → ESC1..ESC4 signal pins
          ├─ SPI IMU(s), baro (I²C/SPI), OSD/SD, UARTs
          └─ 5 V / 3.3 V buck from VBAT
```
