# STM32H743 Nano FC + 4-in-1 ESC (Job #11): Power Stage, Thermal, and Bi-Directional DShot600 Design

## 0. Scope, Architecture, and Assumptions

No component selections were supplied, so this document fixes a reference bill of materials and derives everything parametrically. Where a datasheet value is assumed, it is marked **[A]**. Swap in your real part values and the equations still hold.

**Architecture.** In ArduPilot, the STM32H743 is the flight controller only. It does not commutate motors. The 4-in-1 ESC carries its own MCUs, which run AM32 or BLHeli_32 firmware, and generates the 48 kHz PWM. The H743 sends DShot600 and receives bi-directional eRPM telemetry.

| Item | Reference selection | Key parameters |
|---|---|---|
| FC MCU | STM32H743VIT6 (LQFP100) | 400 MHz SYSCLK, timer kernel clock 200 MHz |
| ESC MCU (×4) | AT32F421K8U7 or STM32G071 (AM32) | 48 kHz complementary PWM |
| Gate driver (×4) | FD6288Q (3-phase, bootstrap) | ~1.0 A source / 1.5 A sink **[A]** |
| MOSFET (×24) | 40 V N-ch, DFN3.3×3.3 | R_DS(on) = 1.6 mΩ max @25 °C, V_GS = 10 V **[A]**; Q_g = 50 nC, Q_gd = 8 nC, Q_rr = 30 nC, Q_oss = 40 nC, R_g,int = 1.5 Ω, V_plateau = 3.5 V **[A]** |
| Bus | 6S LiPo, V_bus = 25.2 V (max), 22.2 V nominal | |
| Form factor | 20×20 mm mounting, ~26×26 mm board, 6-layer, 2 oz all layers | |

> **Early design warning (detailed in §3):** a 20×20 nano 4-in-1 can survive an 80 A per-channel burst for about 1 second. Its continuous rating is only about 13 A per channel under prop-wash cooling. "80 A" must be specified as a burst rating with a defined duration, or the board size must grow.
