# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Sensor Fusion

I don't have the Job #45 specifics such as the motor part number, encoder type, MCU, or mechanical inertias. This design therefore uses explicit, typical gimbal assumptions. Every assumption is a named parameter you can change.

## 1. Loop Architecture

```
            ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ────┐ ┌──────── 20 kHz ─────────┐
 θ_ref ──►(Σ)─► Angle PI ─►(Σ)◄─ ω_ff       (Σ)─► Vel PI ──►(Σ)──► id/iq PI ─► invPark ─► SVPWM ─► Motor
           ▲                │                ▲              ▲  iq_cog     ▲                          │
           │              ω_ref ─────────────┘              │  (anti-cog) │ Clarke/Park              │
           │                                  ω̂ (enc+gyro)  │             └──── i_a,i_b ◄────────────┤
     θ̂ (dual-IMU AHRS) ◄── notch/LPF ◄── IMU A, IMU B       └── LMS(θ_m) ◄──── θ_m encoder ◄───────────┘
```

Bandwidth separation is kept at 5–10× per stage:
- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_p ≈ 2π·25 Hz

## 2. Field-Oriented Control (Inner Current Loop)

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, where θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant model (SPMSM)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 2.3 PI tuning by pole-zero cancellation

With decoupling and back-EMF feedforward, each axis becomes 1/(Ls+R). Choosing

$$K_{p,i} = \omega_c L,\qquad K_{i,i} = \omega_c R$$

gives the closed loop ω_c/(s+ω_c).

The applied voltages include decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 2.4 Voltage limiting

The voltage vector is limited to the linear SVPWM hexagon's inscribed circle:

$$|v| \le V_{dc}/\sqrt3$$

Integrators use back-calculation anti-windup.

### 2.5 SVPWM via min-max zero-sequence injection

$$v_{a,b,c}=\text{invClarke}(v_\alpha,v_\beta),\quad v_0=-\tfrac12(\max+\min),\quad d_x=\tfrac12+\frac{v_x+v_0}{V_{dc}}$$

### 2.6 Torque

$$\tau = K_t\, i_q,\qquad K_t=\tfrac32 p\lambda_m$$

*Note:* Many gimbal motors (R > 5 Ω) are run in voltage mode without current sensing. In that case set `useCurrentSensing=false`. The code then outputs v_q = R·i_q* + ω_e·λ_m directly.

## 3. Cascaded Angle / Velocity Control

### 3.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Here τ_dist covers cable drag, base-motion coupling, and imbalance.
