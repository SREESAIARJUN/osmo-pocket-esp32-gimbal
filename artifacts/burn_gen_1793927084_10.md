# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #32): Electrical, Thermal and DShot Timing Model

**Key findings**

1. **80 A per channel is not sustainable on a nano (20×20 mm) board.** At 80 A, total board dissipation is about 168 W (§3.6). Heating the board from 40 °C to a 110 °C copper limit takes **about 0.9 s** (§4.2). The realistic sustained rating is **about 20–25 A per channel** with good prop-wash cooling (§4.3). Marketing a "80 A burst" requires a stated duration (≤0.5 s is defensible) and firmware current limiting.
2. **The H743 does not drive the gates.** Bidirectional DShot means a dedicated ESC MCU per motor decodes DShot and runs the 48 kHz commutation. This design uses 4× AT32F421 running AM32. The H743 runs ArduPilot and owns the DShot/eRPM timing (§5).
3. **Every device parameter below is an assumption** to be replaced with the selected parts' datasheet values. The model structure and equations hold regardless of parts.

---

## 1. System Architecture

```
 6S LiPo (25.2 V max) ──┬── Bulk cap (external 1000 µF low-ESR + onboard polymer/MLCC)
                         ├── 4× [AT32F421 (AM32) → FD6288Q 3-ph driver → 6× N-MOSFET → motor]
                         ├── Current shunt / INA → H743 ADC
                         └── 12 V / 5 V / 3.3 V buck chain → H743 FC section
 STM32H743 (ArduPilot) ──── 4× DShot600 bidir (TIM3 CH3/CH4, TIM5 CH1/CH2) → ESC MCUs
```
