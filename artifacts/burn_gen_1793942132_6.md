# Job #29: STM32H743 Nano FC + 4-in-1 ESC (80 A Burst)

**Design dossier rev. A**: power-stage loss model, thermal model, bidirectional DShot600 timer and DMA map, and netlist

---

## 0. Architecture Decision and Assumptions

The STM32H743 does **not** commutate the motors directly. The flight controller sends bidirectional DShot600 to four dedicated ESC MCUs, which run AM32 or BLHeli_32-class firmware. This is the only architecture that ArduPilot supports for bidirectional DShot with eRPM telemetry.

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal | |
| Phase current (burst) | I_ph = 80 A per channel, t_burst ≤ 3 s | Section 3 shows why 3 s is the limit |
| PWM frequency | f_sw = 48 kHz, complementary (synchronous rectification) | |
| MOSFET (reference) | 40 V, 5×6 mm (or 3.3×3.3 mm dual-sided cooled) | R_ds(on),25 = 1.0 mΩ @ V_gs = 10 V; Q_g = 55 nC; Q_gd = 12 nC; Q_oss = 60 nC; Q_rr = 50 nC; V_SD = 0.8 V |
| Gate driver | FD6288Q (3-phase, bootstrap), 12 V V_cc | |
| ESC MCU | AT32F421 / STM32G071 (×4) | |
| Board | 30.5×30.5 mm ESC stack (8-layer, 3 oz outer / 2 oz inner) + separate H743 FC | |

> ⚠️ **Feasibility flag.** 80 A continuous per channel is not achievable on a nano footprint. The analysis below proves that 80 A is a **thermally time-limited burst rating**. A true nano (20×20 mm) board cannot carry it at all. A 30.5×30.5 mm board is the minimum.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)],\qquad \alpha \approx 0.0065\ /°C$$

| T_j | R_ds |
|---|---|
| 100 °C | 1.49 mΩ |
| 125 °C | 1.65 mΩ |

Use **R_ds,hot = 1.5 mΩ** for the design case.

### 1.2 Six-step commutation with complementary PWM

At any instant, two phases carry I_ph. The current path is always one high-side FET plus one low-side FET (either the active LS or the synchronous-rectifying complement). Ignoring dead time:

$$P_{cond,ch} = I_{ph}^2 \cdot 2R_{ds,hot} = 80^2 \times 2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

Each of the 6 FETs conducts for 1/3 of the electrical cycle (shared between PWM and SR intervals), so the average per FET is:

$$P_{cond,FET} = 19.2 / 6 = 3.2\ \text{W}$$

The worst-case FET is the PWM high-side at high duty. Its loss is D·I²·R during its 120° window:

$$P_{HS,peak} = \tfrac{1}{3}\, D\, I^2 R \approx 2.9\ \text{W at } D = 0.9$$

The per-FET average of 3.2 W covers this case.

## 2. Switching Losses at 48 kHz

Only the PWM-ing leg switches. There is one hard-switched transition pair per PWM period.

### 2.1 V–I overlap loss

Gate current, with I_g ≈ (V_drv − V_plateau)/R_g = (12 − 4.5)/10 Ω ≈ 0.75 A source (and roughly 1 A sink via the turn-off diode):

$$t_r \approx t_f \approx Q_{gd}/I_g \approx 12\,\text{nC}/0.75\,\text{A} \approx 16\ \text{ns} \;\Rightarrow\; \text{design value } 10\ \text{ns each with diode-assisted turn-off}$$

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f)f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\text{ns} \times 48\,\text{k} = \mathbf{0.97\ W}$$

### 2.2 Dead-time body-diode conduction

The FD6288Q has internal dead time of about 200 ns, and there are 2 events per period:

$$P_{DT} = V_{SD}\, I_{ph}\, (2 t_{dt})\, f_{sw} = 0.8 \times 80 \times 400\,\text{ns} \times 48\,\text{k} = \mathbf{1.23\ W}$$

This is the largest single switching term. Two mitigations:
- Lowering MCU-side dead time (AM32 setting) to about 100 ns roughly halves it.
- A low-Q_rr FET with an integrated Schottky helps.

### 2.3 Reverse recovery and C_oss

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\,\text{nC}\times25.2\times48\,\text{k} = 0.06\ \text{W}$$

$$P_{oss} = Q_{oss}V_{bus}f_{sw} = 60\,\text{nC}\times25.2\times48\,\text{k} = 0.07\ \text{W}$$

### 2.4 Gate drive (dissipated in driver and R_g, not in the FET)

$$P_g = 2\,Q_g V_{drv} f_{sw} = 2\times55\,\text{nC}\times12\times48\,\text{k} = 0.063\ \text{W}$$

### 2.5 Loss budget per channel at 80 A

| Term | W | % |
|---|---|---|
| Conduction (hot) | 19.20 | 85.3 |
| V–I switching | 0.97 | 4.3 |
| Dead-time diode | 1.23 | 5.5 |
| Q_rr + C_oss | 0.13 | 0.6 |
| Gate drive | 0.06 | 0.3 |
| Shunt (0.25 mΩ, I_bat ≈ D·I_ph = 72 A) | 1.30 | 5.8 |
| PCB copper (≈0.15 mΩ effective phase path) | 0.96 | — |
| **Total per channel** | **≈ 23.9 W** | |
| **4 channels** | **≈ 95 W** | |

**Efficiency:** P_out ≈ 22.2 V × 72 A ≈ 1.6 kW per channel, so efficiency is about 98.5% (electrically fine). The problem is purely thermal density: 95 W in 9.3 cm².

**Why 48 kHz is acceptable:** the switching-related terms scale linearly with f_sw.

| f_sw | Switching-related loss |
|---|---|
| 24 kHz | ~1.2 W |
| 48 kHz | 2.4 W |
| 96 kHz | 4.8 W |

At 48 kHz, conduction still dominates. The frequency is justified by lower current ripple and acoustic and efficiency gains on low-inductance motors.

**Phase ripple check** (L_ph ≈ 15 µH line-to-line, D = 0.5):

$$\Delta I = \frac{V_{bus}D(1-D)}{L f_{sw}} = \frac{25.2\times0.25}{15\,\mu\text{H}\times48\,\text{k}} \approx 8.8\ \text{A}_{pp}$$

This is 11% of 80 A, which is acceptable.

## 3. Thermal Model

### 3.1 Junction-to-board (per FET, steady state)

$$\Delta T_{j-pcb} = P_{FET}\cdot R_{\theta JC,eff} = 3.6\,\text{W}\times1.2\,\text{K/W} \approx 4.3\ \text{K}$$

The junction is not the bottleneck. Board bulk temperature is.
