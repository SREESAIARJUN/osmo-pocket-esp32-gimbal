## 1. Conduction Loss Model

### 1.1 Current paths in synchronous 6-step commutation

During any one commutation sector, exactly two legs carry current:

- **PWM leg.** The high-side (HS) FET conducts for duty D. The low-side (LS) FET synchronously rectifies for (1 − D).
- **Return leg.** The LS FET is held on for the whole sector.

So the phase current I flows through exactly **2 R_ds(on) in series at all times**, independent of D, apart from dead-time.

```
P_cond,ch = 2 · I_rms² · R_ds(on)(T_j)
```

### 1.2 Temperature dependence

Use a linearised temperature coefficient, which is typical for trench FETs:

```
R_ds(on)(T_j) = R_25 · [1 + α(T_j − 25)],   α ≈ 0.0045 /K
```

At T_j = 125 °C: R = 1.2 mΩ × 1.45 = **1.74 mΩ**. Use 1.8 mΩ, including package and bond resistance.

### 1.3 Ripple contribution

Phase current is not pure DC. The phase inductance (L_ph) of a typical 5–7" motor is about 10–20 µH. The peak-to-peak ripple is:

```
ΔI_pp = (V_bus − E_bemf)·D / (L_ph · f_sw)
```

The worst case is at D = 0.5 with E_bemf ≈ V_bus/2, giving 6.3 V × 10.4 µs / 15 µH ≈ 4.4 A.

```
I_rms = sqrt(I_dc² + ΔI_pp²/12) = sqrt(6400 + 1.6) ≈ 80.01 A
```

The ripple term is negligible at 80 A, but keep it in the model for light-load efficiency.

### 1.4 Copper and interconnect

Assume 8 mm wide traces, 4 paralleled 2 oz layers (70 µm each), about 15 mm path length per leg pair:

```
R_cu = ρ·L/(w·t) = 1.72e-8 · 0.015 / (0.008 · 4·70e-6) = 0.115 mΩ  (at 25 °C)
R_cu(100 °C) ≈ 0.115 · (1 + 0.0039·75) = 0.149 mΩ
```

Include the solder joints and shunt. With a 0.25 mΩ current-sense shunt on the shared DC return:

```
P_cond,ch = I² · (2·R_ds + R_cu,path)
          = 6400 · (3.6 + 0.15) mΩ
          = 24.0 W   (+ shunt share, see 1.5)
```
