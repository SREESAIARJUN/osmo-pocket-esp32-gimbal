### 0.2 Architecture correction (important)

ArduPilot running on the H743 does **not** commutate the motors. A correct AIO architecture is:

```
STM32H743VIT6 (ArduPilot)  --4x DShot600 bidirectional-->  4x ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                                              -> 3-phase gate driver -> 6 MOSFETs per motor
```

The H743 generates DShot frames and decodes eRPM telemetry. Each ESC MCU generates the 48 kHz PWM.

### 0.3 Feasibility flag

80 A per motor on a 20×20 nano board is a **burst** rating, limited to a few seconds by thermal capacitance (§3). It is not a continuous rating. The model below quantifies that limit.
