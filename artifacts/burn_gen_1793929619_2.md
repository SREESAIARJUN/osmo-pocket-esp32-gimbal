# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion (Job #36)

I don't have the Job #36 specification, so this design uses the assumptions below. Every parameter is a `constexpr` or a config struct, so you can change them without touching the structure.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2 or 3 low-side shunts per motor. A voltage-mode fallback is included. |
| MCU | STM32G4 / H7 class, single-precision FPU, about 170+ MHz |
| Loop rates | Current 20 kHz · Velocity (rate) 4 kHz · Angle 1 kHz · IMU ODR 8 kHz |
| IMUs | 2× ICM-42688-P on the camera payload (inner gimbal frame), SPI at 24 MHz |
| Gimbal topology | Yaw (outer) → Roll (middle) → Pitch (inner), camera on the pitch link |

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is found at commissioning by applying a d-axis vector (v_d = V_align, v_q = 0) and reading the encoder.
