# FOC Motor Control and Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #3 specification, so this design rests on the explicit assumptions in §0. Every equation and the code are parameterized, so you can substitute your actual hardware values.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU). Portable C++17 with a hardware abstraction layer. |
| Motors | 3× gimbal BLDC (GBM2804-class), 12N14P → pole pairs p = 7, slots Nₛ = 12 |
| Rotor sensors | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis, sampled synchronously with PWM |
| Current sensing | 2- or 3-shunt low-side, ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on the camera payload, SPI at 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → camera |

**Loop rates**

| Loop | Rate | Tₛ |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| Velocity | 4 kHz | 250 µs |
| IMU acquisition and filtering | 8 kHz (gyro), decimated to 4 kHz | |
| Attitude estimation and angle loop | 1 kHz | 1 ms |

**Control cascade**

```
q_ref ─►[Attitude error → joint angle error]─►[Angle PI + rate FF]─► ω_ref
      ─►[Velocity PI(D)]─► i_q,ref ─(+ anti-cogging FF + disturbance FF)─►[Current PI d/q]─►SVPWM
```

Velocity feedback per axis combines two sources through a complementary blend:
- the filtered fused gyro projected onto the joint axis (low noise and inertial-referenced at mid/high frequency),
- the encoder-differentiated rate.

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying a fixed d-axis vector (v_d = V_align, v_q = 0) and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b),\qquad (i_c = -i_a - i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model (surface PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with pole-zero cancellation and decoupling

Choose the closed-loop current bandwidth ω_c (rad/s), typically 2π·1.5 kHz at f_PWM = 20 kHz. Then:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c$$

The PI zero cancels the electrical pole R/L, which gives a first-order closed loop: I/I* = ω_c/(s+ω_c).

**Discrete form** (forward Euler on the integrator, with clamping anti-windup):

$$e_x[k]=i_x^*[k]-i_x[k]$$
$$u_x[k]=K_{p,i}e_x[k]+I_x[k-1]+K_{i,i}T_s e_x[k] + v_{x,\text{ff}}[k]$$
$$v_{d,\text{ff}}=-\hat\omega_e L i_q,\qquad v_{q,\text{ff}}=\hat\omega_e(L i_d+\lambda_m)$$

**Voltage limiting** uses the inscribed SVPWM circle, $|v| \le V_{dc}/\sqrt3$:
- v_d gets priority: $v_d^{sat}=\text{clamp}(u_d,\pm V_{max})$
- $v_q^{sat}=\text{clamp}\big(u_q,\pm\sqrt{V_{max}^2-v_d^{sat\,2}}\big)$

**Back-calculation anti-windup**:

$$I_x[k]=I_x[k-1]+K_{i,i}T_s e_x[k]+K_{aw}(v_x^{sat}-u_x)$$

with $K_{aw}\approx 1/K_{p,i}$.
