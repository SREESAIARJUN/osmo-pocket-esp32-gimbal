# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #55): Thermal, Switching, and DShot/DMA Architecture

## 0. Scope, Assumptions, and Feasibility

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It sends bidirectional DShot600 to **four independent ESC MCUs**, one per motor. These are AT32F421-class parts running AM32 or BLHeli_32, and each generates the 48 kHz complementary PWM for its own 3-phase bridge. The H743 does not drive the gates directly, because ArduPilot has no FOC/6-step motor-control path.

**Unverified parameters.** All device parameters below are representative values for a 40 V, 3.3×3.3 mm, roughly 1 mΩ MOSFET class. Before release, replace every **[DS]**-tagged value with the selected part's datasheet number. The schematic is a design-intent netlist, not a fab-ready output. Pin numbers must be checked against the current datasheets and the ST CubeMX pin/AF tables.

**Feasibility.** On a 20×20 or 25.5×25.5 mm board, 80 A per motor is a **burst rating of seconds, not a continuous rating**. Section 3 quantifies this. The datasheet tells you the FETs survive the current, but the binding constraint is the board's heat capacity.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At a design point of T_j = 110 °C: R_DS = 1.0 × (1 + 0.0045·85) = **1.38 mΩ**.

Because conduction loss raises T_j, which raises R_DS, the loss and temperature must be solved together. The fixed point is:

$$T_j = T_{ref} + R_{\theta}\,P(T_j) \;\Rightarrow\; T_j = \frac{T_{ref} + R_\theta P_{25}(1-25\alpha)}{1 - R_\theta P_{25}\alpha}$$

This has a stable solution only while **R_θ·P_25·α < 1**. Beyond that point you get thermal runaway. This is the second reason the rating has to be expressed as a burst.

### 1.2 Six-step trapezoidal with synchronous rectification

In each 60° commutation sector, one phase is PWM'd and one is held low-side ON. With complementary switching, current always flows through exactly two FETs: either HS(A) + LS(B) during D, or LS(A) + LS(B) during 1−D, ignoring dead time.

$$P_{cond,ESC} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2I^2R_{DS}(T_j)$$

**Result (independent of duty cycle):**

$$P_{cond} = 2 \times 80^2 \times 1.38\text{ mΩ} = \mathbf{17.7\ W\ per\ ESC}$$

Two further resistive terms must be included and verified:

- **Copper and plane resistance.** A 0.2 mΩ path at 80 A adds 2×6400×0.2 m = **2.6 W** to the board, which still has to be removed as heat.
- **Shunt resistance.** A 0.25 mΩ shunt adds 1.6 W per ESC if fitted. Many nano designs omit per-ESC shunts and sense total current only.

### 1.3 Per-FET distribution

Each FET is "hot" (carrying the full 80 A) for 1/3 of the electrical period. The worst-case instantaneous FET dissipation is the low-side return FET:

$$P_{FET,peak} = 6400 \times 1.38\text{ m} = 8.8\text{ W}$$

At 14 poles and 20,000 RPM the electrical frequency is f_e = 2333 Hz, so a sector lasts **71 µs**. That is far shorter than the die thermal time constant (~1–5 ms), so per-FET average power governs:

$$\bar P_{FET} \approx P_{ESC,total}/6$$

At low RPM / high-torque stall (f_e < ~50 Hz), sectors exceed 3 ms. Peak power then applies, and junction temperature ripples by about 8.8 W × Z_θ(3 ms). Firmware stall protection must cap current in this regime.
