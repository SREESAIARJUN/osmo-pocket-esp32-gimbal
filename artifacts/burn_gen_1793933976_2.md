# FOC, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #28 specification. The design below is parameterized around a typical brushless gimbal stage. Replace the constants in `GimbalConfig` with your motor and sensor data.

| Item | Assumed value |
|---|---|
| Motor | GBM2804-class, 12N14P → **p = 7 pole pairs**, R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.043 N·m/A |
| Rotor encoder | 14-bit absolute (AS5048A / MT6701), SPI, sampled at the current-loop rate |
| Driver | 3-phase, center-aligned PWM at 20 kHz, inline or low-side shunts |
| Payload inertia per axis | J ≈ 2.5·10⁻⁴ kg·m² (pitch), 4·10⁻⁴ (roll), 6·10⁻⁴ (yaw) |
| IMUs | 2 × ICM-42688-P on the camera/payload plate, SPI at 24 MHz, ODR 8 kHz, synchronized via 32 kHz CLKIN |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

### Loop rates

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c = 2π·1500 rad/s |
| Velocity | 4 kHz | ω_v = 2π·120 rad/s |
| Angle / attitude | 1 kHz | ω_θ = 2π·25 rad/s |
| IMU sampling | 8 kHz | Decimated ×2 into the velocity loop |

The ≈10× bandwidth separation between successive loops lets each outer loop treat its inner loop as a unity-gain block.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle and transforms

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is found at calibration by aligning the rotor to the d-axis with a DC vector.
