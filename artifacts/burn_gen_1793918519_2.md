# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #15, so the design below rests on the assumptions in Section 0. Every gain is derived from motor and plant parameters, so the design can be re-targeted by changing those numbers.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class with single-precision FPU, about 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A, MT6701 or similar), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload center of mass |
| Bus voltage | 12–16 V |
| Kinematic order | Yaw (z) → Roll (x) → Pitch (y), outermost to innermost |

The control system runs as four nested rates:

| Loop | Rate | Trigger |
|---|---|---|
| Current loop + SVPWM | 20 kHz (Ts = 50 µs) | ADC injected end-of-conversion |
| Encoder PLL + anti-cogging + velocity PI | 4 kHz | Every 5th current interrupt |
| IMU fusion + attitude / angle loop | 1 kHz | IMU data-ready (8 kHz ODR, decimated) |
| Setpoint and mode logic | 100 Hz | Main loop |

**Bandwidth separation rule.** Each outer loop should be about 4–10× slower in bandwidth than the loop inside it:

ω_c (≈ 2π·1500) ≫ ω_v (≈ 2π·150) ≫ ω_θ (≈ 2π·25)

## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle is computed from the encoder mechanical angle:

θ_e = p·(θ_m − θ_offset) mod 2π

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant Model and PI Design (Pole–Zero Cancellation)

The dq-frame voltage equations are:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

The plant from voltage to current is G_i(s) = 1 / (L·s + R). Choosing the PI controller

C_i(s) = K_p + K_i/s, with **K_p = L·ω_c** and **K_i = R·ω_c**,

cancels the plant pole and gives a first-order closed loop, i(s)/i*(s) = ω_c / (s + ω_c). Keep ω_c ≤ ω_s / 10 to stay clear of PWM and sampling delay.

**Decoupling and back-EMF feedforward** remove the cross-coupling terms:

- v_d* = PI_d(e_d) − ω_e·L·i_q
- v_q* = PI_q(e_q) + ω_e·L·i_d + ω_e·λ_m

**Voltage limit and anti-windup.** SVPWM can produce at most V_max = V_bus / √3. If |v_dq| > V_max, scale the vector down to V_max with i_d priority, and freeze integrators whose output is saturated (conditional integration).
