# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #62): Engineering Model

## 0. Scope, Assumptions, and Corrections

**Architecture correction.** An STM32H743 does not commutate motors directly in this class of product, and bidirectional DShot is a protocol *between* the flight controller and ESC MCUs. The model therefore assumes this architecture:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AT32F421 / AM32)
                                              └─► 4× 3-phase gate driver ─► 24 (or 48) N-MOSFETs
```

**Feasibility warning.** The thermal analysis in §3 shows that 80 A per motor continuous is not achievable on a nano (20×20 or 30×30 mm) board. 80 A is only viable as a time-limited burst of roughly 1–2 s with strong prop-wash airflow. I treat it that way throughout.

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R = 1.2 mΩ × 1.55 = **1.86 mΩ**. Use 1.8 mΩ for the design case.

### 1.2 Six-step trapezoidal commutation with synchronous rectification

At any instant, current flows through exactly two switch positions in series:

- the PWM'd leg, alternating between the high-side FET (fraction D) and the synchronous low-side FET (fraction 1−D);
- the static low-side FET of the return leg.

Bridge conduction loss per channel:

$$P_{cond,ch} = 2\,I_{rms}^2\,R_{DS}(T_j)$$

At burst (I = 80 A, treating trapezoidal ripple as small):

$$P_{cond,ch} = 2 \times 6400 \times 0.0018 = \mathbf{23.0\ W}$$

Each of the 6 positions conducts about ⅓ of the electrical period, so the per-FET average is:

$$P_{cond,FET} = \frac{I^2 R}{3} = \mathbf{3.84\ W}$$

**With 2 FETs paralleled per position** (recommended), R_eff halves, giving 11.5 W per channel and 0.96 W per FET (4× lower per device).

### 1.3 Shunt loss

$$P_{sh} = I^2 R_{sh} = 6400 \times 0.00025 = \mathbf{1.6\ W\ per\ channel}$$

## 2. Switching-Loss Model at 48 kHz

Hard switching occurs only in the PWM leg: one turn-on and one turn-off per PWM period.
