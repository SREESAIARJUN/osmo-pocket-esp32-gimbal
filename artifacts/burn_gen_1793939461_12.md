# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #53, so this design rests on the assumptions in §0. Every assumption is exposed as a parameter in the code. Change them to match your hardware before tuning.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit magnetic (e.g. MT6701/AS5048A), SPI/SSI |
| Current sense | 2-phase low-side or inline shunts, sampled at PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, DRDY interrupt |
| Bus voltage | 12–16 V |

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) loop + SVPWM | 20 kHz | ADC end-of-conversion at PWM center |
| IMU sampling (both) | 8 kHz | ICM DRDY → SPI DMA |
| Filtering and fusion | 8 kHz in, 2 kHz out | IMU ISR |
| Velocity PI | 2 kHz | Timer |
| Angle (attitude) P/PD | 1 kHz | Timer |
| Cogging LMS adaptation | 2 kHz | Inside the velocity loop, gated |

The bandwidth separation rule is ωc,cur ≥ 5–10·ωc,vel and ωc,vel ≥ 4–5·ωc,ang.

## 1. FOC Current Loop Equations

### 1.1 Electrical angle

θe = p · (θm − θoffset) mod 2π

Here θoffset is found at calibration by aligning the rotor to the d-axis (apply vd > 0, vq = 0, and read the encoder).

### 1.2 Clarke transform (amplitude-invariant, ia + ib + ic = 0)

* iα = ia
* iβ = (ia + 2 ib) / √3

### 1.3 Park transform

* id = iα cos θe + iβ sin θe
* iq = −iα sin θe + iβ cos θe

### 1.4 Motor model in the dq frame

* vd = R id + L did/dt − ωe L iq
* vq = R iq + L diq/dt + ωe L id + ωe λm

Here ωe = p ωm. Torque is τ = (3/2) p λm iq = Kt iq.

### 1.5 PI current control with decoupling

Pole-zero cancellation gives a first-order closed loop with bandwidth ωcc:

* Kp,i = L · ωcc
* Ki,i = R · ωcc

Choose ωcc ≈ 2π·1.5–2 kHz at 20 kHz sampling (keep ωcc·Ts < 0.15 for discretization margin).

The control law is:

* vd = Kp,i ed + Ki,i ∫ed dt − ωe L iq
* vq = Kp,i eq + Ki,i ∫eq dt + ωe L id + ωe λm
* with ed = id* − id and eq = iq* − iq
