# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage, Thermal, and Bi-Directional DShot Design Package

I don't have the Job #4 specification, so this package is built on the assumptions in §0. Every number is derived from those assumptions, so you can substitute your real MOSFET datasheet values and re-run the equations.

---

## 0. Architecture and Assumptions

**Architectural clarification.** In a production "H743 4-in-1 AIO" design, the STM32H743 does not commutate the motors. It runs ArduPilot and sends bi-directional DShot600 to four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32). Each ESC MCU drives a 3-phase gate driver and six MOSFETs. Commutating four motors at 48 kHz from the H743 alongside the flight stack is technically possible but unsupported by ArduPilot. This package assumes the split architecture.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_bus | 6S: 25.2 V max, 22.2 V nominal |
| Burst phase current per motor | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz, complementary (synchronous) PWM |
| MOSFET R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 1.2 mΩ (40 V, 3.3×3.3 mm DFN class) |
| R_DS(on) temperature coefficient | α | 0.0045 /K |
| Switching charge (Q_gs2 + Q_gd) | Q_sw | 12 nC |
| Total gate charge | Q_g | 60 nC |
| Output charge | Q_oss | 40 nC |

**Feasibility warning.** "80 A" on a nano-class board can only be a **burst** rating, of seconds, not continuous. §3 quantifies exactly how many seconds.

## 1. Conduction-Loss Model

### 1.1 Current path in 6-step synchronous PWM

During any commutation sector, phase X is driven by PWM and phase Y is held low:

- **PWM on:** current flows through HS_X → motor → LS_Y.
- **PWM off (synchronous):** current flows through LS_X → motor → LS_Y.

In both states, current flows through exactly **two MOSFET channels**. Ignoring dead time:

$$P_{cond,ch} = I_{rms}^2 \cdot 2R_{DS}(T_j)$$

### 1.2 Temperature dependence and ripple

On-resistance rises with junction temperature:

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C:

$$R_{DS} = 1.2 \times (1 + 0.0045 \times 85) = 1.66\ \text{m}\Omega$$

Phase-current ripple adds to the RMS value:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

Example: L_ph = 15 µH, worst-case ripple at D = 0.5, V_bemf ≈ V_bus/2 gives ΔI ≈ 8.75 A. The ripple term adds less than 0.1 % to I² and is negligible at 80 A.

### 1.3 Result at 80 A, T_j = 110 °C

$$P_{cond,ch} = 6400 \times 2 \times 1.66\times10^{-3} = \mathbf{21.2\ W\ per\ ESC\ channel}$$

**Per-FET split.** Each phase leg is "active" for one-third of the electrical cycle. Over a full rotation, the six FETs share the conduction energy roughly evenly:

$$P_{cond,FET} \approx \frac{I^2 R_{DS}}{3} = \frac{6400 \times 1.66\times10^{-3}}{3} = 3.54\ \text{W}$$

The share is set by duty cycle D: high-side FETs carry the D fraction, low-side FETs carry (1 − D) plus the full sector as return path.

## 2. Switching Losses at 48 kHz

Only the high side of the PWM phase hard-switches. The complementary low side commutates at near-zero V_DS after dead time.

### 2.1 Gate-current-limited transition times

Turn-on (source) current and rise time:

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_g} = \frac{10 - 3.5}{5} = 1.3\ \text{A}, \qquad t_r = \frac{Q_{sw}}{I_{g,on}} = 9.2\ \text{ns}$$

Turn-off (sink) current and fall time:

$$I_{g,off} = \frac{V_{pl}}{R_g} = 0.7\ \text{A}, \qquad t_f = \frac{Q_{sw}}{I_{g,off}} = 17.1\ \text{ns}$$

### 2.2 Loss components (V = 25.2 V, I = 80 A)

| Mechanism | Equation | Loss |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r + t_f) · f_sw | **1.27 W** |
| Body diode during dead time | V_F · I · 2t_dt · f_sw | 0.61 W |
| Reverse recovery | Q_rr · V · f_sw | 0.06 W |
| C_oss discharge | ½ · Q_oss · V · f_sw | 0.02 W |
| Gate charge (2 switching FETs, mostly dissipated in driver/R_g) | 2 · Q_g · V_drv · f_sw | 0.06 W |
| **Switching subtotal per channel** | | **≈ 2.0 W** |
