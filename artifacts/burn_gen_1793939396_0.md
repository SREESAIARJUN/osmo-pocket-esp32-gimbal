# STM32H743 AIO Flight Controller + 4-in-1 ESC: System Design Package (Job #46)

## 0. Architecture Corrections and Assumptions

Three issues need resolving before the math.

**1. The STM32H743 should not commutate the motors.** An H743 running ArduPilot cannot also perform sensorless FOC/6-step commutation for four motors at 48 kHz without jeopardizing EKF timing and failsafe guarantees. ArduPilot has no in-tree ESC firmware for this. The industry-standard and recommended split is:
- **FC domain:** STM32H743VIT6 (480 MHz) runs ArduPilot and emits bidirectional DShot600.
- **ESC domain:** 4× AT32F421K8U7 or STM32G071GBU6 running AM32. These receive DShot and return eRPM telemetry via GCR.

**2. "80 A" is defined here as per-motor phase current, burst.** All four channels at 80 A simultaneously is about 85 W of dissipation on a nano board. Section 3 shows this is survivable for only about 1.3 s. The design must be rated as a time-limited burst, not continuous.

**3. Component values below are representative, not tied to a specific datasheet.** Before release, substitute the exact datasheet values of your selected MOSFET.

## 1. Conduction Loss Model

**Temperature-dependent on-resistance**
R_ds(T_j) = R_ds25 · [1 + α(T_j − 25)]

At the design point T_j = 110 °C: R_ds = 1.0 · (1 + 0.005·85) = **1.425 mΩ**

**Current path.** In 6-step operation with synchronous rectification (complementary PWM), the phase current always flows through exactly two FETs in series: one high-side and one low-side (or its synchronous partner).

**Conduction loss per ESC channel**
P_cond = I² · 2 · R_ds(T_j) = 80² · 2 · 1.425 mΩ = **18.24 W**

**Copper loss.** Each 0.5 mm of 2 oz trace (8-layer stack, paralleled) is roughly 0.15 mΩ of path resistance:
P_cu ≈ 80² · 0.15 mΩ ≈ **0.96 W**

**Per-FET average.** Each FET conducts about 1/3 of the electrical cycle, so 18.24 W / 6 ≈ 3.0 W average per FET. Peak instantaneous loss in a conducting FET is 80² · 1.425 mΩ = 9.1 W. At eRPM > 30k, the electrical period is much shorter than the die thermal time constant, so the average value governs.

**Electrothermal stability check.** Because R_ds rises with temperature, conduction loss feeds back into junction temperature. The fixed point is:

T_j = T_b + R_θjb · P(T_j)

The loop is stable when R_θjb · ∂P/∂T < 1:
- ∂P/∂T = I² · R_ds25 · α · (1/3) = 6400 · 1e-3 · 0.005 / 3 ≈ 0.0107 W/K
- With R_θjb ≈ 8 K/W, loop gain = 0.085, so it is **stable with margin**.

## 2. Switching Loss Model at 48 kHz

Only one leg is PWM-switched at a time. Each period contains one turn-on and one turn-off hard-switching event.

| Loss mechanism | Formula | Value |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r + t_f) · f_sw = ½ · 25.2 · 80 · 45 ns · 48 k | **2.18 W** |
| Reverse recovery | Q_rr · V · f_sw = 50 nC · 25.2 · 48 k | 0.06 W |
| C_oss (2 FETs) | 2 · ½ · C_oss · V² · f_sw | 0.05 W |
| Dead-time diode conduction | V_f · I · 2 · t_dt · f_sw = 0.8 · 80 · 200 ns · 48 k | **0.61 W** |
| Gate drive (borne by driver IC) | 2 · Q_g · V_gs · f_sw | 0.05 W |
| **Total switching** | | **≈ 2.95 W** |

**Per-channel total:** P_ch = 18.24 + 0.96 + 2.95 ≈ **22.2 W**

**All four channels at 80 A:** P_tot ≈ **88.6 W**

**Sensitivity to switching frequency:**
∂P_sw/∂f_sw ≈ 61 µW/Hz per channel. Moving from 48 kHz to 24 kHz saves about 1.4 W per channel, but increases current ripple and motor noise. At 80 A, conduction loss dominates (≈82% of total), so lowering f_sw is a weak lever. Lower R_ds(on) or paralleled FETs are the effective levers.
