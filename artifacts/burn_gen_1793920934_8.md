# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Scope and Assumptions

I don't have the original specification for "Job #2," so this design is built on the assumptions below. Every assumption maps to a single constant in `config.hpp`, so you can correct any that don't match your hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7 with single-precision FPU |
| Motors | Gimbal BLDC, 14 pole pairs (28 magnets), 24 slots, R ≈ 10 Ω, L ≈ 3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A), SPI, 20 kHz |
| Current sensing | 2-shunt, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera payload, mounted at **r₂ = −r₁** about the payload rotation center |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |
| Rates | Current loop **20 kHz**, IMU ODR **8 kHz**, velocity loop **4 kHz**, angle loop **1 kHz** |
