## 0. Architecture Clarifications

These points affect every calculation that follows.

1. **The H743 does not drive the power bridges.** In every practical 4-in-1 design, each ESC channel has its own small MCU running AM32 or BLHeli_32. This design uses one STM32G071 per motor (AT32F421 is a drop-in option).
   - The ESC MCUs generate the 48 kHz complementary PWM, dead time, and BEMF zero-cross detection.
   - The H743 runs ArduPilot and emits bi-directional DShot600 to the four ESC MCUs.
2. **"80 A burst" is defined here as 80 A RMS phase current per motor, all four motors simultaneously, at 6S (25.2 V max).** This is the worst case. The model is parametric, so you can substitute your own numbers.
3. **The headline result: 80 A × 4 on a nano-class board is a transient rating only, roughly 1.5–2 s.** It is not a continuous rating. Section 3 derives this. Any datasheet claiming otherwise without a heatsink and airflow should be treated as marketing.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step trapezoidal commutation with synchronous rectification, two of the three phase legs carry the full phase current at every instant. Within each conducting leg, exactly one MOSFET carries the current at any time:

- During PWM-on, the high-side (HS) FET of the PWM'd leg conducts.
- During PWM-off, its complementary low-side (LS) FET conducts.

So the instantaneous conduction path always contains **exactly two R_ds(on)** in series, regardless of duty cycle D. This excludes the dead-time intervals, which Section 2 treats separately.

$$P_{cond,ESC} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

### 1.2 Temperature dependence

R_ds rises with junction temperature:

$$R_{ds}(T_j) = R_{ds,25}\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

Junction temperature in turn depends on dissipation:

$$T_j = T_{pcb} + P_{FET}\,(R_{\theta JC}+R_{\theta,pad\to pcb})$$

These form a loop, so the solution is found by fixed-point iteration. Electrothermal runaway occurs if the loop gain reaches 1:

$$\frac{\partial P}{\partial T}\cdot R_\theta \;=\; P_{cond}\,\frac{\alpha}{1+\alpha(T_j - 25)}\cdot R_\theta \;\ge 1$$

### 1.3 Numerical result (T_j = 125 °C, R_ds = 3.2 mΩ)

$$P_{cond,ESC} = 2(80)^2(3.2\times10^{-3}) = \mathbf{40.96\ W}$$

**Per-FET distribution.** Each leg is active for 240° of the 360° electrical cycle:

- 120° "sourcing": HS conducts for D, LS for 1 − D.
- 120° "sinking": LS conducts fully, because the low-side of the non-PWM'd leg is held on.
