## 0. Architecture

A single STM32H743 should **not** commutate 12 MOSFETs at 48 kHz while also running the ArduPilot flight stack. The design that works, and that the rest of this document assumes:

```
STM32H743 (ArduPilot FC)
   │  4× bi-directional DShot600 (TIM3 CH3/CH4, TIM5 CH1/CH2)
   ▼
4× ESC MCUs (AT32F421 / STM32G071, AM32 firmware, 48 kHz PWM)
   │  6 PWM lines each
   ▼
4× 3-phase gate drivers (FD6288Q-class)
   ▼
4× 3-phase bridges (6 N-ch MOSFETs each, 24 total)
```
