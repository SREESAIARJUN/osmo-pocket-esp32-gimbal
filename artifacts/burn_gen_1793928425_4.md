# STM32H743 AIO Flight Controller + 80A 4-in-1 ESC: Design Model (Job #21)

## 0. Architecture and Assumptions

This design rests on several assumptions. Where you have actual part numbers or constraints, substitute them; the method stays the same.

| Item | Assumption | Rationale |
|---|---|---|
| Topology | H743 runs ArduPilot. **Four dedicated ESC MCUs** (AT32F421 or STM32G071, running AM32) handle commutation. | The H743 cannot run four 48 kHz FOC/6-step loops alongside ArduPilot. Every production AIO splits the work this way. |
| Form factor | **30.5×30.5 mm mounting (≈36×36 mm board)**, 8-layer, 2 oz on all layers | An 80A/motor burst on a true 20×20 "nano" board is not thermally credible (see §2.5). |
| Bus voltage | 6S, V_bus = 25.2 V max | |
| MOSFET | 40 V N-ch, PDFN5×6. R_DS(on) = 1.0 mΩ @25 °C, tr = tf = 10 ns, Q_g = 60 nC, Q_rr = 40 nC, C_oss(tr) = 1.5 nF, V_SD = 0.8 V | Representative of 40 V / ~1 mΩ trench parts |
| Commutation | 6-step trapezoidal, synchronous rectification, complementary PWM, f_sw = 48 kHz, dead time t_d = 200 ns | |
| Gate drive | 3-phase driver (FD6288Q class), V_GS = 10 V | |

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\left[1+\alpha\,(T_j-25)\right],\qquad \alpha \approx 0.004\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.0 × 1.40 = **1.40 mΩ**.

### 1.2 Current paths in 6-step synchronous mode

In each 60° sector, phase A is PWM-switched (HS_A on for D, LS_A on for 1−D) and phase B is held low (LS_B on 100%). The phase current I therefore always flows through exactly **two** FETs in series:

$$P_{cond,motor} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2\,I^2 R_{DS}(T_j)$$

This result is independent of duty cycle, which makes it a useful design invariant.

At I = 80 A and T_j = 125 °C:

$$P_{cond,motor} = 2 \times 80^2 \times 1.40\,\text{m}\Omega = \mathbf{17.9\ W}$$

### 1.3 Per-FET distribution

Each FET is active for 120° of every 360° electrical. Its time-averaged share is:

$$P_{cond,FET,avg} = \frac{17.9}{6} \approx 3.0\ \text{W}\quad(\text{worst-case HS at } D\to1:\ \approx 3.0\ \text{W})$$

**Caveat at low eRPM:** at startup or stall (an electrical period approaching the thermal time constant of the junction), a single FET carries its full I²R:

$$P_{peak,FET} = 80^2 \times 1.4\,\text{m}\Omega = 8.96\ \text{W}$$

This case is evaluated against Z_th(j-c) in §3.2.

### 1.4 PCB copper loss

Each phase path has trace, plane and via resistance. For 2 oz copper on 4 parallel layers, a 6 mm wide, 15 mm long path:

$$R_{Cu} = \frac{\rho L}{W\,t\,n} = \frac{1.72\times10^{-8}\times0.015}{0.006\times70\times10^{-6}\times4}\approx 0.154\ \text{m}\Omega$$

Both legs of the path together give ≈ 0.31 mΩ, so P_Cu ≈ 80² × 0.31 mΩ ≈ **2.0 W per motor**. Battery pad to bus loss is additional (see §2.4).

## 2. Switching Loss Model @ 48 kHz

Only the PWM leg switches. The held-low leg does not.

### 2.1 Hard-switching V·I overlap (HS turn-on and turn-off)

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\text{ns} \times 48\,\text{kHz} = \mathbf{0.97\ W}$$

### 2.2 Reverse recovery (LS body diode → HS turn-on)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\,\text{nC}\times25.2\times48\,\text{k} = \mathbf{0.05\ W}$$

### 2.3 Output capacitance

$$P_{oss} = \tfrac12 C_{oss}V_{bus}^2 f_{sw}\times 2 = 0.5\times1.5\,\text{nF}\times635\times48\,\text{k}\times2 = \mathbf{0.05\ W}$$

### 2.4 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = V_{SD}\, I\, (2t_d)\, f_{sw} = 0.8\times80\times400\,\text{ns}\times48\,\text{k} = \mathbf{1.23\ W}$$

> **Design lever:** this is the largest switching-related term. Reducing dead time to 100 ns, which the driver and FET t_d(off) margins permit, halves it to 0.61 W. AM32 exposes this setting as the "dead time" parameter.

### 2.5 Gate drive (dissipated in driver and gate resistors, not in the FETs)

$$P_g = Q_g V_{GS} f_{sw}\times 2 = 60\,\text{nC}\times10\times48\,\text{k}\times2 = 0.058\ \text{W per motor}$$

### 2.6 Loss budget at 80A burst (per motor and board total)

| Term | Per motor (W) | ×4 (W) |
|---|---|---|
| Conduction (125 °C) | 17.90 | 71.6 |
| PCB copper | 2.00 | 8.0 |
| V·I switching | 0.97 | 3.9 |
| Dead-time diode | 1.23 | 4.9 |
| Q_rr + C_oss | 0.10 | 0.4 |
| Gate drive | 0.06 | 0.2 |
| **Total** | **22.3** | **≈ 89 W** |

Efficiency check: 4 × 80 A × 25.2 V × D. At D ≈ 0.9 the output is about 7.3 kW, so η ≈ 98.8%. The percentage is good, but the absolute heat is severe for a 13 cm² board.

**Why a 20×20 board fails:** about 89 W into roughly 4 cm² of board area is a flux of ~22 W/cm². That is CPU-heatsink territory, with no heatsink present.

## 3. Thermal Model

### 3.1 Board-level lumped capacitance (adiabatic burst)

For a 36×36 mm board, 8 layers, 2 oz copper, ~60% copper fill:

| Mass | Calculation | C_th (J/K) |
|---|---|---|
| Copper | 36×36×0.07 mm × 8 × 0.6 = 0.435 cm³ → 3.9 g × 0.385 | 1.50 |
| FR4 core/prepreg | 2.07 cm³ × 1.85 g/cm³ = 3.8 g × 1.1 | 4.20 |
| 24 FETs + caps + solder | estimate | 1.00 |
| **Total** | | **≈ 6.7 J/K** |

Adiabatic heating rate (worst case, ignoring airflow):

$$\frac{dT}{dt}=\frac{P}{C_{th}} = \frac{89}{6.7}\approx 13.3\ \text{K/s}$$
