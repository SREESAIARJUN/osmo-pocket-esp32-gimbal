# STM32H743 Nano AIO (Job #44): Power-Stage Thermal Model, Switching Losses, and Bi-Directional DShot600 Allocation

## 0. Assumptions and Feasibility Constraints

These assumptions shape every number below.

1. **Architecture.** The STM32H743 is the flight controller. On a 4-in-1 board, each ESC channel needs its own commutation MCU. This design assumes an AT32F421 per channel running AM32. The H743 sends bi-directional DShot600 to each ESC MCU. The H743 does not drive the gates directly.
2. **80 A is a per-channel transient (burst) rating, not continuous.** On a 20×20 mm board the conduction losses below are too high for steady state. Burst duration is therefore an explicit design output (§3.4).
3. **4 × 80 A = 320 A at the battery is not physically supportable** by any connector or pad set compatible with a nano board. XT30 is about 15 A continuous; XT60 is about 60 A continuous. The battery-side limit must be set by a total-current constraint (§3.5).
4. **Supply voltage.** 6S nominal, with V_bus = 25.2 V (full charge) used for loss calculations. Components are rated for 8.4 V/cell plus regen spikes on a 40 V class.
5. **MOSFET values are parametric.** They represent a 40 V, PQFN 3.3×3.3 class device. Replace them with your selected part's datasheet values. Every equation is written so you can substitute.
6. **Part numbers and pinouts.** Part numbers are given as candidate families. Netlist pin numbers must be verified against the current datasheets before layout. This is a reference design, not a signed-off release.

## 2. Conduction Loss Model (6-Step Trapezoidal, Complementary PWM)

### 2.1 Commutation Topology

In each 60° sector:
- one phase is driven "high" with HS PWM at duty D and complementary LS at 1−D,
- one phase is held "low" with LS continuously on,
- the third phase floats.

Over one electrical period, each phase spends 1/3 of the time in each state.

### 2.2 Per-FET RMS Current

With phase current I flat-topped during conduction:

$$I_{HS,rms}^2 = I^2 \cdot \frac{D}{3}$$

$$I_{LS,rms}^2 = I^2\left[\frac{1}{3} + \frac{1-D}{3}\right] = I^2\cdot\frac{2-D}{3}$$

Per-channel total, summed over 3 legs:

$$P_{cond,ch} = 3R_{ds}\left[\frac{D}{3}+\frac{2-D}{3}\right]I^2 = \mathbf{2\,I^2 R_{ds}}$$

This result is independent of D, which matches intuition: two FETs are always in the current path.
