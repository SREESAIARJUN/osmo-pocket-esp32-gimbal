# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #51): Architecture, Loss Model, DShot DMA Plan, and Netlist

## 0. Scope, Assumptions, and a Feasibility Flag

**Architecture assumed.** An STM32H743 runs ArduPilot as the flight controller. Four dedicated ESC MCUs (AT32F421 running AM32, one per motor) drive the power stages on the same PCB. The H743 does not commutate motors directly, because bidirectional DShot only makes sense when there are separate ESC MCUs to talk to.

**Feasibility flag.** "80 A burst per motor" on a 20×20 mm "nano" board is not thermally credible beyond about 1 second. The math below quantifies this. For 80 A bursts, plan for a 30.5×30.5 mm board or larger, with 2–3 oz copper and a heatsink.

All component parameters below are representative values for the class of part. Substitute datasheet values before sign-off.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current | I_pk | 80 A |

## 1. Conduction Loss Model

**Commutation assumption.** Use 6-step trapezoidal drive with complementary (synchronous) PWM. At any instant, exactly two legs carry current:
- The PWM leg: the high-side FET conducts for duty D, and the synchronous low-side FET for 1−D.
- The static low-side leg: conducts 100% of the time.

**Per-motor conduction loss.**

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

**Temperature dependence.**

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

**Numbers.** At T_j = 115 °C, R_ds = 1.0 × (1 + 0.0055 × 90) ≈ 1.5 mΩ.

$$P_{cond} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W\ per\ motor}$$

**Electrothermal fixed point.** Conduction loss raises temperature, which raises R_ds, which raises loss:

$$T_j = T_{ref} + R_\theta\, 2 I^2 R_{ds,25}[1+\alpha(T_j-25)]$$

Solving for T_j:

$$T_j = \frac{T_{ref} + R_\theta k (1 - 25\alpha)}{1 - R_\theta k \alpha}, \qquad k = 2 I^2 R_{ds,25} = 12.8\ \text{W}$$

**Runaway criterion.** Thermal runaway occurs when R_θ·k·α ≥ 1, which gives R_θ ≥ 14.2 K/W per motor-pair path. A nano board in prop wash is roughly 8–12 K/W per bridge region. That is close to the cliff, so steady-state 80 A operation is impossible on this board.

## 2. Switching Losses at 48 kHz

Only the PWM leg switches. Each PWM period has one turn-on and one turn-off hard transition.

| Loss term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·20 ns·48 k | 0.97 W |
| Dead-time diode conduction | V_f·I·2·t_dt·f_sw = 0.8·80·200 ns·48 k | 0.61 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 k | 0.06 W |
| Coss charge | ½·C_oss·V²·f_sw (C_oss ≈ 1.5 nF) | 0.02 W |
| Gate drive (lands mostly in driver and R_g) | 2·Q_g·V_gs·f_sw = 2·60 nC·10·48 k | 0.06 W |
| **Switching subtotal** | | **≈1.7 W** |

**Per-motor total at 80 A burst:** 19.2 + 1.7 ≈ **20.9 W**.

**All four motors at burst:** ≈ **84 W**.

Add the following before reaching the board total:
- Shunt loss: 0.25 mΩ shared bus shunt × (4 × 80 A × D_avg)² gives about 5 W at peak.
- Copper loss: about 3–6 W on 2 oz pours.

**Board total: ≈ 90–95 W during a full-throttle burst.**

**Design sensitivity.** Conduction loss is about 92% of the total. Choose the FET for R_ds, not for switching speed. Raising f_sw from 24 kHz to 48 kHz costs only about 0.85 W per motor.

## 3. Thermal Calculations

### 3.1 Junction-to-case rise (per FET)

Each motor dissipates 20.9 W across two conducting FETs, roughly 10.5 W per FET.

$$\Delta T_{jc} = 10.5 \times 1.2 = 12.6\ \text{K}$$

This is not the bottleneck.

### 3.2 Board-level lumped RC model

| Element | Heat capacity |
|---|---|
| 20×20 mm FR4, 1.6 mm, 0.7 g | ≈ 0.8 J/K |
| Copper, 8 layers, about 2 g | ≈ 0.8 J/K |
| 12 FETs plus solder | ≈ 0.5 J/K |
| **C_th total** | **≈ 2.1 J/K** |

Board-to-ambient resistance in prop wash: R_θ,ba ≈ 6 K/W.

$$\Delta T(t) = P R_\theta (1 - e^{-t/\tau}), \qquad \tau = R_\theta C_{th} \approx 12.6\ \text{s}$$
