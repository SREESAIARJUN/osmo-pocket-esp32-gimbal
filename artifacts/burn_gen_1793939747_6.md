# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #42)

I don't have the Job #42 specification, so this design uses the assumptions in Section 0. Every assumption is a named constant in the code, so you can retune it without touching the math.

---

## 0. Assumptions and Loop Timing

| Item | Value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5 Ω, L = 2 mH |
| Encoder | 14-bit absolute magnetic (MT6701/AS5048 class), read in the PWM ISR |
| Current sensing | 2-phase low-side shunts (a voltage-mode fallback is noted) |
| PWM / current loop | 20 kHz, center-aligned, ADC triggered at the counter peak |
| Velocity loop | 4 kHz (every 5th current ISR) |
| Angle loop + IMU fusion | 4 kHz IMU data in, 1 kHz attitude/angle loop out |
| IMUs | 2× ICM-42688-P, SPI at 24 MHz, ODR 4 kHz, ±2000 dps, ±16 g |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Bandwidth separation rule.** Each loop is 5–10× slower than the loop inside it:

ω_c,cur ≈ 2π·2000 rad/s  ≫  ω_c,vel ≈ 2π·150  ≫  ω_c,pos ≈ 2π·20

## 1. FOC Core Equations

### 1.1 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

### 1.2 Park transform

θ_e = p·θ_m − θ_offset

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.3 Plant model in the dq frame

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q
```

### 1.4 Current PI with pole-zero cancellation

Use cross-coupling decoupling plus back-EMF feedforward:

```
v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m
```

Choosing K_p = L·ω_cc and K_i = R·ω_cc cancels the electrical pole at R/L. The closed loop then becomes a first-order system with bandwidth ω_cc:

G_cl(s) = ω_cc / (s + ω_cc)

Keep ω_cc ≤ ω_s/10 to tolerate the 1.5-sample delay (computation plus PWM update).
