## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

Electrical angle comes from the mechanical encoder angle with a calibrated offset:

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

**Delay compensation.** The PWM update lands about 1.5 samples after the measurement, so the angle used in the inverse Park transform is advanced:

$$\theta_e^{*} = \theta_e + 1.5\,\omega_e T_s$$

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e^* - v_q\sin\theta_e^*,\qquad v_\beta = v_d\sin\theta_e^* + v_q\cos\theta_e^*$$

### 1.2 Current PI with decoupling

Motor model in the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

**Pole-zero cancellation tuning.** Set the PI zero on the electrical pole $R/L$ to get a closed-loop bandwidth $\omega_c$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10}\;(\approx 2\pi\cdot 2\,\text{kHz})$$

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

**Voltage limit.** The output is clamped to the linear SVPWM hexagon's inscribed circle, $\|v_{dq}\| \le V_{bus}/\sqrt3$. The d-axis gets priority:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

### 1.3 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

Torque is $\tau = K_t i_q$, with $K_t = \tfrac32 p\lambda_m$.

**Voltage-mode fallback (no shunts).** Set $v_d = 0$ and compute

$$v_q = R\,i_q^{ref} + K_e\,\omega_m$$

## 2. Cascaded Angle → Velocity Control

### 2.1 Structure

Each axis runs this cascade:

```
θ_ref ─►(+)─► P_θ ─(+ω_ff)─►(+)─► PI_ω ─(+i_cog_ff + i_ff)─► sat ─► i_q,ref ─► FOC
         ▲−                    ▲−
         θ (attitude, 1 kHz)   ω_cam (filtered gyro, 4 kHz)
```

**Velocity feedback should come from the camera IMU gyro, not the encoder.** The gimbal's job is to hold the camera's *inertial* rate at its command. Encoder rate only measures the motor relative to the base, so base vibration would pass straight through. The encoder is still used for commutation, cogging lookup, and joint limits.
