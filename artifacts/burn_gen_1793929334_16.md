# FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #60)

I don't have the Job #60 specification, so this design states its assumptions explicitly. Swap in your actual motor and inertia parameters. Everything below is derived generally, so the equations still hold when the numbers change.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | BLDC gimbal motors, e.g. 12N14P (N_s=12 slots, N_p=14 poles, p=7 pole pairs) |
| Encoder | 14-bit absolute magnetic encoder (e.g. AS5048A / MT6701) per axis |
| Current sensing | Low-side shunts with 2 or 3 phases, sampled at PWM center |
| PWM | 20 kHz center-aligned SVPWM |
| IMUs | 2× ICM-42688-P rigidly mounted on the camera plate, separate SPI chip-selects, 8 kHz ODR |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates (rate-separated cascade):**

```
 20 kHz  : current loop (FOC)          ← ISR on ADC end-of-conversion
  8 kHz  : IMU sampling + vibration filters
  4 kHz  : velocity loop (+ cogging FF)
  1 kHz  : attitude fusion + angle loop
```

**Control topology for one axis:**

```
θ_ref ─►(Σ)─► P_θ ─►(Σ)◄─ ω_ff (base-rate feedforward)
          ▲          │
     θ_fb (IMU/AHRS) ▼
                    (Σ)─► PI_ω ─►(Σ)─► i_q* ─► PI_d,q (FOC) ─► SVPWM ─► motor
                     ▲               ▲
           ω_fb (filtered gyro)    i_q,cog (anti-cogging FF)
```
