# STM32H743 Nano AIO Flight Controller + 4-in-1 ESC (Job #32)
## Design Note: Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 Timer/DMA Allocation

This note covers architecture, the loss model, the thermal analysis, the ArduPilot timer/DMA configuration, and reference netlists. Read the caveats in §0 first. They change what "80 A" can mean on a nano-format board.

> **Architectural note.** The STM32H743 does not commutate the motors. ArduPilot has no ESC commutation firmware, and running four sensorless BLDC control loops alongside the flight stack is not a viable design. The H743 runs ArduPilot and sends bidirectional DShot600 to four dedicated ESC MCUs. Each ESC MCU runs AM32, which handles the 48 kHz PWM and commutation. All loss analysis below therefore applies to the ESC half of the board.

> **Honesty flag on the "80 A" rating.** The math in §3 shows that a 20×20 board can sustain roughly 20–25 A per channel continuously. 80 A is a **thermal-capacitance-limited transient lasting about 1–2 s**. The spec sheet must state it that way. Marketing an 80 A continuous rating on this format would be a false claim and a field-failure risk.

> **Verification required.** All part parameters above are representative. Substitute your actual BOM datasheet values before release.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\left(1+\alpha\right)^{T_j-25},\quad \alpha \approx 0.0045\ /\mathrm{K}$$

At T<sub>j</sub> = 125 °C:

$$R_{DS(on)} = 1.2\ \mathrm{m\Omega}\times 1.0045^{100} \approx 1.2\times1.566 = 1.88\ \mathrm{m\Omega}$$

Add the layout copper per conduction path. Two FETs in series plus pours gives R<sub>cu</sub> ≈ 0.4 mΩ hot (8-layer, 2 oz, short loops). The effective resistance per conducting switch is then:

$$R_{eff} = R_{DS(on)}(T_j) + \tfrac{1}{2}R_{cu} \approx 2.08\ \mathrm{m\Omega}$$

### 1.2 Six-step complementary PWM topology

In any 60° commutation sector of a channel:
- Phase A high-side is PWMing at duty D.
- Phase A low-side conducts in synchronous rectification for 1−D, minus dead time.
- Phase B low-side is on continuously.
- Phase C floats, used for BEMF sensing.

Phase current I<sub>ph</sub> always flows through exactly two channels' worth of R<sub>eff</sub>:

$$P_{cond,ch} = I_{ph}^2 R_{eff}\left[D + (1-D)\right] + I_{ph}^2 R_{eff} = 2\,I_{ph}^2\,R_{eff}$$

The result is **independent of duty**, which is a useful property of synchronous rectification. Battery current relates as I<sub>bat</sub> ≈ D·I<sub>ph</sub>.

### 1.3 Numbers at 80 A burst

$$P_{cond,ch} = 2 \times 80^2 \times 2.08\times10^{-3} = 26.6\ \mathrm{W}$$

The per-FET average uses the fact that each FET conducts about 1/3 of the electrical period, rotating at kHz electrical rates. That is far faster than the die thermal time constant, so averaging is valid:

$$\bar P_{FET} \approx \frac{26.6}{6} \approx 4.4\ \mathrm{W}$$

The worst-case instantaneous figure, for the continuously-on low-side, is 80²·2.08 mΩ = 13.3 W per 1/3 cycle. This matters only at very low eRPM, such as startup or desync, where the electrical period approaches the die Z<sub>th</sub> time constant (~1 ms).
