## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, λ = 0.012 V·s/rad |
| Encoder | 14-bit absolute magnetic (AS5048A or similar) per axis |
| MCU | STM32G4 / H7 class, single-precision FPU |
| DC bus | V_dc = 12–16 V |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ±2000 dps, ±16 g |

The control loops run at the following rates:

```
 20 kHz  ── ADC → Clarke/Park → PI_d, PI_q → inv-Park → SVPWM        (current loop)
  8 kHz  ── IMU×2 read → calibrate → align → notch/LPF → fuse          (sensor)
  4 kHz  ── velocity PI (gyro rate) + anti-cogging FF → i_q*            (velocity loop)
  1 kHz  ── Mahony attitude → angle P(+FF) → ω*                         (angle loop)
```

Each loop's bandwidth is roughly 4–10× lower than the loop inside it. This separation lets the cascade be designed one loop at a time.

## 1. FOC Current Loop

### 1.1 Transforms

The amplitude-invariant Clarke transform, using the constraint i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform rotates into the rotor frame, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model (SPMSM)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

Electromagnetic torque:

$$\tau_e = K_t\, i_q,\qquad K_t = \tfrac32 p\lambda$$

### 1.3 Decoupled PI by Pole–Zero Cancellation

With the cross-coupling and back-EMF terms fed forward, each axis reduces to the first-order plant 1/(Ls + R).

1. Choose the PI zero to cancel the electrical pole: K_i/K_p = R/L.
2. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{s}}{20}$$

3. The voltage feedforward that removes the coupling terms is:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda)$$

### 1.4 Discretization and Anti-Windup

The PI uses backward Euler with back-calculation anti-windup:

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(\text{sat}(u_k) - u_k)$$

The recommended back-calculation gain is $K_{aw} = 1/K_p \cdot K_i T_s$, which is equivalent to a tracking time constant $T_t = K_p/K_i$.
