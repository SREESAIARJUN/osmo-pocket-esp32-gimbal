# Job #39: STM32H743 Nano AIO (FC + 4-in-1 ESC), 80 A Burst Design Package

**Rev A, Systems Architecture**

---

## 0. Scope, Architecture Assumptions, and Feasibility Flags

Several constraints in this brief interact in ways that need to be resolved before layout.

| Item | Assumption | Note |
|---|---|---|
| Bus voltage | 6S LiPo, 25.2 V max, 22.2 V nominal | 40 V-rated FETs give 1.59× margin, which is the minimum acceptable for ringing. |
| Form factor | "Nano" AIO, 25.5 × 25.5 mm (20 × 20 M2 mounting), 8-layer, 2 oz on all layers | See thermal result in §2.6. |
| Flight controller MCU | STM32H743VIT6 (LQFP100), 480 MHz | Runs ArduPilot. |
| ESC MCUs | 4× AT32F421K8U7 or STM32G071GBU6 running AM32 | **The H743 does not commutate motors.** The 48 kHz PWM runs on the ESC MCUs. The H743 only emits DShot600. |
| Gate driver | 4× FD6288Q-class 3-phase half-bridge driver, VCC ≈ 10 V from a local LDO/buck | |
| MOSFETs | 24× 40 V N-ch, DFN3.3×3.3 class | Representative parameters in §1. **Substitute real datasheet values before release.** |
| PWM | 48 kHz, complementary (synchronous) 6-step, AM32 | |
| "80 A burst" | Per motor phase current, ≤ 2 s | The model shows sustained 80 A is not thermally possible on a nano board. |

**Feasibility flags:**

1. 80 A per channel on a 25.5 mm board is a short-burst rating only. The model in §2 gives roughly 2–3 s to the derated junction limit at 40 °C ambient.
2. Onboard MLCCs cannot handle the bus ripple at this current. An external low-ESR bulk capacitor of at least 1000 µF / 35 V is mandatory (§3.3).
3. The ESC firmware must enforce the burst limit, using AM32 current limiting plus temperature-sensor foldback.
