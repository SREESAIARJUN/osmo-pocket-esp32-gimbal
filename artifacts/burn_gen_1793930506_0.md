# STM32H743 Nano AIO (20×20) with 4‑in‑1 ESC: Engineering Design Package, Job #16

**Scope:** Electro‑thermal model at an 80 A burst per channel, 48 kHz switching‑loss model, ArduPilot bi‑directional DShot600 timer/DMA plan, reference netlists, and thermal budget.

**Status:** This is a pre‑layout reference design. The MOSFET and gate‑driver parameters are representative values for the 40 V, 3.3×3.3 mm DFN class. Before release, replace them with the datasheet values of the parts you select and validate on a thermocouple and IR rig.

## 0. Architectural Ground Truth

The STM32H743 does not drive the MOSFETs directly. On a 4‑in‑1 AIO it runs ArduPilot as the flight controller. Each motor channel has its own ESC MCU, either AT32F421 or STM32G071 running AM32, or EFM8BB21 running BLHeli_S. Each ESC MCU drives a 3‑phase gate driver (FD6288Q class), which drives 6 N‑FETs. The H743 talks to the ESCs only over the four bi‑directional DShot lines.

**Executive conclusion (derived in §3):** On a 20×20 mm board, "80 A" is only credible as a **single‑channel, sub‑second burst**.

- With all four channels at 80 A, the board heats at about **70 K/s**.
- From a 40 °C start, it reaches the T_j = 125 °C limit in about **0.4 s**.
- Sustainable continuous dissipation is about **7–10 W total**, which is roughly **25–30 A per channel** with prop‑wash cooling.

## 1. Conduction Loss Model

### 1.1 Assumed operating point

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V |
| Phase current (burst) | I_ph | 80 A |
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 1.8 mΩ |
| Temperature coefficient | α | 0.0045 /K (≈1.45× at 125 °C) |
| Motor L (line‑line, 2207–2306 class) | L | ~20 µH |
| PWM frequency | f_sw | 48 kHz |
| Commutation | — | 6‑step trapezoidal, complementary (synchronous) PWM |

### 1.2 Temperature‑dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 100 °C: R = 1.8 × 1.3375 ≈ **2.41 mΩ**. At T_j = 125 °C: R ≈ **2.61 mΩ**.

### 1.3 RMS current including PWM ripple

The peak‑to‑peak ripple current is:

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.6\ \text{A}_{pp}\ \ (\text{worst case } D=0.5)$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple contribution is negligible (<0.1 %) at 48 kHz. This is a key benefit of the high switching frequency.
