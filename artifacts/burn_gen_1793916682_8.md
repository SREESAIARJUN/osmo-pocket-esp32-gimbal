# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #45 specification, so this design uses typical gimbal hardware. Every value marked *(param)* is a parameter. Update it from your BOM and measurements before tuning.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 1–3 mH *(param)* |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| MCU | STM32G4 / H7 class: FPU, hardware CORDIC or fast sin/cos, center-aligned PWM, injected ADC |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI + DMA, 8 kHz ODR |
| Kinematics | Yaw (outer, z) → Roll (x) → Pitch (inner, y) |

## 1. Loop Architecture and Timing

```
                1 kHz                    4 kHz                     20 kHz
q_ref ──► [Attitude error → joint frame] ──► [Velocity PI] ──► iq* ──► [Current PI ×2 + decoupling] ──► SVPWM
             ▲  (P + ω feedforward)            ▲    +iq_cog(θm)           ▲ id,iq (Clarke/Park, θe)
             │                                 │    (anti-cogging FF)     │
      Mahony AHRS ◄── dual-IMU fusion ◄── per-IMU filter chain (8 kHz) ◄── 2× ICM-42688-P
                                         gyro rate projected on joint axis
      Encoder (20 kHz) ──► θe for commutation, θm for cogging FF, PLL ω̂ for damping/fallback
```

Bandwidth separation is roughly 5× per stage:

- Current loop: ~1.5–2 kHz
- Velocity loop: ~150–300 Hz
- Angle loop: ~20–40 Hz

The velocity loop uses the **inertial gyro rate** of the payload, not the encoder rate. This is what makes the gimbal reject base motion, because the gyro sees the disturbance directly. The encoder is used for commutation, cogging feedforward, and as a fault-fallback rate source.

## 2. FOC Current Loop (20 kHz)

### 2.1 Electrical Angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p(\theta_m - \theta_{off})\big)$$

θ_off is found at startup: apply V_d with θ_e = 0, wait for the rotor to settle, then record θ_m.

### 2.2 Clarke and Park Transforms

Two-shunt measurement with i_a + i_b + i_c = 0 (amplitude-invariant):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.3 Plant in the Synchronous Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 2.4 PI with Decoupling and Back-EMF Feedforward

$$v_d^* = \mathrm{PI}_d(i_d^* - i_d) - \omega_e L\, i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \omega_e L\, i_d + \omega_e \lambda_m$$
