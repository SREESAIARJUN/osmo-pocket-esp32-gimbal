# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

## 0. Assumptions

I don't have the Job #48 specification, so this design uses common BLDC-gimbal parameters. Each one is parameterized in code (`GimbalConfig`). Replace them with your measured values before tuning.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, ≥170 MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701) per joint |
| Current sensing | 2-shunt low-side, synchronous ADC |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematic order | Yaw (base) → Roll → Pitch (camera) |
| Loop rates | Current 20 kHz · IMU/notch 8 kHz · Rate loop 4 kHz · Attitude 1 kHz |

Two items must be checked before flashing:
- The ICM-42688-P register addresses and AAF/notch tables, against your datasheet revision (DS-000347).
- The current-sense polarity, in a bench test.
