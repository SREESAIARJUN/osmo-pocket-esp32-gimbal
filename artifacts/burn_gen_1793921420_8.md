# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have your Job #47 specification, so the design below is built on explicit, typical assumptions. Every numeric parameter is in a single config struct, so you can substitute your actual motor and inertia data without touching the algorithms.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (GBM2804-class), 12N14P → p = 7 pole pairs, R ≈ 5.6 Ω (phase), L ≈ 2.0 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, on each motor shaft |
| MCU | STM32G4 / H7-class Cortex-M with FPU, single-precision float |
| Inverter | 3-shunt or 2-shunt low-side current sensing, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera payload, mounted 180° apart about Z |

**Loop rates:**

```
PWM / current loop (FOC)     : 25 kHz   (ISR, ADC-triggered)
Encoder PLL + velocity loop  : 5  kHz   (every 5th current ISR)
IMU sample (both, SPI DMA)   : 8  kHz   (ODR)
IMU filter chain             : 8  kHz -> decimate to 1 kHz
Attitude estimator + angle   : 1  kHz
```

**Control structure (per axis):**

```
 q_ref ─► [Attitude err] ─► ω_cam* ─► [J⁻¹(q_joint)] ─► ω_joint*
                │                                         │
            IMU fusion                                    ▼
                                            [Velocity PI] ◄─ ω̂ (encoder PLL)
                                                   │
                                     i_q* = i_q,PI + i_q,cog(θ_m) + i_q,ff
                                                   ▼
                                        [Current PI d/q + decoupling]
                                                   ▼
                                        inverse Park → SVPWM → inverter
```

The design has two deliberate features:

- **Outer loop on the IMU, inner velocity loop on the encoder.** The encoder velocity is vibration-immune and phase-clean, which allows a high inner bandwidth.
- **IMU feedback is confined to the 1 kHz attitude loop.** It runs after heavy, phase-budgeted vibration
