## 1. Loop Architecture and Timing

```
             1 kHz                 8 kHz                    24 kHz
 θ_ref ──►[Attitude P + FF]──ω_ref──►[Rate PI + FF]──iq_ref──►[Current PI]──►SVPWM──►Motor
              ▲                        ▲     ▲                    ▲
              │ attitude q             │ ω_cam (filtered gyro)    │ id,iq
       [Mahony AHRS]◄──────[Dual-IMU fusion + notches]◄── 2×ICM-42688-P @ 8 kHz
                                       │
                         [Cogging FF: iq_ff(θ_m)] ◄── encoder θ_m (24 kHz)
```

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than the loop inside it, and each loop's sample rate should be at least 10× its bandwidth.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 24 kHz | ~1.5 kHz |
| Rate | 8 kHz | ~150 Hz |
| Attitude | 1 kHz | ~30 Hz |

## 2. FOC Current Loop Equations

### 2.1 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 2.2 Park transform (θ_e = p·θ_m − θ_offset)

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.3 Plant model in the dq frame (SPM motor, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 2.4 PI with cross-coupling decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

With λ_m = Kt / (1.5p), choosing the gains by **pole-zero cancellation** makes the closed loop first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Example: ω_c = 2π·1500 rad/s gives K_p = 28.3 V/A and K_i = 94 250 V/(A·s).

### 2.5 Discretization and anti-windup

The PI integrator uses backward Euler with back-calculation:

$$x_{k+1} = x_k + T_s\left[K_i e_k + K_{aw}(u_{\text{sat},k} - u_k)\right],\qquad K_{aw}\approx K_i/K_p$$

### 2.6 Voltage limit (circular, d-axis priority)

$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2-v_d^2},\qquad V_{max}= \frac{V_{bus}}{\sqrt3}\cdot 0.95$$
