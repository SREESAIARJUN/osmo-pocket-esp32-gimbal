# STM32H743 Nano FC + 4-in-1 ESC: Power Stage Loss Model, Thermal Analysis, and Bi-Directional DShot600 DMA Allocation

## 0. Scope and Feasibility Flags

I don't have a prior "Job #30" design file, so this document builds the model from first principles. Every component value is an explicit assumption that you can replace with your datasheet numbers. Three points need to be settled before any number below is trusted.

1. **Partitioning.** The STM32H743 does not drive the MOSFETs. On a 4-in-1 stack it runs ArduPilot and emits DShot. Each motor channel has its own ESC MCU (AT32F421 or STM32G071 running AM32, or EFM8 running Bluejay) that generates the 48 kHz PWM.
2. **80 A on a nano board.** "80 A burst" is only credible as a short per-motor transient. Four motors at 80 A each draw about 320 A from the battery. That is not realistic for a 20×20 or 25.5×25.5 board's battery pads, XT60/XT90 lead, or copper pours. The model below quantifies how short "burst" has to be.
3. **Required tests.** All numbers are first-order. Thermal results especially must be validated with thermocouple or IR measurement on a real board (Section 7).

## 1. Conduction Loss Model

### 1.1 Topology

Assume 6-step trapezoidal drive with complementary (synchronous-rectified) PWM, which is the AM32/Bluejay default. In any commutation sector:

- **Switching leg:** the high-side conducts for D·T_sw and the low-side (sync rectifier) for (1−D)·T_sw.
- **Sink leg:** the low-side conducts continuously.
- **Floating leg:** off.

### 1.2 Per-motor conduction loss

```
P_cond,HS = D·I_rms²·R_DS(Tj)
P_cond,LS(sync) = (1−D)·I_rms²·R_DS(Tj)
P_cond,sink = I_rms²·R_DS(Tj)

P_cond,motor = I_rms²·R_DS(Tj)·[D + (1−D) + 1] = 2·I_rms²·R_DS(Tj)
```

The total is duty-independent. That is a useful property: worst case equals typical case for conduction.

### 1.3 Ripple correction

```
ΔI = V_bus·D(1−D) / (L·f_sw) = 25.2·0.25 / (20e-6·48e3) = 6.56 A_pp   (worst at D = 0.5)
I_rms² = I² + ΔI²/12 = 6400 + 3.6 = 6403.6 A²
```

Ripple contributes less than 0.06 %, so it is negligible at 48 kHz.

### 1.4 Temperature dependence

```
R_DS(Tj) = R₂₅·[1 + α(Tj − 25)],   α ≈ 0.0059 /K  →  k_T ≈ 1.5 at 110 °C
R_DS = 0.85 mΩ × 1.5 = 1.275 mΩ

P_cond,motor = 2 × 6403.6 × 1.275e-3 = 16.33 W
```

This is coupled to T_j, so iterate it with Section 3 until the result converges. Convergence is usually reached in two or three iterations.

## 2. Switching Loss Model (48 kHz)

With synchronous rectification, only the switching-leg high-side hard-switches. The low-side switches at near-zero V_DS because its body diode is already conducting.

| Mechanism | Equation | Result |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·30e-9·48e3 | 1.452 W |
| Reverse recovery (LS body diode) | Q_rr·V·f_sw = 40e-9·25.2·48e3 | 0.048 W |
| C_oss charge/discharge | ½·C_oss(er)·V²·f_sw ×2 FETs | 0.046 W |
| Dead-time diode conduction | 2·V_F·I·t_dt·f_sw = 2·0.8·80·100e-9·48e3 | 0.614 W |
| Gate drive (dissipated in driver/R_g) | Q_g·V_GS·f_sw ×2 FETs | 0.048 W |
| **Switching subtotal** | | **≈ 2.21 W** |

**Design levers:**
- **Dead time.** Dead-time loss is about 28 % of the switching subtotal. Cutting t_dt from 100 ns to 50 ns saves about 0.3 W per motor, but only if the driver propagation-delay mismatch allows it without shoot-through.
- **PWM frequency.** At 24 kHz, the switching subtotal halves to about 1.1 W. Ripple rises to 13 A_pp, which is still negligible against 80 A.
- **Bus voltage.** Overlap loss scales with V_bus. Under an 80 A load, a 6S pack sags to about 21–22 V, which makes 25.2 V conservative.
