# DroneCAN Heartbeat and ESC Telemetry Message Definitions

**Target:** ArduPilot / AP_Periph on STM32H743, using the FDCAN peripheral in classic CAN 2.0B mode at 1 Mbit/s.

> **Note:** I don't know what "Cycle 19" refers to in your project, so I haven't applied any cycle-specific constraints. If it means a particular release or requirements baseline, let me know and I can align these definitions to it.

## 1. Heartbeat: `uavcan.protocol.NodeStatus`

| Property | Value |
|---|---|
| Fixed Data Type ID | **341** |
| DSDL signature | `0x0F0868D0C1A7C6F1` |
| Transfer kind | Message broadcast |
| Payload size | 56 bits = **7 bytes**, which fits a single frame with no transfer CRC |
| Publish period | 1 Hz nominal (min 2 ms, max 1000 ms) |
| Offline timeout | 3000 ms (`OFFLINE_TIMEOUT_MS`) |
| Priority | Low (ArduPilot default ≈ 20–24) |

### DSDL (`341.NodeStatus.uavcan`)
```
uint16 MAX_BROADCASTING_PERIOD_MS = 1000
uint16 MIN_BROADCASTING_PERIOD_MS = 2
uint16 OFFLINE_TIMEOUT_MS         = 3000

uint32 uptime_sec                 # seconds since boot

uint2 HEALTH_OK       = 0
uint2 HEALTH_WARNING  = 1
uint2 HEALTH_ERROR    = 2
uint2 HEALTH_CRITICAL = 3
uint2 health

uint3 MODE_OPERATIONAL     = 0
uint3 MODE_INITIALIZATION  = 1
uint3 MODE_MAINTENANCE     = 2
uint3 MODE_SOFTWARE_UPDATE = 3
uint3 MODE_OFFLINE         = 7
uint3 mode

uint3 sub_mode                    # reserved, set to 0
uint16 vendor_specific_status_code
```

### Bit layout (little-endian, tail-packed)
```
Byte: 0..3        4                       5..6
      uptime_sec  [health:2|mode:3|sub:3] vendor_specific_status_code
```

## 2. ESC Telemetry: `uavcan.equipment.esc.Status`

| Property | Value |
|---|---|
| Fixed Data Type ID | **1034** |
| DSDL signature | `0xA9AF28AEA2FBB254` |
| Payload size | 110 bits → **14 bytes**, a multi-frame transfer |
| Frames (classic CAN) | 14 B payload + 2 B transfer CRC = 16 B → **3 frames** (7 B payload + tail byte each) |
| Frames (CAN FD, 64 B) | 1 frame |
| Publish rate | 50 Hz default (AP_Periph `ESC_RATE`) |
| Priority | Default/medium (≈ 16) |

### DSDL (`1034.Status.uavcan`)
```
uint32 error_count           # resets on ESC power cycle
float16 voltage              # Volt
float16 current              # Ampere, negative when regenerating
float16 temperature          # Kelvin
int18 rpm                    # negative = reverse
uint7 power_rating_pct       # 0..127, instantaneous demand
uint5 esc_index              # 0..31
```

### Bit layout
```
bits   0–31   error_count
bits  32–47   voltage      (IEEE754 half)
bits  48–63   current      (half)
bits  64–79   temperature  (half, Kelvin)
bits  80–97   rpm          (int18)
bits  98–104  power_rating_pct
bits 105–109  esc_index
```

### Optional extension: `uavcan.equipment.esc.StatusExtended` (DTID 1036)
This message is supported in recent ArduPilot. It carries `input_pct`, `output_pct`, `motor_temperature_degC`, `motor_angle`, `status_flags`, and `esc_index`. Use it alongside 1034 if you need motor temperature or ESC state flags. Verify the exact field set against your `DroneCAN/DSDL` submodule revision.

---

## 3. CAN Identifier Composition (29-bit, message frame)

```
[28:24] priority (5 bits)
[23:8]  data type ID (16 bits)   -> 341 or 1034
[7]     service_not_message = 0
[6:0]   source node ID (1..127)
```

Example: NodeStatus from node 10 at priority 24:
`(24<<24) | (341<<8) | 10 = 0x1801550A`

## 4. AP_Periph Publishing Implementation

The structs and encode functions below are generated by `dronecan_dsdlc`.

```cpp
#include <dronecan_msgs.h>

// ---------- Heartbeat (1 Hz) ----------
static void send_node_status(uint32_t now_ms)
{
    uavcan_protocol_NodeStatus ns {};
    ns.uptime_sec  = now_ms / 1000U;
    ns.health      = node_health();            // UAVCAN_PROTOCOL_NODESTATUS_HEALTH_*
    ns.mode        = node_mode();              // OPERATIONAL / MAINTENANCE / SOFTWARE_UPDATE
    ns.sub_mode    = 0;
    ns.vendor_specific_status_code = vendor_status();  // e.g. free stack / error bitmap

    uint8_t buf[UAVCAN_PROTOCOL_NODESTATUS_MAX_SIZE];
    const uint32_t len = uavcan_protocol_NodeStatus_encode(&ns, buf
#if CANARD_ENABLE_TAO_OPTION
        , !canfdout()
#endif
    );

    static uint8_t tid;
    canardBroadcast(&canard,
                    UAVCAN_PROTOCOL_NODESTATUS_SIGNATURE,
                    UAVCAN_PROTOCOL_NODESTATUS_ID,
                    &tid,
                    CANARD_TRANSFER_PRIORITY_LOW,
                    buf, len);
}

// ---------- ESC telemetry (ESC_RATE Hz, per ESC) ----------

{
