# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion (Job #26)

I don't have the Job #26 specification, so the design rests on the stated, typical gimbal assumptions below. Every value you need to change is a named constant in the code.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.075 N·m/A |
| Bus | V_dc = 16.8 V (4S) |
| Rotor encoder | 14-bit absolute (MT6701 / AS5048A), read at 20 kHz |
| Current sensing | Low-side shunts, 2 phases, synchronous to the PWM centre |
| IMUs | 2× ICM-42688-P on the camera payload, SPI, gyro and accel ODR 8 kHz |
| MCU | Cortex-M4F/M7 (hardware single-precision FPU) |

**Rate hierarchy.** Each loop runs at least 4–5× slower in bandwidth than the loop inside it:

```
           1 kHz                 4 kHz                       20 kHz
θ_ref ─► [Angle P + ω_ff] ─► [Velocity PI] ─► τ_ref ─► [÷Kt] ─► i_q,ref ─► [d/q PI + decoupling] ─► SVPWM
   ▲         (camera attitude)     ▲ (fused gyro)              ▲ +i_q,cog(θm)      ▲ (shunts, encoder)
   └── Mahony quaternion ◄── Dual-IMU fusion ◄── notch/LPF chain ◄── 2× ICM
