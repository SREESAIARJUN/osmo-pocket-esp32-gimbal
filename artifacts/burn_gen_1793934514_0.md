## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance
```
R_DS(Tj) = R₂₅ · [1 + k·(Tj − 25)],   k ≈ (α − 1)/100 = 0.005 /K
R_DS(125 °C) = 1.0 mΩ × 1.5 = 1.5 mΩ
```

### 1.2 Bridge conduction with synchronous rectification
In any 60° sector of 6-step commutation, phase A is PWM'd (high side on for D, low side on for 1−D) and phase B's low side is held on.

```
P_cond,bridge = I²·R_DS·D  +  I²·R_DS·(1−D)  +  I²·R_DS·1
              = 2·I²·R_DS                         (independent of duty)
```

Dead-time diode conduction is handled separately in §2.4.

| Case | R_DS | P_cond per ESC channel | ×4 motors |
|---|---|---|---|
| Cold (25 °C) | 1.0 mΩ | 2·80²·1.0e-3 = **12.8 W** | 51.2 W |
| Hot (125 °C) | 1.5 mΩ | 2·80²·1.5e-3 = **19.2 W** | **76.8 W** |

### 1.3 Per-FET distribution
Each of the 6 FETs per channel carries the active role during 1/3 of the electrical period. Averaged over a revolution:
```
P_cond,FET,avg = P_cond,bridge / 6 = 3.2 W (hot)
```
The instantaneous worst case is the low-side FET held fully on: I²·R_DS = **9.6 W** for a 60° sector. This matters only at very low eRPM, such as stall or startup, where a sector can last milliseconds.

### 1.4 Parasitic copper and shunt
```
P_Cu    = I²·R_trace       R_trace ≈ 0.3 mΩ (2 oz, short pours) → 1.9 W/channel
P_shunt = I²·R_shunt       0.25 mΩ shunt                        → 1.6 W (or 0 if no shunt)
```

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches hard. The synchronous low side switches with zero voltage (ZVS) after dead time.

### 2.1 V·I overlap loss (hard-switched high side)
```
P_VI = ½ · V_in · I · (t_r + t_f) · f_sw
     = 0.5 × 25.2 × 80 × 30e-9 × 48e3 = 1.45 W
```

### 2.2 Reverse-recovery loss (low-side body diode)
```
P_rr = Q_rr · V_in · f_sw = 40e-9 × 25.2 × 48e3 = 0.048 W
```

### 2.3 Output capacitance loss
```
P_oss ≈ ½ · Q_oss · V_in · f_sw = 0.5 × 50e-9 × 25.2 × 48e3 = 0.030 W
```

### 2.4 Dead-time body-diode conduction (two transitions per cycle)
```
P_dt = V_F · I · 2·t_dt · f_sw = 0.8 × 80 × 400e-9 × 48e3 = 1.23 W
```

### 2.5 Gate drive (dissipated in the driver and gate resistors, not the FET channel)
```
P_g = Q_g · V_GS · f_sw · N_switching = 60e-9 × 10 × 48e3 × 2 = 0.058 W
```

### 2.6 Total switching-related loss per channel
```
P_sw = 1.45 + 0.048 + 0.030 + 1.23 + 0.058 ≈ 2.82 W
```

Design levers:
- Cutting t_dt to 100 ns halves P_dt.
- Faster gates reduce P_VI but cost EMI and ringing; check the V_DS overshoot against the 40 V rating at 25.2 V plus ringing.

## 3. Total Loss Budget (80 A Burst, All Four Motors)

| Component | Per channel | ×4 |
|---|---|---|
| Conduction (hot) | 19.2 W | 76.8 W |
| Switching + dead time | 2.82 W | 11.3 W |
| Copper | 1.9 W | 7.7 W |
| Shunt | 1.6 W | 6.4 W |
| **Total** | **25.5 W** | **≈ 102 W** |

At a power stage output of 4 × 80 A × ~22 V ≈ 7 kW, this corresponds to about **98.6 % efficiency**. The absolute heat flux, however, is very large for a nano (20×20 or 25.5×25.5 mm) board.

## 4. Thermal Model

### 4.1 Steady state: shows 80 A is burst-only
```
Tj = T_amb + P_FET·R_θJC + P_total·R_θBA
```
A 25×25 mm, 8-layer board with prop-wash airflow has R_θBA ≈ 3–6 K/W.
- At 102 W: ΔT_board = 300–600 K. **This is not sustainable.**
- Continuous rating, solved for ΔT ≤ 70 K: P_total ≤ 70/4 ≈ 17.5 W.
  - Solving 4·(2·I²·1.5e-3 + ...) gives I_cont ≈ 30–35 A per motor.
