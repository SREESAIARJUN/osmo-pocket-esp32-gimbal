# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #35 specification, so this design uses the stated assumptions below. Every motor and plant constant is a parameter in `config.hpp`. Swap in your measured values before tuning.

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 12N14P (N_s = 12 slots, p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH |
| Position sensor | 14-bit magnetic encoder per axis (e.g., AS5048/MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, shared CLKIN |
| MCU | Cortex-M4F/M7 or similar with FPU |

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs (ISR on PWM update) |
| IMU sampling and filtering | 8 kHz | 125 µs (IMU DRDY ISR) |
| Rate (velocity) loop | 4 kHz | 250 µs |
| Attitude (angle) loop and AHRS | 1 kHz | 1 ms |
| Cogging LMS adaptation | runs in current ISR, gated by speed | — |

Bandwidth targets are separated by a factor of about 4 to 5 per stage:
- Current loop: ω_c ≈ 2π·1500 rad/s.
- Rate loop: ω_v ≈ 2π·80 rad/s.
- Angle loop: ω_θ ≈ 2π·15 rad/s.

## 1. FOC Current Loop (Innermost)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose.

### 1.2 Plant (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Controller: PI with Decoupling and Back-EMF Feedforward

$$v_d^* = \underbrace{K_p e_d + K_i\!\int e_d}_{\text{PI}_d} - \hat\omega_e \hat L i_q$$

$$v_q^* = \text{PI}_q + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

Once decoupled, the plant is 1/(Ls+R). Choosing pole–zero cancellation gives a closed loop of ω_c/(s+ω_c):

$$K_p = \hat L\,\omega_c,\qquad K_i = \hat R\,\omega_c$$

### 1.4 Discrete Form and Anti-Windup

The integrator uses forward Euler with back-calculation anti-windup (gain K_aw ≈ 1/K_p·K_i, or simply K_aw = K_i/K_p):

$$u_k = K_p e_k + I_k,\quad \bar u_k = \text{sat}(u_k),\quad I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big]$$

### 1.5 Voltage Limiting and Modulation

Limit the voltage vector to a circle, prioritising d-axis voltage:

$$|v_{dq}| \le \frac{V_{dc}}{\sqrt3}\cdot m_{max}\ (m_{max}\approx0.95)$$

$$v_q^{lim} = \sqrt{V_{max}^2 - v_d^2}$$

SVPWM is implemented by min–max (zero-sequence) injection:

$$v_{off} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad d_x = \tfrac12 + \frac{v_x + v_{off}}{V_{dc}}$$

**Delay compensation:** PWM is applied one period late. Advance the inverse-Park angle accordingly:

$$\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Attitude → Rate → Current Control

### 2.1 Why Inertial Rate, Not Encoder Rate

For stabilisation, the controlled variable is the camera's inertial angular rate, measured by the IMU (ω_cam). The encoder is used for:
- commutation (θ_e),
- the kinematic Jacobian,
- cogging phase,
- mechanical limits.
