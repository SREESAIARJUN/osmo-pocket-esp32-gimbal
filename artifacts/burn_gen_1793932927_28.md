# STM32H743 Nano AIO with 4-in-1 ESC (Job #47): Power, Thermal and DShot Architecture

## 0. Scope, Assumptions and Feasibility

You gave no MOSFET part number, battery voltage, board size or stack-up. I fixed those below as explicit parameters, so the model can be re-run with real datasheet values. **Every numeric result depends on these assumptions and must be verified against the selected parts and bench testing.**

**Architectural clarification.** The STM32H743 does not commutate the motors. A production AIO uses the H743 as the flight controller (ArduPilot) and four dedicated ESC MCUs for commutation and 48 kHz PWM. These are typically AT32F421 or STM32G071 running AM32/BLHeli_32. The H743 talks to them only via bidirectional DShot600. The model is partitioned that way.

> ⚠️ **Feasibility flag.** 80 A × 4 on 6S is about 8 kW peak through a 25.5 mm board. That is physically achievable only as a **short burst (≈1–3 s)** with 4 motors simultaneously, as shown in §3. "80 A" must be specified as a burst rating with a defined duration and duty cycle, and the firmware must enforce it via current limiting and thermal derating. Do not market it as continuous.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous commutation
At any instant two phases conduct: one high-side (HS) and one low-side (LS).
- During PWM **on**, the path is HS(A) → winding → LS(B).
- During PWM **off** (synchronous rectification), the freewheel path is LS(A) → winding → LS(B).

Therefore **exactly two MOSFETs carry I_ph at all times**, excluding dead time.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 110 °C: R_ds = 1.6 × (1 + 0.0045 × 85) = **2.21 mΩ**.

### 1.3 Loss per ESC channel

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{ds}(T_j)$$

For a flat-top 6-step current, I_rms ≈ I_pk = 80 A. Ripple adds about (1 + r²/12) and is negligible for r < 30 %.

$$P_{cond,ch} = 2 \times 6400 \times 2.21\,\text{m}\Omega = \mathbf{28.3\ W}$$

### 1.4 Distribution per MOSFET
Each phase leg's HS conducts for 120° electrical. The LS conducts for its own 120° plus the HS's off-time fraction (1 − D) of that interval.

$$P_{HS} = \tfrac{1}{3} D\, I^2 R_{ds},\qquad P_{LS} = \tfrac{1}{3}(1 + (1-D))\, I^2 R_{ds}$$
