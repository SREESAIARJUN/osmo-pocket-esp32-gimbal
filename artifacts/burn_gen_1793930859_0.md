## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|

| Position sensor | 14-bit absolute magnetic encoder (AS5047P / MT6701 class), one per axis |
| Inverter | 3-phase, center-aligned PWM, low-side shunt current sensing |

|---|---|---|
| Current (FOC) | 20 kHz | PWM-center ADC interrupt |

| Angle (encoder) | 1 kHz | Every 20th current ISR |

## 1. FOC Current Loop

### 1.1 Transforms

Use the amplitude-invariant Clarke transform with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI Design

The PMSM model in the dq frame is:

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

After feedforward decoupling, each axis reduces to G(s) = 1/(Ls + R). Choose the PI zero to cancel the electrical pole (pole–zero cancellation):

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

This makes the closed loop first-order:

$$\frac{i}{i^*} = \frac{\omega_{ci}}{s+\omega_{ci}}$$

Choose ω_ci ≤ 2π·f_pwm/20, which is about 2π·1 kHz at 20 kHz PWM.

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e L_d i_d + \omega_e\lambda_m$$

### 1.3 Voltage Limiting and Anti-Windup

Limit the dq voltage vector to the linear SVPWM region:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Use the d-axis first. Then allocate:

$$v_{q,\max} = \sqrt{V_{max}^2 - v_d^2}$$

For anti-windup, use back-calculation:

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u)$$

with K_aw ≈ K_i/K_p.

### 1.4 SVPWM by Min–Max Zero-Sequence Injection

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The torque constant is:

$$K_t = \tfrac32\,p\,\lambda_m \;[\mathrm{N\,m/A}]$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical Plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity Estimation (Encoder PLL / Tracking Observer)

A raw encoder derivative is far too noisy at 14-bit resolution. Use a type-2 PLL:

$$e_\theta = \mathrm{wrap}(\theta_{enc} - \hat\theta)$$
$$\dot{\hat\omega} = k_2 e_\theta,\qquad \dot{\hat\theta} = \hat\omega + k_1 e_\theta$$

with k₁ = 2ζω_pll and k₂ = ω_pll². Choose ζ = 0.707 and ω_pll ≈ 2π·400 Hz.

### 2.3 Velocity PI (Inner Mechanical Loop)

The velocity plant is ≈ K_t/(Js). Use a PI with crossover ω_v (symmetric optimum):

$$K_p^{v} = \frac{J\,\omega_v}{K_t},\qquad K_i^{v} = \frac{K_p^{v}\,\omega_v}{4}$$

The output is the current reference:

$$i_q^* = K_p^v e_\omega + K_i^v\!\int e_\omega\,dt + i_q^{cog,ff} + \frac{J}{K_t}\dot\omega^*$$

The last term is optional acceleration feedforward.

Constraints:
- ω_v ≤ ω_ci/5.
- ω_v must also sit below the first plate/arm structural resonance. Typically ω_v ≈ 2π·50–150 Hz.
