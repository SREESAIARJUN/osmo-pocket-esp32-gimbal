# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #45, so the design below is built on the assumptions in §0. Every equation is parameterised, so you can substitute your real motor and IMU values. Treat this as a design to verify on the bench, not a finished certified implementation.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701), SPI |
| Current sensing | 2 or 3 low-side shunts, ADC triggered at the PWM center |
| PWM | 25 kHz center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |

**Loop rates**

| Loop | Rate | Period | Driven by |
|---|---|---|---|
| Current (FOC) | 25 kHz | 40 µs | ADC end-of-conversion ISR |
| Velocity | 5 kHz | 200 µs | every 5th FOC tick |
| IMU acquisition + filtering | 8 kHz | 125 µs | IMU data-ready (DRDY) interrupt |
| Attitude estimation and angle loop | 1 kHz | 1 ms | |

**Bandwidth separation rule:** each outer loop runs at ≤ 1/5 of the bandwidth of the loop inside it:

ω_c,i ≈ 2π·1500, ω_c,ω ≈ 2π·150, ω_c,θ ≈ 2π·25 rad/s.

## 1. Field-Oriented Current Control

### 1.1 Electrical angle with latency compensation

θ_e = p·(θ_m − θ_off) + ω_e·(1.5·T_s)

- θ_off is the encoder offset found at alignment.
- The 1.5·T_s term compensates one sample of computation delay plus half a sample of PWM zero-order-hold delay.

### 1.2 Clarke and Park transforms (amplitude-invariant)

**Clarke:**

i_α = i_a
i_β = (i_a + 2·i_b)/√3    (assumes i_a + i_b + i_c = 0)

**Park:**

i_d = i_α·cosθ_e + i_β·sinθ_e
i_q = −i_α·sinθ_e + i_β·cosθ_e

### 1.3 PMSM dq model

v_d = R·i_d + L_d·(di_d/dt) − ω_e·L_q·i_q
v_q = R·i_q + L_q·(di_q/dt) + ω_e·(L_d·i_d + λ_m)

Torque: τ = (3/2)·p·[λ_m·i_q + (L_d − L_q)·i_d·i_q]

For a surface-mounted machine (L_d ≈ L_q), torque reduces to τ ≈ K_t·i_q with K_t = (3/2)·p·λ_m.

### 1.4 PI current controller with decoupling (pole–zero cancellation)

**Controller:**

C_i(s) = K_p,i + K_i,i/s
K_p,i = L·ω_c,i
K_i,i = R·ω_c,i

Because the PI zero cancels the electrical pole R/L, the closed loop becomes first order: i/i* = ω_c,i/(s + ω_c,i).

**Decoupling feedforward:**

v_d* = PI_d(i_d* − i_d) − ω_e·L_q·i_q
v_q* = PI_q(i_q* − i_q) + ω_e·(L_d·i_d + λ_m)

**Voltage limit** (circle limit, linear SVPWM region): |v_dq| ≤ V_bus/√3.

- Preserve v_d priority when clamping.
- Use back-calculation anti-windup: the integrator absorbs (v_sat − v_unsat)/K_p.
