# STM32H743 Nano FC + Integrated 4-in-1 ESC (Job #31): Power, Thermal and DShot Architecture

This is a first-principles reference design package. The figures use the stated component assumptions and must be re-derived against the actual MOSFET datasheet, stack-up and layout before release.

---

## 0. Feasibility Findings

Read these before the derivations.

| Finding | Impact |
|---|---|
| **80A × 4 channels simultaneously = 320A battery current** on a 20×20 mm board. | No 20×20 battery pad or connector carries this. Specify 80A as a **per-channel, non-simultaneous, ≤1 s burst**. Continuous rating comes out around **35–40A/ch** (§3.5). |
| The STM32H743 is the **flight controller** MCU. | Each ESC channel still needs its own commutation MCU (e.g. AT32F421 / STM32G071 running AM32 or BLHeli_32). The H743 drives those MCUs over bidirectional DShot600. It does not drive gates. |
| 48 kHz PWM is the ESC MCU's carrier, not the H743's. | Switching loss is computed per ESC bridge. |
| Nano form factor (20×20 or 25.5×25.5) | It forces 3.3×3.3 mm DFN MOSFETs (24 devices). 5×6 parts do not fit, which drives R_DS(on) up. |

## 1. Design Assumptions

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (worst-case switching) |
| Burst phase current | I_pk | 80 A (DC-equivalent per commutation sector) |
| PWM frequency | f_sw | 48 kHz, complementary (synchronous rectification) |
| MOSFET | — | 40 V, DFN3.3×3.3 |
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 1.6 mΩ |
| Temperature coefficient | α | 0.006 /K |
| Q_gs2 + Q_gd (switching charge) | Q_sw | 11 nC |
| Total gate charge | Q_g | 40 nC |
