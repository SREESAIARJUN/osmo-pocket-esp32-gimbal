## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.5 Ω, L = 2.2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| PWM | 25 kHz, center-aligned, with ADC sampling at the PWM valley |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, data-ready interrupt |

**Loop rates (each is a decimation of the PWM interrupt):**

```
PWM ISR 25 kHz ── current loop (FOC, SVPWM, cogging FF)            Ts_i = 40 µs
   └─ ÷5  5 kHz ── velocity loop (encoder + gyro blend)             Ts_v = 200 µs
        └─ ÷5 1 kHz ── angle loop (IMU attitude → joint rates)      Ts_θ = 1 ms
IMU DRDY ISR 8 kHz ── dual-IMU fusion, notch/LPF, Mahony AHRS       Ts_g = 125 µs
```

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than the loop inside it, and each loop should run at least 10× its own bandwidth:

ω_ci ≈ 2π·1500 rad/s, ω_cv ≈ 2π·150 rad/s, ω_cθ ≈ 2π·25 rad/s.

## 1. FOC Current Loop (Innermost)

### 1.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model and PI Design

The dq-frame voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling feedforward, each axis reduces to a first-order plant 1/(Ls + R).

Pole-zero cancellation gives a first-order closed loop with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

**Discrete PI** (forward Euler on the integrator, with clamping anti-windup):

$$u[k] = K_p e[k] + I[k],\qquad I[k+1] = I[k] + K_i T_s e[k]$$

**Decoupling plus back-EMF feedforward:**

$$v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e (L i_d + \lambda_m)$$

**Voltage limit.** The SVPWM linear range is |v| ≤ V_bus/√3. Apply circular saturation with d-axis priority:

$$v_d \leftarrow \text{sat}(v_d, V_{max}),\qquad v_q \leftarrow \text{sat}\!\left(v_q, \sqrt{V_{max}^2 - v_d^2}\right)$$

The integrator freezes whenever its output saturates.

### 1.3 SVPWM (Min-Max Zero-Sequence Injection)

Inverse Park, then inverse Clarke, gives v_a, v_b, v_c. Then:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and needs no branching on sector.

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant per Axis

$$J\ddot\theta_m = K_t i_q - B\dot\theta_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

where τ_dist includes cable drag, imbalance, and coupling from the other axes.

### 2.2 Velocity Loop (PI with Setpoint Weighting and Back-Calculation)

Velocity measurement is a blend of encoder and gyro (see §2.4).

The continuous-time controller is:

$$i_q^* = K_{p,v}\left(b\,\omega^* - \omega\right) + \frac{K_{i,v}}{s}(\omega^* - \omega) + i_{cog,ff}$$

**Gain design.** The loop is J s / K_t in series with the current loop. Placing crossover at ω_cv, with the PI zero a factor of 4 below it:

$$K_{p,v} = \frac{J\,\omega_{cv}}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_{cv}}{4}$$

This yields roughly 60–65° of phase margin when ω_ci ≥ 8ω_cv.
