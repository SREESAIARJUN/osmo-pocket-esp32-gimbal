# STM32H743 AIO Flight Controller + 4‑in‑1 ESC: Engineering Model (Job #23)

## 0. Scope and Corrections

Three architectural points need to be settled before the math:

1. **The H743 does not generate the 48 kHz bridge PWM.** It runs ArduPilot and emits DShot600. The 48 kHz PWM and commutation come from four dedicated ESC MCUs, one per motor (for example AT32F421 or STM32G071 running AM32). The losses below are generated by those bridges.
2. **"80 A burst" is treated as per‑motor phase current for ≤10 s.** It is not a continuous rating. Section 3 shows that no nano‑class board can hold 4×80 A continuously.
3. **The device parameters are assumptions.** They represent a typical 40 V, 3.3×3.3 PDFN MOSFET. Substitute values from your actual BOM datasheet before release.

## 1. Conduction Loss Model

### 1.1 Current Path per Commutation Step

Two phases conduct in each step:
- **Phase A:** high‑side (HS) FET on for duty D. The complementary low‑side (LS) FET of the same phase conducts during (1−D).
- **Phase B:** LS FET on 100 % of the step.

The bridge conduction loss is therefore independent of D:

$$P_{cond,bridge} = I^2R_{ds}(T_j)\,[D + (1-D) + 1] = 2I^2R_{ds}(T_j)$$

### 1.2 Temperature Coupling

$$R_{ds}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

Because R_DS(on) rises with temperature, the junction temperature must be solved iteratively:

$$T_j = T_{pcb} + R_{\theta,jp}\cdot P_{FET}(T_j)$$

For a burst starting at T_pcb ≈ 60 °C, converging at T_j ≈ 120 °C:

$$R_{ds}(120^\circ C) = 1.0\,\text{m}\Omega \times [1 + 0.0045 \times 95] = 1.43\ \text{m}\Omega$$

$$P_{cond,bridge} = 2 \times 80^2 \times 1.43\text{m} = 18.3\ \text{W per motor}$$

### 1.3 Copper and Shunt Loss

Assume each phase path has 0.25 mΩ of PCB copper (2 oz, inner and outer layers in parallel) plus a 0.25 mΩ low‑side shunt.

$$P_{Cu} \approx 2I^2(0.25\text{m}) + I^2(0.25\text{m}) \approx 4.8\ \text{W per motor}$$

This term is often ignored, and it is not negligible at 80 A.
