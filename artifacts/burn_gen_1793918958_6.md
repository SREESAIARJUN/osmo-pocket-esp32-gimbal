# STM32H743 Nano FC + 4-in-1 80A ESC: Engineering Design Package (Job #41)

## 0. Scope, Assumptions, and One Architectural Correction

**Architectural correction.** ArduPilot does not commutate BLDC motors. The H743 runs ArduPilot as the flight controller and sends bidirectional DShot600 to four ESC MCUs. Each ESC MCU runs AM32 or BLHeli_32, generates the 48 kHz PWM, and performs commutation. This document follows that split:

```
[STM32H743 FC / ArduPilot] --4x BDShot600--> [4x ESC MCU (AM32)] --> [4x 3-phase bridge, 24 MOSFETs]
```

**Assumptions.** No MOSFET part number was specified, so the model is parametric. Numerical results use the representative 40 V, 3.3×3.3 DFN device below. Substitute your datasheet values.

| Symbol | Meaning | Value used |
|---|---|---|
| V_bus | Battery, 6S full | 25.2 V |
| I_pk | Burst phase current per channel | 80 A |
| f_sw | PWM frequency | 48 kHz |
| R_ds25 | R_DS(on) at 25 °C, V_GS = 10 V | 1.2 mΩ |
| k_T | R_DS(on) temperature coefficient | 0.0045 /K |
| t_r, t_f | Switching rise/fall at 80 A | 20 ns each |
| Q_g | Total gate charge | 50 nC |

## 1. Loss Model (per ESC channel, 6-step trapezoidal with synchronous rectification)

In each commutation sector one high-side FET PWMs and one low-side FET conducts continuously. With complementary (synchronous) PWM, motor current flows through exactly two FETs at all times, apart from dead time.

### 1.1 Conduction Loss

The temperature-dependent on-resistance is:

$$R_{ds}(T_j) = R_{ds25}\,[1 + k_T (T_j - 25)]$$

Total conduction loss for the channel is:

$$P_{cond} = 2\, I^2\, R_{ds}(T_j) \;+\; I^2 R_{Cu}$$

The duty cycle D cancels out of the first term: the PWM-leg high-side and low-side FETs share the current in proportions D and (1−D).

At T_j = 100 °C, R_ds = 1.2 mΩ × 1.3375 = **1.605 mΩ**:

$$P_{cond,FET} = 2 \times 80^2 \times 1.605\times10^{-3} = \mathbf{20.5\ W}$$

**Copper term.** Model 15 mm of phase path in 4 × 2 oz layers, 5 mm wide. The sheet resistance of 2 oz copper is about 0.25 mΩ/□.

- Per layer: 3 squares × 0.25 mΩ = 0.75 mΩ.
- Four layers in parallel: R_Cu ≈ 0.19 mΩ.
- Including battery-bus copper, use about 0.3 mΩ.
- P_Cu ≈ 80² × 0.3 mΩ = **1.9 W**.

### 1.2 Switching Losses at 48 kHz

The switching node is the PWM leg only.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·40 ns·48 kHz | **1.94 W** |
| Coss | Q_oss·V·f_sw = 60 nC·25.2·48 kHz | 0.073 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 kHz | 0.060 W |
| Dead-time diode | V_f·I·2t_dt·f_sw = 0.8·80·200 ns·48 kHz | 0.61 W |
| Gate drive (driver side) | 2·Q_g·V_GS·f_sw = 2·50 nC·10·48 kHz | 0.048 W |
| **P_sw total** | | **≈ 2.73 W** |

### 1.3 Total per Channel and Board

| | One channel at 80 A | All four channels at 80 A |
|---|---|---|
| FET conduction | 20.5 W | 82 W |
| Copper | 1.9 W | 7.6 W |
| Switching | 2.7 W | 10.9 W |
| **Total** | **≈ 25.1 W** | **≈ 100 W** |
| Efficiency (P_out ≈ 25.2·80·D_avg; at D=0.8: 1613 W/ch) | ≈ 98.5 % | |

Note that conduction dominates switching by about 8:1. Raising f_sw from 24 to 48 kHz costs about 1.4 W per channel at 80 A. That trade is acceptable because it reduces current ripple and audible noise on low-inductance motors.

### 1.4 Hot-FET Loss

The thermal hot spot is the low-side FET that conducts for a full sector at low duty:

$$P_{FET,max} \approx I^2 R_{ds}(T_j) + P_{sw,share} \approx 10.3 + 1.4 \approx \mathbf{11.7\ W}$$

The commutating leg rotates every 60° electrical, so time-averaged per-FET loss is about 1/3 of this. However, at low eRPM (during a punch-out from hover) the per-sector dwell is long relative to the FET's thermal time constant (~ms). **Design to the 11.7 W instantaneous figure.**

## 2. Thermal Model

### 2.1 Network (Cauer simplification)

```
P_FET ──[R_θJC 1.5 K/W]── T_case ──[R_spread ~4 K/W per FET into 2 oz planes]── T_board ──┬── C_board
                                                                                          └──[R_conv]── T_amb
```

### 2.2 Board Heat Capacity

| Component | Calculation | Heat capacity |
|---|---|---|
| FR4 | 30.5² × 1.6 mm = 1.49 cm³ × 1.85 g/cm³ = 2.75 g × 1.1 J/gK | 3.0 J/K |
| Copper (8 layers × 70 µm × 70 % fill) | 0.365 cm³ × 8.96 = 3.27 g × 0.385 J/gK | 1.26 J/K |
| 24 FETs, caps, solder | | ~0.5 J/K |
| **C_board** | | **≈ 4.8 J/K** |

### 2.3 Convection

Prop-wash forced convection gives h ≈ 80–120 W/m²K. With A = 2 × 9.3 cm² = 1.86 × 10⁻³ m²:

- R_conv ≈ 1/(100 × 1.86e-3) ≈ **5.4 K/W**
- τ_board = R·C ≈ 26 s

Phase wires and battery leads add a parallel path of roughly 10–15 K/W.

Combining both paths, **R_conv,eff ≈ 4 K/W** and **τ_board ≈ 19 s**.

### 2.4 Burst Response

The board temperature follows:

$$T_{board}(t) = T_a + P\,R_{eff}\,(1 - e^{-t/\tau})$$

The junction runs above the board by:

$$T_j = T_{board} + P_{FET}\,(R_{\theta JC} + R_{spread}) = T_{board} + 11.7 \times 5.5 \approx T_{board} + 64\ K$$

With T_a = 35 °C and T_j,max = 150 °C (derated limit: 125 °C), the junction-to-board offset caps the board at about 61 °C for the derated limit.
