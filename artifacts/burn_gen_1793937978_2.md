# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #48)

I don't have the Job #48 spec sheet, so this design uses the assumptions listed in §0. Every assumption is a named constant in the code, so you can change it in one place.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, center-aligned TIM1/TIM8 PWM |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Loop rates | Current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, IMU fusion 1–8 kHz |
| Cogging period | LCM(12, 14) = 84 cycles per mechanical revolution (fundamental) |

The resulting control structure is:

```
θ_ref ─►[Angle P(I)]─ω_ref─►[Velocity PI + FF]─i_q,ref─►(+ i_q,cog)─►[Current PI dq + decouple]─►SVPWM─►Motor
              ▲                     ▲                                          ▲
     θ_cam (IMU fusion)   ω_cam (IMU gyro, filtered)                  i_a, i_b, θ_e (encoder)
```

## 1. FOC Inner Current Loop

### 1.1 Transforms (amplitude-invariant)

Electrical angle:

  θ_e = p·(θ_m − θ_offset), wrapped to [0, 2π)

Clarke transform:

  i_α = i_a
  i_β = (i_a + 2i_b)/√3

Park transform:

  i_d = i_α cos θ_e + i_β sin θ_e
  i_q = −i_α sin θ_e + i_β cos θ_e

Inverse Park transform:

  v_α = v_d cos θ_e − v_q sin θ_e
  v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 Plant and PI design (pole–zero cancellation)

In the dq frame the motor obeys:

  v_d = R i_d + L di_d/dt − ω_e L i_q
  v_q = R i_q + L di_q/dt + ω_e (L i_d + λ_m)

Use these feed-forward terms to cancel the cross-coupling and the back-EMF:

  v_d,ff = −ω_e L i_q
  v_q,ff = ω_e (L i_d + λ_m), where λ_m = 2Kt/(3p)

With a PI controller C(s) = K_p + K_i/s, choose:

  K_p = L·ω_c
  K_i = R·ω_c

The PI zero then cancels the plant pole, and the closed loop becomes 1/(s/ω_c + 1).

Pick ω_c ≤ 2π·f_s/20. At 20 kHz this gives about 2π·1 kHz.

### 1.3 Discrete PI with back-calculation anti-windup

At each step k, with sample time T_s:

  e_k = r_k − y_k
  u*_k = K_p e_k + I_k + u_ff
  u_k = sat(u*_k)
  I_{k+1} = I_k + K_i T_s e_k + K_aw (u_k − u*_k)

Typical choice: K_aw = 1/K_p · (K_i/K_p)·T_s, i.e. a tracking time T_t = √(T_i T_d), or simply T_t ≈ T_i.

The dq voltage limit is a circle:

  ‖(v_d, v_q)‖ ≤ V_bus/√3

Give the d-axis priority:

  v_q,max = √(V_max² − v_d²)

### 1.4 SVPWM (min/max zero-sequence injection)

  v_a = v_α
  v_b = −½v_α + (√3/2)v_β
  v_c = −½v_α − (√3/2)v_β
  v_0 = −½(max + min)
  D_x = ½ + (v_x + v_0)/V_bus

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant

  J ω̇ = K_t i_q − B ω − τ_cog(θ) − τ_dist

### 2.2 Velocity PI

Treat the current loop as an ideal unity block, because ω_c ≫ ω_v.

Design with the symmetric-optimum / zero-placement rule:

  K_p,v = J ω_v / K_t
  K_i,v = K_p,v · ω_v/4   (PI zero a factor of 4 below crossover, giving ~76° phase margin)

Use 2-DOF control with an acceleration feedforward:

  i_q,ref = PI_v(ω_ref − ω̂) + (J/K_t)·α_ref + B ω_ref/K_t + i_q,cog(θ)

The feedback ω̂ is the camera-frame gyro rate projected onto the motor axis, low-pass filtered and notched (§4). Prefer it over the differentiated encoder for the stabilizing loop: it measures what you actually want stabilized and has lower noise.

  ω̂ ← ω̂ + T_s k_2 e_θ
