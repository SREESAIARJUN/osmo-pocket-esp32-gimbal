# STM32H743 Nano FC + 4-in-1 ESC (Job #13): Architecture, Loss Model, DShot DMA Plan

## 0. Architecture Correction and Assumptions

**The STM32H743 cannot do the 48 kHz switching.** ArduPilot does not commutate BLDC motors. A workable 4-in-1 stack therefore splits into two layers:

| Layer | Device | Function |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) running ArduPilot | Generates bidirectional DShot600 and decodes eRPM telemetry |
| ESC (×4) | AT32F421K8U7 running AM32 | Six-step commutation, 48 kHz complementary PWM |
| Gate drive (×4) | FD6288Q, 3-phase half-bridge driver | Drives 6 N-FETs per motor |
| Power stage | 24 × N-MOSFET (single FET per switch position) | 6S bus, 80 A burst per motor |

**Baseline assumptions.** Replace these with your BOM datasheet values and re-run the numbers.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S full) | V_bus | 25.2 V |
| Burst phase current | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| R_DS(on) max @25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ (40 V, 5×6 DFN class) |
| R_DS(on) temperature coefficient | α | 0.0045 /K |
| Switching charge Q_gs2 + Q_gd | Q_sw | 22 nC |
| Total gate charge | Q_g | 95 nC |
| Reverse recovery charge | Q_rr | 60 nC |
| Output charge | Q_oss | 50 nC |
| Gate drive voltage / Miller plateau | V_drv / V_pl | 10 V / 3.0 V |
| Gate loop resistance, on (R_drv + R_ext + R_g,int) | R_on | 9.3 Ω |
| Gate loop resistance, off | R_off | 7.3 Ω |
| Dead time | t_dt | 200 ns |
| Body diode forward voltage | V_f | 0.8 V |
| Design T_j for conduction calculation | T_j | 110 °C |

**Board size.** I am assuming a 30.5 × 30.5 mm board, 8-layer, 2 oz internal copper. A true 20×20 "nano" cannot carry 4 × 80 A. This becomes clear in §3.
