## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701 class), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, gyro and accel ODR = 8 kHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM at 20 kHz |
| Bus | 12–16 V, 3 half-bridges per axis with low-side or inline shunts |

**Loop rates (per axis):**

```
 20 kHz  ── Current loop (FOC: Clarke/Park, PI, SVPWM)      [PWM-synchronous ADC ISR]
  4 kHz  ── Velocity loop (gyro-rate feedback + cogging FF) [decimated from current ISR]
  8 kHz  ── IMU sample, filtering, dual-IMU fusion          [IMU DRDY ISR / DMA]
  1 kHz  ── Attitude estimator + angle loop + joint mapping
```

The cascade is:

```
θ_ref ─►[Angle P/PI]─ω_ref─►(+ω_ff)─►[Velocity PI]─i_q,fb─►(+ i_cog + i_fric)─i_q*─►[FOC current PI]─►SVPWM─►Motor
            ▲                              ▲                                              ▲
     IMU attitude (fused)         gyro rate mapped to joint                       phase currents + encoder θ_e
```

The bandwidth separation rule is that each loop should be at least 4–5× slower than the loop inside it:
ω_c,i ≈ 2π·1500 rad/s, ω_c,v ≈ 2π·150–250 rad/s, ω_c,θ ≈ 2π·20–40 rad/s.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (balanced, i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant model (PMSM in the dq frame)

$$
v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)
$$

Torque (surface PM, L_d ≈ L_q):

$$
\tau = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q
$$

### 1.3 Current PI with decoupling

$$
v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q,\qquad
v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L\, i_d + \hat\lambda_m)
$$

Gains come from pole–zero cancellation. Each axis is then a first-order loop with bandwidth ω_c,i:

$$
K_{p,i} = \hat L\,\omega_{c,i},\qquad K_{i,i} = \hat R\,\omega_{c,i}
$$
