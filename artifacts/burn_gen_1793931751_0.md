I don't have the specification for "Job #7," so this design rests on the assumptions below. Each one maps to a constant in `config`, so you can substitute your actual values without changing the structure.

## 1. Field-Oriented Control (FOC) Core

### 1.1 Clarke and Park transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform, where θ_e = p·θ_m − θ_offset is the electrical angle:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Space-vector PWM (min/max zero-sequence injection)

This method is equivalent to classic SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The linear range extends to |v_αβ| ≤ V_bus/√3. The voltage vector is circularly limited to that radius, with d-axis priority.

### 1.3 Current loop: PI with pole-zero cancellation

The d/q-axis plant is:

$$G_i(s) = \frac{1}{Ls + R}$$

Choose the PI zero at R/L to cancel the electrical pole:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}\;\Rightarrow\; \frac{i_q}{i_q^*} = \frac{\omega_{ci}}{s + \omega_{ci}}$$

Use ω_ci ≈ 2π·1.5 kHz, which is at most 1/10 of the 20 kHz loop rate to leave margin for the 1.5-sample computation and PWM delay.

Decoupling feedforward (small for a gimbal, but cheap):

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

Since K_t = (3/2)·p·λ_m, the flux linkage is λ_m = 2K_t / (3p).

### 1.4 Discrete PI with back-calculation anti-windup

Forward-Euler integration with sample time T_s:

$$u_k = \text{sat}\left(K_p e_k + I_k + u_{ff}\right)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\left(u_k - u_k^{unsat}\right)$$

with K_aw ≈ K_i / K_p (that is, 1/T_i).

## 2. Cascaded Angle → Velocity → Current Control

```
θ*,ω_ff,α_ff ─► [Angle PID] ─ω*─► [Velocity PI] ─iq*─► (+) ─► [Current PI dq] ─► SVPWM
                     ▲                ▲          iq_cog_ff ▲ iq_acc_ff
                  θ_fused          ω_est (PLL)
```

### 2.1 Velocity estimation: encoder PLL

Differentiating a 14-bit encoder directly is too noisy, so a type-2 phase-locked loop (PLL) tracks angle and speed:

$$\varepsilon_k = \text{wrap}_\pi(\theta_{meas,k} - \hat\theta_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + K_{i,pll} T_s\,\varepsilon_k$$

$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll}\varepsilon_k)$$

The gains place a critically damped pole pair at ω_pll:

$$K_{p,pll} = 2\zeta\omega_{pll},\qquad K_{i,pll} = \omega_{pll}^2,\qquad \zeta = 1$$

Use ω_pll ≈ 2π·300 Hz, which must be at least 3–5 times the velocity bandwidth.

### 2.2 Velocity loop

The mechanical plant is:

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Tune the PI by symmetric optimum, with crossover at ω_v and zero at ω_v/a (a ≈ 3–4):

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = \frac{K_{p,v}\,\omega_v}{a^2}$$

The command includes the PI output plus feedforward terms:

$$i_q^* = \text{PI}_v(\omega^* - \hat\omega) + \underbrace{\frac{J\alpha^*}{K_t}}_{\text{accel FF}} + \underbrace{i_{q,cog}(\theta_m)}_{\text{anti-cogging FF}}$$

Use ω_v ≈ 2π·80–150 Hz. It is limited by the first structural mode of the gimbal arm, which a notch on i_q* must cover (see §4).
