# Job #65: STM32H743 Nano FC + 4-in-1 ESC, Systems Architecture Package

## 0. Architecture Note and Design Basis

**Partitioning.** The STM32H743 belongs on the flight controller side. It runs ArduPilot, generates DShot, and decodes bidirectional telemetry. Each ESC channel runs its own commutation firmware on a dedicated MCU. Typical choices are an AT32F421 running AM32 or a similar part running BLHeli_32. The H743 should not commutate motors directly. ArduPilot does not support that, and 48 kHz six-step commutation across four motors alongside the EKF is not a sane workload split.

**Design basis.** All numbers below derive from these assumptions. Change them and re-run the equations.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per channel | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, 5×6 mm PDFN class) | R_ds(on),25 | 0.95 mΩ (V_GS = 10 V) |
| R_ds(on) temperature coefficient | α | 0.0045 /K |
| Rise / fall time (with driver) | t_r, t_f | 20 ns / 20 ns |
| Reverse recovery charge | Q_rr | 50 nC |
| Energy-equivalent output capacitance | C_oss(er) | 2.0 nF |
| Total gate charge | Q_g | 60 nC |
| Dead time | t_dt | 300 ns |
| Body diode forward voltage | V_f | 0.8 V |
| Junction-to-case thermal resistance | R_th(j-c) | 1.0 K/W |
| Maximum junction temperature | T_j,max | 150 °C (design limit; device rated 175 °C) |

**Feasibility warning.** Four channels at 80 A on a nano (20×20 or 30×30 mm) board is a transient rating only. Total battery current would be about 320 A. The math below shows this is thermally limited to a few seconds, and that PCB copper and connectors fail before the silicon does. Treat "80 A burst" as a time-bounded spec and define the burst duration explicitly.

## 1. Conduction Loss Model

### 1.1 Current path

In six-step commutation with synchronous rectification (complementary PWM), the active phase pair always has exactly one high-side path and one low-side path carrying the phase current. During the on-time, current flows through the high-side FET of phase A and the low-side FET of phase B. During the off-time, the synchronous low-side of phase A freewheels with the low-side of phase B.

The duty-cycle terms therefore cancel:

$$P_{cond,ch} = I_{rms}^2 R_{HS}D + I_{rms}^2 R_{LS,A}(1-D) + I_{rms}^2 R_{LS,B} = 2\,I_{rms}^2\,R_{ds(on)}(T_j)$$

Ripple adds a small correction:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12}$$

### 1.2 Temperature dependence

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 110 °C:

$$R = 0.95\,\text{mΩ} \times (1 + 0.0045 \times 85) = 1.31\ \text{mΩ}$$

Ripple check, assuming a phase-to-phase inductance of 2 × 15 µH:

$$\Delta I_{pp} \approx \frac{V_{bus} D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{30\,\mu\text{H} \times 48\,\text{kHz}} = 4.4\ \text{A}$$

The ripple term ΔI²/12 = 1.6 A², which is negligible against 6400 A².

**Conduction loss per channel:**

$$P_{cond} = 2 \times 6400 \times 1.31\,\text{mΩ} = 16.8\ \text{W}$$

### 1.3 Thermal runaway stability check

The loss depends on temperature, and temperature depends on the loss. Substituting gives the steady state:

$$T_j = T_a + R_{th}\,P_{cond}(T_j) \;\Rightarrow\; T_j = \frac{T_a + R_{th} k (1 - 25\alpha)}{1 - R_{th} k \alpha}$$

where k = 2 I² R₂₅ = 12.16 W. A finite solution requires:

$$R_{th}\,k\,\alpha < 1 \;\Rightarrow\; R_{th,ch} < 18.3\ \text{K/W}$$

Steady state is not the binding constraint here. Absolute temperature is the binding constraint (see §3).

## 2. Switching Loss Model at 48 kHz

Hard switching occurs only in the PWM-active leg. With complementary PWM, that is one high-side/low-side pair per channel.

### 2.1 V-I overlap loss

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\,\text{ns} \times 48\,\text{kHz} = 1.94\ \text{W}$$

### 2.2 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\,\text{nC} \times 25.2 \times 48\,\text{k} = 0.06\ \text{W}$$

### 2.3 Output capacitance

$$P_{oss} = \tfrac12 C_{oss(er)} V_{bus}^2 f_{sw} = 0.5 \times 2\,\text{nF} \times 635 \times 48\,\text{k} = 0.03\ \text{W}$$

### 2.4 Dead-time body-diode conduction

This term is dominant at 48 kHz.

$$P_{dt} = V_f\, I\, (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 600\,\text{ns} \times 48\,\text{k} = 1.84\ \text{W}$$

### 2.5 Gate drive

This loss is dissipated in the driver and gate resistors, not in the FET.

$$P_{g} = 2\, Q_g V_{GS} f_{sw} = 2 \times 60\,\text{nC} \times 10 \times 48\,\text{k} = 0.058\ \text{W}$$

### 2.6 Loss budget per channel at 80 A, 110 °C

| Term | Power (W) |
|---|---|
| Conduction | 16.80 |
| V-I overlap | 1.94 |
| Dead-time diode | 1.84 |
| Q_rr + C_oss | 0.09 |
| **FET total** | **20.67** |
| Gate (driver) | 0.06 |
| Shunt (0.25 mΩ) | 1.60 |
| PCB copper (≈ 0.5 mΩ path) | 3.20 |
| **Channel total** | **≈ 25.5** |
| **4 channels** | **≈ 102** |

**Design takeaways:**

- **Dead time:** Cutting t_dt from 300 ns to 150 ns saves about 0.9 W per channel. Use a driver with adaptive or programmable dead time, and tune it in AM32.
- **Frequency:** Moving from 48 kHz to 24 kHz saves about 1.9 W per channel. The cost is more audible noise and current ripple on low-inductance motors.
- **Copper loss:** Copper loss on the board is comparable to switching loss. Use 2 oz or heavier outer layers plus stitched internal power planes.

## 3. Thermal Model (Transient Burst)

### 3.1 Foster network

The thermal network runs from each junction down to ambient:

```
Tj ─[Rjc 1.0 K/W]─ Tc ─[Rcs 0.3 K/W via vias]─ Tboard ─[Rba]─ Ta
                                                  │
                                              [C_board]
```

- **Per-FET dissipation:** 20.67 W ÷ 2 conducting FETs ≈ 10.3 W.
- **Junction-to-board rise:** 10.3 × 1.3 = 13.4 K. The time constant is about 10 ms, so this rise is effectively instantaneous on burst timescales.
- **Board heat capacity:** The PCB (about 8 g, FR4 plus copper), the FETs, and the solder total roughly C_th ≈ 6 J/K. Measure this on the actual build.
- **Board-to-ambient resistance (with prop wash):** R_ba ≈ 3 K/W. That gives τ_ba = 18 s.
