# STM32H743 Nano FC + 4-in-1 ESC: Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Plan

## 0. Scope and Corrections

I don't have prior context for "Job #10," so every assumption is stated explicitly. Substitute your real datasheet values into the parametric equations. Three findings change the design direction:

1. **The H743 does not generate the 48 kHz PWM.** In a 4-in-1 design, each motor bridge is driven by its own ESC MCU (e.g., AT32F421 or STM32G071 running AM32). The 48 kHz figure is a setting on those MCUs. The H743 only sends DShot600 commands and receives eRPM telemetry.
2. **80 A on all four channels at once is not a sustainable operating point on a nano (20×20 mount) board.** The model below shows roughly 110 W of dissipation. Without a heatsink this limits a four-motor burst to about 4 s. Continuous capability is about 24 A per motor.
3. **The schematic netlist is a reference topology, not a fabrication-ready netlist.** A production netlist must come from the EDA tool after part selection, footprint checks, and ERC/DRC. Section 4 gives a reference netlist that you must verify.

## 2. Loss Model

### 2.1 Conduction Losses

**Assumed drive scheme:** trapezoidal six-step with complementary (synchronous) PWM, which is the AM32 default. Over one electrical cycle, each leg spends:

- 120° as the PWM leg: the high-side FET conducts for D, and its own low-side FET conducts for 1 − D.
- 120° as the static low-side leg.
- 120° floating.

**Average conduction loss per leg:**

$$P_{leg}=\tfrac13 I^2R_{ds}\big[D+(1-D)+1\big]=\tfrac23 I^2R_{ds}$$

**Per motor (3 legs):**

$$P_{cond}=2I^2R_{ds,hot}+I^2R_{cu}$$

This is independent of duty cycle because rectification is synchronous.
