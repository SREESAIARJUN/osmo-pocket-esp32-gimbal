# STM32H743 FC + 4-in-1 ESC Nano Stack: Loss Model, Thermal Budget, and Bi-Directional DShot600 Allocation

## 0. Design Basis and Critical Review

I have no access to a "Job #65" specification, so all numeric inputs below are stated assumptions. Replace them with your datasheet values; every equation is written so you can substitute directly.

Three issues come before any math:

1. **The H743 should not commutate the motors.** Production 4-in-1 ESCs use one small MCU per channel (AT32F421 or STM32G071 running AM32 or BLHeli_32). These MCUs handle BEMF zero-cross detection and 48 kHz complementary PWM. The H743 runs ArduPilot and talks to the ESCs over bi-directional DShot600. Running sensorless commutation for four motors plus the flight stack on one H743 is not supported by ArduPilot. The architecture below assumes the split design.
2. **"80 A burst" on a nano board (20×20 or 25×25 mm) is a time-limited rating, not a thermal steady state.** Section 3 shows the board is adiabatically limited to about 2–5 s at 4×80 A. The rating must be defined as a duration at a stated ambient temperature.
3. **Supply voltage:** the analysis assumes **6S, 25.2 V maximum**. Switching losses scale linearly with V, so on 4S they drop by about one third.

## 1. Conduction Loss Model (6-step, synchronous rectification)

In any commutation sector, one bridge leg is PWM-switched (high-side with duty D, complementary low-side with 1−D). A second leg's low-side is held fully on as the return path. Phase current I flows through both legs.

**Per-ESC-channel conduction loss:**

$$P_{cond} = I^2 R_{ds}(T_j)\,[\,D + (1-D) + 1\,] = 2\,I^2 R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

Conduction loss is independent of duty when synchronous rectification is used. Add copper and trace losses separately:

$$P_{Cu} = I^2 R_{trace}, \qquad R_{trace} \approx 0.3\text{–}0.6\ \text{m}\Omega \text{ for a nano board}$$

**At 80 A with T_j = 125 °C (R_ds = 2.33 mΩ):**

$$P_{cond} = 2 \times 6400 \times 2.33\,\text{m}\Omega = 29.8\ \text{W per channel}$$

**Per-FET loss.** Each FET conducts for about one third of the electrical cycle. Electrical frequency is roughly 0.5–3 kHz, which is much faster than the die thermal time constant, so cycle-averaged power applies:

- Instantaneous, while conducting: I²R_ds = 14.9 W
- Cycle-averaged per FET: 29.8 / 6 ≈ **5.0 W**

## 2. Switching Losses at 48 kHz

Only the PWM leg switches, so two FETs per channel see these losses. V = 25.2 V and I = 80 A.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·20 ns·48 k = **0.97 W** |
| Reverse recovery | Q_rr·V·f_sw | 30 n·25.2·48 k = **0.036 W** |
| Output capacitance | Q_oss·V·f_sw | 40 n·25.2·48 k = **0.048 W** |
| Dead-time diode conduction | 2·V_f·I·t_dt·f_sw | 2·0.8·80·100 n·48 k = **0.61 W** |
| Gate drive (dissipated in driver/R_g) | 2·Q_g·V_gs·f_sw | **0.029 W** |

$$P_{sw} \approx 1.67\ \text{W per channel}$$

**Insight:** at this current, dead-time diode loss is about two thirds of the overlap loss. Cutting t_dt from 100 ns to 50 ns saves about 0.3 W per channel. That is worth more than chasing faster edges, which worsen EMI and ringing on a dense board.

### 3.2 Junction temperature (fixed-point, R_ds feedback)

$$T_j = T_{board} + P_{FET}(T_j)\,(R_{\theta jc} + R_{\theta cb})$$

$$P_{FET}(T_j) = \tfrac{1}{3} I^2 R_{25}[1+\alpha(T_j-25)] + \tfrac{1}{2}P_{sw}$$

Solving this closed form gives:

$$T_j = \frac{T_b + R_{\theta}\left(\tfrac{1}{3}I^2R_{25}(1-25\alpha) + \tfrac{1}{2}P_{sw}\right)}{1 - R_{\theta}\,\tfrac{1}{3}I^2R_{25}\,\alpha}$$

**Thermal runaway condition.** The model has no finite solution when the denominator reaches zero:

$$R_\theta \cdot \tfrac{1}{3} I^2 R_{25}\, \alpha \ge 1$$

With R_θ = 13.5 K/W and I = 80 A, the loop gain is 13.5 × 3.2 × 0.0055 = **0.24**. That is stable, but the result is 1/(1−0.24) ≈ 1.31× sensitive to R_θ.

**Worked case (T_board = 90 °C):**

- Numerator: 90 + 13.5·(3.2·0.8625 + 0.83) = 90 + 13.5·3.59 = 138.5
- **T_j ≈ 138.5 / 0.763 ≈ 182 °C**

This exceeds the 150 °C rating (175 °C for automotive-grade parts). It is the quantitative reason a nano board cannot hold 80 A, even before the board itself heats up.
