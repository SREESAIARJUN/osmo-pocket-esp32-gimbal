# STM32H743 Nano AIO (FC + 4-in-1 ESC): Design Model for Job #29

## 0. Scope, Assumptions, and Feasibility Findings

These findings constrain everything that follows, so they come first.

**Architecture assumption.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. Each ESC channel uses its own commutation MCU running AM32, which supports 48 kHz PWM and bidirectional DShot. The reference here is an AT32F421 driving an FD6288Q gate driver. The H743 drives these four ESC MCUs over bidirectional DShot600. Trying to commutate four motors and run the flight stack on the H743 would break ArduPilot's timing and DMA model.
