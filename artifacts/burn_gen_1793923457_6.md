# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion (Job #51)

## 0. Assumptions

I don't have the Job #51 spec sheet, so I assumed the parameters below. Every one is a single constant in the code (`Config` structs), so you can swap in the real values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal PMSM (e.g. GBM2804-class), 12N14P, R = 5.6 Ω, L = 1.9 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic absolute encoder per joint (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class: single-precision FPU, center-aligned PWM, ADC triggered at PWM center |
| Loop rates | Current 20 kHz · velocity 4 kHz · angle/attitude 1 kHz · IMU 8 kHz ODR |
| IMUs | 2× ICM-42688-P on the camera plate (redundant, symmetric about the rotation center), SPI at 24 MHz |
| Joint order | Yaw (base) → Roll → Pitch (camera) |
