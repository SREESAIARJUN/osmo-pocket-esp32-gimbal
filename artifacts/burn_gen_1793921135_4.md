# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual ICM-42688-P Fusion

I don't have the Job #11 spec sheet, so this design rests on the assumptions in §0. Every hardware-dependent number is a named constant you can change. Check the register values in §5 against your ICM-42688-P datasheet revision before flashing.

---

## 0. Baseline Assumptions

| Item | Value (default) |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 2.5 mH (phase), Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), read every current-loop tick |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM, ADC triggered at PWM center |
| PWM / current loop | 20 kHz / 20 kHz (`Ts_i = 50 µs`) |
| Velocity loop | 4 kHz (`Ts_v = 250 µs`) |
| Attitude/angle loop | 1 kHz (`Ts_θ = 1 ms`) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, AAF on, decimated to 4 kHz |
| Gimbal kinematics | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
