## 0. Architecture Clarification and Assumptions

The STM32H743 cannot directly commutate four BLDC motors at 48 kHz while also running ArduPilot's EKF3 and control loops. Production 4-in-1 stacks split the work as follows:

| Function | Device | Firmware |
|---|---|---|
| Flight control, DShot master, telemetry decode | STM32H743VIH6 (or VIT6), 480 MHz | ArduPilot (ChibiOS) |
| Per-motor commutation, 48 kHz PWM, eRPM reply | 4× AT32F421K8U7 or STM32G071GBU6 | AM32 / BLHeli_32-class |
| Gate drive | 4× Fortior FD6288Q (3-phase half-bridge driver, 250 V-class) | none |
| Power stage | 24× 40 V N-MOSFETs, PDFN 3.3×3.3 | none |

Design basis. Change these and re-run the equations below.

| Symbol | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal | 40 V FET gives about 37% margin for ringing |
| I_burst | 80 A per motor (phase-current referenced) | Burst only, see §3 |
| f_sw | 48 kHz, synchronous complementary PWM, 6-step trapezoidal | |
