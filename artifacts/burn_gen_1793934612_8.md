## 1. Control Architecture

```
            ┌──────────── 1 kHz ───────────┐ ┌──────── 4 kHz ────────┐ ┌──────── 20 kHz ─────────┐
θ_ref ──►(+)─► P_θ ─(+)──► ω_ref ──►(+)─► PI-D_ω ─(+)─► i_q* ──►(+)─► PI_q ─┐
          ▲−         ▲ ω_ff         ▲−            ▲ i_cog          ▲−      ├─► inv-Park ─► SVPWM ─► Inverter
          │                         │             │                │       │
          │                         │      Anti-cogging LMS(θ_m)   │   i_d*=0 ─► PI_d ─┘
          │                         │                              │
   θ̂ (Mahony AHRS) ◄── ω̂ fused ◄── Notch+LPF ◄── Dual-IMU fusion    i_d,i_q ◄── Park ◄── Clarke ◄── ADC
                                                                   θ_e = p·θ_m ◄── Encoder
```

The encoder is used for commutation (θ_e) and for anti-cogging phase (θ_m). The IMU closes the stabilization loops, because the controlled quantity is the payload's inertial attitude, not the motor shaft angle.

## 2. Field-Oriented Current Loop (20 kHz)

### 2.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this rotation.

### 2.2 PMSM model and decoupled PI

The motor in the rotating frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The control law cancels the cross-coupling terms and the back-EMF:

$$v_d = \underbrace{K_{p,i}e_d + K_{i,i}\!\int e_d}_{PI} - \omega_e L i_q,\qquad v_q = PI(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

With these terms cancelled, each axis reduces to the plant 1/(Ls+R). PI zero–pole cancellation then gives a first-order closed loop with bandwidth ω_c:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}\;\Rightarrow\; \omega_c \approx 2\pi\cdot 2\,\text{kHz}$$

The flux linkage follows from the torque constant: λ_m = (2/3)·K_t/p, using the amplitude-invariant convention where τ = (3/2)·p·λ_m·i_q.

**Voltage limit.** Linear SVPWM can produce at most |v| ≤ V_bus/√3. Apply it in two steps:

1. Prioritize the d-axis: v_d is clamped first.
2. Then limit the q-axis: v_q ≤ √(V_max² − v_d²).

Anti-windup uses back-calculation with gain K_b = 1/K_p.
