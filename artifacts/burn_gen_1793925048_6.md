# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #41 specification, so the numbers below are labelled assumptions. They are typical for a brushless gimbal: a 12N14P motor, a 14-bit absolute magnetic encoder, an STM32G4-class MCU, and two ICM-42688-P IMUs on the camera plate. Every equation is parameterized, so you only need to replace the values in `Config`.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC, pole pairs p = 7, R = 5.6 Ω, L = 2.1 mH, Kt = 0.065 N·m/A |
| Bus voltage | 12–16.8 V (4S) |
| Load inertia J (per axis) | 1.5e-4 kg·m² (identify it; see §3.4) |
| Encoder | MT6701 / AS5047P, 14-bit, SPI |
| IMUs | 2× ICM-42688-P, gyro ±2000 dps, accel ±16 g, ODR 8 kHz, both on a shared CLKIN |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (PWM-synchronous ISR) | ω_c = 2π·1500 rad/s |
| IMU sample, filtering, velocity loop | 4 kHz (IMU FIFO decimated 8→4 kHz) | ω_v = 2π·120 rad/s |
| Angle/attitude loop | 1 kHz | ω_θ = 2π·25 rad/s |

Spacing rule: each outer loop's bandwidth is at most 1/5 to 1/10 of the inner loop's. This keeps the loops dynamically decoupled, so each can be designed against a unity-gain inner loop.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle: θₑ = p·(θ_m − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.
