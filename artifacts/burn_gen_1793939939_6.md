# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

> **Context note:** I don't have the specification for "Job #10," so this design states its assumptions explicitly (§0). Each one is parameterized in `GimbalConfig`, so you can substitute your real hardware values without restructuring.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.2 mH, K_t ≈ 0.045 N·m/A |
| Driver | 3-phase inverter, 24 kHz center-aligned PWM, 2-shunt or 3-shunt current sensing |
| Encoders | 14-bit magnetic encoder (AS5048A / MT6701 class) per joint |
| IMU A | ICM-42688-P on the **camera payload**, providing attitude feedback |
| IMU B | ICM-42688-P on the **base/handle**, providing the disturbance reference |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| MCU | Cortex-M4F/M7 with single-precision FPU |

**Loop rates and bandwidth separation** (each loop is about 5–10× slower than the loop inside it):

```
 IMU A/B (8 kHz ODR, FIFO) ──► notch/LPF ──► Mahony attitude (1 kHz) ──┐
                                                                      ▼
 Attitude loop  1 kHz   BW ≈ 15–25 Hz   q_err ──► ω_cam,des
 Kinematics     1 kHz   q̇_des = J(q)⁻¹ (ω_cam,des − ω_base)          (IMU B feed-forward)
 Velocity loop  4 kHz   BW ≈ 100–150 Hz  PI ──► i_q,cmd  (+ cogging FF)
 Current loop  24 kHz   BW ≈ 1.5 kHz     PI (d,q) ──► SVPWM
```
