# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #49 specification, so this design states its assumptions explicitly. Each assumption is a parameter in the code, so you can substitute your real values without changing the structure.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| MCU | STM32G4 / H7, single-precision FPU |
| Driver | 3-phase with inline or low-side shunts (current-mode FOC) |
| IMU | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |

Each loop runs 4–10× faster than the loop outside it, so the inner loop looks like unity gain to the outer one:

| Loop | Rate | Closed-loop bandwidth | Feedback |
|---|---|---|---|
| Current (i_d, i_q) | 20 kHz | ~1.5–2 kHz | Phase shunts + encoder angle |
| Velocity (inertial rate) | 4 kHz | ~150–250 Hz | Fused gyro rate projected on motor axis |
| Angle (attitude) | 1 kHz | ~20–40 Hz | Fused attitude quaternion |
| IMU pipeline | 8 kHz in, 4 kHz out | — | — |

For gimbal stabilization, the velocity loop is closed on the inertial camera rate from the gyros, not on the encoder. The encoder handles commutation, the anti-cogging phase reference, and a feed-forward/fallback rate.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Here θ_off is found at calibration by aligning the rotor to the d-axis.

To compensate for the delay between sampling and PWM application (about 1.5 T_s for a PWM-synchronous update), use a predicted angle:

$$\hat\theta_e = \theta_e + p\,\hat\omega_m \cdot 1.5\,T_{s,i}$$

### 1.2 Transforms

Clarke (amplitude-invariant, balanced currents):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.3 Plant and PI design

The dq model of a surface-mount PMSM:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

After decoupling feed-forward, each axis reduces to G(s) = 1/(Ls + R). Use a PI controller C(s) = K_p + K_i/s. Choosing K_i/K_p = R/L places the controller zero on the plant pole, which gives:

$$L_{ol}(s)=\frac{\omega_c}{s},\qquad K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Pick ω_c ≈ 2π·1500 rad/s for 20 kHz sampling. Keep ω_c T_s ≤ 0.5 to retain phase margin given the 1.5-sample delay.
