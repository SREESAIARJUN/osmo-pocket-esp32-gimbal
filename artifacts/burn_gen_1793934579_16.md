## 0. Architecture Assumptions and Feasibility Flags

The H743 does not commutate the motors. The only workable architecture is the one used by every production AIO:

```
                ┌───────────────── FC domain (3V3) ─────────────────┐
 IMU/Baro/OSD ──┤ STM32H743VIT6 (ArduPilot, 480 MHz)                │
                │  TIM1 CH1..CH4 ── bidir DShot600 ──┐              │
                └────────────────────────────────────┼──────────────┘
                ┌──────────── ESC domain (×4, Vbat) ─┼──────────────┐
                │ AT32F421K8U7 (AM32) ◄──────────────┘              │
                │  ├─ 3× complementary PWM @48 kHz ─► FD6288Q driver│
                │  ├─ BEMF comparator (virtual neutral)             │
                │  └─ shunt amp → ADC (current)                     │
                │ 6× N-MOSFET 3-phase bridge ─► motor               │
                └───────────────────────────────────────────────────┘
```

**BLHeli_32 is end-of-life.** AM32 is the assumed ESC firmware. It is open-source, supports 48 kHz PWM, and supports bidir DShot/EDT.

**Feasibility flag.** "80 A burst" on a nano-class (20×20 / 25.5 mm) board is not physically sustainable beyond fractions of a second (§3.5). The model below is parameterized so you can set the burst duration and get a pass/fail. Two interpretations are possible:

- **80 A total (4×20 A):** feasible.
- **80 A per motor:** feasible only on 30.5×30.5 mm boards with 5×6 mm FETs, and only for ~1 s.

## 1. Conduction Loss Model

### 1.1 Current path

AM32 uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At every instant, two phases conduct:

- **Phase A (PWM leg):** the high-side FET conducts for D·T. The low-side FET conducts for (1−D)·T as a synchronous rectifier.
- **Phase B (return leg):** the low-side FET is on for the whole commutation sector.

Excluding dead time, the motor current I_ph therefore always passes through **exactly 2 channels**, independent of duty:

$$P_{cond,motor} = 2\, I_{ph}^2 \, R_{ds}(T_j), \qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha (T_j-25)]$$

The tempco α ≈ 0.005 /K is typical, which gives k_T ≈ 1.5 at 125 °C.

Each FET conducts for an average of one third of the electrical period. Over the 6 FETs:

$$P_{cond,FET,avg} = \frac{P_{cond,motor}}{6}$$

The instantaneous per-FET loss during its active sector is P_cond,motor / 2. This matters for the transient thermal analysis because the commutation sector at low eRPM can exceed the FET thermal time constant.
