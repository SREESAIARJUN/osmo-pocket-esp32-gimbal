## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C using the max value: 1.5 mΩ × 1.5 = **2.25 mΩ**. Using the typical value: 1.2 × 1.5 = **1.8 mΩ**. The worked example uses **1.9 mΩ**, a typical-plus-spread design point.
