# STM32H743 Nano FC + 4-in-1 ESC (Job #16): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Plan

## 0. Read This First: Constraints That Shape the Design

1. **The H743 does not commutate the motors.** In every viable 4-in-1 stack, each ESC channel has its own small MCU running AM32 or BLHeli_32 (for example an AT32F421 or STM32G071). The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. The "48 kHz switching" happens in the ESC MCUs. The DMA analysis (§4) therefore covers the H743-to-ESC signalling link, not the gate PWM.
2. **"80 A burst" on a nano footprint is transient-limited, not steady-state.** The math below shows that a 20×20 mm stack can absorb an 80 A burst on all four channels for about **1.5–2 s**. It is about 15 s if only one motor bursts. That number, not the MOSFET datasheet rating, belongs on the spec sheet.
3. **Component parameters below are representative placeholders** for a 40 V, ~1 mΩ, 3.3×3.3 mm DFN-class MOSFET. Every symbol is defined so you can substitute the real datasheet values. The netlist is a reference topology and must pass ERC/DRC and datasheet review before fabrication.

## 2. Loss Model (Per ESC Channel)

### 2.1 Conduction Losses

**Temperature-dependent on-resistance:**

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At an assumed T_j = 100 °C: R = 1.0 × (1 + 0.0045 × 75) = **1.34 mΩ**. Iterate this value once T_j is known (§3.3).

**Current path in 6-step synchronous PWM.** During each commutation step, two legs carry current:

- **PWM leg:** current flows through the high-side switch for D·T and the low-side switch for (1−D)·T. That is one switch-equivalent of conduction for the full period, independent of duty.
- **Return leg:** the low-side switch is held on continuously.
