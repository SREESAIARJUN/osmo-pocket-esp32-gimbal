## 1. Timing Architecture

```
PWM center ISR (20 kHz) ── ADC iA,iB ─▶ Clarke/Park ─▶ PI(id,iq) ─▶ invPark ─▶ SVPWM
     │ every 5th tick (4 kHz)
     ├─▶ encoder read ─▶ velocity PI(ω) ─▶ iq_ref (+cogging FF +accel FF)
IMU DRDY ISR (8 kHz) ─▶ dual-IMU fusion ─▶ notch/LPF ─▶ gyro rate (to velocity loop D-path)
     │ decimate ×8 (1 kHz)
     └─▶ Mahony AHRS ─▶ angle P(+I) loop ─▶ ω_ref (+ rate FF)
```

**Bandwidth separation rule.** Each loop should be at least 5× slower than the loop it commands:

ω_c,i ≈ 2π·1500 rad/s, ω_c,ω ≈ 2π·150 rad/s, ω_c,θ ≈ 2π·20–30 rad/s

## 2. FOC Current Loop Equations

### 2.1 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 2.2 Park transform

Electrical angle: θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs.

$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

### 2.3 PMSM model in the dq frame

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q$$

### 2.4 PI with decoupling and back-EMF feedforward

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L_d i_d + \omega_e\lambda_m$$

Pole-zero cancellation of the R/L plant gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\;(\text{continuous}),\qquad K_{i,d} = K_i T_s$$

**Voltage limit.** Use a circular limit |v_dq| ≤ V_bus/√3 that prioritizes d over q, with back-calculation anti-windup.

### 2.5 Inverse Park and SVPWM

Inverse Park is followed by SVPWM, implemented as min-max zero-sequence injection. This is equivalent to SVPWM and cheaper to compute:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max+\min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

**Voltage-mode fallback.** High-resistance gimbal motors may lack current shunts. In that case, set v_q = R·i_q* + ω_eλ_m and v_d = −ω_e L i_q*. The code supports this via `useCurrentSense=false`.

## 3. Cascaded Velocity / Angle Control

### 3.1 Angle loop (outer, 1 kHz)

Wrap the angle error into [−π, π):

$$e_\theta = \mathrm{wrap}(\theta^* - \hat\theta)$$

$$\omega^* = K_{p\theta}e_\theta + K_{i\theta}\!\int e_\theta\,dt + \dot\theta^*_{ff}$$

The feedforward term θ̇*_ff is the derivative of the smoothed setpoint trajectory (for example, from a jerk-limited planner), so tracking is not lag-limited.
