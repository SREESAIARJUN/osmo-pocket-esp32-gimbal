## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor position | 14-bit magnetic encoder (e.g. AS5048A / MT6701) per axis |
| Current sensing | 2-phase low-side shunts, sampled at PWM centre |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, on separate SPI buses, UI-path gyro ODR 8 kHz |

### Loop rates

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz | ~1–1.5 kHz |
| IMU read + filtering + fusion | 8 kHz | n/a |
| Rate (velocity) PI, gyro feedback | 8 kHz | 80–150 Hz |
| Angle P(+D), attitude feedback | 1 kHz | 15–30 Hz |
| Attitude estimator (Mahony) | 1 kHz | ~0.1–1 Hz accel correction |
| Anti-cogging feedforward | 20 kHz (evaluation); slow (adaptation) | n/a |

### Signal flow per axis

```
θ_ref ─►(+)─► Angle P+D ─► ω_ref ─►(+)─► Rate PI ─► iq_ref ─►(+)─► Current PI ─► SVPWM ─► Motor
         ▲  + ω_ff                  ▲              + iq_cog ─┘ ▲
         │                          │                          │
    attitude (Mahony) ◄── fused gyro/accel ◄── 2× ICM-42688-P  │
                                  joint rate                ia, ib, θ_enc
```

For stabilisation, the outer loops close on inertial (IMU) measurements. Only the current loop and the cogging compensation use the encoder angle.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θₑ = p·(θ_m − θ_offset).

Clarke transform (amplitude-invariant, ia + ib + ic = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupling

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Feed-forward decoupling terms:

- v_d,ff = −ωₑ·L·i_q
- v_q,ff = ωₑ·L·i_d + ωₑ·λ_m

With these terms, each axis reduces to the first-order plant 1/(Ls + R).

### 1.3 PI tuning by pole-zero cancellation

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c = 2\pi f_c,\; f_c \le f_{s}/15$$

This gives a closed loop of ω_c/(s + ω_c).

### 1.4 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k,\qquad u^{sat}_k = \mathrm{sat}(u_k)$$
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u^{sat}_k - u_k)\right],\qquad K_{aw}\approx K_i/K_p$$

The voltage vector is limited to a circle of radius V_max = V_bus/√3. The d-axis has priority:

$$v_q \le \sqrt{V_{max}^2 - v_d^2}$$
