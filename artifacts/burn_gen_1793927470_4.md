# 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design

I don't have the Job #38 specification, so this design uses the **assumed parameters below**. Every equation is written symbolically, and the code keeps all plant values in one `Config` struct so you can substitute the real numbers.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Motor | — | Gimbal BLDC, 12N14P (pole pairs p = 7) |
| Phase resistance / inductance | R, L | 5.6 Ω, 1.8 mH (line-to-neutral) |
| Flux linkage | λ | 2.2 mWb, so Kt = 1.5·p·λ ≈ 0.0231 N·m/A |
| Axis inertia (with payload) | J | 4.0e-4 kg·m² |
| Bus voltage | V_bus | 16.8 V (4S) |

| IMUs | — | 2 × ICM-42688-P on the camera platform, symmetric about the IMU centroid |
| Loop rates | — | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz, IMU ODR 8 kHz |

## 1. Architecture

```
            ┌────────────── 1 kHz ──────────────┐ ┌──── 4 kHz ────┐ ┌───────── 20 kHz ─────────┐
 q_ref ──►(+)─► Angle P+FF ─► ω_ref ─►(+)─► Velocity PI ─►(+)─► iq_ref ─► Current PI (d,q) ─► SVPWM ─► Motor
           ▲                            ▲                  ▲  (+ decoupling, BEMF FF)   │
           │ attitude error             │ ω_meas            │ iq_ff (anti-cogging)       │ θ_e (encoder)
   Mahony AHRS ◄─ notch/LPF ◄─ dual-IMU fusion ◄─ 2×ICM-42688-P (8 kHz, HW AAF)        │
                                        └── gyro rate mapped to joint rate ◄───────────┘
```

**Design rules:**
- The **encoder** provides commutation (θ_e) and the anti-cogging phase.
- The **IMU** provides inertial stabilization feedback: attitude for the angle loop and platform rate for the velocity loop.
- Bandwidths are separated by roughly 4–5× per cascade level:
  - Current loop: ω_ci ≈ 2π·1.5 kHz
  - Velocity loop: ω_cv ≈ 2π·150 Hz (limited by gyro filtering and structural modes)
  - Angle loop: ω_cθ ≈ 2π·25 Hz
