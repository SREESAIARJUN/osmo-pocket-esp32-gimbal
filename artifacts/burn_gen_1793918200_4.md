# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original spec for Job #22, so this design states its assumptions explicitly. Every parameter is in a single `Config` struct, so you can swap in your real values.

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit magnetic encoder (MT6701/AS5048) per joint |
| MCU | STM32G4 class (Cortex-M4F, 170 MHz), center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate (SPI), 8 kHz ODR, ±2000 dps / ±16 g |
| Gimbal order | Yaw (Z) → Roll (X) → Pitch (Y) → camera |

**Loop rates:**

| Loop | Rate |
|---|---|
| PWM | 20 kHz |
| Current (FOC) | 20 kHz |
| IMU acquisition | 8 kHz per IMU, staggered to 16 kHz effective |
| Rate (velocity) | 4 kHz |
| Angle | 1 kHz |
| AHRS | 1 kHz |

## 1. FOC Core Equations

### 1.1 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

### 1.2 Park and inverse Park

With electrical angle θ_e = p·(θ_m − θ_offset):

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
