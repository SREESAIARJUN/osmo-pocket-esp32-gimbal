## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

**Electrical angle:**

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI design

The dq-frame model of a surface PMSM (L_d = L_q = L) is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

To design the PI, use pole-zero cancellation of the electrical pole R/L, with a target closed-loop bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad\Rightarrow\quad \frac{I(s)}{I^*(s)}=\frac{\omega_c}{s+\omega_c}$$

With f_PWM = 20 kHz, choose ω_c = 2π·1500 rad/s. This is below f_s/10, which gives an adequate phase margin despite the 1.5-sample PWM and computation delay.

**Decoupling and back-EMF feed-forward:**

$$v_d^* = \text{PI}_d(e_d) - \omega_e L\,i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L\,i_d + \omega_e\lambda_m$$

**Voltage limit (circular):** if $\sqrt{v_d^2+v_q^2} > V_{max} = V_{bus}/\sqrt3$, scale both components down. Priority goes to v_d so the flux axis stays controlled.

### 1.3 SVPWM via min-max injection

First compute the phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Then inject the zero-sequence offset and convert to duty cycles:

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and is branch-free.

## 2. Cascaded Angle → Velocity → Current Control

```
θ* ─►[P(+I) angle, 1 kHz]─ω*─►[PI velocity, 4 kHz]─τ*─►(÷Kt)+i_ff(cogging)+i_ff(accel)─►i_q* ─►[FOC 20 kHz]
        ▲ θ (IMU attitude → joint frame)  ▲ ω (gyro + encoder PLL blend)
```

### 2.1 Encoder velocity: PLL observer

The PLL tracks the encoder angle and produces a filtered velocity estimate:

$$e = \operatorname{wrap}(\theta_{\text{enc}} - \hat\theta)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_i T e$$
$$\hat\theta_{k+1} = \hat\theta_k + T(\hat\omega_k + K_p e)$$

The gains are:

$$K_p = 2\zeta\omega_n,\qquad K_i=\omega_n^2,\qquad \zeta = 1,\ \omega_n = 2\pi\cdot 300$$

This estimate is far less noisy than finite-differencing a 14-bit encoder.

### 2.2 Inertial velocity feedback

Stabilization must reject *base* motion, so the velocity loop runs on the **inertial** rate of the axis. The gyro rate is projected onto the joint axis $\hat{\mathbf u}_j$:

$$\omega_{fb} = \hat{\mathbf u}_j^T\,\boldsymbol\omega_{gyro,filtered}$$

The encoder PLL rate ω̂ is used for:
- commutation,
- back-EMF feed-forward,
- the cogging-table lookup,
- fallback if the IMU is faulted.

### 2.3 Velocity PI

The axis plant is $G_v(s) = \frac{K_t}{J s + B}$. Choose a velocity bandwidth ω_v ≈ ω_c/8 to ω_c/10 (about 2π·150 rad/s):

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\,\frac{\omega_v}{4}$$

The integrator zero sits at ω_v/4, which gives roughly 60° phase margin.

**Control law with back-calculation anti-windup** (tracking gain K_aw = K_iv/K_pv):

$$u = K_{pv} e + I,\quad u_{sat} = \text{sat}(u),\quad I \mathrel{+}= T\big(K_{iv}e + K_{aw}(u_{sat}-u)\big)$$
