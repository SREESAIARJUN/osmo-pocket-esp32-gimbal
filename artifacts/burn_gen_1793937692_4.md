# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original Job #2 specification, so this design uses the assumptions listed in §0. Every equation is written in terms of named parameters. If your hardware differs, change the constants in `GimbalConfig`.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, single-precision FPU, CORDIC available |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| Inverter | 3-phase, center-aligned PWM 20 kHz, 3 low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the payload rotation center, SPI @ 24 MHz |
| Kinematic order | Base → Yaw (outer) → Roll (middle) → Pitch (inner) → Camera |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | ADC injected-conversion ISR |
| IMU acquisition and filtering | 8 kHz | IMU DRDY interrupt |
| Velocity (inertial rate) | 4 kHz | Every 2nd IMU sample |
| Attitude / angle | 1 kHz | Every 4th velocity tick |

**Bandwidth separation rule:** each loop's bandwidth should be about ¼ to 1/10 of the bandwidth of the loop inside it:

ω_c,cur ≈ 2π·1500 rad/s,  ω_c,vel ≈ 2π·120 rad/s,  ω_c,ang ≈ 2π·20 rad/s
