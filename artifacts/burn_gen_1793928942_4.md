# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the original specification for Job #18, so this design rests on the assumptions in §0. Every gain derivation is written symbolically, so you can substitute your real motor and inertia parameters.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs $p = 7$), $R_s \approx 8\,\Omega$, $L_s \approx 2.5$ mH, $K_t \approx 0.08$ N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sensing | 2-phase low-side shunts, sampled at the PWM center |
| PWM | 20 kHz center-aligned, SVPWM |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR 8 kHz, SPI @ 24 MHz |
| Gimbal order | Yaw (Z) → Roll (X) → Pitch (Y) → camera |

**Loop-rate hierarchy.** Each loop is kept at least 5× slower than the loop inside it.

| Loop | Rate $f_s$ | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | 1.5 kHz |
| IMU acquisition, filtering, fusion | 4 kHz (decimated from 8 kHz) | – |
| Velocity (inertial rate) | 4 kHz | 80–150 Hz |
| Attitude / angle | 1 kHz | 15–25 Hz |

**Signal flow:**
```
                    ┌────────── Anti-cogging FF  i_cog(θm) ─────────┐
θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Vel PI + J·α_ff]─► iq* ─(+)─►[Current PI d/q]─►SVPWM─► Motor
           ▲                          ▲                                 ▲
           │ q_err (Mahony attitude)  │ ω_joint = J⁻¹ ω_gyro            │ i_abc → Clarke/Park(θe)
           └──── Dual ICM-42688 ─► AAF ─► dyn. notch ─► LPF ─► fusion ─► Mahony
```
