# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the project context for Job #47, so the design below rests on stated assumptions. Every number tied to hardware is a parameter you can change. Values marked **[VERIFY]** must be checked against your hardware or datasheet before use.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, e.g. GBM2804-class: 12N14P → **pole pairs p = 7**, R ≈ 5–10 Ω, L ≈ 1–3 mH **[VERIFY]** |
| Joint encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sensing | 2-phase inline shunts (low-side also works; see §1.4) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI + DMA, ODR 8 kHz |
| Kinematic order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → Camera |

**Rate hierarchy.** Each loop runs at least 5–10× slower in bandwidth than the loop inside it.

```
PWM / current loop (FOC)    20 kHz   ISR (ADC injected-conversion complete)
IMU sample + filter chain    8 kHz   IMU data-ready → DMA-complete ISR
Velocity loop (gyro-based)   4 kHz   every 2nd IMU sample
Attitude estimate + angle    1 kHz   every 8th IMU sample
Cogging identification       offline / background
```

**Target closed-loop bandwidths:**

| Loop | Target bandwidth |
|---|---|
| Current | ω_c ≈ 2π·1.5 kHz |
| Velocity | ω_v ≈ 2π·60–120 Hz (limited by the first structural mode) |
| Angle | ω_a ≈ 2π·8–15 Hz |

## 1. Field-Oriented Control

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

Here θ₀ is the encoder offset at the d-axis alignment. Measure it once by injecting $V_d$ with $\theta_e = 0$, letting the rotor settle, and reading the encoder.

**Latency compensation.** The encoder read and the PWM update are separated by roughly 1.5 PWM periods (T_lat). Compensate with:

$$\hat\theta_e = \theta_e + p\,\omega_m T_{lat}$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

Clarke:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}
