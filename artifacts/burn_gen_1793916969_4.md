# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #15 specification. This design therefore uses the assumptions listed in §0. Every equation is written in terms of symbols, so you can substitute your real motor and board values.

---

## 0. Assumptions

| Item | Value assumed |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC) |
| Motors | 3 × gimbal BLDC, 12N14P (e.g., GBM2804): p = 7 pole pairs, R ≈ 5.6 Ω, L ≈ 1.6 mH, K_t ≈ 0.06 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, each on its own SPI bus, ODR = 8 kHz |
| Loop rates | Current loop 20 kHz. Velocity loop 4 kHz. Attitude loop 1 kHz. |
| Gimbal kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

Treat the register names and bit fields in §6.7 as items to check against your datasheet revision.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

```
θ_e = p · (θ_m − θ_offset)            (mod 2π)
ω_e = p · ω_m
```

Calibrate θ_offset once. Apply a fixed d-axis voltage with V_q = 0, let the rotor settle, and record the encoder reading.

### 1.2 Clarke and Park transforms (amplitude-invariant)

Phase-current reconstruction from two shunts:

```
i_c = −(i_a + i_b)
```

Clarke transform:

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

Park transform:

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.3 Plant model in the dq frame

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q          (surface PMSM, L_d = L_q)
```

### 1.4 Current PI controllers with decoupling and back-EMF feedforward

Control law:

```
v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m
```

Pole-zero cancellation tuning gives a first-order closed loop with bandwidth ω_ci:

```
K_p,i = L · ω_ci
K_i,i = R · ω_ci          ⇒   i/i* = ω_ci / (s + ω_ci)
```

Choose f_ci ≈ f_pwm / 15 ≈ 1.3 kHz. This keeps the 1.5-sample delay (computation plus PWM update) costing less than 25° of phase margin:

```
φ_delay = ω_ci · 1.5 T_s = 2π·1300·75 µs ≈ 35°  →  PM ≈ 55°
```

The current-loop set point is i_d* = 0 (no field weakening on a gimbal).

### 1.5 Voltage limiting

The dq voltage vector must stay inside the linear SVPWM hexagon's inscribed circle:

```
|v_dq| ≤ V_bus / √3
```

When limiting, give priority to v_d. Then:

```
v_q,max = sqrt( (V_bus/√3)² − v_d² )
```
