## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.4 mH (phase), K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (e.g., MT6701 or AS5048A) over SPI |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz, phase or low-side current shunts |
| IMUs | 2 × ICM-42688-P on SPI at 8 kHz ODR, mounted on the camera plate, mirrored about the plate center |
| Supply | V_bus = 12–16 V |

Timing for each axis:

```
 20 kHz  ── Current loop (FOC: Clarke→Park→PI_d,PI_q→invPark→SVPWM)
            + cogging feed-forward injection into i_q*
  8 kHz  ── IMU sampling ×2, calibration, frame rotation, vibration filters
  4 kHz  ── Rate (velocity) loop: gyro rate projected on motor axis → i_q*
  1 kHz  ── Attitude loop (Mahony fusion) → angle P(+FF) → rate*
```

Each loop runs at least about 4× slower than its inner loop's closed-loop bandwidth. Target crossover frequencies are: current ≈ 1.5 kHz, rate ≈ 150 Hz, angle ≈ 15 Hz.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle, where θ_off is the encoder-to-rotor offset found at alignment:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park is the transpose. SVPWM uses min-max zero-sequence injection, which is equivalent to classical 7-segment SVM:

$$v_{a,b,c} \leftarrow v_{a,b,c} - \tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x}{V_{bus}}$$

The linear range is $|v_{dq}| \le V_{bus}/\sqrt3$.

### 1.2 Plant Model and PI Design by Pole-Zero Cancellation

In dq coordinates (surface PM, so L_d = L_q = L):

$$L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q,\qquad L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e \lambda_m$$

Feed-forward decoupling is applied as

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

With decoupling in place, each axis reduces to $G(s) = 1/(Ls + R)$. Choose a PI controller

$$C(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

so that the controller zero cancels the plant pole. The open loop then becomes $\omega_c/s$, giving a first-order closed loop with bandwidth ω_c.

With the effective one-sample PWM plus computation delay T_d ≈ 1.5 T_s, the phase margin is

$$PM = 90^\circ - \omega_c T_d \cdot \tfrac{180}{\pi}$$

For T_s = 50 µs and ω_c = 2π·1500, this gives PM ≈ 49.5°, which is acceptable.
