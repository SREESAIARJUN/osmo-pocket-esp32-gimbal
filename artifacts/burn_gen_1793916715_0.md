# Job #56: 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

**Note:** I don't have the Job #56 spec sheet, so this design rests on the assumptions in §0. Replace those values with your actual motor, encoder, MCU, and payload data. The structure, equations, and code do not change. Only the parameters do.

## 0. Assumed Platform and Loop Timing

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A class), one per joint |
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| IMUs | 2× ICM-42688-P on camera plate, separate SPI buses |
| Axis order | Yaw (outer) → Roll → Pitch (inner, camera) |

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | PWM center ADC trigger |
| IMU sample + filters | 8 kHz | IMU DRDY (both IMUs, shared CLKIN or timestamp-aligned) |
| Velocity (rate) loop | 8 kHz | after IMU fusion |
| Angle (attitude) loop | 1 kHz | decimated ÷8 |
| Cogging learning | 1 kHz | low priority |
