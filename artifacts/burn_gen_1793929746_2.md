## 1. Control Architecture

```
 q_ref ─►[Attitude P + FF]─ω*─►[Velocity PI (gyro)]─τ*─►(+)─iq*─►[Current PI dq + decoupling]─►SVPWM─►Inverter─►Motor
            ▲    (1 kHz)           ▲   (8 kHz)               ▲                 (20 kHz)                       │
            │                      │                  [Anti-cogging FF]◄── θ_m (encoder)                      │
            │                      │                   (Fourier + LMS)                                         │
            └──── q̂ ◄─[Mahony AHRS]◄─ω_f, a_f ◄─[Notch + LPF]◄─[Dual-IMU fusion]◄── IMU1, IMU2 ◄──────────────┘
```

Two design rules apply:

- **Bandwidth separation.** Each outer loop is 5–10× slower than its inner loop: ω_c,i ≈ 2π·1.5 kHz, ω_c,v ≈ 2π·60 Hz, ω_c,θ ≈ 2π·10 Hz.
- **Velocity feedback comes from the gyro, not the encoder.** In inertial stabilization the camera's inertial rate is the controlled variable. The encoder is used only for commutation (θ_e) and for indexing the cogging table.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms
Amplitude-invariant Clarke transform, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant
$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

Torque is τ = (3/2)·p·[λ_m i_q + (L_d − L_q) i_d i_q], which reduces to K_t·i_q for an SPM motor, with K_t = (3/2)·p·λ_m.

### 2.3 PI with decoupling and back-EMF feedforward
$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L_q i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L_d i_d + \hat\lambda_m)$$

Gains come from pole-zero cancellation. Setting K_i/K_p = R/L cancels the electrical pole, which gives a closed loop of 1/(s/ω_c + 1):

$$K_p = L\,\omega_{c,i},\qquad K_i = R\,\omega_{c,i}$$

In discrete form: integral += K_i·T_s·e.

Keep ω_c,i·T_s ≤ 0.5. Also account for the 1.5·T_s delay from computation plus PWM update; if you need more bandwidth, use θ_e + 1.5·ω_e·T_s in the inverse Park transform.

### 2.4 Voltage limiting and anti-windup
The voltage vector is clamped to a circle:

$$|v_{dq}| \le \frac{V_{dc}}{\sqrt3}\cdot m_{max},\qquad m_{max} = 0.95$$

d-axis priority is used: v_q,max = √(V_max² − v_d²).

Anti-windup uses back-calculation, where K_aw ≈ 1/K_p:

$$\dot I = K_i e + K_{aw}(v_{sat} - v_{unsat})$$

### 2.5 SVPWM by min-max injection
First apply the inverse Park and inverse Clarke transforms to get v_a, v_b, v_c. Then compute the common-mode offset and duty cycles:

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM. It gives 15.5% more linear range than sinusoidal PWM.
