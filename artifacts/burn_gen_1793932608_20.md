# STM32H743 FC + 4-in-1 80 A ESC: System Architecture & Engineering Model

**Rev A: Architecture baseline for Job #1**

## 0. Assumptions and Architectural Corrections

Every number below depends on component choices that haven't been specified yet. I've chosen representative values and flagged each one, so you can substitute your actual BOM and the equations still hold.

**Architecture correction.** The H743 should **not** commutate the motors directly. ArduPilot has no BLDC commutation stack. Running 4× FOC/6-step loops at 48 kHz alongside EKF3 would also wreck scheduling determinism. The industry-standard and recommended topology is:

```
[STM32H743 FC, ArduPilot] --4x bidirectional DShot600--> [4x ESC MCU (AT32F421 / STM32G071), AM32 firmware]
                                                              |--> 3-phase gate driver --> 6x N-MOSFET per motor
```

"4-in-1 nano" therefore means a stacked or combined board with one FC MCU and four ESC MCUs.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C:

$$R_{ds} = 1.2\,\text{mΩ} \times (1 + 0.006 \times 85) = 1.81\,\text{mΩ}$$

### 1.2 Current paths in 6-step with synchronous rectification

At any instant, phase current flows through exactly **two FETs in series**:

- **PWM-on interval (D):** high-side of phase A, then low-side of phase B.
- **Freewheel interval (1−D):** low-side of phase A (synchronous rectification) and low-side of phase B.

So the instantaneous conduction loss is independent of duty cycle:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

Plugging in the burst values:

$$P_{cond,motor} = 2 \times 80^2 \times 1.81\,\text{mΩ} = \mathbf{23.2\ W}$$

Distribution across the 6 FETs (each phase is active 2/3 of the electrical period):

- **Average per FET:** ≈ 23.2 / 6 ≈ **3.9 W**
- **Instantaneous per conducting FET:** 11.6 W

The electrical frequency (≥1 kHz under load) is far faster than the FET thermal time constant, so the average value governs.

### 1.3 Self-consistent junction temperature

R_ds depends on T_j, and T_j depends on loss. Solve iteratively:

$$T_j^{(n+1)} = T_{board} + R_{\theta,j\text{-}pcb}\,P_{FET}\big(R_{ds}(T_j^{(n)})\big)$$

This typically converges in 3–4 iterations. If it diverges, you have thermal runaway at that operating point.

### 1.4 PCB copper loss (frequently ignored, not negligible)

Sheet resistance of 2 oz (70 µm) copper:

$$R_\square = \frac{\rho_{Cu}}{t} = \frac{1.72 \times 10^{-8}}{70 \times 10^{-6}} = 0.246\,\text{mΩ/□}\quad(\times 1.34 \text{ at } 110\,°\text{C})$$

For a phase trace of 3 squares over 2 paralleled layers:

$$R \approx 0.5\,\text{mΩ} \;\Rightarrow\; P = 80^2 \times 0.5\,\text{mΩ} = 3.2\,\text{W per phase path}$$

- **Design rule:** stitch phase and bus planes on ≥3 layers with via arrays sized at roughly 1 A per 0.3 mm via, ≥ 80 vias per phase node.
- **Budget:** ~2 W copper loss per motor.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd high-side hard-switches. The synchronous low-side turns on after dead time, while its body diode is already conducting, so it switches at near zero voltage.

### 2.1 V–I overlap (hard switching)

Transition times from the gate charge:

$$t_r \approx t_f \approx \frac{Q_{gd}}{I_{drv}} \approx \frac{8\,\text{nC}}{0.6\,\text{A}} \approx 13\text{–}15\,\text{ns}$$

$$P_{VI} = \tfrac{1}{2}\,V_{bus}\,I_{ph}\,(t_r + t_f)\,f_{sw} = 0.5 \times 25.2 \times 80 \times 30\,\text{ns} \times 48\,\text{kHz} = \mathbf{1.45\ W}$$
