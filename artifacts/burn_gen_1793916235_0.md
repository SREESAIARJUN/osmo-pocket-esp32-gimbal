# Job #60: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #60 specification, so this design uses common values for a gimbal. Every number is a parameter in the code. Replace these with your hardware values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R_ph ≈ 5 Ω, L_ph ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read every current-loop tick |
| Current sensing | 2 or 3 low-side shunts, ADC sampled at PWM center |
| IMUs | 2× ICM-42688-P on SPI at 24 MHz. Gyro ±2000 dps, accel ±16 g, ODR 8 kHz, AAF ≈ 258 Hz |

**Loop rates:**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | f_c = 20 kHz | T_c = 50 µs |
| IMU filter / fusion | f_imu = 8 kHz | |
| Velocity loop | f_v = 4 kHz | |
| Angle loop | f_θ = 1 kHz | |

The bandwidths are separated by about 5–10× per cascade level:

| Loop | Bandwidth |
|---|---|
| Current | ω_c ≈ 2π·1500 rad/s |
| Velocity | ω_v ≈ 2π·150 rad/s |
| Angle | ω_θ ≈ 2π·20 rad/s |
