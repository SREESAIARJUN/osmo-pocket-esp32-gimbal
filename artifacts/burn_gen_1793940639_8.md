# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion (Job #38)

---

## 0. Assumptions and Timing

I have no project file for Job #38, so the design uses the parameters below. Every one of them is a parameter in the code, so you only need to change the values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2.5 mH |
| Position sensing | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A) |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Inverter | 3-phase, center-aligned PWM 20 kHz, V_dc = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate (SPI, 24 MHz), ODR 8 kHz |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC) i_d, i_q | 20 kHz | Shunt ADC, encoder θ_e |
| Rate (velocity) | 4 kHz | Fused gyro (stabilize) or encoder PLL (follow/cal) |
| Attitude (angle) | 1 kHz | Fused quaternion (stabilize) or encoder (joint mode) |
| IMU acquisition + filtering | 8 kHz → decimated to 4 kHz | 2× ICM-42688-P |

Each loop runs at least 4× faster than its closed-loop bandwidth. Each inner loop is at least 5× the bandwidth of the loop outside it. Target bandwidths: current about 1.5 kHz, rate about 80 Hz, attitude about 12 Hz.
