# STM32H743 FC + 4-in-1 80A ESC (Job #27): Architecture, Loss Model, DShot DMA Map, Netlists

## 0. Assumptions and Scope

These points affect every number below, so they come first.

1. **The H743 does not drive the gates.** In every production 4-in-1 design, the FC MCU sends DShot to one ESC MCU per motor (AT32F421 or STM32G071 running AM32 or BLHeli_32), and that MCU runs commutation and the 48 kHz PWM. An H743 cannot run four sensorless 6-step loops with back-EMF zero-cross detection and also run ArduPilot. This document therefore models **FC (H743) → bidirectional DShot600 → 4× ESC MCU → 4× 3-phase gate driver → 24 MOSFETs.**
