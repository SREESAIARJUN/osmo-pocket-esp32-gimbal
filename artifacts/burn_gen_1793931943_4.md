I don't have the Job #18 specification, so this design uses the stated, typical hardware assumptions below. Every value marked **[CONFIG]** must be checked against your actual hardware. ## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2.5 mH, λ ≈ 0.012 Wb **[CONFIG]** |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| PWM | 20 kHz center-aligned, 3 low-side shunts (or inline) |
| IMU-P | ICM-42688-P on the camera payload (attitude truth) |
| IMU-B | ICM-42688-P on the base/handle (motion feedforward and vibration reference) |

**Loop hierarchy** (each loop ≥ 4–5× slower in bandwidth than the one inside it):

```
 8 kHz  IMU ISR    : read both IMUs → AAF (on-chip) → NLMS vib-cancel → notch → LPF
 1 kHz  Attitude   : Mahony AHRS → attitude error → joint-rate cmd (+ base FF)
 4 kHz  Velocity   : PLL speed est → velocity PI → iq_ref (+ cogging FF)
20 kHz  Current    : Clarke/Park → PI d/q + decoupling → SVPWM
```

Target bandwidths: current ≈ 1.5–2 kHz, velocity ≈ 150–250 Hz, angle ≈ 30–50 Hz.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)$$

Park, with electrical angle θₑ = p·θₘ − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park is the transpose.

### 1.2 PMSM model in the rotor frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau_e = \tfrac32\,p\,\lambda\, i_q \equiv K_t\, i_q$$

### 1.3 Current PI with pole-zero cancellation

After decoupling, the plant is 1/(Ls + R). Choose the PI zero to cancel the electrical pole. The closed loop then becomes first-order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The decoupling and back-EMF feedforward terms are:

$$v_d^{ff} = -\omega_e L\, i_q,\qquad v_q^{ff} = \omega_e L\, i_d + \omega_e \lambda$$
