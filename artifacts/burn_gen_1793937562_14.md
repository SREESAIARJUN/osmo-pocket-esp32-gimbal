# STM32H743 Nano AIO with 4-in-1 ESC: Systems Architecture Model

**Scope note.** On every production 4-in-1 design, the STM32H743 runs ArduPilot as the flight controller. Each ESC channel runs its own small MCU, such as an AT32F421 or STM32G071, with AM32 or BLHeli_32 firmware. The H743 does not commutate the motors. This document follows that partitioning. All component values are stated assumptions; substitute your actual BOM parameters into the equations.

**Topology.** Six-step trapezoidal drive with complementary (synchronous-rectified) PWM, which is the AM32/BLHeli_32 default. At any instant two phases conduct: one leg is PWM-switched and the other leg's low-side FET is held on.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_DS = 1.0 × 1.45 = **1.45 mΩ**.

### 2.2 Per-channel conduction loss

With synchronous rectification, current always flows through exactly two FETs in series. In the PWM leg, the high-side FET conducts for duty D and the low-side FET for (1−D). The return leg's low-side FET conducts continuously. Duty cancels:

$$P_{cond,ch} = I^2 R_{DS}[D + (1-D)] + I^2 R_{DS} = 2\,I^2 R_{DS}(T_j)$$

At 80 A:

$$P_{cond,ch} = 2 \times 80^2 \times 1.45\times10^{-3} = \mathbf{18.56\ W}$$

### 2.3 PCB copper loss (non-trivial at 80 A)

Phase and bus copper adds roughly 0.3 mΩ per current path. With 70 µm copper, 8 mm width, ~20 mm effective path, and parallel layers:

$$P_{Cu} = 80^2 \times 0.3\times10^{-3} \approx 1.9\ \text{W per channel}$$

This loss is carried separately because it heats the board directly rather than the junction.

### 2.4 Per-FET distribution

Each FET is active for 120° electrical (1/3 of the period). The electrical frequency is in the kHz range, far faster than the die thermal time constant (~ms), so the die sees the average:

$$\bar P_{FET} \approx \frac{P_{cond,ch}}{6}\times 2 \cdot \tfrac{1}{2} \approx 3.1\ \text{W (conduction share)}$$

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches. One hard-switched transition pair per PWM cycle.

### 3.1 Transition times (Miller-plateau model)

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}}, \quad I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{drv,src}+R_{g,on}+R_{g,int}} = \frac{10-3}{4+5+1} = 0.70\ \text{A}$$

$$t_{on} = 14\,\text{nC}/0.70\,\text{A} = 20\ \text{ns}$$

$$I_{g,off} = \frac{V_{pl}}{R_{drv,snk}+R_{g,off}+R_{g,int}} = \frac{3}{1.5+1+1} = 0.86\ \text{A} \Rightarrow t_{off} = 16.3\ \text{ns}$$

### 3.2 Loss components per channel

| Term | Equation | Value @ 25.2 V, 80 A, 48 kHz |
|---|---|---|
| V–I overlap | ½·V·I·(t_on+t_off)·f_sw | ½·25.2·80·36.3n·48k = **1.76 W** |
| Reverse recovery | Q_rr·V·f_sw | 40n·25.2·48k = **0.048 W** |
| Output capacitance | ½·C_oss(tr)·V²·f_sw | ½·1.5n·635·48k = **0.023 W** |
| Dead-time body diode | V_SD·I·2t_dt·f_sw | 0.8·80·200n·48k = **0.61 W** |
| Gate charge (2 FETs/leg) | 2·Q_g·V_drv·f_sw | 2·50n·10·48k = **0.048 W** (mostly in driver/R_g) |
| **Total** | | **≈ 2.49 W** |
