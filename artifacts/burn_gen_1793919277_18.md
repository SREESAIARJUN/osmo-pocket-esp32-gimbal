## 0. Architecture Correction

**The H743 cannot directly commutate the motors in an ArduPilot system.** ArduPilot is flight-control firmware and does not run sensorless BLDC commutation loops. The architecture therefore has to be:

```
                 ┌──────────────────────────── FC board (20x20 / 25.5x25.5) ───┐
 VBAT ─ fuse ───►│ STM32H743VIT6 @480 MHz  (ArduPilot)                          │
                 │  M1..M4 bidirectional DShot600 (inverted, 1-wire half-duplex) │
                 └──────┬──────┬──────┬──────┬──────────────────────────────────┘
                        │      │      │      │   (8-pin JST-SH or board-to-board)
                 ┌──────▼──────▼──────▼──────▼──── 4-in-1 ESC board ────────────┐
                 │ 4× ESC MCU (e.g. AT32F421 / STM32G071, AM32 or BLHeli_32)     │
                 │ 4× 3-phase gate driver  →  4× 6 N-MOSFET bridge  @ 48 kHz PWM │
                 └───────────────────────────────────────────────────────────────┘
```

- "48 kHz switching" is a parameter of the **ESC MCU firmware** (AM32 `PWM_FREQ`).
- "DShot600 DMA allocation" is an **H743/ArduPilot hwdef** problem.

The model below treats the two separately.

## 2. Conduction Loss Model

### 2.1 Current path

In 6-step commutation, two phases conduct at any instant:

- One phase leg is PWM-switched between HS and LS (complementary, duty D and 1−D).
- The other leg has one FET held on.

The current therefore always flows through exactly **two channel resistances**:

$$P_{cond,ch} = I_{rms}^2 \left[ D\,R_{HS} + (1-D)\,R_{LS} \right] + I_{rms}^2 R_{static} \approx 2\, I_{rms}^2\, R_{DS}(T_j)$$

### 2.2 Temperature dependence

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 110 °C:

$$R_{DS} = 1.2\,\text{m}\Omega \times (1 + 0.0055 \times 85) = 1.76\,\text{m}\Omega$$
