## 0. Architecture Clarification and Assumptions

### 0.1 Architecture

The STM32H743 is the **flight controller** MCU running ArduPilot. It does not commutate motors. ArduPilot has no ESC commutation firmware. The 4-in-1 ESC therefore has **four dedicated ESC MCUs**, one per channel, running AM32 or BLHeli_32. The H743 talks to them over bi-directional DShot600.

```
 VBAT ──┬──────────────────────────────────────────────┐
        │                                              │
   [5V/10V BEC]──► H743 FC (ArduPilot)                 │
                     │ M1..M4 bidir DShot600 (3.3V)    │
                     ▼                                 ▼
        ┌───────── 4-in-1 ESC board ────────────────────────┐
        │ ESC MCU ×4 (AT32F421 / STM32G071, AM32)            │
        │ 3-ph gate driver ×4 → 6 MOSFET half-bridge legs ×4 │
        │ Shunt + amp (total current), bulk caps             │
        └────────────────────────────────────────────────────┘
```

### 0.2 Form-Factor Warning

"Nano" (20×20 mm) and "80A burst per channel" are **thermally incompatible** for anything but sub-second bursts (see §3.4). I model a **30.5×30.5 mm ESC stacked under a 20×20 or 30.5 FC**. That is the smallest geometry where the numbers close. If 20×20 is a hard requirement, derate to roughly 45–55A burst.

## 1. Conduction Loss Model

### 1.1 Current Path in 6-Step Commutation

In any 60° sector, current flows through:

- **Leg A (PWM leg):** high-side for duty D, low-side (synchronous) for 1−D.
- **Leg B (return leg):** low-side ON continuously.

Instantaneous conduction resistance is always one switch in leg A plus one in leg B:

$$R_{path} = R_{ds,hot} + R_{ds,hot} = 2R_{ds,hot}$$

$$R_{ds,hot} = \alpha_T \cdot R_{ds(on),25} = 1.5 \times 0.75 = 1.125\ \text{m}\Omega$$

### 1.2 Per-Channel Conduction Loss

$$P_{cond} = I_{ph}^2 \left[ D R_{HS} + (1-D) R_{LS} + R_{LS,B} \right] = 2 I_{ph}^2 R_{ds,hot}$$

The expression is independent of D for equal FETs.

$$P_{cond} = 2 \times 80^2 \times 1.125\times10^{-3} = \mathbf{14.4\ W}$$

### 1.3 Ripple Correction

Phase current carries a triangular ripple ΔI_pp:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus} - V_{bemf}) D}{L_{ph} f_{sw}}$$

Example: a typical 5" motor has L_ph ≈ 15 µH line-to-line. With D = 0.9 and V_bemf ≈ 20 V:

$$\Delta I_{pp} = \frac{5.2 \times 0.9}{15\,\mu \times 48k} = 6.5\ \text{A}$$

This adds about 0.1% to I_rms², so it is negligible at 48 kHz. **This is a key benefit of 48 kHz over 24 kHz.**
