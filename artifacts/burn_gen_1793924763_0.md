# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

**Scope note:** I have no access to the spec for "Job #27." This design therefore assumes a typical brushless gimbal:

- PMSM gimbal motors driven by FOC with inline/low-side current sensing.
- A 14-bit absolute magnetic encoder per joint.
- Two ICM-42688-P IMUs on the camera plate.
- A Cortex-M7-class MCU (FPU, about 400 MHz).

## 1. System Architecture and Loop Rates

```
                 ┌──────────── 1 kHz ─────────────┐ ┌──── 4 kHz ────┐ ┌──── 20 kHz ────┐
 attitude cmd ─► │ Angle P (+ω_ff)  ──► ω*        │►│ Velocity PI    │►│ Current PI (d,q)│► SVPWM ► Inverter ► Motor
                 │   ▲ attitude (Mahony, dual IMU)│ │  + cog FF + τ_ff│ │  + decoupling   │
                 └───┼────────────────────────────┘ └───▲───────────┘ └──▲──────────────┘
                     │                                   │ gyro rate       │ i_a,i_b, θ_e (encoder)
          dual ICM-42688-P @ 8 kHz ─► AAF ─► fusion ─► notch bank ─► LPF ─┘
```

| Loop | Rate | Target bandwidth | Rule of thumb |
|---|---|---|---|
| Current (d,q) | 20 kHz (PWM-synchronous) | 1.5–2.5 kHz | ≤ f_s / 10 |
| Velocity | 4–8 kHz | 80–150 Hz | ≤ ω_c / 10, below the first structural mode |
| Angle | 1 kHz | 15–30 Hz | ≈ ω_v / 5 |

The inner loops must be at least 4–10× faster in bandwidth than the outer loops. This separation is what lets you tune each loop treating the inner one as ideal.

## 2. Field-Oriented Control (Current Loop)

### 2.1 Motor Model (Rotor dq Frame)

```
v_d = R·i_d + L_d·di_d/dt − ω_e·L_q·i_q
v_q = R·i_q + L_q·di_q/dt + ω_e·(L_d·i_d + λ_m)
τ_e = (3/2)·p·[λ_m·i_q + (L_d − L_q)·i_d·i_q]
J·dω_m/dt = τ_e − τ_cog(θ_m) − B·ω_m − τ_dist
```

Variable definitions:

- θ_e = p·θ_m − θ_offset, where p is the number of pole pairs.
- ω_e = p·ω_m.

Gimbal motors are surface-PM, so L_d ≈ L_q = L. We hold i_d* = 0, which reduces torque to τ = K_t·i_q, with K_t = 1.5·p·λ_m.

### 2.2 Clarke and Park Transforms

These assume a balanced load (i_a + i_b + i_c = 0) and the amplitude-invariant form.

**Clarke:**
```
i_α = i_a
i_β = (i_a + 2·i_b)/√3
```

**Park:**
```
i_d =  i_α·cosθ_e + i_β·sinθ_e
i_q = −i_α·sinθ_e + i_β·cosθ_e
```

**Inverse Park:**
```
v_α = v_d·cosθ_e − v_q·sinθ_e
v_β = v_d·sinθ_e + v_q·cosθ_e
```

### 2.3 Current PI with Decoupling and Pole-Zero Cancellation

```
v_d = PI_d(i_d* − i_d) − ω_e·L·i_q
v_q = PI_q(i_q* − i_q) + ω_e·(L·i_d + λ_m)
```

Choose the gains so the PI zero cancels the electrical pole at R/L:

```
K_p = L·ω_c,   K_i = R·ω_c
```

With these gains the closed loop becomes i/i* = ω_c/(s+ω_c), a first-order response.

**Discretization.** Use backward Euler on the integrator, with dt = T_s. Account for the one-sample PWM transport delay by advancing the angle:

```
θ_e,comp = θ_e + 1.5·ω_e·T_s
```

**Voltage limiting.**

- Clamp |v_dq| ≤ V_bus/√3. This is the linear limit for SVPWM with min-max injection.
- Prioritize v_d, then give v_q the remaining voltage: v_q,max = √(V_max² − v_d²).
- Use back-calculation anti-windup:

```
I ← I + K_i·T_s·e + K_aw·(v_sat − v_unsat)
K_aw ≈ 1/K_p
```

### 2.4 SVPWM (Min-Max Zero-Sequence Injection)

```
v_a = v_α
v_b = −½v_α + (√3/2)v_β
v_c = −½v_α − (√3/2)v_β
v_0 = −½(max(v_a,v_b,v_c) + min(v_a,v_b,v_c))
d_x = ½ + (v_x + v_0)/V_bus
```

This is mathematically identical to centered SVPWM.

## 3. Cascaded Velocity / Angle Control

### 3.1 Velocity Loop

With the current loop treated as ideal, the plant is:

```
G_v(s) = K_t / (J·s + B) ≈ K_t/(J·s)
```

PI controller:

```
i_q* = K_pv·e_ω + K_iv∫e_ω dt + i_q,ff
```

**Gains via the symmetric optimum,** for crossover ω_v and phase margin set by a = 2–3:

```
K_pv = J·ω_v / K_t
K_iv = K_pv·ω_v / a²
```

**Velocity measurement.** The stabilization loop must reject base motion, so use the joint-axis inertial rate rather than encoder speed alone:

```
ω_meas = ĵᵀ·ω_IMU,filtered              (gyro projected on joint axis)
         └ or blended: ω = ω_gyro (high-frequency) + ω_enc (low-frequency)
```

For a full 3-axis gimbal, map the camera-frame rate error to joint space with the inverse Jacobian: ω_joint* = J(q)⁻¹·ω_cam*. The yaw/roll/pitch Jacobian is singular at gimbal lock (roll = ±90°). Clamp the result near that point.

**Velocity-loop low-pass filter.** Apply a 2nd-order Butterworth at f_c ≈ 3–5 × f_v to the measured rate after the notch bank (Section 5).

### 3.2 Angle Loop (2-DOF: Feedback + Feedforward)

```
ω* = K_pθ·wrap(θ* − θ) + θ̇*_ff
i_q,ff = (J/K_t)·θ̈*_ff + (B/K_t)·θ̇*_ff
K_pθ = ω_θ ≈ ω_v / 5
```

- A pure P term is sufficient because the velocity integrator already removes steady-state error caused by constant torque disturbances.
- `wrap()` maps the angle error to the range (−π, π].
- The setpoint trajectory should come from a jerk-limited profile so that θ̇* and θ̈* exist.
