## 0. Architecture Assumptions

Several items need to be fixed up front because they change the numbers.

| Item | Assumption | Rationale |
|---|---|---|
| Topology | AIO stack: H743 flight controller plus four independent ESC MCUs on the same PCB | The H743 does **not** commutate motors. Each ESC runs its own MCU (AM32 or BLHeli_32-class) and receives bidirectional DShot600 from the H743. |
| ESC MCU | AT32F421K8U7 or STM32G071GBU6, one per motor (4×) | Standard AM32 targets |
| Gate driver | Fortior FD6288Q (3-phase, 250 mA/500 mA), one per motor | Common on 4-in-1 designs, with integrated bootstrap |
| MOSFET | 40 V N-ch, PDFN 5×6 (or 3.3×3.3 dual-sided cooled). R_DS(on) = 0.85 mΩ typ / 1.1 mΩ max at 25 °C. Q_g = 55 nC, Q_rr = 45 nC, Q_oss = 60 nC, V_SD = 0.8 V | Representative class. Substitute your actual datasheet values. |
| Bus | 6S LiPo, 25.2 V max | Worst case for switching loss |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal | AM32 default class |
| Dead time | 200 ns per edge | Typical FD6288 + firmware setting |
| Form factor | 30.5×30.5 mm (nano FC footprint 20×20 mounting), 8-layer, 2 oz on all layers | |
| "80 A burst" | Per motor, phase current ≈ motor DC current in 6-step, duration-limited | See §3 for the actual allowable duration |

> **Engineering flag.** A sustained 80 A × 4 on a ~30 mm PCB is not physically achievable without a heatsink. The model below shows 80 A is a **2–5 s burst rating** that depends on airflow. The model is built so you can defend that rating in a review.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\big[1 + \alpha\,(T_j - 25)\big]^{\,}$$

This is the linearized form. For trench FETs, α ≈ 0.0045–0.006 /K. Use the datasheet normalized curve (typically 1.5–1.6× at 125 °C).

Design value: R_DS(on),max(25 °C) = 1.1 mΩ, k(110 °C) ≈ 1.45 → **R_hot = 1.6 mΩ**.

### 1.2 Current paths in 6-step with complementary PWM

In each 60° commutation sector, one phase-leg PWMs and another leg's low-side is held ON. Over a PWM period at duty *D*:

- **Interval D:** the PWMing high-side and the static low-side conduct. Two FETs carry I.
- **Interval (1−D) − 2t_dt·f_sw:** the PWMing leg's low-side (sync rect) and the static low-side conduct. Two FETs carry I.
- **Dead time:** the body diode of the sync FET plus the static low-side conduct.

So, ignoring dead time, **two FET channels always carry the phase current**:

$$P_{cond,ESC} = 2\,I_{ph,rms}^{2}\,R_{DS(on)}(T_j)$$

### 1.3 Phase-current RMS including PWM ripple

Peak-to-peak ripple for motor inductance L_ph–ph (typ. 15–40 µH for 2207–2810 class motors; use 20 µH):

$$\Delta I_{pp} = \frac{(V_{bus} - V_{bemf})\,D}{L\,f_{sw}} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}}\quad(\text{since } V_{bemf}\approx D\,V_{bus})$$

The worst case is at D = 0.5:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\,\text{A}$$

$$I_{rms} = \sqrt{I_{dc}^2 + \frac{\Delta I_{pp}^2}{12}} = \sqrt{80^2 + 3.59} = 80.02\,\text{A}$$

The ripple contribution is negligible at 48 kHz, which is one argument for the high switching frequency.

### 1.4 Numerical result (per ESC, 80 A)

| Condition | R_DS(on) | P_cond (2 × I²R) |
|---|---|---|
| Cold, 25 °C typ | 0.85 mΩ | 10.9 W |
| 25 °C max | 1.1 mΩ | 14.1 W |
| **Hot, T_j ≈ 110 °C, max** | **1.6 mΩ** | **20.5 W** |

### 1.5 Copper and shunt conduction (per ESC)

| Element | R | P at 80 A |
|---|---|---|
| Phase pad + pours (3 phases, 2 active), ≈0.15 mΩ each | 0.30 mΩ | 1.9 W |
| Low-side shunt (if per-ESC sensing), 0.25 mΩ | 0.25 mΩ | 1.6 W |
| Bus-plane share | ~0.1 mΩ | 0.6 W |

Shunt sensing is often a single shared shunt on the 4-in-1. In that case it carries Σ I_bus, not I_phase (see §1.6).

### 1.6 Battery-side current

$$I_{bus} \approx D \cdot I_{ph} + \frac{P_{loss}}{V_{bus}}$$

At full throttle (D → 0.95), I_bus,ESC ≈ 76 A, so the four-motor total is about **300 A**. Consequences:

- The XT60 is undersized for this burst. Specify XT90 or direct solder, with 10 AWG battery leads.
- A shared 0.1 mΩ shunt dissipates 9 W at 300 A. **Use per-ESC low-side shunts or a Hall sensor** for the main current measurement.

## 2. Switching Loss Model at 48 kHz

### 2.1 Hard-switched transitions (the PWMing high-side)

$$P_{sw} = \tfrac{1}{2}\,V_{bus}\,I_{ph}\,(t_{r} + t_{f})\,f_{sw}$$

The transition times are set by gate-driver current and Miller charge:

$$t_{r} \approx \frac{Q_{gd}}{I_{g,on}},\quad I_{g,on}\approx\frac{V_{drv}-V_{plateau}}{R_{g,ext}+R_{g,int}+R_{drv}}$$

With FD6288 (V_drv = 12 V boot, R_drv,on ≈ 24 Ω effective, sourcing ~250 mA → limited), R_g,ext = 4.7 Ω, V_plateau = 4.5 V, and Q_gd = 12 nC:

- I_g,on ≈ (12 − 4.5)/(4.7 + 1.2 + 24) ≈ 0.25 A → t_r ≈ 48 ns
- I_g,off ≈ 4.5/(4.7 + 1.2 + 12) ≈ 0.25 A → t_f ≈ 48 ns (sink is stronger but the plateau voltage is lower)

$$P_{sw} = 0.5 \times 25.2 \times 80 \times 96\,\text{ns} \times 48\,\text{kHz} = \mathbf{4.64\,W}$$

This is the dominant switching term. To recover, add a turn-off speed-up diode (1N4148WS + 0 Ω/2.2 Ω split gate network). That cuts t_f to about 25 ns and **P_sw to ≈ 3.5 W**.
