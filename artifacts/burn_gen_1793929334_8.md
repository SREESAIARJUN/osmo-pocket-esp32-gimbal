# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

> **Scope note.** I don't have the Job #24 specification sheet, so the design below is parameterized. The working assumptions are listed in §0. Every gain is derived from physical parameters, so you only need to replace the numbers in `GimbalConfig` with your measured values. Do not use the default constants on hardware without identifying R, L, λ, J, and the cogging profile first.

## 0. Assumptions and Loop Timing

| Item | Assumed value | Notes |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH | Example: GBM2804-class motor |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) | Used for commutation and cogging phase |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the roll/pitch intersection | Used for inertial stabilization |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7) | Single-precision math |
| PWM / current loop | 20 kHz, center-aligned | Ts_i = 50 µs |
| Velocity loop | 4 kHz | Ts_v = 250 µs |
| Angle loop + AHRS | 1 kHz | Ts_θ = 1 ms |
| IMU ODR | 8 kHz, read via SPI DMA | Decimated to 4 kHz after filtering |

**Bandwidth separation rule.** Each inner loop should be at least 5–10× faster than the loop around it:
ω_c,i ≈ 2π·1500 rad/s ≫ ω_c,v ≈ 2π·80 ≫ ω_c,θ ≈ 2π·12.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle (with N_cpr counts per revolution and encoder offset θ_off):

$$\theta_e = p\,\theta_m - \theta_{off}, \qquad \theta_m = 2\pi\,\frac{n_{enc}}{N_{cpr}}$$

**Clarke transform** (amplitude-invariant, assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM Plant Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque (surface-mount magnets, L_d = L_q):

$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q \equiv K_t\, i_q$$
