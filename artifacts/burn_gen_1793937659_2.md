### Architecture

The STM32H743 is the **flight controller (FC)** running ArduPilot. The 4-in-1 ESC needs **one commutation MCU per channel**. A typical choice is AT32F421 or STM32G071 running AM32 (or BLHeli_32).

- The H743 does **not** drive the gates directly.
- The FC-to-ESC link is bidirectional DShot600, one wire per motor.
- "48 kHz" is treated as the **ESC PWM switching frequency**. It is unrelated to the DShot bit rate.

## 1. Conduction-Loss Model (6-Step Trapezoidal, Complementary PWM)

### 1.1 Commutation Topology

In each 60° electrical sector, two phases conduct:

- **Phase A ("PWM leg"):** the high-side FET switches with duty D. The low-side FET of the same leg switches complementarily (1−D), acting as a synchronous rectifier.
- **Phase B ("return leg"):** the low-side FET is held fully on.
- **Phase C:** floating, used for back-EMF sensing.

The current path always contains **exactly two FETs in series**. Each FET spends 1/3 of the electrical period active in one of these roles.

### 1.2 Per-FET Averages

Over one electrical period, with R = R_ds25·k_T:

```
P_HS = (1/3)·I²·R·D
P_LS = (1/3)·I²·R·[1 + (1−D)] = (1/3)·I²·R·(2−D)
P_leg = P_HS + P_LS = (2/3)·I²·R
P_cond,channel = 3·P_leg = 2·I²·R        (independent of D)
```

The temperature dependence must be iterated, because R_ds rises with T_j, which raises losses, which raises T_j:

```
R_ds(T_j) = R_ds25 · (1 + α·(T_j − 25)),   α ≈ 0.004–0.006 /K
```

Iterate T_j → R_ds → P → T_j until the change is below 1 K. A diverging iteration means thermal runaway.

### 1.3 Worked Example at 80 A, T_j = 125 °C

```
R = 1.0 mΩ × 1.5 = 1.5 mΩ
P_cond,channel = 2 × 80² × 1.5e-3 = 19.2 W
Per FET at D = 1:   P_HS = P_LS = 3.2 W
Per FET at D = 0.5: P_HS = 1.6 W, P_LS = 4.8 W   ← low-side is the hot device at part throttle
```
