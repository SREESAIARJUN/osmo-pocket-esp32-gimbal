## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sense | 2- or 3-shunt, sampled center-aligned with PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, separate CS |
| Mechanical order | Yaw → Roll → Pitch (outer → inner) |

| Loop | Rate | Trigger |
|---|---|---|
| Current loop (FOC) + cogging feedforward | 20 kHz | ADC end-of-conversion ISR, synced to PWM center |
| IMU acquisition + filtering | 8 kHz | ICM-42688 INT1 (data ready) → SPI DMA |
| Velocity loop | 4 kHz | Every 5th current-loop tick |
| Angle loop + attitude estimator | 1 kHz | Every 4th velocity tick |

The rule is that each loop's closed-loop bandwidth should be ≤ 1/5–1/10 of the next inner loop's. Typical targets:
- Current loop: ≈ 1.5–2 kHz
- Velocity loop: ≈ 100–200 Hz
- Angle loop: ≈ 15–30 Hz

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at startup by applying V_d along the α-axis and reading the encoder. Latency compensation for the encoder-to-PWM delay T_d (≈ 1.5 T_s):

$$\theta_e^{comp} = \theta_e + p\,\hat\omega_m\,T_d$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\qquad (i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and decoupled PI

PMSM voltage equations:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

With decoupling feedforward, each axis reduces to G(s) = 1/(Ls + R). Pole-zero cancellation yields a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$
