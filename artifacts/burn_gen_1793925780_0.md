```
     q̂ (Mahony,│               ω_axis (fused gyro,                          ▼
     dual IMU) │                notch-filtered)              Current PI (d,q)│ 25 kHz
               │                                                  │          │
        ┌──────┴──────┐                                       inv-Park → SVPWM → Inverter → Motor
        │ IMU0  IMU1  │◄── 8 kHz                                  ▲
        └─────────────┘                                 θ_e from encoder
```

Two design principles drive this structure:

- **Gyro feedback for the velocity loop.** The camera's inertial rate is what we want to stabilise, so the velocity loop is closed on the gyro, not the encoder.
- **Encoder only for commutation and cogging phase.** The rotor encoder provides θ_e for the Park transforms and the mechanical angle for the cogging lookup.

## 2. Field-Oriented Control (Inner Current Loop)

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 2.2 Plant (PMSM in the dq frame)

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q \;\equiv\; K_t\, i_q \qquad (\text{surface PM},\ L_d = L_q)$$

### 2.3 Current PI with Decoupling

**Control law** (e_d = i_d* − i_d, e_q = i_q* − i_q):

$$v_d^* = K_{p,i}\, e_d + K_{i,i}\!\int e_d\,dt \;-\; \omega_e L\, i_q$$
$$v_q^* = K_{p,i}\, e_q + K_{i,i}\!\int e_q\,dt \;+\; \omega_e (L\, i_d + \lambda_m)$$

**Gain selection by pole-zero cancellation.** Each axis's plant is 1/(Ls + R). Choosing the gains below makes the closed loop first-order, with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

$$\Rightarrow\ \frac{I(s)}{I^*(s)}=\frac{\omega_{ci}}{s+\omega_{ci}}$$

Pick ω_ci ≤ 2π·f_pwm/20, i.e. about 2π·1.2 kHz at 25 kHz.

**Voltage limit (circular, SVPWM linear region).**

$$|v_{dq}| \le V_{max} = \frac{V_{dc}}{\sqrt3}$$

The d-axis has priority. Then:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

**Anti-windup by back-calculation.** The integrator is driven by both the error and the saturation excess:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}), \qquad K_{aw} \approx K_i / K_p$$

### 2.4 SVPWM (min-max zero-sequence injection)

This is equivalent to SVPWM and computationally cheaper:

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
