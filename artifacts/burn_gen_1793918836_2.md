# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #24, so this design uses the assumptions below. Every value marked as an assumption is a single constant in the code and can be changed without touching the structure.

## 0. Assumptions and System Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Driver | 3-phase bridge, center-aligned PWM at 20 kHz, inline or low-side current sense on 2 phases |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701) per axis, SPI |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, gyro and accel output data rate (ODR) of 8 kHz, ±2000 dps and ±16 g |
| MCU | STM32G4/H7-class device with an FPU |
| Axis order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (multirate cascade):**

```
 20 kHz  ISR  : ADC → Clarke/Park → PI(id,iq) → inv-Park → SVPWM     (current loop, ωc ≈ 2π·1.5 kHz)
  4 kHz  task : encoder PLL, IMU read, dual-IMU fusion, notch filters,
                velocity PI + anti-cogging FF                        (velocity loop, ωv ≈ 2π·150 Hz)
  1 kHz  task : attitude estimator, angle P + feedforward           (angle loop, ωθ ≈ 2π·30 Hz)
```

Each loop runs at least 5× slower in bandwidth than the loop inside it. That separation lets each inner loop be treated as unity gain when tuning the outer one.

## 1. FOC Current Loop (Inner Loop)

### 1.1 Electrical model (surface PMSM, Ld ≈ Lq = L)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2} p \lambda_m i_q \equiv K_t\, i_q,\qquad \theta_e = p\,\theta_m - \theta_{off}
$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(i_a+i_b+i_c=0)
$$

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.3 PI with decoupling, pole-zero cancellation and anti-windup

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first order with bandwidth ωc:

$$
K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c
\quad\Rightarrow\quad \frac{i_q}{i_q^*} = \frac{\omega_c}{s+\omega_c}
$$

Constraint: ωc ≤ 2π·f_pwm/10 to stay clear of the PWM and computation delay (≈1.5 T_s).
