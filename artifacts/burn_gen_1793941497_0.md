# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #59)

I don't have the Job #59 specification, so this design states its hardware assumptions explicitly in §0. Every equation is parameterized, so you can substitute your actual values. Items marked **[VERIFY]** depend on datasheet details you should check against your silicon revision.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| Current sensing | 2-shunt or 3-shunt low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on separate SPI buses, ODR 8 kHz |
| Kinematics | Yaw → Roll → Pitch (base → camera) |

**Loop rates (each loop is ≥ 4–5× slower than the one inside it):**

| Loop | Rate | Closed-loop bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz, PWM ISR | 1.5–2 kHz |
| Velocity (gyro feedback) | 4 kHz | 80–150 Hz |
| Angle / attitude | 1 kHz | 15–30 Hz |
| IMU acquisition and filtering | 8 kHz (DRDY / FIFO) | — |

**Signal flow:**

```
IMU_A ─┐ AAF(hw) → notch bank → frame rot ─┐
       │                                   ├─► fusion (inv-variance + χ² gate) ─► Mahony AHRS ─► q_cam
IMU_B ─┘ AAF(hw) → notch bank → frame rot ─┘          │ ω_cam
                                                      ▼
θ_ref ─► [Angle P + FF] ─► ω_ref ─► [Velocity PI + LPF] ─► i_q* ─(+ cogging FF)─► [FOC PI d/q] ─► SVPWM
                                                                                  ▲ θ_e (encoder)
```

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Amplitude-invariant Clarke transform (with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, using electrical angle θ_e = p·(θ_m − θ_offset):

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
