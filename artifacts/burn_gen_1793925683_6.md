# STM32H743 FC + 80 A 4‑in‑1 ESC: Thermal, Switching, and DShot DMA Design Package

## 0. Architecture and Assumptions

### 0.1 System partitioning

The STM32H743 does **not** commutate the motors. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (or one quad-capable ESC MCU), which run AM32 or BLHeli_32 class firmware.

```
 ┌─────────────── FC (STM32H743, ArduPilot) ───────────────┐
 │ TIM1 CH1..CH4 ──► DShot600 (bidir, inverted) ──┐         │
 │ ADC ◄── CURR / VBAT                            │         │
 └────────────────────────────────────────────────┼─────────┘
                    8‑pin JST‑SH stack connector  │
 ┌────────────── 4‑in‑1 ESC ──────────────────────┼─────────┐
 │ 4× ESC MCU (e.g. AT32F421 / STM32G071, AM32) ◄─┘         │
 │ 4× 3‑phase gate driver (e.g. FD6288Q class)              │
 │ 24× N‑MOSFET (6 per motor), shunt + CSA, bulk caps       │
 └──────────────────────────────────────────────────────────┘
```

### 0.2 Design assumptions

Every number below is derived from these values. Replace them with your selected MOSFET's datasheet values; all equations are parametric.

| Symbol | Meaning | Assumed value |
|---|---|---|
| V_bus | 6S, fully charged | 25.2 V |
| I_ph | burst phase current per motor | 80 A |
| f_sw | PWM frequency | 48 kHz |
| R_DS(on),25 | MOSFET, V_GS = 10 V, max | 1.0 mΩ |
| α | R_DS(on) temperature coefficient | 0.0065 /°C |
| Q_g / Q_gd / Q_gs2 | gate charges | 50 / 10 / 5 nC |
| Q_rr | body-diode reverse recovery | 40 nC |
| Q_oss | output charge at V_bus | 30 nC |
| V_SD | body-diode forward voltage | 0.8 V |
| t_dead | dead time | 100 ns |
| I_drv | effective gate drive current (driver + R_g) | ≈0.75 A |
| R_th,JC | junction-to-case (bottom pad) | 1.5 K/W |
| Board | 30.5 × 30.5 mm, 8 layers, 2 oz | — |

Two further conditions apply:

- **Commutation:** 6‑step trapezoidal with synchronous rectification (complementary PWM), which is the default for AM32.
- **"80 A burst"** means 80 A per motor for ≤10 s. It is not a continuous rating; §3 shows why.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)]$$

At T_j = 100 °C: R = 1.0 × (1 + 0.0065 × 75) = **1.49 mΩ**. Use **1.5 mΩ**.

### 1.2 Current path in 6‑step with synchronous rectification

In any 60° sector, phase A (PWM'd) sources current and phase B sinks it:

- **PWM on (D):** HS_A → motor → LS_B
- **PWM off (1−D):** LS_A (sync rectifier) → motor → LS_B

So exactly **two MOSFETs conduct I_ph at all times**:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{DS}(T_j)$$

$$P_{cond,motor} = 2 \times 80^2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

### 1.3 Per-FET distribution

Each phase leg sources for 120° and sinks for 120° of the electrical cycle.

| FET | Conducts | Fraction of period | Avg loss @ D≈1 (burst) |
|---|---|---|---|
| High-side | sourcing, PWM-on | (1/3)·D | 9.6 W × 1/3 = 3.2 W |
| Low-side | sinking + freewheel | 1/3 + (1/3)(1−D) | ≈3.2 W (rises at partial throttle) |

Instantaneous loss in a conducting FET is I²R = **9.6 W**. At electrical frequencies above about 500 Hz the die's thermal time constant (~ms) averages this, so the 3.2 W average is valid for junction-temperature estimates.

### 1.4 Non-MOSFET conduction losses

| Element | Model | Value |
|---|---|---|
| Phase pad/trace copper (2 oz, 0.25 mΩ/□, ~1.5 □ effective incl. vias, 3 layers paralleled) | 2·I²·R_cu, R_cu ≈ 0.12 mΩ | 1.5 W/motor |
| Battery shunt (0.2 mΩ, carries ΣI ≈ 320 A burst) | I²R | **20 W** (unacceptable) |
| Battery shunt (0.1 mΩ) | I²R | 10 W, still large |

**Shunt decision:** use 0.1 mΩ as a 2×2512 parallel pair (0.05 mΩ effective → 5 W), or a Hall sensor. This is commonly the hottest unplanned component on 4‑in‑1 boards.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd high-side switches hard. The low-side sync rectifier switches with near-zero V_DS (soft) but incurs dead-time diode conduction.

### 2.1 Transition time

$$t_{r}\approx t_f \approx \frac{Q_{gs2}+Q_{gd}}{I_{drv}} = \frac{15\text{ nC}}{0.75\text{ A}} = 20\text{ ns}$$

### 2.2 Loss components per motor

1. **V–I overlap loss**

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{n} \times 48\text{k} = \mathbf{1.94\ W}$$

2. **Dead-time body-diode conduction** (two dead times per PWM cycle)

$$P_{DT} = V_{SD} I_{ph}\,2 t_{dead} f_{sw} = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = \mathbf{0.61\ W}$$

3. **
