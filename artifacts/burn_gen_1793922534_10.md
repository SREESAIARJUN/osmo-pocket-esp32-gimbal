# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #34)

I don't have the Job #34 spec sheet, so I've made the hardware assumptions below explicit. Every place where a value depends on them is parameterized in the code. Change the `Config` structs and the derivations still hold.

---

## 0. Assumptions and Loop Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, CORDIC optional |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMU A | ICM-42688-P on the camera payload (attitude feedback) |
| IMU B | ICM-42688-P on the base/handle (disturbance feedforward, vibration reference) |
