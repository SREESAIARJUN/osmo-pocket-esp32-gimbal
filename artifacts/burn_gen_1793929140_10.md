## 0. System Assumptions and Loop Timing

| Item | Value |
|---|---|
| Motors | 3× BLDC gimbal motors, e.g. 12N14P (pole pairs $p=7$) **[ASSUME]** |
| Rotor sensing | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| Current sensing | 2-phase low-side shunts (inline is better) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO with timestamps |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

| Loop | Rate | Runs in |
|---|---|---|
| Current (d/q PI), SVPWM, cogging feedforward | 20 kHz | ADC-triggered ISR |
| Velocity PI (inertial rate from IMU) | 4 kHz | Timer ISR |
| IMU fusion, notch filters, attitude, angle loop | 1–2 kHz (IMU sampled at 8 kHz) | Timer ISR or task |
| Cogging learning (LMS) | 20 kHz update, gated | Inside the current ISR |

Bandwidth separation rule: each outer loop's crossover frequency should be at most 1/4 to 1/5 of the inner loop's.

## 1. FOC Core Equations

### 1.1 Clarke and Park Transforms (amplitude-invariant)

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},
\qquad \theta_e = p\,(\theta_m - \theta_{\text{off}})
$$

### 1.2 PMSM Model in the dq Frame

$$
v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q
$$

$$
v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac32 p\,\lambda_m i_q = K_t i_q \quad (\text{SPM: } L_d = L_q)
$$

### 1.3 Current PI Tuning by Pole-Zero Cancellation

The plant per axis is $1/(Ls+R)$. Choose PI gains so the closed loop becomes first order with bandwidth $\omega_c$:

$$
K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c
\quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}
$$
