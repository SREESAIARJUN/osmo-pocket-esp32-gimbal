# STM32H743 AIO Flight Controller + 4-in-1 80A ESC: Engineering Model

## 0. Architecture Clarification and Baseline Assumptions

**The STM32H743 does not commutate the motors.** ArduPilot is a flight-control stack and does not run six-step or FOC commutation. A practical architecture splits the work as follows:

- **H743 (ArduPilot)** generates bidirectional DShot600 and reads eRPM telemetry.
- **4 independent ESC MCUs** (AT32F421 running AM32 in this design) run 48 kHz synchronous six-step commutation.
- **4 three-phase bridges** contain 24 MOSFETs in total.

The models below follow this split. Change the assumptions in the table and re-run the equations to fit your actual BOM.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path

The bridge uses synchronous, complementary six-step commutation. In each 60° sector:

- **PWM leg:** the high-side (HS) FET conducts for duty D; the complementary low-side (LS) FET conducts for 1−D.
- **Static leg:** the LS FET is fully on.
- **Floating leg:** off; used for back-EMF sensing.

At any instant, motor current flows through exactly **two** channels in series (excluding dead time). The total conduction loss per ESC is therefore:

$$P_{cond,ESC} = 2\, I_{rms}^2 \, R_{ds(on)}(T_j)$$
