# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #13 specification, so this design states its assumptions explicitly. Every number marked **[A]** is a placeholder. Replace it with your hardware values before tuning.

## 0. System Assumptions and Loop Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, ≥170 MHz **[A]** |
| Motors | Gimbal BLDC 12N14P: pole pairs p = 7, slots Ns = 12 **[A]** |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint **[A]** |
| Current sense | 2-shunt low-side, synchronous to PWM center **[A]** |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about a reference point, on SPI @ 24 MHz |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |

**Loop rates and bandwidths**

| Loop | Rate | Target bandwidth | Separation |
