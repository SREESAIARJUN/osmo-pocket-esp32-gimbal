## 2. FOC Current Loop

### 2.1 Transforms

The θ_e used here is the **electrical** angle:

θ_e = Nₚ·θ_m − θ_offset

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 2.2 Plant and PI Tuning

Motor dynamics in the dq frame:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·(L·i_d + ψ_m)

Use a PI controller with pole-zero cancellation, C(s) = K_p + K_i/s, where:

- K_p = L·ω_c,i
- K_i = R·ω_c,i

With these gains the open loop becomes ω_c,i/s, so each axis behaves as a first-order closed loop with bandwidth ω_c,i.

**Decoupling feedforward** (added to the PI outputs):

- v_d* = PI_d − ω_e·L·i_q
- v_q* = PI_q + ω_e·(L·i_d + ψ_m)

where ψ_m = (2/3)·K_t / Nₚ.

### 2.3 Discretization and Anti-Windup

Use forward Euler for the integrator and back-calculation for anti-windup:

- u_k = K_p·e_k + x_k
- ū_k = sat(u_k)
- x_{k+1} = x_k + T_s·[K_i·e_k + K_aw·(ū_k − u_k)]

Choose K_aw ≈ K_i/K_p.

**Voltage saturation:** limit the voltage vector by circular limiting with d-axis priority:

‖v_dq‖ ≤ V_dc/√3
