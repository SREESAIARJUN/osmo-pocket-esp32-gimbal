| Loop | Rate | Target bandwidth |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning: apply V_d with θ_e = 0 and let the rotor settle.

### 1.2 Clarke and Park transforms

Using the amplitude-invariant form, with i_c = −i_a − i_b:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

### 1.3 Machine model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

Torque, assuming a surface PMSM (L_d ≈ L_q):

$$\tau_e = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q$$

### 1.4 Current PI with decoupling and back-EMF feed-forward

The feed-forward terms cancel the cross-coupling and back-EMF, which leaves each axis as a first-order plant 1/(R + sL):

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \hat\omega_e \hat L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \hat\omega_e(\hat L_d i_d + \hat\lambda_m)$$

**Pole-zero cancellation tuning.** Set the PI zero on the electrical pole R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$

**Discretization.** The integral is updated with the forward-Euler form x[k+1] = x[k] + K_i T_s e[k].

The one-sample PWM delay adds phase lag of ω_c·1.5T_s. At 20 kHz with ω_c = 2π·1500 this is 0.71 rad (≈ 40°), which still leaves about 50° of phase margin.

**Voltage limiting.**
- The vector is clamped to the circle |v| ≤ V_bus/√3 (the linear SVPWM region).
- The d-axis has priority: v_q is limited to √(V_max² − v_d²).
- Anti-windup uses back-calculation with gain K_aw = 1/K_p.

### 1.5 Inverse Park and SVPWM (min-max injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Common-mode injection and duty cycles:

$$v_0 = -\tfrac12(\max v_x + \min v_x),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

Min-max injection is mathematically equivalent to sector-based SVPWM. It reaches V_bus/√3 without any sector logic.
