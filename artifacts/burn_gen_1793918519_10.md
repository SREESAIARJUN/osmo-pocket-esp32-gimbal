# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

**Scope note:** I don't have the Job #12 specification, so the design below rests on stated assumptions. Every place that depends on hardware is marked `// HW:` or is a configuration constant. Replace the parameters in §0 with your actual values and re-derive the gains using the formulas in §2–§4.

---

## 0. Assumed Platform and Timing

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2 low-side shunts, ADC triggered at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the pitch axis, SPI at 8 kHz ODR |
| Axis order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (rule of thumb: each loop about 5–10× slower in bandwidth than the one inside it):**

| Loop | Rate | Target closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (ISR) | ~1.5–2 kHz |
| Cogging feedforward | 20 kHz | — |
| IMU filter and fusion | 8 kHz | — |
| Velocity PI | 4 kHz | ~80–150 Hz |
| Angle P | 1 kHz | ~15–30 Hz |
| Attitude estimator | 1 kHz | — |
