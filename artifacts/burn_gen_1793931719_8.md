| Item | Assumption / Correction |

## 1. Conduction Loss Model

### 1.1 Current Path
With complementary PWM in 6-step mode, motor current flows through exactly two FETs at every instant:
- During the on-time, it flows through the PWM-phase HS FET and the always-on LS FET of the return phase.
- During the off-time, it flows through the PWM-phase LS FET (synchronous rectification) and the same return LS FET.

So, independent of duty cycle D (to first order):

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{ds(on)}(T_j)$$

### 1.2 Ripple Correction
The phase current ripple is ΔI_pp:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12}$$

The worst case is at D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}$$

For a typical 5-inch/2207 motor, L_ph ≈ 15 µH:

$$\Delta I_{pp} = \frac{25.2 \cdot 0.25}{15\mu \cdot 48k} = 8.75\ \text{A} \;\Rightarrow\; \frac{\Delta I^2}{12} = 6.4\ \text{A}^2 \quad (\text{negligible vs } 6400)$$

### 1.3 Temperature Coefficient
A typical silicon trench FET follows:

$$R_{ds(on)}(T_j) \approx R_{25}\,\left[1 + 0.0048\,(T_j - 25)\right]$$

At T_j = 125 °C: R = 1.5 mΩ × 1.48 ≈ **2.2 mΩ**. Add about 0.2 mΩ per path for package, plane and solder.

R_path ≈ 2 × 2.4 mΩ = 4.8 mΩ

### 1.4 Result at 80 A

$$P_{cond,motor} = 80^2 \times 4.8\,m\Omega = \mathbf{30.7\ W\ per\ motor}$$

**Per-FET distribution.** Over one electrical revolution each of the 6 FETs carries its share:

$$\bar P_{FET} \approx \frac{30.7}{6} = 5.1\ \text{W average}$$

The peak instantaneous dissipation is 80² × 2.4 mΩ = 15.4 W, carried by the return-LS FET during its 120° interval.

## 2. Switching Loss Model at 48 kHz

Switching losses arise only in the PWM leg (one HS/LS pair per motor at any time).

| Term | Equation | Value (80 A, 25.2 V) |
|---|---|---|
| V–I overlap (hard-switched HS) | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·40n·48k = **1.94 W** |
| Body-diode reverse recovery | Q_rr·V·f_sw | 60n·25.2·48k = **0.073 W** |
| Output capacitance | ½·Q_oss·V·f_sw | 0.5·50n·25.2·48k = **0.030 W** |
| Dead-time diode conduction | 2·V_f·I·t_dt·f_sw | 2·0.8·80·100n·48k = **0.61 W** |
| Gate charge (driver, not FET) | 2·Q_g·V_gs·f_sw | 2·50n·10·48k = **0.048 W** |
| **Total switching per motor** | | **≈ 2.70 W** |
