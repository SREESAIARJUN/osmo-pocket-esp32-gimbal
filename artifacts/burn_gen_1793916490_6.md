# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

> **Assumptions.** I don't have the spec sheet for "Job #38", so the design is parameterized. The defaults assume:
> - Gimbal BLDC motors in the GBM2804 / GBM4108 class.
> - 14-bit absolute magnetic encoder per axis (AS5048A / MT6701).
> - STM32G4/H7-class MCU with an FPU.
> - Two ICM-42688-P IMUs on the camera plate.
> - Inline or low-side current sensing.
>
> Every constant lives in one config struct. Replace the defaults with your measured motor parameters before tuning.

## 1. System Architecture and Timing

```
           ┌───────────────── 1 kHz ─────────────────┐ ┌──── 4 kHz ────┐ ┌─── 20 kHz ───┐
θ_ref ──►[Angle P + rate FF]──ω_ref──►[J⁻¹ map]──►[Velocity PI]──τ──►(+)──i_q*──►[Current PI dq]──►SVPWM──►Motor
              ▲                              ▲              ▲      ▲ i_cog,ff        ▲
              │ q̂_cam (attitude)             │ ω_cam (gyro) │      │                 │ i_abc, θ_e (encoder)
         [Mahony AHRS] ◄── [Dual-IMU fusion + notch + LPF] ◄── 8 kHz ODR ×2    [Anti-cogging Fourier/LMS]
```

| Loop | Rate | Target bandwidth | Separation rule |
|---|---|---|---|
| Current (d,q) | 20 kHz | 1.5–2 kHz | ≤ f_s/10 (PWM + compute delay ≈ 1.5 T_s) |
| Velocity | 4 kHz | 80–150 Hz | ≤ current BW / 10 |
| Angle | 1 kHz | 15–30 Hz | ≤ velocity BW / 4–5 |
| IMU | 8 kHz ODR → decimated to 4 kHz | — | — |

**Rule of thumb on filter lag.** Every filter adds group delay in the velocity path. The phase lag it contributes at the velocity crossover ω_cv comes directly out of the velocity-loop phase margin (§5.5).

## 2. FOC: Field-Oriented Current Control

### 2.1 Motor model (PMSM, rotor dq frame)

$$
v_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2} p \left[\lambda_m i_q + (L_d-L_q) i_d i_q\right] \;\overset{L_d=L_q}{=}\; K_t\, i_q,
\qquad K_t = \tfrac{3}{2} p \lambda_m,
\qquad \theta_e = p\,(\theta_m - \theta_{\text{offset}})
$$
