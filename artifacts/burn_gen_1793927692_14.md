# STM32H743 Nano FC + 80 A 4-in-1 ESC (Job #43): Electro-Thermal and DShot Timing Model

## 0. Architecture Correction and Assumptions

**Architectural point.** The STM32H743 should not commutate the motors. In every production 4-in-1 stack (and in ArduPilot's model), the system is split as follows:

| Function | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743 (400 MHz in ArduPilot) | ArduPilot (ChibiOS) |
| ESC, one per motor (×4) | AT32F421 / STM32G071 / GD32E230 class MCU + 3
