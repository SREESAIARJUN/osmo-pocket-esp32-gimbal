# 3-Axis Gimbal: FOC, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #26 specification, so this design uses the stated assumptions below. Every number derived from them is computed from parameters in the code. Replace them with your measured motor and inertia values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × BLDC gimbal motors, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH (phase), λ ≈ 0.012 V·s/rad |
| Bus | V_dc = 16.8 V (4S) |
| Commutation sensor | 14-bit magnetic encoder per axis (e.g., AS5048/MT6835) |
| IMU-P | ICM-42688-P on the **payload** (camera plate). Used for inertial feedback. |
| IMU-B | ICM-42688-P on the **base** (handle or drone mount). Used for disturbance feedforward and as the vibration reference. |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates**

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| IMU ODR | 8 kHz | 125 µs |
| Velocity | 4 kHz | 250 µs (decimated 2:1 after filtering) |
| Angle and attitude | 1 kHz | 1 ms |

**Bandwidth separation rule:**

ω_c,current ≥ 5–10 · ω_c,vel ≥ 4–5 · ω_c,angle
