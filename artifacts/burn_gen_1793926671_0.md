## 1. Mathematical Design

### 1.1 Field-Oriented Control (innermost loop, 20 kHz)

**Electrical angle.** With encoder angle θ_m, pole pairs p and calibrated offset θ_0:

$$\theta_e = p\,\theta_m - \theta_0 \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**PMSM dq model:**

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Current PI with cross-coupling decoupling.** The plant 1/(Ls+R) is pole-zero cancelled. Choose a closed-loop bandwidth ω_c of about 2π·1.5 kHz (well below f_PWM/10):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\Rightarrow\; \frac{i_q}{i_q^*} = \frac{\omega_c}{s+\omega_c}$$

$$v_d^* = PI_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

The command uses i_d* = 0, since gimbal motors have no field weakening.

**Voltage limit.** The dq voltage vector is circularly limited to the linear SVPWM range:

$$\|v_{dq}\| \le V_{bus}/\sqrt3$$

When the limit is active, it is fed back to the PI integrators for anti-windup (Section 1.2).

**Inverse Park, then SVPWM.** SVPWM is implemented as min-max zero-sequence injection, which is mathematically equivalent to 7-segment SVPWM:

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.2 Cascaded Angle → Velocity → Current Control

The mechanical plant for each axis is:

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

**Velocity loop (4 kHz).** This loop is a PI with setpoint weighting b, a filtered derivative (usually K_d = 0), back-calculation anti-windup, and an acceleration feedforward. The discrete form, with sample time T_s, is:

$$e_k = \omega^*_k - \omega_k$$

$$P_k = K_p(b\,\omega^*_k - \omega_k)$$

$$D_k = \frac{T_f}{T_f+T_s}D_{k-1} - \frac{K_d}{T_f+T_s}(\omega_k - \omega_{k-1})$$

$$u_k = P_k + I_k + D_k + u_{ff,k}$$

$$\bar u_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + \frac{T_s}{T_t}(\bar u_k - u_k)$$

Here T_t = √(T_i·T_d), or T_t = T_i when there is no derivative term.

**Velocity gain tuning (symmetric optimum).** Model the closed current loop as a first-order lag with time constant τ_c = 1/ω_c, plus the velocity-filter lag τ_f. The equivalent small time constant is τ_σ = τ_c + τ_f + 1.5·T_s,v. With the symmetric-optimum parameter a ≈ 2–3:

$$\omega_v = \frac{1}{a\,\tau_\sigma}$$

$$K_{p,v} = \frac{J\,\omega_v}{K_t}\quad[\text{A}/(\text{rad/s})]$$

$$K_{i,v} = \frac{K_{p,v}\,\omega_v}{a^2}$$

The output is i_q*.

**Angle loop (1 kHz).** The plant seen by this loop is approximately an integrator. Use P plus a small I for steady-state stabilization against cable torque, and add a velocity feedforward from the trajectory or stabilization command:

$$\omega^* = K_{p,\theta}\,\text{wrap}(\theta^* - \theta) + K_{i,\theta}\!\int\! e_\theta\,dt + \dot\theta^*_{ff}$$

$$K_{p,\theta} \approx \omega_v/4$$

**Bandwidth separation (required for valid cascade design):**

$$\omega_c : \omega_v : \omega_\theta \approx 1500 : 150 : 35\ \text{Hz}$$

Each loop is at least 4–10× faster than the loop outside it.
