# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for Job #64, so this design rests on the explicit assumptions in §0. Wherever a value depends on your hardware, it is a named constant you can change.

---

## 0. Assumptions and Rate Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804-class), 12N14P → `pole_pairs = 7` |
| Phase parameters | R ≈ 5–12 Ω, L ≈ 1–3 mH, Kt from Kv |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5047-class) |
| Current sense | Inline shunts, 2 phases (a voltage-mode fallback is provided) |
