## 0. Scope, Architecture, and Key Assumptions

### 0.1 Architecture

The STM32H743 does **not** drive the MOSFET gates. The system has two layers:

```
 ┌────────────────────────── FC (STM32H743, ArduPilot) ─────────────────────────┐
 │  TIMx CH1..4 ──(Bidir DShot600, 3.3 V, single wire, half-duplex)──┐          │
 │  ADC (VBAT, CURR)  ◄──────────────────────────────────────────────┼──┐       │
 └────────────────────────────────────────────────────────────────────┼──┼──────┘
                                                                      ▼  │
 ┌──────────────────────── 4-in-1 ESC (4 × ESC MCU, e.g. AT32F421) ──────┴──────┐
 │  ESC MCU (AM32 / BLHeli_32) → 3-ph gate driver → 6 × N-MOSFET → motor phases │
 └──────────────────────────────────────────────────────────────────────────────┘
```

- The 48 kHz PWM is generated by each ESC MCU, not by the H743.
- The H743 only generates DShot frames and captures the eRPM telemetry returned on the same wire.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation Model

The ESC uses trapezoidal 6-step commutation with complementary (synchronous-rectified) PWM on the high side. During any 60° sector:

- **Phase A (PWM leg):** HS_A is on for D, and LS_A is on for (1 − D) as the synchronous rectifier.
- **Phase B (return leg):** LS_B is on 100 % of the sector.
- **Phase C:** floating (used for BEMF sensing).

Each phase leg spends 1/3 of the electrical cycle as the PWM leg, 1/3 as the return leg, and 1/3 floating.

### 1.2 RMS Current Including Ripple

The ripple current is:

$$
\Delta I = \frac{V_{bus}\,D(1-D)}{f_{sw}\,L_{LL}}
\quad\Rightarrow\quad
\Delta I_{max}\,(D=0.5) = \frac{25.2 \times 0.25}{48\,000 \times 20\,\mu H} = 6.56\ \text{A}
$$

The RMS current is then:

$$
I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2
$$
