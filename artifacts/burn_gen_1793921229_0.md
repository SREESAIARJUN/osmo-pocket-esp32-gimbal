## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = \big(p\,(\theta_m - \theta_{\text{off}})\big) \bmod 2\pi$$

Here θ_off is found at commissioning by applying a fixed d-axis voltage and reading the encoder.

**Latency compensation.** The current is sampled at mid-PWM, but the new duty is applied in the next period. The angle used in the inverse Park transform is therefore advanced:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad (i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM model and decoupled PI

The motor model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning.** Choose the current-loop bandwidth ω_c (rad/s):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With this choice the closed loop is first order, $i/i^* = \omega_c/(s+\omega_c)$. Pick $\omega_c \le 2\pi f_{\text{PWM}}/20$, which gives roughly 2π·1 kHz at 20 kHz PWM.

**Control law.** PI plus cross-coupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Normally $i_d^* = 0$, since there is no field weakening on a gimbal.

**Voltage circle limit** (linear SVPWM region):

$$V_{\max} = \frac{V_{\text{bus}}}{\sqrt3}\,m_{\max},\quad m_{\max}\approx0.95$$

The d-axis has priority:

$$v_d \leftarrow \text{clamp}(v_d, \pm V_{\max}),\qquad v_q \leftarrow \text{clamp}\!\left(v_q, \pm\sqrt{V_{\max}^2 - v_d^2}\right)$$

**Discrete PI with back-calculation anti-windup.** Let $u_s$ be the saturated output:

$$u_k = K_p e_k + x_k,\qquad x_{k+1} = x_k + K_i T_s e_k + K_{aw}T_s\,(u_s - u_k),\qquad K_{aw} = K_i/K_p$$
