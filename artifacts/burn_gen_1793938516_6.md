# STM32H743 Nano FC + 80 A 4-in-1 ESC: Systems Architecture Package (Job #9)

**Scope:** Electrothermal model for the ESC power stage, switching-loss model at f_sw = 48 kHz, ArduPilot bidirectional DShot600 timer/DMA plan on the STM32H743, reference netlists, and the derived burst-duration limits.

> **Engineering caveat.** All device parameters below are representative values for a 40 V, ~1 mΩ, 3.3×3.3 mm DFN MOSFET class. They are not quoted from a specific datasheet. Before layout freeze, substitute the selected part's R_DS(on)(T), Q_g, Q_rr, C_oss and Z_th curves, and re-run the model. The equations are written so that this is a direct substitution. The netlists are reference topologies and must be pin-checked against current datasheets and an ERC/DRC run.
