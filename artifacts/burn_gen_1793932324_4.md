# STM32H743 Nano FC + 4-in-1 ESC (Job #15): Design Model

## 0. Architecture Corrections

These issues change the model, so they come first.

1. **The H743 should not drive the power stage directly.** ArduPilot does not commutate motors. A production 4-in-1 needs either one ESC MCU per motor (e.g., AT32F421/STM32G071 running AM32 or BLHeli_32) or a single multi-motor ESC MCU. The H743 sends bidirectional DShot600 to the ESC MCU(s). The 48 kHz PWM and its switching losses belong to the ESC MCUs, not the H743.
2. **80 A burst per motor on a nano form factor (20×20 or 25.5×25.5 mm) is not thermally sustainable** beyond a few seconds (proven in §2.4). Either "80 A" means total pack current, or the burst window must be explicitly limited (about 1–3 s). This should be resolved with the customer before layout.
3. **Bidirectional DShot cannot use complementary (CHxN) timer pins for input capture.** All four motor outputs should be on non-N channels.

Assumptions are flagged with **[A]**. Replace them with datasheet values for the selected parts.

## 2. Thermal Loss Model

### 2.1 Conduction Loss

With complementary-PWM 6-step commutation, two MOSFETs are always in the current path: the high-side of one leg (or its low-side partner during freewheel) plus the low-side of the return leg.

P_cond,motor = I² · 2 · R_DS(hot) = 80² × 2 × 1.0 mΩ = **12.8 W**

Each FET conducts 1/3 of the electrical cycle (120°), so the per-FET average is:

P_cond,FET ≈ 12.8 / 6 = **2.13 W** (peak 6.4 W while conducting)

**PCB copper loss.** Assume 0.5 mΩ total path resistance **[A]** (4-layer 2 oz power planes, battery pad → FET → phase pad):

P_Cu = 80² × 0.5 mΩ = **3.2 W/motor**

### 2.2 Switching Loss at 48 kHz

Only the chopping leg switches hard.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·20 ns·48 kHz | **0.968 W** |
| Output capacitance | Q_oss·V·f_sw = 50 nC·25.2·48 kHz | **0.060 W** |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 kHz | **0.048 W** |
| Dead-time body diode | V_SD·I·2·t_dt·f_sw = 0.8·80·2·100 ns·48 kHz | **0.614 W** |
| Gate charge (driver IC) | 2·Q_g·V_GS·f_sw = 2·60 nC·10·48 kHz | 0.058 W (dissipated in driver) |

P_sw,motor ≈ 0.968 + 0.060 + 0.048 + 0.614 = **1.69 W**

The two biggest levers on switching loss:

- **Dead-time loss is 36 % of switching loss.** Reducing t_dt to 50 ns saves 0.31 W per motor. This is limited by shoot-through margin, so it must be verified on a scope.
- **Overlap loss scales with edge time.** Faster edges reduce it but worsen dv/dt EMI and gyro noise coupling.

### 2.3 Total Dissipation at Burst

| | Per motor | ×4 motors |
|---|---|---|
| Conduction (FETs) | 12.8 W | 51.2 W |
| Switching | 1.69 W | 6.8 W |
| Copper | 3.2 W | 12.8 W |
| Shunt (0.25 mΩ **[A]**, if per-motor current sense) | 1.6 W | 6.4 W |
| **Total** | **19.3 W** | **≈ 77 W** |

ESC efficiency at burst: P_out ≈ 22.2 V × 80 A × 4 ≈ 7.1 kW, so η ≈ 98.9 %. The efficiency is fine. The problem is power density.

### 2.4 Thermal Feasibility

**Junction to case (per FET).** Use the peak-conduction FET:

P_FET ≈ 6.4 W conducting, plus about 0.85 W switching share (high-side chopping FET).

With Z_th(jc) ≈ 0.5 K/W **[A]**:

ΔT_jc ≈ 7.25 × 0.5 ≈ **3.6 K**. This is not the constraint.

**Board-level adiabatic burst (the real constraint).** Assume a 25.5×25.5 mm, 1.6 mm, 6-layer, 2 oz board with 12 FETs at about 5.5 g **[A]**. The blended specific heat is about 0.85 J/g·K, giving:

C_th ≈ 4.7 J/K

Allowed rise: 105 °C board limit − 45 °C ambient/start = 60 K.

t_burst,max = (C_th · ΔT) / P = (4.7 × 60) / 77 ≈ **3.7 s** (adiabatic, all four motors at 80 A)

**Steady state with prop wash.** Assume h ≈ 120 W/m²·K **[A]** and both faces, so A = 2 × 6.5×10⁻⁴ m²:

R_th,sa = 1 / (h·A) = 1 / (120 × 1.3×10⁻³) ≈ 6.4 K/W

P_cont,max = 60 / 6.4 ≈ **9.4 W total**

Working backwards from 9.4 W, sustainable continuous current is about **24 A per motor**.

**Thermal time constant:** τ = R·C = 6.4 × 4.7 ≈ **30 s**.

The temperature response to a burst step is:

T(t) = T_0 + P·R_th·(1 − e^(−t/τ)), with P·R_th = 493 K (asymptote).

| Burst duration | ΔT rise |
|---|---|
| 1 s | 16 K ✔ |
| 2 s | 32 K ✔ |
| 4 s | 61 K ✘ (at limit) |

**Spec recommendation:** "80 A burst ≤ 2 s, 25 A continuous per motor, at 45 °C ambient with airflow."

The ESC firmware should implement an I²t limiter that matches this model. Per-FET or board NTC derating should start at 90 °C.

### 2.5 Bulk Capacitor Ripple

Worst-case ripple at D = 0.5:

I_C,rms ≈ I·√(D(1−D)) = 80 × 0.5 = **40 A rms per motor**

On-board ceramics cannot absorb this alone. The design needs:

- 8–10 × 10 µF/50 V
