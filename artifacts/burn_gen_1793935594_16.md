## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right], \quad \alpha \approx 0.005\ \mathrm{K^{-1}}$$

This gives about 1.5× R_25 at 125 °C. Add PCB and package parasitics as R_pcb (assume 0.3 mΩ per conduction path, from the phase leg plus bus copper).

### 1.2 Conduction path in synchronous 6-step

In any commutation sector, one phase is PWM'd and one phase is held low:

- High-side (PWM phase) conducts for D·T_sw.
- Low-side (PWM phase, synchronous rectification) conducts for (1−D)·T_sw.
- Low-side of the return phase conducts 100% of the time.

The current always flows through exactly **two FETs in series**, so:

$$P_{cond,ch} = I^2\left[D R + (1-D)R + R\right] = 2 I^2 R_{ds(on)}(T_j) + I^2 R_{pcb}$$

This result is independent of duty cycle, which is a useful property of synchronous rectification.

### 1.3 Evaluation at 80 A, assuming T_j ≈ 105 °C

$$R_{ds(on)} = 1.0\,(1 + 0.005 \cdot 80) = 1.40\ \mathrm{m\Omega}$$

$$P_{cond,ch} = 2(80^2)(1.40\times10^{-3}) + 80^2(0.3\times10^{-3}) = 17.92 + 1.92 = \mathbf{19.8\ W}$$

Per-FET average power: each FET conducts roughly one third of the electrical cycle. This gives about 17.9 / 6 ≈ **3.0 W average** per FET, with peaks of I²R = **9.0 W** during the sectors when that FET is the static low-side.

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM phase leg hard-switches in each sector.

### 2.1 V–I overlap loss

Transition time is set by the driver's Miller-plateau current:

$$t_{r,f} \approx \frac{Q_{gd}\,R_G}{V_{drv} - V_{plateau}}$$

With the FD6288Q (≈1.5 A source / 1.8 A sink) and R_G = 4.7 Ω, the result is t_r + t_f ≈ 20 ns
