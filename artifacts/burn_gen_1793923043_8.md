# STM32H743 AIO + 4-in-1 ESC: 80 A Burst Power Stage, 48 kHz Switching, and ArduPilot Bi-directional DShot600

**Job #27: Architecture and Analysis Package, Rev A (pre-layout)**

## 0. Scope, Assumptions, and Clarifications

An "STM32H743 4-in-1 ESC" board does not commute the motors from the H743. The H743 runs ArduPilot and emits DShot600 to dedicated ESC MCUs, which handle commutation and the 48 kHz PWM. This document treats the product as an AIO stack:

| Domain | Device / Basis | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 400 MHz (480 MHz on rev V silicon) | ArduPilot, sensor fusion, DShot600 TX, bidirectional eRPM RX |
| ESC MCUs (×4) | AT32F421 class (Cortex-M4, 120 MHz), AM32 firmware | 6-step commutation, 48 kHz complementary PWM, DShot RX/eRPM TX |
| Gate drivers (×4) | FD6288Q-class 3-phase bootstrap driver | HS/LS gate drive |
| Power MOSFETs (×24) | 40 V N-ch, DFN3.3×3.3 class (parametric, see Table 0.2) | 6 per motor |
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | Bus |
