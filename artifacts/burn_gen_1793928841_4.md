# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #22)

## 0. Assumptions and System Architecture

I don't have the Job #22 spec sheet, so this design is parameterized around a typical brushless gimbal. Replace the values in `GimbalConfig` with your hardware. Each assumption below drives specific numbers in the design.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g., GBM2804-class), p = 7 pole pairs, R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class with an FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |
| Gimbal joint order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop-rate hierarchy (bandwidth separation ≥ 5× per stage):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5 kHz |
| Velocity (PI) | 4 kHz | ~150 Hz |
| Angle (P + rate feedforward) | 1 kHz | ~25 Hz |
| IMU filtering | 8 kHz, decimated to 4 kHz | — |
| Attitude estimator | 1 kHz | — |

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

θ_offset is found at calibration by applying V_d along the α-axis and reading the resulting encoder angle.

### 1.2 Clarke transform (power-variant, assuming i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$
