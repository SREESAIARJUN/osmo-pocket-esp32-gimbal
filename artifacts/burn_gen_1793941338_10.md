# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #17 spec sheet. This design therefore uses the common hardware assumptions in §0. Every numeric value is a named constant, so you can substitute your real hardware values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) |
| Motors | GBM2804-class gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5.6 Ω, L ≈ 2.2 mH, λ ≈ 0.012 Wb |
| Joint encoder | 14-bit magnetic (MT6701 / AS5048A), SPI |
| Supply | 3S Li-ion, V_bus ≈ 12 V |
| IMU_P | ICM-42688-P on the camera plate (payload, feedback) |
| IMU_B | ICM-42688-P on the base/handle (vibration reference + base-rate feedforward) |
| Kinematic order | Yaw (outer) → Roll (middle) → Pitch (inner) |

**Loop rates (all are integer divisions of a 32 kHz master clock):**

| Loop | Rate | Trigger |
|---|---|---|
| Current loop (FOC) + SVPWM | 20 kHz | TIM1 center-aligned update; ADC injected conversion |
| IMU sampling (both IMUs) | 8 kHz | Both IMUs on external CLKIN (32 kHz from MCU timer), so samples are phase-locked |
| Vibration filters + rate loop | 8 kHz | IMU_P data-ready |
| Attitude estimator + angle loop | 1 kHz | Decimated by 8 |
| Cogging adaptation | 1 kHz (background) | — |

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

θ_off is found at commissioning: inject V_d along α and read the encoder.
