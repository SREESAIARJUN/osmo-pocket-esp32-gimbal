# STM32H743 Nano AIO with 4-in-1 ESC (Job #19): Design Basis, Loss Model, DShot/DMA Allocation, and Netlist

## 0. Architecture Assumptions

These assumptions drive every number below. If any are wrong for Job #19, the downstream math changes.

| Item | Assumption |
|---|---|
| Topology | AIO stack: an STM32H743 flight controller drives four independent ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32) over **bi-directional DShot600** |
| Power stage | 4× three-phase bridges, 6 N-MOSFETs per motor (24 total), 3-phase driver per motor (FD6288-class) |
| Bus | 6S LiPo: V_bus nominal 22.2 V, design point **25.2 V** (full charge), abs-max transient 35 V |
| Current | **80 A burst per motor channel**, not 80 A total |
| PWM | 48 kHz, complementary with synchronous rectification, trapezoidal 6-step commutation |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz outer and 2 oz inner power layers, ≈6 g mass |
| MOSFET (reference) | 40 V, 3.3×3.3 mm DFN. R_DS(on) = 0.9 mΩ @ 25 °C/10 V, Q_g = 60 nC, Q_gd = 10 nC, Q_rr = 50 nC, Q_oss = 60 nC, R_θJC = 1.0 K/W |

**Feasibility warning:** 80 A per motor on a 30.5 mm nano board is at the extreme edge. The model below shows it is achievable only as a **seconds-scale thermal burst**. It is not a continuous rating.

## 1. Conduction Loss Model

### 1.1 Current path
In 6-step trapezoidal drive with synchronous rectification, phase current always flows through exactly **two** MOSFET channels in series:
- **ON period (D):** HS of PWM leg → motor winding → LS of the static leg.
- **OFF period (1−D):** LS of PWM leg (synchronous) → winding → LS of the static leg.

So the conduction loss per motor is, independent of duty cycle:

$$P_{cond,FET} = 2\,I^2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\left[1+\alpha_{FET}(T_j-25)\right],\quad \alpha_{FET}\approx 0.006\ \text{K}^{-1}$$

Copper path resistance (busbar, pours, vias, solder pads), with α_Cu = 0.0039 K⁻¹:

$$P_{cond,Cu} = I^2 R_{path}(T),\quad R_{path,25}\approx 0.5\ \text{m}\Omega$$

### 1.3 Numbers at I = 80 A

| Condition | FET loss | Copper loss | Total conduction |
|---|---|---|---|
| T = 25 °C | 2·6400·0.9 mΩ = **11.52 W** | 6400·0.5 mΩ = **3.20 W** | **14.72 W** |
| T_j = 125 °C (R = 1.44 mΩ, R_Cu = 0.70 mΩ) | **18.43 W** | **4.45 W** | **22.9 W** |

### 1.4 Per-FET loss
Each FET conducts for 1/3 of the electrical period.
- **Instantaneous:** up to 80²·1.44 mΩ = **9.2 W**.
- **Averaged:** ≈ 18.4 W / 6 ≈ **3.1 W**.
