# FOC Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #29, so the parameters in §0 are stated assumptions. Every gain in this document is derived from those parameters by formula, not hand-picked. Substitute your measured values and the gains recompute.

## 0. Assumptions and Rate Plan

| Item | Assumed value | Symbol |
|---|---|---|
| MCU | STM32G474 class (Cortex-M4F, single-precision FPU) | — |
| Motor | Gimbal BLDC, 12N14P (12 slots, 14 poles) | N_s = 12, P = 7 pole pairs |
| Phase resistance, line-to-neutral | 5.0 Ω | R |
| Phase inductance, d ≈ q | 2.0 mH | L |
| Flux linkage | 0.012 V·s | λ |
| Torque constant | 1.5·P·λ = 0.126 N·m/A | K_t |
| Load inertia (per axis, reflected) | 2.0e-4 kg·m² | J |
| Encoder | 14-bit magnetic absolute (e.g. AS5048/MT6835) | θ_m |
| Bus voltage | 16.8 V (4S) | V_dc |
| IMUs | 2× ICM-42688-P on camera plate, SPI @ 24 MHz | — |

**Loop rates and bandwidths.** Each loop runs about 4–10× below the loop inside it.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| PWM + current (FOC) | 20 kHz | ω_c = 2π·2000 rad/s |
| Velocity | 4 kHz | ω_v = 2π·200 rad/s |
| Angle / attitude | 1 kHz | ω_θ = 2π·30 rad/s |
| IMU sampling | 8 kHz ODR, decimated to 4 kHz | — |
