## 1. Loop Architecture and Rates

```
            IMU (camera attitude)                  Encoder (rotor angle)
                    │                                       │
  θ_ref ──►[Angle P + FF]──ω_ref──►[Velocity PI]──i_q*──►[Current PI dq]──►SVPWM──►Motor
              1 kHz         ▲        4 kHz       ▲  ▲     20 kHz
                            │                    │  └── i_q,cog(θ_m)  anti-cogging FF
                     ω̂ (gyro, fused)             └──── J·α_ref/K_t     inertia FF
```

Design rules:

- **Bandwidth separation.** Each outer loop should be at least 5–10× slower than the loop inside it:
  - ω_c ≈ 2π·1500 rad/s (current loop)
  - ω_v ≈ 2π·150 rad/s (velocity loop)
  - ω_p ≈ 2π·20 rad/s (angle loop)
- **Feedback sources.**
  - Commutation (θ_e) always comes from the encoder.
  - Velocity feedback uses the fused gyro rate, projected onto the joint axis. This rejects base motion directly; the encoder-PLL rate is the fallback.
  - Angle feedback comes from the attitude estimate (Mahony AHRS).

## 2. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 2.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

where θ_offset is found at calibration by applying v_d > 0 at θ_e = 0 and reading the encoder.

### 2.2 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)\qquad(\text{assuming } i_a+i_b+i_c=0)$$

### 2.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 2.5 PI current controller with decoupling

Plant per axis: $G(s) = \dfrac{1}{Ls+R}$. Placing the PI zero on the plant pole (pole–zero cancellation) gives:

$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Discrete form (Ts = 50 µs), with feed-forward decoupling:

$$v_d = K_{p,c}e_d + I_d - \hat\omega_e L i_q$$
$$v_q = K_{p,c}e_q + I_q + \hat\omega_e L i_d + \hat\omega_e\lambda_m$$
$$I_{k+1} = I_k + K_{i,c}T_s e_k$$

### 2.6 Voltage limit and anti-windup

Limit the voltage vector to the linear SVPWM circle, $|v_{dq}| \le V_{bus}/\sqrt3$:

$$v_d \leftarrow \text{clamp}(v_d,\pm V_{max}),\qquad v_q \leftarrow \text{clamp}\!\left(v_q,\pm\sqrt{V_{max}^2 - v_d^2}\right)$$

Anti-windup uses back-calculation, with $K_{aw} = 1/K_{p,c}$:

$$I_{k+1} = I_k + T_s\left[K_{i,c}e_k + K_{aw}(v_{sat} - v_{unsat})\right]$$

### 2.7 Inverse Park and SVPWM (min-max injection, equivalent to 7-segment SVM)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
