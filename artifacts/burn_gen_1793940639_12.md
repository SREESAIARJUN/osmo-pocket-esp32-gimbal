# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #60)

I don't have the Job #60 spec sheet, so I've made the assumptions below explicit. Every gain is derived from motor parameters, so substitute your measured values and the equations still hold.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A), one per joint |
| IMUs | 2× ICM-42688-P on the camera payload board (redundant, rigidly co-mounted), SPI @ 24 MHz |
| MCU | Cortex-M4
