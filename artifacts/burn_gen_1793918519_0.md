## 1. Loop Architecture and Timing

```
                   ┌──────────── 1 kHz ───────────┐  ┌────── 4 kHz ───────┐ ┌─────── 20 kHz ────────┐
θ_ref (attitude) ─►│ Angle P + vel FF            │─►│ Velocity PI + D_f  │─►│ Current PI (d,q)      │─► SVPWM ─► Motor
                   └──────────▲──────────────────┘  └───────▲────────────┘ │ + decoupling + cogFF  │
                              │                             │              └──────────▲────────────┘
   Dual ICM-42688 ─► notch/LPF ─► fusion ─► Mahony AHRS     │ gyro (body rate)        │ i_a,i_b, θ_e (encoder)
                              (8 kHz → 1 kHz)               └─────────────────────────┘
```

Each loop runs at least 4–5× slower than the loop inside it, so the inner loop looks like a unity gain at the outer loop's crossover:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | f_pwm = 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·80–150 Hz |
| Angle | 1 kHz | ω_θ ≈ 2π·15–30 Hz |

## 2. Field-Oriented Control (Current Loop)

### 2.1 Transforms

Electrical angle from the mechanical encoder angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{offset}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 2.2 PMSM Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \psi_m)$$
$$\tau_e = \tfrac{3}{2} p \left[\psi_m i_q + (L_d - L_q) i_d i_q\right] \;\xrightarrow{\;L_d \approx L_q\;}\; K_t\, i_q,\qquad K_t = \tfrac{3}{2}p\psi_m$$

### 2.3 Current PI with Feedforward Decoupling

$$v_d^* = K_{p,i}\,e_d + K_{i,i}\!\int e_d\,dt \;-\; \omega_e L_q i_q$$
$$v_q^* = K_{p,i}\,e_q + K_{i,i}\!\int e_q\,dt \;+\; \omega_e(L_d i_d + \psi_m)$$

Gain selection by pole-zero cancellation: the PI zero K_i/K_p is placed at the plant pole R/L. The closed loop then becomes first order, 1/(s/ω_c + 1):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The reference is i_d* = 0 (surface-mounted PMSM, no field weakening).

### 2.4 Voltage Limiting and Anti-Windup

The voltage vector is limited to the linear SVPWM circle, |v| ≤ V_bus/√3:

$$\text{if }\sqrt{v_d^2+v_q^2} > V_{max}:\quad v_q \leftarrow \operatorname{sign}(v_q)\sqrt{V_{max}^2 - v_d^2}$$

The d-axis is given priority. Integrators use back-calculation anti-windup with K_aw ≈ 1/K_p:

$$\dot x_I = K_i\,e + K_{aw}\,(u_{sat} - u_{unsat})$$

### 2.5 Space-Vector PWM (Min-Max Injection)

$$v_{a,b,c} = \text{invClarke}(\text{invPark}(v_d, v_q, \theta_e))$$
$$v_{0} = -\tfrac{1}{2}\left[\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\right]$$
$$D_x = \tfrac{1}{2} + \frac{v_x + v_0}{V_{bus}}$$

### 2.6 Delay Compensation

The PWM update has a 1.5-sample delay. Rotate the inverse Park transform by the angle the rotor travels in that time:

$$\theta_e^{PWM} = \theta_e + 1.5\,\omega_e T_s$$

## 3. Cascaded Velocity and Angle Control

### 3.1 Mechanical Plant per Axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

With the current loop treated as ideal, the plant from i_q to ω is K_t/(Js + B).

### 3.2 Velocity Loop

The velocity loop is a PI controller. Derivative action is filtered and acts on the measurement only (no derivative kick). Acceleration feedforward is optional.

$$i_q^* = K_{p,v}e_\omega + K_{i,v}\!\int e_\omega\,dt - K_{d,v}\,\frac{s}{\tau_f s+1}\,\omega + \frac{J}{K_t}\dot\omega^* + i_{q,cog}^{ff}$$

Tuning by symmetric optimum, with crossover ω_v and N ≈ 4 (≈ 37° phase margin; use N = 6 for ≈ 45°):

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{N}$
