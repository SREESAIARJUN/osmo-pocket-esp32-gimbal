# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the original Job #49 specification, so the design rests on the **baseline assumptions below**. Every gain is derived symbolically, so you can substitute your real parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 10 Ω, L = 2.5 mH (phase), λ = 8 mWb |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701 class), one per axis |
| IMU | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Angle/attitude 1 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

## 1. Control Architecture

```
            ┌──────────── 1 kHz ───────────┐ ┌──── 4 kHz ─────┐ ┌──────── 20 kHz ────────┐
 q_ref ─►(Attitude err)─► P + ω_ff ─► ω* ─►(+)─► PI_ω ─► τ*/Kt ─►(+)─► i_q* ─► PI_dq + decoupling ─► SVPWM ─► Motor
                               ▲             −│                 ▲ i_ff(θm)        ▲ i_d,i_q
   q̂ (Mahony) ◄─ DualIMU fusion ◄─ notch/LPF ◄┴── ω_gyro (joint)  │ anti-cogging     │ Clarke/Park ◄─ ADC
                                                                  └── θm (encoder) ──┘
```

Inertial stabilization feeds the **gyro rate** (rotated into joint space) back to the velocity loop, not the differentiated encoder angle. This rejects base motion directly. The encoder provides the commutation angle, the cogging-table index, and the joint Jacobian.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms
With electrical angle θₑ = p·(θₘ − θ_offset):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}\quad(\text{Clarke, amplitude-invariant},\ i_a+i_b+i_c=0)
$$
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}\quad(\text{Park})
$$

### 2.2 Plant and decoupled PI
$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda
$$

The controller adds feed-forward decoupling so each axis becomes 1/(Ls+R):

$$
v_d^* = \text{PI}(i_d^*-i_d) - \omega_e L\, i_q,\qquad
v_q^* = \text{PI}(i_q^*-i_q) + \omega_e L\, i_d + \omega_e \lambda
$$

**Pole-zero cancellation:** set C(s) = K_p + K_i/s with K_i/K_p = R/L. The open loop then becomes ω_c/s, giving a first-order closed loop with bandwidth ω_c:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10\text{–}20}
$$

At f_s = 20 kHz, choose ω_c = 2π·1000 rad/s, which gives K_p = 15.7 V/A and K_i = 62 800 V/(A·s).

**Discretization:** use forward Euler, x_{k+1} = x_k + K_i T_s e_k, with one-sample PWM delay compensation θₑ ← θₑ + 1.5·ωₑT_s in the inverse Park.

**Voltage limit:** the vector is clamped to |v| ≤ V_bus/√3, the linear SVPWM limit. Integrator anti-windup uses back-calculation, ẋ = K_i e + K_aw(v_sat − v_unsat) with K_aw = 1/K_p.

### 2.3 SVPWM (min-max zero-sequence injection)
$$
v_a = v_\alpha,\ v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\ v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$
$$
v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}
$$
