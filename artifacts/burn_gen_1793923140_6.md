# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual ICM-42688-P Sensor Fusion

This design specifies the control law, discretization, and a complete C++ reference implementation for one gimbal axis. It instantiates three times, once each for pitch, roll and yaw. I don't have the Job #56 hardware sheet, so the parameters in §0 are stated assumptions. Every gain is derived from those parameters, so you can substitute your measured values.

---

## 0. Assumptions and Loop Timing

| Item | Value (assumed) | Note |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`) | High-R, low-speed PMSM |
| Phase R, L | R = 10 Ω, L = 2.5 mH (Ld ≈ Lq) | Measure per motor |
| Flux linkage λ | 0.004 Wb | From back-EMF: λ = Ke / (√3·p) for line-line Ke in V·s/rad |
| Bus | 12 V (3S/4S) | |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701) | Used for commutation and the cogging map |
| IMUs | 2 × ICM-42688-P on SPI, ODR 8 kHz, common CLKIN | Mounted on camera plate, symmetric about the rotation center |
| MCU | STM32G4/H7-class with FPU | |

**Loop rates (one shared timer, integer decimation):**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ~1.5 kHz |
| IMU acquisition and filtering | 8 kHz | 125 µs | — |
| Velocity | 4 kHz | 250 µs | ~80–120 Hz |
| Angle (attitude) | 1 kHz | 1 ms | ~15–25 Hz |

Keep a bandwidth separation of at least 4–6× between successive loops. That separation is what allows each outer loop to treat the inner loop as unity gain in its design.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle:

  θe = p·(θm − θ_offset)  (mod 2π)

**Clarke transform** (amplitude-invariant, two shunts, i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2·i_b) / √3

**Park transform:**

  i_d =  i_α·cos θe + i_β·sin θe
  i_q = −i_α·sin θe + i_β·cos θe

### 1.2 Plant and decoupled PI

The PMSM d-q model:

  v_d = R·i_d + L_d·di_d/dt − ωe·L_q·i_q
  v_q = R·i_q + L_q·di_q/dt + ωe·(L_d·i_d + λ)

Torque:

  τ = (3/2)·p·[λ·i_q + (L_d − L_q)·i_d·i_q]  ≈  K_t·i_q,  with K_t = 1.5·p·λ

**Control law** (PI plus feed-forward decoupling):

  v_d* = PI_d(i_d* − i_d) − ωe·L_q·i_q
  v_q* = PI_q(i_q* − i_q) + ωe·(L_d·i_d + λ)

With decoupling in place, each axis reduces to G(s) = 1/(L·s + R).

**Gain selection by pole-zero cancellation:** placing the PI zero on the electrical pole gives a closed loop of ωc/(s + ωc).

  K_p = L·ωc,  K_i = R·ωc
