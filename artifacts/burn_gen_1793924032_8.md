# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

**Scope note:** I don't have the Job #47 specification sheet. Every hardware parameter below is a clearly marked placeholder that you should replace with your measured values. The assumed hardware is:

- Hollow-shaft gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5.6 Ω, L ≈ 1.8 mH
- 14-bit magnetic encoder (AS5048A-class)
- STM32G4-class MCU at 170 MHz
- Two ICM-42688-P IMUs on the camera plate

All of the math is parameterized, so it carries over to other hardware.

## 1. Timing Architecture

| Loop | Rate | Rule of thumb |
|---|---|---|
| PWM / current (FOC) | 20 kHz (Tₛ = 50 µs) | ω_c ≈ 2π·1 kHz (≤ f_s/20, accounting for 1.5·Tₛ delay) |
| IMU sample + filters | 8 kHz | Driven by the IMU's INT1 data-ready. Use the FSYNC pin or a shared read for alignment |
| Velocity (rate) loop | 4 kHz | ω_v ≈ ω_c/8 – ω_c/10 |
| Angle loop + attitude | 1 kHz | ω_θ ≈ ω_v/4 – ω_v/5 |

Each outer loop must be at least 4–5× slower in bandwidth than its inner loop. This bandwidth separation is what makes the cascade design valid.

## 2. FOC Equations

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

### 2.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
