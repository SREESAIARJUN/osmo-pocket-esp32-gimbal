# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #35 specification, so the design below rests on stated assumptions (§0). Everything is parameterised, so substitute your real motor and frame numbers. The math and code are complete. Gains, filter frequencies, and the ICM-42688-P register values still need to be checked on your hardware and against the current datasheet revision.

---

## 0. Assumptions and Loop Rates

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.5 Ω (phase), L = 1.8 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) on each motor shaft |
| MCU | Cortex-M4F/M7 with FPU, single-precision float |
| PWM | 20 kHz center-aligned, 3-shunt current sensing |
| Gimbal kinematics | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
