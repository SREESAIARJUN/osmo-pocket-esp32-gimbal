# Job #9: STM32H743 Nano FC + 4-in-1 80A ESC
## System Architecture, Loss Model, DShot DMA Allocation, Netlists and Thermal Budget

**Rev A. Engineering baseline. Values marked ⚠ are assumptions that must be replaced with datasheet values for the selected parts before release.**

## 0. Architecture Clarification

This is a two-processor system:

| Domain | Processor | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 / VIT6 (480 MHz) | ArduPilot. Generates bidirectional DShot600 and decodes eRPM telemetry. |
| ESC (×4 channels) | 4× AT32F421 / STM32G071 class running AM32 (or 1 MCU per channel in a BLHeli_32-style design) | Commutation, **48 kHz PWM**, dead-time, current limiting |

The H743 never drives the MOSFETs. The 48 kHz switching figure is an ESC firmware parameter (AM32 `PWM frequency = 48 kHz`). The loss model in §1–2 applies to the ESC power stage. The DMA model in §3 applies to the H743.

**Form factor assumption ⚠.** The stack is 30.5×30.5 mm (nano class, 36×36 mm board). An "80A burst" rating at this size is **duration-limited by thermal capacitance, not steady-state resistance**. §4 quantifies this limit.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Reference MOSFET ⚠
The reference part is a 40V N-channel in PDFN 5×6 or 3.3×3.3 dual-cool (TOLL is too large for nano). Representative parameters:

| Parameter | Symbol | Value |
|---|---|---|
| R_DS(on) max @ 25°C, V_GS=10V | R₂₅ | 1.2 mΩ |
| Temperature coefficient | α | 0.007 /K |
| Total gate charge | Q_g | 60 nC |
| Gate-drain charge | Q_gd | 10 nC |
| Post-threshold gate-source charge | Q_gs2 | 5 nC |
| Plateau voltage | V_pl | 4.0 V |
| Output charge @ 25V | Q_oss | 50 nC |
| Body diode reverse recovery | Q_rr | 40 nC (scales with di/dt and I_F) |
| Body diode forward voltage | V_F | 0.8 V |
| Junction-to-case thermal resistance | R_θJC | 0.8 K/W |

There are 6 FETs per channel (3 half-bridges) and 24 FETs total.

### 1.2 Hot R_DS(on)
$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 1.20 mΩ |
| 100 °C | 1.83 mΩ |
| 125 °C | 2.04 mΩ |

### 1.3 Six-step trapezoidal commutation with synchronous rectification
Two phases conduct at any instant, so the current path always passes through one high-side (HS) and one low-side (LS) device. With complementary PWM at duty D:

- PWM-leg HS conducts for D.
- Its synchronous LS conducts for (1−D).
- The fixed-leg LS conducts for 100%.

$$P_{cond} = I^2 R_{DS}(T_j)\,[\,D + (1-D) + 1\,] = 2\,I^2 R_{DS}(T_j)$$

The result is independent of D. Ripple adds a correction factor of $(1 + \tfrac{1}{12}(\Delta I/I)^2)$, which is less than 1% at 48 kHz with typical motor inductance (~10–30 µH), so it is neglected.

**At 80A, T_j = 125 °C:**
$$P_{cond} = 2 \times 80^2 \times 2.04\text{ mΩ} = \mathbf{26.1\ W/channel}$$

The fixed LS device takes 13.1 W. This is the hottest FET, which dictates layout priority (§4.4).

**Additional resistive paths per channel ⚠:**

| Path | Resistance | Loss at 80A |
|---|---|---|
| Shunt | 0.25 mΩ | 1.6 W |
| PCB copper (2oz, 8L) | 0.3 mΩ | 1.9 W |
| **Subtotal** | | **3.5 W** |

## 2. Switching Loss Model at f_sw = 48 kHz

Conditions: V_bus = 25.2 V (6S full charge), I = 80 A. Only the PWM-leg switches.

### 2.1 Gate drive currents
Driver: FD6288Q-class, 10 V supply. R_g,ext = 4.7 Ω, plus internal ~1 Ω.

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,tot}+R_{drv,src}} = \frac{10-4}{5.7+0.5}\approx 0.97\text{ A}$$

$$I_{g,off} = \frac{V_{pl}}{R_{g,tot}+R_{drv,snk}} \approx \frac{4}{5.7+0.3}\approx 0.67\text{ A}$$

A turn-off diode (BAT54 + 2.2 Ω) is fitted in parallel with R_g. It raises I_g,off to about 1.5 A.

### 2.2 Transition times
$$t_r = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{15\text{ nC}}{0.97}\approx 15.5\text{ ns}, \qquad t_f = \frac{15\text{ nC}}{1.5}\approx 10\text{ ns}$$

### 2.3 Loss components (per channel)

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·25.5n·48k | **1.23 W** |
| Output capacitance | Q_oss·V·f_sw = 50n·25.2·48k | 0.06 W |
| Reverse recovery ⚠ | Q_rr·V·f_sw, with Q_rr scaled ×3 at 80A/high di/dt → 120n·25.2·48k | 0.15 W |
| Dead-time diode conduction | V_F·I·2·t_dt·f_sw, t_dt = 250 ns: 0.8·80·2·250n·48k | **1.54 W** |
| Gate drive (dissipated in R_g/driver) | 2·Q_g·V_drv·f_sw = 2·60n·10·48k | 0.06 W |
| **Total switching** | | **≈ 3.0 W** |

**Design insight.** Dead-time loss exceeds overlap loss. Tuning AM32 dead-time down to about 100 ns (validated by double-pulse test) saves about 0.9 W per channel. Raising f_sw to 96 kHz would roughly double this entire table.

### 2.4 Channel and board totals at 80A burst

| Item | W/channel | W/board (4ch) |
|---|---|---|
| Conduction (FETs) | 26.1 | 104.4 |
| Shunt + copper | 3.5 | 14.0 |
| Switching | 3.0 | 12.0 |
| Driver/LDO/MCU | 0.3 | 1.2 |
| **Total** | **32.9** | **≈ 132 W** |

Electrical output at 80A × 25.2V × D≈0.95 is about 1.9 kW per channel, so efficiency is about 98.3% even at burst. Heat density, not efficiency, is the constraint.
