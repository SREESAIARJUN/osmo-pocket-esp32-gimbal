# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Fusion

I don't have the Job #43 specification, so this design uses common gimbal assumptions. **Section 0** lists every one of them. Change those parameters, and the gains derive from them automatically using the equations in Sections 2–3.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.08 N·m/A, PM, SPMSM (L_d ≈ L_q) |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI, read every PWM cycle |
| Bus | 12–16 V, 3-shunt (or 2-shunt) low-side current sensing |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate, rigidly mounted, separated by lever arm **r** (≈ 25–40 mm) |

**Loop rates (timer-synchronous):**

```
20 kHz  ── PWM ISR: ADC → Clarke/Park → current PI (d,q) → inv. Park → SVPWM
            + encoder read, PLL speed observer, anti-cogging FF
 8 kHz  ── IMU FIFO drain (both ICM-42688-P, ODR 8 kHz, CLKIN-synchronised)
            → AAF (on-chip) → dynamic notch → LPF → dual-IMU fusion
 2 kHz  ── Inertial-rate PI loop (per axis) → i_q*
 500 Hz ── Attitude (Mahony) → angle P loop → rate setpoint
```

**Cascade per axis** (outer → inner):

```
θ* ─►[Angle P + FF]─ω*─►[Rate PI(+D) + J·α* FF]─i_q*─►(+ i_cog FF)─►[Current PI]─►SVPWM─►Motor
       ▲ attitude (IMU)      ▲ inertial rate (gyro)        ▲ i_dq (shunts)
```

The rate loop closes on **inertial** rate (gyro), not on encoder speed. This choice is what makes the gimbal *stabilize* rather than merely hold a joint angle. The encoder is used for commutation, cogging compensation, and the joint-space Jacobian.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

The offset θ_off is found by aligning: apply V_d at θ_e = 0 and read θ_m.

**Latency compensation.** The PWM duty applies roughly 1.5 T_s after sampling, so use a predicted angle:

$$\theta_{e,\text{pwm}} = \theta_e + 1.5\,T_s\,p\,\hat\omega_m$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{with } i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and decoupled PI

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

**Discrete PI with decoupling, back-EMF feedforward, and back-calculation anti-windup:**

$$
\begin{aligned}
e_x[k] &= i_x^*[k] - i_x[k]\\
u_x[k] &= K_{p,i}\,e_x[k] + I_x[k] + v_{x,\text{ff}}\\
v_{d,\text{ff}} &= -\hat\omega_e L i_q,\qquad v_{q,\text{ff}} = \hat\omega_e (L i_d + \lambda_m)\\
v_x[k] &= \text{sat}_{\text{circle}}(u_x[k])\\
I_x[k+1] &= I_x[k] + K_{i,i}T_s\,e_x[k] + K_{aw}\,(v_x[k]-u_x[k])
\end{aligned}
$$

The back-calculation gain is typically K_aw = K_i T_s / K_p.

**Pole-zero cancellation tuning.** The PI zero cancels the plant pole R/L. This yields a closed loop that is first order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{20}$$

With f_pwm = 20 kHz: ω_c = 2π·1000 rad/s, giving K_p = 13.2 V/A and K_i = 35 186 V/(A·s).

### 1.4 Voltage limit (circular, d-axis priority)

The linear-region SVPWM limit is V_max = V_dc/√3 · m_max, with m_max ≈ 0.95.

$$v_d \leftarrow \text{clamp}(v_d, \pm V_{max}),\qquad v_q \leftarrow \text{clamp}\big(v_q,\ \pm\sqrt{V_{max}^2 - v_d^2}\big)$$
