## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (Ns = 12 slots, p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.08 N·m/A |
| Encoder | AS5048A / MT6701, 14-bit absolute, SPI, sampled every current cycle |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at the PWM midpoint |
| Current sensing | 2-phase low-side shunts |
| IMUs | 2× ICM-42688-P on separate SPI buses, ODR 8 kHz, both mounted on the camera plate |

**Loop rates:**

```
TIM1 update (20 kHz) ─► Current loop: Clarke/Park, PI d/q, decoupling, SVPWM
        │ ÷5
        ├─────────────► Velocity loop (4 kHz): inertial-rate PI + cogging FF + learning
        │ ÷4
        └─────────────► Angle loop (1 kHz): attitude error → rate command (P + FF)
IMU DRDY (8 kHz, both chips) ─► AAF (on-chip) → adaptive notches → biquad LPF →
                                weighted dual fusion → fault check → Mahony AHRS
```

**Bandwidth separation (≥ 5× between loops):**
- Current loop: ωc,i = 2π·1500 rad/s
- Velocity loop: ωc,ω = 2π·150 rad/s
- Angle loop: ωc,θ = 2π·15 rad/s

## 1. FOC Current Loop (Innermost)

### 1.1 Transforms

Electrical angle with delay compensation. The PWM update lands about 1.5 sample periods after the angle is read:

$$\theta_e = p\,\theta_m - \theta_{off} + 1.5\,T_s\,\omega_e, \qquad \omega_e = p\,\omega_m$$
