## 0. Architecture Clarification, Assumptions & Feasibility Flags

### 0.1 Partitioning (important)

The STM32H743 does **not** commutate the motors. The 48 kHz switching and 6-step commutation run on four dedicated ESC MCUs, one per motor. The H743 runs ArduPilot and talks to each ESC over bidirectional DShot600.

```
 ┌──────────────────────────── FC board (H743, ArduPilot) ───────────────────────────┐
 │ TIM1_CH1..CH4 ──(bidir DShot600, 3V3, single wire per motor)──┐                     │
 └────────────────────────────────────────────────────────────────┼────────────────────┘
                                                                   ▼
 ┌──────────────────────── ESC board (4 × MCU + 4 × 3-ph bridge) ─────────────────────┐
 │ ESCn MCU (AT32F421-class, AM32 fw) → 6-ch gate driver → 6 × N-MOSFET → motor n     │
 │ PWM 48 kHz, complementary w/ dead time, BEMF zero-cross comparator                 │
 └────────────────────────────────────────────────────────────────────────────────────┘
```

### 0.2 Design Assumptions

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max / 22.2 V nom | Design to V_bus = 25.2 V |
