# STM32H743 Nano FC + 4-in-1 ESC (Job #60): Power-Stage Thermal Model, 48 kHz Switching Losses, BDShot600 DMA Allocation, and Reference Netlist

---

## 0. Findings and Architectural Constraints

| # | Finding | Consequence |
|---|---------|-------------|
| F1 | ArduPilot on the H743 does not commutate motors. It emits DShot. Commutation and the 48 kHz PWM run on per-motor ESC MCUs. | The architecture is **H743 FC + 4× ESC MCUs** (e.g., AT32F421 running AM32). The 48 kHz figure is an AM32 setting, not an ArduPilot parameter. |
| F2 | 24 power MOSFETs, 4 ESC MCUs, 2 gate drivers, an H743, an IMU, a baro, an OSD and a regulator do not fit on one 20×20 mm (M2, 25.5 mm) board with adequate copper. | Use a **two-board stack**: FC 20×20 on top of ESC 20×20. This document models the ESC board. |
| F3 | The thermal model (§3) shows a 20×20 board can sustain only **~15–17 A/motor continuous**. 80 A is a **≤1 s all-motor / ~3 s single-motor** transient. | The "80 A burst" rating must carry a duration spec. ArduPilot-side current/temperature limiting is mandatory (§5.6). |
| F4 | At 80 A and D = 0.5, the input-capacitor RMS ripple approaches **40 A per motor**. | The board needs on-board MLCC plus an external low-ESR bulk capacitor at the battery pads. |
