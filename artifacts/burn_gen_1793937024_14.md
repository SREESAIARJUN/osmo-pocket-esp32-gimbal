# STM32H743 Nano FC + 80 A 4-in-1 ESC: Systems Architecture Package (Job #17)

## 0. Architecture Boundary and Key Assumptions

The H743 does not drive the MOSFETs. It is the flight controller and emits four bidirectional DShot600 streams. Each 4-in-1 ESC channel runs its own commutation MCU, so loss and thermal modelling belongs to the ESC board and DMA/timer allocation belongs to the FC.

```
┌──────────────── FC (STM32H743, ArduPilot) ────────────────┐
│ TIM3_CH3/CH4, TIM5_CH1/CH2 ── DShot600 + eRPM telemetry ──┼──► 8-pin JST-SH
└───────────────────────────────────────────────────────────┘      │
┌──────────────── 4-in-1 ESC (AM32-class MCU) ──────────────┐◄─────┘
│ MCU (AT32F421 / STM32G071) → 3-ph gate driver → 6× MOSFET │ ×4
│ Shunt + amp → CURR, VBAT divider → VBAT                   │
└───────────────────────────────────────────────────────────┘
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R_ds = 0.75 mΩ × (1 + 0.0055 × 85) = **1.10 mΩ**.

### 1.2 Six-step current paths

The model assumes complementary PWM on the sourcing leg and a hard-on low-side FET on the sinking leg (the AM32 default). Over each electrical period, each leg spends 1/3 sourcing, 1/3 sinking and 1/3 floating.

- During sourcing, the high-side FET conducts for D and the synchronous low-side FET for (1−D).
- During sinking, the low-side FET conducts for 100% of the interval.

Per-FET average conduction loss is then:

$$P_{HS} = \frac{I^2 R_{ds}\, D}{3}, \qquad P_{LS} = \frac{I^2 R_{ds}\,(2 - D)}{3}$$

Two FETs are always in the current path, so the channel total is independent of D:

$$P_{cond,ch} = 2 I^2 R_{ds}(T_j)$$

### 1.3 Numbers at 80 A, T_j = 110 °C

- I²R = 6400 × 1.10 mΩ = 7.04 W.
- P_cond,ch = **14.1 W per channel**.
- P_HS = 7.04 × 0.95 / 3 = **2.23 W**.
- P_LS = 7.04 × 1.05 / 3 = **2.46 W**.

Ripple adds a small correction, I_rms² = I² + ΔI²/12. For phase inductance L ≈ 20 µH:

$$\Delta I = \frac{V(1-D)D}{L f_{sw}} \approx 1.25\ \text{A}$$

This changes losses by less than 0.1%, so it is neglected.
