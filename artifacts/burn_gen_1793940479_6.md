# STM32H743 Nano Flight Controller with Integrated 4-in-1 ESC: Architecture, Loss Model, and DShot Allocation

**Job #51: Preliminary Design Package (Rev A)**

## 0. Scope and Assumptions

Two points shape this design.

1. **The H743 does not commutate the motors.** ArduPilot does not run ESC firmware. A 4-in-1 ESC on an H743 flight controller needs four dedicated ESC MCUs, here an AT32F421 running AM32 (or an equivalent BLHeli_32-class MCU). The H743 sends bidirectional DShot600 to them. The architecture below reflects this.

2. **80 A is a burst rating, not a continuous one, on a nano footprint.** The math in Section 2 shows that 80 A per channel dissipates about 125 W across the board. A 20×20 or 25.5×25.5 mm board in prop wash can sustain roughly 25 A per channel continuously. The 80 A figure holds for about 1–2 s. Spec sheets and marketing should say "25 A continuous / 80 A 1 s burst," not "80 A."

## 1. System Architecture

```
            ┌──────────────────────── 4-layer+ PCB, 2 oz outer / 2 oz inner ─────────────────────────┐
 VBAT ──┬─► │ Bulk caps ─► 4× [AT32F421 (AM32) ─► 3-ph gate driver ─► 6× N-MOSFET] ─► M1..M4         │
        │   │                    ▲ DShot600 bidir (1 wire each)                                       │
        │   │ Buck 5V/9V ─► LDO 3.3V ─► STM32H743 (ArduPilot)                                         │
        │   │                    TIM3 CH1..CH4 ──────────────┘                                        │
        │   │ Shunt + INA ─► H743 ADC (BATT_CURR), Divider ─► ADC (BATT_VOLT)                         │
        └── │ IMU (SPI1), Baro (I2C/SPI), OSD (SPI), Flash/SD, UART×n, NTC on power stage ─► ADC      │
            └─────────────────────────────────────────────────────────────────────────────────────────┘
```

**Partitioning rule:** keep the H743, IMU, and crystal in a quiet zone. Place them on the opposite end from the hottest FET cluster, with the power ground return isolated by layout rather than by a split plane.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Current Path

With trapezoidal 6-step commutation and synchronous (complementary) PWM, phase current at any instant flows through exactly two conducting devices:

- During the PWM on-state: the high-side FET of the PWM leg plus the low-side FET of the return leg.
- During the PWM off-state: the low-side FET of the PWM leg (synchronous rectification) plus the same return low-side FET.

This holds independent of duty cycle D, apart from dead time, which is handled in Section 3.
