### Signal flow

```
            ┌───────────── IMU B (base) ── filters ── ω_b ─────────────┐ (feedforward)
            │                                                          ▼
q_ref ─► [Attitude P] ─► ω_c* ─► [J(q)^-1 · (ω_c* − Rᵀω_b)] ─► q̇* ─► [Vel PI ×3] ─► τ* ─┐
   ▲                                                                                   │
   └── Mahony(IMU A) ◄── filters ◄── IMU A (camera)                                    ▼
                                                    i_q* = τ*/Kt + i_cog(θ) ─► [FOC PI dq] ─► SVPWM
```

The two IMUs serve different roles:

- **IMU A** (camera) closes the attitude loop. Its true rate also enters the velocity loop through a complementary blend, which gives encoder-free disturbance rejection.
- **IMU B** (base) measures handle motion before it reaches the camera. That measurement is converted into a joint-rate feedforward, which cancels most of the hand-shake disturbance before any error builds up.

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle and transforms

The electrical angle is computed from the mechanical angle and a calibrated offset:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (power-invariant amplitude form, valid for balanced currents with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 PMSM model in the rotor frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The electromagnetic torque is:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

This holds for a surface-mount PM motor, where $L_d = L_q$ and there is no reluctance torque.

### 1.3 Current PI design (pole-zero cancellation)

With cross-coupling decoupled, each axis is the first-order plant $G(s)=1/(Ls+R)$. Choose the PI gains so the PI zero cancels the plant pole:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

The open loop then reduces to $\omega_c/s$, and the closed loop is a first-order lag $\omega_c/(s+\omega_c)$.

The decoupling and back-EMF feedforward terms are added to the PI outputs:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.4 Voltage limit and anti-windup

**Circular voltage limit.** The SVPWM linear region allows $|v_{dq}|\le V_{dc}/\sqrt3$. The limit is applied with d-axis priority:

$$v_q^{max} = \sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}$$

**Anti-windup by back-calculation.** For a PI with saturation, let $u = K_p e + I$ and $u_s = \text{sat}(u)$. The integrator update is:

$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(u_s - u)\big],\qquad K_{aw}=K_i/K_p$$
