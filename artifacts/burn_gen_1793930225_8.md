## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ~170+ MHz) |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.5 Ω, L = 2.4 mH, Kt ≈ 0.07 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read every PWM cycle |
| Current sense | Low-side shunts, 2 or 3 phase |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| PWM | 20 kHz center-aligned |

The loops run at these rates. Each loop is at least 4–5× slower in bandwidth than the loop inside it.

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5 kHz |
| Inertial rate (gyro PI) | 4 kHz | ~150 Hz |
| Attitude (P + rate feedforward) | 1 kHz | ~30 Hz |
| Attitude estimator | 1 kHz | — |

The key design decision for a gimbal is the split between sensors:
- The **encoder** is used only for commutation (electrical angle) and anti-cogging.
- The **velocity loop closes on the fused gyro rate**, which is inertial, not on encoder velocity. This is what rejects base motion.

## 1. FOC Current Loop Equations

### 1.1 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b),\qquad (i_c = -i_a-i_b)$$

### 1.2 Park transform

The electrical angle is $\theta_e = p\,(\theta_m - \theta_{\text{offset}})$.

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Machine model (SPMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI with pole-zero cancellation

The plant is $G(s) = 1/(Ls+R)$. Choosing the controller $C(s)=K_p + K_i/s$ with

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

gives the closed loop $\omega_c/(s+\omega_c)$. Use $\omega_c = 2\pi\cdot1500$.

Cross-coupling decoupling and back-EMF feedforward are added to the PI output:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 Discrete PI with back-calculation anti-windup

The integrator update, with sample time $T_s$, is:

$$I[k+1] = I[k] + K_i T_s\, e[k] + K_{aw}\,(u_{\text{sat}}[k]-u[k]), \qquad K_{aw}\approx \frac{K_i}{K_p}T_s$$

### 1.6 Voltage limiting and SVPWM

**Circular voltage limit.** $\|v_{dq}\|\le V_{bus}/\sqrt3$. Priority goes to $v_d$:

$$v_{q,\max} = \sqrt{V_{max}^2 - v_d^2}$$

**Inverse Park and inverse Clarke** produce $v_a, v_b, v_c$.

**Min-max zero-sequence injection** (equivalent to SVPWM):

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Attitude → Rate → Current Control

### 2.1 Joint-space mapping

Assume a yaw (outer) → roll → pitch (inner) gimbal with joint angles $q=[\psi,\phi,\theta]$ and the IMU on the camera. The camera angular velocity is:

$$\boldsymbol\omega_{cam} = R_{cb}\,\boldsymbol\omega_{base} + J(q)\,\dot q$$

The Jacobian columns are:

$$J(q) = \big[\,R_y(\theta)^T R_x(\phi)^T \hat z\;\;\big|\;\; R_y(\theta)^T\hat x \;\;\big|\;\; \hat y\,\big]$$

Rate errors are computed in the camera frame and mapped to joint torques with $J^{-T}$ (or $J^{-1}$ for rate commands). Near gimbal lock ($\phi\to\pm90°$), use a damped inverse:

$$J^\dagger = J^T(JJ^T+\lambda^2 I)^{-1}$$

### 2.2 Outer attitude loop (P + feedforward)

Use the quaternion error $q_e = q_{ref}^{*}\otimes \hat q$, taking the shortest path by setting $q_e \leftarrow -q_e$ if $q_{e,w}<0$. Then:

$$\boldsymbol\omega_{ref} = -K_\theta\cdot 2\,\text{sign}(q_{e,w})\,\vec q_e + \boldsymbol\omega_{ff},\qquad K_\theta \approx \omega_{bw,\theta}\ (\text{rad/s per rad})$$
