# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #7): Power-Stage and DShot Timing Model

## 0. Scope, Assumptions and Corrections

The brief mixes two separate processors, so the architecture is fixed first:

| Item | Clarification |
|---|---|
| **48 kHz switching** | The 48 kHz PWM is generated by the **ESC MCUs**, not the H743. The H743 runs ArduPilot and only emits and receives DShot. |
| **ESC MCU** | 4 × AT32F421K8U7 running AM32 (one per motor). A single-MCU 4-in-1 is possible, but it does not suit ArduPilot bidirectional telemetry. |
| **Gate driver** | 4 × FD6288Q (3-phase half-bridge driver, 5–20 V VCC, bootstrap). |
| **MOSFETs** | 24 × 40 V N-channel, PDFN5×6. Representative parameters: R_DS(on),25 = 1.2 mΩ @ V_GS = 10 V, Q_g = 40 nC, Q_rr = 50 nC, C_oss(er) = 1.5 nF, t_r + t_f ≈ 20 ns, V_SD = 0.8 V, R_θJC = 1.0 K/W. |
| **Bus** | 6S LiPo: 25.2 V full charge, 22.2 V nominal. |
| **"80 A burst"** | Interpreted as 80 A per motor, all 4 simultaneously. This is the worst case. |
| **Board** | 30.5 × 30.5 mm hole pattern (~36 × 36 mm outline), 8-layer, 2 oz copper on the power layers. |

All numbers below are a parametric model. Substitute your actual MOSFET datasheet values and re-run the equations. Section 3.5 reaches the key conclusion: **4 × 80 A simultaneous burst is thermally limited to about 1–2 s on a nano-class board without a heatsink.**

## 1. Conduction Loss Model (Trapezoidal 6-Step, Synchronous Complementary PWM)

### 1.1 Current paths

In each 60° commutation sector:
- One phase is PWM-switched: high-side on for duty D, low-side synchronous rectification for (1−D).
- One phase is held on (low-side on).
- One phase floats.

The motor current therefore always flows through **exactly two MOSFET channels in series**, either HS + LS or LS + LS.

### 1.2 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

Using an iterated T_j ≈ 110 °C (converged in §3.4):

$$R_{DS}(110) = 1.2\,(1 + 0.0045 \cdot 85) = 1.66\ \text{m}\Omega$$

### 1.3 RMS current including ripple

Phase inductance L ≈ 15 µH (typical 2207-class motor):

$$\Delta I_{pp} = \frac{V_{bus} D(1-D)}{L f_{sw}} = \frac{25.2 \cdot 0.25}{15\mu \cdot 48k} = 8.75\ \text{A (worst case, } D = 0.5)$$

$$I_{rms} = \sqrt{I^2 + \Delta I^2/12} = \sqrt{6400 + 6.4} = 80.04\ \text{A}$$

Ripple is negligible at 48 kHz, so I = 80 A is used below.

### 1.4 Conduction loss per ESC channel

$$P_{cond,FET} = 2\, I^2 R_{DS}(T_j) = 2 \cdot 6400 \cdot 1.66\times10^{-3} = \mathbf{21.2\ W}$$

### 1.5 Parasitic copper and shunt

| Element | R | P = I²R |
|---|---|---|
| PCB phase path + bus planes (2 oz, ~4 mm wide, multi-layer) | 0.25 mΩ | 1.60 W |
| Current-sense shunt (on the common return) | 0.20 mΩ | 1.28 W |
| Solder pads / motor wire pads | 0.05 mΩ | 0.32 W |
| **Subtotal** | | **3.2 W** |
