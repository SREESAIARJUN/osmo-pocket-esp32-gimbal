## 0. Assumptions and Loop Rates

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor encoder | 14-bit magnetic encoder (AS5048A / MT6701), SPI |
| MCU | STM32G4 class, 170 MHz, FPU, CORDIC; center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz |
| Current sense | 2- or 3-shunt, sampled at the PWM center |

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | Shunt currents, encoder electrical angle |
| Velocity (PI + feedforward) | 4 kHz | Fused **IMU gyro rate** (stabilization) |
| Angle (P + rate feedforward) | 1 kHz | Mahony attitude (fused IMUs) |
| Cogging feedforward | 20 kHz | Encoder mechanical angle |

**Key gimbal design point:** the encoder is used only for commutation and cogging lookup. The velocity and angle loops close on the inertial (IMU) measurement of the camera. That is what produces stabilization rather than mere motor positioning.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and current PI

The PMSM model in the dq frame (surface-mount machine, $L_d = L_q = L$):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque is $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$.

The PI controller includes cross-coupling and back-EMF decoupling:

$$v_d^* = K_{pc} e_d + K_{ic}\!\int e_d\,dt - \omega_e L i_q$$

$$v_q^* = K_{pc} e_q + K_{ic}\!\int e_q\,dt + \omega_e L i_d + \omega_e\lambda_m$$

**Tuning by pole-zero cancellation.** Choose

$$K_{pc} = L\,\omega_{cc},\qquad K_{ic} = R\,\omega_{cc}.$$

The closed loop then becomes first order: $i/i^* = \omega_{cc}/(s + \omega_{cc})$. Choose $\omega_{cc} \le 2\pi f_{\text{PWM}}/20$, i.e. about 2π·1 kHz at 20 kHz PWM.

### 1.3 Voltage limiting and anti-windup

The voltage vector is limited to the linear SVPWM hexagon's inscribed circle:

$$|v|_{\max} = V_{bus}/\sqrt3$$

If $\|v^*\| > |v|_{\max}$, scale the vector. Integrator back-calculation then applies:

$$\dot x_I = K_i e + K_{aw}(v_{\text{sat}} - v_{\text{unsat}}),\qquad K_{aw} = 1/K_p\cdot K_i$$

### 1.4 SVPWM (min-max zero-sequence injection)

The phase voltages come from the inverse Clarke transform:

$$v_a = v_\alpha$$

$$v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta$$

$$v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection and duty cycles:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta_m) - \tau_{fric}(\omega) + \tau_{dist}$$

Because the current loop is roughly 10× faster than the velocity loop, the velocity loop sees approximately $G_v(s) = \dfrac{K_t}{J s}$.
