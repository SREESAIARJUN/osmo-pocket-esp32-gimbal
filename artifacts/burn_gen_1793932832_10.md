# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the original specification for Job #14, so this design rests on the assumptions in §0. Every parameter is a named constant, so you can substitute your real values directly.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P → pole pairs `p = 7`, `R = 5.6 Ω`, `L = 2.1 mH`, `Kt ≈ 0.06 N·m/A` |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each axis |
| MCU | STM32G4 / H7 with FPU, center-aligned PWM, 3 shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI + DMA, 8 kHz ODR, shared FSYNC |
| Bus | 3S–4S (11–16.8 V) |

Loop rates:

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (d/q) | 20 kHz (in PWM ISR) | 50 µs | ~1.5 kHz |
| IMU acquisition and filtering | 8 kHz | 125 µs | — |
| Velocity (inertial rate) | 4 kHz | 250 µs | ~60–100 Hz |
| Angle (attitude) | 1 kHz | 1 ms | ~8–15 Hz |

Each outer loop has 5–10× less bandwidth than the loop inside it. This keeps the inner closed loop close to unity gain at the outer crossover frequency.
