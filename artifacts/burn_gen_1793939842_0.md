## 0. Scope and Architecture

The STM32H743 is the **flight controller** MCU running ArduPilot. It does not commutate the motors. Each motor bridge is driven by its own small ESC MCU running AM32 or BLHeli_32 (for example an STM32G071 or AT32F421). The H743 talks to each ESC MCU over one bidirectional DShot600 line. This split is assumed throughout.

```
 6S LiPo ──┬── 4× three-phase bridge (24 FETs) ── M1..M4
           │        ▲ gate drivers ▲
           │   4× ESC MCU (AM32, 48 kHz PWM)
           │        ▲ bidir DShot600 (1 wire each)
           └── 5V/3V3 BEC ── STM32H743 (ArduPilot)
```

**Placeholder values.** Every component value marked **[A]** is an assumption. Replace it with the selected part's datasheet value before release. The equations are general; the numbers illustrate the method.

## 2. Conduction Loss Model

### 2.1 Topology

The model assumes trapezoidal six-step drive with synchronous rectification, which is the AM32 "complementary PWM" mode.

- In each 60° commutation sector, two legs carry the phase current I.
- The PWM leg conducts through its high-side FET during the on-time (D) and its low-side FET during the off-time (1−D).
- The other leg's low-side FET conducts continuously for that sector.

At every instant, therefore, **exactly two FETs carry the full current I**.

### 2.2 Ripple correction

The current is not perfectly flat, so use its RMS value:

$$I_{rms}^2 = I^2\left(1+\frac{r^2}{12}\right),\qquad r=\frac{\Delta I_{pp}}{I}$$

With the motor's phase inductance at 48 kHz, r ≈ 0.1–0.2. The correction is under 0.4 %, so it is neglected below.

### 2.3 Temperature-dependent R_DS(on)

$$R_{ds}(T_j)=R_{ds25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C (the iteration target; see §4.4):

$$R_{ds}=1.2\text{ mΩ}\times(1+0.0055\times85)=1.761\text{ mΩ}$$

### 2.4 Losses

Bridge conduction loss (per motor):

$$P_{cond,bridge}=2\,I^2R_{ds}(T_j)=2\times6400\times1.761\times10^{-3}=\mathbf{22.5\ W}$$

Each FET conducts for about one-third of the electrical cycle on average, so the time-averaged loss per FET is:

$$P_{cond,FET}=\tfrac{1}{3}I^2R_{ds}= \mathbf{7.5\ W}$$

The instantaneous loss while a FET conducts is 11.3 W.

### 2.5 PCB copper loss

Copper loss comes from the battery pads, the phase pads, and the shunt. Assume 0.5 mΩ per conducting path **[A]**, for example 2 oz outer and 2 oz inner layers with the battery pour stitched in parallel:

$$P_{Cu}=I^2R_{path}=6400\times0.5\text{ mΩ}=3.2\text{ W per motor}$$

## 3. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The FET that turns on into the conducting body diode of its complement takes the V·I overlap loss. Its complement switches at near zero voltage but incurs dead-time diode loss and Q_rr loss.

### 3.1 V·I overlap loss

$$P_{VI}=\tfrac12 V_{bus} I (t_r+t_f) f_{sw}=\tfrac12(25.2)(80)(35\text{ ns})(48\text{ kHz})=\mathbf{1.69\ W}$$
