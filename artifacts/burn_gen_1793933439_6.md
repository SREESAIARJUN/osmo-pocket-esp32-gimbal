# 3‑Axis Gimbal: FOC Motor Control and Dual‑IMU Fusion

I don't have the Job #44 specification, so this design states its assumptions explicitly. Each parameter is isolated in a config struct so you can substitute the real values.

## 0. Assumed Platform and Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P, so p = 7 pole pairs. R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14‑bit absolute magnetic encoder (AS5048A / MT6701) on each axis |
| IMUs | 2 × ICM‑42688‑P on the camera plate, SPI, 8 kHz ODR, shared external clock (CLKIN) |
| Inverter | 3‑phase, center‑aligned PWM at 20 kHz, inline or low‑side shunts |

Loop rates follow a bandwidth separation of at least 5× between adjacent loops:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (in the PWM ISR) | ω_c ≈ 2π·1500 rad/s |
| Velocity | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Angle / stabilization | 1 kHz | ω_θ ≈ 2π·20 rad/s |
| IMU filtering and fusion | 8 kHz in, 1 kHz attitude out | — |

## 1. FOC Inner Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude‑invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of the same rotation matrix.

### 1.2 Plant Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$
