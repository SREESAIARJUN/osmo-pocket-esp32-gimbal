# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I have no access to the Job #20 specification. The values below are typical for a 3-axis camera gimbal. Replace the constants in `config.hpp` with your measured motor and inertia data.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC optional) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 1.8 mH, K_t ≈ 0.12 N·m/A |
| Joint encoder | 14-bit absolute (AS5048A / MT6701) over SPI, read every PWM cycle |
| Camera IMUs | 2 × ICM-42688-P on the camera stage, SPI, 8 kHz ODR |
| Kinematic order | Base → **yaw (ψ)** → **roll (φ)** → **pitch (θ)** → camera |
| Loop rates | Current/FOC 20 kHz · velocity 4 kHz · attitude/angle 1 kHz |

**Bandwidth separation.** Each loop is set roughly 5–10× slower than the loop inside it:

ω_c,i = 2π·1000 rad/s  >  ω_c,v = 2π·120 rad/s  >  ω_c,θ = 2π·20 rad/s

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

θ_e = p·(θ_m − θ_off) mod 2π

Here θ_off is found at alignment by injecting a d-axis voltage (V_d = V_align, V_q = 0) and reading the encoder.

### 1.2 Clarke and Park transforms

The Clarke transform is amplitude-invariant and assumes i_a + i_b + i_c = 0:

i_α = i_a,  i_β = (i_a + 2 i_b)/√3

The Park transform rotates into the rotor frame:

i_d = i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ
