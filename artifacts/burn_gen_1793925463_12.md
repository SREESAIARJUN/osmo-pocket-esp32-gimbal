# STM32H743 Nano FC + 80 A 4-in-1 ESC (Job #16): Systems Architecture

This document covers four areas: the thermal and electrical loss model, ArduPilot bi-directional DShot600 timer and DMA allocation, the schematic netlists, and the design verdicts.

**Engineering assumptions.** Where real datasheet values are needed, I use stated *representative* parameters for a 60 V, 5×6 mm PQFN MOSFET. Substitute the selected part's datasheet values before tape-out. The equations are exact. The numbers are only as good as the inputs.

---

## 0. System Partitioning (Clarifying the Architecture)

| Domain | Silicon | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz, LQFP100) | ArduPilot. Generates DShot600 and decodes the bidirectional eRPM telemetry. |
| ESC (×4 channels) | 4× STM32G071 / AT32F421 running AM32 (or BLHeli_32) | Commutation and **48 kHz PWM generation** |
| Power stage (×4) | 3-phase half-bridge driver (FD6288Q-class) + 6× N-FET per motor | Power conversion |

The 48 kHz switching frequency is an **ESC firmware parameter** (AM32 `PWM frequency`). It is not set by the H743. The H743's only hard-real-time obligation to the power stage is DShot framing and telemetry capture.
