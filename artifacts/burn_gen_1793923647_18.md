**Critical finding:** 80A per motor burst is thermally infeasible on a 20×20 mm "nano" board for more than about 1–2 seconds. The derivation below shows why and gives a defensible rating.

## 0. Architecture and Assumptions

### System partition

On a 4-in-1 AIO, the STM32H743 does not commutate the motors. It runs ArduPilot and sends DShot600 to four ESC MCUs. Each ESC MCU (for example AT32F421 or STM32G071 running AM32) does the 48 kHz PWM and commutation, and returns eRPM telemetry over the same wire.

```
           ┌──────────────── STM32H743 (ArduPilot) ────────────────┐
 IMU/SPI ──┤  TIM1 CH1..CH4 ── DShot600 out / GCR eRPM in (BDShot) ├──┐
           └────────────────────────────────────────────────────────┘  │ 4× single-wire
   ┌───────────────┬───────────────┬───────────────┬───────────────┐   │
   │ ESC MCU 1     │ ESC MCU 2     │ ESC MCU 3     │ ESC MCU 4     │◄──┘
   │ 48 kHz 6-step │ ...           │ ...           │ ...           │
   │ 3-ph predrv   │               │               │               │
   │ 6× MOSFET     │ 6× MOSFET     │ 6× MOSFET     │ 6× MOSFET     │
   └───────────────┴───────────────┴───────────────┴───────────────┘
```

## 1. Conduction Loss Model

### 1.1 Six-step conduction topology

In each 60° electrical sector, exactly two phase legs carry the phase current I:

- One leg is PWM'd with duty D. Its high-side FET conducts for D, and its low-side FET (synchronous rectifier) conducts for 1−D.
- One leg has its low-side FET held fully on.

The RMS-squared current in the PWM'd leg is D·I² + (1−D)·I² = I². Dead time is ignored here because it appears separately in §2.4.

The per-motor conduction loss is therefore independent of duty:

$$P_{cond}=2\,I^2\,R_{ds}(T_j),\qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

### 1.2 Electro-thermal fixed point

R_ds depends on T_j, and T_j depends on loss. With a lumped junction-to-ambient resistance θ, the junction temperature is:

$$T_j=T_a+\theta\cdot 2I^2R_{ds,25}[1+\alpha(T_j-25)]
\;\Rightarrow\;
T_j=\frac{T_a+2I^2R_{ds,25}\,\theta\,(1-25\alpha)}{1-2I^2R_{ds,25}\,\theta\,\alpha}$$
