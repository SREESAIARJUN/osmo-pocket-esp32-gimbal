## 1. Timing Architecture

```
20 kHz  ADC ISR  ─► Encoder read ─► Clarke/Park ─► PI(id,iq) ─► invPark ─► SVPWM
                       │
 4 kHz  (÷5)       Velocity PI  ◄── gyro rate (fused, notched)   + cogging FF + accel FF
                       │
 1 kHz  (÷20)      Angle P/PI   ◄── attitude (Mahony on fused IMU)
 8 kHz  IMU DRDY   ─► Dual IMU read ─► align ─► notch/LPF ─► fuse ─► FIFO to 4 kHz/1 kHz
```

**Bandwidth separation.** Choose ω_c : ω_v : ω_θ ≈ 10 : 1 : 0.25.

With the assumed motor, the current loop runs at f_bw,c ≈ 1.5 kHz, so the velocity loop gets f_bw,v ≈ 120 Hz and the angle loop f_bw,θ ≈ 30 Hz.

## 2. Field-Oriented Current Control

### 2.1 Transforms (amplitude-invariant)

**Clarke transform:**

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(\text{assuming } i_a+i_b+i_c=0)
$$

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
