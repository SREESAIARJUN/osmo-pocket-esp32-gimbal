## 1. FOC Current Loop

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{0}) \mod 2\pi$$
Here θ₀ is the encoder offset. It is found at calibration by applying `V_d` at θ_e = 0 and reading θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model and PI design (pole-zero cancellation)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first order with bandwidth ω_c:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With the assumed values: K_p = 0.0018·9425 ≈ 17 V/A and K_i ≈ 52 800 V/(A·s).

**Feedforward decoupling** (added to the PI outputs):
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\qquad \lambda_m = \frac{2K_t}{3p}$$

### 1.5 Voltage limiting
Use a circular limit with q-axis priority:
$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max}\quad(m_{max}\approx0.95)$$
$$v_d \leftarrow \mathrm{clamp}(v_d, \pm V_{max}),\qquad v_q \leftarrow \mathrm{clamp}\!\left(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

The difference between the unsaturated and saturated voltage drives anti-windup (see §2.2).

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM, but it has no branching.

### 1.7 Delay compensation
The PWM update lands about 1.5 T_s after sampling. Advance the angle for the inverse Park only:
$$\theta_e^{out} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure
```
θ_ref ─►[Angle P(+I)]─ω_ref─►(+ω_ff)─►[Velocity PI + D-filt]─τ_ref─►(+τ_cog_ff)─► /Kt ─► i_q,ref ─►[FOC]
            ▲                                ▲
       θ_cam (IMU fused)          ω_cam (fused gyro, joint frame)
```
For stabilization, the outer loops must be closed on inertial camera attitude and rate from the IMUs. The encoder is used only for commutation, and as a fallback velocity source.

**Mapping inertial rate to joint rate.** For a yaw-roll-pitch gimbal, the camera angular velocity is ω = J_g(q)·q̇. Each axis loop uses the component of the fused gyro rate along that motor's axis, expressed in the camera frame. To first order (small cross-axis angles), pitch uses ω_y, roll uses ω_x, and yaw uses ω_z·cos(pitch)/cos(roll). The general solution is
$$\dot q = J_g^{-1}\,\omega_{cam}$$
