## 0. Assumptions and Feasibility Flags

I have no prior Job #10 documentation, so this design rests on the assumptions below. Every equation is parametric, so you can substitute datasheet values for your actual parts.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (22.2 V nominal) |
| Topology | All-in-one board: H743 runs ArduPilot. Four AT32F421 ESC MCUs run AM32 (bidir-DShot capable). Each channel uses a 6-FET bridge. |
| PWM | 48 kHz, complementary (synchronous rectification), dead time t_dt = 100 ns |
| MOSFET | Representative 40 V, R_DS(on) = 1.0 mΩ typ / 1.2 mΩ max at 25 °C, PDFN 5×6, Q_g ≈ 50 nC, Q_gd ≈ 12 nC, Q_rr ≈ 40 nC, Q_oss ≈ 45 nC, R_θJC ≈ 0.8 K/W |
| Gate driver | FD6288Q-class 3-phase driver, ~1.0 A source / 1.5
