# Job #60: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

**Assumptions.** I don't have the Job #60 hardware spec, so this design uses the following baseline. Every assumption is a named constant in the code, so you can change it there.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at the PWM midpoint |
| Motors | Gimbal BLDC (GBM2804-class): 12N14P, so p = 7 pole pairs, R ≈ 5 Ω, L ≈ 2 mH |
| Encoders | 14-bit absolute magnetic encoder (AS5048A/MT6701) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, on-chip AAF enabled |
| Loop rates | Current/FOC 20 kHz, velocity 4 kHz, attitude 1 kHz |
