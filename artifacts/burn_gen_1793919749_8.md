# Job #44: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

**Assumptions to confirm.** I don't have the Job #44 specification, so this design uses these representative parameters. Every one is a named constant in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: Cortex-M4F/M7, single-precision FPU, 3-phase advanced timer, injected ADC |
| Motors | 3× GBM2804-class gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| Current sensing | 2-shunt low-side (a voltage-mode fallback is given for boards without it) |

| Kinematic order | Yaw (outer, base) → Roll → Pitch (inner, camera) |

**Loop rates and bandwidths.** The rule used throughout is a bandwidth separation of at least 5× between cascaded loops.

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM / current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| IMU sampling + filtering | 8 kHz | — |
| Velocity (rate) | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle (attitude) + fusion | 1 kHz | ω_p ≈ 2π·25 rad/s |
| Cogging adaptation | 4 kHz (gated) | slow, τ ≈ seconds |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Coordinate transforms
The electrical angle is θ_e = p·(θ_m − θ_offset), where p = 7 pole pairs.

**Clarke transform (amplitude-invariant, 2 shunts, i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
