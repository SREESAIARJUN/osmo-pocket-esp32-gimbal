## 0. System Architecture and Design Assumptions

### 0.1 Architectural Clarification

In ArduPilot, the STM32H743 **does not commutate the motors**. It generates DShot frames and decodes bidirectional eRPM telemetry. Each motor channel on the 4-in-1 ESC has its own small MCU running AM32 or BLHeli_32, which handles:
- commutation,
- the 48 kHz PWM, and
- the gate driver.

The partitioning therefore looks like this:

```
             ┌──────────── FC section (STM32H743) ────────────┐
 VBAT ──┬──► │ 5V/3V3 bucks, IMU, Baro, OSD, RX, GPS, SD/Flash │
        │    │ TIM1 CH1..CH4 ──► DShot600 bidir (1 wire/motor) │
        │    └──────────────┬─────────────────────────────────┘
        │                   │ M1..M4 signal, CURR, VBAT_SENSE
        │    ┌──────────────▼── ESC section (×4 channels) ─────┐
        └──► │ ESC MCU (AM32) → 3-ph gate driver → 6× N-FET    │
             │ 48 kHz complementary PWM, sync. rectification   │
             └─────────────────────────────────────────────────┘
```

## 1. Conduction Loss Model

### 1.1 Current Path Under Complementary 6-Step PWM

With synchronous rectification, at any instant the motor current flows through **exactly two FETs in series**:
- **ON-state:** one high-side FET plus one low-side FET (opposite phase).
- **Freewheel:** the complementary low-side FET (replacing the high-side) plus the same low-side FET.

So the instantaneous conduction loss is independent of duty cycle D, as long as dead-time intervals are ignored (those are handled in §2):

$$
P_{cond,motor} = 2\,I^2\,R_{ds(on)}(T_j)
$$

The temperature dependence of on-resistance is:

$$
R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}
$$

### 1.2 Per-FET Distribution

Over one electrical revolution, each phase leg is active for 2/3 of the cycle, so loss spreads across all 6 FETs. Within the leg being PWM'd:

- High-side conduction: $P_{HS} = D\,I^2 R$
- Low-side conduction: $P_{LS} = (1-D)\,I^2 R$
