## 1. FOC Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

Here θ_offset is found at startup: inject V_d along α (θ_e = 0), wait for the rotor to settle, then read the encoder.

### 1.2 Clarke transform (two shunts, balanced currents)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 dq plant model (SPMSM)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 Current PI with pole-zero cancellation and decoupling

Choose the closed-loop bandwidth ω_c, typically 2π·1.5 kHz, which must be ≤ f_PWM/10:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The controller zero K_i/K_p = R/L cancels the electrical pole, leaving a first-order closed loop:

$$\frac{i_q}{i_q^*}=\frac{\omega_c}{s+\omega_c}$$

Decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d+\hat\lambda_m)$$

### 1.6 Voltage-mode fallback (no current sensing)

$$v_q^* = R\,i_q^* + \hat\omega_e\hat\lambda_m,\qquad v_d^*=0$$

### 1.7 Voltage limiting (circular, d-axis priority)

$$|v_d^*| \le V_{max} = \frac{V_{dc}}{\sqrt3}$$
$$|v_q^*| \le \sqrt{V_{max}^2 - v_d^{*2}}$$

### 1.8 Inverse Park and SVPWM

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

SVPWM via min/max zero-sequence injection (equivalent to 7-segment SVM):

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

## 2. Cascaded Angle / Velocity Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t\,i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Because the current loop is about 10× faster, the velocity loop sees the plant

$$\frac{\omega}{i_q^*}\approx\frac{K_t}{Js}$$
