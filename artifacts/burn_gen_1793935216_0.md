# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #18, so this design rests on the assumptions in §0. Every equation is parameterized, so you can substitute your real values. The items most likely to differ are the slot/pole count, the encoder, and the MCU.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (GBM2804-class), pole pairs `p = 7`, `R ≈ 5–10 Ω`, `L ≈ 2–4 mH` |
| Joint encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2-shunt low-side, synchronous to PWM center |
| MCU | STM32G4 / H7 class, single-precision FPU |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR |
| Gimbal order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → camera |

**Rate hierarchy.** Each loop has roughly 5–10× bandwidth separation from the next:

```
PWM / ADC / current PI .......... 20 kHz   (ωc ≈ 2π·1500 rad/s)
IMU sample + filtering .......... 8 kHz
Velocity PI (+ cogging FF) ...... 4 kHz    (ωv ≈ 2π·150 rad/s)
Attitude fusion + angle loop .... 1 kHz    (ωθ ≈ 2π·20  rad/s)
```

**Control flow.** In the loop below, ω̂ is velocity feedback blended from the encoder and the gyro:

```
 q_ref ─► [Attitude error → joint-space (J⁻¹)] ─► θ_ref,j
            ┌───────────────────────────────────────────────┐
 θ_ref ─►(+)─► Angle P(+FF) ─► ω_ref ─►(+)─► Velocity PI ─►(+)─► iq_ref ─► Current PI ─► SVPWM
          ▲−                          ▲−                   ▲ iq_cog,ff
          θ̂ (fused)                   ω̂                   Anti-cogging
```

## 1. Field-Oriented Control

### 1.1 Transforms

The electrical angle is computed from the mechanical angle with a calibrated offset:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
