## 1. Timing Architecture

```
 20 kHz  ADC trigger (PWM center) → Clarke/Park → current PI → SVPWM       [ISR, ~6 µs]
  8 kHz  IMU DRDY → dual-IMU fusion → notch/LPF → gyro rate ω_cam          [ISR]
  4 kHz  velocity PI (+cogging FF, +accel FF)  → i_q*                      [every 5th FOC tick]
  1 kHz  attitude filter (Mahony) → angle P(+I) → ω*                       [every 8th IMU tick]
```

Each loop's bandwidth is at least 4–5× below the loop inside it, which makes the cascade separable for design. Typical closed-loop bandwidths:

- Current: 1.5–2 kHz
- Velocity: 150–300 Hz
- Angle: 30–60 Hz

## 2. FOC Equations

### 2.1 Clarke and Park transforms (amplitude-invariant)

With i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad \theta_e = p\,\theta_m - \theta_{\text{off}}$$

θ_off is the encoder-to-rotor offset, found at calibration by aligning the rotor with a d-axis voltage.

### 2.2 PMSM model in dq coordinates

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\,\lambda_m i_q = K_t i_q \qquad (\text{surface PM, } L_d = L_q)$$
