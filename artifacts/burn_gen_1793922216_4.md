## 1. Control Architecture

```
            1 kHz                     4 kHz                       20 kHz
 q_ref ─►[Attitude P + FF]─► ω_ref ─►[Velocity PI]─► i_q* ─┬─►[Current PI d/q]─►[SVPWM]─► Motor
   ▲                  ▲                    ▲               │          ▲
   │                  │ ω_base FF          │ ω̂ (PLL)       │          │ i_a,i_b (ADC)
   │                  │                    │               │          │
 [Mahony AHRS]◄─[Dual-IMU fusion + notch/LPF]   [Encoder PLL]     [Clarke/Park]
                                                    │
                                     [Anti-cogging FF] ──► + i_q,ff(θ_m)
```

The design uses three nested loops with bandwidth separation of at least 4×:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current loop | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity loop | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Attitude loop | 1 kHz | ω_a ≈ 2π·25 rad/s |

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):**

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

**Park transform.** The electrical angle is θ_e = p·(θ_m − θ_off), where p is the number of pole pairs.

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park** applies the transpose of the same rotation matrix.

### 2.2 Plant and PI Design (Pole–Zero Cancellation)

The dq-frame voltage equations are:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

**Decoupling.** Add the feedforward terms below so that each axis reduces to G(s) = 1/(Ls + R):

$$
v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)
$$

**PI gains.** With C(s) = K_p + K_i/s, choosing K_i/K_p = R/L cancels the plant pole. The closed loop then becomes the first-order system ω_c/(s + ω_c):

$$
\boxed{K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c}
$$

**Delay limit.** The digital delay is roughly 1.5·T_s (computation plus PWM hold). Keep ω_c ≤ 1/(4 · 1.5 · T_s) to preserve about 60° of phase margin. At 20 kHz this gives ω_c ≈ 2π·530 Hz as a conservative limit, and up to about 2π·1.5 kHz is achievable with careful timing.

**Discretization.** The integrator uses a trapezoidal (bilinear) rule:

$$
I_k = I_{k-1} + K_i\,\tfrac{T_s}{2}\,(e_k + e_{k-1})
$$

**Anti-windup (back-calculation):**

$$
I_k \leftarrow I_k + K_{aw}\,T_s\,(u_{sat} - u_{unsat}),\qquad K_{aw}\approx K_i/K_p
$$

**Voltage limiting.** The voltage vector is limited circularly. Inside the SVPWM linear region, |v| ≤ V_bus/√3. d-axis priority is given:

$$
v_d \leftarrow \text{clamp}(v_d, \pm V_{max}),\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2}
$$

### 2.3 SVPWM (Min/Max Zero-Sequence Injection)

$$
v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12(\max(v_{abc}) + \min(v_{abc})),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}
$$
