# STM32H743 Nano FC + 4-in-1 ESC: Power Stage, Thermal, and Bi-Directional DShot Design Model

## 0. Scope, Assumptions, and Headline Findings

**Architecture.** Bi-directional DShot needs an ESC MCU to run commutation and return eRPM telemetry, so the system is split:

- **FC:** STM32H743, running ArduPilot. It generates DShot600 and captures the GCR telemetry replies.
- **ESC:** 4× AT32F421 (or STM32G071), running AM32 or BLHeli_32. Each drives a 3-phase bridge through an FD6288Q-class gate driver.
