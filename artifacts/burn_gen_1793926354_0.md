# 3-Axis Gimbal Motor Control and IMU Fusion: Cascaded FOC, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

## 0. Assumptions

I don't have the Job #49 specification, so this design uses typical brushless gimbal parameters. Every value is a named constant, so you can substitute yours.

| Parameter | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) |
| PWM / current loop | 20 kHz, center-aligned, ADC sampled at PWM center |
| Velocity loop | 4 kHz (every 5th current-loop tick) |
| Angle loop + attitude | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro ODR 8 kHz, ±2000 dps, accel ±16 g |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

Rates follow a ≥5× bandwidth separation per cascade stage.

## 1. Field-Oriented Control: Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, where θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform**:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = Ri_d + L\dot i_d - \omega_e L i_q$$

$$v_q = Ri_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 PI with decoupling and back-EMF feedforward

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning.** Choose the gains so the PI zero cancels the electrical pole R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes first order:

$$\frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≈ 2π·1.5 kHz, which is less than or equal to f_PWM/10 after accounting for the 1.5-sample delay.

**Discrete form.** Use forward Euler for the integrator, with T_s = 50 µs:

$$x_{k+1} = x_k + K_iT_s e_k$$

$$u_k = K_pe_k + x_k$$

### 1.4 Voltage limiting

The dq voltage vector is limited to the inscribed circle of the SVPWM hexagon, |v| ≤ V_dc/√3. The d-axis has priority:

$$v_d \leftarrow \mathrm{sat}(v_d,\pm V_{max}),\qquad v_q \leftarrow \mathrm{sat}\!\left(v_q,\pm\sqrt{V_{max}^2-v_d^2}\right)$$

**Anti-windup by back-calculation:**

$$x_{k+1}=x_k+T_s\left[K_ie_k + K_{aw}(u_{sat}-u)\right],\qquad K_{aw}\approx K_i/K_p$$

### 1.5 SVPWM (min–max zero-sequence injection)

This is mathematically equivalent to sector-based SVPWM:

$$v_a=v_\alpha,\quad v_b=-\tfrac12v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0=-\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right)$$

$$D_x=\tfrac12+\frac{v_x+v_0}{V_{dc}}$$

### 1.6 Delay compensation

PWM updates one period late, so the angle used in the inverse Park transform is advanced:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Angle → Velocity → Current Control

```
θ_ref ──►[ P + vel FF ]──ω*──►[ PI + accel FF ]──i_q*──►[ FOC PI ]──► motor
           ▲ θ (IMU att.)        ▲ ω (IMU gyro / enc PLL)    ▲ i_q
                                             + i_cog_ff(θ_m)  (Sec. 3)
```

### 2.1 Feedback sources for a gimbal

- **Outer loop.** The angle error is the camera attitude error from the fused IMU (Section 4), projected onto each motor axis using the joint Jacobian. For a yaw-roll-pitch gimbal at small angles, the error components map directly to the axes.
- **Velocity loop.** The feedback blends the IMU gyro rate (inertial, which is what you want to stabilize) with the encoder rate (relative, with a clean low-frequency response):

$$\omega_{fb}=\underbrace{\mathrm{HPF}(\omega_{gyro,axis})}_{\text{inertial}}+\underbrace{\mathrm{LPF}(\omega_{enc})}_{\text{relative}}$$

In practice, for pure stabilization, use gyro rate on the velocity loop. Use the encoder only for the current-loop electrical angle and for anti-cogging.

### 2.2 Encoder velocity: type-II PLL

A PLL gives a smooth velocity estimate without the quantization noise of differentiating the encoder:

$$e=\mathrm{wrap}(\theta_{meas}-\hat\theta)$$

$$\hat\omega \mathrel{+}= K_{i,pll}T_s\,e$$

$$\hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}\,e)$$

Choose K_p = 2ζω_n and K_i = ω_n², with ω_n ≈ 2π·300 Hz and ζ = 0.707.

### 2.3 Angle loop: P with feedforward

$$\omega^* = K_{\theta}\,\mathrm{wrap}(\theta^*-\theta) + \dot\theta^*_{traj}$$

$$\omega^* \leftarrow \mathrm{sat}(\omega^*, \pm\omega_{max})$$

Choose K_θ ≈ ω_vel / 4 to 6. An integrator is not needed, because the velocity PI removes steady-state torque disturbances.
