# STM32H743 Nano FC + 4-in-1 ESC: 80 A Burst Electro-Thermal Model and BDShot600 DMA Plan (Job #2)

## 0. Scope and Baseline Assumptions

No design inputs (MOSFET part, board size, stack-up, battery) were supplied for Job #2. I fixed a representative baseline so every number below can be traced. Replace the parameters in Table 0 with the real BOM values and the equations still hold.

**Architecture.** An STM32H743 cannot practically commutate 4 BLDC motors and run ArduPilot at the same time. The standard and correct split is:

- **FC MCU:** STM32H743VIT6 running ArduPilot. It sends bidirectional DShot600 to the ESC.
- **ESC MCUs:** 4× AT32F421 (or STM32G071) running AM32 or BLHeli_32. Each has its own 48 kHz PWM and one FD6288Q 3-phase gate driver.
- **Power stage:** 24 N-MOSFETs in 6 per motor (3 half-bridges).

## 1. Conduction Loss Model

### 1.1 Current path (6-step trapezoidal with synchronous rectification)

During any commutation sector, two phases carry I_ph:

- **PWM leg:** current flows in the high-side FET for D·T_sw and in the low-side FET for (1−D)·T_sw. The current is never interrupted, so this leg always presents one R_DS(on).
- **Static leg:** the low-side FET is fully on.

The conduction loss per motor is therefore independent of duty cycle (dead time handled separately):

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence

R_DS(on) rises with junction temperature:

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha_R (T_j-25)]$$

T_j itself depends on the loss, so the two must be solved together (fixed-point iteration):

$$T_j^{(n+1)} = T_{ref} + R_{\theta}\,P\!\left(R_{DS(on)}(T_j^{(n)})\right)$$

At T_j = 125 °C:

- R_DS(on) = 1.0 × 1.5 = **1.5 mΩ**
- P_cond,motor = 2 × 6400 × 1.5 m = **19.2 W**
- At 25 °C (cold start of the burst): 12.8 W

### 1.3 Per-FET distribution

Each FET is "static-on" in 2 of 6 sectors and PWM-active in 2 of 6 sectors.
