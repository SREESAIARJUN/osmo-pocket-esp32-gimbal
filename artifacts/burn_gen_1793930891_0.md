## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle, with zero offset $\theta_0$ found at commissioning:

$$\theta_e = p(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (power-variant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI design (pole–zero cancellation)

The motor model in the dq frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With cross-coupling and back-EMF feedforward, each axis reduces to $G(s)=1/(Ls+R)$. A PI controller $C(s)=K_p + K_i/s$ with $K_i/K_p = R/L$ cancels the plant pole. The closed loop then becomes first-order with bandwidth $\omega_c$:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}$$

For 20 kHz PWM: $\omega_c = 2\pi\cdot 1500 \Rightarrow K_p=19.8\,$V/A, $K_i=52{,}800\,$V/(A·s).

Decoupled voltage commands:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Voltage limiting and SVPWM

Circular limit: if $|v|=\sqrt{v_d^2+v_q^2}>V_{max}=V_{bus}/\sqrt3$, then $d$ takes priority and $q$ gets the remainder:

$$v_q \leftarrow \operatorname{sgn}(v_q)\sqrt{V_{max}^2-v_d^2}$$

Inverse Park, then min-max zero-sequence injection (equivalent to SVPWM):

$$v_{a,b,c}\ \text{from}\ (v_\alpha,v_\beta),\qquad v_0=-\tfrac12(\max+\min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 1.4 Discrete PI with back-calculation anti-windup

Discretization uses backward Euler at $T_s$:

$$u_k = K_p e_k + I_k,\quad \bar u_k=\text{sat}(u_k),\quad I_{k+1}=I_k + K_iT_s e_k + K_{aw}T_s(\bar u_k-u_k),\quad K_{aw}=\frac{K_i}{K_p}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

Because the current loop is roughly 7× faster, it is treated as unity gain.

### 2.2 Velocity loop (5 kHz)

Use PI with symmetric-optimum-style placement. Crossover is $\omega_v$; the PI zero sits at $\omega_v/a$ (with $a=4$):

$$K_{p,v}=\frac{J\omega_v}{K_t},\qquad K_{i,v}=K_{p,v}\frac{\omega_v}{a}$$

Velocity estimate: a PLL/tracking observer on encoder angle. This beats the noisy $\Delta\theta/T$ derivative:

$$e=\text{wrap}(\theta_{enc}-\hat\theta),\qquad \dot{\hat\omega}=k_i e,\qquad \dot{\hat\theta}=\hat\omega + k_p e$$

with $k_p=2\zeta\omega_{pll}$, $k_i=\omega_{pll}^2$, $\omega_{pll}\approx 3\omega_v$.
