# 3-Axis Gimbal: FOC Motor Control, Cascaded PID, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original specification for Job #30, so this design states its assumptions explicitly. Every parameter is collected in one config block so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH (phase), K_t = 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A class), SPI, sampled each PWM period |
| Inverter | Vdc = 12 V (3S/4S), center-aligned PWM 20 kHz, 3-shunt or 2-shunt sensing |
| Current loop | 20 kHz, bandwidth ≈ 2 kHz |
| Velocity loop | 4 kHz, bandwidth ≈ 150–200 Hz |
| Attitude loop | 1 kHz, bandwidth ≈ 30–40 Hz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro/accel ODR 8 kHz |
| Kinematic order | Yaw (base) → Roll → Pitch (camera) |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with single-precision FPU |
