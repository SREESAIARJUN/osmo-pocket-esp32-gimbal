# STM32H743 Nano FC + 80A 4-in-1 ESC: Power-Stage Loss Model, Thermal Budget, and Bi-Directional DShot600 DMA Architecture

## 0. Scope and Assumptions

I don't have the Job #6 BOM, so this model uses an explicit reference parameter set. Every equation is parametric, so you can substitute your actual MOSFET and driver datasheet values.

**System architecture.** The H743 is the flight controller only. Each 4-in-1 ESC channel runs on its own ESC MCU (AM32 or BLHeli_32 class, for example AT32F421 or STM32G071), which generates the 48 kHz PWM. The H743 sends bi-directional DShot600 and receives eRPM over the same wire.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R = 0.70 × 1.45 = **1.015 mΩ**.

### 1.2 Current path in 6-step commutation with synchronous rectification

In every 60° sector, current flows through exactly **two** conducting switches:
- On the PWM leg, either the high side (for duty fraction D) or the complementary low side (for 1−D).
- On the sinking leg, the low side conducts for the full sector.

So the instantaneous conduction loss per channel is independent of D:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j) = 2(80)^2(1.015\times10^{-3}) = \mathbf{13.0\ W}$$

### 1.3 Per-FET distribution

Over one electrical cycle, each phase is high-driven for 120°, low-sinking for 120°, and floating for 120°.

$$P_{HS} = \frac{I^2R}{3}\,D,\qquad P_{LS} = \frac{I^2R}{3}\,(1 + (1-D))\cdot\tfrac{1}{1}\Big|_{\text{sink}}\ \to\ \frac{I^2R}{3}(2-D)\ \text{(normalised)}$$

The low-side FET is always the hottest. Its worst case is at D = 1 (full-throttle burst), where HS and LS each carry I²R/3:

$$P_{FET,max} \approx \frac{6400 \times 1.015\text{ m}\Omega}{3} \approx \mathbf{2.17\ W}\ \text{(LS, D≈1)};\quad 2.17\times(2-D)\ \text{scaling at part throttle}$$

Note that at D < 1 the low side also picks up freewheel conduction. At D = 0.5 with 80 A (a stall or heavy-prop condition), the LS reaches about 3.2 W.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches, with one turn-on and one turn-off per PWM period.

### 2.1 Gate currents and transition times

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,on}} = \frac{7.5}{10} = 0.75\text{ A},\qquad I_{g,off} = \frac{V_{pl}}{R_{g,off}} = 0.90\text{ A}$$
