# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #49): Design Model

## 0. Architecture and Assumptions

**ArduPilot does not commutate motors.** The STM32H743 runs ArduPilot as the flight controller. Commutation and the 48 kHz PWM run on four ESC MCUs (one per channel) using AM32 firmware, for example on an AT32F421. Some 4-in-1 boards use a single ESC MCU; that design is not used here.

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)]$$

At the design junction temperature T_j = 110 °C:

$$R_{DS}(110) = 0.75 \times (1 + 0.005 \times 85) = 1.07\ \text{m}\Omega$$

The temperature and loss are coupled. Solve them iteratively (see §3.4).

### 1.2 Current path in 6-step synchronous mode

During any 60° sector, two legs are active:

- **PWM leg:** the high-side FET conducts for D·T_sw. The low-side FET synchronously rectifies for (1−D)·T_sw.
- **Return leg:** the low-side FET is held on for the whole sector.

So exactly two FETs carry the phase current I at every instant, ignoring dead time.

$$P_{cond,ch} = 2\,I^2 R_{DS}(T_j) + I^2 R_{Cu}$$

### 1.3 Copper path

The path runs from the bus plane through the FET, phase pad, and FET to the ground plane. It has 8 layers in parallel with via transitions. Estimated R_Cu ≈ 0.30 mΩ per channel.
