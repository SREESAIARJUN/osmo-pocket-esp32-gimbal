# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #47 specification, so this design uses an explicit, typical baseline. Replace the numbers in `Params` with your measured values. Every gain below is derived from those parameters, so the equations still hold when the numbers change.

## 0. Baseline Assumptions

| Item | Value (example: GBM2804-class gimbal motor) |
|---|---|
| Motor | 12N14P → pole pairs `p = 7`, slots `Ns = 12` |
| R, L (phase) | 10 Ω, 2.0 mH |
| Kt | 0.08 N·m/A |
| Load inertia J | 2.0e-4 kg·m² (motor + camera about the axis) |
| Vbus | 12 V |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), read in the current ISR |
| Current sense | 3-shunt or 2-shunt, sampled at the PWM centre |
| IMUs | 2× ICM-42688-P on the camera platform, 8 kHz ODR, SPI + FIFO |

**Loop rates**

| Loop | Rate | Bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~2 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~30 Hz |
| IMU fusion | 8 kHz in, 4 kHz out | — |

The bandwidth separation between nested loops is at least 4–10×.

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke (amplitude-invariant):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)$$

**Park,** with electrical angle $\theta_e = p\,(\theta_m - \theta_{off})$:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park with delay compensation.** Computation plus PWM update cause a delay of about 1.5 Tₛ. The modulation angle is therefore advanced:

$$\theta_e^{mod} = \theta_e + 1.5\,T_s\,\omega_e$$
