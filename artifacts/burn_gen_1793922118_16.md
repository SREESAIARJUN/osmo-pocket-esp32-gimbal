**Critical architecture flags (read before layout):**

1. **Size versus current.** Twenty-four 5×6 mm FETs plus drivers will not fit a 20×20 "nano" board. Realistic 80A-burst 4-in-1s are 30.5×30.5 mm mount (about 40×45 mm board). If you are forced to a smaller footprint (3.3×3.3 FETs), R_DS(on) roughly triples and the burst window collapses, as shown in §1.6.
2. **The 48 kHz PWM is ESC-MCU firmware.** The H743 only generates DShot frames and decodes eRPM telemetry.
3. **The "80A" rating is a burst figure.** It is thermally sustainable only for seconds; the derivation follows.

## 1. Power-Stage Loss Model (per ESC channel)

### 1.1 Conduction topology

In 6-step synchronous mode, at any instant:
- **Leg A (PWM leg):** HS conducts for fraction D and LS (sync rect) for 1–D, so effective conduction is 1 × R.
- **Leg B (static leg):** LS conducts for 100%.

Therefore:

$$P_{cond} = I^2 R_{DS}(T_j)\,[D + (1-D)] + I^2 R_{DS}(T_j) = 2\,I^2 R_{DS}(T_j)$$

This result is independent of throttle duty, which is a useful property of synchronous mode.

### 1.2 Temperature dependence of R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At the design point T_j = 125 °C: R = 0.9 mΩ × 1.45 = **1.305 mΩ**

$$P_{cond} = 2 \times 80^2 \times 1.305\times10^{-3} = \mathbf{16.7\ W}$$

Because this loss rises with T_j, solve it self-consistently (§1.6). There is a thermal-runaway condition if dP/dT_j × Z_th ≥ 1.

### 1.3 Switching (V–I overlap) loss at 48 kHz

The gate current during the Miller plateau, with R_g,tot = R_drv + R_g,ext + R_g,int ≈ 2 + 2.2 + 1 = 5.2 Ω and V_drv = 10 V (after the driver's drop from 12 V):

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,tot}} = \frac{6.5}{5.2} = 1.25\ \text{A}, \qquad I_{g,off} = \frac{V_{pl}}{R_{g,tot}} = 0.67\ \text{A}$$

The transition times are:

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{13\ \text{nC}}{1.25} = 10.4\ \text{ns},\qquad t_{off} = \frac{13\ \text{nC}}{0.67} = 19.4\ \text{ns}$$
