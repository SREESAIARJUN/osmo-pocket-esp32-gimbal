# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have your Job #32 specification, so the design below rests on stated assumptions. Every numeric value is a parameter you can change. The equations and code hold for any PMSM/BLDC gimbal motor.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class with single-precision FPU and center-aligned TIM1/TIM8 PWM |
| Motors | 12N14P gimbal BLDC (GBM2804 class): p = 7 pole pairs, R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) over SPI |
| IMUs | 2 × ICM-42688-P over separate SPI buses. **IMU_P** is on the camera payload and provides feedback. **IMU_B** is on the handle/base and provides disturbance feedforward plus cross-check. |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Payload |

### Loop rates

| Loop | Rate | Ts | Closed-loop bandwidth |
|---|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs | ~1.5 kHz |
| Velocity | 4 kHz | 250 µs | ~150 Hz |
| Angle / attitude | 1 kHz | 1 ms | ~25 Hz |
| IMU ODR (gyro + accel) | 8 kHz, decimated to 4 kHz/1 kHz | — | — |
| Cogging LMS | 4 kHz (inside velocity ISR) | — | slow adaptation |

The bandwidth separation is about 10× between the current and velocity loops and about 6× between the velocity and angle loops. That separation is what justifies designing each loop independently.

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform** (θ_e = p·θ_m − θ_offset):

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant (SPM, L_d = L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$
