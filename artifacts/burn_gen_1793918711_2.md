# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Fusion

**Assumptions (Job #56 parameters were not supplied):** These are typical values for a camera gimbal. Each value is marked as a parameter in the code, so replace it with your measured data.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase with 2 or 3 low-side shunts (current-mode FOC); a voltage-mode fallback is given |
| Encoder | 14-bit absolute magnetic (AS5048A or MA730), one per joint |
| IMUs | 2 × ICM-42688-P on the camera plate (SPI, 8 kHz ODR, ±2000 dps, ±16 g) |
| MCU | Cortex-M4F/M7 (STM32G4/H7) with single-precision FPU |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

## 1. Timing Architecture

| Loop | Rate | Feedback | Output |
|---|---|---|---|
| Current (FOC) | f_c = 20 kHz (PWM-synchronous ADC ISR) | i_a, i_b, θ_e (encoder) | v_αβ → SVPWM |
| Velocity (inertial rate) | f_v = 4 kHz | fused gyro mapped to joints | i_q* |
| Angle (attitude) | f_θ = 1 kHz | fused quaternion q̂ | ω_c* |
| IMU sampling and filtering | 8 kHz (FIFO, read at 4 kHz × 2 samples) | — | ω, a |
| Anti-cogging LMS update | 4 kHz (inside velocity task) | i_q,PI | harmonic coefficients |

**Bandwidth separation rule:** each outer loop's crossover frequency should be at most one-fifth of the next inner loop's.

- ω_c,i = 2π·1500 rad/s (current loop)
- ω_c,v = 2π·250 rad/s (velocity loop)
- ω_c,θ = 2π·30 rad/s (angle loop)
