# STM32H743 AIO Flight Controller + 4-in-1 ESC: Reference Design Model (Job #65)

## 0. Scope, Assumptions, and Architectural Corrections

Some clarifications determine whether the rest of the design is valid.

1. **The H743 does not commutate the motors.** At 48 kHz with six FETs per motor, each ESC channel needs its own commutation MCU. This design uses four AT32F421 or STM32G071 MCUs running AM32, which supports 48 kHz PWM and bidirectional DShot. The H743 runs ArduPilot and emits DShot600 on one timer. The 48 kHz switching-loss model applies to the ESC side, and the DMA model applies to the H743 side.
2. **80 A on a nano form factor is a burst rating only.** The model below shows it is limited to roughly 1–2 seconds. It is not a continuous rating.
