## 0. Architectural Ground Rules

Two architecture decisions drive everything else.

1. **The H743 does not commutate the motors.** ArduPilot has no native FOC or 6-step drive path. The 4-in-1 section therefore uses four dedicated ESC MCUs running AM32 or BLHeli_32-class firmware, for example AT32F421 or STM32G071. The H743 talks to them over bi-directional DShot600. Sections 3 and 4 assume this split.

2. **80 A per channel on a nano (20×20 or 30.5×30.5 mm) board is burst-only.** Section 2.6 shows this is a hard limit, not a conservative opinion. Steady-state 80 A per motor has no stable thermal operating point on this form factor.

### Assumed operating point

| Parameter | Symbol | Value |
|---|---|---|
| Battery (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per motor | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| Commutation | — | 6-step trapezoidal, complementary (synchronous) PWM |
| MOSFET (representative 40 V, PDFN 3.3×3.3) | R_DS(on),25 | 1.2 mΩ typ |
| R_DS(on) temperature coefficient | α | 0.006 /K |
| Gate charge / switching charge | Q_g / Q_sw | 40 nC / 8 nC |
| Effective t_r + t_f (layout-limited) | t_sw | 40 ns |
| Dead time | t_dt | 100 ns |
| Body-diode forward voltage | V_f | 0.8 V |
| Reverse recovery charge | Q_rr | 30 nC |
| Energy-equivalent output capacitance | C_oss(er) | 1.5 nF |
| Gate drive voltage | V_gs | 10 V |

The bridge uses one FET per switch position: 6 FETs per ESC, 24 total.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.2 mΩ × 1.6 = **1.92 mΩ**.

### 1.2 Current sharing in 6-step with synchronous rectification

- In each 60° sector, two phase legs carry I_ph (one sourcing, one sinking). The third leg floats.
- Each leg is active for 2/3 of the electrical cycle.
- In the PWM'd leg, current flows through the high-side FET for fraction D and through the low-side FET (synchronous rectification) for 1−D. One FET in the leg always carries I_ph.

Per ESC, at any instant exactly two FETs carry I_ph:

$$P_{cond,ESC} = 2\,I_{ph}^2\,R_{DS}(T_j)$$

$$P_{cond,ESC} = 2 \times 80^2 \times 1.92\,\text{m}\Omega = \mathbf{24.6\ W}$$

### 1.3 Worst-case single FET

At D → 1, the high-side FET conducts for the whole 2/3 active window:

$$P_{FET,max} = I_{ph}^2 R_{DS}\cdot\tfrac{2}{3} = 6400 \times 1.92\text{m} \times 0.667 = \mathbf{8.2\ W}$$

This number sizes the per-FET junction-to-board path.

### 1.4 Ancillary copper loss (do not omit)

| Path | Resistance | Loss at 80 A |
|---|---|---|
| Phase trace + pad (2 oz, 4 layers paralleled) | ~0.3 mΩ | 1.9 W per phase pair |
| Bus shunt (if used) | 0.25 mΩ, at I_bus = D·I_ph | ≤ 1.6 W |
| Battery pads and planes | ~0.2 mΩ | shared; I_bus,total up to ~200 A+ |

Budget **about 3 W per ESC** of copper and shunt loss at burst.
