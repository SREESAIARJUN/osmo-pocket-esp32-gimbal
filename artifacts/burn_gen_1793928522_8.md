# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #8 specification, so the design rests on the assumptions below. Every value is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motors | 3× gimbal BLD
