# STM32H743 AIO Flight Controller with Integrated 4-in-1 ESC: Power-Stage and DShot Design Model

## 0. Assumptions and Feasibility Flags

I have no prior context for "Job #10", so this document states every assumption explicitly. Replace the placeholder values with your datasheet numbers before release.

**Architecture assumption.** ArduPilot does not run motor commutation on the flight-controller MCU. The design is therefore:

- **FC MCU:** STM32H743 running ArduPilot. It sends bidirectional DShot600 to the ESC MCUs.
- **ESC section:** 4× ESC MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32).
- **Gate drivers:** 4× three-phase drivers (FD6288Q-class).
- **Power stage:** 24 N-channel MOSFETs.

**Feasibility flag.** "Nano" (20×20 mm mounting) combined with 80 A burst per channel is not thermally credible for more than a few seconds. Section 3 quantifies this. Commercial 30×30 boards typically rate around 55–60 A burst.

## 1. Conduction Loss Model

In 6-step commutation, two phases carry the full phase current I at all times:

- **PWM leg:** the high-side FET conducts for duty D; the low-side FET conducts for (1−D) as a synchronous rectifier.
- **Return leg:** the low-side FET conducts 100% of the time.

Summing the two legs gives:

```
P_cond,ESC = I²·R_ds(on)(T_j)·[D + (1−D)] + I²·R_ds(on)(T_j)
           = 2·I²·R_ds(on)(T_j)
```

Temperature dependence:

```
R_ds(on)(T_j) = R_25·[1 + α(T_j − 25)],  with α ≈ 0.005 /K
```

At 80 A and T_j = 125 °C:

```
P_cond = 2 × 6400 × 1.5 mΩ = 19.2 W per ESC channel
```

**Copper path loss.** Add the trace and plane loss: P_Cu = I²·R_trace. With R_trace ≈ 0.3 mΩ for the effective two-leg path:

```
P_Cu ≈ 1.9 W per channel
```

**Positive feedback.** R_ds(on) rises with T_j, so conduction loss and temperature reinforce each other. Solve the following iteratively:

```
T_j = T_board + P_FET·R_θJC
```

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches, which means one commutating FET pair.

| Term | Formula | Value at 80 A, 25.2 V |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw | 0.5·25.2·80·35 ns·48 k = **1.69 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 nC·25.2·48 k = **0.048 W** |
| C_oss | 2 × ½·C_oss·V²·f_sw | 1.5 nF·635·48 k = **0.046 W** |
| Body-diode dead time | V_SD·I·2·t_dt·f_sw | 0.8·80·200 ns·48 k = **0.61 W** |
| Gate drive (from driver) | 2·Q_g·V_GS·f_sw | 2·50 nC·10·48 k = **0.048 W** |
| **Total switching loss** | | **≈ 2.45 W per channel** |

**Totals at full burst on all four motors:**

```
P_ch    = 19.2 + 1.9 + 2.45 ≈ 23.6 W
P_total ≈ 94 W
```

**Design levers:**

- Dead time costs about 25% of switching loss. Tune it down to about 50 ns if driver propagation matching allows.
- Moving to 24 kHz roughly halves switching loss (about −1.2 W per channel), at the cost of more current ripple and audible noise.
- Conduction loss dominates (about 80% of the total). Lowering R_ds(on) is the main lever, not switching speed.

## 3. Thermal Model

### 3.1 Junction-to-board

The average dissipation per FET is about 23.6/6 ≈ 3.9 W. The hottest FET is the return-leg low side, which conducts continuously at about 9.6 W during its 120° interval, averaging about 3.2 W plus share.

The commutation period (about 0.1–1 ms) is much shorter than the die thermal time constant (about 5–10 ms), so averaged power applies:

```
ΔT_jc ≈ 4 W × 1.2 K/W ≈ 5 K
```

This is small. The board is the bottleneck.

### 3.2 Board lumped RC (single-node Foster model)

**Thermal capacitance:**

```
C_th ≈ m·c_eff ≈ 8 g × 0.65 J/(g·K) ≈ 5.2 J/K
```

**Thermal resistance to air:** R_th,ba = 1/(h·A), with A = 2 × (0.03 m)² = 1.8×10⁻³ m².

| Airflow condition | h (W/m²K) | R_th (K/W) | τ = RC |
|---|---|---|---|
| Still air / poor prop wash | 50 | 11.1 | 58 s |
| Good prop wash | 150 | 3.7 | 19 s |

**Temperature response:**

```
ΔT(t) = P·R_th·(1 − e^(−t/τ))
```

**Burst time limit.** Taking T_amb = 40 °C and T_board,max = 110 °C gives an allowable rise of ΔT_max = 70 K. Solving for time:

```
t_burst = −τ·ln(1 − ΔT_max/(P·R_th))
```

| Condition | P·R_th | t_burst (all four motors at 80 A) |
|---|---|---|
| h = 50 | 1043 K | 58·(−ln 0.933) ≈ **4.0 s** |
| h = 150 | 348 K | 19·(−ln 0.799) ≈ **4.3 s** |
