# STM32H743 Nano AIO Flight Controller with 4-in-1 ESC: 80A Burst Power Stage, 48 kHz Switching, and ArduPilot Bi-Directional DShot600

## 0. Architecture and Assumptions

I don't have the Job #41 requirements document. Every parameter below is an explicit assumption, so you can substitute your real BOM values into the equations.

**Architecture correction.** The STM32H743 cannot practically run motor commutation for four motors while also running ArduPilot. ArduPilot has no ESC-commutation firmware. The standard and correct partition is:

```
STM32H743 (ArduPilot FC) ──DShot600 bidir x4──► 4× AT32F421K8U7 (AM32 firmware, one per motor)
                                                  └─► 3-phase gate driver ─► 6× N-MOSFET per motor
```

**Voltage margin warning.** A 40 V FET on 6S leaves 37% margin. Switching-node ringing at 80 A with nano-board loop inductance (~2–3 nH) can reach 8–12 V overshoot. Either:
- verify with a 1 GHz probe on the switch node, or
- move to 60 V FETs and accept roughly 1.6× R_ds(on).

## 1. Conduction Loss Model

### 1.1 Current path

The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At any instant, phase current flows through exactly two FETs:

- **PWM on:** HS of phase X + LS of phase Y
- **PWM off:** LS of phase X (sync-rectifying) + LS of phase Y

So the bridge-total conduction loss is **independent of duty cycle**:

$$P_{cond,bridge} = 2\,I^2\,R_{ds(on)}(T_j) + I^2 R_{Cu}$$

$$R_{ds(on)}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right] \approx R_{ds,25}\cdot k_T$$

### 1.2 Per-FET distribution

Each phase is active for 2/3 of an electrical cycle. Over one commutation cycle:

$$P_{HS} = \tfrac{1}{3} D\, I^2 R_{ds} \qquad P_{LS} = \tfrac{1}{3}(1-D)I^2R_{ds} + \tfrac{1}{3}I^2R_{ds}$$

The low-side FETs are always hotter, worst at low duty. Place them on the best copper.

### 1.3 Numbers at 80 A

- R_ds(on) hot = 1.2 mΩ × 1.5 = **1.8 mΩ**
- R_Cu (phase pad to bus cap return, per motor) ≈ 0.4 mΩ

$$P_{cond} = 2(80^2)(1.8\text{m}) + 80^2(0.4\text{m}) = 23.04 + 2.56 = \mathbf{25.6\ W}$$

Hottest low-side FET at D = 0.3:

$$P_{LS} = \tfrac{1}{3}(0.7)(6400)(1.8\text{m}) + \tfrac{1}{3}(6400)(1.8\text{m}) = 2.69 + 3.84 = \mathbf{6.5\ W}$$

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the half-bridge doing PWM switches hard. The steady-on low side of phase Y does not switch.

| Term | Equation | Value @ 80 A |
|---|---|---|
| V-I overlap | ½ · V_bus · I · (t_r + t_f) · f_sw | ½ · 25.2 · 80 · 40n · 48k = **1.94 W** |
| Dead-time diode | V_f · I · 2t_dt · f_sw | 0.8 · 80 · 100n · 48k = **0.31 W** |
| Reverse recovery | Q_rr · V_bus · f_sw | 30n · 25.2 · 48k = **0.036 W** |
| Coss | Q_oss · V_bus · f_sw | 25n · 25.2 · 48k = **0.030 W** |
| Gate drive (2 switching FETs, loss in driver/R_g) | 2 · Q_g · V_gs · f_sw | 2 · 40n · 10 · 48k = **0.038 W** |
| **Total switching** | | **≈ 2.36 W** |

**Per-motor total at 80 A:** P_motor = 25.6 + 2.36 ≈ **28.0 W**

**All four motors bursting simultaneously:** P_total ≈ **112 W**, plus about 1.5 W for the FC, regulators, and ESC MCUs.

**Efficiency:** about 2000 W per motor at full duty, so η ≈ 98.6%. The problem is loss density, not efficiency.

**Sensitivity:** if your FETs have 2× slower edges, V-I overlap goes to 3.9 W per motor. At 48 kHz, switching loss is roughly 10% of conduction loss, so R_ds(on) is the lever, not f_sw. Dropping to 24 kHz saves only about 1.2 W per motor.

## 3. Thermal Model

### 3.1 Network

```
P_FET ─[Rθjc 1.5 K/W]─ T_case ─[Rθ,via+spread ≈ 6 K/W local]─ T_board ─[Rθ,ba]─ T_amb
                                                                  │
                                                             C_board
```

### 3.2 Board heat capacity

| Material | Mass | c_p | Heat capacity |
|---|---|---|---|
| FR4 (30.5² × 1.6 mm) | ≈ 2.8 g | 1.1 J/g·K | 3.1 J/K |
| Copper (≈ 8 oz total equivalent) | ≈ 2.6 g | 0.385 J/g·K | 1.0 J/K |
| FETs, caps, solder | | | ≈ 0.6 J/K |
| **C_th** | | | **≈ 4.7 J/K** |

### 3.3 Steady-state board-to-air

Use h ≈ 80–120 W/m²K under prop wash, with both faces (A = 1.86×10⁻³ m²):

$$R_{\theta,ba} = \frac{1}{hA} \approx \frac{1}{100 \times 1.86\text{e-}3} \approx 5.4\ \text{K/W}$$

### 3.4 Burst survival time (4 motors at 80 A, 113 W)

$$T_b(t) = T_a + P R_{\theta}\left(1 - e^{-t/\tau}\right), \quad \tau = R_\theta C_{th} = 5.4 \times 4.7 \approx 25\ \text{s}$$

Junction rise above the board for the hottest FET:

ΔT_jb = 6.5 W × (1.5 + 6) ≈ **49 K**

For T_j ≤ 150 °C, the board limit is T_b ≤ 101 °C, so the allowed board rise is 61 K:

$$61 = 113 \cdot 5.4\left(1 - e^{-t/25}\right) \;\Rightarrow\; t \approx \mathbf{2.6\ s}$$

The 25 → 40 °C correction already applies via T_a. R_ds(on) rises further as T_j climbs, which is mild positive feedback. Iterating once gives **about 2.3 s**.
