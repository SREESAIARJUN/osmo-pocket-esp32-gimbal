## 0. Architecture Assumptions

An STM32H743 cannot commutate four BLDC motors directly, because it lacks enough advanced-control timers and complementary output pairs. This design therefore uses the standard AIO topology:

| Block | Implementation |
|---|---|
| Flight controller MCU | STM32H743VIT6 (LQFP100, 480 MHz), ArduPilot |
| ESC MCUs | 4× AT32F421K8U7 running AM32, one per motor |
| Gate drivers | 4× FD6288Q (3-phase half-bridge driver, bootstrap) |
| Power stage | 24× N-MOSFET, 40 V, 5×6 DFN (6 per motor) |
| FC↔ESC link | Bi-directional DShot600 (ArduPilot BDShot → AM32 eRPM telemetry) |
| Input | 3–6S LiPo (25.2 V max) |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal |
| Form factor | 30.5×30.5 mm. A 20×20 variant is evaluated in §2.6. |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R = 1.0 × (1 + 0.0045·100) = **1.45 mΩ**.

### 1.2 Current paths in 6-step with synchronous rectification

During each 60° commutation sector, two legs are active:

- **Leg A (PWM leg):** the high-side conducts for duty D, and the low-side conducts for (1–D) as the synchronous rectifier.
- **Leg B (return leg):** the low-side is held fully ON.

So at every instant, motor current I passes through exactly **two** MOSFET channels.

Per-motor conduction loss, including PWM ripple:

$$P_{cond,motor} = 2\,I_{rms}^2\,R_{DS}(T_j), \qquad I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}$$

Per-FET average over one electrical cycle (each FET is active 120° of 360°):

$$P_{HS} = \frac{I^2 R\,D}{3}, \qquad P_{LS} = \frac{I^2 R}{3}\,[1 + (1-D)]$$
