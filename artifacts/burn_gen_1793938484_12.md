# STM32H743 FC + 4-in-1 ESC: 80 A Burst Power Stage Design Package

## 0. Scope, Assumptions, and Architecture

I have no project records for "Job #10," so every parameter below is a stated assumption. The model is parametric, so you can substitute the actual MOSFET datasheet values. The netlists are a **reference design for review**, not a validated, DRC-checked layout.

**Architecture: the H743 does not drive the MOSFETs.** In every production 4-in-1 stack, the STM32H743 runs ArduPilot and sends bidirectional DShot600 to four (or one shared) ESC MCUs running AM32 or BLHeli_32. Those ESC MCUs generate the 48 kHz PWM. This split is assumed throughout:

```
[STM32H743 / ArduPilot] --4x BDShot600--> [4x AT32F421 / AM32] --> [FD6288Q x4] --> [24x N-MOSFET] --> motors
```

| Parameter | Assumed value |
|---|---|
| Bus voltage | 6S, V_bus = 25.2 V (worst case, full charge) |
| Burst current | 80 A phase current per ESC, all 4 simultaneously (worst case) |
| PWM | 48 kHz, complementary (synchronous rectification), dead time 50 ns |
| MOSFET (per switch, 1 per switch) | 40 V, R_DS(on),25 = 1.0 mΩ @ 10 V, Q_g = 60 nC, Q_gd = 8 nC, Q_rr = 40 nC, Q_oss = 50 nC, V_SD = 0.8 V, R_θJC = 1.2 K/W |
| Gate drive | 10–12 V, ~1 A effective switching-plateau current |
| Board | 30×30 mm (20×20 mounting), 6-layer, 2 oz on all layers, 1.6 mm FR4 |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_hot = 1.0 × 1.45 = **1.45 mΩ**.

### 1.2 Conduction path

In 6-step commutation with synchronous rectification, the current always flows through **exactly two FETs in series**:

- During t_on: the HS FET of phase A and the LS FET of phase B.
- During t_off: the LS FET of phase A (synchronous rectification) and the LS FET of phase B.

The loss is therefore approximately independent of duty cycle:

$$P_{cond} = 2\,I_{ph}^2\,R_{hot}$$

$$P_{cond} = 2 \times 80^2 \times 1.45\times10^{-3} = \mathbf{18.6\ W\ per\ ESC}$$

### 1.3 Copper loss (frequently ignored, not negligible)

2 oz copper has a sheet resistance of ρ/t = 1.72×10⁻⁸ / 70×10⁻⁶ = **0.246 mΩ/□**, rising to about 0.33 mΩ/□ at 110 °C.

A phase path of 3 squares on one layer is about 1 mΩ. Paralleling 3 layers brings it to about 0.33 mΩ:

$$P_{Cu} \approx 80^2 \times (2 \times 0.33\,\text{m}\Omega) \approx \mathbf{4.2\ W\ per\ ESC}$$

**Layout implication:** stitch the phase and power planes across at least 4 layers, and use dense via arrays at the FET pads (roughly 1 A per 0.3 mm via, transient).

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Each switching event consists of one hard-switched transition plus a dead-time interval.

| Term | Formula | Value |
|---|---|---|
| V-I overlap (hard switching) | ½ V I (t_r + t_f) f_sw, where t ≈ Q_gd / I_g ≈ 8 ns; use 15 ns each for Miller and parasitics | ½·25.2·80·30 ns·48k = **1.45 W** |
| Reverse recovery | Q_rr V f_sw | 40n·25.2·48k = **0.05 W** |
| Output capacitance | ½ Q_oss V f_sw | **0.03 W** |
| Body-diode dead time | V_SD I (2 t_dt) f_sw | 0.8·80·100 ns·48k = **0.31 W** |
| Gate drive (2 switching FETs, dissipated in driver/R_g) | 2 Q_g V_gs f_sw | 2·60n·10·48k = **0.06 W** |
| **Total switching** | | **≈ 1.9 W per ESC** |

**Design sensitivities:**

- Overlap loss scales linearly with f_sw. Moving from 48 kHz to 24 kHz saves about 0.9 W per ESC, at the cost of more current ripple in low-inductance motors.
- Dead-time loss is the second-largest term. Cutting dead time from 50 ns to 30 ns saves about 0.12 W, but you must verify shoot-through margin at temperature.

## 3. Total Burst Power Budget

| Per ESC | W |
|---|---|
| MOSFET conduction | 18.6 |
| Copper | 4.2 |
| Switching | 1.9 |
| **Per ESC total** | **24.7 W** |
| **4 ESCs at simultaneous 80 A burst** | **≈ 99 W** |

Efficiency check: the input power per ESC at full throttle is about 25.2 V × 80 A ≈ 2 kW, so efficiency is about 98.8%. That looks excellent, but 99 W concentrated on a 30×30 mm board is the real problem.

$$\frac{dT}{dt} = \frac{P}{C_{th}} = \frac{99}{4.8} \approx 20.6\ \text{K/s}$$
