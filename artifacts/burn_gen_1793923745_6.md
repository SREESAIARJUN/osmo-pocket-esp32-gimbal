# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the specification for "Job #2", so this design rests on the explicit assumptions below. Every assumed parameter is collected in one config block in the code so you can substitute your real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM, ADC triggered at the PWM center |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) |
| IMUs | 2× ICM-42688-P on the camera stage, placed symmetrically about the pitch-axis center, each on its own SPI bus |
| Payload | Fixed to the camera stage |
