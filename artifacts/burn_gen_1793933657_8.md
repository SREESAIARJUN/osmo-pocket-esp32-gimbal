## 0. Scope, Assumptions and Architectural Ground Rules

There are no vendor datasheets attached to this job, so every device parameter below is a **representative design value**. Before layout freeze, replace each one with the datasheet number for the part you select. The equations remain valid. The numbers update.

**Architectural decision (non-negotiable):** the STM32H743 does **not** commutate the motors. A 4-in-1 ESC needs four dedicated ESC MCUs, for example AT32F421 or STM32G071 running AM32/BLHeli_32. Each one runs sensorless BEMF commutation for one motor. The H743 talks to them only over bidirectional DShot600. Placing commutation on the H7 would couple flight-critical scheduling to sub-microsecond commutation timing, and no mainstream firmware stack supports it.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current definitions

AM32 and BLHeli_32 use six-step (trapezoidal) commutation with complementary (synchronous) PWM. In any 60° sector, two phases conduct:

- **Leg A (PWM leg):** the high-side FET conducts for duty D. The low-side FET of the same leg conducts for (1−D) as a synchronous rectifier.
- **Leg B (static leg):** the low-side FET is on for the full sector.
- **Leg C:** floating, used for BEMF sensing.

The phase (motor) current is I_ph. The battery current is the duty-weighted phase current:

$$I_{bat} \approx D\cdot I_{ph}$$

"80 A burst" is defined here as **I_ph = 80 A**, which is the worst case for FET heating. A rating based on battery current would imply higher FET current at partial throttle.

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25,max}\,[1+\alpha (T_j-25)],\quad \alpha\approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.3 mΩ × 1.5 = **1.95 mΩ**.

### 1.3 Per-channel conduction loss

The PWM leg always has exactly one FET carrying I_ph, whether that is the high side during D or the low side during 1−D. The static leg always has one FET carrying I_ph. Including inductor ripple:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}$$

$$P_{cond,ch} = 2\,R_{DS}(T_j)\left(I_{ph}^2+\frac{\Delta I_{pp}^2}{12}\right)$$

The ripple for a motor with line inductance L_LL (worst case at D = 0.5) is:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$
