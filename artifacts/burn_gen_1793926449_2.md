# STM32H743 AIO Flight Controller + 4-in-1 ESC: Reference Design Model (Job #47)

## 0. Scope, Architecture Decision, and Assumptions

This is a self-contained reference model built from stated assumptions. I have no access to existing Job #47 files. Every parameter marked **[A]** is an assumption. Replace it with the datasheet value for the parts you actually procure before signing off.

**Architecture correction.** ArduPilot does not run motor commutation on the flight-control MCU. The workable topology is:

- **STM32H743** runs ArduPilot and generates bidirectional DShot600 on 4 timer channels.
- **4× ESC MCUs** (AM32 on AT32F421K8U7 or STM32G071) each run 6-step commutation at 48 kHz PWM.
- **4× three-phase gate drivers** (FD6288Q-class), each driving 6 N-FETs. That is 24 FETs total.

**Feasibility flag.** "80 A burst per channel" on a 20×20 mm nano board is limited by thermal mass, not silicon. Section 3 shows it is a sub-second-to-~1 s capability, not a sustained rating.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)],\qquad \alpha \approx 0.0045\ /^\circ\text{C}$$

At T_j = 125 °C: R_ds = 1.5 × 1.45 = **2.18 mΩ** (round to 2.2 mΩ).

### 1.2 Six-step, complementary PWM current paths

In each 60° sector, two phases conduct:

- **Switching leg:** the high-side FET conducts for duty D. Its complementary low-side FET conducts for (1−D), excluding dead time.
- **Return leg:** the low-side FET is fully on.

Per ESC channel at phase current I:

$$P_{cond} = I_{rms}^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I_{rms}^2\,R_{ds}(T_j)$$

The result is independent of D, which is the benefit of synchronous rectification. Ripple correction:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12},\qquad \Delta I \approx \frac{V_{bus}D(1-D)}{L_{ph} f_{sw}}$$

With L_ph = 15 µH **[A]** and D = 0.5:

- ΔI = 25.2 × 0.25 / (15e-6 × 48e3) = 8.75 A
- ΔI²/12 = 6.4 A², which is negligible against I² = 6400 A².

**Conduction loss at 80 A, T_j = 125 °C:**

$$P_{cond} = 2 \times 6400 \times 0.0022 = \mathbf{28.2\ W\ per\ ESC\ channel}$$

### 1.3 Per-FET distribution

Over one electrical cycle, each phase is the "switching high" leg for 1/6, the "return low" leg for 1/6, and floating for 1/3 (per the standard 6-step pattern). The average loss is spread across 6 FETs:

$$\bar P_{FET,cond} \approx 28.2/6 = 4.7\ \text{W}$$

At low eRPM (startup or stall), one sector can dwell for milliseconds, so a single FET pair carries the full 28 W instantaneously. Use the instantaneous value for junction transients below about 100 eRPM.
