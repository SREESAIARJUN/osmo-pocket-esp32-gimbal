# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #26, so this design rests on the assumptions in Section 0. Each assumption is a single `constexpr` or config field in the code, so you can swap in your actual hardware values.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC (GBM2804-class): 12N14P, so 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701) on each motor shaft |
| Current sensing | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (rigid, near-coincident), SPI at 24 MHz |
| Axis order | Base → Yaw → Roll → Pitch → Camera |

### Loop rates

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ≈ 1.5–2 kHz |
| Encoder PLL / anti-cogging | 20 kHz | 50 µs | ≈ 300 Hz (PLL) |
| Velocity (gyro-rate) | 4 kHz | 250 µs | ≈ 60–120 Hz |
| Angle (attitude) | 1 kHz | 1 ms | ≈ 15–25 Hz |
| IMU ODR / fusion | 8 kHz → 4 kHz decimated | 125 / 250 µs | – |

The cascade separation rule is ω_c,inner ≥ 4–10 × ω_c,outer. Each loop is triggered synchronously from the PWM timer update, so there is no beat between loops.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):**

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform:**

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Electrical angle:**

$$
\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi
$$

The offset θ_off is found at calibration by aligning the rotor with v_d > 0 at θ_e = 0.

### 1.2 Plant (PMSM in the d-q frame)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

$$
\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q
$$

### 1.3 Current PI by pole-zero cancellation

Placing the PI zero on the electrical pole R/L gives the open-loop transfer function ω_cc/s, so the closed loop is first-order with bandwidth ω_cc:

$$
K_{p,i}=L\,\omega_{cc},\qquad K_{i,i}=R\,\omega_{cc},\qquad \omega_{cc}\le \frac{2\pi f_{pwm}}{10}
$$
