# 3-Axis Gimbal: FOC Control Loop, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #18 specification, so §0 lists every assumption. Each one maps to a constant in `config.hpp`. Change those constants and the equations and code still apply.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU), 170 MHz |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.5 Ω, L ≈ 2.2 mH, Kt ≈ 0.09 N·m/A |
| Encoders | 14-bit magnetic (MT6701/AS5048A) on each joint, SPI |
| Current sense | 2-phase low-side shunts, ADC triggered at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetric about the pitch axis, separate SPI buses |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, carries camera) |

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| IMU sampling (ODR) | 8 kHz | 125 µs |
| Velocity loop + vibration filters | 4 kHz | 250 µs |
| Attitude/angle loop + AHRS | 1 kHz | 1 ms |
