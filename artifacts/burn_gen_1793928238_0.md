# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #45 specification, so this design uses the assumptions below. Every parameter is a named constant, so you can substitute the real values without changing the structure.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7 and slots Nₛ = 12 |
| Motor electrical | R = 5.6 Ω, L = 2.1 mH, λ = 4.0 mWb, rotor+load J = 2.5×10⁻⁵ kg·m² |
| Joint encoder | 14-bit absolute magnetic encoder (AS5047P or MT6701 class) |
| Inverter | 3-phase, 24 kHz center-aligned PWM, two low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ±2000 dps, ±16 g |
| Loop rates | Current 24 kHz, velocity 8 kHz, angle/attitude 1 kHz (IMU-synchronous) |

## 1. Field-Oriented Control (Inner Current Loop, 24 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$
θ₀ is found at commissioning by applying v_d = V_align at θ_e = 0 and reading the encoder.

**Latency compensation.** Advance the angle by the 1.5-sample delay between ADC sampling and PWM application:
$$\theta_e^{*} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Clarke and Park transforms
With two shunts and i_c = −i_a − i_b:
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM model in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda)$$
$$\tau_e = \tfrac32 p\,\lambda\, i_q = K_t\, i_q$$

### 1.4 Current PI with pole-zero cancellation
The plant is 1/(Ls + R). Choose the PI zero to cancel the plant pole (K_i/K_p = R/L). The closed loop then becomes first-order with bandwidth ω_c:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c = 2\pi\cdot 1.5\text{ kHz}\;(\approx f_{pwm}/16)$$

Add the decoupling feedforward:
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda)$$

### 1.5 Voltage limiting and anti-windup
The limit is circular:
$$|v_{dq}| \le V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max}$$

Priority goes to d. The q-axis gets the remaining headroom:
$$v_{q,max} = \sqrt{V_{max}^2 - v_d^2}$$

Use back-calculation anti-windup on the integrator:
$$x_{k+1} = x_k + T_s\left[K_i e_k + K_{aw}\,(u_k^{sat} - u_k)\right],\qquad K_{aw} = K_i/K_p$$

### 1.6 SVPWM (min-max zero-sequence injection)
$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$
$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
