## 0. Architecture Correction (Read First)

The request combines two separate control domains. Keeping them separate avoids a common design error.

| Function | Runs on | Rate |
|---|---|---|
| ArduPilot flight control, DShot600 command + bidirectional eRPM capture | **STM32H743** (FC) | 1–8 kHz loop, DShot frames ~26.7 µs |
| 6-step commutation, **48 kHz PWM**, dead-time, BEMF zero-cross | **ESC MCU per motor** (AM32/BLHeli_32 class: STM32G071 / AT32F421 / GD32E230) | 48 kHz carrier |

The H743 never generates the 48 kHz switching. It only issues DShot and decodes the GCR telemetry. The 4-in-1 board therefore contains 4 ESC MCUs (or 2 dual-motor MCUs), 4 three-phase gate drivers and 24 MOSFETs.
