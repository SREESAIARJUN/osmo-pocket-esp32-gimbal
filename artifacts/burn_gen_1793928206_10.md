## 1. Conduction Loss Model

### 1.1 Current path
- AM32 uses 6-step trapezoidal commutation with complementary (synchronous) PWM.
- At any instant, motor current flows through exactly **two conducting MOSFET positions**:
  - the PWM leg (HS during D, LS during 1−D), and
  - the static low leg.
- Each phase leg carries current for 240° of every 360° electrical.

### 1.2 Temperature-dependent on-resistance

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha(T_j-25)],\qquad \alpha\approx0.006\ \text{K}^{-1}$$

At T_j = 100 °C:

$$R_{DS}=1.2\times1.45=1.74\ \text{m}\Omega$$

### 1.3 RMS current including PWM ripple

$$\Delta I_{pp}=\frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

The worst case is D = 0.5. With L_LL = 15 µH and f_sw = 48 kHz:

$$\Delta I_{pp}=\frac{25.2\times0.25}{15\mu\times48k}=8.75\ \text{A}$$

$$I_{rms}^2=I^2+\frac{\Delta I_{pp}^2}{12}=6400+6.4\approx6406\ \text{A}^2$$

Ripple is negligible at 80 A.

### 1.4 Loss per ESC channel

$$P_{cond}=I_{rms}^2\cdot 2R_{DS}(T_j)=6406\times2\times1.74\text{ m}\Omega=\mathbf{22.3\ W}$$

- Averaged over one electrical revolution, this spreads across 6 FETs: **≈3.7 W per FET average**.
- Instantaneous peak is 11.1 W in the two conducting FETs.

### 1.5 Copper and shunt losses (often forgotten)

| Element | R | I²R at 80 A |
|---|---|---|
| Phase pad / plane / vias (per path, both legs) | 0.5 mΩ | 3.2 W |
| Low-side current shunt (per ESC) | 0.25 mΩ | 1.6 W |

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The HS turn-on is hard-switched against LS body-diode recovery.

| Term | Formula | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_r + t_f)·f, with t_r = t_f = 15 ns | ½·25.2·80·30n·48k = **1.45 W** |
| Reverse recovery | Q_rr·V·f | 40n·25.2·48k = **0.048 W** |
| Output capacitance | ½·C_oss·V²·f | ½·1.5n·635·48k = **0.023 W** |
| Dead-time body-diode conduction | V_f·I·2t_dt·f, with t_dt = 50 ns | 0.8·80·100n·48k = **0.31 W** |
| Gate drive (dissipated in driver/R_g) | 2·Q_g·V_GS·f | 2·40n·10·48k = **0.038 W** |
| **Total switching** | | **≈1.87 W** |

**Sensitivity to switching frequency:** P_sw ∝ f_sw.
- At 24 kHz: ≈0.93 W.
- At 48 kHz, switching is still only ~8% of total loss.
- 48 kHz is therefore justified for current-ripple and acoustic reasons. Conduction loss dominates.

### 2.1 Loss budget per channel at 80 A, T_j = 100 °C

| Component | W |
|---|---|
| MOSFET conduction | 22.3 |
| MOSFET switching | 1.9 |
| PCB copper | 3.2 |
| Shunt | 1.6 |
| Gate driver + AT32 + LDO | ~0.2 |
| **Total per ESC** | **≈29 W** |
