# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual ICM-42688-P Sensor Fusion

I don't have the Job #48 specification, so I've stated every hardware-dependent assumption explicitly (§0). Each one is a parameter in the code. Replace them with your real values before tuning.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), ~10 Ω, ~3 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (MT6701 / AS5047 class) |
| Current sense | 2 low-side shunts per motor, sampled at PWM center |
| Bus | V_bus = 12–16 V |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, ±2000 dps, ±16 g |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Joint order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
