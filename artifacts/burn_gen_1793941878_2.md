# STM32H743 AIO Flight Controller + 80 A 4-in-1 ESC: Design Package (Job #27)

## 0. Architecture Correction and Baseline Assumptions

**Architecture correction.** The STM32H743 should not commutate the four motors directly. ArduPilot does not run sensorless BLDC commutation, and 4 × 48 kHz complementary 6-step PWM with BEMF zero-cross detection does not coexist well with a 400 MHz flight stack. The architecture used here is:

- **STM32H743** runs ArduPilot. It emits bi-directional DShot600 to the ESCs and receives eRPM telemetry back.
- **4 × AT32F421K8U7** (one per channel) run AM32 firmware. Each handles 48 kHz PWM, commutation and DShot decoding.
