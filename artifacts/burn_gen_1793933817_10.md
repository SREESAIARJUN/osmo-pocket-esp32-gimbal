# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have a spec sheet for Job #51, so the design is parameterised. Every value marked **⟨param⟩** must be replaced with measured or datasheet data before tuning.

| Item | Assumed baseline |
|---|---|
| MCU | STM32G4 @ 170 MHz (FPU, CORDIC optional), 3 × motor timers |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 3 mH ⟨param⟩ |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 / MA730), SPI |
| Current sense | Low-side shunts, 2 phases (voltage-mode fallback provided) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
