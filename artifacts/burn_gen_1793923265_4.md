## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (Ns = 12 slots, p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.07 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read every PWM cycle |
| MCU | STM32G4 / H7 class (FPU), 3× complementary PWM, synchronized ADC |
| Gimbal kinematics | Yaw (outer) → Roll (middle) → Pitch (inner) → camera |
| IMUs | 2× ICM-42688-P **on the camera plate**, at different positions, IMU-B rotated 180° about z |
| Bus voltage | 12–16 V |

**Loop rates (all integer-divided from one PWM timer):**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC, id/iq PI) | 20 kHz | 50 µs | ~1.5 kHz |
| Velocity (PI + cogging FF) | 5 kHz | 200 µs | ~150 Hz |
| Attitude/angle (P + rate FF) | 1 kHz | 1 ms | ~25 Hz |
| IMU sampling / filtering | 8 kHz ODR, processed at 4–8 kHz | | |

```
 q_ref ──►[Attitude err SO(3)]──►[Kp_θ]──(+ω_ff)──► ω_ref,cam ──►[J⁻¹(φ,θ)]──► θ̇_ref,joint
                    ▲                                                                  │
            q̂ (Mahony, dual IMU)                                                       ▼
                                          ┌──── iq_cog(θm+ω·Td) ◄── [Fourier cogging LUT/NLMS]
                                          ▼
 θ̇_ref,joint ──►[Velocity PI]──(+)──► iq_ref ──►[Current PI + decoupling]──►[SVPWM]──► Motor
        ▲  (ω̂ from fused gyro, projected into joint space; encoder ω as fallback)
```

Key design decision: the velocity loop is closed on the **gyro rate** (inertial), not encoder rate. This gives true inertial stabilization, because base disturbances are rejected directly. The encoder is used for commutation, for the cogging phase, and for the Jacobian.
