# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Fusion

> **Assumptions.** I don't have Job #54's spec sheet, so this design uses these defaults. Every value is a `constexpr` or config field you can change.
> - **Motors:** 3× gimbal BLDC, 12N14P (GBM2804-class), R ≈ 5–10 Ω, L ≈ 2–4 mH.
> - **Encoders:** 14-bit magnetic (AS5048A/MT6701-class) on each joint.
> - **IMUs:** 2× ICM-42688-P on the camera platform, each on its own SPI bus.
> - **MCU:** STM32G4/H7-class with FPU.
> - **Joint order:** yaw (z) → roll (x) → pitch (y), camera last.
