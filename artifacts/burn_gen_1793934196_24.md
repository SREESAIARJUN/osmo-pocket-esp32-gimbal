# STM32H743 Nano FC + 4-in-1 ESC (Job #29): Loss, Thermal, DShot and Netlist Model

## 0. Architecture Assumptions

Several constraints shape the whole analysis, so they come first.

1. **Partitioned control.** The STM32H743 runs ArduPilot and generates bi-directional DShot600. Each ESC channel is commutated by its own small MCU running AM32 or BLHeli_32-class firmware (for example AT32F421 or STM32G071) through a 3-phase gate driver. The 48 kHz PWM is an ESC-firmware parameter, not an H743 timer function. Running 4 sensorless FOC/trapezoidal loops plus flight control on the H743 is possible but non-standard and unsupported by ArduPilot.
2. **"80 A" means burst per motor, not continuous.** Section 3 shows that a nano form factor (20×20 to 30×30 mm) cannot dissipate 80 A continuously. The design target is therefore 80 A for about 1.5 s per motor.
3. **Bus voltage.** 6S, V_bus = 25.2 V (full charge, the worst case for switching loss).
4. **Reference MOSFET (generic 40 V, 3.3×3.3 mm class).** Substitute your actual datasheet values into the equations.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

At a design junction of T_j = 115 °C: R = 1.0 × (1 + 0.0055 × 90) ≈ **1.5 mΩ**.

Using 1.5 mΩ (not the 25 °C value) is essential, because the loss is self-reinforcing. Hotter silicon raises R, which raises loss, which raises temperature. Check stability with:

$$\frac{\partial P}{\partial T}\cdot R_{\theta} < 1$$

### 1.2 Trapezoidal 6-step with synchronous rectification

In each 60° sector, two phases carry the full phase current I:

- **PWM leg:** the high-side conducts for D, the complementary low-side for (1−D).
- **Static leg:** the low-side is on for 100 % of the sector.

$$P_{cond,bridge} = I^2R\,[D + (1-D)] + I^2R = 2I^2R_{DS}(T_j)$$

This is independent of duty, which is a useful property of synchronous rectification.

$$P_{cond,bridge} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W\ per\ motor}$$

Per FET, each device conducts for 1/3 of the electrical cycle at the I²R level:

$$P_{FET,avg} = \tfrac{1}{6}\cdot 19.2 = 3.2\text{ W}, \qquad P_{FET,peak} = I^2R = 9.6\text{ W}$$

The electrical frequency at high eRPM (≥1 kHz) is fast relative to the die thermal time constant (~ms), so the average figure is valid for T_j. Below about 200 Hz electrical (low RPM, high current, e.g. a stalled or locked motor), use the peak value instead.

### 1.3 Shunt and copper

- Phase or bus shunt at 0.25 mΩ: P = I²R_sh ≈ 1.6 W at 80 A (bus shunt current scales roughly with D).
- PCB copper (2 oz outer + 2 oz inner, ~0.3 mΩ per phase path): ≈ 2 × 80² × 0.3 mΩ ≈ 3.8 W per motor. Copper loss is routinely underestimated. Use heavy copper and stitch planes.
