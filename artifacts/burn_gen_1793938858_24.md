# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 Allocation

**Job #2: Architecture Design Package, Rev A**

## 0. Architecture Decision and Stated Assumptions

**Partitioning.** The H743 runs ArduPilot only. Commutation runs on four dedicated ESC MCUs (AT32F421K8U7, AM32 firmware), one per motor. Running ArduPilot's main loop plus four 48 kHz sensorless commutators on one core is not viable: there is no deterministic ISR budget, and it is not supported by AM32 or ArduPilot. The H743 talks to each ESC MCU over bidirectional DShot600.

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus max 25.2 V | Design for 30 V transients |
| Burst current | 80 A phase RMS, per motor | Datasheet "burst" definition |
| PWM frequency | 48 kHz, complementary (sync-rect) | AM32 setting |
| Board | "Nano" format, 20×20 mm mount, ~27×27 mm outline | 8-layer, 2 oz on all layers |
| MOSFET (reference) | 40 V N-ch, PQFN 3.3×3.3 | R_DS(on) 1.2 mΩ typ at 25 °C, Q_g 30 nC, Q_gd 7 nC, Q_rr 40 nC, R_θJC 1.5 K/W |
| Gate driver | FD6288Q-class 3-phase bootstrap driver | ~1 A source / 1.5 A sink |
| Ambient | 35 °C | Summer field condition |

> ⚠️ **Headline finding (Section 3):** 80 A is thermally achievable on this format **only as a single-motor transient of about 10 s**. Four motors at 80 A simultaneously hit the thermal limit in about **2 s**. Steady-state continuous capability is **about 23 A per motor** without forced heatsinking. The product must be specified that way. Otherwise the "80 A" number becomes a field-failure liability.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step complementary PWM

At any commutation step, one leg is PWM-switched, one leg's low-side is held ON, and one leg floats (BEMF sensing).

- During t_on: current flows through HS(A) → motor → LS(B).
- During t_off: current flows through LS(A) (synchronous rectification) → motor → LS(B).

So **exactly two MOSFETs conduct the full phase current at every instant**, independent of duty cycle:

$$P_{cond,motor} = I_{ph}^2 \cdot \big(2\,R_{DS(on)}(T_j) + R_{Cu}\big)$$
