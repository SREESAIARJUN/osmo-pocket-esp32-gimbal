# STM32H743 AIO Flight Controller + 4-in-1 80A ESC: Systems Architecture Package (Job #49)

## 0. Scope, Architecture Clarification, and Assumptions

**Architecture correction.** In a "4-in-1 ESC nano flight controller," the STM32H743 does **not** commutate the motors. The partitioning is:

| Domain | Device | Role |
|---|---|---|
| FC | STM32H743VIT6 (480 MHz) | ArduPilot. Generates bidirectional DShot600 and decodes eRPM telemetry |
| ESC ×4 | AT32F421K8U7 or STM32G071 (one per motor) | AM32/BLHeli_32 firmware. 6-step commutation with 48 kHz complementary PWM |
| Gate drive ×4 | 3-phase half-bridge driver (FD6288Q-class) | Bootstrap high-side drive |
| Power stage ×4 | 6× N-ch MOSFET per motor (24 total) | 80A burst per motor |

## 1. Conduction Loss Model (80A Burst)

### 1.1 Current Path in 6-Step Synchronous Commutation

During any 60° sector, two phases carry current (for example, A+ and B−):
- **PWM ON (duty D):** Q_AH → motor → Q_BL
- **PWM OFF (1−D):** Q_AL (synchronous rectification) → motor → Q_BL

With complementary PWM, current always flows through **exactly two conducting MOSFETs**, independent of duty cycle. Dead-time diode conduction is handled separately in §2.

### 1.2 Temperature-Dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C: R_ds = 0.90 × 1.425 = **1.28 mΩ**

### 1.3 RMS Current

For trapezoidal BLDC with adequate phase inductance, the 120° flat-top current gives I_rms,path ≈ I_ph. The 48 kHz ripple term is:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}$$

With ΔI_pp ≈ 8 A, the ripple correction is +5.3 A², which is negligible (<0.1%).

### 1.4 Per-Motor Conduction Loss

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j) = 2(80)^2(1.28\times10^{-3}) = \mathbf{16.4\ W}$$

**Per-device distribution** over a full electrical cycle:
- Each high-side FET conducts for 120° × D.
- Each low-side FET conducts for 120° (as the return leg) plus 120° × (1−D) (synchronous rectification).

At D ≈ 0.9 (burst near full throttle), the low-side FETs run hotter:
- P_LS ≈ I²R × (1/3)(1 + 0.1) = 8.19 × 0.367 = **3.0 W**
- P_HS ≈ 8.19 × (1/3)(0.9) = **2.46 W**

These are averaged over the electrical cycle. At typical eRPM (>1 kHz electrical), the junction thermal time constant averages them out.
