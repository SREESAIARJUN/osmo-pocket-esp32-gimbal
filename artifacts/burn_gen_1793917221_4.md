# STM32H743 FC + 4-in-1 ESC Nano Stack: Power, Thermal, and DShot Design Reference

## 0. Scope, Assumptions, and Key Findings

I don't have the original Job #58 requirements document, so every assumption is stated explicitly and the models are parameterized. You can substitute datasheet values and the equations still hold.

**Architecture clarification.** The STM32H743 is the flight controller MCU. The 4-in-1 ESC carries four separate ESC MCUs, e.g. AT32F421 or STM32G071 running AM32/BLHeli_32. That is where the 48 kHz PWM runs. The H743 generates bidirectional DShot600 and decodes eRPM telemetry.
