# Job #49: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion Design

## 0. Assumptions

Job #49's specifics weren't provided, so these baseline values are assumed. Every one of them is a parameter in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class (single-precision FPU, 170+ MHz) |
| Motor | Gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s≈5\,Ω$, $L_s≈2\,\text{mH}$, $K_t≈0.08$ N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701/AS5048A) on each joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro/accel ODR 8 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz |
| Driver | 3-phase half-bridge, center-aligned PWM, 3 low-side shunts |

Bandwidth separation is at least 5× per cascade stage:

$$\omega_c \approx 2\pi\cdot1500,\qquad \omega_v\approx 2\pi\cdot150,\qquad \omega_\theta\approx 2\pi\cdot20\ \text{rad/s}$$
