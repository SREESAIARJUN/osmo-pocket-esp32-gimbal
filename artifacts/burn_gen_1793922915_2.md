# STM32H743 AIO Flight Controller + 80 A 4-in-1 ESC: Architecture, Loss Model, and DShot Allocation

## 0. Assumptions and Feasibility Flags

Every number below comes from a stated assumption. The MOSFET parameters are placeholders, so substitute the datasheet values of your selected part. The equations stay valid; only the results change.

| Item | Assumption |
|---|---|
| Battery | 6S LiPo, 25.2 V full (worst case for switching loss) |
| Burst current | 80 A DC-equivalent phase current per motor channel |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal |
| MOSFET (placeholder) | 40 V, R_DS(on) = 1.2 mΩ max @ 25 °C, V_GS = 10 V; Q_g = 50 nC, Q_gs2 = 6 nC, Q_gd = 10 nC, V_pl = 3.5 V, R_g,int = 1 Ω, C_oss,tr = 1.5 nF, Q_rr = 40 nC, V_SD = 0.8 V |
| Topology | 1 FET per switch position, 6 per channel, 24 total |
| Gate driver | FD6288-class 3-phase driver, 12 V drive, ~7 Ω source / ~3 Ω sink effective |
| ESC MCU | 4× STM32G071 or AT32F421 running AM32 (or BLHeli_32) |
| FC MCU | STM32H743 @ 400 MHz running ArduPilot |
| PCB | 30.5 × 30.5 mm, 8 layers, 2 oz copper |

**Architecture flag.** The H743 should not commutate motors directly. ArduPilot does not run ESC firmware, and four sensorless BLDC control loops would consume the H743's timer and ADC resources. The standard architecture is:

- the H743 handles flight control, sending DShot600 with bidirectional eRPM telemetry;
- four dedicated ESC MCUs handle commutation.

The rest of this document assumes that split.

**Feasibility flag.** 80 A per channel × 4 channels draws about 320 A from the battery, roughly 8 kW. On a 20×20 "nano" footprint this is not physically credible: battery pads, bulk capacitance, and copper cross-section all fail. Even on 30.5×30.5, the thermal analysis in §3 shows 80 A on all four channels is a burst of seconds, not a rating. Treat "80 A" as a per-channel peak and verify it with test data, not just this model.

## 1. Conduction Loss Model

### 1.1 Current path
With complementary PWM in 6-step commutation, phase current always flows through exactly two conducting devices:

- the active high-side FET, or its synchronous low-side partner during the PWM off-time, and
- the low-side FET of the return phase.

So channel conduction loss is essentially independent of duty cycle:

$$P_{cond,ch} = I_{rms}^2 \cdot 2\,R_{DS(on)}(T_j)$$

### 1.2 RMS current including ripple
$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\, f_{sw}}$$

For a typical 5" motor (L_ph ≈ 15 µH, D ≈ 0.9 at burst, V_bus − V_bemf ≈ 3 V):

- ΔI ≈ 3.75 A, so the ripple term ΔI²/12 ≈ 1.2 A².
- This is negligible against 6400 A², so use I_rms ≈ 80 A.

### 1.3 Temperature dependence
$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 110 °C: R = 1.2 × 1.425 = **1.71 mΩ**.

### 1.4 Result
$$P_{cond,ch} = 80^2 \times 2 \times 1.71\text{ m}\Omega = \mathbf{21.9\ W}$$

Each FET conducts during 120° of each electrical period. At burst eRPM this period is about 0.3–1 ms, much shorter than the die-plus-board thermal time constant, so the loss averages across all six devices:

$$\bar P_{cond,FET} \approx 21.9/6 = \mathbf{3.65\ W}$$
