# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions and Timing

I don't have the Job #20 specification, so this design uses common gimbal hardware. Every parameter is a named constant you can change.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7 with single-precision FPU |
| Motor | 12N14P gimbal BLDC, pole pairs `p = 7`, R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701), one per joint |
| Current sense | 2–3 phase low-side shunts, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic chain | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |

Loop rates. Each loop is at least 5× slower than the loop inside it, and each loop's bandwidth is roughly 4–10× lower than the inner loop's.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC d/q) | 20 kHz (PWM ISR) | ~1.5–2 kHz |
| Velocity (gyro rate) | 4 kHz | ~150–250 Hz |
| Angle (attitude) | 1 kHz | ~20–40 Hz |
| IMU fusion + filtering | 8 kHz in, decimated to 4 kHz | — |
| Cogging adaptation (LMS) | 4 kHz, enabled only when \|ω\| is within a band | — |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

where θ_m,0 is the encoder offset at which the d-axis aligns with phase A. It is found by injecting a d-axis current at θ_e = 0 at startup.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$
