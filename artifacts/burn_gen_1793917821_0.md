# STM32H743 FC + 4-in-1 80A ESC: Loss Model, Thermal Budget, DShot Allocation and Netlists

## 0. Scope, Assumptions and One Up-Front Warning

I don't have prior project documents for "Job #31," so this is built from stated assumptions. Every number below derives from the parameter table in §1. Swap in your actual MOSFET datasheet values and the equations still hold.

**Architecture assumed (industry-standard):**
- **FC:** STM32H743 running ArduPilot. It outputs bidirectional DShot600 to the ESC.
- **ESC:** a 4-in-1 board with one small MCU per motor (e.g. AT32F421 / STM32G071 running AM32). The H743 does **not** commutate the motors directly. ArduPilot has no ESC firmware, so a single-H743 "AIO ESC" isn't a viable ArduPilot path.
- **Supply:** 6S (V_bus,max = 25.2 V), 40 V MOSFETs, 48 kHz PWM.

> ⚠️ **Feasibility flag:** "Nano" (20×20 mm) and "80 A burst" are in tension. The math below shows ~20 W per channel at 80 A, so ~80 W if all four burst together. That is only survivable for **sub-second bursts** on a 20×20 board. For sustained loads >40 A per channel, use 30.5×30.5 mm. I quantify this in §3.

## 2. Electrical Loss Model (per ESC channel)

### 2.1 Conduction losses

With six-step synchronous commutation, current always flows through exactly two legs. In each leg it passes through either the high-side FET (for duty D) or the synchronous low-side FET (for 1−D). The series path therefore always contains **two conducting FETs**, independent of D:

$$P_{cond} = 2\, I^2\, R_{DS(on)}(T_j) + I^2 R_{pcb}$$

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,[1+\alpha (T_j-25)]$$

Evaluated at a design-limit T_j of 110 °C: R = 0.90 × (1 + 0.0055 × 85) = **1.32 mΩ**.

$$P_{cond} = 2(80^2)(1.32\text{ m}\Omega) + 80^2(0.25\text{ m}\Omega) = 16.9 + 1.6 = \mathbf{18.5\ W}$$

**Thermal runaway check.** Conduction loss is coupled to temperature, so T_j must be solved iteratively:

$$T_j = T_a + R_{th}\cdot P(T_j)$$

The solution is stable only if

$$\frac{dP}{dT}\, R_{th} < 1 \;\Rightarrow\; 2I^2R_{25}\,\alpha\, R_{th} < 1$$

At 80 A: 2 × 6400 × 0.9 m × 0.0055 = 0.063 W/K. So **R_th must stay below 15.8 K/W** (junction-to-ambient, per channel) for a steady-state solution to exist. A 20×20 board without airflow is around 20–30 K/W per channel. **80 A continuous is therefore thermally unstable there.** This is the formal proof that 80 A is a burst-only rating.

### 2.2 Switching losses at 48 kHz

In six-step, one leg switches at a time.

**Hard-switching V–I overlap:**

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(30\text{ns})(48\text{k}) = \mathbf{1.45\ W}$$

**Output capacitance (both FETs in the leg):**

$$P_{oss} = 2\cdot\tfrac12 C_{oss}V^2 f = 1.5\text{n}\cdot 635\cdot 48\text{k} = \mathbf{0.046\ W}$$

**Reverse recovery:**

$$P_{rr} = Q_{rr}V_{bus}f = 40\text{n}(25.2)(48\text{k}) = \mathbf{0.048\ W}$$

**Dead-time body-diode conduction (two edges per period):**

$$P_{dt} = V_{SD}\, I\, (2t_{dt}) f = 0.8(80)(200\text{ns})(48\text{k}) = \mathbf{0.61\ W}$$

**Gate drive (dissipated mostly in the driver and R_g, not the FET):**

$$P_g = 2 Q_g V_{drv} f = 2(50\text{n})(10)(48\text{k}) = \mathbf{0.048\ W}$$

### 2.3 Per-channel total at 80 A

| Loss term | Watts | Share |
|---|---|---|
| Conduction (FETs) | 16.9 | 81 % |
| Conduction (copper) | 1.6 | 8 % |
| V–I switching | 1.45 | 7 % |
| Dead-time diode | 0.61 | 3 % |
| C_oss + Q_rr + gate | 0.14 | <1 % |
| **Total** | **≈20.7 W** | |

**Design insight:** At 80 A the losses are about 90 % conduction-dominated. Raising f_sw from 24 to 48 kHz costs only ~1 W. Halving R_DS(on), for example by paralleling two FETs per switch, saves ~8 W. Spend board area on FETs and copper, not on a lower PWM frequency.

**Scaling law (useful for the ESC current limit):**

$$P(I) \approx 2.89\times10^{-3}\, I^2 + 2.58\times10^{-2}\, I \quad [\text{W}]$$

| Phase current | Loss per channel |
|---|---|
| 30 A | ≈3.4 W |
| 50 A | ≈8.5 W |
| 80 A | ≈20.6 W |

### 2.4 Bus capacitor ripple

$$I_{C,rms} = I\sqrt{D(1-D)} \;\xrightarrow{D=0.5}\; 40\text{ A}_{rms}\ \text{per channel at 80 A}$$

Phases are interleaved only statistically, so assume ≥40 A_rms on the shared bus. Implement this as:
- local MLCC per channel: 4× 10 µF, 50 V X7R 1210; plus
- a bulk low-ESR electrolytic of ≥470 µF / 35 V on the battery leads (off-board if space forbids).

## 3. Thermal Model

### 3.1 Thermal network (per channel, lumped)

```
P(t) ─► [Tj]──Rjc 0.6 K/W──[Tcase]──Rcs 1.0 K/W──[Tpcb]──Rpa──[Tamb]
          │                     │                    │
         Cj ≈0.02 J/K       Cpkg ≈0.15 J/K      Cpcb (copper + FR4)
```

The values are per channel, with 6 FETs per channel.

**Copper heat capacity per channel.** On a 20×20 board, each channel gets about 1/4 of the area. With 4 layers × 2 oz Cu (70 µm):

$$V_{Cu} = 100\text{ mm}^2\times 4\times 0.07\text{ mm} = 28\text{ mm}^3$$

$$C_{Cu} = 28\times10^{-9}\cdot 8960 \cdot 385 \approx 0.097\text{ J/K}$$

Adding FR4 (~0.10 J/K) and the FETs (~0.15 J/K) gives **C_ch ≈ 0.35 J/K**.

**R_pa, PCB to ambient:**

| Condition | R_pa per channel |
|---|---|
| Still air | ≈25 K/W |
| Prop-wash airflow, 5–10 m/s | ≈8 K/W |

### 3.2 Burst-time limit

Treat this as a single-pole adiabatic-dominant model, valid for t ≪ τ = R_pa·C ≈ 3–9 s:

$$t_{burst} \approx \frac{C_{ch}\,(T_{j,max} - T_{j,0} - P R_{jc...s})}{P}$$

Inputs:
- T_j,max = 125 °C (FET max is 150 °C; keep 25 °C margin)
- Start temperature T_j0 = 60 °C (hover)
- Internal junction-to-PCB rise: P(R_jc + R_cs)/6 FETs, but only ~2 conduct, so ≈ 20.7 × 0.8 ≈ 16 °C

$$t_{burst} \approx \frac{0.35\,(125-60-16)}{20.7} \approx \mathbf{0.83\ s}$$

**Steady state with airflow:**

$$T_j = T_a + P(R_{pa}+R_{int}) = 35 + 20.7(8.8) = 217\,°\text{C}$$

This is not survivable, which confirms the burst-only rating.
