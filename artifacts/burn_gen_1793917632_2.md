## 2. Conduction-Loss Model (80 A Burst)

### 2.1 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C:

$$R_{ds} = 0.9\,(1+0.45) = 1.305\ \text{m}\Omega$$

A more conservative datasheet curve gives about 1.6× → **1.45 mΩ**, which is used below.

### 2.2 Current path in 6-step with complementary PWM

At any instant, phase A is PWM-ing and phase B is held low.

- **On-time (D):** current flows through HS_A and then LS_B.
- **Off-time (1−D):** current freewheels through LS_A and then LS_B.

There are therefore always **two FETs in series** in the current path:

$$P_{cond,ch} = I^2 R_{ds}\,D + I^2R_{ds}(1-D) + I^2R_{ds} = 2\,I^2R_{ds}(T_j)$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.45\times10^{-3} = \mathbf{18.6\ W\ per\ channel}$$

### 2.3 Copper and shunt losses

Assume a 0.25 mΩ shunt (or no shunt if current sensing is shared) and about 0.5 mΩ of total copper path on 2 oz inner planes:

$$P_{Cu+shunt} = 80^2 \times 0.75\times10^{-3} = 4.8\ \text{W per channel}$$

### 2.4 Per-FET worst case

HS_A at D = 1 and LS_B continuous:

$$P_{FET,max} = I^2 R_{ds} = 9.3\ \text{W}$$

## 3. Switching-Loss Model at 48 kHz

Only one leg switches per commutation sector, so the following applies per channel.

### 3.1 Hard-switching V–I overlap

$$P_{sw} = \tfrac{1}{2}V_{bus}\,I\,(t_r+t_f)\,f_{sw} = 0.5(25.2)(80)(40\text{ ns})(48\text{ kHz}) = \mathbf{1.94\ W}$$

### 3.2 Dead-time body-diode conduction

$$P_{dt} = V_{SD}\,I\,(2t_{dt})\,f_{sw} = 0.8(80)(200\text{ ns})(48\text{ kHz}) = 0.61\ \text{W}$$

### 3.3 Reverse recovery, C_oss, and gate charge

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ \text{W}$$

$$P_{oss} = Q_{oss}V_{bus}f_{sw} = 0.060\ \text{W}$$

$$P_{gate} = 2\,Q_g V_{drv} f_{sw} = 0.058\ \text{W}$$

The gate-charge loss is dissipated mostly in the gate driver and resistor, not in the FET.

### 3.4 Totals and the thermal reality check

| Loss term | Per channel | 4 channels |
|---|---|---|
| Conduction (FETs) | 18.6 W | 74.4 W |
| Copper + shunt | 4.8 W | 19.2 W |
| Switching (overlap) | 1.94 W | 7.8 W |
| Dead time + Q_rr + C_oss | 0.72 W | 2.9 W |
| **Total** | **≈26 W** | **≈104 W** |

**Steady-state check.** Assume prop-wash convection h ≈ 80 W/m²K over both faces of a 20×20 mm board (A = 8×10⁻⁴ m²):

$$R_{\theta,conv} = \frac{1}{hA} = 15.6\ \text{K/W} \quad\Rightarrow\quad \Delta T_{ss} = 104 \times 15.6 \approx 1600\ \text{K}$$

The board cannot sustain 80 A. Its realistic continuous dissipation budget is about **5–6 W total** (a 90 K rise), which corresponds to roughly **18–20 A continuous per motor**.

**Transient (burst) model.** Use a lumped junction-to-board Foster network plus board thermal mass:

$$\Delta T_j(t) = P_{FET}\sum_{i=1}^{n} R_i\left(1-e^{-t/\tau_i}\right) + \frac{P_{tot}}{C_{board}}\,t \quad (t \ll R_{conv}C_{board})$$

Inputs:

- Board plus FETs is about 4.5 g, with an effective c_p ≈ 0.75 J/g·K, so C_board ≈ 3.4 J/K.
- Board heating rate: 104 / 3.4 ≈ **31 K/s**.
- Junction-to-board term at P_FET = 9.3 W and R_θJC + R_θ,via ≈ 3 K/W: about 28 K, settling within roughly 50 ms.

Starting from a 40 °C board with a T_j limit of 150 °C:

$$t_{burst} = \frac{150-40-28}{31} \approx \mathbf{2.6\ s\ (all\ four\ motors)}$$

This is optimistic.
