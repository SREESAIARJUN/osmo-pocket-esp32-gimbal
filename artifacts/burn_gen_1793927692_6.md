# STM32H743 FC + 4-in-1 ESC Nano Stack (Job #7): Architecture Design Package

This package contains a full loss model, a transient thermal model, DShot timing, a DMA plan, and reference netlists. I had no prior project data for Job #7, so I made the assumptions in §0. Every equation is parametric. Replace the assumed values with datasheet values for your chosen MOSFET and driver, then re-run the numbers.

---

## 0. System Partition and Assumptions

**Architecture correction:** The STM32H743 does not drive the MOSFETs. A 4-in-1 ESC uses four dedicated ESC MCUs that run AM32 or BLHeli_32. The work splits as follows:

- **H743 (ArduPilot):** generates bidirectional DShot600 and receives eRPM telemetry.
- **ESC MCU (×4):** runs 6-step commutation with 48 kHz complementary PWM.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (22.2 V nominal) |
| Burst phase current per motor | I | 80 A (DC-equivalent in 6-step) |
| PWM frequency | f_sw | 48 kHz, center-aligned, complementary |
| MOSFET (per switch) | — | 40 V, PDFN 3.3×3.3 class |
| R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 0.90 mΩ |
| Q_g / Q_gd / Q_rr | — | 40 nC / 9 nC / 40 nC |
| C_oss at 25 V | — | 1.5 nF |
| Rise + fall time (driver-limited) | t_r + t_f | 25 + 25 ns |
| Dead time | t_dt | 100 ns |
| Body-diode V_F at 80 A | V_F | 0.8 V |
| Gate drive voltage | V_GS | 10 V (from the FD6288-class driver supply) |
| Stack size | — | 20×20 mm, 6-layer, 2 oz copper |
| Switches | — | 24 MOSFETs total (6 per motor) |
