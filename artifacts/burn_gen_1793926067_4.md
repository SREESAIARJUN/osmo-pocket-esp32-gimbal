## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal PMSM/BLDC, 12N14P (pole pairs p = 7), R ≈ **5 Ω**, L ≈ **2 mH** |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI or SSI |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7), center-aligned PWM |
| PWM / current loop | 20 kHz PWM, current loop at 20 kHz (Ts_i = 50 µs) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| Velocity loop | 4 kHz (IMU-gyro feedback, inertial rate stabilization) |
| Angle loop | 1 kHz (attitude-estimator feedback) |
| Bandwidths | ω_ci ≈ 2π·1.5 kHz, ω_v ≈ 2π·**60** Hz, ω_θ ≈ 2π·**8** Hz (≥5× separation per stage) |

Signal flow:

```
q_ref ─► [Angle P+FF] ─► ω_ref ─► [Velocity PI+FF] ─► τ_ref ─► ÷Kt ─► i_q* ─► (+ i_cog) ─► [FOC PI dq] ─► SVPWM
             ▲  IMU attitude (Mahony)       ▲ gyro (dual-IMU fused, notch+LPF) mapped by J⁻¹      ▲ encoder θ_e
```

**Key architecture choice:** the inner velocity loop uses the *inertial* gyro rate (camera-frame), mapped to joint space. This is what rejects base motion. The encoder is used for commutation, cogging compensation, and a joint-velocity PLL. The PLL serves as a fallback and for damping.

## 1. Field-Oriented Current Control (20 kHz)

### 1.1 Transforms
Use amplitude-invariant transforms with electrical angle θ_e = p·θ_m − θ_offset.

**Clarke** (2 shunts, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and current PI design
dq model:

$$v_d = Ri_d + L\dot i_d - \omega_e L i_q,\qquad v_q = Ri_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With cross-coupling and back-EMF feedforward,

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,$$

each axis reduces to G(s) = 1/(Ls + R).

The PI is C(s) = K_p + K_i/s. Choosing **pole-zero cancellation** K_i/K_p = R/L gives the open loop ω_ci/s, so the closed loop is first-order with bandwidth ω_ci:

$$\boxed{K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}}$$

Constraint: ω_ci ≲ 2π·f_s/10 to account for the 1.5-sample PWM and compute delay. **Delay compensation:** use θ_e + 1.5·ω_e·Ts_i in the inverse Park transform.
