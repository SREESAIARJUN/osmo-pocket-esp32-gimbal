# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #52)

## 0. Design Assumptions

I don't have the Job #52 specification sheet. The values below are typical for a brushless camera gimbal and are all parameterized in code. Replace them with your measured values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per joint |
| Current sense | 2- or 3-shunt inline/low-side, sampled at the PWM center |
| MCU | STM32G4 class (FPU, CORDIC optional) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, shared CLKIN |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
