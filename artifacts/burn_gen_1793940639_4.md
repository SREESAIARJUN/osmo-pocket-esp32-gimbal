# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the specification for Job #20, so this design rests on the assumptions below. Every parameter is in one config block, so you can substitute your real values without touching the equations.

| Item | Assumption |
|---|---|
| MCU | Cortex-M4F/M7 with single-precision FPU (e.g., STM32G474) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| Current sense | 2 low-side or inline shunts per motor |
| IMUs | Two ICM-42688-P on the camera plate, mounted roughly symmetric about the plate centroid |
| Kinematics | Yaw (ψ, base) → Roll (φ) → Pitch (θ, camera) |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Attitude 1 kHz · IMU 8 kHz ODR |
