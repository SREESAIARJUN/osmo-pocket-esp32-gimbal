## 0. Scope, Assumptions, and Reality Check

**Feasibility.** 80 A per channel on a nano-class board is a *burst* rating only, set by transient thermal capacity. Continuous capability lands near **25 A/channel** (see §3.5). The model below derives both figures so the marketing number and the engineering number come from the same equations.

**Architecture.** The H743 does **not** switch the MOSFETs. Each ESC channel runs its own MCU (AT32F421 / STM32G071 class, AM32 or BLHeli_32), driven by the H743 over bidirectional DShot600. The two must be designed and verified as separate layers.

## 1. Conduction-Loss Model

### 1.1 Current path in 6-step commutation

At any instant two phases conduct:

- **PWM leg:** current flows through the HS FET for duty D, then the LS FET of the same leg for (1−D). This is synchronous rectification, so the body diode conducts only during dead time.
- **Return leg:** the LS FET is on 100% of the sector.

So **two R_ds(on) are always in series** with the phase current, regardless of D:

P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)
