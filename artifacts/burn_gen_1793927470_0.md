## 1. FOC Inner Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

**Clarke transform** (amplitude-invariant, using $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI Design (Pole-Zero Cancellation)

The d-q plant per axis is:

$$L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e \lambda$$

$$L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q$$

Choose a PI controller $C(s) = K_p + K_i/s$ with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The zero then cancels the electrical pole $R/L$, and the closed loop becomes first-order:

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c = 2\pi\cdot 1.5\ \text{kHz}$, which is about $f_{pwm}/13$. This leaves margin for the 1.5-sample delay of PWM update plus ADC conversion.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda),\qquad \lambda = \frac{2K_t}{3p}$$

**Delay compensation:** rotate the output angle by $\theta_e + 1.5\,\omega_e T_s$.

### 1.3 Voltage Limiting and Anti-Windup

Limit the voltage vector to the inscribed circle of the SVPWM hexagon:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

The d-axis has priority. The q-axis receives the remaining headroom:

$$v_{q,\max} = \sqrt{V_{max}^2 - v_d^2}$$

**Back-calculation anti-windup** (with $u_{sat}$ the saturated output, $u$ the unsaturated output):

$$x_I[k+1] = x_I[k] + T_s\left(K_i e[k] + K_{aw}(u_{sat}-u)\right),\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and needs no sector logic.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical Plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

The current loop is fast ($\omega_c \gg \omega_v$), so treat it as unity gain with a lag $1/\omega_c$.

### 2.2 Velocity PI (4 kHz), Symmetric-Optimum Placement

$$C_v(s) = K_{pv}\left(1 + \frac{\omega_{iv}}{s}\right),\qquad K_{pv} = \frac{J\,\omega_v}{K_t},\qquad \omega_{iv} = \frac{\omega_v}{4}$$

Choose $\omega_v = 2\pi\cdot 120$ Hz. This is about $\omega_c/12$, and must stay below the first structural mode of the gimbal arm (measure it; typically 150–300 Hz).
