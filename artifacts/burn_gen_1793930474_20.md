# STM32H743 AIO Nano Flight Controller with 4-in-1 ESC (Job #6): Power-Stage Loss Model, Thermal Analysis, Bidirectional DShot600 DMA Allocation, and Reference Netlist

## 0. Scope, Assumptions and Key Finding

### Architecture

The STM32H743 runs ArduPilot as the flight controller. Each of the four ESC channels has its own local MCU running AM32 or BLHeli_32-class firmware. This document uses an AT32F421 or STM32G071 per channel.

The H743 does **not** commutate motors directly. It sends bidirectional DShot600 commands and receives eRPM telemetry back.

### Key finding

**80 A on all four channels simultaneously is a sub-second event on a nano (20×20 / 25×25 mm) board, not a rating.** Section 3 quantifies this. Size your marketing claims and firmware current limits to that result.

## 1. Conduction-Loss Model

### 1.1 Current in each MOSFET

With 6-step commutation and synchronous rectification, two half-bridges carry I_ph at every instant. One leg is PWM'd and one leg is held low, so exactly **two MOSFETs are always in the current path**.

Each leg is active for 2/3 of the electrical period. Within the PWM'd leg, the duty cycle D splits the current between the high-side and low-side FETs:

$$I_{rms,HS}^2 = \tfrac{1}{3} D\, I_{ph}^2 k_r ,\qquad I_{rms,LS}^2 = \tfrac{1}{3}(1-D)\,I_{ph}^2 k_r + \tfrac{1}{3} I_{ph}^2 k_r$$
