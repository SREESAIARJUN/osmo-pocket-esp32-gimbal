# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture & Mathematical Model

**Document:** Job #15, Rev A (Engineering Baseline)
**Scope:** Power-stage loss model, thermal model, DShot600 bidirectional timing and DMA allocation, reference netlists

---

## 0. Architecture Decision

The STM32H743 should **not** commutate the motors directly. It should be the flight controller, and each motor should have its own ESC MCU.

| Constraint | Direct-drive H743 | H743 FC + 4× ESC MCU |
|---|---|---|
| Complementary PWM outputs needed | 24 (4 motors × 3 half-bridges × 2) | 6 per ESC MCU |
| H743 advanced timers with dead-time | TIM1 and TIM8 (3 pairs each). HRTIM can cover about 1.5 more motors. | N/A |
| BEMF zero-cross comparators | 12 needed. The H743 has 2 COMPs. | Each ESC MCU has its own |
| Firmware ecosystem | Custom | AM32 or BLHeli_32-class firmware, bidirectional DShot proven |
| Fault isolation | One MCU fault drops all motors | Single-motor fault containment |

**Baseline:**
- **FC:** STM32H743VIT6 @ 480 MHz running ArduPilot. It emits 4× bidirectional DShot600.
- **ESC:** 4× AT32F421K8U7 (or STM32G071) running AM32. Each drives one 3-phase bridge via a 3-phase gate driver.

The rest of this document assumes this architecture.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C:

$$R_{DS} = 0.70\,\text{mΩ} \times (1 + 0.0055 \times 100) = 1.085\,\text{mΩ} \approx 1.1\,\text{mΩ}$$

### 2.2 Per-motor conduction loss at burst

With synchronous rectification, current always flows through two channels (high-side, or complementary low-side, plus the return low-side). At full throttle (D → 1):

$$P_{cond} = I^2 \cdot 2 R_{DS}(T_j) = 80^2 \times 2 \times 1.1\times10^{-3} = \mathbf{14.1\ W}$$

### 2.3 Per-FET distribution

In six-step commutation, each FET conducts for 120° (1/3) of the electrical cycle:

$$P_{cond,FET} = \frac{1}{3}\, I^2 R_{DS} = \frac{1}{3}\times 80^2 \times 1.1\text{ m} = 2.35\ \text{W}$$

There are 6 FETs, each carrying this share, so the total is 14.1 W, which is consistent with 2.2.

### 2.4 Self-consistency iteration

Loss depends on T_j, and T_j depends on loss. Iterate:

$$T_j^{(n+1)} = T_{ref} + P(T_j^{(n)})\cdot Z_{th}$$

This converges in 2–3 iterations. If the iteration diverges, the design is in **thermal runaway** and the burst must be cut short (see §4.4).

## 3. Switching Loss Model (48 kHz)

Only the PWM-switching leg incurs hard-switching loss. In each commutation sector, one high-side FET switches and its complement handles freewheeling.

### 3.1 Overlap (V·I crossover) loss

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{ns} \times 48\text{k} = \mathbf{0.968\ W}$$

### 3.2 Output capacitance loss

$$P_{oss} = \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} = 0.5 \times 60\text{n} \times 25.2 \times 48\text{k} = 0.036\ \text{W}$$

### 3.3 Reverse-recovery loss

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\times25.2\times48\text{k} = 0.060\ \text{W}$$

### 3.4 Dead-time body-diode conduction

$$P_{dt} = V_f \cdot I \cdot 2 t_{dt} \cdot f_{sw} = 0.8\times80\times200\text{n}\times48\text{k} = \mathbf{0.614\ W}$$

### 3.5 Gate-drive loss

This loss is dissipated in the driver and R_g, not in the FET:

$$P_{gate} = Q_g V_{GS} f_{sw} \times N_{switching} = 60\text{n}\times10\times48\text{k}\times2 = 0.058\ \text{W}$$

### 3.6 Per-motor loss budget at 80 A burst

| Loss term | W | Share |
|---|---|---|
| Conduction | 14.10 | 89.4 % |
| Switching overlap | 0.97 | 6.1 % |
| Dead-time diode | 0.61 | 3.9 % |
| Q_rr + Q_oss | 0.10 | 0.6 % |
| **FET total** | **15.78** | |
| Gate drive (driver IC) | 0.06 | |
| Shunt (0.25 mΩ, if used) | 1.60 | |
| **Per motor** | **≈ 17.4 W** | |
| **4 motors** | **≈ 70 W** | |

**Design insights:**
1. At 80 A the design is **conduction-dominated**. Raising f_sw from 24 to 48 kHz costs only about 0.8 W per motor. Lowering R_DS(on) is the main lever.
2. Dead-time loss is about 60 % of the overlap loss. Tuning dead time to the minimum safe value (about 50 ns with good layout) recovers roughly 0.3 W per motor.
3. Electrical efficiency at burst is approximately:

$$\eta \approx 1 - \frac{17.4}{25.2 \times 80 \times D_{eff}} \approx 99.1\,\%\ (D \to 1)$$

   Absolute heat flux, not efficiency, is the limiting factor.
