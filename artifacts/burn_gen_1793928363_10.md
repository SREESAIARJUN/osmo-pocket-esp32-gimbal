# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #46. The design below rests on the assumptions in §0. Every gain is given as a formula in physical parameters, so you can substitute your real motor and inertia values.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 3 hardware timers |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5048A) on each motor |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz, Ts_i = 50 µs | ADC ISR |
| Velocity | 4 kHz | Every 5th current tick |
| Angle / attitude | 1 kHz | IMU data-ready, decimated |
| IMU filtering | 8 kHz | Data-ready ISR |

**Bandwidth separation rule.** Each outer loop should be about 4–10× slower than the loop inside it:

- ω_ci ≈ 2π·1500 rad/s (current)
- ω_cv ≈ 2π·100–150 rad/s (velocity)
- ω_cθ ≈ 2π·15–30 rad/s (angle)

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

**Park transform**, using electrical angle θ_e = p·θ_m − θ_offset:

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.2 Plant and Decoupled PI

**Plant in the dq frame:**

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
```

**Decoupling and back-EMF feedforward:**

```
v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q)
