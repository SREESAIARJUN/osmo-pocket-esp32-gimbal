# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the original specification for Job #59, so the design below uses representative values. Every assumption is a named constant in the code. Replace them with your measured values before tuning.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC) |
| Motors | 3 × GBM2804-class, 12N14P (7 pole pairs), R ≈ 5.6 Ω, L ≈ 1.6 mH, Kt ≈ 0.045 N·m/A |
| Encoders | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 via SPI or SSI) |
| Current sensing | 2-shunt, low-side, ADC sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted diametrically opposite about the plate center (r₂ = −r₁), each on its own SPI bus |
| Gimbal kinematic order | Base → Yaw → Roll → Pitch → Camera |

### Loop timing

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | TIM1 update → ADC injected EOC ISR |
| IMU sampling | 8 kHz ODR, 2 × SPI DMA | IMU INT1 (data ready) |
| Fusion + rate (velocity) loop | 4 kHz | Decimate-by-2 after the anti-alias filter |
| Attitude (angle) loop | 1 kHz | Divide-by-4 of the rate loop |
| Cogging adaptation | 1 kHz | Background, gated |
