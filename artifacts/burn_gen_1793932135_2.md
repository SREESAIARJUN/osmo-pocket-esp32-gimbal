# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the spec for Job #17, so this design uses the parameters below. Every one is a constant in the code and can be changed.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class Cortex-M with FPU, single-precision float |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| Current sensing | 2-shunt inline or low-side, ADC triggered at PWM center |
| PWM | 20 kHz center-aligned |
| IMUs | 2 × ICM-42688-P on the camera plate. IMU-B is rotated 180° about z relative to IMU-A. |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz, IMU ODR 8 kHz |

**Gimbal-specific choice:** velocity feedback comes from the fused gyro, projected onto each joint axis, rather than the differentiated encoder. Angle feedback comes from the IMU attitude estimate. The encoder is used only for commutation, for indexing the cogging table, and for the joint Jacobian. This rejects base motion directly.

## 1. FOC Inner Current Loop (20 kHz)

### 1.1 Transforms
θₑ = p·θₘ − θ_offset

**Clarke transform** (amplitude-invariant, with i_c = −i_a − i_b):
- i_α = i_a
- i_β = (i_a + 2i_b)/√3

**Park transform:**
- i_d = i_α cos θₑ + i_β sin θₑ
- i_q = −i_α sin θₑ + i_β cos θₑ

### 1.2 Plant and PI design
The motor model in the dq frame is:

- v_d = R i_d + L di_d/dt − ωₑ L i_q
- v_q = R i_q + L di_q/dt + ωₑ L i_d + ωₑ λ

**Decoupling feedforward:**
- v_d,ff = −ωₑ L i_q
- v_q,ff = ωₑ L i_d + ωₑ λ

With decoupling applied, the plant reduces to 1/(Ls + R). Pole-zero cancellation gives a first-order closed loop of bandwidth ω_c:

- K_p,i = L·ω_c
- K_i,i = R·ω_c

Choose ω_c ≤ 2π·f_pwm/10, so about 2π·2 kHz.

**Discretization.** Use forward Euler for the integrator, plus a 1.5·T_s delay compensation on the angle:

θₑ,comp = θₑ + 1.5·ωₑ·T_s

### 1.3 Voltage limiting and SVPWM
1. Apply a circular limit: if |v_dq| > V_bus/√3, scale v_d and v_q down (d-axis priority).
2. Inverse Park transform gives (v_α, v_β).
3. Min-max zero-sequence injection is equivalent to SVPWM:
   - v_x = Clarke⁻¹(v_α, v_β)
   - v₀ = −(max v_x + min v_x)/2
   - duty_x = ½ + (v_x + v₀)/V_bus

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Joint-space feedback from the IMU
The camera angular velocity ω_c (camera frame) relates to joint rates q̇ = [q̇_yaw, q̇_roll, q̇_pitch] by:

ω_c = J(q) q̇ + R_cb(q) ω_base

For a yaw–roll–pitch chain (outer to inner), the joint axes expressed in the camera frame are:

- a_pitch = e_y
- a_roll = R_y(q_p)ᵀ e_x
- a_yaw = (R_x(q_r) R_y(q_p))ᵀ e_z

**Axis feedback.** Each axis controller stabilizes the inertial rate about its own axis:

ω_k,meas = a_kᵀ ω_c

**Attitude error.** Given the quaternion error q_e = q_ref* ⊗ q̂:

- e_rot = 2·sgn(q_e,w)·q_e,xyz
- The per-axis angle error is e_k = a_kᵀ e_rot

This small-angle-consistent, shortest-path form avoids Euler singularities near the setpoint.

### 2.2 Angle loop (1 kHz): P controller with feedforward
ω_k,ref = K_θ·(−e_k) + ω_k,ff

**Bandwidth:** ω_θ ≈ ω_v/4, so K_θ = ω_θ. An integrator is not needed, because the velocity loop is type-1.

### 2.3 Velocity loop (4 kHz): PI with derivative-on-measurement, back-calculation anti-windup, and setpoint weighting

**Plant:** τ = K_t i_q, with J ω̇ = τ − τ_cog − τ_dist.

**Control law:**

u = K_p(b·ω_ref − ω) + I − K_d·ω̇_f

**Integrator update with back-calculation:**

I[n+1] = I[n] + K_i T_s(ω_ref − ω) + (T_s/T_t)(sat(u) − u)

with T_t = √(K_p/K_i) ... in practice T_t ≈ √(T_i T_d), or T_i/2 when D = 0.

**Filtered derivative of measurement** (Tustin, N = 8–20):

ω̇_f[n] = (2T_d − N T_s)/(2T_d + N T_s)·ω̇_f[n−1] − 2K_d N/(2T_d + N T_s)·(ω[n] − ω[n−1])
