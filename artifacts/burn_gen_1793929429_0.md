# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I don't have the original Job #19 specification, so the design below rests on these assumptions. Every value is a named parameter, so you can swap in the real numbers.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 24N22P (e.g. GM4108-class). Pole pairs `p = 11`, `R = 10 Ω`, `L = 3 mH` (phase), `Kt ≈ 0.06 N·m/A` |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) on each axis |
| MCU | STM32G4 @ 170 MHz, single-precision FPU |
| PWM | 20 kHz center-aligned, synchronous ADC sampling at the PWM valley |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, ODR 8 kHz, on-chip AAF set to 1 kHz |
| Vibration source | Propellers or airframe, typically 80–400 Hz with harmonics, frequency drifts with throttle |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ≈ 1.5 kHz |
| Gyro filtering + velocity loop | 8 kHz → 4 kHz | ≈ 80–120 Hz |
| Attitude estimation + angle loop | 1 kHz | ≈ 15–25 Hz |

The rule of thumb is a bandwidth separation of at least 5–10× between nested loops.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle:
$$\theta_e = p\,(\theta_m - \theta_{off}) \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model and Decoupling

The motor model in the dq frame:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Applying decoupling and back-EMF feedforward:
$$v_d = u_d - \hat\omega_e \hat L i_q,\qquad v_q = u_q + \hat\omega_e \hat L i_d + \hat\omega_e \hat\lambda_m$$

This leaves two identical first-order plants, $G(s) = 1/(Ls+R)$. The flux linkage follows from the torque constant: $\lambda_m = \tfrac{2}{3}K_t/p$.

### 1.3 Current PI Tuning by Pole-Zero Cancellation

Choose
$$K_{p,i} = L\,\omega_{c},\qquad K_{i,i} = R\,\omega_{c}$$

The closed loop then becomes $\omega_c/(s+\omega_c)$. A good choice is $\omega_c = 2\pi\cdot 1500$ rad/s, which is below $f_{pwm}/10$ to leave margin for the 1.5-sample computation and PWM delay.

### 1.4 Discrete PI with Back-Calculation Anti-Windup

$$u_k = K_p e_k + I_k,\qquad \bar u_k=\text{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k),\qquad K_{aw}\approx \frac{K_i}{K_p}T_s$$

The dq voltage vector is limited circularly, with the d-axis given priority:
$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2 - v_d^2},\qquad V_{max}=\frac{V_{bus}}{\sqrt3}$$

### 1.5 SVPWM via Min-Max Zero-Sequence Injection

First apply the inverse Park and inverse Clarke transforms to get $v_a, v_b, v_c$. Then inject the zero-sequence term:
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

Duty cycles:
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and gives 15.5% more linear range than sine PWM.

## 2. Cascaded Angle → Velocity → Torque Control

```
θ_ref ─►(+)─► P / PI (1 kHz) ─► ω_ref ─►(+)─► PI + LPF (4 kHz) ─► τ_ref ─► ÷Kt ─► i_q,ref ─► FOC (20 kHz)
        ▲−                        ▲ +ω_ff  ▲−                ▲ +τ_ff, +τ_cog
        θ_meas (IMU attitude)          ω_meas (gyro, joint axis)
```

### 2.1 Mechanical Plant

$$J\dot\omega = \tau_m - b\,\omega - \tau_{cog}(\theta) - \tau_d$$

Here $\tau_d$ includes cable drag, imbalance, and base motion coupling.

### 2.2 Velocity Loop

The loop uses the **inertial** rate (gyro projected onto the joint axis), not the encoder rate. This makes the loop reject base motion directly. The encoder rate is used only as a fallback and during calibration.

PI controller with a low-pass filter on the output:
$$C_v(s) = \Big(K_{p,v} + \frac{K_{i,v}}{s}\Big)\frac{\omega_f}{s+\omega_f}$$
