# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #28 specification, so this design uses the assumptions in §0. Every parameter is a named constant, so you can substitute your real values.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5 Ω, L ≈ 2 mH |
| Commutation sensor | 14-bit magnetic encoder per axis (e.g., AS5048A / MT6701) |
| Current sensing | 2-phase low-side shunts, sampled at PWM center |
| Mechanical order (base → camera) | Yaw (ψ) → Roll (φ) → Pitch (θ) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |
| MCU | Cortex-M4F/M7 with single-precision FPU |
