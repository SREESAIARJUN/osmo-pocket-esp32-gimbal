## 0. Architecture Clarification (read first)

ArduPilot does not commutate BLDC motors. The H743 cannot drive the bridge gates directly with ArduPilot firmware. The correct partitioning is:

```
6S LiPo ─┬─► 4× 3-phase bridges (24 MOSFETs) ◄── 4× gate drivers ◄── 4× ESC MCUs (AM32, e.g. AT32F421/STM32G071)
         │                                                              ▲   │
         │                                              DShot600 bidir ─┘   └─ eRPM (GCR) return
         └─► FC power tree ─► STM32H743 (ArduPilot) ─ TIM1 CH1–4 ────────────┘
```

| Function | Owner |
|---|---|
| 48 kHz PWM and commutation | AM32 on each ESC MCU (configurable PWM frequency) |
| Command and RPM telemetry | ArduPilot on the H743, via bidirectional DShot600 |
| Harmonic notch filtering | Fed by the eRPM telemetry |

## 1. Conduction Loss Model

### 1.1 Conduction topology

In 6-step commutation, two phases conduct at any instant:

- **PWM leg:** the high-side FET conducts for duty fraction D. The complementary low-side FET (synchronous rectification) conducts for (1−D).
- **Static leg:** the low-side FET of the return phase conducts continuously.

Ignoring dead time, the per-channel conduction loss is:

$$
P_{cond} = I^2 R_{hot}\,[D + (1-D)] + I^2 R_{hot} = 2\,I^2 R_{hot}
$$

This is independent of D. Battery current is I_bat ≈ D·I, but MOSFET loss tracks phase current. That is why low-throttle, high-torque events (punch-outs, prop strikes) are thermally worst.

### 1.2 Temperature-dependent R_DS(on)

$$
R_{hot} = R_{25}\,[1 + \alpha (T_j - 25)] + R_{pcb}
$$

At T_j = 110 °C: R = 1.2 × (1 + 0.004 × 85) = **1.608 mΩ** (FET only).

Add path resistance from copper, vias and solder. For a realistic 8-layer layout, R_pcb ≈ 0.3–0.5 mΩ per conduction path. Below it is held separately as a margin item.

### 1.3 Result at 80 A

$$
P_{cond} = 2 \times 80^2 \times 1.608\text{ mΩ} = \mathbf{20.6\ W\ per\ channel}
$$

Adding R_pcb = 0.4 mΩ gives 25.7 W per channel.

### 1.4 Electro-thermal stability (R_DS(on) runaway check)

$$
T_j = T_b + P_0[1+\alpha(T_j-25)]R_{th} \;\Rightarrow\; T_j = \frac{T_b + P_0 R_{th}(1-25\alpha)}{1-\alpha P_0 R_{th}}
$$
