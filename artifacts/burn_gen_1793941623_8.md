# STM32H743 FC + 80 A 4-in-1 ESC: Power-Stage Model, Thermal Budget, and Bidirectional DShot Allocation

I don't have prior context for Job #58, so this document states every assumption explicitly. Swap in your actual MOSFET datasheet values and the equations will carry through.

**Two architectural corrections up front:**

1. **The H743 should not commutate the motors.** ArduPilot has no on-FC 6-step BLDC driver. The architecture must be:
   - The **H743 acts as the flight controller**. It sends DShot600 and receives eRPM telemetry.
   - **Four ESC MCUs** run AM32 or BLHeli_32-class firmware and generate the 48 kHz PWM. Typical parts are the AT32F421 or STM32G071.
2. **"Nano" + 80 A burst is thermally marginal.** On a 20×20 mm board it is not credible. On a 30.5×30.5 mm board it is credible only for a few seconds (§3). The model below shows exactly where the limit sits.

## 2. Loss Model (Per Motor Channel, 6 MOSFETs)

### 2.1 Commutation Topology

The drive scheme is trapezoidal 6-step with complementary (synchronous) PWM on the active leg. At any instant, two phases conduct:

- **PWM leg:** The high-side FET conducts for D and the low-side FET for (1−D).
- **Static leg:** One FET conducts continuously.

The current path therefore always contains exactly two R_DS(on) drops, independent of duty cycle.
