## 0. System Assumptions and Loop Rates

| Item | Default |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| PWM | 30 kHz center-aligned, 3 half-bridges plus 2–3 shunts |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro ODR 8 kHz |

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 30 kHz | 33.3 µs | ω_c ≈ 2π·1500 rad/s |
| Velocity (inertial rate) | 4 kHz (synchronous with IMU data-ready, decimated) | 250 µs | ≈ 2π·80 Hz |
| Angle (attitude) | 1 kHz | 1 ms | ≈ 2π·15 Hz |
| Attitude estimator | 1 kHz | 1 ms | — |

**Bandwidth separation rule:** keep each outer loop's bandwidth at or below 1/5 to 1/10 of the next inner loop's bandwidth. The cascade can then be designed loop by loop, with each inner loop treated as unity gain.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Angle and Electrical Frame

Mechanical angle from the encoder, with zero offset θ₀ found by d-axis alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Speed estimation (type-II PLL on encoder angle).** This avoids differentiating quantization noise:

$$e_k = \operatorname{wrap}_{\pm\pi}(\theta_{m,k} - \hat\theta_{k-1})$$

$$\hat\omega_k = \hat\omega_{k-1} + T_s k_i e_k$$

$$\hat\theta_k = \hat\theta_{k-1} + T_s(\hat\omega_k + k_p e_k)$$

The gains are $k_p = 2\zeta\omega_n$ and $k_i = \omega_n^2$, with typical values $\omega_n = 2\pi\cdot 300$ and $\zeta = 0.9$.

### 1.2 Clarke and Park Transforms (amplitude-invariant)

Clarke transform:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{since } i_a+i_b+i_c=0)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and Decoupling

The PMSM voltage equations in the rotating frame are:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
