# STM32H743 FC + 4-in-1 ESC "Nano" Stack (Job #51): System Design Package

## 0. Architectural Corrections and Assumptions

Three points need settling before any math, because they change the model.

1. **The H743 is the flight controller, not the ESC MCU.** In a 4-in-1 ESC, each bridge is commutated by its own small MCU running AM32 or BLHeli_32-class firmware, typically an AT32F421 or STM32G071. ArduPilot on the H743 only produces bidirectional DShot600 and decodes eRPM telemetry. The 48 kHz PWM is generated on the ESC MCUs. The model below keeps these two domains separate.

2. **"80 A burst" on a nano (20×20 mm) board is thermally a 1–3 second rating, not a sustained one.** Section 3 derives this from first principles. Treat 80 A as a per-channel transient spec only.

3. **Component values are representative, not from a specific BOM.** Replace them with your selected parts' datasheet values. Every equation is written so you can re-run it with real numbers.

## 1. Conduction-Loss Model (per ESC channel)

### 1.1 Topology

The model assumes 6-step trapezoidal commutation with complementary (synchronous) PWM, as in AM32's default mode. In any 60° sector:

- **PWM leg:** the high-side FET conducts for duty D. The synchronous low-side FET conducts for (1 − D), minus dead time.
- **Return leg:** the low-side FET is on continuously.
- **Floating leg:** off, used for BEMF sensing.

### 1.2 Instantaneous bridge conduction loss

Because the PWM leg always has exactly one FET conducting, the duty cycle cancels:

$$
P_{cond}= I_{ph}^2\left[D\,R_{HS} + (1-D)\,R_{LS} + R_{LS}\right] = 2\,I_{ph}^2\,R_{ds,on}(T_j)\quad (R_{HS}=R_{LS})
$$

### 1.3 Temperature dependence (positive feedback)

$$
R_{ds,on}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right],\qquad \alpha \approx 0.005\ \text{K}^{-1}
$$

At 125 °C: R = 1.0 × 1.5 = **1.5 mΩ**.

$$
P_{cond} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W\ per\ channel}
$$

### 1.4 Copper loss

$$
P_{cu} = I_{ph}^2 R_{cu} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W}
$$

### 1.5 Per-FET distribution

Each leg spends 120° as a high-side participant and 120° as a low-side participant. The averaged dissipation per FET is therefore approximately:

$$
P_{FET,cond} \approx \frac{P_{cond}}{6} \approx 3.2\ \text{W}
$$

The peak occurs within the active sector: up to 9.6 W in the low-side FET of the return leg. This intra-period peak matters for junction ΔT
