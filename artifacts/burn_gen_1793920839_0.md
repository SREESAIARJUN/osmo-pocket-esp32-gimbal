I don't have the Job #17 specification, so this design uses the assumptions below. Every numeric parameter lives in a single `Config` struct so you can substitute your real values.

## 1. Field-Oriented Control (innermost loop, 24 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

`θ_off` is found at startup by applying `v_d` at `θ_e = 0` and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, balanced currents)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p\,\lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with pole-zero cancellation

With decoupling applied, each axis plant is $G(s)=\dfrac{1}{Ls+R}$. Choose

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

The open loop then becomes $\omega_{ci}/s$, so the closed loop is first-order with bandwidth $\omega_{ci}$. Use $\omega_{ci} \le 2\pi f_{pwm}/20$; for 24 kHz that is ≈ 2π·1.2 kHz.

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L\, i_q,\qquad v_q^{ff} = \omega_e (L\, i_d + \lambda_m)$$

### 1.6 Discrete PI with back-calculation anti-windup

Discretization is backward Euler with sample period $T_s$:

$$\begin{aligned}
u_k^{\text{raw}} &= K_p e_k + I_{k} + u^{ff}_k\\
u_k &= \operatorname{sat}(u_k^{\text{raw}})\\
I_{k+1} &= I_k + K_i T_s e_k + K_{aw} T_s\,(u_k - u_k^{\text{raw}}),\quad K_{aw}=K_i/K_p
\end{aligned}$$

Voltage limiting is circular in dq: $\sqrt{v_d^2+v_q^2}\le V_{bus}/\sqrt3$. Priority goes to $v_d$.

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The min-max injection is mathematically identical to sector-based SVPWM and is cheaper to compute.
