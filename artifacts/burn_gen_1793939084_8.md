# 3-Axis Gimbal FOC & Dual-IMU Sensor Fusion: Design Specification and C++ Implementation

I don't have the Job #32 specifics, so this design states its assumptions explicitly. Every assumption is a parameter in the code. Replace them with your motor, encoder, MCU and mechanical data before tuning.

## 0. Baseline Assumptions

| Item | Assumed value | Where it matters |
|---|---|---|
| Motors | Gimbal BLDC, 12N14P (GBM2804-class), pole pairs `p = 7`, `R ≈ 10 Ω`, `L ≈ 2.5 mH` (phase-to-neutral), `Kt ≈ 0.08 N·m/A` | Current PI gains, cogging harmonics |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI | Electrical angle, velocity PLL |
| MCU | STM32G4 / H7-class, single-precision FPU | Float math budget |
| Bus | 12–16.8 V (3S–4S) | SVPWM normalization |
| IMUs | **IMU-C**: ICM-42688-P on the camera plate (control feedback). **IMU-B**: ICM-42688-P on the base/handle (disturbance reference and vibration-frequency tracking). | Fusion architecture |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera | Jacobian feedforward |
