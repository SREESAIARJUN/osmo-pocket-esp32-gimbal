## 0. Architecture Correction (Read First)

An STM32H743 running ArduPilot **does not commutate BLDC motors**. ArduPilot has no sensorless six-step or FOC commutation engine. The only viable architecture is:

```
           ┌──────────────── STM32H743 (ArduPilot) ────────────────┐
           │  TIM1 CH1-4 ── DShot600 bidir ──┐                     │
           └─────────────────────────────────┼─────────────────────┘
                                             ▼  (4 single-wire links)
   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
   │ESC MCU 1 │ │ESC MCU 2 │ │ESC MCU 3 │ │ESC MCU 4 │  AT32F421 / STM32G071 (AM32)
   │48 kHz PWM│ │          │ │          │ │          │
   └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘
     3φ driver    3φ driver    3φ driver    3φ driver   (e.g. FD6288Q-class)
     6× MOSFET    6× MOSFET    6× MOSFET    6× MOSFET   (24 FETs total)
```

The 48 kHz figure is therefore the **ESC MCU's PWM frequency**. AM32 and BLHeli_32 both support this setting. It is not an H743 timer rate.
