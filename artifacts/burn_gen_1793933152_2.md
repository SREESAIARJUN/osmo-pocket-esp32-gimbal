# FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the hardware specification for Job #55, so this design is parameterized. Every quantity that depends on the motor, MCU or mechanics is listed in §0 and set in `GimbalConfig`. Substitute the measured values before tuning.

---

## 0. Baseline Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) | Any M4F/M7 works. |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs) | R ≈ 5–15 Ω, L ≈ 1–3 mH. |
| Encoder | 14-bit magnetic (AS5048A / MT6701) on each motor shaft | |
| Current sensing | 2-shunt inline or low-side | A voltage-mode fallback is given in §1.6. |
| PWM / current loop | 20 kHz center-aligned / 20 kHz | Ts_i = 50 µs |
| Velocity loop | 4 kHz | Ts_v = 250 µs |
| Angle loop + attitude | 1 kHz | Ts_θ = 1 ms |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR 8 kHz, SPI 24 MHz | |

i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
