# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Brushless Gimbal

## 0. Assumptions

I don't have the Job #54 specification, so the design rests on the assumptions in the table below. Every value is a single `constexpr` or config field in the code, so you can change any of them.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz (FPU + CORDIC). The code is portable C++17, with no heap and no exceptions. |
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A/MT6701 class) |
| Current sense | 2 or 3 low-side shunts. A voltage-mode fallback is included for drivers without current sense. |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted point-symmetric about the plate centroid (r₂ = −r₁), on separate SPI buses |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Attitude/Angle 1 kHz. IMU ODR is 8 kHz, decimated to 4 kHz. |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}
$$

**Park transform**, where θ_e = p·θ_m − θ_off is the electrical angle:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform**:

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant and PI design

The PMSM d-q model is:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

**Decoupling.** Feed forward the cross-coupling and back-EMF terms:

- v_d^ff = −ω_e·L·i_q
- v_q^ff = ω_e·(L·i_d + λ_m)

With these cancelled, each axis reduces to G(s) = 1/(Ls + R).
