# 3-Axis Gimbal: FOC Cascade, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the specifics of Job #48, so this design states its assumptions explicitly. Every parameter is a named constant you can replace with your measured values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-shunt low-side per axis (a voltage-mode fallback is provided) |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared FSYNC/CLKIN |
| Kinematic order | Yaw (base) → Roll → Pitch (camera) |

| Loop | Rate | Input | Output |
|---|---|---|---|
| Current (FOC) | 20 kHz (PWM center-aligned ISR) | i_abc, θ_e | v_αβ → SVPWM |
| Velocity + cogging FF | 4 kHz (every 5th PWM ISR) | encoder PLL ω | i_q* |
| IMU filter + fusion | 8 kHz (IMU ODR, data-ready ISR) | 2× gyro/accel | ω_cam, a_cam |
| Attitude (angle) | 1 kHz | quaternion error | joint rate cmds ω* |

The bandwidth separation rule I use is that each outer loop crosses over at ≤ 1/4 to 1/5 of the inner loop: ω_c,i ≈ 2π·1.5 kHz, ω_c,v ≈ 2π·150 Hz, ω_c,θ ≈ 2π·25 Hz.

## 1. FOC Current Loop

### 1.1 Transforms
Clarke (amplitude invariant, i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park, with θ_e = p·θ_m − θ_offset:
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park uses the transpose. Use θ_e advanced by 1.5 T_pwm·ω_e to compensate for the compute + PWM-update delay:
$$\theta_e^{\text{apply}} = \theta_e + 1.5\,T_s\,\omega_e$$
