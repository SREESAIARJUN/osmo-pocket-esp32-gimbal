## 0. Architecture Clarification and Assumptions

The STM32H743 does **not** drive the MOSFETs. The intended topology is:

```
[STM32H743 FC, ArduPilot] --4x bidir DShot600--> [4-in-1 ESC: 4x AM32/BLHeli_32 MCU @ 48 kHz PWM] --> 4x 3-phase bridges
```

The 48 kHz switching frequency belongs to the ESC MCUs. The H743's job is DShot generation and eRPM telemetry capture.

| Parameter | Symbol | Assumed value | Basis |
|---|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V | worst case for switching loss |
| Burst phase current, per ESC | I | 80 A | spec |
| PWM frequency | f_sw | 48 kHz | spec |
| MOSFET | n/a | 40 V, 3.3×3.3 DFN class | nano footprint |
| R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 1.6 mΩ | typical for this package |
| R_DS(on) tempco | α | 0.006 /K |
