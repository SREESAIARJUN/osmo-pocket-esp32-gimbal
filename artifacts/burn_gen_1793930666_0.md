# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #12): Power-Stage Model, Thermal Budget, Bi-directional DShot DMA Plan, and Netlists

## 0. Architecture and Assumptions

The STM32H743 does not drive MOSFET gates. ArduPilot does not run ESC commutation firmware. The H743 is the flight controller (FC). Each of the four ESC channels has its own commutation MCU running AM32 (e.g., AT32F421 or STM32G071) and its own gate driver. The FC talks to the ESCs over bi-directional DShot600.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\qquad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 100 °C: R = 1.2 mΩ × 1.45 = **1.74 mΩ**.

### 1.2 Current paths in 6-step with synchronous rectification

In any commutation sector, two phases carry current:
- **The PWM'd phase:** current flows through the high-side switch for duty fraction D and through the low-side switch (synchronous rectification) for 1−D. The conduction loss is I²R·[D + (1−D)] = I²R, independent of duty.
- **The static phase:** the low-side switch is on continuously, giving I²R.
