# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original specification for "Job #2", so this design rests on the assumptions in §0. Every parameter that depends on them is a named constant, so you can swap in your real values.

---

## 0. Assumptions

| Item | Value |
|---|---|
| MCU | STM32G474 / H7 class, single-precision FPU, 170+ MHz |
| Motors | Gimbal BLDC, e.g. GM4108: N_s = 24 slots, 22 poles → p = 11 pole pairs, R = 10 Ω, L = 3.5 mH, K_t ≈ 0.12 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| Current sensing | Inline or low-side shunt, 2 phases |
| IMU A | ICM-42688-P on the camera payload (control feedback) |
| IMU B | ICM-42688-P on the base/handle (disturbance reference) |
| Kinematic chain | Yaw (outer) → Roll → Pitch (inner/camera). Intrinsic Z-X-Y order. |
