# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Model, Thermal Budget, and Bi-Directional DShot600 Design

**Job #36, Architecture Design Package, Rev A**

---

## 0. Architecture Constraints

Three facts shape the rest of this document.

1. **The H743 does not commutate the motors.** ArduPilot has no field-oriented or six-step motor-control firmware for the main flight MCU. A real AIO board uses four ESC MCUs, typically AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743 talks to them over bi-directional DShot600. The 48 kHz PWM is generated on the ESC MCUs.

2. **80 A per motor on a "nano" board is a transient rating.** Section 3 shows roughly 85 W of power-stage dissipation at 4×80 A. A 20×20 mm or 25.5×25.5 mm board cannot reject that continuously. The design target is therefore:
   - **80 A for 1–3 s bursts**
   - **about 35–40 A continuous per motor**, with prop-wash airflow

   Marketing should not quote 80 A as a continuous figure.

3. **Component values are representative.** I use parameters for a typical 40 V, ~1 mΩ, PDFN 3.3×3.3 or 5×6 MOSFET. Before layout freeze, substitute datasheet values for the selected part. The equations hold regardless of part choice.

**Design basis:**
- 6S LiPo, V_bus = 25.2 V max (22.2 V nominal)
- 30.5×30.5 mm mounting
- 8-layer, 2 oz outer / 2 oz inner copper

## 2. Power-Stage Electrical Model (per ESC channel)

### 2.1 Operating regime

AM32 uses six-step trapezoidal commutation with complementary (synchronous-rectified) PWM:

- At any instant, one phase is PWM'd with a HS/LS complementary pair, one phase has its LS held on, and one phase floats.
- Current flows through **one high-side and one low-side path** continuously, whether that path is the active FET or its complement.
- Only **one half-bridge hard-switches** at any time.

**Parameter definitions:**

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S full charge |
| I_ph | 80 A | burst, DC-equivalent phase current |
| f_sw | 48 kHz | |
| R_DS(on),25 | 1.0 mΩ | @ V_GS = 10 V |
| k_T | 1.5 | R_DS(on) multiplier at T_j ≈ 110 °C (typ. 0.4–0.5 %/K) |
| Q_g / Q_gd / Q_gs2 | 50 / 10 / 5 nC | |

| Q_rr | 40 nC | body diode |
| V_SD | 0.8 V | body diode at 80 A, hot |

| V_drv | 10 V | gate drive |
| R_drv + R_g,ext + R_g,int | 2 + 10 + 1 Ω | |
| V_plateau | 3.0 V | |

### 2.2 Conduction loss

With one HS and one LS path conducting at all times:

$$P_{cond} = 2\,I_{ph}^2\,R_{DS(on),25}\,k_T$$

$$P_{cond} = 2 \times 80^2 \times 1.0\,\text{m}\Omega \times 1.5 = \mathbf{19.2\ W}$$

**Board copper conduction.** This is often ignored but matters at 80 A.

- 2 oz copper has a sheet resistance of R_□ ≈ 0.25 mΩ/□ at 25 °C, rising to about 0.31 mΩ/□ at 85 °C.
- Phase path: about 3 squares from FET to motor pad, paralleled on 4 layers gives ≈ 0.23 mΩ hot.
  - P = 80² × 0.23 m ≈ **1.5 W per phase-pair path**, times 2 paths = **2.9 W per ESC**.

### 2.3 Switching loss (hard-switched leg)

**Gate current during the Miller plateau:**

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{tot}} = \frac{10-3}{13} = 0.54\,\text{A}, \qquad I_{g,off} = \frac{V_{pl}}{R_{tot}} = 0.23\,\text{A}$$

**Transition times** (Q_gs2 + Q_gd = 15 nC):

$$t_r = \frac{15\,\text{nC}}{0.54} = 28\,\text{ns}, \qquad t_f = \frac{15\,\text{nC}}{0.23} = 65\,\text{ns}$$
