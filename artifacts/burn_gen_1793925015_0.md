## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

In any commutation sector:
- One leg PWMs (high-side for D, synchronous low-side for 1−D).
- One low-side is held on as the return path.
- The third leg floats (BEMF sense).

Phase current *I* therefore always flows through exactly **two** conducting channels:

$$P_{cond,bridge} = I^2\left[D\,R_{HS} + (1-D)\,R_{LS}\right] + I^2 R_{LS,ret} \approx 2\,I^2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)],\qquad \alpha \approx 0.005\ /^\circ\text{C}$$

| T<sub>j</sub> | R<sub>DS(on)</sub> |
|---|---|
| 25 °C | 1.20 mΩ |
| 100 °C | 1.65 mΩ |
| 125 °C | 1.80 mΩ |
