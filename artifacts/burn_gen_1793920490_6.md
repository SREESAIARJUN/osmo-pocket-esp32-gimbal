# Job #59: STM32H743 Nano FC with Integrated 4-in-1 ESC

## Design Analysis: 80A Burst Thermal Model, 48 kHz Switching, Bi-Directional DShot600

---

## 0. Architectural Clarification

Before the math, three points about the architecture constrain everything that follows.

1. **The H743 does not commutate the motors.** ArduPilot does not implement sensorless 6-step or FOC commutation. In a 4-in-1 stack, each channel has its own ESC MCU (e.g. AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU generates the 48 kHz PWM. The H743 sends bi-directional DShot600 to the four ESC MCUs and receives eRPM telemetry back. The two domains are modeled separately below.

2. **"80A burst" on a nano board is a thermal-capacity problem, not a steady-state rating.** The model shows that all four channels at 80A can be sustained for only about 2–3 seconds before the board reaches 105 °C. That should be the headline spec, not "80A."

3. **Component values are representative assumptions.** Every Rds(on), Qg, Rth, and timing figure below is a placeholder. Replace each with the datasheet value of the selected part and re-run the equations. The equations are the deliverable; the numbers illustrate magnitude.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R = 1.4 × 1.45 = **2.03 mΩ** (use 2.0 mΩ).

### 2.2 Current path in 6-step with synchronous rectification

At any instant, two phases carry current. With complementary PWM, the current always flows through exactly two channels in series: one high-side or its synchronous low-side partner, plus the static low-side of the return phase.

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{ds}(T_j)$$

### 2.3 Ripple correction

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{\phi\phi}\, f_{sw}}$$

Near full throttle, V_bemf approaches D·V_bus, so ΔI is small. For an example L = 20 µH and a 5 A ripple, the correction is +2 A², which is negligible against 6400 A². The term is ignored at burst.

### 2.4 Result

$$P_{cond,ch} = 2 \times 80^2 \times 0.0020 = \mathbf{25.6\ W}$$

### 2.5 Per-FET distribution

Each of the 6 FETs per channel conducts for 120° of the electrical cycle.

- **Average per FET:** $\bar P_{FET} = \frac{2I^2R}{6} = \frac{I^2 R}{3} = 4.27\ \text{W}$
- **Instantaneous while conducting:** $I^2 R = 12.8\ \text{W}$

**Die ripple check.** Take 30k eRPM at burst, which gives f_e = 500 Hz and a conduction window of about 0.67 ms. Using an example transient thermal impedance of Z_th(0.67 ms) ≈ 0.3 K/W, the die temperature ripple is 12.8 × 0.3 ≈ **4 K**. This is acceptable, so the average-power model is valid.

### 2.6 Copper and connection losses (often forgotten)

| Path | Resistance (example) | Loss at 80A |
|---|---|---|
| Phase pad + trace | 0.3 mΩ | 1.9 W |
| Battery pads/planes, shared | 0.2 mΩ at 320 A | 20 W |

The shared battery path is significant. Use the thickest possible copper on the battery input, place the battery pads at the centerline, and mount the bulk capacitors directly on them.
