# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions and Architecture

I don't have the Job #33 specification, so the design below uses assumptions typical of a camera gimbal. Every assumption is a single constant in `Config`, so you can change any of them without touching the algorithms.

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, CORDIC optional |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per axis |
