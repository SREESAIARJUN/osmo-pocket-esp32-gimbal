## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz (FPU, CORDIC). Any Cortex-M4F/M7 works. |
| Motors | GBM2804-class gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Phase params | R = 5.6 Ω, L = 1.6 mH (line-to-neutral), K_t ≈ 0.055 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each axis, SPI |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR = 8 kHz |
| Supply | V_bus = 12 V |

### Loop rate hierarchy

The bandwidth separation is at least 5× between loops.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | f_c = 20 kHz (PWM-synchronous ISR) | ω_ci ≈ 2π·1500 rad/s |
| Velocity | f_v = 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle / attitude | f_θ = 1 kHz | ω_θ ≈ 2π·25 rad/s |
| IMU filtering | 8 kHz input, decimated to 4 kHz for the velocity loop | — |

### Sensor roles

- **Encoder:** commutation angle only, plus joint angles for the kinematic Jacobian.
- **Gyro (fused):** the velocity-loop feedback. This is inertial stabilization, which is the whole point of a gimbal.
- **Attitude estimate:** the angle-loop feedback.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is found at calibration by applying a d-axis voltage vector at θ_e = 0 and reading the encoder.

Latency compensation: the PWM update occurs about 1.5 T_s after current sampling. Advance the angle used for the inverse Park transform:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,T_s\,p\,\omega_m$$

### 1.2 Clarke transform (amplitude-invariant)

Assume i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame (SPM motor, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The motor constants relate as follows:

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q, \qquad \lambda_m = \frac{2K_t}{3p}$$

### 1.5 PI current controller with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning.** Once decoupled, the plant is 1/(Ls+R). Choosing

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

gives the closed loop

$$\frac{i_q}{i_q^*} = \frac{\omega_{ci}}{s+\omega_{ci}}$$
