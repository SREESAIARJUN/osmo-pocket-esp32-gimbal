# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #11 spec sheet, so I've assumed typical parameters for a hollow-shaft brushless gimbal (listed below). Every gain is computed from these physical parameters, so you can change them without re-deriving the equations.

| Parameter | Assumed value |
|---|---|
| Motor | GBM4108-class, 12N14P → pole pairs `p = 7`, `R = 5.6 Ω`, `L = 2.1 mH`, `Kt ≈ 0.12 N·m/A` |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| MCU | STM32G474 / H7 with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted on the camera plate |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera), i.e. `R = Rz(ψ)·Rx(φ)·Ry(θ)` |

### Loop rate hierarchy

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| IMU sampling | 8 kHz ODR (FIFO burst) | – |
| Velocity | 4 kHz | ~60–100 Hz |
| Angle | 1 kHz | ~12–20 Hz |
| Attitude (AHRS) | 1 kHz | – |

Each loop's bandwidth is at least 5× below the loop inside it. This keeps the cascade stable and lets each inner loop be treated as unity gain when tuning the outer loop.
