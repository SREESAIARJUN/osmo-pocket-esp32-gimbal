## 1. Conduction Loss Model

**Assumed drive scheme:** trapezoidal six-step drive with synchronous (complementary) rectification. In every commutation sector, two phases conduct.

- **Phase A, PWM leg:** the high-side FET is on for duty D, and its complementary low-side FET is on for (1−D).
- **Phase B, return leg:** the low-side FET is on for 100% of the sector.

Within the PWM leg, the current always flows through one FET, either the high side or the low side:

$$P_{cond,A} = I^2 R_{hot}\,D + I^2 R_{hot}(1-D) = I^2 R_{hot}$$

$$P_{cond,B} = I^2 R_{hot}$$

The total per motor is therefore independent of throttle duty (dead time excluded):

$$\boxed{P_{cond} = 2\,I_{ph}^2\,k_T\,R_{ds(on),25}}$$

$$P_{cond} = 2(80)^2(1.5)(1.0\times10^{-3}) = \mathbf{19.2\ W\ per\ motor}$$

### Copper Trace and Plane Loss

Phase and bus copper adds loss. For 2 oz copper, 2 layers in parallel, a 10 mm path, and 4 mm width:

$$R_{Cu} = \frac{\rho L}{w\,t} = \frac{1.72\times10^{-8}\cdot 0.01}{0.004\cdot 2\cdot 70\times10^{-6}} \approx 0.31\ \text{m}\Omega$$

$$P_{Cu} \approx 2 \cdot I^2 R_{Cu} \approx 4.0\ \text{W per motor}$$

This often-ignored term is about 20% of the FET loss. Use 4-layer, 2 oz copper with stitched pours.

### Peak Per-Device Dissipation

The always-on return FET carries the worst case:

$$P_{FET,pk} = I^2 R_{hot} = 6400 \cdot 1.5\times10^{-3} = 9.6\ \text{W}$$

$$\Delta T_{JC} = 9.6 \times 1.2 = 11.5\ \text{K}$$

Averaged over six sectors, each FET dissipates about 19.2/6 = 3.2 W.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Each loss term below applies once per motor.

**(a) V–I overlap loss (hard-switched inductive load):**

$$P_{VI} = \tfrac{1}{2}V_{bus}I(t_r+t_f)f_{sw} = 0.5(25.2)(80)(20\text{ns})(48\text{k}) = \mathbf{0.97\ W}$$

**(b) Reverse recovery loss:**

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.06\ W}$$

**(c) Output capacitance (C_oss) loss:**

$$P_{oss} \approx Q_{oss}V_{bus}f_{sw} = \mathbf{0.06\ W}$$

**(d) Dead-time body-diode conduction (two edges per period):**

$$P_{dt} = 2V_fI\,t_{dt}f_{sw} = 2(0.8)(80)(200\text{n})(48\text{k}) = \mathbf{1.23\ W}$$

**(e) Gate drive loss (2 switching FETs, mostly dissipated in the driver and gate resistor):**

$$P_g = 2\,Q_gV_{GS}f_{sw} = 2(50\text{n})(10)(48\text{k}) = \mathbf{0.05\ W}$$

### Per-Motor Loss Summary

| Term | Value (W) |
|---|---|
| Conduction (FETs) | 19.20 |
| Copper | 4.00 |
| V–I overlap | 0.97 |
| Dead time | 1.23 |
| Q_rr + Q_oss | 0.12 |
| Gate drive | 0.05 |
| **Total per motor** | **≈ 25.6** |
| **4 motors at 80A burst** | **≈ 102** |

**Sensitivities:**

- dP/dI ≈ 2·(2I·R_hot + 2I·R_Cu) ≈ 0.58 W/A at 80A, so loss is quadratic in current.
- Halving f_sw to 24 kHz saves about 1.1 W per motor.
- Reducing dead time to 100 ns saves about 0.6 W per motor.

### DC-Link Capacitor Ripple

$$I_{C,rms} = I\sqrt{D(1-D)} \le 0.5 I = 40\ \text{A per motor (worst case at } D=0.5)$$

Four channels interleave only loosely, so plan for ≥ 60–80 A_rms aggregate ripple. Use:

- Per channel: 4 × 10 µF/50 V X7R 1206 ceramics, placed within 3 mm of the half-bridges.
- Shared: 1 × low-ESR 35 V 1000 µF bulk capacitor at the pads, plus a TVS diode.

## 3. Thermal Model

### 3.1 Network

Each FET is modeled as a lumped Cauer network:

```
P_FET ─► [Tj]─R_JC(1.2)─[Tc]─R_spread(~8 K/W per FET into board)─[T_board]─R_conv─[T_amb]
                                                                  │
                                                             C_board (lumped)
```

### 3.2 Steady State (Shows Why 80A Continuous Is Impossible)

For a 30.5×30.5 mm board in prop wash (h ≈ 80 W/m²K, two sides, A ≈ 1.9×10⁻³ m²):

$$R_{conv} = \frac{1}{hA} = \frac{1}{80 \times 1.9\times10^{-3}} \approx 6.6\ \text{K/W}$$

$$\Delta T_{board,ss} = 102 \times 6.6 \approx 670\ \text{K}$$

This is physically impossible, so 80A must be treated as a transient.

**Continuous rating:** limit the board rise to 60 K, so P ≤ 9 W total, or about 2.3 W per motor. Solving 0.004·I² ≈ 2.3 gives about 24A per channel. With heatsink and good airflow (R_conv about 2 K/W), continuous current rises to about 40A.

### 3.3 Burst (Adiabatic Bound)

Board thermal capacity:

$$C_{board} \approx m_{PCB}c_{FR4} + m_{Cu}c_{Cu} + 24\,m_{FET}c_{Si/Cu} \approx 6(1.1) + 3(0.385) + 0.5 \approx 8.3\ \text{J/K}$$

Temperature rise with no cooling:

$$\Delta T_{board}(t) \approx \frac{P\,t}{C} = \frac{102\,t}{8.3} = 12.3\ \text{K/s}$$

Including convection, the board follows a first-order response with τ = R·C ≈ 55 s:

$$T_j(t) = T_{amb} + P\,R_{conv}(1-e^{-t/\tau}) + P_{FET,pk}(R_{JC} + R_{spread})$$
