# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and C++ Implementation (Job #42)

**Note on assumptions.** I don't have the Job #42 spec sheet, so this design uses the assumptions in §0. Every hardware-specific constant is in one config block, so you can change them in one place. Register values for the ICM-42688-P are taken from the datasheet as I recall it. **Verify them against the DS-000347 revision you build against** before first power-up.

---

## 0. System Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.11 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sense | 2 low-side shunts per motor, ADC synchronized to PWM center |
| MCU | STM32G474 / H7 class with FPU; all math in `float` |
| Mechanical order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → camera |
| IMU A | ICM-42688-P
