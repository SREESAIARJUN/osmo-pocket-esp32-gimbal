# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage Thermal Model, 48 kHz Switching Losses, and ArduPilot Bidirectional DShot600 Allocation (Job #59)

## 0. Architecture and Assumptions

**Architecture.** The STM32H743 cannot practically run four sensorless BLDC commutation loops and flight control at the same time. This design therefore uses:

- **FC:** an STM32H743 running ArduPilot. It generates bidirectional DShot600 and decodes eRPM telemetry.
- **ESC:** four independent ESC MCUs, either AT32F421 or STM32G071, running AM32 or BLHeli_32. Each drives an FD6288Q-class 3-phase gate driver and six N-MOSFETs. The ESC PWM frequency is 48 kHz.
