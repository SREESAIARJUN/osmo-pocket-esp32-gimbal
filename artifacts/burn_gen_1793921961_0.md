## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804-class): 12 slots (N12), 14 poles (P14) → pole pairs p = 7. R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701-class), read over SPI at 20 kHz |
| MCU | STM32G4/H7-class with FPU and center-aligned 3-phase PWM |
| IMUs | 2 × ICM-42688-P on the camera plate. IMU A sits at offset **r**, IMU B at offset −**r** from the plate's rotation centroid |
| Mounting | Each IMU has a known rotation **R_A**, **R_B** into the camera body frame |

The control loops are nested and run at decreasing rates:

```
ISR (20 kHz) ── encoder read → PLL → Clarke/Park → PI_d, PI_q → inv-Park → SVPWM
Task (4 kHz) ── IMU FIFO read ×2 → filter bank → dual-IMU fusion → velocity PI → i_q* + cogging FF
Task (1 kHz) ── attitude estimator → angle P(ID) → ω* (rate setpoint)
```

Each loop's bandwidth should be about 5–10× below the loop inside it. Suggested targets: current ~1.5 kHz, velocity ~150 Hz, angle ~20 Hz.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle comes from the mechanical angle, with θ_off found by calibration:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model

The motor dynamics in the rotating frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.3 Current PI with Decoupling

**Pole-zero cancellation tuning.** Choosing the gains below cancels the motor's R/L pole, so the closed loop becomes first order, $\frac{\omega_c}{s+\omega_c}$:

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c,\qquad \omega_c = 2\pi f_{c,i}$$

**Control law with feedforward decoupling.** The cross-coupling and back-EMF terms are cancelled explicitly:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

The setpoint is $i_d^* = 0$ (surface-mounted PM motor, no field weakening).

**Voltage limiting.** The command is clamped to the inscribed circle of the SVPWM hexagon:

$$\sqrt{v_d^2+v_q^2} \le \frac{V_{bus}}{\sqrt3}$$

d-axis priority is given: $v_q$ is limited to $\sqrt{V_{max}^2 - v_d^2}$.

### 1.4 Discrete PI with Back-Calculation Anti-Windup

The integrator uses forward Euler with sample period $T_s$:

$$u_k = K_p e_k + I_k,\qquad \bar u_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k)$$

A typical choice is $K_{aw} = 1/K_p$, normalized so that $K_{aw}K_p T_s$ is in the range 0.1–1.
