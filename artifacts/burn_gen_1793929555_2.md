# STM32H743 AIO Nano FC + 4-in-1 ESC: Power Stage, Thermal, and Bi-Directional DShot Design (Job #16)

## 0. Architecture and Assumptions

### Architectural clarification

The H743 does **not** generate the 48 kHz motor PWM. The system splits into two domains:

| Domain | MCU | Function |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz, LQFP100) | ArduPilot. Sends bi-directional DShot600 and receives eRPM telemetry. |
| 4-in-1 ESC | 4× STM32G071GBU6 (AM32), one per motor | 48 kHz complementary PWM, commutation, and the GCR telemetry reply. |

## 1. Conduction Loss Model

### 1.1 Current paths

Six-step trapezoidal commutation with complementary (synchronous) PWM is assumed. At any instant, one phase sources current and one sinks it.

- **Source leg.** The high-side (HS) FET conducts for fraction D. The low-side (LS) synchronous FET of the same leg freewheels for (1−D).
- **Return leg.** The LS FET conducts 100% of the time.
