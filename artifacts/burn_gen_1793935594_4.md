# STM32H743 AIO Nano FC with 4-in-1 ESC (Job #42): Power-Stage Physics, Thermal Model, and Bi-Directional DShot600 Architecture

## 0. Architecture Clarification and Stated Assumptions

**The H743 does not drive the MOSFETs.** In every production AIO design, the flight controller runs ArduPilot and sends DShot commands. Each of the four ESC channels has its own small MCU (for example AT32F421 or STM32G071 running AM32 or BLHeli_32). That MCU generates the 48 kHz complementary PWM, commutation and BEMF sensing. The model therefore splits into two domains:

| Domain | Owner | Key parameters |
|---|---|---|
| Power stage (losses, thermal) | ESC MCU + gate driver + 18 MOSFETs | 48 kHz PWM, 80 A burst, 6S |
| Command and telemetry link | STM32H743 timers + DMA (ArduPilot ChibiOS HAL) | DShot600 bi-directional, eRPM telemetry |

No MOSFET part number was specified, so I use a **representative 40 V, 5×6 mm PDFN trench MOSFET**. Every equation is parametric, so you can substitute datasheet values directly.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst case for switching loss) |
| I_burst | 80 A | Per-channel phase current, 10 s burst |
| f_sw | 48 kHz | ESC PWM frequency |
| R_ds(on),25 | 1.0 mΩ | At V_gs = 10 V |
| k_T | 1.5 | R_ds(on) multiplier at T_j ≈ 110–125 °C |
| t_r + t_f | 15 ns + 15 ns | Effective V-I overlap with a ~1.5 Ω gate path |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

The ESC uses six-step (trapezoidal) commutation with synchronous rectification (complementary PWM, AM32 default). At any instant, exactly two MOSFET positions carry the phase current I:

- **On-state (duty D):** high-side of phase X → motor → low-side of phase Y.
- **Off-state (1−D):** the synchronous low-side of phase X freewheels → motor → low-side of phase Y.

So the current always flows through two channels' worth of R_ds(on), independent of D:

$$P_{cond,ch} = I^2 \cdot 2 R_{ds(on)}(T_j) \quad\text{(outside dead time)}$$

With paralleled FETs per position (n_p), use R_ds/n_p. A nano 4-in-1 normally has n_p = 1.

### 1.2 Temperature-dependent R_ds(on) (electro-thermal feedback)

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right],\quad \alpha \approx 0.0055\ \text{K}^{-1}$$

At T_j = 115 °C: R = 1.0 × (1 + 0.0055 × 90) ≈ **1.5 mΩ**.

$$P_{cond,ch} = 80^2 \times 2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

The positive feedback loop is stable only if:

$$\frac{\partial P}{\partial T_j}\cdot R_{th,ja} < 1 \;\Rightarrow\; I^2 \cdot 2R_{25}\,\alpha\, R_{th,ja} < 1$$

With R_th,ja,eff ≈ 6 K/W (see §4), the left side is 6400 × 0.002 × 0.0055 × 6 ≈ **0.42**. The system is stable but has strong gain, with a runaway margin of only about 2.4×. This is why bursts must be time-limited.

### 1.3 PCB copper conduction

The current path is V_bus pad → plane → HS FET → phase pour → motor pad, plus the return path. On 2 oz copper with 6 layers paralleled, a realistic loop resistance is 0.3–0.6 mΩ per channel. Take 0.5 mΩ:

$$P_{Cu,ch} = 80^2 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W}$$

### 1.4 Per-FET distribution

Over one electrical cycle, each phase leg conducts 2/3 of the time. The per-FET average is approximately:

$$\bar P_{FET} \approx \frac{P_{cond,ch}}{6} \approx 3.2\ \text{W}$$
