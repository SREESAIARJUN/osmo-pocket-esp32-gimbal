## 1. Field-Oriented Control (inner loop, 20 kHz)

### 1.1 Transforms
Electrical angle: θₑ = p·θₘ − θ_offset (θ_offset is found by an alignment routine).

**Clarke transform** (amplitude-invariant, assumes i_a + i_b + i_c = 0):

  i_α = i_a,  i_β = (i_a + 2 i_b)/√3

**Park transform:**

  i_d = i_α cos θₑ + i_β sin θₑ
  i_q = −i_α sin θₑ + i_β cos θₑ

**Inverse Park transform:**

  v_α = v_d cos θₑ − v_q sin θₑ
  v_β = v_d sin θₑ + v_q cos θₑ

### 1.2 Plant and current PI with decoupling

Plant:

  L di_d/dt = v_d − R i_d + ωₑ L i_q
  L di_q/dt = v_q − R i_q − ωₑ (L i_d + λ_m)

Choose the PI zero to cancel the electrical pole (R/L). The closed loop then becomes first order with bandwidth ω_c:

  K_p = L·ω_c,  K_i = R·ω_c,  ω_c ≈ 2π·(f_s/20) ≈ 2π·1 kHz

Control law:

  v_d = PI_d(i_d* − i_d) − ωₑ L i_q
  v_q = PI_q(i_q* − i_q) + ωₑ (L i_d + λ_m)

Use i_d* = 0. Torque is τ = (3/2) p λ_m i_q = K_t i_q.

### 1.3 Voltage limiting and SVPWM

- The linear-region voltage limit is V_max = V_bus/√3.
- Give the d-axis priority: |v_d| ≤ V_max, then |v_q| ≤ √(V_max² − v_d²).
- Use min-max zero-sequence injection, which is equivalent to SVPWM:
  - v_off = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c))/2
  - D_x = ½ + (v_x + v_off)/V_bus

### 1.4 Discrete PI with back-calculation anti-windup

  u_k = K_p e_k + I_k
  ū_k = sat(u_k)
  I_{k+1} = I_k + K_i T_s e_k + K_aw T_s (ū_k − u_k),  with K_aw ≈ K_i/K_p

## 2. Velocity Estimation: Encoder PLL

A raw finite difference of a 14-bit encoder at 20 kHz is very noisy (one count ≈ 7.7 rad/s). Use a type-II tracking PLL instead:

  ε_k = wrap_π(θ_meas − θ̂_k)
  θ̂_{k+1} = θ̂_k + T_s (ω̂_k + K_p,pll ε_k)
  ω̂_{k+1} = ω̂_k + T_s K_i,pll ε_k

Gains: K_p,pll = 2ζω_n and K_i,pll = ω_n², with ζ = 0.707 and ω_n ≈ 2π·300 Hz.

The PLL also provides θ̂ as a sub-count-interpolated angle for both the commutation and the cogging tables.

## 3. Cascaded Stabilization Loops

```
θ_cam*  →[Angle PI + rate FF]→ ω* →[Velocity PI + accel FF]→ i_q,pid ─┐
   ↑ IMU attitude (1 kHz)          ↑ gyro rate projected on joint axis │
                                                                      (+)→ i_q* → FOC
                                       cogging FF  i_q,cog(θ̂ₘ, ω̂) ───┘
```

### 3.1 Bandwidth separation
Each outer loop should be at least 4–5× slower than the loop inside it:

  ω_c,current ≈ 2π·1000 > ω_c,vel ≈ 2π·150 > ω_c,angle ≈ 2π·25 rad/s
