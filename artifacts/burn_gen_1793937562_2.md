# STM32H743 Flight Controller + 4-in-1 80A ESC: Systems Design Package (Job #27)

## 0. Architecture and Scope

This package rests on one architectural point that drives everything else.

**The STM32H743 does not switch the MOSFETs.** In a 4-in-1 ESC stack:

| Domain | Device | Function |
|---|---|---|
| Flight controller | STM32H743 (ArduPilot) | Generates DShot600 frames and receives bidirectional eRPM telemetry |
| ESC | 4× ESC MCUs (AM32 or BLHeli_32 class, e.g., AT32F421 or STM32G071) | Commutation and the 48 kHz complementary PWM |
| Power stage | 4× three-phase gate drivers + 24 MOSFETs | 80A burst conduction and switching |

As a result, the thermal model (Sections 1–3) belongs to the ESC board. The DMA and timer model (Section 4) belongs to the H743. They interact only through the 8-pin harness (Section 5).

## 1. Conduction Loss Model (80A Burst)

### 1.1 Current path

In 6-step trapezoidal commutation with synchronous (complementary) PWM, two phases conduct at any instant:

- **PWM leg:** the high-side FET conducts for duty D. The complementary low-side FET conducts for (1 − D − 2t_dt·f_sw).
- **Return leg:** the low-side FET conducts for 100% of the 60° sector.

Through the dead-time intervals, current always flows through exactly two channel resistances (one per leg). The conduction loss is therefore essentially duty-independent:

$$P_{cond} = I^2 \cdot 2R_{ds}(T_j)\cdot\left(1 - 2t_{dt}f_{sw}\right)$$

### 1.2 Temperature-coupled solution

Because R depends on T_j, solve iteratively:

$$R_{ds}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right]$$

Using R₂₅ = 0.9 mΩ (max) and a target T_j = 110 °C:

$$R_{ds}(110) = 0.9\,(1 + 0.0045\cdot 85) = 1.244\ \text{m}\Omega$$

$$P_{cond} = 80^2 \cdot 2 \cdot 1.244\times10^{-3}\cdot(1-0.0096) = \mathbf{15.77\ W\ per\ ESC}$$

### 1.3 Copper and interconnect loss (frequently ignored, not negligible)

$$P_{Cu} = I^2\left(R_{phase\_trace}+R_{bus\_plane}+R_{solder/pad}\right)$$

With 2 × 0.15 mΩ of phase copper in the path, 0.10 mΩ of DC-bus plane share, and 0.05 mΩ of pads, the total is ≈ 0.45 mΩ:

$$P_{Cu} = 6400 \cdot 0.45\times10^{-3} = \mathbf{2.88\ W\ per\ ESC}$$

Copper resistance also rises at about 0.39%/K, so add roughly 20% at a 75 °C board temperature, giving **≈ 3.4 W**.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. The return leg is static within a sector.

### 2.1 Hard-switching V·I overlap (high-side FET)

$$P_{VI} = \tfrac{1}{2}V_{bus}I\,(t_r+t_f)\,f_{sw} = 0.5\cdot25.2\cdot80\cdot20\text{ ns}\cdot48\text{ kHz} = \mathbf{0.968\ W}$$

For a design margin, derive t_r and t_f from the gate-plateau model instead of datasheet typicals:

$$t_{r} \approx \frac{Q_{gd}\,R_{g,tot}}{V_{drv}-V_{plateau}}, \qquad t_{f} \approx \frac{Q_{gd}\,R_{g,tot}}{V_{plateau}}$$

### 2.2 Body-diode reverse recovery

The low-side body diode conducts during dead time and is then hard-commutated:

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.060\ W}$$

### 2.3 Output-capacitance loss

$$P_{oss} = \tfrac{1}{2}Q_{oss}V_{bus}f_{sw}\cdot 2 = 60\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.073\ W}$$

### 2.4 Dead-time diode conduction

$$P_{dt} = V_f\,I\,(2t_{dt})\,f_{sw} = 0.8\cdot80\cdot200\text{ ns}\cdot48\text{k} = \mathbf{0.614\ W}$$

### 2.5 Gate drive

This loss is dissipated in the driver and R_g, not in the FET die:

$$P_{gate} = 2\,Q_gV_{drv}f_{sw} = 2\cdot60\text{n}\cdot10\cdot48\text{k} = 0.058\ \text{W}$$

### 2.6 Per-ESC and quad totals (80A burst)

| Term | Per ESC (W) |
|---|---|
| Conduction (FETs at 110 °C) | 15.77 |
| Copper / interconnect | 3.40 |
| V·I switching | 0.97 |
| Dead-time diode | 0.61 |
| Q_rr + Q_oss | 0.13 |
| Gate drive | 0.06 |
| **Total** | **20.94** |
| **Quad (4 × 80A, worst case)** | **≈ 83.8 W** |

**Interpretation:** at 80A, conduction loss dominates (≈ 90%). Lowering f_sw would save less than 1.5 W per ESC. R_ds(on) and copper are therefore the levers that matter.

**Worst single FET:** the high-side PWM FET or the return-leg low-side FET.

$$P_{FET,max} \approx 80^2\cdot1.244\text{m} + P_{VI} + \tfrac{1}{2}P_{rr+oss} \approx 7.96+0.97+0.07 = \mathbf{9.0\ W}$$

## 3. Thermal Model

### 3.1 Network (Cauer / Foster hybrid)

```
P_FET ─[R_θjc 1.2 K/W]─ T_case ─[R_θcb ≈ 0.5 K/W (vias+pad)]─ T_board
                                                                 │
                                                       C_board ≈ 5 J/K
                                                                 │
                                                  R_θba (forced conv.) ─ T_amb
```

### 3.2 Board thermal capacitance

$$C_{board} = \sum m_i c_i \approx (3.5\text{ g FR4}\cdot1.1) + (2.5\text{ g Cu}\cdot0.385) + (\text{FETs, caps}\approx0.6) \approx \mathbf{5.4\ J/K}$$

### 3.3 Convective resistance under prop wash

For an effective two-sided area A ≈ 1.86×10⁻³ m² and h ≈ 60–120 W/m²K (prop-wash dependent):

$$R_{\theta ba} = \frac{1}{hA} \approx 4.5\text{–}9\ \text{K/W}\quad(\text{use } 6\ \text{K/W})$$

$$\tau = R_{\theta ba}C_{board} = 6\cdot5.4 \approx \mathbf{32\ s}$$
