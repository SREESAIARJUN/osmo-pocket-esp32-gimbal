# STM32H743 Nano AIO with 4-in-1 ESC: Systems Architecture Model (Job #50)

## 0. Scope, Assumptions and One Architectural Correction

**Architecture correction.** The STM32H743 should be the **flight controller**, not the commutation controller. Mainstream 4-in-1 ESCs run AM32 or BLHeli_32 on small, cheap MCUs (AT32F421, STM32G071, GD32E230), one per channel or a single MCU across four channels. A Cortex-M7 at 480 MHz doing commutation would waste power and board area. It would also have no supported firmware path. The model below therefore assumes:

- **H743 (FC, ArduPilot)** sends bidirectional DShot600 to **4 × AT32F421 (AM32)**.
- Each AT32F421 drives **1 × 3-phase gate driver**, which drives **6 × N-MOSFETs**.

**Design basis.** The 80 A burst figure is assumed to be per channel, because that is how ESC ratings are normally quoted. All derivations are parametric, so you can substitute your real datasheet numbers.

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | Battery voltage, 6S full | 25.2 V |
| I_b | Burst phase current per channel | 80 A |
| t_burst | Burst duration target | 5 s |

| R_ds(on),25 | MOSFET on-resistance (40 V, 5×6 or 3.3×3.3 class) | 0.9 mΩ |

**Physical reality check.** 4 × 80 A on a 20×20 nano board is not physically sustainable. Even on 30×30 the 80 A figure is strictly a **time-limited burst**, as Section 3 proves.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation topology

With 120° trapezoidal six-step drive and complementary PWM (AM32 default), the current path at any instant is:

- one high-side FET (PWM-switching), plus
- one low-side FET (static ON),

with the switching leg's synchronous partner conducting during the off-time. Exactly **two FET channels are always in the current path**, regardless of duty cycle D:

$$P_{cond,ch} = I_{rms}^2 \left[ D\,R_{HS} + (1-D)\,R_{LS,sync} + R_{LS,static} \right] = 2\,I^2 R_{ds}(T_j)$$

when all FETs are identical. This assumes flat-top current with negligible ripple, which is valid because motor L/R ≫ 1/f_sw.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 110 °C: R_ds = 0.9 × (1 + 0.0055 × 85) = **1.32 mΩ**.

### 1.3 Copper path resistance

The copper path adds to the FET resistance. Assume 4 layers of 2 oz pour in parallel, path length 12 mm, width 6 mm:

$$R_{Cu} = \frac{\rho_{Cu}(T)\,\ell}{w\,t\,n} = \frac{1.72\times10^{-8}(1+0.0039\cdot 85)\cdot 0.012}{0.006 \cdot 70\times10^{-6}\cdot 4} \approx 0.16\ \text{m}\Omega$$

### 1.4 Result per channel at 80 A

$$P_{cond} = 80^2 \left(2 \times 1.32 + 0.16\right)\times10^{-3} = 6400 \times 2.80\times10^{-3} = \mathbf{17.9\ W}$$
