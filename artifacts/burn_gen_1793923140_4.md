# Job #47: 3-Axis Gimbal FOC Control and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #47 spec sheet, so this design uses the parameters below. Every constant is a single `constexpr`, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC), one per axis or one for all 3 |
| Motor | Gimbal BLDC (GBM2804-class), 12N14P, so **pp = 7**, R = 5.6 Ω (phase), L = 1.8 mH, Kt ≈ 0.07 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sense | 2-shunt inline or low-side, sampled center-aligned |
| PWM / current loop | 20 kHz, current loop at 20 kHz |
| Velocity loop | 4 kHz (decimate by 5) |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on SPI @ 24 MHz, gyro ODR 8 kHz, accel 1 kHz |
| IMU-P | Mounted on the **payload** (camera plate). Used for feedback. |
| IMU-B | Mounted on the **base** (frame/handle/airframe). Used as vibration reference and disturbance feedforward. |
| Payload inertia (worst axis) | J ≈ 4×10⁻⁴ kg·m² |

## 1. Timing Architecture

```
TIM1 update (20 kHz, center-aligned) → ADC injected trigger
  ADC JEOC ISR  [prio 0]: read Ia,Ib, encoder θ → PLL → Clarke/Park → PI_d, PI_q
                          → inv-Park → SVPWM → write CCRs            (~6 µs budget)
  every 5th:   set PendSV flag
PendSV        [prio 1, 4 kHz]: velocity loop + cogging FF + base-rate FF → iq_ref
IMU DRDY EXTI [prio 2, 8 kHz]: SPI DMA both IMUs → filter chain →
