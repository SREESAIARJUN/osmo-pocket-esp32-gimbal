## 0. Architectural Clarification (Important)

Before modeling, the partitioning must be correct. On every production AIO of this class:

| Function | Silicon | Clock / Rate |
|---|---|---|
| Flight control, ArduPilot, DShot master | **STM32H743** (480 MHz, Rev V) | Loop 400 Hz – 2 kHz+ |
| Commutation, 48 kHz PWM, BEMF zero-cross | **4× ESC MCUs** (e.g., AT32F421 / STM32G071 / EFM8BB51) running AM32 or BLHeli_32-class firmware | PWM 48 kHz |
| Gate drive | 3-phase half-bridge driver per motor (e.g., FD6288Q class) | — |
| Power stage | 6 N-ch MOSFETs per motor (24 total) | — |

**The H743 does not generate the 48 kHz PWM.** It sends DShot600 frames to the ESC MCUs and receives eRPM telemetry back. Sections 1–2 model the ESC power stage. Section 3 models the H743 timer/DMA side.

## 1. Conduction Loss Model (80 A Burst, 6S)

### 1.1 Assumptions (replace with your datasheet values)

| Symbol | Value | Basis |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst case for switching) |
| I_ph | 80 A | Burst phase current |
| R_DS(on),25 | 0.80 mΩ | 40 V trench FET, 5×6 / 3×3 PQFN class, V_GS = 10 V |
| α (temp. coeff.) | 0.0045 /K | Typical normalized R_DS(on) slope |
| T_j (operating) | 125 °C | Design point |
| R_cu,path | 0.35 mΩ / motor | Pad, via, and plane path from battery pad to motor pad, 2 oz outer + 2 oz inner |
| R_shunt | 0.25 mΩ (shared) or none | Many nano ESCs use one bus shunt |

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)] = 0.80\,(1+0.0045\cdot100) = 1.16\ \text{m}\Omega$$

### 1.3 Six-Step Synchronous Commutation

In each 60° sector, two phases conduct:

- **PWM phase:** the high-side FET conducts for duty fraction D. The complementary low-side FET (synchronous rectification) conducts for (1 − D). Current flows in one FET or the other at all times, apart from dead time.
- **Static phase:** the low-side FET is on 100 % of the sector.

Per motor, therefore:

$$P_{cond,motor} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2\,I^2 R_{DS}(T_j)$$

$$P_{cond,motor} = 2 \cdot 80^2 \cdot 1.16\times10^{-3} = \mathbf{14.85\ W}$$

Copper path loss:

$$P_{cu} = I^2 R_{cu} = 6400 \cdot 0.35\times10^{-3} = \mathbf{2.24\ W}$$

### 1.4 Per-FET Worst Case (for junction checks)

The statically-on low-side FET carries the full current for its 120° electrical conduction window, so its average over one electrical revolution is:

$$P_{FET,LS,avg} \approx I^2 R_{DS}\cdot\tfrac{1}{3}(1 + \text{PWM share}) \approx 3.5\text{–}5\ \text{W}$$

Instantaneous dissipation during the conducting window is 80² × 1.16 mΩ = **7.4 W**. This is the value that drives Z_th(j-pcb) at motor electrical periods. Electrical periods run ~0.2–2 ms, which is short relative to FET thermal time constants, so the averaged value is valid for steady junction rise.

### 1.5 Thermal Runaway Check

Loss sensitivity to temperature:

$$\frac{\partial P_{cond}}{\partial T} = 2I^2 R_{DS,25}\,\alpha = 2\cdot6400\cdot0.8\text{m}\cdot0.0045 = 0.046\ \text{W/K per motor}$$

Board cooling conductance (Section 2.4) is about 0.25 W/K for 4 motors, or ~0.06 W/K per motor. Since 0.046 < 0.06, the system is **stable but with low margin**. At poor airflow (stationary bench test) the loop gain approaches 1 and temperature diverges. **Never bench-test 80 A without prop wash.**

## 2. Switching Loss Model (48 kHz)

### 2.1 Parameters

| Symbol | Value | Note |
|---|---|---|
| f_sw | 48 kHz | |
| t_r + t_f | 40 ns | ~1 A gate drive, small R_G; measure on prototype |
| Q_rr | 50 nC | Body diode |
| C_oss(er) | 1.5 nF | At 25 V |
| Q_g | 90 nC | At V_GS = 10 V |
| V_F | 0.8 V | Body diode at 80 A, hot |
| t_dead | 2 × 200 ns per period | AM32 default range |

### 2.2 Loss Terms per Motor

Only the PWM phase switches, so there is one hard-switched commutation pair per motor.

**V–I overlap (hard switching):**

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot40\text{n}\cdot48\text{k} = \mathbf{1.94\ W}$$

**Reverse recovery:**

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.06\ W}$$

(Hot Q_rr can double; budget 0.12 W.)

**Dead-time body-diode conduction:**

$$P_{dt} = V_F\, I\, (2t_{dead}) f_{sw} = 0.8\cdot80\cdot400\text{n}\cdot48\text{k} = \mathbf{1.23\ W}$$

This term is large. Trimming dead time to ~100 ns, if the driver propagation matching allows, saves about 0.6 W per motor.

**Output capacitance:**

$$P_{oss} = \tfrac12 C_{oss} V^2 f_{sw} \times 2 = 1.5\text{n}\cdot635\cdot48\text{k} = \mathbf{0.05\ W}$$

**Gate charge** (dissipated mostly in the driver and R_G, not the FET):

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\cdot90\text{n}\cdot10\cdot48\text{k} = \mathbf{0.09\ W}$$
