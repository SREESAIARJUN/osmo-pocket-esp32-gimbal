# STM32H743 FC + 80 A 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Design Package

## 0. Architecture Correction and Assumptions

**Architecture.** The STM32H743 does not commutate the motors. ArduPilot has no BLDC commutation firmware. The partition is:

- **FC (STM32H743 @ 480 MHz):** ArduPilot sends bidirectional DShot600 to four ESC MCUs.
- **4-in-1 ESC:** four independent MCUs (AT32F421 or STM32G071) running AM32 or BLHeli_32. Each drives one 3-phase bridge at 48 kHz PWM and returns eRPM over the same wire.

| Parameter | Value |
|---|---|

| Burst current | 80 A per motor (phase current of the conducting pair) |
| PWM | 48 kHz, 6-step trapezoidal, complementary (synchronous) PWM |
