# Job #32: STM32H743 Nano FC + 80A 4-in-1 ESC Design Package

## 0. Architecture Clarification and Assumptions

**The STM32H743 does not drive the MOSFET bridges.** In every production 4-in-1 stack, the H743 runs ArduPilot as the flight controller. Each motor channel has its own ESC MCU, typically an AT32F421 or STM32G071 running AM32 or BLHeli_32, which commutates the bridge. The H743 talks to those MCUs over bidirectional DShot600. This package is written for that architecture: an H743 FC plus four AM32-class ESC MCUs. A single H743 commutating four motors is possible in principle, but no ArduPilot firmware path supports it.

**MOSFET parameters are assumed.** They are representative of 40V, 3.3×3.3 mm DFN parts used on 20×20 and 30×30 stacks. Replace them with your selected part's datasheet values and rerun the equations; every result below is parametric.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S full charge |
| I_burst | 80 A | Phase-average per channel |
| R_ds(on),25 | 1.5 mΩ | At V_gs = 10 V |
| k_T | 1.5 | Multiplier for R_ds at T_j ≈ 110 °C |
| Q_g / Q_gd | 50 nC / 10 nC | Gate charges |
| C_oss,eff | 1.5 nF | Effective output capacitance |
| Q_rr | 30 nC | Body diode reverse recovery charge |
| V_f | 0.8 V | Body diode forward voltage |
| t_r, t_f | 10 ns each | With ~1.5 A gate drive |
| t_dead | 200 ns | Per edge |
| f_sw | 48 kHz | PWM frequency |
| R_θJC | 1.5 K/W | Per FET |

**Physics warning up front:** 80A on a nano-class (20×20) board is only achievable as a short burst, measured in seconds. The math below proves this.

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses trapezoidal 6-step commutation with complementary (synchronous) PWM. At any instant, two phases carry the full current I:

- **PWM phase:** the high-side FET conducts for duty D. The low-side FET of the same leg conducts for (1−D), excluding dead time.
- **Return phase:** the low-side FET is held on 100%.

### 1.2 Per-channel conduction loss

```
R_hot = k_T · R_ds,25 = 1.5 × 1.5 mΩ = 2.25 mΩ

P_cond,PWM-leg    = I²·R_hot·D + I²·R_hot·(1−D) = I²·R_hot     (independent of D with sync rect.)
P_cond,return-leg = I²·R_hot

P_cond,channel = 2·I²·R_hot
```

At 80A:

```
P_cond = 2 × 6400 × 0.00225 = 28.8 W per channel
```

### 1.3 Loss distribution across FETs

Rotating over 6 commutation states, each of the 6 FETs averages:

```
P_FET,avg = 28.8 / 6 ≈ 4.8 W
```

The instantaneous worst-case FET carries the full 14.4 W for 1/3 of the electrical period. The electrical period is short (for example, 4 ms at 14 pole-pairs and 1000 RPM), so thermal averaging applies to the junction.

### 1.4 Copper and bus loss

This loss is frequently ignored but significant. Assume 2 oz copper with an effective 8 mΩ round-trip bus and phase trace resistance per channel, plus 1 mΩ for the shunt.

```
P_Cu = I²·R_Cu = 6400 × 0.003 (phase traces, per channel) ≈ 19 W
```

This term is the strongest argument for thick copper and short phase pads.

On the shared DC bus, total current with 4 × 80A at average duty D ≈ 0.75 is about 240A (I_bus ≈ D·ΣI_phase). Through 1 mΩ of shared bus copper, that is about **58 W**. A nano board cannot sustain this. Realistically, "80A" means a single-channel burst rating, not all four channels simultaneously.

## 2. Switching Loss Model at 48 kHz

Only the PWM-leg FETs switch. The return leg is static.

| Term | Equation | Value |
|---|---|---|
| V-I overlap (hard-switched HS) | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·20 ns·48k | 0.97 W |
| C_oss charge | ½·C_oss·V²·f_sw = ½·1.5n·635·48k | 0.023 W |
| Reverse recovery (LS body diode) | Q_rr·V·f_sw = 30n·25.2·48k | 0.036 W |
| Dead-time diode conduction | V_f·I·2·t_dead·f_sw = 0.8·80·400 ns·48k | 1.23 W |
| Gate drive (2 switching FETs) | 2·Q_g·V_gs·f_sw = 2·50n·10·48k | 0.048 W (dissipated in driver) |
| **P_sw,channel** | | **≈ 2.3 W** |

Design levers:

- Dead-time loss dominates the switching budget. Cutting t_dead from 200 ns to 100 ns saves about 0.6 W per channel. Only do this if the driver propagation-delay mismatch allows it.
- Overlap loss scales linearly with f_sw. At 24 kHz it is about 0.48 W, but current ripple doubles (see §2.1).

### 2.1 Ripple check (justifies 48 kHz)

```
ΔI_pp = V_bus·D·(1−D) / (L_ph·f_sw)
```

With L_ph = 15 µH (a low-inductance racing motor phase-to-phase) and D = 0.5:

```
ΔI_pp = 25.2 × 0.25 / (15e-6 × 48e3) = 8.75 A
```

This is about 11% of 80A, which is acceptable. At 24 kHz the ripple would be 17.5 A, adding RMS loss and acoustic noise.

### 2.2 Total per-channel burst loss

```
P_total,ch = P_cond + P_sw + P_Cu,phase ≈ 28.8 + 2.3 + 19 ≈ 50 W
```

Even with heavy copper (R_Cu → 1 mΩ, giving 6.4 W), the floor is about 37 W.

## 3. Thermal Model

### 3.1 Steady state (proves burst-only operation)

| Path | R_θ |
|---|---|
| Junction to case (6 FETs in parallel paths, ~2 hot at once) | ≈ 0.75 K/W effective |
| Case to PCB (thermal vias, 2 oz) | ≈ 3 K/W per channel quadrant |
| PCB to air (20×20 board quadrant ≈ 1 cm², prop-wash h ≈ 100 W/m²K, both sides) | ≈ 50 K/W |

```
ΔT_ss = 37 W × ~54 K/W ≈ 2000 K
```

This is physically impossible. Steady-state 80A cannot exist on this board, so the rating must be transient.

### 3.2 Transient (lumped capacitance) model

Per channel quadrant, the thermal mass is:

- 6 FETs at ~0.1 g Cu equivalent
- PCB copper at ~1.5 g
- FR4 at ~1 g

```
C_th ≈ 1.6 g × 0.385 + 1 g × 1.1 + 0.6 (FETs + solder) ≈ 2.3 J/K

dT/dt = P / C_th = 37 / 2.3 ≈ 16 K/s
```

Starting from 50 °C board temperature with a 120 °C PCB limit (FR4 Tg margin and solder reliability):

```
t_burst ≈ (120 − 50) / 16 ≈ 4.4 s
```

### 3.3 Junction overshoot during burst

Using the datasheet's transient thermal impedance Z_θJC at the conduction pulse width (typically ≈ 0.3·R_θJC for a 10 ms pulse):

```
ΔT_jc = P_FET,peak · Z_θJC = 14.4 × 0.45 ≈ 6.5 K above case
T_j,peak ≈ 120 + 6.5 ≈ 127 °C
```

This is within a 150 °C (175 °C for some parts) limit, with margin for R_ds drift.

### 3.4 Thermal runaway check

R_ds rises with temperature, so conduction loss rises too: P = I²·R₀·(1 + α·ΔT), with α ≈ 0.005/K. The loop is stable if:

```
α·P_cond·R_θ,total < 1
```

During a transient the effective R_θ is low, so the loop stays stable. In steady state it would be unstable. **Firmware must therefore enforce burst limiting:** use the AM32 current limit plus a temperature-derate curve. Set the ArduPilot `BATT_*` current limits accordingly.

### 3.5 Recommended published rating

| Rating | Value |
|---|---|
| Continuous | ~35–45 A per channel (with prop-wash airflow) |
| Burst | 80 A for ≤ 3 s, single channel |
| All-4 burst | 60 A for ≤ 2 s (bus copper limited) |

If you need a true 80A continuous rating, move to a 30.5×30.5 board with 5×6 mm FETs and an external heatsink.
