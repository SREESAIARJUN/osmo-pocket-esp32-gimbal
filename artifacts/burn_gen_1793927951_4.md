# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

**Scope note:** I don't have the Job #22 spec sheet. Every assumption below is collected in one table and parameterized in the code (`Config` structs). Swap in your actual motor, encoder and MCU values. Gains are derived from those values, not hard-coded.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value | Symbol |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804H-100T) | pole pairs $p=7$ |
| Phase resistance / inductance | 5.6 Ω / 1.9 mH (line-neutral) | $R_s, L_s$ |
| Torque constant | 0.065 N·m/A | $K_t$ |
| Axis inertia (motor + payload) | 4.5·10⁻⁵ kg·m² (per axis, measure it) | $J$ |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) | $\theta_m$ |
| MCU | STM32G4 @170 MHz, FPU, 3-shunt sensing | — |
| Bus | 12 V | $V_{dc}$ |
| IMU A ("payload") | ICM-42688-P on camera plate, SPI @ 24 MHz | — |
| IMU B ("base") | ICM-42688-P on handle/drone mount, SPI | — |
