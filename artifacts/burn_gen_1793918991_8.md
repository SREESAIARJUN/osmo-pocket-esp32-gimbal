# STM32H743 AIO Flight Controller with 4-in-1 ESC: 80 A Burst, 48 kHz PWM, Bi-directional DShot600

**Design Basis Document, Rev A (Job #33)**

> **Scope and honesty note.** I have no access to prior Job #33 artifacts, so every component value below is a declared, representative assumption, and every result is parameterized so you can substitute datasheet values. The analysis contains one finding you need before reading further: **on a nano (20×20 mm) board, an 80 A per-motor burst on all four channels at once is limited to about 1 second by thermal capacitance.** The math is in §2.6. Treat "80 A" as a short-transient rating, never as continuous.

---

## 0. Architecture and Assumptions

### 0.1 Who does what

The H743 does **not** generate the 48 kHz phase PWM. On every real 4-in-1 design, each ESC channel has its own MCU running the commutation firmware (AM32 or BLHeli_32), and that MCU produces the 48 kHz switching. The H743 runs ArduPilot and talks to those four MCUs using bi-directional DShot600.

```
6S LiPo ──► VBAT bus (shared copper pour)
            ├─► ESC1: AT32F421 (AM32) → FD6288Q 3φ gate driver → 6× N-MOSFET → Motor 1
            ├─► ESC2 … ESC4 (identical)
            ├─► 12V/5V/3V3 buck chain → STM32H743VIT6 (ArduPilot), IMU, baro, OSD
            └─► INA-style shunt + amplifier → H743 ADC (battery current)
H743 ──DShot600 bidir (1 wire per motor, open-drain-style pull-up)──► ESC MCUs
```
