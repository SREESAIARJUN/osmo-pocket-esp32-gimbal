# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions and Architecture

I don't have the Job #43 specification, so the design below rests on stated assumptions. Each one is a single constant in the code, so you can change it.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701/AS5048-class), SPI |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7-class), 3-phase PWM, inline or low-side current sensing |
| IMU A | ICM-42688-P on the **camera payload** (stabilization reference) |
| IMU B | ICM-42688-P on the **base/handle** (disturbance feedforward, vibration reference) |
| Gimbal order | Base → Yaw → Roll → Pitch → camera |

The control loops run at the following rates:

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC d/q PI + SVPWM) | 20 kHz | PWM-center ADC interrupt |
| Velocity (rate) PI + cogging feedforward | 4 kHz | Every 5th current tick |
| Angle (attitude) loop | 1 kHz | IMU data-ready, decimated |
| IMU sampling | 8 kHz ODR, both IMUs, decimated to 4 kHz after filtering | IMU data-ready |

The cascade runs as follows: attitude error is fed to the angle P loop, which outputs a rate setpoint. The rate PI loop, using payload gyro feedback, outputs an i_q setpoint. That setpoint plus the cogging feedforward goes to the FOC current PI, then to SVPWM.

## 1. Field-Oriented Control Equations

### 1.1 Clarke transform (amplitude-invariant, balanced phases)
$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

### 1.2 Park transform
The electrical angle is θ_e = p(θ_m − θ_0), where θ_0 is the encoder offset from alignment.
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.3 PMSM model in the dq frame
$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

Torque is $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$, where $K_t = \tfrac32 p\lambda_m$.

### 1.4 Current PI with decoupling (pole-zero cancellation)
The plant per axis is $G_i(s) = \frac{1}{Ls+R}$. Choose the controller $C_i(s) = K_p + K_i/s$ with
$$
K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}
\;\Rightarrow\; L_{open}(s)=\frac{\omega_{ci}}{s}
$$

This gives a first-order closed loop of bandwidth ω_ci. Choose $\omega_{ci} \le 2\pi f_{PWM}/20$, e.g. 2π·1 kHz at 20 kHz.
