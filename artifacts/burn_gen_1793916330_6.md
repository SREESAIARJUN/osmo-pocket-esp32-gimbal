# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage and DShot Design Package (Job #37)

## 0. Architecture Clarification and Design Basis

**The H743 does not commutate the motors.** It runs ArduPilot and generates bi-directional DShot600. Each motor needs its own commutation MCU, because ArduPilot has no 6-step or FOC ESC firmware for the H7. The topology is:

```
6S LiPo ─┬─ Bulk/TVS ─┬─ 4× [ESC MCU (AT32F421, AM32 fw) → 3-ph gate driver → 6× N-FET] → Motors 1–4
         │            └─ Shunt + INA → H743 ADC (battery current)
         └─ Buck 5V/10V ─ LDO 3.3V ─ STM32H743VIT6 (ArduPilot) ── bi-DShot600 ×4 ──┘
```
