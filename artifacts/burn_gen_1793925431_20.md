# STM32H743 Nano FC + 4-in-1 ESC (Job #20): Power-Stage Loss Model, Thermal Analysis, and ArduPilot Bi-Directional DShot600 Allocation

**Result:** At 80 A per channel, losses are about 26 W per channel and about 103 W with all four channels saturated. A nano-class board has roughly 3–6 J/K of thermal mass. That supports an **80 A burst of about 1–2 s on one or two channels**, not four channels at 80 A for 10 s. ## 0. Architecture Baseline and Assumptions

The STM32H743 does not commutate the motors. It runs ArduPilot and talks bi-directional DShot600 to four independent ESC MCUs, which handle commutation at 48 kHz.

```
 ┌────────────────────────── FC SECTION ──────────────────────────┐
 │ STM32H743VIT6 @ 480 MHz   IMU (SPI1)   Baro (I2C2)   Flash/SD   │
 │   TIM3_CH3/CH4, TIM5_CH1/CH2 ──► M1..M4 DShot600 (bidir, 1-wire)│
 │   ADC: VBAT divider, CURR (shunt amp)                           │
 └─────────────┬───────────────────────────────────────────────────┘
               │ 4× DShot (open-drain/push-pull, 3.3 V, 100–220 Ω series)
 ┌─────────────▼──────────── ESC SECTION (×4) ─────────────────────┐
 │ AT32F421 (AM32)  ─►  3-ph gate driver (e.g. FD6288Q class)       │
 │                   ─►  6× N-MOSFET 40 V (3.3×3.3 DFN)             │
 │ BEMF dividers ◄── phase A/B/C        shunt ──► shared I-sense     │
 └──────────────────────────────────────────────────────────────────┘
```

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C:

R_ds = 1.2 mΩ × 1.425 = **1.71 mΩ**

### 1.2 Current path in 6-step with complementary (synchronous) PWM

At any instant the motor current flows through one high-side path and one low-side path.

- The active high-side FET conducts for a fraction D of the time.
- Its complementary low-side FET conducts for (1−D), excluding dead time.
- The opposite-leg low-side FET conducts continuously during that 60° sector.
