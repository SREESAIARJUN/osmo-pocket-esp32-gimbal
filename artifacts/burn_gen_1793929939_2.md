# FOC Motor Control and Sensor Fusion for a 3-Axis Gimbal

## 0. Scope and Assumptions

I have no access to the specification for "Job #60," so the design is fully parameterized. These are the baseline values I assumed. Replace them with your actual hardware numbers.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI, read at the current-loop rate |
| MCU | STM32G4/H7 class with FPU and CORDIC (or `sinf/cosf`) |
| PWM / current loop | 20 kHz center-aligned. Current loop runs at 20 kHz in the ADC-complete ISR. |
| Velocity loop | 4 kHz (decimation 5) |
| Angle / stabilization loop | 1 kHz (decimation 20) |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro and accel ODR 8 kHz, synchronized via CLKIN |
| Attitude estimator | 1 kHz Mahony complementary filter with vibration-gated accel correction |

Timing hierarchy:

```
 20 kHz  ADC ISR : encoder → PLL → anti-cog FF → Id/Iq PI → SVPWM
  8 kHz  IMU DRDY: dual-IMU read → AAF already in silicon → notch bank → LPF → fusion
  4 kHz  velocity PI (feedback = camera gyro ⊕ encoder rate)
  1 kHz  Mahony attitude → joint-space angle error → angle P + FF
```
