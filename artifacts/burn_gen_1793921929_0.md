## 0. Assumed Hardware Baseline

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class), on the rotor |
| Current sensing | 2-phase inline shunts + 12-bit ADC, sampled at the PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G4 / H7 class) |
| IMUs | IMU-P (payload/camera plate) and IMU-B (base/handle), both ICM-42688-P on SPI |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (each loop runs at least 4–10× slower than the loop inside it):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz, synchronous with PWM | ω_i ≈ 2π·1500 rad/s |
| Velocity | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle | 1 kHz | ω_θ ≈ 2π·30 rad/s |
| IMU sampling | 8 kHz ODR, decimated to 4 kHz | — |
| Attitude estimation | 1 kHz | — |

## 1. FOC Current Loop

### 1.1 Electrical Angle

θ_e = p · (θ_m − θ_offset)  (mod 2π)

θ_offset is found at commissioning: inject a d-axis current with θ_e forced to 0, let the rotor settle, and read the encoder.

### 1.2 Clarke Transform

Amplitude-invariant, assuming i_a + i_b + i_c = 0:

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3

### 1.3 Park Transform

- i_d =  i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 1.4 Motor Model in the dq Frame

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
- τ = (3/2) p λ_m i_q ≡ K_t i_q

### 1.5 Current PI with Decoupling (Pole-Zero Cancellation Tuning)

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes a first-order system with bandwidth ω_i:

- K_p,i = L ω_i
- K_i,i = R ω_i

The discrete control law, with sample time T_s = 1/f_PWM, is:

- v_d* = K_p,i e_d + x_d − ω_e L i_q
- v_q* = K_p,i e_q + x_q + ω_e L i_d + ω_e λ_m
- x_{k+1} = x_k + K_i,i T_s e_k + K_aw (v_sat − v_unsat)   (back-calculation anti-windup, K_aw ≈ 1/K_p,i)
