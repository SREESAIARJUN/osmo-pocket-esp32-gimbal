# STM32H743 AIO (FC + 4-in-1 ESC): Thermal, Switching, and Bidirectional DShot Design Package

## 0. Architecture Assumptions

An H743 running ArduPilot does not commutate motors directly. ArduPilot has no native ESC firmware path. So this design assumes the standard AIO split:

- **FC domain:** STM32H743 at 400 MHz, ArduPilot, sending bidirectional DShot600 to 4 ESC MCUs.
- **ESC domain:** 4× ESC MCUs (STM32G071 or AT32F421 class) running AM32 at 48 kHz PWM with synchronous rectification. Each drives a 3-phase half-bridge driver and 6 N-MOSFETs.

| Parameter | Value | Note |
|---|---|---|
| Bus voltage | 6S, V_bus = 25.2 V max | 22.2 V nominal |
| MOSFET | 40 V, 5×6 mm PDFN | R_ds(on)25 = 1.5 mΩ, Q_g = 50 nC, Q_oss = 50 nC, Q_rr = 60 nC, V_SD = 0.8 V |
| Effective switching edges | t_r + t_f = 40 ns | Set by gate resistor and driver |
| Dead time | 100 ns per edge | |
| Board | 30.5×30.5 mm pattern, 8 layers, 2 oz copper | |
| Burst current | 80 A phase-RMS per ESC | |

Substitute your actual MOSFET datasheet values into the equations below. The structure holds, but the numbers scale directly with them.

## 1. Conduction Loss Model

**Temperature-corrected resistance:**

R_ds(on)(T_j) = R_25 · (T_j/298)^α, with α ≈ 2.0–2.3 for trench silicon.

At T_j = 125 °C: R ≈ 1.5 mΩ × 1.6 = **2.4 mΩ**.

**Six-step commutation with synchronous rectification.** In each 60° sector, one leg is statically on and one leg PWMs complementarily (HS for D, LS for 1−D). One FET in each conducting leg is always carrying current:

P_cond,ESC = 2 · I_rms² · R_ds(on)(T_j) · (1 + r²/12)

where r is the inductor current ripple ratio ΔI/I. It is about 0.1 at 48 kHz with typical motor inductance, so the correction is under 0.1% and negligible.

**Evaluated at 80 A:**
- Per ESC: P_cond = 2 × 6400 × 0.0024 = **30.7 W**
- 4 ESCs (all motors at burst): **123 W**

**Hottest single FET:** the statically-on device takes I²R = **15.4 W** during its 120° conduction window. Averaged over one electrical cycle, it takes about 1/3 of that, but at low eRPM the window is long enough to matter thermally.

**Copper/plane losses** (often forgotten): a 2 oz layer has about 0.25 mΩ/sq. Assuming roughly 2 squares from pad to phase output across 2 paralleled layers gives about 0.25 mΩ per phase path. That adds 2 × 80² × 0.25 mΩ ≈ **3.2 W per ESC**.

## 2. Switching Loss Model at f_sw = 48 kHz

The model is evaluated per ESC. Only the PWM leg switches hard: the HS turns on and off hard, while the LS soft-switches.

| Term | Equation | Value |
|---|---|---|
| V-I overlap (HS) | ½ · V · I · (t_r + t_f) · f | ½ × 25.2 × 80 × 40 ns × 48 kHz = **1.94 W** |
| Output charge | Q_oss · V · f | 50 nC × 25.2 × 48k = **0.06 W** |
| Reverse recovery (LS body diode) | Q_rr · V · f | 60 nC × 25.2 × 48k = **0.07 W** |
| Dead-time diode conduction | V_SD · I · 2·t_dead · f | 0.8 × 80 × 200 ns × 48k = **0.61 W** |
| Gate drive (6 FETs, driver-side) | 6 · Q_g · V_GS · f | 6 × 50 nC × 10 V × 48k = **0.14 W** |
| **Total P_sw per ESC** | | **≈ 2.8 W** |

**Frequency sensitivity:** dP_sw/df ≈ 55 µW/Hz per ESC.
- Dropping to 24 kHz saves about 1.3 W per ESC.
- Moving to 96 kHz costs about 2.7 W per ESC.

At 80 A, conduction loss is about 10× switching loss. A 48 kHz switching frequency is therefore not the thermal problem; R_ds(on) and copper are.

**Total burst dissipation:**

| Scope | Calculation | Result |
|---|---|---|
| Per ESC | 30.7 + 2.8 + 3.2 | **36.7 W** |
| 4 ESCs | 4 × 36.7 | **≈ 147 W** |
| Everything else | H743 ~0.5 W, BEC/regulators ~1–2 W | ~2 W |
| **P_total** | | **≈ 149 W** |

## 3. Thermal Model

### 3.1 Lumped Board Heat Capacity

| Element | Mass | c_p | C |
|---|---|---|---|
| Copper (8 × 70 µm × 9.3 cm²) | 4.7 g | 385 J/kg·K | 1.8 J/K |
| FR-4 (1.6 mm) | 2.75 g | 1100 J/kg·K | 3.0 J/K |
| 24 FETs, passives, ICs, solder | ~3 g | ~700 J/kg·K | ~2.1 J/K |
| **C_board** | | | **≈ 7 J/K** |

### 3.2 First-Order RC Model

C · dT/dt = P − (T − T_a)/R_sa

T(t) = T_a + P · R_sa · (1 − e^(−t/τ)), with τ = R_sa · C

**Assumptions:**
- R_sa ≈ 6 K/W for a bare 30×30 board in prop wash. It is about 15 K/W in still air.
- This gives τ ≈ 42 s.

Because the burst duration is much shorter than τ, the board behaves adiabatically:

dT/dt ≈ P / C = 149 / 7 ≈ **21 K/s**

### 3.3 Junction Rise Above Board (Hottest FET)

ΔT_jb = P_FET · Z_th,jc(t_p) + P_FET · R_th,solder

Assuming Z_th,jc(1 s) ≈ 1.0 K/W and R_th,solder ≈ 0.5 K/W, with P_FET ≈ 15.4 + 1.9 = 17.3 W:

ΔT_jb ≈ **26 K**
