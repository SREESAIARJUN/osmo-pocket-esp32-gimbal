# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #3, so I've designed against a typical brushless camera gimbal. Every assumption is collected in §0. They are also exposed as configuration constants in the code, so you can substitute your real numbers without changing the structure.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: FPU, 170+ MHz, 3 advanced timers |
| Motors | GM4108-class gimbal BLDC: 24N22P (p = 11 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Current sensing | 2-shunt or inline per motor. A voltage-mode fallback is provided. |
| Rotor encoder | 14-bit absolute magnetic sensor (AS5048A / MT6701), SPI |
| IMUs | 2× ICM-42688-P on camera plate, separate SPI buses, rigidly co-mounted |
| Base vibration | Multirotor; propeller fundamental at 80–250 Hz plus harmonics |

| Loop | Rate | Feedback signal |
|---|---|---|
| PWM | 25 kHz center-aligned | — |
| Current (d/q) | 25 kHz (ADC-triggered ISR) | Phase currents, encoder θe |
| Velocity | 5 kHz | Fused gyro (inertial rate), with encoder PLL as fallback |
| Angle / attitude | 1 kHz | Attitude quaternion from fused IMU |
| IMU sampling | 8 kHz ODR per IMU, read at 8 kHz, decimated to 5 kHz/1 kHz | — |

**Key design decision.** The stabilization loops close on the *inertial* sensors, not the encoder. The goal is to hold the camera still in inertial space, and the base disturbance enters through the motor stator. The encoder is used for:

- commutation (θe),
- cogging feedforward (θm),
- an optional joint-rate damping term.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.3 Decoupled PI with Pole-Zero Cancellation

Choose the PI zero to cancel the electrical pole, $K_i/K_p = R/L$. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}$$

At 25 kHz PWM this gives ω_c ≈ 2π·2 kHz.

Voltage commands with cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e \lambda_m$$
