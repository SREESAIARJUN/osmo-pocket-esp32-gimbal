# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #50)

## 0. Design Assumptions

I don't have the Job #50 specification, so the design below rests on the assumptions in this table. Every one of them is a parameter in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz or faster |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A, MT6701 or similar), one per axis |
| Platform IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, shared CLKIN |
| PWM / current loop | 20 kHz center-aligned PWM; current loop at 20 kHz (T_i = 50 µs) |
| Velocity loop | 4 kHz (T_v = 250 µs), synchronized to IMU data-ready (decimated) |
| Angle loop | 1 kHz (T_θ = 1 ms) |

**Loop architecture per axis:**

```
θ_ref ─►[Angle P + FF]─► ω_ref ─►[Velocity PI]─► i_q,ref ─►(+ i_q,cog)─►[d/q Current PI]─► SVPWM
          ▲  (IMU attitude)        ▲  (fused gyro)                         ▲  (phase currents, θ_e from encoder)
```

- **Commutation** always uses the encoder.
- **Stabilization** (angle and rate) uses the fused IMU data, mapped into joint space.
