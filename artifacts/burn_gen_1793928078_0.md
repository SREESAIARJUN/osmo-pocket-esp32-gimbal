## 1. FOC Current Loop (Innermost)

### 1.1 Transforms

Assume balanced phases (i_a + i_b + i_c = 0) and electrical angle θ_e = p·θ_m − θ_off.

**Clarke transform:**
- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

**Park transform:**
- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park transform:**
- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 Plant model and decoupled PI

The PMSM dq model is:
- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

Torque is τ = (3/2) p λ_m i_q = K_t i_q.

**Gain selection (pole-zero cancellation).** With crossover ω_c:
- K_p = L ω_c
- K_i = R ω_c

This makes the closed loop first order, i(s)/i*(s) = ω_c/(s + ω_c).

**Discrete PI with back-calculation anti-windup.** Ts = 1/f_pwm.

- e[k] = i*[k] − i[k]
- u_unsat[k] = K_p e[k] + I[k] + u_ff[k]
- u[k] = sat(u_unsat[k])
- I[k+1] = I[k] + K_i Ts e[k] + K_aw (u[k] − u_unsat[k])
- Use K_aw ≈ K_i Ts / K_p (≈ ω_c Ts).

**Decoupling feedforward:**
- u_ff,d = −ω_e L i_q
- u_ff,q = ω_e L i_d + ω_e λ_m

**Voltage limit.** Apply a circular limit |v_dq| ≤ V_bus/√3, with d-axis priority.

**Delay compensation.** Advance the angle used for the inverse Park by 1.5 Ts:

θ_e,pwm = θ_e + 1.5 ω_e Ts

### 1.3 SVPWM (min/max injection, equivalent to sector SVPWM)

1. Compute phase voltages:
   - v_a = v_α
   - v_b = −½ v_α + (√3/2) v_β
   - v_c = −½ v_α − (√3/2) v_β
2. Common-mode offset: v_0 = −½ (max(v_a, v_b, v_c) + min(v_a, v_b, v_c)).
3. Duty cycles: d_x = ½ + (v_x + v_0)/V_bus, for x ∈ {a, b, c}.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 What is regulated

For stabilization, the outer loop regulates **camera inertial attitude** from the IMU, not the motor angle.

**Attitude error.** With target q_t and estimate q̂ (from §4):
- q_e = q̂^{-1} ⊗ q_t
- e_cam = 2·sgn(q_e,w)·q_e,xyz (small-angle rotation vector, camera frame)

**Mapping to joint space.** For Yaw–Roll–Pitch with joint angles (ψ, φ, θ), camera angular velocity in the camera frame is

ω_cam = J(φ, θ) · [ψ̇, φ̇, θ̇]ᵀ, with

```
J = [ -cosφ·sinθ    cosθ    0 ]
    [  sinφ          0      1 ]      (rows: cam x, y(pitch), z ordering per your frame)
    [  cosφ·cosθ    sinθ    0 ]
```

The exact sign/row layout depends on your frame convention. Derive J from your URDF.

- Joint-space error: e_j = J⁻¹ e_cam.
