# STM32H743 Nano FC + 4-in-1 ESC (Job #24): Power-Stage Loss Model, Thermal Budget, and Bi-Directional DShot600 Timer/DMA Architecture

## 0. Scope, Partitioning, and Assumptions

### 0.1 System partitioning

The H743 does **not** generate the 48 kHz motor PWM. ArduPilot runs on the STM32H743 and sends DShot600 frames. Four ESC MCUs commutate the motors and run the 48 kHz PWM: one per motor, typically AT32F421 or STM32G071 class running AM32 or BLHeli_32. This split shapes the design:

| Domain | Owner | Relevant to |
|---|---|---|
| DShot600 TX, eRPM RX, timers, DMA | STM32H743 (ArduPilot) | Section 4 |
| 48 kHz PWM, dead time, commutation | ESC MCU firmware | Sections 1–3 |
| Gate drive, MOSFETs, sensing | ESC hardware | Sections 1–3, 5 |
