## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is found at calibration. Apply a d-axis current, let the rotor align, and record the encoder reading.

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Machine model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

where ω_e = p ω_m and λ_m = (2/3)K_t/p.

### 1.4 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation, so the closed loop is first order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Discrete form (forward Euler), with back-calculation anti-windup:

$$e_x[k] = i_x^* - i_x$$

$$I_x[k+1] = I_x[k] + K_{i,i}T_c\,e_x[k] + K_{aw}T_c\,(v_x^{sat}-v_x)$$

$$v_d = K_{p,i}e_d + I_d - \omega_e L i_q$$

$$v_q = K_{p,i}e_q + I_q + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limit (circular).** The SVPWM linear region has radius V_max = V_bus/√3. Give d-axis priority:

$$v_d^{sat}=\operatorname{clamp}(v_d,\pm V_{max}),\qquad v_q^{sat}=\operatorname{clamp}\!\left(v_q,\ \pm\sqrt{V_{max}^2-(v_d^{sat})^2}\right)$$

Set i_d* = 0. Gimbal motors never need field weakening.
