## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,\theta_m - \theta_{\text{off}}\big)$$

Here θ_off is found at commissioning: drive a d-axis voltage so the rotor aligns, then read the encoder.

### 1.2 Clarke and Park transforms

The phases are balanced, so i_a + i_b + i_c = 0.

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.3 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e(L i_d + \lambda_m)$$

The torque is

$$\tau = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q.$$

### 1.4 Current PI with decoupling

To cancel the pole, choose the gains so that the open loop becomes ω_c/s:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{\text{PWM}}}{10}$$

The controller adds decoupling feedforward terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(L i_d + \lambda_m)$$

The reference i_d* is 0, so the motor runs in MTPA for a surface PMSM.

### 1.5 Voltage limit and SVPWM

Limit the voltage vector circularly to the linear modulation range, giving priority to v_d:

$$|v|\le V_{\max}=\frac{V_{bus}}{\sqrt3}\,m_{\max},\quad v_q^{\lim}=\operatorname{sgn}(v_q)\sqrt{V_{\max}^2-v_d^2}$$

Then apply the inverse Park transform and inverse Clarke transform. SVPWM is implemented by min-max zero-sequence injection:

$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.6 Discretization (Tustin) with back-calculation anti-windup

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s\,\frac{e_k+e_{k-1}}{2} + K_{aw}T_s\big(\operatorname{sat}(u_k)-u_k\big)$$

Use K_aw ≈ K_i / K_p.

## 2. Velocity Estimation: Encoder PLL (20 kHz)

Differentiating the encoder signal directly amplifies quantization noise. A type-II PLL tracking observer avoids this:

$$\varepsilon = \operatorname{wrap}_{\pi}(\theta_{meas}-\hat\theta),\qquad \hat\omega \mathrel{+}= K_i T_s\,\varepsilon,\qquad \hat\theta \mathrel{+}= T_s(\hat\omega + K_p\varepsilon)$$

The closed-loop characteristic polynomial is s² + K_p s + K_i. Gains follow from

$$K_p = 2\zeta\omega_n,\qquad K_i=\omega_n^2,\qquad \zeta=1,\ \omega_n\approx 2\pi\cdot 300\,\text{Hz}$$

## 3. Cascaded Angle and Velocity Control

### 3.1 Plant seen by the velocity loop

The current loop is fast enough to treat as unity gain, so

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta_m) - B\omega - \tau_{dist}.$$

### 3.2 Velocity PI (4 kHz)

The design uses a "symmetric optimum"-style placement. The crossover is ω_v ≈ ω_c / 8:

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = \frac{K_{p,v}\,\omega_v}{4}$$

The control law combines the PI term, acceleration feedforward, and the cogging feedforward from §4:

$$i_q^* = \text{PI}_v(\omega^*-\omega_{fb}) + \frac{J}{K_t}\dot\omega^* + i_{q,cog}(\theta_m) \quad\text{(clamped to } \pm I_{max})$$
