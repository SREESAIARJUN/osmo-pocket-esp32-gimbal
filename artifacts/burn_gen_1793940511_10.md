# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I have no specifications for Job #29, so this design rests on the assumptions in §0. Every gain is derived from symbols (R, L, J, Kₜ, bandwidths), so you can substitute your measured values.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, e.g. 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A/MT6701), SPI |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, shared CLKIN |
| MCU | Cortex-M7/M33 with FPU (STM32H7/G4) |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates (all phase-locked to the PWM timer):**

```
PWM / current loop (FOC)   : 20 kHz  (Ts_i = 50 µs)   ← ADC trigger at PWM center
IMU sample + filtering     :  8 kHz  (Ts_g = 125 µs)  ← IMU DRDY, both IMUs on CLKIN
Velocity (rate) loop       :  4 kHz  (Ts_v = 250 µs)
Attitude estimator         :  2 kHz
Angle (attitude) loop      :  1 kHz  (Ts_θ = 1 ms)
Anti-cogging adaptation    :  4 kHz  (inside velocity loop)
```
