## 1. Control Architecture

```
 Setpoint (quat/RC) ─► [Angle P + ω_ff] ─► [Velocity PI + accel_ff] ─► Σ ─► [Current PI dq + decoupling] ─► SVPWM ─► Motor
                            ▲                    ▲                     ▲          ▲
                    attitude error (IMU)   gyro rate (IMU)   anti-cogging iq_ff   ia, ib (ADC), θe (encoder)
                                                                      ▲
                                                              θm (encoder), LMS learner
```

**Bandwidth separation.** Each inner loop is at least 5× faster than the loop around it:

- Current loop: ≈ 1.5–2 kHz
- Velocity loop: ≈ 100–150 Hz
- Angle loop: ≈ 15–25 Hz

## 2. Field-Oriented Control: Current Loop (20 kHz)

### 2.1 Transforms

With a balanced Y-connected motor (i_a + i_b + i_c = 0), only two phase currents need to be measured.

**Clarke transform:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform**, using electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Delay compensation.** Rotate the inverse-Park angle forward by the PWM transport delay:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

### 2.2 Motor Model and Torque

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \psi_m)$$

$$\tau = \tfrac32\, p\,\psi_m\, i_q = K_t\, i_q \quad (i_d^* = 0)$$

### 2.3 PI Controller with Pole-Zero Cancellation

Choose the PI zero to cancel the electrical pole (R/L). This gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10}$$

**Discrete form (forward Euler)** with decoupling feedforward:

$$v_q^* = K_p e_q + I_q + \omega_e(L_d i_d + \psi_m),\qquad v_d^* = K_p e_d + I_d - \omega_e L_q i_q$$

$$I_k = I_{k-1} + K_i T_s\, e_k + K_{aw}\,(v_{sat} - v_{unsat})$$

The last term is back-calculation anti-windup, with K_aw = 1/K_p.

### 2.4 Voltage Limit and SVPWM

**Circular voltage limit**, giving priority to the d-axis:

$$|v| \le V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

$$v_q \le \sqrt{V_{max}^2 - v_d^2}$$

**SVPWM via min-max injection** (equivalent to conventional SVPWM):

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 3. Velocity and Angle Loops (2 kHz)

### 3.1 Velocity PI

Mechanical plant per axis: J·ω̇ = K_t·i_q − τ_cog(θ_m) − τ_d.

For velocity crossover ω_v, with zero placed at ω_v/4 for phase margin ≈ 60°:

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\,\frac{\omega_v}{4}$$

The current reference combines PI output, inertia feedforward and anti-cogging feedforward:
