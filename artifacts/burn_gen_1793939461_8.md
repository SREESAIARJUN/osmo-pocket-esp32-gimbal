# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #37)

I don't have the Job #37 specification, so the design below states its assumptions explicitly. Every parameter is a named constant, so you can substitute your real values.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, at least 170 MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), for example GBM2804 class |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) |
| Current sense | 2-phase low-side shunts. A voltage-mode fallback is provided. |
| PWM / current loop | 30 kHz PWM, current loop at 30 kHz (center-aligned, sampled at the counter peak) |
| Velocity (rate) loop | 4 kHz |
| Angle (attitude) loop | 1 kHz |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro and accel ODR 8 kHz, data-ready interrupt |
| Gimbal order | Base → Yaw (Z) → Roll (X) → Pitch (Y) → camera |

Bandwidth separation rule: each outer loop's crossover should sit at most 1/5 (ideally 1/10) of the inner loop's crossover.
