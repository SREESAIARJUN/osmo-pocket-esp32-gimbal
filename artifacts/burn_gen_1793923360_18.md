## 0. Architecture Assumptions and Design Review Flags

The scope needs to be pinned down before the math, because several of these choices determine whether the design is feasible.

| # | Item | Position |
|---|------|----------|
| A1 | **The H743 does not commutate motors.** | It runs ArduPilot and emits DShot600 to four ESC MCUs (AT32F421K8U7 running AM32, one per motor). These MCUs drive a 3-phase gate driver (FD6288Q class). This is the standard 4-in-1 topology. Bi-directional DShot only makes sense with this split. |
| A2 | Supply | 6S LiPo: V_bus,max = 25.2 V, V_nom = 22.2 V. |
| A3 | "80 A burst" | Interpreted as **80 A phase (motor) current per motor**, for a burst of a few seconds. Battery current is lower: I_batt = D·I_phase. |
| A4 | MOSFET | 40 V, ~0.7 mΩ class PQFN 3.3×3.3 / 5×6. Assumed parameters: R_ds(on),25 = 0.70 mΩ, Q_g = 90 nC, Q_gd = 15 nC, Q_gs2 = 8 nC, V_plateau = 3.2 V, Q_rr = 60 nC, V_SD = 0.8 V, R_g,int = 1.0 Ω, R_θJC = 0.6 K/W. **Replace these with values from your selected part's datasheet.** |
| A5 | Modulation | 6-step trapezoidal, complementary (synchronous-rectified) PWM at f_sw = 48 kHz, dead time t_dt = 200 ns. |

> ⚠️ **Feasibility flag:** The thermal result in §3 shows that 4 × 80 A simultaneously on a nano-format board (20×20 or 25.5×25.5 mm) is survivable for **roughly 2–4 seconds**, not as a sustained rating. A 40 V FET on 6S also leaves limited avalanche margin. Both points are addressed below.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

In any 60° sector, phase A is the PWM'd high-side (HS) leg and phase B is the low-side (LS) return. The other phase floats.

- **During D·T_sw:** current flows HS_A → motor → LS_B.
- **During (1−D)·T_sw:** current freewheels LS_A (synchronous) → motor → LS_B.
