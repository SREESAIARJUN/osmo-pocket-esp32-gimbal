## 1. Field-Oriented Control: Inner Current Loop (20 kHz)

### 1.1 Electrical angle

Let θ_m be the mechanical angle from the encoder, θ_off the calibrated electrical zero, and p the number of pole pairs:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

For delay compensation, extrapolate by the PWM-to-sampling latency T_d (typically 1.5·T_pwm):

$$\hat\theta_e = \theta_e + p\,\omega_m T_d$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model and decoupling

The PMSM voltage equations in the rotating frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Adding decoupling and back-EMF feedforward makes each axis a first-order plant $1/(Ls+R)$:

$$v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.4 PI tuning by pole-zero cancellation

Use the controller $C(s)=K_p + K_i/s$. Choosing $K_i/K_p = R/L$ cancels the plant pole and gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Rule: keep ω_c ≤ 2π·f_pwm/20. At 20 kHz this gives ω_c ≈ 2π·1000 rad/s.

### 1.5 Discretization and voltage limiting

The integrator uses forward Euler:

$$x_k = x_{k-1} + K_i T_s e_k$$

The output is limited to the linear SVPWM hexagon-inscribed circle, $|v| \le V_{bus}/\sqrt3$. When the vector is clamped, it is scaled radially, and q-axis priority is applied:

$$v_{q,\max} = \sqrt{V_{\max}^2 - v_d^2}$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle/Velocity Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta) - b\,\omega - \tau_{dist}$$

### 2.2 Structure (bandwidth separation ≥ 4–5× per stage)

```
θ_ref ─►[P + FF]─► ω_ref ─►[PI + FF]─► i_q* ─► [Current PI] ─► SVPWM
          ▲  ω_ff        ▲  i_ff = Jα_ref/Kt + τ̂_cog/Kt
          θ (attitude)   ω (gyro ⊕ encoder)
```

For a stabilized gimbal, **the velocity feedback should be the fused gyro rate** projected onto the motor axis, because it is inertial and low-noise. The encoder rate is used only for commutation and for the cogging map.

### 2.3 Velocity loop (PI, 4 kHz)

$$i_q^* = K_{pv} e_\omega + K_{iv}\int e_\omega\,dt + \underbrace{\frac{J\,\dot\omega_{ref}}{K_t}}_{\text{accel FF}} + \underbrace{\frac{\hat\tau_{cog}(\theta_m)}{K_t}}_{\text{anti-cogging}}$$

Tuning by crossover placement at ω_v, with the inner loop treated as unity:

$$K_{pv} = \frac{J\omega_v}{K_t},\qquad K_{iv} = K_{pv}\frac{\omega_v}{4}$$

This places the PI zero a quarter-decade below crossover and gives about 76° of phase margin before delays.
