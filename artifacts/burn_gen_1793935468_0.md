## 0. Architectural Corrections and Assumptions

Three issues must be resolved before the math is meaningful.

**1. The H743 does not commutate the motors.** In a 4-in-1 ESC each channel has its own ESC MCU (AT32F421, STM32G071, or EFM8BB51) running AM32 or BLHeli. These MCUs generate the 48 kHz complementary PWM. The H743 only sends DShot600 frames and receives eRPM telemetry. The loss model therefore applies to the ESC power stage, and the DMA model applies to the H743.

**2. "80A burst" on a nano (20×20 mm) board needs a definition.** I compute both interpretations:
- **Case A:** 80A per channel (320A total).
- **Case B:** 80A total across four motors (20A per channel).

The analysis shows that Case A is not physically achievable on a nano footprint beyond roughly 1 s. This is the most important finding in the document.

## 1. Conduction Loss Model

In 6-step trapezoidal drive with synchronous rectification, two FET positions carry phase current at every instant:
- The low-side FET of the sinking phase.
- Either the PWM high-side FET (for duty D) or its complementary low-side FET (for 1−D).

$$P_{cond} = I^2 R_{DS,hot}\,[D + (1-D)] + I^2 R_{DS,hot} = 2\,I^2 R_{DS}(T_j)$$

with the temperature dependence

$$R_{DS}(T_j) = R_{DS,25}\,\big[1 + \alpha (T_j - 25)\big],\quad \alpha \approx 0.005\ /^\circ C$$

Copper and shunt losses are added separately:

$$P_{Cu} = I^2 (R_{sh} + R_{trace}),\quad R_{trace} \approx 0.3\ \text{m}\Omega \ \text{(2 oz, short pours)}$$

| | Case A (80A/ch) | Case B (20A/ch) |
|---|---|---|
| P_cond (FETs) | 2·6400·1.8m = **23.0 W** | 2·400·1.8m = **1.44 W** |
| P_Cu (shunt + trace) | 6400·0.55m = **3.5 W** | 400·0.55m = **0.22 W** |

## 2. Switching Loss Model at 48 kHz

### 2.1 Hard-switching V·I overlap
$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw}$$
- Case A: 0.5·25.2·80·40n·48k = **1.94 W**
- Case B: **0.48 W**

### 2.2 Dead-time body-diode conduction (two transitions per period)
$$P_{dt} = V_f\, I\, (2 t_{dt})\, f_{sw}$$
- Case A: 0.8·80·200n·48k = **0.61 W**
- Case B: **0.15 W**

### 2.3 Reverse recovery
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}·25.2·48\text{k} = \mathbf{0.06\ W}$$
(Q_rr scales with di/dt and I; the conservative value is used for both cases.)

### 2.4 Output capacitance (high-side and low-side)
$$P_{oss} = 2·\tfrac{1}{2} C_{oss,eq} V_{bus}^2 f_{sw} = 1\text{n}·635·48\text{k} = \mathbf{0.03\ W}$$

### 2.5 Gate drive (dissipated in the driver and gate resistors, not the FET)
$$P_g = 2\,Q_g V_{GS} f_{sw} = 2·40\text{n}·10·48\text{k} = \mathbf{0.04\ W}$$

### 2.6 Per-channel totals

| Loss | Case A | Case B |
|---|---|---|
| Conduction | 23.0 | 1.44 |
| Copper / shunt | 3.5 | 0.22 |
| Switching | 1.94 | 0.48 |
| Dead time | 0.61 | 0.15 |
| Q_rr + C_oss | 0.09 | 0.09 |
| **Per channel** | **≈ 29.1 W** | **≈ 2.4 W** |
| **Four channels** | **≈ 117 W** | **≈ 9.5 W** |

**Key observations:**
- At 80A, conduction loss is about 80% of the total. Raising f_sw from 24 kHz to 48 kHz adds only about 2.5 W per channel.
- **Design lever 1: FET R_DS(on).** This dominates everything else.
- **Design lever 2: dead time.** Reducing it from 100 ns to 50 ns saves 0.3 W per channel at 80A.
