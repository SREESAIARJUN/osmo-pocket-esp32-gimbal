# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model (Job #32)

## 0. Scope and Assumptions

The STM32H743 cannot practically run four sensorless BLDC commutation loops and fly the aircraft at once. The architecture is therefore:

| Block | Device | Role |
|---|---|---|
| FC MCU | STM32H743VIT6 (480 MHz, rev V) | ArduPilot. Generates bi-directional DShot600. |

## 1. Conduction Loss Model (80 A burst)

### 1.1 Topology

AM32 uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At any instant the phase current flows through exactly two conducting FETs:

- the PWM-switched leg: high side for D, low side for (1−D);
- the low-side FET of the return leg, which is fully on.

### 1.2 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R = 1.0 × 1.55 = **1.55 mΩ**.

### 1.3 RMS current including PWM ripple

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

Using L_LL = 20 µH (typical 2207 line-to-line), V = 25.2 V, D = 0.85, f = 48 kHz:

$$\Delta I = \frac{25.2 \times 0.85 \times 0.15}{20\times10^{-6}\times 48\times10^{3}} = 3.35\ \text{A}_{pp}$$

The ripple adds ΔI²/12 = 0.93 A², which is negligible against 6400 A².

### 1.4 Channel conduction loss

$$P_{cond,ch} = I_{rms}^2 \cdot 2R_{DS}(T_j) = 6401 \times 2 \times 1.55\,\text{m}\Omega = \mathbf{19.8\ W}$$

Over one electrical cycle each of the 6 FETs conducts for 120°. At full throttle the motor electrical frequency is about 5 kHz, far faster than the die thermal time constant (a few ms), so the loss averages per device:

$$P_{cond,FET} \approx 19.8/6 = 3.3\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate drive currents

Assume an FD6288 driver output resistance of about 6 Ω and an external 10 Ω gate resistor, giving R_total ≈ 17.5 Ω.

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{tot}} = \frac{10-4.5}{17.5} = 0.31\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{R_{tot}} = 0.26\ \text{A}$$

### 2.2 Transition times

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 35\ \text{ns}, \qquad t_{off} = \frac{11\ \text{nC}}{0.26} = 42\ \text{ns}$$

### 2.3 Loss terms per channel (V = 25.2 V, I = 80 A, f = 48 kHz)

| Term | Equation | Result |
|---|---|---|
| V–I overlap | ½·V·I·(t_on + t_off)·f | **3.73 W** |
| Dead-time body-diode conduction (t_dt = 200 ns, 2 edges) | V_F·I·2·t_dt·f | **1.23 W** |
| Reverse recovery | Q_rr·V·f | 0.06 W |
| C_oss discharge | ½·C_oss(er)·V²·f | 0.02 W |
| Gate drive (2 switching FETs) | 2·Q_g·V_drv·f | 0.04 W |
| **Total switching** | | **≈ 5.1 W** |

### 2.4 Channel and board totals

$$P_{ch} = 19.8 + 5.1 \approx \mathbf{24.9\ W\ per\ channel}$$

$$P_{board} \approx \mathbf{100\ W\ at\ 4 \times 80\ A}$$
