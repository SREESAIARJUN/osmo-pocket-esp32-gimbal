## 0. Scope, Assumptions & a Critical Architectural Note

### 0.1 The STM32H743 does not commutate the motors

In every production AIO design, the H743 runs ArduPilot and generates DShot600. Motor commutation (6-step or FOC, with PWM at 48 kHz) runs on **dedicated ESC MCUs**, such as 4× AT32F421 or 4× STM32G071 running AM32. The alternative is one ESC MCU per motor pair.

Running ArduPilot plus four 48 kHz commutation loops plus BEMF zero-cross detection on one H743 is not supported by ArduPilot. It would also violate the fault-isolation boundary: an FC hang must not lock the bridges ON.

This package therefore models:

```
[STM32H743 / ArduPilot] --4x bidirectional DShot600--> [4x ESC MCU (AM32)] --> [4x 3-phase bridges, 24 MOSFETs]
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In 6-step commutation, phase A is driven high (PWM) and phase B is held low. The current loop alternates between two states:

- **ON:** HS_A → motor → LS_B
- **OFF:** LS_A (synchronous rectification) → motor → LS_B

In both states, **exactly two MOSFETs carry the full phase current I**. With synchronous rectification, the conduction loss is therefore independent of duty cycle D:

```
P_cond,ch = I² · [ D·R_HS + (1−D)·R_LS + R_LS ]  ≈  2 · I² · R_DS(on)(T_j)
```

### 1.2 Temperature-dependent R_DS(on)

```
R_DS(on)(T_j) = R_25 · [1 + α·(T_j − 25)]        α ≈ 0.0059 /K
R(110 °C)     = 1.2 mΩ × 1.5 = 1.8 mΩ
```

### 1.3 Numerical result

```
P_cond,ch = 2 × 80² × 1.8e-3 = 2 × 6400 × 1.8e-3 = 23.04 W   per motor channel
```

Add the PCB copper loss. A typical phase path is about 0.3 mΩ (vias plus pad plus pour):

```
P_Cu,ch ≈ 80² × 0.3e-3 = 1.92 W
```

### 1.4 Per-device distribution

Each of the 6 FETs in a channel conducts for about one third of the electrical period in a heavily weighted state. The averages work out as:

```
P_FET,avg ≈ 23.04 / 6   ≈ 3.8 W
P_FET,pk  ≈ 23.04 / 2   ≈ 11.5 W   (instantaneous, during its conduction interval)
```

The peak value matters only if the electrical period is long compared with the FET die thermal time constant (~1–5 ms). At burst RPM (>1 kHz electrical), use the average value.

### 1.5 Thermal-runaway check

R_DS(on) rises with temperature, so loss rises with temperature. The loop is stable if the following holds:

```
dP/dT · R_θ < 1
→ 2·I²·R_25·α · R_θ,ja,eff < 1
→ 2 × 6400 × 1.2e-3 × 0.0059 × R_θ < 1
→ R_θ < 11 K/W (system level)
```

The system R_θ in §4 is about 8 K/W. The design is **stable, but with only ~27 % margin**. Do not let the board R_θ degrade, for example by conformal coat on the bottom pour or by an enclosed stack.

## 2. Switching Loss Model (48 kHz)

Per PWM period, one half-bridge per channel hard-switches: the high-side turns on and off, and the low-side commutates through its body diode during the dead time.

### 2.1 V·I overlap (hard switching)

```
P_sw = ½ · V_bus · I · (t_r + t_f) · f_sw
     = 0.5 × 25.2 × 80 × 18e-9 × 48e3
     = 0.871 W
```

### 2.2 Reverse recovery

```
P_rr = Q_rr · V_bus · f_sw = 40e-9 × 25.2 × 48e3 = 0.048 W
```

### 2.3 Output capacitance

```
P_oss ≈ ½ · Q_oss · V_bus · f_sw = 0.5 × 50e-9 × 25.2 × 48e3 = 0.030 W
```
