# STM32H743 FC + 4-in-1 ESC Nano Stack (Job #3): Architecture, Loss Model, DShot/DMA Plan and Netlists

No MOSFET, gate driver, board size or burst duration was specified, so I assumed representative values. Each assumption is labeled so you can substitute your datasheet numbers. Two architectural issues come first because they change the design.

---

## 0. Architecture Corrections

### 0.1 The H743 should not commutate the motors

Directly driving 4 three-phase bridges needs 12 complementary pairs (24 outputs) with hardware dead-time. The H743 does not have enough suitable timers:

| Resource | What it provides |
|---|---|
| TIM1, TIM8 (advanced timers) | 3 complementary pairs each, so only 2 motors |
| HRTIM | 10 outputs, so roughly 1.6 more motors, with awkward dead-time and fault mapping |

ArduPilot also does not run motor commutation on the FC.

**Correct partition:**

```
[STM32H743 FC] --4x bidirectional DShot600--> [4x ESC MCU, e.g. AT32F421 running AM32]
                                                     |
                                                     +-- 4x 3-phase gate driver --> 24x MOSFET
```

- The 48 kHz PWM is generated by each ESC MCU.
- The H743 owns DShot generation, eRPM capture, the harmonic notch and the flight control loops.

### 0.2 "Nano" and "80 A" conflict

On a 20×20 or 30.5×30.5 mm board, 80 A per motor is only achievable as a short, time-limited burst. Section 3 derives that limit (about 2–4 s from a 40 °C start). Treat it as a firmware-enforced constraint, not a continuous rating.

## 2. Electrical Loss Model (per motor, 6-step synchronous)

In each commutation sector exactly one high-side (HS) and one low-side (LS) FET path carries the phase current I. The HS FET is PWM'd at duty D and the LS FET in the same leg is driven complementarily (synchronous rectification). The opposite-phase LS FET is held ON for the whole sector.

### 2.1 Conduction loss

R_DS(on) depends on junction temperature:

R(T_j) = R₂₅ · [1 + α(T_j − 25)]

The current always flows through two channel resistances in series (PWM leg plus return leg), independent of D:

**P_cond = 2 · I² · R(T_j)**

| Condition | Result |
|---|---|
| T_j = 25 °C | 2 · 80² · 1.0 mΩ = **12.8 W** |
| T_j = 125 °C | 2 · 6400 · 1.4 mΩ = **17.9 W** |

Because R depends on T_j and T_j depends on loss, this is a positive feedback loop. Solve self-consistently with the thermal model in §3. Use roughly 16–18 W per motor for the burst design point.

**Distribution across FETs:**

- HS FET: I²·R·D
- Sync LS FET: I²·R·(1 − D)
- Return LS FET: I²·R

Each leg spends 1/3 of the electrical cycle as the PWM leg and 1/3 as the return leg, so the average per-FET loss is:

**P_FET,cond ≈ (2/6) · I²R ≈ 3.0 W** (averaged over a rotation at 125 °C)

The instantaneous peak per FET is I²R ≈ 9 W, which matters for Z_th(transient) at low eRPM.

### 2.2 Switching loss (hard-switched edges at 48 kHz)

Only the PWM'd leg switches.

**V–I overlap:**

P_sw = ½ · V · I · (t_r + t_f) · f_sw = 0.5 · 25.2 · 80 · 20 ns · 48 kHz = **0.97 W**

**Reverse recovery** (LS body diode recovers when the HS turns on):

P_rr = Q_rr · V · f_sw = 50 nC · 25.2 · 48k = **0.06 W**

**Output capacitance:**

P_oss = Q_oss · V · f_sw = 40 nC · 25.2 · 48k = **0.05 W**

**Dead-time body-diode conduction** (two edges per period):

P_dt = V_SD · I · 2·t_dt · f_sw = 0.8 · 80 · 200 ns · 48k = **0.61 W**

**Gate drive** (2 switching FETs, dissipated mostly in the driver and gate resistors):

P_g = 2 · Q_g · V_DRV · f_sw = 2 · 60 nC · 12 · 48k = **0.07 W**

### 2.3 Totals at 80 A, T_j ≈ 100–125 °C

| Loss | Per motor | ×4 motors |
|---|---|---|
| Conduction | 17.9 W | 71.6 W |
| Switching (overlap) | 0.97 W | 3.9 W |
| Dead-time diode | 0.61 W | 2.4 W |
| Q_rr + Q_oss | 0.11 W | 0.4 W |
| Gate | 0.07 W | 0.3 W |
| Shunt / copper / connectors (est.) | 2.0 W | 8.0 W |
| **Total** | **≈ 21.7 W** | **≈ 87 W** |

**Design insights:**

- Conduction dominates (about 82 %). Switching at 48 kHz costs only about 1.8 W per motor.
