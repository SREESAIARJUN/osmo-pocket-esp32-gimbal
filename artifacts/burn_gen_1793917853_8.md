# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original Job #5 specification, so this design uses the representative parameters below. Every one of them is a named constant in the code. Replace them with your actual hardware values before tuning.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| IMU A | ICM-42688-P on the **payload** (camera plate). Used for attitude and the rate loop. |
| IMU B | ICM-42688-P on the **base/handle**. Used as the vibration reference and for base-rate feedforward. |
| Kinematics | Yaw → Roll → Pitch (base → payload) |

The control loops run at four rates:

```
 20 kHz  PWM ISR      : encoder → Clarke/Park → current PI → SVPWM
  8 kHz  IMU DRDY ISR : read A+B → AAF (on-chip) → adaptive notch → NLMS → LPF
  4 kHz  Rate loop    : rate PID (payload gyro) + anti-cogging FF + base-rate FF → iq*
  1 kHz  Attitude     : Mahony AHRS → attitude P(I) → rate setpoint
```

Cascade bandwidth rule: each loop should be at least 4–6× faster than the loop outside it. Targets:

- current loop: about 2 kHz
- rate loop: about 150–250 Hz
- attitude loop: about 20–40 Hz
