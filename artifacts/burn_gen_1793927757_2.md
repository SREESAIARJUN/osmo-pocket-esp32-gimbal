# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #25)

## 0. Assumptions

I don't have the Job #25 spec sheet, so the design is parameterized around a typical stack. Every value below is a `constexpr` or a config field in the code. Replace them with your measured values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with single-precision FPU, 3 synchronized timers |
| Current loop (FOC) | 20 kHz, synchronous with center-aligned PWM |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the payload plate, SPI, ODR 8 kHz, ±2000 dps, ±16 g |
| Bus | 12–16 V; 2-shunt or 3-shunt low-side current sensing |

**Architecture.** The angle loop uses the payload attitude from IMU fusion. The velocity loop uses the inertial body rate, which is the fused gyro projected onto the motor axis. The current loop uses the encoder only, for commutation and the cogging map.

This "inertial rate" inner loop is what lets the gimbal reject base motion. Encoder-derived velocity would only stabilize the joint, not the camera.

## 1. Field-Oriented Current Control (20 kHz)

### 1.1 Transforms

**Electrical angle:**

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \pmod{2\pi}$$

**Clarke transform (amplitude-invariant), with $i_a + i_b + i_c = 0$:**

$$i_\alpha = i_a, \qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix} \begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI design

The surface PMSM model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

After decoupling, each axis reduces to the plant $G_i(s) = 1/(Ls + R)$.

Use a PI controller $C_i(s) = K_p + K_i/s$. Pole-zero cancellation ($K_i/K_p = R/L$) gives a first-order closed loop with bandwidth $\omega_c$:

$$\boxed{K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c}\qquad \omega_c \le \frac{2\pi f_{\text{PWM}}}{10}\;(\approx 2\pi\cdot 1.5\text{ kHz})$$

**Voltage command with decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$
