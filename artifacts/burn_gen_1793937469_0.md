# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

> **Assumptions.** I don't have the Job #53 specification, so I used typical gimbal values throughout:
> - **Motors:** gimbal BLDC, 12N14P (7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH.
> - **Encoders:** 14-bit magnetic (MT6701 / AS5048A).
> - **Processor:** STM32G4 / H7 class.
> - **IMUs:** two ICM-42688-P. **IMU-A** is on the camera plate (attitude feedback). **IMU-B** is on the gimbal base (disturbance feedforward).
>
> Every parameter is a named constant, so you can substitute the real values.

## 1. Loop Architecture and Rate Plan

| Loop | Rate | Target bandwidth | Input → Output |
|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (PWM-synchronous) | ω_c ≈ 2π·1.5 kHz | i_d*, i_q* → v_αβ → SVPWM |
| Velocity PI (+ cogging FF) | 4 kHz | ω_v ≈ 2π·120 Hz | ω* → i_q* |
| Angle P(+I) | 1 kHz (accumulate at 4 kHz) | ω_θ ≈ 2π·25 Hz | θ* → ω* |
| IMU sampling, notches, AHRS | 8 kHz ODR, filtered at 4 kHz | — | raw gyro/accel → camera attitude, base rate |

**Rule:** separate consecutive loop bandwidths by at least 4–5×. The total delay τ_d (ADC + computation + PWM half-period + IMU group delay) must satisfy ω_v·τ_d < ~0.3 rad to keep ≥ 45° phase margin.

**Signal flow:**

```
θ*_cam ─►(+)─► Angle P ─►(+)─► Vel PI ─►(+)─► i_q* ─► Current PI ─► SVPWM ─► Motor
          ▲ −            ▲ −  ▲ +        ▲ +
          │              │    │          └── i_q,cog(θ_e)   anti-cogging FF
   θ̂_cam (AHRS-A)        │    └── ω_ff = −J⁻¹ R ω_base      (IMU-B feedforward)
                         └── ω̂_joint (encoder + IMU-A blend)
```

## 2. Field-Oriented Current Loop

### 2.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad p = 7$$

**Clarke** (amplitude-invariant, two-shunt sensing with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Machine Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 2.3 Current PI with Decoupling (Pole-Zero Cancellation)

The plant per axis is $G_i(s) = 1/(Ls+R)$. Choose:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Add the decoupling and back-EMF feedforward terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set $i_d^* = 0$ (no field weakening is needed for a gimbal).

**Voltage limiting.** Use the circular limit $\sqrt{v_d^2+v_q^2}\le V_{dc}/\sqrt3$. Give d-axis priority, and let q receive the remainder:

$$v_{q,\max} = \sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}$$

### 2.4 Discrete PI with Back-Calculation Anti-Windup

With sample time $T_s$, error $e_k$, and saturation $\text{sat}(\cdot)$:

$$u_k = K_p e_k + I_k,\qquad \bar u_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s(\bar u_k - u_k),\qquad K_{aw}\approx K_i/K_p$$
