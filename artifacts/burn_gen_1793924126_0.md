# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #5): Loss Model, Thermal Budget, DShot DMA Plan, Reference Netlist

## 0. Architecture Corrections

These affect every number below.

1. **The H743 does not generate the 48 kHz motor PWM.** In a 4-in-1 AIO, the STM32H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU running AM32 or BLHeli_32, typically AT32F421 or STM32G071. That MCU generates the 48 kHz complementary PWM. The loss model applies to the ESC power stage. The DMA model applies to the H743.
2. **80 A on a 20×20 mm board is a burst rating limited by heat capacity, not a steady-state rating.** Section 4 shows four simultaneous 80 A channels saturate the board in about 3 s. Treat "80 A" as a single-channel or short-burst figure, and state the duration on the datasheet.
3. **All component parameters below are representative assumptions** (Table 1). Replace them with the selected MOSFET's datasheet values and re-run the equations before release.

## 1. Design Assumptions

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | Bus voltage (6S, full charge) | 25.2 V |
| I_ph | Burst phase current per channel | 80 A |
| f_sw | PWM frequency | 48 kHz |
| R_ds(25) | MOSFET on-resistance at 25 °C, V_gs = 10 V | 1.2 mΩ (40 V, 3.3×3.3 DFN class) |
| α | R_ds temperature coefficient | 0.0055 /K |
| T_j,design | Design junction temperature | 115 °C, giving R_ds ≈ 1.8 mΩ |
| t_r, t_f | Switching transition times (~1.5 A driver) | 20 ns each |
| Q_rr, Q_oss, Q_g | Diode recovery, output, and gate charge | 40 nC, 40 nC, 30 nC |
| V_f | Body-diode forward voltage | 0.8 V |
| t_dt | Dead time | 100 ns |
| L_ph-ph | Motor phase-to-phase inductance | 20 µH |
| R_cu | PCB copper per conduction path (bus to motor pad and back) | 0.5 mΩ |

**Commutation scheme:** six-step trapezoidal with synchronous complementary PWM (AM32 default).
- At any instant one phase is PWM'd: the high side conducts for duty D and the complementary low side for 1−D.
- One phase is held low-side on.
- One phase floats.

## 2. Conduction Loss Model

### 2.1 Instantaneous Loss

Synchronous rectification means exactly one FET in the PWM leg conducts at any time, in series with the held-on low side. Ignoring dead time:

$$P_{cond}(t) = I_{rms}^2\,\big[R_{ds}(T_j)\cdot 2\big]$$

This is **independent of duty cycle**, a key result for synchronous six-step.

### 2.2 Temperature Dependence

$$R_{ds}(T_j) = R_{ds(25)}\,[1+\alpha (T_j-25)] = 1.2\,(1+0.0055\cdot 90) \approx 1.80\ \text{m}\Omega$$

### 2.3 Ripple Current

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} \;\le\; \frac{25.2\cdot 0.25}{20\,\mu\text{H}\cdot 48\,\text{kHz}} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 = 6403.6\ \text{A}^2 \quad(\text{ripple contributes } <0.1\%)$$

### 2.4 Conduction Loss per Channel at 80 A

$$P_{cond,FET} = 6403.6 \cdot 2 \cdot 1.8\times10^{-3} = \mathbf{23.05\ W}$$

$$P_{cond,Cu} = 6403.6 \cdot 0.5\times10^{-3} = \mathbf{3.20\ W}$$

### 2.5 Per-FET Distribution

Each phase leg conducts for 2/3 of the electrical cycle, so the per-FET average is approximately:

$$P_{FET,avg} \approx \frac{23.05}{6} \approx 3.8\ \text{W}$$

The held-on low side sees a peak of I²·R_ds = 11.5 W during its 120° window. Check this peak against the FET's transient thermal impedance at the commutation period (Section 4.4).

## 3. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. Each term is per channel.

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·40 ns·48 kHz | **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 kHz | **0.05 W** |
| Output capacitance | Q_oss·V·f_sw (approximately) | **0.05 W** |
| Dead-time diode conduction | V_f·I·2·t_dt·f_sw = 0.8·80·200 ns·48 kHz | **0.61 W** |
| Gate drive (2 FETs) | 2·Q_g·V_gs·f_sw = 2·30 nC·10 V·48 kHz | **0.03 W** (dissipated mostly in the driver and gate resistor) |
| **Total switching loss** | | **≈ 2.68 W** |

**Sensitivities:**
- Overlap loss scales linearly with f_sw. At 24 kHz it falls to about 1.0 W, but ripple doubles (still negligible here).
- Dead-time loss scales with t_dt·I. Trimming the dead time from 100 ns to 50 ns saves about 0.3 W per channel.

| Scenario | Loss |
