# STM32H743 Nano FC + 80A-Burst 4-in-1 ESC: Systems Architecture Model (Job #21)

## 0. Scope and Assumptions

No datasheet set came with the job, so this document uses a **representative component set**. Every result is derived symbolically first, so you can substitute real datasheet values without changing the method. Three points should be settled before layout starts.

1. **Two-MCU split.** The STM32H743 runs ArduPilot and generates bidirectional DShot600. The ESC side uses one AM32-class MCU per motor (AT32F421K8U7) that commutates the bridge at 48 kHz. Putting H743 timers directly on the gate drivers is not viable with ArduPilot, which has no FOC or 6-step ESC firmware.
2. **80A on a nano (20×20 / 30.5×30.5) footprint is a short burst rating, not continuous.** The thermal model in §3 gives a time-limited envelope of about **6 s at 4×80A** under prop-wash cooling. Treat any "80A continuous" claim on this form factor as non-physical.
3. **Reference conditions:**

| Parameter | Value |
|---|---|
| Battery | 6S, V_bus = 25.2 V max (worst case for switching loss) |
| Ambient | T_amb = 40 °C |
| Board temperature limit | 110 °C |
| MOSFET junction limit | Tj ≤ 150 °C (derated target 125 °C) |

## 1. Power Stage Topology

Each ESC channel is a 3-phase bridge with **2 paralleled MOSFETs per switch**, giving 12 FETs per channel and 48 in total. The **4-in-1 board** is 30.5×30.5 mm, 8-layer, with 2 oz outer and 2 oz inner power planes.

### 1.1 Representative MOSFET (40 V, PDFN 3.3×3.3 or 5×6 class)

| Symbol | Value | Meaning |
|---|---|---|
| R_ds(on),25 | 0.90 mΩ @ Vgs = 10 V | On-resistance |
| α_R | 0.0065 /K | R(T) = R25·[1 + α(Tj − 25)] |
| Q_gs2 + Q_gd = Q_sw | 12 nC | Switching charge |
| Q_g(tot) | 60 nC | Total gate charge |
| Q_rr | 40 nC | Body-diode reverse recovery |
| Q_oss | 50 nC | Output charge at 25 V |
| V_plateau | 3.5 V | Miller plateau |
| R_g(int) | 1.0 Ω | Internal gate resistance |
| V_SD | 0.8 V | Body-diode forward drop |
| R_θJC | 1.2 K/W | Junction to case (bottom pad) |

**Gate driver:** FD6288Q-class 3-phase driver.
- Gate drive voltage V_DRV = 10 V (from a 10 V LDO).
- Effective driver output resistance R_drv ≈ 4 Ω.
- External gate resistance R_g(ext) = 5 Ω.
- Dead time t_d = 200 ns.
