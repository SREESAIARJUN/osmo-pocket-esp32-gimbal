## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), where p is the number of pole pairs.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Tuning

Each axis of the dq model is a first-order R-L plant with cross-coupling:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Use pole-zero cancellation: PI(s) = K_p + K_i/s, with K_i/K_p = R/L. The closed loop then becomes 1/(s/ω_c + 1), giving:

$$K_{p,i} = L\,\omega_{c},\qquad K_{i,i} = R\,\omega_{c},\qquad \omega_c \le 2\pi\cdot\frac{f_{PWM}}{20}\ (\approx 2\pi\cdot 1\,\text{kHz})$$

**Decoupling feedforward** (added after the PI):

$$v_d^{ff} = -\hat\omega_e L i_q,\qquad v_q^{ff} = \hat\omega_e(L i_d + \lambda_m)$$

### 1.3 Voltage Limiting and Anti-Windup

The voltage vector is limited to |v| ≤ V_bus/√3, the linear SVPWM region. The d-axis has priority:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

**Back-calculation anti-windup** (discrete form, sample time Tₛ):

$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(u_{sat,k} - u_{k})\big],\qquad K_{aw}\approx 1/T_s\cdot\tfrac{K_i}{K_p}$$

### 1.4 SVPWM (min-max zero-sequence injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12[\max(v_{abc}) + \min(v_{abc})],\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Velocity Estimation (Encoder PLL Observer)

Differentiating a 14-bit encoder at 4 kHz produces quantization noise of roughly 2π/16384 · 4000 ≈ 1.5 rad/s RMS-scale. A type-II PLL avoids this.

The error is wrapped to (−π, π]:

$$e_k = \text{wrap}(\theta_{m,k} - \hat\theta_k)$$

The observer state updates are:

$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + k_1 e_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + T_s k_2 e_k$$

$$k_1 = 2\zeta\omega_n,\quad k_2=\omega_n^2,\quad \zeta = 0.707,\ \omega_n \approx 2\pi\cdot 300\ \text{Hz}$$

Run the PLL in the 20 kHz ISR, or at the encoder sample rate.
