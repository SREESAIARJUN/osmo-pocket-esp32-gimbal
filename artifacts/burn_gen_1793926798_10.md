## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal PMSM/BLDC, 12N14P (Np = 7 pole pairs), Rs ≈ 5–15 Ω, Ls ≈ 1–3 mH |
| Rotor position sensor | 14-bit magnetic encoder (AS5048A/MT6701 class) per axis |
| Current sensing | 2 or 3 low-side shunts, ADC sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with a single-precision FPU |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera (IMUs on the camera/pitch link) |

**Loop rate hierarchy (bandwidth separation of ≥ 5–10× between nested loops):**

| Loop | Rate | Closed-loop bandwidth | Trigger |
|---|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz | ~1.5–2 kHz | ADC end-of-conversion ISR |
| Cogging feedforward | 20 kHz | — | inside current ISR |
| IMU filtering + fusion | 8 kHz | — | IMU DRDY / FIFO |
| Velocity PI (gyro-based) | 4 kHz | ~100–200 Hz | timer |
| Angle (attitude) P + FF | 1 kHz | ~20–40 Hz | timer |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = N_p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = N_p\,\omega_m$$

θ_off is found at calibration by applying a d-axis voltage vector at θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (power-variant, amplitude-invariant)

With three shunts, first remove the common-mode component: $i_x \leftarrow i_x - \tfrac13(i_a+i_b+i_c)$. Then:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame

$$v_d = R_s i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R_s i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

Electromagnetic torque for a surface PM machine (L_d ≈ L_q, so i_d* = 0):

$$\tau_e = \tfrac32 N_p \lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \hat\omega_e \hat L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \hat\omega_e(\hat L_d i_d + \hat\lambda_m)$$
