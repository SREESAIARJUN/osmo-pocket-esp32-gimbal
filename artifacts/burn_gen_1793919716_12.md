# STM32H743 Nano FC + 4-in-1 ESC (Job #64): Power, Thermal, and DShot Architecture

## 0. Assumptions and Design Risks

These are assumptions until the BOM is frozen. Every number below is parametric, so you can substitute datasheet values directly.

| Parameter | Assumed value | Notes |
|---|---|---|
| Bus voltage | 6S, 25.2 V max, 22.2 V nominal | 40 V MOSFETs required |
| Topology | FC (STM32H743) plus 4 independent ESC MCUs (AT32F421 / STM32G071 class, AM32 or BLHeli_32) | The H743 does **not** commutate motors. It sends DShot600 and receives eRPM telemetry. |
| MOSFET | 40 V, R_DS(on) = 1.2 mΩ at 25 °C (≈1.0 mΩ typ) in PDFN 5×6 | 3.3×3.3 parts are typically 2–3 mΩ, which roughly doubles the losses below |
| Gate driver | FD6288Q-class 3-phase driver, ~1.5 A source / 1.8 A sink | |
| PWM | 48 kHz, complementary (synchronous rectification) | |
| Burst | 80 A **per motor channel** | |

**Design risks to resolve before layout:**

1. **Battery current.** "80 A burst ×4" means 320 A from the pack. No XT60 or XT90 connector, and no nano-size pad, survives that. The realistic spec is either 80 A per channel for one or two channels transiently, or 80 A total. The model below covers the worst case (4 × 80 A), which you should treat as the thermal design boundary, not a sustained operating point.
2. **Board size.** At 20×20 mm, PDFN 5×6 FETs (24 required) physically do not fit. 80 A burst implies at least a 30.5×30.5 mm board, or a stacked FC/ESC design. I assume a stacked 30.5 mm design with a single-board option analysed.
3. **Heat source.** Conduction losses dominate at 80 A, not switching. The 48 kHz choice is thermally acceptable, as shown below.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)],\qquad \alpha\approx 0.006\ \text{K}^{-1}$$

At T_j = 110 °C:

$$R = 1.2\,\text{mΩ}\,(1+0.006\cdot 85) = 1.81\ \text{mΩ}$$

### 2.2 Six-step current path with synchronous rectification

At any instant, motor current flows through exactly **two** FET positions:

- The PWM leg: the high-side for duty D, and the complementary low-side for (1−D).
- The return leg: the low-side, fully on.

The per-ESC conduction loss is therefore independent of duty:

$$P_{cond,ESC} = I^2\,\big(2R_{DS(on)}(T_j) + R_{Cu} + R_{shunt}\big)$$

With R_Cu ≈ 0.25 mΩ (2 oz, 6-layer bus pours) and R_shunt = 0.25 mΩ:

$$P_{cond,ESC} = 80^2\,(3.62 + 0.25 + 0.25)\,\text{mΩ} = 6400 \times 4.12\,\text{mΩ} = \mathbf{26.4\ W}$$

### 2.3 Per-FET loss

Each phase leg conducts for 2/3 of an electrical revolution. The worst-case device is the low-side, which carries return current for 1/3 of the period plus freewheel during the PWM third.

Peak instantaneous dissipation:

$$p_{FET,inst} = I^2 R = 80^2 \times 1.81\,\text{mΩ} = 11.6\ \text{W}$$

Average per FET:

$$P_{FET,avg} \approx \frac{2 R I^2}{6} \approx 3.9\ \text{W}$$

## 3. Switching Loss Model at f_sw = 48 kHz

Switching occurs only in the PWM leg. Per ESC:

$$P_{sw} = \underbrace{\tfrac12 V I (t_r+t_f) f}_{\text{V–I overlap}} + \underbrace{Q_{rr} V f}_{\text{recovery}} + \underbrace{\tfrac12 C_{oss}V^2 f \cdot 2}_{\text{output cap}} + \underbrace{V_F I\,(2t_{dt}) f}_{\text{dead-time diode}} + \underbrace{2 Q_g V_{GS} f}_{\text{gate (in driver)}}$$

Inputs: V = 25.2 V, I = 80 A, t_r + t_f = 20 ns, Q_rr = 40 nC, C_oss = 1.5 nF, t_dt = 50 ns, V_F = 0.8 V, Q_g = 50 nC, V_GS = 10 V.

| Term | Calculation | Loss |
|---|---|---|
| Overlap | 0.5·25.2·80·20 ns·48 k | 0.97 W |
| Q_rr | 40 nC·25.2·48 k | 0.05 W |
| C_oss | 1.5 nF·25.2²·48 k | 0.05 W |
| Dead time | 0.8·80·100 ns·48 k | 0.31 W |
| Gate (driver) | 2·50 nC·10·48 k | 0.05 W |
| **Total** | | **≈1.43 W/ESC** |

**Implications:**

- Switching is about 5% of conduction loss.
- Raising f_sw to 96 kHz adds only about 1.3 W per ESC.
- Driver dissipation is negligible, so the FD6288Q is fine.

### 3.1 Bus capacitor ripple

$$I_{C,rms} = I\sqrt{D(1-D)} \le 80 \times 0.5 = 40\ \text{A}_{rms}\ \text{(per ESC, D = 0.5)}$$

Phase interleaving across 4 ESCs is not guaranteed, so assume correlated worst case locally:

- **Per ESC:** at least 6× 10 µF/50 V X7R 1206, placed under 3 mm from each half-bridge.
- **Shared bulk:** 1× 470 µF/35 V low-ESR electrolytic, external on short leads.
- **Low-ESR polymer per ESC:** 2× 100 µF/35 V.
