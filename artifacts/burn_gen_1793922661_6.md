# FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

This document gives the equations and a C++17 implementation for:

- the cascaded current, velocity and angle loops,
- adaptive anti-cogging feedforward,
- dual ICM-42688-P vibration rejection and attitude fusion.

> **Assumptions.** I don't have the Job #20 spec sheet, so this design uses typical gimbal hardware, listed below. Every value is a named constant. Please confirm or replace them, especially the motor slot/pole count, because that sets the cogging harmonics.

| Item | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), p = 7 pole pairs, Rs ≈ 5 Ω, L ≈ 1.5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 / H7-class with FPU, center-aligned PWM at 20 kHz |
| Current sensing | 2 low-side shunts, sampled at PWM center. Voltage-mode fallback is provided. |
| IMU A | ICM-42688-P on the camera plate (attitude) |
| IMU B | ICM-42688-P on the base / handle (base-motion feedforward and redundancy) |
| Axis order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |
