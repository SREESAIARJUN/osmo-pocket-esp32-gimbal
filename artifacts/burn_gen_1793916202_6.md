# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #2 specification, so this design uses the stated **baseline assumptions** below. Every numeric constant lives in one config block so you can change them to match the actual hardware.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701 class) |
| MCU | Cortex-M4F/M7 (STM32G4/H7), hardware FPU, center-aligned PWM |
| Gimbal topology | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |
| IMUs | 2× ICM-42688-P **on the payload**, separate SPI buses, different mount positions/orientations |
| Loop rates | Current 20 kHz · IMU/filters 8 kHz · Velocity 2 kHz · Attitude 1 kHz |
| Vibration sources | Airframe props (frequency from ESC telemetry), fixed structural mode |

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle and latency compensation

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

PWM updates take effect about 1.5 periods after sampling (compute delay plus ZOH half-period). The angle used for the inverse Park transform is therefore advanced:

$$\hat\theta_e^{\,inv} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Clarke and Park transforms

Power-invariant scaling is not used. This is the amplitude-invariant form:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM model and decoupled current PI

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque (surface PM, so $L_d = L_q$):

$$\tau = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

**Control law.** This is a PI with feedforward decoupling and back-EMF cancellation, for $x\in\{d,q\}$:

$$v_x^* = K_{p,i}\,e_x + K_{i,i}\!\int e_x\,dt + v_{x,\text{dec}}$$
$$v_{d,\text{dec}}=-\omega_e L i_q,\qquad v_{q,\text{dec}}=\omega_e L i_d+\omega_e\lambda_m$$
