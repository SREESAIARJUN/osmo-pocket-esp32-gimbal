## 0. Architectural Assumptions

Every number below depends on these assumptions. Replace the bracketed `[ ]` parameters with values from the selected MOSFET datasheet, then rerun the equations.

| Item | Assumption |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V (full charge, worst case) |
| Topology | 4 independent 3-phase bridges, 1 MOSFET per switch (24 FETs), 3.3×3.3 mm DFN |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, 48 kHz |
| ESC control | **Per-ESC MCU** (e.g., AT32F421 running AM32). The H743 does **not** generate the 48 kHz bridge PWM. It sends bidirectional DShot600 to the ESC MCUs. |
| Gate driver | FD6288Q-class 3-phase driver, V_DRV = 10 V |
| "80 A burst" | Interpreted as **80 A phase current per motor**, simultaneously on all 4 motors (worst case) |
| Board | 30.5×30.5 mm mounting pattern ("nano" class), 8-layer, 2 oz copper on outer layers |
| Ambient | 40 °C, with propwash convection |
