## 0. Architecture Baseline and Assumptions

### 0.1 Partitioning

The STM32H743 runs ArduPilot and does not commutate motors. Each motor channel has its own ESC MCU, either AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware. The H743 talks to those MCUs over bidirectional DShot600. This is how every production AIO board works. Commutating four sensorless motors from the H7 alongside ArduPilot is not supported by ArduPilot.

```
VBAT(6S) ─┬─► 4× [ESC MCU + 3-ph gate driver + 6× N-MOSFET] ─► M1..M4
          └─► Buck 5V/3V3 ─► STM32H743 (ArduPilot) ──DShot600 bidir──► ESC MCUs
```

## 1. Conduction Loss Model

### 1.1 Topology Insight

With 6-step trapezoidal commutation and synchronous rectification (complementary PWM), exactly two MOSFETs are in the current path at every instant: one high-side and one low-side, in two different phases. Therefore the instantaneous bridge conduction loss is independent of duty cycle:

$$P_{cond,bridge} = 2\, I^2\, R_{ds(on)}(T_j), \qquad R_{ds(on)}(T_j) = R_{ds,25}\left[1+\alpha (T_j-25)\right] \approx k_T R_{ds,25}$$

### 1.2 Per-Device Distribution

Assume the high side carries the PWM and each phase sources for 120° and sinks for 120°.

$$P_{HS} = \tfrac{1}{3} D\, I^2 R, \qquad P_{LS} = \tfrac{1}{3}(1-D)\,I^2R + \tfrac{1}{3} I^2R = \tfrac{(2-D)}{3}I^2R$$

The worst-case device is the low-side FET at low duty cycle (D → 0), where P_LS → (2/3) I²R.

### 1.3 Numbers at 80 A

R_hot = 1.5 mΩ.

| Quantity | Result |
|---|---|
| P_cond,bridge | 2 · 6400 · 0.0015 = **19.2 W per channel** |

### 1.4 Copper Loss (Do Not Omit)

$$P_{Cu} = I^2 R_{trace}, \qquad R_{trace} = \frac{\rho_{Cu}(T)\, L}{W\, t}$$

Example: a 2 oz (70 µm) inner pair in parallel, phase path L = 15 mm, W = 4 mm.

- R ≈ 1.72e-8 · 0.015 / (0.004 · 140e-6) ≈ 0.46 mΩ, about 0.6 mΩ hot.
- At 80 A this adds about **3.8 W per channel**.

This is comparable to one FET's loss. Use 3 oz outer layers plus stitched inner pours.
