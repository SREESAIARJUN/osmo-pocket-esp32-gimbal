# STM32H743 4-in-1 ESC Nano Stack (Job #53): Design Reference

**Scope:** 80 A burst conduction model, 48 kHz switching-loss model, transient thermal model, ArduPilot bidirectional DShot600 timer and DMA plan, and reference netlists.

---

## 0. Architecture Clarification and Feasibility

**The H743 does not commutate the motors.** ArduPilot is a flight-control stack and contains no BLDC commutation firmware. The only workable architecture is:

```
STM32H743 (ArduPilot FC) ──4× bidir DShot600──► 4× ESC MCU (AT32F421 / STM32G071, AM32) ──► 4× 3-phase bridges
```

This document therefore designs the H743 as the FC and the "4-in-1" as four independent ESC MCU + bridge channels.

**The "nano" (20×20 mm) + 80 A burst combination is not thermally credible.** Section 3 shows four channels at 80 A dissipate about 120 W into roughly 2.6 J/K of board mass. That heats the board at about 45 K/s, so it overheats in about 1.5 s. The math is derived in full below so the decision can be audited. Section 3.5 gives the redesign recommendation.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.3 mΩ × 1.60 = **2.08 mΩ**.

### 1.2 Six-step synchronous bridge

In any of the six commutation sectors, two phases carry I_ph:

- **PWM leg:** the high-side conducts for D, and its complementary low-side conducts for (1−D).
- **Static leg:** the low-side stays fully on.
