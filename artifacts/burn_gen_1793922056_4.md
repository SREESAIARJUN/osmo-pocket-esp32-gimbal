## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class, 170 MHz, FPU (and optionally the CORDIC unit for sin/cos) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Gimbal joint order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (cascaded, each loop's bandwidth at least 4–10× below the inner loop's):**

```
PWM / current (FOC)  : 20 kHz   bandwidth ωc  ≈ 2π·1500 rad/s

IMU sampling         :  8 kHz   (internal AAF) → filtered → decimated to 4 kHz
AHRS (attitude)      :  1 kHz
Cogging learning     :  4 kHz   (active only when the conditions in §3.3 hold)
```

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle (with encoder offset θ₀ found by d-axis alignment):

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
