# Job #27: STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal & DShot Architecture

## 0. Scope, Assumptions and a Feasibility Warning

**Architecture.** The H743 cannot commutate four BLDC motors at 48 kHz while also running ArduPilot. The standard and correct partition is:

- **FC domain:** STM32H743 running ArduPilot. It emits bidirectional DShot600 on 4 timer channels and receives eRPM telemetry back.
- **ESC domain:** 4 × dedicated ESC MCUs (e.g. AT32F421 or STM32G071 running AM32), each driving 3 half-bridges at 48 kHz.

**Assumed design point.** These values are illustrative. Replace them with datasheet values before release.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, max / nominal) | V_bus | 25.2 V / 22.2 V |
| Burst phase current per ESC | I | 80 A |
| MOSFET (40 V, PDFN 5×6 class) R_DS(on) @ 25 °C, V_GS=10 V | R₂₅ | 1.0 mΩ |
| R_DS(on) temperature factor @ T_j=110 °C | k_T | 1.4 |
| Rise / fall time (2 A-class driver, R_g ≈ 2 Ω) | t_r / t_f | 15 / 12 ns |
| Body-diode Q_rr / Q_oss / Q_g | | 40 / 60 / 60 nC |
| Diode forward voltage | V_f | 0.8 V |
| Dead time | t_d | 100 ns per edge |
| PWM frequency | f_sw | 48 kHz |
| Copper path resistance per conduction loop | R_cu | 0.3 mΩ |
| Current shunt | R_sh | 0.25 mΩ |

> **Feasibility flag:** 80 A per channel × 4 on a 20×20 or 30×30 board yields roughly 90 W of dissipation (derived below). That is survivable only as a **seconds-long burst** relying on board thermal mass. It is **not** a continuous rating. The model below lets you size the allowed burst duration.

## 1. Conduction Loss Model

**Path count.** With 6-step trapezoidal commutation and complementary (synchronous) PWM, current always flows through exactly **two** conducting FETs:
- one FET in the PWM leg (the HS during on-time, the LS during off-time), and
- one FET in the static leg.

**Temperature dependence of R_DS(on):**

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)],\quad \alpha\approx 0.0045/\text{K} \Rightarrow k_T\approx1.4 \text{ at } 110^\circ\text{C}$$

**Conduction loss per ESC channel (motor):**

$$P_{cond} = I^2\left(2R_{DS}(T_j) + 2R_{cu} + R_{sh}\right)$$

| Term | Calculation | Result |
|---|---|---|
| MOSFETs | 80² × 2 × 1.4 mΩ | **17.9 W** |
| Copper | 80² × 0.6 mΩ | 3.8 W |
| Shunt | 80² × 0.25 mΩ | 1.6 W |
| **Channel total** | | **23.3 W** |

**Per-FET distribution.** In each 60° sector, the static-leg FET carries the full I² R. The PWM-leg pair splits it by duty D (HS ∝ D, LS ∝ 1−D). Averaged over 360°, each FET carries 1/3 of the per-path loss. So the worst-case FET dissipates about

$$P_{FET,cond}\approx \tfrac{1}{3}I^2R_{DS} \approx 3.0\ \text{W}.$$

Copper loss is a PCB problem, not a FET problem. Use ≥2 oz on inner planes plus via stitching.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. The loss terms are:

$$P_{sw,VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw}$$
$$P_{rr} = Q_{rr}V_{bus}f_{sw},\qquad P_{oss}=\tfrac12 Q_{oss}V_{bus}f_{sw}$$
$$P_{dt} = 2\,V_f\,I\,t_d\,f_{sw},\qquad P_{gate}=2\,Q_gV_{GS}f_{sw}\ (\text{dissipated in driver}/R_g)$$

| Term | Calculation | Result |
|---|---|---|
| V·I overlap | 0.5 × 25.2 × 80 × 27 ns × 48 k | 1.31 W |
| Reverse recovery | 40 nC × 25.2 × 48 k | 0.05 W |
| Coss | 0.5 × 60 nC × 25.2 × 48 k | 0.04 W |
| Dead-time diode | 2 × 0.8 × 80 × 100 ns × 48 k | 0.61 W |
| Gate drive | 2 × 60 nC × 10 V × 48 k | 0.06 W |
| **Channel total** | | **≈ 2.1 W** |

**Design insights:**

- At 48 kHz, conduction dominates by about 11:1.
- Halving dead time (100 → 50 ns) saves about 0.3 W per channel.
- Moving to 24 kHz saves about 1 W per channel, at the cost of current ripple and acoustic noise.
- The scaling laws are P_cond ∝ I² and P_sw ∝ V·I·f_sw.

## 3. Total Burst Loss and Thermal Model

**Board-level dissipation.**

$$P_{ch} = 23.3 + 2.1 = 25.4\ \text{W},\qquad P_{tot}=4P_{ch}\approx \mathbf{102\ W}$$

About 90 W of this lands in the FETs plus copper; the rest is in the shunts.

### 3.1 Thermal network (lumped Cauer model)

```
P_FET ─► R_jc ─► R_spread ─► [C_board] ─► R_conv ─► T_amb
          (j)      (case)       (board)      (air)
```

| Element | Basis | Value |
|---|---|---|
| R_jc | PDFN 5×6 exposed pad | ≈ 1.0 K/W |
| R_spread | Pad into 2 oz planes via thermal via array (≥ 12 × 0.3 mm vias/pad) | ≈ 4 K/W |
| C_board | 30×30 mm, 6-layer, 2 oz, plus components ≈ 5 g | 4.3 J/K (board) + 1.5 J/K (FETs, caps, connectors) ≈ **6 J/K** |
| R_conv (in prop wash, ~10 m/s) | h ≈ 80 W/m²K, A ≈ 2 × 9 cm² | ≈ 7 K/W |
| Board time constant | τ = R_conv · C | ≈ 42 s |

### 3.2 Transient response

Board temperature rise:

$$\Delta T_{board}(t) = P_{tot}R_{conv}\left(1-e^{-t/\tau}\right)\approx \frac{P_{tot}}{C}\,t \quad (t\ll\tau)$$

Adiabatic slope: 102 / 6 ≈ **17 K/s**.

Junction temperature:

$$T_j(t) = T_{amb} + \Delta T_{board}(t) + P_{FET}(R_{jc}+R_{spread})$$

With P_FET ≈ 3.0 + 0.35 (switching share) ≈ 3.4 W, the junction-to-board offset is 3.4 × 5 = **17 K**.

**Maximum burst duration.** For T_amb = 35 °C and a T_j limit of 125 °C (derated from 150 °C):

$$\Delta T_{board,max}=125-35-17=73\ \text{K}\Rightarrow t_{burst}\approx -\tau\ln\!\left(1-\frac{73}{102\cdot7}\right)\approx \mathbf{4.5\ s}$$

- **Steady-state continuous current** (board ≤ 73 K rise, R_conv = 7 K/W → ≤ 10.4 W total, ≈ 2.6 W per channel): I_cont ≈ **26 A per channel**.
- **Firmware mitigation.** Enable the AM32 temperature limit and current limit (e.g. 80 A peak, I²t fold-back to 30 A). Also route ESC temperature telemetry to ArduPilot for logging.
