# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

I don't have the Job #62 specification, so this design uses the assumptions in §0. Every hardware-dependent number is a named constant you can replace. Register values for the ICM-42688-P are from memory of the datasheet; check them against your datasheet revision before flashing.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A (GBM2804-class) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 / H7-class with FPU, center-aligned PWM at 20 kHz |
| IMU A (payload) | ICM-42688-P on the camera plate. Feedback sensor. |
| IMU B (base) | ICM-42688-P on the handle or airframe. Disturbance feedforward sensor. |
