# STM32H743 AIO + 4-in-1 ESC (Job #40): Power-Stage, Thermal and Bi-Directional DShot Design Package

## 0. Architecture Correction and Assumptions

**The architecture needs one correction before any design work.** The STM32H743 should not commutate the motors directly. ArduPilot has no ESC-commutation firmware, and running four sensorless FOC/6-step loops alongside the flight stack is not a supported configuration. The workable architecture is:

```
STM32H743 (ArduPilot FC) ──DShot600 bidir x4──► 4 × ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                                      └─► 3-phase gate driver ─► 6 × N-MOSFET per channel
```

**Design assumptions.** Change these and re-run the equations below.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst current per channel | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, PQFN 3.3×3.3 class) | R_ds(on),25 | 1.0 mΩ |

**Form factor:** 80 A × 4 cannot be sustained on a 20×20 "nano" board. The model below shows why. Section 2 quantifies the burst window instead.

## 1. Loss Model (per ESC channel, 6-step trapezoidal, complementary PWM)

### 1.1 Conduction Losses

In any 60° commutation sector, current flows through three switches:
- the PWM'd high-side (duty D),
- its synchronous low-side (1 − D),
- the opposite-leg low-side (100%).

$$P_{cond,path} = I^2 R_{hot}\,[D + (1-D)] + I^2 R_{hot} = 2\,I^2 R_{hot}$$

The result is independent of D, which is the benefit of synchronous rectification.

$$R_{hot} = k_T R_{ds(on),25} = 1.6\ \text{m}\Omega$$

$$P_{cond,path} = 2(80)^2(1.6\times10^{-3}) = \mathbf{20.48\ W}$$

Each FET conducts for 120° of 360°, so the per-FET average is:

$$P_{cond,FET} = \frac{I^2 R_{hot}}{3} = \frac{10.24}{3} = \mathbf{3.41\ W}$$

Copper and shunt loss:

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.5\text{m} = \mathbf{3.2\ W}$$

### 1.2 Switching Losses at 48 kHz

Only the PWM'd high-side hard-switches.

| Mechanism | Equation | Result |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f = 0.5·25.2·80·30n·48k | **1.452 W** |
| Dead-time diode | V_f·I·2t_dt·f = 0.8·80·200n·48k | **0.614 W** |
| Reverse recovery | Q_rr·V·f = 30n·25.2·48k | 0.036 W |
| C_oss | ½·C_oss·V²·f = 0.5·1n·635·48k | 0.015 W |
| Gate drive (2 FETs) | 2·Q_g·V_gs·f = 2·40n·10·48k | 0.038 W* |
| **Total switching** | | **≈ 2.16 W** |

*Gate-drive loss is dissipated in the driver and gate resistors, not the FET.

### 1.3 Totals at 80 A Burst

| | Per channel | 4 channels |
|---|---|---|
| Conduction (FETs) | 20.48 W | 81.9 W |
| Switching | 2.16 W | 8.6 W |
| Copper / shunt | 3.2 W | 12.8 W |
| **Total** | **25.8 W** | **103 W** |
| Efficiency (P_out ≈ 25.2·80·0.95 ≈ 1915 W/ch) | ≈ 98.7 % | |

**Frequency sensitivity:** ∂P_sw/∂f ≈ 45 µW/Hz per channel. Moving to 24 kHz saves about 1.05 W/ch but increases motor current ripple and audible noise. Moving to 96 kHz adds about 2.1 W/ch.

**Hottest FET:** the PWM'd high-side carries 3.41 + 2.12 ≈ **5.5 W** averaged over a commutation cycle.

## 2. Thermal Model

### 2.1 Steady State (shows why 80 A is burst-only)

Board convective resistance under prop wash, using h ≈ 80 W/m²K and two sides × 30.5² mm ≈ 1.86×10⁻³ m²:

$$R_{th,sa} = \frac{1}{hA} \approx 6.7\ \text{K/W} \;\Rightarrow\; \Delta T_{ss} = 103 \times 6.7 \approx 690\ \text{K}$$

This is physically impossible, so 80 A on all four channels is a transient rating only.

The sustainable continuous current, for ΔT = 60 K (40 °C ambient to 100 °C PCB):

$$P_{max} = 60/6.7 \approx 9\ \text{W total} \Rightarrow I_{cont} \approx 80\sqrt{9/103} \approx \mathbf{24\ A/ch}$$

This is the honest continuous rating. Switching losses scale roughly linearly with current, so the true figure is slightly higher, around 25–28 A.
