# DroneCAN Node Heartbeat and ESC Telemetry Message Definitions for ArduPilot on STM32H743

I couldn't map "Cycle 7" to any DroneCAN or ArduPilot convention, so I've treated it as your internal iteration label. The definitions below follow the standard DroneCAN DSDL set used by ArduPilot (`modules/DroneCAN/DSDL`), the `dronecan_dsdlc`-generated C API, and the AP_Periph publishing conventions. The STM32H743's FDCAN peripheral supports both Classic CAN and CAN FD. Verify DTIDs and signatures against your checked-out DSDL tree before freezing the interface.

---

## 1. Node Heartbeat: `uavcan.protocol.NodeStatus`

**Data Type ID:** 341 (broadcast)  
**Signature:** `0x0F0868D0C1A7C6F1`  
**Serialized size:** 56 bits (7 bytes), which fits in a single Classic CAN frame.

### DSDL (`341.NodeStatus.uavcan`)
```
uint16 MAX_BROADCASTING_PERIOD_MS = 1000
uint16 MIN_BROADCASTING_PERIOD_MS = 2
uint16 OFFLINE_TIMEOUT_MS         = 3000

uint32 uptime_sec

uint2 HEALTH_OK       = 0
uint2 HEALTH_WARNING  = 1
uint2 HEALTH_ERROR    = 2
uint2 HEALTH_CRITICAL = 3
uint2 health

uint3 MODE_OPERATIONAL     = 0
uint3 MODE_INITIALIZATION  = 1
uint3 MODE_MAINTENANCE     = 2
uint3 MODE_SOFTWARE_UPDATE = 3
uint3 MODE_OFFLINE         = 7
uint3 mode

uint3 sub_mode                     # reserved, set to 0
uint16 vendor_specific_status_code
```

### Bit layout
| Bits  | Field                         |
|-------|-------------------------------|
| 0–31  | `uptime_sec`                  |
| 32–33 | `health`                      |
| 34–36 | `mode`                        |
| 37–39 | `sub_mode`                    |
| 40–55 | `vendor_specific_status_code` |

### Publishing rules
- **Rate:** 1 Hz nominal. Never exceed 1000 ms between messages, or peers will mark the node offline after 3000 ms.
- **Priority:** `CANARD_TRANSFER_PRIORITY_LOW`.
- **Mode transitions:**
  - Use `INITIALIZATION` until sensors and ESC drivers are up, then `OPERATIONAL`.
  - Use `SOFTWARE_UPDATE` while the bootloader or firmware update path is active.
- **Health:** Set `WARNING` on an over-temperature or telemetry timeout, and `ERROR` or `CRITICAL` on a hard fault.
- **Vendor status code:** Suggested packing is `[15:8] ESC fault bitmask` and `[7:0] reset cause` (RCC_RSR snapshot), which is useful for H7 watchdog diagnosis.

## 2. ESC Telemetry: `uavcan.equipment.esc.Status`

**Data Type ID:** 1034 (broadcast)  
**Signature:** `0xA9AF28AEA2FBB254`  
**Serialized size:** 110 bits (14 bytes). On Classic CAN this is a multi-frame transfer of 2 frames with CRC. On CAN FD it fits in a single frame.

### DSDL (`1034.Status.uavcan`)
```
uint32  error_count        # cumulative, wraps
float16 voltage            # Volt
float16 current            # Ampere; negative = regen
float16 temperature        # Kelvin
int18   rpm                # negative = reverse
uint7   power_rating_pct   # 0–127 %, instantaneous demand
uint5   esc_index          # 0–31, matches RawCommand array index
```

### Bit layout
| Bits    | Field              |
|---------|--------------------|
| 0–31    | `error_count`      |
| 32–47   | `voltage`          |
| 48–63   | `current`          |
| 64–79   | `temperature`      |
| 80–97   | `rpm`              |
| 98–104  | `power_rating_pct` |
| 105–109 | `esc_index`        |

### Optional companion: `uavcan.equipment.esc.StatusExtended` (DTID 1036)
Confirm this DTID against your DSDL revision.
```
uint7  input_pct          # commanded throttle %
uint7  output_pct         # applied duty %
int9   motor_temperature_degC
uint9  motor_angle        # electrical/mech angle, 0–511 scaled
uint19 status_flags       # vendor fault/state bits
uint5  esc_index
```

### Publishing rules
- **Rate:** Driven by the `ESC_TLM_RATE`-style parameter (AP_Periph uses `ESC_TELEM_RATE`, default 50 Hz). Round-robin across ESC indices so each ESC gets the configured rate without burst saturation.
- **Priority:** `CANARD_TRANSFER_PRIORITY_LOW` (or `MEDIUM` if the flight controller relies on RPM for harmonic notch).
- **Temperature:** Send in Kelvin (`degC + 273.15f`).
- **Missing values:** Send `NaN` for any unavailable float field. Do not send 0.
- **ArduPilot mapping:** The flight controller maps `esc_index` to the `CAN_Dx_UC_ESC_OF` offset. Keep indices consistent with the `RawCommand` ordering.

## 3. AP_Periph-style Publishing Code (STM32H743)

#include <dronecan_msgs.h>   // generated by dronecan_dsdlc

// ---------- NodeStatus heartbeat (call from 1 Hz loop) ----------
void AP_Periph_FW::send_node_status()
{
    uavcan_protocol_NodeStatus ns {};
    ns.uptime_sec = AP_HAL::millis() / 1000U;
    ns.health     = compute_health();   // UAVCAN_PROTOCOL_NODESTATUS_HEALTH_*
    ns.mode       = node_mode;          // UAVCAN_PROTOCOL_NODESTATUS_MODE_*
    ns.sub_mode   = 0;
    ns.vendor_specific_status_code = (uint16_t(esc_fault_mask) << 8) | reset_cause;

    uint8_t buffer[UAVCAN_PROTOCOL_NODESTATUS_MAX_SIZE];
    const uint16_t len = uavcan_protocol_NodeStatus_encode(&ns, buffer, !canfdout());

    canard_broadcast(UAVCAN_PROTOCOL_NODESTATUS_SIGNATURE,
                     UAVCAN_PROTOCOL_NODESTATUS_ID,
                     CANARD_TRANSFER_PRIORITY_LOW,
                     buffer, len);
}
