## 1. Conduction Loss Model

### 1.1 Current path in 6-step complementary PWM

In any commutation sector (e.g., phase A high, phase B low), the current path is:

- **High-side leg A:** HS_A conducts for duty D. LS_A (synchronous rectifier) conducts for (1 − D − 2t_dt·f_sw).
- **Low-side leg B:** LS_B conducts 100% of the sector.

Ignoring the dead-time fraction, which is handled in §2, there are **always exactly two R_DS(on) in series** with the motor current:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS(on)}(T_j) + I_{ph}^2\,R_{Cu}$$
