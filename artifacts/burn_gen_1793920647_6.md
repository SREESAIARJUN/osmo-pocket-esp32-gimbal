# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #47 spec sheet, so this design rests on the assumptions in §0. Every hardware-dependent constant is a named parameter, so you can substitute your real values without changing the structure.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701/AS5048A), SPI |
| MCU | STM32G4/H7 class, FPU, center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, ±2000 dps, ±16 g |
| Supply | V_dc = 16.8 V (4S) |

**Loop rates.** Each loop runs well below the bandwidth of the loop inside it.

```
 20 kHz  Current loop (FOC, PI, SVPWM)      ω_c ≈ 2π·1500 rad/s
  8 kHz  IMU read → AAF (HW) → notch bank → dual fusion
  4 kHz  Velocity loop (PI + cogging FF)    ω_v ≈ 2π·150 rad/s
  1 kHz  Attitude estimator + angle loop    ω_θ ≈ 2π·30 rad/s
```

**Feedback sources.**
- **Angle loop:** fused camera attitude from the IMUs.
- **Velocity loop:** gyro rate projected onto the joint axis.
- **Commutation and cogging lookup:** the encoder.
