# STM32H743 Nano FC + 4-in-1 ESC: Design Model and Allocation Package

## 0. Architecture Corrections

Three issues need to be settled before the numbers mean anything.

1. **The H743 should not commutate the motors.** ArduPilot has no motor-commutation firmware for the H743. A working stack is:
   - H743 runs ArduPilot and emits bidirectional DShot600.
   - Four ESC MCUs (AT32F421 or STM32G071 running AM32, or EFM8 running BlueJay) commutate the motors and send eRPM back.

   The model below assumes this partition.
2. **"80 A burst" must be defined.** I treat it as 80 A RMS phase current per channel for 1 to 10 s. Battery current is lower: I_batt ≈ D·I_phase.
3. **Nano format (20×20 mm) cannot dissipate 4×80 A for more than about 1 s.** Section 3 proves this. Treat the 80 A rating as single-channel, transient-only, or move to a 30.5×30.5 mm board.

**Assumed parameters.** Replace these with your BOM datasheet values.

| Parameter | Value |
|---|---|
| Bus | 6S, V_bus,max = 25.2 V |
| MOSFET | 40 V, DFN3.3×3.3, R_DS(on) = 1.5 mΩ @25 °C, temperature coefficient α ≈ 0.0055/K (×1.55 at 125 °C) |
| Charges | Q_g = 30 nC, Q_gs2 = 3 nC, Q_gd = 6 nC, Q_rr = 60 nC (at 80 A), C_oss = 900 pF |

| PWM | f_sw = 48 kHz, complementary (synchronous rectification), dead time t_dt = 50 ns |

## 1. Conduction Loss Model

In 6-step complementary PWM, two FETs always carry phase current:

- During t_on: HS_A and LS_B conduct.
- During t_off: LS_A (synchronous) and LS_B conduct.

Per channel:

$$P_{cond} = 2\,I_{rms}^2\,R_{DS}(T_j), \qquad R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

Add a ripple correction:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}D(1-D)}{L_{ph}f_{sw}}$$

For a 20 µH phase at D = 0.5: ΔI = 25.2·0.25/(20e-6·48e3) ≈ 6.6 A. The ripple term is 3.6 A², which is negligible against 6400 A².

**Electrothermal fixed point.** Solve T_j = T_ref + R_θ·P(T_j). Because P_cond ∝ (1+αT_j), this has a closed form:

$$P_{cond}(T_j) = \frac{2I^2R_{25}(1+\alpha(T_{ref}-25))}{1-2I^2R_{25}\,\alpha\,R_{\theta}/2}$$

The thermal-runaway criterion is that the denominator goes to 0 or below. Iterating to 125 °C:

| T_j | R_DS | P_cond per channel (80 A) |
|---|---|---|
| 25 °C | 1.50 mΩ | 19.2 W |
| 100 °C | 2.12 mΩ | 27.2 W |
| 125 °C | 2.33 mΩ | **29.8 W** |

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches (HS_A ↔ LS_A).

**Transition times.** Gate current during the plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g}=1.3\text{ A}, \quad I_{g,off} = \frac{V_{pl}}{R_g}=0.7\text{ A}$$

$$t_{on}=\frac{Q_{gs2}+Q_{gd}}{I_{g,on}}=6.9\text{ ns}, \quad t_{off}=12.9\text{ ns}$$

Layout inductance (common-source L_s ≈ 1 nH) increases these. Use t_on ≈ 20 ns and t_off ≈ 15 ns for design.

**Loss terms per channel (V = 25.2 V, I = 80 A, f = 48 kHz):**

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on+t_off)·f | **1.69 W** |
| Reverse recovery | Q_rr·V·f | 0.073 W |
| C_oss (×2 FETs) | 2·½·C_oss·V²·f | 0.027 W |
| Dead-time body diode | V_f·I·2t_dt·f (V_f = 0.8 V) | 0.31 W |
| Gate charge (driver side) | 2·Q_g·V_drv·f | 0.029 W |
| **P_sw total** | | **≈ 2.13 W** |

**Totals.**

- P_channel = 29.8 + 2.1 ≈ **31.9 W**
- **P_4ch ≈ 128 W**, plus about 3 W for the shunt and copper.

**Frequency trade-off.** Dropping to 24 kHz saves about 1 W per channel but worsens current ripple and acoustic noise. At 80 A, switching loss is only about 7% of the total, so frequency is not the main lever. R_DS(on) and FET paralleling are.

## 3. Thermal Model

### Network per FET (Cauer, simplified)

T_j → R_θJC (1.5 K/W) → T_case → R_θCB (solder/via, 2 K/W) → board copper → board-to-air.

### Board-to-air

- Area A = 2 × 4 cm² = 8×10⁻⁴ m².
- h = 150 W/m²K under prop wash. This is optimistic.

$$R_{\theta BA} = \frac{1}{hA} \approx 8.3\text{ K/W}$$

**Steady state at 4×80 A:** ΔT = 131 W × 8.3 K/W ≈ **1090 K**. This is impossible, so the design is purely transient.
