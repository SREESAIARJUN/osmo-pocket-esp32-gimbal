## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle with a calibrated offset:

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and Controller

The PMSM in the dq frame (surface magnets, $L_d = L_q = L$):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The controller is a PI per axis plus cross-coupling decoupling and back-EMF feedforward:

$$v_d^* = K_{p,i}e_d + K_{i,i}\!\int e_d\,dt - \omega_e L i_q$$

$$v_q^* = K_{p,i}e_q + K_{i,i}\!\int e_q\,dt + \omega_e L i_d + \omega_e \lambda_m$$

**Gain design by pole-zero cancellation.** Once decoupled, the plant is $1/(Ls+R)$. Choose:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

The closed loop then becomes $\omega_{ci}/(s+\omega_{ci})$.

**Bandwidth limit from delay.** The digital loop has an effective delay $T_d \approx 1.5\,T_{s}$. For roughly 60° of phase margin, use

$$\omega_{ci} \le \frac{\pi}{6\,T_d}$$

At $T_s = 50\,\mu s$, this gives $\omega_{ci} \le 2\pi\cdot 1.1\,\text{kHz}$.

### 1.3 Voltage Limiting and Anti-Windup

Limit the voltage vector to the linear SVPWM region:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

When saturated, scale the vector with $d$-axis priority. Use back-calculation anti-windup on each integrator:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw}\approx \frac{K_i}{K_p}$$

### 1.4 SVPWM (min-max zero-sequence injection)

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Phase voltages:

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection and duty cycle:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Angle advance for PWM delay.** Evaluate the inverse Park at

$$\theta_e + 1.5\,\omega_e T_s$$
