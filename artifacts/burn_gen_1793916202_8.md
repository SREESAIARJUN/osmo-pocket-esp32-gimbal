# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #23 specification, so this design states its assumptions explicitly. Every assumed value is a parameter in the code. Change them to match the actual hardware.

---

## 0. Assumed Platform and Loop Rates

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC) |
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, clocks synchronized via CLKIN |
| Joint order | Yaw (outer, base) → Roll → Pitch (inner, camera) |

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz (PWM center-aligned, 20 kHz) | 50 µs |
| Velocity | 4 kHz | 250 µs |
| Angle / attitude | 1 kHz | 1 ms |
| IMU sampling and filtering | 8 kHz (decimated to 4 kHz) | 125 µs |

## 1. FOC Current Loop

### 1.1 Electrical model (surface PMSM, L_d ≈ L_q = L)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2} p \lambda_m i_q = K_t i_q,\qquad \omega_e = p\,\omega_m,\qquad \theta_e = p\,\theta_m - \theta_{\text{off}}
$$
