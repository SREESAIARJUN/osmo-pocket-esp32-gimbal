## 0. Architecture Clarification and Assumptions

### Partitioning
This partitioning determines where each part of the math applies.

- **The STM32H743 does not drive the MOSFETs.** It runs ArduPilot and emits bidirectional DShot600 on 4 timer channels.
- **The 48 kHz PWM is generated by four ESC MCUs** on the 4-in-1 board. These are typically AT32F421 or STM32G071 running AM32 or BLHeli_32, each driving a 3-phase gate driver and 6 MOSFETs.

```
 6S LiPo ──► 4-in-1 ESC ── [ESC MCU ×4] ─ 48 kHz PWM ─► [Gate drv ×4] ─► [6 FET ×4] ─► Motors
                 ▲  │
          DShot600  │ eRPM (GCR, same wire)
                 │  ▼
           STM32H743 FC (ArduPilot) ── TIM3 / TIM5 + DMA
```
