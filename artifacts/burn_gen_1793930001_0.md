# STM32H743 AIO Flight Controller + 4-in-1 ESC: Reference Architecture and Loss Model

This is a first-principles design package. Every number depends on component parameters I have assumed and listed in §1. Swap in your real datasheet values before committing to a layout. One finding matters more than the rest: **80 A per channel on a nano-format board is only a burst rating of a few seconds. The thermal model in §4 shows why and gives the burst limit as a closed-form expression.**

---

## 0. System Partitioning

The STM32H743 should **not** commutate the motors. Running four FOC/6-step loops at 48 kHz alongside ArduPilot's scheduler would be a bad use of the H7. The standard architecture, which this design follows, is:

```
          ┌──────────────────────── STM32H743VIH6 (ArduPilot) ──────────────────────┐
          │ IMU (SPI1/SPI4), Baro (I2C2), OSD (SPI2), SD (SDMMC1), UARTs, CAN         │
          │ Motor out: TIM8_CH2N/CH3N, TIM5_CH1/CH2 → bi-dir DShot600                 │
          └───────┬──────────────┬──────────────┬──────────────┬────────────────────┘
                  │ DSHOT1       │ DSHOT2       │ DSHOT3       │ DSHOT4   (3.3V, 100Ω series)
            ┌─────▼────┐   ┌─────▼────┐   ┌─────▼────┐   ┌─────▼────┐
            │AT32F421  │   │AT32F421  │   │AT32F421  │   │AT32F421  │  AM32 firmware, 48 kHz PWM
            │ + FD6288Q│   │ + FD6288Q│   │ + FD6288Q│   │ + FD6288Q│  3-phase gate driver
            │ 6× MOSFET│   │ 6× MOSFET│   │ 6× MOSFET│   │ 6× MOSFET│  (24 FETs total)
            └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

## 2. Conduction Loss Model

### 2.1 Commutation topology
With 6-step trapezoidal drive and synchronous PWM, at any instant exactly **two half-bridges** carry the phase current:
- **Leg A (PWM leg):** the current alternates between the high-side FET (duty D) and the low-side FET (1−D, synchronous freewheel).
- **Leg B (return leg):** the low-side FET conducts continuously.

The current path therefore always crosses **two R_ds(on) in series**, regardless of D:

$$
P_{cond,ch} = I^2 \left[ D\,R_{ds} + (1-D)\,R_{ds} \right] + I^2 R_{ds} = 2 I^2 R_{ds}(T_j)
$$

### 2.2 Temperature dependence

$$
R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]
$$

### 2.3 Numbers at 80 A

| T_j | R_ds | P_cond per channel | P_cond for 4 channels |
|---|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W | 51.2 W |
| 100 °C | 1.41 mΩ | 18.1 W | 72.4 W |
| 125 °C | 1.55 mΩ | 19.8 W | 79.2 W |

### 2.4 Parasitic copper and shunt
- **Phase and bus trace resistance.** Budget R_cu ≈ 0.3 mΩ per channel (3 oz inner planes, multiple via arrays). This adds P = 80²·0.3 mΩ = **1.9 W per channel**.
- **Current shunt.** If a single 0.25 mΩ bus shunt is used, it dissipates 1.6 W at 80 A. Use a 2512, 3 W part, or a Hall sensor (e.g., ACS770 off-board, or TMCS1100 for lower currents).

### 2.5 Per-FET distribution
Each FET conducts for a 120° electrical window. Averaged over an electrical cycle:

$$
\bar P_{FET} \approx \frac{P_{ch,total}}{6}
$$

During its active window, however, the instantaneous FET loss is around 2–3× that average. This matters at low eRPM, where the window becomes comparable to the junction thermal time constant (roughly 1–10 ms).

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches. That leg has one hard-switched transition pair per period; the synchronous FET switches ZVS-like after dead time.

### 3.1 V–I overlap (hard-switched FET)

$$
P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = \tfrac12 (25.2)(80)(50\text{ ns})(48\text{ kHz}) = \mathbf{2.42\ W}
$$

### 3.2 Dead-time body-diode conduction

$$
P_{dt} = V_f\, I\, (2 t_{dt})\, f_{sw} = 0.8 \cdot 80 \cdot 200\text{ ns} \cdot 48\text{ kHz} = \mathbf{0.61\ W}
$$

### 3.3 Reverse recovery

$$
P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\cdot 25.2 \cdot 48\text{k} = \mathbf{0.06\ W}
$$

### 3.4 Output capacitance

$$
P_{oss} = Q_{oss} V_{bus} f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.05\ W}
$$
