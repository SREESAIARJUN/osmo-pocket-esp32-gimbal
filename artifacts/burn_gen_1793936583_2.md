# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Sensor Fusion

I don't have the original specification for Job #7, so this design rests on the assumptions below. Every assumption maps to one constant in `GimbalConfig`, so you can change them without touching the algorithms.

## 1. Control Architecture

```
 θ_ref ──►[Angle PI + FF]──ω_ref──►[Velocity PI]──i_q*──►(+)──►[Current PI d/q]──►[InvPark]──►[SVPWM]──► Motor
   ▲          1 kHz      ▲             5 kHz             ▲          20 kHz
   │                     │                               │
   │    ω_ff = θ̇_ref     │                     i_ff = −τ̂_cog(θ_m)/K_t + J·α_ref/K_t
   │                     │
 θ_cam (fused attitude) ◄── Dual-IMU fusion ◄── 2× ICM-42688-P (8 kHz, AAF, notch)
```

**Bandwidth separation rule.** Each loop is placed at least 4–5× below the loop inside it:

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\qquad \omega_{c,\omega} \approx 2\pi\cdot 150\text{ Hz},\qquad \omega_{c,\theta} \approx 2\pi\cdot 25\text{ Hz}.$$

## 2. FOC Equations

### 2.1 Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 2.2 Park transform

The electrical angle is $\theta_e = p\,(\theta_m - \theta_{\text{offset}})$.

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.3 Motor model in the dq frame (SPM motor, $L_d = L_q = L$)

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 2.4 Current PI by pole-zero cancellation

Choose the gains so the PI zero cancels the electrical pole $R/L$:

$$K_p = L\,\omega_{c,i},\qquad K_i = R\,\omega_{c,i}$$

This gives a closed loop of $\frac{\omega_{c,i}}{s+\omega_{c,i}}$.

Decoupling and back-EMF feedforward are then added:

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 2.5 Voltage limiting (circular)

Let $V_{max} = V_{dc}/\sqrt3$. The d-axis has priority:

$$v_d \leftarrow \text{clamp}(v_d,\pm V_{max})$$

$$v_q \leftarrow \text{clamp}\!\left(v_q,\pm\sqrt{V_{max}^2 - v_d^2}\right)$$

### 2.6 SVPWM (min-max zero-sequence injection)

$$v_{abc} = \text{InvClarke}(\text{InvPark}(v_d, v_q)),\qquad v_0 = -\tfrac12\left(\max v_x + \min v_x\right)$$

$$\text{duty}_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 3. Cascaded PID: Discrete Form

All three loops use a single discrete PID structure with these features:

- setpoint weighting $b$ on the proportional term;
- derivative on measurement, with first-order filter $N$;
- back-calculation anti-windup with gain $K_{aw}$;
- Tustin (bilinear) discretization at sample time $T_s$.

### 3.1 Proportional term

$$P_k = K_p\,(b\,r_k - y_k)$$

### 3.2 Filtered derivative

$$D(s) = -\frac{K_d s}{1 + s K_d/(K_p N)}\,Y(s)$$

Discretized with Tustin:

$$D_k = \frac{2T_f - T_s}{2T_f + T_s}D_{k-1} - \frac{2K_d}{2T_f+T_s}(y_k - y_{k-1}),\qquad T_f = \frac{K_d}{K_p N}$$

### 3.3 Integrator with back-calculation anti-windup

$$I_{k} = I_{k-1} + K_i T_s\,e_k + K_{aw}T_s\,(u^{sat}_{k-1} - u_{k-1})$$

A typical choice is $K_{aw} \approx \sqrt{K_i/T_d}$, or $K_{aw} = K_i/K_p$ for a pure PI.

### 3.4 Output

$$u_k = P_k + I_k + D_k + u_{ff},\qquad u_k^{sat} = \text{clamp}(u_k)$$

### 3.5 Gain design from the plant model

The plant from current to speed is $\omega_m / i_q = K_t / (J s)$, where $J$ is the payload inertia reflected to the axis.

**Velocity PI** (symmetric optimum, crossover $\omega_{c,\omega}$, phase-margin factor $a \approx 3$):

$$K_{p,\omega} = \frac{J\,\omega_{c,\omega}}{K_t},\qquad K_{i,\omega} = \frac{K_{p,\omega}\,\omega_{c,\omega}}{a^2}$$

**Angle loop** (P or PI, with velocity feedforward $\omega_{ff} = \dot\theta_{ref}$):

$$K_{p,\theta} = \omega_{c,\theta},\qquad K_{i,\theta} = K_{p,\theta}\,\omega_{c,\theta}/10$$

The angle integrator removes steady-state error due to cable drag and imbalance.

**Inertia (acceleration) feedforward** into $i_q$:

$$i_{q,ff} = \frac{J\,\ddot\theta_{ref}}{K_t}$$

### 3.6 Gimbal-specific feedback choices

- **Angle loop feedback:** the fused camera attitude (IMU), projected to the joint axis.
- **Velocity loop feedback:** the *IMU gyro rate* for the stabilization path (inertial rate), blended with encoder rate below ~1 Hz to remove drift.
- **Commutation:** always the encoder.
