# STM32H743 Nano FC + 4-in-1 ESC (Job #84): Power-Stage, Thermal, and DShot Architecture

## 0. Architecture Clarification and Assumptions

**The H743 does not switch the MOSFETs.** In a 4-in-1 stack, the STM32H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU, here an AT32F421 running AM32, which generates the 48 kHz commutation PWM. The power-loss model therefore lives on the ESC side, and the DMA/timer model lives on the FC side. The connecting signal is DShot plus eRPM telemetry.

**No MOSFET part number was specified.** The model below is fully parametric. Numbers are evaluated for a representative 40 V, 3.3×3.3 mm DFN FET of the kind used in high-current 4-in-1 ESCs. Before release, replace these values with the selected device's datasheet values.

## 1. Conduction Loss Model (6-Step Trapezoidal, Complementary PWM)

### 1.1 Commutation sector model

Over one electrical period, each phase leg spends:
- 120° with the **high-side switching at duty D**, while the low-side carries the complementary interval;
- 120° with the **low-side held fully on**;
- 2 × 60° floating.

Let I be the DC motor current in the active phases (ripple neglected).

**High-side FET:**
$$P_{cond,HS} = I^2 \, R_{DS}(T_j)\cdot \frac{D}{3}$$

**Low-side FET:**
$$P_{cond,LS} = I^2 \, R_{DS}(T_j)\cdot \left[\frac{1-D}{3} + \frac{1}{3}\right] = I^2 R_{DS}(T_j)\,\frac{2-D}{3}$$

**Temperature dependence (approximately linear above 25 °C):**
$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha = \frac{1.60-1}{100} = 0.006\ \text{K}^{-1}$$

### 1.2 Evaluation at 80 A burst, D = 0.95, T_j = 125 °C

- R_DS = 0.90 × 1.60 = **1.44 mΩ**
- I²R = 6400 × 1.44×10⁻³ = **9.22 W** instantaneous

| Device | Expression | Loss |
|---|---|---|
| HS FET | 9.22 × 0.95/3 | **2.92 W** |
| LS FET | 9.22 × 1.05/3 | **3.23 W** |
| Per leg | — | 6.15 W |
| Per channel (3 legs) | — | **18.4 W** |
| 4 channels | — | **73.8 W** |
