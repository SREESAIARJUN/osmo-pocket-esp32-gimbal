# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

I don't have the original Job #28 spec, so this design rests on the explicit assumptions in §0. Every tunable value is derived from physical parameters rather than hard-coded. Plug in your motor and frame data and the gains follow.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value | Notes |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH | Hollow-shaft gimbal type |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI | Mechanical angle θ_m |
| Current sense | 2- or 3-shunt, ADC triggered at PWM center | Voltage-mode fallback given in §2.5 |
| PWM | 20 kHz center-aligned | |
| IMU-C | ICM-42688-P on the camera plate | Attitude and inertial rate feedback |
| IMU-B | ICM-42688-P on the base/handle | Disturbance feedforward and vibration reference |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU | |

**Loop rates (each ≥ 5× bandwidth separation):**

```
20 kHz  ISR_PWM : ADC → Clarke/Park → current PI → SVPWM          (BW_i ≈ 1.5–2 kHz)
 4 kHz  ISR_CTL : IMU FIFO → filters/ANC → velocity PI + cogging FF (BW_v ≈ 60–120 Hz)
 1 kHz  TASK_ATT: attitude fusion → angle loop → joint setpoints   (BW_θ ≈ 10–25 Hz)
 20 Hz  TASK_BG : vibration peak search → notch retune, LMS gating
```

## 1. Notation

- θ_m: mechanical rotor angle. θ_e = p·θ_m − θ_off: electrical angle.
- ω_m = dθ_m/dt.
- K_t: torque constant [N·m/A]. For a PMSM, K_t = (3/2)·p·λ_m.
- J: reflected inertia of motor plus everything it moves [kg·m²].
- T_s: sample period of the loop under discussion.
- z⁻¹: unit delay.
