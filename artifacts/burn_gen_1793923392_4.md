# STM32H743 AIO Flight Controller + 80 A 4-in-1 ESC (Job #50): Engineering Design Package

This package covers the architecture, loss model, thermal budget, DShot timer and DMA plan, and a reference netlist.

## 0. Architecture Clarification

ArduPilot running on the STM32H743 does **not** commutate motors. The H743 generates bi-directional DShot600. Each ESC channel then needs its own commutation MCU running AM32 or BLHeli_32. The H743 cannot do sensorless 6-step on 24 phases in real time alongside the flight stack, and ArduPilot has no such firmware path.

| Block | Device (reference choice) | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 400 MHz | ArduPilot, DShot600 BDShot master |
| ESC MCU ×4 | AT32F421K8U7 or STM32G071GBU6 | AM32 firmware, 48 kHz complementary PWM |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap) | High-side and low-side gate drive |
| MOSFET ×24 | 40 V, ~1.0 mΩ typ @25 °C, PQFN 3.3×3.3 | Power stage |
| Bus | 6S LiPo (25.2 V max) | Design point |

**Every number below is model-based.** Replace the assumed MOSFET parameters with your selected part's datasheet values before release.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Assumptions

| Symbol | Value | Note |
|---|---|---|
| I_ph | 80 A | Burst phase current per channel |
| R_ds(on),25 | 1.0 mΩ | Typical at V_GS = 10 V |
| α | 0.0045 /°C | Temperature coefficient of R_ds(on) |
| T_j | 110 °C | Design junction temperature |
| R_pcb | 0.25 mΩ | Copper and solder path per conducting leg pair |

### 1.2 Temperature-Corrected R_ds(on)

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)] = 1.0\,(1+0.0045\cdot85)=1.38\ \text{m}\Omega$$

### 1.3 Channel Conduction Loss

With complementary (synchronous) PWM, the current path always passes through exactly two conducting FETs: the high-side or its synchronous low-side complement, plus the fixed low-side. This holds at any duty cycle D:

$$P_{cond,ch}=I_{ph}^2\,(2R_{ds}(T_j)+R_{pcb})=6400\,(2.76+0.25)\times10^{-3}=\mathbf{19.3\ W}$$

The MOSFETs alone contribute 17.7 W of this. Over a full electrical cycle, symmetry spreads the loss evenly across the 6 FETs:

$$P_{cond,FET}=17.7/6=\mathbf{2.95\ W}$$

### 1.4 Electrothermal Feedback

Loss raises T_j, which raises R_ds(on), which raises loss. The fixed point is:

$$T_j = T_b + R_{\theta jb}\,P_{FET}(T_j)$$

This converges when $R_{\theta jb}\cdot I^2 R_{ds,25}\,\alpha/3 < 1$. Here the product is ≈ 0.03, so the loop is strongly convergent and **thermal runaway is not a risk at the FET level**. The board, analysed in §3, is the actual limit.

## 2. Switching Loss Model (f_sw = 48 kHz)

| Parameter | Value |
|---|---|
| V_bus | 25.2 V |
| t_r + t_f | 20 ns (FD6288 ~1.5/1.8 A drive, R_g = 4.7 Ω) |
| t_dead | 50 ns per edge |
| V_SD (body diode) | 0.8 V |
| Q_rr | 30 nC |
| C_oss,eff | 1.5 nF |
| Q_g | 40 nC @ 10 V |

Each channel has one hard-switching leg at any instant.

| Loss term | Equation | Result |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f | ½·25.2·80·20 ns·48 k = **0.968 W** |
| Dead-time diode | V_SD·I·2t_dt·f | 0.8·80·100 ns·48 k = **0.307 W** |
| Reverse recovery | Q_rr·V·f | 30 nC·25.2·48 k = **0.036 W** |
| C_oss | ½·C_oss·V²·f ×2 | **0.046 W** |
| Gate charge (in driver and R_g) | Q_g·V_GS·f ×2 | **0.038 W** |
| **Total P_sw per channel** | | **≈ 1.40 W** |

**Key insight:** at 48 kHz and 80 A, switching loss is only about 7% of total loss. Conduction dominates. The next lever is lower R_ds(on), or paralleled FETs, not faster edges. Faster edges also worsen EMI and ringing on a nano layout.
