# Gimbal Motor Control and Dual-IMU Sensor Fusion: FOC, Cascaded PID, Anti-Cogging, and Vibration Rejection

## 0. Assumptions

I don't have the Job #9 specification, so this design uses common gimbal hardware. Every constant is in one config block so you can substitute your values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per axis |
| Current sensing | 2 low-side shunts per motor (voltage-mode fallback provided) |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses with chip selects, FSYNC tied together |
| PWM | 20 kHz center-aligned |
| Loop rates | Current 20 kHz · Rate/velocity 4 kHz · Attitude 1 kHz · IMU ODR 8 kHz |

The cascade, outer to inner:

```
 q_ref ─►[Attitude P (1 kHz, IMU quaternion)]─► ω_ref ─►[Rate PI + FF (4 kHz, fused gyro)]─► τ_ref
       ─►[÷Kt + anti-cogging FF + friction FF]─► i_q,ref ─►[Current PI dq (20 kHz)]─► v_dq ─►[SVPWM]
                 encoder θ_m ──► θ_e = p·θ_m (commutation) and cogging phase
```

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms

Clarke transform (power-variant, two shunts, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park is the transpose of the same matrix.

### 1.2 Plant model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q \equiv K_t\, i_q$$

### 1.3 Current PI with pole–zero cancellation and decoupling

The decoupled plant is $G_i(s) = \dfrac{1}{Ls + R}$. Choose:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$
