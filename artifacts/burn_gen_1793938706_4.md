# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion (Job #22)

I don't have the Job #22 spec sheet, so this design starts from the stated assumptions below. Every parameter is a named constant, so you can substitute your real values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (GBM2804-class). 12N14P, so pole pairs p = 7. R = 5.6 Ω, L = 1.8 mH, Kt ≈ 0.06 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) over SPI |
| MCU | STM32G4 @ 170 MHz (FPU + CORDIC), center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| Bus | 3S–4S (11–16.8 V) |
| Mechanics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |

```
                   1 kHz                  4–8 kHz               20 kHz
 q_ref ──► [Attitude/Angle P] ──ω_cam*──► J⁻¹(q) ──q̇*──► [Velocity PI] ──i_q*──►(+)──► [Current PI d/q] ──► SVPWM ──► Motor
                ▲                                          ▲               i_ff,cog ─┘          ▲
                │ quaternion                               │ q̇_meas                             │ i_abc, θ_e
        [Mahony AHRS] ◄── [Dual IMU fusion] ◄── [IMU A chain]   (gyro rate, inertial)     encoder → PLL
                                            ◄── [IMU B chain]
```

**Bandwidth separation rule:** each outer loop should be at least 4–5× slower than its inner loop.

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
