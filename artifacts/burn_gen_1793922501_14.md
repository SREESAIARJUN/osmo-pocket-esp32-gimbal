## 0. Architecture Clarification and Assumptions

### 0.1 System partition

The STM32H743 does **not** commutate the motors directly. ArduPilot has no BLDC commutation code, so the system splits into two layers:

```
 ┌─────────────────────── FC LAYER ───────────────────────┐
 │ STM32H743VIT6 @ 480 MHz  (ArduPilot ChibiOS)           │
 │  IMU (SPI) · Baro (I2C) · OSD · SD · UARTs             │
 │  TIM3 CH3/CH4, TIM4 CH1/CH2 → bidirectional DShot600    │
 └────────┬──────────┬──────────┬──────────┬──────────────┘
          │M1        │M2        │M3        │M4   (3V3 single-wire, bidir)
 ┌────────▼──┐ ┌─────▼────┐ ┌───▼──────┐ ┌─▼────────┐
 │AT32F421 #1│ │ #2       │ │ #3       │ │ #4       │  AM32 firmware
 │FD6288Q    │ │ FD6288Q  │ │ FD6288Q  │ │ FD6288Q  │  48 kHz complementary PWM
 │6× 40V FET │ │ 6× FET   │ │ 6× FET   │ │ 6× FET   │  
 └───────────┘ └──────────┘ └──────────┘ └──────────┘
```

### 0.2 Design assumptions

The job specification does not name the MOSFETs, gate driver, or stackup. Every number below follows from these assumptions, so substitute your actual datasheet values.

| Symbol | Value | Basis |
|---|---|---|
| V_bus | 25.2 V (6S full), 22.2 V nominal | Worst case for switching loss |
| f_sw | 48 kHz | Spec |
| I_burst | 80 A per motor (phase RMS ≈ DC-link-referred) | Spec |
