# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #50 spec, so the design is built on the assumptions in §0. Every hardware-dependent number is a named constant in the code. Measure your actual motor R, L, Kt and inertia J before using the tuning formulas.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (e.g. GBM2804), pole pairs p = 7 |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI chip-selects, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) + cogging feedforward | 20 kHz | ADC injected end-of-conversion, center-aligned PWM |
| Velocity PI | 4 kHz | Every 5th current tick |
| IMU acquisition + vibration filters | 8 kHz | IMU data-ready (INT1) |
