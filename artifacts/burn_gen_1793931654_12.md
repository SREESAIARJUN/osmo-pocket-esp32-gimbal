## 1. Conduction-Loss Model

### 1.1 Current paths in synchronous 6-step commutation

In any commutation sector:

- **Phase A (PWM phase):** the high-side FET conducts for duty D. The low-side FET synchronously rectifies for (1−D), because complementary PWM is enabled.
- **Phase B (sink phase):** the low-side FET is held on for 100% of the sector.
- **Phase C:** floating (BEMF sensing).

The instantaneous conducting loss per ESC is therefore:

$$
P_{cond} = I_{rms}^2 \cdot R_{DS}(T_j)\,\big[\,D + (1-D) + 1\,\big] = 2\, I_{rms}^2\, R_{DS}(T_j)
$$

This is **independent of duty**, which is the benefit of synchronous rectification.

### 1.2 Temperature dependence (positive-feedback term)

$$
R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right],\qquad \alpha = \frac{k_T - 1}{100} = 0.006\ \text{K}^{-1}
$$

### 1.3 Ripple correction

The motor phase inductance L_ph (assume 15 µH line-to-line) produces ripple:

$$
\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\, f_{sw}},\qquad 
I_{rms}^2 = I_{pk}^2\left(1 + \frac{1}{12}\left(\frac{\Delta I}{I_{pk}}\right)^2\right)
$$

At D = 0.5, V_bemf ≈ 0.5·V_bus ≈ 12.6 V:

ΔI = 12.6 × 0.5 / (15e-6 × 48e3) = **8.75 A**, so the ripple factor = 1 + (8.75/80)²/12 = **1.001**. This is negligible at 48 kHz, which is one argument for the higher PWM frequency.

## 2. Switching-Loss Model at 48 kHz

Only the PWM-phase half-bridge switches in each sector. The low-side FET turns on into a conducting body diode (soft, ZVS-like). The high-side FET hard-switches against the reverse recovery of the low-side diode.
