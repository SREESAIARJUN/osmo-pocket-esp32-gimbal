## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

The electrical angle comes from the encoder, with an offset found during alignment:

$$\theta_e = p\,(\theta_m - \theta_{off}) \pmod{2\pi}$$

**Clarke transform** (assuming balanced currents, $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Motor Model (dq frame, surface PMSM, $L_d=L_q=L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau_e = \tfrac32 p\lambda\, i_q = K_t i_q$$

### 1.3 Current PI with Decoupling

The per-axis plant is $G(s)=1/(Ls+R)$. Placing the PI zero on the plant pole gives

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

The closed loop then becomes a first-order system $\omega_{ci}/(s+\omega_{ci})$. Choose $\omega_{ci}\approx 2\pi\cdot 1.5\text{ kHz}$, which is at most $f_{pwm}/10$.

The cross-coupling and back-EMF terms are cancelled by feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e(L i_d + \lambda)$$

Set $i_d^* = 0$, since no field weakening is needed at gimbal speeds.

### 1.4 Voltage Limiting and SVPWM

The voltage vector is limited to the linear SVPWM circle, $|v|\le V_{bus}/\sqrt3$. If it exceeds the limit, $v_q$ is clamped first and $v_d$ is given priority.

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Inverse Clarke:**

$$v_a=v_\alpha,\quad v_b=\tfrac{-v_\alpha+\sqrt3 v_\beta}{2},\quad v_c=\tfrac{-v_\alpha-\sqrt3 v_\beta}{2}$$

**Min-max zero-sequence injection** (equivalent to SVPWM):

$$v_0 = -\tfrac12(\max_k v_k + \min_k v_k),\qquad D_k = \tfrac12 + \frac{v_k+v_0}{V_{bus}}$$

### 1.5 Anti-Windup (Back-Calculation)

This is used in every PI loop:

$$I[k+1] = I[k] + T_s\Big(K_i e[k] + K_{aw}\big(u_{sat}[k]-u[k]\big)\Big),\qquad K_{aw}\approx \frac{K_i}{K_p}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant (per axis)

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

The current loop is about 10× faster than the velocity loop, so it is treated as unity gain.
