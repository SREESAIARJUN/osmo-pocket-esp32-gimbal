## 0. Architecture and Rate Plan

```
                ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ────┐ ┌──────── 20 kHz ────────┐
 θ_ref ──►(+)──► Angle P/PI ──► ω_ref ─►(+)──► Velocity PI ──► iq_fb ─►(+)─► Current PI (d,q)
          ▲ −                          ▲ −                      iq_ff ─►│     + decoupling
          │                            │                    (cogging)   │     → inv-Park → SVPWM
   attitude (Mahony)            gyro rate on joint axis                 ▲
          ▲                            ▲                          ia,ib │ θ_e (encoder)
   Dual IMU fusion ◄── notch + LPF ◄── ICM-42688-P ×2 (8 kHz ODR, HW AAF)
```

| Loop | Rate | Target bandwidth | Separation |
|---|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz | – |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz | ≈10× below current |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·20 Hz | ≈7× below velocity |
| IMU pipeline | 8 kHz ODR | AAF ≈ 500 Hz | – |
