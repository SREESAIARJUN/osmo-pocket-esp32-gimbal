## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (e.g., GBM2804-class): 12N14P, p = 7 pole pairs, R = 5.5 Ω (phase), L = 1.8 mH, Kt ≈ 0.06 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) or equivalent |
| Inverter | 3-phase, center-aligned PWM at 40 kHz, low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate (rigid), separate SPI buses |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (each rate is an integer divisor of the PWM rate):**

| Loop | Rate | Trigger | Content |
|---|---|---|---|
| Current (FOC) | 20 kHz | ADC injected-conversion end-of-conversion (EOC) | Clarke, Park, PI, SVPWM |
| Velocity | 4 kHz | every 5th FOC tick | PI on gyro-derived joint rate, cogging feedforward |
| IMU sampling | 8 kHz ODR | IMU DRDY interrupt | Read, align, notch, fuse |
| Angle / attitude | 1 kHz | every 20th FOC tick | AHRS, angle P(I), rate feedforward |

**Bandwidth separation rule:** each outer loop should be at least 4–5× slower than the inner loop:

- ω_c (current) ≈ 2π·1500 rad/s
- ω_v (velocity) ≈ 2π·150 rad/s
- ω_θ (angle) ≈ 2π·25 rad/s

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

`θ_offset` is found at calibration: apply a vector at θ_e = 0 and read the encoder.

### 1.2 Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 dq plant and decoupling

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The controller outputs are the PI terms plus feedforward decoupling, where $\omega_e = p\,\omega_m$ and $\lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 Current PI tuning by pole-zero cancellation

With the decoupling in place, the plant is $G(s) = \dfrac{1}{Ls+R}$. Choosing $K_p = L\,\omega_c$ and $K_i = R\,\omega_c$ cancels the electrical pole, giving the closed loop:

$$T(s) = \frac{\omega_c}{s+\omega_c}$$

**Discrete form** (backward Euler integrator, sample time $T_s$):

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_{\text{sat},k} - u_k)$$

The last term is back-calculation anti-windup, with $K_{aw} = K_i / K_p$.

**Voltage limit:** clamp the voltage vector to the circle of radius $V_{dc}/\sqrt3$, prioritizing $v_d$:

$$|v_d| \le V_{\max},\qquad |v_q| \le \sqrt{V_{\max}^2 - v_d^2}$$

**Gimbal-specific simplification:** gimbal motors are high-R and low-speed. Many designs skip current sensing and use voltage-mode control, $v_q \approx R\,i_q^* + \omega_e\lambda_m$. The code supports both modes, selected with `kUseCurrentSensing`.

### 1.6 Inverse Park and SVPWM

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
