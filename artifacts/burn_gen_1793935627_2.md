# STM32H743 FC + 4-in-1 ESC Stack: Power, Thermal, and Bi-Directional DShot600 Design Model

**Document:** Job #3, System Architecture Baseline, Rev A
**Scope:** 6S, 4×80 A burst, 48 kHz PWM, ArduPilot bi-directional DShot600

---

## 0. Architectural Clarification and Baseline Assumptions

**Clarification.** The STM32H743 does not drive the gate drivers directly. The H743 is the flight controller and runs ArduPilot. It sends bi-directional DShot600 to four (or one quad-core) ESC MCUs, which generate the 48 kHz bridge PWM. This document models both sides:

```
 ┌────────────── FC (STM32H743, ArduPilot) ──────────────┐
 │ TIM3/TIM5 + DMA  ──► BDShot600 (4 lines, 3V3, inverted)│
 └───────────────────────────┬───────────────────────────┘
                             │ 8-pin JST-SH (VBAT, GND, CUR, TLM, M1–M4)
 ┌───────────────────────────▼───────────────────────────┐
 │ 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware)       │
 │ 4× FD6288Q 3-phase gate driver                         │
 │ 24× 40 V N-MOSFET (1 per switch position)              │
 └───────────────────────────────────────────────────────┘
```

**Form-factor warning.** 80 A per channel is not physically credible on a 20×20 mm "nano" board. Copper area, FET count, and bulk capacitance cannot support it. This model therefore assumes:

- a **30.5×30.5 mm ESC**, 6-layer, 2 oz outer / 2 oz inner copper;
- a 20×20 or 30.5 mm FC stacked above it.

If the 20×20 ESC is a hard requirement, the burst rating must drop to roughly 35–45 A.
