# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project-specific data for Job #47, so this design rests on the assumptions listed in §0. Every parameter that depends on your hardware is a named constant in the code. Replace those with values you measure or identify on the real system.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5 Ω, L = 2 mH, λ_m from Kt |
| Commutation sensor | 14-bit magnetic encoder per joint (e.g. AS5048A / MT6701) |
| Attitude sensors | 2 × ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Bus voltage | V_dc = 12–16 V, measured every PWM cycle |

**Loop rates and bandwidths.** Each outer loop's bandwidth is at least 5–10× below the inner loop's.

```
 20 kHz  Current (FOC) loop       BW ≈ 1.5–2 kHz    (ADC-triggered ISR)
  8 kHz  IMU sample + filtering   ODR 8 kHz both IMUs (data-ready ISR / DMA)
  4 kHz  Velocity loop            BW ≈ 100–200 Hz   (gyro-based, camera-frame)
  1 kHz  Attitude/angle loop      BW ≈ 15–30 Hz
```

**Cascade, per axis:**

```
θ_ref ─►[Angle P(I)]─ω_ref─►[Velocity PI(D)]─i_q,pid─►(+)─i_q*─►[FOC PI d/q]─►SVPWM─►Motor
           ▲                    ▲                      ▲
        θ̂ (fusion)        ω̂ (dual gyro, notched)   i_q,cog(θ_m) anti-cogging FF
```
