# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion (Job #5)

## 0. Assumptions

I don't have the Job #5 specification sheet, so this design uses the values below. Every one is a named constant in the code, so you can substitute your real values directly.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motor | Gimbal BLDC 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each motor shaft |
| IMU A | ICM-42688-P on the camera payload. This is the control IMU. |
| IMU B | ICM-42688-P on the base/handle. This is the vibration reference. |
| Loop rates | Current/FOC 20 kHz. IMU and filters 8 kHz. Velocity loop 4 kHz. Angle loop 1 kHz. |
| Drive | 3-phase half-bridge, center-aligned PWM, V_bus = 12 V |

**Rate hierarchy:** each loop runs at least 5× slower than the loop inside it. The bandwidths are set to keep a clear separation between loops:

- Current loop ω_c ≈ 2π·1500 rad/s
- Velocity loop ω_v ≈ 2π·120 rad/s
- Angle loop ω_θ ≈ 2π·25 rad/s

## 1. FOC Inner Current Loop

### 1.1 Electrical angle

$$\theta_e = \operatorname{wrap}_{2\pi}\big(p\,\theta_m - \theta_{off}\big)$$

θ_off is found at commissioning. Inject a d-axis voltage vector at θ_e = 0, let the rotor settle, and record θ_m. Then θ_off = p·θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
