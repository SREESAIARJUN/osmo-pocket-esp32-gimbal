# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #37, so I've assumed a typical brushless gimbal design. The equations are parameterized, so you can substitute your own motor, MCU and loop rates.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A), one per joint |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM at 20 kHz |
| Gimbal order | Yaw → Roll → Pitch (base to camera) |

**Loop rate hierarchy**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity (gyro-based) | 4 kHz | ω_v ≈ 2π·60–100 Hz |
| Angle (attitude) | 1 kHz | ω_θ ≈ 2π·10–20 Hz |
| IMU filtering + fusion | 8 kHz → 4 kHz | — |

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
