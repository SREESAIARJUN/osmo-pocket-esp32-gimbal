## 1. Loop Architecture and Timing

```
           1 kHz                 4 kHz (gyro-rate)            20 kHz (PWM)
 θ_ref ─►[Angle P + FF]─ω_ref─►[Velocity PI + anti-windup]─τ_ref─►÷K_t─►(+)─iq_ref─►[FOC current PI]─►SVPWM─►Motor
            ▲                         ▲                          ▲                       ▲
   attitude (Mahony/AHRS)    joint rate from fused gyro       i_q,cog FF            i_a,i_b, θ_e (encoder)
            ▲                         ▲                     (anti-cogging, θ_m)
            └──── Dual ICM-42688-P (8 kHz ODR) ► AAF ► dynamic notches ► fusion
```

**Bandwidth separation rule.** Each loop must be 4–10× slower than the loop inside it:

- ω_c,current ≈ 2π·1000 rad/s (1 kHz)
- ω_c,vel ≈ 2π·60–120 rad/s
- ω_c,angle ≈ 2π·10–25 rad/s
