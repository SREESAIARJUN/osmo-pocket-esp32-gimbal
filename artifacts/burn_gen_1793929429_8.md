# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

> **Context note:** I don't have access to the "Job #2" specification, so the design below uses typical brushless-gimbal values (listed in §0). Every gain is derived from symbols, so you can substitute your measured motor and inertia parameters directly.

## 0. Assumptions and Timing Architecture

| Item | Value (default) |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (MT6701/AS5048-class) |
| IMUs | 2 × ICM-42688-P on camera plate, SPI, gyro ODR 8 kHz |
| Bus | Vdc = 12–16 V |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (PWM-synchronous ISR) | ω_c ≈ 2π·1.5 kHz |
| Velocity + PLL | 4 kHz | ω_v ≈ 2π·120 Hz |
| Angle / stabilization | 1 kHz | ω_θ ≈ 2π·25 Hz |
| IMU filter + fusion | 8 kHz in, 1 kHz attitude out | — |

Rule: keep each outer loop's bandwidth at least 5× below the next inner loop's. The inner loop can then be modeled as unity gain plus a small delay.

## 1. FOC Inner Current Loop

### 1.1 Transforms
Electrical angle: θ_e = p·θ_m − θ_off (θ_off is found by aligning the rotor at V_d > 0, V_q = 0).

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (SPMSM, L_d = L_q = L)

$$v_d = Ri_d + L\dot i_d - \omega_e L i_q,\qquad v_q = Ri_q + L\dot i_q + \omega_e(Li_d + \lambda_m)$$

Torque: τ = K_t·i_q, with K_t = (3/2)·p·λ_m.

### 1.3 PI with Pole-Zero Cancellation and Decoupling
Controller: C(s) = K_p + K_i/s.

- Choose K_p = L·ω_c and K_i = R·ω_c.
- The open loop then becomes ω_c/s, so the closed loop is ω_c/(s + ω_c).

Decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(L i_d + \lambda_m)$$

Constraints:

- **Delay:** the total delay (≈1.5 T_s with PWM) limits ω_c ≲ 0.2/T_s.
- **Voltage limit:** |v_dq| ≤ V_dc/√3 (linear SVPWM region). When saturating, prioritize v_d and scale v_q.
- **Anti-windup:** back-calculation, ẋ_I = K_i·e + K_aw(u_sat − u), with K_aw ≈ K_i/K_p.

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)
Inverse Park, then inverse Clarke, gives v_a, v_b, v_c. Then:

$$v_0 = -\tfrac12(\max v_x + \min v_x),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$
