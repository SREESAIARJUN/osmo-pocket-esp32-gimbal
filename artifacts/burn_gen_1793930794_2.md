## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path
For 6-step trapezoidal drive with complementary PWM on the high side of the active leg:

- **ON interval (D):** HS_a → motor → LS_b
- **OFF interval (1−D):** LS_a (synchronous freewheel) → motor → LS_b

Exactly two MOSFETs carry the phase current at all times, apart from dead time. Per channel:

$$P_{cond} = 2\, I_{rms}^2 \, R_{ds(on)}(T_j)$$

### 1.2 RMS current with ripple

$$I_{rms}^2 = I_{pk,avg}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} \approx \frac{V_{bus} D(1-D)}{L_{ph-ph}\, f_{sw}}$$

Example: L_ph-ph = 20 µH (typical 2207-class motor), D = 0.5:

ΔI_pp = 25.2 × 0.25 / (20 µH × 48 kHz) = 6.6 A. The ripple term adds 3.6 A², which is 0.06% of 6400 A². It is negligible at 80 A, so I_rms ≈ 80 A.

### 1.3 Temperature dependence

$$R_{ds(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.0045 × 100) = **1.45 mΩ**.

### 1.4 Result

$$P_{cond} = 2 \times 80^2 \times 1.45\,\text{m}\Omega = \mathbf{18.6\ W\ per\ channel}$$

This must be solved self-consistently with the thermal model in §4, because T_j depends on P, which depends on R_ds(T_j). Section 4.4 closes that loop.
