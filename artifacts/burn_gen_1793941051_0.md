## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

Clarke (assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park, using electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park is the transpose.

Inverse Clarke:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

### 1.2 SVPWM (min-max zero-sequence injection)

$$v_{0} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The linear range is |v_dq| ≤ V_bus/√3.

### 1.3 Plant and decoupled PI design

The surface-PMSM model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

Apply decoupling and back-EMF feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda)$$

Each axis then reduces to $G(s)=\frac{1}{Ls+R}$.

Use a PI controller $C(s)=K_p + K_i/s$ with pole-zero cancellation (K_i/K_p = R/L). The closed loop becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$
