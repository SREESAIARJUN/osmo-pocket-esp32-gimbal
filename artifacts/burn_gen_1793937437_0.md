## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model (SPMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 PI tuning by pole-zero cancellation

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c$$

The PI zero cancels the electrical pole R/L, so the closed loop becomes first order: i/i* = ω_c / (s + ω_c).

- Choose ω_c = 2π·1500 rad/s.
- This is below f_pwm/10 once the 1.5-sample computation and PWM delay is accounted for.

### 1.6 Decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.7 Voltage limiting

Limit the voltage vector to the SVPWM linear region, giving priority to the d-axis:

$$|v| \le V_{dc}/\sqrt3$$

### 1.8 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

### 1.9 Anti-windup (back-calculation)

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u),\qquad K_{aw} = K_i / K_p$$

### 1.10 Discretization

The integrator uses forward Euler with step T_s. This is adequate because ω_c·T_s ≈ 0.47.

## 2. Cascaded Angle and Velocity Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Since i_q tracks its reference with bandwidth ω_c ≫ ω_v, the current loop is treated as a unity-gain block.

### 2.2 Velocity loop (PI, pole placement)

Open-loop transfer function:

$$\frac{K_t}{Js}\left(K_p^{(v)} + \frac{K_i^{(v)}}{s}\right)$$

Tuning:

$$K_p^{(v)} = \frac{J\,\omega_v}{K_t},\qquad K_i^{(v)} = \frac{K_p^{(v)}\,\omega_v}{4}$$

The PI zero sits at ω_v/4, which gives about 76° of phase margin.

**Velocity estimate.** Use a PLL tracking observer on the encoder angle rather than a differentiate-and-filter scheme:

$$e_\theta = \text{wrap}(\theta_{enc} - \hat\theta)$$
$$\dot{\hat\omega} = k_2 e_\theta,\qquad \dot{\hat\theta} = \hat\omega + k_1 e_\theta$$
$$k_1 = 2\zeta\omega_o,\qquad k_2 = \omega_o^2,\qquad \omega_o \approx 2\pi\cdot 400,\ \zeta = 1$$

### 2.3 Angle loop (P plus feedforward)

$$\omega^* = K_p^{(\theta)}\,\text{wrap}(\theta^* - \theta) + \dot\theta^*_{ff},\qquad K_p^{(\theta)} = \omega_\theta$$

- An outer integrator is unnecessary because the velocity PI already rejects constant torque disturbances.
- For stabilization, θ is the IMU-derived camera attitude (§4), not the encoder angle. The encoder angle is used only for commutation
