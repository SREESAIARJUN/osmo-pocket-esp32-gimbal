# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the "Job #28" specification, so this design rests on common gimbal-class assumptions, all of which are parameterized:

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474) |
| Motor | GBM2804-class, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 1.5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| PWM / current loop | 20 kHz, center-aligned, 2-shunt or 3-shunt |
| Velocity loop | 4 kHz (÷5) |
| Angle / attitude loop | 1 kHz (÷20) |
| IMUs | 2× ICM-42688-P at 8 kHz ODR over SPI. **IMU-P** on the payload (camera plate), **IMU-B** on the base/handle |

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, with iₐ + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (PMSM in the dq Frame)

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q\dot i_q + \omega_e(L_d i_d + \lambda_m)$$

$$\tau = \tfrac32\,p\,\big(\lambda_m i_q + (L_d-L_q)i_d i_q\big)\;\approx\;K_t\, i_q,\qquad K_t=\tfrac32 p\lambda_m$$

### 1.3 Current PI Controller with Decoupling

Choose the gains to cancel the electrical pole (R/L) and place the closed-loop bandwidth at ω_c:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c\qquad (\omega_c \le 2\pi f_{PWM}/10 \approx 2\pi\cdot 2\text{ kHz})$$

The controller adds back-EMF and cross-coupling feedforward to each axis:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)$$

The reference is i_d* = 0 (surface PM, no field weakening needed at gimbal speeds).

**Voltage-vector limit:** |v_dq| ≤ V_bus/√3 (linear SVPWM region). v_d is given priority, and v_q is clamped to √(V_max² − v_d²).

**Anti-windup (back-calculation):**

$$\dot x_I = K_i e + K_{aw}(v_{sat}-v_{unsat}),\qquad K_{aw}\approx K_i/K_p$$

### 1.4 SVPWM via Min-Max Zero-Sequence Injection

This is mathematically equivalent to sector-based SVPWM.

1. Inverse Clarke:

$$v_a=v_\alpha,\quad v_b=-\tfrac12v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

2. Zero-sequence offset:

$$v_0=-\tfrac12(\max+\min)$$

3. Duty cycles:

$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 1.5 Discretization and Delay Compensation

PWM update plus sampling introduces roughly 1.5 Tₛ of delay. Compensate the angle used in the inverse Park transform:

$$\theta_e^{comp}=\theta_e+1.5\,\omega_e T_s$$
