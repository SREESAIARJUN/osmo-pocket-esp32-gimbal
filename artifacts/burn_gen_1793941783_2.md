# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #42, so this design rests on the assumptions in §0. Every parameter that depends on your hardware is a named constant. Check those constants against your motor datasheet and frame before you power the stage.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | 3-phase gimbal BLDC/PMSM. For example, GBM4108: 12N14P, so pole pairs p = 7, R ≈ 10 Ω, L ≈ 4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A or MT6701) |
| Driver | 3 low-side shunts, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses. Gyro and accel output data rate (ODR) = 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4 or H7), single-precision FPU |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates and bandwidths**

```
IMU 8 kHz ──► notch filters / fusion ──► 1 kHz AHRS (attitude estimate)
                                               │
 setpoint ─► [ANGLE P+FF] 1 kHz ─► ω* ─► [VELOCITY PI] 4 kHz ─► iq* ─(+ cogging FF)─► [CURRENT PI] 20 kHz ─► SVPWM
                  ▲                              ▲                                          ▲
           camera attitude (AHRS)     gyro rate (mapped to joint) ⊕ encoder rate     phase currents, θ_e
```

The bandwidths are separated by roughly 5–10× between nested loops:

- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_θ ≈ 2π·30 Hz

## 1. Field-Oriented Control (FOC) Equations

### 1.1 Transforms

The Clarke transform is amplitude-invariant. It assumes the three phase currents sum to zero: i_a + i_b + i_c = 0.

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

The Park transform uses the electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

The inverse Park transform is the transpose of this matrix.
