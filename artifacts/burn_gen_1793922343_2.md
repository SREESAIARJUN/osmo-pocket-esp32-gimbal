**Loop rates (multirate cascade):**

```
 IMU 8 kHz ──► fusion + vibration filters ──► attitude (Mahony) 1 kHz
                                                   │
 Angle loop   1 kHz  : θ_ref,θ_world  → ω_ref
 Velocity loop 4 kHz : ω_ref, ω_gyro  → i_q,ref (+ cogging FF + inertia FF)
 Current loop 20 kHz : i_q,ref, i_d=0 → v_d,v_q → SVPWM
```

The bandwidth separation rule is ω_c ≥ 4·ω_v ≥ 16·ω_θ. This keeps each inner loop approximately unity gain over the outer loop's bandwidth.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform (with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, with θ_e = p·θ_m − θ_offset and p = 7:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Controller: PI with pole-zero cancellation

The controller is

$$C_i(s) = K_{p,i} + \frac{K_{i,i}}{s},\qquad K_{p,i} = L\,\omega_c,\quad K_{i,i} = R\,\omega_c$$

With this choice the open loop is ω_c/s, and the closed loop is first-order with bandwidth ω_c.

Choose ω_c ≈ 2π·1.5 kHz. That is less than or equal to f_PWM/10, which keeps the 1.5-sample transport delay below about 15° of phase loss.

### 1.4 Decoupling feedforward

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\qquad \lambda_m = \tfrac{2}{3}K_t/p$$

### 1.5 Voltage limiting

Apply a circular limit:

$$\|v_{dq}\| \le \frac{V_{bus}}{\sqrt3}$$

Within that circle, d-axis priority is used and v_q gets the remainder.

### 1.6 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c}^* = v_{a,b,c} - \tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$d_x = \tfrac12 + v_x^*/V_{bus}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Discrete PID with derivative filter and back-calculation anti-windup

The continuous form is:

$$u = K_p e + K_i\!\int e\,dt - K_d\frac{s}{1+s/N}\,y$$

The D-term acts on the measurement, which avoids derivative kick on setpoint steps.

Discretized with backward Euler (sample time T_s):

$$\begin{aligned}
D_k &= \frac{1}{1+N T_s}D_{k-1} - \frac{K_d N}{1+N T_s}(y_k - y_{k-1})\\
v_k &= K_p e_k + I_{k-1} + D_k + u^{ff}_k\\
u_k &= \mathrm{sat}(v_k)\\
I_k &= I_{k-1} + K_i T_s e_k + K_{aw}T_s(u_k - v_k)
\end{aligned}$$

Set K_aw = 1/T_t, with T_t = √(T_i T_d), or T_t = T_i/2 for a PI controller.

### 2.2 Velocity loop (4 kHz)

With the current loop modeled as unity gain, the plant is:

$$\frac{\omega}{i_q} = \frac{K_t}{J s}$$

PI tuning for velocity bandwidth ω_v ≈ 2π·150 Hz:

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The ω_v/4 zero placement gives roughly 76° of phase margin before delays are counted.

**Feedback signal:** use the fused gyro rate, projected onto the joint axis. Do not use the differentiated encoder. The gyro measures the inertial rate of the camera
