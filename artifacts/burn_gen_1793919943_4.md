# 3-Axis Gimbal: FOC, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I have no access to a spec for "Job #43," so this design uses a typical brushless-gimbal configuration. Every parameter below is a named constant in the code, so substitute your actual values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / Cortex-M4F @ 170 MHz, single-precision FPU |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic encoder (AS5048A / MT6701) per joint |
| Current sensing | 2- or 3-shunt, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, gyro ±500 dps, accel ±4 g |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, carries camera) |
