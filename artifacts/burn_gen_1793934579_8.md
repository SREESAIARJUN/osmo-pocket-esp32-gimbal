# STM32H743 Nano FC + 4-in-1 ESC (Job #70): Power-Stage Model, Thermal Budget, Bidirectional DShot Allocation and Netlists

## 0. Architecture Clarifications

These points affect everything downstream.

1. **The H743 does not drive the MOSFETs.** ArduPilot runs on the H743 and emits DShot600. Each motor needs its own ESC MCU (AM32 or BLHeli_32 class, e.g. STM32G071 or AT32F421) running 6-step commutation at 48 kHz. The DShot/DMA design (Section 4) and the power-stage design (Sections 1–3) are separate domains joined by four signal wires.
2. **"80 A" is defined here as per-motor phase current**, i.e. 4 × 80 A potential. Battery current is roughly D × I_phase per motor.
3. **Feasibility finding.** On a nano-format board with 3.3 × 3.3 mm FETs, an 80 A per-motor burst is only survivable for **about 0.3–1 s** (derived in Section 3). If the requirement is sustained or multi-second, the board must grow (30.5 mm, 5 × 6 FETs) or the rating must drop to about 45–55 A burst. I recommend raising this with the requirements owner before layout.

## 1. Conduction Loss Model

### 1.1 Current paths

The topology is 6-step trapezoidal with complementary (synchronous) PWM on the high side. In each 60° sector, phase X is PWM-driven and phase Y is held low.

- **On-time (D):** current flows HS_X → motor → LS_Y.
- **Off-time (1−D):** current flows LS_X (sync rectifier) → motor → LS_Y.

The phase current always passes through exactly **two conducting FETs**.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx \frac{k_T-1}{100} = 0.006\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.8 × 1.6 = **2.88 mΩ**.

### 1.3 Per-FET average over one electrical cycle

Each phase leg spends 120° as the "high" phase, 120° as the "low" phase, and 120° floating.

$$P_{HS} = \tfrac{1}{3}D\,I^2R_{ds} \qquad P_{LS} = \tfrac{1}{3}\left[1 + (1-D)\right]I^2R_{ds}$$

$$P_{cond,ESC} = 3(P_{HS}+P_{LS}) = 2\,I^2R_{ds}$$

### 1.4 Numbers at 80 A, D = 0.9, T_j = 125 °C

I²R = 6400 × 0.00288 = 18.43 W.

| Quantity | Value |
|---|---|
| P_HS per FET | 0.300 × 18.43 = **5.53 W** |
| P_LS per FET | 0.367 × 18.43 = **6.76 W** (hottest device) |
| P_cond per ESC | **36.9 W** |
| P_cond, 4 motors | **147.5 W** |

### 1.5 PWM ripple correction

The RMS current through a FET rises above its DC value because of phase-current ripple:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus}-E_{bemf})\,D}{L_{ph}\,f_{sw}}$$

For a typical 5" motor (L_ph ≈ 15 µH line-line) at high throttle, ΔI ≈ 3–6 A. This adds less than 0.05 %, so it can be neglected at 48 kHz. That is one benefit of the high switching frequency.

### 1.6 Electrothermal stability

Because P_cond depends on T_j through R_ds, the steady state must satisfy:

$$T_j = T_{ref} + R_{th}\,P(T_j)$$

This has a stable solution only if R_th · ∂P/∂T < 1, i.e. R_th · α · P_25 < 1.

For the LS FET (P_25 ≈ 4.2 W at 1.8 mΩ), the result is R_th < 40 K/W. Thermal runaway is therefore not the binding constraint; the absolute temperature limit is. Iterate R_ds(T_j) in the transient solver (Section 3.4).

## 2. Switching Loss Model at 48 kHz

Per ESC, only the PWM leg switches hard: one HS/LS pair per PWM period.
