# STM32H743 FC + 4-in-1 ESC Stack (Job #62): Electro-Thermal Model, Bidirectional DShot600 Allocation and Reference Netlist

## 0. Architecture Clarifications

These points set the scope of every calculation below.

1. **The H743 does not commutate the motors.** ArduPilot has no BLDC commutation firmware. The H743 is the flight controller and sends bidirectional DShot600. Each of the four ESC channels has its own MCU running AM32 or BLHeli_32. This model uses an AT32F421, which generates the 48 kHz PWM.
2. **"80A burst" on a nano form factor is thermally marginal.** The model below shows that 4 × 80 A can only be sustained for a few seconds, even with ideal MOSFETs. I use a 30.5 × 30.5 mm (36 × 36 mm outline) board. A 20 × 20 mm board cuts the thermal capacity by about 2.5×, so the burst window shrinks to about 2–3 s.
3. **All device parameters are stated assumptions** (representative 40 V DFN5×6 MOSFET). Re-run the equations with the datasheet values of the parts you actually select.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

R_DS(T_j) = R₂₅ · [1 + α(T_j − 25)]

At T_j = 125 °C: R_DS = 1.0 mΩ × 1.45 = **1.45 mΩ**
