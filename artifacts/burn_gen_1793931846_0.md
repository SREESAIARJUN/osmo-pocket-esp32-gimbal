**Engineering flag.** 4 × 80 A burst on a 20×20 nano board is at the edge of physical plausibility. The thermal model in §3 shows it is a **burst-only rating of about 1–2 s**. Continuous capability is roughly 25–35 A per channel with airflow. Marketing should rate the board "80 A burst (1 s)" or not at all.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\bigl[1+\alpha\,(T_j-25)\bigr],\qquad \alpha\approx 0.0045\ /\mathrm{K}$$

At T_j = 125 °C: R_DS ≈ 1.0 × 1.45 = **1.45 mΩ**.

### 1.2 Six-step BLDC with synchronous rectification

At any instant two phase legs conduct the phase current I:

- **Phase A (PWM leg):** the high-side switch conducts for duty D. The complementary low-side switch conducts for (1−D).
- **Phase B (return leg):** the low-side switch conducts continuously for the 120° sector.

Total conduction loss per ESC channel, independent of D because synchronous rectification always provides a MOSFET path:

$$P_{cond,ch} = I^2 R_{DS}(T_j)\,[D + (1-D)] + I^2 R_{DS}(T_j) = 2\,I^2 R_{DS}(T_j)$$

Add the PCB copper and solder path to the phase pads and battery input:

$$P_{cu,ch} = I^2 R_{trace},\qquad R_{trace}\approx 0.4\ \mathrm{m\Omega}\ \text{(8-layer, 2 oz paralleled, hot)}$$

**At 80 A, T_j = 125 °C:**

$$P_{cond,ch} = 2(80)^2(1.45\times10^{-3}) = 18.6\ \mathrm{W}$$
$$P_{cu,ch} = 80^2(0.4\times10^{-3}) = 2.56\ \mathrm{W}$$

### 1.3 RMS refinement

In real motor operation the phase current has ripple. The PWM ripple term is:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

Example: a 2207-class motor with L_ph ≈ 15 µH (line-line), V_bus − V_bemf = 3 V at the burst operating point, and D = 0.9:

$$\Delta I \approx \frac{3 \times 0.9}{15\times10^{-6}\times 48\times10^{3}} \approx 3.75\ \mathrm{A}$$

The ripple term ΔI²/12 ≈ 1.2 A² is negligible against 6400 A². The DC model holds at burst.

## 2. Switching Loss Model at 48 kHz

These losses occur only on the PWM leg, once per PWM period.

### 2.1 Hard-switching V–I overlap (high-side switch)

$$P_{sw} = \tfrac12\,V_{bus}\,I\,(t_r+t_f)\,f_{sw} = \tfrac12(25.2)(80)(20\times10^{-9})(48\times10^3) = 0.97\ \mathrm{W}$$

### 2.2 Reverse recovery of the low-side body diode

$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = (40\times10^{-9})(25.2)(48\times10^3) = 0.048\ \mathrm{W}$$

Q_rr scales with di/dt and current. Use about 2× the datasheet value at 80 A, giving roughly **0.1 W**.

### 2.3 Output capacitance (Q_oss) loss

$$P_{oss} = Q_{oss}\,V_{bus}\,f_{sw} = (35\times10^{-9})(25.2)(48\times10^3) = 0.042\ \mathrm{W}$$

### 2.4 Dead-time body-diode conduction

There are two dead-time intervals per period:

$$P_{dt} = V_F\,I\,(2\,t_{dt})\,f_{sw} = (0.8)(80)(100\times10^{-9})(48\times10^3) = 0.31\ \mathrm{W}$$

### 2.5 Gate drive

This is dissipated in the driver and gate resistors, not in the MOSFETs. There are two switching FETs per PWM leg:

$$P_{gate} = 2\,Q_g\,V_{GS}\,f_{sw} = 2(45\times10^{-9})(10)(48\times10^3) = 0.043\ \mathrm{W}$$

### 2.6 Per-channel switching total

$$P_{sw,ch} = 0.97 + 0.10 + 0.042 + 0.31 \approx 1.42\ \mathrm{W}$$

**Design note.** Switching loss is about 7 % of total at 80 A. Dropping to 24 kHz saves only about 0.7 W per channel but adds audible noise and current ripple. **Keep 48 kHz.** Conduction loss dominates, so spend the money on R_DS(on), not Q_g.

## 3. Thermal Model

### 3.1 Total burst dissipation

| Term | Per channel | ×4 channels |
|---|---|---|
| MOSFET conduction | 18.6 W | 74.4 W |
| Copper | 2.56 W | 10.2 W |
| Switching (MOSFET) | 1.42 W | 5.7 W |
| Driver, LDOs, ESC MCU | 0.15 W | 0.6 W |
| **Total** | **≈ 22.7 W** | **≈ 91 W** |

Peak per-MOSFET dissipation occurs on the continuously-on low-side FET of the return leg:

$$P_{FET,max} = I^2 R_{DS} = 6400 \times 1.45\times10^{-3} = 9.3\ \mathrm{W}$$

### 3.2 Lumped thermal RC network

```
 P_FET ──► [Z_th,jc = 1.2 K/W, τ≈5 ms] ──► Board node (C_b, T_b) ──► [R_ba] ──► T_amb
                                              ▲
                     all other FET/copper loss ┘
```

**Board heat capacity:**

| Component | Calculation | Heat capacity |
|---|---|---|
| Copper | 8 layers × ~60 % fill × 26×26 mm × 70 µm ≈ 0.28 cm³ → 2.5 g × 0.385 J/g·K | 0.96 J/K |
| FR4 | ≈ 1.5 g × 1.1 J/g·K | 1.65 J/K |
| 24 MOSFETs + solder + capacitors | ≈ 1.2 g × 0.6 J/g·K | 0.72 J/K |
| **C_b** | | **≈ 3.3 J/K** |

**Board-to-ambient resistance:**
- Still air: R_ba ≈ 25 K/W
- Prop-wash airflow (about 5–10 m/s): R_ba ≈ 8 K/W

### 3.3 Board temperature during burst

$$T_b(t) = T_{amb} + P_{tot}R_{ba}\left(1-e^{-t/(R_{ba}C_b)}\right)$$

With airflow, τ = R_ba·C_b ≈ 26 s ≫ t_b. The burst is therefore heat-capacity limited:

$$\frac{dT_b}{dt}\approx \frac{P_{tot}}{C_b} = \frac{91}{3.3} \approx 27.6\ \mathrm{K/s}$$

### 3.4 Junction temperature

$$T_j(t) = T_b(t) + P_{FET}\,Z_{th,jc}(t)$$

The junction is thermally settled after about 20 ms:

$$\Delta T_{jc} = 9.3 \times 1.2 = 11.2\ \mathrm{K}$$

### 3.5 Burst time limit

Assumptions:
- Start condition: T_amb = 35 °C, with a cruise pre-heat to T_b0 = 60 °C
- Limit: T_j,max = 150 °C. Derate to 125 °C for margin, consistent with the R_DS value used above.

$$t_b = \frac{(125 - 11.2) - 60}{27.6} \approx \mathbf{1.95\ s}$$

From a cold start (T_b0 = 35 °C), t_b ≈ 2.9 s.

### 3.6 Iterating for self-consistency

1. Assume T_j.
2. Compute R_DS.
3. Compute P.
4. Compute T_j.
5. Repeat until converged.
