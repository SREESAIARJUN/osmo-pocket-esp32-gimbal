## 0. Architecture Clarification and Assumptions

**Architecture.** ArduPilot does not commutate BLDC motors. The practical architecture is therefore:

- **Flight controller:** an STM32H743 running ArduPilot. It generates the DShot600 command stream and decodes bi-directional (BDShot) eRPM telemetry.
- **ESC section:** four independent ESC MCUs (for example AT32F421 or STM32G071 running AM32/
