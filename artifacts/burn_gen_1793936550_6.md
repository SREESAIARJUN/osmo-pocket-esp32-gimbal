# STM32H743 FC + 80A 4-in-1 ESC: Loss, Thermal, and DShot DMA Model (Job #52)

## 0. Scope and Assumptions

**Architecture.** Bi-directional DShot requires the ESC to run its own firmware, such as AM32 or BLHeli_32. The system is therefore partitioned as follows:

```
[STM32H743 FC, ArduPilot] --4x BDShot600--> [4x ESC MCU (AT32F421)] --> [3-ph gate driver] --> [6x2 MOSFET bridge] --> motor
```

The H743 does not drive the gates. It generates DShot frames and captures eRPM telemetry.
