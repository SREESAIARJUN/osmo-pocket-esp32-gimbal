## 0. Assumptions and System Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC (e.g., GBM2804-class): 12N14P → pole pairs $p = 7$, 12 slots |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A/MT6701 class) |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7). The code is single-precision `float`. |
| Kinematic chain | Base → **Yaw** (z) → **Roll** (x) → **Pitch** (y) → camera |
| IMU-A (ICM-42688-P) | Mounted on the camera plate. Provides inertial feedback. |
| IMU-B (ICM-42688-P) | Mounted on the base/handle. Provides base-motion feedforward and a vibration reference. |
| IMU config | Gyro ±2000 dps (16.4 LSB/°/s), accel ±16 g (2048 LSB/g), ODR 8 kHz, on-chip AAF ≈ 1 kHz |

### Loop-rate hierarchy

Each outer loop runs at least 5× slower than the loop inside it, so the inner loop can be treated as ideal during design.

```
 20 kHz  ── FOC current loop (PWM-synchronous ISR, ADC injected trigger)
  4 kHz  ── Velocity loop  (inertial rate from IMU-A, mapped to joint space)
  1 kHz  ── Angle loop     (attitude from Mahony filter)
  8 kHz  ── IMU acquisition + vibration filtering (FIFO/DMA, timestamped)
```

| Loop | Target bandwidth | Separation |
|---|---|---|
| Current | ~2 kHz | — |
| Velocity | ~150–250 Hz | ≥8× below current |
| Angle | ~20–40 Hz | ≥5× below velocity |

## 1. Field-Oriented Control (Current Loop)

### 1.1 Electrical model (surface PMSM, $L_d = L_q = L$)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2} p \lambda_m i_q = K_t i_q,\qquad \theta_e = p\,\theta_m - \theta_{\text{off}},\qquad \omega_e = p\,\omega_m
$$

### 1.2 Clarke transform (amplitude-invariant, $i_a+i_b+i_c=0$)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

### 1.3 Park transform and its inverse

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} v_d\\ v_q\end{bmatrix}
$$

### 1.4 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation: place the PI zero on the electrical pole $R/L$, so the closed loop becomes first order with bandwidth $\omega_{ci}$.

$$
K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}
\;\;\Rightarrow\;\; \frac{i_q}{i_q^*} = \frac{\omega_{ci}}{s+\omega_{ci}}
$$

The commanded voltages add decoupling and back-EMF terms:

$$
v_d^* = \text{PI}_d(i_d^* - i_d) - \hat\omega_e \hat L i_q,\qquad
v_q^* = \text{PI}_q(i_q^* - i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)
$$
