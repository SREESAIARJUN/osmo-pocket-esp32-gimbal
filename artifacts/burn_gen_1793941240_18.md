# STM32H743 Nano FC + 4-in-1 ESC (Job #16): Loss, Thermal, DShot/DMA and Netlist Package

**Scope and assumptions.** The parameters below are representative. Every derived number traces back to the assumptions table, so you can substitute your actual BOM values.

## 0. Architecture Correction

The STM32H743 does **not** switch the MOSFETs. A 4-in-1 ESC needs a dedicated ESC MCU, either one per motor or one shared (for example AT32F421 or STM32G071 running AM32). That MCU generates the **48 kHz** complementary PWM. ArduPilot on the H743 only sends **bidirectional DShot600** and receives eRPM telemetry. The model is split accordingly:

| Domain | Owner | Key parameter |
|---|---|---|
| Power stage, 48 kHz PWM, burst current | ESC MCU (AM32, `PWM_FREQ=48`) | Losses, thermal |
| Motor command and telemetry | H743 / ArduPilot | Timers, DMA, timing |

## 2. Conduction Loss Model

### 2.1 Topology

The model uses six-step trapezoidal commutation with complementary (synchronous-rectified) PWM on the switching leg. At any instant, phase current flows through exactly **two conducting channels**:

- either the high-side of the PWM leg (fraction D) or its low-side as synchronous rectifier (fraction 1−D), and
- the static low-side of the return leg.

So, independent of D:

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{DS}(T_j)$$

### 2.2 Ripple Correction

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}} \;\Rightarrow\; \Delta I_{pp,max}\big|_{D=0.5} = \frac{25.2 \times 0.25}{30\,\mu\text{H}\times 48\,\text{kHz}} = 4.4\ \text{A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 1.6 \approx 6402\ \text{A}^2$$

Ripple is negligible (<0.03%) at 48 kHz. This is a key benefit of 48 kHz over 24 kHz, where ripple would be about 4× larger.

### 2.3 Temperature-Dependent R_DS(on), Solved Self-Consistently

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

Iterating with the thermal model in §4 converges at T_j ≈ 110 °C:

$$R_{DS}(110) = 1.2 \times (1 + 0.006 \times 85) = 1.81\ \text{m}\Omega$$

$$P_{cond,motor} = 2 \times 6402 \times 1.81\times10^{-3} = \mathbf{23.2\ W}$$

Each FET conducts for one-third of the electrical cycle on average. The electrical frequency is about 3.5 kHz (14-pole motor at 30 krpm), which is much faster than the die thermal time constant (ms). The losses therefore average:

$$P_{cond,FET} = \frac{P_{cond,motor}}{6} \approx 3.87\ \text{W}$$

### 2.4 Thermal Runaway Check

$$\frac{dP_{cond}}{dT_j} = 2I^2 R_{25}\alpha = 2(6400)(1.2\text{m})(0.006) = 0.092\ \text{W/K (per motor)}$$

Per FET this is 0.015 W/K. Multiplied by the local R_θ of about 11.5 K/W, the loop gain is about 0.18, which is below 1. The design is stable, but the margin shrinks quickly if R_θ degrades (for example from poor solder voiding).
