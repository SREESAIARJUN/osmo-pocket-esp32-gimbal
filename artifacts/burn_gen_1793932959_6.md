# STM32H743 AIO + 4-in-1 ESC: Power-Stage, Thermal and Bi-Directional DShot Design Model

This is a design-intent package, not a release package. It gives you the governing equations, a worked numerical model with every assumption stated, the ArduPilot timer and DMA plan, and reference netlists.

Before any of the numbers, two issues need flagging:

1. **Architecture.** The H743 does not commutate the motors. A 48 kHz six-step bridge with BEMF zero-cross detection needs a dedicated ESC MCU per motor. The model below assumes 4× AT32F421 (or STM32G071) running AM32, with the H743 as the flight controller speaking DShot600 to them on-board. If you meant the H743 to run FOC directly, DShot disappears from the design entirely and the timer plan changes.
2. **Feasibility.** "80 A burst" per channel on a nano (20×20 mm) board is not thermally achievable for more than about a second. The model below proves this. Treat the 80 A figure as a short-transient rating, and plan around the board-size or rating changes in §3.4.
