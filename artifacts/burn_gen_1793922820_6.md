# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #45, so the design below is parameterized. Every assumption is listed in §0. Replace those values with your hardware's before tuning.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class: FPU, CORDIC optional, 3× ADC injected on PWM center |
| Motors | Gimbal BLDC, e.g. GBM2804: 12N14P, so pole pairs p = 7, R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per joint, read over SPI |
| Current sense | Low-side shunts on 2 or 3 phases |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz |
| Gimbal order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |

**Loop rates (each ≥ 5× bandwidth separation):**

```
 20 kHz  Current PI (d,q) + SVPWM                     BW ≈ 1.5–2 kHz
  4 kHz  Velocity PI (+ cogging FF, accel FF)          BW ≈ 150–250 Hz
  8 kHz  IMU sampling → dual-IMU fusion → filters
  1 kHz  Angle P(D) + attitude estimator                BW ≈ 20–40 Hz
```
