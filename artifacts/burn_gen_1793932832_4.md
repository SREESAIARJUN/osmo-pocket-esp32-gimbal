# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the specification for "Job #7", so this design uses the assumptions in §0. Every motor- or board-specific number is a named constant you can replace.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC) or STM32H7 |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Commutation sensor | 14-bit magnetic encoder per joint (AS5048A / MT6701) |
| Current sensing | 2-shunt, synchronized to PWM center |
| IMUs | 2× ICM-42688-P on the **camera plate**, SPI, gyro ODR 8 kHz, accel ODR 1 kHz |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop schedule (cascaded, integer rate ratios):**

```
20 kHz  : ADC → Clarke/Park → current PI (id, iq) → SVPWM          [ISR, ~6 µs]
 4 kHz  : dual-IMU read → filters → fusion → joint-rate mapping → velocity PI(D) + cogging FF
 1 kHz  : Mahony attitude update → angle P(I) loop → velocity setpoint
```

Velocity feedback comes from the **camera gyro**, not the encoders. Inertial rate is the quantity being stabilized. The encoders are used only for commutation and the cogging map.

## 1. FOC Current Loop (innermost, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 Current PI with pole-zero cancellation
Choose the closed-loop bandwidth $\omega_c$, typically 2π·1.5 kHz, which is at most $f_{pwm}/10$.

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This gives a first-order closed loop, $i_q/i_q^* = \omega_c/(s+\omega_c)$.

Discrete form (forward Euler, $T_s = 1/f_{pwm}$) with decoupling feedforward:

$$e_k = i^*_k - i_k,\quad I_k = I_{k-1} + K_{i,i} T_s e_k + K_{aw}(v_{sat} - v_{unsat})_{k-1}$$
$$v_d = K_{p,i} e_d + I_d - \omega_e L i_q,\qquad v_q = K_{p,i} e_q + I_q + \omega_e (L i_d + \lambda_m)$$

**Voltage limiting:** $v_d$ has priority. Then

$$|v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = V_{bus}/\sqrt3$$

**Back-calculation anti-windup:** $K_{aw} = 1/K_{p,i}$.
