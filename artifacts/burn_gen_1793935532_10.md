I don't have the Job #56 specification, so this design uses the stated baseline assumptions below. Every parameter is a named constant, so you can substitute your real values.

## 0. Baseline Assumptions & Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz (FPU, CORDIC, 3× ADC, HRTIM/TIM1) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 10 Ω, L = 4 mH (phase-to-neutral ≈ R/2, L/2 for line measurements; use per-phase values) |
| Kt | 0.08 N·m/A (measure: Kt = 1.5·p·λ_m) |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the pitch/roll intersection, sharing a 32 kHz CLKIN |
| Bus voltage | 12–16 V |
