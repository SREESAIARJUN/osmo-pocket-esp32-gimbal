# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Model (Job #33)

## 0. Scope, Architecture, and Design Warnings

This is an architecture-level model. The MOSFET, driver, and thermal parameters below are representative values. Before layout release, replace them with datasheet values for the parts you actually select. The netlists are reference topology, not a production-verified BOM.

### Architecture

The STM32H743 runs ArduPilot only. It does not commutate motors. Each of the 4 ESC channels has its own commutation MCU (AT32F421, running AM32 or BLHeli_32-class firmware). The H743 sends DShot600 frames to the ESCs and receives GCR-encoded eRPM telemetry back on the same wire.

```
                 ┌──────────────────── STM32H743 (ArduPilot) ────────────────────┐
 IMU (SPI1/DMA)──┤ TIM1_CH1..CH4 ── bidir DShot600 ──┐                           │
 Baro (I2C2)  ───┤ USARTx (GPS, RC, ESC-telem opt.)  │                           │
 OSD/Flash(SPI)──┤ ADC: VBAT, CURR                   │                           │
                 └───────────────────────────────────┼───────────────────────────┘
                     ┌──────────────┬────────────────┼──────────────┐
                 ESC1 MCU       ESC2 MCU         ESC3 MCU       ESC4 MCU  (AT32F421)
                 3ph driver     3ph driver       3ph driver     3ph driver
                 6× MOSFET      6× MOSFET        6× MOSFET      6× MOSFET
                 └──────── shared VBAT bus, bulk + MLCC decoupling ────────┘
```

### Critical design warning: 80A on a nano board is burst-only

An 80A burst on all four channels of a nano board (20×20 or 25.5×25.5 mm) is thermally feasible only for a few seconds. Section 1.6 shows this quantitatively. The board must be rated as **"80A burst (≤2–3 s), ~35–45A continuous"**, or the form factor must grow.

### 1.2 Conduction loss

The ESC runs 6-step trapezoidal commutation with complementary (synchronous) PWM. At every instant, the phase current flows through exactly two conducting devices: one in the PWM leg (high-side or low-side) and the low-side of the return leg. This holds regardless of duty cycle D, so the conduction loss per ESC channel is:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds(on)}(T_j), \qquad R_{ds(on)}(T_j)=R_{25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 100 °C:

- R_ds(on) = 1.3 mΩ × (1 + 0.005·75) = **1.79 mΩ**
- P_cond = 2 × 6400 × 1.79×10⁻³ = **22.9 W per channel**

**Electrothermal feedback.** Because R_ds(on) rises with temperature, conduction loss feeds back on itself:

$$P_{cond}(T_j)=P_0\,[1+\alpha(T_j-25)],\quad T_j = T_a + R_{th}\,P_{total}$$

The loop is stable only if α·R_th·P₀ < 1. With P₀ = 16.6 W (the 25 °C value), the effective board-level R_th per channel must stay below about 12 K/W to avoid runaway. This is easily met in steady state, but it shows why sustained 80A cooks the board.

### 1.3 Switching losses at 48 kHz

Only one leg switches per commutation sector, which gives one hard-switched pair per channel.

**(a) V–I overlap.** The switching time is t_sw ≈ Q_sw / I_gate = 12 ns per edge, so t_r + t_f ≈ 24 ns.

$$P_{VI}=\tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw}=0.5\cdot25.2\cdot80\cdot24\text{ns}\cdot48\text{k}= \mathbf{1.16\ W}$$

**(b) Dead-time body-diode conduction.**

$$P_{dt}=V_f\,I_{ph}\,(2t_{dt})\,f_{sw}=0.8\cdot80\cdot200\text{ns}\cdot48\text{k}=\mathbf{0.61\ W}$$

**(c) Reverse recovery.**

$$P_{rr}=Q_{rr}V_{bus}f_{sw}=50\text{nC}\cdot25.2\cdot48\text{k}=\mathbf{0.06\ W}$$

The real value is often 2–3× higher with snappy diodes. It also adds turn-on loss in the opposite FET.

**(d) C_oss charge and discharge, both devices in the leg.**

$$P_{oss}=C_{oss}V_{bus}^2 f_{sw}=1.5\text{nF}\cdot635\cdot48\text{k}=\mathbf{0.05\ W}$$

**(e) Gate drive, dissipated mostly in the driver and gate resistors.**

$$P_g = 2\,Q_g V_{GS} f_{sw}=2\cdot40\text{nC}\cdot10\cdot48\text{k}=\mathbf{0.04\ W}$$

**Total switching loss ≈ 1.9 W per channel.**

At 80A, conduction loss is about 12× switching loss. Lowering f_sw from 48 kHz to 24 kHz saves only about 1 W per channel. The dominant lever is R_ds(on), meaning paralleled FETs or a bigger package.

### 1.4 Ancillary losses

| Source | Model | Estimate per channel |
|---|---|---|
| PCB copper (phase + bus) | I²·R_cu. 2 oz Cu, ~0.4 mΩ path | 2.6 W |
| Input cap ESR (MLCC bank, ESR ~2 mΩ) | I_cap,rms = I_ph·√(D(1−D)), max 40 A at D = 0.5 | 3.2 W (whole bank, at D = 0.5) |
| Shunt (if per-channel, 0.25 mΩ) | I²R | 1.6 W |

**Capacitor ripple.** The 40 A_rms ripple per channel is a hard design constraint. Interleaving the four ESCs' PWM phases reduces it. AM32 does not phase-lock its channels, so assume worst-case additive ripple: the √4 × 40 = 80 A_rms combined value applies only if the channels are uncorrelated.
