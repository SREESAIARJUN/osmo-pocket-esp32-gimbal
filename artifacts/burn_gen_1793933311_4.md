## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

Electrical angle: θ_e = p·(θ_m − θ_offset), wrapped to [0, 2π).

**Clarke** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.3 Decoupled PI Controller with Pole-Zero Cancellation

After feedforward decoupling, each axis reduces to G(s) = 1/(Ls + R). Choose the PI controller

$$C(s) = K_p + \frac{K_i}{s}, \qquad K_p = L\,\omega_{ci},\quad K_i = R\,\omega_{ci}.$$

The controller zero then cancels the plant pole, so the closed loop becomes the first-order system ω_ci/(s + ω_ci).

Set ω_ci ≈ 2π·1.5 kHz. Keep it below about f_s/10 so the 1.5-sample transport delay (ADC sampling plus PWM update) costs less than about 20° of phase margin.

The applied voltages, with decoupling feedforward, are:

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q, \qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$
