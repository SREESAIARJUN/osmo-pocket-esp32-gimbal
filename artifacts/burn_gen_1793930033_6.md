# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #12 spec sheet, so this design uses the assumptions listed below. Every parameter is a named constant, so you can substitute your real motor, encoder and MCU values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class with single-precision FPU, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, data-ready interrupts |
| Loop rates | Current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, attitude 1 kHz |

## 1. System Architecture

```
            ┌────────────── 1 kHz ──────────────┐ ┌──── 4 kHz ────┐ ┌───── 20 kHz ─────┐
θ_ref ──►(Σ)─► Angle P + rate FF ─► ω_ref ──►(Σ)─► Vel PI ──►(Σ)─► i_q* ─► Current PI ─► SVPWM ─► Motor
          ▲                                ▲                ▲ i_q,ff                 ▲ i_d,i_q
          │ θ_joint (attitude→joint)       │ ω_joint        │                        │ Clarke/Park
          │                                │                └── Cogging FF(θ_m, ω) ◄─┤ θ_e = p·θ_m
     Mahony AHRS ◄── Dual-IMU fusion ◄── notch/LPF bank ◄── 2× ICM-42688-P (8 kHz)   │
                                             ▲ tracking notch at k·ω_m       Encoder ─┘
```

Feedback sources:

- **Inertial rate** (gyro, mapped to joint axes) closes the velocity loop. This is what gives stabilization.
- **Fused attitude** closes the angle loop.
- **Encoder** is used for commutation, cogging phase, and a PLL speed estimate. The PLL rate is blended in at low frequency so the joint does not drift.

## 2. Current (FOC) Loop — 20 kHz

### 2.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}})$$

Clarke transform (amplitude-invariant, assuming $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant and decoupling

The PMSM dq-axis voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Adding feed-forward decoupling terms removes the cross-coupling and back-EMF:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis is first order: $G(s) = 1/(Ls+R)$.

### 2.3 PI tuning by pole-zero cancellation

Choose a closed-loop current bandwidth $\omega_c$ (about $2\pi \cdot 1.5$ kHz, i.e. at most $f_{pwm}/10$) and set:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This cancels the plant pole, so the closed loop becomes $\omega_c/(s+\omega_c)$.

### 2.4 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k$$
$$u_k^{sat} = \operatorname{sat}(u_k)$$
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u_k^{sat} - u_k)\right]$$

A typical choice is $K_{aw} = K_i/K_p$.

### 2.5 Voltage limiting and SVPWM

The voltage vector is limited to the inscribed circle $|v| \le V_{dc}/\sqrt3$. When limiting is needed, $v_d$ gets priority and $v_q$ takes the remainder.

SVPWM uses min-max zero-sequence injection:

$$v_0 = -\tfrac12\left(\max(v_{a,b,c}) + \min(v_{a,b,c})\right)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

> **Voltage-mode fallback.** Many gimbal motors have no phase-current shunts. In that case, set $v_q = R\,i_q^* + \omega_e\lambda_m$ and $v_d = -\omega_e L i_q^*$ (open-loop current). The outer loops are unchanged.

## 3. Velocity and Angle Cascade

### 3.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

The torque constant is $K_t = \tfrac32 p \lambda_m$.
