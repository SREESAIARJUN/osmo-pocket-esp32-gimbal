## 0. Design Assumptions

| MCU | STM32G4 / H7 class, FPU, 170+ MHz | Single-precision float budget |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH | Current-loop gains, cogging order |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI | Electrical angle, velocity |
| Current sensing | 2-shunt inline or low-side | If absent, use voltage mode (§2.5) |
| PWM | 25 kHz center-aligned | |
| Current loop | 25 kHz (1 per PWM) | Bandwidth ≈ 1.5–2.5 kHz |
| Velocity loop | 5 kHz | Bandwidth ≈ 150–300 Hz |
| Attitude loop | 1 kHz | Bandwidth ≈ 20–40 Hz |
| IMU A | ICM-42688-P on the camera plate (feedback) | Gyro ODR 8 kHz, FIFO |
| IMU B | ICM-42688-P on the handle/base (disturbance feedforward + redundancy) | Same configuration |

The loop bandwidths are deliberately separated by about 5–10×, so each inner loop looks like unity gain to the loop around it.

## 1. Coordinate Frames and Notation

- θ_m: mechanical rotor angle. θ_e = p·θ_m − θ_off is the electrical angle.
- ω_m: mechanical speed. ω_e = p·ω_m.
- Torque: τ = K_t·i_q, with K_t = (3/2)·p·λ_m.
- q ∈ ℍ: camera attitude quaternion (world ← camera).
- R_A, R_B: fixed mounting rotations from each IMU's frame into the camera frame and base frame, respectively.

## 2. Field-Oriented Control (Innermost Loop, 25 kHz)

### 2.1 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

### 2.2 Park transform

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Before the transform, compensate the electrical angle for the sampling and PWM transport delay:

$$
\hat\theta_e = \theta_e + \omega_e \cdot 1.5\,T_s
$$

### 2.3 Plant model and decoupled PI

The motor in the dq frame:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

The controller is a PI per axis plus cross-coupling and back-EMF feedforward:

$$
v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L\, i_q
$$

$$
v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L\, i_d + \omega_e \lambda_m
$$

**Tuning by pole-zero cancellation.** Choose the target current bandwidth ω_c, then set

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
$$

so the PI zero K_i/K_p = R/L cancels the electrical pole. The closed loop is then first order, i/i* = ω_c/(s + ω_c).

Bound the bandwidth with ω_c ≤ 2π·f_s/10. At 25 kHz, f_c ≈ 2 kHz.

### 2.4 Voltage limiting and SVPWM

**Circular limit.** Clamp the voltage vector to the linear SVPWM range:

$$
|v| \le V_{dc}/\sqrt3
$$

Give d-axis priority:

$$
v_q \le \sqrt{V_{max}^2 - v_d^2}
