## 2. FOC Current Loop

### 2.1 Transforms
Use the amplitude-invariant Clarke transform with two measured phase currents (i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform, with electrical angle θ_e = p·(θ_m − θ_offset) and p = 7:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 PMSM Model (dq frame, surface-mount so L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32\,p\,\lambda_m\,i_q \equiv K_t\, i_q$$

### 2.3 Controller
Cancel the cross-coupling and back-EMF with feedforward terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

With these removed, each axis reduces to the plant G(s) = 1/(Ls + R). A PI controller whose zero cancels the plant pole,

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,$$

gives a first-order closed loop:

$$\frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Discretize with backward Euler on the integrator, then add a one-sample delay compensation on the angle: θ_e ← θ_e + 1.5·ω_e·T_s. The 1.5 accounts for the computation delay plus the PWM zero-order hold.

### 2.4 Voltage Limiting and Anti-Windup
Limit the voltage vector to the linear SVPWM circle, |v| ≤ V_bus/√3:
- Give **d priority**.
- Then set $v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$.

The integrators use **back-calculation**:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw} = \frac{K_i}{K_p}=\frac{R}{L}$$

### 2.5 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and has no branching.
