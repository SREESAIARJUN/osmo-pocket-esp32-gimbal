# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model (Job #20)

## 0. Feasibility Findings

Three issues change the architecture, so they come first.

1. **The STM32H743 does not drive the MOSFET bridges.** In an AIO design, the H743 runs ArduPilot and sends DShot600 to four dedicated ESC MCUs. Those are typically AT32F421 or STM32G071 chips running AM32 or BLHeli_32. Each ESC MCU generates the 48 kHz complementary PWM and handles commutation. The H743 has no spare advanced timers or CPU budget to run four sensorless FOC/6-step loops and ArduPilot together.
2. **80 A per channel on a "nano" (20×20 mm) board is not thermally achievable.** The math in §3 shows the board heats at roughly 20–25 K/s with all four channels at 80 A, so it can sustain the burst for about 2–3 s. The realistic options are:
   - a 30.5×30.5 mm board with 5×6 mm FETs, or
   - an 80 A rating defined as a sub-second, single-channel peak.
3. **The 80 A figure needs a defined duty cycle.** The model below assumes a **10 s burst, 6S (25.2 V max), all four channels simultaneously** as the worst case, then derates.

All values in this document are engineering estimates. Validate them against the specific MOSFET datasheet Zth curves and a thermocouple or IR test before release.

## 2. Loss Model (per ESC channel, 6-step trapezoidal, synchronous rectification)

### 2.1 Definitions

| Symbol | Value | Meaning |
|---|---|---|
| I | 80 A | phase DC current (burst) |
| V_bus | 25.2 V | 6S full charge (worst case) |
| f_sw | 48 kHz | PWM frequency |
| R₂₅ | 0.8 mΩ | R_DS(on) @ 25 °C |
| α | ≈ 0.0045 /K | R_DS(on) temperature coefficient |
| t_r, t_f | 20 ns, 15 ns | voltage rise/fall at the I_g used |
| t_dt | 100 ns | dead time per edge |
| V_SD | 0.8 V | body-diode forward voltage |
| Q_rr | 40 nC | body-diode reverse recovery |
| Q_g | 60 nC | total gate charge @10 V |
| C_oss,er | 1.5 nF | energy-related output capacitance |

R_DS(on) as a function of temperature:

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)] \;\Rightarrow\; R_{DS}(100^\circ C)\approx 1.34\,R_{25} = 1.07\text{ m}\Omega$$

Use **1.2 mΩ** to include package and copper spreading resistance.

### 2.2 Conduction Loss

In 6-step operation, two half-bridges conduct at any instant. With synchronous rectification, the phase current always flows through exactly one FET per active leg, either the high side during D or the low side during 1−D.

**Per-leg loss**, including ripple:

$$P_{cond,leg} = I_{rms}^2\,R_{DS}(T_j), \qquad I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}$$

The ripple term is small because ΔI is set by L_motor / f_sw. With 10% ripple, it adds 0.08%, which is negligible.

**Per channel** (two active legs):

$$P_{cond} = 2\,I^2 R_{DS} = 2 \times 6400 \times 1.2\times10^{-3} = \mathbf{15.4\ W}$$

**Per-FET split** at throttle duty D. Each FET conducts one-third of the electrical cycle on average across 6 commutation states:

$$P_{HS} = \tfrac{1}{3}\,I^2 R_{DS}\,D \cdot 2,\qquad P_{LS} = \tfrac{1}{3}\,I^2 R_{DS}\,(1-D)\cdot 2$$

Averaged, the losses spread over six FETs at about **2.6 W each**. However, the instantaneous load on the conducting pair is **7.7 W per FET**, and this is the figure that matters for the junction transient (§3.3).

### 2.3 Switching Loss at 48 kHz

Only the hard-switched FET in the PWM-ed leg contributes. The synchronous partner turns on ZVS-like after dead time.

**1. V–I overlap loss**

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(35\text{ns})(48\text{k}) = \mathbf{1.69\ W}$$

**2. Dead-time body-diode conduction** (two edges per period)

$$P_{dt} = V_{SD}\,I\,(2t_{dt})\,f_{sw} = 0.8(80)(200\text{ns})(48\text{k}) = \mathbf{0.61\ W}$$

**3. Reverse recovery**

$$P_{rr} = V_{bus} Q_{rr} f_{sw} = 25.2(40\text{n})(48\text{k}) = \mathbf{0.048\ W}$$

**4. C_oss loss**

$$P_{oss} = \tfrac12 C_{oss,er} V_{bus}^2 f_{sw} = 0.5(1.5\text{n})(635)(48\text{k}) = \mathbf{0.023\ W}$$

**5. Gate drive** (6 FETs; only the PWM pair switches at f_sw, so the bound is conservative)

$$P_g = Q_g V_{GS} f_{sw} \times 2 = 60\text{n}(10)(48\text{k})(2) = \mathbf{0.058\ W}$$

This loss lands in the driver and gate resistors, not in the FETs.

$$P_{sw,total} \approx \mathbf{2.43\ W}$$

**Design levers:**
- **P_VI** scales with f_sw. At 24 kHz it halves, but motor current ripple and audible noise increase.
- **P_dt** is the second-largest term. AM32 dead-time tuning to about 50 ns saves roughly 0.3 W per channel. Verify shoot-through margin with a scope first.

### 2.4 Other Losses

| Item | Model | Value |
|---|---|---|
| Shunt (per channel, 0.25 mΩ) | I²R | 1.60 W |
| PCB copper (est. 0.3 mΩ path, 2 oz × 4 layers) | I²R | 1.92 W |
| Bus capacitor ESR (I_rms,cap ≈ 0.5·I) | (0.5I)²·ESR, 3 mΩ eff. | 4.80 W ⚠ |
