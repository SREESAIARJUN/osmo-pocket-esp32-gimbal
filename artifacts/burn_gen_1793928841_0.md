| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |

### Loop rates

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | PWM-center ADC interrupt |
| Velocity | 4 kHz | Every 5th FOC tick |
| Attitude/angle | 1 kHz | Every 4th velocity tick, after IMU fusion |
| IMU | 8 kHz | Data-ready interrupt → DMA → fusion runs at 4 kHz on 2-sample averages |

Each loop runs about 5× faster than the one inside it, and each loop's bandwidth is set to roughly 1/5–1/10 of the inner loop's bandwidth.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

where $p$ is the number of pole pairs and $\theta_{\text{off}}$ is the calibrated encoder offset.

**Clarke transform** (amplitude-invariant, using $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model and current PI design

The PMSM voltage equations in the rotor frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

where $\omega_e = p\,\omega_m$ and $\lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$.

**Decoupling.** Adding the cross-coupling and back-EMF terms as feedforward leaves the plant $G_i(s) = \frac{1}{Ls+R}$:

$$v_d^{\text{ff}} = -\omega_e L i_q,\qquad v_q^{\text{ff}} = \omega_e L i_d + \omega_e\lambda_m$$

**PI design by pole-zero cancellation.** With $C_i(s) = K_p + K_i/s$, choosing

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

makes the zero $K_i/K_p = R/L$ cancel the electrical pole. The closed loop then becomes first-order:

$$T_i(s) = \frac{\omega_{ci}}{s + \omega_{ci}}$$

Bandwidth choice: $\omega_{ci} = 2\pi\cdot 1.5\text{ kHz}$. This is below $f_s/10$ at 20 kHz, which leaves enough phase margin to absorb the one-sample computation delay plus the PWM zero-order hold (≈ $1.5T_s$ total).

**Discretization** (backward Euler, $T_s = 50\,\mu s$):

$$x_k = x_{k-1} + K_i T_s e_k,\qquad u_k = K_p e_k + x_k$$

### 1.3 Voltage limiting and anti-windup

The output voltage vector is limited to the linear SVPWM region, $|v| \le V_{\text{bus}}/\sqrt3$, with the q-axis given priority:

$$v_d \leftarrow \operatorname{sat}(v_d,\,V_{\max}),\qquad v_q \leftarrow \operatorname{sat}\!\left(v_q,\,\sqrt{V_{\max}^2 - v_d^2}\right)$$

**Back-calculation anti-windup**, with $K_{aw} = 1/K_p$:

$$x_k \leftarrow x_k + K_{aw}\,(u^{\text{sat}}_k - u_k)$$
