# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #48)

## 0. Assumptions

I don't have the Job #48 spec sheet, so the parameters below are typical for a 1–2 kg camera payload. Every number is a `constexpr` or config field in the code, so you can replace them directly.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: FPU, 170+ MHz, hardware trig optional |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Power stage | 3-phase driver, 2 or 3 low-side shunts, V_bus = 12–16 V |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 8 kHz ODR |

| Loop | Rate | Feedback |
|---|---|---|
| PWM / current (FOC) | 20 kHz | Phase currents + encoder |
| Velocity | 4 kHz | Fused gyro rate (inertial) |
| Angle / attitude | 1 kHz | Fused attitude estimate |
| Cogging learning | 4 kHz | Velocity-loop effort |

Keep at least a 4–5× bandwidth separation between loops (current ≈ 1.5 kHz, velocity ≈ 150–250 Hz, angle ≈ 20–40 Hz).

## 1. Field-Oriented Control (Inner Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \pmod{2\pi}, \qquad \hat\theta_e^{\,\text{comp}} = \theta_e + p\,\omega_m\,T_d$$

Here T_d ≈ 1.5 T_PWM compensates for sampling and PWM-update latency.

### 1.2 Clarke transform

Amplitude-invariant form, using two shunts:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32\, p\, \lambda_m\, i_q \equiv K_t\, i_q$$
