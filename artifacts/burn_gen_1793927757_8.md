# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #61)

## 0. Design Assumptions

These assumptions drive the numbers below. Change them in `GimbalConfig` if your hardware differs.

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Encoder | 14-bit absolute magnetic (AS5048A/MA730 class), one per axis |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the plate's rotation centre |
| Mechanical order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| Loop rates | Current/FOC: 20 kHz. Rate: 4 kHz. Attitude: 1 kHz. IMU ODR: 8 kHz (decimated ×2 to 4 kHz) |

### Control architecture

```
                 IMU fusion (camera attitude q̂, rate ω̂)
                          │                │
θ_ref ─►(+)─► Angle P/PI ─► ω_ref ─►(+)─► Rate PI ─► iq_ref ─►(+)─► Current PI (d,q) ─► SVPWM ─► Motor
        −▲                        −▲                 ▲ iq_cog    −▲
         └ q̂ (IMU)                 └ ω̂ (gyro)         │           └ Park(Clarke(i_abc), θ_e)
                                                Anti-cogging FF(θ_m from encoder)
```

Two notes on this architecture:

- The **encoder** is used only for commutation (θ_e) and for anti-cogging (θ_m).
- The **stabilisation loops** close on the IMU, which measures the inertial camera attitude.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

**Electrical angle:**
θ_e = p·(θ_m − θ_offset)

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

**Park transform:**
- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park transform:**
- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 Plant and decoupled PI

The motor model in the dq frame is:

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

**Decoupling feedforward:**
- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e L i_d + ω_e λ_m

After decoupling, each axis is the first-order plant 1/(Ls + R). Choosing the PI zero to cancel the plant pole gives a closed-loop bandwidth of ω_c:

- K_p,i = L·ω_c
- K_i,i = R·ω_c

Choose ω_c ≤ 2π·f_PWM/20, i.e. about 2π·1 kHz at 20 kHz PWM.
