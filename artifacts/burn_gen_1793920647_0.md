## 1. Field-Oriented Control: Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder:
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, balanced phases so $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and PI Tuning

The motor in the rotating $dq$ frame:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Decoupling feedforward** removes the cross-coupling and back-EMF terms:
$$v_d^{ff} = -\omega_e L\, i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

After decoupling, each axis reduces to the first-order plant $G(s)=\dfrac{1}{Ls+R}$.

**Pole-zero cancellation tuning.** Choose the PI zero to cancel the plant pole, so the closed loop becomes first order with bandwidth $\omega_c$:
$$C(s)=K_p+\frac{K_i}{s},\quad K_p=L\,\omega_c,\quad K_i=R\,\omega_c \;\Rightarrow\; T(s)=\frac{\omega_c}{s+\omega_c}$$

Use $\omega_c = 2\pi\cdot 1500$ rad/s. This satisfies $\omega_c \le \omega_{\text{PWM}}/10$, accounting for the 1.5-sample PWM transport delay.

**Torque constant** (SPM, $i_d^* = 0$):
$$\tau = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 SVPWM with Voltage Limiting

The voltage vector is limited to the linear-modulation circle, giving priority to $v_d$:
$$|v|\le \frac{V_{dc}}{\sqrt3},\qquad v_q \leftarrow \text{sign}(v_q)\min\!\left(|v_q|,\sqrt{V_{\max}^2 - v_d^2}\right)$$

**Min–max zero-sequence injection** (equivalent to SVPWM):
$$v_{abc} = \text{invClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12(\max v_{abc}+\min v_{abc}),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

### 1.4 Discrete PI with Back-Calculation Anti-Windup

Forward-Euler integrator with back-calculation from the saturated output:
$$u_k = K_p e_k + I_k + u^{ff}_k,\qquad \bar u_k=\text{sat}(u_k)$$
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(\bar u_k - u_k)\right],\qquad K_{aw}\approx \frac{K_i}{K_p}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Feedback Signal Selection

For a camera gimbal, the controlled quantity is **camera inertial attitude**, not motor angle. Therefore:

- **Velocity loop feedback:** the fused gyro rate projected onto the joint axis. This is the primary stabilization signal; it is low-noise and has no encoder-differentiation lag.
- **Angle loop feedback:** the attitude error from the estimator (§4), mapped into joint space.
- **Encoder:** used for commutation, anti-cogging phase, and the kinematic Jacobian.
