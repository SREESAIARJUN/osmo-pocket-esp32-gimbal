# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the original Job #4 spec, so this design rests on the assumptions in §0. Every parameter is a named constant, so you can substitute your real values directly.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (GM4108-class), 24N22P → pole pairs p = 11, R ≈ 10 Ω, L ≈ 4 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701) |
| MCU | STM32G4 / H7-class, single-precision FPU |
| Current sensing | 2-shunt inline or low-side. A voltage-mode fallback is provided. |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
