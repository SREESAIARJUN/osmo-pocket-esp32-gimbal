## 0. Architecture

The STM32H743 cannot practically run the flight stack and commutate 12 half-bridges at the same time. The architecture is therefore:

```
STM32H743 (ArduPilot, 400 MHz)
   │  4× bi-directional DShot600 (TIM1 CH1–CH4, DMA)
   ▼
4× AT32F421 / STM32G071 ESC MCUs (AM32 / BLHeli_32-class firmware)
   │  6-step or sinusoidal PWM @ 48 kHz, complementary w/ dead-time
   ▼
4× 3-phase gate driver (FD6288Q-class) → 24× N-MOSFET (12 half-bridges)
```

The 48 kHz switching frequency belongs to the ESC MCUs. The H743 only generates DShot frames and decodes eRPM telemetry.

**Design-feasibility verdict:** On a nano/20×20 or 30×30 board, "80 A burst" per motor is achievable only for about 1–2 s. Continuous capability is about 20 A per motor. Section 3 derives these numbers.

## 1. Conduction Loss Model

### 1.1 Parameters

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | 6S full charge | 25.2 V |
| I_ph | Burst phase current | 80 A |
| R_ds,25 | R_DS(on) at 25 °C, V_GS = 10 V | 1.6 mΩ **[DS]** |
| α | R_DS(on) temperature coefficient | 0.0055 /K **[DS]** |
| T_j | Design junction temperature | 110 °C |
| R_th,jc | Junction-to-case (bottom) | 1.2 K/W **[DS]** |

### 1.2 Temperature-corrected on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.6\,(1+0.0055\cdot85) = 2.35\ \text{m}\Omega$$

### 1.3 Six-step commutation with synchronous rectification

In each 60° sector, two phases carry I_ph:

- **Phase A (PWM leg):** The high-side FET conducts for duty D. The low-side FET then conducts the freewheel current synchronously for 1–D. The leg's conduction is therefore continuous:
  $$P_{A}=I^2R_{ds}\,D + I^2R_{ds}(1-D) = I^2R_{ds}$$
- **Phase B (static leg):** The low-side FET is on for the whole sector:
  $$P_B = I^2 R_{ds}$$

The loss per ESC channel is:

$$\boxed{P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)} = 2\cdot 80^2\cdot 2.35\times10^{-3} = 30.1\ \text{W}$$

The worst single FET is the static low-side, at about **15 W during the sector**. It rotates between three legs, giving a time-averaged ≈ 10 W per leg pair. Thermally, use the peak value, because a sector at low eRPM (e.g., 1 ms) is long compared with the die's thermal time constant (around 1–5 ms).

With all four motors at 80 A: **P_cond,total ≈ 120 W**.

### 1.4 Copper and shunt losses (often ignored, should not be)

- **Battery bus:** I_bat ≈ 4·I_ph·D. At D = 0.8, I_bat ≈ 256 A.
- **Shunt:** A 0.25 mΩ shunt at 256 A dissipates **16 W**. This is why most 4-in-1 boards use per-motor sensing or a smaller shunt. Recommendation: use 4 × 0.5 mΩ, one per ESC. Each carries about 64 A and dissipates 2 W.
- **Planes:** 2 oz copper is ≈ 0.25 mΩ/□ at 25 °C. Budget about 0.5 mΩ effective path per phase, giving 80²·0.5 m = **3.2 W/ch**. Use 3–4 oz outer layers plus stitched inner planes.
