# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #38 specification, so the design below rests on explicit assumptions. Each one is a parameter in the code.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (GBM2804 class), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Driver | 3-phase PWM, 2 or 3 low-side shunts |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR = 8 kHz |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |

## 1. Loop Architecture and Rates

```
                     ┌──────────── 1 kHz ────────────┐  ┌──── 4 kHz ────┐  ┌──── 20 kHz ────┐
 q_ref ─► Attitude ─►│ angle P + rate FF → J⁻¹(q)    │─►│ Rate PI (IMU) │─►│ i_q PI + FOC   │─► PWM
          error(SO3) │ (camera frame → joint frame)  │  │ + cogging FF  │  │ SVPWM          │
                     └───────────────▲───────────────┘  └──────▲────────┘  └───────▲────────┘
                       fused attitude│              fused gyro │      i_abc, θ_e    │
                 ┌───────────────────┴─────────────────────────┴──┐                 │
                 │ Dual ICM-42688-P: AAF → calib → lever-arm      │    Encoder → PLL observer
                 │ cancel → dyn. notch → LPF → weighted fusion    │    (θ_m, ω_m) for commutation
                 │ → Mahony attitude                              │    and the cogging table
                 └────────────────────────────────────────────────┘
```

Bandwidth separation rule: each outer loop should be at least 4–5× slower than the loop inside it.

- Current loop: ω_c ≈ 2π·1.5 kHz
- Rate loop: ω_v ≈ 2π·60–120 Hz
- Angle loop: ω_a ≈ 2π·10–20 Hz
