# FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion for a 3-Axis Gimbal

## 0. Assumptions

"Job #26" didn't come with hardware details, so this design uses a typical brushless gimbal stack. Every value below is a parameter you can change.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz (FPU + CORDIC) |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–12 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per joint |
| Current sense | 2-shunt or inline, 12-bit ADC sampled at the PWM center |
| PWM / current loop | 20 kHz center-aligned PWM, current loop at 20 kHz |
| Velocity loop | 4 kHz (fed by the IMU gyro for inertial stabilization) |
| Angle / attitude loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, ODR 8 kHz, SPI @ 24 MHz |

Loop bandwidths are separated by about 4–10× per stage:

- Current loop: ω_i ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_θ ≈ 2π·30 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m, the pole-pair count p, and a calibrated offset θ_off:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
