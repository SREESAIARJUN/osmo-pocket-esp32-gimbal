## 0. Architecture Clarification and Design Assumptions

ArduPilot running on the STM32H743 does **not** commutate motors. A 4-in-1 ESC needs four dedicated ESC MCUs running AM32 or BLHeli_32. The H743 talks to them over bidirectional DShot600 (BDShot).

**Architecture:** H743 FC → 4× BDShot lines → 4× AT32F421 (AM32) → 4× FD6288Q gate drivers → 24 MOSFETs.

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (analysis case), 22.2 V nominal |
| Burst current | 80 A per motor (phase/DC-link current), up to 10 s |
| PWM | 48 kHz, complementary (synchronous) 6-step trapezoidal |
| MOSFET (reference class) | 40 V N-ch, PDFN 5×6 (e.g., Toshiba TPHR8504PL, onsemi NTMFS5C404N class) |
| R_DS(on) | 0.9 mΩ @ 25 °C, V_GS = 10 V |
| Q_g | 70 nC |
| Q_gd | 10 nC |
| Q_oss | 60 nC |
| Q_rr | 50 nC |
| V_SD | 0.8 V |
| Gate drive | 10 V, R_g(ext) = 4.7 Ω, dead time 100 ns |
| Form factor | 30.5×30.5 mm stack, 4-layer FC + 6-layer 2 oz ESC |
| Ambient | 40 °C |
| Cooling | Prop-wash convection, h ≈ 50 W/m²K |

> **Feasibility flag (up front):** On a nano or 30.5 mm board, 80 A is a *burst* rating only. The model below shows sustained current is about 24 A per motor. Any datasheet claim must state burst duration and conditions.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)],\qquad \alpha \approx 0.005\ \mathrm{K^{-1}}$$

At T_j = 110 °C:
**R_DS = 0.9 × (1 + 0.005 × 85) = 1.28 mΩ.**

### 1.2 Per-ESC conduction during a 6-step sector

In each sector, two phases conduct:

- **PWM-ed phase:** the high-side (HS) conducts for duty D, and the synchronous low-side (LS) conducts for 1 − D.
- **Return phase:** the LS is on continuously.

$$P_{cond} = I^2\left[R_{HS}D + R_{LS}(1-D)\right] + I^2 R_{LS} = 2I^2R_{DS}\quad(\text{equal FETs})$$

$$P_{cond} = 2(80)^2(1.28\times10^{-3}) = \mathbf{16.4\ W}$$

### 1.3 Copper and interconnect loss

Assume an effective path resistance of R_Cu ≈ 0.5 mΩ (pads, 2 oz planes, vias, solder, wire pads):

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W}$$

### 1.4 Per-FET worst case

The continuously-on return LS FET dissipates:

$$I^2 R = 6400 \times 1.28\ \mathrm{m\Omega} = \mathbf{8.2\ W}$$

This is concentrated in one 5×6 package for one-sixth of an electrical revolution. Thermally it averages over the revolution, but you should design to the instantaneous peak at low eRPM.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times

Gate current during the Miller plateau, using the FD6288Q (≈1.5 A source, 1.8 A sink nominal) and R_g = 4.7 Ω + R_g(int) 1 Ω, with V_plateau ≈ 3.5 V:

$$I_{g,on} = \frac{10-3.5}{5.7} \approx 1.14\ \mathrm{A}\;\Rightarrow\; t_r \approx \frac{Q_{gd}+Q_{gs2}}{I_{g,on}} \approx \frac{10+7\ \mathrm{nC}}{1.14} \approx 15\ \mathrm{ns}$$

$$I_{g,off} = \frac{3.5}{5.7} \approx 0.61\ \mathrm{A},\ \text{with a turn-off diode/low-R sink path}\;\Rightarrow\; t_f \approx 10\ \mathrm{ns}$$

### 2.2 Loss components (per ESC; only the PWM-ed leg hard-switches)

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·25 ns·48 kHz | **1.21 W** |
| C_oss | ½·Q_oss·V·f·2 ≈ Q_oss·V·f | 0.07 W |
| Body-diode reverse recovery | Q_rr·V·f | 0.06 W |
| Dead-time diode conduction | 2·V_SD·I·t_dt·f = 2·0.8·80·100 ns·48 kHz | **0.61 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_GS·f | 0.07 W |
| **Total switching-related** | | **≈ 2.0 W** |

**Key insight:** At 48 kHz, switching is about 10% of losses. Conduction dominates, so 80 A performance is set by R_DS(on), copper, and thermal mass, not f_sw.

Dead-time loss is the largest secondary term. To reduce it:
- Trim AM32 dead time to the minimum safe value (verify with a double-pulse test).
- Note that 48 kHz versus 24 kHz roughly doubles this term (+0.6 W).

### 2.3 Total per ESC and per board at burst

$$P_{ESC} = 16.4 + 3.2 + 2.0 \approx \mathbf{21.6\ W}\qquad P_{board} = 4\times21.6 \approx \mathbf{86\ W}$$

Efficiency at 80 A, 25.2 V (≈2 kW in): **≈ 98.9%**.

### 2.4 DC-link capacitor ripple (often the real failure point)

$$I_{C,rms} \approx I\sqrt{D(1-D)} \le 0.5\,I = \mathbf{40\ A_{rms}}\ \text{per ESC (worst case, D = 0.5)}$$

The four ESCs are asynchronous, so the board-level combination is roughly √4 × 40 ≈ 80 A_rms worst case, with local high-frequency ripple taken mostly by MLCCs.

Required capacitance:
- **Per ESC:** 4× 10 µF/50 V X7R 1210 placed within 3 mm of each half-bridge. Each provides about 3 A_rms, which supplies high-frequency current only.
- **Board level:** 1× 35 V 1000 µF low-ESR electrolytic on the battery leads (mandatory, external), plus 2× 100 µF/35 V polymer on-board.
