## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Drive | 3-phase half-bridge, center-aligned PWM 24 kHz, 2-shunt inline current sense |
| Encoder | 14-bit absolute magnetic (AS5048A/MA730-class) per joint |
| IMUs | 2× ICM-42688-P on the camera plate, symmetric about the payload center of mass, SPI at 24 MHz, gyro/accel ODR 8 kHz, FSYNC/CLKIN shared |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7-class) |

**Loop timing.** All loops run off one timer, so their phase relationships are deterministic.

```
PWM 24 kHz ──► Current loop (FOC, d/q PI)         24 kHz   ISR
           └─÷3─► IMU read + filters + rate loop     8 kHz
                 └─÷8─► Attitude estimator + angle loop  1 kHz
Background: cogging LMS adaptation, IMU health, telemetry
```

**Cascade per axis.**

```
θ_ref ─►[Angle P/PI]─► ω_ref ─►[Rate PI-D]─► τ_ref ─►(+ cogging FF + gravity FF)─► i_q* ─►[FOC PI]─► SVPWM
           ▲ q_cam (fused attitude)   ▲ ω_cam (fused gyro, filtered)              ▲ i_d, i_q (shunts)
```

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m, with calibrated offset θ_0:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e (L i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q \quad (\text{surface PM},\ L_d = L_q)$$

### 1.3 PI Design by Pole–Zero Cancellation

The plant is $G(s) = 1/(Ls+R)$. Choose the PI controller $C(s) = K_p + K_i/s$ with

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

For a 24 kHz loop with one-sample computation delay plus ZOH, keep $\omega_c \le 2\pi f_s/20 \approx 2\pi\cdot1.2$ kHz. This leaves at least 60° of phase margin.

Cross-coupling decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$
