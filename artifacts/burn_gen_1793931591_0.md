# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original "Job #2" specification, so this design states its hardware assumptions explicitly (§0). Every parameter is isolated in config structs so you can substitute your actual values.

## 0. Assumed Hardware and Timing Architecture

| Item | Assumption |
|---|---|
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase, center-aligned PWM 20 kHz, 2- or 3-shunt sensing |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, mounted point-symmetric about the plate centroid |
| IMU ODR | 8 kHz gyro/accel, data-ready interrupt, shared CLKIN (32 kHz) for synchronization |

**Loop rates (cascaded with ≥4–5× bandwidth separation):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| IMU filtering | 8 kHz | n/a |
| Velocity | 4 kHz | ~150–250 Hz |
| Attitude/angle | 1 kHz | ~30–50 Hz |

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:
$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

Park transform:
$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

Inverse Park transform:
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac{3}{2} p \lambda_m i_q \equiv K_t\, i_q$$
