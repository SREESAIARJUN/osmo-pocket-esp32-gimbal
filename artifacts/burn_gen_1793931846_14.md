**Rev A: Engineering Baseline**

## 0. Scope and Constraints

Three issues shape the rest of this document:

1. **The H743 does not commutate the motors.** ArduPilot cannot run four 48 kHz FOC/6-step loops while also running the flight stack. The industry-standard and only supportable architecture is:
   - STM32H743 running ArduPilot (the flight controller).
   - Four independent ESC MCUs (STM32G071 or AT32F421) running AM32, at 48 kHz PWM.
   - Bidirectional DShot600 between them.

   This document models that architecture.
2. **"80A burst" on a nano form factor is thermally marginal.** Section 3 shows it is achievable only as a **≤1–2 s burst** on a 30×30 mm board. It is not achievable on 20×20 mm, and it is not achievable continuously. I state this up front rather than let the numbers hide it.
3. **Component values are engineering assumptions.** Wherever a datasheet value is assumed, it is flagged [A]. Re-run the model with your actual BOM.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 110 °C:

$$R = 1.1\ \text{m}\Omega \times 1.383 = 1.52\ \text{m}\Omega$$

### 1.2 Current Paths in 6-Step with Synchronous PWM

In any 60° sector, one phase is high (HS active), one phase is low (LS active), and the third floats. With complementary PWM at duty D:

- The PWM'd HS FET conducts for D·T.
- Its complementary LS FET conducts for (1−D)·T, minus the dead-time.
- The opposite-phase LS FET conducts continuously.

There are always **two channels in series with the phase current I_ph**:

$$P_{cond,ESC} = 2\,I_{ph,rms}^2\,R_{DS(on)}(T_j)$$

### 1.3 Phase Current versus Battery Current

$$I_{bat} \approx D \cdot I_{ph} \quad\Rightarrow\quad I_{ph} = I_{bat}/D$$

At burst (D → 0.95–1.0), I_ph ≈ I_bat. The worst case for the FETs is high current at mid duty, for example a locked prop or hard punch-out at low RPM: 80 A phase current at D = 0.5 corresponds to only 40 A battery current. The FET stage must therefore be rated on **phase** current, which AM32 limits via `CURRENT_LIMIT` and stall protection.

### 1.4 Numerical Result (80 A Phase, T_j = 110 °C)

$$P_{cond,FET} = 2 \times 80^2 \times 1.52\times10^{-3} = 19.5\ \text{W per ESC}$$

**Copper path loss.** With 2 oz copper, ~0.3 mΩ effective per phase path (bus → HS → phase pad → motor and return):

$$P_{Cu} = 2 \times 80^2 \times 0.3\times10^{-3}/2 \approx 1.9\ \text{W}$$

Busbar strips plus solder-filled phase pads are mandatory.

**Per-FET distribution.** Each FET conducts 1/3 of the electrical cycle:
- Instantaneous loss while conducting: 9.7 W.
- Cycle-averaged loss per FET: 3.25 W.
