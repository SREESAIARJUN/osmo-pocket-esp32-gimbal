## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× outrunner gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase-phase 11.2 Ω), L = 2.0 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701 class), SPI |
| Inverter/MCU | STM32G474 class (170 MHz, FPU, CORDIC optional), center-aligned PWM 20 kHz, 24 V bus, 2-shunt or inline current sensing |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro ±2000 dps, accel ±16 g, ODR 8 kHz |
| Mechanical order | Yaw (outer) → Roll → Pitch (inner, camera) |

**Loop rates (all phase-locked to the PWM timer):**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz | Ts_i = 50 µs |
| IMU read + filtering | 8 kHz | Ts_imu = 125 µs |
| Velocity (rate) | 4 kHz | Ts_v = 250 µs |
| Angle (attitude) | 1 kHz | Ts_a = 1 ms |

**Bandwidth separation.** Each outer loop runs about 5–10× slower in bandwidth than the loop inside it:

- Current loop: ω_ci = 2π·2000 rad/s
- Velocity loop: ω_cv = 2π·150 rad/s
- Angle loop: ω_ca = 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

θ_e = p·(θ_m − θ_offset) mod 2π

θ_offset is found at calibration by applying a d-axis voltage vector and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

### 1.3 Park transform

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 1.4 PMSM model in the dq frame

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

Here ω_e = p·ω_m. Torque is τ = (3/2) p λ_m i_q = K_t i_q (surface PM, so L_d = L_q).

### 1.5 PI current controller with decoupling (pole-zero cancellation)

Gains:

- K_p,i = L·ω_ci
- K_i,i = R·ω_ci

Applying these cancels the plant pole R/L, so the closed loop becomes first order:

i_q / i_q* = ω_ci / (s + ω_ci)

Control law:

- v_d* = PI(i_d* − i_d) − ω_e L i_q
- v_q* = PI(i_q* − i_q) + ω_e L i_d + ω_e λ_m

For gimbals, i_d* = 0.

### 1.6 Discrete PI with back-calculation anti-windup

- u_k = K_p e_k + I_k
- u_sat = clamp(u_k, ±U_max)
- I_(k+1) = I_k + K_i T_s e_k + K_aw T_s (u_sat − u_k)

Choose K_aw ≈ K_i/K_p, i.e. the inverse of the integral time.

**Voltage vector limiting.** Use circular limiting with q-priority:

- |v_dq| ≤ V_bus/√3 (linear SVPWM limit)
- v_q,max = √(V_max² − v_d²)

### 1.7 Inverse Park + SVPWM (min-max zero-sequence injection)

Inverse Park:

- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

- v_a = v_α
- v_b = −½v_α + (√3/2)v_β
- v_c = −½v_α − (√3/2)v_β
