# STM32H743 FC + 4-in-1 80A ESC (Job #24): Loss Model, Thermal Model, and Bi-Directional DShot600 Timer/DMA Allocation

## 0. Architecture and Assumptions

### 0.1 Partitioning

The STM32H743 runs the **flight controller** (ArduPilot). Each ESC channel has its **own small MCU** running AM32 or BLHeli_32-class firmware, for example an AT32F421 or STM32G071.

The H743 does not commutate 24 FETs directly. Doing so would compromise loop determinism, and no mainstream ArduPilot firmware supports that topology.

### 0.3 Sanity Flag

Four channels at 80 A simultaneously would draw **about 320 A from the battery**. No nano-class pack, XT60 connector, or 12 AWG lead sustains that.

"80A burst" is treated here as a **per-channel transient rating**. The full 4×80 A case is computed as an absolute worst-case envelope.

## 1. Conduction Loss Model

### 1.1 Current Path (6-step trapezoidal, synchronous/complementary PWM)

At any instant, phase current flows through **exactly two conducting devices**:

- one switching leg (either the HS FET, or the LS FET acting as a synchronous rectifier), and
- one static low-side FET in the return phase.

Deadtime excursions are handled separately in §2.4. The model is:

```
P_cond,ch = I² · (2·R_ds(T_j) + R_pcb)
R_ds(T_j) = R_ds,25 · [1 + α·(T_j − 25)]
```
