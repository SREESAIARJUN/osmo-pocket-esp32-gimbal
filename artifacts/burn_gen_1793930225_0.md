### Loop rates

| Loop | Rate | Ts | Bandwidth target |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | 50 µs | ω_c ≈ 2π·1.5 kHz |
| Velocity (PI) + anti-cogging | 4 kHz | 250 µs | ω_v ≈ 2π·150 Hz |

Bandwidth rule: each outer loop should have ≤ ¼ to ⅕ of the bandwidth of the loop inside it.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Find θ_off at startup by applying the voltage vector V_d along α and reading the encoder.

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant (PMSM in the rotor frame)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque:

$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI with decoupling and back-EMF feedforward

Pole-zero cancellation gives a first-order closed loop with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Control law in discrete form, with back-calculation anti-windup:

$$e_k = i^*_k - i_k$$

$$u_k = K_{p,i}e_k + I_k + v_{ff}$$

$$v_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + T_s\big[K_{i,i}e_k + K_{aw}(v_k - u_k)\big],\qquad K_{aw}\approx \tfrac{K_{i,i}}{K_{p,i}}$$

Feedforward terms:

$$v_{ff,d} = -\hat\omega_e L i_q,\qquad v_{ff,q} = \hat\omega_e(L i_d + \lambda_m)$$

**Voltage limiting.** Limit the vector magnitude to the linear SVPWM region, with d priority:

$$|v| \le V_{dc}/\sqrt3$$

$$v_d \leftarrow \mathrm{clamp}(v_d, \pm V_{max})$$

$$v_q \leftarrow \mathrm{clamp}\big(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\big)$$

**Delay compensation.** Advance the inverse-Park angle by 1.5 Ts to cover ADC→PWM latency:

$$\theta_e' = \theta_e + 1.5\,\hat\omega_e T_s$$

### 1.5 Inverse Park and SVPWM (min-max injection)

$$v_\alpha = v_d\cos\theta_e' - v_q\sin\theta_e',\qquad v_\beta = v_d\sin\theta_e' + v_q\cos\theta_e'$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$
