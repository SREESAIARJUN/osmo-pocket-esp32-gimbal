## Systems Architecture, Loss Model, Thermal Analysis, DShot DMA Plan, and Netlists

## 0. Architecture Decision

The STM32H743 should not commutate the motors. ArduPilot has no in-tree sensorless BLDC commutation, and closing 4× commutation loops at 48 kHz PWM on the flight MCU would compete with the EKF and IMU loops. The architecture is therefore:

```
                ┌──────────────────────── FC BOARD (30.5×30.5, M3) ─────────────────────────┐
  IMU(SPI1) ──► │ STM32H743VIT6 @400MHz (ArduPilot ChibiOS)                                  │
  BARO (I2C2)   │  TIM1 CH1..CH4 ──► bidir DShot600 (single wire per motor, open-drain style)│
  OSD  (SPI2)   │  ADC: VBAT, CURR (from ESC)   UARTs: GPS, RC, ESC-telem(optional)          │
                └───────────────┬────────────────────────────────────────────────────────────┘
                        8-pin JST-SH: VBAT, GND, CURR, TLM, M1..M4
                ┌───────────────┴──────────── ESC BOARD (4-in-1) ───────────────────────────┐
                │ 4× AT32F421K8U7 (AM32 firmware) → 4× FD6288Q 3-phase gate driver          │
                │ 24× N-MOSFET 40V (PDFN 5×6 / 3.3×3.3 by current class)                    │
                │ shared shunt + INA-class amplifier → CURR                                  │
                └────────────────────────────────────────────────────────────────────────────┘
```

**Note on the "nano" form factor and 80A.** A 20×20 board cannot thermally sustain 4×80 A, and section 2 shows why. This design assumes a 30.5×30.5 board for the 80A burst class. The 20×20 variant should be derated to roughly 35–45 A burst.

## 1. Loss Model (per ESC channel)

### 1.1 Assumptions

| Symbol | Meaning | Value |
|---|---|---|

| I_ph | Burst phase current | 80 A |

| R_ds,on(25 °C) | 40 V MOSFET, V_GS = 10 V | 1.0 mΩ |
| α | R_ds temperature coefficient | 0.0045 /K |

| C_oss,eff | Effective output capacitance | 1.5 nF |
| Q_rr | Body-diode reverse recovery charge | 50 nC |
| V_SD | Body-diode forward drop | 0.8 V |
| t_dt | Dead time per edge | 100 ns |
| Q_g | Total gate charge | 60 nC |
| V_drv | Gate drive voltage | 10 V |

### 1.2 Conduction losses

The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At every instant, the phase current flows through exactly two MOSFETs:

- the PWM leg's high-side switch (for duration D) or its low-side switch (for 1−D), and
- the return leg's low-side switch.

The total conduction loss is therefore independent of duty cycle:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j), \qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

| T_j | R_ds | P_cond @ 80 A |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 100 °C | 1.34 mΩ | 17.1 W |
| 125 °C | 1.45 mΩ | 18.6 W |
| 150 °C | 1.56 mΩ | 20.0 W |

**Copper path loss.** Add trace and plane resistance. Typically 0.3–0.5 mΩ per current loop on 2 oz × 6-layer copper:

$$P_{Cu} \approx 80^2 \times 0.4\,\text{m}\Omega \approx 2.6\ \text{W}$$

**Per-device distribution.** Each phase spends 1/3 of the electrical period as the PWM-high leg and 1/3 as the return-low leg. Averaged over a revolution, the hottest device is a low-side FET:

$$P_{LS} \approx \tfrac13\,I^2R(1-D) + \tfrac13\,I^2R$$

At D = 0.5 and 125 °C, this gives about **4.6 W** per low-side FET.

### 1.3 Switching losses at 48 kHz

Hard switching occurs only in the PWM leg, at 2 edges per period.

**V-I overlap loss:**
$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5\times25.2\times80\times40\text{ns}\times48\text{k} = \mathbf{1.94\ W}$$

**Output capacitance loss** (HS + LS nodes):
$$P_{oss} = C_{oss}V^2 f_{sw} = 1.5\text{n}\times635\times48\text{k} = 0.046\ \text{W}$$

**Reverse recovery loss:**
$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{n}\times25.2\times48\text{k} = 0.060\ \text{W}$$

**Dead-time diode conduction loss:**
$$P_{dt} = V_{SD}\,I_{ph}\,(2t_{dt})\,f_{sw} = 0.8\times80\times200\text{n}\times48\text{k} = 0.61\ \text{W}$$

**Gate drive loss** (6 FETs, dissipated mostly in the driver and gate resistors):
$$P_g = 6\,Q_gV_{drv}f_{sw} = 6\times60\text{n}\times10\times48\text{k} = 0.17\ \text{W}$$

**Total switching loss:**
$$P_{sw,total} \approx \mathbf{2.83\ W/channel}$$
