# Job #63: STM32H743 Nano AIO (FC + 4-in-1 ESC), Architecture, Loss Model, DShot Allocation

**Status: Engineering reference design, Rev A (pre-layout)**

---

## 0. Architecture Review: Three Issues to Resolve First

**1. The STM32H743 should not commutate the motors.**
Running ArduPilot on the H743 while it also drives 12 FETs (6-step or FOC) for four motors is not a supported configuration. ArduPilot has no ESC firmware path, and the timer and ADC budget does not close.

The industry-standard AIO partition, which this design adopts, is:
- **H743**: flight control. It outputs bi-directional DShot600.
- **4 × ESC MCUs** (AT32F421 or STM32G071) running **AM32**. Each one commutates a single motor at 48 kHz and returns eRPM over the same DShot wire.

**2. 80 A per channel is incompatible with a nano board as a sustained rating.**
Section 3 shows each channel dissipates about 21 W at 80 A, or about 86 W across the board. A 25.5 × 25.5 mm board heats at roughly 20 K/s under that load.

**Recommendation:** label the product **"45 A continuous / 80 A burst (≤1 s)"**. Firmware current limiting (AM32 current limit plus ArduPilot `BATT_CURR_MAX`-style protection) must enforce this.

**3. The MOSFET is not specified.**
All numbers below use a representative 40 V, 3.3 × 3.3 mm (PDFN3333) part. Substitute your selected device's datasheet values into the equations; the structure of the model does not change.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS0}\,[1 + \alpha (T_j - 25)]$$

A linear fit is adequate for this purpose. The datasheet normalized curve is typically 1.5–1.7× at 125 °C.

### 2.2 Current path under 6-step synchronous PWM

At any instant, exactly two legs carry the phase current I:
- **The PWM leg.** It conducts through the HS FET for duty D and through the LS FET for (1 − D). It conducts through the body diode only during dead time.
- **The static leg.** Its LS FET is held on for the whole 60° sector.

The instantaneous conducting resistance is therefore always 2·R_DS, independent of D. This simplification is what makes synchronous rectification attractive.

$$P_{cond,ch} = 2\,R_{DS}(T_j)\,I_{rms}^2$$

### 2.3 Ripple correction

The phase inductor current carries triangular ripple ΔI:

$$I_{rms}^2 = I_{dc}^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{2 L_{ph}\, f_{sw}}$$

The factor of 2 appears because the phase pair is in series. Take a typical 5-inch-class motor with L_ph = 15 µH, at worst-case D = 0.5:

$$\Delta I = \frac{25.2 \times 0.25}{2 \times 15\mu \times 48k} = 4.4\ \text{A} \;\Rightarrow\; \Delta I^2/12 = 1.6\ \text{A}^2$$

This is negligible compared with 6400 A². The ripple term is retained in the model for low-inductance or high-KV motors.

### 2.4 Self-consistent junction temperature

Conduction loss depends on T_j, which depends on loss. Solve by fixed-point iteration:

$$T_j^{(k+1)} = T_{ref} + P_{FET}(T_j^{(k)})\cdot Z_{\theta}(t)$$

Iteration converges if $\partial P/\partial T_j \cdot Z_\theta < 1$, that is, if $2 I^2 R_{DS0}\alpha\, Z_\theta/6 < 1$. At 80 A with Z_θ = 40 K/W this criterion gives 0.43, so it converges. With poor heatsinking it fails, which corresponds to genuine **thermal runaway**. Treat this as a design check.

### 2.5 Numerical result at 80 A, T_j = 110 °C

$$R_{DS} = 1.0 \times (1 + 0.005 \times 85) = 1.425\ \text{mΩ}$$
$$P_{cond,ch} = 2 \times 1.425\text{m} \times 6401.6 = \mathbf{18.25\ W}$$

**Per-FET average:** each FET carries its share of the 2·I²R product during 1/3 of the electrical cycle:

$$\bar P_{cond,FET} = \frac{P_{cond,ch}}{6} = 3.04\ \text{W}$$

**Interconnect losses (same I² law):**

| Element | Resistance | Loss @ 80 A |
|---|---|---|
| Shunt (0.25 mΩ, in DC return) | 0.25 mΩ | 1.60 W |
| PCB copper, 2 oz × 4 layers, phase + bus path est. | 0.20 mΩ (×2 phases in path) | 2.56 W |
| Motor-wire solder pads/vias | ~0.05 mΩ | 0.32 W |

The copper term is not optional. In a nano board it is usually the second-largest heat source, and it heats the same board that cools the FETs.

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches. Each switching period produces one turn-on and one turn-off of the hard-switched device, plus one diode recovery event.

### 3.1 Gate-drive timing

$$R_{G} = R_{drv} + R_{g,ext} + R_{g,int} = 2 + 3.3 + 1 = 6.3\ \Omega$$
