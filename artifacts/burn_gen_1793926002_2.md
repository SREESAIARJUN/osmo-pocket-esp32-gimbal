## 0. System Architecture and Operating Point

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal, 19.8 V sag at burst |
| Design bus voltage for loss calculations | V_bus = 25.2 V (worst case for switching loss) |
| Per-channel current | 80 A burst (≤ 5 s), 45 A continuous target |
| PWM frequency | f_sw = 48 kHz, complementary (synchronous) PWM |
| Commutation | 6-step trapezoidal (AM32 / BLHeli_32-class firmware) |
| Flight controller | STM32H743 at 400 MHz (TIM clocks: APB1 and APB2 timer clock = 200 MHz) |
| ESC MCUs | 4 × AT32F421 (one per channel; the H743 does **not** commutate motors) |
| FC → ESC protocol | Bidirectional DShot600 (ArduPilot) |

**Partitioning note.** The STM32H743 only generates DShot frames and decodes eRPM telemetry. Commutation and the 48 kHz PWM run on each ESC MCU. A single H743 cannot run 4 × 6-step commutation alongside the flight stack with adequate determinism.

## 1. Power Device Model [ASSUMED parameters]

Each channel uses 6 × 40 V N-channel MOSFETs, PDFN 5×6, logic level, driven at V_GS = 10 V.

| Symbol | Value | Meaning |
|---|---|---|
| R_DS(on),25 | 1.30 mΩ (max at 10 V) | On-resistance |
| α | 0.0055 K⁻¹ | R_DS temperature coefficient |
| Q_g | 55 nC | Total gate charge |
| Q_gs2 + Q_gd | 4 + 12 nC | Switching charge (plateau region) |
| V_plateau | 4.2 V | Miller plateau |
| Q_rr | 45 nC (at 80 A, di/dt ≈ 500 A/µs) | Body-diode reverse recovery |
| C_oss(er) | 1.1 nF at 25 V | Output capacitance |
| V_SD | 0.80 V | Body-diode forward voltage at 80 A, hot |
| R_θJC | 1.2 K/W | Junction to case (bottom) |
| R_g(int) | 1.0 Ω | Internal gate resistance |

**Temperature-dependent resistance:**

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 110 °C: R_DS = 1.30 × 1.4675 = **1.91 mΩ**.
