# FOC Motor Control and Dual‑IMU Fusion for a 3‑Axis Gimbal

## 0. Assumptions

I don't have the Job #44 specification, so this design uses common gimbal hardware. Everything is parameterised, so substitute your actual values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (GBM2804‑class). Pole pairs `p = 7`, `R ≈ 10 Ω`, `L ≈ 2.5 mH`, `Kt ≈ 0.08 N·m/A` |
| Encoder | 14‑bit absolute magnetic encoder (AS5048A / MT6701), read over SPI every current cycle |
| MCU | STM32G4 at 170 MHz with FPU, center‑aligned PWM at 20 kHz, ADC injected conversion at the PWM center |
| IMUs | 2× ICM‑42688‑P on separate SPI buses, mounted on the camera plate. ODR 8 kHz, ±2000 dps, ±16 g |
| Loop rates | Current 20 kHz → velocity 5 kHz → angle/attitude 1 kHz. IMU filtering runs at 8 kHz, attitude at 1 kHz |

The control structure is:

```
θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI]─► iq_fb ─(+)─► iq_ref ─►[Current PI d/q]─►[SVPWM]─► Motor
          ▲ attitude                  ▲ ω̂ (PLL)              ▲ iq_cog (anti-cogging FF)
          │ (dual-IMU Mahony)         │ encoder              │ LMS learns from iq_fb
```

## 1. Field‑Oriented Current Loop (20 kHz)

### 1.1 Transforms

Amplitude‑invariant Clarke transform, assuming `i_a + i_b + i_c = 0`:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle `θ_e = p·θ_m − θ_offset`:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant and PI design

The machine model in the rotating frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

1. **Decoupling.** Add a feedforward term so each axis behaves as a first‑order `1/(Ls+R)` plant:
   $$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$
   where `λ_m = Kt/(1.5·p)`.

2. **Pole‑zero cancellation.** Place the PI zero on the electrical pole:
   $$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$
   The closed loop is then `ω_ci/(s+ω_ci)`.

3. **Bandwidth limit.** Choose `ω_ci ≤ 2π·f_pwm/10`. With the assumed values, `ω_ci = 2π·1500 rad/s`.

### 1.3 Discrete PI with back‑calculation anti‑windup

Using forward Euler with `T_s = 1/f`:

$$u_k = K_p e_k + I_k + u^{ff}_k,\qquad u^{sat}_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}T_s\,(u^{sat}_k - u_k),\qquad K_{aw}\approx K_i/K_p$$

**Voltage vector limit.** Saturate the `(v_d, v_q)` vector to the linear SVPWM circle, `|v| ≤ V_bus/√3`. Give `v_d` priority:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

### 1.4 SVPWM by min‑max zero‑sequence injection

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max v_x + \min v_x),\quad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector‑based SVPWM and gives 15.5% more linear range than sinusoidal PWM.
