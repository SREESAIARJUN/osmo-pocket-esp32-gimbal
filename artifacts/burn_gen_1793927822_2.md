# STM32H743 Nano FC + 4-in-1 ESC (Job #6): Power-Stage, Thermal, and DShot Architecture

## 0. Design Review Findings

Five constraints shape everything below:

| # | Issue | Consequence |
|---|---|---|
| 1 | **The H743 does not run the ESC.** In a 4-in-1 stack, the H743 is the flight controller. Each motor channel has its own ESC MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU generates the 48 kHz PWM. | Switching-loss math applies to the ESC MOSFETs. The DShot/DMA math applies to the H743. |
| 2 | **80 A × 4 on a nano (20×20 mm) board is not thermally sustainable.** | 80 A is treated strictly as a **burst rating**, with time limits computed in §3. |
| 3 | **Battery current.** At full throttle, I_batt ≈ D·ΣI_phase, up to about 320 A. An XT60 is ~60 A continuous, and a 20×20 board's copper cannot carry this continuously. | Requires an XT90/AS150 class connector, 14 AWG or heavier leads, and a burst current limit set in firmware. |
| 4 | **Complementary timer outputs (TIMx_CHxN) cannot do input capture.** | Bidirectional DShot pins **must** be on non-N channels. |
| 5 | **No MOSFET part number was specified.** | I use a parameterised generic 40 V, ~1 mΩ-class FET. Substitute datasheet values; all equations are explicit for that purpose. |

## 2. Loss Model (per motor channel)

### 2.1 Conduction Loss

With complementary PWM in 6-step commutation, two phase legs carry current at any instant. In each active leg, either the high-side or low-side FET conducts the full current (ignoring dead time). The current path therefore always crosses **two FET channel resistances**, independent of duty cycle:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C:

$$P_{cond} = 2(80)^2(1.5\text{ m}\Omega) = \mathbf{19.2\ W}$$

At 25 °C it would be 12.8 W. The Rds tempco therefore creates positive electrothermal feedback. Solve iteratively with the thermal model in §3.

**PCB copper loss.** Model each phase path as an equivalent trace resistance R_cu, typically 0.3–0.6 mΩ on a 20×20 board with 2 oz copper and stacked vias:

$$P_{cu} = 2\,I_{ph}^2\,R_{cu} \approx 2(6400)(0.4\text{ m}\Omega) = \mathbf{5.1\ W}$$

This term is frequently ignored and is significant at this size.

### 2.2 Hard-Switching Loss (V–I overlap)

One hard-switched transition pair per PWM period on the active leg:

$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(20\text{ ns})(48\text{ kHz}) = \mathbf{0.97\ W}$$

### 2.3 Capacitive (Coss) Loss

$$P_{oss} \approx Q_{oss} V_{bus} f_{sw} = (50\text{ nC})(25.2)(48\text{ k}) = \mathbf{0.06\ W}$$

### 2.4 Reverse-Recovery Loss

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = (60\text{ nC})(25.2)(48\text{ k}) = \mathbf{0.07\ W}$$

### 2.5 Dead-Time Body-Diode Conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = 2\,V_f\,I_{ph}\,t_{dt}\,f_{sw} = 2(0.8)(80)(200\text{ ns})(48\text{ k}) = \mathbf{1.23\ W}$$

> Dead time is the **largest switching-related term**. Reducing t_dt from 200 ns to 100 ns saves about 0.6 W per channel. This is a firmware setting (AM32/BLHeli dead-time register), constrained by the driver's propagation skew.

### 2.6 Gate-Drive Loss

The loss is dissipated in the driver and gate resistors, not in the FET die. Two FETs switch per PWM period:

$$P_g = 2\,Q_g V_{drv} f_{sw} = 2(50\text{ nC})(10)(48\text{ k}) = \mathbf{0.05\ W}$$

### 2.7 Summary @ 80 A Burst, T_j = 125 °C

| Loss | Per channel | 4 channels |
|---|---|---|
| Conduction (FET) | 19.20 W | 76.8 W |
| Copper (PCB) | 5.12 W | 20.5 W |
| Switching overlap | 0.97 W | 3.9 W |
| Dead-time diode | 1.23 W | 4.9 W |
| Q_rr + Q_oss | 0.13 W | 0.5 W |
| Gate drive | 0.05 W | 0.2 W |
| **Total** | **≈ 26.7 W** | **≈ 106.8 W** |

**Key insight:** At 80 A, conduction loss is about **92 %** of dissipation. Switching at 48 kHz is minor. Reducing f_sw to 24 kHz saves only about 1.1 W per channel and worsens current ripple and acoustic noise. The lever is **R_DS(on) and copper**, not frequency.

**Crossover current.** Conduction loss equals frequency-dependent loss when:

$$2I^2R_{ds} = \tfrac12 V I (t_r+t_f)f + 2V_f I t_{dt} f \;\Rightarrow\; I_x = \frac{f\left[\tfrac12 V(t_r+t_f) + 2V_f t_{dt}\right]}{2R_{ds}} \approx 7.3\text{ A}$$

Above roughly 7 A, conduction dominates.
