## 0. Architecture Clarification and Assumptions

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32, for example an AT32F421. The H743 sends DShot600 to each ESC MCU and receives eRPM telemetry back on the same wire (bi-directional DShot).

```
STM32H743 (ArduPilot) --DShot600 bidir x4--> 4x ESC MCU --> 4x 3-phase gate driver --> 4x (6 MOSFET) bridges --> motors
```

**Device parameters.** You did not specify the MOSFET, gate driver, or battery. All numbers below use the representative parameter set in this table. Swap in your datasheet values and the equations remain valid.

| Symbol | Meaning | Value used |
|---|---|---|
| V_bus | Bus voltage (6S, worst case full charge) | 25.2 V |
| I_ph | Burst phase current per motor | 80 A |
| D | PWM duty at burst | 0.90 |
| f_sw | Switching frequency | 48 kHz |
| R_ds,on(25 °C) | MOSFET on-resistance, 40 V device in 3.3×3.3 DFN, V_gs = 10 V | 1.5 mΩ |
| k_T | R_ds,on temperature coefficient at T_j ≈ 100 °C | 1.5 |
| Q_g / Q_gs2 / Q_gd | Gate charges | 30 / 3 / 6 nC |
| Q_oss / Q_rr | Output and reverse-recovery charge | 25 / 30 nC |
| V_pl | Miller plateau at 80 A | 2.8 V |
| R_g,int | Internal gate resistance | 1 Ω |
| V_drv | Gate drive voltage | 10 V |
| R_src / R_snk | Driver source/sink resistance | 4 Ω / 1.5 Ω |
| V_f | Body-diode forward voltage at 80 A | 0.9 V |
| t_dt | Dead time per edge | 50 ns |
| R_θJC | Junction-to-case (bottom pad) | 1.5 K/W |

> ⚠️ **Feasibility flag.** 80 A per channel on a 20×20 mm "nano" board is a transient rating only. The math below proves that steady-state operation at this current is physically impossible at this form factor. The deliverable is therefore a burst-duration limit, not a continuous rating.
