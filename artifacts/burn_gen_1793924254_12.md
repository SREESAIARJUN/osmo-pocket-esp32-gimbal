# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bi-Directional DShot600 Architecture

## 0. Scope, Architecture, and Assumptions

I have no record of earlier "Job #28" documents, so I state every assumption below. All equations are parametric: substitute your actual BOM values and the numbers update.

**Architecture correction.** The STM32H743 does not commutate the motors. A 4-in-1 ESC runs four dedicated ESC MCUs (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071). Those MCUs generate the 48 kHz complementary PWM. The H743 runs ArduPilot and sends bi-directional DShot600 to them. The analysis is split the same way.

```
 6S LiPo ──► Bus caps ──► 4× [ESC MCU → 3-ph gate driver → 6× N-FET half-bridges] ──► Motors
                                   ▲ BDShot600 (1-wire, bidir)
 STM32H743 (ArduPilot) ────────────┘  TIM1 CH1-4
```
