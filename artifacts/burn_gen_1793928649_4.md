# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #22 spec sheet, so this design states its assumptions explicitly in §0. Every tunable constant is derived from those assumptions and kept in one config block, so you can substitute your real motor and frame values directly.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.5 Ω, L = 2.2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz |
| Bus | V_bus = 12 V, PWM 20 kHz center-aligned, inline or low-side shunts |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle / attitude | 1 kHz | ~25 Hz |
| IMU sampling | 8 kHz | (filtered, then decimated ÷2 to the 4 kHz velocity loop) |

**Bandwidth separation rule:** each outer loop should be ≥ 5–10× slower than the loop inside it:

$$\omega_{c,i} \ge 5\,\omega_{c,v} \ge 25\,\omega_{c,\theta}$$
