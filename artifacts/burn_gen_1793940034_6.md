# FOC Motor Control and Dual-IMU Sensor Fusion for the 3-Axis Gimbal (Job #24)

## 0. Assumptions

I don't have Job #24's specification sheet, so these are the baseline assumptions. Everything below is parameterized; change the constants in `GimbalConfig`.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC). Portable C++17. |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sensing | 2-phase inline shunts |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, data-ready interrupt |

Loop rates:

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| Velocity | 4 kHz | 250 µs |
| Attitude/angle | 1 kHz | 1 ms |
| IMU sampling, then decimation | 8 kHz → 4 kHz | — |

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$
