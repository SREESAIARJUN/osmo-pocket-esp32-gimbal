# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #2," so this design uses the assumptions below. Every parameter is a named constant, so you can substitute your real hardware values without changing the structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), one FOC stage per axis |
| Motors | Gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, gyro and accel at ODR = 8 kHz |
| PWM / current loop | 40 kHz PWM, current loop at 20 kHz |
| Velocity (rate) loop | 4 kHz, on fused gyro data |
| Attitude loop | 1 kHz, on Mahony quaternion |
| Bus voltage | 12–16 V |
