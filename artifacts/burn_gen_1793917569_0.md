# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the spec for Job #47, so this design rests on the assumptions in Section 0. Every parameter is a named constant, so you can substitute real values without changing the structure.

## 0. Assumed System Parameters

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, ≥170 MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor encoder | 14-bit magnetic (AS5048A / MT6701), SPI |
| Current sensing | 2-shunt inline or low-side. A voltage-mode fallback is provided. |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro ODR 8 kHz |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Angle 1 kHz → Attitude 1 kHz |
| Vibration source | Propeller / airframe, roughly 80–400 Hz, plus motor-induced harmonics |

Bandwidth separation rule: each outer loop should have at least 4–10× lower bandwidth than the loop inside it.

## 1. Field-Oriented Control (Inner Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

Here θ_off is found at commissioning by applying v_d = V_align at θ_e = 0 and reading θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the d-q frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q, \qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Torque (SPM motor, L_d ≈ L_q):

$$\tau = K_t i_q, \qquad K_t = \tfrac32 p\lambda_m$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation with target bandwidth ω_c, typically 2π·1.5 kHz at f_s = 20 kHz:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop then reduces to a first-order system, i_q / i_q* = ω_c / (s + ω_c).

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set i_d* = 0 (no field weakening is needed for a gimbal).

Voltage limiting uses a circular limit to preserve vector direction, with d-axis priority:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad m_{max}\approx0.95$$

### 1.6 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k,\qquad \hat u_k = \text{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\hat u_k - u_k), \qquad K_{aw}\approx \frac{K_i}{K_p}T_s$$

### 1.7 Inverse Park and SVPWM (min-max injection, equivalent to SVPWM)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.8 Delay compensation

Total delay is roughly 1.5·T_s (one sample for computation plus half a PWM period for the ZOH). Advance the angle used for the inverse Park transform:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_s$$

At 20 kHz this matters little at gimbal speeds, but it costs nothing.

### 1.9 Voltage-mode fallback (no current sensing)

$$v_q^* = R\,\frac{\tau^*}{K_t} + \omega_e\lambda_m, \qquad v_d^* = -\omega_e L\,\frac{\tau^*}{K_t}$$

## 2. Cascaded Position/Velocity Control

For a gimbal, the controlled variable is the **camera attitude in the inertial frame**, not the motor angle. Use:

- **Angle feedback:** the IMU-fused attitude, projected onto this joint axis (Section 4.6).
- **Velocity feedback:** the filtered gyro rate about the joint axis. This is far better than a differentiated encoder signal, which only gives the *relative* rate.
- **Encoder:** used only for commutation, and as a low-weight velocity aid during IMU faults.

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity loop (4 kHz): PI plus feedforward

Choose target bandwidth ω_v ≈ ω_c/10, for example 2π·150 Hz. This must stay below the first structural mode of the camera/arm assembly.

$$K_{p,v} = \frac{J\,\omega_v}{K_t}, \qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The PI zero is placed at ω_v/4 to keep about 60° of phase margin.

$$i_q^* = \text{PI}_v(\omega^* - \omega_f) + \underbrace{\frac{J\dot\omega^*}{K_t}}_{\text{inertia FF}} + \underbrace{\frac{B\omega^*}{K_t}}_{\text{friction FF}} + \underbrace{i_{cog}(\theta_m)}_{\text{anti-cogging FF}}$$

Here ω_f is the gyro rate after the vibration filters in Section 4.
