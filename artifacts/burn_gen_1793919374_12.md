## 1. Control Architecture

```
            ┌──────────── 1 kHz ─────────────┐ ┌──── 4 kHz ─────┐ ┌──────── 20 kHz ───────┐
q_ref ──►(Attitude P, SO(3))──ω_cam*──►J⁻¹(q)──►ω_joint*──►(Vel PI)──►i_q*──(+)──►(Current PI ×2 + decoupling)──►SVPWM──►Motor
              ▲ q_est                                 ▲ ω_joint     ▲ cogging FF(θ_m)           ▲ i_d,i_q (Park)
       [Dual IMU → notch/LPF → fusion → Mahony]   [gyro mapped + encoder]                  [phase currents, θ_e]
```

The velocity loop uses gyro-derived joint rate blended with encoder rate. The gyro is low-noise and sees the camera's real motion. The encoder supplies commutation angle and a high-frequency rate estimate free of structural vibration.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms
Electrical angle: θₑ = p·(θₘ − θ_offset), with p = 7.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 2.2 Motor model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t i_q \quad (\text{SPM: } L_d=L_q=L)$$

### 2.3 Current PI with decoupling and pole-zero cancellation
The decoupled plant is $G(s) = \frac{1}{Ls+R}$. The PI controller is $C(s)=K_p + K_i/s$. Choosing $K_i/K_p = R/L$ cancels the electrical pole, giving a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10}\ \ (\approx 2\pi\cdot 1.5\text{ kHz at } f_s=20\text{ kHz})$$

Discrete form (backward Euler) with back-calculation anti-windup:

$$u_k = K_p e_k + I_k,\quad \bar u_k = \text{sat}(u_k),\quad I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big],\quad K_{aw}\approx \frac{K_i}{K_p}$$

Decoupling feedforward:

$$v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e(L i_d + \lambda_m)$$

**Voltage limit (circular, q-axis priority):**

$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.96$$

### 2.4 SVPWM (min-max zero-sequence injection)
The min-max method is mathematically equivalent to 7-segment SVPWM:

$$v_{a,b,c}=\text{InvClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
