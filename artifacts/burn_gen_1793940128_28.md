# STM32H743 FC + 4-in-1 ESC "Nano" Stack (Job #8): Design Model

**Scope:** Power-stage loss model at 80 A burst and 48 kHz PWM, transient thermal model, ArduPilot bidirectional DShot600 timer/DMA plan, and reference netlists.

## 0. Architecture Clarifications and Assumptions

### 0.1 Partitioning

The STM32H743 belongs on the **flight controller**. It runs ArduPilot and generates the DShot600 frames.

The 4-in-1 ESC uses one small MCU per channel, such as an AT32F421 or STM32G071 running AM32 or BLHeli_32. Putting an H743 on the ESC would be expensive and power-hungry, and AM32 does not support it. The model below follows that partitioning.

### 0.3 Headline Result

In this form factor, **80 A is a burst rating of about 3 seconds, not a continuous one.** The physics supports roughly **18 to 25 A continuous per channel**. The derivation is in Section 3.

## 1. Conduction Loss Model

### 1.1 Current Path

In 6-step commutation with complementary PWM, during each 60° sector:
- **Leg X (PWM leg):** the high-side (HS) conducts for fraction D and the low-side (LS) synchronously rectifies for 1 − D. One FET in this leg always carries I_ph.
- **Leg Y (return leg):** the LS is held on continuously and carries I_ph.
- **Leg Z:** floating, used for back-EMF zero-cross sensing.

So at every instant, exactly two FETs carry the full phase current, independent of D:

$$P_{cond,ch} = 2\, I_{ph}^2\, R_{DS}(T_j), \qquad R_{DS}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

### 1.2 Numerical Result at 80 A, T_j = 125 °C

R_DS = 1.0 mΩ × 1.40 = 1.40 mΩ

$$P_{cond,ch} = 2 \times 80^2 \times 1.40\times10^{-3} = \mathbf{17.92\ W}$$

Each FET conducts for 120° electrical per cycle (two of the six sectors), so averaged over one revolution:

P_FET,cond ≈ 17.92 / 6 = 2.99 W per FET

### 1.3 Thermal Runaway Check

Solve P(T_j) self-consistently with T_j = T_ref + R_θ · P(T_j). The solution is stable when:

$$\frac{\partial P}{\partial T_j}\, R_\theta < 1 \;\Rightarrow\; 2 I^2 R_{25}\,\alpha\, R_\theta < 1$$

At 80 A: 2 × 6400 × 1e-3 × 0.004 × R_θ < 1, which requires **R_θ < 19.5 K/W** (per-channel effective). This is satisfied (see Section 3), but it shows how quickly margin disappears at burst current.

### 1.4 Copper and Shunt Adders

- **Shunt:** 0.25 mΩ, carrying battery current I_bat = D·I_ph. Worst case D = 1 gives 1.6 W, shared across the board.
- **Phase/bus copper:** about 0.3 mΩ per channel path gives about 1.9 W at 80 A.

These are included in the board-level budget in Section 3.
