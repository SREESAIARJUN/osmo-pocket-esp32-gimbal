# Gimbal Control Design: FOC, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

**Scope note:** I don't have the Job #57 specification sheet. I've used the assumptions in §0. Every hardware-dependent constant is in one config block, so you can substitute the real values without touching the algorithms.

**Verification status:**
- The control equations are standard and derived below.
- The C++ is written to compile and run deterministically (C++17, no heap). It has not been run against your hardware.
- The ICM-42688-P register addresses and AAF coefficients are from my recollection of the datasheet. Check them against your datasheet revision before flashing.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4/H7, FPU, center-aligned PWM at 20 kHz, ADC synced to PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetric about the tilt axis, shared CLKIN |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates:**

```
20 kHz  ISR_PWM : ADC → Clarke/Park → PI_d, PI_q → invPark → SVPWM   (per motor)
 8 kHz  ISR_IMU : 2× gyro/accel read (DMA) → AAF(on-chip) → notch → fuse → LPF
 4 kHz  Velocity loop (inertial rate, gyro) + cogging FF → iq_ref
 1 kHz  Attitude estimator (Mahony) + angle loop → ω_ref
```

**Bandwidth separation rule:**
- ω_c,cur ≥ 5·ω_c,vel ≥ 25·ω_c,ang
- Typical targets: 1.5 kHz / 150 Hz / 25 Hz.
