# STM32H743 Nano FC with Integrated 4-in-1 ESC (Job #53): Power, Thermal and DShot Architecture

## 0. Architectural Clarifications

Three points need settling before the math, because they change what is being modeled.

1. **The H743 does not commutate the motors.** In a 4-in-1 design, each ESC channel (or the shared ESC die) runs its own MCU with BLHeli_32-class or AM32 firmware. This model uses an AT32F421 or STM32G071 running AM32. Consequences:
   - 48 kHz switching is an ESC-firmware parameter (`PWM_FREQUENCY` in AM32), not an ArduPilot one.
   - The H743 only generates bidirectional DShot600 frames and decodes the eRPM replies.
2. **"80 A burst" is per motor.** A full burst is therefore 4 × 80 = 320 A from a 6S pack. The math in §3 shows this does not fit a 20×20 mm nano footprint beyond roughly one second.
3. **Assumed operating point.** Where values are not specified, these are used and labelled:

| Parameter | Value |
|---|---|
| V_bus | 25.2 V (6S, full charge) |
| MOSFET class | 40 V N-ch, 3.3×3.3 DFN |
| R_DS(on) at 25 °C | 1.6 mΩ @ V_GS = 10 V |
| Q_g | 50 nC |
| Q_rr | 40 nC |
| Q_oss | 30 nC |
| R_θJC | 1.5 K/W |
| Gate driver | FD6288Q-class 3-phase, 10 V gate drive |
| Gate transitions | t_r = t_f = 15 ns |
| Dead time | t_dt = 200 ns |
| Body diode V_F | 0.8 V |
| Commutation / PWM | 6-step trapezoidal, complementary (synchronous) PWM |

## 1. Conduction Loss Model (80 A burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)],\qquad \alpha \approx 0.0067\ \text{K}^{-1}$$

This α gives the typical ≈1.57× factor at 110 °C. At T_j = 110 °C:

$$R_{DS}(110) = 1.6\times1.57 = 2.51\ \text{m}\Omega$$

### 1.2 Current paths in one commutation step

In each 6-step state, phase A switches with duty D, phase B is held low-side ON, and phase C floats (BEMF sensing).

| Device | Conduction fraction | Loss |
|---|---|---|
| Q_AH (high side, PWM) | D | D·I²·R_DS |
| Q_AL (synchronous rectifier) | (1−D) − dead-time share | (1−D)·I²·R_DS |
| Q_BL (low side, held on) | 1 | I²·R_DS |

$$P_{cond,ESC} = I^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2I^2R_{DS}(T_j)$$

The result is **independent of duty cycle** under synchronous rectification. At I = 80 A, T_j = 110 °C:

$$P_{cond} = 2(80)^2(2.51\times10^{-3}) = \mathbf{32.1\ W\ per\ ESC}$$

### 1.3 Copper path loss

Assume about 0.4 mΩ of effective trace and via resistance per phase path (2 oz outer and 2 oz inner layers, 20×20 board).

$$P_{Cu} = I^2 R_{Cu,path}\cdot 2 \approx 80^2 \times 0.4\text{m}\Omega \times 2 = \mathbf{5.1\ W\ per\ ESC}$$

On a nano board this term is easy to overlook and is not negligible.

### 1.4 Current-sense shunt (if fitted, 0.25 mΩ shared on the battery rail)

$$P_{shunt} = (4\times80)^2 \times 0.25\text{m}\Omega = \mathbf{25.6\ W}$$

This is a major contributor. Options:
- Use a 0.1 mΩ shunt (10.2 W).
- Use Hall-effect sensing.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM-ing half-bridge (phase A) switches. Phase B is static during the sector.

**2.1 Hard-switching V–I overlap**

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(30\text{ ns})(48\text{ k}) = \mathbf{1.45\ W}$$

**2.2 Body-diode conduction during dead time** (two dead-time intervals per PWM period)

$$P_{dt} = V_F\, I\, (2t_{dt})\, f_{sw} = 0.8(80)(400\text{ ns})(48\text{ k}) = \mathbf{1.23\ W}$$

**2.3 Reverse recovery of Q_AL's body diode**

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 40\text{n}(25.2)(48\text{k}) = 0.048\ \text{W}$$

**2.4 Output capacitance**

$$P_{oss} = Q_{oss}V_{bus}f_{sw} = 30\text{n}(25.2)(48\text{k}) = 0.036\ \text{W}$$

**2.5 Gate drive** (two switching FETs; this loss lands in the driver and gate resistors)

$$P_g = 2Q_gV_{GS}f_{sw} = 2(50\text{n})(10)(48\text{k}) = 0.048\ \text{W}$$

### 2.6 Total per ESC at 80 A burst

| Term | W |
|---|---|
| Conduction (FETs) | 32.1 |
| Copper | 5.1 |
| Overlap switching | 1.45 |
| Dead-time diode | 1.23 |
| Q_rr + Q_oss + gate | 0.13 |
| **Per ESC** | **≈ 40.0** |
| **× 4 ESCs** | **160 W** |
| Battery shunt (0.25 mΩ) | +25.6 |
| **Board total** | **≈ 186 W** |

Switching at 48 kHz accounts for only about 7 % of the loss at burst. Lowering f_sw to 24 kHz saves about 1.3 W per ESC, which is not decisive. **Conduction dominates; R_DS(on) and copper are the levers.**

## 3. Thermal Model

### 3.1 Network topology (lumped Foster/Cauer hybrid)

```
P_FET ──[R_θJC 1.5 K/W]── Case ──[R_θCB ≈ 2 K/W/FET, via array]── Board node (C_board) ──[R_θBA]── Ambient
                                                                         │
                                                                    C_board ≈ 2.5 J/K
```

### 3.2 Per-FET junction rise above the board

Average per-FET dissipation is P_FET ≈ 37.2 W / 6 ≈ 6.2 W. The electrical period at speed (≤ 2 ms) is much shorter than the package time constant (≥ 10 ms), so averaging is valid.

$$\Delta T_{j-b} = 6.2\,(1.5+2.0) = \mathbf{21.7\ K}$$

### 3.3 Board-to-ambient steady state

- Board area: 2 × (20 × 20 mm) = 8×10⁻⁴ m².
- Convection coefficient in prop wash: h ≈ 100 W/m²K.

$$R_{\theta BA} = \frac{1}{hA} = \frac{1}{100\times 8\times10^{-4}} = 12.5\ \text{K/W}$$

The steady-state rise would be 186 × 12.5 ≈ 2300 K. **No steady state exists at 80 A on a 20×20 board.** The 80 A rating is purely a transient (thermal-mass) rating.

### 3.4 Burst duration (adiabatic approximation)

Thermal capacity:

$$C_{board} \approx m_{Cu}c_{Cu} + m_{FR4}c_{FR4} \approx (1.5\text{ g})(0.385) + (1.5\text{ g})(1.1) + \text{FETs} \approx 2.5\ \text{J/K}$$
