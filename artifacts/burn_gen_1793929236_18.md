# STM32H743 Nano FC + 80A 4-in-1 ESC (Job #3): System Architecture & Mathematical Model

## 0. Architecture Clarification

An STM32H743 running ArduPilot cannot also commutate four motors at 48 kHz without dropping ArduPilot. This design assumes the standard split architecture:

| Function | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIT6 (400 MHz under ArduPilot) | ArduPilot ChibiOS |
| ESC ×4 | AT32F421 / STM32G071 (one per motor) | AM32, 48 kHz complementary PWM |
| Link | Bidirectional DShot600, 1 wire per motor | GCR eRPM telemetry |

If you actually intended a single-MCU design, tell me. The DMA plan in §4 would change completely.

**Component values are representative placeholders.** Verify every part number, pinout and datasheet figure against current revisions before layout.

## 2. Loss Model (per ESC channel, 6-step trapezoidal, synchronous rectification)

### 2.1 Conduction loss

In any 60° commutation sector, two phases conduct.

- **PWM leg:** current alternates between HS (duty D) and LS (1 − D, sync rect).
- **Return leg:** LS is on continuously.

At every instant, exactly two channels are in series with the current:

$$P_{cond} = I^2 \, R_{ds,hot}\,[D + (1-D)] + I^2 R_{ds,hot} = 2\,I^2 R_{ds,hot}$$

The result is independent of duty, so it holds from hover to WOT.

$$R_{ds,hot} = 0.9\,\text{m}\Omega \times 1.45 = 1.31\,\text{m}\Omega$$

$$P_{cond} = 2 \times 80^2 \times 1.31\times10^{-3} = \mathbf{16.8\ W}$$

Copper and connector path (pads, planes, solder joints, ~0.4 mΩ effective):

$$P_{Cu} = 80^2 \times 0.4\times10^{-3} = \mathbf{2.6\ W}$$

### 2.2 Switching loss (hard-switched PWM leg only)

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = \mathbf{1.94\ W}$$

### 2.3 Dead-time body-diode conduction (2 edges/period)

$$P_{dt} = V_f \, I \, (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 200\text{ns} \times 48\text{k} = \mathbf{0.61\ W}$$

### 2.4 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{nC} \times 25.2 \times 48\text{k} = \mathbf{0.06\ W}$$

### 2.5 C_oss loss

$$P_{oss} = \tfrac12 C_{oss,er} V_{bus}^2 f_{sw} = 0.5 \times 2\text{nF} \times 635 \times 48\text{k} = \mathbf{0.03\ W}$$

### 2.6 Gate drive (2 FETs switching in the PWM leg)

$$P_g = 2\,Q_g V_{gs} f_{sw} = 2 \times 60\text{nC} \times 10 \times 48\text{k} = \mathbf{0.06\ W}$$

This power is dissipated in the gate driver and gate resistors, not the FETs.

### 2.7 Loss summary @ 80 A, T_j = 125 °C

| Loss | W / channel | ×4 channels |
|---|---|---|
| Conduction | 16.8 | 67.2 |
| Copper | 2.6 | 10.4 |
| Switching | 1.94 | 7.8 |
| Dead time | 0.61 | 2.4 |
| Q_rr + C_oss + gate | 0.15 | 0.6 |
| **Total** | **≈ 22.1 W** | **≈ 88 W** |

**Key insight:** at 80 A, conduction is about 76% of the loss. Raising f_sw from 24 → 48 kHz costs only ~1.3 W/channel. If thermals fail, attack R_ds(on), not frequency.

### 2.8 Hottest single FET

The continuously-on return LS sees the full I²R:

$$P_{FET,max} = I^2 R_{ds,hot} = 8.4\ \text{W}$$

The PWM-leg HS (at D ≈ 1, WOT) adds its share of switching loss:

$$P_{FET,max} \approx 8.4 + 1.94 = \mathbf{10.3\ W}$$
