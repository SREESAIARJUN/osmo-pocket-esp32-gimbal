# 3-Axis Gimbal: FOC Motor Control, Cascaded Loops, Anti-Cogging, and Dual ICM-42688-P Fusion

**Design package for Job #36: equations, tuning laws, and reference C++17 implementation**

---

## 0. Assumptions and Architecture

I don't have the Job #36 hardware spec, so the design is parameterized. Every constant marked `// HW` must be replaced with measured values from your hardware.

| Item | Assumed baseline |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at PWM center |
| Current sensing | 2- or 3-shunt low-side. A voltage-mode fallback is provided because many gimbal motors are run open-current. |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, synchronized via shared CLKI
