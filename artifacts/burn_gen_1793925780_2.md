## 1. FOC Current Loop (Inner, 20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, with iₐ + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Machine Model (dq frame)

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \;\approx\; K_t\, i_q,\qquad K_t = \tfrac32 p \lambda_m$$

For a surface-mount PM motor, L_d ≈ L_q = L. Gimbals run with i_d* = 0.

### 1.3 PI Control with Decoupling

$$v_d^* = K_{p,i}\,e_d + K_{i,i}\!\int e_d\,dt - \omega_e L i_q$$
$$v_q^* = K_{p,i}\,e_q + K_{i,i}\!\int e_q\,dt + \omega_e (L i_d + \lambda_m)$$

Choosing the gains for pole-zero cancellation makes the closed loop a first-order lag with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

$$\frac{i_q}{i_q^*} = \frac{\omega_c}{s + \omega_c}$$

Choose ω_c ≤ 2π·f_pwm/10 (≈ 2π·2 kHz). Account for the 1.5·T_s computation-plus-PWM delay: phase margin ≈ 90° − ω_c·1.5·T_s·(180/π).

### 1.4 Voltage Limiting and Anti-Windup

With SVPWM the linear-region limit is

$$|v_{dq}| \le \frac{V_{dc}}{\sqrt3}$$

- **Priority:** v_d is clamped first, then v_q is limited to √(V_max² − v_d²).
- **Anti-windup:** back-calculation, using the saturated output:

$$\dot I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.5 SVPWM (Min-Max Zero-Sequence Injection)

$$v_{a,b,c} = \text{invClarke}(\text{invPark}(v_d, v_q)),\qquad v_0 = -\tfrac12\left[\max(v_{abc}) + \min(v_{abc})\right]$$

$$\text{duty}_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

**Low-cost option:** high-R gimbal motors can run voltage-mode (no current sensing), using v_q ≈ R·i_q* + ω_e·λ_m. The code supports this via `kVoltageMode`.
