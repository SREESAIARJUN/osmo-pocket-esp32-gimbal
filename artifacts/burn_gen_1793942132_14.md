## 0. Architectural Clarification and Assumptions

**Important correction to the brief.** The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. Four dedicated ESC MCUs handle that, one per channel, for example AT32F421 or STM32G071 running AM32.

ArduPilot has no native 6-step or FOC motor drive for multirotor ESCs. A single H743 cannot run 4× sensorless commutation and ArduPilot at the same time.

The correct topology is:

```
VBAT ──► [Bulk C + TVS] ──► 4× (3-phase bridge, 6 N-FETs)
                                  ▲
H743 (ArduPilot) ──DShot600 BiDir──► 4× ESC MCU ──► 4× 3-phase gate driver
          ▲                                 │
          └────── eRPM telemetry (GCR) ◄────┘
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in 6-step synchronous commutation

In each 60° sector, two phases are active:
- **PWM leg:** the high-side conducts for D. The complementary low-side (synchronous rectification) conducts for (1−D).
- **Return leg:** the low-side is on continuously.

The motor current I therefore always flows through exactly **two** channels in series:

$$
P_{cond,ch} = I^2 R_{hot}\,[D + (1-D)] + I^2 R_{hot} = 2 I^2 R_{hot}
$$

Conduction loss is therefore **independent of duty cycle** with synchronous rectification. This is a key result.

$$
P_{cond,ch} = 2 \times 80^2 \times 1.8\,\text{m}\Omega = 2 \times 11.52 = \mathbf{23.04\ W}
$$

### 1.2 Phase RMS current

Each phase conducts 120° of every 180° half-cycle:

$$
I_{ph,rms} = I\sqrt{\tfrac{2}{3}} = 80 \times 0.8165 = 65.3\ \text{A}
$$

### 1.3 Copper / interconnect loss

Assume R_cu ≈ 0.5 mΩ effective for bus + phase path (pads, vias, solder joints, phase wire pads):

$$
P_{cu,ch} = I^2 R_{cu} = 6400 \times 0.5\text{m} = \mathbf{3.2\ W}
$$

### 1.4 Electro-thermal convergence

R_DS(on) depends on T_J, so the model must be iterated:

$$
R(T_J) = R_{25}\,[1 + \alpha (T_J - 25)],\quad \alpha \approx 0.0059\ /\text{K}
$$

Iterate T_J → R → P → T_J. The worked example uses the converged ~110 °C value (×1.5).

## 2. Switching Losses at 48 kHz

Hard switching occurs only on the PWM leg: one turn-on and one turn-off per period.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·30 ns·48 k | **1.452 W** |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 k | 0.048 W |
| C_oss | C_oss,eff·V²·f_sw = 1.5 nF·635·48 k | 0.046 W |
| Dead-time diode | V_F·I·2·t_dt·f_sw = 0.8·80·100 ns·48 k | 0.307 W |
| Gate drive* | Q_g·V_GS·f_sw·2 = 50 nC·10·48 k·2 | 0.048 W |
| **Total switching** | | **≈ 1.90 W** |

*Gate drive loss is dissipated mostly in the driver and gate resistors, not in the FET.
