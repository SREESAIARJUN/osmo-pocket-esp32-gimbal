# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #22)

I don't have the Job #22 spec, so the design below rests on the assumptions in §0. Every motor- and frame-specific constant is a named parameter that you can replace with your measured values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each axis |
| Current sensing | 2-shunt or inline, sampled at PWM center |
| MCU | STM32G4/H7-class with FPU, single precision |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, ±2000 dps, ±16 g |
| Joint order (base → camera) | Yaw ψ → Roll φ → Pitch θ |

**Loop rates and bandwidths.** Each outer loop's bandwidth should be at least 4–5× below the loop inside it.

| Loop | Rate | Target bandwidth | Signal source |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | ω_ci ≈ 2π·1.5 kHz | Phase shunts |
| Velocity (PI + feedforward) | 4 kHz | ω_cv ≈ 2π·80–150 Hz | Filtered fused gyro, projected onto joint axes |
| Angle / attitude (P + feedforward) | 1 kHz | ω_cθ ≈ 2π·15–30 Hz | Attitude estimator (camera) + encoders (follow axes) |
| IMU sampling | 8 kHz | Decimated to 4 kHz | 2× ICM-42688-P, FIFO or data-ready interrupt |
