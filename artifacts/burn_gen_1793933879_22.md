## 0. Architecture Decisions and Assumptions

### 0.1 System Architecture

ArduPilot does not commutate motors. On every production AIO (all-in-one) board, the **H743 is the flight controller only**. Each motor phase bridge is driven by a dedicated ESC MCU running AM32 or BLHeli_32-class firmware. The H743 talks to those MCUs over bidirectional DShot600.

```
6S LiPo ─┬─► 4× ESC power stage (6 FETs + 3-ph gate driver + ESC MCU) ─► Motors 1–4
         │         ▲ DShot600 bidir (1 wire per motor)
         │         │
         └─► Buck 5V/3A ─► LDO 3.3V ─► STM32H743VIT6 (FC) ─► IMU / Baro / OSD / Flash / UARTs
```
