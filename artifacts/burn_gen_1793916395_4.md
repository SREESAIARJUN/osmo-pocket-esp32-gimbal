The loops run at these rates:

| Loop | Rate | Closed-loop bandwidth | Feedback signal |
|---|---|---|---|
| Current (FOC) | 20 kHz (ISR) | ω_c = 2π·1500 rad/s | Phase currents |
| Velocity (inertial rate) | 4 kHz | ω_v = 2π·60 rad/s | Fused gyro rate |
| Angle (attitude) | 1 kHz | ω_θ = 2π·10 rad/s | Fused attitude |
| IMU filtering & fusion | 8 kHz → decimated to 4 kHz | — | — |

Each outer loop is placed at least 5× slower than the loop inside it. This keeps the cascade dynamically decoupled.

## 1. Field-Oriented Current Loop

### 1.1 Transforms
Let θ_e = p·θ_m − θ_offset be the electrical angle.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2 i_b)/√3

**Park transform:**

  i_d =  i_α cos θ_e + i_β sin θ_e
  i_q = −i_α sin θ_e + i_β cos θ_e

### 1.2 Plant in the dq frame

  v_d = R i_d + L di_d/dt − ω_e L i_q
  v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

### 1.3 PI design by pole-zero cancellation
With decoupling feedforward, each axis reduces to G(s) = 1/(Ls + R). Choose:

  C(s) = K_p + K_i/s, with K_p = L ω_c and K_i = R ω_c

The PI zero cancels the electrical pole, so the closed loop is first-order: T(s) = ω_c/(s + ω_c).

The discrete form uses forward Euler for the integrator plus back-calculation anti-windup, with gain K_aw ≈ K_i/K_p = R/L:

  u = K_p e + x_i + u_ff
  u_sat = sat(u)
  x_i[k+1] = x_i[k] + T_s (K_i e + K_aw (u_sat − u))

The decoupling feedforward terms are:

  u_ff,d = −ω_e L i_q
  u_ff,q = ω_e L i_d + ω_e λ_m

### 1.4 Delay compensation and SVPWM
PWM update introduces about 1.5·T_s of delay. Compensate by rotating with a predicted angle:

  θ_e,pwm = θ_e + 1.5 T_s ω_e

The inverse Park transform yields (v_α, v_β). Apply min-max zero-sequence injection, equivalent to SVPWM:

  v_x = (v_a, v_b, v_c) from inverse Clarke
  v_0 = −(max v_x + min v_x)/2
  d_x = ½ + (v_x + v_0)/V_bus

The linear range is |v_αβ| ≤ V_bus/√3. Limit the voltage vector circularly, giving d-axis priority:

  v_q,max = √(V_max² − v_d²)
