# Job #46: 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I made the following assumptions. Change the constants in `config.hpp` if your hardware differs.

| Item | Assumption |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), e.g. GBM2804-class: R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| Current sensing | 2-phase low-side shunts. A voltage-mode fallback is provided for boards without shunts. |
| MCU | STM32G4 / H7 class, FPU, ≥170 MHz |
| IMUs | ICM-42688-P **A** on the camera plate (feedback). ICM-42688-P **B** on the frame/base (disturbance reference). |
| Loop rates | Current/FOC 20 kHz · Velocity 4 kHz · Angle 1 kHz · IMU ODR 8 kHz (gyro), decimated to 4 kHz |
| Kinematics | Yaw (outer, q₁) → Roll (q₂) → Pitch (inner, q₃) |

**Bandwidth plan.** Each loop should be at least 5–10× slower than the one inside it:

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_θ ≈ 2π·15 rad/s
