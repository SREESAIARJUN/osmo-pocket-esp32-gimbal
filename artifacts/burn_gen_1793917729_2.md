## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Electrical angle

θ_e = p·(θ_m − θ_off) mod 2π

θ_off is found at commissioning by applying a d-axis voltage V_d with V_q = 0 and recording θ_m.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

i_α = i_a
i_β = (i_a + 2·i_b) / √3

### 1.3 Park transform

i_d = i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 Plant in the dq frame

L·di_d/dt = v_d − R·i_d + ω_e·L·i_q
L·di_q/dt = v_q − R·i_q − ω_e·L·i_d − ω_e·λ_m

Here ω_e = p·ω_m and λ_m = 2K_t / (3p).

### 1.5 Current PI with decoupling and back-EMF feedforward

v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

**Pole-zero cancellation tuning** for a target bandwidth ω_c,i:

K_p,i = L·ω_c,i
K_i,i = R·ω_c,i

The closed loop then becomes approximately ω_c,i / (s + ω_c,i). Choose ω_c,i ≤ 2π·f_s/20. At 20 kHz this gives about 2π·1000 rad/s.

**Discrete PI with back-calculation anti-windup** (T_s = 1/f_s):

u_k = K_p·e_k + I_k
u_k^sat = sat(u_k)
I_(k+1) = I_k + K_i·T_s·e_k + K_aw·(u_k^sat − u_k), with K_aw = K_i / K_p

**Voltage limiting.** The dq voltage vector is limited to the SVPWM linear-region circle |v_dq| ≤ V_dc/√3. v_d is given priority, and v_q gets the remaining magnitude √(V_max² − v_d²).

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e

v_a = v_α
v_b = −½v_α + (√3/2)v_β
v_c = −½v_α − (√3/2)v_β

v_0 = −½·(max(v_abc) + min(v_abc))

D_x = ½ + (v_x + v_0) / V_dc

This is equivalent to SVPWM and is cheaper to compute than sector logic.

**Delay compensation.** Advance the angle used in the inverse Park by 1.5 sample periods: θ_e + 1.5·ω_e·T_s. This accounts for one computation period plus half a PWM period.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant (per axis)

J·dω/dt = K_t·i_q − B·ω − τ_cog(θ) − τ_dist

### 2.2 Velocity loop (5 kHz)

The inner current loop is roughly unity gain at these frequencies (ω_c,i ≫ ω_c,v). The velocity plant is therefore approximately K_t / (J·s + B).

Control law (PI with velocity and acceleration feedforward):

i_q* = K_p,v·e_ω + K_i,v·∫e_ω dt + (J/K_t)·α_ff + (B/K_t)·ω_ff + i_cog,ff(θ)

where e_ω = ω* − ω̂.

**Tuning by symmetric bandwidth placement:**

K_p,v = J·ω_c,v / K_t
K_i,v = K_p,v·ω_c,v / 4

The PI zero sits at ω_c,v/4, which gives about 60° of phase margin. Keep ω_c,v ≤ ω_c,i/5. A typical value is 2π·150 rad/s.

**Velocity estimate.** Raw encoder differentiation is noisy (Δθ_LSB = 2π/16384), so use a 2nd-order PLL tracking observer:

e_θ = wrap(θ_meas − θ̂)
θ̂ ← θ̂ + T_s·(ω̂ + k_1·e_θ)
ω̂ ← ω̂ + T_s·k_2·e_θ

with k_1 = 2ζω_o and k_2 = ω_o², using ζ = 1 and ω_o ≈ 3–5·ω_c,v.
