# STM32H743 Nano FC + 4-in-1 ESC (Job #42): Design Model

## 0. Design Basis and Feasibility Check

The STM32H743 cannot directly commutate four BLDC motors in this design. The architecture is split into two layers:

| Layer | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (400/480 MHz) | ArduPilot. Generates bi-directional DShot600 and decodes eRPM telemetry. |
| ESC (×4 channels) | AT32F421K8U7 or STM32G071 running AM32 | 6-step commutation at 48 kHz complementary PWM |
| Gate drive | 3-phase half-bridge driver per channel (FD6288Q class) | Bootstrapped HS/LS drive |
| Power stage | 24× N-MOSFET, 40 V, PDFN 3.3×3.3 | 6 per channel |

All component values below are **assumed for modelling**. Replace them with datasheet values for the parts you actually select. The equations are general.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V |
| Burst phase current per motor | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| R_DS(on) @ 25 °C, V_GS = 10 V | R_25 | 1.6 mΩ |
| R_DS(on) tempco | α | ≈ 0.0045 /K (≈1.5× at 110 °C) |
| Gate charge (total / Q_gs2 / Q_gd) | Q_g / Q_gs2 / Q_gd | 30 / 3 / 6 nC |
| Reverse recovery charge @ 80 A | Q_rr | 40 nC |
| Energy-equivalent C_oss | C_oss,er | 600 pF |
| Body diode V_f | V_f | 0.8 V |
| Dead time | t_dt | 100 ns |
| Driver source / sink resistance, R_g,ext, R_g,int | | 3 Ω / 1.5 Ω, 4.7 Ω, 1 Ω |
| Gate drive voltage, Miller plateau | V_drv, V_pl | 10 V, 3 V |
| Board size | | 20×20 mm, 6-layer, 2 oz inner |

> ⚠️ **Feasibility flag:** "80 A burst" on a 20×20 board is only a **sub-second to ~1 s** rating. The calculation in §3 shows why. Specify it as "80 A / 1 s, 40 A continuous with airflow" or similar, not as an unqualified number.
