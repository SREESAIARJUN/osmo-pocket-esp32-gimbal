# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #49): Design Package Rev A

## 0. Architecture and Assumptions

### 0.1 System partition

An STM32H743 does not commutate the motors directly. It runs ArduPilot, and each motor channel has its own ESC MCU running AM32 or BLHeli_32-class firmware. This document treats the board as an all-in-one (AIO) stack:

```
[6S LiPo] ─► VBAT bus ─┬─► 4× 3-phase bridges (24 FETs) ◄─ 4× gate drivers ◄─ 4× ESC MCU (AT32F421 / STM32G071, AM32)
                       │                                                         ▲  bidirectional DShot600 (1 wire per motor)
                       └─► Buck 5V / 3V3 ─► STM32H743 (ArduPilot) ───────────────┘
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

At T<sub>j</sub> = 110 °C: R<sub>DS</sub> = 1.2 mΩ × 1.425 = **1.71 mΩ**.

### 1.2 Current paths in six-step commutation

At any instant, two phases carry current:

- The PWM leg conducts through the high side for duty D and through the low side (synchronous freewheel) for 1−D.
- The return leg's low-side FET conducts continuously during the sector.

Every instant therefore has exactly two FETs in series:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

Averaged over an electrical cycle, the load spreads over 6 FETs:

$$\bar P_{cond,FET} = \frac{2 I^2 R_{DS}}{6} = \frac{I^2 R_{DS}}{3}$$

### 1.3 Numbers at 80 A

$$P_{cond,ch} = 2 \times 6400 \times 1.71\times10^{-3} = \mathbf{21.9\ W\ per\ motor\ channel}$$

Average per FET: **3.65 W**.

### 1.4 Electrothermal convergence

R<sub>DS</sub> depends on T<sub>j</sub>, and T<sub>j</sub> depends on loss, so iterate:

$$T_j^{(n+1)} = T_{board} + R_{\theta,jb}\cdot P_{FET}\big(R_{DS}(T_j^{(n)})\big)$$

The loop converges when the thermal-runaway criterion holds:

$$\frac{\partial P}{\partial T}R_{\theta} = \frac{I^2 R_{DS,25}\,\alpha}{3}R_{\theta,jb} < 1$$

Check with R<sub>θ,jb</sub> ≈ 4 K/W: 6400 × 1.2e-3 × 0.005 / 3 × 4 = **0.051**, so the loop is stable.
