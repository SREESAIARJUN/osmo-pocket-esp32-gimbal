> ⚠️ **Feasibility warning (read before layout):** 80 A per channel × 4 on a 30.5 mm board is a **burst-only** rating. The model below shows roughly **88 W of dissipation** at full burst. Commercial "80 A" nano ESCs carry the same physics, usually behind marketing-grade ratings. The design must therefore include temperature-based current derating, as specified in §3.5.

## 1. Conduction Loss Model

### 1.1 Current Waveform (6-step trapezoidal, synchronous rectification)

In 6-step commutation, each phase conducts for 120° of every 180° half-cycle, so each MOSFET carries current for **1/3 of the electrical period**. At duty D:

- **High-side (HS)** conducts for D·T_pwm.
- **Low-side (LS) of the same leg**, in synchronous/complementary mode, freewheels for (1−D)·T_pwm.
- **Opposite-phase LS** conducts for the full 1/3 period.

The current path always contains exactly two MOSFET channels, so the resistive path is 2·R_DS regardless of D (excluding dead time).

### 1.2 Equations

Hot on-resistance:

$$R_{DS,hot} = R_{25}\cdot k_T = 0.90\ \text{m}\Omega \times 1.5 = 1.35\ \text{m}\Omega$$

Per-MOSFET average conduction loss, using I_RMS² = I²/3 for 120° conduction:

$$P_{cond,FET} = \frac{I^2 R_{DS,hot}}{3} = \frac{6400 \times 1.35\times10^{-3}}{3} = \mathbf{2.88\ W}$$

Per-channel conduction loss (6 FETs):

$$P_{cond,ch} = 2 I^2 R_{DS,hot} = 2 \times 6400 \times 1.35\times10^{-3} = \mathbf{17.28\ W}$$

Copper and shunt loss, assuming a 0.25 mΩ shunt plus 0.25 mΩ of trace/via resistance in the path:

$$P_{Cu,ch} = I^2 R_{path} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W}$$

### 1.3 Sensitivity (conduction dominates, so R_DS(on) selection is critical)

| R₂₅ | P_cond per channel @ 80 A | All 4 channels |
|---|---|---|
| 0.6 mΩ | 11.5 W | 46 W |

## 2. Switching Loss Model at 48 kHz

Only one leg actively PWMs at any instant, so there is one hard-switched commutation pair per channel.

**Worst-case operating point.** At D = 1 (true 100% throttle), PWM switching stops and the switching loss approaches zero. The worst combined case is therefore D ≈ 0.9 with I ≈ 80 A. The analysis assumes this point.

### 2.1 Gate Charge Timing

Turn-on (Miller interval):

$$I_{g,on} = \frac{V_{dr} - V_{pl}}{R_{g,tot}} = \frac{10 - 3.5}{3.2} = 2.03\ \text{A} \Rightarrow t_r = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{12\ \text{nC}}{2.03} \approx 5.9\ \text{ns}$$

Turn-off:

$$I_{g,off} = \frac{V_{pl}}{R_{g,tot}} = \frac{3.5}{3.2} = 1.09\ \text{A} \Rightarrow t_f \approx 11.0\ \text{ns}$$

> **Driver limit:** an FD6288Q-class driver is specified at roughly 1.5 A source / 1.8 A sink, so the real t_r will be limited to about 8 ns. Re-run the model with your driver's actual I_source and I_sink.
