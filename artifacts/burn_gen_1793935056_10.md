## 0. Architecture Clarification and Key Findings

**Partitioning.** The STM32H743 does **not** commutate the motors. Running four sensorless 48 kHz power stages plus the ArduPilot flight stack on one core is not viable. The standard and recommended split is:

```
┌──────────────── FC (STM32H743, ArduPilot) ─────────────────┐
│ TIM1 CH1..CH4 ──bidir DShot600 (single wire, open-drain-ish)│
└──────┬──────────┬──────────┬──────────┬──────────────────────┘
       ▼          ▼          ▼          ▼
   ESC MCU 1  ESC MCU 2  ESC MCU 3  ESC MCU 4   (e.g. AT32F421 / STM32G071, AM32 or BLHeli_32)
   48 kHz PWM 48 kHz PWM 48 kHz PWM 48 kHz PWM
       ▼          ▼          ▼          ▼
   3-ph bridge ×4 (24 MOSFETs) → motors
```

**Critical finding: the "80 A burst" rating.** The analysis in §3 shows that a 20×20 mm board dissipates about 125 W with all four motors at 80 A. With a realistic board heat capacity, the board can sustain that load for only **~1–1.5 s** before the junctions reach their limits. The 80 A rating must be specified as a **≤1 s burst, per motor, with a 25 °C start**. If marketing wants 5–10 s bursts, the design needs a 30×30 board or paralleled FETs.

## 2. Loss Model (per ESC, 6-step trapezoidal commutation)

### 2.1 Conduction Loss

With complementary PWM there are always **two** MOSFETs in the current path:
- either the HS or LS device of the PWM'd leg, and
- the static return device of the other active leg.

The phase current has an RMS value that includes the inductor ripple ΔI:

$$
I_{rms}^2 = I_{pk}^2\left(1 + \frac{1}{12}\left(\frac{\Delta I}{I_{pk}}\right)^2\right)
$$

The ripple is:

$$
\Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}
$$

For L_ph = 15 µH and D = 0.5:
- ΔI = 25.2 · 0.25 / (15e-6 · 48e3) = **8.75 A**
- The ripple correction factor is 1.001, which is negligible.

Total conduction loss per ESC:

$$
P_{cond} = 2\,I_{rms}^2\,R_{ds,hot} = 2(80)^2(2.24\,\text{m}\Omega) = \mathbf{28.7\ W}
$$

This loss is **not shared evenly** between devices:
- The static return FET carries I²R = **14.3 W** continuously during its 120° conduction window.
- The PWM leg splits its 14.3 W as D (HS) and 1−D (LS).
- **The worst-case single device therefore sees 14.3 W.** Size the copper pour around the return FETs.

**Electro-thermal feedback.** Because R_ds rises with temperature, iterate:

$$
R_{ds}(T_j) = R_{ds,25}\left[1 + 0.006(T_j - 25)\right]
$$

At T_j = 100 °C, R_ds = 2.03 mΩ, giving P_cond = 26.0 W. Using 2.24 mΩ throughout is the conservative bound.
