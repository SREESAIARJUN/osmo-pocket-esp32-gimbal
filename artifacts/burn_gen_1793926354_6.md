# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection (Job #26)

## 0. Assumptions and Architecture

I don't have the Job #26 spec sheet, so these assumptions are explicit. Every one is a named constant in the code and can be changed.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), sinusoidal back-EMF, low-current (≤ 2 A) |
| Encoder | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701-class) |
| MCU | Cortex-M4F/M7 with FPU, center-aligned PWM, synchronized ADC |
| IMU A | ICM-42688-P on the **camera payload**: the stabilization target |
| IMU B | ICM-42688-P on the **base/vehicle frame**: vibration reference and disturbance feedforward |

If both IMUs sit on the payload instead (a redundancy layout), Section 5.4 still applies. Replace the LMS canceller with the averaging and fault-voting block noted there.

### Loop Rates

All loops are derived from one PWM timer, so they are phase-coherent.

| Loop | Rate | Ts | Executes in |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ADC-complete ISR |
| IMU sampling (both) | 8 kHz ODR | 125 µs | SPI DMA, FIFO-free register read |
| Vibration filters + velocity loop | 4 kHz | 250 µs | PWM ISR ÷5 |
| Attitude fusion + angle loop | 1 kHz | 1 ms | PWM ISR ÷20 (or low-priority task) |
| Cogging adaptation | 1 kHz | 1 ms | background |

## 1. Plant Model (per axis)

Mechanical model, in the motor-shaft frame:

$$
J\,\ddot\theta_m = K_t\, i_q - b\,\dot\theta_m - \tau_{cog}(\theta_m) - \tau_{d}(t), \qquad K_t = \tfrac{3}{2}\,p\,\lambda_m
$$

Electrical model in the dq frame (SPM motor, so $L_d = L_q = L$):

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q, \qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m, \qquad \omega_e = p\,\dot\theta_m
$$

The electrical angle is $\theta_e = p(\theta_m - \theta_{0})$, where $\theta_0$ is the encoder offset found at calibration by aligning to the d-axis.

## 2. Field-Oriented Control (Current Loop)

### 2.1 Transforms

Clarke (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park uses the transpose of that matrix.

### 2.2 Current PI with Decoupling and Back-EMF Feedforward
