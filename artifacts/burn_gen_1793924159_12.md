## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), `R ≈ 5–15 Ω`, `L ≈ 1–3 mH` |
| Current sensing | 2 or 3 inline/low-side shunts; voltage-mode fallback supported |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6835 class), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the plate's rotational centre (see §4.4) |
| Axis order | Yaw (outer) → Roll (middle) → Pitch (inner/camera) |

**Loop rates (all phase-locked to the PWM center interrupt):**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz | `T_i = 50 µs` |
| Velocity | 4 kHz (every 5th) | `T_v = 250 µs` |
| Angle and attitude | 1 kHz (every 20th) | `T_θ = 1 ms` |
| IMU sampling | 8 kHz ODR, read via DMA, decimated to 4 kHz | |
| Peak tracker (SDFT) | 1 kHz | |

**Signal flow per axis:**

```
q_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI + J·α_ff]─► i_q,fb ─┐
            ▲                          ▲                            (+)◄─ i_q,cog (anti-cogging)

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: `θ_e = p·(θ_m − θ_offset)`, wrapped to [−π, π).

**Clarke transform (amplitude-invariant), using `i_a + i_b + i_c = 0`:**

```
i_α = i_a
i_β = (i_a + 2·i_b) / √3
```

**Park transform:**

```
i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e
```

**Inverse Park transform:**

```
v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e
```
