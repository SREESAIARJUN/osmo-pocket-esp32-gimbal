## 1. Field-Oriented Control: the Current Loop

### 1.1 Transforms

The Clarke transform (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

The Park transform, where θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform applies the transpose of this matrix.

### 1.2 Plant and torque

In the dq frame, with surface PMSM and L_d = L_q = L:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q \equiv K_t\, i_q$$

The control law sets i_d* = 0. Gimbal motors operate far below base speed, so field weakening is not needed.

### 1.3 Current PI with decoupling and back-EMF feedforward

$$v_d^* = PI_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e \lambda_m$$

Choose the gains by pole-zero cancellation, where ω_c is the target bandwidth (here ω_c ≈ 2π·1.5 kHz, below f_PWM/10):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes approximately ω_c/(s+ω_c).

### 1.4 Voltage limit and SVPWM

The voltage vector is limited to the inscribed hexagon circle:

$$|v^*| \le V_{bus}/\sqrt3$$

When the limit is hit, scale the vector and apply back-calculation anti-windup.

SVPWM is implemented by min/max zero-sequence injection:

$$v_{x}=\text{invClarke}(v_\alpha,v_\beta),\quad v_0=-\tfrac12(\max v_x+\min v_x),\quad D_x=\tfrac12+\frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Position and Velocity Control

### 2.1 Structure

```
θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI + α_ff]─► i_q,pid ─(+ i_q,cog + i_q,ff)─► Current loop
   ▲  (1 kHz)                 ▲  (4 kHz)                                                 (20 kHz)
 θ̂ camera attitude (IMU)    ω̂ fused rate (gyro + encoder)
```

The feedback signals for stabilization are chosen as follows:
- **Angle loop:** uses the camera attitude from the IMU fusion, projected onto each joint axis.
- **Velocity loop:** uses a complementary blend of the gyro rate (true inertial rate) and the encoder rate (low-noise relative rate), plus base-rate feedforward.

### 2.2 Angle loop (P with velocity feedforward)

The error is wrapped to (−π, π]:

$$e_\theta = \operatorname{wrap}(\theta_{ref}-\hat\theta)$$

$$\omega_{ref} = \operatorname{sat}_{\omega_{max}}\!\big(K_{p\theta}\,e_\theta + \dot\theta_{ref}\big)$$

A pure P term suffices because the velocity loop already contains an integrator, so the cascade is type-2 to angle disturbances. Pick K_pθ ≈ ω_v/4, where ω_v is the velocity-loop bandwidth.

### 2.3 Velocity loop: PI with filtered D and anti-windup

The continuous form is:

$$u = K_p e + K_i\!\int e\,dt - K_d\,\frac{N s}{s+N}\,\omega_{meas}$$

The derivative acts on the measurement, which avoids setpoint kick.

The discrete form (sample time T) uses backward Euler for the integral and a Tustin-filtered derivative:

$$P_k = K_p e_k$$

$$D_k = \frac{2-NT}{2+NT}D_{k-1} - \frac{2K_dN}{2+NT}(y_k-y_{k-1})$$

$$v_k = P_k + I_{k-1} + D_k + u_{ff},\qquad u_k=\operatorname{sat}(v_k)$$

$$I_k = I_{k-1} + K_iT e_k + K_{aw}T(u_k - v_k)\quad\text{(back-calculation, } K_{aw}\approx \sqrt{K_i/K_p}\cdot K_i/K_p\text{ or simply }1/T_i)$$

The acceleration feedforward is:

$$i_{q,ff} = \frac{J\,\dot\omega_{ref} + B\,\omega_{ref}}{K_t}$$

### 2.4 Gain design for a rigid inertia J

The plant is approximately ω/i_q = K_t/(Js). For a target velocity bandwidth ω_v (around 2π·80 Hz, limited by encoder noise and plate resonances):

$$K_p = \frac{J\omega_v}{K_t},\qquad K_i = K_p\frac{\omega_v}{4}$$
