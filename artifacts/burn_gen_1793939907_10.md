# STM32H743 Nano FC + 4-in-1 ESC (Job #66): Power-Stage Losses, Thermal Model, Bidirectional DShot600 DMA Allocation, and Reference Netlists

## 0. Architecture and Assumptions

This is the standard ArduPilot partitioning:

```
 STM32H743 (ArduPilot) ──4× bidir DShot600──► 4× ESC MCU (AT32F421 / AM32 firmware)
                                                   │ 48 kHz complementary PWM
                                                   ▼
                                       4× (3-phase gate driver + 6 MOSFETs)
```

The H743 does **not** switch the FETs. The 48 kHz PWM comes from the per-channel ESC MCUs. If Job #66 actually intends the H743 to drive the gates directly, that is a different architecture. It needs 24 complementary outputs with dead time (TIM1/TIM8 only give 6 each), and that is not supported by ArduPilot. Flag it before layout.
