# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #38)

I don't have the specification sheet for Job #38. This design therefore uses a typical brushless gimbal configuration. Every assumption is listed in §0 and exposed as a configuration constant in the code, so you can substitute your values.

---

## 0. Assumptions and Loop Rates

| Item | Value (default) |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), p = 7 pole pairs, R = 5.6 Ω, L = 2.1 mH (phase-to-neutral), K_t ≈ 0.045 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), on each joint |
| MCU | STM32G4 / H7 class with FPU at 170+ MHz, center-aligned PWM |
| Bus voltage | 12 V |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the plate centroid (r₂ = −r₁) |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5 kHz |
| Velocity (PI + filtered D) | 4 kHz | ~80–120 Hz |
| Angle (P + rate feedforward) | 1 kHz | ~15–25 Hz |
| IMU sampling | 8 kHz ODR, decimated to 4 kHz | — |

Each loop's bandwidth stays at least 5× below the bandwidth of the loop inside it. This preserves cascade separation.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
