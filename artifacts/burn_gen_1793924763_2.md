# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Sensor Fusion

I don't have the Job #15 specification, so this design uses the assumptions listed in §0. Each one is a parameter in `GimbalConfig`. If your motor, sensors or MCU differ, change those values and the gain-design functions recompute the controller gains.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs $p = 7$), $R_s = 5.5\,\Omega$, $L_s = 2.2\,\text{mH}$, $K_t \approx 0.12\,\text{N·m/A}$ |
| Inverter | 3-phase, 24 V bus, 20 kHz center-aligned PWM, 2-shunt or inline current sensing |
| Encoders | 14-bit absolute magnetic encoder per joint (MT6701 / AS5047P class) over SPI |
| IMUs | 2× ICM-42688-P on the camera plate. Both run in SPI mode at 8 kHz ODR, gyro ±1000 dps, accel ±8 g. |
| MCU | Cortex-M4F/M7 (STM32G4/H7) with single-precision FPU |
| Payload inertia (pitch axis) | $J \approx 2.5\times10^{-4}\,\text{kg·m}^2$ |

### Loop rate hierarchy

```
 20 kHz  ─ Current loop (FOC): Clarke → Park → PI(d,q) → inv-Park → SVPWM
           Cogging feedforward added to i_q*.
  8 kHz  ─ IMU data-ready: read both ICM-42688-P → align → lever-arm correct
           → fuse → adaptive notch + static notch + LPF
  4 kHz  ─ Rate (velocity) loop: PI on fused gyro rate (per joint axis)
  1 kHz  ─ Attitude estimate (Mahony) + angle loop (P + rate feedforward)
           + joint-space mapping via gimbal Jacobian
```

The bandwidth separation between loops is about 5–10× (§1.6).

## 1. FOC Current Loop Equations

### 1.1 Clarke transform (amplitude-invariant)

With $i_a + i_b + i_c = 0$:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\left(i_a + 2 i_b\right)
$$

### 1.2 Park transform

The electrical angle is $\theta_e = p\,\theta_m - \theta_{\text{off}}$, where $\theta_{\text{off}}$ is the encoder-to-rotor offset found at calibration.

$$
\begin{bmatrix} i_d \\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}
$$

### 1.3 PMSM model in the dq frame

$$
\begin{aligned}
v_d &= R_s i_d + L_d \dot i_d - \omega_e L_q i_q \\
v_q &= R_s i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)\\
\tau_e &= \tfrac32\, p\,\big[\lambda_m i_q + (L_d - L_q) i_d i_q\big] \;\approx\; K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m
\end{aligned}
$$

The approximation holds for a surface-mount motor ($L_d = L_q = L$) with $i_d^* = 0$.

### 1.4 Current PI with decoupling and back-EMF feedforward

$$
\begin{aligned}
v_d^* &= K_{p,i}\,e_d + K_{i,i}\!\int e_d\,dt \;-\; \omega_e L i_q \\
v_q^* &= K_{p,i}\,e_q + K_{i,i}\!\int e_q\,dt \;+\; \omega_e (L i_d + \lambda_m)
\end{aligned}
$$

Here $e_{d,q} = i_{d,q}^* - i_{d,q}$.

**Gain design by pole-zero cancellation.** Choose the PI zero to cancel the electrical pole $R/L$. The closed loop then becomes first order with bandwidth $\omega_{ci}$:

$$
K_{p,i} = L\,\omega_{ci}, \qquad K_{i,i} = R_s\,\omega_{ci}
\quad\Rightarrow\quad \frac{i_q}{i_q^*} = \frac{\omega_{ci}}{s + \omega_{ci}}
$$

- Choose $\omega_{ci} \le 2\pi f_{\text{PWM}}/10 \approx 2\pi\cdot 2\,\text{kHz}$.
- Account for the 1.5-sample PWM/computation delay by limiting $\omega_{ci}T_s \lesssim 0.6$.

**Voltage limiting.** Limit to the inscribed circle of the SVPWM hexagon:

$$
|v_{dq}| \le \frac{V_{dc}}{\sqrt3}
$$

Give $v_d$ priority. Then $v_q$ is limited to $\sqrt{V_{max}^2 - v_d^2}$.
