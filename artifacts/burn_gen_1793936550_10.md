# STM32H743 Nano FC + 80 A 4-in-1 ESC: Power-Stage and DShot Architecture (Job #58)

---

## 0. Architecture Baseline and Assumptions

The STM32H743 does not drive the bridge MOSFETs, and in a standard ArduPilot stack it should not. The H743 runs ArduPilot and emits bi-directional DShot600. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32. That MCU generates the 48 kHz complementary PWM, handles commutation and dead-time, and returns eRPM.

```
 6S LiPo ──┬─────────────────────────────────────────────────────────┐
           │                                                         │
   ┌───────▼────────┐  DShot600 bidir ×4   ┌──────────────────────────▼──────┐
   │  FC: STM32H743 │◄────────────────────►│ 4-in-1 ESC                      │
   │  ArduPilot     │  CURR, VBAT (analog) │  4× ESC MCU (AM32, 48 kHz PWM)  │
   │  TIM1 CH1-4    │◄─────────────────────│  4× 3-ph gate driver            │
   └────────────────┘                      │  4× 6 MOSFET bridge (24 FETs)   │
                                           └─────────────────────────────────┘
```
