## 1. Conduction Loss Model

### 1.1 Current paths in trapezoidal BLDC commutation

In any 60° commutation sector, two phases conduct. With complementary (synchronous-rectified) PWM on the switching leg:

- **Switching leg:** the high-side FET conducts for D·T_sw; the low-side FET conducts (sync-rectification) for (1–D)·T_sw.
- **Return leg:** the low-side FET conducts continuously.

Per-channel conduction loss:

$$P_{cond} = I_{rms}^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I_{rms}^2\,R_{DS}(T_j)$$

This result is **independent of duty cycle**, because synchronous rectification puts exactly one FET in the switching leg in the current path at all times.

### 1.2 Ripple correction

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}$$

For a typical 5-inch to 7-inch motor (L_ph ≈ 20 µH line-to-line) at D = 0.5:

$$\Delta I = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.6\ \text{A} \;\Rightarrow\; \frac{\Delta I^2}{12} = 3.6\ \text{A}^2$$

This is negligible against 6400 A², and ΔI → 0 at full throttle. So I_rms ≈ I.

### 1.3 Temperature-dependent resistance (electrothermal coupling)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha(T_j - 25)]$$

At T_j = 108 °C: R_DS = 1.0 × (1 + 0.006 × 83) ≈ **1.5 mΩ**.
