## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1 + \alpha\,(T_j - 25)\big]$$

At T_j = 108 °C: R_ds = 1.0 mΩ × 1.50 = **1.5 mΩ**.

### 1.2 Current path in 6-step synchronous commutation

In any 60° sector, current flows through one high-side and one low-side FET. During PWM off-time it freewheels through the complementary FET of the PWM leg. With synchronous rectification, the current path always contains **two conducting channels**:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

$$P_{cond,motor} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

### 1.3 Per-device distribution

Each FET conducts for 120° of 360° (duty-weighted between HS and LS of the PWM leg):

$$P_{cond,FET,avg} = \frac{19.2}{6} = 3.2\ \text{W}, \qquad P_{cond,FET,inst} = I_{ph}^2 R_{ds} = 9.6\ \text{W}$$

The 9.6 W instantaneous figure drives junction ripple (§4.3).

### 1.4 Electro-thermal stability (runaway criterion)

Since P ∝ R_ds(T) and T rises with P through R_θ:

$$T_j = T_a + R_\theta\,I^2 R_{ds,25}[1+\alpha(T_j-25)]$$

$$\Rightarrow\quad T_j = \frac{T_a + R_\theta I^2 R_{ds,25}(1-25\alpha)}{1 - \alpha R_\theta I^2 R_{ds,25}}$$

**Stability requires** α·R_θ·I²·R_ds,25 < 1. With I = 80 A this gives R_θ < 1/(0.006 × 6.4) ≈ **26 K/W** per conduction pair. A nano board meets this electrically, but see §4: the thermal mass, not runaway, is the binding constraint.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The synchronous partner switches at near-zero voltage (ZVS after dead-time), so it contributes dead-time diode loss rather than V·I overlap loss.

### 2.1 Gate current and transition times

$$I_g = \frac{V_{drv} - V_{plateau}}{R_{g,tot}} = \frac{10-3.5}{5} = 1.3\ \text{A}$$

$$t_r \approx t_f \approx \frac{Q_{gd}+Q_{gs2}}{I_g} = \frac{15\ \text{nC}}{1.3\ \text{A}} = 11.5\ \text{ns}$$
