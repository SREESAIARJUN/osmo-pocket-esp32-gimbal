# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

**Scope and assumptions.** I don't have the Job #40 specification, so the design assumes the following. Every assumption is a configuration constant in the code, so you can substitute the real values.

| Item | Assumption |
|---|---|
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G474), single-precision float |
| Motors | 3× BLDC gimbal motors, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Current sensing | 2 or 3 low-side/inline shunts per motor |
| Rotor angle | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701 class) |
| Camera IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, FIFO or data-ready IRQ |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

These parameters are not verified against your hardware. Before running on real motors, check them, measure the actual R, L and inertia, and confirm the ICM-42688-P register values against your datasheet revision.

## 1. Loop Architecture and Timing

```
           1 kHz                4 kHz                    20 kHz
 q_ref ─► [Attitude P/PD] ─► ω_ref ─► [Rate PI + FF] ─► i_q,ref ─► [Current PI ×2] ─► SVPWM ─► Motor
             ▲                  ▲          ▲  ▲               ▲
             │ q̂ (camera)       │ ω̂ (cam)  │  └─ i_q,cog(θ_m) │ i_d,i_q (Clarke/Park)
        [Mahony AHRS] ◄── [Dual-IMU fusion + notch bank] ◄── 2× ICM-42688-P @ 8 kHz
                                                           θ_m (encoder) ─► θ_e for Park
```

Rule of thumb: each loop's bandwidth should be at most 1/4–1/5 of the next-inner loop's bandwidth. Each loop's sample rate should be at least 10× its own bandwidth.

| Loop | Rate Ts | Target bandwidth |
|---|---|---|
| Current (d/q) | 50 µs (20 kHz) | ω_c ≈ 2π·1500 rad/s |
| Rate (velocity) | 250 µs (4 kHz) | ω_v ≈ 2π·60–120 rad/s |
| Attitude (angle) | 1 ms (1 kHz) | ω_θ ≈ 2π·10–25 rad/s |
| IMU sampling | 125 µs (8 kHz) | AAF ≈ 258 Hz, decimated to 4 kHz |

## 2. FOC Current Loop

### 2.1 Motor model (rotor dq frame, SPM motor so L_d ≈ L_q = L)

$$
\begin{aligned}
v_d &= R\,i_d + L\frac{di_d}{dt} - \omega_e L\, i_q\\
v_q &= R\,i_q + L\frac{di_q}{dt} + \omega_e L\, i_d + \omega_e \lambda_m\\
\tau_e &= \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q,\qquad \omega_e = p\,\omega_m,\quad \theta_e = p\,\theta_m - \theta_{\text{off}}
\end{aligned}
$$
