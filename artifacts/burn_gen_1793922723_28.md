# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture

**Job #18, Rev A (engineering baseline)**

This document develops the thermal, electrical, and firmware-timing models from first principles. It includes a feasibility check, because the numbers impose hard limits on what a nano form factor can deliver at 80 A.

---

## 0. Architecture Clarification and Assumptions

The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. A 4-in-1 ESC requires a dedicated motor-control MCU per channel (or a dual-motor MCU). The 48 kHz PWM is generated on the ESC side.

| Parameter | Value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_max = 25.2 V, V_nom = 22.2 V | Calculations use 25.2 V (worst case for switching) |
| Board | 20 × 20 mm mounting (≈ 25.5 × 25.5 mm outline), 8-layer, 2 oz all layers | "Nano" interpreted as 20 × 20 |
| FC MCU | STM32H743VIH6 or VIT6, 400 MHz (ArduPilot default), timer clock 200 MHz | |
| ESC MCU | 4 × AT32F421K8U7 running AM32 firmware | Alternative: STM32G071 |
| Gate driver | 4 × FD6288Q (3-phase half-bridge, bootstrap) | |
| MOSFET | 40 V N-ch, PDFN 3.3 × 3.3 mm. R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V, Q_g = 40 nC, Q_gd = 8 nC, Q_rr = 40 nC, Q_oss = 50 nC, R_θJC = 1.5 K/W | Representative best-in-class 3×3 part. Substitute datasheet values. |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM | AM32 default |
| f_sw | 48 kHz | |
| Burst current | 80 A per channel (phase/DC-link) | |
