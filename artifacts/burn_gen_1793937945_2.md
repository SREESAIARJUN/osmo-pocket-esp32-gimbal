# STM32H743 AIO Nano FC + 4-in-1 ESC: Loss Model, Thermal Budget, Bi-Directional DShot DMA Plan and Reference Netlist

## 0. Scope, Architecture and Assumptions

I don't have the Job #55 project files, so every number below comes from stated assumptions. Each one is marked **[A]** and must be replaced with values from your BOM datasheets before release.

**Architecture correction up front.** The STM32H743 does not commutate the motors. On an AIO "FC + 4-in-1" board:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (e.g., AT32F421 / STM32G071, AM32 or BLHeli_32)
                                              └─► 3-phase gate driver ─► 6 MOSFETs ─► motor
```

The 48 kHz switching frequency is an ESC-firmware PWM setting. The H743's job is DShot generation, eRPM capture via timer DMA, and the bidirectional DShot (BDShot) RPM notch filter.

**Feasibility flag.** 80 A per channel on a nano-format AIO is a *burst* rating measured in about one second, not a continuous rating. The math below shows why. Treat any marketing "80 A" on a 20×20 mm board with suspicion. A realistic continuous rating is 25–35 A per channel with prop-wash cooling.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C:

$$R_{ds} = 1.5 \times (1 + 0.005 \times 85) = 2.14\ \text{mΩ}$$

### 1.2 Six-step trapezoidal drive with synchronous (complementary) PWM

During each 60° sector, phase A is PWM'd and phase B is held low:

| Device | Conduction fraction | Loss |
|---|---|---|
| A-high | D | I²·R·D |
| A-low (sync rectifier) | 1 − D | I²·R·(1 − D) |
| B-low | 1 | I²·R |

$$P_{cond,ch} = I^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

This is independent of D, which is a useful property of synchronous rectification.

Add copper and shunt losses: P_Cu = I²·(R_trace + R_shunt). Assume R_trace ≈ 0.3 mΩ **[A]**, plus 0.5 mΩ for the shunt if fitted.

**At 80 A:**

- FET conduction: 2 × 6400 × 2.14 mΩ = **27.4 W/ch**
- Copper + shunt: 6400 × 0.8 mΩ = **5.1 W/ch**

### 1.3 Per-FET averaging

The electrical frequency is f_e = (poles/2)·RPM/60. For example, 14 poles at 30k RPM gives 3.5 kHz. That is much faster than the die-to-board thermal time constant (ms to tens of ms), so loss can be averaged over 360°. Each switch is "active" for 120°:

$$P_{LS} = \frac{I^2R}{3}[1+(1-D)], \qquad P_{HS} = \frac{I^2R}{3}D + \frac{P_{sw}}{3}$$

At D = 0.9 and 80 A:

- P_LS = 4.57 × 1.1 = **5.0 W**
- P_HS = 4.11 + switching/3 ≈ **4.8 W**

## 2. Switching Loss Model at 48 kHz

Only the PWM'd high-side/low-side pair hard-switches.

| Component | Formula | Value at 25.2 V, 80 A |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw | 0.5 × 25.2 × 80 × 40 ns × 48 k = **1.94 W** |
| Body-diode reverse recovery | Q_rr·V·f_sw | 30 nC × 25.2 × 48 k = **0.036 W** |
| C_oss energy | ½·C_oss,er·V²·f_sw (C_oss,er ≈ 1 nF) | **0.015 W** |
| Dead-time diode conduction | V_f·I·2·t_dt·f_sw | 0.8 × 80 × 200 ns × 48 k = **0.61 W** |
| Gate charge (lands in driver / R_g) | 2·Q_g·V_gs·f_sw | **0.029 W** |
| **Total switching** | | **≈ 2.6 W/ch** |

**Key design insight.** Switching loss scales with D(1−D)-shaped mid-throttle operation
