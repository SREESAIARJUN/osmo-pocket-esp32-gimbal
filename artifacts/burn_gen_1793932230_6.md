# 3-Axis Gimbal Motor Control and Dual-IMU Sensor Fusion: FOC, Cascaded Control, Anti-Cogging, and Vibration Rejection

## 0. Assumptions

I don't have the Job #14 spec sheet, so the design rests on the assumptions below. Every value is a named constant in the code. Replace them with your measured parameters before tuning.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7). R = 5.0 Ω phase-neutral, L = 1.8 mH, K_t = 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (e.g. AS5048A / MA730), read every PWM period |
| MCU | STM32G4/H7-class with FPU. Center-aligned PWM at 20 kHz |
| Loop rates | Current/FOC 20 kHz. Velocity 4 kHz. Angle/attitude 1 kHz. IMU sampling 8 kHz |
| IMU A ("payload") | ICM-42688-P on the camera plate. This is the control feedback sensor. |
| IMU B ("base") | ICM-42688-P on the handle/airframe side of the dampers. Used as the disturbance reference sensor. |
| Gimbal order | Yaw (base) → Roll → Pitch (payload) |
