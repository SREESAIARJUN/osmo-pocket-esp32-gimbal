### 0.2 Feasibility warning

80 A per channel on a 20×20 board is **only** achievable as a ~1–2 s thermal-capacitance-limited burst. Continuous capability with prop-wash cooling is ≈20–25 A per channel. This is derived in §2.4. If marketing requires "80 A," spec it explicitly as *"80 A burst, ≤1 s, 40 °C start."*

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha \approx 0.005\ \text{K}^{-1}$$

| T_j | R_ds |
|---|---|
| 25 °C | 1.0 mΩ |
| 100 °C | 1.375 mΩ |
| 125 °C | 1.5 mΩ (design value for burst) |

### 1.2 Current path in 6-step synchronous PWM

During each 60° sector, one phase is PWM'd high and another is held low:

- The high-side (HS) of the PWM phase conducts for duty D.
- That phase's low-side (LS) synchronously rectifies for (1−D), minus dead time.
- The return phase's LS conducts 100 % of the sector.

So the motor current always flows through **exactly two channels** (two FETs, or one FET plus a body diode during dead time).

### 1.3 RMS current including ripple

Phase current I_ph has PWM ripple ΔI = V_bus·D(1−D)/(L_ph·f_sw). Its RMS is:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}$$

For L_ph ≈ 15 µH (typical 2207 motor), D = 0.5, f_sw = 48 kHz:

- ΔI = 25.2·0.25/(15e-6·48e3) ≈ 8.75 A
- ΔI²/12 ≈ 6.4 A², which is negligible against 80² = 6400 A² (+0.
