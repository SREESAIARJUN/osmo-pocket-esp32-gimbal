## 1. FOC Current Loop (innermost, 20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, with electrical angle θ_e = p·θ_m − θ_off:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$
$$\tau_e = \tfrac32 p\lambda\, i_q = K_t i_q$$

### 1.3 PI with Decoupling and Back-EMF Feedforward

$$v_d^* = \underbrace{K_p e_d + K_i\!\int e_d}_{PI} - \hat\omega_e L i_q$$
$$v_q^* = K_p e_q + K_i\!\int e_q + \hat\omega_e L i_d + \hat\omega_e\lambda$$

With decoupling, each axis reduces to G(s) = 1/(Ls + R). Pole-zero cancellation (K_i/K_p = R/L) gives the closed loop ω_c/(s + ω_c):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$
