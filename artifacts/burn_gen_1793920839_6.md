# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #49)

I don't have the Job #49 specification, so the design below rests on stated assumptions. Each one is a single constant in the code, so changing it is easy.

## 0. Assumptions and Loop Architecture

| Item | Value (assumed) |
|---|---|
| Motor | Gimbal BLDC, 12N14P (GM4108-class), p = 7 pole pairs, R ≈ 10 Ω, L ≈ 4 mH (phase) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class, FPU, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload pivot, separate SPI buses, shared FSYNC |

The loops run at these rates:

| IMU fusion | 8 kHz ODR, decimated to 4 kHz | — |

## 1. FOC Current Loop

### 1.1 Transforms
With electrical angle θₑ = p·θₘ − θ_offset:

**Clarke transform** (amplitude-invariant, balanced phases):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:** $v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e$, $\; v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$

### 1.2 Plant and decoupling
The dq-frame voltage equations of an SPMSM (L_d = L_q = L) are:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Adding these feedforward terms decouples the axes:
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

What remains on each axis is the first-order plant $G_i(s) = 1/(Ls+R)$.
