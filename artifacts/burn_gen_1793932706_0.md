# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #42 specification, so this design uses the typical BLDC gimbal parameters below. Every value is a `constexpr` or a tuning parameter, so you can substitute your real figures.

**Mechanical layout:** yaw (outer), roll (middle), pitch (inner). The camera IMUs measure payload attitude and rate.

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m, with offset θ₀ found at calibration:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model (SPM motor, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 Current PI with decoupling (pole–zero cancellation)

Choose the closed-loop current bandwidth ω_c (rad/s). Keep ω_c ≤ 2π·f_pwm/10, i.e. about 2π·2 kHz here.

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This cancels the electrical pole R/L and gives a first-order closed loop 1/(s/ω_c + 1).

Discrete form (sample period T_s = 1/f_pwm), with feedforward decoupling:

$$v_d^* = K_{p,i} e_d + I_d - \omega_e L\, i_q$$
$$v_q^* = K_{p,i} e_q + I_q + \omega_e L\, i_d + \omega_e\lambda_m$$
$$I_{d,q}[k+1] = I_{d,q}[k] + K_{i,i} T_s\, e_{d,q} + K_{aw}\big(v^{sat} - v^{*}\big)$$

**Anti-windup:** back-calculation with K_aw ≈ 1/K_p,i (normalized).

**Voltage circle limit**, with d-axis priority:

$$|v_d|\le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max}\;(m_{max}\approx 0.96)$$

### 1.4 SVPWM (min-max zero-sequence injection, equivalent to 7-segment SVM)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}},\quad x\in\{a,b,c\}$$

### 1.5 Velocity estimation: PLL observer on the encoder angle

Wrap the phase error into the range [−π, π]:

$$e_\theta = \mathrm{wrap}(\theta_m - \hat\theta)$$
$$\hat\omega \mathrel{+}= K_{i,pll} T_s\, e_\theta$$
$$\hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}\, e_\theta)$$

Gains: K_p,pll = 2ζω_n and K_i,pll = ω_n², with ζ = 0.707–1 and ω_n ≈ 2π·300 Hz.
