## 0. System Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), e.g. GBM2804-class |
| Phase resistance / inductance | R ≈ 5–12 Ω, L ≈ 1–3 mH (measure per axis) |
| Commutation encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sensing | 2-phase low-side shunts. A voltage-mode fallback is provided. |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |
| IMU_C | ICM-42688-P on the **camera platform**: primary attitude and rate feedback |
| IMU_B | ICM-42688-P on the **base/handle/airframe**: vibration reference and disturbance feedforward |

**Loop rates (time-scale separation of at least 4–5× between cascade levels):**

```
 20 kHz  PWM / FOC current loop      (ω_c  ≈ 2π·1500 rad/s)
  8 kHz  IMU sampling (both ICMs)    (ODR 8 kHz, AAF on-chip)
  4 kHz  Velocity loop + anti-cog    (ω_v  ≈ 2π·120 rad/s)
  1 kHz  Angle loop + AHRS           (ω_θ  ≈ 2π·25  rad/s)
```

**Control structure (per axis):**

```
θ_ref ─►(Σ)─► Angle P/PI ─►(Σ)─► Velocity PI ─►(Σ)─► i_q,ref ─► Current PI (FOC) ─► SVPWM ─► Motor
        ▲ −                ▲ −  ▲ +                ▲ +
        │                  │    │ ω_ff (base-rate   │ i_q,cog (anti-cogging)
   θ̂ (AHRS,           ω̂ (IMU_C gyro,           │ + i_q,grav (optional)
   IMU_C+IMU_B)        vibration-cancelled)     
        Encoder θ_m ──► electrical angle θ_e = p·θ_m − θ_offset (commutation only)
```

The key gimbal-specific choices are:

1. **Outer-loop feedback comes from the camera IMU, not the encoder.** We stabilize the camera's inertial attitude, not the joint angle. The encoder is used for commutation, cogging phase, and joint kinematics.
2. **The base IMU provides two things.** It supplies a **disturbance feedforward** (counter-rotate the joint by the base rate before the error develops). It also supplies the **reference signal** for adaptive vibration cancellation.
