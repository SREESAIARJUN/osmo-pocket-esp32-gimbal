## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7-class with single-precision FPU, center-aligned PWM |
| Motors | Gimbal BLDC, e.g. GBM4108: 12 slots / 14 poles (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis, SPI |
| Current sense | 2-shunt or 3-shunt inline, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR = 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner), camera on the pitch link |

**Loop rates (hardware-timer driven, nested by integer division):**

```
PWM / current loop (FOC)   f_i = 20 kHz   (ISR, ADC-triggered)
IMU read + filters         f_g =  8 kHz   (IMU DRDY / FIFO watermark)
Velocity (rate) loop       f_v =  4 kHz
Attitude estimator + angle f_a =  1 kHz
Cogging adaptation         runs inside the current ISR (cheap LMS)
```

**Signal flow per axis:**

```
θ_ref ─►(Σ)─► Angle P(I) ─► ω_ref ─►(Σ)─► Velocity PI ─► i_q* ─►(Σ)─► Current PI(d,q) ─► SVPWM ─► Motor
         ▲  ff: θ̇_ref ──────────────┘ ▲  ff: J·θ̈_ref/K_t ───────┘ ▲
         │                             │       + cogging ff ────────┘
     IMU attitude              gyro→joint rate (Jacobian)
     (Mahony, dual IMU)        + encoder-rate blend
```

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
