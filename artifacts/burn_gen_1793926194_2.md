## 1. FOC Current Loop (Innermost, 20 kHz)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset) mod 2π

**Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque (surface PMSM, assuming L_d = L_q):

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.3 PI Control with Pole-Zero Cancellation

The PI is in parallel form:

$$C_i(s) = K_{p,i} + \frac{K_{i,i}}{s}$$

Choose the gains so the PI zero cancels the electrical pole. This makes the closed loop first-order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}\;\;(\approx 2\pi\cdot 2\,\text{kHz})$$

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d - \hat\omega_e L i_q,\qquad v_q^* = \text{PI}_q + \hat\omega_e L i_d + \hat\omega_e\lambda_m$$

### 1.4 Voltage Limiting and Anti-Windup

The maximum linear SVPWM voltage is V_max = V_bus/√3.

- **Limit priority:** clamp v_d to V_max first, then allow |v_q| ≤ √(V_max² − v_d²).
- **Back-calculation anti-windup:** the integrator state x follows

$$x_{k+1} = x_k + T_s\big[K_i e_k + K_{aw}(u^{sat}_k - u_k)\big],\qquad K_{aw} \approx K_i/K_p$$

### 1.5 SVPWM (Min-Max Zero-Sequence Injection)

This is equivalent to sector-based SVPWM.

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12[\max(v_{abc}) + \min(v_{abc})]$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Rotor Velocity Estimation (PLL Tracking Observer)

Differentiating the encoder directly is too noisy, so use a type-2 PLL:

$$e_k = \text{wrap}_{\pm\pi}(\theta_{m,k} - \hat\theta_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + K_{i,pll}T_s e_k,\qquad \hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll}e_k)$$

The closed loop is ω_n²/(s² + 2ζω_n s + ω_n²), with

$$K_{p,pll} = 2\zeta\omega_n,\qquad K_{i,pll} = \omega_n^2$$

Typical values are ζ = 0.707 and ω_n = 2π·400 rad/s at 20 kHz.
