# 3-Axis Gimbal: FOC Control, Cascaded Loops, Anti-Cogging, and Dual ICM-42688-P Fusion

## 0. Assumptions

I don't have the Job #34 spec sheet. This design is built around a typical high-performance gimbal configuration, and every assumption below is a named parameter in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 12N14P gimbal BLDC (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate (SPI, 24 MHz) |
| Current sensing | Inline or low-side shunts, sampled at the PWM center |
| Loop rates | Current/FOC: 20 kHz. Rate loop: 8 kHz (IMU ODR). Angle loop: 1 kHz |

**Bandwidth separation rule.** Each outer loop should be at least 4–10× slower than the loop inside it:

ω_c,i ≈ 2π·2000 rad/s → ω_c,ω ≈ 2π·150 rad/s → ω_c,θ ≈ 2π·30 rad/s
