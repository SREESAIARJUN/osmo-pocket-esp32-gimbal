**Architectural correction.** An H743 cannot sensibly run four sensorless FOC/6-step commutation loops while also running ArduPilot. The correct partition is:

- **H743:** runs ArduPilot and emits bidirectional DShot600.
- **Four ESC MCUs:** handle commutation and return eRPM telemetry.

The rest of this document assumes that partition.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.0045\ /^\circ\text{C}$$

At T_j = 150 °C, R_ds = 1.0 × 1.5625 ≈ **1.56 mΩ**. At T_j = 125 °C it is 1.45 mΩ.

Because R_ds rises with temperature and loss rises with R_ds, the solution must be found iteratively (§3.4). As a starting point, use **R_hot = 1.45 mΩ**.

### 1.2 Current path in 6-step complementary PWM

During one commutation sector (phase A driving to phase B, current I):

| Device | On fraction | Current |
|---|---|---|
| A-high | D | I |
| A-low (synchronous rectifier) | 1 − D (minus dead time) | I |
| B-low (return leg) | 1 | I |

At every instant, exactly **two FETs carry I**, independent of D:

$$P_{cond,ch} = 2 I^2 R_{hot}$$

The per-device split, averaged over six sectors, matters for hot-spot analysis. Each FET is active in 2 of 6 sectors as the PWM leg and 2 of 6 as the return leg:

$$P_{HS} = \tfrac{1}{3} I^2 R\, D, \qquad P_{LS} = \tfrac{1}{3} I^2 R (1-D) + \tfrac{1}{3} I^2 R$$

Most firmware alternates which side PWMs or uses a low-side return, so **low-side FETs run hotter**. The peak instantaneous per-device loss is I²R in the return-leg FET.

### 1.3 Copper and interconnect

| Element | Resistance |
|---|---|
| Phase pad to motor wire | ~0.15 mΩ |
| Bus planes, share per channel | ~0.10 mΩ |
| Shunt (if per channel) | 0.25 mΩ |
| **R_cu** | **≈ 0.25 mΩ without shunt, 0.5 mΩ with** |

Copper's temperature coefficient is 0.0039 /°C, so at 100 °C board temperature, R_cu ≈ 0.32 mΩ.

$$P_{cu} = I^2 R_{cu}$$

### 1.4 Numbers at 80 A

- P_cond = 2 × 6400 × 1.45e-3 = **18.6 W per channel**
- P_cu = 6400 × 0.32e-3 = **2.0 W per channel**
- Peak single-FET dissipation (return leg, instantaneous) = 6400 × 1.45e-3 = **9.3 W**
