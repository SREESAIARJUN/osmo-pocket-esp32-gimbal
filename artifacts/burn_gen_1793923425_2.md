## 0. Architecture Clarifications and Design Assumptions

**The STM32H743 is the flight controller, not the motor controller.** ArduPilot runs on the H743 and emits bi-directional DShot600. Each of the four channels on the 4-in-1 ESC is commutated by its own small MCU running AM32 or BLHeli_32. This document uses an STM32G071 running AM32. ArduPilot does not commutate motors, so the "48 kHz" figure refers to the ESC-side PWM frequency.

**This is a parametric model.** Because no MOSFET part number was specified, I use the representative parameter set below. Replace these values with your actual datasheet figures and re-run the equations. The structure of the model stays the same.

| Symbol | Meaning | Assumed value |
|---|---|---|
| V_bus | Bus voltage, 6S fully charged | 25.2 V (model also checked at 4S, 16.8 V) |
| I_ph | Burst phase current per channel | 80 A |
| f_sw | ESC PWM frequency | 48 kHz |
| R_ds,25 | MOSFET on-resistance @ 25 °C (40 V N-ch, PDFN 3.3×3.3) | 1.0 mΩ |
| α | Temperature coefficient of R_ds | 0.0045 /K |
| Q_g / Q_gd / Q_gs | Gate charges | 30 / 8 / 9 nC |
| Q_rr, Q_oss | Reverse-recovery and output charge @ 25 V | 30 nC, 40 nC |
| V_SD | Body-diode forward drop | 0.8 V |
| t_dt | Dead time | 100 ns |
| Gate driver | FD6288Q (3-phase, bootstrap) | ~1.5 A source / 1.8 A sink |
| Board | 20×20 mm (nano), 6-layer, 2 oz Cu, 1 MOSFET per switch (24 total) | — |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM | — |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha\,(T_j - 25)]$$

At T_j = 125 °C, R_ds = 1.0 mΩ × 1.45 = **1.45 mΩ**.

For better accuracy above 100 °C, you can use the power-law fit R_ds,25·(T_K/298)^2.3. It gives about 1.47 mΩ at 125 °C, so the linear model is adequate here.
