# STM32H743 AIO Nano Flight Controller with 4-in-1 ESC: Power-Stage Thermal Model, 48 kHz Switching Losses, and Bidirectional DShot600 Allocation

## 0. Scope, Assumptions, and a Feasibility Warning

I have no prior context for "Job #18", so this document works from stated assumptions. Every parameter below is a variable you can replace with your actual BOM values.

**Assumptions**

| Item | Assumed value |
|---|---|
| Form factor | 25.5 × 25.5 mm (20 × 20 mm M2 mounting), 8-layer, 2 oz copper on all layers |
| Battery | 6S LiPo: V<sub>max</sub> = 25.2 V, V<sub>nom</sub> = 22.2 V |
| Flight controller MCU | STM32H743VIT6 (LQFP100), 400 MHz, timer clock 200 MHz |
| ESC MCUs | 4 × AT32F421 running AM32 (supports bidirectional DShot and 48 kHz PWM) |
| Gate drivers | 4 × FD6288Q-class 3-phase drivers, V<sub>drv</sub> ≈ 10 V |
| MOSFETs | 24 × 40 V, 3.3 × 3.3 mm DFN (see parameters in §1) |
| Commutation | 6-step trapezoidal with complementary PWM (synchronous rectification) |

**The H743 does not drive the MOSFETs.** The ESC MCUs generate the 48 kHz PWM. The H743 only sends DShot600 commands and receives eRPM telemetry. Keep this partition. Running 24-gate commutation on the flight controller would wreck timing and DMA budgets.

**Feasibility warning.** As derived in §3, 80 A per motor on a nano-format board is a burst rating of roughly 1–2 seconds, not a continuous rating. Marketing figures for this class of board are usually adiabatic peaks. The model below quantifies that so the rating is defensible.
