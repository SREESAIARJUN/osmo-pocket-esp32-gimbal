# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I have no access to the Job #18 specification, so this design uses typical gimbal values. Every value below is a parameter in the code.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (GBM2804-class), 12N14P, so pole pairs p = 7, slots N_s = 12 |
| Electrical | R ≈ 5–12 Ω, L ≈ 1–3 mH, K_t ≈ 0.05–0.1 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701) on each axis |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM at 20 kHz, inline or low-side current sensing |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, placed symmetric about the camera center |
| Loop rates | Current 20 kHz · velocity 4 kHz · angle 1 kHz · IMU sampling 8 kHz · attitude fusion 1 kHz |

The bandwidth separation between loops should be at least 5–10×:

- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_θ ≈ 2π·20–30 Hz

## 1. Field-Oriented Control (Inner Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at startup by aligning the d-axis: apply V_d with θ_e = 0 and read the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 Current PI with decoupling and back-EMF feedforward

The control law is

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Choose the gains by pole-zero cancellation:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

This gives a closed-loop transfer function of $\frac{\omega_c}{s+\omega_c}$.

Discretize with backward Euler at T_s = 50 µs. Keep ω_c T_s ≲ 0.5 to stay robust to the one-sample PWM delay.

**Voltage-mode fallback.** Gimbal motors often have R ≈ 10 Ω, so current sensing is poor. In that case use:

$$v_q^* = R\,i_q^* + \omega_e\lambda_m$$

The code supports both modes.

### 1.6 Inverse Park and SVPWM

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Use min-max (zero-sequence) injection, which is equivalent to SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The voltage vector is limited to the inscribed circle, $|v_{dq}| \le V_{bus}/\sqrt3$, with d-axis priority.

### 1.7 Phase-delay compensation

Rotate θ_e by ω_e · 1.5 T_s to account for the sampling delay plus half the PWM period.
