# 3-Axis Gimbal Motor Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the original specification for Job #26, so this design rests on the assumptions below. Every assumption is a single constant in the code, so you can change it without restructuring anything.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A, MT6701 or similar) on each joint |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| MCU | Cortex-M4F/M7 or STM32G4 class, with a single-precision FPU |
| Loop rates | Current/FOC 20 kHz; velocity 4 kHz; angle 1 kHz; attitude 1 kHz |
| Bus | 12–16 V |

## 1. System Architecture

```
            ┌──────────── 1 kHz ────────────┐┌──── 4 kHz ────┐┌─────── 20 kHz ───────┐

          ▲  (IMU attitude)           ▲    (gyro rate)    ▲              ▲  decoupling
          │                           │                   │              │

   (lever-arm, AAF, adaptive notch,   │       (Fourier, LMS-learned)
    inverse-variance, fault detect) ──┘
```
