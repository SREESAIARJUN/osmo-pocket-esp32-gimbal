# Job #55: STM32H743 AIO Flight Controller with 4-in-1 ESC (80 A Burst)

## Design Package Rev A: Mathematical Models, DMA Allocation, Netlists, Thermal Budget

This package uses assumed component parameters. Every number below should be re-run against the actual MOSFET datasheet, PCB stack-up and measured gate waveforms before release.

### 0. Architecture and Assumptions

The H743 does not drive the MOSFETs. It sends bidirectional DShot600 to four ESC MCUs, which generate the 48 kHz PWM.

```
6S LiPo ──┬── Bulk/MLCC bank ── 4× [ESC MCU → 3-ph gate driver → 6× MOSFET] ── Motors 1-4
          └── 5V/10V BEC ── STM32H743 FC ── (DShot600 BIDIR ×4) ──┘
```

| Parameter | Assumed value |
|---|---|
| Bus voltage | 6S, V_bus,max = 25.2 V (design worst case) |
| ESC MCU | AT32F421 / STM32G071-class, AM32 firmware, f_sw = 48 kHz |
| Gate driver | FD6288Q-class, 3-phase, V_DRV = 12 V |
| MOSFET (per switch) | 40 V, R_DS(on) = 1.0 mΩ @25 °C, Q_g = 60 nC, Q_gd = 10 nC, Q_gs2 = 6 nC, Q_rr = 40 nC, V_SD = 0.8 V, R_g,int = 1 Ω, R_θJC = 1.2 K/W |
| Gate resistors | R_g,on = 10 Ω, R_g,off = 10 Ω (baseline; optimized in §2.6) |
| Dead time | t_d = 300 ns (baseline) |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM on the high side |
| Burst | 80 A per motor, all 4 motors at once, target 3 s |

> ⚠️ **Feasibility flag.** 4 × 80 A on a nano (20×20 or 25.5×25.5 mm) AIO is at or beyond the physical limit. Sections 3–4 show it is survivable only as a short burst. The continuous rating will be much lower.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1+\alpha(T_j-25)\right],\quad \alpha \approx 0.006\ /\mathrm{K}$$

At T_j = 125 °C: R_DS = 1.0 × 1.6 = **1.6 mΩ**.

### 1.2 Current path in 6-step commutation

At any instant, current flows through two devices in series:
- the PWM leg, which is either the high-side FET (fraction D) or the synchronous low-side FET (fraction 1−D);
- the static low-side FET of the return phase.

Because of synchronous rectification, the series path always has two channel resistances, independent of D (dead time is handled separately in §2.4):

$$P_{cond,motor} = 2\,I^2 R_{DS}(T_j) = 2(80)^2(1.6\ \mathrm{m\Omega}) = \mathbf{20.5\ W}$$

### 1.3 Per-device average

Each FET carries current for 1/3 of the electrical period:

$$P_{cond,FET} = \frac{I^2 R_{DS}}{3} = \frac{6400 \times 0.0016}{3} = \mathbf{3.41\ W}$$

### 1.4 Ripple correction

The phase-current ripple adds to the RMS current:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus}-E)\,D}{2 L_{ph}\,f_{sw}}$$

For a typical 5″-class motor (L_ph ≈ 15 µH line-to-line, D ≈ 0.9, E ≈ 18 V), ΔI_pp ≈ 4.5 A. The correction is <0.03 %, so it is negligible at 48 kHz.

## 2. Switching Loss Model at 48 kHz

### 2.1 V-I overlap (hard switching, HS PWM leg)
