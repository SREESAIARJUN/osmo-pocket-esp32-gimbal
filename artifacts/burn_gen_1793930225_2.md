# FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection for a 3-Axis Gimbal

I don't have the specification for Job #32, so the design below uses the parameters in §0. Every equation is written symbolically. Replace the constants in `GimbalConfig` with your measured values.

---

## 0. Assumptions

| Item | Value (replace with measured) |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (`p = 7` pole pairs, `Ns = 12` slots) |
| Phase params | `R = 5.6 Ω`, `L = 2.1 mH` (phase-to-neutral), `λ = Kt/(1.5·p)` |
| Torque constant | `Kt = 0.065 N·m/A` (amplitude-invariant Clarke) |
| Position sensor | 14-bit absolute magnetic encoder on each motor shaft |
| Current sensing | Low-side or inline shunts, synchronous to PWM center |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (every 5th PWM period) |
| Angle loop / attitude | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, 8 kHz ODR, ±2000 dps, ±16 g |
| IMU placement | Mirrored about the pitch axis: `r₂ = −r₁` (lever arms from the center of rotation) |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
