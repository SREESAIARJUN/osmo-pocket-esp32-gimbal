# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Architecture (Job #18)

## 0. Architecture Clarifications

These points affect the math, so they come first.

1. **The STM32H743 does not commutate the motors.** In an AIO design, the H743 runs ArduPilot as the flight controller. Each motor bridge is driven by a dedicated ESC MCU running AM32 or BLHeli_32, such as the AT32F421 or STM32G071, through a 3-phase gate driver. Bidirectional DShot is the link between the H743 and those ESC MCUs. The H743 decodes the eRPM telemetry; it never touches the FET gates.
2. **80 A burst on a 20×20 mm nano board is thermally infeasible for all four motors at once.** Section 3 quantifies this. My recommendation is to rate the design at 80 A burst per motor for ≤ 5 s with all four loaded, or ≥ 20 s with one motor loaded. That requires a 30.5×30.5 mm minimum footprint with 2 oz outer and 2 oz inner copper. Treat any "nano" 80 A rating as a marketing number unless it is backed by the transient analysis below.
3. **Assumed operating point:** 6S pack (V_bus = 25.2 V full charge), 48 kHz complementary PWM, 6-step trapezoidal commutation with synchronous rectification, 14-pole motors.

## 1. Conduction-Loss Model (80 A Burst)

### 1.1 Reference MOSFET parameters

These are generic values for a 40 V device in a 5×6 or 3.3×3.3 mm package. Substitute datasheet values for the actual part.

| Parameter | Symbol | Value |
|---|---|---|
| On-resistance at 25 °C, V_GS = 10 V | R_ds25 | 1.2 mΩ |
| Temperature coefficient | α | ≈ 0.0055 /K |
| Total gate charge | Q_g | 50 nC |
| Gate-drain (Miller) charge | Q_gd | 8 nC |
| Output capacitance at 25 V | C_oss | 1.2 nF |
| Reverse-recovery charge at 80 A | Q_rr | 60 nC |
| Body-diode forward voltage | V_f | 0.8 V |
| Thermal resistance, junction to case | R_θJC | 1.2 K/W |

### 1.2 Temperature-dependent on-resistance

```
R_ds(T_j) = R_ds25 · [1 + α (T_j − 25)]
At T_j = 100 °C:  R_ds = 1.2 mΩ × 1.41 ≈ 1.7 mΩ   (1.8 mΩ used below for margin)
```

### 1.3 Six-step conduction with synchronous rectification

During each 60° commutation sector, current I flows through two paths:

- **The PWM leg:** the high-side FET conducts for a fraction D of each period, and its complementary low-side FET conducts for the remaining (1 − D).
- **The return leg:** the low-side FET of the second active phase is on continuously.

```
P_cond,motor = I²R·D + I²R·(1−D) + I²R = 2·I²·R_ds        (independent of D, dead time neglected)
```

At I = 80 A and R_ds = 1.8 mΩ:

```
P_cond,motor = 2 × 6400 × 0.0018 = 23.0 W
```
