# STM32H743 AIO Nano FC + 4-in-1 ESC: Systems Architecture Package

**Scope:** Electro-thermal model at 80 A burst, 48 kHz switching loss model, ArduPilot bidirectional DShot600 timer/DMA plan, reference netlists.

## 0. Architecture and Assumptions

### 0.1 Architecture Clarification

The H743 runs **ArduPilot as the flight controller**. It does **not** commutate the motors directly. Each motor channel has a dedicated ESC MCU running AM32, which handles commutation, and receives a bidirectional DShot600 command from the H743. This is the only practical topology. The H743 cannot run 4× sensorless 6-step commutation alongside ArduPilot's scheduler.

```
VBAT(6S) ─┬─ Bulk caps ─┬─ 4× [ESC MCU → 3-ph gate driver → 6× N-MOSFET] → M1..M4
          │             └─ Shunt/INA → ADC (H743)
          └─ Buck 5V/3A ─ LDO 3.3V ─ STM32H743VIT6 (LQFP100)
                                      ├─ TIM3/TIM5 → DShot600 bidir → ESC MCUs
                                      ├─ SPI1: IMU (ICM-42688-P)
                                      ├─ I2C/SPI: Baro, OSD (AT7456E), Flash
                                      └─ UARTs: RC, GPS, VTX, Telem
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Six-Step Conduction Topology

In trapezoidal (6-step) commutation, at any instant **two phases** conduct, one high-side path and one low-side path. Each MOSFET position conducts for 1/3 of the electrical period.

With complementary (synchronous) PWM at duty *D*:
- The active high-side FET conducts for *D*.
- Its complementary low-side FET freewheels for *(1 − D)*.

So the current path *always* passes through two channel resistances.

### 1.2 Hot R_ds(on) (Iterative)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.0067/\mathrm{K} \Rightarrow R_{ds}(100^\circ C) = 1.5\ \mathrm{m\Omega}$$

### 1.3 Loss Per Motor

$$P_{cond,motor} = 2\, I_{pk}^2\, R_{ds}(T_j) = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

### 1.4 Loss Per MOSFET (Time-Averaged)

Each switch position carries current 1/3 of the electrical cycle. The high/low split depends on *D*, but the leg total is constant.

$$P_{cond,leg} = \tfrac{2}{3} I^2 R_{ds} = 6.4\ \mathrm{W},\qquad P_{cond,FET,avg} \approx 3.2\ \mathrm{W}$$

The worst-case asymmetry is the low-side FET at D → 0, which carries the full 6.4 W per leg.

### 1.5 Copper and Shunt Losses

Assume 0.3 mΩ per phase path (PCB copper plus pads) and a 0.25 mΩ shunt in the shared return.

$$P_{Cu,motor} = 2 \times 80^2 \times 0.3\ \mathrm{m\Omega} = 3.84\ \mathrm{W}$$

Copper loss is non-trivial. Use 2 oz outer layers plus stitched inner power planes, or it will rival the FETs.

## 2. Switching Loss Model at 48 kHz

Only **one leg hard-switches per PWM cycle**: the PWM-modulated leg. The other conducting leg is held statically on for the 60° sector.

### 2.1 V–I Overlap

$$P_{sw} = \tfrac12 V_{bus} I_{pk}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\mathrm{ns} \times 48\,\mathrm{kHz} = \mathbf{0.968\ W}$$

### 2.2 Dead-Time Body-Diode Conduction

$$P_{dt} = V_{SD}\, I_{pk}\, (2 t_{dead}) f_{sw} = 0.8 \times 80 \times 200\,\mathrm{ns} \times 48\,\mathrm{kHz} = 0.614\ \mathrm{W}$$

### 2.3 Reverse Recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 30\,\mathrm{nC}\times 25.2 \times 48\,\mathrm{kHz} = 0.036\ \mathrm{W}$$

### 2.4 Output Capacitance

$$P_{oss} = \tfrac12 C_{oss} V_{bus}^2 f_{sw} \times 2 = 1\,\mathrm{nF}\times 635 \times 48\,\mathrm{kHz} = 0.030\ \mathrm{W}$$

### 2.5 Gate Drive

This loss is dissipated in the driver and gate resistors, not in the FET.

$$P_{gate} = Q_g V_{gs} f_{sw} \times 2_{(\text{HS+LS switching})} = 40\,\mathrm{nC}\times10\times48\,\mathrm{kHz}\times2 = 0.038\ \mathrm{W}$$

### 2.6 Per-Motor Loss Budget at 80 A Burst

| Term | W |
|---|---|
| Conduction (FET) | 19.20 |
| Copper / shunt | 3.84 |
| Switching overlap | 0.97 |
| Dead-time diode | 0.61 |
| Q_rr + C_oss | 0.07 |
| Gate drive | 0.04 |
| **Total per motor** | **≈ 24.7 W** |
| **All 4 motors at burst** | **≈ 98.8 W** |

**Design insight:** Conduction dominates (~78%). Raising f_sw from 24 → 48 kHz costs only about 1.6 W per motor. Selecting 0.7 mΩ FETs saves about 5.8 W per motor. **Spend the BOM money on R_ds(on), not on slower switching.**

### 2.7 Efficiency at Burst

$$P_{out} \approx 4 \times 80 \times 25.2 \times \bar{D}$$

At D̄ = 0.9, P_out ≈ 7.26 kW, giving η ≈ 98.7%.
