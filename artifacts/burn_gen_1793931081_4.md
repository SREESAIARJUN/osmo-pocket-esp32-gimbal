# STM32H743 Nano AIO with 4-in-1 80 A ESC: Engineering Design Package (Job #23)

## 0. Architecture Correction and Assumptions

**The STM32H743 does not commutate the motors.** ArduPilot is flight-control firmware and has no BLDC commutation engine. The 48 kHz PWM, dead-time and back-EMF/zero-cross logic run on four dedicated ESC MCUs (AM32 on AT32F421 is assumed). The H743 generates bidirectional DShot600 and decodes eRPM telemetry.

```
6S Batt ─┬─> 4× [ESC MCU AT32F421 → FD6288Q driver → 6× N-FET bridge] → Motors 1–4
         │         ▲ DShot600 bidir (1 wire/motor)
         └─> 5V/3V3 BEC → STM32H743 (ArduPilot) ─┘
```

## 1. Conduction Loss Model

### 1.1 Current path
In 6-step trapezoidal commutation, two phases conduct at any instant. With synchronous rectification:
- During the on-time, the high-side FET of phase A and the low-side FET of phase B conduct.
- During the off-time, the low-side FET of phase A and the low-side FET of phase B conduct.

Therefore exactly two R_ds(on) are always in series with the phase current, independent of duty cycle D:

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{ds}(T_j) + I_{rms}^2 R_{Cu}$$

### 1.2 Temperature dependence

$$R_{ds}(T_j) = R_{25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.5 mΩ × 1.45 = **2.18 mΩ**.

### 1.3 Ripple contribution

$$\Delta I = \frac{V\,D(1-D)}{L\,f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}_{pp}\ (\text{worst case at } D=0.5)$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple term is negligible at this current.

### 1.4 Result

$$P_{cond,ch} = 2 \times 6404 \times 2.18\times10^{-3} = \mathbf{27.9\ W}$$

The copper term adds roughly 0.
