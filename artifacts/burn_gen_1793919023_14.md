## 0. Architecture Clarification and Assumptions

### 0.1 System partition

ArduPilot does not perform motor commutation. On every production 4-in-1 design, each motor channel has its own ESC MCU running commutation firmware. The STM32H743 runs ArduPilot and talks to the ESCs over DShot.

```
┌──────────────────────────── AIO Board ─────────────────────────────┐
│  STM32H743 (ArduPilot)  ──DShot600 BIDIR x4──►  4× ESC MCU (AM32)  │
│        │                                          │                │
│     IMU/Baro/OSD                          4× FD6288Q gate driver   │
│                                           4× 3-phase MOSFET bridge │
└────────────────────────────────────────────────────────────────────┘
```
