# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #6): System Architecture, Loss Model, Thermal Model, DShot DMA Allocation, and Netlists

## 0. Assumptions and Architectural Corrections

These points shape every number below.

1. **The H743 does not drive the MOSFETs.** ArduPilot has no FOC or 6-step motor-control path. The architecture is:
   - **STM32H743 (flight controller)**, which emits bidirectional DShot600.
   - **4× ESC MCUs** (AT32F421K8U7 or STM32G071KBU6 running AM32). Each one drives its own 3-phase bridge at 48 kHz.
   
   "48 kHz switching" therefore refers to the ESC MCU's PWM, not the H743.

2. **"80 A burst" on a nano (20×20 or 25.5×25.5 mm) board is a transient rating, not a continuous one.** Section 3 shows that four channels at 80 A will reach board limits in about 2–3 s. Treat the 80 A figure as a ≤1–2 s per-channel rating.

## 1. Conduction Loss Model (80 A burst)

### 1.1 Current paths in 6-step synchronous PWM

In any commutation sector, phase A is PWM'd and phase B is held low-side ON. With duty D and motor current I_m:

| Device | Conducts | Loss |
|---|---|---|
| Q_AH (high side, PWM) | fraction D | I_m² · R · D |
| Q_AL (sync rectifier) | fraction (1−D), minus dead time | I_m² · R · (1−D) |
| Q_BL (static low side) | 100 % | I_m² · R |

The D terms cancel:

$$P_{cond,ch} = 2\,I_m^2\,R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right],\ \alpha \approx 0.005\ \mathrm{K^{-1}}$$

Each FET is active for 1/3 of an electrical cycle. The electrical frequency is f_e = (poles/2)·RPM/60, roughly 3.5 kHz for 14 poles at 30k RPM. That is far faster than the die's thermal time constant (milliseconds), so the loss averages evenly across the six FETs:

$$\bar P_{cond,FET} = \tfrac{1}{6}P_{cond,ch} = \tfrac{1}{3} I_m^2 R_{DS(on)}$$

### 1.2 Shunt and copper

$$P_{shunt} = I_{bus,rms}^2 R_{sh}$$

The bus current through a low-side shunt is approximately I_bus ≈ D·I_m on average. Its RMS value is ≈ √D·I_m. As a worst case, take D → 1:

$$P_{shunt} \le I_m^2 R_{sh}$$
