# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the original specification for "Job #3", so the design below rests on stated assumptions. Every parameter is a `constexpr` or a config field, so you can swap in your real hardware values.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× hollow-shaft gimbal BLDC, 12N14P (GBM2804-class), pole pairs `p = 7`, R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701-class) over SPI |
| Current sensing | 2- or 3-shunt inline, 12-bit ADC sampled at PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G474 / H723) |
| Current loop (FOC) | 20 kHz, synchronous with PWM |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera payload, SPI at 24 MHz, ODR 8 kHz, data-ready interrupts |
| Disturbances | Propeller/motor vibration, roughly 80–400 Hz, plus frame resonances |
