# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #49 specification, so this design uses typical gimbal values. Change the constants in `GimbalConfig` to match the actual hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7 class with FPU, 3 timers in center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P. IMU-A is on the camera plate (the controlled body). IMU-B is on the same plate, rotated 180° about Z, on a separate SPI bus. |
| Loop rates | Current/FOC 20 kHz. Velocity 4 kHz. Angle 1 kHz. IMU ODR 8 kHz, decimated to 4 kHz. |
| Disturbance | Platform vibration (props/engine/wheels) at 60–400 Hz, possibly time-varying |

## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude-invariant, two shunts, $i_a+i_b+i_c=0$)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Motor model in the dq frame (SPM, $L_d=L_q=L$)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation. With current bandwidth $\omega_c$ (typically $2\pi\cdot 1.5$ kHz at 20 kHz PWM):
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop then becomes $\dfrac{i}{i^*}=\dfrac{\omega_c}{s+\omega_c}$.

Control law, discretized at $T_c = 1/f_{PWM}$:
$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e\lambda_m$$

### 1.6 Voltage limiting (circular, with q priority)
$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad m_{max}\approx0.95$$
$$|v_d^*|\le V_{max},\qquad |v_q^*| \le \sqrt{V_{max}^2 - v_d^{*2}}$$

### 1.7 Anti-windup (back-calculation)

Every PI in this design uses back-calculation:
$$x_I[k+1] = x_I[k] + K_i T\,e[k] + K_{aw}\,(u_{sat}[k]-u[k]),\qquad K_{aw}\approx \frac{K_i}{K_p}T$$

### 1.8 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max(v_{abc})+\min(v_{abc})),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and is branch-free.

### 1.9 Delay compensation

Total delay is about 1.5 $T_c$ (sample, compute, PWM update). Advance the angle used for inverse Park:
$$\theta_e^{inv} = \theta_e + 1.5\,\hat\omega_e T_c$$
