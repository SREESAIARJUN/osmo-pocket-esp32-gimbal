# STM32H743 AIO Nano FC with Integrated 80 A 4-in-1 ESC (Job #8): System Architecture, Loss Model, Thermal Model, DMA Plan and Netlists

## 0. Architecture Assumptions

The STM32H743 does not drive the MOSFET gates directly. In every production 4-in-1 design, each motor channel has its own ESC MCU (e.g. AT32F421 or STM32G071 running AM32/BLHeli_32), or a single small MCU runs all four channels. The H743 runs ArduPilot and talks to the ESC MCUs over bi-directional DShot600. I model it that way.

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V worst case | 22.2 V nominal |
| Burst rating | 80 A per motor-channel (phase current), ≤10 s | All 4 channels simultaneously = worst case |
| Commutation | 6-step trapezoidal, synchronous rectification, complementary PWM | AM32-style |
| f_sw | 48 kHz | |
