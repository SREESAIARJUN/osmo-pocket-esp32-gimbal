## 0. System Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (GBM2804-class), 12N14P, so pole pairs p = 7, R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) over SPI, sampled each PWM period |
| Current sense | 2-phase low-side shunts, synchronous ADC at PWM center |
| PWM | 20 kHz center-aligned. **Current loop runs at 20 kHz.** |
| Velocity loop | 4 kHz (every 5th PWM ISR) |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro and accel ODR 8 kHz, decimated to 4 kHz |
| IMU A | On the camera payload. Primary feedback. |
| IMU B | On the base/handle. Disturbance reference and feedforward. |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7-class) |

**Control architecture (per axis):**

```
 θ_ref ─►(Σ)─► Angle P/PD ─► ω_ref ─►(Σ)─► Velocity PI ─► i_q* ─►(Σ)─► FOC current PI ─► SVPWM ─► Motor
          ▲      1 kHz          ▲   +ω_ff   ▲    4 kHz        ▲ +i_cog(θm)   20 kHz
          │                     │           │                 │
     fused attitude        IMU-A gyro   notch+NLMS        anti-cogging
     (Mahony, dual IMU)    (rate fdbk)  vibration filt    Fourier table
```

The angle and rate loops close on the **payload IMU**, because that is what you want stabilized. The motor encoder is used only for commutation, cogging lookup, and the frame-to-joint mapping.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle: θe = p·(θm − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

**Park transform:**

```
i_d =  i_α cos θe + i_β sin θe
i_q = −i_α sin θe + i_β cos θe
```

**Inverse Park transform:**

```
v_α = v_d cos θe − v_q sin θe
v_β = v_d sin θe + v_q cos θe
```

### 1.2 Plant and Decoupling

```
v_d = R i_d + L di_d/dt − ωe L i_q
v_q = R i_q + L di_q/dt + ωe L i_d + ωe λ_m
```

Feedforward decoupling is added to the PI outputs:

```
v_d,ff = −ωe L i_q
v_q,ff =  ωe L i_d + ωe λ_m
```

Here λ_m = Kt / (1.5 p), with ωe = p·ωm.

### 1.3 PI Tuning by Pole-Zero Cancellation

Placing the PI zero on the plant pole R/L makes the closed loop first-order with bandwidth ωc:

```
Kp_i = L · ωc
Ki_i = R · ωc      (continuous form: C(s) = Kp + Ki/s)
```

Choose ωc ≤ 2π·f_pwm/20. At 20 kHz PWM, ωc = 2π·1000 rad/s, which gives Kp = 13.2 V/A and Ki = 35 186 V/(A·s).

**Discrete form** (backward Euler with back-calculation anti-windup):

```
e[k]     = i* − i
u_raw[k] = Kp e[k] + I[k−1] + v_ff
u[k]     = sat(u_raw[k])
I[k]     = I[k−1] + Ki Ts e[k] + Kaw (u[k] − u_raw[k]),   with Kaw = 1/Kp · Ki Ts ≈ Ts·ωc
```

**Voltage vector limit:**

1. Prioritize d: |v_d| ≤ V_max.
2. Then limit q: |v_q| ≤ √(V_max² − v_d²).
3. V_max = V_bus/√3 · m_max, with m_max = 0.95. This is the linear SVPWM region.

### 1.4 SVPWM by Min–Max Zero-Sequence Injection

This is equivalent to sector-based SVPWM and is cheaper to compute.

v_b = −½ v_α + (√3/2) v_β
v_c = −½ v_α − (√3/2) v_β
v_0 = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c)) / 2
D_x = ½ + (v_x + v_0) / V_bus,    x ∈ {a,b,c},
