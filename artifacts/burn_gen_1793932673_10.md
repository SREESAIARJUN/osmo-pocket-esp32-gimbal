## 1. Conduction Loss Model

### 1.1 Current paths in six-step synchronous commutation

In each 60° commutation sector (example: A+ PWM, B− on):

- **On-time (D):** current flows Q_AH → motor → Q_BL
- **Off-time (1−D):** current freewheels Q_AL (synchronous rectifier) → motor → Q_BL

At every instant, exactly two FETs carry the full phase current I. The duty cycle cancels out:

$$P_{cond,ch} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

### 1.2 Temperature dependence of R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha\,(T_j - 25)], \qquad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 110 °C:

$$R_{ds} = 1.5 \times (1 + 0.006 \times 85) = 2.27\ \text{mΩ}$$

### 1.3 Copper path resistance

Each channel's current path includes roughly 2 × 0.25 mΩ of pad, plane, and via resistance (phase pad plus bus path, at 2 oz with via farms):

$$P_{Cu,ch} = I^2 R_{Cu} = 6400 \times 0.5\ \text{mΩ} = 3.2\ \text{W}$$

### 1.4 Conduction result at 80 A

| Term | Expression | Value |
|---|---|---|
| FET conduction | 2 × 80² × 2.27 mΩ | **29.0 W** |
| Copper | 80² × 0.5 mΩ | 3.2 W |
| Hottest single FET | Q_BL (on for the full sector): 80² × 2.27 mΩ | **14.5 W** |

### 1.5 Self-consistent junction temperature (thermal runaway check)

Because loss rises with temperature, T_j and P must be solved together. Write P(T_j) = P₂₅[1 + α(T_j − 25)], where P₂₅ = 2I²R_ds,25 = 19.2 W, and T_j = T_ref + R_θ · P(T_j). The closed form is:

$$T_j = \frac{T_{ref} + R_\theta P_{25}(1 - 25\alpha)}{1 - \alpha R_\theta P_{25}}$$

A finite steady state exists only if:

$$\alpha\,R_\theta\,P_{25} < 1$$

Applying this per FET (P₂₅ = 9.6 W, α = 0.006):

$$R_{\theta,crit} = \frac{1}{0.006 \times 9.6} = 17.4\ \text{K/W}$$
