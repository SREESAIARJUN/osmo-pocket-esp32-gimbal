# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #48 specification, so the design uses typical gimbal parameters. Every value marked **[ASSUME]** lives in one `Config` struct in the code and should be replaced with your measured values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, λ_m = 0.012 V·s/rad **[ASSUME]** |
| Joint encoders | 14-bit absolute magnetic (AS5048A / MT6701 class) |
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474), center-aligned PWM |
| Bus voltage | V_dc = 12 V |
| Gimbal order | Yaw
