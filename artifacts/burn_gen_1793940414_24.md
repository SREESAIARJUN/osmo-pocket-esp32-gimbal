## 0. Assumptions and Architectural Ground Truth

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | Requires 40 V MOSFETs (≥1.5× margin) |
| Burst current | 80 A **per motor, phase-side**, ≤10 s | 4×80 A = 320 A from the battery, see §3.5 |
| Commutation | 6-step trapezoidal, complementary PWM (AM32/BLHeli_32-class firmware) | |
| PWM frequency | 48 kHz | |
| Board | 30.5×30.5 mm mount, 8-layer, 2 oz (70 µm) copper | A 20×20 "nano" board cannot carry 80 A burst; see §3.6 |
| FC MCU | STM32H743 at 400 MHz (ArduPilot default), timer clock 200 MHz | |
| FC→ESC link | Bi-directional DShot600, 4 lines | |

**Critical architectural point.** The STM32H743 does not generate the 48 kHz gate PWM. In every production 4-in-1 design, each motor has a dedicated ESC MCU (e.g., AT32F421 or STM32G071 running AM32) that handles commutation, PWM, and the eRPM telemetry reply. The H743 only sends and receives DShot frames. Having the H743 drive 24 gates directly would require 12 complementary advanced-timer channel pairs with dead time; it has only TIM1/TIM8 (2×3 pairs). That design is not viable, so this document does not use it.

## 2. Conduction Loss Model

### 2.1 Current waveform

In 6-step, at any instant one high-side and one low-side leg conduct. With complementary PWM at duty D:
- **PWM leg:** HS conducts for D, the synchronous LS of the same leg for (1−D).
- **Static leg:** LS conducts 100% of the sector.

The phase current is a trapezoid with PWM ripple:

$$
\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}} \quad\Rightarrow\quad I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}
$$

Example: a typical 5" motor has L_ph ≈ 15 µH (line-line 30 µH). At burst, D≈0.95 and V_bus−V_bemf≈4 V:

ΔI = 4·0.95/(30e-6·48e3) ≈ 2.6 A, so ΔI²/12 = 0.57 A², which is negligible against 6400 A². **48 kHz makes ripple loss irrelevant.** That is its main benefit.

### 2.2 Conduction power

$$
P_{cond} = I_{rms}^2\left[R_{DS}(T_j)\,D + R_{DS}(T_j)(1-D) + R_{DS}(T_j)\right] + I_{rms}^2 R_{Cu} + I_{dc}^2 R_{shunt}
$$

$$
P_{cond} = I_{rms}^2\,(2R_{DS}(T_j) + R_{Cu}) + I_{dc}^2 R_{shunt},\qquad R_{DS}(T_j) = R_{DS25}\left[1+\alpha(T_j-25)\right]
$$

Note that the expression is independent of D. Synchronous rectification makes the conduction path always two FETs.
