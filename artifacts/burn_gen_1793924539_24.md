## 0. Architecture and Assumptions

**The STM32H743 does not commutate the motors.** In every viable 4-in-1 design, each ESC channel has its own small MCU running AM32 or BLHeli_32. The H743 runs ArduPilot and sends DShot600 to those MCUs. Running the 48 kHz PWM in those ESC MCUs is the only way to get both 48 kHz switching and bidirectional DShot telemetry. The architecture is:

```
             ┌──────────────────── STM32H743 (ArduPilot) ───────────────────┐
             │ TIM1 CH1..CH4 ── bidir DShot600 (inverted, open-drain-ish)    │
             └───┬────────────┬────────────┬────────────┬───────────────────┘
                 │            │            │            │
          AT32F421 #1   AT32F421 #2   AT32F421 #3   AT32F421 #4   (AM32, 48 kHz PWM)
                 │            │            │            │
          FD6288Q drv   FD6288Q drv   FD6288Q drv   FD6288Q drv
                 │            │            │            │
          6× N-MOSFET   6× N-MOSFET   6× N-MOSFET   6× N-MOSFET
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.45) ≈ **1.45 mΩ**. Use **1.5 mΩ** for design margin.

### 1.2 Current path in 6-step with synchronous rectification

At any instant, exactly two FETs carry the phase current:

- **PWM on:** HS_A and LS_B conduct.
- **PWM off:** LS_A (synchronous rectification) and LS_B conduct.

Total conduction loss per ESC channel is therefore independent of duty cycle:

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j) = 2 \cdot 80^2 \cdot 1.5\text{ mΩ} = \mathbf{19.2\ W}$$
