# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #46 specification, so I've assumed the parameters below. Every value lives in a config struct, so you can substitute your own without touching the equations.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU, CORDIC optional |
| Motor | Gimbal BLDC (e.g. GBM2804), 12N14P → p = 7 pole pairs, R≈5 Ω, L≈2 mH (phase), Kt≈0.06 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701), per axis |
| Current sensing | 2-shunt or inline, ADC synced to PWM center |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz |
| Velocity loop | 4 kHz (÷5) |
| Angle loop | 1 kHz (÷20) |
| IMUs | 2× ICM-42688
