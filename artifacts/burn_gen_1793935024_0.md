# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage & DShot Architecture Package (Job #5)

## 0. Architecture Clarification and Assumptions

**The H743 does not commutate the motors.** In every production 4-in-1 design the bridge is driven by four dedicated ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32), one per motor. The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. The model below follows that partition. A single-MCU design that does both flight control and FOC on the H743 is a different and much harder project.

**Baseline parameters.** Every number below derives from these. Replace them with your actual BOM values.

**Reality check (stated up front).** 80 A per channel on all four channels simultaneously means about 320 A and 8 kW from the battery. That is a transient, adiabatic rating, not a thermal steady state. The rest of this package quantifies exactly how transient.

## 1. Conduction Loss Model

### 1.1 Commutation topology

Commutation is six-step trapezoidal with complementary (synchronous-rectified) PWM. At any instant, current in a channel flows through exactly **two conducting devices**:

- one device in the PWM leg (either the high-side FET or, during the off-time, the synchronous low-side FET), and
- one low-side FET in the static leg.

### 1.2 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C this gives R_ds = 1.5 mΩ × 1.6 = **2.4 mΩ**.

### 1.3 Channel conduction loss

With the PWM ripple ΔI_pp small relative to I (the usual case for motor inductances of 10–50 µH at 48 kHz):

$$P_{cond,ch} = 2\,I_{ph,rms}^2\,R_{ds}(T_j) \approx 2\,I^2 R_{ds}(T_j)$$

$$P_{cond,ch} = 2(80)^2(2.4\text{ m}\Omega) = \mathbf{30.7\ W\ per\ channel}$$

**Per-FET distribution.** Each of the six FETs carries current for 120° of each 360° electrical cycle, so the loss is shared:

- Average per FET: 30.7 / 6 ≈ **5.1 W**
- Instantaneous while conducting: I²R = **15.4 W**

That instantaneous 15.4 W lasts for one commutation sector. At 30 k eRPM a sector is about 330 µs, which is short compared with the die thermal time constant (τ_jc ≈ 1–5 ms). The junction therefore sees roughly the 5.1 W average plus a small ripple.

### 1.4 Board-level conduction loss

$$P_{cond,total} = 4 \times 30.7 = \mathbf{123\ W}$$

**Copper loss.** Add I²R in the copper. A 320 A battery bus through 2 oz pours at about 0.15 mΩ effective gives about **15 W**. Each phase pad and trace at about 0.1 mΩ adds 0.64 W, or about **2.6 W** for all four channels.

## 2. Switching Loss Model at 48 kHz

### 2.1 Loss terms per channel

Only one leg PWMs at a time, so there is one hard-switched high-side/low-side pair per channel.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = ½(25.2)(80)(20 ns)(48 k) | 0.97 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200 ns·48 k | 0.61 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 k | 0.06 W |
| C_oss | ½·Q_oss·V·f_sw | 0.02 W |
| Gate drive (dissipated in the driver/R_g, not the FET) | 2·Q_g·V_gs·f_sw = 2·40 nC·10·48 k | 0.04 W |
| **Total P_sw per channel** | | **≈ 1.7 W** |
| **Board total P_sw** | | **≈ 6.8 W** |

### 2.2 Interpretation

- At full-throttle burst, conduction loss is about 95 % of the total. Switching loss only matters at partial throttle and high V_bus.
- Raising f_sw from 24 kHz to 48 kHz roughly doubles P_sw. It is justified by lower current ripple and quieter low-inductance motors.
- Dead-time loss (0.61 W) is the largest *controllable* term. Reducing t_dt to about 50 ns saves about 0.3 W per channel, but only if the driver propagation-delay matching guarantees no shoot-through.
