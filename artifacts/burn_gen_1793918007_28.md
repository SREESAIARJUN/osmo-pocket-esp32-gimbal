# STM32H743 AIO (FC + 4-in-1 ESC): Engineering Model, Job #31

## 0. Architecture and Assumptions

A note on architecture first. The STM32H743 does not commutate the motors. In every production AIO, the H743 runs ArduPilot and sends bidirectional DShot600 to **four separate ESC MCUs** (AT32F421 / STM32G071 running AM32 or BLHeli_32). The **48 kHz PWM is an ESC-firmware parameter**, not an FC parameter. The model is partitioned accordingly.

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S, V_bus,max = 25.2 V | Worst case for switching loss |
| Burst current | 80 A **phase** RMS per motor | Battery current = D·I_phase |
| f_sw | 48 kHz, complementary (synchronous) PWM | AM32 "PWM freq" setting |
| MOSFET | 40 V, DFN5x6, R_DS(on) = 1.2 mΩ max @25 °C, Q_g = 50 nC, Q_gs2+Q_gd = 16 nC, Q_rr = 40 nC, V_SD = 0.8 V | Representative; replace with your datasheet values |
| Gate driver | 3-phase, 12 V V_CC, ~1 A effective source/sink at Miller plateau | e.g. FD6288Q class |
| Dead time | 300 ns per edge | Typical AM32 default region |
| Motor L (phase-phase) | 20 µH | 2306–2808 class |
| Board | 30.5×30.5 mm, 6-layer, 2 oz outer / 1 oz inner | A 20×20 "nano" changes the conclusion (§2.6) |

Every result below is parametric. Substitute your BOM values into the equations.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

```
R_DS(T_j) = R_DS25 · [1 + α(T_j − 25)],   α ≈ 0.0045 /K (Si trench, 40 V)
R_DS(125 °C) = 1.2 mΩ · 1.45 = 1.74 mΩ
```

### 1.2 Current path in 6-step trapezoidal commutation

At any instant, two phases carry current. With complementary PWM, the current always flows through **exactly two MOSFETs in series**:
- either the HS of the PWM leg and the LS of the return leg (during D),
- or the LS of the PWM leg and the LS of the return leg (during 1−D).

```
P_cond,motor = I_rms² · 2 · R_DS(T_j)
```

### 1.3 PWM ripple correction

```
ΔI_pp = V_bus · D(1−D) / (L · f_sw)
      = 25.2 · 0.25 / (20e-6 · 48e3)   = 6.56 A_pp   (worst case, D = 0.5)
I_ripple,rms = ΔI_pp / √12             = 1.89 A
I_rms,total  = √(80² + 1.89²)          = 80.02 A   → negligible (+0.06 %)
```

### 1.4 Result

```
P_cond,motor = 80² · 2 · 1.74e-3 = 22.3 W   (at T_j = 125 °C)
             = 80² · 2 · 1.20e-3 = 15.4 W   (at T_j = 25 °C)
```

Per-FET distribution over one electrical cycle:
- Each LS FET conducts for 120° as the return path, plus (1−D)·120° freewheeling.
- Each HS FET conducts for D·120°.
- At high throttle (D → 1), losses shift onto the HS devices. The design case is therefore D ≈ 0.95:

```
P_HS ≈ I²·R·(D/3)              ≈ 3.5 W
P_LS ≈ I²·R·(1/3 + (1−D)/3)    ≈ 3.9 W   (hottest device)
```

### 1.5 PCB copper loss (often forgotten)

Phase pad to motor wire is about 8 mm of 2 oz copper, 5 mm wide, on 2 layers:

```
R_Cu = ρL/A = 1.72e-8 · 0.008 / (2 · 0.005 · 70e-6) ≈ 0.20 mΩ
```
