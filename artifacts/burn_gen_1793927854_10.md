## 0. Scope, Architecture Correction, and Design Basis

The STM32H743 does not commutate the MOSFETs. In every production AIO and stacked 4-in-1 design, the H743 runs ArduPilot and emits DShot. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32, and that MCU generates the 48 kHz PWM. The model below is split along that boundary:

| Domain | Device | Responsibility |
|---|---|---|
| Flight control | STM32H743VIT6 (480 MHz, LQFP100) | ArduPilot, DShot600 TX, bidirectional eRPM RX, harmonic notch |
| Commutation ×4 | AT32F421K8U7 or STM32G071GBU6 | AM32, 48 kHz complementary PWM, BEMF zero-cross |
| Gate drive ×4 | FD6288Q-class 3-phase bootstrap driver (or a 60 V-rated equivalent for 6S margin) | High/low-side drive, dead time backup |
| Power stage ×4 | 6 × N-MOSFET per channel (24 total, or 48 if paralleled) | Bridge |

## 1. Conduction Loss Model

### 1.1 Current path in trapezoidal (6-step) synchronous commutation

At any instant one phase is PWM-driven complementarily (HS on for D, LS on for 1−D) and one phase's low side is held fully on. The phase current therefore always flows through exactly **two** MOSFET channels in series:

$$P_{cond,ch} = I_{ph}^2 \left[ D\,R_{HS} + (1-D)\,R_{LS} + R_{LS,static} \right] \approx 2\,I_{ph}^2\,R_{DS(on)}(T_j)$$

This approximation is valid when all FETs share the same part number. The result is **duty-independent**, which is a consequence of synchronous rectification.

### 1.2 Temperature dependence and the electrothermal fixed point

$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha_R (T_j - 25)]$$

$$T_j = T_{ref} + R_{\theta}\cdot 2 I^2 R_{25}[1+\alpha_R(T_j-25)]$$
