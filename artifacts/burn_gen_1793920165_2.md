# STM32H743 Nano AIO (FC + 4-in-1 ESC): Architecture, Loss Model, Thermal Model, and DShot DMA Plan

**Scope and assumptions.** No component datasheets were supplied, so every device parameter below is an assumption, marked **[A]**. All equations are parametric, so you can substitute real datasheet values. Values marked **[V]** must be verified against RM0433, DS12110 or the ArduPilot source before tape-out.

**Baseline.**
- Battery: 6S, V_bus = 25.2 V maximum.
- Ambient: T_a = 40 °C. Starting board temperature at hover: 45 °C.
- Form factor: 30.5 × 30.5 mm AIO board (25.5 mm nano variants scale the thermal mass down by about 30%).

**Key architectural point.** The H743 does **not** generate the 48 kHz inverter PWM. It sends bidirectional DShot600 to four ESC MCUs (for example AT32F421 running AM32). Those ESC MCUs generate the 48 kHz complementary PWM. The loss model therefore belongs to the ESC power stage, and the DMA model belongs to the H743.

## 1. System Block Architecture

```
VBAT (2–6S) ──┬── TVS + Bulk C ──► 4× [ESC MCU → 3-ph Gate Driver → 6× N-FET] ──► M1..M4
              │                         ▲ DShot600 bidir (1-wire, per motor)
              ├── Buck 10V (gate drive + VTX) │
              ├── Buck 5V ── LDO 3.3V ──► STM32H743VIT6 (480 MHz)
              └── Shunt (0.25 mΩ) → INA → ADC   ├─ SPI1: IMU (ICM-42688-P)
                                                ├─ SPI2: OSD (AT7456E)
                                                ├─ SPI3: Flash / SDMMC
                                                └─ I2C1: Baro (DPS310) / Mag
```

## 3. Conduction Loss Model (80 A burst)

The ESC uses complementary PWM with synchronous rectification.

- During t_on: HS(A) and LS(B) conduct.
- During t_off: LS(A) and LS(B) conduct.

Exactly **two FETs are in the current path at all times**, regardless of duty D. For trapezoidal (6-step) drive with phase current approximately equal to the DC-link equivalent I:

$$P_{cond,ch} = 2\, I^2\, R_{ds}(T_j)$$

FOC/sinusoidal drive gives a similar value: three phases, $I_{rms,ph} = I_{pk}/\sqrt{2}$, giving $P = 3 \cdot I_{rms}^2 R$.
