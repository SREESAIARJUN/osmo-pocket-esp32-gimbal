# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

> **Assumptions about Job #21.** I don't have your build documents, so the following are assumed. Each is a single constant to change.
> - **Motors:** outrunner BLDC gimbal motors, 12N14P (pole pairs p = 7, slots Nₛ = 12).
> - **Feedback:** 14-bit absolute magnetic encoders (AS5048A/MT6701 class).
> - **Current sensing:** in-line shunts. A voltage-mode fallback is given for drivers without shunts.
> - **IMUs:** two ICM-42688-P on the camera plate, each on its own SPI bus.
> - **MCU:** Cortex-M7 class (STM32H7) with single-precision FPU.
> - **Gimbal order:** yaw (outer) → roll → pitch (inner, camera).

## 1. Timing Architecture

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1.5 kHz |
| IMU sampling (both, ODR) | 8 kHz | 125 µs | — |
| IMU filtering + fusion | 8 kHz → decimated to 4 kHz | 250 µs | — |
| Rate (velocity) loop | 4 kHz | 250 µs | ω_v ≈ 2π·60–120 Hz |
| Angle loop + attitude | 1 kHz | 1 ms | ω_θ ≈ ω_v/4 … ω_v/6 |

**Separation rule.** Each outer loop's bandwidth must be at most 1/4 to 1/6 of the inner loop's. Total phase lag at the rate-loop crossover, including filter delay, must stay below about 35°. Section 5.6 shows how to budget this.

**Synchronisation.** Trigger the ADC from the PWM centre (TIM update at counter peak). Run the current ISR on ADC EOC. Use the ICM-42688-P **INT1 data-ready from IMU A** to clock the IMU/rate task. IMU B is read in the same ISR. Both IMUs are fed the same external `CLKIN` (pin 9, RTC mode) so their sample instants share one clock and do not drift relative to each other.
