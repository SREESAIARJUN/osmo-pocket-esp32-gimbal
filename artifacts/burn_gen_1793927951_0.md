## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$
θ₀ is the encoder offset. It is found by aligning the rotor with a d-axis voltage vector.

### 1.2 Clarke transform (amplitude-invariant)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{with } i_a+i_b+i_c=0)$$

### 1.3 Park transform
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (SPM motor, L_d = L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda_m)$$
$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Discrete PI with decoupling and back-calculation anti-windup
Pole-zero cancellation for a target current bandwidth ω_c (rad/s):
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$
Use ω_c ≤ 2π·f_PWM/10 (about 2π·2 kHz at 20 kHz).

For x ∈ {d, q}:
$$u_x[k] = K_{p,i}\,e_x[k] + I_x[k] + v_{x,\text{ff}}$$
$$v_{d,\text{ff}} = -\omega_e L i_q,\qquad v_{q,\text{ff}} = \omega_e(L i_d + \lambda_m)$$
$$\bar u_x = \text{sat}(u_x),\qquad I_x[k+1] = I_x[k] + K_{i,i}T_s e_x[k] + K_{aw}(\bar u_x - u_x)$$
A typical choice is K_aw = K_{i,i}T_s / K_{p,i}.

**Voltage-circle limit.** With V_max = V_dc/√3 (the linear SVPWM region), d-axis priority is applied:
$$v_d \leftarrow \text{clamp}(v_d, \pm V_{max}),\qquad v_q \leftarrow \text{clamp}\big(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\big)$$
