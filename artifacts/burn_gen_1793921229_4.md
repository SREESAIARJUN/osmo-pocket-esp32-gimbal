# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #32 spec sheet, so this design rests on the explicit assumptions below. Every parameter is isolated in one config struct so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (e.g. GBM2804-class), pole pairs p = 7 |
| Phase params | R ≈ 5.6 Ω (phase-phase 11.2), L ≈ 2.0 mH, Kt ≈ 0.07 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701-class), read every PWM cycle |
| MCU | Cortex-M4F/M7 with FPU, 3-shunt current sensing |
| IMU-A | ICM-42688-P on camera payload (attitude + rate feedback) |
| IMU-B | ICM-42688-P on gimbal base/handle (disturbance reference) |
| Rates | PWM/current 20 kHz, IMU 8 kHz, velocity 4 kHz, angle/attitude 1 kHz |

## 1. Loop Architecture and Timing

```
             1 kHz                    4 kHz                        20 kHz
θ_ref ─►[Angle P+I]─ω_ref─►(+)─►[Velocity PI]─i_q*─►(+)─►[FOC current PI]─►SVPWM─►Motor
            ▲          ▲ω_ff     ▲                    ▲ i_cog,ff     ▲
            │          │         │ω_meas              │              │ i_abc, θ_e
     q_payload     -ω_base·ê    (IMU-A gyro, filtered)  Cogging FF(θ_m)  encoder
     (Mahony)      (IMU-B)
```

**Bandwidth separation.** Each outer loop gets at most ~1/5–1/10 of the inner loop's bandwidth:

| Loop | Closed-loop bandwidth |
|---|---|
| Current | ω_c ≈ 2π·1500 rad/s (≈ f_pwm/13) |
| Velocity | ω_v ≈ 2π·60–120 Hz, limited by structural mode and gyro filter delay |
| Angle | ω_θ ≈ 2π·10–20 Hz |

**Delay budget** for the velocity loop's phase margin, at 100 Hz crossover:

| Source | Delay |
|---|---|
| IMU AAF (~1 kHz) group delay | ≈ 0.25 ms |
| SPI/sample | 0.125 ms |
| ZOH at 4 kHz | 0.125 ms |
| Notches | ≈ 0.1 ms off-center |
| **Total τ_d** | **≈ 0.6 ms** |

The resulting phase loss is φ = ω·τ_d = 2π·100·0.6e-3 ≈ 22°. Budget for this when choosing the velocity crossover.

## 2. Field-Oriented Control (Current Loop, 20 kHz)

### 2.1 Coordinate transforms

Electrical angle, where θ_off is calibrated by aligning to the d-axis at startup:

  θ_e = p·(θ_m − θ_off) mod 2π

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2 i_b)/√3

Park transform:

  i_d = i_α cos θ_e + i_β sin θ_e
  i_q = −i_α sin θ_e + i_β cos θ_e

Inverse Park:

  v_α = v_d cos θ_e − v_q sin θ_e
  v_β = v_d sin θ_e + v_q cos θ_e

### 2.2 Plant model in the dq frame

  v_d = R i_d + L di_d/dt − ω_e L i_q
  v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
  τ_e = (3/2) p λ_m i_q = K_t i_q,  where K_t = (3/2) p λ_m

### 2.3 PI current controller with decoupling

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

  K_p,i = L·ω_c
  K_i,i = R·ω_c   (continuous form: C(s) = K_p + K_i/s)

Decoupling and back-EMF feedforward:

  v_d* = PI_d(i_d* − i_d) − ω_e L i_q
  v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m

Set i_d* = 0 (surface PMSM; no field weakening is needed at gimbal speeds).

### 2.4 Voltage limiting and SVPWM

The linear modulation limit is |v| ≤ V_bus/√3. Apply circular limiting with q-axis priority:

  v_d ← clamp(v_d, ±V_max)
  v_q ← clamp(v_q, ±√(V_max² − v_d²))

SVPWM uses the min-max zero-sequence injection, which is equivalent to classic sector SVPWM:

  v_a = v_α
  v_b = −½v
