# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

## 0. Assumptions and Architecture

I don't have the Job #20 specification, so the design below rests on stated assumptions. Every parameter is a named constant, so the design adapts by changing values rather than equations.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A) on each axis |
| Gimbal order | Yaw (outer, base-fixed) → Roll → Pitch (inner, camera) |
| IMU A | ICM-42688-P on the camera payload. Used for stabilization feedback and attitude. |
| IMU B | ICM-42688-P on the handle/base. Used for disturbance feedforward, vibration-frequency reference, and fault cross-check. |
| PWM / current loop | 20 kHz center-aligned PWM, current loop at 20 kHz |
| Rate loop | 4 kHz (ICM ODR 8 kHz, decimated by 2) |
