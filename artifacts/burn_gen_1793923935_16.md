# STM32H743 Nano FC + 4-in-1 ESC (Job #36): System Architecture, Loss Model and Thermal Analysis

## 0. Architecture Clarifications and Design Risks

These points constrain everything that follows.

1. **Two separate processor domains.** The STM32H743 is the flight controller MCU running ArduPilot. It does not commutate motors. Each ESC channel uses its own small MCU (for example AT32F421 or STM32G071 running AM32/BLHeli_32), which drives a 3-phase gate driver. The H743 talks to the ESC MCUs over bi-directional DShot600. The 48 kHz figure is the ESC MCU's PWM frequency, not an H743 timer.
2. **80 A per motor is a burst rating, not a continuous one.** On a nano (20×20 or 26×26 mm) board, four simultaneous 80 A channels produce more than 130 W of heat. The math below shows this lasts only about 1–2 s before you hit the junction limit.
3. **Input current.** 4 × 80 A = 320 A battery current. No XT60 or XT90, and no nano-scale battery pad, survives this continuously. Battery leads, pads and the board's DC bus copper become first-order loss terms.
4. **Placeholder component values.** All MOSFET and driver values below are representative of a 40 V, 3.3×3.3 mm DFN class part. You must substitute the datasheet values of your chosen part. The equations are exact; the numbers are illustrative.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

R_ds(on)(T_j) = R_ds(on),25 · [1 + α (T_j − 25)], with α ≈ 0.005 /K

At T_j = 125 °C: R = 1.6 × 1.5 = **2.4 mΩ**

Because conduction loss raises T_j, which raises R_ds(on), the loss must be solved self-consistently:

T_j = T_case + R_θJC · I² · R_ds(on)(T_j)

This converges only if α · R_θJC · I² · R_25 < 1. At 80 A: 0.005 × 1.5 × 6400 × 1.6 mΩ = 0.077, so it is stable.

### 1.2 Six-Step (Trapezoidal) Commutation with Complementary PWM

In each 60° commutation sector:
- The high-side FET of the PWM'd leg conducts for duty D.
- Its complementary low-side FET (synchronous rectification) conducts for (1 − D).
- The low-side FET of the return leg conducts 100% of the time.

P_cond,ch = I²R·D + I²R·(1 − D) + I²R = **2 I² R_ds(on)(T_j)**

With ripple, replace I² with I_rms² = I_dc² + ΔI²/12, where ΔI = V_bus·D(1−D)/(L_ph·f_sw).

### 1.3 Numbers at 80 A, T_j = 125 °C

| Quantity | Value |
|---|---|
| Per conducting FET (instantaneous) | 6400 × 2.4 mΩ = **15.4 W** |
| Per channel | **30.7 W** |
| Four channels | **122.9 W** |

The worst-case device is the return-leg low-side FET. It carries 15.4 W for a full 60° sector and 0% in other sectors, so its average over an electrical revolution is about 1/3 of that. However, at low eRPM the sector time (milliseconds) exceeds the FET's thermal time constant. You must therefore design to the **15.4 W instantaneous** figure.

### 1.4 Copper and Shunt Losses

- **Phase copper:** For 2 oz copper on 4 layers in parallel, a 3 mm wide, 8 mm long path gives R ≈ 0.17 mΩ. Loss is I² · R_trace ≈ 1.1 W per phase path, and two phases carry current, so about 2.2 W per channel.
- **Current shunt:** A 0.25 mΩ shunt gives 80² × 0.25 m = 1.6 W during burst. It is commonly placed only on the DC bus return of the 4-in-1.
- **DC bus at 320 A:** A 0.1 mΩ bus loses 10 W. Use pads on all layers plus via stitching.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches in six-step, so there is one hard-switched commutation pair per channel.

### 2.1 V–I Overlap Loss

The gate current at the Miller plateau sets the switching times:

- **Turn-on (source):** I_g,on = (V_drv − V_pl)/(R_ext + R_int) = 7 / 5.7 = 1.23 A, so t_r = Q_sw / I_g,on = 6.5 ns
- **Turn-off (sink):** I_g,off = V_pl / 5.7 = 0.53 A, so t_f = 15.1 ns

P_VI = ½ · V_bus · I · (t_r + t_f) · f_sw = ½ × 25.2 × 80 × 21.6 ns × 48 kHz = **1.05 W**

Driver output impedance adds to R_ext. Measure the actual edges; layout inductance typically forces R_ext upward to control ringing.

### 2.2 Reverse Recovery Loss
