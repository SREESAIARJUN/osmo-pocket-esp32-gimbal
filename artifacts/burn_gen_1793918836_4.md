## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle comes from the mechanical encoder angle:

θ_e = p·(θ_m − θ_offset)  mod 2π

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b)/√3

Park transform:

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

Inverse Park:

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and PI design (pole-zero cancellation)

The motor electrical model is:

- v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
- v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + λ_m)

Use decoupling feed-forward:

- v_d,ff = −ω_e·L·i_q
- v_q,ff = ω_e·(L·i_d + λ_m)

Each axis then reduces to G(s) = 1/(L·s + R). Choose the PI controller C(s) = K_p + K_i/s with:

- K_p = L·ω_c
- K_i = R·ω_c

This cancels the electrical pole. The closed loop becomes ω_c/(s + ω_c), a first-order system with bandwidth ω_c.

The 1.5-sample PWM/compute delay limits the usable bandwidth:

ω_c ≤ 1/(10·T_s)

At 20 kHz this gives ω_c ≈ 2π·300 Hz to 2π·1.5 kHz.

### 1.3 Discretization and anti-windup

Use backward Euler with back-calculation anti-windup:

1. u_k = K_p·e_k + I_k + u_ff
2. u_sat = sat(u_k)
3. I_{k+1} = I_k + K_i·T_s·e_k + K_aw·(u_sat − u_k),  with K_aw ≈ K_i/K_p

### 1.4 Voltage limiting and SVPWM

Limit the dq voltage vector to |v| ≤ V_bus/√3, giving priority to v_d.

Min-max (equivalent to SVPWM) zero-sequence injection:

- v_a = v_α
- v_b = −½v_α + (√3/2)v_β
- v_c = −½v_α − (√3/2)v_β
- v_0 = −(max + min)/2
- duty_x = ½ + (v_x + v_0)/V_bus

## 2. Velocity and Angle Loops

### 2.1 Mechanical plant

J·ω̇ = K_t·i_q − B·ω − τ_cog(θ) − τ_dist

The torque constant is K_t = (3/2)·p·λ_m. With the current loop closed, it appears to the outer loop as approximately unity gain with a delay of ≈1/ω_c.

The velocity loop uses the fused gyro, not the differentiated encoder. Plant: G_v(s) = K_t/(J·s). The total loop delay is:
