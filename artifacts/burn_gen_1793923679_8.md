# STM32H743 Nano FC + 4-in-1 80A ESC: Reference Architecture (Job #28)

## 0. Scope and Assumptions

**Architecture.** The STM32H743 does not commutate the motors. It runs ArduPilot and sends bi-directional DShot600 to four dedicated ESC MCUs (AT32F421 running AM32), which drive the bridges at 48 kHz. This partitioning is the only sane way to put an FC and an 80A-class ESC on one stack. An H743 running FOC for four motors alongside ArduPilot's scheduler would be a different project.

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_J) = R_{DS,25}\,[1+\alpha(T_J-25)]$$

$$R_{DS}(110) = 0.90\,(1 + 0.006 \cdot 85) = 1.36\ \text{m}\Omega$$
