# STM32H743 Nano FC + 4-in-1 ESC: Design Package (Job #1)

**Scope:** Power-stage loss model (80 A burst, 48 kHz), thermal model, ArduPilot bidirectional DShot600 timer/DMA plan, and reference netlists.
**Status:** Engineering baseline. All component values are assumptions to verify against selected datasheets and bench data (Section 7).

---

## 0. Architecture Decisions and Assumptions

| Item | Decision | Rationale |
|---|---|---|
| Topology | H743 FC + 4× AT32F421 ESC MCUs running AM32 on the same PCB stack | The H743 should not commutate 4 motors directly. ArduPilot drives standard DShot, and AM32 provides bidirectional telemetry. |
| Battery | 6S LiPo, V_bus = 25.2 V max (22.2 V nominal) | |
| MOSFET | 40 V N-ch, PQFN 5×6 (e.g., BSC007N04LS6 class, ~0.7 mΩ typ @ 25 °C) | 3×3 parts cannot survive 80 A thermally. |
| Gate driver | FD6288Q-class 3-phase half-bridge driver, one per motor | Proven AM32 reference |
| Form factor | 30.5×30.5 mm mounting, ~37×37 mm outline, 8-layer, 2 oz inner / 3 oz outer power planes | A 20×20 "nano" cannot carry 80 A. See Section 3.5. |
| 80 A definition | **Phase (motor) current per ESC channel**, burst | Battery current = I_phase × duty |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal | AM32 default behavior |

> **Key finding up front:** The 80 A rating is a **≤2–3 s burst rating only**. The continuous rating on this footprint with prop-wash cooling is about **30–35 A per motor**. Derivation follows.

## 1. Conduction Loss Model

### 1.1 Parameters

| Symbol | Value | Notes |
|---|---|---|
| R_DS(on),25 | 0.75 mΩ | Typical @ V_GS = 10 V |
| α | 0.006 /K | R_DS(on) temperature coefficient (≈1.5× at 110 °C) |
| R_pcb | 0.35 mΩ | Per conduction path (pads, vias, phase pad) |
| I_ph | 80 A | Burst |
| r | 0.2 | Peak-to-peak ripple / I_ph |

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 110 °C: R_DS = 0.75 × 1.51 = **1.13 mΩ**

### 1.3 RMS current with ripple

$$I_{rms} = I_{ph}\sqrt{1+\frac{r^2}{12}} = 80 \times 1.00167 = 80.13\ \text{A}$$

### 1.4 Per-motor conduction loss

With 6-step commutation and synchronous rectification, two FETs are always in the current path (one per active phase leg). Each FET conducts one third of the electrical period on average.

$$P_{cond,motor} = I_{rms}^2\,(2R_{DS}(T_j) + R_{pcb})$$

$$= 80.13^2 \times (2 \times 1.13 + 0.35)\,\text{m}\Omega = 6421 \times 2.61\times10^{-3} = \mathbf{16.8\ W}$$

- FET share: 14.5 W
- Copper share: 2.25 W

Per FET, time-averaged: 14.5 / 6 ≈ **2.4 W**. While a FET is in its conduction window, it dissipates 7.3 W instantaneous (matters for Z_th, Section 3.3).

### 1.5 Electrothermal stability criterion

Loss rises with temperature, so the loop must have gain below 1:

$$\frac{\partial P}{\partial T_j}\,R_{th,ja} < 1, \qquad \frac{\partial P}{\partial T_j}\Big|_{FET} = I_{rms}^2 \cdot \frac{2}{6} \cdot R_{DS,25}\,\alpha = 6421 \times 0.333 \times 0.75\text{m} \times 0.006 = 9.6\ \text{mW/K}$$

With an effective R_th,ja of about 12 K/W per FET on this board, the loop gain is 0.12. **Stable.** Runaway would require R_th,ja > 100 K/W, which only happens with a delaminated pad or a void-heavy solder joint. This is why X-ray void inspection (<25 % voiding) is mandatory.

## 2. Switching Loss Model (f_sw = 48 kHz)

In 6-step mode, only **one leg per motor** is PWM-switched at a time; the other active leg is static. Losses are therefore computed per motor as one switching half-bridge.

### 2.1 Parameters

| Symbol | Value |
|---|---|
| V_bus | 25.2 V (worst case) |
| t_r, t_f | 20 ns each (R_G = 4.7 Ω, ~1 A plateau drive) |
| t_dead | 100 ns per edge |
| V_SD | 0.8 V body diode @ 80 A |
| Q_rr | 50 nC |
| Q_oss | 40 nC (E_oss ≈ ½·Q_oss·V) |
| Q_g | 50 nC @ 10 V |

### 2.2 V–I overlap

$$P_{VI} = \tfrac{1}{2}V_{bus}I_{ph}(t_r+t_f)f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = \mathbf{1.94\ W}$$

### 2.3 Dead-time body-diode conduction

$$P_{DT} = V_{SD}\,I_{ph}\,(2t_{dead})\,f_{sw} = 0.8 \times 80 \times 200\text{ns} \times 48\text{k} = \mathbf{0.61\ W}$$

### 2.4 Reverse recovery

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.06\ W}$$

### 2.5 Output capacitance (both FETs in the leg)

$$P_{oss} \approx Q_{oss}V_{bus}f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.05\ W}$$
