# STM32H743 Nano FC + 4-in-1 80A ESC: Architecture, Loss Model, DShot DMA Plan, and Reference Netlist

## 0. Architecture Decisions and Caveats

**1. The H743 cannot commutate the motors under ArduPilot.**
ArduPilot has no on-FC BLDC/FOC commutation. The architecture must therefore be:

- **H743 (ArduPilot)** sends bidirectional DShot600 to **4× ESC MCUs** (e.g., STM32G071GBU6 running AM32).
- Each ESC MCU drives a **3-phase gate driver** and **6× MOSFETs**.

The 48 kHz PWM is generated by the ESC MCUs, not the H743.

**2. "80A on a nano board" is only valid as a time-limited burst.**
The thermal model below shows roughly 107 W total dissipation at 4×80 A. With no heatsink, that gives about 2–3 s of thermal headroom. "80A continuous" must not appear on a datasheet for this form factor.

**3. Component parameters are representative, not vendor-verified.**
The MOSFET values below describe a 40 V, ~1.2 mΩ PQFN class device. Re-run every equation with the chosen part's datasheet values at the actual V_GS and T_j. The netlist is a reference topology. It is not fab-ready and must go through ERC/DRC and SI review.

## 2. Conduction Loss Model

### 2.1 Per-device RMS current

In 6-step commutation, each leg is active for 240° of the electrical cycle: 120° sourcing and 120° sinking.

- **Sourcing interval (1/3 of the cycle):**
  - The high-side FET (HS) conducts for fraction D of each PWM period.
  - The low-side FET (LS) conducts the remaining 1−D, as a synchronous rectifier.
- **Sinking interval (1/3 of the cycle):** LS is fully on.

This gives:

$$I_{HS,rms}^2 = \frac{D}{3}I^2 \qquad I_{LS,rms}^2 = \frac{(1-D)+1}{3}I^2$$

### 2.2 Per-channel conduction loss

$$P_{leg} = I^2R_{hot}\left[\frac{D}{3}+\frac{2-D}{3}\right] = \frac{2}{3}I^2R_{hot}$$

$$P_{cond,ch} = 3\cdot P_{leg} = 2\,I^2R_{hot}$$

This result is independent of D. Physically, two FETs are always in the current path.

With R_hot = 1.2 mΩ × 1.6 = 1.92 mΩ:

$$P_{cond,ch} = 2(80)^2(1.92\times10^{-3}) = \mathbf{24.6\ W}$$

### 2.3 Hottest single device

The hottest device is the low-side FET at low duty (D → 0):

$$P_{LS,max} = \tfrac{2}{3}(6400)(1.92\text{m}) = \mathbf{8.2\ W}$$

### 2.4 Copper loss

Assume R_cu ≈ 0.3 mΩ per current path (motor pad, plane, vias) on 2 oz copper:

$$P_{Cu} \approx 2\,I^2R_{cu}\cdot\tfrac{?}{}\approx 2(6400)(0.3\text{m}) \approx \mathbf{3.8\ W/ch}$$
