# STM32H743 AIO / 4-in-1 ESC: Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Plan

**Engineering Design Note, Job #38, Rev A (preliminary)**

## 0. Assumptions and Corrections

These are stated first because they change the conclusions.

1. **The H743 does not run the motors.** On an AIO, the STM32H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel is commutated by its own ESC MCU (typically AT32F421 or STM32G071 running AM32 or BLHeli_32). The 48 kHz switching frequency is an **ESC firmware parameter**, not an H743 timer setting. The two halves of this note therefore have separate boundaries.
2. **No BOM was supplied.** Losses are computed parametrically. The worked numbers use a representative 40 V, 5×6 mm (PQFN) MOSFET. Substitute your datasheet values into the equations.
3. **80 A burst on a nano-format AIO is a burst rating only.** The math below shows it is thermally sustainable for seconds, not continuously. Treat any "80 A" marketing figure accordingly.

## 1. Conduction Loss Model

**Topology.** The bridge uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At any instant the current path contains one high-side or synchronous low-side FET in the PWM'd leg, plus one low-side FET in the return leg. So two R_ds(on) are always in series:

$$P_{cond,ESC} = I_{rms}^2 \cdot \left(2\,k_T\,R_{ds(on),25} + R_{cu}\right)$$

In the trapezoidal flat-top region, I_rms ≈ I_pk = 80 A.

| Term | Calculation | Result |
|---|---|---|
| FET conduction | 80² × 2 × 1.05 mΩ | **13.44 W** |
| PCB copper | 80² × 0.5 mΩ | **3.20 W** |
| **Per ESC** | | **16.6 W** |

**Per-FET share.** Each FET conducts about one third of the electrical cycle (120° of 360°):

$$P_{FET} \approx \frac{13.44}{6} \approx 2.24\ \text{W average, } 6.7\ \text{W instantaneous while conducting}$$

**Temperature feedback.** R_ds(on) rises roughly 0.4–0.5 %/K. For a self-consistent solution, iterate:

$$R(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \qquad T_j = T_a + P(T_j)\,Z_{th}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches hard. Its two FETs share one turn-on and one turn-off per PWM period.

**(a) V–I overlap, hard switching:**
$$P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{ns} \times 48\text{k} = \mathbf{0.968\ W}$$

**(b) Output capacitance:**
$$P_{oss} = \tfrac12 C_{oss(er)} V^2 f = 0.5 \times 1.5\text{n} \times 635 \times 48\text{k} = \mathbf{0.023\ W}$$

**(c) Reverse recovery:**
$$P_{rr} = Q_{rr} V f = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.048\ W}$$

**(d) Dead-time body-diode conduction:**
$$P_{dt} = V_f \cdot I \cdot 2t_{dt} \cdot f = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = \mathbf{0.614\ W}$$

**(e) Gate drive** (two switching FETs; this loss lands mostly in the driver and R_g, not the FET):
$$P_g = 2 Q_g V_{gs} f = 2 \times 60\text{n} \times 10 \times 48\text{k} = \mathbf{0.058\ W}$$

### Switching Summary

| Component | W per ESC |
|---|---|
| Overlap | 0.968 |
| C_oss | 0.023 |
| Q_rr | 0.048 |
| Dead time | 0.614 |
| Gate (driver) | 0.058 |
| **Total switching** | **≈ 1.71** |

**Interpretation.** At 80 A, conduction dominates by about 10:1. Moving from 24 kHz to 48 kHz costs only about 0.85 W per ESC. Dead time is the second-largest switching term, so trim t_dt in firmware to the minimum safe value.

## 3. Total Burst Dissipation and Thermal Model

| Scenario | P_ESC | Board total (4×) |
|---|---|---|
| 80 A burst, all four motors | 16.6 + 1.7 = **18.3 W** | **73 W** |
| 40 A sustained | 4.15 + 0.8 + 0.85 ≈ 5.8 W | 23 W |
| 20 A hover | ≈ 1.8 W | 7 W |

### 3.1 Adiabatic Board Heating (Lumped Model)

For a 30.5 mm-class board, 6–8 layers, 2 oz outer copper, with FETs and connectors, estimated mass is about 6 g. With an effective specific heat of about 0.75 J/(g·K):

$$C_{th} \approx 4.5\ \text{J/K}, \qquad \frac{dT}{dt}\Big|_{burst} = \frac{73}{4.5} \approx \mathbf{16\ K/s}$$

### 3.2 Steady-State Board Sink

Assume R_th,board-amb ≈ 3 K/W with strong prop-wash and ≈ 8 K/W in still air. The thermal time constant is then:

$$\tau = R_{th} C_{th} \approx 3 \times 4.5 \approx 13.5\ \text{s}$$

$$\Delta T_{board}(t) = P\,R_{th}\,(1 - e^{-t/\tau})$$

| Burst duration | ΔT_board (73 W, 3 K/W) |
|---|---|
| 1 s | 15.6 K |
| 3 s | 43.6 K |
| 5 s | 68.4 K |
| ∞ | 219 K → **destructive** |

### 3.3 Junction Rise per FET

Use the instantaneous 6.7 W from Section 1 and Z_th,j-pcb ≈ 1.5 K/W, which applies at a few ms to tens of ms:

$$T_j = T_a + \Delta T_{board}(t) + P_{FET} Z_{th,j\text{-}pcb}$$

At T_a = 35 °C and t = 3 s: T_j ≈ 35 + 43.6 + 10 ≈ **89 °C**. That is acceptable.

At t = 5 s: T_j ≈ **114 °C**. This approaches derating, and the R_ds(on) feedback of about +10 % pushes it higher.

### 3.4 Rating Conclusion

- **80 A burst:** ≤ 3 s, with airflow, at ≥ 10 s spacing.
- **Continuous:** approximately 35–40 A per channel on this form factor.

**Required mitigations:**
- Enforce an ESC-firmware temperature limit (AM32 `temperature_limit`).
- Set ArduPilot `MOT_BAT_CURR_MAX` / `BATT_*` current limits.
- Mount an NTC per FET bank.

## 4. Bidirectional DShot600 on the H743 (ArduPilot)

### 4.1 Protocol Timing

| Item | Value |
|---|---|
| Bit time | 1/600 kHz = 1.667 µs |
| Command frame (16 bit) | 26.7 µs |
| T0H / T1H duty | 37.5 % / 75 % |
| Turnaround before ESC reply | ~30 µs |
| Telemetry reply | 21 bits GCR at 5/4 × 600 kbit/s (750 kbit/s) → 1.33 µs/bit → 28 µs |
| Full cycle | ≈ 85 µs, well inside the 400 Hz–2 kHz loop rate |

The line is idle-high and inverted for bidirectional mode, so pull-ups are required.

**Timer clock.** The H743 at 400 MHz runs APB1/APB2 timer clocks at 200 MHz:

$$\text{ARR} = \frac{200\ \text{MHz}}{(PSC+1)\cdot 600\ \text{kHz}}$$

ArduPilot selects PSC automatically for integer bit periods. With PSC = 0, ARR ≈ 333, so a "0" bit is CCR ≈ 125 and a "1" bit is CCR ≈ 250.
