## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = N_{pp}\,(\theta_m - \theta_{off}) \bmod 2\pi,\qquad N_{pp} = 7$$

The offset θ_off is found at startup by applying a fixed d-axis voltage vector and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, two shunts)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque relation:

$$\tau = \tfrac32 N_{pp}\lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

$$v_d^* = K_{p,i}\,e_d + K_{i,i}\!\int e_d\,dt - \omega_e L\, i_q$$
$$v_q^* = K_{p,i}\,e_q + K_{i,i}\!\int e_q\,dt + \omega_e L\, i_d + \omega_e \lambda_m$$

Gains are chosen by pole-zero cancellation for a target current bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}$$

With f_PWM = 20 kHz, use ω_c ≈ 2π·1.5 kHz. The closed loop is then approximately

$$\frac{i_q}{i_q^*} \approx \frac{\omega_c}{s + \omega_c}$$

### 1.6 Voltage limiting (circular, q-axis priority)

$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max} \approx 0.95$$
$$v_d \leftarrow \operatorname{sat}(v_d,\pm V_{max}),\qquad v_q \leftarrow \operatorname{sat}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

The PI integrators use back-calculation anti-windup:

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u)$$

### 1.7 Inverse Park transform and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM.
