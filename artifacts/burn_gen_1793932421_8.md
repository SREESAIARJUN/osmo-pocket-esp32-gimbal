# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the spec for "Job #0", so the design below rests on explicit assumptions (§0). Every numeric parameter is a named constant, so you can substitute your hardware values.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC). The code is portable C++17. |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–4 mH, low-Kv |
| Encoder | 14-bit absolute magnetic (AS5048A or MT6701), one per joint |
| Driver | 3-phase, low-side shunts, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, gyro ±2000 dps, accel ±16 g |
| Gimbal kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

**Loop rates (time-scale separation of 4–5× minimum):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current / FOC | 20 kHz (ADC-triggered ISR) | ~1.5 kHz |
| IMU filtering | 8 kHz (data-ready / FIFO) | — |
| Velocity | 4 kHz | ~150–250 Hz |
| Angle / attitude | 1 kHz | ~20–40 Hz |
