## 2. Field-Oriented Control Equations

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, balanced three-phase so i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with θ_e the electrical angle:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The **inverse Park transform** is the transpose of this matrix.

**Electrical angle with delay compensation.** The computed voltage is applied about 1.5 Ts after the current sample (one Ts for computation, half a Ts for the PWM zero-order hold). The forward transform uses the measured angle; the inverse transform uses an advanced angle:

$$\theta_e = p\,(\theta_m - \theta_{off}),\qquad \theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s$$

Here p is the number of pole pairs and θ_off is the encoder offset.

### 2.2 Motor Model (Surface PMSM, Gimbal Motor L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau_e = \tfrac32 p\lambda\, i_q = K_t i_q$$

### 2.3 Current PI Controllers (Pole-Zero Cancellation)

$$G_i(s) = \frac{1}{Ls+R}$$

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$
