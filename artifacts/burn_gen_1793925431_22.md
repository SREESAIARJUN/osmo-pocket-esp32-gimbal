# STM32H743 Nano FC + 4-in-1 80 A ESC: Thermal, Switching, and DShot Design Package (Job #3)

## 0. Scope, Assumptions, and Red Flags

**Architecture.** The STM32H743 does not drive gates directly. The topology is:

`H743 (ArduPilot FC) → 4× bidirectional DShot600 → 4-in-1 ESC (4× AM32/BLHeli_32-class MCUs) → 4× three-phase gate drivers → 24 MOSFETs`

**Placeholder parameters.** No MOSFET was specified, so I use a representative 40 V shielded-gate PDFN3.3×3.3 FET. Replace these values with the actual datasheet numbers.

| Parameter | Symbol | Value |
|---|---|---|
| Rds(on) @25 °C, Vgs=10 V | R₂₅ | 1.5 mΩ |
| Rds(on) temperature factor @125 °C | k_T | 1.6 |
| Total gate charge | Q_g | 30 nC |
| Q_gs2 + Q_gd (switching charge) | Q_sw | 7 nC |
| Reverse recovery | Q_rr | 40 nC |
| Body diode Vf @80 A | V_f | 0.8 V |
| Junction–case (bottom pad) | R_θJC | 1.2 K/W |

| PWM frequency | f_sw | 48 kHz |

**Red flags to resolve before layout:**
1. **80 A per channel × 4 on a "nano" board is a burst-only rating.** Section 3 shows roughly 130 W of dissipation for all four channels at 80 A. A 20×20 board cannot sustain this for more than about 1–2 s. Define "burst" contractually (e.g., 80 A for 2 s, 10 % duty).
2. **Do not use a shared current-sense shunt at 320 A.** A 0.25 mΩ shunt dissipates 320² × 0.25 mΩ = 25.6 W. Use per-channel shunts or a Hall-effect sensor.
3. **The pin and DMA mapping must be validated** against the actual package (LQFP100 vs. TFBGA) and the current ArduPilot hwdef conventions.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-corrected resistance

$$R_{ds}(T_j)=R_{25}\,[1+\alpha(T_j-25)],\qquad k_T=1.6 \Rightarrow R_{hot}=2.4\,\text{m}\Omega$$

$$I^2R_{hot}=80^2\times0.0024=15.36\ \text{W (one conducting device)}$$

### 1.2 Six-step trapezoidal drive with complementary (synchronous) PWM

In each 60° sector, two phases conduct:
- **Source leg:** the high-side (HS) device conducts for D, and the low-side (LS) synchronous rectifier conducts for 1 − D.
- **Sink leg:** the LS device conducts 100 %.

$$P_{cond,sector}= I^2R\,[D+(1-D)] + I^2R = 2I^2R = 30.7\ \text{W per channel}$$

### 1.3 Per-device average

Each leg sources for 1/3 of the electrical cycle and sinks for 1/3.

$$P_{HS}=\tfrac13 D\,I^2R,\qquad P_{LS}=\tfrac13(1-D)I^2R+\tfrac13 I^2R$$

The worst case is the LS device at D → 0, where it conducts 2/3 of the cycle:

$$P_{LS,max}=\tfrac23(15.36)=10.2\ \text{W}$$

The HS device at full throttle (D ≈ 1) carries 5.1 W.

**Design consequence:** LS FETs run hotter at partial throttle under high current, for example in punch-outs where the ESC is current-limited. Give the LS devices equal or better copper than the HS devices.

### 1.4 Parasitic conduction (often forgotten)

| Path | Typical R | P @80 A |
|---|---|---|
| Per-phase copper (2 oz, ~15 mm) | 0.3 mΩ | 1.9 W (×2 conducting) |
| Motor pad/solder joint | 0.1 mΩ | 0.64 W |
| Per-channel shunt (0.5 mΩ) | 0.5 mΩ | 3.2 W |

Copper parasitics add roughly 5–8 W per channel. Use 3–4 oz inner layers or split planes.

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing (source) leg switches hard at any instant.

### 2.1 Transition times from gate charge

$$I_{g,on}=\frac{V_{drv}-V_{plateau}}{R_{g,ext}+R_{g,int}}=\frac{10-3.5}{4.7+1.0}=1.14\,\text{A}$$

$$t_r\approx\frac{Q_{sw}}{I_{g,on}}=6.1\ \text{ns}\ \text{(ideal)}$$

Common-source inductance and layout parasitics stretch this in practice. I use the empirically realistic values t_r = 20 ns and t_f = 15 ns.
