# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #48)

I don't have the Job #48 hardware specification, so this design is parameterised. Every assumption is collected in §0 and in `GimbalConfig`. Replace the placeholders with measured values (§7) before closing any loop on hardware.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (e.g. AS5048/MT6701) |
| IMUs | 2× ICM-42688-P on SPI at 24 MHz. **IMU-P** on the camera plate, **IMU-B** on the base/handle |
| Joint order | Yaw (base) → Roll → Pitch (camera) |
| MCU | Cortex-M4F/M7 with FPU, center-aligned PWM at 20 kHz |

### Rate hierarchy (bandwidth separation of at least 4× per stage)

```
 20 kHz  ISR  : ADC → Clarke/Park → id/iq PI → SVPWM       (ωc ≈ 2π·1500 rad/s)
                encoder PLL, cogging feedforward lookup
  4 kHz  task : IMU FIFO read (ODR 8 kHz, 2 samples/tick) → filters → rate loop  (ωv ≈ 2π·150)
  1 kHz  task : AHRS update → attitude (angle) loop → rate setpoints            (ωθ ≈ 2π·30)
```
