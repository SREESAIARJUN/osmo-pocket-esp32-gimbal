# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original Job #7 specification. The design below therefore rests on the assumptions in §0. All of them are parameterized in code, so you can substitute your real values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU |
| Motors | 3× gimbal BLDC, 24N22P (e.g. GM4108), so p = 11 pole pairs, R ≈ 10 Ω, L ≈ 4 mH (verify) |
| Encoder | 14-bit absolute magnetic (AS5048A/MA730), read every PWM cycle |
| Current sensing | 2-shunt inline or low-side, center-aligned ADC trigger |
| IMU0 | ICM-42688-P on the **camera payload**. Used for attitude feedback. |
| IMU1 | ICM-42688-P on the **base/handle**. Used for disturbance feedforward and as the vibration-frequency reference. |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Payload |

**Loop rates (all phase-locked to the PWM interrupt):**

```
20 kHz  : ADC → Clarke/Park → d/q current PI → SVPWM          (ISR, per motor)
 4 kHz  : velocity PI + anti-cogging FF + base-rate FF          (every 5th tick)
 8 kHz  : IMU read (SPI DMA, ODR 8 kHz) → filter chain
