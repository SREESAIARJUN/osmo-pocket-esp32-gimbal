**Job #23. Revision A: Analytical model and reference design**

## 0. Architecture Clarification and Assumptions

The STM32H743 should not generate motor PWM directly. On every production 4-in-1 AIO, the H743 runs ArduPilot as the flight controller and talks to **four dedicated ESC MCUs** over DShot. The ESC MCUs run AM32 or BLHeli_32 and handle commutation. This document models that topology:

```
            ┌──────────── STM32H743 (ArduPilot) ────────────┐
 IMU/Baro ──┤ SPI/I2C            TIM1 CH1..CH4 (DShot600 BiDir)│
            └──────┬──────┬──────┬──────┬───────────────────┘
                   │M1    │M2    │M3    │M4   (single-wire, bidirectional)
               ┌───▼──┐┌──▼───┐┌─▼────┐┌▼─────┐
               │ESC MCU││ESC MCU││ESC MCU││ESC MCU│  AT32F421 / STM32G071 (AM32)
               │48 kHz ││48 kHz ││48 kHz ││48 kHz │
               └───┬──┘└──┬───┘└──┬───┘└──┬───┘
               3φ driver + 6×MOSFET per motor (24 FETs total)
```

**Design assumptions** (change these and re-run the equations):

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S: 25.2 V max, 22.2 V nominal |
| Burst phase current | I_pk | 80 A per motor |
| PWM frequency | f_sw | 48 kHz |
| MOSFET | — | 30–40 V, DFN3.3×3.3, R_ds(on)25 = 1.6 mΩ @ V_gs = 10 V |
| Temp. coefficient | α | 0.0045 /K |
| Rise/fall time | t_r, t_f | 15 ns / 15 ns (≈1 A gate driver, 4.7 Ω R_g) |
| Gate charge | Q_g | 40 nC |
| Output charge | Q_oss | 50 nC |
| Reverse recovery | Q_rr | 40 nC |
| Dead time | t_dt | 100 ns |
| Body diode V_f | V_f | 0.8 V |
| Board | — | 20×20 mm "nano", 6-layer, 2 oz copper |

> **Engineering flag, stated up front:** an 80 A burst on a 20×20 mm board is a **sub-second transient rating**, not a sustainable operating point. Section 3 quantifies this. I recommend marketing it as "80 A burst (≤0.5 s, single motor)" with roughly 15 A continuous. Any higher claim fails thermal qualification.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At a design-limit junction temperature of T_j = 110 °C:

$$R_{ds}(110) = 1.6\,\text{m}\Omega \times (1 + 0.0045 \times 85) = 1.6 \times 1.383 = 2.21\,\text{m}\Omega$$
