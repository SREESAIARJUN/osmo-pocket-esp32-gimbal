# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have access to the Job #47 specification, so I designed against the reference hardware below. Every hardware-dependent constant is in one `Config` block, so you can retarget it by editing that block.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class with FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit magnetic encoder per axis (AS5048A / MT6835), SPI |
| Current sense | 2- or 3-shunt, synchronous to PWM center |
| IMUs | 2 × ICM-42688-P on the camera payload (redundancy plus √2 noise reduction), SPI, ODR 8 kHz |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, carries camera) |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (d/q PI) | 20 kHz (= PWM) | ω_c ≈ 2π·1500 rad/s |
| Velocity (inertial rate, PI) | 4 kHz | ω_v ≈ 2π·100 rad/s |
| Angle / attitude (P + feedforward) | 1 kHz | ω_p ≈ 2π·15 rad/s |
| IMU sampling and filtering | 8 kHz → decimated to 4 kHz | — |
| Attitude estimator (Mahony) | 1 kHz | — |

Each outer loop has roughly a 5–10× bandwidth separation from the loop inside it, which lets each loop treat the inner one as unity gain.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

The electrical angle comes from the mechanical angle, the pole-pair count, and a calibrated encoder offset:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.3 PI Design by Pole-Zero Cancellation

After the cross-coupling terms are cancelled, each axis behaves as the plant 1/(Ls + R). Use a PI controller:

$$C(s) = K_p + \frac{K_i}{s}$$

with

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero then cancels the plant pole, and the closed loop becomes ω_c/(s + ω_c), a first-order response with bandwidth ω_c. Choose ω_c ≤ 2π·f_PWM/10.

**Decoupling feedforward:**

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$
