# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for Job #56, so the design uses the explicit assumptions in §0. Every equation is parameterized. Change the constants in the `Config` block to match your hardware, and verify the ICM-42688-P register values against your datasheet revision before flashing.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 24N22P (GM4108-class), p = 11 pole pairs, R ≈ 10 Ω, L ≈ 3 mH (phase-equivalent dq) |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6835 class), SPI |
| Current sense | 2-phase inline shunts with synchronized ADC sampling. A voltage-mode fallback is given in §1.5 |
| MCU | Cortex-M4F/M7 with FPU (STM32G474/H723 class) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the rotation centroid, sharing the CLKIN reference |

**Loop rates (all integer-locked to one timer):**

```
PWM / current loop (FOC)      : 20 kHz   Ts_i = 50 µs   (PWM ISR, ADC-triggered)
IMU sample (both chips, DMA)  :  8 kHz   Ts_g = 125 µs
Rate (velocity) loop          :  4 kHz   Ts_v = 250 µs  (2:1 decimation after AAF/notch)
Attitude (angle) loop + AHRS  :  1 kHz   Ts_a = 1 ms
Cogging LMS adaptation        :  4 kHz   (gated, background-enabled)
```
