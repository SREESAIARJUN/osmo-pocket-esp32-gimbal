## 0. Architecture Clarification and Assumptions

The STM32H743 does not generate the 48 kHz gate PWM. In a 4-in-1 AIO the partitioning is:

| Block | Function | Typical device |
|---|---|---|
| FC MCU | ArduPilot, attitude loop, DShot600 TX / eRPM RX | STM32H743VIT6 (LQFP100) |
| ESC MCU ×4 | Commutation, 48 kHz complementary PWM | AT32F421 / STM32G071 running AM32 or BLHeli_32 |
| Gate driver ×4 | 3-phase half-bridge driver with bootstrap | FD6288Q-class |
| Power stage ×4 | 6 N-FETs per channel (24 total) | 40 V, ~1.6 mΩ DFN3.3 |

The 48 kHz figure is an ESC-firmware PWM setting. The H743's job is DShot timing and DMA.
