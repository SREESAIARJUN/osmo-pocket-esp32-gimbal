# STM32H743 Nano FC + 80A 4-in-1 ESC: System Architecture Model (Job #16)

## 0. Architecture Clarification

The STM32H743 is the **flight controller (FC)**. It does not generate the 48 kHz motor PWM. The 4-in-1 ESC uses **four dedicated ESC MCUs** (AT32F421 running AM32 is assumed here), and each drives its own 3-phase bridge. The H743 sends bidirectional DShot600 and receives eRPM telemetry on the same wire.

| Domain | Device | Function |
|---|---|---|
| FC | STM32H743VIH6 (400 MHz, APB timer clock 200 MHz) | ArduPilot, DShot generation and telemetry capture |
| ESC ×4 | AT32F421K8U7 (AM32) | 48 kHz six-step/FOC PWM, BEMF, telemetry |
| Gate driver ×4 | FD6288Q (3-phase, 20 V boot) | Bridge drive |
| Power stage | 6 switches/motor, **2× paralleled** 40 V PDFN5×6 per switch | 48 FETs total |

**Assumed MOSFET parameters.** These are representative of a 40 V, ~1 mΩ PDFN5×6 part. Substitute your actual datasheet values.

| Parameter | Value |
|---|---|
| R_DS(on) @ 25 °C, V_GS = 10 V | 1.0 mΩ |
| Temperature coefficient α | 0.0045 /K (k(T) ≈ 1.45 @ 125 °C) |
| Q_g / Q_gd / Q_oss / Q_rr | 50 / 8 / 40 / 50 nC |
| V_SD (body diode) | 0.8 V |
| R_th(j-c) | 1.2 K/W |
| R_th(j-board), via array | 8 K/W |

**Operating point:** 6S (V_bus = 25.2 V), I_phase = 80 A burst, f_sw = 48 kHz, dead time t_dt = 50 ns, ambient T_a = 40 °C.

> **Feasibility flag:** 80 A per motor on a "nano" (20×20 or 25.5×25.5) footprint is beyond any sustained rating. The model below treats 80 A strictly as a **time-limited burst** and on a 30.5×30.5 mm board. On 20×20, scale the thermal capacitance down by about 0.43×. The allowable burst then shrinks to roughly 40% of the values below.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

With N_p paralleled devices per switch, the effective resistance is R_sw = R_DS(T_j)/N_p.

### 1.2 Six-step synchronous commutation

In each 60° sector, two phases conduct: phase A high side (HS) is PWM'd at duty D and phase B low side (LS) is held on continuously.
