# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Package (Job #11)

## 0. Scope, Architecture Decision, and Assumptions

### 0.1 Architecture

**The STM32H743 does not commutate the motors.** Bidirectional DShot is an FC→ESC protocol, so the architecture is:

```
[STM32H743 FC, ArduPilot] --4x BiDir DShot600--> [4x ESC MCU, AM32/BLHeli_32-class]
                                                    └─ 3-phase gate driver ─ 6x MOSFET ─ motor
```

Each ESC channel uses its own small MCU, such as an AT32F421 or STM32G071. A single-MCU ESC handling four motors is possible, but the firmware ecosystem and ArduPilot integration favor one MCU per motor.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path

In 6-step mode with synchronous rectification, two phases conduct at any instant:

- **PWM on:** the high-side FET of phase A and the low-side FET of phase B conduct.
- **PWM off:** the low-side FET of phase A (sync rectifier) and the low-side FET of phase B conduct.

So the phase current always passes through **exactly two MOSFET channels**, regardless of duty cycle (dead time excluded, see §2.4).

### 1.2 Temperature-Dependent Resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

$$R_{ds}(100^\circ C) = 1.0\,\text{mΩ}\times1.45 = 1.45\ \text{mΩ}$$

### 1.3 Per-Channel Conduction Loss

$$P_{cond,ch} = I_{ph}^2 \cdot 2\,R_{ds}(T_j) = 80^2 \times 2 \times 1.45\times10^{-3} = \mathbf{18.6\ W}$$
