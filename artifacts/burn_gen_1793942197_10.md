# STM32H743 FC + 80A-Burst 4-in-1 ESC: Analytical Design Package

> **Scope and honesty note.** "Job #50" has no fixed BOM, so this package is a **parametric model** with representative component values. Every number below comes from a stated assumption. Before layout freeze, substitute your chosen MOSFET, driver and stack-up into the equations.
>
> The derivation also exposes an important result: **80 A burst per channel is thermally achievable for about 1–3 s on a 30×30 board and about 1 s on a true 20×20 "nano" board.** This is set by board heat capacity, not by the silicon. See §3.

## 0. System Architecture and Assumptions

| Item | Assumption |
|---|---|
| Battery | 6S LiPo. Worst-case V_bus = 25.2 V (full charge) |
| Topology | 4× three-phase bridges, 6 N-FETs per motor (24 total) |
| ESC control | **One ESC MCU per motor** (e.g., AT32F421 / STM32G071 running AM32 or BLHeli_32). The H743 does **not** drive gates. It sends bidirectional DShot600. |
| Commutation | 6-step trapezoidal, synchronous (complementary) PWM, f_sw = 48 kHz, on the high side of the active leg |
| Gate driver | FD6288Q-class 3-phase driver. V_drv = 10–12 V. Source ≈ 1.5 A, sink ≈ 1.8 A |
| MOSFET (representative 40 V, PDFN 3.3×3.3) | R_DS(on),max = 1.2 mΩ @ 25 °C, 10 V. Q_g = 50 nC, Q_gs = 10 nC, Q_gd = 8 nC, Q_oss ≈ 40 nC, Q_rr ≈ 40 nC, V_plateau ≈ 3.0 V, V_SD ≈ 0.8 V, R_θJC ≈ 1.1 K/W, R_g,int ≈ 1 Ω |
| Burst current | I_ph = 80 A DC-equivalent per motor. Motor inductance smooths ripple, so I_rms ≈ I_avg |
| Design limit | T_j ≤ 125 °C, board ≤ 110 °C, ambient 40 °C |

Bus-side burst for 4 motors at full throttle: I_bus ≈ D·ΣI_ph ≈ **320 A** (D → 1). This sizes the battery pads, XT90 connector and the 2 oz-plus power planes. It is not a "nano" number. Flag this early to the mechanical team.

## 1. Conduction Losses

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha\,(T_j-25)],\qquad \alpha\approx0.004\ \text{K}^{-1}$$

At T_j = 110 °C: R_DS = 1.2 mΩ × 1.34 = **1.61 mΩ**.

### 1.2 Bridge conduction with synchronous PWM

In any 60° commutation sector, current flows through two phases.

- **PWM leg:** the high-side (HS) FET conducts for D·T, and the complementary low-side (LS) FET conducts for (1–D)·T.
- **Fixed leg:** the LS FET is on for 100% of the sector.

The duty-cycle terms cancel:

$$P_{cond}=I^2R_{DS}\,[D+(1-D)]+I^2R_{DS}=2\,I^2R_{DS}$$

$$P_{cond}=2(80)^2(1.61\times10^{-3})=\mathbf{20.6\ W\ per\ motor}$$
