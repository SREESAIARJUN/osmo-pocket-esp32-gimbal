# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

This design covers the cascaded control loops, anti-cogging compensation and dual ICM-42688-P vibration rejection for the gimbal in Job #46.

## 0. Assumptions

I don't have the Job #46 spec sheet, so the design is parameterized around a typical brushless gimbal stack. Replace the numbers in `Config` with your measured values.

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC (GBM2804-class), 12N14P, so p = 7 pole pairs |
| R, L, λ (per phase) | ~5 Ω, ~1.5 mH, measured |
| Position sensor | 14-bit magnetic encoder (MT6701/AS5048A) on each motor shaft |
| MCU | STM32G474 @ 170 MHz (FPU, CORDIC, 3× advanced timers) |
| Current loop | 20 kHz, synchronized to center-aligned PWM |
| Velocity loop | 4 kHz (IMU-driven, ODR 8 kHz decimated to 4 kHz) |
| Angle loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, on-chip AAF enabled |

### Timing hierarchy

| Rate | Tasks |
|---|---|
| 20 kHz ISR | ADC → Clarke → Park → PI(id, iq) → inv Park → SVPWM, plus the cogging feedforward added to iq* |
| 4 kHz | Dual-IMU read → notch/LPF → fusion → velocity PI → iq* |
| 1 kHz | Attitude filter → angle P + rate feedforward → ω* |

Bandwidth separation of at least 5× between loops is enforced:

- Current loop: ω_ci ≈ 2π·2000 rad/s
- Velocity loop: ω_cv ≈ 2π·150 rad/s
- Angle loop: ω_ca ≈ 2π·20 rad/s

## 1. FOC Current Loop Equations

### 1.1 Electrical angle

The electrical angle is derived from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

### 1.2 Clarke transform (power-invariant amplitude form, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda$$

The electromagnetic torque is:

$$\tau_e = \tfrac32 p \lambda\, i_q = K_t\, i_q$$

### 1.5 Current PI with pole-zero cancellation

The plant per axis, after decoupling, is $G(s) = 1/(Ls+R)$. Choosing the controller

$$C(s) = K_p + \frac{K_i}{s}$$

with

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

cancels the plant pole. The closed loop then becomes $\omega_{ci}/(s+\omega_{ci})$, a first-order response with bandwidth ω_ci. Keep ω_ci ≤ 2π·f_pwm/10.

### 1.6 Decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L i_d + \lambda)$$

### 1.7 Voltage limiting

The voltage vector is limited to the linear SVPWM region:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

d-axis priority is used: v_d is clamped first, and v_q gets the remaining headroom:

$$v_{q,\max} = \sqrt{V_{max}^2 - v_d^2}$$

### 1.8 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s\,(\text{sat}(u_k) - u_k)$$

with $K_{aw} = K_i / K_p$, which equals ω_ci·R/L·L/R, i.e. the natural choice.

### 1.9 SVPWM via min-max zero-sequence injection

First the inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Then the inverse Clarke transform:

$$v_a = v_\alpha$$

$$v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2} v_\beta$$

$$v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2} v_\beta$$

Zero-sequence injection and duty computation:

$$v_0 = -\tfrac12\,(\max(v_{abc}) + \min(v_{abc}))$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and has no branches per sector.

### 1.10 Timing compensation

The rotor moves during the one-sample computation delay. Advance the angle used in the inverse Park transform by 1.5 samples:

$$\theta_{e,\text{pwm}} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Angle → Velocity Control

### 2.1 Feedback signals

For camera stabilization, the inner loops must close on inertial quantities, not on joint angles:

- **Velocity feedback** ω_axis is the fused, filtered gyro rate projected onto the motor axis.
- **Angle feedback** θ_axis comes from the attitude filter (Section 4).
- **The encoder** is used only for commutation, cogging lookup and joint limits.
