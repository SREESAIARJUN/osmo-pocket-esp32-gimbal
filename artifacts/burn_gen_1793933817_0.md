## 0. System Assumptions & Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motors | Gimbal BLDC, 12N14P (`p = 7` pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase, 2-shunt or inline current sense, 12-bit ADC |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), SPI |
| IMUs | 2× ICM-42688-P, SPI @ 24 MHz, ODR 8 kHz, gyro ±2000 dps, accel ±16 g |
| PWM | 20 kHz center-aligned, ADC triggered at center |

**Loop rates**

| Loop | Rate | Period | Execution context |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ADC-complete ISR |
| Velocity | 5 kHz | 200 µs | every 4th current ISR |
| IMU acquisition + filtering | 8 kHz | 125 µs | DRDY / DMA-complete ISR |
| Angle / attitude | 1 kHz | 1 ms | timer ISR / low-priority task |

**Bandwidth separation rule:** each outer loop's bandwidth should be at most 1/5 to 1/10 of the inner loop's.
- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_θ ≈ 2π·15–25 Hz

## 1. Field-Oriented Current Loop

### 1.1 Transforms (amplitude-invariant)

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (2-shunt, using $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model (SPMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.3 PI controller with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L\, i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e (L\, i_d + \lambda_m)$$

**Pole-zero cancellation tuning.** Choosing

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

makes the closed loop first-order: $i_q/i_q^* = \omega_c/(s+\omega_c)$.

Discretization uses forward Euler for the integrator, with $T_s = 50\,\mu s$. Account for the one-sample PWM delay by keeping $\omega_c T_s \lesssim 0.2$.

**Voltage limiting (circular).** Let $V_{max} = V_{bus}/\sqrt3$ (the linear SVPWM limit).
- Clamp $v_d$ to $\pm V_{max}$.
- Clamp $v_q$ to $\pm\sqrt{V_{max}^2 - v_d^2}$.

**Anti-windup by back-calculation:**

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw} \approx K_i/K_p$$

### 1.4 SVPWM (min-max zero-sequence injection)

Phase voltages:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset:

$$v_0 = -\tfrac12(\max + \min)$$

Duty cycle per phase:

$$d_x = \tfrac12 + (v_x+v_0)/V_{bus}$$

This is mathematically identical to sector-based SVPWM, but branch-free.

## 2. Cascaded Angle → Velocity Control

### 2.1 Velocity estimation: PLL observer on encoder angle

Differentiating a 14-bit encoder directly at 5 kHz gives quantization noise of $2\pi/16384 \cdot 5000 \approx 1.9$ rad/s. That is unusable without filtering, so a type-2 PLL is used:

$$e_\theta = \text{wrap}(\theta_{meas} - \hat\theta)$$

$$\hat\omega \mathrel{+}= K_{i,pll}\, e_\theta\, T_s$$

$$\hat\theta \mathrel{+}= (\hat\omega + K_{p,pll}\, e_\theta)\, T_s$$

Gains: $K_{p,pll} = 2\zeta\omega_{pll}$ and $K_{i,pll} = \omega_{pll}^2$, with $\zeta = 1$ and $\omega_{pll} \approx 2\pi\cdot 400$ Hz (≥ 2–3× the velocity loop bandwidth).
