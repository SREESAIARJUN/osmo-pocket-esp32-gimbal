# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #22 spec sheet, so this design rests on the assumptions in §0. Every hardware-dependent constant is a named parameter and can be changed without touching the derivations.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic absolute encoder per axis (AS5048A / MT6701 class), SPI |
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) or equivalent |
| IMU A ("camera") | ICM-42688-
