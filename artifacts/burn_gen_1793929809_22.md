# STM32H743 AIO Nano FC + 80A 4-in-1 ESC: Systems Architecture & Mathematical Model (Job #34)

## 0. Architectural Baseline and Assumptions

This document provides a design-grade model. Every numerical result depends on the parameters below. **Replace them with the datasheet values of the parts you actually procure before releasing anything to layout.**

### 0.1 Architecture decision

The STM32H743 does **not** drive the power stage directly. ArduPilot has no field-oriented control or trapezoidal motor commutation in the FC firmware. The standard and correct partitioning is:

```
STM32H743 (ArduPilot) ──DShot600 bidir (×4)──► 4× ESC MCU (AT32F421 / AM32) ──► 4× 3-ph gate driver ──► 24× MOSFET
```

The 48 kHz PWM is generated by the ESC MCUs, not the H743.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C this gives R_ds = 1.6 mΩ × 1.5 = **2.4 mΩ**. Use this value for the burst worst case.

### 1.2 Six-step trapezoidal commutation with synchronous rectification

In each 60° sector, two legs carry current:

- **PWM leg:** the high side conducts for a fraction D and the low side (synchronous) for 1−D. Ignoring dead time, this leg always presents one R_ds in series.
- **Return leg:** the low side is on continuously, adding one more R_ds.

$$P_{cond,ch} = I_{ph}^2\,R_{ds}\,[D + (1-D) + 1] = 2\,I_{ph}^2\,R_{ds}$$

**Key result:** with synchronous rectification, conduction loss is independent of duty cycle.

$$P_{cond,ch} = 2 \times 80^2 \times 2.4\,\text{m}\Omega = \mathbf{30.7\ W\ per\ channel}$$

Averaged over a full electrical cycle, each of the 6 FETs dissipates about 5.1 W. The instantaneous peak while a FET is in conduction is higher; see §5.3.

### 1.3 Parasitic copper and shunt loss

| Path | Resistance | Loss @ 80 A |
|---|---|---|
| Phase/bus copper, both conduction paths | ≈ 0.3 mΩ × 2 | 3.8 W |
| Shunt (if per-channel, 0.25 mΩ) | 0.25 mΩ | 1.6 W |

## 2. Switching Loss Model at 48 kHz

### 2.1 V–I overlap loss (PWM leg high side; the low side soft-switches)

Gate currents during the Miller plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = 1.2\ \text{A},\qquad I_{g,off} = \frac{V_{pl}}{R_g} = 0.8\ \text{A}$$
