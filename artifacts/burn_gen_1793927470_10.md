|---|---|

| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz |
| Velocity loop | 4 kHz (inertial rate from IMU) |
| Angle loop | 1 kHz (attitude from fusion) |
| IMUs | IMU-P: ICM-42688-P on the payload/camera. IMU-B: ICM-42688-P on the base/handle. Both at 8 kHz ODR. |
| MCU | Cortex-M4F/M7 with single-precision FPU |

**Why two IMUs?** They have different roles:
- **IMU-P (payload)** closes the stabilization loops.
- **IMU-B (base)** provides:
  1. A base-motion feedforward signal.
  2. A correlated vibration reference for an adaptive noise canceller.

This dual-sensor arrangement gives two vibration rejection filter stages, described in §5.

## 1. Loop Architecture

```
            1 kHz                 4 kHz                    20 kHz
 q_ref ─► [Angle P + ff] ─► ω_ref ─► [Velocity PI] ─► τ* ─► [÷Kt] ─► iq* ─► [Current PI d/q] ─► SVPWM
             ▲                 ▲  ▲                    ▲ +                        ▲
   attitude (Mahony)   ω_payload  base-rate ff   τ_cog_ff(θm)              id, iq (Clarke/Park)
             ▲                 ▲                         ▲
   IMU-P ─► Stage-1 (AAF+notch, on-chip) ─► Stage-2 (dynamic notch + LMS ANC w/ IMU-B ref)
                                              encoder θm ─► θe = p·θm − θoffset
```

**Bandwidth separation rule** (each outer loop at most ~1/5 of its inner loop):

$$\omega_{c,i} \ge 5\,\omega_{c,v} \ge 25\,\omega_{c,\theta}$$

Typical choices:
- Current loop: $\omega_{c,i} = 2\pi\cdot1500$ rad/s
- Velocity loop: $\omega_{c,v} = 2\pi\cdot150$ rad/s
- Angle loop: $\omega_{c,\theta} = 2\pi\cdot20$ rad/s

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Electrical angle with delay compensation.** One PWM period plus half a period of transport delay:

$$\theta_e = p\,\theta_m - \theta_0 + 1.5\,\omega_e T_s$$
