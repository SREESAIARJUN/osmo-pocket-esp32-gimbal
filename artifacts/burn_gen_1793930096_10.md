# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bi-Directional DShot600 Design Package

## 0. Scope and Architecture Correction

I don't have the specifications for "Job #28," so this package uses explicitly stated assumptions (§1). Replace them with your BOM values. All equations are parametric, so the numbers will re-flow.

**The H743 does not generate the 48 kHz motor PWM.** In an ArduPilot AIO design, the H743 runs the flight stack and sends bi-directional DShot600 to the ESC controller(s). Commutation and the 48 kHz PWM run on dedicated ESC MCUs, such as 4× AT32F421 or STM32G071 running AM32 or BLHeli_32. The design is therefore partitioned as follows:

```
[H743 FC: ArduPilot] --4x BDShot600 (1 wire each, bidirectional)--> [4x ESC MCU (AM32)]
                                                                         |
                                             FD6288Q 3-ph driver --> 6x N-MOSFET bridge --> motor
```

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Current path
With 6-step commutation and synchronous (complementary) PWM, the motor current always flows through exactly two conducting devices: one high-side and one low-side.

- The PWM-ing phase splits conduction between its HS FET (fraction D) and its LS FET (fraction 1−D).
- The current magnitude through the path is I_pk regardless of D.

### 2.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.2 mΩ × 1.5 = **1.8 mΩ**.
