# 3-Axis Gimbal FOC Control and Dual ICM-42688-P Sensor Fusion: Design Specification and C++ Reference Implementation

I don't have the Job #3 requirements document, so this design uses the stated assumptions in §0. Every hardware-dependent number is a named constant, so you can substitute your real values without touching the math.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (e.g., GBM2804-class): N_slot = 12, pole pairs p = 7 |
| Phase parameters | R_s ≈ 5.6 Ω (line-to-neutral), L_s ≈ 1.2 mH, K_t ≈ 0.08 N·m/A |
| Rotor encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A) over SPI |
| Current sense | 2-shunt low-side, sampled at the PWM center |
| MCU | STM32G4/H7 with single-precision FPU |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (÷5) |
| Angle loop | 1 kHz (÷20) |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, gyro and accel ODR = 8 kHz |
| IMU mounting | IMU B rotated 180° about z relative to IMU A, symmetric about the plate centroid |
