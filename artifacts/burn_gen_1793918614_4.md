# STM32H743 Flight Controller + 80 A 4-in-1 ESC (Job #37): Power, Thermal, and DShot Design Model

## 0. Architecture Correction

The STM32H743 should not commutate the motors. ArduPilot does not run motor commutation, and a single H743 running 4× six-step or FOC at 48 kHz alongside the flight stack is not a reasonable partition. The defensible architecture is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (400 MHz, timers at 200 MHz) | ArduPilot, bidirectional DShot600 master |
| ESC MCUs (×4) | AT32F421K8U7 or STM32G071 | AM32 firmware, 48 kHz PWM, eRPM telemetry |
| Gate drivers (×4) | FD6288Q (3-phase, bootstrap) | 10–12 V gate drive |
| Power stage | 24× N-MOSFET, 40 V, ~1 mΩ | 4 motors × 3 half-bridges |
| Bus | 6S LiPo (25.2 V max) | |

Everything below derives losses for the ESC power stage and timing/DMA for the H743. **All device parameters are stated assumptions; substitute your actual datasheet values before release.**
