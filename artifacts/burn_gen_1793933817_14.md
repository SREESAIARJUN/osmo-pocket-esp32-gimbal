# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #57, so this design rests on the assumptions in §0. They are typical for a 3-axis camera gimbal with direct-drive BLDC motors, and they are all exposed as parameters in the code. Replace them with your actual motor, encoder and MCU data before tuning.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 1–3 mH, K_t ≈ 0.05–0.2 N·m/A |
| Encoder | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the plate centroid, SPI at 24 MHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) and center-aligned PWM |
| Mechanics | Yaw on the base, roll in the middle, pitch carrying the camera |

```
          1 kHz                 4 kHz                       20 kHz
 q_ref ─►[Attitude P + FF]─ω_ref─►[Rate PI + FF]─τ─►J⁻ᵀ─iq*─►[Current PI d/q]─►SVPWM─►Motor
              ▲                      ▲         ▲                  ▲
       Mahony attitude      fused gyro     anti-cogging     Clarke/Park, θ_e
              ▲            (notch+LPF)     iq_ff(θ_m)       from encoder
     Dual ICM-42688-P @ 8 kHz ODR ──► dual-IMU fusion ──► vibration-rejection filters
```

**Rate separation.** Each loop's bandwidth should be at least 5× lower than the loop inside it:
- Current loop: 1.5–2 kHz bandwidth.
- Rate loop: 60–150 Hz.
- Attitude loop: 10–25 Hz.

## 1. Field-Oriented Control (Current Loop, T_s = 50 µs)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, using the three-phase constraint i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e
