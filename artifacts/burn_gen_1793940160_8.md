## 0. Architectural Clarification

The STM32H743 does **not** switch the motors. It cannot run 4× three-phase commutation with BEMF zero-cross detection alongside an ArduPilot flight stack.

The correct partitioning is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 400 MHz in ArduPilot | Flight stack, bidirectional DShot600 master |
| ESC ×4 | AT32F421K8U7 (or STM32G071) running AM32 / BLHeli_32 | 6-step commutation, **48 kHz PWM** |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap) | High-side and low-side gate drive |
| Power stage ×4 | 6× N-MOSFET, 40 V, PDFN 3.3×3.3 | Half-bridges |

So the 48 kHz switching analysis applies to the ESC MCUs. The DShot/DMA analysis applies to the H743.
