## 0. Architecture Decisions and Stated Assumptions

You did not specify a MOSFET, gate driver, board size or burst duration, so I have fixed representative values below. **Every number downstream is parametric.** Swap in your datasheet values and the equations still hold.

### 0.1 Architectural correction (important)

ArduPilot does not perform sensorless BLDC commutation. An "STM32H743 4-in-1 ESC flight controller" must therefore be split into two kinds of processor:

| Block | Processor | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100, 480 MHz max, run at 400 MHz) | ArduPilot | Attitude control, emits bi-directional DShot600 |
| ESC ×4 | AT32F421K8U7 or STM32G071GBU6 (one per motor) | AM32 | 6-step commutation, BEMF ZC detection, 48 kHz PWM, eRPM telemetry |

This can be a single PCB (an AIO, "all-in-one") or a stack. The DShot link stays either way.
