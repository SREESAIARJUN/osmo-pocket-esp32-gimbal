# STM32H743 Nano FC + 4-in-1 ESC (Job #68): Power-Stage Thermal Model, DShot Timing/DMA Plan, and Reference Netlists

## 0. Scope, Assumptions and Key Findings

**Architecture.** An STM32H743 is not used as the ESC commutation MCU in production 4-in-1 designs. It is the flight controller running ArduPilot. The ESC side uses four dedicated commutation MCUs (STM32G071 running AM32 is assumed here; BLHeli_32-class parts are equivalent). The H743 sends bi-directional DShot600 to them. The model below follows that split.

**Design point.** All numbers below are parametric. Swap in your datasheet values; the equations hold.

| Parameter | Symbol | Value used |
|---|---|---|
| Battery (6S, full charge, worst case) | V_bus | 25.2 V |
| Burst phase current per motor | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, PDFN 3.3×3.3 class) | R_ds(on),25 | 1.2 mΩ @ V_GS = 10 V |
| R_ds(on) temperature coefficient | α | 0.0065 /K |
| Rise / fall time (with ~1.5 A gate driver) | t_r, t_f | 15 ns / 15 ns |
| Total gate charge | Q_g | 40 nC |
| Body-diode reverse recovery | Q_rr | 40 nC |
| Output charge | Q_oss | 30 nC |
| Body-diode forward voltage | V_f | 0.8 V |
| Dead time | t_dt | 50 ns |
| Copper path resistance per motor (bus + phase) | R_cu | 0.5 mΩ |
| Board thermal mass, 20×20 or 25×25 stack | C_th,board | ≈ 4 J/K (est.) |

**Headline finding.** 80 A per motor on a nano-format board is a transient (burst) rating, not a continuous one. At 4×80 A the stack dissipates about 110 W. Burst time must be limited by firmware current limiting and a temperature-derived timer, as shown in §1.6.

## 1. Thermal and Loss Model (Per Motor, Then ×4)

### 1.1 Conduction Topology

The model assumes trapezoidal six-step commutation with complementary (synchronous) PWM:

- At any instant, phase current flows through one high-side path and one low-side path.
- During the on-time D, the path is HS(A) → motor → LS(B).
- During the off-time (1−D), the path is LS(A) (synchronously rectified) → motor → LS(B).
- Either way, current passes through 2 FET channels in series.

Conduction loss is therefore:

$$P_{cond}=2\,I_{rms}^2\,R_{ds(on)}(T_j)$$

For a flat-top burst, I_rms ≈ I_pk = 80 A. This ignores ripple, which adds a factor (1 + r²/12) for ripple ratio r. That correction is negligible for r < 0.3.

### 1.2 Temperature-Dependent R_ds(on): Self-Consistent Solution

$$R(T_j)=R_{25}\,[1+\alpha\,(T_j-25)]$$

$$T_j = T_{ref} + P_{FET}(T_j)\cdot R_{th,j\text{-}ref}$$

Substituting the conduction term gives a closed form:

$$T_j=\frac{T_{ref}+k\,R_{25}(1-25\alpha)}{1-k\,R_{25}\,\alpha}, \qquad k = I^2 \cdot \text{share} \cdot R_{th}$$

**Thermal runaway.** The solution diverges when k·R₂₅·α ≥ 1. This is the analytical thermal-runaway boundary.

**Practical evaluation point.** T_j = 100 °C gives R = 1.2 × 1.4875 ≈ 1.79 mΩ.

$$P_{cond}=2\cdot80^2\cdot1.79\,\text{m}\Omega = \mathbf{22.9\ W}$$

### 1.3 Switching Losses at 48 kHz

Only the PWM-ing leg hard-switches.

**(a) V–I overlap:**

$$P_{sw}=\tfrac12 V I (t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot30\text{ns}\cdot48\text{k} = \mathbf{1.45\ W}$$

**(b) Reverse recovery.** This occurs at HS turn-on into the conducting LS body diode.

$$P_{rr}=Q_{rr}V f = 40\text{n}\cdot25.2\cdot48\text{k}=\mathbf{0.048\ W}$$

**(c) Output capacitance:**

$$P_{oss}\approx Q_{oss}V f = 30\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.036\ W}$$

**(d) Dead-time body-diode conduction** (two dead-time intervals per period):

$$P_{dt}=V_f I\,(2t_{dt}) f = 0.8\cdot80\cdot100\text{n}\cdot48\text{k}=\mathbf{0.307\ W}$$

**(e) Gate drive.** The HS and LS of the active leg switch. This loss is mostly dissipated in the driver and gate resistors, not the FETs.

$$P_g = 2\,Q_g V_{GS} f = 2\cdot40\text{n}\cdot10\cdot48\text{k} = \mathbf{0.038\ W}$$

**(f) Copper:**

$$P_{cu}=I^2R_{cu}=6400\cdot0.5\text{m}=\mathbf{3.2\ W}$$

### 1.4 Loss Budget at 80 A Burst

| Term | Per motor (W) | ×4 (W) |
|---|---|---|
| Conduction (T_j = 100 °C) | 22.9 | 91.6 |
| Switching overlap | 1.45 | 5.8 |
| Dead-time diode | 0.31 | 1.2 |
| Q_rr + Q_oss | 0.08 | 0.3 |
| Gate drive | 0.04 | 0.15 |
| Copper | 3.2 | 12.8 |
| **Total** | **≈ 28.0** | **≈ 112** |

Efficiency at the burst point is 1 − 28 / (25.2·80) ≈ **98.6 %**. The efficiency is good, but the absolute loss density is extreme for about 4–6 cm² of board.

**Frequency sensitivity.** Only about 1.8 W per motor scales with f_sw. Dropping to 24 kHz saves about 0.9 W per motor. Conduction dominates, so raising the f_sw parameter is cheap thermally, but it costs gate-driver heat and EMI.

### 1.5 Junction Rise per FET

- Commutation frequency at, for example, 210k eRPM is 3.5 kHz. Its 286 µs period is much shorter than the die thermal time constant (~5–10 ms).
- Each FET therefore sees time-averaged power. Six FETs share the conduction loss, and each conducts about 1/3 of the electrical cycle.

$$P_{FET,avg}\approx \frac{P_{cond}+P_{sw}+P_{dt}+P_{rr}}{6}\cdot 2\approx \frac{24.7}{3}\approx 8.2\text{ W (on active FETs)}$$

This is conservative: it uses the per-motor loss divided by the 3 FETs active at any time.

Using R_th(j-board) ≈ 1.5 K/W (package) + 1.0 K/W (via array into 2 oz planes) = 2.5 K/W:

$$\Delta T_{j\text{-}board}\approx 8.2\cdot2.5\approx \mathbf{20.5\ K}$$

### 1.6 Board-Level Transient: Burst Time Limit

**Lumped first-order model:**

$$C_{th}\frac{dT_b}{dt}=P_{tot}-\frac{T_b-T_a}{R_{th,b\text{-}a}}$$

$$T_b(t)=T_a+P R_{th}\left(1-e^{-t/\tau}\right),\quad \tau=R_{th}C_{th}$$

**Thermal mass estimate.**

- FR4: about 2.5 g × 1.1 J/gK.
- Copper (8-layer, 2 oz): about 3 g × 0.385 J/gK.
- FETs and connectors add the rest.
- Total C_th ≈ 4 J/K.

**Board-to-air resistance.** With prop-wash airflow, R_th,b-a ≈ 6 K/W, so τ ≈ 24 s.

**All four motors at 80 A (P = 112 W).** The initial slope is 112/4 ≈ **28 K/s**.

Constraint: T_j,max = 150 °C with 25 °C margin gives T_j ≤ 125 °C. That means T_b ≤ 125 − 20.5 = 104.5 °C. Starting from T_a = 35 °C:

$$t_{burst}=-\tau\ln\!\left(1-\frac{\Delta T}{P R_{th}}\right)=-24\ln\!\left(1-\frac{69.5}{672}\right)\approx \mathbf{2.6\ s}$$

**One motor at 80 A, the rest at 30 A.** P ≈ 28 + 3×(≈4.5) ≈ 41.5 W, giving t ≈ 9 s.

**Steady-state continuous rating.** For T_b = 104.5 °C, P_max = 69.5/6 ≈ 11.6 W total. That corresponds to roughly **4 × 33 A continuous** (solve 4·2·I²·R(T) + copper = 11.6 W, including switching). This should be the label rating; 80 A is a ≤2 s burst.

**Firmware requirement.**

- AM32: set the current limit and use the NTC temperature limit.
- ArduPilot side: use `MOT_BAT_CURR_MAX`, or rely on ESC-telemetry temperature from bdshot EDT for logging.
