# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original Job #3 specification, so this design states its assumptions explicitly. Each one is parameterized in the code. Change the constants and the design still holds.

| Item | Assumption |
|---|---|
| MCU | STM32G474 / H7 class: FPU, 3-phase advanced timer, ADC triggered from PWM center |
| Motors | Gimbal BLDC, e.g. GBM2804: 12 slots (N), 14 poles (p = 7 pole pairs), R ≈ 5–10 Ω |
| Commutation sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701), read over SPI at the current-loop rate |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted with opposite orientation, common CLKIN, SPI at 24 MHz |
| Loop rates | Current/FOC 20 kHz · velocity 4 kHz · angle 1 kHz · IMU ODR 8 kHz |
| Disturbance | Platform vibration (propeller/motor harmonics, 80–500 Hz) plus motor cogging |

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms
Assuming a power-invariant convention is *not* used (amplitude-invariant):

**Clarke** (assuming $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
