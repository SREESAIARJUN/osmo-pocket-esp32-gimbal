**Joint order:** yaw (outer), roll (middle), pitch (inner). The camera rotation is

$$R_{cam} = R_z(\psi)\,R_x(\phi)\,R_y(\theta).$$

## 1. Control Architecture

```
          ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ────┐ ┌────── 20 kHz ──────┐
q_ref ──► │ quaternion error → joint error │►│ velocity PI    │►│ i_d, i_q PI → SVPWM │► motor
          │ (inverse Jacobian) → P + ω_ff  │ │ + cogging FF   │ │ Clarke/Park         │
          └──────────────▲─────────────────┘ └───▲─────────────┘ └──────▲──────────────┘
                         │ attitude q̂            │ joint rate q̇       │ i_a, i_b, θ_e
          Dual-IMU fusion (8 kHz) ─► Mahony (1 kHz)  encoder + gyro      shunts + encoder
```

- **Attitude loop.** The outer loop stabilizes the camera attitude measured by the IMUs, not the encoder angle.
- **Rate loop.** The velocity loop uses a blended rate. The gyro (projected to joint space) supplies the high-frequency, inertial part. The encoder supplies low-frequency joint kinematics and handles the case when the gyro saturates.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

Electrical angle, with encoder offset $\theta_0$ found by d-axis alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Electromagnetic torque (SPMSM, so $L_d = L_q$):

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 2.2 Plant and Decoupling

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

After decoupling, each axis reduces to $G_i(s) = \dfrac{1}{Ls + R}$.

### 2.3 PI Design by Pole-Zero Cancellation

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = \omega_{ci} L,\quad K_i = \omega_{ci} R$$
