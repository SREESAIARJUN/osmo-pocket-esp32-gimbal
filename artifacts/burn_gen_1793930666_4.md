## 0. Architecture and Loop Rates

```
          ┌──────── 1 kHz ────────┐  ┌─────── 4 kHz ───────┐  ┌────── 20 kHz ──────┐
θ_ref ──▶ │ Angle P + vel FF      │─▶│ Velocity PI + AW    │─▶│ id/iq PI + decouple│─▶ SVPWM ─▶ Motor
          └───────────▲───────────┘  │ + cogging FF (LMS)  │  │ Clarke/Park        │
                      │              └──────────▲──────────┘  └─────────▲──────────┘
         Mahony attitude (1 kHz)       ω_axis (gyro, 4 kHz)        θ_e (encoder), i_abc
                      ▲                          ▲
        Dual ICM-42688-P @ 8 kHz ─▶ AAF ─▶ calibration ─▶ dynamic notch ─▶ LPF ─▶ inverse-variance fusion
```

| Loop | Rate | Feedback | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | Phase shunts, encoder θₑ | ω_c,i ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | Fused gyro projected on the joint axis | ω_c,v ≈ 2π·60 Hz |
| Angle | 1 kHz | Attitude estimate (or encoder in follow mode) | ω_c,θ ≈ 2π·10 Hz |
| IMU ODR | 8 kHz | Two ICM-42688-P, decimated 2:1 to 4 kHz | — |

Each loop's bandwidth is at least about 5× the bandwidth of the loop outside it. That keeps the inner loops effectively transparent to the outer ones.

## 1. FOC Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, where θₑ = p·θₘ − θ_offset and p is the number of pole pairs:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transpose of the same matrix.

### 1.2 PMSM Model and Decoupling

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t i_q,\qquad K_t = \tfrac32 p \lambda_m$$

Applying feedforward decoupling gives

$$v_d^* = u_d - \omega_e L_q i_q,\qquad v_q^* = u_q + \omega_e(L_d i_d + \lambda_m)$$

so each axis reduces to the first-order plant 1/(Ls + R).
