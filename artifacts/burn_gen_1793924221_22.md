# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #34): System Architecture & Mathematical Model

## 0. Scope, Architecture Assumptions, and Caveats

The STM32H743 runs the **flight controller (ArduPilot)**. It does not commutate motors. Commercially viable 4-in-1 ESCs use **one small MCU per motor channel** running AM32 or BLHeli_32-class firmware, and those MCUs generate the 48 kHz PWM.

The architecture modelled here:

```
                 ┌──────────────────────┐   DShot600 bidir (1-wire, per motor)
 IMU/Baro/RX ───►│ STM32H743 (ArduPilot)│──────────────┬──────┬──────┬──────┐
                 └──────────────────────┘              ▼      ▼      ▼      ▼
                                                    ESC MCU ×4 (AT32F421 / STM32G071, AM32)
                                                       │ 6× PWM @ 48 kHz (complementary)
                                                    3-ph gate driver ×4
                                                       │
                                                    6× N-MOSFET bridge ×4  ──► motors
```

**Numerical assumptions** (all parametric, so substitute datasheet values for your BOM):

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst case for switching) |
| I_ph | 80 A | Burst phase current per channel |
| R_ds(on),25 | 1.8 mΩ | 40 V PDFN3.3×3.3 class FET at V_gs = 10 V |
| k_T | 1.5 | R_ds(on) multiplier at T_j ≈ 110–125 °C |
| R_cu | 0.5 mΩ | Copper and solder path per conducting loop |
| t_r, t_f | 10 ns each | Edge times with a ~1–1.5 A gate driver |
| t_dt | 100 ns | Dead time per edge |
| V_SD | 0.8 V | Body-diode forward drop |
| Q_rr | 50 nC | Reverse-recovery charge |
| Q_g | 40 nC | Total gate charge |
| f_sw | 48 kHz | Switching frequency |
| Board | 20×20 mm (nano), 8-layer, 2 oz | Thermal mass basis |

> ⚠️ **Feasibility flag:** 80 A per channel on a 20×20 mm nano board is a **sub-2-second transient rating, not a continuous one**. Section 1 derives this quantitatively. Any spec sheet should state burst duration and initial temperature alongside the 80 A figure.

## 1. Loss Model (per motor channel, 6-step trapezoidal with synchronous rectification)

### 1.1 Conduction losses

In 6-step commutation, two phases carry current at any instant. With complementary PWM (synchronous rectification), current always flows through **exactly two FETs in series**. These are HS+LS during the on-time and LS+LS during the freewheel. Conduction loss is therefore **independent of duty cycle**:

$$
P_{cond} = I_{ph}^2 \left( 2\,R_{ds(on)}(T_j) + R_{cu} \right),\qquad R_{ds(on)}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]
$$

With α ≈ 0.0059 /K, which gives k_T ≈ 1.5 at 110 °C:

$$
P_{cond} = 80^2 \,(2 \times 2.7\text{ m}\Omega + 0.5\text{ m}\Omega) = 6400 \times 5.9\text{ m}\Omega = \mathbf{37.8\ W}
$$

The same calculation at T_j = 25 °C gives 6400 × 4.1 mΩ = **26.2 W**. That 44 % rise with temperature is the positive-feedback term in Section 3.

**Per-FET split.** Each FET conducts for 120° electrical (1/3 of the period). Averaged over a commutation cycle, the per-FET average is P_cond/6 summed across the bridge, roughly 5.4 W from the R_ds term. The instantaneous peak per FET is about 17 W, and that is what drives Z_th,jc.
