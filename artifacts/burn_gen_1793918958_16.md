## 0. Scope, Architecture, and Assumptions

### 0.1 Architectural Correction

The 48 kHz switching loop does **not** run on the H743. ArduPilot does not commutate motors. The standard and correct partition is:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 @ 400 MHz (ArduPilot) | Attitude control, bidirectional DShot600 master, eRPM consumer for harmonic notch |
| ESC ×4 | STM32G071GBU6 (or AT32F421) running AM32 | 6-step commutation, 48 kHz complementary PWM, DShot decode, GCR eRPM reply |
| Gate drive ×4 | Fortior FD6288Q (3-phase half-bridge driver, bootstrap) | 6 gate outputs per motor |
| Power stage ×4 | 6× N-MOSFET per motor (24 total) | 3-phase bridge |

## 1. Conduction Loss Model

### 1.1 Current Path in 6-Step with Complementary (Synchronous) PWM

AM32 uses complementary PWM. In each 60° commutation sector:

- The **PWM leg** high-side conducts for D·T, and its low-side synchronously rectifies for (1−D)·T.
- The **return leg** low-side conducts for the full T.
- The **floating leg** is off (BEMF sensing).

Exactly **two FETs are always in the current path**. This is independent of duty cycle, apart from the dead-time interval covered in §2.4.

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{ds}(T_j)$$

### 1.2 RMS Current Including PWM Ripple

Phase inductance L_ph is about 15 µH for a typical 2207-class 1750 KV motor, so the line-to-line inductance is 2L_ph. The worst-case ripple occurs at D = 0.5 with V_bemf ≈ V_bus/2:

$$\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{2L_{ph}\, f_{sw}} = \frac{12.6 \times 0.5}{30\,\mu H \times 48\,kHz} = 4.4\ \text{A}_{pp}$$

$$I_{rms}^2 = I_{dc}^2 + \frac{\Delta I^2}{12} = 6400 + 1.6 \approx 6402\ \text{A}^2$$

Ripple is therefore negligible at 80 A, contributing less than 0.03%. At light load it dominates the ratio but not the absolute loss.

### 1.3 Temperature-Dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$
