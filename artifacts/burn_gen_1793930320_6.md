# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #25 specification, so the design below uses assumptions typical of a camera gimbal. They are listed in §0. Every gain is derived from plant parameters, so you can substitute your measured values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), e.g. GBM2804-class, R ≈ 10 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) on each axis for commutation |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| MCU | STM32G4/H7-class (FPU), center-aligned PWM at 20 kHz |
| Gimbal order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) → camera |

### Rate hierarchy

The design rule is ≥ 4–5× bandwidth separation between nested loops.

```
 20 kHz  ── Current (FOC) loop     ω_c ≈ 2π·1500 rad/s
  8 kHz  ── IMU fetch + filtering + dual-IMU fusion
  4 kHz  ── Velocity loop          ω_v ≈ 2π·150 rad/s
  1 kHz  ── Angle loop + attitude  ω_θ ≈ 2π·30 rad/s
```

### Signal flow per axis

```
θ_ref ─►(+)─► P_θ ─►(+)─► PI_ω ─►(+)─► i_q* ─► FOC PI ─► SVPWM ─► Motor
        ▲  −       ω_ff▲ −   ▲     i_cog(θ_m,ω) ▲
        │              │     └─── anti-cogging FF
   θ̂ (IMU attitude)   ω̂ (fused gyro → joint rate)
```

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Use the amplitude-invariant Clarke transform with two-shunt sensing:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{offset}}$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 PMSM model in the dq frame

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q \quad (\text{surface PM},\ L_d=L_q)
$$
