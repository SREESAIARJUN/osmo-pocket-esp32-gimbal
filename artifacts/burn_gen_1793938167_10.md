# Job #48: STM32H743 Nano AIO (FC + 4-in-1 ESC) Power-Stage and DShot Architecture

## 0. Scope, Assumptions and Feasibility Warnings

**Architecture assumed.** The STM32H743 runs ArduPilot as the flight controller. It sends bidirectional DShot600 to four ESC MCUs (STM32G071/AT32F421 class, running AM32). Each ESC MCU drives one 3-phase bridge at 48 kHz. The H743 does not commutate motors, so "48 kHz switching" is an ESC-side parameter.

**Feasibility warnings:**

1. **80 A is burst only.** On a 30×30 mm nano board, 80 A on all four channels is a burst rating of roughly 4 s, not a continuous one. The derivation below shows why.
2. **Phase current exceeds battery current.** At duty D < 1, phase current is higher than battery current. "80 A" must be specified as either phase or battery current. I treat it as **80 A phase current** (worst case for the FETs).
3. **The netlist is a reference topology, not a released design.** It needs schematic review, SI/PI simulation, and thermal validation on hardware before fabrication.

## 1. Conduction Loss Model

### 1.1 Current paths

With 6-step trapezoidal commutation and complementary (synchronous) PWM, two phase legs carry I_ph at any instant:

- In the PWM-active leg, the high-side FET conducts for D·T. Its complementary low-side FET conducts for (1−D)·T.
- In the return leg, the low-side FET conducts for 100% of the interval.

So the current always passes through exactly **two R_ds(on)** in series, independent of D:

$$P_{cond,ch} = I_{rms}^2 \cdot 2R_{ds}(T_j)$$

### 1.2 Ripple correction

The phase current carries PWM ripple, which adds to its RMS value:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph} f_{sw}}$$

For a typical 5-inch motor (L_ph ≈ 15 µH line-to-line, D = 0.5, V_bemf ≈ 12 V):

- ΔI ≈ 9.2 A
- ΔI²/12 ≈ 7 A², which is negligible against 6400 A².

### 1.3 Temperature-coupled R_ds (fixed-point iteration)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)], \qquad T_j = T_{case} + P_{FET}\,R_{\theta JC}$$

Starting from T_j = 125 °C: R_ds = 0.90 × 1.55 = **1.395 mΩ**.

$$P_{cond,ch} = 6407 \times 2 \times 1.395\text{ mΩ} = \mathbf{17.9\ W}$$

### 1.4 Copper path

The PCB path is roughly: battery pad → bus plane → FET → phase pad, plus the return path. With 2 oz copper on 4 of 8 layers this is about 0.5 mΩ, and copper resistance rises about 0.39%/°C.

$$P_{Cu,ch} = 80^2 \times 0.5\text{ mΩ} \times 1.3 \approx \mathbf{4.2\ W}$$

Current-sense shunt (0.25 mΩ on the DC bus, scaled by D): ≈ **0.8 W**.
