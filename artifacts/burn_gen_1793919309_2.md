# STM32H743 AIO Flight Controller + 4-in-1 80A ESC (Job #38): Architecture & Analysis Package

## 0. Scope, Assumptions and Architectural Corrections

The FET part number, board size and cooling are not specified, so this analysis rests on the stated assumptions below. **Re-run the model with the real datasheet values before releasing the design.** Every equation is parameterized so this is straightforward.

**Architectural corrections:**
1. **ArduPilot does not commutate the motors.** The H743 runs ArduPilot and generates bidirectional DShot600. Each motor needs its own ESC MCU running AM32 or BLHeli_32 firmware, which owns the 48 kHz PWM, dead-time and BEMF zero-cross detection. This design uses 4× AT32F421 (AM32-supported).
2. **"80A per channel" on a nano/AIO footprint is a burst rating only.** As shown in §3, a 30×30 mm board cannot sustain this current continuously. The numbers below quantify the burst window.
