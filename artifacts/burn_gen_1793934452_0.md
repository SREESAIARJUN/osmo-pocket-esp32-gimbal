## 1. Control Architecture

```
            attitude ref q_ref
                  │
        ┌─────────▼──────────┐ 1 kHz
        │  ANGLE LOOP (P+FF) │◄──── q̂ (dual-IMU Mahony)  [inertial]
        └─────────┬──────────┘
            ω_ref (+ω_ff)
        ┌─────────▼──────────┐ 5 kHz
        │ VELOCITY LOOP (PI) │◄──── ω_gyro (notched + LPF, dual-IMU)
        └─────────┬──────────┘
    i_q,fb  ──────┤
                  ⊕◄──── i_q,cog(θ_m)  (Fourier anti-cogging FF, LMS-adapted)
                  ⊕◄──── i_q,acc = J·α_ref/K_t (inertia FF)
        ┌─────────▼──────────┐ 25 kHz
        │ CURRENT LOOP (PI)  │◄──── i_d, i_q  (Clarke/Park from shunts)
        │ + decoupling + SVM │◄──── θ_e from encoder
        └────────────────────┘
```

Key design decision: the velocity loop is closed on the gyro, not the encoder. That gives inertial stabilization, so base motion becomes a disturbance rather than a reference. The encoder is used for commutation, cogging-table indexing and joint limits.
