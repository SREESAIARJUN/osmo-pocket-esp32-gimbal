## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`, slots `Ns = 12`) |
| Phase params | `R = 5.6 Ω`, `Ld ≈ Lq = 2.1 mH`, flux linkage `λ = 3.2 mWb` |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701 class) |
| Drive | 3-phase PWM, 20 kHz center-aligned, 2- or 3-shunt current sensing |
| IMUs | 2× ICM-42688-P on the **payload (camera) plate**, SPI + DMA, 8 kHz ODR |
| Payload inertia (per axis) | `J ≈ 2.5e-4 kg·m²` (identify it; see 2.3) |
| Vibration source | Multirotor propellers: 80–350 Hz fundamental plus harmonics |

**Loop rates and bandwidths (each loop is at least 5× faster than the loop outside it):**

```
 20 kHz  ── Current (FOC) loop      BW ≈ 1.5 kHz
  8 kHz  ── IMU sample + filter + dual fusion
  4 kHz  ── Velocity loop (inertial gyro rate)  BW ≈ 60–120 Hz
  1 kHz  ── Attitude/angle loop + AHRS          BW ≈ 10–20 Hz
```

**Feedback roles:**
- **Encoder:** commutation (electrical angle), cogging-table index, and joint velocity fallback.
- **Payload IMUs:** inertial rate (velocity loop) and inertial attitude (angle loop). These are the quantities the gimbal must actually stabilize.

## 1. FOC Current Loop

### 1.1 Transforms
Clarke transform (amplitude-invariant, balanced phases, `ia + ib + ic = 0`):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e$$

$$v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda)$$

The torque equation for an SPM motor ($L_d = L_q$) is:

$$\tau = \tfrac32\,p\,\lambda\,i_q \equiv K_t\, i_q,\qquad K_t = \tfrac32 p\lambda$$

### 1.3 PI with decoupling and back-EMF feedforward

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L_q i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L_d i_d + \hat\lambda)$$

**Gain selection (pole-zero cancellation).** After decoupling, the plant is $1/(Ls+R)$. Choose $K_i/K_p = R/L$. The closed loop then becomes the first-order system $\omega_c/(s+\omega_c)$, with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

For example, with $\omega_c = 2\pi\cdot1500$: $K_p = 19.8$ V/A and $K_i = 52.8\text{k}$ V/(A·s).

**Delay check.** Keep $\omega_c T_s \lesssim 0.5$ to tolerate the 1.5-sample computation/PWM delay. Here $\omega_c T_s = 0.47$ ✓.

### 1.4 Voltage limiting and SVPWM

- Give d-axis priority.

- Feed the clamped value back to the integrator (anti-windup, Section 2.1).
