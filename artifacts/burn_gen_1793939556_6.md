## 0. Architecture Clarification and Key Findings

**The H743 does not commutate the motors.** Bidirectional DShot is a protocol between the flight controller and *ESC* MCUs. This document therefore assumes the industry-standard AIO partition:

| Domain | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 (480 MHz, timers at 240 MHz) | ArduPilot |
| ESC ×4 | AT32F421K8U7 (or STM32G071), one per motor | AM32 (supports 48 kHz PWM and bidir DShot / EDT) |
| Gate drive ×4 | FD6288Q 3-phase bootstrap driver | n/a |
| Power stage | 24× N-MOSFET, 40 V, DFN3.3×3.3 | n/a |

If you intended the H743 to run FOC directly on 12 half-bridges, that is a different architecture. It would need 3× advanced-timer complementary PWM per motor, but the H743 has only TIM1 and TIM8 as advanced timers. It is not feasible for 4 motors.

**Key findings:**

1. **Conduction loss dominates.** It is about 21× the switching loss at 48 kHz.
2. **80 A on all four motors simultaneously is thermally limited to about 1.5 to 2.5 s** on a nano board, starting from a 50 °C board. Rate it as "80 A burst, 1 s, single-motor-pair transient" or move to a 30.5 mm board with 5×6 FETs.
3. **The DShot600 bidir frame cycle is about 88 µs.** This comfortably supports an ArduPilot loop rate up to 2 kHz.
