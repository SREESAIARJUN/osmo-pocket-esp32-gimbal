# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

## 0. Assumptions

I don't have the Job #21 specification, so the design uses typical gimbal values. Every value below is a named constant in the code, so you can replace it with the real hardware numbers.

| Item | Value assumed |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7, slots Ns = 12), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor position sensor | 14-bit magnetic encoder (MT6701/AS5048A), SPI |
| IMUs | 2 × ICM-42688-P on the camera platform, rigid mount, SPI at 24 MHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Current loop | 20 kHz, synchronous with the PWM centre |
| Velocity loop | 4 kHz |
| Angle/attitude loop | 1 kHz |
| IMU ODR | 8 kHz, decimated to 4 kHz after filtering |

The loop bandwidths are separated by about 5–10× at each stage, which lets each inner loop be treated as unity gain by the loop above it:

$$
\omega_{c,i}\approx 2\pi\cdot 2\,\text{kHz},\qquad
\omega_{c,v}\approx 2\pi\cdot 150\,\text{Hz},\qquad
\omega_{c,\theta}\approx 2\pi\cdot 25\,\text{Hz}
$$

## 1. Field-Oriented Control

### 1.1 Electrical angle

$$
\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi
$$

- θ_off is found at commissioning by applying a d-axis current (vd > 0, θe = 0) and reading the encoder.
- To compensate the latency from ADC/encoder sampling to PWM update (T_d ≈ 1.5 T_s), use the predicted angle in the inverse Park transform:

$$
\hat\theta_e = \theta_e + p\,\omega_m\,T_d
$$

### 1.2 Clarke and Park transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.3 Plant model

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

with torque

$$
\tau = \tfrac32 p\lambda_m i_q = K_t i_q
$$

### 1.4 Current PI controllers

Use pole-zero cancellation, so the closed loop becomes first order with bandwidth ω_ci:

$$
K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}
$$

Discrete form (backward Euler integrator, sample time T_s):

$$
\begin{aligned}
e_x[k] &= i_x^*[k]-i_x[k]\\
v_x^{PI}[k] &= K_{p,i}\,e_x[k] + I_x[k]\\
v_d[k] &= v_d^{PI}[k] - \omega_e L\,i_q[k]\\
v_q[k] &= v_q^{PI}[k] + \omega_e(L\,i_d[k]+\lambda_m)
\end{aligned}
$$

The decoupling and back-EMF feedforward terms remove the cross-coupling from the plant model.
