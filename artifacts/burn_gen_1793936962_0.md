## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 1.3 Park transform
$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

### 1.4 Plant in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac{3}{2}p\lambda_m i_q = K_t i_q$$

### 1.5 Current PI controller with decoupling
Choose the zero to cancel the electrical pole $R/L$. The closed loop then becomes first order with bandwidth $\omega_c$:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{\text{PWM}}}{10\text{–}20}$$

For 20 kHz PWM, $f_c \approx 1.5$ kHz.

The control law is:
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L\, i_q,\qquad
v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e \lambda_m$$

Use $i_d^* = 0$ (surface PM, no field weakening).

**Voltage limiting.** Clamp to the linear SVPWM hexagon-inscribed circle:
$$\sqrt{v_d^2+v_q^2}\le \frac{V_{dc}}{\sqrt3}$$
Prioritize $v_d$, and give $v_q$ the remainder. Integrator anti-windup uses back-calculation:
$$\dot x_I = K_i e + K_{aw}(u_{\text{sat}} - u_{\text{unsat}}),\qquad K_{aw}\approx K_i/K_p$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

**Delay compensation.** Advance the angle used in the inverse Park by 1.5 PWM periods:
$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Velocity source
For a gimbal, the stabilization rate loop should be closed on the camera-frame gyro rate, projected onto each joint axis. The motor encoder remains the commutation source and provides a fallback rate.

With $\boldsymbol\omega_{cam}$ (body rates of the camera) and joint axes $\hat{\mathbf a}_j$ expressed in the camera frame, the stabilization error rate per joint is:
$$\omega_j^{\text{meas}} = \mathbf J^{-1}(\mathbf q)\,\boldsymbol\omega_{cam}$$

$\mathbf J$ is the 3×3 Jacobian whose columns are the joint axes in the camera frame. Near the nominal pose, for a yaw-roll-pitch gimbal, this reduces to $\approx \mathbf I$ with a few cosine terms. These terms are implemented in `GimbalController::jointRates`.

### 2.2 Velocity PI controller
The rigid-body plant is $J_m\dot\omega = K_t i_q - \tau_{\text{dist}}$, so the plant transfer function is $P_v(s) = K_t/(J s)$.

With PI $C_v = K_{p,v}(1 + \omega_z/s)$ and crossover $\omega_v$:
$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad \omega_z = \frac{\omega_v}{4},\qquad K_{i,v} = K_{p,v}\,\omega_z$$

This gives about 76° phase margin, ignoring the current loop. Required separation: $\omega_v \le \omega_c/5$ (e.g. $f_v \approx 150$–$250$ Hz, limited by structural modes).

**Feedback filtering.** The measured rate passes through:
- dynamic notches at structural and motor harmonics (§4.4), then
- a 2nd-order low-pass at about $3\omega_v$ to $5\omega_v$.

### 2.3 Angle P(+D) controller with feedforward
The closed velocity loop is approximately $1/(s/\omega_v + 1)$. The outer angle loop is:
$$\omega^* = K_{p,\theta}\,(\theta^* - \theta) + \dot\theta^*_{ff},\qquad K_{p,\theta} = \frac{\omega_v}{4\text{–}6}$$

A small $K_{i,\theta}$ can be added to remove steady error from residual friction. Use conditional integration: integrate only when $|\omega^*| < \omega_{\max}$.

$\dot\theta^*_{ff}$ is the operator or follow-mode rate command. An acceleration feedforward $J\ddot\theta^*/K_t$ is added at the velocity-loop output.
