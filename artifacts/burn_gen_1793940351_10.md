# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

**Assumptions.** I don't have the original specification for Job #21, so this design rests on the assumptions below. Each one is marked `// ASSUMPTION` in the code so you can change it.

| Item | Assumed value |
|---|---|
| MCU | Cortex-M7 / M33 with FPU (STM32H7/G4 class) |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6835 class) on each axis |
| IMUs | Two ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Cam
