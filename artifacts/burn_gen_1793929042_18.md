# STM32H743 FC + 80 A 4-in-1 ESC (Job #37): Design-Basis Engineering Package

## 0. Scope, Assumptions, and Red Flags

I don't have Job #37's requirements file, so this package rests on stated assumptions. Every value marked **[A]** is an assumption to replace with your datasheet or requirement values. The model structure stays valid when those values change.

### 0.1 Architectural correction

The STM32H743 runs ArduPilot as the flight controller. It does **not** generate the 48 kHz commutation PWM. A production 4-in-1 ESC uses four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32 or BLHeli_32). The H743 sends them bi-directional DShot600 and receives eRPM telemetry back. Putting six-step commutation for four motors plus the ArduPilot scheduler on one H7 is technically possible, but nothing in the ArduPilot ecosystem supports it. This package uses the conventional split:

```
6S LiPo ─┬─► 4× [ESC MCU → 3-phase driver → 6× N-MOSFET] ─► Motors 1–4
         └─► BEC 5V/3V3 ─► STM32H743 (ArduPilot) ──DShot600 bidir──► ESC MCUs
```

### 0.2 Red flags to resolve before layout

| Issue | Why it matters |
|---|---|
| "Nano" + 80 A | A 20×20 mm board cannot carry 4×80 A. Copper cross-section and heat capacity are insufficient. This package assumes a **30.5×30.5 mm or larger board, 8-layer, 2 oz outer and 2 oz inner power planes**. |
| "80 A burst" definition | I treat 80 A as the **phase (motor) current per channel for ≤ 5 s**, at a battery-side current near 80 A when D≈1. If 80 A is battery-side current at partial throttle, phase current is I_batt/D and the losses grow quadratically. |
| Whole-board power | At burst, the board dissipates about 100 W (Section 3). The rating is thermal-capacitance-limited, not steady-state. |
