## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.2 mH (phase), K_t ≈ 0.09 N·m/A |
| Driver | 3-phase inverter, V_bus = 12–16 V, center-aligned PWM 20 kHz, 2-shunt or in-line current sense |
| Position sensor | 14-bit magnetic encoder (e.g. AS5048/MT6701) on each motor |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR = 8 kHz, ±2000 dps, ±16 g |
| MCU | Cortex-M7/M4F with FPU (STM32H7/G4 class) |

**Loop rates**

| Loop | Rate | Sensor / output |
|---|---|---|
| Current loop | 20 kHz (in PWM ISR) | Feedback: i_a, i_b, θ_e |
| Velocity / rate loop | 4 kHz | Feedback: fused gyro rate projected on the joint axis |
| Attitude / angle loop | 1 kHz | Feedback: fused attitude quaternion |
| IMU pipeline | 8 kHz in, decimated to 4 kHz | Out: ω̂, â, α̂ (angular acceleration) |

Cascade bandwidth rule: each inner loop should be at least 4–10× faster than the loop around it.
- ω_c(current) ≈ 2π·1.5 kHz
- ω_c(rate) ≈ 2π·150 Hz
- ω_c(angle) ≈ 2π·20 Hz

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the rotor frame
$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac32 p\,\lambda_m i_q \;\Rightarrow\; K_t = \tfrac32 p \lambda_m$$

### 1.5 Current PI with decoupling and back-EMF feedforward
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)$$

**Gain selection (pole–zero cancellation).** Choosing the PI zero to cancel the electrical pole R/L gives a first-order closed loop with bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Big(\text{PI}(s)=K_p + \tfrac{K_i}{s}\Big)$$

### 1.6 Voltage limiting
The linear SVPWM region is the circle
$$|v| \le V_{\max} = \frac{V_{bus}}{\sqrt3}$$
- Give the d-axis priority: v_d ← sat(v_d, ±V_max).
- Then limit the q-axis: v_q ← sat(v_q, ±√(V_max² − v_d²)).
- Prevent windup with back-calculation: the integrator receives K_aw·(v_sat − v_unsat).

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a = v_\alpha,\; v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\; v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max + \min),\quad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
