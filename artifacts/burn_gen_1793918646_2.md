# STM32H743 AIO (FC + 4-in-1 ESC) Nano Board: 80 A Burst Thermal Model, 48 kHz Switching Losses, and ArduPilot Bidirectional DShot600 Allocation

## 0. Architecture and Assumptions

### 0.1 Architectural clarification

The STM32H743 does **not** commutate the motors. A production-viable partition is:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) at 400 MHz (rev Y) or 480 MHz (rev V) | ArduPilot |
| ESC MCU, ×4 | AT32F421 / STM32G071 (one per motor) | AM32 or BLHeli_32 |
| Gate drivers, ×4 | 3-phase driver, e.g. FD6288Q class | — |
| Power stage | 24 × N-MOSFET, 5×6 mm (or 3.3×3.3 mm) | — |

The 48 kHz PWM is an **ESC-MCU parameter**. The H743 only emits DShot600 frames and decodes eRPM telemetry.

### 0.2 Assumed parameters

**Feasibility warning:** 80 A on four channels simultaneously on a 20×20 or 30×30 board is a **seconds-scale burst rating only**. The math below shows why.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step trapezoidal commutation with synchronous rectification, the motor current always flows through **one high-side path and one low-side path**:
- The PWM leg alternates HS and LS by duty D.
- The opposite leg's LS is on solidly.

Total series resistance in the conduction path is therefore 2·R_ds at all times, regardless of duty:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds(on)}\,k_T$$

$$P_{cond,motor} = 2 \times 80^2 \times 1.0\text{m}\Omega \times 1.5 = \mathbf{19.2\ W}$$

### 1.2 Copper loss

$$P_{Cu} = I_{ph}^2 R_{Cu} = 6400 \times 0.5\text{m}\Omega = \mathbf{3.2\ W}$$

This is significant. A 2 oz outer layer gives about 0.25 mΩ/□. Doubling copper or paralleling inner layers through via farms is mandatory.

### 1.3 Temperature-dependent closed form

For an iterative solve, use R_ds(T) = R_25·[1 + α(T_j − 25)] with α ≈ 0.006 /K. The loss and junction temperature are then coupled:

$$P_{cond}(T_j) = 2I^2R_{25}\,[1+\alpha(T_j-25)]$$

$$T_j = T_b + P_{FET}\,R_{th,jb}$$

Iterate to convergence. **Thermal runaway** occurs if

$$\frac{\partial P}{\partial T}\cdot R_{th} \ge 1$$

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches; one HS turn-on and one turn-off occur per period. With complementary PWM, the LS transitions are soft (diode-clamped).

| Loss term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·40 ns·48 kHz | 1.94 W |
| Dead-time diode conduction | V_SD·I·2t_dt·f_sw = 0.8·80·400 ns·48 kHz | 1.23 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 kHz | 0.06 W |
| C_oss | ½·C_oss·V²·f_sw, ×2 FETs in leg | 0.05 W |
| Gate drive (from driver, not FET) | Q_g·V_gs·f_sw ×2 = 50 nC·10 V·48 kHz·2 | 0.05 W |
| **Total switching, per motor** | | **≈ 3.3 W** |

**Frequency sensitivity:**

$$\frac{dP_{sw}}{df} \approx 3.3\ \text{W}/48\ \text{kHz} = 0.069\ \text{W/kHz per motor}$$

- 24 kHz saves about 1.6 W per motor.
- 96 kHz adds about 3.3 W per motor.

48 kHz is a reasonable compromise for low-inductance nano motors, where current ripple matters.

Dead-time loss is about 37% of switching loss. Tuning t_dt down to 100 ns, as far as the driver propagation spread allows, is the cheapest efficiency win.
