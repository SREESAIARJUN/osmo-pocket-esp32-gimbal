# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Model

This is a parametric engineering model. Device parameters such as R_DS(on), Q_rr, and R_θ are **representative assumptions** for a 40V-class 5×6/3×3 MOSFET. Substitute values from your actual BOM datasheets before sign-off. The netlists are reference topologies and still need ERC/DRC and bench validation.

## 0. System Partitioning

```
 6S LiPo (25.2V max) ──┬── Bulk caps ── 4× three-phase bridges (24 MOSFETs)
                       │                     ▲ gate drive (3× half-bridge drivers/motor)
                       │               ESC MCU ×4 (AM32/BLHeli_32-class)
                       │                     ▲ bi-directional DShot600 (1 wire/motor)
                       └── 5V/3V3 BEC ── STM32H743 FC (ArduPilot) — TIM3 CH1–4
```

The H743 does **not** switch MOSFETs. It generates DShot frames and decodes eRPM telemetry. The 48 kHz PWM and commutation are produced by the per-motor ESC MCUs.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent Resistance

$$R_{DS}(T_j) = R_{DS25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_DS = 1.0 mΩ × 1.70 = **1.70 mΩ**

### 1.2 Six-Step Trapezoidal with Synchronous Rectification

In each commutation sector, two phases carry current:

- **PWM phase:** the HS FET conducts for D, the LS FET (sync rect) conducts for (1−D). Current always flows through exactly one FET of this leg.
- **Return phase:** the LS FET conducts continuously.

Two R_DS(on) are therefore always in series with the phase current, independent of duty:

$$P_{cond,motor} = 2\,I^2\,R_{DS}(T_j)$$

Each FET is active for 1/3 of the electrical cycle, either as PWM-leg or return-leg. Averaged over a revolution, all six FETs share the loss equally:

$$P_{cond,FET} = \frac{P_{cond,motor}}{6}\ \text{(average)}, \qquad P_{cond,FET,inst} \le I^2 R_{DS}$$

### 1.3 Numbers @ 80 A, T_j = 125 °C

$$P_{cond,motor} = 2 \times 80^2 \times 1.70\,\text{m}\Omega = \mathbf{21.8\ W}$$

- P_cond,FET (average) = 3.6 W
- P_cond,FET (instantaneous peak) = 10.9 W

### 1.4 Thermal Runaway Check

Loss rises with T_j, and T_j rises with loss. The loop is stable only if:

$$\frac{\partial P}{\partial T_j}\,R_{\theta JA} = 2 I^2 R_{DS25}\,\alpha\,R_{\theta JA} < 1$$

At 80 A, 2·80²·1 mΩ·0.007 = 0.0896 W/K. Steady state therefore needs R_θJA,eff < 11 K/W (board-level, per motor). A nano board does not achieve this continuously, so **80 A must remain a time-limited burst** (§4).

## 2. Switching Loss Model @ 48 kHz

The model is evaluated per motor (one hard-switched leg active at a time).

### 2.1 V-I Overlap (Hard Switching)

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{n} \times 48\text{k} = \mathbf{0.968\ W}$$

### 2.2 Reverse Recovery (LS Body Diode → HS Turn-On)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.048\ W}$$

### 2.3 Output Capacitance

$$P_{oss} = \tfrac12 C_{oss,eq} V_{bus}^2 f_{sw} = 0.5 \times 1.5\text{n} \times 635 \times 48\text{k} = \mathbf{0.023\ W}$$

### 2.4 Dead-Time Diode Conduction (2 Edges/Cycle)

$$P_{dt} = V_{SD}\, I\, (2 t_{dead}) f_{sw} = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = \mathbf{0.614\ W}$$

### 2.5 Gate Drive (Dissipated in Driver/R_g, Not the FET)

$$P_{gate} = 2\,Q_g V_{drv} f_{sw} = 2 \times 30\text{n} \times 10 \times 48\text{k} = \mathbf{0.029\ W}$$

### 2.6 Switching Totals

$$P_{sw,motor} = 0.968 + 0.048 + 0.023 + 0.614 + 0.029 \approx \mathbf{1.68\ W}$$

**Design insight:** dead-time loss is about 37% of the switching loss. Reducing t_dead from 100 ns to 50 ns saves about 0.3 W per motor. Verify shoot-through margin against driver propagation-delay mismatch before doing so.
