# Job #57: 3-Axis Gimbal FOC Control Loop and Dual-IMU Vibration Rejection

## 0. Assumptions and Architecture

I have no project file for Job #57, so the design below uses typical gimbal assumptions. Replace the parameters marked `// [PARAM]` with measured values.

| Item | Assumption |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, e.g. GBM4108-class, 12N14P, R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per axis |
| IMU A | ICM-42688-P on the camera payload. This is the control feedback. |
| IMU B | ICM-42688-P on the base/handle. This is the disturbance reference. |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Current sensing | Inline or low-side shunts, sampled at PWM center |

**Loop rates.** Each loop's bandwidth is kept at least 5–10× below the loop inside it.

```
 20 kHz  ISR (PWM-synced): ADC → Clarke/Park → current PI (d,q) → SVPWM      ωc ≈ 2π·1.5 kHz
  4 kHz  task: IMU FIFO (8 kHz ODR, 2 samples) → filters → velocity PI       ωv ≈ 2π·120 Hz
  1 kHz  task: attitude estimator → angle P → gimbal kinematics              ωθ ≈ 2π·25 Hz
 Background: cogging-map adaptation, notch frequency tracking, diagnostics
```

**Signal flow for one axis.** The three axes are coupled through the kinematics in §5.

```
θ_ref ─►(Σ)─► Kθ ─►(Σ)◄─ ω_ff ──► PI_ω ─►(Σ)◄─ i_ff (inertia + friction + cogging) ─► PI_iq ─► Motor
         ▲               ▲                                                                   │
         │ θ̂ (Mahony)    │ ω_fb = clean payload gyro (notch + LMS)                            │
         └───────────────┴──────────── IMU A ◄── vibration ──► IMU B (reference) ◄── base ──┘
```
