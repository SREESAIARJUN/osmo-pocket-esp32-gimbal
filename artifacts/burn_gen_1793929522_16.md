# STM32H743 AIO Nano FC + 80A 4-in-1 ESC: Engineering Model (Job #21)

**Bottom line:** The electrical design can be done, but an **80A burst per motor on a 20×20 mm nano board only holds for about 1–2 seconds**, not the usual 10-second rating. The sections below show the derivation and how to set the rating. All component values are stated assumptions. Replace them with your actual MOSFET datasheet values and rerun the equations before release.

---

## 0. Architecture Decision

The H743 should **not** drive the 24 gate signals directly. The standard, flight-proven partition is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100) | ArduPilot; sends bidirectional DShot600 to the ESC MCUs |
| ESC MCUs (×4) | AT32F421K8U7 or STM32G071 | Runs AM32. Generates the **48 kHz** complementary PWM and handles sensorless commutation |
| Gate drivers (×4) | 3-phase half-bridge driver, about 1A source / 1.5A sink, VDRV ≈ 10V | Gate drive |
| Power stage | 24× 40V N-MOSFET, 3.3×3.3 or 5×6 DFN | 6 per motor |

Consequences:
- The **48 kHz switching frequency is set in the AM32 firmware** (PWM frequency parameter), not by ArduPilot.
- ArduPilot only handles the DShot timing (Section 3).

## 1. Operating Assumptions

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, fully charged) | V_in | 25.2 V |
| Burst phase current per motor | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET on-resistance at 25°C, V_GS = 10V | R_ds25 | 1.0 mΩ |
| R_ds(on) temperature coefficient | α | 0.005 /K |
| Gate–drain charge / post-threshold gate–source charge | Q_gd / Q_gs2 | 6 nC / 3 nC |
| Total gate charge | Q_g | 40 nC |
| Effective output capacitance (energy-related) | C_oss(er) | 1 nF |
| Body-diode reverse-recovery charge | Q_rr | 20 nC |

| Dead time | t_dt | 100 ns |
| Junction-to-case thermal resistance | R_θJC | 1.5 K/W |
| Design junction temperature | T_j | 110 °C |

Hot on-resistance:

R_ds(T) = R_ds25 · [1 + α(T − 25)] = 1.0 · (1 + 0.005·85) = **1.43 mΩ**

## 2. Loss Model (per motor, 6-step trapezoidal, synchronous complementary PWM)

### 2.1 Conduction Loss

In 6-step commutation, exactly two legs conduct at any instant:
- The "high" phase PWMs between its high-side and low-side FETs.
- The "low" phase holds its low-side FET fully on.

Current therefore always flows through **two FETs in series**, whatever the duty cycle D:

P_cond,motor = 2 · I² · R_ds(T) = 2 · 6400 · 1.43 mΩ = **18.3 W** (12.8 W when cold)

Per-FET distribution over one electrical period:
- High-side FET: P_HS = I²R · D/3
- Low-side FET: P_LS = I²R · (2 − D)/3

At full-throttle burst (D → 1), each FET dissipates I²R/3 = **3.05 W**.

At low duty with high current (punch-out from a hover), the low-side FET is the hotspot: up to 2I²R/3 = **6.1 W**. This is the case that sets low-side FET selection.

Add PWM ripple. With motor inductance L, the ripple is ΔI ≈ V_in·D(1−D)/(L·f_sw), and

I_rms² = I² + ΔI²/12

This is usually less than 1% at 48 kHz for typical 5" motors (L ≈ 20–40 µH).

### 2.2 Switching (V–I Overlap) Loss

Gate current during the Miller plateau (V_pl ≈ 3.5 V):
- Turn-on: I_g,on = (V_DRV − V_pl)/(R_drv + R_g,ext + R_g,int) = 6.5/(2+3+1) ≈ 1.08 A
- Turn-off: I_g,off = V_pl/(R_drv,sink + R_g,off + R_g,int) ≈ 3.5/3 ≈ 1.17 A

Ideal transition times:
- t_on = (Q_gs2 + Q_gd)/I_g,on ≈ 8.3 ns
- t_off ≈ 7.7 ns

Layout parasitics (common-source inductance, loop inductance) realistically stretch these to about **20 ns each**. Use the measured double-pulse values.

Per switching event pair:

P_sw = ½ · V_in · I · (t_on + t_off) · f_sw = ½ · 25.2 · 80 · 40 ns · 48 kHz = **1.94 W**
