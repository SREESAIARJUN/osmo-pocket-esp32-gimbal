# FOC Control and Dual-IMU Fusion for a 3-Axis Gimbal (Job #49)

## 0. Assumptions and Architecture

I don't have the Job #49 spec sheet, so the design below rests on the assumptions in this table. Every one of them is a parameter in the code; change them to match your hardware.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (GBM2804-class), 12N14P, pole pairs `p = 7`, R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.06 N·m/A |
| Joint encoder | 14-bit magnetic (MT6701/AS5048A) on each motor, read over SPI at 20 kHz |
| Current sensing | 2 inline or low-side shunts, ADC synced to PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (IMU-A, IMU-B), SPI, ODR 8 kHz, FIFO off, data-ready interrupt |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |

The loops run at these rates:

```
20 kHz : ADC → Clarke/Park → PI(id,iq) → inv-Park → SVPWM        (ISR, highest priority)
 4 kHz : encoder PLL, gyro velocity, velocity PI, cogging FF       (decimated from 20 kHz ISR)
 8 kHz : IMU-A/IMU-B read → adaptive notch → biquad LPF            (DRDY ISR)
 1 kHz : dual-IMU fusion → attitude (Mahony) → angle P → ω_ref    (task)
```

The loops are spaced by bandwidth: current loop ≈ 1.5 kHz, velocity loop ≈ 150 Hz, angle loop ≈ 25–30 Hz. Each loop is roughly 5–10× slower than the one inside it.

## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle comes from the mechanical angle, the pole-pair count, and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

**Clarke transform** (amplitude-invariant, assuming $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant in the dq frame (surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque is proportional to $i_q$:

$$\tau = \tfrac32 p\lambda_m\, i_q = K_t i_q$$

### 1.3 Decoupled PI with pole-zero cancellation

After the cross-coupling and back-EMF terms are fed forward, each axis behaves as $1/(Ls+R)$. Choosing the PI zero to cancel the plant pole gives:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$
