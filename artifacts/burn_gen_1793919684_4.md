# STM32H743 AIO + 4-in-1 ESC (Job #8): Electrical, Thermal and DShot Timing Model

## 0. Scope and Assumptions

Two points about the architecture shape every number in this document.

**1. The H743 does not drive the bridges.** In any ArduPilot-compatible 4-in-1 design, the H743 runs the flight controller and emits bidirectional DShot600. Each motor channel has its own ESC MCU (AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU generates the 48 kHz complementary PWM, senses BEMF and does commutation. The netlists below reflect this split.

**2. "80 A burst" on a nano (20×20 / 25.5×25.5 mm) board is a seconds-scale or sub-second rating, not a sustained one.** Section 3 derives the actual allowable burst duration rather than taking the label at face value.

## 1. Conduction Loss Model (6-Step, Complementary PWM)

### 1.1 Current paths

AM32/BLHeli_32 use trapezoidal 6-step commutation with synchronous rectification:

- **PWM on-time:** HS(phase A) → winding → LS(phase B). Two FETs carry I_ph.
- **PWM off-time:** LS(phase A, sync-rect) → winding → LS(phase B). Two FETs still carry I_ph.

So at every instant, **two channels' worth of R_ds(on)** carries the full phase current, regardless of duty D. Each FET conducts for 120° electrical, which is 1/3 of the period.
