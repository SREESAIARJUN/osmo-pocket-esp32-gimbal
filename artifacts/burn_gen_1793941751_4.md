# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #14 spec, so this design states its assumptions explicitly. Every gain is derived from motor and plant parameters, so you can substitute your real numbers directly.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), or any Cortex-M4F/M7 |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.09 N·m/A |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5048A) via SPI or ABZ |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the payload centroid |
| Bus voltage | 12–16 V |

The control runs as nested loops at decreasing rates:

```
 ┌──────────────── 1 kHz ────────────────┐
 │ Attitude error (quaternion) → angle P │──► ω_ref (per joint)
 └───────────────────────────────────────┘
 ┌──────────────── 4 kHz ────────────────┐
 │ Velocity PI (gyro-rate feedback)      │──► i_q,ref
 │ + inertia FF + cogging FF + friction  │
 └───────────────────────────────────────┘
 ┌──────────────── 20 kHz (PWM ISR) ─────┐
 │ Encoder → PLL → θ_e                    │
 │ Clarke/Park → d/q PI + decoupling      │──► SVPWM duty
 └───────────────────────────────────────┘
 IMUs: ODR 8 kHz, hardware AAF, FIFO burst read at 4 kHz → fusion
```

Loop rates are separated by at least 4–5× in bandwidth so that each inner loop looks like unity gain to the loop around it.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

**Clarke transform (amplitude invariant, with i_a + i_b + i_c = 0):**

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)
$$

**Park transform (θ_e = p·θ_m − θ_offset):**

$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant Model (SPMSM, L_d = L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

The electromagnetic torque is:

$$
\tau_e = \tfrac{3}{2}p\lambda_m i_q = K_t i_q
$$

### 1.3 PI Design by Pole-Zero Cancellation

Each axis, after decoupling, is the first-order plant $G(s)=\frac{1}{Ls+R}$. Use a PI controller $C(s)=K_p + K_i/s$ and choose $K_i/K_p = R/L$ so the controller zero cancels the plant pole. The closed loop then becomes first-order:

$$
\boxed{K_p = L\,\omega_c,\qquad K_i = R\,\omega_c}
\quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}
$$

Choose $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz PWM this gives $\omega_c = 2\pi\cdot 1000$ rad/s. With the assumed motor: K_p = 13.2 V/A and K_i = 35 186 V/(A·s).

### 1.4 Decoupling and Back-EMF Feedforward

$$
v_d^* = PI_d(e_d) - \hat\omega_e L\, i_q,\qquad
v_q^* = PI_q(e_q) + \hat\omega_e (L\, i_d + \lambda_m)
$$
