# STM32H743 Nano FC + 4-in-1 ESC (Job #64): System Architecture, Loss Model, DShot DMA Plan, and Netlist

## 0. Architecture Corrections and Feasibility

Three points need settling before any numbers are trustworthy.

**1. The H743 should not run the ESC commutation.** ArduPilot does not commutate BLDC motors. The correct architecture is:
- The **STM32H743** runs ArduPilot and generates bi-directional DShot600.
- **Four ESC MCUs** (for example AT32F421 or STM32G071) run AM32 or BLHeli_32. Each does 6-step or FOC commutation, PWM at 48 kHz, and returns eRPM telemetry over the same DShot wire.

Putting commutation for 4 motors on the H743 alongside the EKF is not supported by ArduPilot and is not recommended.

**2. "80 A burst" must be defined.** I model **80 A phase current per motor** (≈72 A battery-side at D = 0.9). Four motors means **~290–320 A from the pack**. That exceeds XT60 (60 A continuous) and XT90 ratings and requires ≥ 8 AWG leads.

**3. A 20×20 mm "nano" board cannot hold 4×80 A even briefly.** Section 3 shows it reaches thermal limits in about 2–4 s. I give the math for the requested spec, then a recommended derating.

All device parameters below are **assumed representative values**. Replace them with the datasheet values for the parts you select.

### 1.2 Current path
In 6-step commutation with synchronous rectification, **two FETs are always in series with the phase current I** (one high-side, one low-side). This holds whether the PWM-ed leg is in its ON state or its freewheel state.

Total conduction loss per motor channel:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j) + I^2 R_{Cu}$$

Per-FET distribution with high-side PWM at duty D (each leg active 1/3 of the electrical cycle):

$$P_{HS} = \tfrac{D}{3} I^2 R_{DS}, \qquad P_{LS} = \tfrac{2-D}{3} I^2 R_{DS}$$

Check: 3·D/3 + 3·(2−D)/3 = 2 ✓

### 1.3 Numbers at I = 80 A, T_j = 100 °C (R_DS = 0.98 ≈ 1.0 mΩ; 1.05 mΩ used with layout margin)

- I²R = 6400 × 1.05 mΩ = **6.72 W**
- P_cond,ch = 2 × 6.72 = **13.44 W**
- Copper/via/solder path at 0.5 mΩ: 6400 × 0.5 mΩ = **3.2 W**
- **Total conduction ≈ 16.6 W per motor**

Per FET at D = 0.9:
- HS: 0.30 × 6.72 = 2.02 W
- LS: 0.37 × 6.72 = 2.46 W

## 2. Switching Loss Model at f_sw = 48 kHz

Operating point: V_bus = 25.2 V (6S full), I = 80 A. Gate driver of ~1.5 A source/sink, giving t_r ≈ t_f ≈ 20 ns.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f | ½·25.2·80·40 ns·48k = **1.94 W** |
| Dead-time diode | V_SD·I·2·t_dt·f (t_dt = 100 ns) | 0.8·80·200 ns·48k = **0.61 W** |
| Reverse recovery | Q_rr·V·f | 40 nC·25.2·48k = **0.05 W** |
| C_oss | ½·C_oss·V²·f (×2 FETs) | 2·0.5·1 nF·635·48k = **0.03 W** |
| Gate drive (driver dissipation) | Q_g·V_GS·f (×2 switching FETs) | 2·50 nC·10·48k = **0.05 W** |
| **P_sw,ch** | | **≈ 2.68 W** |

Notes:
- **At D = 1.0 there is no PWM switching**, so P_sw → 0. The worst *combined* case is D ≈ 0.85–0.95, so I use D = 0.9.
- Switching loss is split as follows:
  - HS FET: ≈ 1.94/3 ≈ 0.65 W average (each HS PWMs for 1/3 of the cycle).
  - Paired LS FET: diode and Q_rr losses ≈ 0.22 W.

### 2.1 Totals at D = 0.9, I = 80 A

| Level | Loss |
|---|---|
| Per motor channel | 16.6 + 2.7 ≈ **19.3 W** |
| 4-in-1 ESC | **≈ 77 W** |
| Plus FC/BEC (5 V/3 A buck at 90 %, plus H743 ≈ 0.6 W) | **≈ 79 W total board dissipation** |
| Hottest single FET (LS) | 2.46 + 0.22 ≈ **2.7 W** |
| Hottest HS FET | 2.02 + 0.65 ≈ **2.7 W** |

### 2.2 Junction temperature (solve iteratively, because R_DS depends on T_j)

$$T_j = T_{pcb} + P_{FET}(T_j)\cdot R_{\theta J\text{-}PCB}$$

$$T_j \approx T_{pcb} + 2.7 \times 2.0 = T_{pcb} + 5.4\ \text{K}$$

The FET-to-board drop is small. **The board, not the die, is the limiter.**
