# STM32H743 AIO Flight Controller + 4-in-1 80 A ESC: Design Model (Job #20)

## 0. Scope and Architecture Decisions

Three facts constrain everything else in this design.

1. **The H743 does not commutate motors.** It runs ArduPilot and emits bi-directional DShot600. Each motor needs its own commutation MCU running AM32, which generates the 48 kHz PWM. I've specified **4× AT32F421K8U7** (AM32-native), one per motor.
