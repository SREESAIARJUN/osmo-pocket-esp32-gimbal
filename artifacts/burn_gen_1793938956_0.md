|---|---|---|---|

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle:

$$\theta_e = N_p\,\theta_m - \theta_{\text{off}}$$

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupling

The d-q plant for an SPMSM is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Feedforward decoupling is:

$$v_d = u_d - \omega_e L i_q,\qquad v_q = u_q + \omega_e L i_d + \omega_e\lambda_m$$

This leaves two decoupled first-order plants $1/(Ls+R)$.

### 1.3 PI Tuning by Pole-Zero Cancellation

Choose $K_p = L\,\omega_c$ and $K_i = R\,\omega_c$. The closed loop then becomes $\omega_c/(s+\omega_c)$.

With $\omega_c = 2\pi\cdot1500$:
- $K_p = 18.8$ V/A
- $K_i = 9.4\times10^4$ V/(A·s)

The discrete form uses backward Euler with $T_s = 50\,\mu s$:

$$u[k] = K_p e[k] + I[k],\qquad I[k+1] = I[k] + K_i T_s e[k] + K_{aw}(u_{\text{sat}}[k] - u[k])$$

The back-calculation gain is $K_{aw} = 1/K_p \cdot K_i T_s$, i.e. tracking time constant $T_t = K_p/K_i$.

Voltage limiting is a circular limit. Give priority to d, then q gets the remainder:

$$|v_q| \le \sqrt{V_{\max}^2 - v_d^2}$$

where $V_{\max} = V_{dc}/\sqrt3$, the SVPWM linear limit.

### 1.4 SVPWM by Min-Max Zero-Sequence Injection

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically identical to sector-based SVPWM and is cheaper to compute.
