# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

I don't have the Job #41 specification, so this design uses stated assumptions (§0). Every assumption is a named constant in the code, so you can substitute your actual motor, encoder and MCU values.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (12 slots, p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MT6701 class), SPI |
| MCU | STM32G4/H7 class, single-precision FPU |
| PWM | 25 kHz, center-aligned, ADC triggered at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro/accel ODR = 8 kHz |
| Loop rates | Current 25 kHz · Velocity 5 kHz · Angle 1 kHz · Attitude fusion 8 kHz (decimated to 1 kHz output) |

## 1. Field-Oriented Control (Innermost Loop, 25 kHz)

### 1.1 Coordinate Transforms

**Electrical angle:**
θ_e = p·(θ_m − θ_offset) mod 2π

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Space-Vector PWM (Min-Max Zero-Sequence Injection)

1. Phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Zero-sequence offset: v_0 = −½·(max(v_a, v_b, v_c) + min(v_a, v_b, v_c))
3. Duty cycles: D_x = ½ + (v_x + v_0) / V_bus, clamped to [D_min, D_max]
4. Linear range: |v_αβ| ≤ V_bus/√3

### 1.3 Current-Loop Plant and PI Design

**Plant (dq frame):**
- L·di_d/dt = v_d − R·i_d + ω_e·L·i_q
- L·di_q/dt = v_q − R·i_q − ω_e·L·i_d − ω_e·λ_m

**Controller.** Use a PI with cross-coupling and back-EMF decoupling feedforward:

v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m
v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q

**Gain selection.** Pole-zero cancellation (zero at R/L) gives a first-order closed loop with bandwidth ω_c:
- K_p,i = L·ω_c
- K_i,i = R·ω_c
- ω_c ≤ 2π·f_pwm / 20. At 25 kHz this gives ω_c ≈ 2π·1.25 kHz.

**Torque:**
- τ = (3/2)·p·λ_m·i_q = K_t·i_q
- Set i_d* = 0, since the motor is a surface-mount PMSM.

### 1.4 Rotor Velocity Estimate (Encoder PLL)

Differentiating a 14-bit encoder directly is too noisy, so use a type-2 PLL:

- e = wrap_π(θ_meas − θ̂)
- ω̂ ← ω̂ + K_i·e·T
- θ̂ ← θ̂ + (ω̂ + K_p·e)·T

with K_p = 2ζω_n, K_i = ω_n², ζ = 0.707, ω_n ≈ 2π·300 rad/s.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical Plant per Axis

J·ω̇ = K_t·i_q − b·ω − τ_cog(θ_m) − τ_dist

### 2.2 Velocity Loop (PI, 5 kHz)

**Gain selection.** Choose the crossover ω_v ≤ ω_c/5 and the PI zero at ω_v/N (N ≈ 4):
- K_p,v = J·ω_v / K_t
- K_i,v = K_p,v·ω_v / N

**Discrete form:** forward-Euler integrator with back-calculation anti-windup:
- u = K_p·e + I
- u_sat = clamp(u, ±I_max)
- I ← I + T·[K_i·e + K_aw·(u_sat − u)], with K_aw ≈ K_i/K_p

**Velocity feedback for stabilization.** Use the inertial camera rate rather than the motor rate:

ω_fb = (ŵ_cam)_axis, from the fused IMUs (§4), complementary-blended with the encoder rate:

ω_fb = α·ω_imu + (1 − α)·ω_enc,  α → 1

The encoder rate is retained for startup, for IMU-fault fallback, and as a low-latency term.

### 2.3 Angle Loop (P + Rate Feedforward, 1 kHz)

ω* = K_θ·wrap_π(θ* − θ̂_cam) + ω*_ff

- K_θ = ω_θ, with ω_θ ≤ ω_v/4
- An optional small integral term K_iθ handles static imbalance.
