# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #23 specification, so this design uses typical brushless gimbal hardware. Every assumption is a parameter in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P → pole pairs `p = 7`, slots `Ns = 12` |
| Phase R / L / λ | 10 Ω / 2.5 mH / 0.004 V·s/rad (electrical) |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each joint |
| Current sensing | 2- or 3-shunt, sampled at PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz |

Timescale separation follows a rule of at least 5× bandwidth between loops:
- current ≈ 1.5–2 kHz
- velocity ≈ 80–150 Hz
- angle ≈ 10–20 Hz

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Coordinate transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda)$$
