# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #42 specification, so this design states its assumptions explicitly. Every parameter lives in one config struct so you can substitute your real values.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.12 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), read at 20 kHz |
| Inverter | 3-phase, center-aligned PWM 20 kHz, low-side shunts (2 or 3) |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro/accel ODR 8 kHz |
| Platform | Multirotor-mounted, so propeller-driven vibration of 80–400 Hz plus harmonics is present |

### Multi-rate loop structure

```
           1 kHz                  4 kHz                   20 kHz
 θ_ref ─►[Angle P + FF]─ω_ref─►[Velocity PI]─i_q*─►(+)─►[Current PI d/q]─►[SVPWM]─► Motor
          ▲                    ▲               i_cog ┘     ▲
          │ θ_cam (fused IMU)  │ ω_cam (gyro)  ▲           │ i_abc, θ_e (encoder)
          │                    │               │
     [Mahony AHRS]◄──[Dual-IMU fusion + notch/LPF]   [Anti-cogging FF(θ_m)]
                     8 kHz
```

The rate rule of thumb is that each inner loop bandwidth should be at least 4–5× its outer loop's:

- Current loop: ω_c ≈ 2π·1.5 kHz.
- Velocity loop: ω_v ≈ 2π·120 Hz.
- Angle loop: ω_θ ≈ 2π·25 Hz.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off comes from an alignment procedure: apply V_d at θ_e = 0 and read the encoder.

Latency compensation: the PWM update takes effect about 1.5 T_s after sampling, so the angle used in the inverse Park transform is advanced:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt 3}\quad(\text{assumes } i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM dq model

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI with decoupling (pole-zero cancellation)

The plant is G_i(s) = 1/(Ls + R). Choose the PI zero to cancel the plant pole:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop then becomes a first-order system, i_q/i_q* = ω_c/(s+ω_c).
