# STM32H743 Nano FC + 4-in-1 ESC: Design Model (Job #0)

## 0. Scope, Assumptions and Corrections

Your brief did not specify the MOSFETs, battery voltage, board size or cooling, so I have stated every assumption as an explicit parameter. Swap in datasheet values and the equations still hold.

**Architecture correction.** In a 4-in-1 stack the STM32H743 runs ArduPilot on the flight controller. It does **not** commutate the motors. Each ESC channel needs its own commutation MCU (AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU closes the commutation loop and answers bi-directional DShot. The H743's job is to generate DShot600 and decode the eRPM telemetry. The model below covers both sides.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (22.2 V nominal) |
| Form factor | "Nano" = 20×20 mm mounting, ~26×26 mm board, 6-layer, 2 oz Cu |
| Burst | 80 A per channel, phase current, ≤ 2 s |
| MOSFET (per switch) | 40 V, PQFN 3.3×3.3 class |
| R_ds(on) | 1.2 mΩ @ 25 °C, temperature coefficient ≈ +0.6 %/K |
| Q_g / Q_gs2+Q_gd / Q_oss / Q_rr | 30 nC / 8 nC / 25 nC / 30 nC |
| Body-diode V_f @ 80 A | 0.85 V |
| R_θJC | 1.5 K/W |
| Gate driver | FD6288Q-class, V_drv = 10 V, effective R_g ≈ 3.5 Ω |
| Modulation | 6-step trapezoidal, complementary synchronous PWM, f_sw = 48 kHz, dead time 100 ns |

**Realism warning.** 80 A per channel on a 20×20 board is a marketing number. The model below shows it is thermally sustainable only for roughly 1 s. Design the burst rating from the transient model, not from the steady-state one.

## 1. Conduction Loss Model

In 6-step operation two phases conduct at any instant:

- **Phase A (PWM phase):** the high side Q_AH conducts for duty D. The synchronous low side Q_AL conducts for (1−D), minus dead time.
- **Phase B (return phase):** the low side Q_BL conducts continuously for the 60° sector.

Temperature-corrected on-resistance:

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)],\quad \alpha=0.006\,\text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.2 mΩ × 1.6 = **1.92 mΩ**.

Conduction loss per channel:

$$P_{cond}=I^2R_{ds}(T_j)\big[D+(1-D-2t_{dt}f_{sw})\big]+I^2R_{ds}(T_j)\approx 2I^2R_{ds}(T_j)$$

$$P_{cond}=2(80)^2(1.92\times10^{-3}) = \mathbf{24.6\ W}$$

Copper and solder add to this. Phase path resistance (pads + vias + pours) is about 0.3 mΩ:

$$P_{Cu}=I^2R_{Cu}=6400\times0.3\times10^{-3}=1.9\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate drive currents and transition times

Assume a Miller plateau V_pl ≈ 3.0 V.

- Turn-on gate current: I_g,on = (V_drv − V_pl)/R_g = 7/3.5 = **2.0 A**
- Turn-off gate current: I_g,off = V_pl/R_g = 3/3.5 = **0.86 A**

Transition times:

$$t_r=\frac{Q_{gs2}+Q_{gd}}{I_{g,on}}=4\text{ ns},\qquad t_f=\frac{8\text{ nC}}{0.86}=9.3\text{ ns}$$

Real layout inductance roughly doubles these. Use **t_r ≈ 10 ns** and **t_f ≈ 15 ns**.

### 2.2 Loss components per channel (only the PWM phase hard-switches)

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·25 ns·48k | **1.21 W** |
| Output charge | Q_oss·V·f_sw = 25n·25.2·48k | 0.030 W |
| Reverse recovery | Q_rr·V·f_sw = 30n·25.2·48k | 0.036 W |
| Dead-time diode | V_f·I·2t_dt·f_sw = 0.85·80·200n·48k | **0.65 W** |
| Gate drive (2 FETs) | 2·Q_g·V_drv·f_sw | 0.029 W |
| **P_sw total** | | **≈ 1.96 W** |

### 2.3 Totals

- **Per channel:** P_cond + P_Cu + P_sw ≈ 24.6 + 1.9 + 2.0 = **28.5 W**
- **Four channels at simultaneous burst:** **≈ 114 W**

Conduction is about 86 % of the loss. Raising f_sw from 24 to 48 kHz costs only about 1 W per channel, so 48 kHz is justified by acoustic and current-ripple benefits. The lever that actually matters is R_ds(on). Paralleling two FETs per switch halves P_cond; it costs board area you probably do not have.

## 3. Thermal Model

### 3.1 Per-FET loss split

| Switch | Loss | Value |
|---|---|---|
| Q_BL (continuous) | I²R | 12.3 W |
| Q_AH (D = 0.5) | 6.1 W + 1.21 W sw | 7.4 W |
| Q_AL | 6.1 W + 0.65 W diode | 6.8 W |

Commutation rotates the roles every 60°, so the time-averaged loss per FET is (28.5 − 1.9)/6 × 2 ≈ **8.9 W**. That figure uses 6 FETs per channel with 2 of them active.

Peak junction rise over case for Q_BL:

$$\Delta T_{jc}=12.3\times1.5=\mathbf{18.5\ K}$$

### 3.2 Board heat capacity (lumped, 26×26 mm)

| Element | Calculation | Heat capacity |
|---|---|---|
| Copper | 676 mm² × 6 layers × 70 µm = 0.284 cm³ → 2.54 g | 0.98 J/K |
| FR4 | 676 mm² × 1.6 mm = 1.08 cm³ → 2.0 g | 2.2 J/K |
| 24 FETs + caps + solder | ~1.5 g | 0.8 J/K |
| **Total C_th** | | **≈ 4.0 J/K** |

### 3.3 Foster network (junction → ambient)

| Stage | R_i (K/W) | τ_i |
|---|---|---|
| Die → case | 0.5 | 0.3 ms |
| Die → case | 1.0 | 3 ms |
| Case → local copper spread | 2.0 | 80 ms |
| Board → air (prop-wash, ~5 m/s) | 3.5 (whole board) | 14 s |

Transient junction temperature:

$$T_j(t)=T_a+\sum_i P_iR_i\left(1-e^{-t/\tau_i}\right)$$

### 3.4 Burst result

Start from T_a = 35 °C and a board pre-warmed to 60 °C by 30 A cruise. Apply 114 W total.

- **Board heating rate:** 114/4.0 ≈ **28.5 K/s** (adiabatic; airflow removes only ~7 K/s at a 25 K rise)
- **Local stack:** 12.3 W × (1.5 + 2.0) ≈ 43 K, settling in about 0.3 s

$$T_j(t)\approx 60 + 43 + 21.5\,t\ \ [^\circ\text{C}]$$
