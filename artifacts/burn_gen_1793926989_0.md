## 0. Assumptions

The architecture is a standard three-level cascade:

```
θ_ref ─►[Angle P/PI]─► ω_ref ─►[Velocity PI]─► iq_ref ─(+)─► [Current PI d/q] ─► SVPWM ─► Motor
                ▲                   ▲                 iq_ff (anti-cogging, accel FF)
                │                   │
     attitude (Mahony on      fused gyro rate
     fused dual-IMU data)     (notch + LPF filtered)
```

## 1. FOC Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform, using the electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform applies the transpose of the same matrix.

### 1.2 Plant and gain design

The d/q voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

After decoupling, each axis reduces to the first-order plant G(s) = 1/(Ls + R).

Use a PI controller C(s) = K_p + K_i/s and choose the gains for pole-zero cancellation:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Bandwidth guideline: ω_c ≤ 2π·f_pwm/20. At 20 kHz this gives ω_c ≈ 2π·1000 rad/s.

Feedforward decoupling terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,\qquad \lambda_m = \frac{2K_t}{3p}$$

### 1.3 Discrete PI with back-calculation anti-windup

Sample time T, saturation sat(·), anti-windup gain K_aw ≈ K_i/K_p:

$$u_k = K_p e_k + I_k,\qquad \bar u_k = \mathrm{sat}(u_k)$$
$$I_{k+1} = I_k + T\left[K_i e_k + K_{aw}(\bar u_k - u_k)\right]$$

### 1.4 Voltage limiting and SVPWM

Limit the voltage vector magnitude, giving v_d priority:

$$\|v_{dq}\| \le \frac{V_{bus}}{\sqrt3}$$

Then apply min-max zero-sequence injection (equivalent to SVPWM). For each phase:

$$v_x' = v_x - \tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x'}{V_{bus}}$$

## 2. Velocity and Angle Loops

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

With the current loop treated as ideal (ω_c much greater than ω_v), the velocity plant is Kt/(Js).

### 2.2 Velocity PI (symmetric-optimum style)

Choose the crossover ω_v ≈ ω_c/8 and spacing factor a = 3–4:

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\frac{\omega_v}{a^2}$$

### 2.3 Velocity feedback

The velocity loop uses the gimbal-frame gyro rate projected onto the motor axis, rather than a differentiated encoder signal. For gimbal stabilization, the inertial rate is what you want to null.

A blend is useful for robustness:

$$\hat\omega = \mathrm{LPF}_{f_1}\!\big(\Delta\theta_{enc}/T_v\big) + \mathrm{HPF}_{f_1}\!\big(\omega_{gyro,axis}\big)$$

- If you fully trust the IMU, set f_1 → 0.
- If you are stabilizing relative to the frame, use the encoder.
