## 0. System Partitioning and Assumptions

The H743 does not drive the MOSFETs directly. The architecture has two layers:

```
┌──────────────── STM32H743 (ArduPilot) ────────────────┐
│ TIM1 CH1–4 ── Bi-dir DShot600 ──┐                     │
└─────────────────────────────────┼─────────────────────┘
          ┌───────────┬───────────┼───────────┐
     ESC MCU #1   ESC MCU #2   ESC MCU #3   ESC MCU #4   (AM32 on STM32G071 / AT32F421)
     48 kHz PWM   → 3-phase gate driver → 6× N-MOSFET → motor
```
