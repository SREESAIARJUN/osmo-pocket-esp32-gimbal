# STM32H743 FC with Integrated 4-in-1 ESC (Job #23): Architecture & Analysis

## 0. Scope, Assumptions, and Design Flags

### Architectural partitioning

The STM32H743 does **not** drive the power stage directly. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32-class firmware. That MCU generates the 48 kHz complementary PWM. The H743 runs ArduPilot and sends bi-directional DShot600 to each ESC MCU.
