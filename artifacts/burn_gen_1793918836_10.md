# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #52 specification, so this design uses the assumptions in §0. Every parameter is a named constant, so you can substitute your real hardware values without changing the structure.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class (Cortex-M4F, 170 MHz, FPU, CORDIC optional) |
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5047P) per axis |
| Current sense | 2 or 3 low-side shunts, sampled at PWM center |
| PWM / current loop | 20 kHz, center-aligned |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI + DMA, ODR 8 kHz, gyro read at 4 kHz |
| Velocity (rate) loop | 4 kHz |
| Angle loop | 1 kHz |

**Loop timing**

```
TIM1 update (20 kHz)  ─► ADC inject ─► CurrentLoop ISR   (priority 0)
IMU DRDY/FSYNC (4 kHz)─► SPI DMA ─► Fusion + RateLoop     (priority 1)
SysTick/TIMx (1 kHz)  ─► AngleLoop + notch retune + Mahony (priority 2)
```
