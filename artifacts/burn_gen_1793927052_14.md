## 0. Architectural Ground Truth (Read First)

Three corrections to the brief, because they change the math.

1. **The H743 should not commutate the motors.** It has only two advanced timers with complementary outputs (TIM1, TIM8). That is 6 complementary pairs, but 4 motors need 12. Running 4× 48 kHz commutation loops alongside the ArduPilot EKF3 scheduler is also poor partitioning.
   - **Adopted architecture:** H743 runs ArduPilot and emits bi-directional DShot600 to **4× AT32F421K8U7 (AM32 firmware)**, one per motor. Each AT32 drives its own gate driver and 6 MOSFETs at 48 kHz.
2. **"80A burst" is a phase-current transient, not a continuous rating.** Section 3 shows a 30×30 board cannot hold 4×80A in steady state. The model below gives the burst *duration* limit.
3. **Board class.** 80A per channel is not achievable on a 20×20 "nano" footprint. The model assumes **30.5×30.5 mounting on a 37×37 mm, 8-layer, 2 oz board**. If 20×20 is a hard requirement, scale to roughly 35–45A burst (Section 3.6).

All component parameters below are **representative values for the model**. Replace them with the datasheet values of the selected parts before tape-out.

| Symbol | Meaning | Value |

| Q_g | Total gate charge | 60 nC |

| t_dead | Dead time (AM32 setting) | 100 ns per edge |
| V_SD | Body-diode forward voltage at 80A | 0.8 V |
| R_cu | PCB copper resistance, bus → phase pad, per conducting path | 0.25 mΩ |
| T_amb | Ambient inside the frame stack | 35 °C |

**Conduction topology.** In 6-step trapezoidal operation with synchronous (complementary) PWM, exactly two phase legs carry current:

- **Driven leg:** the high-side FET conducts for duty D, and the low-side FET (synchronous rectification) conducts for 1−D.
- **Return leg:** the low-side FET conducts continuously for the 60° sector.

Battery current and phase current are related by **I_batt ≈ D·I_ph**. The 80A phase burst occurs mainly at high D (punch-outs), but conduction loss is nearly D-independent with synchronous rectification. This is shown next.

## 2. Loss Model (per motor channel)

### 2.1 Conduction losses

The hot on-resistance is:

$$R_{ds,hot} = k_T \cdot R_{ds(on),25} = 1.6 \times 0.90 = 1.44\ \text{m}\Omega$$

The driven leg dissipates:

$$P_{drv} = I^2 R_{ds,hot}\,[D + (1-D)] = I^2 R_{ds,hot}$$

The return leg dissipates:

$$P_{ret} = I^2 R_{ds,hot}$$

Total MOSFET conduction loss:

$$P_{cond,FET} = 2 I^2 R_{ds,hot} = 2(80)^2(1.44\times10^{-3}) = \mathbf{18.43\ W}$$

Copper loss (two current paths per channel):

$$P_{cu} = 2 I^2 R_{cu} = 2(6400)(0.25\times10^{-3}) = \mathbf{3.20\ W}$$

**Temperature coupling.** R_ds is itself a function of T_j, which creates positive feedback. A linearized form:

$$R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.006\ \text{K}^{-1}$$

Iterate this with the thermal model in Section 3. At these values it converges in 2–3 iterations. Thermal runaway occurs if:

$$\frac{\partial P}{\partial T_j}\, R_{th} \ge 1$$

### 2.2 Switching losses (hard-switched edge, driven leg only)

**Overlap (V-I crossover):**

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5(25.2)(80)(30\times10^{-9})(48\times10^3) = \mathbf{1.452\ W}$$

**Reverse recovery** (the synchronous FET's body diode recovers at each turn-on):

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = (50\times10^{-9})(25.2)(48\times10^3) = \mathbf{0.060\ W}$$

**Output capacitance:**

$$P_{oss} \approx \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} \cdot 2 = (60\times10^{-9})(25.2)(48\times10^3) = \mathbf{0.073\ W}$$

**Dead-time body-diode conduction** (two dead-time intervals per period):

$$P_{dt} = V_{SD} I (2 t_{dead}) f_{sw} = 0.8(80)(200\times10^{-9})(48\times10^3) = \mathbf{0.614\ W}$$

**Gate drive** (the driven-leg HS/LS pair switches; dissipated mostly in the driver and R_g):

$$P_{gate} = 2 Q_g V_{GS} f_{sw} = 2(60\times10^{-9})(10)(48\times10^3) = \mathbf{0.058\ W}$$
