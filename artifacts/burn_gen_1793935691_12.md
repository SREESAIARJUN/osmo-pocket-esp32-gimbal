# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #20, so this design starts from a stated baseline. Every parameter is a named constant, so you can substitute your hardware's values.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC (use it for sin/cos and atan2) |
| Motors | 3 × GBM2804-class, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701) |
| Current sense | 2 or 3 in-line/low-side shunts, synchronous ADC sampling at PWM center |
| PWM | 20 kHz center-aligned |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, FIFO + timestamp |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

**Loop rates** (each loop at least 5× above the bandwidth of the loop it feeds):

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz | ~60–120 Hz |
| Angle / attitude | 1 kHz | ~10–20 Hz |
| IMU fusion and filters | 8 kHz in, decimated to 4 kHz | — |
