# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for "Job #39", so the design below rests on explicit assumptions. Every parameter is a named constant, so you can substitute your real hardware values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO or DRDY |
| Bus | Vbus = 12–16 V |

| Loop | Rate | Target bandwidth | Feedback |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | 1.5–2 kHz | Phase currents + encoder θe |
| Velocity (PI) | 4 kHz | 80–150 Hz | Filtered fused gyro (inertial) blended with encoder PLL |
| Angle / attitude (P + I) | 1 kHz | 15–30 Hz | Mahony quaternion from fused IMUs |
| IMU filtering and fusion | 8 kHz → decimated to 4 kHz | — | 2× ICM-42688-P |

**Design rule:** each outer loop's bandwidth should be at most 1/5 of the inner loop's, after accounting for filter group delay (see §5.5).

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform, assuming balanced currents (i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix},\qquad \theta_e = p\,(\theta_m-\theta_{\text{off}})$$
