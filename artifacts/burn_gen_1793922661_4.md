# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #7 spec sheet, so this design uses the assumptions below. Every one of them is a constant in `Config`, so you can change them without touching the algorithms.

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with single-precision FPU |
| Motors | 12N14P gimbal BLDC, R ≈ 5–15 Ω, L ≈ 2–5 mH, 14-bit magnetic encoder per axis |
| Kinematics | Yaw (Z) → Roll (X) → Pitch (Y), IMUs mounted on the camera plate |
| Loop rates | Current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, IMU ODR 8 kHz |
