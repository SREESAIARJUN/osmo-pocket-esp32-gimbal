## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g., GBM2804-class), 7 pole pairs, 12 slots, R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Driver | 3-phase half-bridge with low-side shunts on 2 phases (or inline), 12-bit ADC |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates (all synchronized to the PWM timer):**

```
PWM / current loop (FOC)      20 kHz   (Ts_i = 50 µs)   ISR, highest priority
IMU sampling + filters         8 kHz   (FIFO / DRDY)
Velocity loop                  4 kHz   (Ts_v = 250 µs)  every 5th current ISR
Angle / attitude loop          1 kHz   (Ts_a = 1 ms)
Cogging LMS update             1 kHz   (background)
```

**Control structure per axis:**

```
θ_ref ─►(+)─► Angle P(I) ─►(+)─► Velocity PI ─►(+)─► i_q* ─► Current PI (d,q) ─► SVPWM ─► Motor
        ▲-                ▲- ▲ω_ff            ▲- ▲ i_ff,accel + i_ff,cog
        │                 │                   │
   attitude (IMU AHRS)    ω (dual-IMU gyro, mapped to joint frame)  ◄── encoder PLL fallback
```

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \mod 2\pi$$

Here $p$ is the number of pole pairs. $\theta_{\text{offset}}$ is found at startup by applying $v_d = V_{\text{align}}$ at $\theta_e = 0$ and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, balanced currents with $i_a + i_b + i_c = 0$)

$$i_\alpha = i_a, \qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$
