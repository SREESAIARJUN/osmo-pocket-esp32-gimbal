# STM32H743 Nano FC + 4-in-1 ESC (Job #63): Electro-Thermal Model and ArduPilot DShot Architecture

## 0. Scope, Assumptions and a Feasibility Flag

The numbers below come from a parametric model with representative component values. Replace every parameter marked **[DS]** with figures from the MOSFET, driver and capacitor datasheets you actually procure before release.

**System partition:**

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 @ 480 MHz | ArduPilot, bidirectional DShot600 master |
| ESC (×4 channels) | 4× STM32G071 (or AT32F421) running AM32 | 6-step commutation, 48 kHz PWM, eRPM telemetry |
| Gate driver (×4) | FD6288Q-class three-phase bootstrap driver | 6 gates per channel |
| Power stage | 24× 40 V N-MOSFET, PDFN 3.3×3.3 | 6 per channel |
| Bus | 6S LiPo, V_bus,max = 25.2 V | |

**Interpretation of "80 A burst":** the model assumes 80 A per channel, all four channels simultaneously. That is the worst case. Section 4.5 shows the per-motor-only and 80 A-total cases.

> **Feasibility flag:** A 20×20 mm "nano" 4-in-1 cannot sustain 4×80 A at 6S for more than about 1 second. The model in §4 shows why. The "80 A burst" rating is only defensible as a ≤1 s transient, or with a 30.5×30.5 mm board using 5×6 mm FETs. This should be resolved with the customer before layout freeze.

## 2. Conduction Loss Model (6-Step Trapezoidal, Synchronous Complementary PWM)

### 2.1 Commutation Structure

In each 60° sector:

- one phase is PWM'd complementary (high-side on for D, low-side on for 1−D);
- a second phase has its low-side held fully on;
- the third phase floats (used for BEMF zero-cross sensing).

Over 360° electrical, each phase spends 120° PWM-active, 120° low-held and 120° floating.
