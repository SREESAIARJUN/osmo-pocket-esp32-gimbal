# STM32H743 Flight Controller + 80 A 4-in-1 ESC (Job #28): Architecture, Loss Model, DShot DMA Plan, Netlist

## 0. Architecture Correction and Baseline Assumptions

**The STM32H743 should not commutate the motors directly.** It lacks the timers, DMA, and real-time margin to run four sensorless 6-step loops alongside ArduPilot. Use the standard split instead:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743 (400 MHz, Cortex-M7) | ArduPilot, bidirectional DShot600 master |
| ESC MCU ×4 | AT32F421 or STM32G071 class | AM32 or BLHeli_32-class firmware, 6-step commutation |
| Gate driver ×4 | 3-phase half-bridge driver (FD6288Q class), V_DRV = 10 V | Bootstrap high-side drive |
| Power stage ×4 | 6× 40 V N-MOSFET (12 V not used) | 3 half-bridges per motor |
