## 0. Architecture Correction and Assumptions

### 0.1 Architectural constraint

The STM32H743 cannot be the commutation controller for the four ESC channels under ArduPilot. ArduPilot does not implement sensorless BLDC commutation, and a single MCU cannot run four independent 48 kHz complementary-PWM, back-EMF zero-cross loops while also running the flight stack.

The correct topology is:

```
STM32H743 (ArduPilot FC) ──4× bidirectional DShot600──► 4× ESC MCU (AM32 / BLHeli_32-class)
                                                          └─► 3-phase gate driver ─► 6× N-FET per motor
```

The analysis below covers both domains.
