# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection (Job #11)

I don't have the Job #11 spec sheet, so this design rests on the assumptions below. Every one is a named constant in the code, so you can change it without touching the math.

| Item | Assumption |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (e.g., GBM2804-class), 12N14P, so pole pairs `Np = 7` |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-shunt low-side per axis (a voltage-mode fallback is included) |
| MCU | STM32G4/H7-class FPU, center-aligned PWM at 20 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Attitude 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, gyro and accel ODR = 8 kHz, ±2000 dps / ±4 g |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

## 1. Control Architecture

```
          ┌──────────────── 1 kHz ────────────────┐ ┌──── 4 kHz ────┐ ┌────── 20 kHz ──────┐
q_ref ──► │ Attitude P (SO(3) error) + ω_ff        │►│ Rate PI + J ff │►│ i_q PI ─► SVPWM   │──► Motor
          │   ω_ref(cam) ─► J⁻¹(θ) ─► θ̇_ref(joint) │ │ + anti-cogging │ │ i_d PI (=0)       │
          └──────────────▲─────────────────────────┘ └──────▲────────┘ └──────▲─────────────┘
                         │ q̂ (Mahony)                       │ ω̂ (blended)      │ i_a,i_b, θ_e
             Dual ICM-42688-P ─► align ─► fuse ─► notch/LPF ─┘  Encoder ─► PLL ┘
```

The bandwidths are separated by roughly 4–5× per stage. The current loop runs at about 2 kHz, the rate loop at 60–100 Hz, and the attitude loop at 15–20 Hz.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

The electrical angle is θ_e = N_p·(θ_m − θ_offset). A balanced load is assumed, so i_c = −i_a − i_b.

**Clarke (amplitude-invariant):**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**
$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

**Inverse Park:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 Plant and PI design

The dq model is:
$$L\dot i_d = v_d - Ri_d + \omega_e L i_q,\qquad L\dot i_q = v_q - Ri_q - \omega_e L i_d - \omega_e\lambda_m$$

**Gains by pole-zero cancellation.** The closed-loop target is i/i* = ω_c/(s+ω_c). This gives:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad(\text{continuous}),\qquad \omega_c \le 2\pi f_{pwm}/10$$

**Decoupling and back-EMF feedforward:**
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limit.** The dq voltage vector is circularly limited to |v| ≤ V_bus/√3, which is the SVPWM linear region.

**Anti-windup.** Back-calculation is used:
$$x_{k+1} = x_k + T_s\big[K_i e_k + K_{aw}(u^{sat}_k - u_k)\big],\qquad K_{aw}\approx K_i/K_p$$

### 2.3 SVPWM (min-max zero-sequence injection)

The phase voltages are obtained by inverse Clarke:
$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

The zero-sequence offset and duty cycles are:
$$v_0 = -\tfrac12(\max+\min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM.

### 2.4 Rotor speed: encoder PLL

The encoder angle is tracked with a type-II PLL. It gives a low-noise speed and unwraps the angle:
$$e=\mathrm{wrap}(\theta_{meas}-\hat\theta),\quad \hat\omega \mathrel{+}= T_s K_i e,\quad \hat\theta \mathrel{+}= T_s(\hat\omega + K_p e)$$

The gains come from ω_n and ζ:
$$K_p = 2\zeta\omega_n,\quad K_i=\omega_n^2 \qquad(\omega_n \approx 2\pi\cdot 300\ \text{Hz},\ \zeta=0.707)$$

## 3. Cascaded Attitude → Rate Control

### 3.1 Attitude error on SO(3) (1 kHz)

Let q̂ be the estimated camera quaternion and q_r the reference. The error quaternion is:
$$q_e = q_r^{*}\otimes\hat q$$

Choose the shortest path: if q_{e,w} < 0, set q_e ← −q_e. The camera-frame rate command is then:
$$\omega^{cam}_{ref} = -K_\theta\,\mathrm{sgn}(q_{e,w})\cdot 2\,\vec q_e + \omega^{ff}_{r}$$

Here 2·q⃗_e ≈ the rotation-vector error for small angles. ω_r^ff is the reference rate, used for smooth follow and pan modes. Set K_θ ≈ ω_v/5 (rad/s per rad).

### 3.2 Camera rate → joint rate (Jacobian)

The chain is Yaw (z) → Roll (x) → Pitch (y), with joint angles θ = [θ_y, θ_r, θ_p] from the encoders. The camera angular velocity in the camera frame is:

J = \begin{bmatrix}
-\cos\theta_r\sin\theta_p & \cos\theta_p & 0\\
\sin\theta_r & 0 & 1\\
\cos\theta_r\cos\theta_p & \sin\theta_p & 0
\end{bmatrix}$$
