## 0. Architecture Clarification and Key Assumptions

**Correction to the job title.** The STM32H743 does not commutate the motors. In every production 4-in-1 design it is the flight controller MCU. Each motor channel has its own small ESC MCU running AM32 or BLHeli_32-class firmware, typically an STM32G071 or AT32F421. The resulting partition is:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743 @ 400 MHz (ArduPilot default clocking) | Attitude control, BDShot600 TX/RX ×4 |
| ESC ×4 | STM32G071 / AT32F421 class | 6-step or FOC commutation, 48 kHz PWM, eRPM telemetry |
| Power stage ×4 | 3-phase gate driver + 6× N-MOSFET | Half-bridges |

**Feasibility warning (read before layout).** An 80 A per-channel rating on a nano (≈26×26 mm) board is a **burst-only** rating lasting single-digit seconds. Section 3 shows that steady-state 80 A on all four channels is physically impossible in this form factor. The thermal model therefore treats 80 A as a time-limited transient.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step complementary PWM

During any 60° sector two phases conduct:
- **PWM leg:** the high-side (HS) conducts for fraction D. The synchronous low-side (LS) conducts for the remaining 1−D.
- **Static leg:** the LS is fully on.

Motor current therefore always flows through **exactly two channels**. Per ESC channel:

$$P_{cond} = 2\,I_{rms}^2\,R_{DS}(T_j)$$

### 1.2 Ripple correction

For a triangular ripple of peak-to-peak ΔI:

$$I_{rms}^2 = I^2\left(1 + \frac{r^2}{12}\right), \qquad r = \frac{\Delta I}{I}$$

At 48 kHz with typical motor inductance (≈10–30 µH line-to-line), r ≲ 0.3. The correction is therefore ≈ +0.75%, which is negligible and dropped below.

### 1.3 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C:

$$R_{DS} = 0.90 \times 1.45 = 1.305\ \text{mΩ}$$

### 1.4 Conduction loss at 80 A

$$P_{cond} = 2 \times 80^2 \times 1.305\times10^{-3} = \mathbf{16.7\ W\ per\ channel}$$

Because loss depends on T_j and T_j depends on loss, the model must be closed with the thermal loop (Section 3.4).
