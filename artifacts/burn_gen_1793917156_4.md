## 0. Architecture Clarification and Assumptions

The STM32H743 does **not** commutate the motors. In any production AIO design, the H743 runs ArduPilot and sends bidirectional DShot600 to **four dedicated ESC MCUs** running AM32 or BLHeli_32. Those ESC MCUs generate the 48 kHz complementary PWM. The model below reflects that split.

## 1. Conduction Loss Model

### 1.1 Topology Reasoning

Assume 6-step trapezoidal drive with complementary (synchronous) PWM. At any instant, phase current flows through exactly one switch in the PWM'd leg (the high side during D, the synchronous low side during 1−D) and one static low-side switch in the return leg. Two switch positions therefore conduct at all times, outside dead time:

$$P_{cond,ch} = 2\, I^2\, R_{sw}(T_j), \qquad R_{sw}(T_j)=\frac{R_{25}\,[1+\alpha(T_j-25)]}{N_p}$$

This result does not depend on duty cycle. That is a useful property of synchronous rectification.

### 1.2 Temperature-Dependent Resistance

| T_j (°C) | Factor | R_sw (mΩ, N_p = 2) |
|---|---|---|
| 25 | 1.00 | 0.75 |
| 100 | 1.34 | 1.00 |
| 125 | 1.45 | 1.09 |

### 1.3 80 A Burst, T_j = 125 °C

$$P_{cond,ch} = 2 \times 80^2 \times 1.09\times10^{-3} = 13.9\ \text{W per motor}$$

With a single FET per switch (N_p = 1), this becomes 27.9 W per motor, which is not survivable on a nano board.

### 1.4 Thermal Runaway Check

Conduction loss rises with T_j, which in turn raises R_DS(on). The loop converges if:

$$\frac{\partial P}{\partial T}\cdot R_{th} < 1 \;\Rightarrow\; 2I^2 \frac{R_{25}\alpha}{N_p} R_{th} = 2(6400)(0.75\text{m})(0.0045)(R_{th}) = 0.043\,R_{th}$$

The design is stable for R_th < 23 K/W at the dominant node. The board node (≈6–8 K/W, §3) satisfies this, so there is no runaway.
