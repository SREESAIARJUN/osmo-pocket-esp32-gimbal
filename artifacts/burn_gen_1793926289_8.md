# STM32H743 AIO 4-in-1 ESC Nano FC: Power-Stage Thermal Model and Bi-Directional DShot Architecture

**Job #14, Rev A (engineering baseline)**

> **Scope and honesty note.** This package is a design baseline. Every MOSFET, driver and PCB parameter below is a stated assumption that must be replaced with values from the selected part's datasheet and verified on the bench (thermocouple and IR camera, double-pulse test). The math is general, so you can substitute your own numbers directly. One architectural point matters throughout: on a 4-in-1 AIO, the **H743 is the flight controller**. The 48 kHz commutation PWM is generated by **per-motor ESC MCUs** (assumed 4× AT32F421 running AM32), not by the H743. The H743 only sources DShot600 and decodes bi-directional telemetry.

---

## 1. System Architecture

```
 6S LiPo (25.2V max) ──┬── TVS + 4×470µF low-ESR bulk + 16×10µF/50V X7R per bridge
                       │
        ┌──────────────┴──────────────────────────────────────────┐
        │  4× [ AT32F421 (AM32) → FD6288Q 3-ph driver → 6× N-MOSFET ]  │
        └──────────────┬──────────────────────────────────────────┘
                       │ DShot600 bidir (1 wire/motor, 3.3V, open line w/ pull-up)
              STM32H743VIT6 @ 400 MHz (ArduPilot)
              TIM1_CH1..CH4 → M1..M4
```

**Design assumptions (form factor):**

* Board: 20×20 mm (nano), 6-layer, 2 oz copper on all layers.
* 12× ESC FETs are ganged onto 2 sides (the actual nano constraint). This requires 3.3×3.3 mm DFN parts.
* Ambient: 40 °C.
