## 0. Architecture Decisions and Assumptions

### 0.1 Architecture

The H743 should **not** commutate the motors. It runs ArduPilot and emits DShot600. Each motor channel gets its own small ESC MCU (AT32F421 / STM32G071 running AM32 or BLHeli_32). Reasons:

- ArduPilot has no 4-motor sensorless BLDC commutation stack.
- Running 4× 48 kHz complementary PWM plus BEMF zero-cross detection on the FC's timers would consume all advanced timers (TIM1/TIM8) and the ADCs that the FC needs.

```
            +-------------------- AIO PCB (30.5x30.5 or 25.5x25.5) ---------------------+
 6S ----+-->| VBAT bus -- bulk caps -- 4x [ESC MCU -> 3-ph driver -> 6x N-FET bridge] -> M1..M4
        |   |                ^ DShot600 BDShot (1 wire each, bidirectional)             |
        |   |   STM32H743 ---+  M1..M4  (TIM3_CH3/4, TIM5_CH1/2)                         |
        +-->| 12V/5V/3V3 bucks, IMU(SPI), baro(I2C), OSD, UARTs, SD, current sense ADC    |
            +-----------------------------------------------------------------------------+
```

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C: R_ds = 0.9 mΩ × (1 + 0.0065 × 85) = 0.9 × 1.553 = **1.40 mΩ**.

### 1.2 Six-step trapezoidal commutation with synchronous rectification (AM32 default)

In any 60° sector, two half-bridges carry I_ph:

- **Switching leg (duty D):** the high side conducts for D·T and the low side (synchronous rectifier) for (1−D)·T. That leg's loss is I²·R_ds regardless of D.
- **Return leg:** the low side is on for the whole sector, so its loss is I²·R_ds.

$$\boxed{P_{cond,ch} = 2\,I_{ph,rms}^2\,R_{ds}(T_j)}$$

The ripple correction is $I_{rms}^2 = I^2 + \Delta I_{pp}^2/12$. With L_motor ≈ 15 µH and 48 kHz, ΔI_pp ≈ 8 A. That adds 5.3 A² against 6400 A², about 0.08 %, so it is negligible.

**At an 80 A burst, T_j = 110 °C:**
$$P_{cond} = 2 \times 80^2 \times 1.40\,\text{m}\Omega = \mathbf{17.9\ W\ per\ channel}$$

### 1.3 Self-consistency loop (thermal runaway check)

R_ds rises with T_j, which raises losses, which raises T_j. Iterate:

$$T_j^{(n+1)} = T_{ref} + Z_{th}\,P(T_j^{(n)})$$

The loop converges only if

$$\frac{\partial P}{\partial T}Z_{th} = 2I^2R_{ds,25}\,\alpha\,Z_{th} < 1$$

At 80 A: 2 × 6400 × 0.9 mΩ × 0.0065 = 0.075 W/K. You therefore need **Z_th < 13 K/W**, which is easily met, so there is no runaway. The real limit is absolute temperature, not stability.

### 1.4 Non-FET conduction paths (per channel, 80 A)

| Path | R | P = I²R |
|---|---|---|
| Phase pad + 2 oz trace, 4 mm × 8 mm, plus vias | ~0.25 mΩ | 1.6 W |
| Current shunt (if used), 0.25 mΩ | 0.25 mΩ | 1.6 W |
| Shared VBAT plane share and pad | ~0.10 mΩ | 0.64 W |

**These are not negligible.** Copper loss is 15–25 % of FET conduction loss on nano boards.

## 2. Switching-Loss Model at 48 kHz

Only the switching leg's high-side FET hard-switches. The low side commutates softly through the body diode during dead time.

### 2.1 V–I overlap (hard switching)

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5\times25.2\times80\times20\text{ns}\times48\text{k} = \mathbf{0.97\ W}$$

### 2.2 Reverse recovery

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{n}\times25.2\times48\text{k} = 0.060\ \text{W}$$

### 2.3 Output capacitance

$$P_{oss} = Q_{oss}V_{bus}f_{sw}\ (\text{charge-based, conservative}) = 60\text{n}\times25.2\times48\text{k} = 0.073\ \text{W}$$

### 2.4 Dead-time body-diode conduction

$$P_{dt} = V_F\,I\,(2t_{dt})\,f_{sw} = 0.85\times80\times200\text{ns}\times48\text{k} = \mathbf{0.65\ W}$$

This is comparable to the V–I loss. Reducing dead time from 100 ns to 50 ns saves 0.33 W/channel, but only if the driver's propagation-delay mismatch allows it.

### 2.5 Gate drive (dissipated mostly in driver and R_g, not in the FET)

$$P_{gate} = 6\,Q_gV_{GS}f_{sw} = 6\times60\text{n}\times10\times48\text{k} = 0.17\ \text{W/channel}$$
