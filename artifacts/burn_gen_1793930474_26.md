# STM32H743 Nano FC + 4-in-1 ESC (Job #32): Power Stage, Thermal, and Bi-Directional DShot600 Design Package

## 0. Scope and Assumptions

Some ground rules up front, because a few of the numbers in this request can't be derived from the job title alone.

1. **Architecture.** The STM32H743 is the flight controller. It does **not** switch the MOSFETs. The 48 kHz commutation PWM runs on per-channel ESC MCUs (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071). The H743 talks to them over bi-directional DShot600. Both domains are modeled below.
2. **"80A burst" is interpreted as 80 A per motor channel**, peak phase current, for ≤ 5 s. This is the usual 4-in-1 marketing convention.
3. **The MOSFET and driver parameters are placeholders.** They are representative 40 V, 5×6 DFN values. Every equation is parametric: substitute the real datasheet values before release.

## 1. Conduction Loss Model (Six-Step, Synchronous Rectification)

### 1.1 Current path

In any 60° commutation sector, two phases conduct:

- **Phase A** is PWM-switched (high-side and low-side complementary).
- **Phase B** has its low side held ON.

The resulting current paths are:

- **PWM on (duty D):** Q_AH → motor → Q_BL. Two FETs conduct.
- **PWM off (1 − D):** Q_AL → motor → Q_BL, synchronous freewheel. Two FETs conduct.

So two R_ds(on) are always in series with the phase current, **independent of duty cycle**:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j) + I_{ph}^2 R_{pcb}$$

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

### 1.2 Numbers at 80 A

- At T_j = 110 °C: R_ds = 1.0 × (1 + 0.005 × 85) = **1.425 mΩ**
- FET conduction: 2 × 6400 × 1.425 mΩ = **18.24 W**
- PCB copper: 6400 × 0.4 mΩ = **2.56 W**

### 1.3 Battery current versus phase current

Battery current is not the same as phase current: I_batt ≈ D · I_ph. An 80 A phase-current burst at D = 0.85 draws 68 A per channel from the pack.

## 2. Switching Loss Model at 48 kHz

Only the PWM phase switches, so there are **two hard transitions per PWM period per channel**.

### 2.1 Gate currents during the Miller plateau

**Turn-on:**

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{drv,src}+R_{g,ext}+R_{g,int}} = \frac{6.5}{6} = 1.08\text{ A}$$

**Turn-off:**

$$I_{g,off} = \frac{V_{pl}}{R_{drv,snk}+R_{g,ext}+R_{g,int}} = \frac{3.5}{4.5} = 0.78\text{ A}$$
