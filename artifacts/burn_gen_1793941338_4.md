# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the hardware spec for Job #36, so the design is parameterized on the reference platform below. Every constant lives in one config block. The plant-specific values (R, L, J, Kt, pole count, slot count) must be measured on your hardware before you trust any gain.

---

## 0. Reference Platform and Timing Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), 3× center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701 SSI) per axis |
| Current sense | 2-shunt, sampled at PWM center |
| IMUs | 2× ICM-42688-P on SPI (24 MHz), ODR 8 kHz |
| IMU A | On the camera plate (attitude feedback) |
| IMU B | On the handle/base (disturbance reference) |

The loops run at decreasing rates, each with bandwidth separated from the next by at least 5×:

```
PWM / current loop   20 kHz   (ADC ISR)          BW_i  ≈ 1.5–2 kHz
Encoder + vel PLL    20 kHz   (same ISR)
Velocity loop         4 kHz   (every 5th ISR)    BW_v  ≈ 150–250 Hz
IMU read + filters    8 kHz   (IMU DRDY, DMA)
Attitude/angle loop   1 kHz   (timer)            BW_θ  ≈ 25–40 Hz
```

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical Model (Rotor dq Frame)

$$
v_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\big[\lambda_m i_q + (L_d-L_q)i_d i_q\big] \;\xrightarrow{\;L_d\approx L_q\;}\; \tau_e = K_t\, i_q,\quad K_t=\tfrac32 p\lambda_m
$$

The electrical angle is $\theta_e = p\,(\theta_m - \theta_{off})$ and the electrical speed is $\omega_e = p\,\omega_m$.
