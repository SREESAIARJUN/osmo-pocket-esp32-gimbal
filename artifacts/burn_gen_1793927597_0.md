# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #53)

I don't have the hardware specification for Job #53, so this design rests on the assumptions in §0. Every parameter that depends on them is a named constant in the code.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), one MCU for all 3 axes |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sense | 2- or 3-shunt low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, DMA |
| Mechanical order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |
