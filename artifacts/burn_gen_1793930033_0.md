## 1. Field-Oriented Control Equations

### 1.1 Electrical model

Rotor-frame (dq) voltage equations for an SPM motor (L_d = L_q = L):

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$
$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda$$
$$\tau_e = \tfrac{3}{2}p\lambda\, i_q = K_t i_q,\qquad \omega_e = p\,\omega_m,\quad \theta_e = p\,\theta_m - \theta_{off}$$

### 1.2 Clarke and Park transforms

Amplitude-invariant, with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transpose matrix.

### 1.3 Delay compensation

The PWM update takes effect about 1.5·T_s after sampling. The angle used for the inverse Park transform is therefore advanced:

$$\theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s$$

### 1.4 Current PI with decoupling (pole-zero cancellation)

The plant per axis is G(s) = 1/(Ls + R). With PI controller C(s) = K_p + K_i/s, choose:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Voltage commands with feed-forward decoupling and back-EMF compensation:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda$$

### 1.5 Voltage limiting and anti-windup

The voltage vector is limited to the linear SVPWM region:

$$\|v_{dq}\| \le V_{max} = \frac{V_{bus}}{\sqrt3}$$

Priority goes to v_d, with v_q limited to √(V_max² − v_d²). Integrator anti-windup uses back-calculation with K_aw = 1/K_p:

$$x_{k+1} = x_k + T_s\left[K_i e_k + K_{aw}(u_{sat}-u_{unsat})\right]$$

### 1.6 SVPWM (min-max zero-sequence injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12[\max(v_{abc})+\min(v_{abc})],\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant

With the current loop closed (fast enough to be treated as unity gain):

$$J\dot\omega_m = K_t i_q - b\,\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity PI (symmetric-optimum style, damping ζ ≈ 0.7–1)

Plant G_v(s) = K_t/(Js). Choose:

$$K_{p,v} = \frac{J\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The zero sits a factor of 4 below crossover, which gives about 65° phase margin.

The velocity measurement comes from the encoder through a PLL observer (removes quantization noise without the lag of a plain differentiator):

$$\hat\theta_{k+1} = \hat\theta_k + T_s\hat\omega_k + T_s K_1 e_\theta,\qquad \hat\omega_{k+1} = \hat\omega_k + T_s K_2 e_\theta,\qquad e_\theta = \text{wrap}(\theta_{enc}-\hat\theta)$$

with K_1 = 2ζω_pll, K_2 = ω_pll², and ω_pll ≈ 2π·400 Hz.

### 2.3 Velocity reference filtering

A 2nd-order low-pass at ω_v on the velocity reference shapes the setpoint. A biquad notch at the first mechanical (bracket/payload) resonance f_r is applied to the i_q* output:

$$N(s) = \frac{s^2 + 2\zeta_z\omega_r s + \omega_r^2}{s^2 + 2\zeta_p\omega_r s + \omega_r^2},\qquad \zeta_z \ll \zeta_p$$
