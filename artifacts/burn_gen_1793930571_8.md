# 3-Axis Gimbal FOC Control and Dual ICM-42688-P Sensor Fusion: Design and Implementation

**Scope note:** I don't have the Job #55 specification, so the hardware assumptions are listed first (§0). Every gain is derived symbolically from those parameters. Substitute your measured values and the gains recompute automatically.

---

## 0. Assumed Hardware and Timing

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| Current sense | 2-phase low-side shunts. A voltage-mode fallback is provided for high-R motors. |
| IMUs | 2× ICM-42688-P on the camera plate, mounted **symmetrically about the pitch-axis rotation center** (r_B = −r_A). This symmetry is what enables the lever-arm cancellation in §4.2. |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), FPU, SPI with DMA |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

**Loop rates:**

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| IMU sampling (ODR) | 8 kHz | 125 µs |
| Velocity loop + fusion | 4 kHz | 250 µs |
| Attitude (angle) loop | 1 kHz | 1
