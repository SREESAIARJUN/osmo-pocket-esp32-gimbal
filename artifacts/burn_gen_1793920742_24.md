# STM32H743 Nano AIO (FC + 4-in-1 ESC): Power-Stage Model, DShot DMA Architecture & Netlists

**Job #35 · Architecture Baseline Rev A**

---

## 0. Executive Findings

These findings drive every section below.

1. **The H743 does not commutate the motors.** ArduPilot has no native motor-commutation path, and the H743 has only two complementary-output advanced timers (TIM1/TIM8). The correct topology is:
   - H743 runs ArduPilot.
   - The H743 sends bi-directional DShot600 to **four dedicated ESC MCUs** (e.g. AT32F421 running AM32, one per motor).
   - Each ESC MCU drives a 3-phase gate driver at 48 kHz.
2. **80 A per motor is a burst rating, not a continuous one.** At 80 A on all four motors the stage dissipates about **89 W** and draws **320 A** from the pack. A nano-class PCB (≈2.8 J/K heat capacity) heats at about **32 K/s**. The usable burst window is about **1.5–2 s** from a 45 °C start. This must be enforced in firmware.
3. **A true 20×20 mm board cannot physically host 24 power FETs plus 4 ESC MCUs.** This model assumes a **30.5×30.5 mount (≈36×36 mm board), 8-layer, 2 oz inner/outer copper**. If the program insists on 20×20, the 80 A spec must be dropped to roughly 35–40 A burst.
4. **Input capacitance is a first-order design driver.** With ceramics alone, the 48 kHz input ripple voltage would exceed 20 V. A low-ESR bulk capacitor at the pad and a pigtail capacitor are mandatory.

All component parameters below are **representative assumptions** for model closure. Every number must be re-run with the selected FET's datasheet values. All equations are parameterized for that purpose.
