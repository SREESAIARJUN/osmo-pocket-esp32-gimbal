# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

> **Assumptions.** I don't have the original Job #4 spec, so this design uses common gimbal hardware. All parameters are in one `Config` struct so you can substitute yours.
> - **Motor:** GBM-class outrunner, 24N22P (11 pole pairs), R ≈ 5.6 Ω, L ≈ 2.4 mH.
> - **Encoder:** 14-bit magnetic (AS5048A / MT6701).
> - **Current sensing:** low-side shunts.
> - **MCU:** STM32G4 / H7-class with an FPU.
> - **IMUs:** two ICM-42688-P on SPI, mounted on the camera platform.

---

## 1. Architecture and Loop Timing

| Loop | Rate | Bandwidth target | Input → Output |
|---|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz | i_d*, i_q* → v_α, v_β (SVPWM) |
| IMU sampling + filtering | 8 kHz (ODR) | n/a | raw → filtered ω, a |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz | ω* → i_q* |
| Attitude / angle | 1 kHz | ω_p ≈ 2π·30 Hz | q* → ω* |
| Cogging adaptation | 4 kHz (gated) | slow (μ-limited) | e_ω → â_k, b̂_k |

**Bandwidth separation rule:** ω_c ≥ 5·ω_v ≥ 25·ω_p. Each outer loop then sees the inner loop as a unit gain with a small lag.

```
 q*  ┌────────┐ ω*  ┌───────┐ τ* ┌──────┐ iq* ┌─────────┐ v ┌──────┐
 ──►│Attitude│──┬─►│ Vel PI │──►│ ÷Kt  │─(+)─►│Current PI│─►│SVPWM │─► Motor
    │ P + FF │  │  └───────┘    └──────┘  ▲  └─────────┘   └──────┘
    └────────┘  │      ▲                  │ iq_cog = −τ̂_cog(θ)/Kt
        ▲       │      │ ω̂_joint (gyro ⊕ encoder PLL)
        │ q̂ (dual-IMU Mahony)
```

## 2. Field-Oriented Current Loop

### 2.1 Transforms

With θ_e = p·θ_m − θ_offset:

**Clarke (amplitude-invariant, i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$
