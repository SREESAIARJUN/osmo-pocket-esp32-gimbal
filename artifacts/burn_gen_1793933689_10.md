# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #11 specification, so the design below rests on explicit assumptions (§0). Every numeric constant is parameterized so you can substitute your actual hardware.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| Current sense | 2- or 3-shunt low-side, sampled at the PWM center |
| MCU | STM32G474 / H7 class, FPU, CORDIC optional |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, sampled on DRDY |
| Gimbal kinematics | Base → yaw (z) → roll (x) → pitch (y) → camera |

**Loop rates (multirate, phase-locked to the PWM timer):**

```
PWM / current loop (FOC)      : 20 kHz  (Ts_i = 50 µs)   ADC-triggered ISR
Velocity loop + cogging FF    :  4 kHz  (Ts_v = 250 µs)  every 5th current ISR
IMU acquisition + prefilter   :  8 kHz  (DRDY ISR, both IMUs)
Fusion + attitude + angle loop:  1 kHz  (Ts_θ = 1 ms)
```

**Control structure per axis:**

```
 q_ref(camera attitude) ──► [Attitude error, SO(3)] ──► ω_c,des
                                   ▲                       │ J(q)^-1
                       Dual-IMU fusion (q̂, ω̂_c)            ▼
                                                    q̇_des,k ──► [Velocity PI] ──► i_q,fb
                                                                    ▲                 │
                                           ω̂_k (gyro-projected + encoder PLL)         + i_q,ff (anti-cogging + inertia)
