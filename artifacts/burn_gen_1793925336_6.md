# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #7", so this design states its assumptions explicitly. Adjust the constants in `GimbalConfig` to match your hardware.

| Item | Assumption |
|---|---|
| Motor | Gimbal BLDC/PMSM, for example GBM4108 (11 pole-pairs, 12 slots), R≈10 Ω, L≈4 mH |
| Position sensor | Absolute magnetic encoder, 14-bit (AS5048A or MT6701) |
| Inverter | 3-phase, center-aligned PWM at 20 kHz, inline or low-side shunts |
| MCU | Cortex-M4F or M7 with FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz, IMU fusion 8 kHz |

---

## 1. System Architecture

```
 q_ref ─►[Attitude err (quat)]─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI]─► iq_pi ─┐
              ▲                                       ▲                          (+)─► iq* ─►[Current PI + decoupling]─► SVPWM
              │ q̂ (Mahony)                            │ ω̂ (gyro ⊕ encoder)       │
     [Dual ICM-42688 ─► calib ─► fuse ─► ANF ─► LPF]   │                  iq_ff (anti-cogging, θ_m)
                                                       │
                                     encoder ─► PLL ─► θ_m, ω_m, θ_e
```

Bandwidths are separated by a factor of 5–10 or more between loops:

- Current loop: ω_ci = 2π·1.5 kHz
- Velocity loop: ω_cv = 2π·150 Hz
- Angle loop: ω_cθ = 2π·20 Hz
