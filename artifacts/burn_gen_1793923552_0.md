## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motor | Gimbal PMSM, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–5 mH, surface-mount so L_d ≈ L_q |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (e.g. AS5048A or MT6701) |
| Inverter | 3-phase, 3-shunt current sensing, PWM at 20 kHz, center-aligned |
| IMUs | 2 × ICM-42688-P on the camera payload, each at 8 kHz ODR over SPI |
| MCU | Cortex-M4F/M7 class (single-precision FPU) |

**Loop rates**

| Loop | Rate | Period | Typical bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz, in the ADC ISR | T_i = 50 µs | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | T_v = 250 µs | ω_v ≈ 2π·80–150 Hz |
| Angle | 1 kHz | T_a = 1 ms | ω_a ≈ 2π·15–30 Hz |
| IMU fusion | 8 kHz in, 1 kHz attitude out | — | — |

**Design rule:** keep each loop's bandwidth at least 5–10× below the loop it encloses.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (dq frame)

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p\,\big[\lambda_m i_q + (L_d - L_q) i_d i_q\big] \approx K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m$$

### 1.3 Decoupled PI Current Control

The current controller adds feedforward decoupling terms to the PI outputs:

$$v_d^* = \mathrm{PI}_d(i_d^* - i_d) - \hat\omega_e \hat L_q i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \hat\omega_e(\hat L_d i_d + \hat\lambda_m)$$

With ideal decoupling, each axis reduces to the first-order plant 1/(Ls + R). Choosing the PI zero to cancel the plant pole gives:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop is then exactly ω_c/(s + ω_c).

**Constraints on ω_c:**
- Keep ω_c ≤ 2π·f_PWM/10 to account for the 1.5-sample delay (computation plus PWM update).
- Set i_d* = 0 (no field weakening is needed at gimbal speeds).

### 1.4 Voltage Limiting and Anti-Windup

The linear range of SVPWM is a circle of radius V_max = V_bus/√3. Clamp the command vector to that circle:

$$\text{if } \sqrt{v_d^{*2} + v_q^{*2}} > V_{max}:\quad v_{dq} \leftarrow v_{dq}\cdot \frac{V_{max}}{|v_{dq}|}$$

**Back-calculation anti-windup** is applied on each axis:

$$x_I[k+1] = x_I[k] + T\big(K_i e[k] + K_{aw}(v^{sat} - v^{unsat})\big),\qquad K_{aw} \approx K_i / K_p$$

### 1.5 SVPWM by Min–Max Zero-Sequence Injection

This is mathematically equivalent to sector-based SVPWM:

1. Inverse Clarke:
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
2. Zero-sequence offset:
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
3. Duty cycles:
$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}},\quad x \in \{a,b,c\}$$

**Delay compensation:** the PWM update applies one period late. Advance the angle used in the inverse Park transform accordingly:

$$\theta_e^{pwm} = \theta_e + 1.5\,\hat\omega_e T_i$$
