# STM32H743 Nano AIO with 4-in-1 ESC: Systems Architecture Package (Job #3)

## 0. Architecture Decisions and Assumptions

### 0.1 Topology
ArduPilot on the STM32H743 cannot commutate BLDC motors directly. The H743 is the flight controller. Each of the four motor channels needs its own ESC MCU running AM32 or BLHeli_32-class firmware (e.g., AT32F421 or STM32G071). The H743 talks to each ESC MCU over bidirectional DShot600. The 48 kHz switching frequency is the ESC-MCU PWM setting, not an H743 function.

```
VBAT(6S) ──┬── 4× [ESC MCU → 3-phase driver → 6× MOSFET → Motor]
           │         ▲ bidir DShot600 (1 wire each)
           └── Buck 5V/3V3 ── STM32H743 (ArduPilot) ── IMU/Baro/OSD/UARTs
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right]$$

At T_j = 110 °C: R = 1.4 mΩ × (1 + 0.005 × 85) = **1.995 mΩ ≈ 2.0 mΩ**

### 1.2 Phase-leg loss (6-step trapezoidal, synchronous rectification)

During PWM, current flows through the high-side FET for fraction D and the low-side FET for (1−D):

$$P_{leg,active} = I^2 R_{DS}\left[D + (1-D)\right] = I^2 R_{DS}$$

So leg loss does not depend on duty cycle; only the split between high and low side shifts. In 6-step commutation, each phase conducts for 2/3 of the electrical cycle:

$$\bar P_{leg} = \tfrac{2}{3}\,I^2 R_{DS}(T_j)\,(1+k_{rip}^2/12)$$

Here k_rip is the peak-to-peak ripple as a fraction of I. It is about 0.1 for typical motor inductance at 48 kHz, which adds less than 0.1 % and can be neglected.
