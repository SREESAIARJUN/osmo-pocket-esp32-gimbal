## 0. Architectural Ground Rules and Assumptions

The H743 does not commutate motors. In every production-grade 4-in-1 design, each ESC channel runs its own MCU, which closes the commutation loop at the 48 kHz PWM rate. The H743 runs ArduPilot and sends bi-directional DShot600 to those MCUs. This document uses AM32 firmware on an AT32F421K8U7, the standard current choice.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in complementary 6-step

During any 60° commutation sector, one leg is PWM-switched and one leg is held low (sink). The third leg floats.

- **Switching leg:**
  - High-side conducts for D·T_sw.
  - Low-side (synchronous) conducts for (1 − D)·T_sw, minus dead time.
- **Sink leg:** low-side conducts 100 % of the time.

Within the switching leg, exactly one FET carries the phase current at every instant (ignoring dead time). The bridge loss is therefore **independent of duty cycle**:

```
P_cond,bridge = I_ph² · R_DS(T_j) · [D + (1−D)] + I_ph² · R_DS(T_j)
              = 2 · I_ph² · R_DS(T_j)
```

### 1.2 Phase current vs. battery current

```
I_batt ≈ D · I_ph        →   I_ph = I_batt / D
```

An "80 A" rating is only meaningful as phase current near full throttle. At D = 0.6 with 80 A battery current, I_ph = 133 A. **The ESC MCU current limit must act on I_ph, not I_batt.**

### 1.3 Temperature-dependent R_DS(on)

```
R_DS(T_j) = R_DS,25 · [1 + α · (T_j − 25)]
```

With α = 0.0045 /K:

| T_j | Factor |
|---|---|
| 100 °C | 1.34 |
| 125 °C | 1.45 |
| 150 °C | 1.56 |
