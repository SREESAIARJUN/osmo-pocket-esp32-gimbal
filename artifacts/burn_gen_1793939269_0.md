# STM32H743 Nano FC + 4-in-1 ESC (Job #18): Power-Stage Model, Thermal Budget, Bidirectional DShot600 Allocation

## 0. Architecture Review: Read Before the Math

The math below raises two design problems that should be resolved before layout.

**Issue 1: The STM32H743 should not commutate the motors.**
No ArduPilot build runs sensorless 6-step commutation on the flight MCU. The production-proven architecture is:

- **FC side:** an STM32H743 running ArduPilot. It sends bidirectional DShot600 to the ESC MCUs.
- **ESC side:** four small MCUs (for example AT32F421K8U7 or STM32G071) running AM32 or BLHeli_32-class firmware. Each drives a 3-phase gate driver and six MOSFETs.

The rest of this document assumes that split.

**Issue 2: An 80 A burst on a 20×20 nano board is time-limited to about 1–2 s.**
Section 3 shows the numbers:

- Continuous capability on a roughly 26×26 mm board is about 20–25 A per motor in typical prop-wash airflow.
- "80 A burst" can only be a short adiabatic rating.
- I recommend specifying it as **"80 A / 1 s, T_start ≤ 40 °C"**, not an unqualified burst figure.

## 2. Loss Model (per motor, 6-step trapezoidal, synchronous rectification)

### 2.1 Conduction losses

At any instant in 6-step commutation, two phases conduct:

- **Switched leg:** the high-side FET conducts for D·T. The low-side FET (synchronous rectification) conducts for (1−D)·T.
- **Static leg:** the low-side FET conducts continuously.

The temperature-adjusted on-resistance is:

$$R(T_j)=R_{25}\,[1+\alpha_R(T_j-25)]$$

At T_j = 100 °C: R = 1.5 × 1.34 ≈ **2.0 mΩ**.

Total conduction loss for one motor:

$$P_{cond}=I_{ph}^2R\,[D+(1-D)] + I_{ph}^2R = 2\,I_{ph}^2R(T_j)$$

At 80 A:

$$P_{cond}=2(80)^2(2.0\,\text{m}\Omega)=\mathbf{25.6\ W\ per\ motor}$$

Per-device split:

- Static low-side FET: about 12.8 W.
- Switched leg: 12.8 W, shared between its HS and LS FETs according to D.

**Phase vs. battery current.** The phase current is related to battery current by I_ph ≈ I_dc / D. At part throttle, phase current exceeds battery current. Size the hardware on **phase current**.
