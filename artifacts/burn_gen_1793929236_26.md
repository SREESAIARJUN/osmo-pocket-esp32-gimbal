# STM32H743 AIO Flight Controller with 4-in-1 ESC: System Architecture Model

**Scope:** 80 A burst conduction losses, 48 kHz switching losses, thermal budget, ArduPilot bidirectional DShot600 timer and DMA allocation, and reference netlists.

---

## 0. Architecture Clarifications and Assumptions

### 0.1 Architectural correction

The STM32H743 does not commutate the motors. In any DShot-based AIO, the H743 runs ArduPilot and sends DShot600 frames. Separate ESC MCUs generate the 48 kHz 6-step PWM. This design assumes 4× AT32F421 running AM32, one per motor. A single-MCU 4-in-1 such as BLHeli_32 on an STM32G071 is also possible.

This split determines which equations apply to which silicon:

| Domain | Silicon | Covered in |
|---|---|---|
| Power stage (conduction and switching losses) | ESC MCU, gate drivers, 24 MOSFETs | §1–§3 |
| Motor protocol (DShot timers and DMA) | STM32H743 | §5 |
