## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle, with offset θ_off found at calibration:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform, amplitude-invariant, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform maps (v_d, v_q) back to (v_α, v_β).

### 1.2 Plant model and decoupling

The machine is a surface PMSM, so L_d = L_q = L:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Feed-forward decoupling makes each axis a first-order plant, 1/(Ls + R):

$$v_d^{*} = u_d - \omega_e L i_q,\qquad v_q^{*} = u_q + \omega_e L i_d + \omega_e \lambda_m$$

Here λ_m = Kt / (1.5 p).

### 1.3 Current PI gains (pole–zero cancellation)

With C(s) = K_p + K_i/s, choose:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

This gives a closed loop of ω_c / (s + ω_c).

- Choose ω_c = 2π·1500 rad/s, which is below f_PWM/10 and accounts for the 1.5-sample delay.
- Discretize with forward Euler: I[k+1] = I[k] + K_i·T_s·e[k].

**Anti-windup.** Use back-calculation with K_aw = 1/K_p. Apply circular voltage limiting:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

The d-axis has priority.
