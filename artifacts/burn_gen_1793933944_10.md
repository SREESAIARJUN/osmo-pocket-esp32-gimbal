## 0. Architecture Scope and Design Assumptions

**Architectural correction.** The STM32H743 does not commutate the motors.

- **Commutation on the H743 is not feasible.** It has only two advanced-control timers (TIM1, TIM8), each with three complementary pairs. That covers two bridges, not four.
- **ArduPilot does not run commutation firmware.**

The valid architecture is therefore:

```
H743 (ArduPilot) ──bidir DShot600 ×4──► 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware)
                                         └─► 4× 3-phase gate driver ─► 24 MOSFETs ─► 4 motors
```

The 48 kHz switching frequency is set in the ESC MCU firmware (AM32 `PWM_FREQ`). DShot600 timing is set in the H743 / ArduPilot.
