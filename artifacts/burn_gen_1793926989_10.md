## 0. Assumptions and System Architecture

| Item | Assumed value **[A]** |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| PWM | 25 kHz center-aligned |
| IMUs | 2× ICM-42688-P on SPI, camera-side, mirrored placement |

**Loop rates**

| Loop | Rate | Executes in |
|---|---|---|
| Current (FOC) | 25 kHz | ADC-complete interrupt |
| Velocity | 5 kHz | Every 5th FOC tick |
| Attitude/angle | 1 kHz | Separate low-priority task |
| IMU sampling + filtering | 8 kHz ODR | DRDY interrupt → DMA |
