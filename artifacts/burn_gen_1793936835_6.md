# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the original spec for "Job #5," so this design uses the assumptions below. Every parameter is a named constant, so you can change any of them to match your hardware.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, ≥170 MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sense | 2–3 phase shunt, synchronous ADC at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI + DMA, 8 kHz ODR, ±2000 dps, ±4 g |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC d/q PI) | 20 kHz | ~1.5–2 kHz |
| IMU acquisition and filtering | 8 kHz | n/a |
| Velocity (inertial rate) PI | 4 kHz | ~150–250 Hz |
| Angle (attitude) P/PI and Mahony AHRS | 1 kHz | ~20–40 Hz |

Each loop has 5–10× bandwidth separation from the next, so every inner loop looks like unity gain to the loop around it.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform:**

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q
