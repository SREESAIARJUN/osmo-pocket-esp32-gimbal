# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I don't have the Job #23 specification, so the design assumes the typical brushless gimbal platform below. Every value is a parameter in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motor | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class, FPU, 3× center-aligned PWM, injected ADC |
| Current sense | 2 or 3 low-side shunts (if absent, use voltage-mode FOC, §2.6) |
| IMUs | 2× ICM-42688-P on the camera plate, symmetric about the payload CoM, sharing a CLKIN |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz · IMU ODR 8 kHz |

**Bandwidth separation rule.** Each outer loop should be 5–10× slower than the loop it drives:

ω_c,i ≈ 2π·1.5 kHz ≫ ω_c,ω ≈ 2π·150 Hz ≫ ω_c,θ ≈ 2π·20 Hz
