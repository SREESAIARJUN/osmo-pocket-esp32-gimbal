# STM32H743 + 80A 4-in-1 ESC Nano Stack: Reference Engineering Model

## 0. Scope and Assumptions

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate motors. Each of the four ESC channels has its own small MCU (for example an AT32F421 running AM32, or BLHeli_32-class firmware) driving a 3-phase bridge. The H743 sends bi-directional DShot600 to those MCUs and receives eRPM telemetry back. This is how every production "H743 + 4-in-1" stack works.

The job sheet does not fix several parameters, so I have assumed them. Swap in your datasheet values; every equation is parametric.
