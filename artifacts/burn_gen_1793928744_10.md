## 1. Loss Model (Per Motor Bridge)

### 1.1 Temperature-dependent on-resistance

```
R_ds(T) = R_ds,25 · [1 + α·(T_j − 25)]      α ≈ 0.0045 /K (40 V trench, typical)

T_j = 100 °C  →  R_ds = 1.2 mΩ × 1.3375 = 1.605 mΩ
T_j = 125 °C  →  R_ds = 1.2 mΩ × 1.45   = 1.740 mΩ
```

### 1.2 Conduction loss

In 6-step operation with synchronous rectification, two FETs always carry phase current:
- the PWM leg (high-side for D, low-side for 1−D), and
- the static low-side of the return leg.

So the conduction loss is independent of duty cycle:

```
P_cond = 2 · I² · R_ds(T_j)

At I = 80 A, T_j = 100 °C:
P_cond = 2 × 6400 × 1.605e-3 = 20.54 W
```

The per-FET average over an electrical cycle (each FET conducts about 1/3 of the time) is about 20.54 / 6 ≈ **3.4 W**. The instantaneous peak in a conducting FET is **10.3 W**.

Copper and solder path, assuming R_pcb ≈ 0.4 mΩ (bus plus phase pour plus the motor pad):

```
P_cu = I² · R_pcb = 6400 × 0.4e-3 = 2.56 W
```

### 1.3 Hard-switching loss at 48 kHz

The gate current during the Miller plateau sets the transition times. Use V_drv = 10 V, V_pl = 3.5 V, R_g,ext = 4.7 Ω, and FD6288 equivalent driver resistance R_src ≈ 10 Ω and R_sink ≈ 5 Ω.

```
I_g,on  = (V_drv − V_pl)/(R_src + R_g,ext + R_g,int) = 6.5/15.7 = 0.414 A
I_g,off =  V_pl/(R_sink + R_g,ext + R_g,int)         = 3.5/10.7 = 0.327 A

t_on  = Q_sw / I_g,on  = 10 nC / 0.414 A = 24.2 ns
t_off = Q_sw / I_g,off = 10 nC / 0.327 A = 30.6 ns

E_sw  = ½ · V_bus · I · (t_on + t_off)
      = 0.5 × 25.2 × 80 × 54.8e-9 = 55.2 µJ

P_sw  = E_sw · f_sw = 55.
