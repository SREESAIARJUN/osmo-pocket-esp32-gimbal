# STM32H743 Nano FC + 80A 4-in-1 ESC (Job #38): Reference Design Analysis

## 0. Architecture and Assumptions

**Correction to the brief.** On any ArduPilot-compatible design, the H743 does not drive the MOSFETs. It runs ArduPilot and emits bi-directional DShot600. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32, and that MCU generates the 48 kHz PWM. The work therefore splits into two domains:

```
 FC board (H743, ArduPilot)          ESC board (4x AM32 MCU, 4x 3-phase bridge)
 ┌────────────────────────┐  8-pin   ┌──────────────────────────────────────┐
 │ TIMx CH1..4 ─ BDShot600 ├─────────►│ MCU1..4 ─ gate driver ─ 6xMOSFET each │
 │ ADC ◄─ VBAT/CURR       │◄─────────┤ shunt/amp, VBAT divider               │
 │ UART RX ◄─ ESC telem   │          │ 48 kHz complementary PWM               │
 └────────────────────────┘          └──────────────────────────────────────┘
```

**Design parameters.** All values marked (A) are assumptions. Replace them with your selected parts' datasheet values; the equations hold regardless.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | worst-case switching voltage (A) |
| I_ph | 80 A burst / channel | phase current, ~full throttle (A) |
| f_sw | 48 kHz | ESC PWM frequency |
| R_ds25 | 1.0 mΩ @ V_gs=10 V | 40 V MOSFET, PDFN 5×6 class (A) |
| α | 0.006 /°C | R_ds temperature coefficient (A) |
| Q_g / Q_sw | 40 nC / 10 nC | total gate charge / (Q_gs2+Q_gd) (A) |
| Q_oss, Q_rr | 40 nC, 30 nC | (A) |
| t_dt | 100 ns | dead time per edge (A) |
| V_f | 0.8 V | body-diode forward voltage (A) |
| R_g | 10 Ω ext + 1.5 Ω int, driver ~5 Ω | (A) |
| V_plateau | 3.0 V | Miller plateau (A) |
| Board | 30.5×30.5 mm, 8-layer, 2 oz | (A) |

> ⚠️ **Feasibility flag.** 80 A per channel on a "nano" (20×20 mm) board is not physically credible. Even on 30.5×30.5 mm, as shown in §3, 80 A is a **seconds-scale burst**, not a rating. Confirm whether "80A" means per channel or total board current.

## 1. Conduction Losses (6-step, complementary/synchronous PWM)

### 1.1 Current paths
In each 60° commutation sector, one leg PWMs and another leg's low side is held on. Because the PWM leg is synchronous, either its high side (HS, for duty D) or its low side (LS, for 1−D) carries I_ph. Exactly **two devices conduct at any instant**:

```
P_cond,ch = 2 · I_ph² · R_ds(T_j)          R_ds(T_j) = R_ds25 · [1 + α(T_j − 25)]
```

Note that I_ph is phase current. Battery current is I_bat ≈ D·I_ph
