# STM32H743 Nano FC + 4-in-1 ESC (Job #28): Power, Thermal, and DShot Architecture

## 0. Feasibility Findings and Assumptions

You did not provide a MOSFET part number, board stack-up, battery voltage, or ESC firmware, so I chose the values below. **Every number in this document is a parameterized estimate. Replace the parameters in Table 0.1 with datasheet values before release.**

Four findings affect the architecture before any detailed design:

1. **The H743 does not commutate the motors.** In a production 4-in-1 design, each motor channel needs its own ESC MCU (AT32F421 / STM32G071 running AM32, or EFM8 running BLHeli_S). The H743 runs ArduPilot and *sends* DShot600. The 48 kHz PWM is generated by the ESC MCUs, not the H743. The model below assumes this partition.
2. **"80A burst" on a nano (20×20 mm) board is a transient rating, not a thermal steady state.** The math in §3 shows roughly 120 W total dissipation at 4×80 A, which allows only about 1–2 s of adiabatic burst. Market it as a ≤1 s burst rating at most, and validate with a thermal camera.
3. **Putting the H743 and the ESC on the same PCB is risky.** About 120 W burst heat next to the IMU causes gyro bias drift and temperature-compensation trouble. I recommend a two-board stack (FC over ESC with a 6–8 pin harness). If it must be one board, put the IMU on a soft-mounted, isolated island.
4. **The 4× battery current is a separate problem.** 320 A peak through a battery pad and shunt on a 20×20 board is not credible. Plan for about 4×80 A *phase* burst at reduced duty, so battery current stays well below phase current (see §1.1).

## 1. Conduction Loss Model

### 1.1 Current Relationships (6-step trapezoidal, complementary PWM)

At any instant two phases conduct: the PWM phase and the low-side return phase. Battery-side and phase-side current relate through the duty cycle:

$$I_{bat} = D \cdot I_{ph}$$

At full-throttle burst (D → 1) these converge, which is the worst case for conduction.

With synchronous rectification:
- **During t_on:** current flows through HS(A) and LS(B).
- **During t_off:** current freewheels through LS(A) and LS(B).

Either way, **two FETs carry I_ph at all times** (ignoring the dead-time intervals, which §2 handles).

### 1.2 Temperature-Dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 100 °C: R_ds = 1.5 mΩ × 1.3375 ≈ **2.0 mΩ**.
