# STM32H743 AIO Flight Controller with Integrated 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bi-Directional DShot600 DMA Allocation

## 0. Scope and Assumptions

The STM32H743 cannot directly commutate four BLDC motors at 48 kHz. Commercial AIO boards therefore split the work between two processor tiers:

```
                 ┌──────────────────────────── AIO PCB ────────────────────────────┐
 VBAT (6S) ──────┤──> Bulk caps ──> 4× [ESC MCU + gate driver + 6× N-MOSFET] ──> M1..M4
                 │                         ▲ bidir DShot600 (1 wire/motor)          │
                 │   STM32H743 (ArduPilot) ┘   + ESC telemetry/current sense        │
                 └─────────────────────────────────────────────────────────────────┘
```

- **ESC MCU:** AT32F421 or STM32G071, running AM32 or BLHeli_32. It generates the 48 kHz complementary PWM.
- **Flight controller:** The H743 runs ArduPilot and talks to each ESC over bidirectional DShot600.

**Baseline parameters.** These are representative, not a specific part number. Substitute datasheet values before release.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | Worst case for switching loss |
| I_ph | 80 A | Burst phase current per ESC |
| R_ds(on),25 | 1.2 mΩ @ V_gs = 10 V | 40 V PDFN5×6-class FET |
| α | 0.005 /K | R_ds temperature coefficient |
| Q_gs2 + Q_gd | 4 + 8 nC | Switching-relevant gate charge |
| Q_g | 40 nC | Total gate charge |
| C_oss,eff | 1.5 nF | Effective output capacitance |
| Q_rr | 60 nC @ 80 A | Body-diode reverse recovery |
| V_SD | 0.8 V | Body-diode forward voltage |
| V_drv, V_pl | 10 V, 3.5 V | Gate drive and Miller plateau |
| R_g,on / R_g,off | 10 Ω / 5 Ω | Total gate loop resistance |
| t_dt | 250 ns | Dead time |
| f_sw | 48 kHz | PWM frequency |
| R_Cu | 1.0 mΩ | Copper path per active current loop |

**Modulation:** six-step trapezoidal with synchronous rectification ("complementary PWM", the AM32 default). At any instant, exactly two MOSFETs carry I_ph: one in the PWM leg and the low-side of the return leg.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_ds = 1.2 × 1.5 = **1.8 mΩ**.

### 1.2 Per-ESC conduction loss

With synchronous rectification, two FETs always conduct regardless of duty cycle D:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j) = 2 \times 6400 \times 1.8\times10^{-3} = \mathbf{23.0\ W}$$

### 1.3 Per-FET loss

Each FET conducts I_ph while it is active, at an instantaneous loss of 11.5 W. Averaged over a commutation cycle, the load spreads across all six devices:

$$\bar P_{FET} \approx 23.0 / 6 = \mathbf{3.84\ W}$$

### 1.4 Dead-time (body-diode) loss

There are two dead-time intervals per PWM period:

$$P_{dt} = 2\,V_{SD}\,I_{ph}\,t_{dt}\,f_{sw} = 2(0.8)(80)(250\text{n})(48\text{k}) = \mathbf{1.54\ W}$$

### 1.5 Copper loss

$$P_{Cu} = I_{ph}^2 R_{Cu} = 6400 \times 1.0\text{ m}\Omega = \mathbf{6.4\ W}$$

On a nano board this term is often underestimated. 2 oz outer and 2 oz inner copper, and short phase pads, are mandatory.

### 1.6 Thermal-runaway criterion

The loop is stable only if

$$\frac{\partial P_{cond}}{\partial T_j}\,R_{\theta} = 2 I^2 R_{ds,25}\,\alpha\,R_\theta < 1$$

At 80 A: 2·6400·1.2 mΩ·0.005 = 0.0768 W/K. Runaway therefore occurs if the effective R_θ exceeds about **13 K/W**. As Section 4 shows, a 20×20 board is at roughly this limit.
