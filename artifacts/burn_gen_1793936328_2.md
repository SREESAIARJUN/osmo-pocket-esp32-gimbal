# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #56 specification, so the design below rests on stated assumptions (§0). Every parameter that depends on your hardware is collected in one config struct, so you only need to change it in one place.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MA730 / AS5048A class) on each motor |
| Current sense | 2 or 3 inline/low-side shunts per motor, ADC sampling synchronized to PWM center |
| PWM | 20 kHz center-aligned |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ideally sharing a CLKIN |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

Loop rates:

```
 20 kHz  ── Current loop (FOC: Clarke/Park, PI id/iq, SVPWM)     [ADC ISR]
  8 kHz  ── IMU ingest, AAF→rotate→fuse→notch→LPF                 [IMU DRDY/FIFO]
  4 kHz  ── Rate (velocity) PI(D) + anti-cogging feedforward      [timer ISR]
  1 kHz  ── Attitude estimator (Mahony) + angle P(I) loop         [timer ISR]
```

Signal flow for one axis:

```
θ_ref ─►(Σ)─► C_θ(s) ─►(Σ)◄─ ω_ff ─► C_ω(s) ─►(Σ)◄─ i_cog,ff(θ_m) ─► i_q* ─► FOC ─► motor
        ▲−                ▲−                                                         │
        │                 └──────── fused, notched gyro (camera frame→joint) ◄───────┤
        └──────────────── Mahony attitude estimate ◄─────────────────────────────────┘
```
