# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the original Job #33 specification, so the assumptions below stand in for it. Every hardware-specific number is a parameter in the code. Replace these values with your own and the equations still hold.

---

## 0. Assumed Platform and Loop Rates

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic (AS5048A / MT6701 class), one per joint |
| Current sensing | 2-shunt or inline. A voltage-mode fallback is noted below. |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the camera centre of rotation, sharing one CLKIN |

| Loop | Rate | Bandwidth target |
|---|---|---|
| PWM / current (FOC) | 20 kHz | ω_c = 2π·1500 rad/s |
| Velocity (gyro feedback) | 4 kHz | ω_v = 2π·60 rad/s |
| Angle (attitude) | 1 kHz | ω_θ = 2π·10 rad/s |
| IMU ODR | 8 kHz (both) | AAF ≈ 536 Hz |
| Anti-cogging feedforward | 20 kHz evaluation, 4 kHz adaptation | n/a |

Each outer loop's bandwidth is at least 5× below the loop inside it. This lets each inner loop be treated as unity gain when you design the loop around it.
