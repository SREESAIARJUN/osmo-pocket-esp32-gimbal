# STM32H743 AIO Nano FC + 80A-Burst 4-in-1 ESC: Engineering Model and Architecture Reference

**Job #25, Rev A (Preliminary)**

## 0. Scope, Architecture Assumptions and Up-Front Findings

### 0.1 Architecture clarification

An STM32H743 does not commutate the motors. A production AIO uses this split:

```
┌──────────────────── FC domain ────────────────────┐   ┌──────── ESC domain (×4) ────────┐
│ STM32H743 (ArduPilot) ── DShot600 bidir (1-wire) ─┼──►│ ESC MCU (AM32 / BLHeli_32-class)│
│                                                    │   │   └─► 3-ph gate driver ─► 6 FETs│
└────────────────────────────────────────────────────┘   └─────────────────────────────────┘
```

The 48 kHz PWM is generated by each ESC MCU. The H743 is responsible for DShot600 output and eRPM telemetry capture only.

### 0.3 Key findings (stated plainly)

1. **80 A is a transient rating, not continuous.** On a nano/30×30 form factor, the model below gives **~26–28 W per channel** at 80 A. That is **~110 W for the full board**, which is roughly 10× what the board can reject in prop-wash.
2. **Usable burst at 80 A on all 4 channels is about 2–5 s, board-limited.** Single-FET junction limits allow somewhat longer for a single-channel burst.
3. **Realistic continuous current is about 30–40 A per channel**, assuming strong airflow.
4. **Bidirectional DShot600 on the H743 is comfortable.** DMAMUX gives a 6-stream budget for 4 motors, out of 16 available streams.

## 1. Conduction-Loss Model

### 1.1 Current path

In 6-step trapezoidal commutation with complementary PWM:

- During PWM-on, current flows HS(x) → motor → LS(y).
- During PWM-off, current freewheels LS(x) (synchronous rectification) → motor → LS(y).

Two FETs are therefore in the current path at all times, except during dead time, when a body diode replaces one FET.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha_R(T_j-25)]$$

At T_j = 125 °C, the multiplier is 1.45, giving **R_hot = 1.885 mΩ**.

### 1.3 Channel conduction loss

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j)\,(1-2t_{dead}f_{sw})$$

The dead-time correction factor is 1 − 2·100 ns·48 kHz = 0.9904.

$$P_{cond,ch}=2(80)^2(1.885\times10^{-3})(0.9904)=\mathbf{23.9\ W}$$

### 1.4 Per-FET distribution

Over one electrical period, each phase spends 120° high, 120° low and 120° floating.

| FET role | Conduction fraction |
|---|---|
| HS of the PWM phase | D · (1/3) |
| LS of the PWM phase (sync rect) | (1 − D) · (1/3) |
| LS of the "low" phase | 1/3 (full) |

Averaged over rotation, each of the 6 FETs carries about 1/3 of the I²R. This gives:

$$P_{FET,avg}\approx \frac{P_{cond,ch}}{6}\approx 4.0\ \text{W}$$

**Electrothermal coupling.** Because R_ds depends on T_j, solve the fixed point:

$$T_j = T_{ref} + Z_{th}\,P(T_j)$$

This converges only if:

$$Z_{th}\cdot\frac{\partial P}{\partial T_j}=Z_{th}\cdot 2I^2R_{25}\alpha_R<1$$

At 80 A, ∂P/∂T is about 0.075 W/K per channel. Per FET with Z_th(j-amb, steady) around 40 K/W, the loop gain is 40 × 0.0125 = 0.5. This is stable but strongly amplifying (×2), so **thermal runaway margin is thin in steady state**. This is another reason 80 A must remain burst-only.
