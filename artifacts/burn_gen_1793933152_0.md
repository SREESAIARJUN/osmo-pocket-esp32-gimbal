## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so p = 7 pole pairs. R ≈ 5.6 Ω, L ≈ 2.5 mH, K_t ≈ 0.08 N·m/A. |
| Encoder | 14-bit magnetic encoder (AS5048A / MT6701) on each axis, SPI. |
| IMUs | 2 × ICM-42688-P rigidly mounted on the camera plate (IMU_A, IMU_B), ODR 8 kHz, gyro ±2000 dps, accel ±16 g. |
| MCU | Cortex-M4F/M7 class (STM32G4/H7), center-aligned PWM at 20 kHz. |
| Kinematics | Yaw (z) → Roll (x) → Pitch (y), base to camera. |

**Loop rates and bandwidths**

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (rate) | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~20 Hz |
| IMU fusion | 8 kHz in, decimated to 4 kHz | — |

Each loop's bandwidth sits at least 5–10× below the loop inside it. That separation lets each inner loop be treated as unity gain when designing the loop outside it.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at startup by aligning the d-axis (inject V_d, read the encoder).

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

where ω_e = p·ω_m and λ_m = (2/3)·K_t/p.

### 1.5 PI controller with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gain selection by pole-zero cancellation.** The plant is 1/(R + sL). Set K_i/K_p = R/L so the PI zero cancels the plant pole. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

With ω_c = 2π·1500: K_p ≈ 23.6 V/A and K_i ≈ 52 800 V/(A·s).

### 1.6 Discrete PI with back-calculation anti-windup

Forward-Euler discretization with sample period T:

$$u_k = K_p e_k + I_k$$

$$\bar u_k = \text{sat}(u_k)$$

$$I_{k+1} = I_k + T\left[K_i e_k + K_{aw}(\bar u_k - u_k)\right]$$

Use K_aw ≈ K_i/K_p, i.e., the reciprocal of the integral time constant.

**Voltage limiting.** The dq voltage vector is clamped to the linear SVPWM circle, |v_dq| ≤ V_bus/√3. The d-axis gets priority:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^{*2}}$$

### 1.7 Inverse Park and SVPWM

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Min-max zero-sequence injection, which is mathematically equivalent to SVPWM:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** PWM update plus sampling adds about 1.5 T of delay. Advance the angle used in the inverse Park by:

$$\theta_e^{\,inv} = \theta_e + 1.5\,\omega_e T$$
