# STM32H743 Nano FC + 4-in-1 ESC: System Architecture Reference

**Scope.** This document covers three things:

1. An electro-thermal loss model for one ESC channel at an 80 A burst and 48 kHz PWM, scaled to four channels.
2. ArduPilot bidirectional DShot600 timer and DMA allocation on the STM32H743.
3. Reference netlists and a thermal budget.

**Assumptions.** I've stated assumptions explicitly. You must re-run the model with your actual MOSFET, gate driver and PCB stack-up datasheet values before committing to a layout.

**Architectural premise.** The H743 does not drive the power stage. It is the flight controller. It sends bidirectional DShot600 to four independent ESC MCUs (e.g., AT32F421 running AM32 or BLHeli_32). Each ESC MCU generates 48 kHz complementary PWM for its own 3-phase bridge. The two halves are coupled by the 8-pin FC–ESC harness, by thermal and EMI interaction on a stacked board, and by telemetry.
