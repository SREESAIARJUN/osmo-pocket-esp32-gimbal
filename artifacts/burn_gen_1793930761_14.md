## 0. Architecture Clarification and Design Assumptions

**The STM32H743 does not commutate the motors.** ArduPilot runs on the H743, which sends bidirectional DShot600 to four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32). Those ESC MCUs generate the 48 kHz six-step PWM. Merging the two roles would put hard-real-time commutation inside ArduPilot's scheduler. ArduPilot does not support that, and it would be a reliability failure.

The topology on the shared PCB is:

```
VBAT(6S) ──► 4× [ESC MCU → 3-ph gate driver → 6× N-MOSFET] ──► M1..M4
                 ▲ bidirectional DShot600 (1 wire/motor)
STM32H743 (ArduPilot) ── IMU/Baro/OSD/UARTs
```

All calculations below depend on these assumptions. Substitute datasheet values for your specific BOM.

## 1. Conduction Loss Model (80 A Burst)

**Commutation model.** Six-step trapezoidal drive with synchronous rectification (complementary PWM) means current always flows through exactly two FET channels in series: one in the high-side leg and one in the low-side leg. During PWM off-time, the complementary FET carries the current instead of the body diode.

The hot on-resistance is:

$$R_{hot} = k_T \cdot R_{25} = 1.6 \times 1.2\,\text{m}\Omega = 1.92\,\text{m}\Omega$$

**Per ESC channel conduction loss:**

$$P_{cond,ch} = I_{ph}^2 \cdot 2R_{hot} = 80^2 \times 3.84\,\text{m}\Omega = \mathbf{24.6\,W}$$

**Per-FET breakdown.** Each FET carries current for 1/3 of the electrical period. Averaged over a commutation cycle, this gives:

$$P_{cond,FET,avg} = \frac{2 \times 24.6}{6} \approx 8.2\,\text{W}$$

The instantaneous per-FET loss while conducting is I²·R_hot = 12.3 W. This value drives the junction transient.

**Copper loss per channel:**

$$P_{cu,ch} = 80^2 \times 0.5\,\text{m}\Omega = 3.2\,\text{W}$$

**Temperature feedback.** R_DS(on) rises roughly linearly with T_j, so P_cond(T) = P₂₅·[1 + α(T−25)], with α ≈ 0.006 /K. The fixed-point solution exists only while R_θ·P₂₅·α < 1. On a nano board without airflow, this stability condition fails at 80 A continuous. That failure is the formal reason 80 A must be treated as a burst rating only.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times (charge-based)

Turn-on gate current through the Miller region:

$$I_{g,on} = \frac{V_{dr}-V_{pl}}{R_{src}+R_g} = \frac{7}{6} = 1.17\,\text{A} \Rightarrow t_r = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 9.4\,\text{ns}$$

Turn-off gate current:

$$I_{g,off} = \frac{V_{pl}}{R_{snk}+R_g} = \frac{3}{4.5} = 0.67\,\text{A} \Rightarrow t_f = \frac{11\,\text{nC}}{0.67\,\text{A}} = 16.5\,\text{ns}$$
