# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #47, so this design rests on the baseline assumptions below. Each assumption maps to one parameter struct in the code. Replace the values with your measured ones and the equations still hold.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (for example GBM2804), pole pairs **p = 7**, R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A or MT6701) over SPI |
| Current sensing | 2 or 3 low-side shunts, ADC triggered at PWM center |
| PWM | 25 kHz, center-aligned |
| IMUs | 2× ICM-42688-P on the camera payload, SPI @ 24 MHz, ODR 8 kHz |
| Loop rates | Current 25 kHz · Velocity 4 kHz · Angle/attitude 1 kHz · Cogging LMS 4 kHz |

Two rules govern the loop structure:

- **Bandwidth separation.** Each outer loop should have at least 5–10× lower bandwidth than the loop inside it: ω_c ≈ 2π·1.5 kHz, ω_v ≈ 2π·80 Hz, ω_θ ≈ 2π·10–15 Hz.
- **Inertial feedback.** In a stabilizer, the velocity loop is closed on the **inertial gyro rate** of the payload, and the encoder is used for commutation only. This is what rejects base motion. The encoder velocity is used as a fallback and for cogging identification.

## 1. FOC Current Loop

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame (SPMSM, $L_d \approx L_q = L$)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q \equiv K_t\, i_q$$

### 1.5 PI with decoupling and back-EMF feedforward
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Pole–zero cancellation of $1/(R+Ls)$ gives a first-order closed loop with bandwidth $\omega_c$:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad(\text{continuous: } \text{PI}(s)=K_p + K_i/s)$$

Keep $\omega_c \le \omega_{PWM}/10$ because of the one-sample computation delay plus the ZOH.

### 1.6 Voltage limiting
The usable voltage vector is limited to the inscribed circle of the SVPWM hexagon:
$$|v_{dq}|\le V_{max}=\tfrac{V_{bus}}{\sqrt3}\cdot m_{max}$$

Priority goes to $v_d$. Then:
$$v_q \leftarrow \text{clamp}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

### 1.7 Anti-windup by back-calculation
$$\dot I = K_i e + K_{aw}(u_{sat} - u_{unsat}),\qquad K_{aw}\approx K_i/K_p$$

### 1.8 Inverse Park and SVPWM (min/max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$
$$v_0=-\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 1.9 Voltage-mode fallback
High-resistance gimbal motors (R > 10 Ω) often lack usable current sensing. In that case, drop the current PI and use:
$$v_q^* = R\,i_q^* + \omega_e\lambda_m,\qquad v_d^* = -\omega_e L\, i_q^*$$

The code supports both modes.
