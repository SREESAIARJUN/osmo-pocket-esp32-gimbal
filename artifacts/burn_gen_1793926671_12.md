# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have any project-specific context for "Job #36", such as the motor part number, encoder, MCU or mechanical inertias. This design therefore uses clearly stated assumptions that you should replace with measured values. Every equation is written so it can be re-parameterized.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. 2804-class): pole pairs p = 7, slots N_s = 12 |
| R, L_d ≈ L_q, λ_m | ~5 Ω, ~1.5 mH, from datasheet or measured K_v |
| Encoder | 14-bit magnetic absolute (MT6701 / AS5047 class) |
| IMU | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| PWM / current loop | 20 kHz, center-aligned, current sampled at the PWM valley |
| Velocity loop | 4 kHz |
| Attitude/angle loop | 1 kHz |

```
 q_target ─► [Attitude error] ─► Angle P(I) ─► ω_ref ─► Velocity PI ─► i_q,ref ─► Current PI (d,q) ─► SVPWM
              ▲ (1 kHz)                          ▲ (4 kHz)    ▲  +i_q,ff (anti-cogging)   ▲ (20 kHz)
              │                                   │           │                           │
        Mahony AHRS ◄── Dual-IMU fusion ◄─────────┴── gyro rate ◄── notch(ω_m) ◄── ICM-42688-P ×2
                                           encoder ─► PLL ─► θ_m, ω_m ──────────────────┘ (θ_e = pθ_m)
```

**Bandwidth separation.** Each outer loop should be 5–10× slower than the loop inside it:

- ω_c,i ≈ 2π·1500 rad/s (current loop)
- ω_c,v ≈ 2π·150 rad/s (velocity loop)
