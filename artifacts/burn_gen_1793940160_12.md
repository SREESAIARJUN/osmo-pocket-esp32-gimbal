# Job #39: STM32H743 AIO Flight Controller with 80 A-Burst 4-in-1 ESC
## Architecture, Loss Model, DShot DMA Plan, Netlists, and Thermal Analysis

This is a **reference design**. Every device parameter below is an explicit assumption. Before release you must replace each one with values from the datasheets of the parts you actually buy, then validate the design on the bench with thermocouples or an IR camera and a current probe. I state the conclusions up front where the numbers force them. The biggest one: **80 A on all four channels at once is not a steady-state rating for a 20×20/25.5×25.5 board.** It is a few-second thermal-mass event. The math below shows why.

## 1. System Architecture

### 1.1 Partitioning decision

The STM32H743 does **not** commutate the motors. ArduPilot runs on the H743 and emits bidirectional DShot600. Four dedicated ESC MCUs run AM32 at a 48 kHz PWM frequency.

Why it is split this way:
- ArduPilot has no field-oriented or six-step motor-control stack for running bridges directly.
- AM32 (open source, supports 48 kHz and bidirectional DShot) is mature on small Cortex-M0+/M4 parts.
- It isolates the hard-real-time commutation from flight-control jitter.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{25}\,\big[1 + \alpha\,(T_j - 25)\big],\qquad \alpha \approx 0.005\ \text{K}^{-1}$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 0.90 mΩ |
| 100 °C | 1.24 mΩ |
| 125 °C | **1.35 mΩ** (design value) |

### 2.2 Six-step trapezoidal current paths

At any instant two phases conduct. One high-side FET (HS) is PWM'd at duty D. The return low-side FET (LS) is held on. With synchronous rectification, the complementary LS of the PWM'd leg conducts during (1−D).

Per-channel conduction loss, with I = phase current during conduction:

$$P_{cond,ch} = I^2\Big[\underbrace{D\,R_{HS}}_{\text{PWM HS}} + \underbrace{(1-D)\,R_{LS,sync}}_{\text{freewheel}} + \underbrace{R_{LS,ret}}_{\text{return leg}}\Big] + I^2 R_{Cu,ch}$$

All R_DS are equal, so this simplifies to:

$$\boxed{P_{cond,ch} = I^2\,(2R_{DS(on)}(T_j) + R_{Cu,ch})}$$

The result is independent of D.
