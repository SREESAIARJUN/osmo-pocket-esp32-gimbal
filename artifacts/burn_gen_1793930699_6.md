# Job #25: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Baseline Assumptions

Job #25's hardware details weren't provided, so this design assumes the following. Every assumed value is a named constant in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz), one per axis or one for all three |
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), *R* ≈ 5–10 Ω, *L* ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sense | 2-phase inline or low-side shunts, ADC triggered at PWM center |
