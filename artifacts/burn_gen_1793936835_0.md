## Part 1 — FOC Current Loop (innermost, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

Find θ_offset at commissioning:
1. Apply V_d with θ_e = 0 so the rotor aligns.
2. Record θ_m.
3. Verify the direction by sweeping θ_e and checking the sign of the change in θ_m.

### 1.2 Clarke transform (balanced 3-phase, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt{3}}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac{3}{2}p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \;\approx\; K_t\, i_q,\qquad K_t = \tfrac{3}{2}p\lambda_m$$

The approximation holds for a surface-mount PM motor (L_d ≈ L_q) with i_d* = 0.

### 1.5 Current PI with feed-forward decoupling

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e \lambda_m$$

**Pole-zero cancellation tuning.** Choose the gains so the closed loop becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{\text{PWM}}}{10}$$

**Discrete PI with back-calculation anti-windup** (T_s = 1/f_loop):

$$u = K_p e + I_k,\qquad u_{\text{sat}} = \text{sat}(u)$$
$$I_{k+1} = I_k + T_s\left[K_i e + K_{aw}(u_{\text{sat}} - u)\right],\qquad K_{aw}\approx K_i/K_p$$

**Voltage vector limit** (circular, d-axis priority):

$$|v_d| \le V_{\max},\qquad |v_q| \le \sqrt{V_{\max}^2 - v_d^2},\qquad V_{\max} = \frac{V_{bus}}{\sqrt 3}\cdot 0.95$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left[\max(v_{abc}) + \min(v_{abc})\right],\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.7 Latency compensation

Rotate θ_e forward by 1.5 T_s × ω_e before the inverse Park. This accounts for one sample of computation delay plus half a period of PWM hold.

## Part 2 — Velocity Estimation (PLL observer)

Differentiating the encoder directly amplifies quantization noise. Use a type-II tracking PLL instead:

$$e_\theta = \text{wrap}(\theta_{\text{meas}} - \hat\theta)$$
$$\hat\omega_{k+1} = \hat\omega_k + T_s K_{i,pll}\, e_\theta$$
$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll}\, e_\theta)$$

The PLL is critically damped (ζ = 1) with these gains:

$$K_{p,pll} = 2\omega_{pll},\qquad K_{i,pll} = \omega_{pll}^2$$

Choose ω_pll ≈ 2π·300 rad/s.
