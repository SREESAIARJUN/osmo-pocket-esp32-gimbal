# STM32H743 AIO Flight Controller with 4-in-1 ESC: 80 A Burst Design Analysis

## 0. Architecture and Assumptions

### 0.1 Architecture

The STM32H743 does not commutate the MOSFETs directly. ArduPilot has no on-board FOC or 6-step ESC driver, so the H743 sends **bidirectional DShot600** to four dedicated ESC MCUs. Each ESC MCU runs AM32 or BLHeli_32 and generates the 48 kHz complementary PWM.

```
 VBAT 6S ─┬─────────────────────────────────────────────────────────┐
          │                                                         │
   [STM32H743 FC]  ── DShot600 bidir (×4) ──►  [ESC MCU ×4] ──► [FD6288Q ×4] ──► [6× MOSFET ×4] ──► M1..M4
   (TIM8 CH1–4)   ◄── eRPM telemetry (GCR) ──   AT32F421 / STM32G071
```

**Reality check (stated up front):** 80 A on all four channels of a 30×30 mm board is a **transient thermal-mass rating**, not a thermal-resistance rating. The analysis below quantifies how many seconds that burst can last.

## 1. Conduction Loss Model

### 1.1 Commutation Topology

In 6-step trapezoidal drive with synchronous rectification (AM32 / BLHeli_32 "complementary PWM"), phase current always flows through exactly **two** MOSFET channels in series:

- **During the ON interval:** high-side of phase A, then low-side of phase B.
- **During the OFF interval:** low-side of phase A (synchronous rectification), then low-side of phase B.

Duty cycle therefore redistributes loss between devices, but the **per-channel total** is duty-independent (excluding dead time):

$$P_{cond,ch} = I_{ph,rms}^2 \cdot 2\,R_{ds(on)}(T_j) + I_{ph,rms}^2 \cdot R_{Cu}$$
