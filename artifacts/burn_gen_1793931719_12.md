# STM32H743 Nano FC + 4-in-1 ESC: 80 A Burst Design Package

## 0. Architecture Clarification and Baseline Assumptions

**Architecture.** ArduPilot does not commutate motors. The STM32H743 runs the flight stack and emits bidirectional DShot600. Each ESC channel needs its own commutation MCU, for example an AT32F421 or STM32G071 running AM32 or BLHeli_32. That ESC MCU generates the 48 kHz complementary PWM. The power stage math below belongs to the ESC side, and the DMA math belongs to the H743.

All device parameters below are representative of 40 V, 3.3×3.3 mm PDFN-class MOSFETs. **Replace them with your datasheet values before sign-off.**

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | Bus voltage |
| I_ph | 80 A | Burst phase current, per ESC |
| f_sw | 48 kHz | PWM frequency |
| R_ds(on),25 | 1.0 mΩ | On-resistance at 25 °C (V_gs = 10 V) |
| α_R | 0.006 /K | R_ds(on) temperature coefficient |
| Q_g / Q_gd | 50 nC / 8 nC | Gate charge |
| C_oss(er) | 1.0 nF | Energy-related output capacitance |
| Q_rr | 30 nC | Reverse-recovery charge |
| V_SD | 0.8 V | Body-diode forward voltage |
| t_dt | 100 ns | Dead time |
| Gate drive | 10 V, R_g,ext 5 Ω + R_g,int 1 Ω, V_plateau 3 V | Gate loop |
| R_Cu,phase | 0.5 mΩ | PCB copper per phase path, 2 oz |
| Board | 20×20 mm, ~6 g populated | Thermal mass |

**Commutation scheme.** Six-step trapezoidal, high-side PWM, synchronous rectification. In each 60° sector:
- Phase A high side switches at duty D.
- Phase A low side conducts the complementary (1−D) interval.
- Phase B low side is on 100%.
- Phase C floats for BEMF sensing.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha_R (T_j - 25)]$$

At T_j = 125 °C: R = 1.0 × (1 + 0.6) = **1.6 mΩ**.

### 1.2 Per-sector current path

Within each sector, the current passes through two FET positions:
- The PWM leg contributes D + (1−D) = 1, minus dead time.
- The fixed low leg contributes 1.

$$P_{cond,ESC} = 2\,I_{ph}^2\,R_{ds}(T_j)\,(1 - 2 t_{dt} f_{sw})$$

$$= 2(6400)(0.0016)(1 - 0.0096) = \mathbf{20.3\ W}\ \text{per ESC channel}$$

The result is nearly duty-independent. At low throttle and high current (punch-out from hover), conduction loss is just as severe as at full throttle.

### 1.3 Per-FET distribution

Over one electrical cycle, each phase spends 1/3 as the PWM leg, 1/3 as the fixed low leg, and 1/3 floating.

$$P_{HS} = \tfrac{D}{3} I^2 R \qquad P_{LS} = \tfrac{1}{3}I^2R + \tfrac{1-D}{3}I^2R$$

| Condition | P_HS | P_LS |
|---|---|---|
| D = 1 (burst) | 3.41 W | 3.41 W |
| D = 0.5 | 1.71 W | 5.12 W |

The low-side FET is the thermal worst case at part throttle.

### 1.4 Copper loss

$$P_{Cu} = 2 I^2 R_{Cu} = 2(6400)(0.0005) = \mathbf{6.4\ W}\ \text{per ESC}$$
