# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #27 spec sheet, so this design states its assumptions explicitly. Every parameter is a named constant you can replace with your real hardware values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, ≥170 MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701), absolute |
| Current sense | 2-shunt inline or low-side (voltage-mode fallback provided) |
| IMU A | ICM-42688-P on the **camera payload** (attitude and rate feedback) |
| IMU B | ICM-42688-P on the **base/handle** (base-rate feedforward and vibration reference) |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle 1 kHz, IMU ODR 8 kHz |

If your two IMUs are instead a co-located redundant pair, Section 4.4 gives the redundant-fusion variant. The code supports both modes.
