## 0. Architectural Corrections and Stated Assumptions

### 0.1 Partitioning: the H743 does not commutate motors

The STM32H743 runs ArduPilot and is the flight controller. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32, and the 48 kHz PWM is generated there. The H743 only emits bidirectional DShot600 and receives eRPM telemetry.

```
6S Bus ──┬── 4× [ESC MCU (AM32) → 3-phase gate driver → 6× MOSFET → Motor]
         │          ▲ DShot600 bidir (1 wire per motor)
         └── 5V/10V BEC ── STM32H743 (ArduPilot) ── IMU/Baro/OSD/UARTs
```

### 0.2 "80A burst" on a nano board is a transient rating, not a thermal rating

The math below shows that 80A per channel is sustainable for roughly 1–2 seconds. The model makes this explicit so the rating is defensible.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Six-step current path with synchronous rectification

In each 60° sector, phase A (PWM) sources current and phase B (low-side held ON) sinks it.

- High-side A conducts for duty D.
- Low-side A (synchronous) conducts for (1−D).
- Low-side B conducts 100% of the sector.

$$P_{cond,ch} = I^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

The result is independent of duty cycle, which makes it a clean worst-case bound.

### 1.2 Temperature dependence

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha_R (T_j-25)]$$

At T_j = 125 °C:

$$R_{ds} = 1.0 \times 1.45 = 1.45\ \text{m}\Omega$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.45\text{m} = \mathbf{18.6\ W}$$

### 1.3 Shunt and copper losses

Shunt loss is non-trivial:

$$P_{shunt} = I^2 R_{sh} = 6400 \times 0.5\text{m} = \mathbf{3.2\ W}$$

Copper trace loss, with ~0.3 mΩ of effective path resistance on 2 oz inner layers:

$$P_{Cu} \approx 6400 \times 0.3\text{m} \approx \mathbf{1.9\ W}$$

### 1.4 Peak per-FET instantaneous loss

The constant-on low-side carries the highest instantaneous loss:

$$P_{FET,pk} = 80^2 \times 1.45\text{m} = 9.3\ \text{W}$$

$$\Delta T_{jc} = 9.3 \times 1.5 = 14\ \text{K}$$
