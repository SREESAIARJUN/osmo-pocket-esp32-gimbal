**Architecture.** Each axis uses an encoder for commutation and for cogging compensation. The camera-mounted IMUs provide inertial rate for the velocity loop and attitude for the angle loop.

This split is the key design choice. The gimbal's purpose is to null inertial camera motion, not joint motion. Closing the velocity loop on joint rate would faithfully transmit base vibration to the camera.

## 1. Field-Oriented Control (20 kHz inner loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

The offset θ_off is found at commissioning. Inject a stationary d-axis voltage v_d = V_align with θ_e = 0, wait for the rotor to settle, then record θ_m.

**Latency compensation.** The encoder sample and the PWM update are separated by roughly T_d ≈ 1.5 T_pwm (sample, compute, PWM shadow load). Advance the angle used for the inverse Park transform:

$$\hat\theta_e = \theta_e + \omega_e T_d$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b) \quad(\text{using } i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and current controller

The surface-PM motor model in the rotating frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The electromagnetic torque is:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

The PI controller uses feed-forward decoupling and pole-zero cancellation. Choose the current bandwidth ω_c ≤ 2π f_i / 10 (e.g. 2π·1.5 kHz). Then:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With these gains the closed loop is first-order:

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

The discrete control law (backward Euler) is:

$$u_x[k] = K_{p,i} e_x[k] + I_x[k] + v_x^{ff}$$
$$I_x[k+1] = I_x[k] + K_{i,i}T_i\,e_x[k] + K_{aw}\big(u_x^{sat}[k]-u_x[k]\big)$$

The decoupling feed-forward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

The reference is i_d* = 0, since there is no field weakening at gimbal speeds.

**Voltage limit (circular, d-axis priority).**

$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{lim},\quad m_{lim}=0.95$$

$$v_d^{sat} = \operatorname{clamp}(v_d,\pm V_{max}),\qquad v_q^{sat} = \operatorname{clamp}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

Use the back-calculation gain K_aw = 1/K_{p,i}·(K_{i,i}T_i)·κ with κ ≈ 1. Equivalently, set the anti-windup time constant T_t = √(T_i,PI · T_d).
