## 0. Executive Findings (Read First)

| # | Finding | Severity |
|---|---|---|
| 1 | At 80 A per channel, each ESC dissipates **≈23 W**. With all four channels at burst, the total is **≈92 W** on a ~20×20 mm-class board. | 🔴 Critical |
| 2 | If all four channels burst at 80 A simultaneously, the adiabatic board heating rate is **≈37 K/s**. The safe burst window is **≈1.5–2 s** from a 40 °C start, not the 5–10 s typical of marketing "burst" ratings. | 🔴 Critical |
| 3 | 4 × 80 A = 320 A battery current. This exceeds XT30/XT60 connectors and 12–14 AWG leads. The spec most likely means 80 A on a single channel, or 80 A total. **Clarify before layout.** | 🔴 Critical |
| 4 | Conduction loss dominates (≈89%). The 48 kHz switching loss (≈1.8 W) is secondary. Dead-time diode conduction (≈0.6 W) is the next lever. | 🟡 Design |
| 5 | Bi-directional DShot600 on 4 motors needs **6 DMA streams** (2 timers × UP + 4 × CCx, or fewer if shared). The H743 DMAMUX makes this easy, but buffers **must not live in DTCM**. | 🟢 Solvable |

## 1. System Architecture

```
            6S LiPo (25.2 V max)
                 │
        ┌────────┴─────────────────────────────────────────┐
        │  VBAT bus ── TVS ── Bulk cap ── MLCC array       │
        │     │                                            │
        │  ┌──┴──┐ ┌─────┐ ┌─────┐ ┌─────┐                 │
        │  │ESC1 │ │ESC2 │ │ESC3 │ │ESC4 │  AT32F421 +     │
        │  │     │ │     │ │     │ │     │  gate driver +  │
        │  └──▲──┘ └──▲──┘ └──▲──┘ └──▲──┘  6× N-MOSFET    │
        │     │ BDShot (inverted, 1-wire, bidirectional)   │
        │  ┌──┴───────┴───────┴───────┴──┐                 │
        │  │  STM32H743VIT6 @ 480 MHz     │── IMU / Baro / OSD / UARTs
        │  └──────────────────────────────┘                 │
        └──────────────────────────────────────────────────┘
```

**Note:** The H743 does not drive the MOSFETs. Each channel has a dedicated ESC MCU (AT32F421 running AM32, or an equivalent). The 48 kHz PWM is generated by the ESC MCU. The H743 sends only DShot commands and receives eRPM telemetry.
