## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform, using i_c = −i_a − i_b:
```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

Electrical angle, where θ_off is the encoder-to-rotor alignment offset found at calibration:
```
θ_e = p · (θ_m − θ_off)   (mod 2π)
```

Park transform:
```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

Inverse Park transform:
```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
```

### 1.2 Plant and current PI design

The motor model in the dq frame is:
```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
```

Decoupling feedforward:
```
v_d,ff = −ω_e L i_q
v_q,ff =  ω_e L i_d + ω_e λ_m
```

With decoupling, each axis reduces to G(s) = 1/(Ls + R). Pole-zero cancellation with a PI controller C(s) = K_p + K_i/s gives a first-order closed loop with bandwidth ω_c:
```
K_p = L · ω_c
K_i = R · ω_c
```
Choose ω_c ≤ 2π·f_pwm/10. For f_pwm = 20 kHz, ω_c = 2π·1500 rad/s.

To compensate the one-sample computation delay, rotate the output by half a period using θ_e + 1.5·ω_e·T_s in the inverse Park transform.

Torque produced:
```
τ = (3/2) p λ_m i_q = K_t i_q
```
Control uses i_d* = 0.

### 1.3 Voltage limiting and anti-windup

Limit the voltage vector to the inscribed circle of the space-vector hexagon:
```
|v_dq| ≤ V_bus/√3
```
Give d-axis priority:
```
v_d = sat(v_d, ±V_max)
v_q = sat(v_q, ±√(V_max² − v_d²))
```

Back-calculation anti-windup:
```
I[k+1] = I[k] + T_s · ( K_i·e + K_aw·(v_sat − v_unsat) )
K_aw ≈ K_i / K_p
```

### 1.4 SVPWM (min/max zero-sequence injection)

```
v_a = v_α
v_b = −½v_α + (√3/2)v_β
v_c = −½v_α − (√3/2)v_β

v_0 = −½ (max(v_a, v_b, v_c) + min(v_a, v_b, v_c))

D_x = ½ + (v_x + v_0) / V_bus,   clamped to [0, 1]
```
