# STM32H743 AIO (FC + 4-in-1 ESC) Nano: Power, Thermal, and Bi-Directional DShot Architecture

## 0. Scope, Assumptions, and Design Warnings

**Architecture assumption.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. Each motor channel has its own ESC MCU (assumed AT32F421 running AM32), a 3-phase gate driver (FD6288Q-class), and 6 N-MOSFETs. This is the only practical way to get 48 kHz complementary PWM, bi-directional DShot telemetry, and ArduPilot support together.

**Parameter caveat.** All device values below are representative assumptions for a 20×20 mm-class AIO. Replace them with datasheet values for the parts you actually select. The equations are general; the numbers are only illustrative.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | DC link voltage |
| I_ph | 80 A | Burst phase current, per motor |
| R_ds(on),25 | 1.5 mΩ | 40 V, 3.3×3.3 mm PDFN-class FET |
| α | 0.0045 /K | R_ds(on) temperature coefficient |
| t_r + t_f | 20 + 15 ns | At ~2 A gate drive |
| Q_rr | 40 nC | Body diode reverse recovery charge |
| C_oss(er) | 1.5 nF | Effective output capacitance |
| V_SD | 0.8 V | Body diode forward voltage |
| t_dead | 100 ns | Per edge |
| Q_g | 40 nC | Gate charge at V_GS = 10 V |
| f_sw | 48 kHz | PWM frequency |

> ⚠️ **Feasibility flags. Read these before committing to the spec.**
> 1. **Board heat.** 80 A on all four motors at once produces about 125 W of heat in roughly 7 cm² of board. As shown in §4, this is a **≈2-second burst rating**, not a continuous one.
> 2. **Battery current.** At 90% duty, 4 × 80 A means I_bat ≈ 290 A. XT60 connectors, 12–14 AWG leads, and pad copper cannot carry this. "80 A burst" should be specified **per motor, non-simultaneous**, or the input interface must be redesigned.
> 3. **Validation.** Every number here must be validated by thermocouple or IR test on a real board.

## 2. Conduction Loss Model

### 2.1 Commutation geometry
With 6-step trapezoidal commutation and synchronous rectification (AM32 complementary PWM):

- At any instant, exactly **two legs** carry the phase current I_ph.
- In each conducting leg, exactly one FET of the pair is ON, apart from dead-time.

The current path is therefore always two R_ds(on) in series:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j)$$
