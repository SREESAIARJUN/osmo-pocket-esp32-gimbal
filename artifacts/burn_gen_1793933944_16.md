# STM32H743 FC + 4-in-1 ESC (Job #61): Design Model

## 0. Architecture Corrections and Assumptions

Two points about the request need correcting before the analysis.

**1. ArduPilot does not run on the ESC.** In a "flight controller + 4-in-1 ESC" stack:

- **FC:** STM32H743 running ArduPilot. It generates bidirectional DShot600 and parses the eRPM telemetry.
- **ESC:** a separate MCU per motor or a shared MCU. This is typically an AT32F421, STM32G071 or GD32 running AM32 or BLHeli_32. It does the 48 kHz PWM, commutation and BEMF sensing.

The DMA/timer analysis below is for the H743. The loss and thermal analysis is for the ESC power stage.

**2. "Nano" plus 80 A burst is a contradiction.** It is only physically credible on a 30×30 mm mounting pattern (about 36×40 mm board). On a 20×20 board the thermal capacitance roughly halves, and the burst duration computed in §3 drops below about 1.5 s. I model the 30×30 case and flag the 20×20 deltas.
