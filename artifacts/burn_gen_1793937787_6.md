# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the original specification for Job #9, so the design below rests on the assumptions in §0. Every parameter is exposed as a named constant, so you can substitute your real hardware values without changing the structure.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: Cortex-M4F/M7, single-precision FPU, CORDIC optional |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A) |
| Inverter | 3-phase, center-aligned PWM at 20 kHz, inline or low-side shunts |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, ODR 8 kHz |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

**Rate hierarchy.** Each loop runs at roughly 4–10× the bandwidth of the loop it commands.

```
 20 kHz  ADC-triggered ISR : current sampling → Clarke/Park → PI(id,iq) → SVPWM
  8 kHz  IMU DRDY ISR      : read both IMUs → rotate → notch/LPF → fuse
  4 kHz  velocity task     : encoder PLL, gyro projection, velocity PI, anti-cogging FF
  1 kHz  attitude task     : quaternion fusion (Mahony), attitude P(+I) → rate commands
```

**Bandwidth targets.**
- Current loop: ω_c ≈ 2π·2000 rad/s.
- Velocity loop: ω_v ≈ 2π·150 rad/s.
- Angle loop: ω_θ ≈ 2π·30 rad/s.
