# STM32H743 Nano FC + 4-in-1 80 A ESC: Systems Architecture Model (Job #18)

**Document class:** Architecture derivation. All component values are design-intent and must be confirmed against the selected vendors' datasheets before layout freeze.

---

## 0. Architectural Ground Truth and Feasibility Flags

Several constraints shape the rest of this design.

| # | Issue | Consequence |
|---|---|---|
| F1 | A 4-in-1 ESC does not run on the H743. Each motor's commutation (48 kHz PWM, BEMF/ZC detection) runs on an ESC-side MCU (e.g., AT32F421 with AM32, or a BLHeli_32-class part). The H743 runs ArduPilot and sends **DShot600 commands** while receiving **bidirectional eRPM telemetry**. | Two firmware domains and two netlists: the FC and the ESC. |
| F2 | **80 A/motor in a "nano" (20×20 mm) footprint is not credible.** The total is 320 A from the battery and about 84 W of dissipation (§2). | The power stage is specified at **30.5×30.5 mm**. The FC may be 20×20, stacked, or the whole design can be an AIO board on 30.5. |
| F3 | "80 A" is treated as a **burst** rating. Continuous capability is about 35–45 A/motor (§3). | The burst duration limit is derived in §3.4. |
| F4 | 48 kHz is the ESC PWM carrier. DShot600 is a separate serial link. | The two are decoupled. Only the DShot frame timing constrains the loop rate. |

**Baseline operating point:** 6S LiPo, V_bus = 25.2 V (full charge, worst case for switching losses), T_amb = 35 °C, prop-wash convection.

### 1.2 Gate driver

The gate driver is an FD6288Q-class 3-phase bootstrap driver, with V_CC = 10 V from the ESC-local LDO/buck.

- R_G(on) = 10 Ω, R_G(off) = 4.7 Ω (with a fast-off diode).
- Effective gate current at the Miller plateau is about 0.7 A on and 1.2 A off.

## 2. Loss Model (per motor channel)

### 2.1 Conduction losses (80 A burst)

**Temperature-dependent on-resistance:**

$$R_{DS}(T_j) = R_{DS0}\,[1+\alpha(T_j-25)]$$

At the design target T_j = 115 °C: R_DS = 1.0 × (1 + 0.0055 × 90) = **1.50 mΩ**.

**Conduction topology.** The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At any instant, two legs carry the phase current I:

- **The PWM'd leg:** current alternates between the high-side (HS) switch for duty D and the low-side (LS) switch for duty (1−D). Exactly one switch conducts I at all times, except during dead time.
- **The static leg:** one switch is held fully on.

The conduction loss per motor is therefore:

$$P_{cond} = \underbrace{I^2R_{DS}D + I^2R_{DS}(1-D)}_{\text{PWM leg}} + \underbrace{I^2R_{DS}}_{\text{static leg}} = 2I^2R_{DS}$$

This result is independent of duty cycle. At I = 80 A:

$$P_{cond} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W}$$

**Copper loss.** Each phase path has about 3 squares of copper per layer. With 2 oz copper, sheet resistance is R_□ = ρ/t = 1.72×10⁻⁸ / 70×10⁻⁶ = 0.246 mΩ/□ at 25 °C. With 4 parallel power layers at about 100 °C (×1.3), the path resistance is ≈ 0.24 mΩ, giving:

$$P_{Cu} \approx 80^2 \times 0.24\text{ mΩ} \approx 1.5\ W$$
