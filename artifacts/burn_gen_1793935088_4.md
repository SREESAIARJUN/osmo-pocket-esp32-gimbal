# STM32H743 Flight Controller + 80 A 4-in-1 ESC: Systems Architecture Package (Job #66)

## 0. Architecture Baseline and Feasibility Flags

Three points determine whether this design works, so they come first.

**Flag 1: The H743 does not commutate the motors.** ArduPilot running on the H743 is the flight controller. It sends bi-directional DShot600 to four dedicated ESC MCUs. Each ESC MCU (AT32F421K8U7 running AM32, or STM32G071 running BLHeli_32/AM32) runs six-step commutation at 48 kHz PWM. Bi-directional DShot only makes sense with this split. ArduPilot has no on-H7 motor commutation path.

**Flag 2: "Nano" and "80 A burst" conflict.**
- A 20×20 mm board cannot hold 24 power FETs at the R_DS(on) required. The model below (§1.5) shows an 80 A burst produces about 26 W per channel.
- The **minimum viable form factor is 30.5×30.5 mm**, 8-layer, with 2 oz outer and 2 oz inner power planes.
- I treat "nano" as the FC stack (H743 board at 20×20) mounted on a 30.5 mm ESC. If 20×20 is a hard requirement, the honest rating is about **45 A burst / 25 A continuous**.

**Flag 3: The thermal results set the product rating.** The model shows 80 A per channel is a **≈4 s burst** with all four channels loaded. Continuous capability is about **28–32 A per channel** with no heatsink. Datasheets and marketing must reflect this.

## 1. Loss Model

### 1.1 Conduction Path (Six-Step, Complementary PWM)

In any 60° commutation sector:
- One phase leg is PWM-switched. Current flows through its high-side (HS) FET for duty D, and through its synchronous low-side (LS) FET for 1 − D.
- One leg's LS FET is held on as the static return path.
- The third leg floats (BEMF sensing).

So there are **always exactly two FET channels in series with the phase current**, independent of D:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j) + I^2 R_{Cu}$$

Per-FET RMS currents over one electrical period (each FET is active for 1/3 of the period):

$$I_{HS,rms}^2 = \frac{I^2 D}{3},\quad I_{LS,sync,rms}^2 = \frac{I^2(1-D)}{3},\quad I_{LS,static,rms}^2 = \frac{I^2}{3}$$

LS FETs serve both the synchronous and static roles in different sectors, so they run hotter. **Place LS FETs nearest the thermal via fields and ground pour.**
