# STM32H743 FC + 4-in-1 80A ESC (Nano Stack): System Architecture Model

## 0. Scope and Baseline Assumptions

I don't have the Job #54 BOM, so this model uses a declared reference design. Every equation is parametric, so you can substitute the real datasheet values.

| Parameter | Symbol | Value | Basis |
|---|---|---|---|
| Battery | V_bus | 25.2 V (6S full) | Worst case for switching loss |
| Burst phase current per motor | I_ph | 80 A | Requirement |
| PWM frequency (ESC MCU) | f_sw | 48 kHz | Requirement |
| MOSFET | — | 40 V, 5×6 mm or 3.3×3.3 mm, Rds(on) = 1.0 mΩ typ @ 25 °C, Vgs = 10 V | Class-typical |
| Rds(on) tempco | α | 0.006 /K | Typical trench Si |
| Q_g / Q_rr / Q_oss | — | 60 nC / 30 nC / 40 nC | Class-typical |
| t_r + t_f at 80 A | t_sw | 22 ns | Strong gate driver, ~2 Ω R_g |
| Dead time | t_d | 100 ns per edge | Typical AM32/BLHeli_32 |
| Body diode V_f | V_f | 0.8 V | — |
| Rth junction to case | R_θJC | 1.2 K/W | — |
| Motor phase inductance | L_ph | 20 µH | Typical 2207–2810 class |
| Board | — | 30.5 mm mount, 8-layer, 2 oz outer and inner power planes | "Nano" stack |

**Architectural note:** In a 4-in-1 ESC the 48 kHz commutation PWM is generated by four independent ESC MCUs, not by the H743. The H743 runs ArduPilot and sends bi-directional DShot600. Typical ESC MCUs are the AT32F421 or STM32G071 running AM32 or BLHeli_32. Keeping this split avoids saturating the H743's timer and DMA resources and isolates high-dV/dt firmware faults.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Topology current paths

The ESC uses six-step trapezoidal commutation with synchronous rectification. In each 60° sector:

- one phase is PWM-switched (high-side for duty D, low-side as sync rectifier for 1−D),
- one low-side FET is held fully on,
- the third phase floats for BEMF sensing.

At any instant, exactly two FETs carry the full phase current:

$$P_{cond,ch} = 2\, I_{ph,rms}^2\, R_{ds(on)}(T_j)$$

### 1.2 Ripple contribution

The ripple is largest at D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus} D(1-D)}{L_{ph} f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple adds 0.06 % and can be neglected at burst current. It does matter for core loss in the motor, which is outside the scope of this board.

### 1.3 Temperature-dependent Rds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

| T_j | Rds(on) | P_cond per channel |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 110 °C | 1.51 mΩ | **19.3 W** |
| 150 °C | 1.75 mΩ | 22.4 W |

### 1.4 Electro-thermal stability check

Conduction loss rises with temperature, so check for thermal runaway. The loop gain is:

$$G = \frac{\partial P}{\partial T}\,R_{\theta} = 2 I^2 R_{25}\,\alpha\,R_\theta$$

With R_θ ≈ 3.2 K/W per FET (junction to board) and per-FET loss of about 9.7 W:

$$G = 9.7 \times \frac{0.006}{1.51} \times 3.2 \times 1.51 \approx 0.19$$

G is well below 1, so the system is locally stable. The effective temperature rise is amplified by

$$\frac{1}{1-G} = 1.23$$

## 2. Switching Loss Model at 48 kHz

Losses are counted for each PWM-switched leg.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½ V I t_sw f_sw = 0.5 × 25.2 × 80 × 22 ns × 48 k | **1.06 W** |
| Reverse recovery | Q_rr V f_sw = 30 nC × 25.2 × 48 k | 0.036 W |
| Output capacitance | ½ Q_oss V f_sw | 0.024 W |
| Dead-time diode conduction | V_f I (2 t_d) f_sw = 0.8 × 80 × 200 ns × 48 k | **0.61 W** |
| Gate drive (2 FETs) | 2 Q_g V_gs f_sw = 2 × 60 nC × 10 V × 48 k | 0.058 W (in driver) |
| **Switching subtotal** | | **≈ 1.73 W** |

Totals:

- **Per channel at burst (T_j = 110 °C):** 19.3 + 1.73 ≈ **21.0 W**
- **Four channels:** ≈ **84 W**
- **Electrical efficiency at burst:** Battery power is roughly 4 × 80 A × 25.2 V × D. At D = 0.9 that is about 7.26 kW, so efficiency is about 98.8 %.

The efficiency figure looks good, but the issue is heat density, not efficiency.

**Frequency trade:** Moving from 48 kHz to 24 kHz saves about 0.85 W per channel but increases ripple to about 13 A pp, plus acoustic noise and motor core loss. At burst, 48 kHz is defensible because conduction loss dominates at 92 %.

## 3. Thermal Model

### 3.1 Network

```
Tj ──R_θJC 1.2──┬── Tcase ──R_θ,vias/spread 2.0──┬── T_board ──R_θ,conv──┬── T_amb
                │                                 │                       │
             C_j ≈ 0.05 J/K                  C_board ≈ 6 J/K             (prop wash)
```

The hot-FET junction rise above the board is:

$$\Delta T_{j-b} = \frac{21.0}{2}\times(1.2+2.0) \approx 34\ \text{K}$$

After the ×1.23 electro-thermal factor, this becomes about **41 K**.
