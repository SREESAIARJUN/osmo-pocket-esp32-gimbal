# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #42 specification, so this design states its assumptions explicitly. Each one is a parameter you can change.

| Parameter | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, e.g. GBM2804: 12N14P, so 7 pole pairs, R ≈ 10 Ω, L ≈ 2 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each axis |
| MCU | Cortex-M4F/M7 class with single-precision FPU (STM32G4/H7) |
| Current loop | 20 kHz (in the PWM interrupt) |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| IMU | 2 × ICM-42688-P on separate SPI buses, gyro and accel ODR 8 kHz |
| Attitude output | 1 kHz |

## 1. Motor Model and the FOC Current Loop

### 1.1 Frame transforms

The amplitude-invariant Clarke transform is:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)\qquad (i_a+i_b+i_c=0)
$$

The Park transform and its inverse use the electrical angle θₑ = p·(θₘ − θ_offset):

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} v_d\\ v_q\end{bmatrix}
$$

### 1.2 PMSM dynamics (surface magnets, so L_d = L_q = L)

$$
L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q
$$

$$
L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e\lambda_m
$$

The torque constant and mechanical dynamics are:

$$
\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q
$$

$$
J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{load}
$$

### 1.3 Current PI with decoupling

The decoupling feedforward terms cancel the cross-coupling and back-EMF:

$$
v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m
$$

After decoupling, each axis reduces to the plant 1/(Ls + R). Using pole-zero cancellation with closed-loop bandwidth ω_c gives the gains:

$$
K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c
\;\;\Rightarrow\;\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}
$$

Choose ω_c ≤ 2π·f_pwm/20, which gives about 2π·1 kHz at 20 kHz PWM.

Gimbal motors have high resistance and low current. If the drive is voltage-mode without current sensing, set v_q = R·i_q* + ω_e·λ_m directly. The code supports both modes.

### 1.4 Voltage limiting and SVPWM

Limit the voltage vector to the linear-modulation circle while prioritising v_d:

$$
|v| \le V_{bus}/\sqrt3
$$

Use min-max zero-sequence injection, which is equivalent to SVPWM:

$$
v_0 = -\tfrac12(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c))
$$

$$
D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}
$$

### 1.5 Discrete PI with back-calculation anti-windup

$$
e_k = r_k - y_k,\qquad u_k = K_p e_k + I_k + u^{ff}_k
$$

$$
\bar u_k = \mathrm{sat}(u_k)
$$

$$
I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big]
$$

A typical anti-windup gain is K_aw = K_i/K_p, i.e. the reciprocal of the integral time constant.

## 2. Velocity Estimation (PLL Observer)

Differentiating a 14-bit encoder at 4 kHz gives a quantisation noise of about 1.5 rad/s. A type-2 PLL avoids this:

$$
\varepsilon_k = \mathrm{wrap}_{\pi}(\theta_k - \hat\theta_k)
$$

$$
\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + k_p\varepsilon_k)
$$

$$
\hat\omega_{k+1} = \hat\omega_k + T_s k_i\varepsilon_k
$$

The gains are:

$$
k_p = 2\zeta\omega_n,\qquad k_i=\omega_n^2,\qquad \zeta=1,\quad \omega_n \approx 2\pi\cdot 150\,\text{Hz}
$$
