| Item | Assumption | Notes |

| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) | Used for commutation and cogging |
| Current sense | 2-phase low-side shunts, sampled at PWM center | |
| MCU | STM32G4 / H7 (FPU, ≥170 MHz) | |
| PWM / current loop | 20 kHz center-aligned / 20 kHz | T_i = 50 µs |
| Velocity loop | 4 kHz (gyro-driven) | T_v = 250 µs |
| Attitude loop | 1 kHz | T_θ = 1 ms |
| IMUs | 2× ICM-42688-P on SPI, ODR 8 kHz, FIFO-less data-ready reads | Mounted on the camera plate |
| Axis order | Base → Yaw → Roll → Pitch → Camera | |
