# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #5 specification, so this design uses the following baseline. Every value is a named constant in the code, so you can substitute your real hardware parameters.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s\approx 5\,\Omega$, $L_s\approx 2\,\text{mH}$, $K_t\approx 0.08\,\text{Nm/A}$ |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| MCU | STM32G474 (FPU, CORDIC) or equivalent Cortex-M4F/M7 |
| IMU A | ICM-42688-P on the camera payload (attitude, payload rate) |
| IMU B | ICM-42688-P on the base/handle (disturbance feedforward) |
| Axis order | Base → Yaw (z) → Roll
