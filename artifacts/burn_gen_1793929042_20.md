## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path in 6-Step Complementary PWM

At any commutation step, phase A's high side is PWM'd at duty D, phase B's low side is held on, and phase C floats.

- **During D:** current flows through HS_A, the motor, then LS_B.
- **During (1−D):** current freewheels through LS_A (synchronous rectification), the motor, then LS_B.

So the motor current always passes through exactly **two conducting FETs**, independent of D. The only exception is dead time, which is handled in §2.

### 1.2 Equations

On-resistance versus temperature:

$$
R_{ds}(T_j) = R_{ds,25}\left[1+\alpha\,(T_j-25)\right]
