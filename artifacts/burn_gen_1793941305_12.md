# STM32H743 + 4-in-1 ESC Nano Stack (Job #65): Architecture, Loss Model, DShot DMA Plan, Netlists, Thermals

## 0. Scope, Assumptions, and Two Upfront Findings

**Finding 1: Architectural correction.** The STM32H743 should run ArduPilot (flight control) only. It should not commutate motors. The 4-in-1 ESC needs four dedicated ESC MCUs, one per motor. AT32F421 or STM32G071 parts running AM32 are typical. The H743 talks to them over bi-directional DShot600. ArduPilot has no BLDC commutation firmware, and doing 4×3-phase commutation at 48 kHz on the FC would break its real-time scheduler.

**Finding 2: Thermal reality check.** The math below shows that an "80 A burst" rating in a nano form factor (20×20 mm mounting, about 30×30 mm board) is only achievable:

- for roughly 1–3 seconds with all four motors loaded simultaneously, or
- for single-motor transients.

Sustained capability is roughly 12–18 A per channel, depending on prop-wash airflow. Treat "80 A" as a transient rating and enforce it in firmware.

### 2.2 Current path in 6-step with synchronous rectification

In each commutation sector, one leg is PWM'd (complementary HS/LS) and a second leg is held statically on.

- The current always passes through exactly **two conducting FETs**:
  - the static FET, which conducts 100% of the time, and
  - either the PWM leg's HS (for duty D) or its LS (for duty 1−D).
- So the per-motor conduction loss is independent of duty:

$$P_{cond,motor} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

Per-device split within a sector:

$$P_{static} = I^2 R_{ds},\quad P_{HS,pwm} = D\, I^2 R_{ds},\quad P_{LS,pwm} = (1-D)\, I^2 R_{ds}$$
