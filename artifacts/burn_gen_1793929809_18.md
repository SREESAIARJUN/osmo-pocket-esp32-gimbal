# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Reference

**Scope:** A loss model for one ESC power stage (×4), thermal transient analysis for an 80 A burst, a bi-directional DShot600 timer and DMA plan for ArduPilot on the H743, and reference netlists.

**Assumptions.** I don't have the Job #14 BOM or stack-up, so every device value below is a stated placeholder. The equations are general. Substitute the datasheet values for your selected MOSFET, gate driver, and board before you sign off.
