# FOC Motor Control and Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #39", so this design rests on the explicit assumptions in §0. Every parameter is a named constant so you can substitute your hardware values. Three groups of items must be checked against your hardware before you power motors:

- The ICM-42688-P AAF/notch register values (verify against your datasheet revision).
- Encoder alignment and calibration.
- The gimbal axis order, which must match the Jacobian in §4.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, e.g. GBM4108: N_p = 11 pole pairs, N_s = 12 slots |
| Phase R / L | 5.5 Ω / 2.0 mH (line-to-neutral) |
| Encoder | 14-bit magnetic, e.g. AS5048A / MT6701, on each joint |
| IMU A | ICM-42688-P on the **camera/payload plate**: attitude and inertial-rate feedback |
| IMU B | ICM-42688-P on the **base/handle**: disturbance feedforward and vibration reference |
| Axis order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → camera |

Loop rates and timing:

```
 20 kHz  : Current (FOC) loop      — ADC-triggered ISR, center-aligned PWM
  8 kHz  : IMU sampling (both)     — FIFO/DRDY, AAF + notch + LPF
  4 kHz  : Joint velocity loop     — encoder velocity + base-gyro feedforward
  1 kHz  : Attitude loop           — Mahony fusion → inertial angle → rate command
```

The control cascade:

```
θ_ref ─►[Attitude P + FF]─► ω_p,ref ─►[J⁻¹(q)]─► q̇_ref ─►[Velocity PI]─► i_q,ref ─►[Current PI + SVPWM]─► Motor
              ▲ IMU-A fused attitude      ▲ −J⁻¹R·ω_base (IMU-B FF)   ▲ encoder q̇   ▲ + i_cog(θ) feedforward
```

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle is θ_e = N_p·(θ_m − θ_offset).

**Clarke** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Current PI with decoupling and pole-zero cancellation

The PI law, with cross-coupling decoupling and back-EMF feedforward:

$$v_d^* = \underbrace{K_p e_d + K_i\!\int e_d}_{\text{PI}} - \omega_e L i_q,\qquad v_q^* = K_p e_q + K_i\!\int e_q + \omega_e L i_d + \omega_e\lambda_m$$

Choose the gains to cancel the plant pole s = −R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

**Delay constraint.** The computation plus PWM delay is about T_d ≈ 1.5·T_s = 75 µs. Requiring a phase margin of at least 60° gives:

$$\omega_c \le \frac{\pi/2 - \pi/3}{T_d}\;\Rightarrow\;\omega_c \le 7.0\text{ krad/s}\;(\approx 1.1\text{ kHz})$$

For the assumed motor, use ω_c = 2π·800, which gives K_p = 10.05 V/A and K_i = 27.6 kV/(A·s).
