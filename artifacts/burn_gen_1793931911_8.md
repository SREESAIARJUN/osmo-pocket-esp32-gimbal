## 0. Architecture Decision and Assumptions

### 0.1 Topology correction (read first)

The STM32H743 should **not** commutate the motors directly. ArduPilot does not run ESC firmware, and bidirectional DShot implies a separate ESC controller. The architecture is therefore:

```
            ┌──────────────── H743 Flight Controller (ArduPilot) ────────────────┐
 IMU/Baro ──┤ SPI1/SPI4/I2C2   TIM1 CH1–CH4 ── bidir DShot600 ──┐                 │
 GPS/RC  ───┤ UARTs            ADC (Vbat, Ibat)                 │                 │
            └────────────────────────────────────────────────────┼────────────────┘
                                                                 ▼
         4 × ESC MCU (AT32F421 / STM32G071, AM32 firmware, 48 kHz PWM)
         4 × 3-phase gate driver  →  4 × 6 MOSFET bridges  →  M1..M4
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,(1+\alpha)^{(T_j-25)},\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C:

$$R_{DS}(125) = 1.2\,\text{m}\Omega \times 1.005^{100} = 1.2 \times 1.647 = 1.98\ \text{m}\Omega$$
