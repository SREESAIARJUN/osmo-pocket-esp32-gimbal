The H743 does not switch the bridges. It sends DShot600 to the four ESC MCUs and receives eRPM telemetry back. The 48 kHz PWM lives in AM32, not ArduPilot. If you intend the H743 to run four FOC loops directly, that is a different, much harder design. Flag it now if so.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

In any 60° sector, exactly two phases carry the full motor current I. The PWM leg alternates between its high-side (HS) MOSFET (fraction D) and its low-side (LS) MOSFET (fraction 1−D). The return leg's LS stays fully on.

So at every instant, exactly two MOSFETs carry current I in series:

$$P_{cond,ch} = 2\,I^2\,R_{DS(on)}(T_j) + I^2 R_{Cu,path}$$

The per-device split over one electrical period, per leg:

$$\bar{P}_{HS} = \tfrac{1}{3} D\, I^2 R_{DS}, \qquad \bar{P}_{LS} = \tfrac{1}{3}(1-D) I^2 R_{DS} + \tfrac{1}{3} I^2 R_{DS}$$

At high throttle (D → 1), HS and LS devices load roughly equally, at about 1/3 · I²R each. The LS device is always the more stressed one at partial throttle.

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\,\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.0055\ /\mathrm{K}$$

| Quantity | Value |
|---|---|
| R<sub>DS(on)</sub> at T<sub>j</sub> = 115 °C | 1.2 × 1.50 ≈ 1.8 mΩ |
| R<sub>Cu,path</sub> (pads, vias, phase pour, solder) | ≈ 0.25 mΩ, to be confirmed by 4-wire measurement on the first article |

### 1.3 Numbers at I = 80 A

$$P_{cond,ch} = 2(80^2)(1.8\,\mathrm{m\Omega}) + 80^2(0.25\,\mathrm{m\Omega}) = 23.0 + 1.6 = \mathbf{24.6\ W}$$

Peak per-device instantaneous loss during its conduction window is 80² × 1.8 mΩ = **11.5 W**. The average per device is about 3.8 W.

**Phase current shape.** Each phase conducts 240° of the 360° electrical period, so:

$$I_{RMS,phase} = I\sqrt{2/3} = 65.3\ \mathrm{A}$$

Size the phase pours and motor pads for 65 A RMS, not 80 A.
