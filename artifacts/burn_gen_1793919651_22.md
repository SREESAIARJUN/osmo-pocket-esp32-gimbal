# STM32H743 FC + 80 A 4-in-1 ESC: System Architecture Package

## 0. Scope and Assumptions

I don't have a spec on file for "Job #0", so this package states its baseline explicitly. Every number below derives from the parameters in §0.2. If you change a parameter, the equations show how the results change.

### 0.1 Partitioning

The STM32H743 is the **flight controller** (ArduPilot). It does not drive the MOSFET gates. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32-class firmware, for example an AT32F421 or STM32G071. This is the only workable partitioning: ArduPilot has no 6-step or FOC commutation path for 48 kHz gate drive on four motors. The H743 is responsible for:

- Bi-directional DShot600 command and eRPM telemetry
- Current and voltage sensing
- Optional serial ESC telemetry
