## 0. Architecture Clarification

The STM32H743 does **not** drive the power stage directly. The standard and recommended partition is:

| Block | Device | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz, LQFP100) | ArduPilot | Attitude control, DShot600 master, RPM notch |
| ESC controllers (×4) | AT32F421K8U7 or STM32G071 (QFN32) | AM32 | Commutation and 48 kHz PWM generation, bi-dir telemetry |
| Gate drivers (×4) | FD6288Q (3-phase, 250 V-class) | n/a | High/low gate drive with bootstrap |
| Power stage (×4) | 6× N-MOSFET, 40 V, DFN 3.3×3.3 | n/a | 3-phase bridge |

The H743 talks to each ESC MCU over a single DShot wire per motor. That is why §4 deals with timer and DMA allocation on the H743, while the 48 kHz switching happens in the ESC MCUs.

## 2. Loss Model (per ESC channel)

### 2.1 Conduction Loss

**Temperature-corrected on-resistance:**

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

**Conduction path in 6-step synchronous commutation.** At any instant, current flows through:

- one PWM'd leg (high-side FET, or the complementary low-side FET during the off-time), and
- one static return leg (low-side FET).

Under synchronous rectification the current therefore always sees exactly two R_ds(on) in series. This holds regardless of duty cycle, apart from dead time, which is handled in §2.3.

$$P_{cond} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

**At 80 A, T_j = 125 °C:**

- R_ds = 1.5 mΩ × (1 + 0.006 × 100) = 1.5 mΩ × 1.6 = **2.40 mΩ**
- P_cond = 2 × 80² × 2.40 mΩ = **30.7 W**

**Electrothermal feedback.** R_ds(on) rises with T_j, so the loss must be solved self-consistently:

$$T_j = T_a + P(T_j)\,R_{th,ja} \;\Rightarrow\; T_j = \frac{T_a + 2I^2R_{25}(1-25\alpha)R_{th}}{1 - 2I^2R_{25}\,\alpha\,R_{th}}$$

**Stability condition.** Thermal runaway occurs if the denominator reaches zero:

$$2I^2R_{25}\,\alpha\,R_{th} \ge 1$$
