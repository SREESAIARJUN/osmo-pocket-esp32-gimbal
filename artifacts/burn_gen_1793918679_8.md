# 3-Axis Gimbal: FOC Motor Control & Dual-IMU Sensor Fusion

I don't have the original Job #4 spec, so this design is built on the assumptions below. Every numeric constant is a `constexpr` or configuration value, so you can re-target it by changing parameters.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 (Cortex-M4F, 170 MHz, FPU, center-aligned TIM1 PWM) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read per PWM cycle |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the plate centroid, SPI at 24 MHz, ODR 8 kHz |
| Joint order | Yaw (base) → Roll → Pitch (camera) |
