# Job #52: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #52 spec sheet, so the design rests on the parameters below. They are typical for a camera gimbal. Each one is a single constant in the code, so you can substitute your values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7, slots N_s = 12), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (MT6701/AS5048A) on each axis |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Bus | V_dc = 12 V, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, ODR = 8 kHz |
| Gimbal order (base → camera) | Yaw (Z) → Roll (X) → Pitch (Y) |
