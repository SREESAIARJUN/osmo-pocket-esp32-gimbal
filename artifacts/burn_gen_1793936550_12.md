# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #61): Design Model

## 0. Architecture Clarification and Assumptions

The STM32H743 cannot commutate four BLDC motors and run ArduPilot simultaneously. The H743 runs ArduPilot and emits bidirectional DShot600. Four dedicated ESC MCUs run AM32 or BLHeli_32-class firmware. This is the only architecture that works with ArduPilot's DShot driver.

```
VBAT 6S ─┬─► ESC ch1..4: MCU(AT32F421/STM32G071) → 3-ph gate driver → 6× N-FET → motor
         └─► 5V/3V3 BEC → STM32H743 (ArduPilot) ──DShot600 bidir──► ESC MCUs
```

All device parameters below are design assumptions. Replace them with datasheet values for the selected FET. The method stays the same.
