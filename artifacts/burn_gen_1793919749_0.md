## 0. Assumptions and System Architecture

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

With mechanical angle θ_m from the encoder and calibrated zero offset θ₀:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

### 1.2 Clarke transform (amplitude invariant, two shunts, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

Electromagnetic torque for a surface PM motor (L_d = L_q):

$$\tau_e = \tfrac32\,p\,\lambda_m\, i_q \equiv K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation for a closed-loop bandwidth ω_c (rad/s):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop then becomes first order: $i/i^* = \omega_c/(s+\omega_c)$. Choose ω_c ≤ 2π·f_s/20, i.e. about 2π·1 kHz at 20 kHz.

The voltage commands are:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set $i_d^* = 0$; field weakening is not needed for gimbals.

### 1.6 Voltage limiting (circular, d-axis priority)

$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad |v_d|\le V_{max},\quad |v_q| \le \sqrt{V_{max}^2 - v_d^2}$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and gives the 15.5% linear-range extension over sinusoidal PWM.

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant per axis

$$J\dot\omega = K_t\, i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{fric} + \tau_{dist}$$

Because the camera is balanced, gravity torque is about 0. The residual imbalance enters as part of τ_dist.

### 2.2 Velocity loop design (PI on a pure inertia)

Assume the current loop is fast, so i_q ≈ i_q*. The open-loop transfer function is then:

$$L_\omega(s) = \frac{K_t}{Js}\cdot K_{p,\omega}\frac{s + K_{i,\omega}/K_{p,\omega}}{s}$$

The symmetric-optimum-style choice for crossover ω_v is:

$$K_{p,\omega} = \frac{J\,\omega_v}{K_t},\qquad \frac{K_{i,\omega}}{K_{p,\omega}} = \frac{\omega_v}{a^2}\ (a\approx 2 \Rightarrow \text{PM}\approx 37^\circ+;\ a=3\Rightarrow 53^\circ)$$

Constraints:

- ω_v ≤ ω_c / 5.
- ω_v must sit well below the first structural resonance of the arm/camera assembly. This is typically 80–200 Hz, so ω_v ≈ 2π·(20–40) Hz.

### 2.3 Angle loop

The closed velocity loop looks approximately like ω_v/(s + ω_v). Wrap a P or PI around it:

$$K_{p,\theta} = \omega_\theta \approx \omega_v/4,\qquad K_{i,\theta} = K_{p,\theta}\,\omega_\theta/10$$

Add velocity feedforward from the trajectory (ω_ff = θ̇_ref) and from base motion (§4.6).
