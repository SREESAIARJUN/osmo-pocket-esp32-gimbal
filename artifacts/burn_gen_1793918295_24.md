# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #5): Power-Stage Model, Thermal Budget, and Bidirectional DShot Architecture

## 0. Architecture Decision and Key Assumptions

**The STM32H743 should not commutate the motors directly.** It runs ArduPilot as the flight controller. Each motor gets its own ESC MCU (AT32F421 or STM32G071 running AM32), its own gate driver, and its own MOSFET bridge.

Reasons for this split:

- **Bidirectional DShot needs a separate ESC MCU.** It is a protocol between the FC and an ESC, and the ESC must return eRPM telemetry.
- **48 kHz PWM is set in ESC firmware**, not by ArduPilot. AM32 supports 24–48 kHz.
- **The H7 cannot spare 24 PWM channels or 4 sensorless back-EMF loops** alongside the EKF.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation Topology
The model assumes 6-step trapezoidal drive with complementary (synchronous) PWM. In each 60° sector:

- **Phase X (the PWM leg):** the high-side FET conducts for duty D. The low-side FET of the same leg conducts for 1−D (synchronous rectification).
- **Phase Y (the return leg):** the low-side FET is on continuously.
- **Phase Z:** floating, used for back-EMF sensing.

The current path therefore always crosses exactly two FET channels, ignoring dead time:

$$
P_{cond,motor} = I^2 R_{DS}(T_j)\,[D + (1-D)] + I^2 R_{DS}(T_j) = 2\,I^2\,R_{DS}(T_j)
$$

**This result is independent of duty cycle.** It is a key property of synchronous 6-step drive.
