# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #19)

## 0. Design Assumptions

I don't have the Job #19 specification, so I assumed typical values for a camera gimbal. Replace each one with your measured value before tuning. The equations do not depend on these numbers, but the gains do.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz, FPU, 3× advanced timers |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kv ≈ 25 rpm/V |
| Encoder | 14-bit magnetic absolute (MT6701 / AS5047P) on each axis |
| Supply | V_dc = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetric about the tilt/roll rotation center (see §4.1); SPI @ 24 MHz |
| Loop rates | Current 20 kHz · Velocity (rate) 4 kHz · Angle (attitude) 1 kHz · IMU ODR 8 kHz |

The architecture follows standard gimbal practice:

```
attitude ref ──► [Angle P + FF] ──► ω_ref ──► [Rate PI + FF] ──► i_q* ──► [FOC current PI] ──► SVPWM
                     ▲ q̂ (Mahony)                 ▲ ω_gyro (fused, notched)     ▲ i_d,i_q   ▲ θ_e (encoder)
                     └──────── dual ICM-42688-P fusion ◄── vibration filters
                                                 + anti-cogging i_q,ff(θ_m)
```

The encoder is used only for commutation and the cogging map. The stabilization loops close on inertial (IMU) measurements, because the goal is an inertially fixed camera rather than a fixed joint angle.

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Motor model in the rotor frame (amplitude-invariant transforms)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q,\qquad 
\lambda_m = \frac{60}{\sqrt{3}\,\pi\,K_v\,p}\ \ (\text{Kv in rpm/V, line-line peak})
$$

The electrical angle is $\theta_e = p(\theta_m - \theta_{\text{offset}})$, with $\omega_e = p\,\omega_m$.

### 1.2 Clarke and Park transforms

Clarke, assuming balanced currents ($i_a+i_b+i_c=0$):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} = 
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$
