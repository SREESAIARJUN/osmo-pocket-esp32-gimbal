# STM32H743 Nano FC + 4-in-1 ESC (Job #13): Reference Design Package

## 0. Scope, Assumptions, and Caveats

No part numbers or board outline were specified, so every number below follows from the stated parameters. Each one should be re-run with the real datasheets before layout freeze.

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max / 22.2 V nom | Switching losses use V_max (worst case) |
| PWM frequency | 48 kHz, complementary (synchronous rectification) | ESC firmware setting (AM32 / BLHeli_32 class) |
| Burst current | 80 A per channel | Duration is derived in §3, not assumed |
| MOSFET (placeholder) | 40 V, R_DS(on) = 1.0 mΩ @ 25 °C, V_GS = 10 V | Q_g = 50 nC, Q_gs2 = 6 nC, Q_gd = 10 nC, Q_rr = 60 nC @ 80 A, V_SD = 0.8 V @ 80 A, R_g,int = 1 Ω, R_θJC = 1.0 K/W |
| Gate driver | 10 V drive, R_source = 5 Ω, R_sink = 2 Ω | Plus R_g,ext = 2.2 Ω |
| Motor | L_phase-phase = 20 µH, 14 poles | Typical 5" to 7" class |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz, 1.6 mm | "Nano" 20×20 is worse; see §3.5 |
| Dead time | 100 ns per edge | |

**Architectural note.** On a 4-in-1 design the STM32H743 does not drive the bridges. It is the flight controller. The 48 kHz PWM is generated by four ESC MCUs (for example AT32F421 or STM32G071 running AM32). The H743's role is DShot600 command output and bidirectional eRPM capture (§4).
