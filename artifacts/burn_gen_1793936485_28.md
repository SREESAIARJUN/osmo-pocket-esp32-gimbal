# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power-Stage and DShot Design Model

**Scope and assumptions.** I don't have prior context for "Job #10," so this treats it as a fresh specification. Every assumed parameter is stated so you can substitute your actual component values. Two architectural issues need resolving first, because they change the math.

1. **The STM32H743 cannot be the motor controller.** ArduPilot on an H743 cannot also run four sensorless commutation loops. The correct architecture is:
   - H743 running ArduPilot, sending bidirectional DShot600 to
   - four ESC MCUs (AT32F421 or STM32G071, running AM32 or BLHeli_32-class firmware), driving
   - three-phase gate drivers and 24 MOSFETs.
2. **"Nano" (20×20 mm) and 80 A burst are incompatible.** The model below shows roughly 80 W of dissipation per board at 4×80 A. A 20×20 board physically cannot hold 24 MOSFETs with adequate copper. The numbers are therefore worked for a **30.5×30.5 mm** layout. The equations scale directly if you keep the smaller footprint, and the result for 20×20 is an 80 A rating that is either marketing or valid for under 1 s.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 110 °C: R_ds = 1.0 × (1 + 0.005 × 85) = **1.425 mΩ**. Add about 0.15 mΩ for package, solder, and copper per current path, giving **R_eff ≈ 1.575 mΩ**.

### 2.2 Six-step current path

In any commutation sector:
- **Phase A:** the high side (HS) conducts for duty D, and its synchronous low side (LS) conducts for (1−D).
- **Phase B:** the LS conducts continuously.

$$P_{cond,motor} = I_{rms}^2 R_{eff}\left[D + (1-D)\right] + I_{rms}^2 R_{eff} = 2\,I_{rms}^2 R_{eff}$$

Synchronous rectification makes conduction loss independent of duty. That is a key result: burst loss is the same at partial and full throttle for a given current.

### 2.3 Ripple contribution

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu\text{H}\times 48\,\text{kHz}} = 6.6\ \text{A}_{pp}$$

$$I_{rms} = \sqrt{I_{DC}^2 + \frac{\Delta I_{pp}^2}{12}} = \sqrt{80^2 + 3.6} \approx 80.02\ \text{A}$$

Ripple is negligible at 48 kHz. This is one justification for the high switching frequency.

### 2.4 Result

$$P_{cond,motor} = 2 \times 80^2 \times 1.575\,\text{m}\Omega = \mathbf{20.2\ W}$$

## 3. Switching Loss Model at 48 kHz

### 3.1 Gate-drive transition times

$$I_{g,on} = \frac{V_{drv} - V_{plateau}}{R_{g,tot}} = \frac{10 - 3.5}{5} = 1.3\ \text{A},\qquad I_{g,off} = \frac{V_{plateau}}{R_{g,tot}} = 0.7\ \text{A}$$

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} \approx 7\ \text{ns},\qquad t_{off} = \frac{9\,\text{nC}}{0.7} \approx 13\ \text{ns}$$

The turn-off path dominates. If you want faster turn-off, add a fast-off diode in parallel with R_g.
