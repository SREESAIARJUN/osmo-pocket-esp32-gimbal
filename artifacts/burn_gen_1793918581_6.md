## 0. Architecture Clarification and Baseline Assumptions

### 0.1 Partitioning

ArduPilot does not run motor commutation. The architecture is therefore:

- **H743 flight controller:** runs ArduPilot and emits bidirectional DShot600 on 4 timer channels.
- **4× ESC MCUs:** AT32F421K8U7 (QFN32), running AM32. AM32 is chosen because it supports bidirectional DShot and has an open, adjustable PWM frequency, so 48 kHz is directly settable.
- **4× 3-phase gate drivers:** FD6288Q (QFN24, bootstrap, 600 mA source / 1.2 A sink nominal).
- **24× N-MOSFETs:** 40 V, PDFN 3.3×3.3 mm.

## 1. Conduction-Loss Model (6-Step Trapezoidal, Synchronous Rectification)

### 1.1 Current Path

In each 60° commutation sector exactly two phase legs carry current I:

- **PWM leg:** current alternates between the high-side FET (duty D) and the low-side FET (1 − D). Synchronous rectification is used, with no diode freewheeling except during dead time.
- **Return leg:** the low-side FET is held fully on.

So at any instant there are two R_ds(on) in series with the motor, independent of D:

$$P_{cond,motor} = I^2 \left( 2R_{ds,hot} + 2R_{pcb} \right)$$

### 1.2 Including Current Ripple

Phase inductance L_ph is assumed to be 15 µH (typical of a 7–8 mm stator 2207 motor). Peak-to-peak ripple is worst at D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}} = \frac{25.2 \times 0.25}{15\mu \times 48k} = 8.75\ \text{A}$$

$$I_{rms} = \sqrt{I^2 + \frac{\Delta I_{pp}^2}{12}} = \sqrt{6400 + 6.38} = 80.04\ \text{A}$$

Ripple is negligible at 48 kHz, which is a benefit of the high f_sw.

### 1.3 Result per Motor at 80 A

$$P_{FET} = 80^2 \times 2 \times 2.25\text{m} = 28.8\ \text{W}$$

$$P_{Cu} = 80^2 \times 2 \times 0.4\text{m} = 5.12\ \text{W}$$

### 1.4 Per-FET Distribution

Each leg conducts 2/3 of the electrical cycle. Averaged over a revolution, each of the 6 FETs dissipates:

$$\bar{P}_{FET,i} = \frac{28.8}{6} = 4.8\ \text{W}$$

The instantaneous peak while a FET is on is $I^2 R = 14.4$ W. This is the value to use for thermal ripple of the junction at low eRPM, where sector dwell becomes comparable to the die's thermal time constant (roughly 1–10 ms).

### 1.5 Thermal Runaway Check

R_ds(on) rises with T_j. Write it as R(T) = R_25[1 + α(T − 25)], with α ≈ 0.0059/K (fit so that k_T = 1.5 at 110 °C). The coupled equation is:

$$T_j = T_a + R_{th,ja}\, I^2 R_{25}[1 + \alpha(T_j - 25)]$$

The closed form is:

$$T_j = \frac{T_a + R_{th}I^2R_{25}(1 - 25\alpha)}{1 - R_{th}I^2R_{25}\alpha}$$

The system is stable only while $R_{th} I^2 R_{25}\alpha < 1$. For a single FET at the 14.4 W peak case, I²R₂₅α = 9.6 × 0.0059 = 0.0566 W/K, so **R_th,ja must stay below 17.7 K/W** to avoid runaway. A 3.3×3.3 PDFN on a nano board with prop wash is typically 25–40 K/W in steady state.

**Steady-state 80 A is thermally unstable on this board.** It is valid only as a transient. This is the formal justification for the "burst" rating.

## 2. Switching-Loss Model at 48 kHz

Only the PWM leg switches: one HS/LS pair per motor per sector.

### 2.1 Hard-Switching V-I Overlap

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{n} \times 48\text{k} = 1.45\ \text{W}$$

### 2.2 Reverse Recovery

The LS body diode conducts during dead time and is recovered by the HS turn-on:

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = 0.048\ \text{W}$$

The recovery current also adds to the HS turn-on loss. Approximately:

$$\Delta P \approx V_{bus}\, I_{rr} \tfrac{t_{rr}}{2} f_{sw} \approx 25.2 \times 3 \times 10\text{n} \times 48\text{k} = 0.036\ \text{W}$$
