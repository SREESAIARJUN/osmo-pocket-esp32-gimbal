# STM32H743 FC + 4-in-1 ESC (80 A Burst): Power-Stage Loss Model, Thermal Budget, and ArduPilot Bi-Directional DShot600 Timer/DMA Architecture

**Document:** Job #0, Reference Architecture Rev A

**Scope and partitioning:** The STM32H743 is the flight controller. It generates bi-directional DShot600 and decodes eRPM telemetry. The 48 kHz PWM and commutation run on the ESC-side MCU (assumed to be four AT32F421 or STM32G071 running AM32). This document models both sides.

> **Basis of the numbers:** I have no datasheets for a specific "Job #0" BOM, so every device parameter below is a stated, typical value for a 40 V PDFN3.3×3.3 MOSFET and an FD6288Q-class driver. The equations are general. Before sign-off, substitute your actual datasheet values and validate them on a thermal-camera bench test. The netlists are reference topologies and must go through ERC/DRC against your actual library parts.
