## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, center-aligned PWM at 20 kHz **[ASSUMED]** |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt = 0.11 N·m/A **[ASSUMED]** |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5047), read at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, ±500 dps / ±4 g |
| Load inertia | J ≈ 4×10⁻⁴ kg·m² per axis **[ASSUMED, identify per axis]** |

**Loop rates.** Each loop runs at least 4–5× slower in bandwidth than the loop inside it.

```
20 kHz : ADC → Clarke/Park → PI_d, PI_q (+decoupling) → SVPWM      (ω_c ≈ 2π·1.5 kHz)
 8 kHz : IMU pair read → dual-IMU fusion → notch/LPF chain
 4 kHz : velocity PI (gyro-based joint rate)  + cogging FF + friction FF   (ω_v ≈ 2π·80 Hz)
 1 kHz : attitude estimator (Mahony) → angle P + rate FF → joint-rate setpoint (ω_θ ≈ 2π·15 Hz)
```
