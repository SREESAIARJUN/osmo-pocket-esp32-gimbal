# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

I don't have the original specification for "Job #9", so the design is built on the assumptions in §0. Every equation is written symbolically, so you can substitute your real motor and mechanical parameters.

## 0. Assumed System Parameters

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, with FPU and CORDIC |
| Motors | 3× GBM2804-class gimbal BLDC, 12N14P, so p = 7 pole pairs. R ≈ 5.6 Ω, L ≈ 2.0 mH, K_t ≈ 0.10 N·m/A |
| Encoders | 14-bit absolute (AS5048A / MT6701), one per joint |
