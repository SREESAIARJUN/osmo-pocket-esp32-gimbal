# STM32H743 AIO Flight Controller with 4-in-1 ESC: 80 A Burst Power Stage, 48 kHz Switching, and ArduPilot Bi-Directional DShot600

## 0. Architecture and Assumptions

### 0.1 Partitioning

The STM32H743 does **not** drive the MOSFETs. In a 4-in-1 AIO design:

- **H743 (flight controller):** runs ArduPilot and sends bi-directional DShot600 to four ESC MCUs.
- **4× ESC MCU** (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32): generates the **48 kHz PWM** and does commutation.
- **The 48 kHz switching frequency** is an ESC firmware setting (AM32 `PWM frequency`). It is not an ArduPilot parameter.

### 0.2 Feasibility Warning: 80 A on a Nano Board

A true nano (20×20 mm) board cannot sustain 80 A per motor. The physical limits of the 3×3 mm DFN FETs and the copper cross-section make it infeasible. The model below therefore assumes:

- a **30.5×30.5 mm, 8-layer, 2 oz** board,
- **80 A as a ≤10 s burst** per channel.

Section 3 shows quantitatively why the duration must be limited.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Six-Step Synchronous Commutation

During each 60° sector, two half-bridges conduct:

- **Leg A (PWM leg):** the high-side FET is on for D, and the low-side FET synchronously rectifies for 1−D.
- **Leg B (return leg):** the low-side FET is on for 100% of the sector.

The conduction loss for one ESC channel is:

$$P_{cond} = I_{rms}^2 R_{HS} D + I_{rms}^2 R_{LS}(1-D) + I_{rms}^2 R_{LS} \approx 2\,I_{rms}^2\,R_{ds}(T_j)$$

This result is **independent of duty cycle**, because synchronous rectification keeps two FET resistances in the current path at all times.

### 1.2 Ripple Correction

The peak-to-peak ripple current is:

$$\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph,eff}\, f_{sw}}, \quad L_{ph,eff} = 2L_{ph}$$

At D = 0.9 and V_bemf ≈ 20 V:

$$\Delta I = \frac{5.2 \times 0.9}{30\times10^{-6} \times 48\times10^{3}} = 3.25\ \text{A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 0.88 \approx 6401\ \text{A}^2$$

The ripple contribution is negligible at 48 kHz. This is one benefit of the higher switching frequency.

### 1.3 Temperature-Dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$
