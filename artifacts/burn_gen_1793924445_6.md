# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #49, so the design below uses explicit, typical assumptions for a brushless camera gimbal. Every assumption is collected in one parameter structure (§7.1), so you can replace them with your hardware's values. Values marked *verify* must be checked against your datasheets or measured on your hardware.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal PMSM, 12N14P (pole pairs *p* = 7), R = 5.5 Ω, L = 2.2 mH, Kt ≈ 0.08 N·m/A |
| Driver | 3-phase, 3-shunt sensing, 24 V bus, PWM 20 kHz center-aligned |
| Position sensor | 14-bit magnetic encoder (e.g., AS5048A or MT6701) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate, rigid mount, SPI at 24 MHz, gyro ODR 8 kHz |
| MCU | Cortex-M7 / M4F class with single-precision FPU |

```
            1 kHz               4 kHz                 20 kHz
 θ_ref ─►[Angle P + FF]─ω_ref─►[Velocity PI + FF]─iq_ref─►[Current PI dq + decoupling]─►SVPWM─►Motor
              ▲                     ▲      ▲ + iq_cog(θ_e)       ▲
              │ θ̂ (attitude)        │ ω̂   └─[Anti-cogging LMS]  │ id, iq (Clarke/Park of shunts)
     [Mahony/complementary]  [Dual-IMU filter chain]         [Encoder → θ_e, PLL ω]
```

**Bandwidth separation rule:** each loop's crossover should be about 4–10× lower than the loop inside it.

| Loop | Rate | Crossover |
|---|---|---|
| Current | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle | 1 kHz | ω_θ ≈ 2π·25 Hz |

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\psi_m$$

$$\tau_e = \tfrac32\,p\,\psi_m\, i_q \equiv K_t\, i_q$$

### 1.3 Current controller design (pole-zero cancellation)

Use a PI controller

$$C_i(s) = K_{p,i} + \frac{K_{i,i}}{s}$$

on the plant 1/(Ls + R), and choose the gains so the controller zero cancels the plant pole:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The open loop then becomes ω_c/s, so the closed loop is first order: 1/(s/ω_c + 1).
