# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #60 specification, so this design assumes a typical brushless gimbal. Every assumption is a parameter in the code. Change the numbers, not the structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class Cortex-M4F/M7, single-precision FPU |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5047P / MT6701), per axis |
| Current sensing | 2- or 3-shunt, synchronous with PWM center |
