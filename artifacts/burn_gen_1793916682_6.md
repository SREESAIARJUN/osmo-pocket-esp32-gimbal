## 1. FOC Current Loop

### 1.1 Transforms

**Clarke (amplitude-invariant, i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** applies the transpose.

### 1.2 Plant Model

For an SPMSM, L_d = L_q = L:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque:

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 PI Design (Pole-Zero Cancellation)

The per-axis plant is G(s) = 1/(Ls + R). Use the controller C(s) = K_p + K_i/s with K_i/K_p = R/L. The open loop then becomes ω_c/s, which gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}\ (\approx 2\pi\cdot 2\,\text{kHz})$$

**Decoupling and back-EMF feed-forward:**

$$v_d^* = PI_d - \hat\omega_e \hat L i_q,\qquad v_q^* = PI_q + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

**Voltage limiting.** The vector is limited circularly to |v| ≤ V_bus/√3 (the linear SVPWM region). The d-axis has priority:

$$v_{q,max} = \sqrt{V_{max}^2 - v_d^2}$$

**Anti-windup by back-calculation (discrete):**

$$x_{k+1} = x_k + T_s\left[K_i e_k + K_b(u_{sat,k} - u_k)\right],\qquad K_b \approx K_i/K_p$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_{abc} = \text{invClarke}(v_\alpha,v_\beta),\quad v_0 = -\tfrac12(\max v_{abc} + \min v_{abc}),\quad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Encoder Velocity Observer (PLL)

The error is computed with wrapping:

$$e_k = \text{wrap}_{\pm\pi}(\theta_{meas} - \hat\theta_k)$$

The observer updates are:

$$\hat\omega_{k+1} = \hat\omega_k + T_s K_{i,pll} e_k$$

$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll}e_k)$$

The gains are set by the observer bandwidth:

$$K_{p,pll} = 2\zeta\omega_n,\qquad K_{i,pll} = \omega_n^2$$

Typical values are ζ = 1 and ω_n ≈ 2π·300 rad/s. This provides θ_m for commutation and a fallback joint velocity.
