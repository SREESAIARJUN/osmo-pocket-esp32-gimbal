# STM32H743 AIO "Nano" FC + 4-in-1 ESC: Architecture Package (Job #22)

## 0. Assumptions and Feasibility

I don't have earlier Job #22 documents, so this package fixes the baseline below. Change any row and the equations still apply; only the numbers move.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal |
| Board | 20 × 20 mm mounting (≈25.5 × 25.5 mm outline), 6-layer, 2 oz on all layers |
| "80 A burst" | **Per motor channel**, ≤ 1 s (also evaluated: 80 A total) |
| ESC MCUs | 4 × AT32F421K8U7 running AM32 (supports bidir DShot and 48 kHz PWM) |
| FC MCU | STM32H743VIH6
