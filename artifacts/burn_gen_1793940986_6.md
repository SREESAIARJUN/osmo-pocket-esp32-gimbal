# STM32H743 Nano FC + 4-in-1 ESC (Job #46): Power-Stage, Thermal and DShot Architecture

## 0. Scope, Partitioning and Stated Assumptions

**Architectural clarification.** The STM32H743 does not generate the 48 kHz phase PWM. In any practical 4-in-1 design it runs ArduPilot and emits bi-directional DShot600. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32-class firmware, which produces the 48 kHz complementary PWM.

| Partition | Device | Function |
|---|---|---|
| Flight controller | STM32H743 (rev V, 480 MHz) | ArduPilot, bidir DShot600 TX/RX, ESC telemetry |
| ESC ×4 (or 1 MCU ×4 ch) | STM32G071 / AT32F421 class | 6-step or FOC commutation, 48 kHz PWM |
| Gate driver ×4 | 3-phase half-bridge driver (FD6288Q class) | 6 gate outputs, bootstrap high side |
| Power stage ×4 | 6× N-MOSFET per motor (24 total) | Phase bridges |
