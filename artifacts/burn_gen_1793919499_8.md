# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original specification for Job #49, so this design is built on the assumptions below. Each one maps to a single constant in the code, so you can replace it with your real values.

| Parameter | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701 class) per axis |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Current-sense rate | 20 kHz, center-aligned PWM, sampling in the low-side shunt window |
| IMUs | 2 × ICM-42688-P on the camera plate, gyro and accel ODR = 8 kHz |
| Kinematics | Yaw (z) → Roll (x) → Pitch (y), from base outward |

Loop rates:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q) | 20 kHz | 1.5–2 kHz |
| Velocity (gyro feedback) | 4 kHz | 150–250 Hz |
| Angle (attitude) | 1 kHz | 30–50 Hz |
| IMU fusion and filtering | 8 kHz | n/a |
