# STM32H743 Nano FC + 4-in-1 80A ESC: System Design Package (Job #1)

## 0. Scope and Assumptions

### 0.1 Architecture Correction

A production 4-in-1 ESC does not run its motors from the STM32H743. The H743 is the flight controller running ArduPilot. It sends bidirectional DShot600 to **four dedicated ESC MCUs** (for example AT32F421 or STM32G071 running AM32). Each ESC MCU generates the 48 kHz commutation PWM.

This split is mandatory for three reasons:

- ArduPilot has no field-oriented-control or 6-step commutation stack for direct bridge drive.
- Back-EMF zero-cross detection needs dedicated comparators and ADC timing on every channel.
- Fault isolation requires that one motor desync cannot stall the flight loop.
