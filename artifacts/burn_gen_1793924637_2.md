# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #12 specification, so this design states its assumptions explicitly. Every parameter is a constant you can replace.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, Cortex-M4F/M7 with single-precision FPU |
| Motors | Gimbal BLDC (GM4108-class): 12 slots (N_s), 14 poles (7 pole pairs, p), R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) |
| Axis order | Yaw (outer, ψ) → Roll (middle, φ) → Pitch (inner, θ), i.e. Z-X-Y |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, synced through CLKIN |
| Loop rates | Current 20 kHz · velocity 4 kHz · angle 1 kHz · attitude 1 kHz |

The loop bandwidths are separated by at least a factor of 5:

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_a ≈ 2π·20 rad/s

## 1. Field-Oriented Control: Inner Current Loop

### 1.1 Transforms

The electrical angle is derived from the mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI design (pole–zero cancellation)

The dq-frame plant is

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Choose the PI gains so that the controller zero cancels the electrical pole:

$$K_p^{c} = L\,\omega_c,\qquad K_i^{c} = R\,\omega_c$$

The closed loop is then first order, $i/i^* = \omega_c/(s+\omega_c)$.

Add decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

### 1.3 Voltage-circle limit with d-axis priority

The SVPWM linear range limits the voltage vector to

$$V_{\max} = V_{dc}/\sqrt3$$

Allocate d-axis voltage first, then give q the remainder:

$$v_d^{\text{sat}} = \text{clamp}(v_d^*, \pm V_{\max}),\qquad v_q^{\text{lim}} = \sqrt{V_{\max}^2 - (v_d^{\text{sat}})^2}$$

### 1.4 Discrete PI with back-calculation anti-windup

Used by every PI loop in the cascade:

$$u_k = K_p e_k + I_k,\qquad u_k^{\text{sat}} = \text{sat}(u_k)$$

$$I_{k+1} = I_k + T_s\left[K_i e_k + K_b\,(u_k^{\text{sat}} - u_k)\right],\qquad K_b \approx K_i/K_p$$

### 1.5 SVPWM (min–max zero-sequence injection)

1. Inverse Park: $(v_d, v_q) \rightarrow (v_\alpha, v_\beta)$.
2. Inverse Clarke:
   $$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2} v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2} v_\beta$$
3. Zero-sequence offset: $v_0 = -\tfrac12(\max + \min)$ of the three phase voltages.
4. Duty cycles: $d_x = \tfrac12 + (v_x + v_0)/V_{dc}$.

### 1.6 Delay compensation

Rotate the inverse Park transform by $\theta_e + 1.5\,\omega_e T_s$. This accounts for one sample of computation delay plus half a period of PWM delay.
