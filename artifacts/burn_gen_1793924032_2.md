## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle comes from the mechanical angle, a pole-pair count, and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

The Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$) is:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

The Park transform rotates into the rotor frame:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model and PI with decoupling

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

With the cross-coupling and back-EMF terms cancelled as feedforward, each axis reduces to $G(s)=\frac{1}{Ls+R}$.

Choose a PI with $K_p = L\,\omega_c$ and $K_i = R\,\omega_c$. The PI zero then cancels the plant pole, and the closed loop becomes $\frac{\omega_c}{s+\omega_c}$. A typical bandwidth is $\omega_c = 2\pi\cdot 1.5\text{ kHz}$, which is below $f_{pwm}/10$.

The control law is:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda)$$

The reference is $i_d^*=0$, since this is an SPM motor with no field weakening.

**Discrete PI with back-calculation anti-windup** (forward Euler, period $T$):

$$u_k = K_p e_k + x_k,\quad \bar u_k=\text{sat}(u_k),\quad x_{k+1}=x_k + T\left[K_i e_k + K_{aw}(\bar u_k-u_k)\right]$$

where $K_{aw}\approx K_i/K_p$.

**Voltage vector limit.** Limit the vector magnitude, not each axis separately:

$$\|v_{dq}\|\le \frac{V_{bus}}{\sqrt3}\,m_{max}$$

Give priority to $v_d$, then clip $v_q$ to $\sqrt{V_{max}^2-v_d^2}$.

### 1.3 Inverse Park and SVPWM

Convert $v_{\alpha\beta}$ to phase voltages with the inverse Clarke transform. Then inject the min-max zero-sequence:

$$v_0 = -\tfrac12(\max v_x + \min v_x),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

This is mathematically equivalent to 7-segment SVPWM.

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist},\qquad K_t = \tfrac32 p\lambda$$

### 2.2 Velocity estimate

Raw encoder differencing is too noisy, so use a PLL tracking observer at 20 kHz:

$$e_\theta = \text{wrap}(\theta_{enc}-\hat\theta),\quad \dot{\hat\omega} = k_i e_\theta,\quad \dot{\hat\theta}=\hat\omega + k_p e_\theta$$

The gains are $k_p = 2\zeta\omega_o$ and $k_i=\omega_o^2$, with $\omega_o \approx 2\pi\cdot 400$ Hz and $\zeta=0.707$.

### 2.3 Velocity PI (4 kHz)

The design rule is to keep the velocity bandwidth at least 4× below the current bandwidth ($\omega_v \le \omega_c/4$). Then the closed current loop looks like approximately 1 to the velocity loop:

$$K_{p,v} = \frac{\hat J\,\omega_v}{K_t},\qquad K_{i,v} = \frac{K_{p,v}\,\omega_v}{4}$$
