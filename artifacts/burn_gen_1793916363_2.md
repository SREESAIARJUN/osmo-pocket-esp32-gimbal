# STM32H743 Nano FC with Integrated 4-in-1 ESC: Power-Stage Thermal Model, DShot Allocation and Reference Netlist

## 0. Scope and Architecture Correction

I have no project file for "Job #58," so this document states every assumption explicitly. Replace the assumed values with your BOM data and the equations will still hold.

**Architecture correction:** ArduPilot does not commutate motors, so the STM32H743 cannot generate the 48 kHz gate PWM. The design therefore has two layers:

- **Flight controller:** STM32H743 running ArduPilot. It sends bidirectional DShot600 to the ESC MCUs.
- **ESC:** 4× AT32F421 or STM32G071 running AM32. Each MCU runs 6-step commutation at 48 kHz, drives a 3-phase gate driver and reads back-EMF (BEMF).

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Conduction Topology

In 6-step synchronous (complementary) PWM, each 60° commutation state has:

- **The PWM leg:** the high-side (HS) conducts for fraction D, and the synchronous low-side (LS) conducts for (1 − D).
- **The return leg:** its LS conducts continuously.

Per-channel conduction loss is then:

$$P_{cond,ch} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

This result is **independent of duty cycle**, which is a useful property for worst-case sizing.

### 1.2 Numbers at T_j = 100 °C

- R_ds = 1.0 × 1.34 = 1.34 mΩ
- P_cond,ch = 2 × 80² × 1.34×10⁻³ = **17.2 W per channel**

**Per-FET loss.** Each FET conducts for 120° of each 360° electrical cycle:

- Instantaneous loss on the continuously-on LS: 80² × 1.34 mΩ = 8.6 W.
- Cycle-averaged loss per FET: 17.2 / 6 = **2.87 W**.

At 30k eRPM the electrical period is 2 ms. That is shorter than or comparable to the die thermal time constant (~1–5 ms), so the ripple in T_j is small but not negligible. Section 3.3 accounts for it.

### 1.3 Copper and Interconnect Loss

Estimate the effective path resistance (battery pad → bus → FETs → phase pad, plus return) at R_cu ≈ 0.5 mΩ:

- P_cu = 80² × 0.5×10⁻³ = **3.2 W per channel**

Copper resistance also rises by about 0.39 %/K, so this figure is roughly +30 % at 100 °C. I include it in the margin below.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM leg switches in any given state. Per channel:

| Term | Equation | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_r + t_f)·f = 0.5 × 25.2 × 80 × 30 ns × 48k | **1.45 W** |
| Output capacitance (Coss) | Q_oss·V·f = 25 nC × 25.2 × 48k | 0.03 W |
| Reverse recovery | Q_rr·V·f = 20 nC × 25.2 × 48k | 0.024 W |
| Dead-time diode conduction | V_f·I·2t_dt·f = 0.8 × 80 × 100 ns × 48k | **0.31 W** |
| Gate charge (dissipated in driver) | 2·Q_g·V_gs·f = 2 × 30 nC × 10 V × 48k | 0.029 W |
| **Total P_sw,ch** | | **≈ 1.84 W** |

**Sensitivity:**

- The overlap term scales linearly with f_sw and edge time.
- Going to 96 kHz roughly doubles switching loss to ~3.7 W per channel.
- Adding gate resistance that slows each edge to 25 ns gives ~2.4 W per channel at 48 kHz.
