## 2. Loss Model (Per ESC Channel, 6-Step Trapezoidal, Synchronous Rectification)

### 2.1 Conduction Loss

Temperature-corrected on-resistance:

```
R_ds(Tj) = R_ds,25 · [1 + α(Tj − 25)]
At Tj = 125 °C:  R_ds = 1.2 mΩ · 1.5 = 1.8 mΩ
```

In 6-step operation, **two legs conduct at every instant**:
- In the PWM leg, either HS (during D) or LS (sync-rect during 1−D) carries I_ph.
- In the static leg, LS carries I_ph.

Instantaneous bridge loss is therefore independent of D:

```
P_cond,bridge = 2 · I_ph² · R_ds(Tj)
             = 2 · 80² · 1.8e-3 = 23.0 W   per channel
```
