# STM32H743 Nano FC + 4-in-1 ESC: Design Model (Job #58)

## 0. Architecture Correction and Assumptions

**The STM32H743 cannot be the ESC commutation controller in an ArduPilot system.** ArduPilot runs on the H743 as the flight controller. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32, which generates the 48 kHz PWM. The H743 talks to the ESCs over bidirectional DShot600. The models below follow that split.

## 1. Conduction Loss Model

### 1.1 Current distribution in 6-step commutation with complementary PWM

Each phase spends one electrical period as follows:
- **120°** driven high (high-side FET is PWM'd at duty D)
- **120°** driven low (low-side FET fully on)
- **2 × 60°** floating, used for BEMF sensing

With complementary PWM, the low-side FET of the PWM'd phase synchronously rectifies during the off-time. The RMS currents per FET are therefore:

$$I_{HS,rms}^2 = \frac{I^2 D}{3}, \qquad I_{LS,rms}^2 = \frac{I^2\left[1 + (1-D)\right]}{3} = \frac{I^2(2-D)}{3}$$

Summing over 3 phases × (HS + LS):

$$P_{cond,motor} = 3R_{ds}(T_j)\left[\frac{I^2D}{3} + \frac{I^2(2-D)}{3}\right] = \boxed{2\,I^2\,R_{ds}(T_j)}$$

This result is independent of D, as it should be: exactly two FETs are always in series with the winding.

### 1.2 Temperature dependence

$$R_{ds}(T_j) = R_{25}\left[1 + \alpha(T_j - 25)\right]$$

At T_j = 125 °C: R_ds = 1.6 × 1.45 = **2.32 mΩ**

### 1.3 Numbers at 80 A burst

| Quantity | Value |
|---|---|
| Per FET (at D ≈ 1) | 80² × 2.32 mΩ / 3 = **4.95 W** |
| Per motor | 2 × 6400 × 0.00232 = **29.7 W** |
| 4 motors | **118.8 W** |

Also add these, which are often forgotten:
- **Shunt:** 0.25 mΩ → 1.6 W/motor if per-channel shunts are fitted
- **PCB copper:** a 2 oz, 3 mm-wide, 10 mm path is ≈ 1.1 mΩ round trip → ~7 W/motor. **This rivals the FETs.** Stitch power planes across multiple layers.

### 1.4 Thermal runaway check

Positive feedback through R_ds(T_j) converges only if:

$$\frac{\partial P}{\partial T_j}\cdot R_{th} = 2I^2R_{25}\,\alpha\,R_{th} < 1$$

## 2. Switching Loss Model at 48 kHz

Per motor, only one FET hard-switches per PWM edge pair: the high side of the active phase. The low side commutates softly, through dead-time diode conduction.

| Loss term | Formula | Inputs | P per motor |
|---|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f | t_r = t_f = 15 ns | 0.5·25.2·80·30n·48k = **1.45 W** |
| Output capacitance | ½·Q_oss·V·f | Q_oss = 20 nC | **0.012 W** |
| Reverse recovery | Q_rr·V·f | Q_rr = 30 nC | **0.036 W** |
| Dead-time diode | V_f·I·2t_dt·f | V_f = 0.8 V, t_dt = 100 ns | **0.61 W** |
| Gate drive (HS + LS) | 2·Q_g·V_drv·f | Q_g = 30 nC, 10 V | **0.029 W** |
| **Total** | | | **≈ 2.14 W** |

Overlap time from gate charge:

$$t_{sw} \approx \frac{Q_{gd}+Q_{gs2}}{I_g},\qquad I_g = \frac{V_{drv}-V_{plateau}}{R_g + R_{drv}}$$

**Caveat:** at true 100 % duty there is no switching. AM32 typically limits maximum duty, so at an 80 A burst you sit near the D_max ≈ 0.95–0.98 edge and the switching figures above apply.

**PWM resolution:** on a 64 MHz G071, ARR = 64 MHz / 48 kHz ≈ 1333 counts → **10.4-bit** duty resolution.

**Total burst dissipation:** (29.7 + 2.1) × 4 ≈ **127 W**, plus copper loss.
