# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #52", so this design uses the explicit assumptions listed in §0. Every assumed number is a named constant in the code, so you can substitute your actual motor, encoder and MCU values.

---

## 0. Assumptions

| Item | Value assumed |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (e.g. MT6701 or AS5047), one per joint |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM |
| Current loop | 20 kHz (synchronous with PWM) |
| Velocity loop | 4 kHz (gyro-driven) |
| Angle / attitude loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro ODR 8 kHz, ±2000 dps |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning: inject a d-axis voltage V_align and read θ_m once the rotor has settled.

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b),\qquad (i_c = -i_a - i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$
