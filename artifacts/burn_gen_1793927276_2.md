## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at commissioning: inject i_d = I_align with θ_e = 0 and read the encoder.

### 1.2 Clarke transform (amplitude-invariant, two sensed phases)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model (surface-mounted PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

where $\omega_e = p\,\omega_m$ and $\lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$.

### 1.5 PI controller with decoupling and back-EMF feedforward

$$v_d^* = PI_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = PI_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

**Gain selection by pole-zero cancellation.** Place the PI zero on the electrical pole R/L. The closed loop then becomes first order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Constraint: ω_c ≤ 2π·f_s/20. With f_s = 20 kHz, ω_c ≈ 2π·1000 rad/s, so K_p = 7.54 V/A and K_i = 35 186 V/(A·s).

### 1.6 Voltage limiting (circular) and anti-windup

Apply the limit with d-axis priority:

$$V_{max} = \frac{V_{bus}}{\sqrt3}$$
$$v_q^{lim} = \operatorname{sat}\!\left(v_q^*,\ \pm\sqrt{V_{max}^2 - v_d^{*2}}\right)$$

Use back-calculation anti-windup:

$$\dot x_I = K_i\, e + K_{aw}\,(v^{lim} - v^*),\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** Advance θ_e by ω_e·1.5·T_s. This covers one sample of computation plus half a PWM period.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ* ─►[Angle P(I)]─ω*─►(+)─►[Velocity PI + LPF]─i_q*─►(+)─►[Current PI]─►Motor
       ▲               ▲ ω_ff                 ▲         ▲ i_cog,ff
   θ̂ (attitude est.)   ω̂ (gyro/encoder blend)    J·α* feedforward
```

The reference feedforward is $\omega_{ff} = \dot\theta^*$ and the inertial feedforward is $i_{ff} = J\ddot\theta^*/K_t$.

### 2.2 Velocity loop (4 kHz)

$$i_q^* = \operatorname{sat}\!\Big[K_{pv}\,e_\omega + K_{iv}\!\int e_\omega\,dt\Big] + \frac{J\,\alpha^*}{K_t} + i_{cog}(\theta_m)$$

where $e_\omega = \omega^* - \hat\omega$.

**Gain derivation.** The current loop is fast relative to this loop, so the plant is $G_v(s) = K_t / (J s + B)$. Place a crossover at ω_v with a PI zero at ω_v/4:

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\,\frac{\omega_v}{4}$$

Rules for choosing ω_v:

- Keep ω_v ≤ ω_c/5.
- Keep ω_v below the lowest structural resonance divided by 2. Typical values are 2π·(60–150) Hz.

**Output filter.** Apply a 2nd-order LPF on i_q* with cutoff ≈ 4ω_v, followed by a notch at the identified frame resonance (Section 4.4).

### 2.3 Angle loop (1 kHz)

$$\omega^* = K_{p\theta}\, e_\theta + K_{i\theta}\!\int e_\theta\,dt + \dot\theta^*$$

where $e_\theta = \operatorname{wrap}_{\pi}(\theta^* - \hat\theta)$.

Gains:

- $K_{p\theta} = \omega_v/4$, giving an angle bandwidth of about ω_v/4.
- A small $K_{i\theta}$ is optional. It removes steady offsets from cable drag.
