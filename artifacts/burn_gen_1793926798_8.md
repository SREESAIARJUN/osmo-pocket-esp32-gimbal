I don't have the original Job #32 specification, so this design uses the stated assumptions below. Every parameter that depends on them is a named constant, so you can re-fit it to your hardware.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s\approx 5\,\Omega$, $L_s\approx 2\,\text{mH}$ |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each joint |
| Current sensing | 2-shunt low-side. A voltage-mode fallback is given in §1.6. |
| IMUs | 2× ICM-42688-P on the camera plate, both on SPI at 24 MHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| MCU | Cortex-M4F/M7 with single-precision FPU |
