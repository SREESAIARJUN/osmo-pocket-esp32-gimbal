# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #34 specification, so the design below rests on these assumptions. Every value is a named constant in `GimbalConfig` and can be changed there.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU, about 170 MHz |
| Motor | Gimbal BLDC (GBM2804 class): 12N14P, so p = 7 pole pairs, R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Motor encoder | 14-bit magnetic (MT6701 / AS5047), read by SPI every PWM cycle |
| Current sensing | 2 or 3 low-side shunts, sampled at the PWM centre |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, on-chip AAF enabled |
| Loop rates | Current: 20 kHz (PWM ISR). Velocity: 5 kHz. Angle: 1 kHz. AHRS: 1 kHz, fed by IMU filtering at 8 kHz. |

## 1. Current (Torque) Loop: Field-Oriented Control

### 1.1 Coordinate transforms

The electrical angle is

  θₑ = p·θₘ − θ_off, wrapped to [0, 2π).

The amplitude-invariant Clarke transform (using i_a + i_b + i_c = 0) is

  i_α = i_a
  i_β = (i_a + 2 i_b)/√3

The Park transform is

  i_d = i_α cos θₑ + i_β sin θₑ
  i_q = −i_α sin θₑ + i_β cos θₑ

The inverse Park transform is

  v_α = v_d cos θₑ − v_q sin θₑ
  v_β = v_d sin θₑ + v_q cos θₑ

### 1.2 Plant model and PI design

The dq-frame voltage equations are

  v_d = R i_d + L di_d/dt − ωₑ L i_q
  v_q = R i_q + L di_q/dt + ωₑ L i_d + ωₑ λ

With decoupling feedforward, each axis reduces to G(s) = 1/(Ls + R).

The PI controller C(s) = K_p + K_i/s is designed by pole-zero cancellation for a closed-loop bandwidth ω_c:

  K_p = L·ω_c,  K_i = R·ω_c  ⟹  T(s) = ω_c/(s + ω_c)

The total loop delay is about 1.5 T_s (computation plus PWM zero-order hold). For a phase margin of at least 60°, choose ω_c ≤ 0.2/T_s. At 20 kHz this gives ω_c ≈ 2π·600 Hz to 2π·1 kHz.

### 1.3 Discrete PI with back-calculation anti-windup

  e[k] = r[k] − y[k]
  u_u[k] = K_p e[k] + I[k]
  u[k] = sat(u_u[k])
  I[k+1] = I[k] + T_s (K_i e[k] + K_aw (u[k] − u_u[k])),  with K_aw ≈ K_i/K_p

### 1.4 Voltage limiting and SVPWM

The decoupling terms are

  v_d* = PI_d − ωₑ L i_q
  v_q* = PI_q + ωₑ (L i_d + λ)

The linear modulation limit is V_max = V_dc/√3. Prioritise the d-axis:

  v_d ← clamp(v_d, ±V_max)
  v_q ← clamp(v_q, ±√(V_max² − v_d²))

The PI anti-windup uses the clamped values.

SVPWM is implemented with min-max zero-sequence injection, which is equivalent to SVPWM:

  v_a = v_α
  v_b = −½v_α + (√3/2)v_β
  v_c = −½v_α − (√3/2)v_β
  v₀ = −(max(v_abc) + min(v_abc))/2
  D_x = ½ + (v_x + v₀)/V_dc
