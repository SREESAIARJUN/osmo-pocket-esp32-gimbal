# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the spec sheet for Job #55, so this design is parameterized. **§0 lists the assumptions.** Replace them with your motor, encoder and mechanical data. All gains in the code are derived from physical parameters rather than hard-coded.

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804/4108 class), 12N14P, pole pairs p = 7 |
| Phase params | R ≈ 5–15 Ω, L ≈ 2–5 mH (line-to-neutral) |
| Current sensing | 2-shunt or inline (optional; voltage-mode fallback provided) |
| Encoder | 14-bit magnetic absolute (MT6701 / AS5047P / AS5600) |
| IMUs | 2 × ICM-42688-P on the camera stage, SPI, 8 kHz ODR, FIFO + timestamps |
| Kinematic order | Base → Yaw → Roll → Pitch → Camera |

The loops are scheduled in a strict rate hierarchy:

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM / current (FOC) | 20 kHz (PWM 20–40 kHz, center-aligned) | ω_c ≈ 2π·1.5 kHz |
| Velocity (gyro-based) | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·30 Hz |
| IMU acquisition | 8 kHz ODR, FIFO-drained at 4 kHz | — |
| AHRS update | 1 kHz | — |

The bandwidth separation rule used throughout is ω_c ≥ 8–10·ω_v and ω_v ≥ 4–5·ω_θ.

## 1. FOC Core Equations

### 1.1 Electrical Angle

θ_e = p·(θ_m − θ_offset) mod 2π

θ_offset is found at calibration. Inject V_d = V_align at θ_e = 0, wait until the rotor settles, then read the encoder.

The angle is latency-compensated for sample-to-PWM delay T_d (typically 1.5·T_pwm):

θ̂_e = θ_e + ω_e·T_d

### 1.2 Clarke Transform (power-invariant amplitude form, balanced: i_a + i_b + i_c = 0)

i_α = i_a
i_β = (i_a + 2·i_b) / √3

### 1.3 Park Transform

i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 PMSM Model in the dq Frame

v_d = R·i_d + L_d·di_d/dt − ω_e·L_q·i_q
v_q = R·i_q + L_q·di_q/dt + ω_e·(L_d·i_d + λ_m)

Torque:

τ = (3/2)·p·[λ_m·i_q + (L_d − L_q)·i_d·i_q] ≈ K_t·i_q, with K_t = (3/2)·p·λ_m

The approximation holds for surface PM motors (L_d ≈ L_q).

### 1.5 Current PI with Decoupling (pole–zero cancellation)

The plant is G(s) = 1/(L·s + R). Choose:

K_p,c = L·ω_c
K_i,c = R·ω_c

so that K_i/K_p = R/L cancels the electrical pole. The closed loop is then first-order with bandwidth ω_c.

The control law adds decoupling feedforward:

v_d* = PI_d(0 − i_d) − ω_e·L·i_q
v_q* = PI_q(i_q* − i_q) + ω_e·(L·i_d + λ_m)

### 1.6 Voltage Limiting (circular, d-priority)

|v_dq| ≤ V_bus/√3 (SVPWM linear range)

v_d = clamp(v_d*, ±V_max)
v_q = clamp(v_q*, ±√(V_max² − v_d²))

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e

v_a = v_α
v_b = −½·v_α + (√3/2)·v_β
v_c = −½·v_α − (√3/2)·v_β

v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2

D_x = ½ + (v_x + v_0)/V_bus, for x ∈ {a, b, c}

### 1.8 Voltage-Mode Fallback (no current sensors)

Use v_q ≈ R·i_q* + ω_e·λ_m and v_d = −ω_e·L·i_q*. The velocity loop absorbs the model error.

## 2. Cascaded Angle / Velocity Control

### 2.1 Mechanical Plant per Axis

J·θ̈ = K_t·i_q − B·θ̇ − τ_cog(θ) − τ_grav(θ) − τ_dist

With the inner current loop closed (i_q ≈ i_q*), the velocity plant is:

G_v(s) = K_t / (J·s + B)

### 2.2 Velocity Loop (PI on gyro-measured joint rate)

Velocity feedback comes from the IMU, mapped to the joint frame (§2.4), and blended with encoder differentiation:

ω_meas = α·ω_gyro,joint + (1 − α)·ω_enc,  α ≈ 0.8–1.0

Gains:

K_p,v = J·ω_v / K_t
K_i,v = K_p,v·ω_v / 4

(The ¼ factor gives a PI zero at ω_v/4, which yields about 65° phase margin.)

Control law:

i_q* = K_p,v
