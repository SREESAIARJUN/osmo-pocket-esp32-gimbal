# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have access to the Job #17 specification, so this design uses the assumptions in §0. Every hardware-dependent value is a named constant, so the design adapts by editing parameters, not equations. Where the design depends on a datasheet value, I say so. Verify those values against your exact silicon revision before use.

---

## 0. Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz | Code is HAL-agnostic |
| Motors | Gimbal BLDC, e.g. GBM2804, 7 pole pairs, 12N14P | R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) | |
| Current sensing | 2-shunt low-side, sampled at PWM center | A voltage-mode fallback is given in §1.6 |
| PWM | 20 kHz center-aligned | Current loop runs at 20 kHz |
| IMU A | ICM-42688-P on the camera platform | Attitude feedback |
| IMU B | ICM-42688-P on the base/handle | Disturbance reference and feedforward |
| IMU ODR | 8 kHz gyro, 1 kH
