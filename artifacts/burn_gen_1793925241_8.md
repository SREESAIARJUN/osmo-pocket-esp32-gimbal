# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #42 specification, so I designed this against a typical direct-drive brushless gimbal. All parameters live in config structs so you can substitute your real values.

| Parameter | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC, R = 5.6 Ω (phase-phase), L ≈ 2.2 mH, K_t ≈ 0.08 N·m/A, 7 pole pairs |
| Encoder | 14-bit magnetic (MT6701 / AS5047-class), read in the current-loop ISR |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro/accel ODR = 8 kHz |
| Bus | 12–16 V, 3-phase inverter, center-aligned PWM @ 20 kHz |
| MCU | Cortex-M4F/M7 (single-precision FPU) |
