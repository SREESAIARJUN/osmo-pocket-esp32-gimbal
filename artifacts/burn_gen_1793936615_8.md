# 3-Axis Gimbal FOC Control and Dual-IMU Vibration Rejection

I don't have the specification for "Job #3", so this design rests on the assumptions below. Every assumption is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU, about 170 MHz or more |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A or MT6701) per axis |
| Inertial sensors | 2 × ICM-42688
