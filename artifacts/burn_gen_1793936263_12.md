# STM32H743 Nano Flight Controller with 4-in-1 80 A ESC (Job #66): Power-Stage Loss Model, Thermal Analysis, and Bidirectional DShot600 DMA Allocation

## 0. Scope, Architecture, and Assumptions

### 0.1 Architecture

A 4-in-1 ESC is not driven directly by the H743. The workable partitioning is:

| Block | Function |
|---|---|
| STM32H743 (FC) | Runs ArduPilot. Generates 4× bidirectional DShot600 on one advanced timer. Receives eRPM telemetry. |
| 4× ESC MCU (e.g., AT32F421 / STM32G071 running AM32) | Commutation and 48 kHz PWM generation for one motor each |
| 4× 3-phase gate driver | Bootstrap high-side drive |
| 24× N-ch MOSFET | 6 per motor (3 half-bridges) |

Running FOC or 6-step for four motors on the H743 alongside ArduPilot is not something ArduPilot supports.
