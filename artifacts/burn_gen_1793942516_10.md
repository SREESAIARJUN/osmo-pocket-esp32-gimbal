# STM32H743 AIO Flight Controller with Integrated 4-in-1 ESC: Thermal, Loss, and DShot Architecture

## 0. Scope and Assumptions

I have no Job #54 spec sheet, so every parameter below is a **stated assumption**. All equations are parametric. Swap in your actual MOSFET, gate driver, and PCB stackup values and the numbers will update.

**Architecture assumed (industry-standard AIO topology):**
- **Flight controller MCU:** STM32H743 at 400 MHz, running ArduPilot. Timer kernel clock is 200 MHz.
- **ESC MCUs:** four independent ESC MCUs (e.g. AT32F421 or STM32G071) running AM32 or BLHeli_32-class firmware.
- **Interface:** the H743 does not commutate motors. It sends DShot600 to each ESC MCU and receives eRPM telemetry back.
