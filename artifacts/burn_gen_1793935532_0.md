## 1. Field-Oriented Control (Current Loop)

### 1.1 Reference-frame transforms

Electrical angle from the encoder:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** (inverse of the above), giving v_α and v_β.

**Latency compensation.** The PWM update is applied one period after sampling, and its average takes effect half a period later. Advance the angle used in the inverse Park transform accordingly:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_{s,i}$$

### 1.2 PMSM model and decoupled PI

The motor in the rotor (dq) frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Control law: a PI on each axis, plus cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L\, i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e (L\, i_d + \lambda_m)$$

**Pole-zero cancellation tuning.** Choose the PI zero to cancel the electrical pole at R/L. The closed loop then becomes first order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \frac{i_q}{i_q^*} = \frac{\omega_c}{s+\omega_c}$$

Constraint from the 1.5-sample delay (phase margin ≳ 50°):

$$\omega_c \le \frac{1}{6\,T_{s,i}}$$

At 20 kHz this gives ω_c ≤ 3.3 krad/s. Use ω_c = 2π·400 Hz ≈ 2513 rad/s, so:

- K_p = 4.52 V/A
- K_i = 14 074 V/(A·s)

**Discretization.** Use backward Euler on the integrator, with clamping anti-windup:

$$I_k = I_{k-1} + K_i T_s e_k \quad\text{(update only if the output is unsaturated, or if } \operatorname{sgn} e_k \neq \operatorname{sgn} u_{k-1})$$

**Voltage limiting.** The output is limited to the linear SVPWM hexagon's inscribed circle, |v| ≤ V_bus/√3. If exceeded, scale by priority:

1. Keep v_d.
2. Assign the remaining magnitude to v_q:

$$v_q^{\max} = \sqrt{V_{\max}^2 - v_d^{*2}}$$

### 1.3 Space-vector PWM (min/max zero-sequence injection)

Phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset and duty cycles:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}},\quad x \in \{a,b,c\}$$

This is mathematically identical to sector-based SVPWM and is branch-light.

## 2. Rotor Velocity Estimation (PLL / Tracking Observer)

Differentiating a quantized encoder angle is unusable: 14 bits at 4 kHz gives a resolution of 1.5 rad/s per LSB. Use a type-2 PLL running at the FOC rate.

**Observer equations:**

$$e_\theta = \operatorname{wrap}_{\pi}(\theta_{\text{meas}} - \hat\theta)$$

$$\hat\omega \mathrel{+}= K_{i,\text{pll}} T_s\, e_\theta$$

$$\hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,\text{pll}} e_\theta)$$

**Gains.** For a critically damped observer with bandwidth ω_pll:

$$K_{p,\text{pll}} = 2\omega_{\text{pll}},\qquad K_{i,\text{pll}} = \omega_{\text{pll}}^2$$

Choose ω_pll ≈ 2π·150 Hz. This is 3–5× the velocity-loop bandwidth, which keeps the phase lag acceptable.

## 3. Cascaded Velocity and Angle Control

### 3.1 Plant

The mechanical plant is a rigid body:

$$J\dot\omega = K_t i_q - B\omega - \tau_{\text{cog}}(\theta) - \tau_{\text{dist}}$$

The current loop is a first-order lag, so the inner plant is:

$$G_v(s) = \frac{K_t}{Js}\cdot\frac{\omega_c}{s+\omega_c}$$
