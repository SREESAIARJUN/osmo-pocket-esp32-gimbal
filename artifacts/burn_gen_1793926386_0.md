# 3-Axis Gimbal: FOC Loop, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #50 specification, so the design below rests on stated assumptions. Every constant that depends on hardware is collected in one config struct so you can replace it.

---

## 0. Design Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC | Any Cortex-M4F/M7 works |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs) | e.g. GBM2804-class |
| Phase R / L | 5.6 Ω / 1.6 mH (line-to-neutral) | **Measure yours** |
| K_t | 0.045 N·m/A | From back-EMF constant |
| Joint inertia J | 2.0e-4 kg·m² (pitch, with payload) | Per axis |
| Encoder | 14-bit magnetic (MT6701/AS5048A) over SPI | Rotor angle for commutation |
| Current sensing | 2-shunt inline, 12-bit ADC | Voltage-mode fallback in §1.6 |
| PWM | 20 kHz center-aligned | Current loop 20 kHz |
| IMUs | 2× ICM-42688-P on camera plate, SPI @ 24 MHz | ODR 8 kHz |
| Loop rates | Current 20 kHz / Velocity 4 kHz / Angle 1 kHz / Attitude 1 kHz
