**Bandwidth separation rule.** Each outer loop should be 4–10× slower than the loop inside it:
- Current loop: f_c,i ≈ 1.5–2 kHz
- Velocity loop: f_c,ω ≈ 150–250 Hz
- Angle loop: f_c,θ ≈ 20–40 Hz

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms (amplitude-invariant)

**Clarke transform**, using two shunts and assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 Plant and PI tuning (pole-zero cancellation)

The dq-frame plant is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

A PI controller C(s) = K_p + K_i/s acts on the plant 1/(Ls + R). Choose K_i/K_p = R/L so the controller zero cancels the electrical pole. The closed loop then becomes first order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c = 2\pi f_{c,i}$$

**Decoupling plus back-EMF feedforward:**

$$v_d^* = \text{PI}_d - \omega_e L i_q,\qquad v_q^* = \text{PI}_q + \omega_e L i_d + \omega_e\lambda_m$$

**Delay compensation.** The PWM update has a 1.5-sample delay. Advance the angle used in the inverse Park transform accordingly:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

**Voltage limiting.** Clamp the voltage vector to the SVPWM linear region:

$$|v| \le V_{dc}/\sqrt3$$

Prioritize v_d, then give v_q the remaining headroom:

$$v_{q,\max}=\sqrt{V_{max}^2 - v_d^2}$$
