# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Fusion (Job #25)

## 0. Assumptions and Architecture

I don't have the Job #25 specification, so the design rests on the assumptions below. Every constant is a named parameter, so you can swap in the real values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), `R ≈ 5–12 Ω`, `L ≈ 2–4 mH`, `Kt ≈ 0.05–0.1 N·m/A` |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| MCU | STM32G4/H7 class with FPU and synchronized 3-phase PWM plus ADC |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Axis order | Yaw (base) → Roll → Pitch (camera) |

The loops are nested by rate. Each outer loop has at least 4–5× less bandwidth than the loop inside it.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz | ~150–250 Hz |
| Angle / attitude | 1 kHz | ~30–50 Hz |
| IMU sampling and fusion | 8 kHz → decimated to 4 kHz | — |

The signal chain is:

```
Attitude setpoint ─► [Angle P + FF] ─► ω_ref ─► [Velocity PI + FF] ─► i_q,ref ─► [FOC PI dq] ─► SVPWM
        ▲                                ▲                     ▲
        │                                │      i_q,cog(θ_m) ──┘ (anti-cogging FF)
  q̂ (Mahony on fused, notched IMU)   ω̂_joint (gyro → joint-space via Jacobian, blended w/ encoder)
```

## 1. Field-Oriented Current Control

### 1.1 Transforms

The electrical angle is `θ_e = p·(θ_m − θ_offset)`.

Clarke transform (amplitude-invariant, with `i_a + i_b + i_c = 0`):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park is the transpose of the same matrix.

### 1.2 Motor Model (Surface PMSM, `L_d = L_q = L`)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

Torque is `τ = (3/2)·p·λ_m·i_q = K_t·i_q`.

### 1.3 PI Gains by Pole-Zero Cancellation

The plant is `G(s) = 1/(Ls + R)`. Choose the controller `C(s) = K_p + K_i/s` with:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\;\Rightarrow\;\; T(s)=\frac{\omega_c}{s+\omega_c}
$$

Pick `ω_c = 2π·f_c` with `f_c ≤ f_PWM/10`, for example 2 kHz at 20 kHz.

The discrete form uses `T_s = 1/f_PWM` and forward Euler:

$$
I_k = I_{k-1} + K_i T_s\,e_k + K_{aw}(v_{sat}-v_{unsat})_{k-1}
$$

### 1.4 Decoupling and Back-EMF Feedforward

$$
v_d^{*} = \text{PI}_d - \hat\omega_e \hat L i_q,\qquad
v_q^{*} = \text{PI}_q + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m
$$
