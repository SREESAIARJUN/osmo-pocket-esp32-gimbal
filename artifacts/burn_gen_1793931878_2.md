## 0. Baseline Assumptions

I don't have the Job #26 requirements document, so this package uses the representative parameters below. Every equation is symbolic first, so you can substitute your actual datasheet values.

| Parameter | Symbol | Assumed Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (worst case for switching) |
| Burst phase current per channel | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz, complementary (synchronous rectification) |
| Commutation | — | 6-step trapezoidal (AM32/BLHeli_32 style) |
| MOSFET (generic 40 V, 5×6 / 3.3×3.3 class) | R_ds,on(25°C) | 1.2 mΩ max at V_gs = 10 V |
| | Q_g / Q_gs / Q_gd | 50 / 12 / 8 nC |
| | Q_gs2 (post-threshold) | ~5 nC |
| | V_plateau | 3.5 V |
| | Q_rr, C_oss(tr) | 40 nC, 1.1 nF |
| | R_g,int | 1.0 Ω |
| | R_θJC (bottom) | 1.0 K/W |
| | Body diode V_f | 0.8 V at 80 A |
| Gate driver | V_drv, R_g,ext | 10 V, 4.7 Ω |
| Dead time | t_dt | 100 ns per edge |
| ESC MCUs | — | 4× independent (e.g., AT32F421 / STM32G071) running AM32 |
| FC timer clock | f_TIM | 240 MHz (H743 at 480 MHz, APB timer clock) |
| ESC board | — | 30.5×30.5 mm, 6-layer, 2 oz copper on all layers |

**Architectural note:** In a 4-in-1 stack, the STM32H743 does not drive the FETs. It sends DShot to four ESC MCUs, each of which runs its own 48 kHz complementary PWM. The power math (Sections 1–4) applies to the ESC board. The DMA/timer math (Section 5) applies to the H743.
