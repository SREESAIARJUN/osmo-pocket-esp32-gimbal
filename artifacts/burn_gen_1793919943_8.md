| Velocity loop | 4 kHz | |

| IMU A (payload) | ICM-42688-P on the camera plate | Feedback |
| IMU B (base) | ICM-42688-P on the handle / airframe | Disturbance feedforward |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) | |

**Why one IMU on the payload and one on the base.** The payload IMU closes the stabilization loop. The base IMU measures the disturbance rate *before* it couples through joint friction and cogging. That lets the controller apply feedforward torque and rate cancellation without waiting for an error to build up.

     q̂ (payload IMU)  (base IMU)    ω̂_m (PLL) θ_m (encoder)         (shunts)

**Bandwidth separation.** Each loop is at least 5–10× faster than the loop around it:
- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_θ ≈ 2π·20 rad/s

## 2. FOC Current Loop

### 2.1 Transforms
Assume balanced currents (i_a + i_b + i_c = 0). The electrical angle is

  θ_e = p·θ_m − θ_off

**Clarke transform:**
- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

**Park transform:**
- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park transform:**
- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 2.2 Plant
- L di_d/dt = v_d − R i_d + ω_e L i_q
- L di_q/dt = v_q − R i_q − ω_e L i_d − ω_e λ_m

Here λ_m = K_t / (1.5 p) for the amplitude-invariant transform.

### 2.3 PI tuning by pole-zero cancellation
The plant is G(s) = 1/(Ls + R). With the controller C(s) = K_p + K_i/s:

- K_p = L·ω_c
- K_i = R·ω_c

This choice gives the closed loop ω_c/(s + ω_c), a first-order response.

- v_q* = PI_q(e_q) + ω_e L i_d + ω_e λ_m
