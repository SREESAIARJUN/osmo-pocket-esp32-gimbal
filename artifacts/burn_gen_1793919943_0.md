## 0. Assumptions and Rate Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, about 170 MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701) per axis |
| Current sense | 2-phase low-side shunts (voltage-mode fallback given in §1.5) |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz, symmetric about the plate's rotation center |
| PWM | 20 kHz center-aligned |

**Loop rates:** the bandwidth of each loop is separated from the next by 5–10×.

| Loop | Rate | Target closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–2 kHz |
| Velocity (gyro rate) | 4 kHz | 150–250 Hz |
| Angle (attitude) | 1 kHz | 20–40 Hz |
| IMU fusion | 4 kHz (decimated from 8 kHz) | – |

The fast inner loops use these sensors:

- **Commutation** uses the encoder.
- **Stabilization** uses inertial feedback: velocity from the gyro, angle from the fused attitude.

This is the key gimbal-specific point. Encoder-based angle and velocity loops would hold the motor joint still, not the camera.

## 1. Field-Oriented Control

### 1.1 Transforms

Electrical angle from the mechanical encoder reading θ_m:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt 3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor Model (dq frame)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q \equiv K_t\, i_q$$

### 1.3 Current PI with Decoupling and Back-EMF Feedforward

Choose the current-loop bandwidth ω_c (rad/s). Pole-zero cancellation of the R/L plant gives:

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c$$

This makes the closed loop first order: i/i* = ω_c/(s+ω_c).

**Discrete form** (backward Euler, T_s = 1/20 kHz), with back-calculation anti-windup:

$$u_k = K_p e_k + I_k,\qquad v_k = \text{sat}(u_k + v_{ff})$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(v_k - u_k - v_{ff})$$

Here K_aw ≈ K_i/K_p.

**Feedforward terms:**

$$v_{d,ff} = -\omega_e L i_q,\qquad v_{q,ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limiting:** clamp the vector magnitude to $\sqrt{v_d^2+v_q^2}\le V_{bus}/\sqrt3$, which is the linear SVPWM limit. Prioritize v_d, then give v_q the remainder.
