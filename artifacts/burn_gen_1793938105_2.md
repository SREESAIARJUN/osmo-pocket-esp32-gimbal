## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Electrical angle

θ_e = p·(θ_m − θ_offset) mod 2π

θ_offset is found at startup by aligning to the d-axis: inject V_d with θ_e = 0, wait, then read θ_m.

### 1.2 Clarke and Park transforms (amplitude-invariant)

Clarke, using two measured phase currents and i_a + i_b + i_c = 0:

- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

Park:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 1.3 dq plant and decoupling

The motor model in the rotating frame is:

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

Here ω_e = p ω_m and λ_m = 2K_t/(3p).

The feed-forward decoupling terms are:

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e (L i_d + λ_m)

With these applied, each axis reduces to the first-order plant 1/(Ls + R).

### 1.4 Current PI by pole-zero cancellation

C(s) = K_p + K_i/s, with:

- K_p = L·ω_c
- K_i = R·ω_c

This gives the closed loop i/i* = ω_c/(s + ω_c), a pure first-order response.

The discrete implementation (forward Euler is adequate since ω_c·T_s ≈ 0.47 < 1) is:

u[k] = K_p e[k] + I[k],  I[k+1] = I[k] + K_i T_s e[k] + K_aw (u_sat[k] − u[k])

Anti-windup uses back-calculation with K_aw ≈ K_i/K_p = R/L.

**Transport-delay compensation.** The PWM update is delayed by 1.5 samples. The Park inverse therefore uses:

θ_e,out = θ_e + 1.5 ω_e T_s

### 1.5 Voltage limit (circular)

The commanded voltage must satisfy |v_dq| ≤ V_max = V_dc/√3 · 0.95. Give d priority, then:

v_q ← sign(v_q) · min(|v_q|, √(V_max² − v_d²))

### 1.6 SVPWM by min/max zero-sequence injection

1. Inverse Park gives v_α, v_β.
2. Phase voltages:
   - v_a = v_α
   - v_b = −½v_α + (√3/2)v_β
   - v_c = −½v_α − (√3/2)v_β
3. Zero-sequence offset: v_0 = −(max + min)/2.
4. Duty cycles: d_x = ½ + (v_x + v_0)/V_dc.

### 1.7 Velocity estimation (PLL tracking observer)

The estimator works on the wrapped error ε = wrap_π(θ_m − θ̂):

- ω̂ ← ω̂ + K_i,pll T_s ε
- θ̂ ← θ̂ + T_s(ω̂ + K_p,pll ε)

The gains are K_p,pll = 2ζω_n and K_i,pll = ω_n², with ω_n ≈ 2π·400 rad/s and ζ = 1. This removes the quantization noise that a raw dθ/dt would produce.
