## 1. Conduction Loss Model

### 1.1 Current path

In 6-step complementary PWM, two phases are active in each commutation sector:
- **Phase A (PWM phase):** the high-side FET conducts for duty D. Its low-side synchronous rectifier conducts for 1−D.
- **Phase B (return phase):** the low-side FET is held on for the whole sector.

So at every instant, the phase current flows through exactly **two** channel resistances. This holds independent of D.

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C: R = 1.0 mΩ × 1.6 = **1.6 mΩ**

### 1.3 Per-bridge conduction loss

$$P_{cond,bridge} = 2\, I^2 R_{DS}(T_j) = 2 (80)^2 (1.6\times10^{-3}) = \mathbf{20.5\ W}$$

**Distribution across the six FETs:**
- Each FET is in the path roughly one-third of the electrical cycle.
- Average per FET: P_cond,FET,avg = I²R/3 = **3.41 W**.
- Instantaneous, while conducting: I²R = **10.2 W**. This matters because the die thermal time constant (~ms) is comparable to the commutation period at low eRPM.

### 1.4 Parasitic copper and shunt

Assume an effective R_Cu ≈ 0.5 mΩ in series per current loop (traces, vias, phase pads):

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W/channel}$$

This loss heats the PCB directly, so it adds to the board thermal load.
