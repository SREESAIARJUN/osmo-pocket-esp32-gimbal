# STM32H743 AIO Nano FC + 4-in-1 ESC: Architecture, Loss Model and DShot Allocation

## 0. Design Review Findings

Three issues change the design, so they come first.

1. **The H743 cannot be the ESC controller under ArduPilot.** ArduPilot does not run sensorless BLDC commutation. The board must be two systems:
   - **FC domain:** STM32H743, running ArduPilot.
   - **ESC domain:** four AM32-class MCUs (STM32G071 or AT32F421), one per motor.
   
   The 48 kHz figure is the ESC's PWM frequency, set in AM32. Bidirectional DShot600 is the link between the two domains.
2. **"80A burst" on a nano footprint is thermally bounded to about 1 s with all four motors loaded.** The math is in §3. The spec must define burst as ≤1 s per motor at 6S with a board temperature limit enforced by the ESC. Without that definition, the claim is unsupportable on a 20×20 or 25.5×25.5 board.
3. **All component values below are design assumptions.** Replace them with the datasheet values for the parts you actually select before freezing the design.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

At T_j = 100 °C: R_ds = 1.3 × 1.3375 ≈ **1.74 mΩ**. Using datasheet curve normalisation (typically ~1.45× at 100 °C) gives **1.89 mΩ**. Use **1.89 mΩ** as the conservative value.

### 1.2 Current path

In 6-step commutation with synchronous PWM, exactly two MOSFETs are in the current path at every instant:
- the active high-side or its synchronous low-side, depending on PWM state, and
- the continuously-on low-side of the return phase.

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j) \quad\text{(independent of duty } D\text{)}$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.89\text{ m}\Omega = \mathbf{24.2\ W\ per\ motor\ channel}$$

### 1.3 Ripple correction

Assume a motor phase-to-phase inductance of L ≈ 20 µH. Worst-case ripple occurs at D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus}D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{20\mu\text{H}\times 48\text{k}} = 6.6\text{ A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6$$

The ripple adds less than 0.1 % and is negligible at 80 A.

### 1.4 Copper loss

Assume the bus-to-phase-to-motor-pad path is about 0.5 mΩ (2 oz outer layers plus vias):

$$P_{Cu} = 80^2 \times 0.5\text{ m}\Omega = 3.2\text{ W per channel}$$
