# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #49)

## 0. Design Assumptions

I don't have the Job #49 specification, so this design uses typical brushless-gimbal values. Every value below is a parameter in the code. Change them to match your hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz, hardware CORDIC optional) |
| Motors | GBM2804-class, 12N14P, 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sense | 2-phase low-side or inline shunts, synchronous ADC |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Rate loop | 4 kHz (decimated from the 8 kHz gyro) |
| Attitude loop | 1 kHz |
| Gimbal kinematics | Yaw (Z) → Roll (X) → Pitch (Y), camera on the pitch link |

Loop bandwidth separation is at least 5× at every stage:

- current loop: about 1.5 kHz
- rate loop: about 80–150 Hz
- attitude loop: about 10–20 Hz
