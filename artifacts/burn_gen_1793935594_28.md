# Job #33: STM32H743 Nano FC + 4-in-1 ESC Architecture Model

> **Scope and assumptions.** On this class of board the STM32H743 runs ArduPilot and drives four ESC microcontrollers (e.g., AT32F421 running AM32/BLHeli_32) over bi-directional DShot600. The ESC MCUs generate the 48 kHz gate PWM. Device parameters below are representative of 40 V, 3.3×3.3 mm PDFN MOSFETs. **Replace them with your selected part's datasheet values before sign-off.** Every equation is parametric, so the numbers update directly.

## 0. Feasibility Flag

Before any modeling, the physical envelope needs to be stated.

| Interpretation of "80 A burst" | Battery current (4 motors) | Verdict on a ~26×26 mm board |
|---|---|---|
| 80 A **per channel**, all four simultaneously | 320 A | **Not physically viable.** The XT60 and pads, the copper, and the thermal mass all fail within about 2–3 s. |
| 80 A per channel, single-channel transient | ≤ 80 A + 3×hover | Viable for about 1–3 s bursts |
| 80 A **aggregate** (20 A/ch) | 80 A | Viable for bursts. Continuous operation is marginal without airflow. |

The model below computes the worst case (80 A/ch on all four channels) so that margins are explicit. Section 3.5 then derives the honest continuous rating.

## 1. Conduction Loss Model

| Q_oss | 40 nC | at 25 V |

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS(on)}(T_j) = R_{DS(on),25}\left[1 + \alpha\,(T_j - 25)\right]$$

At T_j = 125 °C: R = 1.3 × 1.45 = **1.89 mΩ**.

### 1.3 Six-Step Commutation with Synchronous Rectification

In any 60° sector, current flows through exactly **two** FETs in series:

- the PWM'd leg (high-side during D, low-side during 1−D, which is synchronous freewheeling), plus
- the static low-side of the return phase.

The result is that conduction loss is **independent of duty cycle**:

$$P_{cond,motor} = 2\,I^2\,R_{DS(on)}(T_j)$$

$$P_{cond,motor}(80\,\text{A}) = 2 \times 6400 \times 1.89\times10^{-3} = \mathbf{24.2\ W}$$

### 1.4 Per-FET Loss

Each FET conducts over 120° of the electrical cycle:

- Instantaneous: P_inst = I²R = **12.1 W**
- Cycle average: P_avg ≈ 12.1/3 ≈ **4.0 W**

### 1.5 Copper and Shunt Losses

| Path | Resistance | Loss @ 80 A |
|---|---|---|
| Phase trace: 4 layers × 2 oz, 3 mm wide, 8 mm long | ≈ 0.35 mΩ | 2.2 W |
| Shunt: 0.25 mΩ, in the shared V− return (total current) | — | see 4.5 |

**Coupled iteration.** R_DS(on) depends on T_j, which in turn depends on loss. Iterate:

$$T_j^{(k+1)} = T_{pcb} + P_{FET}\big(R(T_j^{(k)})\big)\cdot R_{\theta J\text{-}PCB}$$

This converges in about 3 iterations. Thermal runaway occurs only if α·P·R_θ > 1, which is not the case here (≈0.05).

## 2. Switching Loss Model at f_sw = 48 kHz

Conditions: V_bus = 25.2 V (6S full charge), I = 80 A. Only one leg per motor switches at a time.

### 2.1 Hard-Switching Overlap

Using a gate driver with R_g,on = 4.7 Ω and R_g,off = 2.2 Ω gives t_r + t_f ≈ 30 ns effective.

$$P_{sw} = \tfrac12 V I (t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(30\,\text{ns})(48\,\text{k}) = \mathbf{1.45\ W}$$
