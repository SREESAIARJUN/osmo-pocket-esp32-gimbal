# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Thermal Model and Bidirectional DShot600 Architecture

**Scope:** This is an engineering reference derivation for Job #38. Component values are representative assumptions, flagged as such. Validate them against your actual MOSFET datasheet, stack-up, and ArduPilot's generated `hwdef.h` before releasing to layout.

## 0. Architecture Clarification

The STM32H743 runs ArduPilot as the flight controller. It does **not** run the 48 kHz commutation. That job belongs to four dedicated ESC MCUs (recommended: AT32F421 or STM32G071 running AM32), one per motor. The resulting partition:

```
VBAT(6S) ──┬── 4× [ESC MCU → 3-ph gate driver → 6× N-MOSFET → motor]
           │          ▲ DShot600 bidir (1 wire per motor)
           └── BEC 5V/3V3 ── STM32H743 (ArduPilot) ── TIM1 CH1-4
```

**Design assumptions:**

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal |
| Burst current | 80 A per channel, phase current, 6-step trapezoidal, complementary synchronous PWM |
| PWM frequency | f_sw = 48 kHz |
| MOSFET (representative 40 V, PDFN 3.3×3.3) | R_ds(on),25 = 1.5 mΩ @ V_gs = 10 V |
| | Q_g = 50 nC, Q_gs2 + Q_gd = 12 nC, Q_oss = 50 nC, Q_rr = 40 nC, V_SD = 0.8 V |

| Gate driver | ~1 A effective at the Miller plateau |
| Dead time | t_dt = 200 ns |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.0063\ \text{K}^{-1}$$

At the design point T_j = 120 °C:

$$R_{ds}(120) = 1.5\,\text{m}\Omega \times 1.60 = 2.4\ \text{m}\Omega$$

### 1.2 Current path in 6-step with synchronous PWM

During any commutation sector:
- One leg is PWM-switched. Its high-side FET conducts for duty D, and its complementary low-side FET conducts for 1 − D.
- One low-side FET in another leg is held fully on.

The current therefore always flows through exactly **two** FET channels, independent of D (ignoring dead time):

$$P_{cond,ch} = 2\,I^2\,R_{ds}(T_j)$$

$$P_{cond,ch} = 2 \times 80^2 \times 2.4\times10^{-3} = \mathbf{30.7\ W\ per\ motor\ channel}$$

### 1.3 Per-FET distribution

Each FET is active for 1/3 of the electrical cycle:
- **Instantaneous** dissipation in a conducting FET: I²R = **15.4 W**.
- **Cycle-averaged** dissipation per FET: 30.7 / 6 ≈ **5.1 W**.

The die thermal time constant (~ms) is longer than the electrical period. For example, a 14-pole motor at 30 kRPM has an electrical frequency of 3.5 kHz. The junction therefore effectively sees the averaged value plus a small ripple.

### 1.4 Parasitic copper

Each path also crosses roughly 0.3 mΩ of trace, via, and solder:

$$P_{Cu} = 80^2 \times 0.3\,\text{m}\Omega \approx 1.9\ \text{W/ch}$$

This heat is spread into the board rather than the junction.

## 2. Switching Loss Model (48 kHz)

Only one leg switches per sector, so all terms below apply once per channel.

### 2.1 V·I overlap

The transition time per edge is set by the switching charge and gate current:

$$t_{sw} \approx \frac{Q_{gs2}+Q_{gd}}{I_g} = \frac{12\,\text{nC}}{1\,\text{A}} = 12\ \text{ns}$$

$$P_{VI} = \tfrac12 V I (t_r+t_f) f_{sw} = 0.5\times25.2\times80\times24\text{ns}\times48\text{k} = \mathbf{1.16\ W}$$

### 2.2 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = V_{SD}\,I\,(2t_{dt})\,f_{sw} = 0.8\times80\times400\text{ns}\times48\text{k} = \mathbf{1.23\ W}$$

This is the largest switching-related term. Cutting dead time to 100 ns saves about 0.6 W per channel, provided shoot-through margin is verified.
