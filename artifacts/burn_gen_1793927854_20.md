### 0.1 System Partition

The STM32H743 does not drive the MOSFETs directly. In every production 4-in-1 stack, each motor has its own ESC MCU running the 48 kHz complementary PWM and commutation. The H743 only generates DShot and captures the telemetry reply.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path

In 6-step trapezoidal (or FOC near peak), current flows through two legs at any instant. With synchronous rectification there is always exactly one conducting FET per active leg: the HS FET during on-time, the LS FET during off-time. The return leg's LS FET is on continuously.

The resistance in the current path is therefore always 2·R_ds(T_j), plus copper.

### 1.2 Temperature-Dependent Resistance

R_ds(T_j) = R_ds,25 · [1 + α (T_j − 25)]

### 1.3 Loss per Motor

The phase current has small PWM ripple, ΔI_pp ≈ V/(L·f_sw) ≪ 80 A for typical motors, so:

P_cond,motor = 2 · I_rms² · R_ds(T_j) + I_rms² · R_cu

Ripple correction factor: I_rms² = I² + ΔI_pp²/12. This is negligible here.

**Worst case (T_j = 125 °C, R_ds = 1.5 mΩ):**

- P_cond,FET = 80² × 1.5 mΩ = **9.6 W** (instantaneous, on the conducting device)
- P_cond,motor = 2 × 9.6 = **19.2 W**

### 1.4 Per-FET Distribution

Averaged over an electrical cycle, the 19.2 W spreads over 6 FETs, giving about 3.2 W average each. The FET die thermal time constant is about 1–10 ms. So:

- **At high eRPM**, use the average value (3.2 W).
- **At low eRPM or stall burst**, use the instantaneous 9.6 W per FET (see §3.3).

### 1.5 Copper Loss

R_cu covers phase pads, the bus plane and the via field. Target ≤ 0.3 mΩ per path:

P_cu = 6400 × 0.3 mΩ ≈ **1.9 W per motor**

### 1.6 Electro-Thermal Fixed Point

Iterate the coupled equations:

- T_j = T_board + P_FET(T_j) · R_θ,j-b
- P_FET(T_j) = I² · R_ds(T_j)

The system converges if:

∂P/∂T · R_θ = I² · R_ds,25 · α · R_θ < 1

With the §3.3 values: 6400 × 1e-3 × 0.005 × 3 = **0.096**. This is stable with no thermal runaway at 80 A.

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM-ing leg of each motor switches. The return LS FET is static.

### 2.1 V-I Overlap Loss (Hard-Switched HS FET)

Switching time from gate charge:

t_sw ≈ Q_sw / I_g, with I_g = (V_drv − V_plateau) / R_g = (10 − 3) / 5.7 ≈ 1.23 A

This gives t_r ≈ t_f ≈ 12.2 ns. Use **15 ns** for margin.

P_ov = ½ · V_bus · I · (t_r + t_f) · f_sw
= 0.5 × 25.2 × 80 × 30e-9 × 48e3
= **1.45 W**
