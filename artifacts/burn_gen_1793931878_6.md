# STM32H743 Flight Controller + 80 A 4-in-1 ESC (Job #46): Design Model

## 0. Scope and Assumptions

I have no prior Job #46 documentation, so the design rests on the baseline below. Change any line and the equations still apply; only the numbers move.

| Parameter | Assumed value | Notes |
|---|---|---|
| Architecture | STM32H743 FC running ArduPilot, plus 4-in-1 ESC with **4 × AT32F421 running AM32** | An H743 cannot practically commutate 4 BLDCs while also running ArduPilot. The FC drives the ESC MCUs with bidirectional DShot600. |
| Bus voltage | 6S, V_bus,max = 25.2 V | Derate to 22.2 V nominal where noted |
| MOSFETs | 40 V, PDFN5×6, R_ds(on) = 1.0 mΩ max at 25 °C, V_GS = 10 V | Example: Infineon BSC007N04LS6 class. Substitute your datasheet values. |
| Gate driver | FD6288Q (3-phase, about 1.0 A source / 1.5 A sink) | One per motor |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal | AM32 default style |
| Dead time | 250 ns | Tune per FET pair |
| "80 A burst" | Per-motor phase current, ≤ 5 s | Worst case analysed: all 4 motors at once |
| Board | 30.5 × 30.5 mm, 6-layer, 2 oz outer and inner copper | "Nano" 20 × 20 is addressed in §3.5 |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)],\qquad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 1.0 mΩ × 1.45 = **1.45 mΩ**.
