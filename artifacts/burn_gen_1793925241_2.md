## 1. FOC Inner Current Loop

### 1.1 Transforms
Use amplitude-invariant transforms with balanced phases, so i_a + i_b + i_c = 0.

**Clarke transform:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform**, where θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Machine Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m$$

### 1.3 Current PI with Decoupling and Pole-Zero Cancellation
With the cross-coupling terms removed by feedforward, the per-axis plant is

$$G_i(s) = \frac{1}{Ls + R}$$

Choose the PI zero to cancel the electrical pole. Then

$$K_{p,i} = \omega_{ci} L,\qquad K_{i,i} = \omega_{ci} R \;\Rightarrow\; \frac{I(s)}{I^*(s)} = \frac{\omega_{ci}}{s + \omega_{ci}}$$

Use ω_ci = 2π·1500 rad/s. This is ≤ f_PWM/10, which gives margin for the ~1.5-sample computation and PWM delay.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e (L_d i_d + \lambda_m)$$

**Voltage limiting.** The linear SVPWM limit is

$$|v|_{max} = V_{bus}/\sqrt3$$

Give the d-axis priority, then allocate the remainder to q:

$$v_q^{max} = \sqrt{|v|_{max}^2 - v_d^2}$$

### 1.4 Discrete PI with Back-Calculation Anti-Windup (Forward Euler, T_s)

$$u_k^{u} = K_p e_k + I_k,\qquad u_k = \text{sat}(u_k^{u})$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s (u_k - u_k^{u}),\qquad K_{aw} \approx K_i / K_p$$

### 1.5 SVPWM by Min-Max Zero-Sequence Injection

$$v_{a,b,c} = \text{inverse Clarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\left(\max v_x + \min v_x\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to 7-segment SVPWM.
