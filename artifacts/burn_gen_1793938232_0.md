# STM32H743 Nano FC + 4-in-1 ESC (Job #50): Design Model

## 0. Architecture Assumptions and Feasibility Warnings

**Topology.** The H743 never drives gates. The flight controller sends bidirectional DShot600 to the ESC board. A dedicated MCU per channel (or one shared MCU) runs AM32 or BLHeli_32 and drives a 3-phase gate driver. This document models both boards, linked by the stack connector.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, 25.2 V max (V_DS rating ≥ 40 V) |
| Form factor | 20×20 mm (M2 holes), ~25×25 mm board outline |
| Current | 80 A **burst per motor** (≤ 2 s); continuous rating derived below |
| PWM | 48 kHz, complementary/synchronous, 6-step (trapezoidal) |
| MOSFET (representative 40 V, 5×6 or 3.3×3.3) | R_DS(on) = 1.0 mΩ @ 25 °C, α ≈ +0.5 %/K, Q_g = 60 nC, Q_gd = 15 nC, Q_rr = 50 nC, C_oss ≈ 1.5 nF, R_θJC = 1.0 K/W |

> **All MOSFET parameters are placeholders.** Substitute the datasheet values of the part you select. The model below is fully parametric.

> **Feasibility red flag:** 4 × 80 A = **320 A** total battery current on a 20×20 stack. The math below shows this is only survivable as a short transient. The board-level thermal mass, the shunt, the XT60/XT90 connector and the battery leads all become limiting factors before the FETs do.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path in 6-step synchronous drive
In any commutation sector, current flows through the high-side FET of phase *x* and the low-side of phase *y*. With synchronous rectification:

- During the ON interval (duty D), current flows through HS_x and LS_y.
- During the OFF interval (1−D), current flows through LS_x (sync) and LS_y.

So **two channel-resistances are always in series**, regardless of D:

$$P_{cond,ch} = I^2 \left[ R_{DS}(T_j)\cdot D + R_{DS}(T_j)(1-D) \right] + I^2 R_{DS}(T_j) = 2\,I^2 R_{DS}(T_j)$$

### 1.2 Temperature dependence

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)]$$

At T_j = 125 °C: R_DS = 1.0 mΩ × 1.5 = **1.5 mΩ**.

$$P_{cond,ch} = 2 \times 80^2 \times 1.5\text{ m}\Omega = \mathbf{19.2\ W}$$

Copper trace and phase-pad resistance must be added. With about 0.3 mΩ of path resistance per channel: 80² × 0.3 mΩ = **1.9 W**.

### 1.3 Electrothermal fixed point (runaway criterion)
With steady state $T_j = T_a + P(T_j)\,R_{\theta}$ and $P(T_j) = P_0[1+\alpha(T_j-25)]$:

$$T_j = \frac{T_a + P_0 R_\theta (1 - 25\alpha)}{1-\alpha P_0 R_\theta}$$

A stable solution requires **α·P₀·R_θ < 1**.

Example: P₀ (at 25 °C) = 12.8 W per channel, α = 0.005, R_θ(ch→air) ≈ 8 K/W gives αP₀R_θ = 0.51.
- The solution is "stable", but it yields T_j ≈ 230 °C.
- **80 A continuous is therefore impossible.** Inverting the model with T_j,max = 120 °C gives I_cont ≈ 32–38 A per channel, depending on airflow.

## 2. Switching Loss Model at 48 kHz

Only the PWM-switching FET (the HS in this scheme) hard-switches. Per channel:

| Term | Formula | Value (25.2 V, 80 A, 48 kHz) |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·40 ns·48k = **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw | 50 nC·25.2·48k = **0.06 W** |
| Output capacitance | ½·C_oss·V²·f_sw | ½·1.5 nF·635·48k = **0.02 W** |
| Dead-time body diode | V_f·I·2·t_dt·f_sw | 0.8·80·2·100 ns·48k = **0.61 W** |
| Gate drive (×2 FETs, in driver) | Q_g·V_gs·f_sw | 60 nC·10 V·48k ×2 = **0.06 W** |

### 2.1 Edge-time derivation (check that t_r ≈ 20 ns is realistic)

$$t_{sw} \approx \frac{Q_{gd}\,R_{g,tot}}{V_{drv}-V_{plateau}}= \frac{15\text{ nC}\times 5\,\Omega}{10-3.5}\approx 11.5\text{ ns}$$

Plus the Q_gs ramp gives ≈ 20 ns, consistent with the assumption. A faster edge lowers switching loss but worsens ringing and EMI on the IMU. Keep R_g at 3–5 Ω and size dead-time at ≥ 2× the worst-case t_f.

### 2.2 Totals per channel at 80 A burst

| Component | Loss |
|---|---|
| Conduction (FETs, 125 °C) | 19.2 W |
| Copper | 1.9 W |
| Switching + Q_rr + C_oss | 2.0 W |
| Dead-time diode | 0.6 W |
| **Channel total** | **≈ 23.7 W** |
| **4-in-1 board total** | **≈ 95 W** |

Efficiency check: 95 W lost out of about 25.2 × 320 ≈ 8 kW processed, roughly 98.8%. The percentage loss is small; the problem is *heat density*, not efficiency.

### 2.3 Optimal switching frequency
Total loss as a function of switching frequency:

$$P(f) = 2I^2R + f\,(E_{sw}+E_{rr}+E_{oss}+E_{dt})$$

Frequency-dependent energy per cycle is E_f ≈ 54 µJ, so each 10 kHz adds ≈ 0.54 W per channel at 80 A. Running at 48 kHz instead of 24 kHz costs about 1.3 W per channel. The gains are lower current ripple and quieter motors. This is acceptable.

## 3. Thermal Model

### 3.1 Network (Cauer, per channel)

```
P_ch ─► [R_θJC 1.0 K/W ÷ 2 FETs active] ─► Case/pad ─► [R_θ,spread 3 K/W] ─► Board copper (C_board)
                                                                        └─► [R_θ,conv 5–15 K/W] ─► Air
```

### 3.2 Junction-to-board rise during burst
Each active FET dissipates about 10–11 W:

$$\Delta T_{JC} \approx 10.5 \times 1.0 = 10.5\text{ K}$$

The junction leads the board by about 10–15 K. The board copper is the real bottleneck.

### 3.3 Adiabatic burst (board heat capacity dominates)
Effective board-plus-FET thermal mass:
- 4 oz-equivalent copper ≈ 3 g × 0.385 J/g·K
- FR4 plus components ≈ 1.5 g × 1.1 J/g·K

This gives C_th ≈ **2.8 J/K**.

$$\frac{dT}{dt} = \frac{95\text{ W}}{2.8\text{ J/K}} \approx 34\text{ K/s}$$

| Burst duration | Board ΔT | T_j (T_a = 35 °C, start 50 °C) |
|---|---|---|
| 0.5 s | 17 K | ≈ 80 °C |
| 1.0 s | 34 K | ≈ 97 °C |
| 2.0 s | 68 K | ≈ 130 °C (**limit**) |

**Result: an 80 A rating is valid for ≈ 1.5 s bursts from a 50 °C board.** It is not valid for continuous operation.

Firmware requirements:
- Enable ESC temperature protection, with the NTC on the ESC board near the FETs.
- Set an ArduPilot `BATT_MAX_AMPS`/current limit or `MOT_BAT_CURR_MAX` to enforce the continuous budget.
