# STM32H743 Nano AIO Flight Controller + 4-in-1 ESC: Systems Architecture Package (Job #40)

> **Read this first.** You did not specify MOSFET part numbers, board size, layer stack, battery cell count, burst duration or cooling. I have therefore stated every assumption explicitly as a parameter. The equations are general. The numbers are a worked example that must be re-run with your actual datasheet values before layout freeze.
>
> **Critical design finding.** 80 A burst per motor on a 20×20 mm "nano" board is not thermally viable for more than about 1 second (Section 3.4). Treat 80 A as either a total-bus burst or a single-motor transient, or move to a 30.5×30.5 mm format. I flag this up front because it drives every other decision.

## 0. System Architecture

```
            ┌──────────────────────── STM32H743VIT6 (FC, 400 MHz) ─────────────────────┐
 IMU1 ─SPI1─┤                                                                          │
 IMU2 ─SPI4─┤  TIM1 CH1..CH4 ── DShot600 (bidirectional) ──┐                           │
 Baro ─I2C2─┤  ADC: VBAT, IBUS                             │                           │
 Flash─SPI2─┤  UART1..UART7: RC, GPS, VTX, ESC-telem (opt) │                           │
            └───────────────────────────────────────────────┼──────────────────────────┘
                                                            ▼
                ┌─────────── 4-in-1 ESC section (×4 identical channels) ───────────┐
                │ AT32F421 (AM32 / BLHeli_32) ── 48 kHz complementary PWM          │
                │      │                                                           │
                │ 3-phase gate driver (FD6288Q-class) ── 6× N-MOSFET (3 half-bridges) │
                │ Bulk + MLCC bus capacitance, phase-voltage dividers for BEMF ZC   │
                └──────────────────────────────────────────────────────────────────┘
```

**Clarification on clock domains.** The 48 kHz switching frequency belongs to the ESC MCUs, not the H743. The H743 only generates DShot600 frames and decodes eRPM telemetry. The loss model (Sections 1–2) and the DMA model (Section 4) are therefore physically independent subsystems.
