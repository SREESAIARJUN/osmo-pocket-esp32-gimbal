# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

**Scope.** This document covers current, velocity and angle cascaded control, anti-cogging feedforward, and dual ICM-42688-P vibration rejection.

**Assumptions.** I don't have the Job #36 specification, so the design rests on the assumptions below. Replace them with your actual parameters before tuning.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz) |
| Motors | 3 × gimbal PMSM, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A class) |
| Current sense | 2-phase low-side shunts, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera (payload) plate, SPI, 8 kHz ODR, ±500 dps / ±4 g |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz |

## 1. Plant Model

### 1.1 PMSM in the rotor (dq) frame

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e (L_d i_d + \lambda_m)
$$

$$
\tau_m = \tfrac{3}{2}\,p\,\big[\lambda_m i_q + (L_d-L_q)i_d i_q\big] \;\overset{L_d=L_q}{=}\; K_t\, i_q,\qquad K_t=\tfrac32 p\lambda_m
$$

Here $\omega_e = p\,\omega_m$ and $\theta_e = p\,\theta_m - \theta_{\text{offset}}$.
