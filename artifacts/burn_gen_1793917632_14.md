# Job #22: STM32H743 Flight Controller + 4-in-1 80A ESC Stack
## Systems Architecture, Loss Model, DShot Allocation, Netlists

---

## 0. Feasibility Findings

Read these before the math. They drive every decision below.

| # | Finding | Consequence |
|---|---|---|
| F1 | 80A per channel × 4 channels on a 20×20 mm "nano" footprint is not thermally or physically feasible. 24 power FETs at about 1 mΩ need roughly 600+ mm² of FET land alone, plus bulk capacitance. | The architecture specifies 30.5×30.5 mm minimum for the ESC. The FC can stay 20×20 (nano). |
| F2 | The STM32H743 does not commutate the motors. A 4-in-1 ESC runs its own MCUs (AM32 or BLHeli_32 class, e.g. STM32G071 or AT32F421, one per motor). | The H743 is the DShot master only. ESC MCUs generate the 48 kHz PWM. |
| F3 | "80A burst" must have a defined duration. The thermal model in §3 shows about 2 s is the realistic all-motors limit without forced cooling. | The ESC spec should read "80A, 2 s burst, all channels" or "80A, 10 s, single channel". |
| F4 | All device parameters below are representative values for a 40V, ~1 mΩ trench FET class. | Re-run the model (§2.6 table) with the selected part's datasheet values. |

## 1. System Architecture

```
 6S LiPo (25.2V max)
   │
   ├──► ESC board (30.5×30.5, 8L 2oz)
   │      ├─ 4× ESC MCU (AM32 on STM32G071) ── 48 kHz complementary PWM
   │      ├─ 4× FD6288Q-class 3-phase gate driver
   │      ├─ 24× N-FET (6 per motor)
   │      ├─ Shunt + INA-class current sense → CURR pin to FC
   │      └─ Bulk: 1× 35V 470–1000µF low-ESR + 4× 10µF X7R per phase pair
   │
   └──► FC board (H743, 20×20 or 30.5)
          ├─ 4× bidirectional DShot600 lines (single-wire, half-duplex)
          ├─ ESC telemetry UART (optional; RPM comes via bidir DShot)
          ├─ VBAT divider, CURR sense input
          └─ IMU (SPI), baro (I²C), OSD, receivers
```

## 2. Loss Model (per motor channel)

### 2.1 Operating Assumptions

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst-case switching) |
| I_ph | 80 A | Phase current during burst (6-step, 2 phases conducting) |
| f_sw | 48 kHz | PWM frequency |
| R_ds(on),25 | 1.0 mΩ | Typical at V_gs = 10 V |
| α | 1.6 | R_ds multiplier at T_j ≈ 125 °C |
| t_r, t_f | 20 ns each | Effective V–I overlap with the chosen R_g |
| t_dt | 200 ns | Dead time per edge |
| V_SD | 0.8 V | Body-diode forward drop at 80 A |
| Q_rr | 50 nC | Body-diode reverse recovery charge |
| Q_oss | 50 nC | Output charge at V_bus |
| Q_g | 60 nC | Total gate charge at 10 V |
| D | 0…1 | PWM duty (complementary/synchronous rectification) |

### 2.2 Conduction Loss

In 6-step trapezoidal commutation, two phases conduct at any instant:

- **Chopping leg:** the high side (HS) conducts for D and the synchronous low side (LS) for (1−D). The current always flows through exactly one FET of this leg.
- **Return leg:** the LS is held fully on.

Per-FET conduction loss:

$$P_{cond,HS}=I^2 R_{ds,hot}\,D,\qquad P_{cond,LS,sync}=I^2R_{ds,hot}(1-D),\qquad P_{cond,LS,ret}=I^2R_{ds,hot}$$

Per-motor conduction loss, independent of D:

$$P_{cond,motor}=2\,I^2 R_{ds}(25^\circ\mathrm{C})\,\alpha$$

$$P_{cond,motor}=2\cdot80^2\cdot1.0\,\text{m}\Omega\cdot1.6=\mathbf{20.48\ W}$$

Copper and trace losses must be added. Each phase path has about 0.3 mΩ (2oz, 8L, via-stitched), plus 0.5 mΩ for the shunt. For two phases plus the shunt:

$$P_{Cu}=80^2(2\cdot0.3+0.5)\,\text{m}\Omega=7.04\ \text{W}$$

**Design note:** use a low-side shunt per motor of 0.25 mΩ or less, or a single input shunt. This halves P_Cu.

### 2.3 Switching Loss (hard-switched HS, 48 kHz)

$$P_{sw}=\tfrac12 V_{bus} I (t_r+t_f) f_{sw}=\tfrac12\cdot25.2\cdot80\cdot40\text{ns}\cdot48\text{k}=\mathbf{1.94\ W}$$

Switching loss scales with D:

- At D = 1 there are no transitions, so P_sw → 0.
- The worst case for the combined loss is mid-throttle at high current. This happens in punch-outs, where the current transient leads the RPM.

### 2.4 Secondary Switching Terms

**Reverse recovery** (LS body diode recovers when the HS turns on):

$$P_{rr}=Q_{rr}V_{bus}f_{sw}=50\text{n}\cdot25.2\cdot48\text{k}=0.060\ \text{W}$$

**Output capacitance:**

$$P_{oss}=\tfrac12 Q_{oss}V_{bus}f_{sw}\times2=0.060\ \text{W}$$

**Dead-time diode conduction** (2 edges per period):

$$P_{dt}=V_{SD}\,I\,(2t_{dt})\,f_{sw}=0.8\cdot80\cdot400\text{n}\cdot48\text{k}=\mathbf{1.23\ W}$$

Mitigation: AM32 dead-time tuning down to about 100 ns halves this term. Verify against the FD6288 propagation mismatch first.

**Gate drive** (6 FETs, only 2 switching at 48 kHz in 6-step; mostly dissipated in R_g and the driver):

$$P_g=Q_gV_{gs}f_{sw}\times2=60\text{n}\cdot10\cdot48\text{k}\cdot2=0.058\ \text{W}$$
