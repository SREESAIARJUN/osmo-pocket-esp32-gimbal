# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I have no specification for Job #28, so the design below rests on assumptions about typical brushless gimbal hardware. Replace the values in `config` (Section 7) with your measured parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC, HRTIM) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 1.6 mH, K_t ≈ 0.09 N·m/A |
| Joint encoders | 14-bit absolute magnetic encoders (MT6701/AS5048A), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

The control loops run at these rates:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| IMU fusion and filters | 8 kHz | n/a |
| Inertial-rate loop | 4 kHz | ~120 Hz |
| Attitude loop | 1 kHz | ~20 Hz |

Each loop's bandwidth is at least 5–10× below the loop inside it. That separation lets each inner loop be treated as unity gain when tuning the next loop out.

## 1. Field-Oriented Control (current loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = \big(p\,\theta_m - \theta_{\text{off}}\big) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

The offset θ_off is found by aligning the rotor to a known voltage vector at startup.

### 1.2 Clarke transform

This is the amplitude-invariant form, with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform and its inverse

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix}=\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} v_d\\ v_q\end{bmatrix}$$

### 1.4 Motor model in the dq frame

For a surface-mount PMSM (L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The torque and flux constants are related by

$$\tau = \tfrac{3}{2} p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI (pole–zero cancellation)
