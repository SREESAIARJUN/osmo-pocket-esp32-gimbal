## 0. Architecture Findings You Should Read First

These four findings affect the feasibility of the whole design, so they come before the math.

1. **The H743 does not generate the 48 kHz bridge PWM.** In every ArduPilot-compatible 4-in-1 design, the H743 is the flight controller. It sends bidirectional DShot600 to four ESC MCUs (or one quad-capable MCU). Those ESC MCUs run AM32 or BLHeli_32-class firmware on parts such as the AT32F421 or STM32G071, and they generate the 48 kHz commutation PWM. The two timing domains are fully decoupled, and the models below treat them separately.
2. **80 A on a nano footprint is a burst rating limited by thermal capacitance, not a continuous rating.** Section 3 shows roughly 1–2.5 s at 4×80 A before the board reaches about 100 °C. Market it as a burst rating with an explicit duration, or the claim will not hold up.
3. **The H743 package constrains board size.** The smallest practical option is the TFBGA100 at 8×8 mm. An H743 plus 12 power FETs plus bulk capacitance on one 20×20 board is not realistic at 80 A. Recommended options:
   - a 20×20 stack (FC board plus ESC board), or
   - a 30.5×30.5 AIO.

   The thermal math is given for both 20×20 and 30×30 ESC boards.
4. **Input capacitor ripple current is the second failure mode after FET temperature.** It is derived in §2.5.

## 2. Loss Model (per ESC channel, 6-step trapezoidal, synchronous complementary PWM)

### 2.1 Conduction-state bookkeeping

In 6-step commutation each phase leg spends one third of the electrical cycle in each of three states:

| State | High-side FET | Low-side FET |
|---|---|---|
| **Source** (PWM leg) | On for D | On for (1−D), synchronous rectification |
| **Sink** | Off | On for 100 % |
| **Float** | Off | Off |

Time-averaged I² weighting per FET of one leg:

```
High-side:  k_HS = D/3
Low-side:   k_LS = (1−D)/3 + 1/3 = (2−D)/3
Per leg:    k_HS + k_LS = 2/3
Bridge:     3 legs × 2/3 = 2  →  exactly two FETs in the current path at all times (excluding dead time)
```

### 2.2 Conduction loss

```
P_cond = 2 · I_ph² · R_ds(on)(T_j)

At T_j = 25 °C :  2 · 80² · 1.0 mΩ = 12.8 W
At T_j = 125 °C:  2 · 80² · 1.6 mΩ = 20.5 W   ← design value
```

The worst single FET is the low side at low duty (k_LS → 2/3):

```
P_LS,max = (2/3) · 80² · 1.6 mΩ = 6.8 W average
Instantaneous during the sink interval: 80² · 1.6 mΩ = 10.2 W
```

The instantaneous value matters because the electrical period, for example 1/(14 poles/2 × 400 rev/s) = 357 µs, is comparable to the FET die thermal time constant.

**Thermal-runaway check.** R_ds rises with temperature, so the steady-state junction temperature solves:

```
T_j = T_board + R_θ,j-board · P(T_j)
```

A stable solution exists only if:

```
R_θ · dP/dT_j < 1
dP/dT ≈ P · 2.3/T_j  ≈ 6.8 W · 2.3/398 K ≈ 0.039 W/K
→ requires R_θ,j-board < 25 K/W
```

This is easily satisfied with a properly via-stitched thermal pad (about 2–3 K/W). Runaway is a board-level problem, not a junction-level one.
