# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #5 specification. This design uses the assumptions in §0. Every assumed value is a parameter in the code, so you can substitute the real values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, on-chip AAF enabled |
| Kinematic chain | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |

```
                        2 kHz                     4 kHz                   20 kHz
 q_ref ─►[Attitude P + ω_ff]─► ω_ref ─►[J⁻¹]─► q̇_ref ─►[Velocity PI]─► i_q* ─►[Current PI + FOC]─► PWM
              ▲                                ▲              ▲  ▲                 ▲
              │ q̂ (Mahony)                     │ q̇_meas       │  └ i_q,ff (anti-cog, from θ_m)
   Dual ICM-42688 @8 kHz ─►[rotate, notch, LPF, fuse, FDI]─► ω_cam ─► J⁻¹      encoder θ_m
```

Each outer loop's bandwidth is kept 4–10× below the loop inside it:

- ω_c,current ≈ 2π·1.5 kHz
- ω_c,vel ≈ 2π·60–120 Hz
- ω_c,att ≈ 2π·10–20 Hz
