# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

## 0. System Assumptions

| Item | Value |
|---|---|
| Motor | Gimbal PMSM, 12N14P (pole pairs `p = 7`), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), per joint |
| Bus | Vdc = 12–16 V, 3-phase inverter, 2 low-side shunts |
| Current loop | 20 kHz (PWM-synchronous ISR) |
| Velocity loop | 5 kHz (every 4th current ISR) |
| Angle loop + attitude | 1 kHz |
| IMUs | 2 × ICM-42688-P on the payload, gyro/accel ODR 8 kHz, FIFO or DRDY-driven |

The loop hierarchy runs from slowest to fastest:

**Attitude (1 kHz) → Angle (1 kHz) → Velocity (5 kHz) → Current/FOC (20 kHz).**

Keep at least a 5–10× bandwidth separation between successive loops.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

Here θ_off is found at commissioning: inject i_d = I_align at θ_e = 0 and read θ_m.

### 1.2 Clarke Transform

This form assumes a balanced system, i_a + i_b + i_c = 0.

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

Electromagnetic torque:

$$\tau = \tfrac{3}{2} p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t\, i_q \quad (\text{SPM},\ i_d^* = 0)$$

### 1.5 Current PI with Decoupling

The PI acts on the error, and the cross-coupling and back-EMF terms are added as feedforward:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L_d i_d + \lambda_m)$$

**Gain selection (pole-zero cancellation).** Cancel the plant pole and set the closed loop to a first-order response with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes G_cl(s) = ω_c / (s + ω_c). Choose ω_c ≈ 2π·1.5 kHz, which is below f_s/10 at 20 kHz.

**Discrete PI with back-calculation anti-windup:**

$$u_k = K_p e_k + I_k,\qquad u_k^{sat} = \text{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s (u_k^{sat} - u_k),\qquad K_{aw} \approx K_i/K_p$$

### 1.6 Voltage Limiting

Limit the voltage vector to the linear SVPWM region, preserving direction and prioritizing d:

$$|v_{dq}| \le V_{max} = \frac{V_{dc}}{\sqrt{3}}$$

### 1.7 Inverse Park and SVPWM

Apply the inverse Park transform, then the inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Inject the min-max zero sequence, which is equivalent to SVPWM:

$$v_0 = -\tfrac12(\max v_x + \min v_x),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

### 1.8 Encoder Velocity: Type-II PLL Tracker

This gives low-noise ω and θ, and removes the quantization noise of numerical differentiation.

$$e_k = \text{wrap}_{\pi}(\theta_{m,k} - \hat\theta_k)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_{i,pll} T_s e_k$$
$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll} e_k)$$

Gains: K_p,pll = 2ζω_n and K_i,pll = ω_n², with ζ = 0.707 and ω_n ≈ 2π·300 Hz.
