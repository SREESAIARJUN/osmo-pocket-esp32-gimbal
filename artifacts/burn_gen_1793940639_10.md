# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #50, so the design below is built on explicit assumptions. Every assumed number is a parameter in `GimbalConfig`. Swap in your motor, encoder and MCU values and the gain formulas re-derive automatically.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (2804/4108 class), 12N14P → pole pairs p = 7, slots Nₛ = 12, R = 5.6 Ω (phase), L = 1.8 mH (phase), K_t = 0.075 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A) on each motor shaft |
| MCU | STM32G4 / H7 class with FPU and 3 inline or low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

**Rate hierarchy.** Each loop is roughly 5–10× slower in bandwidth than the loop inside it.

| Loop | Rate | Bandwidth |
|---|---|---|
| Current (FOC PI) | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| IMU acquisition, filtering, fusion | 8 kHz | — |
| Velocity PI (gyro feedback) | 4 kHz | ≈ 2π·150 Hz |
| Angle P/PI (attitude feedback) | 1 kHz | ≈ 2π·20 Hz |
| Attitude estimator (Mahony) | 1 kHz | — |

**Role of each sensor.**

- **Encoder:** commutation angle θₑ and the anti-cogging phase.
- **IMU gyro**, projected onto the joint axis: inertial-rate feedback for the velocity loop. Feeding back inertial rate rather than relative rate is what rejects base disturbances.
- **IMU attitude:** angle-loop feedback.

## 1. Field-Oriented Current Control

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, assuming iₐ + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with θₑ = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupling

The PMSM model in the dq frame (surface-mount, so L_d = L_q = L) is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

**Feedforward decoupling:**

$$v_d^* = \text{PI}_d - \omega_e L i_q,\qquad v_q^* = \text{PI}_q + \omega_e(L i_d + \lambda_m),\qquad \lambda_m = \tfrac{2K_t}{3p}$$

After decoupling, each axis reduces to a first-order plant 1/(Ls + R).
