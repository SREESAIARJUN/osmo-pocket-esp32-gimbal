# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #45, so the design below states every hardware assumption explicitly. Each assumption is isolated as a parameter in the code, so you can substitute your real values without restructuring anything.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value | Where to change |
|---|---|---|
| Motors | 3× BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.3 mH, K_t ≈ 0.07 N·m/A | `MotorParams` |
| Commutation sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701 class) | `EncoderInput` |
| Current sense | 2-phase inline shunts, ADC triggered at PWM center | `foc_isr()` |
| MCU | Cortex-M4F/M7 with single-precision FPU | — |
