# Job #60: 3-Axis Gimbal FOC Control and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #60 spec sheet, so this design uses the defaults below. Change the parameters in `config.hpp` to match your hardware. All equations are parametric, so nothing else needs rewriting.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s\approx 5\,\Omega$, $L\approx 2\,\text{mH}$, $K_t\approx 0.08\,\text{Nm/A}$ |
| Encoders | 14-bit absolute magnetic, one per joint (MT6701 / AS5048A class) |
| IMU_P | ICM-42688-P on the camera payload. Provides the inertial feedback. |
| IMU_F | ICM-42688-P on the frame/handle. Provides the vibration reference and disturbance feedforward. |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, payload) |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | $f_c = 20$ kHz | PWM-center ADC trigger |
| Velocity + IMU filtering | $f_v = 8$ kHz | IMU_P data-ready (ODR 8 kHz) |
| Angle + attitude fusion | $f_\theta = 1$ kHz | Decimated from the 8 kHz loop |

Bandwidths are separated by at least 5–10× per stage:

| Loop | Target bandwidth |
|---|---|
| Current | $\omega_c = 2\pi\cdot 1500$ |
| Velocity | $\omega_v = 2\pi\cdot 120$ |
| Angle | $\omega_\theta = 2\pi\cdot 15$ rad/s |
