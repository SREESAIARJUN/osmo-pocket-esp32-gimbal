# Gimbal Motor Control and Dual-IMU Sensor Fusion Design (Job #42)

I don't have the Job #42 spec, so the hardware assumptions are listed first. Every equation is parameterized, so you can substitute your real values.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4-class Cortex-M4F at 170 MHz, single-precision FPU (CORDIC optional) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz, data-ready interrupts |
| Current loop | f_i = 20 kHz (center-aligned PWM, ADC sampled at the PWM valley) |
| Rate loop | f_v = 4 kHz |
