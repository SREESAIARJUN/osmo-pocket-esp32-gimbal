# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #44, so I've assumed a typical brushless gimbal configuration. Each assumption is parameterized. Swap in your actual values and the equations and code still hold.

## 0. Design Assumptions

| Item | Assumed value | Symbol |
|---|---|---|
| Motor | GM4108-class gimbal BLDC, 24N22P | N_s = 24, p = 11 pole pairs |
| Phase resistance / inductance | 10 Ω / 3 mH (line-neutral) | R, L |
| Torque constant | 0.08 N·m/A | K_t |
| Rotor plus payload inertia, per axis | 2–8 × 10⁻⁴ kg·m² | J |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI | θ_m |
| Current sensing | 2-phase inline shunts | i_a, i_b |
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC | |
| IMU A (payload) | ICM-42688-P on camera plate, used for feedback | ω_p, a_p |
| IMU B (base) | ICM-42688-P on handle/frame, used for feedforward | ω_b, a_b |

**Loop rates (one timer, integer dividers):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~2 kHz |
| IMU sample / filter | 8 kHz ODR, processed in 4 kHz task | — |
| Velocity | 4 kHz | ~120–150 Hz |
| Angle / attitude | 1 kHz | ~25–35 Hz |

Each loop keeps a separation of at least 4× (ideally 8×) in bandwidth from the loop inside it.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at calibration by applying v_d > 0, v_q = 0 and reading θ_m.

The angle is extrapolated to the PWM midpoint to remove one sample of transport delay:

$$\hat\theta_e = \theta_e + p\,\hat\omega_m\left(T_{\text{SPI}} + \tfrac{1}{2}T_{\text{PWM}}\right)$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model and decoupling

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The decoupling plus back-EMF feedforward is:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,\qquad \lambda_m = \frac{2K_t}{3p}$$

### 1.4 Current PI by pole-zero cancellation

The plant is $G_i(s)=1/(Ls+R)$. Choosing

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

gives the closed loop $i/i^* = \omega_{ci}/(s+\omega_{ci})$. With ω_ci = 2π·2000:

- K_p = 37.7 V/A
- K_i = 1.26 × 10⁵ V/(A·s)

### 1.5 Voltage limit and SVPWM

The voltage vector is limited to the linear hexagon-inscribed circle:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

The q-axis gets priority:

$$v_d \leftarrow \operatorname{sat}\!\left(v_d,\ \pm V_{max}\right),\qquad v_q \leftarrow \operatorname{sat}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

SVPWM is implemented as min-max zero-sequence injection, which is mathematically identical to the 7-segment form:

$$v_{a,b,c} = \text{invClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
