# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #44 specification, so this design states its assumptions explicitly. Every parameter is a named constant you can replace with your hardware values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz, FPU, center-aligned TIM1/TIM8 PWM |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MT6701) per axis |
| IMUs | 2 × ICM-42688-P on camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematic order | Base → Yaw → Roll → Pitch → Camera |

| Loop | Rate | Feedback | Bandwidth target |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | Phase shunts | ω_c ≈ 2π·1500 rad/s |
| Velocity (PI + cogging FF) | 4 kHz | Fused gyro rate projected onto joint | ω_v ≈ 2π·80 rad/s |
| Angle (P + rate FF) | 1 kHz | Fused attitude | ω_θ ≈ 2π·12 rad/s |
| IMU fusion | 8 kHz in, 4 kHz out | 2 × ICM-42688-P | — |

The bandwidths are separated by at least 5× between successive loops (ω_c/ω_v ≈ 19, ω_v/ω_θ ≈ 6.7). This lets each inner loop be approximated as unity gain in the design of the loop outside it.

## 1. Field-Oriented Control Equations

### 1.1 Clarke Transform
This uses the amplitude-invariant form with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.2 Park Transform
θ_e = p·θ_m − θ_offset is the electrical angle.

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.4 Current PI Controller with Decoupling and Back-EMF Feedforward

**Gain design.** Pole-zero cancellation of the RL plant 1/(Ls+R) gives a first-order closed loop with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

**Controller.** With e_q = i_q* − i_q:

$$v_q^{*} = K_{p,i}e_q + K_{i,i}\!\int e_q\,dt + \underbrace{\omega_e L i_d + \omega_e\lambda_m}_{\text{decoupling + BEMF}}$$

$$v_d^{*} = K_{p,i}e_d + K_{i,i}\!\int e_d\,dt - \omega_e L i_q$$

The d-axis reference is i_d* = 0, since gimbal motors use no field weakening.

**Voltage limit.** The output vector is limited to the linear SVPWM region:

$$\sqrt{v_d^2+v_q^2} \le \frac{V_{bus}}{\sqrt3}$$

The d axis gets priority, and the q axis receives the remaining headroom.

**Discretization rule.** The sampling period T_s = 50 µs must satisfy ω_c·T_s ≪ 1. Here ω_c·T_s = 0.47. Forward-Euler integration is acceptable at this ratio. Add 1.5·T_s of delay compensation to θ_e in the inverse Park transform.
