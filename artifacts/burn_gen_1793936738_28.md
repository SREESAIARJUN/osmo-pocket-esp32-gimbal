## 0. Architecture Decision (Read First)

ArduPilot does **not** run motor commutation. The H743 cannot drive the 24 MOSFETs directly under ArduPilot, so the correct partition is:

```
┌──────────────────────────┐   4× DShot600 bidir   ┌──────────────────────────┐
│ STM32H743VIT6 (ArduPilot)│ ────────────────────► │ 4× ESC MCU (AM32 / BLHeli│
│ IMU, baro, OSD, UARTs    │ ◄──── eRPM (GCR) ──── │ e.g. AT32F421K8U7)       │
└──────────────────────────┘                       │ 4× FD6288Q gate driver   │
                                                   │ 24× 40 V N-MOSFET        │
                                                   └──────────────────────────┘
```

**Design basis (assumptions):**

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (22.2 V nominal) |
| Burst phase current | 80 A per channel, all four channels simultaneously (worst case) |
| PWM frequency | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal |
| Form factor | 30.5 × 30.5 mm mounting, 8-layer, 2 oz copper on all layers |
| MOSFET (representative 40 V PDFN3.3×3.3) | R_ds(on),25 = 1.0 mΩ @ V_gs = 10 V; Q_g = 40 nC; Q_gd = 8 nC; Q_gs2 ≈ 4 nC; Q_rr ≈ 50 nC; C_oss ≈ 1.5 nF; R_θJC ≈ 1.5 K/W; V_SD ≈ 0.8 V |

**Feasibility flag.** 80 A × 4 on a nano/30 mm board is only achievable as a **short burst of roughly 2–4 s**. It is not a continuous rating. Section 3 proves this.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)],\qquad \alpha \approx 0.005\text{ K}^{-1}$$

At T_j = 125 °C: R_ds = 1.0 × 1.5 = **1.5 mΩ**.

### 1.2 Current Path in 6-Step Complementary PWM

In every commutation sector, exactly two phase legs carry current:

- **PWM leg:** the high-side FET conducts for duty D. The low-side FET (synchronous rectifier) conducts for 1 − D.
- **Return leg:** the low-side FET is on for the whole sector.

At any instant, therefore, the current passes through **exactly two MOSFET channels**. This holds regardless of D (dead-time is neglected here and handled in §2).

Including inductor ripple (Δi peak-to-peak, ripple ratio r = Δi/I):

$$I_{rms}^2 = I^2\left(1 + \frac{r^2}{12}\right)$$

The total conduction loss per channel is:

$$P_{cond,ch} = 2\,I^2\left(1+\frac{r^2}{12}\right) R_{ds}(T_j)$$

With I = 80 A, r = 0.2, and R = 1.5 mΩ:

$$P_{cond,ch} = 2 \times 6400 \times 1.0033 \times 1.5\times10^{-3} = \mathbf{19.3\ W}$$

### 1.3 Per-FET Distribution

Over one electrical revolution, each of the six FETs carries the current for, on average, 1/3 of the time:

$$P_{cond,FET} = \frac{P_{cond,ch}}{6}\times 2 \cdot \frac{1}{2}\ \Rightarrow\ \frac{I^2 R}{3} \approx \mathbf{3.2\ W}$$

### 1.4 PCB Copper Loss

The phase/bus copper path is about 0.4–0.6 mΩ per channel. Extract the exact figure from layout with a DC-IR tool.

$$P_{Cu,ch} = I^2 R_{Cu} = 6400 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W}$$
