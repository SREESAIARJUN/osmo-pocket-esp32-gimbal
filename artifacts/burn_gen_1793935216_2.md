# 3-Axis Gimbal Control: FOC Cascade, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #22 specification, so this design states its assumptions explicitly. Every parameter is collected in one config struct, so you can substitute your real motor and board values.

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7 with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R≈5 Ω, L≈2 mH, Kt≈0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each joint |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted on the camera plate |
| Bus | 12–16 V, center-aligned PWM at 20 kHz |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz, in the ADC ISR | ω_c ≈ 2π·1.5 kHz |
| IMU sample + filtering | 8 kHz (ODR) | — |
| Rate (velocity) PI | 4 kHz | ω_v ≈ 2π·60 Hz |
| Attitude (angle) P/PI | 1 kHz | ω_p ≈ 2π·12 Hz |

Separating each loop's bandwidth by a factor of 4–5 or more lets each inner loop be treated as unity gain when you design the loop outside it.

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$
