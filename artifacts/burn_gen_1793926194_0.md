## 1. Field-Oriented Control (Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is the encoder offset at which the d-axis aligns with phase A. Measure it once by injecting V_d with θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant)

With $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Motor model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q \quad (\text{SPM},\ L_d = L_q)$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation. With target bandwidth ω_c, the plant $1/(Ls+R)$ gives:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{pwm}/20$, i.e. ≈ 2π·1 kHz at 20 kHz PWM. This keeps the 1.5·Ts transport delay below about 25° phase loss.

Control law:

$$v_d^* = \mathrm{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

Voltage limiting uses a circular limit with q-axis priority, with $V_{max} = V_{dc}/\sqrt3$:

$$v_d \leftarrow \mathrm{sat}(v_d, \pm V_{max}),\qquad v_q \leftarrow \mathrm{sat}\!\left(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

**Gimbal-motor note.** At R ≈ 10 Ω and L ≈ 2 mH, the electrical pole is R/L ≈ 800 Hz. Voltage-mode control ($v_q = R\,i_q^* + \omega_e\lambda_m$) is a legitimate fallback if current sensing is poor. The code supports both modes.
