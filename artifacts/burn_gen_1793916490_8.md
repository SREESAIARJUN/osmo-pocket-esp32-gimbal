# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

**Assumptions.** I don't have the Job #12 spec sheet, so the parameters below are typical for a camera gimbal and are isolated in config structs. Replace them with your measured values:

- **Motors:** GBM2804-class motors, 12N14P (7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH.
- **Encoder:** AS5048A, 14-bit, per axis.
- **IMUs:** two ICM-42688-P on the camera plate.
- **Base vibration:** from a multirotor (props at roughly 80–250 Hz).

## 1. Loop Architecture and Rates

| Loop | Rate | Bandwidth target | Feedback |
|---|---|---|---|
| Current (d/q PI) | 20 kHz (PWM-synchronous ADC ISR) | ω_c ≈ 2π·1500 rad/s | Phase currents |
| IMU acquisition + filtering | 8 kHz (ODR) | n/a | 2× ICM-42688-P via SPI/DMA |
| Velocity PI + anti-cogging FF | 4 kHz | ω_v ≈ 2π·60 rad/s | Fused gyro (inertial rate) |
| Angle P(I) | 1 kHz | ω_θ ≈ 2π·12 rad/s | Attitude estimator |

Each loop runs at least 5× slower in bandwidth than the loop inside it. This lets each inner loop be modeled as unity gain from the outer loop's point of view.

```
θ_ref ─►[Angle PI]─ω_ref─►(+ω_ff)─►[Velocity PI]─i_q,pi─►(+i_q,cog)─►[Current PI d/q]─►[SVPWM]─►Motor
            ▲                           ▲                                   ▲
       attitude (Mahony)          fused gyro (notched)                 i_abc, θ_e (encoder)
```

## 2. FOC Current Loop Equations

**Electrical angle (encoder offset θ₀ found at calibration):**

  θ_e = p·(θ_m − θ₀) mod 2π

**Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):**

  i_α = i_a
  i_β = (i_a + 2·i_b)/√3

**Park transform:**

  i_d = i_α·cosθ_e + i_β·sinθ_e
  i_q = −i_α·sinθ_e + i_β·cosθ_e

**PMSM model in the dq frame:**

  v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
  v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + λ_m)
  τ = (3/2)·p·λ_m·i_q = K_t·i_q

**PI with decoupling.** Pole-zero cancellation of the R/L plant gives:

  K_p,c = L·ω_c
  K_i,c = R·ω_c

The decoupling and back-EMF feedforward terms are added to the PI outputs:

  v_d* = PI_d(e_d) − ω_e·L·i_q
  v_q* = PI_q(e_q) + ω_e·(L·i_d + λ_m)

**Voltage limit (circular, with d-axis priority):**

  |v_d| ≤ V_max
  |v_q| ≤ √(V_max² − v_d²)
  V_max = V_bus/√3

**Inverse Park:**

  v_α = v_d·cosθ_e − v_q·sinθ_e
  v_β = v_d·sinθ_e + v_q·cosθ_e

**Inverse Clarke:**

  v_a = v_α
  v_b = −½·v_α + (√3/2)·v_β
  v_c = −½·v_α − (√3/2)·v_β
