## 1. System Architecture and Timing

| Loop | Rate | Input → Output |
|---|---|---|
| Current (FOC) | 20 kHz | i_q\*, θ_e → PWM duty |
| Velocity | 4 kHz | ω\* → i_q\* (+ cogging FF) |
| Angle | 1 kHz | θ\* → ω\* |
| IMU sampling | 8 kHz ODR (both IMUs) | gyro and accel → fused body rate |
| Attitude estimate | 1 kHz | fused IMU → camera attitude |

**Loop placement:**
- The velocity loop closes on the **IMU gyro**, which gives inertial stabilization.
- The current loop closes on the **encoder**, which provides commutation.
- The angle loop closes on the **attitude estimate**.

**Bandwidth separation:** each loop should be at least 4–5× faster than the loop it serves:

$$\omega_{c,i} \gtrsim 5\,\omega_{c,v} \gtrsim 25\,\omega_{c,\theta}$$

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, using electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant (PMSM in the dq frame)

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

### 2.3 Current PI with decoupling

**Gain selection (pole–zero cancellation).** Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

A good starting point is ω_ci ≈ 2π·1.5 kHz at f_s = 20 kHz.

**Control law with feedforward decoupling.** The cross-coupling and back-EMF terms are cancelled by feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)$$

The d-axis reference is i_d\* = 0 (surface PMSM, no field weakening).

**Voltage limiting.** The voltage vector is limited to the linear SVPWM region:

$$\sqrt{v_d^2+v_q^2}\le V_{bus}/\sqrt3$$

The d-axis gets priority, and the q-axis receives the remaining headroom.

### 2.4 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c} = \text{inverse Clarke}(v_\alpha, v_\beta)$$

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 2.5 Voltage-mode fallback (no current sensing)

Gimbal motors often have high resistance (around 10 Ω). Without current sensing, use the steady-state model:

$$v_q^* = R\,i_q^* + \omega_e\lambda_m$$

## 3. Cascaded Velocity / Angle Control

### 3.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{d}$$

The torque constant is:

$$K_t = \tfrac32 p\lambda_m$$

### 3.2 Velocity loop: PI + acceleration feedforward + cogging feedforward

$$i_q^* = \underbrace{K_{p,v}e_\omega + K_{i,v}\!\int e_\omega}_{u_{fb}} + \underbrace{\frac{J\dot\omega^*}{K_t}}_{\text{accel FF}} + \underbrace{\hat i_{cog}(\theta_m)}_{\text{§4}}$$

The velocity error is e_ω = ω\* − ω̂, where ω̂ is the fused gyro rate projected onto the motor axis.

**Gain selection** (symmetric-optimum style, with ω_cv ≈ ω_ci / 5):

$$K_{p,v}=\frac{J\,\omega_{cv}}{K_t},\qquad K_{i,v}=K_{p,v}\frac{\omega_{cv}}{4}$$

### 3.3 Angle loop: P (+ small I) + rate feedforward

$$\omega^* = K_{p,\theta}\,\mathrm{wrap}(\theta^*-\hat\theta) + K_{i,\theta}\!\int e_\theta + \dot\theta^*$$

The angle bandwidth is K_p,θ = ω_cθ ≈ ω_cv / 5. The wrap function maps the error to (−π, π].
