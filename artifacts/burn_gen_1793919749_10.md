# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #48 spec sheet, so this design uses the **typical-gimbal assumptions** below. Every value marked `cfg` is a parameter you should replace with your hardware's numbers.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs *p* = 7), *R* ≈ 5–15 Ω, *L* ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic
