# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

**Scope note.** I have no specification for "Job #0", so this design rests on stated assumptions. Every numeric value marked **[ASSUME]** must be replaced with your measured motor and IMU parameters before the gains mean anything.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kv ≈ 22 rpm/V **[ASSUME]** |
| Encoder | 14-bit magnetic (MA730/AS5048 class) via SPI, read every current-loop tick |
| Current sensing | 2-shunt, in-line or low-side, synchronized to PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, shared CLKIN |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude 1 kHz, IMU ODR 8 kHz |
| Bus voltage | 12 V |
