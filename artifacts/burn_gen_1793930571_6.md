# Job #42: 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

I don't have the Job #42 spec sheet, so this design rests on the assumptions in §0. Every gain is derived symbolically, so you can substitute your real motor and inertia numbers. The register values are written from memory of ICM-42688-P datasheet DS-000347. **Verify them against your datasheet revision before flashing.**

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (MT6701/AS5047) on each axis |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM, synchronized ADC |
| IMU A ("cam") | ICM-42688-P on the camera plate. Used for feedback. |
| IMU B ("base") | ICM-42688-P on the handle or base. Used as the vibration reference and for feedforward. |
| IMU sync | Both IMUs clocked from the MCU via CLKIN (32 kHz), ODR 8 kHz, read via FIFO or DMA |

**Loop rates and bandwidths.** Keep at least a 5–10× bandwidth separation between nested loops.

```
 20 kHz  : current (FOC) loop          ω_c ≈ 2π·1500 rad/s
  8 kHz  : IMU sampling, notch/ANC filters, encoder PLL
  4 kHz  : rate (velocity) loop        ω_v ≈ 2π·150 rad/s
  1 kHz  : attitude (angle) loop       ω_θ ≈ 2π·20  rad/s
  1 kHz  : Mahony attitude estimator
 ~100 Hz : cogging-table LMS adaptation (gated)
```
