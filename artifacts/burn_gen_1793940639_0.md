## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Clarke** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Decoupling (Pole-Zero Cancellation)

The plant per axis is G_i(s) = 1/(Ls + R). Choose a PI controller C(s) = K_p + K_i/s with K_i/K_p = R/L. The zero then cancels the electrical pole, and the closed loop becomes first order at bandwidth ω_c:

$$\boxed{K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c}\qquad\Rightarrow\qquad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

With ω_c = 2π·1500: K_p = 19.8 V/A and K_i = 52,780 V/(A·s). Keep ω_c ≤ ω_PWM/10 to respect the sampling delay.

**Decoupling feed-forward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limiting:** the dq voltage vector is circularly limited to |v| ≤ V_dc/√3, which is the SVPWM linear range. Priority goes to v_d. The PI controllers use **back-calculation anti-windup** with gain K_aw = 1/K_p:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat})$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12[\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)]$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM and is branch-light.

## 2. Cascaded Angle / Velocity Control

A gimbal stabilizes the **camera's inertial attitude**, not the motor shaft angle. The signals are therefore split by role:

- **Encoder** → commutation (θ_e) only, plus a fallback velocity estimate.
- **Fused gyro** → velocity loop feedback, measured in the joint axis after kinematic projection.
- **Attitude estimator** → angle loop feedback.

### 2.1 Plant (Per Axis, Rigid-Body Approximation)

$$J\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Since the current loop is ≈1 at velocity-loop frequencies:

$$G_\omega(s) = \frac{K_t}{Js + b}\approx\frac{K_t}{Js}$$
