# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

**Scope and assumptions.** I don't have the Job #14 specification, so I've stated every assumption below. Each value is a parameter in the code. Change the values in `config.hpp`, and all gains are recomputed from the plant model.

| Item | Assumption |
|---|---|
| MCU | STM32G4 / Cortex-M4F @ 170 MHz, single-precision FPU |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.2 mH, K_t ≈ 0.09 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A-class), one per joint |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Loop rates | Current 20 kHz · Velocity/rate 4 kHz · Attitude 1 kHz · Cogging LMS 4 kHz |

## 1. Field-Oriented Current Loop (innermost, 20 kHz)

### 1.1 Transforms
With electrical angle θₑ = p·θₘ − θ_offset:

**Clarke (amplitude-invariant):**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose. Space-vector PWM uses min-max (zero-sequence) injection:
$$v_{0} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.2 Plant and pole-zero-cancelling PI
In the dq frame, each axis is $G_i(s) = \dfrac{1}{Ls+R}$. The cross-coupling is $\mp\omega_e L i_{q/d}$, and the back-EMF is $\omega_e\lambda_m$ (decoupled by feedforward).

Choose PI $C_i(s) = K_p + K_i/s$ with zero at $R/L$:
$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}\;\Rightarrow\; T_i(s)=\frac{\omega_{ci}}{s+\omega_{ci}}$$

Choose $\omega_{ci} = 2\pi f_{ci}$ with $f_{ci} \le f_{pwm}/20$. With 1.5-sample transport delay (computation plus PWM), the phase margin is
$$\text{PM} = 90^\circ - \omega_{ci}\cdot 1.5T_s\cdot\tfrac{180}{\pi}.$$
At f_ci = 1 kHz and T_s = 50 µs, PM ≈ 63°.
