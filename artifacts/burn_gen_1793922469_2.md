# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #45): System Architecture Package

**Scope:** 80 A burst thermal and conduction model, 48 kHz switching losses, ArduPilot bidirectional DShot600 timer/DMA plan, and reference netlists.

**Assumptions:** No MOSFET part number, stack-up or enclosure was specified, so every number below comes from stated parametric assumptions (§0). The equations are general. Replace the parameters with your selected datasheet values and the results scale directly.

**Why 3.3×3.3 packages:** 24 FETs × 5×6 mm (~30 mm² each) needs about 720 mm². That exceeds the entire 20×20 board area. A 3.3×3.3 package (~11 mm²) uses about 260 mm², which is the only realistic option. The cost is roughly 1.5× higher R_DS(on) than 5×6 parts.
