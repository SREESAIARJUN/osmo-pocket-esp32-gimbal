# STM32H743 AIO Nano FC with 4-in-1 ESC (Job #31): Power Stage, Thermal and Bi-Directional DShot Architecture

> **Assumptions.** I don't have a Job #31 spec package, so this design uses the representative parameters listed in §0. Every equation is written symbolically so you can substitute your actual MOSFET datasheet values. Treat all numeric results as **design-envelope estimates**, not qualification data. Validate them with thermocouple and IR measurements on a prototype.

---

## 0. System Definition and Assumed Parameters

**Architecture.** In an AIO "4-in-1 ESC FC", the H743 does not commutate the motors. It runs ArduPilot and sends bi-directional DShot600 to four ESC MCUs (assumed AT32F421 running AM32). Each ESC MCU drives a 3-phase gate driver and a 6-FET bridge at 48 kHz PWM.
