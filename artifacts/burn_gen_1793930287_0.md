# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model (Job #18)

## 0. Scope and Assumptions

The STM32H743 does not drive MOSFETs directly. Each ESC channel uses a dedicated ESC MCU running AM32 or BLHeli_32. The H743 runs ArduPilot and sends bidirectional DShot600 to the ESC MCUs. The models below follow that architecture.

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | 40 V FETs give 1.6× margin |
| Burst current | 80 A per channel, ≤ 5 s | Continuous rating derived in §3 |
| PWM frequency | 48 kHz, complementary (synchronous) | AM32-style |
| MOSFET (reference) | 40 V, R_DS(on) = 1.0 mΩ typ / 1.3 mΩ max @ 25 °C, Q_g = 50 nC, Q_rr = 40 nC, C_oss(tr) ≈ 1.5 nF, V_SD = 0.8 V | 5×6 DFN class |
| Gate driver | 3-phase half-bridge driver with bootstrap (FD6288Q class), I_src/I_sink ≈ 1.5 A / 1.8 A | One per channel |
| ESC MCU | AT32F421 or STM32G071, one per channel | Runs AM32 |
| Board | 30.5 × 30.5 mm mounting, 8-layer, 2 oz on all layers | |

Two flags before going further:
- **The 80 A burst is a transient rating only.** §3 shows it is not sustainable on a board this size. Four channels at 80 A means about 320 A from the pack, which also stresses the XT60 and battery leads.
- **Verify all part-specific numbers against the selected datasheets before layout freeze.**

## 1. Conduction Loss Model

### 1.1 Current path

Six-step trapezoidal commutation with synchronous rectification works as follows:
- **ON interval (duty D):** high-side FET of phase A and low-side FET of phase B conduct.
- **OFF interval (1 − D):** low-side FET of phase A (synchronous freewheel) and low-side FET of phase B conduct.

So exactly two FETs carry the phase current I_ph at every instant (dead time excluded):

$$P_{cond,ch} = I_{ph}^2 \cdot R_{DS,hot}\,[D + (1-D)] + I_{ph}^2 R_{DS,hot} = 2\,I_{ph}^2\,R_{DS,hot}$$

### 1.2 Temperature correction

$$R_{DS,hot} = R_{DS,25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 110 °C with the max datasheet value: R_DS,hot = 1.3 mΩ × 1.51 ≈ **1.96 mΩ**.

### 1.3 PCB copper loss

Phase and bus path length is about 25 mm on 3 layers of 2 oz copper (70 µm), with a 4 mm effective width.

$$R_{Cu} = \frac{\rho L}{w\,t\,n} = \frac{1.72\times10^{-8}\cdot 0.025}{0.004\cdot 70\times10^{-6}\cdot 3}\approx 0.51\ \text{m}\Omega\ (25\,°\text{C}) \rightarrow \approx 0.65\ \text{m}\Omega\ \text{hot}$$

### 1.4 Results at 80 A

| Term | Expression | Value |
|---|---|---|
| FET conduction | 2 · 80² · 1.96 mΩ | **25.1 W** |
| Copper (phase in + out) | 80² · 0.65 mΩ | 4.2 W |
| **Per channel** | | **≈ 29.3 W** |

## 2. Switching Loss Model at 48 kHz

Per channel, only one leg is PWM-switching at a time, so the switching events per period are one turn-on plus one turn-off of the hard-switched FET.

### 2.1 V–I overlap loss

Transition time: t ≈ Q_sw / I_g. With Q_gd + Q_gs2 ≈ 18 nC, a 1.5 A driver, and gate resistance, t_r ≈ t_f ≈ 20 ns.

$$P_{VI} = \tfrac{1}{2} V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot40\text{ns}\cdot48\text{k} = 1.94\ \text{W}$$

### 2.2 Reverse recovery

The body diode conducts during dead time, then recovers:

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ \text{W}$$

The resulting Q_rr ringing matters more for EMI than for loss.

### 2.3 Output capacitance

$$P_{oss} = \tfrac{1}{2} C_{oss} V^2 f = 0.5\cdot1.5\text{n}\cdot635\cdot48\text{k} = 0.023\ \text{W}$$

### 2.4 Dead-time diode conduction

With dead time t_dt = 200 ns:

$$P_{dt} = V_{SD} I_{ph}\cdot 2 t_{dt}\cdot f = 0.8\cdot80\cdot400\text{ns}\cdot48\text{k} = 1.23\ \text{W}$$

This term is a strong argument for tuning dead time down. At 100 ns it halves to 0.61 W.

### 2.5 Gate drive

This loss is dissipated in the driver and gate resistors, not in the FETs:

$$P_g = 2\,Q_g V_{GS} f = 2\cdot50\text{n}\cdot10\cdot48\text{k} = 0.048\ \text{W}$$

### 2.6 Switching total

| Term | W |
|---|---|
| V–I overlap | 1.94 |
| Q_rr | 0.05 |
| C_oss | 0.02 |
| Dead time | 1.23 |
| Gate | 0.05 |
| **Σ switching** | **≈ 3.3 W** |

### 2.7 Totals at 80 A burst

| Scope | Calculation | Loss |
|---|---|---|
| Per channel | 29.3 + 3.3 | **≈ 32.6 W** |
| 4 channels, simultaneous burst | | **≈ 130 W** |

Efficiency check: P_out per channel ≈ 25.2 V × 80 A × D. At D ≈ 0.9 this is about 1.8 kW, giving η ≈ 98.2%. That is a plausible figure.
