**Architectural correction.** The H743 does not commutate the ESC FETs in ArduPilot. The standard architecture is:

- **STM32H743 (ArduPilot):** generates DShot600 and receives bidirectional eRPM telemetry.
- **4× ESC MCUs (AT32F421 / STM32G071, AM32 firmware):** each runs 48 kHz PWM, commutation, and BEMF sensing for one motor.

The model below follows that split.

**Feasibility warning (stated up front):** 4×80 A simultaneous on a nano-footprint board is a few-second burst rating at best. This is quantified in §3.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

| T_j (°C) | Multiplier | R_DS (mΩ) |
|---|---|---|
| 25 | 1.00 | 1.80 |
| 80 | 1.33 | 2.39 |
| 110 | 1.51 | 2.72 |
| 125 | 1.60 | 2.88 |

### 1.2 RMS phase current including PWM ripple

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} = \frac{25.2\times0.25}{20\,\mu H\times48\,kHz} = 6.56\ \text{A (worst case, } D=0.5)$$

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

Ripple contributes only 0.06%, so it can be ignored at 80 A.

### 1.3 Conduction path

With complementary 6-step drive, two phase legs are always active. Each active leg has exactly one FET conducting (HS or LS, the other being in its complementary state). There are therefore always **2 R_DS in series** with the motor current:

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{DS}(T_j)$$

At T_j = 110 °C:

$$P_{cond,ch} = 2\times6404\times2.72\,\text{m}\Omega = \mathbf{34.8\ W\ per\ channel}$$
