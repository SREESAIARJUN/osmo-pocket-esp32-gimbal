## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying a d-axis voltage at θ_e = 0 and reading θ_m.

### 1.2 Clarke transform (amplitude-invariant, balanced 3-phase, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant and PI design (pole-zero cancellation)
The motor dynamics in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With PI controller $C(s)=K_p + K_i/s$ and the choices
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,$$
the closed loop becomes the first-order system $\omega_c/(s+\omega_c)$.

- Choose $\omega_c \le 2\pi f_{pwm}/20$. For 20 kHz this gives ω_c ≈ 2π·1000 rad/s.
- Feed-forward decoupling:
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m),\qquad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$$

### 1.5 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The voltage vector is limited to the inscribed circle:
$$|v_{dq}| \le V_{bus}/\sqrt3$$
The d-axis has priority, and the q-axis gets the remainder:
$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant
$$J\dot\omega = K_t\,i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Because the current loop is about 5× faster than the velocity loop, it can be treated as unity gain with lag $1/\omega_c$.

### 2.2 Velocity PI (symmetric-optimum)
$$i_q^* = K_{p,v}\,e_\omega + K_{i,v}\int e_\omega\,dt + i_q^{ff},\qquad e_\omega = \omega^* - \hat\omega$$

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = \frac{K_{p,v}\,\omega_v}{a^2},\qquad a = 2..4,\qquad \omega_v \le \omega_c/5$$

**Anti-windup (back-calculation):**
$$\dot I = K_{i,v}\,e_\omega + K_{aw}\,(i_q^{sat} - i_q^{unsat}),\qquad K_{aw} = 1/K_{p,v}$$

### 2.3 Velocity estimation (encoder PLL)
A raw encoder derivative is too noisy. Use a 2nd-order tracking PLL instead:

$$e_\theta = \text{wrap}(\theta_{enc} - \hat\theta)$$
$$\hat\omega \mathrel{+}= T\,K_{i,pll}\,e_\theta$$
$$\hat\theta \mathrel{+}= T(\hat\omega + K_{p,pll}\,e_\theta)$$

Design values: $K_{p,pll}=2\zeta\omega_{pll}$, $K_{i,pll}=\omega_{pll}^2$, with ζ = 1 and ω_pll ≈ 2π·400 rad/s.
