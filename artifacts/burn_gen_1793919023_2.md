# STM32H743 Nano FC + 80A 4-in-1 ESC (Job #55): Design Model

## 0. Architecture and Assumptions

The H743 cannot drive the bridges directly. A production "H743 4-in-1" is an FC + ESC stack (or a single board with two domains):

| Domain | Device | Role |
|---|---|---|
| FC | STM32H743VIT6 @ 400 MHz | ArduPilot, generates DShot600 and decodes bidir eRPM |
| ESC ×4 | STM32G071 or AT32F421 running AM32 (or BLHeli_32) | 6-step commutation, 48 kHz PWM, eRPM GCR reply |
| Gate drive ×4 | FD6288Q (3-phase half-bridge, 10–12 V bootstrap) | |
| Power stage | 24× 40 V N-MOSFET, DFN3.3×3.3 class | |

**Electrical assumptions** (substitute your BOM values):

| Parameter | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S, fully charged |
| R_ds(on) | 1.4 mΩ typ at 25 °C, V_gs = 10 V | |
| R_ds(on) hot | 2.1 mΩ | k_T ≈ 1.5 at T_j ≈ 110 °C |
| t_r + t_f | 20 ns | 1 A-class driver, R_g = 3.3 Ω |
| Q_g | 30 nC | |
| Q_rr | 40 nC | |
| V_f (body diode) | 0.8 V | |
| C_oss(er) | 1.5 nF | |
| Dead time t_dt | 100 ns per edge | |
| f_sw | 48 kHz | Complementary (synchronous) PWM |

**Definition of "80 A burst":** 80 A per ESC channel, the industry convention. All four channels at 80 A gives the worst case of 320 A.

## 1. Conduction Loss Model

In 6-step commutation with synchronous rectification, phase current always flows through exactly two MOSFET channels at a time:

- one high-side (or its LS complement during off-time), and
- one low-side return.

So per channel:

$$P_{cond,ch} = I_{rms}^2 \cdot 2\,R_{ds(on)}(T_j)$$

$$R_{ds(on)}(T_j) = R_{25}\,\big[1 + \alpha (T_j - 25)\big],\quad \alpha \approx 0.006/\text{K}$$

**Ripple correction.** Motor current ripple adds to the RMS value:

$$I_{rms} = \sqrt{I_{dc}^2 + \tfrac{\Delta I^2}{12}}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph\text{-}ph}\,f_{sw}}$$

With L = 15 µH (typical 2207–2810 motor) and D = 0.5:

- ΔI = 25.2·0.25 / (15µ·48k) = **8.75 A**
- I_rms = √(80² + 6.4) ≈ 80.04 A, so ripple is negligible at 48 kHz.

**Result per channel (80 A, hot):**

- P_cond = 80² × 2 × 2.1 mΩ = **26.9 W**
- That is 13.4 W per conducting FET.

**Commutation sharing.** Each FET conducts for 1/3 of the electrical cycle, but at burst timescales the hot pair dominates the junction temperature. Use 13.4 W per FET for junction calculations.

## 2. Switching Loss Model (48 kHz)

Only the actively PWM'd FET hard-switches. The complementary FET switches with ZVS after dead time.

| Term | Formula | Value @ 80 A |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·20n·48k = **0.97 W** |
| Dead-time diode | V_f·I·2t_dt·f_sw | 0.8·80·200n·48k = **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw | 40n·25.2·48k = **0.05 W** |
| C_oss | ½·C_oss·V²·f_sw | 0.5·1.5n·635·48k = **0.02 W** |
| Gate (driver side) | Q_g·V_gs·f_sw·2 | 30n·10·48k·2 = **0.03 W** |
| **Total P_sw per channel** | | **≈ 1.68 W** |

**Totals:**

- P_ch = 26.9 + 1.68 ≈ **28.6 W per channel**
- P_total (4 × 80 A) ≈ **114 W**
- Add PCB copper loss, about 3–6 W at 320 A for 2 oz × 8 L power planes.
- **Total ≈ 120 W.** Efficiency at 320 A × 25.2 V (8.06 kW) is ≈ 98.5%.

Conduction is 94% of the loss. Lowering f_sw to 24 kHz saves only about 0.8 W per channel. **Spend design effort on R_ds(on) and copper, not frequency.**

## 3. Thermal Model

### 3.1 Steady-state junction rise above local copper (per hot FET)

| Element | R_th |
|---|---|
| Junction-to-case (pad), DFN3.3 | 1.2 K/W |
| Solder + via array (≥12 vias, 0.3 mm, filled) | 0.8 K/W |
| Local spreading in 2 oz planes | 1.0 K/W |
| **Total junction → board bulk** | **3.0 K/W** |

The hot FET carries 13.4 + ~1 W (switching) = 14.4 W, so **ΔT_jb ≈ 43 K**.

### 3.2 Board thermal mass (30.5 × 30.5 mm ESC, 8 L, 2 oz)

- **Copper:** 9.3 cm² × 8 × 70 µm = 0.52 cm³, giving 4.65 g and **1.79 J/K**
- **FR4:** ≈ 0.95 cm³, giving 1.76 g and **1.94 J/K**
- **FETs, solder, components:** ≈ **0.6 J/K**
- **C_th ≈ 4.3 J/K**

### 3.3 Convective sink

In prop wash, h ≈ 60 W/m²K. Two sides of 9.3 cm² gives R_conv ≈ 9 K/W, so τ = R·C ≈ 39 s.

### 3.4 Burst-duration limit

$$T_{board}(t) = T_a + P R_{conv}\,(1 - e^{-t/\tau})$$

$$T_j = T_{board} + 43\ \text{K}$$

**Constraints:**

- T_j,max = 150 °C, derated to 140 °C for margin
- T_a = 40 °C
- The board may therefore rise 57 K.

**Solve:** 120 × 9 × (1 − e^(−t/39)) = 57, so 1 − e^(−t/39) = 0.0528, giving **t ≈ 2.1 s**. The initial adiabatic slope is 120/4.3 ≈ **28 K/s**.

| Load (all 4 ch) | P_total | Max burst (T_a 40 °C) |
|---|---|---|
| 80 A | 120 W | **~2 s** |
| 60 A | 68 W | ~5.5 s |
| 45 A | 39 W | continuous only if R_conv < 7.5 K/W |
| 35 A | 24 W | Continuous |

**Conclusion:** "80 A burst" is honest only as a ≤2 s, single-event rating. Continuous rating is about **35–40 A per channel**. Firmware should implement an I²t limiter using the model above, with AM32 temperature/current protection or the ArduPilot `BATT_` current limit.

### 3.5 Bulk capacitor ripple

- Per channel: I_cap,rms = I·√(D(1−D)) = 40 A at D = 0.5.
- Four uncorrelated channels: ≈ 80 A rms worst case.
- On-board ceramics: 8× 10 µF 50 V X7R 1206. After DC bias ≈ 25 µF effective.
- External: 1000 µF 35 V low-ESR electrolytic at the XT60 is mandatory. Without it, voltage spikes exceed 40 V FET ratings.
