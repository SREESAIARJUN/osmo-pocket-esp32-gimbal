## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (two shunts, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_off:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM dq Model (surface magnets, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The electromagnetic torque is

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q.$$

### 1.3 PI Current Control by Pole-Zero Cancellation

Choose the current-loop bandwidth ω_c. A safe limit is ω_c ≤ 2π·f_pwm/20, giving ω_c = 2π·1 kHz. Then:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With these gains the PI zero cancels the electrical pole. The closed loop then reduces to a first-order system:

$$G_{cl}(s) = \frac{\omega_c}{s+\omega_c}$$

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

**Discretization.** Use backward-Euler on the integrator with period T_s = 1/f_pwm. Compensate the one-sample computation and PWM delay by advancing the Park angle:

$$\theta_e^{comp} = \theta_e + 1.5\,\omega_e T_s$$

### 1.4 Voltage Limiting and SVPWM

The linear-modulation limit is

$$|v_{dq}| \le V_{dc}/\sqrt3.$$

Clamp the d-axis first: v_d is clamped to ±V_max. Then

$$v_q \le \sqrt{V_{max}^2 - v_d^2}.$$

**Anti-windup.** Use back-calculation with gain K_aw = 1/K_p:

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u)$$

**SVPWM via min-max zero-sequence injection:**

$$v_{0} = -\tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically identical to sector-based SVPWM and avoids branching.
