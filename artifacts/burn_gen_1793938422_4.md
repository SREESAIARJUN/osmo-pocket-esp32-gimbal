## 1. Field-Oriented Control (Inner Loop, 20 kHz)

### 1.1 Transforms
Electrical angle from the mechanical encoder angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \mod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transpose of this matrix. Electromagnetic torque for a surface-PM machine:

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.2 Plant and Decoupled PI Current Control
The dq voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The controller uses a PI per axis plus cross-coupling and back-EMF feedforward:

$$v_d^* = K_p e_d + K_i\!\int e_d - \omega_e L i_q$$
$$v_q^* = K_p e_q + K_i\!\int e_q + \omega_e L i_d + \omega_e \lambda_m$$

Gains come from pole-zero cancellation, which yields a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}$$

For f_pwm = 20 kHz, choose ω_c = 2π·1500 rad/s, giving K_p ≈ 20.7 V/A and K_i ≈ 52.8 kV/(A·s).

Discretization uses forward Euler on the integrator. Anti-windup works in two steps:
1. The voltage vector is clamped to the linear SVPWM region, $|v| \le V_{bus}/\sqrt3$.
2. Integration is conditional: the integrator does not accumulate if the output is saturated and the error has the same sign as the output.

### 1.3 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a,v_b,v_c = \text{invClarke}(v_\alpha,v_\beta),\quad v_0 = -\tfrac12(\max + \min)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM.

### 1.4 Delay Compensation
PWM introduces about 1.5 sample periods of transport delay. Advance the angle used in the inverse Park transform accordingly:

$$\theta_e^{\text{out}} = \theta_e + 1.5\,\omega_e T_s$$
