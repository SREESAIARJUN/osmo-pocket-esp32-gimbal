## 0. Scope, Assumptions and Key Findings

**Architecture.** ArduPilot does not commutate motors directly from the H743. The only flight-proven topology is:

```
STM32H743 (ArduPilot) ──DShot600 bidirectional──► 4× ESC MCU (STM32G071 / AT32F421, AM32 firmware)
                                                   └─► 4× 3-phase gate driver ─► 24× N-MOSFET
```

The 48 kHz PWM is an AM32 ESC-side parameter. The H743 owns DShot generation, eRPM telemetry capture, and harmonic notch filtering.

**Working assumptions.** Every result below scales from these values. Replace them with your BOM datasheet values before you freeze the design.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S, fully charged (worst case for switching) |
| I_ph | 80 A | Burst phase current, **per channel** |
| R_ds(on),25 | 1.3 mΩ | 40 V N-FET, 3.3×3.3 mm package, V_gs = 10 V |
| α | 0.0045 /K | R_ds(on) temperature coefficient |
| t_r, t_f | 15 ns each | With ~2 Ω gate resistance and a 1–2 A driver |
| t_dt | 100 ns | Dead time per edge |
| V_SD | 0.8 V | Body-diode forward voltage at 80 A (hot) |
| Q_rr / Q_oss / Q_g | 40 / 30 / 40 nC | Switching charges |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz outer and inner power planes | Mechanical / stack-up |

**Key findings.**

1. "80 A" is a **1–3 second burst rating**, not a continuous rating.
2. Realistic continuous current is about **20–25 A per channel** at a 40 °C ambient in prop wash.
3. Section 3 derives both numbers.

## 1. Conduction Loss Model

### 1.1 Six-step synchronous commutation

In any commutation sector, two phases conduct:

- **Leg A (PWM leg):** the high side (HS) conducts for duty D. The low side (LS) synchronously rectifies for (1−D).
- **Leg B (return leg):** the LS is held on for the whole sector.

The current path therefore always crosses exactly two channels in series:

$$P_{cond,motor} = I_{ph}^2 \left[ 2R_{ds}(T_j) + R_{Cu,path} + R_{shunt} \right]$$

$$R_{ds}(T_j) = R_{ds,25}\left[1+\alpha (T_j-25)\right]$$

### 1.2 Numbers at T_j = 125 °C

- R_ds(125) = 1.3 mΩ × (1 + 0.0045 × 100) = **1.885 mΩ**
- FET conduction loss: 80² × 2 × 1.885 mΩ = **24.1 W per motor**
- Copper path loss (assumed 0.3 mΩ for the phase pour, vias and pad): 6400 × 0.3 mΩ = **1.9 W**
- Shunt loss: 6400 × 0.25 mΩ = **1.6 W**
  - Recommendation: use a single shared bus shunt, or none, on a nano board. Per-motor sensing via R_ds is acceptable.

**Per motor: P_cond ≈ 26–28 W. Four motors: ≈ 105–110 W.**

### 1.3 Per-FET distribution

Each FET conducts for 1/3 of the electrical cycle. Average per-FET loss is therefore about 24.1 / 6 ≈ **4.0 W**.
