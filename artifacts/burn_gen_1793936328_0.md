# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the specification for Job #50, so this design uses the **assumptions in §0**. Every gain is computed from physical parameters, so you can substitute your measured values.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A or MT6701 class) |
| Inverter | 3-phase, 3 low-side shunts, 20 kHz center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz, shared CLKIN |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates (cascade separation of at least 4–5× between loops):**

```
20 kHz  PWM ISR      : ADC → Clarke/Park → current PI (d,q) → inv. Park → SVPWM
 8 kHz  IMU DRDY ISR : read 2× ICM-42688 → align → notch/LPF → fuse
 4 kHz  velocity loop: gyro-rate PI + anti-cogging FF + gravity FF → i_q*
 1 kHz  angle loop   : quaternion error → P(+FF) → body-rate cmd → joint rates
 500 Hz attitude     : Mahony complementary filter (can also run at 1 kHz)
```

**Bandwidth targets:**

| Loop | Bandwidth | Rate |
|---|---|---|
| Current | ω_c = 2π·1500 rad/s | 20 kHz |
| Velocity | ω_v = 2π·60 rad/s | 4 kHz |
| Angle | ω_θ = 2π·12 rad/s | 1 kHz |
