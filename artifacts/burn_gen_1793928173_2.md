# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #22): System Design Package

**Scope.** This package covers the power stage electro-thermal model at an 80 A burst and the switching-loss model at 48 kHz. It also covers ArduPilot bi-directional DShot600 timer and DMA allocation, and gives a reference netlist and thermal budget.

---

## 0. Architecture Assumptions

These choices drive every number below. Change any of them and re-run the model in §1–§3.

| Parameter | Value | Note |
|---|---|---|
| Form factor | 30.5 × 30.5 mm AIO stack. FC is the STM32H743VIT6. ESC uses 4× AT32F421 running AM32. | ArduPilot does not commutate motors. Each motor channel needs its own ESC MCU. |
| Bus voltage | 6S: 22.2 V nominal, 25.2 V max | Use 25.2 V for worst-case switching loss. |
| MOSFET (per switch position) | 40 V N-channel, PDFN 5×6 / SuperSO8 class (see the parameter table in §1.1) | 24 FETs total, one per position. |
| Gate driver | 3-phase half-bridge driver, FD6288Q-class, one per motor | Bootstrap high side. |
| Commutation | 6-step trapezoidal with synchronous rectification (complementary PWM) | This is AM32 default behavior. |
| PWM frequency | f_sw = 48 kHz | |
| Burst definition | 80 A per motor, all four motors simultaneously | Worst case. §3 shows this definition is **time-limited** on a 30.5 mm board. |
