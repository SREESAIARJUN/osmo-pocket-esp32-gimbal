# STM32H743 Nano FC + 4-in-1 ESC: Design Package for Job #4

**Scope:** 80 A burst conduction losses, 48 kHz switching losses, the thermal model, ArduPilot bidirectional DShot600 timer and DMA allocation, and reference netlists.

> **Engineering caveat.** All device parameters below are worked-example values: a typical 40 V, 5×6 mm, ~0.8 mΩ MOSFET and a 6S pack. Replace each with your actual datasheet values before release. The netlists are reference topology. They are not fab-ready and need schematic capture, ERC/DRC, and bench validation. The headline result is that **a nano-format board cannot sustain 4×80 A continuously.** 80 A is a seconds-scale burst rating, and Section 3 quantifies that.

---

## 0. Architecture Clarification

The H743 does not drive the MOSFETs. ArduPilot runs on the H743 and outputs bidirectional DShot600. Each ESC channel has its own commutation MCU (for example AM32 on an STM32G071 or AT32F421). That MCU generates the 48 kHz PWM through a 3-phase gate driver.

```
6S LiPo ──┬── ESC power stage (4× [MCU + FD6288-class driver + 6 FETs]) ── motors
          │        ▲  DShot600 bidir (4 lines, 3.3 V)
          └── BEC ─┴─ STM32H743 FC (ArduPilot) ── IMU/Baro/OSD/RX/GPS
```

**Operating point:**

| Parameter | Value |
|---|---|
| V_bus | 25.2 V max (6S full), 22.2 V nominal |
| I_ph (burst) | 80 A phase current per channel |
| f_sw | 48 kHz |
| Modulation | Six-step trapezoidal, complementary (synchronous) PWM, dead time t_d = 100 ns |
