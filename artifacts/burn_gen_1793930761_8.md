# STM32H743 Nano FC + 4-in-1 ESC (Job #14): Design Model

**Scope note:** On a 4-in-1 stack, the H743 flight controller does not switch the MOSFETs. Each of the 4 ESC channels has its own MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32) that does commutation at 48 kHz. The H743 generates bidirectional DShot600 and decodes eRPM telemetry. The model is split along that boundary.

**Assumptions.** All device parameters below are representative placeholders. Replace them with values from your selected MOSFET and driver datasheets before sign-off. The equations are exact; the numbers are only as good as these inputs.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path
In 6-step drive, two phases carry current in each sector:
- **PWM leg:** the high-side FET conducts for D. With synchronous rectification, the low-side FET of the same leg conducts for (1−D).
- **Return leg:** its low-side FET conducts continuously for the sector.

So phase current always flows through exactly two channels in series, independent of D:

$$P_{cond,ch} = 2\,I^2\,R_{DS(on)}(T_j)$$

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

### 1.2 Per-FET distribution
Over one electrical revolution, each of the 6 FETs carries 1/6 of the total path-time:

$$P_{cond,FET} = \frac{2I^2R(T_j)}{6} = \frac{I^2R(T_j)}{3}$$

This average is valid only if the electrical period is much shorter than the FET thermal time constant. At low eRPM (startup or stall), one FET can carry the full current for a whole sector. Treat stall separately; see §3.4.

### 1.3 Numbers at T_j = 110 °C (R = 1.81 mΩ)

| Quantity | Value |
|---|---|
| P_cond per channel | 2 · 6400 · 1.81e-3 = **23.2 W** |
| P_cond per FET (avg) | **3.86 W** |
| 4 channels | **92.7 W** |

### 1.4 Parasitic copper loss
Add the copper loss: P_Cu = I² · R_trace. For 2 mΩ of effective trace + pad + solder path per channel:

- **12.8 W per channel**

This is often overlooked and is comparable in scale to the FET loss. Use 2 oz or heavier copper, stack parallel layers, and keep pours short.

## 2. Switching Loss Model (48 kHz)

Only the PWM leg switches. The return leg commutates at the electrical frequency, which is negligible.

| Term | Equation | Value |
|---|---|---|
| V–I overlap (HS FET) | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·20e-9·48e3 = **0.968 W** |
| Reverse recovery | Q_rr·V·f_sw | 30e-9·25.2·48e3 = **0.036 W** |
| C_oss | ½·Q_oss·V·f_sw | **0.024 W** |
| Dead-time body-diode conduction | V_f·I·2t_dt·f_sw | 0.8·80·100e-9·48e3 = **0.307 W** |
| Gate drive (2 FETs/leg; dissipated in driver + R_g) | 2·Q_g·V_drv·f_sw | **0.048 W** |
| **Total per channel** | | **≈1.38 W** |

Switching loss scales linearly with f_sw. Going from 24 to 48 kHz adds about 0.69 W per channel at 80 A, which is small next to conduction. 48 kHz is justified by lower current ripple and audible noise.

The dead-time term is the largest lever after t_r/t_f. Minimize t_dt (the AM32 dead-time setting) to the shortest value that does not cause shoot-through. Verify on the scope at V_bus,max.

### 3.2 Self-consistent steady-state junction temperature
With P(T_j) = P₂₅[1+α(T_j−25)] and junction-to-ambient resistance θ:

$$T_j = \frac{T_a + \theta P_{25}(1-25\alpha)}{1-\theta P_{25}\alpha}$$

**Thermal runaway** occurs when θ·P₂₅·α ≥ 1.

Example for one FET: P₂₅ = 80²·1.2e-3/3 = 2.56 W, α = 0.006.
