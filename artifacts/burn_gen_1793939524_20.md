# STM32H743 AIO (FC + 4-in-1 ESC): 80 A Burst Electro-Thermal, Switching, and Bidirectional DShot600 Design Package

**Assumptions.** I have no prior context for "Job #12", so this package rests on the explicit assumptions below. Every device parameter is a placeholder: replace it with datasheet values before release. The equations hold regardless of the parts chosen.

**Architecture note.** On an AIO board the STM32H743 does not commutate the motors. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (AT32F421 / STM32G071 class, AM32 or BLHeli_32), and those MCUs drive the gate drivers.
