## 0. Architecture and Assumptions

**Architecture.** The STM32H743 does not commutate the motors. A 48 kHz, 6-step BLDC power stage needs a dedicated real-time MCU per motor, and ArduPilot does not run ESC firmware. The partitioning is therefore:

```
 ┌──────────── STM32H743 (ArduPilot, 400 MHz) ─────────────┐
 │ TIM1 CH1..CH4 ── bidirectional DShot600 (1 wire/motor) ─┼──► ESC MCU ×4 (AM32 on AT32F421 / STM32G071)
 └─────────────────────────────────────────────────────────┘          │ 48 kHz complementary PWM
                                                                       ▼
                                          FD6288Q 3-ph gate driver ×4 → 6× N-MOSFET ×4 (24 FETs)
```

## 1. Conduction-Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C this gives R_DS = 1.2 × 1.55 = **1.86 mΩ**.

### 1.2 Six-step bridge with synchronous rectification

During any 60° commutation sector, phase A is PWM-ing (HS_A ↔ LS_A complementary), phase B has its low side held ON, and phase C floats (BEMF sensing). Phase current I flows through exactly two conduction paths:

- **PWM leg:** HS_A for duty D, LS_A (sync rectification) for 1−D.
- **Return leg:** LS_B for 100 % of the sector.

$$P_{cond,ch} = I^2\big[D\,R_{HS} + (1-D)R_{LS}\big] + I^2 R_{LS} \;\overset{R_{HS}=R_{LS}=R}{=}\; 2I^2R$$

The result is independent of throttle, because sync rectification removes the D-dependence. Copper is added explicitly:

$$P_{cond,ch} = I^2\,(2R_{DS}(T_j) + R_{Cu} + R_{shunt})$$

Assume R_Cu ≈ 0.4 mΩ (2 oz inner pours, 6-layer, phase-pad to bus-cap path) and R_shunt = 0
