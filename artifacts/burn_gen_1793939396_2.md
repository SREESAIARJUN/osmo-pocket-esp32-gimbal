# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage and DShot Design Model

**Scope and assumptions.** I have no access to the internal "Job #3" requirements, so I've fixed the assumptions explicitly below. Every number is a parameter you can replace with your datasheet values.

**Architecture note.** On a 4-in-1 AIO board, the STM32H743 is the flight controller. Each ESC channel has its own ESC MCU (for example AT32F421 or STM32G071 running AM32 or BLHeli_32), and that MCU generates the 48 kHz PWM. The H743 only produces DShot600 frames and decodes bidirectional eRPM replies. The math below follows that split.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery (6S, worst case full charge) | V_bus | 25.2 V |
| Burst phase current per motor | I_ph | 80 A |
| PWM frequency (ESC MCU) | f_sw | 48 kHz |
| MOSFET R_DS(on) at 25 °C, 10 V gate drive | R₂₅ | 1.2 mΩ (40 V, 5×6 mm or 3.3×3.3 mm DFN class) |
| R_DS(on) temperature coefficient | α | 0.006 /K (gives 1.6× at 125 °C) |
| Rise + fall time | t_r + t_f | 20 ns + 20 ns |
| Body-diode reverse recovery charge | Q_rr | 50 nC |
| Output capacitance | C_oss | 1.5 nF |
| Total gate charge | Q_g | 60 nC |
| Gate drive voltage | V_GS | 10 V |
| Dead time | t_d | 300 ns |
| Body-diode forward voltage | V_f | 0.8 V |
| Ambient inside the frame | T_a | 40 °C |
| Commutation scheme | — | 6-step trapezoidal, complementary (synchronous) PWM |

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation, current always flows through two series MOSFETs:
- One high-side FET of the PWM'd phase, or its low-side FET during the freewheel interval.
- One low-side FET of the return phase.

With complementary PWM, the PWM'd leg splits its conduction between the high-side (fraction D) and low-side (fraction 1−D). The total I²R is therefore independent of D.

**Channel conduction loss:**

$$P_{cond,ch} = I_{ph}^2 \cdot 2R_{DS}(T_j), \qquad R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

**Worked example at T_j = 125 °C:**

- R_DS = 1.2 mΩ × 1.6 = 1.92 mΩ
- P_cond,ch = 6400 × 3.84 mΩ = **24.6 W**

### 1.2 Hottest single FET

The return-phase low-side FET conducts 100% of its 120° interval.

**Burst case:** at full throttle (D ≈ 1), the high-side FET of the active phase is equally loaded. The hot-spot FET therefore sees:

$$P_{FET,hot} = I^2 R_{DS} = 6400 \times 1.92\text{ m}\Omega = 12.3\ \text{W}$$

This holds during its conduction interval. Thermal time constants (≥ 0.5 ms) are long compared with the commutation period at high eRPM. For burst analysis, use the conservative interval value rather than the 1/3 duty average.

### 1.3 PCB copper

Assume the phase-to-bus copper path is about 0.3 mΩ (2 oz, short pours, vias):

$$P_{Cu} = 6400 \times 0.3\text{ m}\Omega \approx 1.9\ \text{W per channel}$$

## 2. Switching Losses at 48 kHz

Only the PWM'd leg hard-switches. The terms are:

| Loss term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·40 ns·48 kHz | 1.94 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 kHz | 0.06 W |
| C_oss charge/discharge | ½·C_oss·V²·f_sw = ½·1.5 nF·635·48 kHz | 0.02 W |
| Dead-time diode conduction | 2·t_d·V_f·I·f_sw = 2·300 ns·0.8·80·48 kHz | 1.84 W |
| Gate drive (2 FETs) | 2·Q_g·V_GS·f_sw | 0.06 W (mostly in driver and R_g) |
| **Switching subtotal** | | **≈ 3.9 W** |
