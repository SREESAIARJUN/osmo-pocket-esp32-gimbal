# STM32H743 4-in-1 AIO Flight Controller (Job #8): Power-Stage, Thermal and Bidirectional DShot Architecture

## 0. Architecture Assumptions and Scope Correction

An STM32H743 running ArduPilot does not commutate motors. ArduPilot has no ESC firmware path, and the H743 lacks the time budget for four sensorless 6-step commutators alongside the flight stack. The correct partition for a "4-in-1 ESC nano FC" is:

| Block | Part (baseline) | Role |
|---|---|---|
| FC MCU | STM32H743VIH6 (TFBGA100, 400 MHz under ArduPilot) | Flight control, DShot600 master, eRPM telemetry |
| ESC MCU ×4 | AT32F421K8U7 (QFN32) running AM32 | 6-step sensorless commutation, 48 kHz complementary PWM, bidirectional DShot slave |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap, 250 V) | HS/LS drive |
