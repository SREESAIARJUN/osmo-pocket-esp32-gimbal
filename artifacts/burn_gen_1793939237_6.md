# STM32H743 AIO Flight Controller + 4-in-1 ESC: Architecture & Math Model (Job #15)

## 0. Architecture Assumptions

An STM32H743 cannot run four sensored or sensorless FOC/6-step loops while also running ArduPilot at production quality. The standard partition, used here, is:

| Domain | Silicon | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 (TFBGA100), 400 MHz | ArduPilot |
| ESC ×4 | AT32F421K8U7 (or STM32G071) | AM32, 48 kHz PWM, bidirectional DShot |
| Gate drive ×4 | FD6288Q (3-phase, 250 V, bootstrap) | n/a |
| Power stage ×4 | 6× 40 V N-MOSFET, PDFN3.3×3.3 | n/a |

**Design point:** 6S (V_bus max = 25.2 V), **80 A phase-current burst per motor**, ambient 40 °C, junction limit T_j ≤ 150 °C (derated target 135 °C).

**Reference MOSFET (parametric):** 40 V, PDFN3.3.

| Parameter | Value |
|---|---|
| R_ds(on) @ 25 °C, V_gs = 10 V | 1.1 mΩ |
| Temperature coefficient α | 0.0045 /K |
| Q_g | 55 nC |
| Q_gd | 9 nC |
| Q_rr | 30 nC |
| Q_oss | 40 nC |
| V_f (body diode) | 0.8 V |

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses 6-step trapezoidal drive with complementary (synchronous) PWM. In each 60° sector:
- **Leg A (PWM leg):** the high side conducts for fraction D, and the low side conducts for (1−D) minus dead time.
- **Leg B (return leg):** the low side conducts 100 %.
- **Leg C:** floating, used for BEMF sensing.

The phase current I_ph flows through exactly **two** channels at every instant, outside dead time.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.1 × 1.45 = **1.60 mΩ**.

### 1.3 Per-ESC conduction loss

$$P_{cond}=I_{ph}^2 R_{ds}(T_j)\,\big[D+(1-D-2t_d f_{sw})\big]+I_{ph}^2R_{ds}(T_j)\approx 2I_{ph}^2R_{ds}(T_j)$$

Copper and shunt terms add to this:

$$P_{Cu}=I_{ph}^2(R_{trace}+R_{shunt})$$

With R_trace ≈ 0.4 mΩ (2 oz, 8-layer stacked pours) and R_shunt = 0.25 mΩ:

| Term | Calculation | Result |
|---|---|---|
| MOSFET conduction | 2 × 80² × 1.60 mΩ | **20.5 W** |
| Copper + shunt | 80² × 0.65 mΩ | **4.2 W** |

Phase current and battery current are related by I_bat ≈ D·I_ph. A burst of 80 A phase current at D = 0.85 corresponds to roughly 68 A battery current per motor.

### 1.4 Per-device worst case

The return-leg low side carries the full current for 120° electrical:

$$P_{LS,peak}=I_{ph}^2R_{ds}=80^2\times1.60\text{ mΩ}=10.2\text{ W (instantaneous)}$$

Averaged over an electrical cycle, the per-FET loss is about one third of this. However, at low eRPM the instantaneous value governs junction rise, because τ_jc is approximately 2–5 ms.

## 2. Switching Losses at f_sw = 48 kHz

Only the PWM leg switches in each sector: one hard-switched high-side event plus one synchronous low-side event per period.

### 2.1 Gate-drive transition time

FD6288Q drive strength is about 1.5 A source and 1.8 A sink. With R_g,ext = 4.7 Ω, the plateau current is:

$$I_g\approx\frac{V_{drv}-V_{plateau}}{R_g+R_{g,int}}=\frac{12-3.2}{4.7+1.0}\approx1.5\text{ A}$$

$$t_{r}\approx t_f\approx\frac{Q_{gd}}{I_g}+\frac{Q_{gs2}}{I_g}\approx 9\text{ ns}\Rightarrow t_{sw}=t_r+t_f\approx 18\text{ ns}$$

### 2.2 Loss components

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5×25.2×80×18 ns×48 k | **0.87 W** |
| Reverse recovery | Q_rr·V·f_sw = 30 nC×25.2×48 k | **0.036 W** |
| Coss | ½·Q_oss·V·f_sw = 0.5×40 nC×25.2×48 k | **0.024 W** |
| Dead-time diode | V_f·I·2t_d·f_sw = 0.8×80×2×150 ns×48 k | **0.92 W** |
| Gate charge (2 FETs) | 2·Q_g·V_drv·f_sw = 2×55 nC×12×48 k | **0.063 W** |
| **Total switching** | | **≈ 1.91 W** |

**Design lever:** dead-time diode conduction is the dominant switching-band term. Reducing t_d from 150 ns to 80 ns saves about 0.43 W per ESC. AM32 dead-time must be validated against the FD6288Q's internal 200 ns minimum: the effective dead time is max(internal, programmed).

### 2.3 Per-ESC and board totals at 80 A burst

$$P_{ESC}=P_{cond}+P_{Cu}+P_{sw}=20.5+4.2+1.9\approx\mathbf{26.6\ W}$$

$$P_{board}=4\times26.6+P_{FC}(\approx1.5)+P_{BEC}(\approx2)\approx\mathbf{110\ W}$$

## 3. Thermal Model

### 3.1 Two-node Cauer network per FET, plus a lumped board mass

```
P_FET ──► [C_j] ──R_jc(1.5 K/W)──► [C_board (shared)] ──R_ba──► T_amb
                                         ▲
                       all 24 FETs + Cu losses inject here
```

### 3.2 Board heat capacity

For a 20×20 mm nano board, 8 layers at 2 oz, 1.6 mm thick:

| Element | Calculation | Heat capacity |
|---|---|---|
| Copper | 400 mm² × 0.56 mm = 0.224 cm³ → 2.0 g × 0.385 J/g·K | 0.77 J/K |
| FR4 | 400 mm² × 1.04 mm = 0.42 cm³ → 0.77 g × 1.1 J/g·K | 0.85 J/K |
| Components (FETs, caps, MCUs) | | ≈ 0.45 J/K |
| **C_board total** | | **≈ 2.1 J/K** |

Convective resistance with prop-wash airflow (about 8 m/s, h ≈ 60 W/m²K, both faces) is R_ba ≈ 1/(60 × 8×10⁻⁴) ≈ **21 K/W**. The thermal time constant is τ_b = R·C ≈ 44 s, so a 1–3 s burst is essentially **adiabatic**.

### 3.3 Burst temperature trajectory

$$T_b(t)=T_a+P_{board}R_{ba}\left(1-e^{-t/\tau_b}\right)\approx T_0+\frac{P_{board}}{C_{board}}t$$

$$\frac{dT_b}{dt}=\frac{110}{2.1}\approx \mathbf{52\ K/s}$$
