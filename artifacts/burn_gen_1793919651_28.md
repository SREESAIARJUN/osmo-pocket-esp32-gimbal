## 0. Architecture Clarification and Design-Basis Assumptions

**Architecture.** ArduPilot does not commutate motors from the H743. The realistic architecture is:

```
STM32H743 (ArduPilot FC) ──4× bidir DShot600──► 4× ESC MCU (AM32 on AT32F421 / STM32G071)
                                                   └─► 3-phase gate driver ─► 6× N-MOSFET per motor
```

The H743 only generates DShot frames and decodes the eRPM telemetry. The 48 kHz PWM is generated by each ESC MCU. AM32 supports a selectable 24/48/96 kHz PWM.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in 6-step trapezoidal drive with synchronous rectification
In any 60° commutation sector, one phase sources current and one phase sinks it.

- **Sourcing leg:** the high-side FET conducts for duty D, and the low-side FET of the same leg (sync rect.) conducts for 1−D.
- **Sinking leg:** the low-side FET is on 100 %.

Over the full PWM period, two R_DS(on) are in series continuously:

$$
P_{cond} = I_{rms}^2 \, R_{DS}(T_j)\,[D + (1-D)] + I_{rms}^2 \, R_{DS}(T_j) = 2\,I_{rms}^2\,R_{DS}(T_j)
$$

The result is independent of D, which is the benefit of sync rectification.
