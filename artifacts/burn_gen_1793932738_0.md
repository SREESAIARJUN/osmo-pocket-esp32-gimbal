## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), where θ_offset comes from the alignment calibration (lock the d-axis with V_d > 0 and V_q = 0).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and Current PI Design

The dq-frame model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau_e = \tfrac32 p\lambda\, i_q \equiv K_t i_q \quad (\text{surface PMSM},\ L_d = L_q)$$

Apply decoupling and back-EMF feedforward:

$$v_d = u_d - \omega_e L i_q,\qquad v_q = u_q + \omega_e L i_d + \omega_e\lambda$$

Each axis then reduces to 1/(Ls + R). A PI controller C(s) = K_p + K_i/s with zero/pole cancellation gives:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

The resulting closed loop is a first-order system with bandwidth ω_ci. Choose ω_ci ≤ 2π·f_PWM/20 to keep phase margin despite the 1.5-sample computational and PWM delay. At 20 kHz this gives ω_ci ≈ 2π·1000 rad/s.

**Discretization and anti-windup.** Use forward Euler for the integral and back-calculation anti-windup with gain K_aw = 1/K_p:

$$u_k = K_p e_k + I_k,\quad u^{sat}_k = \text{sat}(u_k),\quad I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u^{sat}_k - u_k)\right]$$

**Voltage vector limiting.** Apply a circular limit |v_dq| ≤ V_bus/√3, which is the SVPWM linear-region limit. Give v_d priority.

### 1.3 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.4 Voltage-Mode Fallback (No Current Sensing)

Many gimbal drivers lack current sensing. In that case, command the voltage directly:

$$v_q = R\,i_q^* + \omega_e\lambda,\qquad v_d = -\omega_e L\, i_q^*$$

The outer loops below remain unchanged, because they still output i_q*.

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical Plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{d}$$

Here τ_d includes cable drag and imbalance. With the current loop treated as unity gain up to ω_ci:

$$G_v(s) = \frac{K_t}{Js}$$
