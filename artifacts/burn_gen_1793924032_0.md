## 1. Field-Oriented Control: the Inner Current Loop

### 1.1 Transforms

The electrical angle comes from the mechanical angle and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Here ω_e = p·ω_m is the electrical speed and λ_m = K_t / (1.5p) is the flux linkage. Electromagnetic torque is:

$$T_e = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 Current PI Controller with Decoupling (Pole-Zero Cancellation)

After the cross-coupling terms are cancelled, each axis behaves as a first-order plant:

$$G(s) = \frac{1}{Ls + R}$$

Choose the PI zero to cancel the plant pole:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

This makes the closed loop a first-order system, 1/(s/ω_c + 1). Pick the bandwidth as

$$\omega_c = \frac{2\pi f_{pwm}}{20} \approx 6.3\text{ krad/s} \approx 1\text{ kHz}$$

which leaves good phase margin against the 1.5-sample delay of the PWM update.

The final voltage commands add feed-forward decoupling:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

The d-axis reference is i_d* = 0, because a surface PMSM produces no reluctance torque.

**Voltage limit.** Limit the voltage vector to the inscribed circle of the SVPWM hexagon, |v| ≤ V_bus/√3. Give the d-axis priority:

$$v_{q,\max} = \sqrt{V_{\max}^2 - v_d^2}$$

> **Voltage-mode fallback.** Many gimbal motors have no shunt amplifiers. Because R is large (about 10 Ω), the electrical time constant τ = L/R is about 0.3 ms. In that case you can use v_q* = R·i_q* + ω_e·λ_m directly. The code supports both modes via `kUseCurrentSensing`.

### 1.4 Space-Vector PWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{a,b,c}) + \min(v_{a,b,c})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to seven-segment SVPWM, and it extends linear modulation to V_bus/√3.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ* ─►(+)─► P_θ ──(+ω_ff)──►(+)─► PI_ω ──(+i_ff,accel)(+i_cog)──► i_q* ─► [FOC current loop]
      ▲−                    ▲−
      θ̂ (IMU attitude/      ω̂ (gyro rate on stabilised
       encoder)              frame, or encoder rate)
```

In a stabilised gimbal, the **outer angle loop** closes on the IMU-estimated camera attitude (in the inertial frame). The **velocity loop** closes on the camera-frame gyro rate projected onto that motor's axis. The camera gyro is the best rate sensor because it directly measures what you want to keep still.

### 2.2 Mechanical Plant

$$J\dot\omega = K_t i_q - B\omega - T_{cog}(\theta_m) - T_{dist}$$
