| Item | Value (assumed) |

| Encoder | 14-bit magnetic (AS5048A/MT6701 class), read at 20 kHz |
| MCU | Cortex-M7 / M4F, single-precision FPU |
| PWM / current loop | 20 kHz, center-aligned, SVPWM |
| Rate (velocity) loop | 4 kHz (decimate ÷5) |
| Attitude (angle) loop | 1 kHz (decimate ÷4) |
| IMUs | 2 × ICM-42688-P, ODR 8 kHz, ±1000 dps, ±8 g, SPI @ 24 MHz |

Bandwidth separation rule, roughly ≥5× between loops:

$$\omega_{c,i}\approx 2\pi\cdot 1.5\text{ kHz}\;>\;5\,\omega_{c,\omega}\;(\approx 2\pi\cdot 150\text{ Hz})\;>\;5\,\omega_{c,\theta}\;(\approx 2\pi\cdot 25\text{ Hz})$$

**Feedback sources:**

- The encoder provides commutation angle and the anti-cogging phase.
- The gyro provides inertial rate feedback.
- The fused attitude provides angle feedback.

This is the standard "inertially stabilized" topology. Base disturbances enter as a rate error the gyro sees directly.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle: θ_e = p·(θ_m − θ_offset).

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Delay compensation: the PWM update lands about 1.5·T_s after sampling. Use this angle for the inverse Park transform:

$$\theta_e^{*}=\theta_e+1.5\,\omega_e T_s$$

### 1.2 Plant & PI with decoupling

The dq model of a surface PMSM:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Use a PI controller with pole-zero cancellation:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

This makes the closed loop ≈ ω_c,i/(s + ω_c,i).

Discrete form (forward Euler on the integrator), with back-calculation anti-windup:

$$\begin{aligned}
e[k]&=i^*[k]-i[k]\\
u_{\text{raw}}&=K_p e + x[k] + v_{\text{ff}}\\
u&=\text{sat}(u_{\text{raw}})\\
x[k+1]&=x[k]+K_iT_s\,e[k]+K_{aw}\,(u-u_{\text{raw}})
\end{aligned}$$

Choose K_aw ≈ 1/K_p·K_i·T_s, or simply 0.5–1.0 × K_i·T_s/K_p.

$$v_{d,ff}=-\omega_e L i_q,\qquad v_{q,ff}=\omega_e L i_d+\omega_e\lambda_m$$
