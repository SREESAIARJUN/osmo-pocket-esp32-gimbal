# Job #66: STM32H743 AIO Flight Controller with 4-in-1 80A ESC

**System Architecture, Loss Modeling, Thermal Analysis, and DShot DMA Plan (Rev A, Engineering Draft)**

> **Scope note:** This analysis uses parametric MOSFET and driver values typical of current 40V parts, not one vendor's datasheet. Every number is reproducible from the equations, so you can substitute your actual BOM values. The netlists are reference topology and need ERC/DRC and vendor review before fabrication.

## 0. Architecture Decisions and Feasibility Flags

Three constraints shape everything below.

**1. The H743 is the flight controller, not the motor commutator.** ArduPilot sends bi-directional DShot to an ESC MCU on each motor. It does not run ESC firmware, and the H743 has only 2 advanced timers with complementary outputs (TIM1, TIM8) plus the HRTIM, which is not enough for 4 sensorless 6-step bridges alongside an FC stack. The architecture is therefore:
- **FC:** STM32H743VIT6 running ArduPilot.
- **ESC:** 4× AT32F421 or STM32G071 running AM32, which supports a 48 kHz PWM option and bidirectional DShot/EDT.

**2. 80A burst on a "nano" (20×20 mm) footprint is not physically credible.** The thermal mass is far too small, as §3 shows. This design therefore assumes:
- a **30.5×30.5 mm** board with 8 layers and 2 oz copper on all layers;
- **24 MOSFETs** (2 in parallel per switch position), or 12 positions using 5×6 mm parts.

The "nano" label below refers to the stack height class, not 20×20 mounting. If you must use 20×20, de-rate to roughly 45A burst / 30A continuous.

**3. "80A burst" is defined as 80A per channel for ≤10 s on one channel**, with the other channels at ≤40A. Four simultaneous channels at 80A is analyzed and survives only about 2–3 s (see §3.4).

**Operating point:** 6S Li-ion/LiPo, V_bus = 25.2 V max (22.2 V nominal), f_sw = 48 kHz, ambient 40 °C.
