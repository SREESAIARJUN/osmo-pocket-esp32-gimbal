# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #40 specification, so this design states its assumptions explicitly (§0). Every hardware-dependent number lives in one config struct. Change those values to match your motors, encoder, MCU and frame. The equations are general, and the code is self-contained C++17 for a Cortex-M4F/M7-class MCU. It uses no heap and no exceptions, and the HAL hooks are stubbed.

---

## 0. Assumptions and System Architecture

| Item | Assumed value | Notes |
|---|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R≈5 Ω, L≈2 mH | High-R gimbal type |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (e.g. MT6701/AS5047) | Used for commutation and joint angle |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR | Inertial rate and attitude |
