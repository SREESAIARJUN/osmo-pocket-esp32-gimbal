# 3-Axis Gimbal: FOC Cascade, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the specification for "Job #12," so this design states its assumptions explicitly. Every parameter is exposed as a constant and should be re-derived for your hardware.

| Item | Assumed value |
|---|---|
| Motors | Gimbal PMSM, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MT6701 class), read by SPI every current cycle |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at PWM center |
| Loop rates | Current loop 20 kHz; velocity loop 5 kHz; angle loop 1 kHz; IMU ODR 8 kHz |
| IMUs | Two ICM-42688-P on separate SPI chip-selects, mounted on the camera plate at r₂ ≈ −r₁ about the plate center |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms
Electrical angle: θₑ = p·(θₘ − θ_offset).

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$
