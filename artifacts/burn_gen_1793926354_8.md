# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for "Job #29," so this design rests on the assumptions in §0. Anything marked **[ID]** must be identified on your hardware before closing the loops.

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7 (e.g. GBM2804-class) |
| Phase R, L, Kt | **[ID]**. Typical values are R ≈ 5–12 Ω, L ≈ 1–4 mH, Kt ≈ 0.05–0.15 N·m/A |
| Rotor encoder | 14-bit absolute magnetic sensor (AS5048A/MT6835-class), read every current-loop tick |
| MCU | STM32G4/H7-class with FPU, center-aligned PWM, ADC triggered at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (stabilized side), placed symmetric about the plate's rotation center |
| Supply | V_dc = 12–16 V |

The loops run at these rates. Each loop's bandwidth is at least 5× below the next inner loop.

| Loop | Rate | Target closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (T_c = 50 µs) | 1.5–2.5 kHz |
| Anti-cogging feedforward | 20 kHz | n/a (feedforward) |
| Velocity (gyro feedback) | 4 kHz (T_v = 250 µs) | 150–300 Hz |
| Angle (fused attitude) | 1 kHz (T_a = 1 ms) | 20–40 Hz |
| IMU sampling and filtering | 8 kHz ODR, decimated to 4 kHz | n/a |
