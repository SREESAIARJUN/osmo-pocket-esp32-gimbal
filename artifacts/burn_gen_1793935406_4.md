# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #23 spec sheet, so this design uses the assumptions below. Every value is a named parameter in the code, so you can substitute yours.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH, K_t ≈ 0.05–0.15 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at PWM center |
| Loop rates | Current 20 kHz · rate 4 kHz · attitude 1 kHz · IMU 8 kHz ODR |
| IMUs | 2 × ICM-42688-P on SPI, shared CLKIN (hardware time-synchronized), ideally mounted at **r₂ = −r₁** about the camera-frame IMU reference point |

**Control architecture per axis:**

```
                      ┌──────────── feed-forward (ω_ref, α_ref, cogging) ───────────┐
 θ_ref ─►(Σ)─► P/PI ─►(Σ)─► PI (rate) ─►(Σ)─► i_q* ─► PI current (d,q) ─► SVPWM ─► motor
          ▲  attitude  ▲   4 kHz                        20 kHz   ▲
          │  1 kHz     │                                         │ θ_e (encoder)
   attitude from   fused gyro rate                               │
   Mahony AHRS ◄── dual-IMU fusion + notch/LPF ◄── 2× ICM-42688-P
```

The outer loops close on **inertial** quantities (IMU), because a gimbal stabilizes the camera in space. The encoder is used for commutation, cogging-table indexing and joint-limit safety.

## 1. Field-Oriented Current Control (20 kHz)

### 1.1 Transforms
Amplitude-invariant Clarke transform:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(i_a+i_b+i_c=0)$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{off})$:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Dynamics and decoupling
The PMSM model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The torque is $\tau = \tfrac32 p\lambda_m i_q = K_t i_q$, with $i_d^* = 0$.

The decoupled voltage commands are:

$$v_d^* = \text{PI}_d(e_d) - \hat\omega_e \hat L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$
