**IMU topology.** "Dual" IMUs are used in the most effective vibration-rejection arrangement:
- **IMU-P** sits on the camera payload. This is the controlled variable.
- **IMU-B** sits on the gimbal base/handle. This is the vibration reference for adaptive cancellation and for feedforward of base motion.

If both IMUs are actually on the payload (redundancy), Section 4.6 covers that case.

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

$\theta_{off}$ is found at startup by applying a d-axis voltage vector at $\theta_e = 0$ and reading the encoder.

### 1.2 Clarke and Park transforms (amplitude-invariant)

With $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Machine model in the d-q frame

$$v_d = R_s i_d + L_s\frac{di_d}{dt} - \omega_e L_s i_q$$

$$v_q = R_s i_q + L_s\frac{di_q}{dt} + \omega_e L_s i_d + \omega_e \lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

Here $\omega_e = p\,\omega_m$ and $\lambda_m = \dfrac{2K_t}{3p}$.

### 1.4 Current PI with decoupling and back-EMF feedforward

Use pole-zero cancellation with target current bandwidth $\omega_c$. Choose $\omega_c \le 2\pi f_{pwm}/20$, giving $\omega_c = 2\pi\cdot 1\,\text{kHz}$:

$$K_{p,c} = L_s\,\omega_c,\qquad K_{i,c} = R_s\,\omega_c$$

so that the closed loop is $\dfrac{i}{i^*}=\dfrac{\omega_c}{s+\omega_c}$.

Control law:

$$v_d^* = K_{p,c}e_d + K_{i,c}\!\int\! e_d\,dt \;-\; \omega_e L_s i_q$$

$$v_q^* = K_{p,c}e_q + K_{i,c}\!\int\! e_q\,dt \;+\; \omega_e L_s i_d + \omega_e\lambda_m$$

### 1.5 Voltage limiting and anti-windup

1. Limit the voltage vector to the linear SVPWM region, $|v| \le V_{dc}/\sqrt3$. Give $v_d$ priority, then $v_q \le \sqrt{V_{max}^2 - v_d^2}$.
2. Apply back-calculation anti-windup:

$$\dot{x}_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.6 SVPWM (min-max zero-sequence injection)

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

Duty cycles:

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

### 1.7 Delay compensation

Total delay is roughly 1.5 $T_c$ (computation plus PWM hold). Advance the angle used in the inverse Park transform:

$$\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_c$$
