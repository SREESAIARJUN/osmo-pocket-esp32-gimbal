# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Design

**Scope note.** I have no prior context for "Job #10", so this analysis states every assumption explicitly. Replace the values marked **[A]** with your BOM datasheet values. The equations hold regardless of those values.

**Architectural correction.** The H743 does not perform the 48 kHz motor commutation. On a 4-in-1 AIO, each ESC channel has its own MCU, for example an AT32F421 or STM32G071 running AM32 or BLHeli_32. Those MCUs run the 48 kHz complementary PWM. The H743 only:

- generates bidirectional DShot600 and captures the eRPM telemetry,
- reads current and voltage sense,
- runs ArduPilot.

The document is partitioned accordingly.
