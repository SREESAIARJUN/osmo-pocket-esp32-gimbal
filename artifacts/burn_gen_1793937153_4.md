## 1. Field‑Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical Angle

```
θ_e = wrap_{2π}( p · (θ_m − θ_offset) )
```

Here θ_offset is found at calibration by applying V_d with V_q = 0 and reading the encoder.

### 1.2 Clarke Transform (Amplitude‑Invariant, 2 Shunts)

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

### 1.3 Park Transform

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.4 Motor Model in the dq Frame

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m          (ω_e = p ω_m)
```

### 1.5 Current PI with Decoupling and Back‑EMF Feedforward

Using pole‑zero cancellation, the closed loop becomes first order at ω_c:

```
K_p,i = L ω_c         K_i,i = R ω_c
v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m
```

Set i_d* = 0 (surface PMSM). The torque is then τ = (3/2) p λ_m i_q = K_t i_q.

### 1.6 Voltage Circle Limit and Anti‑Windup

The limit keeps the vector inside the SVPWM linear region:

```
V_max = V_bus / √3
if |v_dq| > V_max:  v_dq ← v_dq · V_max/|v_dq|
```

Back‑calculation anti‑windup is applied to each axis:

```
I ← I + T_s [ K_i e + K_aw (v_sat − v_unsat) ],    K_aw = 1/K_p (≈ ω_c/K_i·K_i/K_p)
```

### 1.7 Inverse Park and SVPWM (Min‑Max Injection)

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
v_a = v_α
v_b = −½ v_α + (√3/2) v_β
v_c = −½ v_α − (√3/2) v_β
v_0 = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c)) / 2
D_x = ½ + (v_x + v_0)/V_bus ,   x ∈ {a,b,c}
```

This is mathematically equivalent to sector‑based SVPWM and gives 15.5 % more linear range than SPWM.

## 2. Encoder Velocity Estimation (PLL Tracking Observer)

A raw encoder derivative is too noisy at 4 kHz, so a type‑II PLL tracks angle and speed:

```
e_θ   = wrap_{±π}(θ_meas − θ̂)
ω̂    ← ω̂ + K_i,pll e_θ T_s
θ̂    ← θ̂ + (ω̂ + K_p,pll e_θ) T_s
K_p,pll = 2 ζ ω_n ,  K_i,pll = ω_n² ,  ζ = 0.707–1, ω_n ≈ 2π·400 Hz
```

The PLL is zero‑lag for constant velocity.

## 3. Cascaded Angle → Velocity → Current Control

### 3.1 Plant Model per Axis

```
J dω/dt = K_t i_q − B ω − τ_cog(θ) − τ_dist
```

Here J is the payload plus rotor inertia about that joint. Identify it with a chirp test.

### 3.2 Velocity Loop (4 kHz, PI + Acceleration Feedforward)

For a gimbal, the **velocity feedback** is the camera‑axis rate from the fused gyro (Section 5), projected onto the joint axis. This is what makes the camera inertially stable. The encoder PLL rate is used only as a fallback and for low‑speed blending.

Complementary blend at crossover ω_b ≈ 2π·5 Hz:

```
ω_fb = HP_{ω_b}(ω_gyro,joint) + LP_{ω_b}(ω̂_enc + ω_base,joint)
```

In practice, use the gyro directly. The blend matters only in follow mode with large base rates.
