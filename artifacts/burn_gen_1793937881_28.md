# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #44): Architecture, Loss Model, Thermal Analysis, and Bidirectional DShot600 Allocation

> **Read this first.** This is an engineering baseline built on stated assumptions, not a release package. Every MOSFET parameter, pin mapping and netlist entry must be checked against the actual datasheets, the ArduPilot hwdef DMA resolver output, and bench thermal measurements before layout freeze. The analysis leads to one key conclusion, stated up front: **an 80 A per-motor burst on a nano-format board is limited by thermal capacity to roughly 2–4 seconds.** It is not a sustainable rating. Section 3 derives this.

---

## 0. Architecture Clarification

The STM32H743 does **not** commutate the motors. A 4-in-1 ESC is built in two layers:

| Layer | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 (400/480 MHz) | Runs ArduPilot and generates 4× bidirectional DShot600 |
| ESC MCUs (×4) | e.g., AT32F421K8U7 running AM32 | 6-step or sinusoidal commutation, 48 kHz PWM, eRPM telemetry |
| Gate drivers (×4) | 3-phase half-bridge driver (e.g., FD6288Q class) | Level shifting, bootstrap supply, dead-time |
| Power stage (×4) | 6× N-MOSFET per motor (24 total) | 3 half-bridges per motor |

The 48 kHz switching frequency is an **ESC firmware setting** (AM32 PWM frequency). The H743 only sets the DShot command rate.

## 2. Electrical Loss Model (per motor channel)

### 2.1 Conduction Loss

In 6-step drive with synchronous rectification, current flows through exactly two phases at any instant. The path is one high-side device (during duty D) or its complementary low-side device (during 1−D), plus one low-side device in the return phase. Two R_DS(on) are therefore always in series:

$$P_{cond} = I^2 \cdot 2R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

$$P_{cond} = 80^2 \times 2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

At a cold start (R = 1.0 mΩ) this is 12.8 W. Because R rises with temperature, the loss **increases** during the burst. This positive feedback is why the hot value is used.

### 2.2 Hard-Switching Loss (active leg only)

Only the PWM'd leg switches; the commutating leg is static within a PWM period.

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{ns} \times 48\text{k} = \mathbf{0.97\ W}$$

### 2.3 Dead-Time (Body-Diode) Loss

$$P_{dt} = V_f \cdot I \cdot 2t_{dt} \cdot f_{sw} = 0.8 \times 80 \times 200\text{ns} \times 48\text{k} = \mathbf{0.61\ W}$$

### 2.4 Reverse Recovery, C_oss and Gate Drive

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n} \times 25.2 \times 48\text{k} = 0.06\ \text{W}$$
$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 0.05\ \text{W}$$
$$P_{gate} = 2 \cdot Q_g V_{gs} f_{sw} = 2 \times 60\text{n} \times 7.5 \times 48\text{k} = 0.04\ \text{W}$$

Gate-drive loss is dissipated mostly in the driver and gate resistors, not in the MOSFET die.

### 2.5 Totals

| Loss term | Per motor (W) | 4 motors (W) |
|---|---|---|
| Conduction (hot) | 19.20 | 76.8 |
| Switching | 0.97 | 3.9 |
| Dead-time | 0.61 | 2.4 |
| Q_rr + Q_oss + gate | 0.15 | 0.6 |
| **Total** | **20.9** | **≈ 83.7** |
