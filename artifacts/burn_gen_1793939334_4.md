# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s \approx 5\,\Omega$, $L_s \approx 2\,\text{mH}$, $K_t \approx 0.08\,\text{N·m/A}$ |
| Rotor position | 14-bit magnetic encoder (AS5048A / MT6701) per axis, SPI |
| MCU | STM32G474 @ 170 MHz with FPU (CORDIC optional) |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted mirror-symmetric about the plate centroid ($\mathbf r_2 = -\mathbf r_1$) |
| Gimbal order | Base → Yaw → Roll → Pitch → Camera |

**Loop rates.** Each inner loop is at least 5–10× faster in bandwidth than the loop around it.

| Loop | Rate $f_s$ | Target bandwidth |
|---|---|---|
| Current (FOC) | 24 kHz (PWM-centered ADC) | $\omega_{cc} = 2\pi\cdot 1.5$ kHz |
| IMU sample + filters | 8 kHz (ODR, SPI-DMA, FIFO off) | — |
| Rate (velocity) loop | 8 kHz, synchronous with IMU | $\omega_{vc} = 2\pi\cdot 120$ Hz |
| Angle loop + attitude fusion | 1 kHz | $\omega_{\theta c} = 2\pi\cdot 20$ Hz |

**Feedback sources.** The stabilizing velocity loop uses the **gyro rate**, mapped into joint space, as feedback. It does not use the encoder derivative, because the gyro measures inertial rate, which is what must be zeroed. The encoder is used for:
- FOC commutation,
- the anti-cogging phase reference,
- the kinematic Jacobian.
