# STM32H743 Nano FC + 4-in-1 80 A ESC: Systems Architecture Package (Job #10)

## 0. Architecture Clarification and Feasibility Flags

**Topology.** The STM32H743 is the flight controller MCU running ArduPilot. It cannot commutate 4 BLDC motors directly at 48 kHz with ArduPilot's scheduler. The architecture below is therefore:

```
STM32H743 (ArduPilot) ──4× bidir DShot600──► 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware)
                                              └─► 4× 3-phase gate driver ──► 24 MOSFETs
```

If you intended the H743 to run commutation itself, say so. That would be a fundamentally different (and not recommended) design.

**Flag 1: 80 A on a nano footprint.** 80 A per channel × 4 channels on a 20×20 or 25.5×25.5 mm board produces about 86 W of loss. The model below shows this is **burst-only (≈3–8 s)**. The continuous rating will be roughly 35–45 A per channel depending on airflow. Spec sheets should state both figures.

**Flag 2: MOSFET parameters are representative, not authoritative.** They match a typical 40 V, 3.3×3.3 mm DFN MOSFET. Replace every value marked ⟨param⟩ with your selected part's datasheet values before release.

## 2. Conduction Loss Model

### 2.1 Current paths in 6-step commutation with synchronous rectification

At any instant two phases conduct:
- **PWM leg:** the high-side FET conducts for duty D, and the complementary low-side conducts for (1−D).
- **Return leg:** the low-side FET is on for the full 120° commutation interval.

Integrated over a commutation period, the current always flows through exactly **two FETs in series**:

$$P_{cond,ESC} = I_{ph}^2 \cdot R_{ds}(T_j)\cdot\big[D + (1-D)\big] + I_{ph}^2 \cdot R_{ds}(T_j) = 2\,I_{ph}^2\,R_{ds}(T_j)$$

This is independent of D (dead time is handled separately in §3.3).

### 2.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 0.9 mΩ × 1.5 = **1.35 mΩ**. Use 1.5 mΩ to include PCB via and solder resistance.

### 2.3 Self-consistent junction temperature (fixed-point iteration)

The junction temperature depends on R_ds, and R_ds depends on junction temperature:

$$T_j = T_{ref} + P_{FET}(T_j)\cdot R_{th} \quad\Rightarrow\quad T_j = \frac{T_{ref} + I^2 R_{ds,25}(1-25\alpha)R_{th}}{1 - I^2 R_{ds,25}\,\alpha\,R_{th}}$$

**Thermal runaway criterion:** the denominator must stay positive, so

$$I^2 R_{ds,25}\,\alpha\,R_{th} < 1$$

Applying this to the worst-case FET (return-leg low-side, 100 % conduction during its interval):
- I² R_ds,25 = 6400 × 0.9 mΩ = 5.76 W
- With R_th(j-to-local board) ≈ 1.5 + 8 = 9.5 K/W: 5.76 × 0.005 × 9.5 = **0.27**, which is stable.

### 2.4 Numbers at 80 A, T_j ≈ 125 °C, R_ds = 1.5 mΩ

$$P_{cond,ESC} = 2 \times 6400 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

Peak single-FET instantaneous loss is 9.6 W. Because each FET only conducts part of the electrical cycle (1/3 for the return function, plus PWM sharing), the average per FET is approximately 19.2 / 6 ≈ 3.2 W, with peaks of 9.6 W.

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches hard. There is one hard-switched commutation pair per PWM cycle.

### 3.1 V–I overlap (hard switching)

$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{ ns}\times 48\text{ kHz} = \mathbf{1.45\ W}$$

### 3.2 Capacitive, recovery and gate losses

| Term | Formula | Value |
|---|---|---|
| C_oss | ½·C_oss·V²·f × 2 FETs | 0.5·1 nF·635·48k·2 = **0.030 W** |
| Q_rr | V_bus·Q_rr·f_sw | 25.2·50 nC·48k = **0.060 W** |
| Gate drive | Q_g·V_GS·f_sw × 2 FETs | 50 nC·10 V·48k·2 = **0.048 W** (dissipated in driver and gate R) |

### 3.3 Dead-time body-diode conduction

$$P_{dt} = V_{SD}\,I_{ph}\cdot 2t_{dt}\cdot f_{sw} = 0.8\times80\times200\text{ ns}\times48\text{k} = \mathbf{0.61\ W}$$

Reducing dead time to 50 ns halves this term. That reduction is only safe if gate-loop inductance is under about 3 nH, which requires a Kelvin-source layout.

### 3.4 Frequency sensitivity

$$\frac{\partial P_{sw,total}}{\partial f_{sw}} \approx 45\ \mu\text{W/Hz}$$

Dropping to 24 kHz saves about 1.1 W per ESC. The cost is higher current ripple:

$$\Delta I = \frac{V_{bus}D(1-D)}{L_{ph} f_{sw}}$$

For a low-inductance 2306 motor (L_ph ≈ 15 µH, line-to-line 30 µH), ripple at D = 0.5 is about 4.4 A at 48 kHz versus 8.8 A at 24 kHz. Ripple adds conduction loss of order I_rms² ≈ I² + ΔI²/12, which is negligible here. **48 kHz is justified mainly by audible noise and current smoothness, not efficiency.**

## 4. Loss Budget Summary at 80 A Burst

| Loss term | Per ESC | ×4 channels |
|---|---|---|
| Conduction (2 I² R_ds) | 19.20 W | 76.8 W |
| Hard switching | 1.45 W | 5.8 W |
| Dead-time diode | 0.61 W | 2.4 W |
| Q_rr + C_oss | 0.09 W | 0.4 W |
| Gate drive | 0.05 W | 0.2 W |
| Shunt (0.25 mΩ, 1 per ESC, avg I²R) | 1.60 W | 6.4 W |
| Copper planes (≈0.3 mΩ path, 2 oz × 4 layers) | 1.9 W | 7.7 W |
| **Total** | **≈24.9 W** | **≈99.7 W** |

Efficiency at 80 A × 4 (≈8 kW input): about 98.8 %. The problem is not efficiency; it is **power density**.

**Shunt note:** if the design uses a single bus shunt, the loss is 320² × 0.25 mΩ = 25.6 W. That is unacceptable, so a per-ESC shunt is mandatory, or use the low-side R_ds sensing that AM32 supports.
