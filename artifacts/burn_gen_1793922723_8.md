# STM32H743 AIO Flight Controller + 4-in-1 ESC: 80 A Burst Design Package (Job #35)

## 0. Feasibility Issues

These four constraints shape the rest of the design.

1. **The STM32H743 cannot run the ESCs.** The H743 is the flight controller. Each motor bridge needs its own commutation MCU running AM32 (an AT32F421 or STM32G071 class part) so it can do BEMF zero-cross sensing and decode DShot. One H743 cannot commutate four motors at 48 kHz while also running ArduPilot. The architecture below is an H743 FC driving 4 ESC MCUs.
2. **"Nano" and "80 A burst" do not fit together.** At 80 A per channel the four bridges dissipate about 85 W (Section 2). A 20×20 mm board has roughly 4 J/K of heat capacity and would overheat in under 5 s with no airflow. This package therefore assumes a **30.5×30.5 mm (36×36 mm outline), 8-layer, 2 oz copper** board. If 20×20 mm is mandatory, derate to about 40 A burst.
3. **80 A is treated as phase current per channel**, in bursts of 5 s or less. Continuous rating is about 45 A with no forced airflow.
4. **Component values are representative, not tied to a specific part.** The MOSFET parameters below describe a typical 40 V, 1 mΩ PDFN5×6 device. Replace them with your chosen part's datasheet values; every equation is written so you can substitute directly.

## 1. Conduction Loss Model

### 1.1 Topology accounting

The ESC uses 6-step trapezoidal drive with synchronous (complementary) PWM. At any instant, current flows through exactly two conducting channels:
- the high-side or its complementary low-side on the PWM leg, and
- the low-side of the return leg.

Synchronous rectification makes the PWM leg's resistance the same in both PWM states, so the duty cycle D cancels out:

$$P_{cond,ch} = 2\,I_{ph,rms}^2\,R_{ds}(T_j)$$

### 1.2 Current form factor

Trapezoidal phase current with ripple ΔI has an RMS value of:

$$I_{rms} = I_{ph}\sqrt{1+\frac{1}{12}\left(\frac{\Delta I}{I_{ph}}\right)^2}$$

The ripple is:

$$\Delta I = \frac{V_{bus} D(1-D)}{L_{ph} f_{sw}}$$

Take a typical 5" motor, L_ph ≈ 15 µH (line-to-line 30 µH). The worst case is D = 0.5:
- ΔI = 25.2·0.25 / (30 µH·48 kHz) ≈ 4.4 A
- Form factor = 1.0003, which is negligible.

**Use I_rms ≈ I_ph.**

### 1.3 Temperature-coupled solution

R_ds depends on T_j, and T_j depends on loss, so the two must be solved together:

$$T_j = T_{board} + R_{\theta}\,P_{FET}(T_j)$$

Each FET conducts 120° out of 360° of the electrical cycle, so six FETs share two conduction paths:

$$P_{cond,FET} = \frac{1}{3}I^2R_{25}\left(1+\alpha(T_j-25)\right)$$

Solving for T_j in closed form:

$$T_j = \frac{T_b + R_\theta \tfrac{1}{3}I^2R_{25}(1-25\alpha)}{1 - R_\theta \tfrac{1}{3}I^2R_{25}\alpha}$$

**Stability condition (thermal runaway):** the denominator must stay positive:

$$R_\theta \tfrac{1}{3}I^2R_{25}\alpha < 1$$

At 80 A this evaluates to 8·2.133·0.0045 = 0.077, so the design is well inside the stable region.
