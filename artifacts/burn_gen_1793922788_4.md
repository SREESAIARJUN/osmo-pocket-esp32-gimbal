# STM32H743 FC + 80A 4-in-1 ESC Stack: Loss Model, Thermal Budget, Bidirectional DShot600 Allocation, and Netlists

## 0. Architecture and Assumptions

### 0.1 Partitioning

The STM32H743 does **not** commutate the MOSFETs. A 48 kHz, 6-step drive across 4 motors needs dedicated per-motor control loops. Every production 4-in-1 ESC uses one small MCU per motor (AT32F421, STM32G071 or EFM8 running AM32 or BLHeli_32). The partition is:

```
[STM32H743 / ArduPilot] --4x bidirectional DShot600 (1-wire, open-drain-ish, pulled up)--> [4x ESC MCU + 4x 3-phase gate driver + 24 MOSFETs]
```

### 0.2 Feasibility flag

"Nano" (20×20 mm) at 80 A per motor is not thermally realistic. Section 3 shows that even a 30.5×30.5 mm board survives only seconds at 4×80 A. The model below therefore treats 80 A strictly as a **burst rating** and derives the burst time from first principles.

## 1. Conduction Loss Model

### 1.1 Topology behaviour

The drive is 6-step trapezoidal with complementary (synchronous) PWM on the high side. In every commutation sector:

- **On-time (D):** the HS FET of phase A conducts, plus the LS FET of phase B (static).
- **Off-time (1−D):** current freewheels through the LS FET of phase A (synchronous), plus the LS FET of phase B.

So **two R_ds(on) are in the current path at all times**, independent of duty:

$$P_{cond,motor} = 2\, I^2\, R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

### 1.2 Evaluation at T_j = 110 °C

- R_ds = 0.9 × (1 + 0.0055 × 85) = **1.32 mΩ**
- P_cond = 2 × 80² × 1.32×10⁻³ = **16.9 W per motor**

### 1.3 Per-device distribution

Each FET conducts for 120° electrical of each 360°. The electrical frequency is several kHz, while the junction thermal time constant is ~1–10 ms, so averaging is valid:

$$\bar P_{cond,FET} = \frac{P_{cond,motor}}{6} = 2.82\text{ W}$$

### 1.4 Copper loss

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.5\text{ m}\Omega = 3.2\text{ W per motor}$$

This loss is spread across the board planes.
