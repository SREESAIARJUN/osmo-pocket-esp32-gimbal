# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specifications for Job #47, so this design states its assumptions explicitly. Every constant lives in one config block. Replace the assumed values with your measured motor, encoder and inertia data before closing any loop.

## 0. Assumed Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| Current sense | 2- or 3-shunt inline/low-side, synchronous ADC at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, ODR 8 kHz (gyro and accel), SPI at 24 MHz |
| Joint order | Base → yaw (ψ) → roll (φ) → pitch (θ) → camera |
| MCU | Cortex-M4F/M7 with a single-precision FPU |

**Loop rates (all integer-divided from one PWM-synchronous interrupt):**

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity (inertial rate) | 4 kHz | ω_v ≈ 2π·120 rad/s |
| IMU filters and attitude | 4 kHz (decimated from 8 kHz) | — |
| Angle | 1 kHz | ω_θ ≈ 2π·25 rad/s |

The rule of thumb is to separate cascaded bandwidths by at least 5×. Each inner loop then looks approximately like unity gain to the loop outside it.

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi, \qquad \omega_e = p\,\omega_m$$

θ₀ is the encoder offset. Find it by applying v_d > 0 with θ_e = 0 and reading θ_m once the rotor settles.

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{using } i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque: $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$.

### 1.4 Current PI with pole-zero cancellation

Use the controller $C(s)=K_p + K_i/s$. Choose the zero to cancel the electrical pole R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The open loop then becomes $\omega_c/s$, and the closed loop is first-order with bandwidth ω_c.

**Discretization.** Use the forward-Euler integral with $T_c = 1/f_{pwm}$. Keep $\omega_c T_c \lesssim 0.5$, since PWM and ADC add about 1.5 samples of delay.

**Decoupling feedforward:**

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

The back-EMF term matters even for gimbal motors because their high λ_m is large relative to Vdc.

**Voltage limit (circular, linear SVPWM region):**

$$|v_{dq}| \le V_{max} = \tfrac{V_{dc}}{\sqrt3}\cdot m,\qquad m\approx0.95$$

Priority goes to v_d. Then:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

**Anti-windup (conditional integration).** Freeze the integrator whenever the output is saturated *and* the error would push it further into saturation.
