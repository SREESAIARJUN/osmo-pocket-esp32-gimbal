# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no access to the Job #42 specification, so this design uses the assumptions in §0. Each assumption is a single `constexpr` in the code, so you can substitute your real values directly.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC (code is portable C++17) |
| Motors | GM4108-class gimbal BLDC, 24 slots / 22 poles (p = 11 pole pairs), R ≈ 10 Ω, L ≈ 4 mH, K_t ≈ 0.09 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, ±1000 dps / ±8 g |
| Loop rates | Current (FOC): 20 kHz · Velocity: 4 kHz · Angle/attitude: 1 kHz · IMU fusion: 8 kHz → decimated to 1 kHz |
| Inverter | 3-phase, center-aligned PWM, 3-shunt sensing, V_bus = 12–16 V |
