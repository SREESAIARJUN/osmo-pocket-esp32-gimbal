# STM32H743 FC + 4-in-1 ESC "Nano" Stack (Job #16): Design Model & Feasibility Review

**Feasibility finding:** On a nano (20×20 mm) footprint, **80 A per motor can only be a transient burst rating. It is not a continuous rating.** The math below shows that a 20×20 board running all four motors at 80 A has an adiabatic burst budget of about 2 s. Realistic continuous current is 25–35 A per motor. I recommend we spec the product as "35 A continuous / 80 A ≤ 1 s burst" and enforce that limit in firmware.

**Architecture correction:** ArduPilot running on an STM32H743 does not drive MOSFET gates directly. The correct architecture has two parts:

- **FC:** STM32H743 running ArduPilot. It sends bidirectional DShot600.
- **ESC:** four independent ESC MCUs running AM32 or BLHeli_32-class firmware. Suitable parts include the AT32F421 or STM32G071. These MCUs do the 48 kHz commutation PWM.

The 48 kHz switching analysis applies to the ESC MCUs. The DShot and DMA analysis applies to the H743.

## 2. Conduction Loss Model (80 A burst)

### 2.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.006\,/^\circ C \Rightarrow R_{ds}(125^\circ C)\approx 1.6\ \text{m}\Omega$$

### 2.2 Six-step commutation with complementary PWM

At any instant, the motor current flows through exactly two conducting devices in series:

- One high-side FET, or its synchronous low-side partner during the PWM off-time.
- One low-side FET in the return phase.

Synchronous rectification means the freewheel path is also a FET channel rather than a body diode, except during dead time. Therefore:

$$P_{cond,motor} = I^2\,(2R_{ds}(T_j) + R_{cu})$$

$$P_{cond,motor} = 80^2 \times (2\times1.6 + 0.5)\times10^{-3} = 6400\times3.7\times10^{-3} = \mathbf{23.7\ W}$$

### 2.3 Per-FET distribution

Each phase leg conducts for 2/3 of the electrical cycle: 1/3 high-side and 1/3 low-side. The split between the high-side FET and its synchronous partner depends on duty D:

$$I_{rms,HS} = I\sqrt{D/3},\qquad I_{rms,LS} = I\sqrt{(1-D)/3 + 1/3}$$

At worst case D = 1.0 (full throttle burst):

- I_rms,HS = 80 × 0.577 = 46.2 A → P_HS = 46.2² × 1.6 mΩ = **3.41 W**
- I_rms,LS = 46.2 A (return-path conduction only) → **3.41 W**

Six FETs × 3.41 W = 20.5 W, which matches the 2R_ds term above. Copper loss adds the remaining 3.2 W.

## 3. Switching Loss Model at 48 kHz

Under complementary PWM, each motor has one hard-switched leg per PWM period: the active high-side FET.

### 3.1 V–I overlap loss

Transition time:

$$t_{r}\approx t_f \approx \frac{Q_{gs2}+Q_{gd}}{I_g} = \frac{15\ \text{nC}}{1\ \text{A}} = 15\ \text{ns}$$

Overlap energy per cycle and resulting power:

$$E_{sw} = \tfrac12 V_{bus} I (t_r+t_f) = 0.5\times25.2\times80\times30\text{ns} = 30.2\ \mu J$$

$$P_{sw} = E_{sw} f_{sw} = 30.2\ \mu J\times48\ \text{kHz} = \mathbf{1.45\ W}$$

### 3.2 Output capacitance loss

Both FETs in the leg charge and discharge their C_oss:

$$P_{oss} = 2\cdot\tfrac12 C_{oss}V^2 f = 1.5\text{nF}\times635\times48\text{k} = 0.046\ \text{W}$$

### 3.3 Body-diode reverse recovery

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 50\text{nC}\times25.2\times48\text{k} = 0.060\ \text{W}$$

### 3.4 Dead-time diode conduction

There are two dead-time intervals per period:

$$P_{dt} = 2\,V_f\,I\,t_{dt}\,f_{sw} = 2\times0.8\times80\times100\text{ns}\times48\text{k} = \mathbf{0.61\ W}$$

### 3.5 Gate drive loss

This loss is dissipated in the driver and gate resistors, not in the FET:

$$P_g = 2\,Q_g V_{drv} f_{sw} = 2\times50\text{nC}\times10\times48\text{k} = 0.048\ \text{W}$$

### 3.6 Switching subtotal per motor

| Term | Power |
|---|---|
| V–I overlap | 1.45 W |
| Dead-time diode | 0.61 W |
| Q_rr | 0.06 W |
| C_oss | 0.05 W |
| Gate | 0.05 W |
| **Total** | **≈ 2.2 W** |

**Sensitivity:** P_sw scales linearly with f_sw. At 24 kHz it is about 1.1
