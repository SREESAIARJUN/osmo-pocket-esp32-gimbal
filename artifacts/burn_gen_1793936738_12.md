## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)],\qquad \alpha \approx 0.0055\ \text{K}^{-1}$$

At a burst-end junction temperature T_j = 125 °C, R_DS = 1.2 × 1.55 = **1.86 mΩ**.

### 1.2 Current path topology (6-step trapezoidal with synchronous rectification)

At any instant, exactly two phase legs carry I:
- The PWM leg: the high-side conducts for duty D, and the synchronous low-side conducts for (1−D).
- The return leg: its low-side conducts for 100% of the 60° sector.

So **two MOSFETs are always in series with the motor current**, regardless of D.

Per channel:
$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

Per individual FET, averaged over the electrical cycle (each FET is active 1/3 of the time):
$$P_{HS} = \tfrac{1}{3}\,I^2 R_{DS}\,D,\qquad P_{LS} = \tfrac{1}{3}\,I^2R_{DS}\,(1-D) + \tfrac{1}{3}\,I^2R_{DS}$$

> The low-side FETs run hotter. Each one also serves as the 100% return path. Place them nearest the thermal vias and ground pour.

### 1.3 Numbers at 80 A

| Term | Calculation | Result |
|---|---|---|
| MOSFET conduction, T_j = 125 °C | 2 × 80² × 1.86 mΩ | **23.8 W** |
| MOSFET conduction, T_j = 25 °C (burst start) | 2 × 80² × 1.2 mΩ | 15.4 W |
| PCB copper, 0.25 mΩ path (in + out) | 80² × 0.25 mΩ | 1.6 W |
| Current-sense shunt, if used (0.25 mΩ) | 80² × 0.25 mΩ | 1.6 W |
| **Per channel, hot** | | **≈ 27 W** |
| **4 channels, all at 80 A** | | **≈ 108 W** |

### 1.4 Electrothermal stability

The closed-loop junction temperature is
$$T_j = T_a + R_\theta\, 2I^2R_{25}[1+\alpha(T_j-25)]$$

It has a finite solution only if
$$\boxed{\;2I^2R_{25}\,\alpha\,R_\theta < 1\;}$$

At 80 A this gives R_θ < 1 / (2 × 6400 × 0.0012 × 0.0055) = **11.8 K/W** per channel-pair. A nano board's steady-state R_θ to air is easily 5–10 K/W per channel with no airflow. That is why 80 A is a **burst-only** rating. See §3.

## 2. Switching Loss Model at 48 kHz

In 6-step mode, only one leg switches per sector. That means one hard-switched HS turn-on/turn-off pair per PWM cycle, plus the synchronous low-side.
