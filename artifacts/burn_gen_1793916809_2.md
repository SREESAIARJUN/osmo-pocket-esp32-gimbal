## 1. FOC Current Loop (Innermost, 20 kHz)

### 1.1 Transforms

The motor uses an electrical angle θₑ = p·θₘ − θ_offset.

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau_m = \tfrac32 p\lambda\, i_q = K_t\, i_q$$

### 1.3 Decoupled PI with Pole–Zero Cancellation

Once the cross-coupling terms are fed forward, each axis reduces to the plant 1/(Ls + R).

1. Choose the PI controller as C(s) = K_p + K_i/s, with K_p = L·ω_c and K_i = R·ω_c.
2. The controller zero then cancels the plant pole, giving a closed loop of ω_c/(s + ω_c).
3. Set the current bandwidth to ω_c ≈ 2π·1.5 kHz, which is below f_PWM/10.

The commanded voltages add the decoupling and back-EMF feedforward terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e(L i_d + \lambda)$$

### 1.4 Voltage Limiting and Anti-Windup

**Circular limit.** The voltage vector must stay inside the linear SVPWM region:

$$|v_{dq}| \le V_{bus}/\sqrt3$$

The d axis has priority. The q axis receives whatever voltage remains:

$$v_{q,max} = \sqrt{V_{max}^2 - v_d^2}$$

**Back-calculation anti-windup.** When the output saturates, the integrator is pulled back toward the limit:

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u_{unsat}),\qquad K_{aw} = K_i/K_p$$

### 1.5 SVPWM via Min-Max Zero-Sequence Injection

Each phase duty cycle is computed as:

$$d_x = \tfrac12 + \frac{v_x - \tfrac12(\max v + \min v)}{V_{bus}}$$
