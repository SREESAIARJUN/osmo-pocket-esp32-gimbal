# STM32H743 AIO + 80 A-Class 4-in-1 ESC: Engineering Model

This package covers the power-stage loss model, the transient thermal model, ArduPilot bi-directional DShot600 timer/DMA allocation, and reference netlists.

> **Read before using.** The numbers below follow from stated assumptions, not from a specific MOSFET datasheet. Replace every parameter marked ⟨P⟩ with the values for your selected part before release. Section 3 contains a feasibility finding that the requirement owner must resolve: **80 A per channel in a 20×20 mm form factor is not thermally viable beyond sub-second bursts.**

---

## 0. System Architecture and Assumptions

```
          6S LiPo (25.2 V max / 22.2 V nom)
                    │
   ┌────────────────┴───────────────────────────────┐
   │  4-in-1 ESC board                               │
   │  4 × [ESC MCU (AT32F421/STM32G071, AM32)        │
   │       + 3-phase gate driver + 6 × N-MOSFET]     │
   │  48 kHz center-aligned PWM, sync. rectification │
   └───────▲──────────────────────────┬──────────────┘
           │ DShot600 bidir (×4)      │ VBAT, CURR, GND
   ┌───────┴──────────────────────────▼──────────────┐
   │  FC: STM32H743 @ 400/480 MHz, ArduPilot         │
   └─────────────────────────────────────────────────┘
```

**Clarification:** the H743 does not commutate the motors. Each ESC channel has its own MCU generating the 48 kHz PWM. The H743 only issues DShot commands and decodes the eRPM telemetry.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | Worst case (6S full charge) for switching loss |
| I_pk | 80 A | Burst phase current per channel ⟨requirement⟩ |
| f_sw | 48 kHz | ESC PWM frequency |
| R_ds,25 | 1.5 mΩ ⟨P⟩ | 40 V, 3.3×3.3 mm class FET @ V_gs = 10 V |
| α | 0.0045 /K ⟨P⟩ | R_ds(on) temperature coefficient |
| t_r, t_f | 20 ns each ⟨P⟩ | Effective V-I overlap with a ~1.5 A driver and 4.7 Ω R_g |
| Q_g | 40 nC ⟨P⟩ | Total gate charge @ 10 V |
| Q_rr | 50 nC ⟨P⟩ | Body-diode reverse recovery |
| Q_oss | 40 nC ⟨P⟩ | Output charge @ V_bus |
| V_f | 0.8 V | Body-diode forward drop @ 80 A |
| t_dt | 200 ns | Dead time per edge |
| R_cu | 0.5 mΩ | PCB copper + solder path per conducting phase pair |

**Topology:** 6-step trapezoidal with complementary (synchronous) PWM. Exactly two phase legs carry current in any commutation sector.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.5 mΩ × 1.45 ≈ **2.2 mΩ**. Use 2.4 mΩ to cover the batch-max spread (≈1.1× typical).
