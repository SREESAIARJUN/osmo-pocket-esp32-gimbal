## 0. Architecture Decision and Assumptions

### 0.1 Partitioning

The STM32H743 should **not** commutate the motors directly. ArduPilot has no in-tree ESC firmware, and running four sensorless 6-step or FOC loops on the flight MCU would compromise the scheduler. The architecture is therefore:

```
                 ┌──────────────── STM32H743VIT6 (ArduPilot) ────────────────┐
 IMU(SPI1/SPI4)──┤ TIM1_CH1..CH4 ── bidir DShot600 ──► 4× ESC MCU (AT32F421 / │
 Baro (I2C2)     │                                      STM32G071, AM32 or    │
 OSD (SPI2)      │ ADC: VBAT, IBAT                      BLHeli_32-compatible) │
 SDMMC1, UARTs   └───────────────────────────────────────────────────────────┘
                                                            │ 6× PWM each
                                         3-phase gate driver (e.g. FD6288Q)
                                                            │
                                         6× N-MOSFET per motor (24 total)
```

## 1. Conduction Loss Model

### 1.1 Topology Current Path

In 6-step commutation with synchronous rectification, two legs carry current in any 60° sector:

- **PWM leg:** The high-side (HS) conducts for duty D. The low-side (LS) conducts for (1−D), minus dead time.
- **Static leg:** The LS of the return phase is fully on.
