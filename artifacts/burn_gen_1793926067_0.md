# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original Job #7 specification, so this design states its assumptions explicitly. Every assumption is a parameter in the code. Replace the values with your hardware before tuning.

## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms
Electrical angle: θ_e = p·θ_m − θ_off.

**Clarke** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park**:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park**:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Current PI with decoupling and back-EMF feedforward

$$v_d = PI_d(i_d^* - i_d) - \hat\omega_e L i_q$$
$$v_q = PI_q(i_q^* - i_q) + \hat\omega_e L i_d + \hat\omega_e\lambda_m$$

Pole-zero cancellation for a closed-loop bandwidth ω_c (choose ω_c ≤ 2π·f_s/10; ≈ 2π·1.5 kHz here):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This makes the closed loop ≈ ω_c/(s + ω_c).

The voltage vector is limited to the inscribed SVPWM circle |v| ≤ V_dc/√3. v_d has priority, and v_q gets the remainder. Anti-windup uses back-calculation.

### 1.4 SVPWM (min-max injection, equivalent to sector SVPWM)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical plant per axis

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta) - B\omega - \tau_{fric} - \tau_{dist}$$

### 2.2 Velocity feedback

Velocity feedback is a blend of two signals:

- **Inertial rate.** The gyro rate of the camera, projected onto the motor axis (Section 2.5). It is low-noise and gives true inertial stabilization.
- **Joint rate.** The encoder rate from a PLL tracking observer.

**Encoder PLL observer** (ζ = 1, ω_n ≈ 2π·300 Hz):

$$e = \operatorname{wrap}(\theta_{meas} - \hat\theta),\quad \hat\omega \mathrel{+}= K_i e\,T,\quad \hat\theta \mathrel{+}= (\hat\omega + K_p e)\,T$$

with K_p = 2ζω_n and K_i = ω_n².

### 2.3 Discrete PID (2-DOF, filtered D, back-calculation anti-windup)

$$u = K_p(b\,r - y) + I + D + u_{ff}$$
$$D_k = \frac{2T_f - T}{2T_f + T}D_{k-1} - \frac{2K_d}{2T_f + T}(y_k - y_{k-1})$$

The derivative is taken on the measurement and discretized with Tustin. N = T_d/T_f ≈ 8–20.

$$I_{k+1} = I_k + K_i T\,e_k + \frac{T}{T_t}\big(\operatorname{sat}(u_k) - u_k\big)$$

The tracking time constant is T_t = √(T_i T_d), or T_t = T_i when K_d = 0.

### 2.4 Tuning by bandwidth separation

Keep each loop's bandwidth at least 4–5× below the loop inside it:

$$\omega_{pos} \le \omega_{vel}/5 \le \omega_c/25$$

**Velocity PI** (plant K_t/(Js)), with crossover ω_v (e.g. 2π·80 Hz), PI zero at ω_v/4:

$$K_{p,v} = \frac{J\,\omega_v}{K_t}\ [\text{A/(rad/s)}],\qquad K_{i,v} = K_{p,v}\,\frac{\omega_v}{4}$$
