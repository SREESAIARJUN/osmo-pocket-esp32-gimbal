# STM32H743 Nano FC + 80 A 4-in-1 ESC: Engineering Model (Job #38)

## 0. Architecture and Assumptions

The STM32H743 does not drive the MOSFETs. The H743 runs ArduPilot and generates bidirectional DShot600. Each motor channel on the 4-in-1 ESC has its own ESC MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32) that generates the 48 kHz PWM. The loss model therefore applies to the ESC board, and the DMA/timer model applies to the H743.

All results below are computed from these assumptions. Replace them with datasheet values for your selected parts and re-run the equations.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V |
| Burst phase current (per motor) | I_ph | 80 A |
| MOSFET R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ (40–60 V, PQFN 3.3×3.3 / 5×6) |
| R_DS(on) temperature coefficient | α | 0.005 /K |
| Junction temperature (design point) | T_j | 125 °C |
| Rise / fall time | t_r, t_f | 15 ns each |
| Body-diode reverse recovery charge | Q_rr | 30 nC |
| Energy-equivalent output capacitance | C_oss(er) | 1.2 nF |
| Total gate charge | Q_g | 50 nC at 10 V |
| Dead time | t_dt | 50 ns per edge |
| Body-diode forward voltage | V_f | 0.8 V |
| PWM frequency | f_sw | 48 kHz |
| Copper/solder path resistance per phase path | R_cu | 0.5 mΩ |
| Board (nano form factor) | — | ~20×20 mm, 8-layer, 2 oz |

The 80 A figure is interpreted as **phase (motor) current**. Battery current is lower:

I_batt ≈ D · I_ph

## 1. Conduction Loss Model

**Commutation model.** In 6-step trapezoidal commutation with synchronous (complementary) PWM, two phases conduct at any instant. During the on-time, current flows through HS(x) and LS(y). During the off-time, it flows through LS(x) and LS(y). In both cases there are exactly **two MOSFET channels in series** in the current path.

**Hot on-resistance.**

R_hot = R₂₅ · [1 + α (T_j − 25)] = 1.0 mΩ · (1 + 0.005·100) = **1.5 mΩ**

**Ripple correction.** With ripple ratio r = ΔI/I_ph:

I_rms² = I_ph² · (1 + r²/12)

For a typical r = 0.3, the factor is 1.0075. It is neglected below.

**Per-channel conduction loss.**

P_cond = 2 · I_ph² · R_hot = 2 · 6400 · 1.5×10⁻³ = **19.2 W**

**Copper loss.**

P_cu = I_ph² · R_cu = 6400 · 0.5×10⁻³ = **3.2 W**

**Per-device peak.** While a device conducts, it dissipates I²R_hot = **9.6 W**. Each device conducts roughly ⅓ of an electrical cycle, so its average is ≈ 3.2 W.

## 2. Switching Loss Model at 48 kHz

Only the PWM-modulated leg hard-switches. The high-side turn-on, with reverse recovery from the opposing low-side body diode, dominates.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½ · V_bus · I_ph · (t_r + t_f) · f_sw = ½·25.2·80·30 ns·48 kHz | **1.452 W** |
| Reverse recovery | Q_rr · V_bus · f_sw = 30 nC·25.2·48 kHz | **0.036 W** |
| Coss (both devices in leg) | 2 · ½ · C_oss(er) · V_bus² · f_sw | **0.037 W** |
| Dead-time diode conduction | V_f · I_ph · 2t_dt · f_sw = 0.8·80·100 ns·48 kHz | **0.307 W** |
| Gate drive (mostly in driver) | 2 · Q_g · V_GS · f_sw | 0.048 W |

**Per-channel switching loss (in the MOSFETs):**

P_sw ≈ **1.83 W**

**Sensitivities:**

- **Rise/fall time:** P_sw scales linearly with t_r + t_f. Gate resistors that slow edges to 30 ns each double the overlap term to about 2.9 W.
- **PWM frequency:** dropping from 48 kHz to 24 kHz halves P_sw, at the cost of higher current ripple and audible noise.
- **Dead time:** this is the second-largest term. Use the minimum dead time the driver supports safely.
