# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #28): Power Stage, Thermal, and DShot Design Model

## 0. Scope and Assumptions

You didn't specify MOSFETs, gate driver, board size, or the ESC MCU, so I state every assumption below. The model is fully parametric: substitute datasheet values and all results follow. **Values marked ⚠ must be confirmed against your selected parts before layout freeze.**

**Architectural note:** The STM32H743 runs ArduPilot as the *flight controller*. It does not commutate the motors. Each motor (or all four) is driven by a separate ESC MCU running AM32 or BLHeli_32, for example an AT32F421 or STM32G071. The H743 sends bidirectional DShot600 to that ESC MCU. The model below covers both domains.
