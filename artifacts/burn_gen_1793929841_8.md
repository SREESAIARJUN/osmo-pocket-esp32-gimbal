# STM32H743 FC + 4-in-1 ESC (Job #48): Power-Stage Loss Model, Thermal Budget, and Bi-Directional DShot600 Allocation

## 0. Scope, Assumptions, and an Architecture Note

I don't have the Job #48 requirements package, BOM, or layout. Everything below is built on **stated, swappable assumptions**. Replace every value marked **[A]** with datasheet or measured numbers before design review. The equations are general. The numbers are illustrative.

**Architecture clarification.** ArduPilot runs on the STM32H743 flight controller. It does not run the ESC commutation loop. The 48 kHz switching happens on four ESC MCUs running AM32 or BLHeli_32 (e.g., AT32F421 or STM32G071). The design therefore splits into three domains:

| Domain | Owner | Covered in |
|---|---|---|
| Power stage losses and thermal | ESC hardware | §1–5 |
| ESC PWM generation at 48 kHz | ESC MCU firmware | §3.6 |
| DShot600 bidir, timers/DMA | H743 + ArduPilot hwdef | §6 |
