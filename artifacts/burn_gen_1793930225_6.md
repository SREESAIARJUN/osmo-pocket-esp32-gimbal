## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GM4108H-120T), 12N14P → **pole pairs p = 7**, R ≈ 11 Ω, L ≈ 4 mH (phase), K_t ≈ 0.1 N·m/A. Low-KV, high-R motors are typical for gimbals. |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701), SPI |
| MCU | STM32G474 @ 170 MHz with FPU and CORDIC |
| Inertial sensors | 2× ICM-42688-P on the camera plate, on separate SPI buses, FSYNC tied together |
| Loop rates | Current (FOC) 20 kHz · velocity 4 kHz · attitude/angle 1 kHz · IMU ODR 8 kHz, decimated to 4 kHz |
| Gimbal order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y), payload frame FRD |
