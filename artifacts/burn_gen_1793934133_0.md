# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the original spec for Job #17, so this design uses the assumptions below. Every parameter is a named constant, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701 class) on each motor shaft |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with FPU, center-aligned PWM, ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, rigidly mounted with a known lever arm |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Angle 1 kHz → Attitude fusion 1 kHz |

## 1. Control Architecture

```
 Attitude setpoint ─► [Angle P + ω_ff] ─ω*─► [Velocity PI] ─iq*─┬─► [Current PI d/q] ─► SVPWM ─► Inverter ─► Motor
        ▲                  1 kHz                4 kHz            │        20 kHz
        │                                                        ▼
        │                                          [Anti-cogging FF iq_cog(θm)] (adaptive)
        │
 [Mahony fusion] ◄── [Dual-IMU combine] ◄── [AAF + notch + LPF] ◄── ICM-42688-P ×2
        │  (camera attitude: angle loop outer feedback)
        └─ gyro ω (body rate, projected per joint) → velocity loop feedback (blended with encoder)
```

**Feedback assignment (standard for camera gimbals):**

- **Current loop:** phase currents plus encoder electrical angle θₑ.
- **Velocity loop:** IMU gyro rate projected onto the joint axis. This is what the camera actually experiences. It is blended with encoder-derived rate at high frequency for robustness.
- **Angle loop:** fused camera attitude from the IMUs, resolved per joint.

## 2. Field-Oriented Control Equations

### 2.1 Coordinate transforms (amplitude-invariant)

**Electrical angle:**
$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$
where p is the pole-pair count and θ_off is the encoder-to-rotor offset found at calibration.

**Clarke transform**, assuming i_a + i_b + i_c = 0:
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 PMSM model in the dq frame

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

**Torque (surface PM, L_d ≈ L_q):**
$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 2.3 Current PI controller with decoupling

**Control law:**
$$v_d^* = K_{p,i}e_d + K_{i,i}\!\int e_d\,dt - \omega_e L i_q$$
$$v_q^* = K_{p,i}e_q + K_{i,i}\!\int e_q\,dt + \omega_e L i_d + \omega_e\lambda_m$$

**Tuning by pole-zero cancellation.** The plant is 1/(Ls+R). Choosing the gains below makes the closed loop first-order, $i/i^* = \omega_{ci}/(s+\omega_{ci})$:
$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

**Bandwidth choice.** Use $\omega_{ci} \le 2\pi f_{pwm}/20$. At 20 kHz this gives ω_ci ≈ 2π·1000 rad/s.

**Voltage limiting.** Apply a circular limit:
$$\sqrt{v_d^2+v_q^2}\le V_{dc}/\sqrt3$$
d-axis priority is used. The excess is fed back to the integrators by back-calculation anti-windup with gain $K_{aw}=1/K_{p}$.

> **High-R gimbal motors.** If R > 10 Ω and you have no current sensing, the loop degrades to voltage-mode control: $v_q = R\,i_q^* + \omega_e\lambda_m$. The code supports this through `kVoltageMode`.

### 2.4 SVPWM (min-max zero-sequence injection)

This is equivalent to SVPWM and cheaper to compute:
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\left[\max(v_{abc}) + \min(v_{abc})\right],\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 3. Cascaded Velocity and Angle Control

### 3.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

The current loop is fast (ω_ci ≫ ω_v), so treat it as unity gain. The velocity plant is then:
$$P_v(s) = \frac{K_t}{Js+B}\approx\frac{K_t}{Js}$$

### 3.2 Velocity PI controller (symmetric optimum / bandwidth placement)

**Control law:**
$$i_q^* = K_{p,v}\,e_\omega + K_{i,v}\!\int e_\omega\,dt + i_{q,cog}(\theta_m) + i_{q,ff}$$

**Gains for crossover ω_v:**
$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{a^2}$$

- a = 2 to 4 gives phase margin $\phi_m = \arctan\!\left(\frac{a^2-1}{2a}\right)$; a = 3 gives ≈ 53°.
- Typical values: ω_v ≈ 2π·80–150 rad/s, set at least 5× below ω_ci and well below the first structural mode.
