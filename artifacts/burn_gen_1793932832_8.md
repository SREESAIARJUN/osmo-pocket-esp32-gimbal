# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

I don't have the Job #44 specification, so this design uses the assumptions in §0. Replace those values with your actual motor, encoder, and mounting parameters.

---

## 0. Assumptions and Loop Architecture

| Item | Value (default) |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5 Ω, L = 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (e.g. AS5048/MA730), sampled each PWM period |
| Gimbal order | Yaw (outer, z), Roll (middle, x), Pitch (inner, y) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI. Placed symmetric about the pitch pivot (r₂ = −r₁) and rotated 180° about z relative to each other |

The control runs as four nested loops:

```
 20 kHz  ── FOC current loop (PWM-synchronous ISR)
  8 kHz  ── IMU ODR (both chips, FIFO or DRDY) → filters → fusion
  2 kHz  ── velocity loop (camera-body rate, gyro feedback) + anti-cogging FF
  1 kHz  ── attitude estimator (Mahony) + angle loop
```

Each loop's bandwidth should be at most about 1/5 of the loop it feeds.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)$$

**Park transform**, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Design

The dq-frame plant is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Decoupling feed-forward**

$$v_d^{ff}=-\omega_e L i_q,\qquad v_q^{ff}=\omega_e L i_d+\omega_e\lambda_m,\qquad \lambda_m=\tfrac{2}{3}\tfrac{K_t}{p}$$
