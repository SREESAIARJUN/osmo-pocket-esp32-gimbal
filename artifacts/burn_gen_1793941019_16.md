# STM32H743 AIO Flight Controller with 4-in-1 80A ESC: Design Model

This document derives:

1. Conduction losses at 80 A burst
2. Switching losses at 48 kHz
3. Thermal transient behaviour
4. ArduPilot bidirectional DShot600 timer/DMA allocation
5. Reference netlists

**Before using any number here, note these constraints:**

- **The H743 does not generate the 48 kHz motor PWM.** In a 4-in-1 design the MOSFET bridges are commutated by dedicated ESC MCUs running AM32 or BLHeli_32, such as AT32F421 or STM32G071, one per motor. The H743 runs ArduPilot and talks to them over bidirectional DShot600. 48 kHz is an ESC-firmware setting.
- **80 A on a nano (20×20 mm) board is physically non-sustainable.** The thermal model below shows it lasts about 1 s before limits on a 20×20 board, and about 4–5 s on a 30.5-pattern board. Treat "80 A" strictly as a burst rating and specify a burst duration.
- **The MOSFET parameters are assumed representative values for a 40 V, 3.3×3.3 DFN part.** Substitute your actual datasheet values into the equations; the model is fully parametric.
- **The netlists are net-level (signal connectivity by pin function).** Verify pin numbers against the exact datasheet revision and package before layout.

## 2. Conduction Loss Model

### 2.1 Current paths in 6-step complementary PWM

In each 60° commutation step, two phases carry I_ph:

- **Leg A (PWM leg):** the high-side conducts for duty D. The complementary low-side conducts for (1−D) during freewheeling.
- **Leg B (return leg):** the low-side conducts 100 % of the step.

Instantaneous conduction loss per motor channel:

$$P_{cond} = I_{ph}^2 R_{hot}\,[\,D + (1-D) + 1\,] = 2\,I_{ph}^2 R_{hot}$$

This is independent of D, because synchronous rectification always keeps two FET channels in series with the winding.
