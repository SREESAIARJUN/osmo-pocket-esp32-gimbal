## 1. FOC Inner Current Loop

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), wrapped to [0, 2π).

**Clarke** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupled PI

The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Control law.** A PI controller acts on each axis, with feed-forward decoupling and back-EMF compensation (λₘ = Kt/(1.5p)):

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Tuning by pole-zero cancellation.** The closed loop becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Constraint: ω_c ≤ 2π·f_pwm/10–20, accounting for the 1.5-sample computational and PWM delay. With f_pwm = 20 kHz, choose ω_c = 2π·1500 rad/s.

**Discretization.** Use the forward-Euler integrator at T_s = 50 µs.

**Anti-windup.** Clamp the integrator and use back-calculation:

$$x_{k+1} = x_k + T_s\left[K_i e_k + K_{aw}(v_{sat}-v_{unsat})\right],\qquad K_{aw}=K_i/K_p$$

**Voltage limit.** The SVPWM linear region is a circle of radius |v| ≤ V_dc/√3. Prioritize d-axis voltage:

$$v_d \leftarrow \text{clamp}\!\left(v_d, \pm \tfrac{V_{dc}}{\sqrt3}\right),\qquad v_q \leftarrow \text{clamp}\!\left(v_q,\ \pm\sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}\right)$$

### 1.3 SVPWM (min-max zero-sequence injection)

This is equivalent to sector-based SVPWM:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

**Angle latency compensation.** Advance θₑ by 1.5·T_s·ωₑ to compensate for sample-to-PWM-update delay.
