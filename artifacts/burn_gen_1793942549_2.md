## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, CORDIC optional |
| Motor | 12N14P gimbal BLDC (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 1.8 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701/AS5048), SPI, read every PWM period |
| IMU | 2 × ICM-42688-P, gyro and accel at 8 kHz ODR, SPI at 24 MHz, FIFO off, data-ready IRQ |
| Bus | 12–16 V |

**Loop rates (all phase-locked to the PWM timer):**

```
PWM / current loop (FOC)     20 kHz   Ts_i = 50 µs   ← ADC injected trigger at PWM center
Velocity loop                 4 kHz   Ts_v = 250 µs  ← every 5th current tick
IMU sample + filtering        8 kHz                  ← data-ready IRQ, decimated to 4 kHz
Attitude / angle loop         1 kHz   Ts_θ = 1 ms
```

**Signal flow per axis:**

```
θ_ref ─►(Σ)─► P_θ ─(+ω_ff)─►(Σ)─► PI_ω ─► τ_cmd/Kt ─(+ i_cog_ff)─► i_q,ref ─► PI_iq ─► SVPWM
          ▲−                  ▲−                                                  │
     θ_est (fused IMU)    ω_axis (fused gyro → joint rate)        i_q (ADC+Park) ◄┘
```

The **velocity loop feeds back the fused gyro rate**, not the differentiated encoder. The encoder is used only for electrical commutation and cogging phase. This is the main reason gimbals achieve high stabilization bandwidth.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m, with offset θ_0 found during alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a, \qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of the same matrix.

### 1.2 Plant Model and PI Design

In the rotor frame (SPM motor, L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

With feed-forward decoupling, each axis reduces to $G(s) = 1/(Ls + R)$.

A PI controller $C(s) = K_p + K_i/s$ with **pole-zero cancellation** ($K_i/K_p = R/L$) gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c, \qquad K_i = R\,\omega_c, \qquad T_{cl}(s) = \frac{\omega_c}{s+\omega_c}$$

**Choosing ω_c.** Choose ω_c ≤ 2π·f_PWM/20 to keep phase loss from the 1.5-sample delay (computation + PWM update) under ~15°. At 20 kHz this gives ω_c ≈ 2π·1 kHz. For the assumed motor: K_p = 11.3 V/A, K_i = 35 kV/(A·s).
