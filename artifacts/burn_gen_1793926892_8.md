# STM32H743 Nano AIO Flight Controller with 4-in-1 80A ESC: Systems Architecture Model

## 0. Scope, Assumptions, and Architectural Corrections

I have no project documentation for "Job #12", so every parameter below is a stated assumption. Swap in your datasheet values; the equations are written to be re-evaluated.

**Architectural correction.** The STM32H743 cannot commutate four BLDC motors itself in this architecture. The standard and recommended split is:

- **Flight controller (FC):** STM32H743, running ArduPilot. It sends bi-directional DShot600 to the ESCs.
- **4× ESC MCUs:** e.g., AT32F421 running AM32, or EFM8BB51 running Bluejay. Each handles one motor's six-step commutation, BEMF zero-cross detection, and the 48 kHz PWM.

The "48 kHz switching" analysis therefore applies to the ESC MCUs. The H743 analysis is limited to DShot timers and DMA.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

At T_j = 125 °C: R_ds = 0.70 × 1.55 = **1.085 mΩ**.

### 1.2 Six-step operation with complementary (synchronous) PWM

During each 60° commutation sector, one phase is PWM-chopped and one is held on. Current always flows through exactly two FET channels in series:

- **Chopped leg:** the high-side FET for duty D, then the synchronous low-side FET for (1 − D).
- **Held leg:** the low-side FET for 100% of the sector.

So the conduction loss per channel is independent of D:

$$P_{cond,ch} = I^2 \cdot 2R_{ds}(T_j) = 80^2 \cdot 2.17\,\text{m}\Omega = \mathbf{13.9\ W}$$

Copper loss adds:

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W}$$

### 1.3 Per-FET distribution

Each FET is active in 2 of 6 sectors (120 electrical degrees).

| FET role | Average conduction loss |
|---|---|
| Chopped high-side (D = 0.8) | (1/3)·D·I²R = 1.85 W |
| Its synchronous low-side | (1/3)(1−D)·I²R = 0.46 W |
| Held low-side | (1/3)·I²R = 2.31 W |

Because the chopping assignment rotates, the worst-case single FET averages about 2.3 W (conduction only). Note that the instantaneous loss in a conduction window is I²R = 6.9 W. This matters for die-level transient temperature at low eRPM.

### 1.4 Thermal runaway check

Electrothermal feedback is stable if:

$$\frac{\partial P}{\partial T}\cdot R_{th} < 1 \;\Rightarrow\; I^2 R_{ds,25}\,\alpha\,R_{th,j\text{-}a} < 1$$

For one FET: 6400 × 0.7e-3 × 0.0055 × R_th < 1, which gives R_th < 40 K/W. This is easily met. Runaway is not the limit; board heat capacity is (see §3).

## 2. Switching Loss Model at 48 kHz

Only the chopped leg switches, so there are two FETs per channel and two hard edges per period.

### 2.1 V–I overlap (hard switching)

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(30\text{n})(48\text{k}) = \mathbf{1.45\ W}$$

### 2.2 Dead-time body diode conduction

$$P_{dt} = V_f\, I\, (2t_{dt})\, f_{sw} = 0.8 \times 80 \times 100\text{n} \times 48\text{k} = \mathbf{0.31\ W}$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.06\ W}$$

(This term also adds turn-on current overshoot, which partly appears in 2.1.)

### 2.4 Output capacitance

$$P_{oss} \approx Q_{oss} V_{bus} f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.05\ W}$$

### 2.5 Gate drive

This loss is dissipated in the driver and gate resistors, not the FET.

$$P_g = 2\, Q_g V_{gs} f_{sw} = 2(50\text{n})(10)(48\text{k}) = \mathbf{0.05\ W}$$

### 2.6 Per-channel and board totals at 80 A burst (T_j = 125 °C)

| Loss | Per channel | 4 channels |
|---|---|---|
| Conduction (FET) | 13.9 W | 55.6 W |
| Switching + dead-time + Qrr + Coss | 1.87 W | 7.5 W |
| Copper | 3.2 W | 12.8 W |
| Gate drive | 0.05 W | 0.2 W |
| **Total** | **19.0 W** | **≈76 W** |
