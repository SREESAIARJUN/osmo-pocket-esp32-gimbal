# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #37 specification, so this design uses a typical 3-axis camera-gimbal baseline. Every assumed value is a named constant, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Driver | 3-phase, 2 low-side shunts per axis, 24 V bus, center-aligned PWM at 20 kHz |
| Encoder | 14-bit magnetic (AS5048A / MT6701 class), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Joint order | Base → Yaw → Roll → Pitch → Camera |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz, in the ADC-trigger ISR | ~1.5 kHz |
| Velocity (gyro feedback) | 4 kHz | ~60 Hz |
| Angle (attitude feedback) | 1 kHz | ~8 Hz |
| IMU acquisition | 8 kHz, SPI DMA, decimated ×2 to 4 kHz after filtering | — |

The bandwidths are separated by roughly 5–10× per stage. Without that separation, the stability argument for the cascade (each inner loop treated as unity gain) fails.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \pmod{2\pi}, \quad p = 7$$

**Clarke transform** (amplitude-invariant, using two shunts and i_a + i_b + i_c = 0):

$$i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e, \qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI tuning by pole-zero cancellation

The dq-frame motor model is:

$$L\,\dot i_d = v_d - R\,i_d + \omega_e L\,i_q$$

$$L\,\dot i_q = v_q - R\,i_q - \omega_e L\,i_d - \omega_e \lambda_m$$

Each axis behaves as the first-order plant G(s) = 1 / (Ls + R). Choose the PI controller C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_c, \qquad K_i = R\,\omega_c$$

The PI zero then cancels the plant pole, and the closed loop becomes a first-order system with bandwidth ω_c:

$$\frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$

**Bandwidth limit.** Choose ω_c ≤ 2π·f_PW
