## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

$\theta_0$ is the encoder offset, found by aligning the d-axis with a fixed voltage vector $V_d$ at $\theta_e = 0$.

### 1.2 Clarke transform (amplitude-invariant, 2 shunts, $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant and PI design

The dq-axis motor model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Use pole-zero cancellation with the PI controller $C(s) = K_p + K_i/s$. Choose:

$$K_p^{(i)} = L\,\omega_{ci},\qquad K_i^{(i)} = R\,\omega_{ci}$$

The closed loop then becomes $\frac{\omega_{ci}}{s+\omega_{ci}}$. Choose $\omega_{ci} \le 2\pi f_c/10$, so with $f_c$ = 20 kHz, $\omega_{ci} ≈ 2\pi\cdot 1500$.

**Decoupling plus back-EMF feedforward:**

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 Discretization (Tustin / trapezoidal integrator)

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i\frac{T}{2}(e_k + e_{k-1}) + K_{aw}\,T\,(u^{sat}_k - u_k)$$

The last term is back-calculation anti-windup, with $K_{aw} ≈ K_i/K_p$.

### 1.6 Voltage limiting (circular, d-axis priority)

$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad m_{max}≈0.95$$

$$v_d^{sat} = \text{clamp}(v_d^*, \pm V_{max}),\quad v_q^{sat} = \text{clamp}\!\left(v_q^*, \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\ \ v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\ \ v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Latency compensation:** The PWM update takes effect about $1.5T$ later, so use $\theta_e + 1.5\,\omega_e T$ in the inverse Park transform.

## 2. Velocity Estimation (Encoder PLL)

Differentiating a 14-bit encoder is too noisy. Use a type-II PLL instead.

The phase error, wrapped to $(-\pi,\pi]$:

$$\varepsilon_k = \text{wrap}(\theta_{m,k} - \hat\theta_k)$$

The update equations are:

$$\hat\omega_{k+1} = \hat\omega_k + K_{i}^{pll} T\,\varepsilon_k$$

$$\hat\theta_{k+1} = \hat\theta_k + T(\hat\omega_k + K_p^{pll}\varepsilon_k)$$

For critical damping at bandwidth $\omega_{pll}$, set $K_p^{pll} = 2\omega_{pll}$ and $K_i^{pll} = \omega_{pll}^2$. Typical $\omega_{pll} = 2\pi\cdot 400$.

**Important for a gimbal:** The stabilizing velocity loop should use the **camera gyro rate** mapped to the joint, not only the encoder rate. That is what rejects base disturbances (§4). The encoder PLL is used for commutation, cogging lookup, and as a fallback.
