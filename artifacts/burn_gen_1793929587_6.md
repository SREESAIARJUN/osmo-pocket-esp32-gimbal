## 0. Architecture Clarification

The DShot requirement shapes the whole architecture. **Bi-directional DShot is an FC→ESC protocol**, so the H743 cannot also be the commutation MCU. ArduPilot does not run sensorless BLDC commutation, and a 48 kHz six-step loop for four motors on the same core as EKF3 is not viable.

**Topology:**

```
            ┌──────────── STM32H743 (ArduPilot) ────────────┐
            │ TIM1 CH1..CH4 ── BDShot600 (bidir, 1-wire) ──►│
            └───────┬────────┬────────┬────────┬────────────┘
                    │        │        │        │
               AT32F421  AT32F421  AT32F421  AT32F421   (AM32 firmware, 48 kHz PWM)
                    │        │        │        │
               FD6288Q   FD6288Q   FD6288Q   FD6288Q    (3-ph gate drivers)
                    │        │        │        │
                 6×FET     6×FET     6×FET     6×FET     (24 MOSFETs total)
```

**Form factor reality check:** the H743 smallest package is TFBGA100 (8×8 mm), and 24 MOSFETs need 5×6 or 3.3×3.3 PQFN pads. On a 20×20 mm board this fits only as a stacked pair (FC + ESC). Section 3 shows that **80 A is a burst-only rating on a nano footprint**. Continuous capability is far lower.

## 2. Conduction Loss Model

### 2.1 Six-Step Complementary PWM

In any commutation sector, two phases carry current I_ph:
- **PWM phase:** the high side (HS) conducts for fraction D, and the synchronous low side conducts for (1−D).
- **Return phase:** the low side (LS) is on continuously.

$$
P_{cond,ESC} = I_{ph}^2 R_{ds}(T_j)\,[D + (1-D)] + I_{ph}^2 R_{ds}(T_j) = 2\,I_{ph}^2\,R_{ds}(T_j)
$$

With synchronous rectification, **conduction loss is independent of duty cycle**. Battery current, however, is I_bat ≈ D·I_ph. A "80 A ESC" rating should therefore specify phase current.

### 2.2 Temperature Dependence

$$
R_{ds}(T_j) = R_{ds(25)}\,[1+\alpha\,(T_j-25)]
$$

At T_j = 110 °C: R_ds = 1.2 mΩ × (1 + 0.0065 × 85) = **1.86 mΩ**

### 2.3 Copper Path Loss

Use 2 oz copper, effective phase path ≈ 0.25 mΩ, and a low-side shunt of 0.25 mΩ:

$$
P_{Cu+shunt} = I_{ph}^2 (R_{trace} + R_{shunt}\cdot k_{sh})
$$

The shunt conducts roughly 2/3 of the time. This gives 6400 × (0.25 + 0.17) mΩ ≈ **2.7 W**.

### 2.4 Results at 80 A, T_j = 110 °C

| Term | Per ESC | ×4 |
|---|---|---|
| MOSFET conduction: 2·I²·R_ds | 2 × 6400 × 1.86 mΩ = **23.8 W** | 95.2 W |
| Copper + shunt | 2.7 W | 10.8 W |

The positive feedback (higher T_j raises R_ds, which raises P) requires an iterative solve. This is covered in §4.3.
