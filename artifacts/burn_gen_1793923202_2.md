# STM32H743 Nano FC + 4-in-1 ESC: System Architecture & Mathematical Model

**Document:** Job #1, Rev A (engineering baseline)
**Scope:** Power-stage loss model (80 A burst), switching loss at f_sw = 48 kHz, transient thermal model, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

> **Note on the numbers:** All component parameters below are representative values for a modern 40 V, ~0.7 mΩ class MOSFET. Every equation is parameterized so you can substitute the datasheet values of the part you actually source. These figures are a design baseline and must be confirmed by bench measurement before release (see §7).

---

## 0. Architecture Decision

The H743 does **not** commutate the motors. Each motor channel needs its own commutation MCU running AM32 or BLHeli_32 (e.g., AT32F421 or STM32G071). The H743 sends DShot600 commands and receives eRPM telemetry over the bidirectional DShot line.

```
                ┌───────────────── FC (STM32H743VIT6) ─────────────────┐
 VBAT ─► ADC    │ TIM1_CH1..CH4 ─► DShot600 bidir ─► 4× ESC MCU         │
 ISENSE ─► ADC  │ SPI1/SPI4 IMUs, SDMMC1, UARTs, I2C baro/mag           │
                └───────────────────────────────────────────────────────┘
 ESC MCU (×4) ─► 3-ph gate driver (FD6288Q) ─► 6× N-MOSFET ─► motor
```

**Form-factor warning.** An 80 A-per-channel burst is about 320 A aggregate. A 20×20 mm "nano" board cannot carry this with acceptable copper loss or thermal mass. The baseline in this document is a **30.5×30.5 mm, 8-layer, 3 oz outer / 2 oz inner** ESC board stacked under a 20×20 FC. The model in §3 shows why.

## 2. Electrical Loss Model (per channel)

### 2.1 Conduction topology

Assume 6-step trapezoidal commutation with complementary (synchronous) PWM:

- **PWM on:** HS(x) and LS(y) conduct I.
- **PWM off:** LS(x) and LS(y) conduct I (synchronous freewheel; only dead time uses the body diode).

So at every instant **exactly two MOSFETs carry the phase current**, regardless of duty cycle D.

### 2.2 Ripple current

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}$$

The worst case is D = 0.5:

$$\Delta I = \frac{25.2 \times 0.25}{20\times10^{-6}\times 48\times10^{3}} = 6.56\ \text{A}_{pp}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.59 = 6403.6\ \text{A}^2$$

Ripple adds less than 0.06 % to conduction loss, so you can neglect it at this inductance. Recheck it for low-inductance motors (L < 8 µH).

### 2.3 Conduction loss

$$P_{cond} = 2\,I_{rms}^2\,R_{ds}(T_j)$$

| T_j | R_ds(T_j) | P_cond per channel |

| 25 °C | 0.70 mΩ | 8.96 W |
| 100 °C | 0.70·(373/298)^2.3 = 1.17 mΩ | 14.98 W |
| 125 °C | 1.32 mΩ | 16.90 W |
