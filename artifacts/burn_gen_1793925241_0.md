## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 14 poles (p = 7 pole pairs), 12 slots, R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor position | 14-bit absolute magnetic encoder per joint (e.g. AS5048/MA730) |
| Inverter | 3-phase, 2 low-side shunts, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera (inner) stage, SPI, ODR = 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

**Loop rates (all phase-locked to the PWM timer):**

```
PWM / current loop (FOC)  : 20 kHz   (Ts_i = 50 µs)   ISR, highest priority
Velocity loop             :  4 kHz   (every 5th current ISR)
IMU read + filtering      :  8 kHz   (DMA, data-ready IRQ)
Attitude fusion + angle   :  1 kHz
```

The bandwidths are separated by about 4–10× per cascade level:

```
ω_c ≈ 2π·1500 rad/s   (current)
ω_v ≈ 2π·150  rad/s   (velocity)
ω_p ≈ 2π·30   rad/s   (angle)
```

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform** (θ_e = p·θ_m − θ_offset):

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Decoupling and Back-EMF Feedforward

Pole-zero cancellation of the R-L plant gives a first-order closed loop with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c\quad(\text{zero at } R/L)$$

The voltage commands are:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e \hat L\, i_d + \hat\omega_e\hat\lambda_m$$

The reference is i_d* = 0 (no field weakening is needed for a gimbal).

$$v_{d,\text{sat}}=\mathrm{clip}(v_d^*,\pm V_{\max}),\qquad v_{q,\text{sat}}=\mathrm{clip}\!\left(v_q^*,\pm\sqrt{V_{\max}^2-v_{d,\text{sat}}^2}\right)$$
