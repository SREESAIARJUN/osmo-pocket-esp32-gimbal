**Loop rates and bandwidths.** The rule is to separate bandwidths by at least 5× per cascade level.

```
 20 kHz  ── Current loop (FOC, PI d/q)          f_bw,i  ≈ 2.0 kHz
  4 kHz  ── Velocity loop (PI + cogging FF)     f_bw,ω  ≈ 150–250 Hz
  2 kHz  ── Angle loop (P/PD + rate FF)         f_bw,θ  ≈ 30–50 Hz
  8 kHz  ── IMU sample (FIFO)  → 4 kHz fused gyro → 1 kHz attitude (Mahony)
```

**Control topology for one axis:**

```
θ_ref ─►(+)─► C_θ(s) ─►(+)─► C_ω(s) ─►(+)─► i_q,ref ─► FOC current PI ─► SVPWM ─► Motor
        ▲-             ▲  ω_ff      ▲-       ▲  i_cog,ff (anti-cogging)
        │              │            │        │
   θ_cam (IMU attitude)│       ω_meas (fused gyro, frame-projected)
                       └──── ω_ref feedforward from setpoint derivative
```

Velocity feedback uses the **IMU gyro**, which measures camera inertial rate, the quantity to be stabilized. Angle feedback uses **IMU attitude**. The encoder is used for commutation, cogging compensation (which is a function of rotor angle), and joint-limit/kinematic mapping.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here θ_{m,0} is the encoder offset at which the d-axis aligns with phase A. It is found by injecting a d-axis voltage at θ_e = 0 and reading the encoder (§6, `calibrateOffset`).

### 1.2 Clarke Transform (Amplitude-Invariant, Balanced Currents)

$$i_\alpha = i_a, \qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 PMSM Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p\,\lambda_m\, i_q \;=\; K_t\, i_q \qquad (L_d \approx L_q \text{ for SPM gimbal motors})$$

### 1.5 Current PI with Decoupling and Back-EMF Feedforward

$$v_d^* = \underbrace{K_{p,i} e_d + K_{i,i}\!\int e_d}_{\text{PI}} - \omega_e L_q i_q$$
$$v_q^* = K_{p,i} e_q + K_{i,i}\!\int e_q + \omega_e L_d i_d + \omega_e\lambda_m$$
