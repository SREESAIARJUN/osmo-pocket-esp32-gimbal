# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification

I don't have the original specification for Job #9, so this design starts from the stated assumptions in Section 0. Change those parameters, and the gains in the code will be recomputed from them automatically.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.2 mH (phase), Kt ≈ 0.08 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2-phase low-side shunt, sampled at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, each on a separate SPI bus, both clocked from a shared 32 kHz CLKIN, ODR 8 kHz, ±250 dps /
