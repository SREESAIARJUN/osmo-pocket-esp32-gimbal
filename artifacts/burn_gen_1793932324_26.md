**Architecture clarification.** The STM32H743 does **not** commutate the motors. Each motor gets a dedicated ESC MCU running AM32 or BLHeli_32, e.g. AT32F421 or STM32G071. ## 1. Conduction Loss Model

### 1.1 Commutation topology
Assume trapezoidal 6-step with complementary (synchronous) PWM, which is the AM32 default. In any sector:
- **Leg A (PWM leg):** the high-side conducts for D·T, and the low-side synchronously rectifies for (1−D)·T.
- **Leg B (return leg):** the low-side is on for 100 % of the sector.
- **Leg C:** floating, used for back-EMF sensing.

With phase current I (ripple neglected; L_motor·f_sw is large enough that ΔI/I is under 10 %):

$$P_{cond,A} = I^2 R_{ds}(T_j)\,[D + (1-D)] = I^2 R_{ds}(T_j)$$
$$P_{cond,B} = I^2 R_{ds}(T_j)$$
$$\boxed{P_{cond,motor} = 2\,I^2\,R_{ds}(T_j)} \quad \text{(independent of D under sync rectification)}$$

Including ripple: replace I² with I_rms² = I² + ΔI²/12.

### 1.2 Temperature-dependent R_ds(on)
$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

This is coupled to the thermal model (§3), because T_j depends on P, which depends on R_ds(T_j). The fixed-point solution is:

$$T_j = T_{ref} + R_{th} \cdot I^2 R_{ds,25}[1+\alpha(T_j-25)]
\;\Rightarrow\;
T_j = \frac{T_{ref} + R_{th} I^2 R_{ds,25}(1-25\alpha)}{1 - \alpha R_{th} I^2 R_{ds,25}}$$

**Thermal runaway criterion:** the denominator must stay positive, so α·R_th·I²·R_ds,25 < 1.

For one FET at 80 A: I²R_ds,25 = 5.76 W, so α·R_th·5.76 < 1 requires R_th < 38.6 K/W. This is easily met, so no runaway occurs at the device level.

### 1.3 Numerical values @ 80 A
Iterating with the board temperature from §3 gives T_j ≈ 110 °C on the 100 %-on return FET, so R_ds = 0.9·(1 + 0.0045·85) = **1.24 mΩ**.
