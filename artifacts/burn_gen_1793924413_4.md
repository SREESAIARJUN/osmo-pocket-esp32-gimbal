## 0. Architecture Clarification and Feasibility Flags

Two points need to be settled before any modeling.

### 0.1 The H743 is the flight controller, not the ESC controller

The H743 runs ArduPilot and generates bi-directional DShot600. Each motor still needs its own commutation MCU running 48 kHz complementary PWM. Typical choices are the AT32F421 or STM32G071 running AM32.

A single H743 running both ArduPilot and 4× FOC/6-step commutation is not supported by ArduPilot. It would also violate the DShot interface the brief requires.

```
VBAT ──┬── 4× [ESC MCU + 3× half-bridge] ──► M1..M4
       │         ▲ DShot600 bidir (1 wire/motor)
       └── 5V/9V BEC ──► STM32H743 (ArduPilot)
```

### 0.2 "Nano" form factor vs. 80 A burst

- **20×20 mm:** 80 A per motor (4×80 A) is physically impossible on this footprint. There is not enough copper cross-section or thermal mass, as Section 3 shows.
- **30.5×30.5 mm:** I model this footprint with 8-layer, 2 oz copper.
- **Burst limit:** Even at 30.5×30.5, 80 A on all four motors is a burst of a few seconds, not a continuous rating. Section 3.4 quantifies this.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous commutation

In any 60° sector, phase A is PWM'd and phase B low-side is held on:

- **PWM on-time (D):** current flows Q_AH → motor → Q_BL.
- **PWM off-time (1−D):** current flows Q_AL (synchronous rectification) → motor → Q_BL.

Exactly **two FETs are in series at all times**, independent of D. Per motor:

$$P_{cond} = I_{rms}^2 \cdot 2R_{ds}(T_j)$$

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C, R_ds = 1.0 × 1.6 = **1.6 mΩ**.
