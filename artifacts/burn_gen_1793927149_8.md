# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original specification for Job #18, so this design uses typical gimbal hardware. Every assumption is collected in §0 and in one `constexpr` config block in the code. Replace those values with your actual motor, encoder, MCU and IMU-mounting data before tuning.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU), or similar |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 1.9 mH (phase), K_t ≈ 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis, SPI |
| Current sense | Two-phase low-side shunts, sampled at PWM center |
| IMU-A | ICM-42688-P on the **camera payload**. Primary attitude and rate sensor. |
| IMU-B | ICM-42688-P on the **base / handle**. Vibration reference and base-motion feedforward. |
| IMU ODR | 8 kHz, gyro ±1000 dps, accel ±8 g, on-chip AAF + notch enabled |

**Loop rates** (each loop should run at least 5–10× faster than the bandwidth of the loop outside it):

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (rate) | 4 kHz | ~150 Hz |
| Angle (attitude) | 1 kHz | ~25 Hz |
| IMU filtering | 8 kHz | n/a |
| Attitude estimation | 1 kHz | n/a |
