## 0. Architecture and Feasibility Findings

### 0.1 System architecture

The STM32H743 cannot be the commutation controller. ArduPilot does not run sensorless BLDC commutation, so the architecture is:

```
6S LiPo ──► Power stage ×4 (3-phase bridge, 6 FETs each = 24 FETs)
              ▲ gate drive
           ESC MCU ×4 (AT32F421-class, AM32 firmware)
              ▲ bidirectional DShot600 (one wire per motor)
           STM32H743 (ArduPilot) — TIM1 CH1–CH4
```
