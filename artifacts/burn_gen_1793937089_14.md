# STM32H743 Nano FC + 4-in-1 ESC (Job #53): 80 A Burst Electro-Thermal Model, 48 kHz Switching Losses, and ArduPilot Bi-Directional DShot600 DMA Allocation

## 0. Assumptions and Architecture Corrections

I don't have a Job #53 specification on file. I've built the model from explicit, stated assumptions. Every number below is parameterized so you can substitute your actual BOM values. Datasheet-dependent values are marked **[VERIFY]**.

**Architecture correction.** The STM32H743 cannot practically commutate 4 BLDC motors at 48 kHz while also running ArduPilot. Real designs, and this one, use the following split:

```
H743 (ArduPilot FC) ──DShot600 bidir (×4)──► 4× ESC MCU (AM32 / BLHeli_32-class, e.g. AT32F421 / STM32G071)
                                               └─► 3-phase gate driver ─► 6 N-FETs per motor (24 total)
```

The 48 kHz PWM, dead-time, and commutation run on the ESC MCUs. The H743 owns DShot generation, eRPM capture, and the harmonic notch.
