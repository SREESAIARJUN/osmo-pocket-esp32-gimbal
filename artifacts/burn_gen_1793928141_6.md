# STM32H743 Nano AIO Flight Controller with 4-in-1 ESC: 80 A Burst Power-Stage Model, 48 kHz Switching Analysis, and ArduPilot Bi-Directional DShot600 DMA Allocation

## 0. Architectural Assumptions

I don't have the original Job #26 spec, so the analysis rests on the assumptions below. Every equation is parametric, so you can substitute your actual BOM values.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | Use 16.8 V for 4S |
| Burst current | 80 A per motor phase (peak, ≤10 s) | Continuous rating to be derived |
| PWM frequency | 48 kHz, center-aligned, complementary (sync rectification) | |
| Commutation | 6-step trapezoidal, 2 phases active | Matches AM32 and BLHeli_32 behavior |
| MOSFET | 40 V N-ch, PDFN 3.3×3.3 or 5×6 | R_DS(on),25 = 1.0 mΩ max at V_GS = 10 V; Q_g = 60 nC; Q_gd = 12 nC; Q_rr = 60 nC; Q_oss = 80 nC; V_SD = 0.8 V |
| Gate driver | FD6288Q-class 3-phase half-bridge, about 1.0 A source / 1.5 A sink | |
| Dead time | 100 ns | |
| Board | 30.5 × 30.5 mm, 6-layer, 2 oz outer and 2 oz inner power planes | |

**Critical architectural point.** ArduPilot does not commutate motors. The STM32H743 runs ArduPilot and emits bi-directional DShot600. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32. Typical choices are an AT32F421, an STM32G071, or one MCU per pair of channels. The H743 never drives gate drivers directly. The design is therefore an AIO board with five MCUs, or an H743 FC stacked over a 4-in-1 ESC.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\left[1 + \alpha\,(T_j - 25)\right], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 1.00 mΩ |
| 100 °C | 1.34 mΩ |
| 125 °C | 1.45 mΩ |
| 150 °C | 1.56 mΩ |

### 1.2 Current path in a 6-step sector (complementary PWM)

In each sector, phase A is driven by PWM and phase B low-side is held on.

- **During the D interval:** current flows through Q_AH and then Q_BL.
- **During the (1−D) interval:** current freewheels through Q_AL (synchronous) and then Q_BL.

$$P_{cond} = I_{rms}^2 R\,[D + (1-D)] + I_{rms}^2 R = 2\,I_{rms}^2\,R_{DS(on)}(T_j)$$

The result is independent of duty cycle. This is the key advantage of synchronous rectification.

### 1.3 Ripple contribution

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

The worst case is at D = 0.5. With L_LL = 30 µH:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{30\,\mu\text{H} \times 48\,\text{kHz}} = 4.4\ \text{A}$$

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 1.6 \approx 6401.6\ \text{A}^2$$

The ripple term is negligible, under 0.03%.

### 1.4 Result per channel at 80 A

| T_j | P_cond per channel |
|---|---|
| 25 °C | 2 × 6400 × 1.00 mΩ = **12.8 W** |
| 100 °C | 2 × 6400 × 1.34 mΩ = **17.2 W** |
| 125 °C | 2 × 6400 × 1.45 mΩ = **18.6 W** |

### 1.5 Additional copper and parasitic losses at 80 A, per channel

| Element | R | P = I²R |
|---|---|---|
| Phase pad and trace (2 oz, short) | 0.15 mΩ | 0.96 W |
| Shunt, if fitted (0.25 mΩ, on the total bus) | 0.25 mΩ | 1.6 W (shared) |
| Battery pad to FET bus planes | 0.10 mΩ | 0.64 W (shared) |

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate-driven transition times

Charge-based estimate:

$$t_r \approx \frac{Q_{gs2} + Q_{gd}}{I_{G,src}}, \qquad I_{G,src} = \frac{V_{DRV} - V_{plateau}}{R_{G,ext} + R_{G,int} + R_{drv}}$$

With V_DRV = 10 V, V_pl = 3.5 V, R_G,ext = 4.7 Ω, R_G,int = 1.2 Ω, and R_drv = 5 Ω:

- I_G ≈ 0.6 A
- Q_sw ≈ 17 nC
- t_r ≈ 28 ns and t_f ≈ 18 ns (faster sink), giving **t_r + t_f ≈ 46 ns**

### 2.2 Loss components, per channel (one hard-switched leg)

**(a) V–I overlap**

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 46\,\text{ns} \times 48\,\text{kHz} = \mathbf{2.23\ W}$$

**(b) Body-diode reverse recovery**

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 60\,\text{nC} \times 25.2 \times 48\,\text{k} = \mathbf{0.073\ W}$$

The real value is often 2–3× higher at high di/dt, so budget **0.2 W**.

**(c) Output capacitance**

$$P_{oss} = \tfrac12 Q_{oss} V_{bus} f_{sw} = 0.5 \times 80\,\text{nC} \times 25.2 \times 48\,\text{k} = \mathbf{0.048\ W}$$
