## 0. Architecture Baseline and Assumptions

No public specification exists for "Job #34," so this document fixes a reference design. All numbers flow from the parameter table in §0.2. Substitute your actual MOSFET datasheet values and every result will propagate.

### 0.1 System Architecture

The STM32H743 does **not** drive the MOSFETs directly. ArduPilot cannot run 6-step BLDC commutation, so the board is partitioned like this:

```
                ┌──────────────────────── 30.5×30.5 mm AIO (or 20×20 "nano") ───────────────────────┐
 VBAT 6S ──┬──► │ Bulk C + TVS ──► 4× ESC power stages (3 half-bridges each = 24 MOSFETs)             │
           │    │                    ▲ gate drive                                                      │
           │    │  4× ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32, fPWM = 48 kHz)                 │
           │    │                    ▲ bidirectional DShot600 (1 wire per motor, open-drain style)    │
           │    │  STM32H743 @ 400/480 MHz running ArduPilot (TIM3/TIM5 or TIM1/TIM8 + DMA)            │
           └──► │  5 V / 9 V / 3.3 V BEC rails                                                          │
                └──────────────────────────────────────────────────────────────────────────────────────┘
```
