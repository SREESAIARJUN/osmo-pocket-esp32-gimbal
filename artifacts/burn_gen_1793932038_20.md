# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bidirectional DShot600 DMA Allocation

## 0. Scope and Baseline Assumptions

I have no prior project file for Job #25, so this document fixes a reference design. Every number is parameterized: substitute the selected MOSFET and driver datasheet values into the equations.

**Architecture.** The STM32H743 runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (e.g., AT32F421 or STM32G071 running AM32). The ESC MCUs generate the 48 kHz commutation PWM.

The H743 cannot practically drive 24 gates and do back-EMF sensing for four motors while running the flight stack. That is why the 48 kHz PWM lives on the ESC side and DShot lives on the FC side.
