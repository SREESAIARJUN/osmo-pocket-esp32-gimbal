## 1. FOC Current Loop (Inner, 20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** uses the transpose.

**SVPWM** uses min-max zero-sequence injection, which is equivalent to 7-segment SVPWM:

$$v_{a,b,c}^{*} = \text{invClarke}(v_\alpha,v_\beta),\quad v_0 = -\tfrac12(\max + \min),\quad d_x = \tfrac12 + \frac{v_x^{*}+v_0}{V_{dc}}$$

The linear range is |v_αβ| ≤ V_dc/√3. The voltage vector is circularly limited to that radius.

### 1.2 Plant and PI design (pole-zero cancellation)

The dq model of an SPM motor is:

$$L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q,\qquad L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e\lambda_m$$

Use a PI controller C(s) = K_p + K_i/s with:

$$K_p = \omega_c L,\qquad K_i = \omega_c R \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/20 ≈ 2π·1 kHz.

**Decoupling plus back-EMF feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

**Delay compensation.** Sampling plus PWM update adds about 1.5 T_s of delay. Use θₑ + 1.5·T_s·ωₑ for the inverse Park only.
