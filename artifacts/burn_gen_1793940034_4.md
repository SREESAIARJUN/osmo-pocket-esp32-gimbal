# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

I don't have the specific parameters for Job #14. The design below uses typical values for a camera gimbal, and every value is a named constant you can replace. **Section 0 lists the assumptions to check first.**

## 0. Baseline Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G4 / H7, single-precision FPU | Any Cortex-M4F/M7 works. |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH | Example: GBM2804H-100T. |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) | Read by SPI each PWM period. |
| Current sense | 2- or 3-shunt, low-side, synchronized to PWM center | A voltage-mode fallback is given in §2.6. |
| PWM | 20 kHz, center-aligned | |
| Loop rates | Current 20 kHz · Rate (velocity) 4 kHz · Attitude 1 kHz | |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, ±2000 dps, ±16 g | |
| Cogging period | LCM(12, 14) = 84 cycles per mechanical rev | |

## 1. Control Architecture

```
               camera frame (IMU)                         joint frame (encoder)
 q_ref ──►[Attitude P + FF]──ω_cam_ref──►[J⁻¹(q)]──q̇_ref──►[Rate PI]──τ_ref──►(÷Kt)──i_q_ref
              ▲                                   ▲            ▲                       │
         q̂_cam (dual-IMU AHRS)            ω̂_cam (fused gyro)   │            + i_q_ff (anti-cog)
                                                               │                       ▼
                                                     encoder PLL ω̂_m        [Current PI + decoupling]
                                                                                       │
                                                                       inv-Park → SVPWM → inverter
```
