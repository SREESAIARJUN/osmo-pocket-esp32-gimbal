## 0. System Architecture Clarification

The STM32H743 does **not** drive the MOSFETs. In every viable 4-in-1 design:

```
                 ┌────────────── FC (STM32H743, ArduPilot) ──────────────┐
 IMU/Baro/OSD ──►│ TIM3_CH3/CH4, TIM5_CH1/CH2 → bidir DShot600 (1 wire/ESC)│
                 └──────┬──────────┬──────────┬──────────┬───────────────┘
                     M1 │       M2 │       M3 │       M4 │   (3.3 V, single-wire, half-duplex)
                 ┌──────▼──┐ ┌─────▼───┐ ┌────▼────┐ ┌───▼─────┐
                 │ESC MCU 1│ │ESC MCU 2│ │ESC MCU 3│ │ESC MCU 4│  AT32F421 / STM32G071 (AM32/BLHeli_32)
                 │ 48kHz PWM│ │         │ │         │ │         │
                 └────┬────┘ └────┬────┘ └────┬────┘ └────┬────┘
                   FD6288Q     FD6288Q     FD6288Q     FD6288Q    3-ph gate drivers
                   6×MOSFET    6×MOSFET    6×MOSFET    6×MOSFET   24 FETs total
```

The 48 kHz switching frequency is set in the **ESC firmware**. ArduPilot only sets the DShot command rate.
