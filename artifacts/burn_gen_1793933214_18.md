# STM32H743 Nano FC + 4-in-1 ESC (Job #14): Design Model

## 0. Architecture Constraints

Three facts shape the rest of the model.

1. **The H743 is the flight controller, not the ESC.** ArduPilot runs on the H743 and generates bidirectional DShot600. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32 (AT32F421 / STM32G071 class) and a 3-phase gate driver. ArduPilot cannot commutate motors. So "48 kHz switching" is an ESC-firmware PWM setting, not an H743 timer.
2. **80 A burst per channel on a 20×20 mm "nano" stack is not thermally sustainable.** It is survivable only for about 1–3 s. Section 3 quantifies this. Treat 80 A as a time-limited burst rating with firmware enforcement, not a continuous rating. If the requirement really means 80 A, a 30.5×30.5 mm ESC is the realistic platform.
3. **The netlist below is a reference topology**, not a release-ready production netlist. Part numbers are representative. Every value marked ⚠ must be checked against your chosen MOSFET and driver datasheets.

## 1. Conduction Loss Model

**Temperature-dependent on-resistance**

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 100 °C: R_ds = 1.2 × 1.45 = **1.74 mΩ**

**Per-motor conduction loss**

In 6-step with synchronous rectification, exactly one high-side path and one low-side path carry the phase current at every instant. Complementary freewheeling only moves the current between FETs; it does not reduce the conducting count.

$$P_{cond,motor} = 2\,I^2 R_{ds}(T_j) = 2(80)^2(1.74\,\text{m}\Omega) = \mathbf{22.3\ W}$$

**Per-FET average loss** (6 FETs share the load over one electrical cycle)

$$P_{cond,FET} = \frac{I^2 R_{ds}}{3} = \mathbf{3.7\ W}$$

**PCB copper loss**

- Sheet resistance of 2 oz (70 µm) copper: R_□ = ρ/t = 1.72×10⁻⁸ / 70×10⁻⁶ = 0.246 mΩ/□, rising to about 0.32 mΩ/□ at 100 °C.
- For a path of about 4 squares on 3 paralleled layers: R_pcb ≈ 0.43 mΩ.
- Loss: P_pcb = I² R_pcb ≈ **2.7 W per motor**.

**Self-heating feedback loop**

R_ds rises with T_j, which raises P, which raises T_j. Solve iteratively:

$$T_j^{(n+1)} = T_a + \theta_{ja}\, P\!\left(T_j^{(n)}\right)$$

This iteration converges only if:

$$\theta_{ja} \cdot \frac{\partial P}{\partial T_j} = \theta_{ja} \cdot \frac{I^2 R_{25}\,\alpha}{3} < 1$$

At 80 A that derivative is 0.0154 W/K per FET. With a board-level θ around 40 K/W per FET, the loop gain is 0.6, so it converges, but slowly and to a destructive temperature (see Section 3).

## 2. Switching Loss Model at 48 kHz

Only one half-bridge per motor is PWM-switching at a time.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw = 0.5·25.2·80·30 ns·48 k | 1.45 W |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 k | 0.05 W |
| C_oss | ½·Q_oss·V·f_sw | 0.02 W |
| Dead-time diode | V_f·I·2·t_dt·f_sw = 0.8·80·200 ns·48 k | 0.61 W |
| Gate drive (2 FETs) | 2·Q_g·V_gs·f_sw | 0.04 W |
| **Total per motor** | | **≈ 2.2 W** |
