# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have a spec sheet for Job #31, so the design is parameterized. The defaults below are typical for a camera gimbal. Replace every `constexpr` in the code with your measured values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with FPU, C++17, no heap |
| Current sensing | 2-shunt inline or low-side. A voltage-mode fallback is given for boards without it. |
