## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 or H7 class, with single-precision FPU and CORDIC (optional) |
| Motor | Gimbal BLDC, 12 slots / 14 poles (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A or MT6701), read every current-loop cycle |
| Current sensing | Low-side or inline shunts, sampled at PWM center |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (÷5) |
| Angle loop | 1 kHz (÷20) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz, FIFO or DRDY driven |
| Disturbances | Propeller vibration 80–400 Hz (drone), motor electrical harmonics, structural modes |

### Signal flow per axis

```
            1 kHz                   4 kHz                         20 kHz
θ_ref ─►(+)─► Angle PD ─► ω_ref ─►(+)─► Velocity PI ─► i_q* ─►(+)─► Current PI (d,q) ─► SVPWM ─► Motor
        ▲  (+ω_ff)                ▲                      ▲  ▲
        │                         │        i_q,cog_ff ───┘  │ i_q,ff = J·α_ref/K_t
   θ_cam (attitude from     ω_cam·axis (inertial rate,
   fused dual IMU)          notch + LPF filtered)
                                                     Encoder ─► θ_e ─► Park/Clarke
                                                     Encoder ─► PLL ─► ω_m (for cogging LUT phase, FOC)
```

Stabilization feedback is **inertial**: the camera IMU supplies the rate and attitude. The encoder is used for commutation, cogging phase and the joint-angle limits. This is the key structural difference between a gimbal and a servo.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

Clarke transform, with $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with $\theta_e = p\,\theta_m - \theta_{\text{offset}}$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Angle delay compensation.** The PWM update takes effect about 1.5 periods after sampling, so the electrical angle is advanced:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 Plant and PI design

The machine equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Choose the PI zero to cancel the electrical pole $R/L$:

$$C(s) = K_p + \frac{K_i}{s},\quad K_p = L\,\omega_c,\quad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$
