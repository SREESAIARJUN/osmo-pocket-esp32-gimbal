# STM32H743 Nano FC + 4-in-1 ESC (Job #44): System Architecture and Mathematical Model

## 0. Architectural Corrections Before Modeling

Three requirements as stated would produce a non-functional or unsafe design. The models below rest on these corrections.

| Issue | Problem | Resolution |
|---|---|---|
| **H743 does not commutate motors** | ArduPilot on the H743 *sends* DShot600 and *receives* telemetry. The 48 kHz PWM and commutation run on per-motor ESC MCUs (AM32 / BLHeli_32). | 4× AT32F421K8U7 (or STM32G071) ESC MCUs running AM32. The H743 is the master. |
| **"Nano" + 80 A + H743** | The H743 is LQFP100 (14×14 mm) or TFBGA100/240. 24 power FETs plus an H743 cannot fit 20×20 mm, and 20×20 copper cannot sink 80 A×4 even briefly. | Two-board stack at 30.5×30.5 mm: FC on top, ESC below. 80 A is a **≤10 s per-motor burst**, not continuous. |
| **"80 A" definition** | Ambiguous between battery and phase current. | Defined as **phase RMS current per motor**. Battery current is I_bat = D·I_phase. |

**Assumed operating point:** 6S (25.2 V max), f_sw = 48 kHz, complementary PWM with synchronous rectification, 6-step trapezoidal drive.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.006\ \mathrm{K^{-1}}$$

### 1.2 Current path in 6-step with synchronous rectification

In each 60° sector, exactly two FETs carry phase current at any instant:

- one in the PWM leg (high-side during D, low-side during 1−D);
- one static low-side in the return leg.

$$P_{cond,motor} = I_{ph}^2\left[D\,R_{HS} + (1-D)\,R_{LS} + R_{LS}\right] = 2\,I_{ph}^2\,R_{DS}(T_j)$$

This holds when R_HS = R_LS, and is then independent of D.

Add PCB and solder-joint resistance (R_pcb ≈ 0.3 mΩ per phase path, 2 oz inner + 3 oz outer):

$$P_{cond,motor} = I_{ph}^2\,\left[2R_{DS}(T_j) + R_{pcb}\right]$$

### 1.3 Self-consistent solution at 80 A

The equation is iterative because T_j depends on loss.

| Iteration | T_j assumed | R_DS | P_cond/motor |
|---|---|---|---|
| 0 | 25 °C | 1.20 mΩ | 6400·(2.40+0.30)e-3 = **17.3 W** |
| 1 | 90 °C | 1.67 mΩ | 6400·(3.34+0.30)e-3 = **23.3 W** |
| 2 | 110 °C | 1.81 mΩ | 6400·(3.62+0.30)e-3 = **25.1 W** |
| 3 (converged) | ~115 °C | 1.85 mΩ | **≈25.6 W** |

Each FET conducts on average one-third of the electrical cycle. The per-FET average is 25.6/6 ≈ **4.3 W**, with instantaneous peaks of ~6.3 W per FET.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches (one complementary pair per sector).

### 2.1 V–I overlap (hard-switched edge)

Gate driver: FD6288Q class, I_source ≈ 1.0 A, I_sink ≈ 1.5 A, with R_g = 4.7 Ω external.

$$t_r \approx \frac{Q_{gd}}{I_{g,on}},\quad t_f \approx \frac{Q_{gd}}{I_{g,off}}$$

With the plateau-limited current and the external R_g, this gives t_r ≈ 22 ns and t_f ≈ 18 ns.

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(40\,\mathrm{ns})(48\,\mathrm{kHz}) = \mathbf{1.94\ W}$$

### 2.2 Dead-time body-diode conduction (two dead-times per period, t_dt = 100 ns)

$$P_{dt} = V_{SD}\,I_{ph}\,(2t_{dt})\,f_{sw} = 0.8\cdot80\cdot200\,\mathrm{ns}\cdot48\,\mathrm{k} = \mathbf{0.61\ W}$$
