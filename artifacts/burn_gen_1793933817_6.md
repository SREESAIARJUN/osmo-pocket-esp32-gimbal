## 1. Field-Oriented Control (inner current loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, using electrical angle θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** uses a delay-compensated angle. PWM is applied about 1.5 sample periods after the ADC sample, so:

$$\theta_e^{*} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 Plant and current PI design

The PMSM d/q model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With cross-coupling and back-EMF feedforward,

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m),\qquad \lambda_m = \tfrac{2K_t}{3p},$$

each axis reduces to the first-order plant 1/(Ls + R). A PI controller C(s) = K_p + K_i/s with pole-zero cancellation gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{20}\;(\approx 2\pi\cdot 1\,\text{kHz at }20\,\text{kHz})$$

**Saturation.** Voltage is limited to the SVPWM linear region:

$$|v_{dq}| \le V_{bus}/\sqrt3$$

The d-axis has priority, and v_q gets the remaining margin:

$$v_{q,max}=\sqrt{V_{max}^2 - v_d^2}$$

**Anti-windup** uses back-calculation with K_aw = K_i/K_p:

$$\dot x_I = K_i e + K_{aw}(v_{sat}-v_{unsat})$$

### 1.3 SVPWM (min-max zero-sequence injection)

This is equivalent to 7-segment SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta_m) - \tau_{fric}(\omega) - \tau_{dist}$$

For gimbal stabilization, the **feedback signals come from the camera IMU**, projected onto each joint axis:
- **Velocity feedback:** the fused gyro rate, mapped into joint space through the inverse gimbal Jacobian (§2.4).
- **Angle feedback:** attitude error from the Mahony filter (§4.5), mapped the same way.
- **Encoder:** used for commutation (θ_e) and cogging compensation (θ_m) only.
