# Job #20: 3-Axis Gimbal FOC Control and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #20 spec, so the design uses the typical brushless camera-gimbal configuration below. Every value is a `constexpr` or a parameter in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | GBM2804-class, 12N14P, so pole pairs p = 7. R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.045 N·m/A |
| Encoders | 14-bit magnetic (MT6701 / AS5048A), one per joint |
| Current sensing | 2-shunt (inline or low-side), sampled at the PWM center |
| IMU A | ICM-42688-P on the camera plate. Used for attitude feedback. |
| IMU B | ICM-42688-P on the base/handle. Used for disturbance feedforward and as the vibration reference. |
| Joint order | Yaw (outer, base side) → Roll → Pitch (inner, camera side) |

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Electrical angle

With encoder offset θ₀ found at alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Sample-delay compensation: the PWM update lands about 1.5 Tₛ after sampling, so advance the angle:

$$\hat\theta_e = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
