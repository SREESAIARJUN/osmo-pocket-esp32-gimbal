## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder per joint (e.g. AS5048/MT6701), read at 20 kHz |
| Inverter | 3-phase, V_dc = 12–16 V, centre-aligned PWM at 20 kHz, inline current sense |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz, shared CLKIN |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

Loop rates follow a ≥5× bandwidth-separation rule:

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | ≈ 1.5 kHz |
| IMU acquisition, filtering, fusion | 8 kHz | (filters) |
| Velocity (gyro-rate PI + D) | 4 kHz | ≈ 80–150 Hz |
| Angle (attitude P/PI) | 1 kHz | ≈ 15–30 Hz |
| Anti-cogging adaptation | 4 kHz (gated) | ≪ 1 Hz (learning) |

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

With mechanical angle θ_m from the encoder, pole pairs p, and calibrated electrical offset θ_0:

$$\theta_e = \big(p\,\theta_m - \theta_0\big) \bmod 2\pi, \qquad \omega_e = p\,\omega_m$$

**Calibrating θ_0:** apply V_d = V_cal at θ_e = 0 open-loop, let the rotor settle, read θ_m, and set θ_0 = p θ_m mod 2π. Repeat in both directions and average to cancel friction.

### 1.2 Clarke transform (amplitude-invariant, balanced phases)

$$i_\alpha = i_a, \qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
