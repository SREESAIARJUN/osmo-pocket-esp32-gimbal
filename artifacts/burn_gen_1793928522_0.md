## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (GM4108-class): 12N14P, so pole pairs p = 7 and slots Ns = 12 |
| Phase parameters | R ≈ 10 Ω, L ≈ 4 mH (phase-to-neutral), Kt ≈ 0.18 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) over SPI, one per axis |
| MCU | STM32G474 @ 170 MHz with FPU and CORDIC; center-aligned PWM; low-side shunt ADC triggered at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, each on its own SPI bus, ODR 8 kHz, hardware AAF enabled |
| Gimbal order | Yaw (outer), Roll (middle), Pitch (inner) |

### Loop timing

| Loop | Rate | Ts | Bandwidth target |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1.5 kHz |
| IMU fusion and gyro filtering | 8 kHz | 125 µs | n/a |
| Velocity (camera-rate) | 4 kHz | 250 µs | ω_v ≈ 2π·120 Hz |
| Angle / attitude | 1 kHz | 1 ms | ω_p ≈ 2π·20 Hz |

Each loop's bandwidth is set at least 5× below the loop inside it. With that separation, the inner loop can be treated as unity gain when designing the outer loop.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{\text{off}})\big)$$

θ_off is found at commissioning: inject i_d = I_align at θ_e = 0, let the rotor settle, and record θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model and current PI tuning

The motor voltage equations in the rotating frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Adding decoupling and back-EMF feedforward to the PI outputs:

$$v_d^* = \text{PI}_d(e_d) - \hat\omega_e \hat L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

reduces each axis to the first-order plant 1/(Ls+R).

Choosing the PI zero to cancel the plant pole (pole-zero cancellation) gives:

$$K_p = \hat L\,\omega_c,\qquad K_i = \hat R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

### 1.5 Discrete PI with anti-windup

The PI uses forward Euler with back-calculation anti-windup:

$$\begin{aligned}
u_k &= K_p e_k + I_k\\
\bar u_k &= \text{sat}(u_k)\\
I_{k+1} &= I_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big],\quad K_{aw}\approx K_i/K_p
\end{aligned}$$
