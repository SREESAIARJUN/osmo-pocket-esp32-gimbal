# FOC Control, Anti-Cogging, and Dual-IMU Fusion for a 3-Axis Gimbal

"Job #2" isn't defined here, so the design below rests on explicit assumptions (Section 0). Every hardware-dependent number is a parameter, so you can substitute your own values.

---

## 0. Assumed Platform

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU |
| Motors | 3 × gimbal BLDC, e.g. GM4108H: 24 slots (N_s), 22 poles (p = 11 pole pairs), R ≈ 10 Ω, L ≈ 4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sensing | 2 or 3 low-side shunts per motor |
| IMU A | ICM-42688-P on the camera plate. Used for feedback. |
| IMU B | ICM-42688-P on the frame/handle. Used as the vibration reference and for disturbance feedforward. |
| Joint order (base→camera) | Yaw (z) → Roll (x) → Pitch (y) |
| Loop rates | Current/FOC 20 kHz · IMU sampling and filtering 8 kHz · inertial rate loop 4 kHz · attitude loop 1 kHz |

**The cascade:**

```
q_ref ─► [Attitude P] ─► ω_cmd ─► J⁻¹ ─► [Rate PI + FF] ─► τ ─► ÷Kt ─► i_q* ─► [FOC PI] ─► SVPWM
             ▲                      ▲                        + cogging FF
         q̂ (Mahony)            ω_gyro (filtered, LMS-cleaned)
```
