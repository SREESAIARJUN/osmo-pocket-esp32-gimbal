# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #13): Architecture, Loss Model, Thermal Analysis, and DShot DMA Plan

## 0. Feasibility Findings

Three findings shape the rest of this document.

1. **The STM32H743 cannot be the ESC commutation MCU.** ArduPilot does not run BLDC commutation, and per-motor commutation at 48 kHz requires dedicated firmware. The correct topology is:
   - The **H743 runs ArduPilot** and emits bidirectional DShot600.
   - **Four ESC MCUs run AM32 firmware.** The AT32F421K8U7 is a common choice and supports 48 kHz complementary PWM.
   - Each ESC MCU drives a **triple half-bridge gate driver**, which drives **6 MOSFETs per motor**.
2. **"80 A burst per channel" on a nano board is thermally adiabatic, not steady-state.** Section 3 shows roughly 115 W of heat at 4×80 A. On a 30.5 mm board this allows about **4–5 s** from 40 °C to a 125 °C board limit, with no meaningful steady state. Specify the rating as "80 A / 5 s burst, ≤35 A continuous with airflow."
