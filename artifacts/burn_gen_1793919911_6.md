# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Derivation (Job #67)

This document covers the electrothermal loss model at 80 A burst, the switching-loss model at 48 kHz, the ArduPilot bidirectional DShot600 timer and DMA plan, the reference netlists, and the thermal verdict.

**Read this first: three architectural facts that shape everything below**

1. **The H743 does not commutate the motors.** A 4-in-1 ESC has its own per-motor MCUs (or one quad-capable MCU) running AM32 or BLHeli_32-class firmware. The H743 runs ArduPilot and *sends* DShot600 to the ESC MCUs. The 48 kHz switching frequency is an ESC-firmware setting (AM32 supports 24/48/96 kHz), not an H743 function.
2. **80 A per motor on a nano-class board is a thermal edge case, not a continuous rating.** The math below shows why. Treat 80 A as a *seconds-scale burst* figure. It must be validated by thermocouple or IR test before it goes on a spec sheet.
3. **Every device parameter below is labeled ASSUMED.** These are representative values for a 40 V, ~1 mΩ PDFN5×6 MOSFET class. Substitute the actual datasheet values for your selected parts, because the model is parametric for exactly this reason.

## 2. Conduction Loss Model

### 2.1 Current path in six-step with synchronous rectification

In each 60° sector, one phase is "high" (PWM), one is "low" (LS fully on), and one floats.

- **High phase:** HS conducts for fraction D; the complementary LS conducts for (1−D).
- **Low phase:** LS conducts 100%.

The instantaneous conduction loss per motor is therefore:

$$
P_{cond,motor} = I^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{DS}(T_j)
$$

This result is **independent of duty cycle.** Two R_DS(on) are always in the current path.

### 2.2 Temperature dependence

$$
R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]
$$

At T_j = 115 °C: R_DS = 1.0 × (1 + 0.0055 × 90) ≈ **1.50 mΩ**.

### 2.3 Per-motor conduction loss at 80 A

$$
P_{cond,motor} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}
$$

### 2.4 Per-FET distribution (averaged over one electrical cycle)

Each phase spends 120° as "high", 120° as "low", and 60° floating.

$$
P_{HS} = \frac{D}{3} I^2 R \qquad P_{LS} = \frac{(1-D) + 1}{3} I^2 R
$$
