# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the original Job #3 specification. This design therefore rests on the explicit assumptions in §0. Each parameter is isolated so you can substitute your real values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU, 170 MHz) |
| Motors | Gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s≈5\,\Omega$, $L_s≈2\,\text{mH}$, $K_t≈0.08\,\text{N·m/A}$ |
| Encoders | 14-bit absolute magnetic sensor per axis (MT6701/AS5048A) |
| Current sense | 2-phase low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted at $\pm\mathbf r$ about the plate centroid, on separate SPI buses |
| Kinematic chain | base → **y
