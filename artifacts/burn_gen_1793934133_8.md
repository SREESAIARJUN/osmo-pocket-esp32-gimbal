## 1. System Architecture

```
            ┌─────────────── 1 kHz ───────────────┐ ┌──── 4 kHz ────┐ ┌──── 20 kHz ────┐
 θ_ref ──►(+)─► Angle P + ω_ff ─► J⁻¹ map ─►(+)─► Velocity PI ─►(+)─► iq_ref ─► Current PI ─► SVPWM ─► Motor
          ▲-                                ▲-                   ▲+ (cogging FF)      ▲ id,iq
          │ attitude (Mahony)               │ ω_gyro (filtered)  │ τ_cog(θm)/Kt       │ Clarke/Park
          │                                 │                    │                    │
   Dual ICM-42688-P ─► AAF ─► Adaptive notch ×2 ─► Biquad LPF ─► Fusion ◄──── encoder θm (PLL)
```

The control structure has three layers:

* **Inner loop:** field-oriented current control.
* **Middle loop:** velocity control, using the filtered IMU gyro projected onto the motor axes.
* **Outer loop:** angle control on the fused attitude.

The rule of thumb for the cascade is that each outer loop's bandwidth should be at most one-fifth of the inner loop's bandwidth.

## 2. Field-Oriented Control (20 kHz)

### 2.1 Coordinate transforms

The electrical angle comes from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

where $p$ is the number of pole pairs.

**Clarke transform** (amplitude-invariant, 2-shunt, using $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 Plant model (SPMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The electromagnetic torque is:

$$\tau_e = \tfrac{3}{2} p \lambda_m i_q \equiv K_t\, i_q$$

### 2.3 Current PI with decoupling and back-EMF feedforward

**Pole-zero cancellation tuning.** Choose a closed-loop current bandwidth $\omega_c$ (for example $2\pi \cdot 1.5$ kHz, which is below $f_{\text{PWM}}/10$). Then set:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$
