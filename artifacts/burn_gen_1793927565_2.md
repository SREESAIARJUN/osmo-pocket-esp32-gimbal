# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions and Target Platform

I don't have the Job #44 specification sheet, so this design uses typical values for a camera gimbal. Every assumption is a single named constant in the code (§9.1). Re-derive the gains (§3.4) once the real plant numbers are measured.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class (FPU, 170–480 MHz), one MCU per axis or one for all three |
| Motor | 12N14P gimbal BLDC (GBM2804-class), pole pairs `p = 7`, R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Payload | Inertia about each axis J ≈ 2–6×10⁻⁴ kg·m² |
| PWM / current loop | 20 kHz center-aligned PWM; current loop 20 kHz |
| Velocity loop | 4 kHz |
| Angle / attitude loop | 1 kHz |
| IMU A (payload) | ICM-42688-P on the camera plate. Primary attitude sensor. ODR 8 kHz, decimated to 4 kHz |
| IMU B (base) | ICM-42688-P on the gimbal base/handle. Gives the base-rate feedforward and the vibration reference for adaptive cancellation |

Bandwidths are separated by at least 5× so each inner loop looks like unity gain to the loop outside it:

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_θ ≈ 2π·20 rad/s

## 2. Field-Oriented Control (Inner Current Loop)

### 2.1 Transforms

**Electrical angle** (θ_m is mechanical angle; θ_off is calibrated at alignment):

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude invariant; assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
