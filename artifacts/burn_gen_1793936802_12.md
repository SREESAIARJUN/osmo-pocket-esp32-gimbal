# STM32H743 Flight Controller + 80 A 4-in-1 ESC (Job #78): System Architecture, Loss Model, DShot DMA Plan, and Netlists

> **Scope and assumptions.** This is a design baseline built on stated, representative component parameters. Every number marked **[A]** is an assumption. Replace each one with datasheet values from your chosen parts, then validate on hardware with thermocouples or an IR camera and a dyno before release. Two architectural points come first because they change the math:
>
> 1. **The H743 does not generate the 48 kHz PWM.** In a standard FC + 4-in-1 stack, the H743 runs ArduPilot and sends **DShot600** to four ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32/Bluejay). The ESC MCUs generate the 48 kHz complementary PWM. Switching-loss parameters belong to the ESC firmware configuration, not ArduPilot.
> 2. **"80 A burst" means 80 A DC per motor channel for ≤10 s.** The analysis shows this is achievable on one or two channels but **thermally capacity-limited to about 3–5 s when all four channels burst simultaneously** on a 30×30 board without a heatsink. Specify "nano" accordingly.

## 3. Conduction Loss Model

### 3.1 Current path
With complementary PWM in six-step, current always flows through **exactly two FETs** of the conducting phase pair:
- During the on-time D: HS(phase A) + LS(phase B).
- During the off-time (1−D): LS(phase A, synchronous rectifier) + LS(phase B).

The conduction loss is therefore independent of D, apart from dead-time diode conduction, which is treated separately in §4.4.

### 3.2 RMS current including ripple
Phase-current ripple at 48 kHz:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{pp}\,f_{sw}}$$

The worst case is at D = 0.5:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{20\times10^{-6}\times 48\times10^{3}} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.59 = 6403.6\ \text{A}^2$$

The ripple contributes +0.06 %, which is negligible. This is a benefit of 48 kHz: at 24 kHz the ripple term would be 4× larger, which is still small. The real cost of higher f_sw appears in §4.
