## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 24N22P (p = 11 pole pairs), R ≈ 5.6 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| MCU | Cortex-M4F/M7/G4 with single-precision FPU, center-aligned PWM, synchronous ADC |
| IMUs | 2 × ICM-42688-P on the camera payload, both on SPI, gyro ODR 8 kHz |
| Bus | 12–16 V |

**Loop rates**

```
 20 kHz  : Current loop (FOC)  ← ADC phase currents, encoder angle
  4 kHz  : Velocity loop       ← fused gyro rate projected on joint axis (+ encoder PLL)
  1 kHz  : Angle/attitude loop ← quaternion attitude (Mahony) → joint-space error
  8 kHz  : IMU sampling, filtering, fusion
```

**Cascade structure (per axis)**

```
θ_ref ─►(+)─► P/PI_angle ─► ω_ref ─►(+)─► PI_vel ─► i_q,fb ─►(+)─► PI_id/iq ─► v_dq ─► invPark ─► SVPWM
        ▲−                          ▲−          ▲   i_q,cog(θ) ─┘ ▲−
        θ_meas (IMU attitude)       ω_meas (gyro·axis)              i_dq (Clarke/Park)
                                    ω_ref·J/Kt·s (accel FF) ────────┘
```

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset).

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupling

The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

where λₘ = Kt/(1.5p) for the amplitude-invariant transform.

The decoupling and back-EMF feedforward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$
