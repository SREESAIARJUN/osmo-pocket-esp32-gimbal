# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion (Job #10)

This design covers the full chain:

1. Field-oriented current control.
2. Cascaded angle → velocity → current control.
3. Anti-cogging harmonic feedforward with online learning.
4. Dual ICM-42688-P vibration rejection and attitude fusion.
5. Complete C++17 implementation.

## 0. Baseline Assumptions

The "Job #10" spec was not provided, so the values below are typical for a camera gimbal. Every value is a single constant in the code, so substitute your actual hardware parameters.

| Item | Value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), one per axis or one for all three |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt = 0.08 N·m/A |
| Driver | 3-phase, V_bus = 12 V, 20 kHz center-aligned PWM, 2-shunt low-side sensing |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI, read every current-loop tick |
| IMUs | 2 × ICM-42688-P on the **payload plate**, diametrically opposite the payload center of mass |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz · IMU ODR 8 kHz |

The **bandwidth hierarchy** is chosen so each loop is at least 4–5× faster than the loop outside it:

$$\omega_{c,i}=2\pi\cdot 1500,\quad \omega_{c,v}=2\pi\cdot 120,\quad \omega_{c,\theta}=2\pi\cdot 25 \ \text{rad/s}$$
