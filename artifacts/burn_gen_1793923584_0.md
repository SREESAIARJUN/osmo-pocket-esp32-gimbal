I don't have the original Job #59 hardware sheet, so this design uses the **assumed baseline** below. Every gain is derived from symbolic plant parameters, so you can substitute your measured values without changing the structure.

## 1. Architecture

```
            1 kHz                     4 kHz                    20 kHz
 q_ref ─► [Attitude/Angle PID] ─ω_ref─► [Velocity PI] ─iq*─► [Current PI dq] ─► SVPWM ─► Motor
             ▲      │ ω_ff ────────────────▲              ▲ iq_cog (anti-cogging FF)
             │      └─────────────────────────────────────┘
   Dual ICM-42688 ─► AAF ─► notch bank ─► LPF ─► consistency/fusion ─► Mahony AHRS
   Encoder ─► θ_m, θ_e ─► PLL velocity observer ──────────► (velocity + cogging phase)
```

The loops are separated in bandwidth by roughly 5–10× each:

- current ≈ 2 kHz
- velocity ≈ 150–250 Hz
- angle ≈ 20–40 Hz

## 2. Field-Oriented Control (inner current loop, Ts = 50 µs)

### 2.1 Transforms

Electrical angle from the mechanical encoder:

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant and decoupled PI

Motor model in the dq frame (ω_e = p ω_m, λ = flux linkage):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda$$

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda$$

What remains is a first-order plant 1/(Ls+R). Pole-zero cancellation with target bandwidth ω_c gives:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c \quad(\text{closed loop} = \tfrac{\omega_c}{s+\omega_c})$$

With ω_c = 2π·2000 rad/s: Kp ≈ 27.6 V/A and Ki ≈ 70 400 V/(A·s).

Discrete PI with back-calculation anti-windup:

$$e_k = i^*_k - i_k$$
$$u_k = K_p e_k + I_k + v^{ff}_k$$
$$\bar u_k = \text{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k),\qquad K_{aw}\approx \tfrac{K_i}{K_p}T_s$$

### 2.3 Voltage limiting and SVPWM

Vector limit, with priority given to the d-axis:

$$|v_{dq}| \le \tfrac{V_{bus}}{\sqrt3}$$
$$v_q^{max} = \sqrt{(V_{bus}/\sqrt3)^2 - v_d^2}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Min-max (zero-sequence injection) SVPWM, equivalent to sector-based SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 2.4 Delay compensation

PWM update plus sampling introduce about 1.5·Ts of delay. Advance the angle used in the inverse Park transform by:

$$\theta_e^{pwm} = \theta_e + 1.5\,T_s\,\omega_e$$

## 3. Encoder Velocity Observer (PLL)

Raw differentiation of a 14-bit encoder at 4 kHz gives about ±1.5 rad/s of quantisation noise, so a type-2 PLL is used instead:

$$e_\theta = \text{wrap}(\theta_{meas} - \hat\theta)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_{i}^{pll} T_s e_\theta$$
$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_p^{pll} e_\theta)$$

The gains follow from a critically damped design with natural frequency ω_n:

$$K_p^{pll} = 2\zeta\omega_n,\qquad K_i^{pll} = \omega_n^2,\qquad \zeta = 1$$

Use ω_n ≈ 2π·400 Hz, which is above the velocity-loop bandwidth.

## 4. Cascaded Velocity / Angle Control

### 4.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Treat the current loop as approximately unity gain. The velocity plant is then:

$$P_\omega(s) = \frac{K_t}{Js + B}$$

### 4.2 Velocity PI (Ts = 250 µs)

The design targets crossover ω_v with PI zero ω_v/4, giving about 60° of phase margin before delay:

$$K_p^{\omega} = \frac{J\,\omega_v}{K_t},\qquad K_i^{\omega} = K_p^{\omega}\frac{\omega_v}{4}$$
